# 袁可嘉
原：袁可嘉一九二一年生，浙江慈溪人。一九四六年毕业于昆明西南联大外文系。一九五○年至一九五六年间，历任中共中央宣传部毛泽东选集英译室、外文出版社翻译。现任中国社会科学院外国文学研究所副研究员。中国作家协会会员。著有诗歌数十篇，诗论十万字，介绍评论英美诗歌和西方现代派文学的文章四十多篇。译本有《米列诗选》(1957,新文艺出版社)、《彭斯诗选》(1959，上海文艺出版社)、《英国宪章派诗选》(1960,人民文学出版社)、《试论独创性作品》(1963,人民文学出版社)和《美国歌谣选》(付印中)等。并负责编辑《现代英美资产阶级文艺理论文选》(1962,作家出版社)和《外国现代派作品》(1980,上海文艺出版社)。目前正从事《西方现代派文学研究》一书的撰写工作，并在中国社会科学院研究生院任教。一九八年九月应邀赴美讲学，并担任美国艺术科学院全国人文中心研究员一年。

# 沉钟
原：让我沉默于时空，
原：如古寺锈绿的洪钟，
原：负驮三千载沉重，
原：听窗外风雨匆匆；
原：把波澜掷给大海，
原：把无垠还诸苍穹，
原：我是沉寂的洪钟，
原：沉寂如蓝色凝冻；
原：生命脱蒂于苦痛，
原：苦痛任死寂煎烘，
原：我是锈绿的洪钟，
原：收容八方的野风！
原：一九四六年
原：选自《文艺复兴》二卷一期

# 岁暮
原：庭院中秃枝点黑于暮鸦，
原：(一点黑，一分重量)
原：禿枝颤颤垂下；
原：墙里外遍地枯叶逐风沙，
原：(掠过去，沙沙作响)
原：挂不住，又落下；
原：暮霭里盏盏灯火唤归家，
原：(山外青山海外海)
原：鸟有巢，人有家；
原：多少张脸庞贴窗问路人：
原：(车破岭呢船破水?)
原：等远客？等雪花？
原：一九四六年
原：选自《诗抄》

# 空
原：水包我用一片柔，
原：湿淋淋浑身浸透，
原：垂枝吻我风来搂，
原：我底船呢，旗呢，我底手？
原：我底手能掌握多少潮涌，
原：学小贝壳水磨得玲珑？
原：晨潮晚汐穿一犀灵空，
原：好收容海啸山崩？
原：小贝壳取形于波纹，
原：铸空灵为透明，
原：我乃自溺在无色的深沉，
原：夜惊于尘世自己底足音。
原：一九四六年
原：选自《文艺复兴》二卷一期

# 冬夜
原：冬夜的城市空虚得失去重心，
原：街道伸展如爪牙勉力捺定城门；
原：为远距离打标点，炮声砰砰，
原：急剧跳动如犯罪的良心；
原：谣言从四面八方赶来，
原：像乡下大姑娘进城赶庙会，
原：大红大绿披一身色彩，
原：招招摇摇也不问你爱不爱；
原：说忧伤也真忧伤，
原：狗多梦，人多沮丧，
原：想多了，人就若痴若呆地张望，
原：活像开在三层楼上的玻璃窗；
原：身边天边确都无以安慰，
原：这阵子人见面都叹见鬼；
原：阿狗阿毛都像临危者抓空气，
原：东一把，西一把，却越抓越稀。
原：这儿争时间无异争空间，
原：聪明人却都不爱走直线；
原：东西两座圆城门伏地如括弧，
原：括尽无耻，荒唐与欺骗；
原：起初觉得来往的行人个个不同，
原：像每一户人家墙上的时辰钟；
原：猛然发现他们竟一如时钟的类似，
原：上紧发条就滴滴答答过日子；
原：测字摊要为我定终身，
原：十字架决定于方向夹时辰；
原：老先生，我真感动于你的天真，
原：测人者怎不曾测准自己的命运？
原：商店伙计的手势拥一海距离，
原：“我只是看看”，读书人沉得住气；
原：十分自谦里倒也真觉希奇，
原：走过半条街，这几文钱简直用不出去；
原：哭笑不得想学无线电撒谎，
原：但撒谎者有撒谎者的哀伤；
原：夜深心沉，也就不想再说什么，
原：恍惚听见隔池的青蛙叫得真寂寞。
原：一九四七年
原：选自《文学杂志》二卷三期

# 进城
原：走进城就走进了沙漠，
原：空虚比喧哗更响；
原：每一声叫卖后有窟窿飞落，
原：熙熙攘攘真挤得荒涼：
原：踏上街如踏上轻气球，
原：电线柱也带花花公子的轻浮；
原：街上车，车上人，人上花，
原：不真实恰似“春季廉价”的广告画；
原：无线电里歌声升起又升起，
原：叫人想起黄浦滩畔的大出丧，
原：空洞乏味如官定纪念烈士的假期，
原：滑稽得一样令逝者心伤；
原：转过身，三轮车夫打量你的脚步，
原：你只好低头打量腳踢起的尘土，
原：“啊，我如今真落得无地自处！”
原：两旁树叶齐声喊：“呜呼！呜呼！”
原：一九四七年
原：选自《文学杂志》二卷三期

# 上海
原：不问多少人预言它的陆沉，
原：说它每年都要下陷几寸，
原：新的建筑仍如魔掌般上伸，
原：攫取属于地面的阳光、水分
原：而撒落魔影。贪婪在高空进行；
原：一场绝望的战争扯响了电话铃，
原：陈列窗的数字如一串错乱的神经，
原：散布地面的是饥馑群真空的眼睛。
原：到处是不平。日子可过得轻盈，
原：从办公房到酒吧间铺一条单轨线，
原：人们花十小时赚钱，花十小时荒淫。
原：绅士们捧着大肚子走进写字间，
原：迎面是打字小姐红色的呵欠，
原：拿张报，遮住脸：等待南京的谣言。
原：一九四八年
原：选自《中国新诗》第二期

# 南京
原：一梦三十年，醒来到处是敌视的眼睛，
原：手忙脚乱里忘了自己是真正的仇敌；
原：满天飞舞是大潮前红色的蜻蜓，
原：怪来怪去怪别人：第三期的自卑结。
原：总以为手中握着一支高压线，
原：一已的喜怒便足以控制人间，
原：讨你喜欢，四面八方都负责欺骗，
原：不骗你的便被你当作反动、叛变。
原：官员满街走，开会领薪俸，
原：乱在自己，戡向人家，手持德律风，
原：向叛逆的四方发出训令：四大皆空。
原：糊涂虫看着你觉得心疼，
原：精神病学家断定你发了疯，
原：华盛顿摸摸钱袋：好个无底洞！
原：一九四八年
原：选自《中国新诗》第二期

# 旅店
原：对于贴近身边的无所祈求，
原：你的眼睛永远注视着远方；
原：风来过，雨来过，你要伸手抢救
原：远方的慌乱，黑夜的徬徨；
原：你一手接过来城市村庄，
原：拼拼凑凑够你编一张地图，
原：图形多变，不变的是深夜一星灯光，
原：和投奔而来的同一种痛苦；
原：我们惭愧总辜负你的好意，
原：不安像警铃响彻四方的天空，
原：无情的现实迫我们匆匆来去，
原：留下的不过是一串又一串梦。
原：一九四八年
原：选自《文学杂志》三卷二期

# 难民
原：要拯救你们必先毁灭你们，
原：这是实际政治的传统秘密；
原：死也好，活也好，都只是为了别的，
原：逃难却成了你们的世代专业；
原：太多的信任把你们拖到城市，
原：向贪婪者求乞原是一种讽刺；
原：饥饿的疯狂掩不住本质的诚恳，
原：慧黠者却轻轻把诚恳变作资本；
原：像脚下的土地，你们是必需的多余，
原：重重的存在只为轻轻的死去；
原：深恨现实，你们缺乏必需的语言，
原：到死也说不明白这被人作弄的苦难。
原：一九四八年
原：选自《文学杂志》三卷二期

# 航
原：航行者离开陆地而怀念陆地，
原：送行的视线如纤线在后追踪，
原：人们恐怕从来都不曾想起，
原：一个多奇妙的时刻：分散又集中。
原：年青的闭上眼描摹远方的面孔，
原：远行的开始担心身边的积蓄；
原：老年人不安地看看钟，听听风，
原：普遍泛滥的是绿得像海的忧郁；
原：只有小孩们了解大海的欢跃，
原：破坏以驯顺对抗风浪的嘱咐，
原：船像摇篮，喜悦得令人惶惑；
原：大海迎接人们以不安的国度：
原：像被移植空中的断枝残叶，
原：航行者夜夜梦着绿色的泥土。
原：一九四八年
原：选自《文学杂志》三卷二期

# 母亲
原：迎上门来堆一脸感激，
原：仿佛我的到来是太多的赐予；
原：探问旅途如顽童探问奇迹，
原：一双老花眼总充满疑惧；
原：从不提自己，五十年谦虚，
原：超越恩怨，你建立绝对的良心；
原：多少次我担心你在这人世寂寞，
原：紧挨你的却是全人类的母亲。
原：面对你我觉得下坠的空虚，
原：像狂士在佛像前失去自信；
原：书名人名如残叶掠空而去，
原：见了你才恍然于根本的根本。
原：一九四八年
原：选自《文学杂志》三卷二期

# 墓碑
原：愿这诗是我底墓碑，
原：当生命熟透为尘埃；
原：当名字收拾起全存在，
原：独自看墓上花落花开；
原：说这人自远处走来，
原：这儿他只来过一回；
原：刚才卷一包山水，
原：去死底窗口望海！
原：一九四六年
原：选自《人间世》
