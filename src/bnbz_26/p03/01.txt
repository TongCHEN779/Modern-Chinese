# 序
原：这本诗一个月前就交给了书店，本来这时就可以印好的，后来因为里面的两篇诗在内容上有点不合适，只好删去一篇，另一篇换一条尾巴，而被删的一篇那雄健的音节自己很爱，在序言中曾经特别提出过作为比《烙印》进步的证例，于今既然这样，序言不得不重写了。
原：回想《烙印》出世后的反响，使我印这第二本诗时感到了很大的不安！如果有人要问这本诗比第一本进步了多少，那真是不容易爽口回答的，对这，自己的心也仿佛做不了尺度似的。反正又不能这样解释：《烙印》是几年中作品选汰的结果，而这是最近期间成绩的总合。因为读者只知道看货色(那是应该的)，不能以时间的关系来原谅或是非难一个作品的。不过从这本诗里可以看出我的一个倾向来：在外形上想脱开过分的拘谨渐渐向博大雄健处走，这可以拿《罪恶的黑手》做例子，虽然这篇诗的技巧上缺陷还很多。还有《答客问》的音节自己也感到欢喜。内容方面，竭力想抛开个人的坚忍主义而向着实际着眼，但结果还是没有摆脱得净。
原：我是乡下人，生性爱乡村，所以写来也还算地道，不过在这里面的一些诗中我只划出了一个恐怖破碎的乡村的面孔，没能够指出一条出路来，许多限制使我只能这样。另外有一些小诗算是反映了时代的苦闷，然而是那样薄弱！我希望这个集子结束了我的短诗。老是这样写下去，自己不满意不必提，是会辜负多数希望着我的人们的。我已经下了最大的决心，最近的将来就要下工夫写长一点的叙事诗，好像叙事诗在我国还很少见，应该有人向这方面努力，老舍兄告诉我他已在开始著了。
原：这本诗的名字原想用《壮士心》的，后从广田之琳的意见改成了今名，是觉得这样好些。还有《都市的春天》也是听从了他俩才加进去的，他们诚恳的关心着我的东西，使我非常的感激和高兴。
原：二十三年六月二十二日离青前

# 盘
原：刻着各色的梦，寂灭了，
原：向你映一下空虚的眼，
原：像一粒无根的砂石，
原：挂不住万古的悬岸。
原：一个跌不死的希望，
原：不倒翁似的永不怕累，
原：硬撑住你跌倒，跌倒，
原：又爬起来的双腿。
原：日子过得没有骗人，
原：这你自己一定知道，
原：试试什么压住了心，
原：这么沈又这么牢靠。
原：总得抖一股劲朝前走，
原：像盘一座陡峭的山头，
原：爬过去就是平原，
原：心里无妨先存着个喜欢。
原：二二年

# 小婢女
原：她才认识了自己；
原：同时也认识了命运的铁脸，
原：是用了怎样的一股力量呵，
原：从十万匹马力贪玩的吸引里，
原：她严酷的牵回了
原：不满十个年头的心，
原：还有那条像株小树的身躯，
原：也不让它在游戏中滋长；
原：她紧张起生命的全力，
原：给白天，黑夜，一刻一刻的时间
原：深镌上辛苦的殷勤。
原：她真聪慧，
原：甚至聪慧得有点可怜了，
原：点化快乐的一双天真的眼睛，
原：现在却专用来测人的眉头了，
原：轻云样飘忽的孩子的笑，
原：淋漓无常的孩子的眼泪，
原：都不能从她腮边，眼中，
原：放情的舒卷与点滴了，
原：因为她什么都懂透了：
原：生活的意义，
原：卖身契上她的名字。
原：默默老挂在她嘴角上，
原：不，又将抱怨那个呢？
原：上帝造成了人，
原：该是一种可以感谢的恩德吧？
原：妈妈的心更是慈悲的，
原：生了她，于今又活了她，
原：她自己呢？情愿被咀嚼在
原：万里外故乡灾荒的大口里。
原：这小生命将活得很长很长，
原：好用一颗连记忆上
原：也寻不到一点快活的心，
原：去测人生最深的悲哀。
原：一九三三年夏

# 罪恶的黑手
原：罪恶的黑手在这都市的道旁，
原：划出一块大的空场，
原：在这空场的中心，
原：正在建一座大的教堂。
原：交横的木架比蛛网还密，
原：像用骷髅架起的天梯，
原：一万只手，几千颗心灵，
原：从白到黑在上面搏动。
原：这称起是压倒全市的一件神工，
原：无妨用想像先给它绘个图形：
原：“四面高墙隔绝了人间的罪恶，
原：里边的空气是一片静寞，
原：一根草，一株树，甚至树上的鸟，
原：只是生在圣地里也觉到骄傲。
原：大门顶上横一面伟大的十字架，
原：街上过路的人都走在它底下，
原：耶稣的圣像高高在千尺之上，
原：看来是怎样的伟大，慈祥！
原：他立在上帝与人世中间，
原：用无声的话传达主的教言：
原：奴隶们，什么都应该忍受，
原：饿死了也要低着头，
原：谁给你的左腮贴上耳光，
原：顶好连右腮也给送上，
原：忍辱原是至高的美德，
原：连心上也不许存一丝反抗！
原：人间的是非肉眼那能看清？
原：死过之后主自有公平的判定。
原：早晨的太阳先掠过这圣像，
原：从贵人的高楼再落到穷汉的屋上，
原：黄昏后，这四周严肃得叫人害怕，
原：神堂的影子像个魔鬼倒在地下。
原：早晨的钟声像个神咒，
原：(这钟声不同别处的钟声。)
原：牵来了一群杂色人等，
原：男女牧士们走在前面，
原：黑色的头巾佩着长衫，
原：微风吹着头巾飘荡，
原：仿佛罪恶在光天之下飞扬。
原：后面逐着些漂亮男子，
原：肥白的脸皮上挂着油丝，
原：脚步轻趋着，低声交语，
原：用心做了一脸肃穆。
原：还有一队女人缀在后边，
原：脂粉的香气散满了庭院，
原：一个用长臂挽着别个，
原：像一个花圈套一个花圈。
原：阳光像是主的爱，照着这群人，
原：也照着他们脚下的石阶，
原：钟声一阵暴雨的急响，
原：送他们进了神圣的教堂。
原：中间有的是刚放下了屠刀，
原：手上还留着血的腥臭；
原：有的是因为失掉了爱情，
原：来到这儿求些安宁；
原：有的在现世享福还嫌不够，
原：为来世的荣华到此苦修；
原：有的是宇宙伤了他多情的心，
原：来对着耶稣慰藉心神；
原：有的用过来眼看破了人生，
原：来求心上刹那的真诚；
原：有的不是来为了求恕，
原：不过为追逐一个少女。
原：虽是这些心的颜色全然异样，
原：然而他们统统跪下了，朝着上方。
原：牧士登在台上像威权临着这群众，
原：用灵巧的嘴，
原：用灵巧的手势，
原：讲着教义像讲着真理。
原：他叫人好好管束自己，
原：不要叫心做了叛逆，
原：他怕这空说没有力量，
原：又引了成套惩劝的旧例。
原：每次饭碗还没触着口，
原：感谢的歌声先颤在咽喉，
原：晚上每在上床之前，
原：先用祈祷来做个检点，
原：这功课在各人心上刻了板，
原：他们做来却无限新鲜。”
原：然而这一切，一切未来的繁华，
原：与脸前这一群工人无干，
原：他们在一条辛苦的铁鞭下，
原：只忙着去赶契约上的期间。
原：有的在几千尺之上投下只黑影，
原：冒着可怕的一低头的晕眩，
原：石灰的白雾迷了人形，
原：泥巴给人涂一身黑点，
原：铁锤下的火花像彗星向人扫射，
原：风挟着木屑直往鼻眼里钻。
原：这里终天奏着狂暴的音乐：
原：人声的叫喊，轧轧的起重机，
原：你听，这是多么高亢的歌！
原：大锯在木桩上奏着提琴，
原：节奏的铁砧扣着拍子，
原：这群工人在这极度的狂乐里，
原：活动着，手应着心，也极度的兴奋。
原：有的把巧思运入一方石条的花纹，
原：有的持一块木片仔细的端详，
原：有的把手底的砖块飞上半空，
原：有的用罪恶的黑手捏成耶稣慈悲的模样。
原：这群人从早晨背起太阳，
原：一天的汗雨泄尽了力量；
原：平地上，一万幕灯火闪着黄昏，
原：灯光下喘息着累倒了的心。
原：他们用土语放浪的调笑，
原：杂一些低级的诙谐来解疲劳，
原：各人口中抽一缕长烟，
原：烟丝中杂着深味的乡谈，
原：那是家乡场园上用消夏夜的，
原：永不嫌俗，一遍两遍，不怕一万遍，
原：于今在都市中他们也谈起来了，
原：谈起也想起了各人的家园。
原：他们一点也不明白为什么要盖这教堂，
原：却惊叹外洋人真是有钱，
原：同时也觉得说不出的感激，
原：有了这建筑他们才有了饭碗。
原：(虽然不像是为了吃饭才工作，
原：倒是像为了工作才吃饭。)
原：这大建筑把这大众从天边拉在一起，
原：陌生的全变成亲热的兄弟，
原：白天忙碌紧据在各人的心中，
原：没有闲暇去做思乡的梦，
原：黑夜的沉睡如同快活的死，
原：早晨醒来个奴隶的身子。
原：是什么造化，谁作的主，
原：生下他们来为了吃苦？
原：太阳的烤炙，风雨的浸淋，
原：铁色的身上生起片片的黑云，
原：机器的凶狞，铁石的压轧，
原：谁的体躯是金钢铸成？
原：室家的累赘，病魔的侵袭，
原：苦涩中模糊了无色的四季，
原：一阵头晕，或一点不小心，
原：坠下半空成一摊肉泥，
原：这真算不了什么希奇，
原：生死文书上勾去个名字；
原：然而他们什么都不抱怨，
原：只希望这工程的日期延长到无限。
原：不过天下的事谁敢保定准？
原：今日的叛逆也许是昨日的忠心，
原：谁料定大海上那刹起风暴？
原：万年的古井也说不定会涌起波涛！
原：等这群罪人饿瞎了眼睛，
原：认不出上帝也认不清真理，
原：狂烈的叫嚣如同沸水，
原：像地狱里奔出来一群魔鬼，
原：用蛮横的手撕碎了万年的积卷，
原：来一个无理性的反叛！
原：那时，这教堂会变成他们的食堂或是卧室，
原：他们创造了它终于为了自己，
原：那时这儿也有歌声，
原：不是神秘，不是耶稣的赞颂，
原：那是一种狂暴的嘻嚷，
原：太阳落到了罪人的头上。
原：九月五日全夜写强半，六日完成。
原：二二年于青岛

# 亮的影子
原：爬楼梯似在残冰上试探着迈步，
原：地板也像要逐步倾陷，
原：在这样旅舍的两页木板上，
原：每天晚上我大睁着寂寞的双眼。
原：间壁是一张沙漠的白纸，
原：不亮的灯光在上面开出个亮的影子。
原：是那么灵动，却全不自觉，
原：像一只神乌无心的飘过银河。
原：灵动的是那神秘的鬓影，
原：飘飘地，仿佛飘飘地要将人飞腾。
原：那矫挠的发辫，一条生力的鞭，
原：鞭破了这客夜的寂寞，寂寞的我的心境。
原：有时它也会定住，有意让我细细端详，
原：端详那转动的眼轮，腮边的笑蕊，嘴角上跳动的天真，
原：那静里的美。
原：我也听熟了，在深更里，
原：不稳的地板上那一串脚步的颤动，
原：接着，簇簇的影子来纸上翻腾，
原：那戏弄的情态丑得人睁不开眼，
原：我听到人家的调笑，她无知的打预。
原：过一刻，她的鼾声从我耳中响动，
原：这鼾声响出了她心的洁白，
原：这时，笑浪随著她落了潮，
原：剩一个妇人滴打的语丝，
原：像寒漏支持著这残更。
原：每晚，用变幻的姿态
原：这影子逗著我的眼睛，
原：我能够合起眼皮
原：用心给它剪一副有声的影。
原：今天晚上，夜丝丝的长了，
原：今天的夜也格外寂聊，
原：地板再不把一串声响打动我的倾听，
原：灯光给白纸留下了个老重的孤影，
原：深垂著头，只双手在微动，
原：我听到了声声断续的叮咚，
原：这不是凄咽的寒漏，是金声。
原：我看它眼里滴一条黑线，
原：我还听到叮咚掩不住的长叹。
原：二二年岁暮

# 壮士心
原：江庵的夜和着青灯残了，
原：壮士的梦正灿烂的开花，
原：枕着一卷兵书一支剑，
原：灯光开出了一头白发。
原：突然睁大了眼睛，战鼓在催他，
原：(深殿里木鱼一声又一声)
原：跨出门来，星斗恰是当年，
原：铁衣上响着塞北的朔风。
原：前面分明是万马奔腾，
原：他举起剑来嘶喊了一声，
原：从此不见壮士归来，
原：门前的江潮夜夜澎湃。
原：二三年一月十一日于青岛

# （无题）
原：我是平凡，心永远在泥土里开花，
原：再不去做那些荒唐的梦，
原：这世纪，魔鬼撕破了真理的面孔，
原：还给它捏造了无数的诡名，
原：思想，一条透明的南针，
原：永不回头，我朝着前进，
原：像一只大鹏掠过了苍空，
原：翅膀下透出来一串响声。
原：百炼的钢条铸成了我的骨头，
原：那么坚韧，又那么多的锋棱，
原：不受生活的贿赂去为它低头，
原：喧的大河是我的生命。
原：你相信风能撼摇铁的树头，
原：可是你更得相信我这个心！
原：(血肉可以给刀刃剁成烂泥，
原：然而骨子永远是我的！)
原：在这一片撒谎的日子里，
原：我给人间保留一丝天真，
原：我是热情，要用一勺沸水
原：去浇开宇宙的坚冰。
原：恐怖就让是六月的淫雨，
原：我却能估得透它的寿命，
原：并不胆怯，你看脸前那一列人影，
原：(无数的心在我的心上跳动)
原：我将提起喉咙高歌正义，
原：不做画眉愿做只天鸡。
原：二三年一月一四日

# 吊
原：像枯木的寒影，这凋零的一排，
原：你更给凋零扩大了空隙，
原：惬意的过去最怕上心来，
原：然而今夜，你叫我如何关紧记忆？
原：剥开守岁的心的年轮，
原：(你的和我的那青的一段)
原：一圈展不尽的笑纹—
原：罩上了一层永久的黯淡。
原：家人从今没了新岁，
原：蒙头睡过这元旦的早晨，
原：用一串最忌讳的眼泪，
原：滴穿了一万重迎心的欢欣。
原：黄河岸上，遥遥地
原：三千里外的天涯，
原：纵使生死不是异路，
原：一个没头鬼怕也难还家！
原：二十三年旧历元旦于故乡

# 元宵

原：没有风，什么都很平静，
原：家家门前的灯光
原：也亮得很稳，
原：彻夜的爆竹，把无数的欢心
原：开花到天上。
原：今夜，遥想枯瘠的乡村，
原：多少儿童
原：手把住大门，
原：望穿了一条黑巷，
原：大人合起感伤的眼睛，
原：一片荣华在脸前浮荡。
原：二三年元宵后数日于青岛

# 村夜
原：太阳刚落，
原：大人用恐怖的故事
原：把孩子关进了被窝，
原：(那个小心正梦想着
原：外面朦胧的树影
原：和无边的明月）
原：再捻小了灯，
原：强撑住万斤的眼皮，

# 无窗室
原：搬下来了，我搬下来了，
原：从那座摩天的石头楼上，
原：像一只黄鹂蹬开了乔木，
原：一头栖下了万丈的幽谷。
原：在楼头，我的心晒不上太阳，
原：望望海涛，我拍一下窒塞的胸膛，
原：我身边死钉着一个鬼影，
原：白天黑夜一点也不放松。
原：我闭上了这一扇门扉，
原：四壁一齐泄下了光辉，
原：一只黑手掏煞了世界，
原：在这里边我呼吸着自在。
原：二三年三月二二日于相州

# 答客问
原：我才从乡村里来，
原：这用不到我说一句话，
原：你只须望一望我的脸，
原：或向着我的衣襟嗅一下。
原：我很地道的知道那里的一切，
原：什么都知道，
原：像一个小孩子知道母亲一样，
原：他清楚她身上的那根汗毛长。
原：你要问什么？
原：问清明时节纷纷细雨中
原：长堤上那一行烟柳的蒙蒙？
原：还是夕阳下，春风里，
原：女颊映着桃花红？
原：问炎夏山涧沁出的清凉，
原：黄昏朦胧中蝙蝠傍着古寺飞翔？
原：还问什么？
原：问秋山的秀，
原：秋风里秋云的舒卷，
原：无边大野上残照的苍凉？
原：我知道你要问冬夜里那八遍鸡声，
原：一个老妪摇着纺车守一盏昏黄的小灯。
原：你要问这，这我全熟习，
原：可是我要告诉你的是另外的一些事。
原：你听了不要惊惶，也无须叹气，
原：那显得你是多么无知。
原：我告诉你，乡村的庄稼人
原：现在正紧紧腰带挨着春深，
原：他们并不会放松自家，
原：风里雨里把身子埋在坡下，
原：他们仍然撒种子到大地里，
原：可是已不似往常撒种也撒下希望，
原：单就叱牛的声音，
原：你就可以听出一个无劲的心！
原：他们工作，不再是唱呕呕的高兴，
原：解疲劳的烟缕上也冒不出轻松，
原：这可怪不得他们，一条身子逐着日月转，
原：到头来，三条肠子空着一条半！
原：八十老妪口中的故事，
原：已不是古代的英雄而是他们自己，
原：她说亲眼见过长毛作反，
原：可是这样的年头真头一回见！
原：凭着五谷换不出钱来，
原：不是闹兵就是闹水灾，
原：太阳一落就来了心惊，
原：头侧在枕上直听到五更，
原：饥荒像一阵暴烈的雨滴，
原：打得人心抬不起头来，
原：头顶的天空一样是发青，
原：然而乡村却失掉了平静。
原：二三年三月二二日于相州

# 民谣
原：刚才我从街头过，
原：听到一群村儿唱歌，
原：他们用手指着太阳，
原：脚跺着地，齐声高唱。
原：提到这支歌真叫人心惊，
原：曾使得一个暴君投身火坑，
原：今天它来得真也奇怪，
原：今天是一个什么世界？
原：二三年三月二四日于相州

# 生命的叫喊
原：高上去又跌下来，
原：这叫卖的呼声—
原：一支音标，沉浮着，
原：在测量这无底的五更。
原：深围无眠的心，将把这
原：做成诗意的幽韵？
原：不，这是生命的叫喊，
原：一声一口血，喊碎了这夜心。
原：二三年四月五日于相州

# 新年
原：真不容易，辛苦了三百六十天，
原：才熬到一个新年；
原：然而有了这一天，
原：三百六十日的辛苦全酿成了甘甜！
原：无分穷富，通把顶吉祥的话
原：写上了大红的迎春的新联，
原：古朴的山村，联文多颠倒了上下，
原：那关什么，新年怎么办都是吉祥，
原：为图吉利“有”字都是倒转，
原：牛栏猪栅也贴满了吉庆的字样，
原：忙年的人连起了日夜，
原：男女杂在一起，忙在手上，
原：口里的故事讲得却那么安闲，
原：老女人用最虔敬的心祈祷上天，
原：祈祷一件一件，
原：声音低微得只有上天才可以听见。
原：把年夜起身的方向，
原：开口的第一句话，
原：先牢牢的记好，
原：再把应该回避的弄个停当，
原：用草纸擦一下孩子的嘴，
原：再对神禀告：
原：小孩子无知的话权当是屁响。
原：夜来的爆竹从每个人心上响起，
原：(这时百神一齐下界，
原：没有一个心不是严肃！)
原：震散了一切的晦气，
原：迎来了一个元旦的旭日。
原：拜年的人们结成了队伍，
原：一队一队随处里发现，
原：刚从新装里辨出了人面，
原：老远送过来一声祝福，
原：深闺里的娇娃今天也把脸露给春风，
原：几世的仇敌也用了笑脸相迎，
原：街上，糖球杆子插成了树行，
原：孩子们包围成一条胡同，
原：赌博场中上下着一列头颅，
原：钱像水淌，桌面上一片响声。
原：是那个先圣订下了一些忌讳，
原：勤苦的人在这天也不敢做营生，
原：每个人心像一支漏，
原：迟迟的滴打着快意的安闲，
原：从多少世纪就这么下来，
原：一年的辛苦报答这一天。
原：今年的年头百事反常，
原：新年全没了往昔的景象，
原：虽是还用著古老的形式，
原：形式内剥尽了甘甜的赢！

原：小孩子的手头再不是那样大方，
原：大人们低着头哼一声就算是祝福，
原：接着是一声悠长的嗟叹！
原：是什么抓去了天下的人心？
原：看！大家用一脸愁对着元旦。
原：二三年四月十日于相州
