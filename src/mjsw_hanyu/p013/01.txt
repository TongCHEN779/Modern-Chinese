# 元日酬蔡州马十二尚书去年蔡州元日见寄之什
诗：元日新诗已去年，/蔡州遥寄荷相怜。/今朝纵有谁人领？/自是三峰不敢眠。

# 华山女
诗：街东街西讲佛经，/撞钟吹螺闹宫庭。/广张罪福资诱胁，/听众狎恰排浮萍。
诗：黄衣道士亦讲说，/座下寥落如明星。/华山女儿家奉道，/欲驱异教归仙灵。
诗：洗妆拭面著冠帔，/白咽红颊长眉青。/遂来升座演真诀，/观门不许人开扃。
诗：不知谁人暗相报，/訇然振动如雷霆。/扫除众寺人迹绝，/骅骝塞路连辐𫐌。
诗：观中人满坐观外，/后至无地无由听。/抽钗脱钏解环佩，/堆金叠玉光青荧。
诗：天门贵人传诏召，/六宫愿识师颜形。/玉皇颔首许归去，/乘龙驾鹤来青冥。
诗：豪家少年岂知道，/来绕百匝脚不停。/云窗雾阁事慌惚，/重重翠幔深金屏。
诗：仙梯难攀俗缘重，/浪凭青鸟通丁宁。

# 左迁至蓝关示侄孙湘
诗：一封朝奏九重天，/夕贬潮州路八千。/欲为圣明除弊事，/肯将衰朽惜残年。
诗：云横秦岭家何在？/雪拥蓝关马不前。/知汝远来应有意，/好收吾骨瘴江边。

# 武关西逢配流吐蕃
诗：嗟尔戎人莫惨然，/湖南地近保生全。/我今罪重无归望，/直去长安路八千。

# 路傍堠
诗：堆堆路傍堠，/一双复一只。/迎我出秦关，/送我入楚泽。
诗：千以高山遮，/万以远水隔。/吾君勤听治，/照与日月敌。
诗：臣愚幸可哀，/臣罪庶可释。/何当迎送归，/缘路高历历。

# 次邓州界
诗：潮阳南去倍长沙，/恋阙那堪又忆家。/心讶愁来惟贮火，/眼知别后自添花。
诗：商颜暮雪逢人少，/邓鄙春泥见驿赊。/早晚王师收海岳，/普将雷雨发萌芽。

# 食曲河驿
诗：晨及曲河驿，/凄然自伤情。/群乌巢庭树，/乳雀飞檐楹。
诗：而我抱重罪，/子子万里程。/亲戚顿乖角，/图史弃纵横。
诗：下负朋义重，/上孤朝命荣。/杀身谅无补，/何用答生成？

# 过南阳
诗：南阳郭门外，/桑下麦青青。/行子去未已，/春鸠鸣不停。
诗：秦商邈既远，/湖海浩将经。/孰忍生以戚？/吾其寄余龄。

# 题楚昭王庙
诗：丘坟满自衣冠尽，/城阙连云草树荒。/犹有国人怀旧德，/一间茅屋祭昭王。

# 泷吏
诗：南行逾六旬，/始下昌乐泷。/险恶不可状，/船石相春撞。
诗：往问泷头吏，/潮州尚几里？/行当何时到？/土风复何似？
诗：泷吏垂手笑：/官何问之愚！/譬官居京邑，/何由知东吴？
诗：东吴游宦乡，/官知自有由。/潮州底处所？/有罪乃窜流。
诗：侬幸无负犯，/何由到而知？/官今行自到，/那遽妄问为？
诗：不虞卒见困，/汗出愧且骇。/吏曰聊戏官，/侬尝使往罢，
诗：岭南大抵同，/官去道苦辽。/下此三千里，/有州始名潮。
诗：恶溪瘴毒聚，/雷电常汹汹。/鳄鱼大于船，/牙眼怖杀侬。
诗：州南数十里，/有海无天地。/飓风有时作，/掀簸真差事。
诗：圣人于天下，/于物无不容。/比闻此州囚，/亦有生还侬。
诗：官无嫌此州，/固罪人所徙。/官当明时来，/事不待说委。
诗：官不自谨慎，/宜即引分往。/胡为此水边，/神色久傥慌？
诗：泷鲸大瓶罂小，/所任自有宜。/官何不自量，/满溢以取斯？
诗：工农虽小人，/事业各有守。/不知官在朝，/有益国家不？
诗：得无虱其间，/不武亦不文，/仁义饰其躬，/巧奸败群伦。
诗：叩头谢吏言：/始惭今更羞。/历官二十余，/国恩并未酬。
诗：凡吏之所诃，/嗟实颇有之。/不即金木诛，/敢不识恩私。
诗：潮州虽云远，/虽恶不可过。/于身实已多，/敢不持自贺。

# 题临泷寺
诗：不觉离家已五千，/仍将衰病入泷船。/潮阳未到吾能说，/海气昏昏水拍天。

# 晚次宣溪辱韶州张端公使君惠书叙别酬以绝句二章
诗：韶州南去接宣溪，/云水苍茫日向西。/客泪数行元自落，/鹧鸪休傍耳边啼。
诗：兼金那足比清文，/百首相随愧使君。/俱是岭南巡管内，/莫欺荒僻断知闻。

# 过始兴江口感怀
诗：忆作儿童随伯氏，/南来今只一身存。/目前百口还相逐，/旧事无人可共论。

# 赠别元十八协律六首
诗：知识久去眼，/吾行其既远。/瞢瞢莫訾省，/默默但寝饭。
诗：子兮何为者，/冠珮立宪宪。/何氏之从学，/兰蕙已满畹？
诗：于何玩其光，/以至岁向晚？/治惟尚和同，/无俟于謇謇。
诗：或师绝学贤，/不以艺自挽。/子兮独如何，/能自媚婉娩？
诗：金石出声音；/宫室发关楗。/何人识章甫，/而知骏蹄跪？
诗：惜乎吾无居，/不得留息偃。/临当背面时，/裁诗示缱绻。
诗：英英桂林伯，/实维文武特。/远劳从事贤，/来吊逐臣色。
诗：南裔多山海，/道里屡纡直。/风波无程期，/所忧动不测。
诗：子行诚艰难，/我去未穷极。/临别且何言？/有泪不可拭。
诗：吾友柳子厚，/其人艺且贤。/吾未识子时，/已览赠子篇。
诗：寤寐想风采，/于今已三年。/不意流窜路，/旬日同食眠。
诗：所闻昔已多，/所得今过前。/如何又须别，/使我抱悁悁？
诗：势要情所重，/排斥则埃尘。/骨肉未免然，/又况四海人？
诗：嶷嶷桂林伯，/矫矫义勇身。/生平所未识，/待我逾交亲。
诗：遗我数幅书，/继以药物珍；/药物防瘴疠，/书劝养形神。
诗：不知四罪地，/岂有再起辰？/穷途致感激，/肝胆还轮困。
诗：读书患不多，/思义患不明，/患足已不学，/既学患不行。
诗：子今四美具，/实大华亦荣。/王官不可阙，/未宜后诸生。
诗：嗟我摈南海，/无由助飞鸣。
诗：寄书龙城守，/君骥何时秣？/峡山逢飓风，/雷电助撞摔。
诗：乘潮簸扶胥，/近岸指一发，/两岩虽云牢，/术石乐飞发。
诗：屯门虽云高，/亦映波浪没。/余罪不足惜，/子生未宜忽。
诗：胡为不忍别？/感谢情至骨。

# 初南食贻元十八协律
诗：鲎实如惠文，/骨眼相负行。/蚝相黏为山，/百十各自生。
诗：蒲鱼尾如蛇，/口眼不相营。/蛤即是虾蟆，/同实浪异名。
诗：章举马甲柱，/斗以怪自呈。/其余数十种，/莫不可叹惊。
诗：我来御魑魅，/自宜味南烹。/调以咸与酸，/笔以椒与橙。
诗：腥臊始发越，/咀吞面汗骍。/惟蛇旧所识，/实惮口眼狞。
诗：开笼听其去，/郁屈尚不平。/卖尔非我罪，/不屠岂非情。
诗：不祈灵珠报，/幸无嫌怨并。/聊歌以记之，/又以告同行。

# 宿曾江口示侄孙湘二首
诗：云昏水奔流，/天水漭相围。/三江灭无口，/其谁识涯圻？
诗：暮宿投民村，/高处水半扉。/犬鸡俱上屋，/不复走与飞。
诗：篙舟入其家，/暝闻屋中唏。/问知岁常然，/哀此为生微。
诗：海风吹寒晴，/波扬众星辉。/仰视北斗高，/不知路所归。
诗：舟行亡故道，/屈曲高林间。/林间无所有，/奔流但潺潺。
诗：嗟我亦拙谋，/致身落南蛮。/茫然失所诣，/无路何能还？

# 答柳柳州食虾蟆
诗：虾蟆虽水居，/水特变形貌。/强号为蛙蛤，/于实无所校。
诗：虽然两股长，/其奈脊皴疱。/跳踯虽云高，/意不离泞淖。
诗：鸣声相呼和，/无理只取闹。/周公所不堪，/洒灰垂典教。
诗：我弃愁海滨，/恒愿眠不觉。/叵堪明类多，/沸耳作惊爆。
诗：端能败笙磬，/仍工乱学校。/虽蒙勾践礼，/竟不闻报效。
诗：大战元鼎年，/孰强孰败桡？/居然当鼎味，/岂不辱钓罩？
诗：余初不下喉，/近亦能稍稍，/常惧染蛮夷，/失平生好乐。
诗：而君复何为，/甘食比豢豹？/猎较务同俗，/全身斯为孝。
诗：哀哉思虑深，/未见许回棹。

# 琴操十首并序
原：将归操
原：孔子之赵闻杀鸣犊作。
诗：狄之水兮，/其色幽幽。/我将济兮，/不得其由。
诗：涉其浅兮，/石啮我足。/乘其深兮，/龙入我舟。
诗：我济而悔兮，/将安归尤？/归兮归兮！/无与石斗兮，
诗：无应龙求。
原：猗兰操
原：孔子伤不逢时作。
诗：兰之猗猗，/扬扬其香。/不采而佩，/于兰何伤？
诗：今天之旋，/其曷为然？/我行四方，/以日以年。
诗：雪霜贸贸，/荠麦之茂。/子如不伤，/我不尔觏。
诗：荠麦之茂，/荠麦之有。/君子之伤，/君子之守。
原：龟山操
原：孔子以季桓子受齐女乐，谏不从，望龟山而作。
诗：龟之氛兮，/不能云雨。/龟之桩兮，/不中梁柱。
诗：龟之大兮，/只以奄鲁。/知将隳兮，/哀莫余伍。
诗：周公有鬼兮，/嗟归余辅。
原：越裳操
原：周公作。
诗：雨之施，/物以孳。/我何意于彼为？/自周之先，
诗：其艰其勤。/以有疆宇，/私我后人。/我祖在上，
诗：四方在下。/厥临孔威，/敢戏以侮。/孰荒于门？
诗：孰治于田？/四海既均，/越裳是臣。
原：拘幽操
原：文王美里作。
诗：目窈窈兮，/其凝其盲。/耳肃肃兮，/听不闻声。
诗：朝不日出兮，/夜不见月与星。/有知无知兮，/为死为生？
诗：呜呼！/臣罪当诛兮，/天王圣明。
原：岐山操
原：周公为太王作。
诗：我豳于家，/自我先公。/伊我承序，/敢有不同？
诗：今狄之人，/将土我疆。/民为我战，/谁使死伤？
诗：彼岐有岨，/我往独处。/尔莫余追，/无思我悲。
原：履霜操
原：尹吉甫子伯奇无罪，为后母谐而见逐，自伤作。
诗：父兮儿寒，/母兮儿饥。/儿罪当笞，/逐儿何为？
诗：儿在中野，/以宿以处。/四无人声，/谁与儿语？
诗：儿寒何衣？/儿饥何食？/儿行于野，/履霜以足。
诗：母生众儿，/有母怜之。/独无母怜，/儿宁不悲？
原：雉朝飞操
原：牧犊子七十无妻，见雉双飞，感之而作。
诗：雉之飞，/于朝日。/群雌孤雄，/意气横出。
诗：当东而西，/当啄而飞。/随飞随啄，/群雌粥粥。
诗：嗟我虽人，/曾不如彼雉。/生身七十年，/无一妾与妃。
原：别鹄操
原：商陵穆子娶妻五年无子，父母欲其改娶。其妻闻之，中夜悲啸。
诗：穆子感之而作。
诗：雄鹄衔枝来，/雌鹄啄泥归。/巢成不生子，/大义当乖离。
诗：江汉水之大，/鹄身鸟之微。/更无相逢日，/且可绕树相随飞。
原：残形操
原：曾子梦见一狸不见其首作。
诗：有兽维狸兮，/我梦得之。/其身孔明兮，/而头不知。
诗：吉凶何为兮，/觉坐而思。/巫咸上天兮，/识者其谁。

# 量移袁州张韶州端公以诗相贺因酬之
诗：明时远逐事何如？/遇赦移官罪未除。/北望讵令随塞雁，/南迁才免葬江鱼。
诗：将经贵郡烦留客，/先惠高文起谢予。/暂欲系船韶石下，/上宾虞舜整冠裾。

# 别赵子
诗：我迁于揭阳，/君先揭阳居。/揭阳去京华，/其里万有余。
诗：不谓小郭中，/有子可与娱。/心平而行高，/两通《诗》与《书》。
诗：婆娑海水南，/簸弄明月珠。/及我迁宜春，/意欲携以俱。
诗：摆头笑且言，/我岂不足欤？/又奚为于北，/往来以纷如？
诗：海中诸山中，/幽子颇不无。/相期风涛观，/已久不可渝。
诗：又尝疑龙虾，/果谁雄牙须？/蚌赢鱼鳖虫，/瞿瞿以狙狙。
诗：识一已忘十，/大同细自殊。/欲一穷究之，/时岁屡谢除。
诗：今子南且北，/岂非亦有图？/人心未尝同，/不可一理区。
诗：宜各从所务，/未用相贤愚。
