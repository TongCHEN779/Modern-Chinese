# 东都遇春
诗：少年气真狂，/有意与春竞。/行逢二三月，/九州花相映。
诗：川原晓服鲜，/桃李晨妆靓。/荒乘不知疲，/醉死岂辞病。
诗：饮噉惟所便，/文章倚豪横。/尔来曾几时，/白发忽满镜。
诗：旧游喜乖张，/新辈足嘲评。/心肠一变化，/羞见时节盛。
诗：得闲无所作，/贵欲辞视听。/深居疑避仇，/默卧如当暝。
诗：朝曦入牖来，/鸟唤昏不醒。/为生鄙计算，/盐米告屡罄，
诗：坐疲都忘起，/冠侧懒复正。/幸蒙东都官，/获离机与穽。
诗：乖慵遭傲僻，/渐染生弊性。/既去焉能追，/有来犹莫聘。
诗：有船魏王池，/往往纵孤泳。/水容与天色，/此处皆绿净。
诗：岸树共纷披，/渚牙相纬经。/怀归苦不果，/即事取幽进。
诗：贪求匪名利，/所得亦已并。/悠悠度朝昏，/落落捐季孟。
诗：群公一何贤，/上戴天子圣。/谋谟收禹绩，/四面出雄劲。
诗：转输非不勤，/稽逋有军令，/在庭百执事，/奉职各祗敬。
诗：我独胡为哉？/坐与亿兆庆，/譬如笼中鸟，/仰给活性命。
诗：为诗告友生，/负愧终究竟。

# 感春五首
诗：辛夷高花最先开，/青天露坐始此回。/已呼孺人戛鸣瑟，/更遣稚子传清杯。
诗：选壮军兴不为用，/坐狂朝论无由陪。/如今到死得闲处，/还有诗赋歌康哉！
诗：洛阳东风几时来？/川波岸柳春全回。/宫门一锁不复启，/虽有九陌无尘埃。
诗：策马上桥朝日出，/楼阙赤白正崔嵬。/孤吟屡阕莫与和，/寸恨至短谁能裁？
诗：春田可耕时已催，/主师北讨何当回？/放车载草农事济。/战马苦饥谁念哉？
诗：蔡州纳节旧将死，/起居谏议联翩来。/朝廷未省有遗策，/肯不垂意缾与罍。
诗：前随杜尹拜表回，/笑言溢口何欢哈。/孔丞别我适临汝，/风骨峭峻遗尘埃。
诗：音容不接只隔夜，/凶讣讵可相寻来。/天公高居鬼神恶，/欲保性命诚难哉！
诗：辛夷花房忽全开，/将衰正盛须频来。/清晨辉辉烛霞日，/薄暮耿耿和烟埃。
诗：朝明夕暗已足叹，/况乃满地成摧颓。/迎繁送谢别有意，/谁肯留念少环回？

# 送郑十校理并序
原：秘书，御府也。天子犹以为外且运，不得朝夕视，始更聚书集贤殿，别置校雠宫，曰学士，曰校理，常以宠丞相为大学士。其他学士，皆达官也。校理则用天下之名而能文学者。苟在选，不计其秩次，惟所用之。由是集贤之书盛积，尽秘书所有，不能处其半。书日益多，官日益重。四年，郑生涵始以长安尉选授校理。人皆曰：是宰相子，能恭俭守教训，好古义。施于文词音。如是而在选，公卿大夫家选之子弟其劝耳矣。愈为博士也，始事相公于祭酒。分教东都生也，事相公千东大学。令为郎于都官也。又事相公居守。三为属吏，经时五年，观道德干前后，听教诲于左右，可谓亲薰而炙之矣。其高大远密者，不敢隐度论也。其勤已而务博施，以己之有，欲人之能，不知古君子何如耳？今生始进仕，获重语于天下，而慊慊若不足，真能守其家法矣。其在门下者，可进贺也。求告来宁，朝夕侍侧。东都士大夫，不得见其面，于其行日，分司郎吏与留守之从事，窃载酒肴席定鼎门外，盛宾客以饯之。既醉，各为诗五韵，且属愈为序。
诗：相公倦台鼎，/分正新邑洛。/才子富文华，/校雠天禄阁。
诗：寿觞嘉节过，/归骑春衫薄。/鸟哢正交加，/杨花共纷泊。
诗：交亲谁不羡，/去去翔寥廓。

# 送石处士赴河阳幕

诗：出栏抽五六，/当户罗三四。/高标陵秋严，/贞色夺春媚。

# 送湖南李正字归

诗：历历余所经，/悠悠子当返。/孤游怀耿介，/旅宿梦婉娩。
诗：风土稍殊昔，/鱼虾日异饭。/亲交俱在此，/谁与同息偃？

# 月蚀诗效玉川子作
诗：元和庚寅斗插子，/月十四日三更中。/森森万木夜僵立，/寒气垒眉顽无风。
诗：月形如白盘，/完完上天东。/忽然有物来噉之，/不知是何虫？
诗：如何至神物，/遭此狼狈凶？/星如掇沙出，/攒集争强雄。
诗：油灯不照席，/是夕吐焰如长虹。/玉川子涕泗，/下中庭独行。
诗：念此日月者，/为天之眼睛。/此犹不自保，/吾道何由行？
诗：尝闻古老言，/疑是虾蟆精。/径圆千里纳女腹，/何处养女百丑形？
诗：杷沙脚手钝，/谁使女解缘青冥？/黄帝有四日，/帝舜重其明。
诗：今天只两目，/何故许食使偏盲？/尧呼大水浸十日，/不惜万国赤子鱼头生。
诗：女于此时若食日，/虽食八九无馋名。/赤龙黑乌烧口热，/翎鬣倒侧相搪撑。
诗：婪酣大肚遭一饱，/饥肠彻死无由鸣。/后时食月罪当死，/天罗磕匝何处逃女刑？
诗：玉川子立于庭而言曰：/地行贱臣仝，/再拜敢告上天公。/臣有一寸刃，
诗：可刳凶蟆肠。/无梯可上天，/天阶无由有臣趴。/寄笺东南风，
诗：天门西北祈风通。/丁宁附耳莫漏泄，/薄命正值飞廉慵。/东方青色龙，
诗：牙角何呀呀？/从官百余座，/嚼啜烦官家。/月蚀女不知，
诗：安用为龙窟天河？/赤鸟司南方，/尾秃翅鳍沙。/月蚀于女头，
诗：女口开呀呀。/虾蟆掠女两吻过，/忍学省事不以女觜啄虾蟆？/於菟蹲于西，
诗：旗旄卫毵掺。/既从白帝祠，/又食于蜡礼有加。/忍令月被恶物食，
诗：枉于女口插齿牙？/乌龟怯奸怕寒，/缩颈以壳自遮。/终令夸蛾抉女出，
诗：卜师烧锥钻灼满板如星罗。/此外内外官，/琐细不足科。/臣请悉扫除，
诗：慎勿许语今啾哗。/并光全耀归我月，/盲眼镜净无纤瑕。/弊蛙拘送主府官，
诗：帝箸下腹尝其皤。/依前使兔操杵臼，/玉阶桂树闲婆娑。/恒娥还宫室，
诗：太阳有室家。/天虽高，/耳属地。/感巨赤心，
诗：使臣知意。/虽无明言，/潜喻厥旨，/有气有形，
诗：皆吾赤子。/虽忿大伤，/忍杀孩稚？/还女月明，
诗：安行于次。/尽释众罪，/以蛙磔死。

# 燕河南府秀才
诗：吾皇绍祖烈，/天下再太平。/诏下诸郡国，/岁贡乡曲英。
诗：元和五年冬，/房公尹东京。/功曹上言公，/是月当登名。
诗：乃选二十县，/试官得鸿生。/群儒负己材，/相贺简择精。

诗：自非绝殊尤，/难使耳目惊。/今者遭震薄，/不能出声鸣。
诗：鄙夫忝县尹，/愧栗难为情。/惟求文章写，/不敢妒与争。
诗：还家敕妻儿，/具此煎包烹。/柿红蒲萄紫，/肴果相扶擎。
诗：芳荼出蜀门，/好酒浓且清。/何能充欢燕？/庶以露厥诚。

诗：阴风搅短日，/冷雨涩不晴。/勉哉戒徒驭，/家国迟子荣。

# 招扬之罘一首
诗：柏生两石间，/万岁终不大；/野马不识人，/难以驾车盖。
诗：柏移就平地，/马羁入厩中，/马思自由悲，/柏有伤根容。
诗：伤根柏不死，/千丈日以至；/马悲罢还乐，/振迅矜鞍辔。
诗：之罘南山来，/文字得我惊。/馆置使读书，/日有求归声。
诗：我令之罘归，/失得柏与马。/之罘别我去，/计出柏马下。
诗：我自之罘归，/入门思而悲。/之罘别我去，/能不思我为？
诗：洒扫县中居，/引水经竹间。/嚣哗所不及，/何异山中闲？
诗：前陈百家书，/食有肉与鱼。/先王遗文章，/缀缉实在余。
诗：《礼》称独学陋，/《易》贵不远复。/作诗招之罘，/晨夕抱饥渴。

# 寄卢仝
诗：玉川先生洛城里，/破屋数间而已矣。/一奴长须不裹头，/一婢赤脚老无齿。
诗：辛勤奉养十余人；/上有慈亲下妻子。/先生结发憎俗徒，/闭门不出动一纪。
诗：至令邻僧乞米送，/仆忝县尹能不耻？/俸钱供给公私余，/时致薄少助祭祀。
诗：劝参留守谒大尹，/言语才及辄掩耳。/水北山人得名声，/去年去作幕下士。
诗：水南山人又继往，/鞍马仆从寒闾里。/少室山人索价高，/两以谏官征不起。
诗：彼皆刺口论世事，/有力未免遭驱使。/先生事业不可量，/惟用法律自绳己。
诗：《春秋》三传束高阁，/独抱遗经究终始。/往年弄笔嘲同异，/怪辞惊众谤不已。
诗：近来自说寻坦涂，/犹上虚空跨绿。/去岁生儿名添丁，/要令与国充耘耔。
诗：国家丁口连四海，/岂无农夫亲耒耜？/先生抱才终大用，/宰相未许终不仕。
诗：假如不在陈力列，/立言垂范亦足恃。/苗裔当蒙十世宥，/岂谓贻厥无基址？
诗：故知忠孝本天性，/洁身乱伦安足拟？/昨晚长须来下状：/隔墙恶少恶难似，
诗：每骑屋山下窥阚，/浑舍惊怕走折趾。/凭依婚媾欺官吏，/不信今行能禁止？
诗：先生受屈未曾语，/忽来此告良有以。/嗟我身为赤县令，/操权不用欲何俟？
诗：立召贼曹呼五百，/尽取鼠辈尸诸市先生又遣长须来，/如此处置非所喜，/况又时当长养节，
诗：都邑末可猛政理。/先生固是余所畏，/度量不敢窥涯涘。/放纵是谁之过欤？
诗：效尤戮仆愧前史。/买羊沽酒谢不敏，/偶逢明月曜桃李。/先生有意许降临，
诗：更遣长须致双鲤。

# 谁氏子

# 石鼓歌

诗：从臣才艺咸第一，/拣选撰刻留山阿。/雨淋日炙野火燎，/鬼物守护烦㧑呵。

# 双鸟诗

诗：自从两鸟鸣，/聒乱雷声收。/鬼神怕嘲咏，/造化皆停留。
诗：草木有微情，/挑抉示九州。/虫鼠诚微物，/不堪苦诛求。
诗：不停两鸟鸣，/百物皆生愁；/不停两鸟鸣，/自此无春秋；
诗：不停两鸟鸣，/日月难旋辀；/不停两鸟鸣，/大法失九畴。
诗：周公不为公，/孔丘不为丘。/天公怪两鸟，/各捉一处囚。
诗：百虫与百鸟，/然后鸣啾啾。/两鸟既别处，/闭声省愆尤。
诗：朝食干头龙，/暮食干头牛；/朝饮河生尘，/暮饮海绝流。
