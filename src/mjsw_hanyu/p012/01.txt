# 闲游二首
诗：雨后来更好，/绕池遍青青。/柳花闲度竹，/菱叶故穿萍。
诗：独坐殊未厌，/孤斟讵能醒？/持竿至日暮，/幽咏欲谁听？
诗：兹游苦不数，/再到遂经旬，/萍盖污池净，/藤笼老树新。
诗：林乌鸣讶客，/岸竹长遮邻，/子云只自守，/奚事九衢尘？

# 赠刑部马侍郎
诗：红旗照海压南荒，/征入中台作侍郎。/暂从相公平小寇，/便归天阙致时康。

# 过鸿沟
诗：龙疲虎困割川原，/亿万苍生性命存。/谁劝君王回马首，/真成一掷赌乾坤？

# 送张侍郎
诗：司徒东镇驰书谒，/丞相西来走马迎。/两府元臣今转密，/一方逋寇不难平。

# 奉和裴相公东征途经女几山下作
诗：旗穿晓日云霞杂，/山倚秋空剑戟明。/敢请相公平贼后，/暂携诸吏上峥嵘。

# 郾城晚饮奉赠副使马侍郎及冯李二员外
诗：城上赤云呈胜气，/眉间黄色见归期。/幕中无事惟须饮，/即是连镳向阙时。

# 酬别留后侍郎
诗：为文无出相如右，/谋帅难居郤縠先。/归去雪销溱洧动，/西来旌旆拂晴天。

# 同李二十八夜次襄城
诗：周楚仍连接，/川原乍屈盘。/云垂天不暖，/尘涨雪犹干。
诗：印绶归台室，/旌旗别将坛。/欲知迎候盛，/骑火万星攒。

# 同李二十八员外从裴相公野宿西界
诗：四面星辰著地明，/散烧烟火宿天兵。/不关破贼须归奏，/自趁新年贺太平。

# 过襄城
诗：郾城辞罢过襄城，/颍水嵩山刮眼明。/已去蔡州三百里，/家山不用远来迎。

# 宿神龟招李二十八冯十七
诗：荒山野水照斜晖，/啄雪寒鸦趁始飞。/夜宿驿亭愁不睡，/幸来相就盖征衣。

# 次硖石
诗：数日方离雪，/今朝又出山。/试凭高处望，/隐约见潼关。

# 和李司勋过连昌宫
诗：夹道疏槐出老根，/高甍巨桷压山原。/宫前遗老来相问：/今是开元几叶孙？

# 桃林夜贺晋公
诗：西来骑火照山红，/夜宿桃林腊月中。/手把命珪兼相印，/一时重叠赏元功。

# 次潼关先寄张十二阁老使君
诗：荆山已去华山来，/日出潼关四扇开。/刺史莫辞迎候远，/相公亲破蔡州回。

# 次潼关上都统相公
诗：暂辞堂印执兵权，/尽管诸公破贼年。/冠盖相望催入相，/待将功德格皇天。

# 晋公破贼回重拜台司以诗示幕中宾客愈奉和
诗：南伐旋师太华东，/天书夜到册元功。/将军旧压三司贵，/相国新兼五等崇。
诗：鹭欲归仙仗里，/熊罴还入禁营中。/长惭典午非材职，/得就闲官即至公。

# 送李员外院长分司东都
诗：去年秋露下，/羁旅逐东征。/今岁春光动，/驱驰别上京。
诗：饮中相顾色，/送后独归情。/两地无千里，/因风数寄声。

# 读皇甫湜公安园池诗书其后二首
诗：晋人目二子，/其犹吹一映。/区区自其下，/顾肯挂牙舌？
诗：《春秋》书王法，/不诛其人身。/《尔雅》注虫鱼，/定非磊落人。
诗：湜也困公安，/不自闲其闲。/穷年枉智思，/掎摭粪壤间。
诗：粪壤多污秽，/岂有臧不臧？/诚不如两忘，/但以一概量。
诗：我有一池水，/蒲苇生其间。/虫鱼沸相嚼，/日夜不得闲。
诗：我初往观之，/其后益不观。/观之乱我意，/不如不观完。
诗：用将济诸人，/舍得业孔颜。/百年能几时，/君子不可闲。

# 独钓四首
诗：侯家林馆胜，/偶入得垂竿。/曲树行藤角，/平池散芡盘。
诗：羽沈知食𫘝，/缗细觉牵难。/聊取夸儿女，/榆条系从鞍。
诗：一径向池斜，/池塘野草花。/雨多添柳耳，/水长减蒲芽。
诗：坐厌亲刑柄，/偷来傍钓车。/太平公事少，/吏隐讵相赊？
诗：独往南塘上，/秋晨景气醒。/露排四岸草，/风约半池萍。
诗：鸟下见人寂，/鱼来闻饵馨。/所嗟无可召，/不得倒吾瓶。
诗：秋半百物变，/溪鱼去不来。/风能坼芡觜，/露亦染梨腮。
诗：远岫重叠出，/寒花散乱开。/所期终莫至，/日暮与谁回？
