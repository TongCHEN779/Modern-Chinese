# 元和圣德诗并序
原：臣愈顿首再拜言：臣见皇帝陛下即位已来，诛流奸臣，朝廷清明，无有欺蔽。外斩杨惠琳、刘辟以收夏、蜀，东定青、徐积年之叛，海内怖骇，不敢违越。郊天告庙，神灵欢喜，风雨晦明，无不从顺。太平之期，适当今日。臣蒙被恩泽，日与群臣序立紫宸殿下，亲望穆穆之光。而其职业，又在以经籍教导国子，诚宜率先作歌诗以称道盛德，不可以辞语浅薄，不足以自效为解。辄依古作四言《元和圣德诗》一篇，凡千有二十四字，指事实录，具载明天子文武神圣，以警动百姓耳目，传示无极。其诗曰：
诗：皇帝即阼，/物无违拒，/曰旸而旸，/曰雨而雨。
诗：维是元年，/有盗在夏，/欲覆其州，/以踵近武。
诗：皇帝曰嘻！/岂不在我？/负鄙为艰，/纵则不可。
诗：出师征之，/其众十旅，/军其城下，/告以福祸。
诗：腹败枝披，/不敢保聚，/掷首陴外，/降播夜竖。
诗：疆外之险，/莫过蜀土。/韦皋去镇，/刘辟守后。
诗：血人于牙，/不肯吐口。/开库啗士，/曰随所取，
诗：汝张汝弓，/汝鼓汝鼓，/汝为表书，/求我帅汝。
诗：事始上闻，/在列咸怒。/皇帝曰然，/嗟远士女，
诗：苟附而安，/则且付与。/读命于庭，/出节少府，
诗：朝发京师，/夕至其部。/辟喜谓党：/汝振而伍，
诗：蜀可全有，/此不当受。/万牛脔炙，/万瓮行酒，
诗：以锦缠股，/以红帕首。/有恇其凶，/有饵其诱，
诗：其出穰穰，/队以万数。/遂劫东川，/遂据城阻。
诗：皇帝曰嗟！/其又可许！/爰命崇文，/分卒禁御，
诗：有安其驱，/无暴我野。/日行三十，/徐壁其右。
诗：辟党聚谋，/鹿头是守。/崇文奉诏，/进退规矩，
诗：战不贪杀，/擒不滥数。/四方节度，/整兵顿马，
诗：上章请讨，/俟命起坐。/皇帝曰嘻！/无汝烦苦；
诗：荆并洎梁，/在国门户，/出师三干，/各选尔丑。
诗：四军齐作，/殷其如阜，/或拔其角，/或脱其距，
诗：长驱洋洋，/无有龃龉。/八月壬午。/辟弃城走，
诗：载妻与妾，/包裹稚乳。/是日崇文，/入处其宇。
诗：分散逐捕，/搜原剔薮。/辟穷见窘，/无地自处，
诗：俯视大江，/不见洲渚，/遂自颠倒，/若杵投臼。
诗：取之江中，/枷脰械手。/妇女累累，/啼哭拜叩。
诗：来献阙下，/以告庙社。/周示城市，/咸使观睹。
诗：解脱挛索，/夹以砧斧。/婉婉弱子，/赤立伛偻，
诗：牵头曳足，/先断腰膂。/次及其徒，/体骇撑拄。
诗：末乃取辟，/骇汗如写，/挥刀纷纭，/争刺脍脯。
诗：优赏将吏，/枋珪缀组，/帛堆其家，/粟塞其庾。
诗：哀怜阵殁，/廪给孤寡，/赠官封墓，/周匝宏溥。
诗：经战伐地，/宽免租赋。/施今酬功，/急疾如火。
诗：天地中间，/莫不顺序。/魏幽恒青，/东尽海浦，
诗：南至徐蔡，/区外杂虏，/怛威赧德，/踧踖蹈舞，
诗：掉弃兵革，/私习簋簠，/来请来觐，/十百其耦。
诗：皇帝曰吁！/伯父叔舅，/各安尔位，/训厥甿晦。
诗：正月元日，/初见宗祖，/躬执百礼。/登降拜俯。
诗：荐于新宫，/视瞻梁梠。/戚见容色，/泪落入俎，
诗：侍祠之臣，/助我侧楚。/乃以上辛，/于郊用牡。
诗：除于国南，/鳞笋毛帘。/庐幕周施，/开揭磊砢。
诗：兽盾腾拏，/圆坛帖妥。/天兵四罗，/旗常婀娜。
诗：驾龙十二，/鱼鱼雅雅。/宵升于丘，/奠璧献啴。
诗：众乐惊作，/轰融冶。/紫燄嘘呵，/高灵下堕，
诗：群星从坐。/错落侈哆。/日君月妃，/焕赫蜾姤。
诗：渎鬼蒙鸿，/岳祇嶪峨。/饫膻燎芗，/产祥降嘏。
诗：凤凰应奏，/舒翼自拊。/赤麟黄龙，/逶陀结纠。
诗：卿士庶人，/黄童白叟，/踊跃欢呀，/失喜噎欧。
诗：干清坤夷，/境落褰举。/帝车回来，/日正当午，
诗：幸丹凤门，/大赦天下。/涤濯划硖，/磨灭瑕垢。
诗：续功臣嗣，/拔贤任者。/孩养无告，/仁滂施厚。
诗：皇帝神圣，/通达今古。/听聪视明，/一似尧禹，
诗：生知法式。/动得理所。/天锡皇帝，/为天下主。
诗：并包畜养，/无异细钜。/亿载万年，/敢有违者？
诗：皇帝俭勤，/盥濯陶瓦。/斥遣浮华。/好此绨纻。
诗：敕戒四方，/侈则有咎。/天锡皇帝。/多麦与黍。
诗：无召水旱，/耗于雀鼠。/亿载万年，/有富无窭。
诗：皇帝正直，/别白善否。/擅命而狂，/既翦既去。
诗：尽逐群奸，/靡有遗侣。/天锡皇帝，/厖臣硕辅，
诗：博问遐观，/以置左右。/亿载万年，/无敢余侮。
诗：皇帝大孝，/慈祥悌友。/怡怡愉愉，/奉太皇后。
诗：浃于族亲，/濡及九有。/天锡皇帝，/与天齐寿。
诗：登兹太平，/无怠永久。/亿载万年，/为父为母。
诗：博士臣愈，/职是训诂。/作为歌诗，/以配吉甫。

# 记梦
诗：夜梦神官与我言，/罗缕道妙角与根。/挈携陬维口澜翻，/百二十刻须臾间。
诗：我听其言未云足，/舍我先度横山腹。/我徒三人共追之，/一人前度安不危。
诗：我亦平行蹋秔，/神完骨𫏋脚不掉。/侧身上视溪谷盲，/杖撞玉版声彭觥。
诗：神官见我开颜笑，/前对一人壮非少。/石坛坡陀可坐卧，/我手承颏肘拄座。
诗：隆楼杰阁磊嵬高，/天风飘飘吹我过。/壮非少者哦七言，/六字常语一字难。
诗：我以指撮白玉丹，/行且咀噍行诘盘。/口前截断第二句，/绰虐顾我颜不欢。
诗：乃知仙人未贤圣，/护短凭愚邀我敬。/我能屈曲自世间，/安能从女巢神山。

# 三星行
诗：我生之辰，/月宿南斗。/牛奋其角，/箕张其口。
诗：牛不见服箱，/斗不挹酒浆。/箕独有神灵，/无时停簸扬。
诗：无善名已闻，/无恶声已欢。/名声相乘除，/得少失有余。
诗：三星各在天，/什伍东西陈。/嗟汝牛与斗，/汝独不能神！

# 剥啄行
诗：剥剥啄啄，/有客至门。/我不出应，/客去而嗔。
诗：从者语我；/子胡为然？/我不厌客，/困于语言。
诗：欲不出纳，/以堙其源。/空堂幽幽，/有秸有莞。
诗：门以两版，/丛书于间。/窅窅深堑，/其墉甚完，
诗：彼宁可隳，/此不可干。/从者语我：/嗟子诚难！
诗：子虽云尔，/其口益蕃。/我为子谋，/有万其全。
诗：凡今之人，/急名与官。/子不引去，/与为波澜。
诗：虽不开口，/虽不开关，/变化咀嚼，/有鬼有神，
诗：今去不勇，/其如后艰。/我谢再拜，/汝无复云，
诗：往追不及，/来不有年。

# 嘲鼾睡二首
诗：澹师昼睡时，/声气一何猥。/顽吹肥脂，/坑谷相嵬磊。
诗：雄哮乍咽绝，/每发壮益倍。/有如阿鼻尸，/长唤忍众罪。
诗：马牛惊不食，/百鬼聚相待。/木枕十字裂，/镜面生痱癗。
诗：铁佛闻皱眉，/石人战摇腿。/孰云天地仁？/吾欲责真宰。
诗：幽寻虱搜耳，/猛作涛翻海。/太阳不忍明，/飞御皆惰怠。
诗：乍如彭与黥，/呼冤受俎醢。/又如圈中虎，/号疮兼吼馁。
诗：虽令伶伦吹，/苦韵难可改。/虽令巫咸招，/魂爽难复在。
诗：何山有灵药？/疗此愿与采。
诗：澹公坐卧时，/长睡无不稳。/吾尝闻其声，/深虑五藏损。
诗：黄河弄滇瀑，/梗涩连拙。/南帝初奋槌，/凿窍泄混沌。
诗：迥然忽长引，/万丈不可忖。/谓言绝于斯，/继出方衮衮。
诗：幽幽寸喉中，/草木森苯尊。/盗贼虽狡狯，/亡魂敢窥阃。
诗：鸿蒙总合杂，/诡谲骋戾狠。/乍如斗呶呶，/忽若怨恳恳。
诗：赋形苦不同，/无路寻根本。/何能堙其源？/惟有土一畚。

# 酬裴十六功曹巡府驿途中见寄
诗：相公罢论道，/聿至活东人。/御史坐言事，/作吏府中尘。
诗：遂令河南治，/今古无俦伦。/四海日富庶，/道途隘蹄轮，
诗：府西三百里，/候馆同鱼鳞。/相公谓御史：/劳子去自巡。
诗：是时山水秋，/光景何鲜新，/哀鸿鸣清耳，/宿雾褰高曼。
诗：遗我行旅诗，/轩轩有风神，/譬如黄金盘，/照耀荆璞真。
诗：我来亦已幸，/事贤友其仁。/持竿洛水侧，/孤坐屡穷辰，
诗：多才自劳苦，/无用只因循。/辞免期匪远，/行行及山春。

# 孟东野失子并序
原：东野连产三子，不数日辄失之。几老，念无后以悲。其友人昌黎韩愈，惧其伤也，推天假其命以喻之。
诗：失子将何尤？/吾将上尤天。/女实主下人，/与夺一何偏？
诗：彼于女何有，/乃令蕃且延？/此独何罪辜，/生死旬日间？
诗：上呼无时闻，/滴地泪到泉。/地祇为之悲，/瑟缩久不安。
诗：乃呼大灵龟，/骑云款天门，/问天主下人，/薄厚胡不均？
诗：天曰天地人，/由来不相关。/吾悬日与月，/吾系星与辰，
诗：日月相噬契，/星辰踣而颠，/吾不女之罪，/知非女由缘。
诗：且物各有分，/孰能使之然？/有子与无子，/祸福未可原。
诗：鱼子满母腹，/一一欲谁怜？/细腰不自乳，/举族长孤鳏。
诗：鸱枭啄母脑，/母死子始翻。/蝮蛇生子时，/坼裂肠与肝。
诗：好子虽云好，/未还恩与勤。/恶子不可说，/鸱枭蝮蛇然。
诗：有子且勿喜，/无子固勿叹。/上圣不待教，/贤闻语而迁，
诗：下愚闻语惑，/虽教无由悛。/大灵顿头受，/即日以命还。
诗：地祇谓大灵：/女往告其人。/东野夜得梦，/有夫玄衣巾，
诗：闯然入其户，/三称天之言。/再拜谢玄夫，/收悲以欢忻。

# 莎栅联句
诗：冰溪时咽绝，/风枥方轩举愈。/此处不断肠，/定知无断处郊。

# 赠唐衢
诗：虎有爪兮牛有角，/虎可搏兮牛可触。/奈何君独抱奇材，/手把鉏犂饿空谷。
诗：当今天子急贤良，/匦函朝出开明光。/胡不上书自荐达，/坐令四海如虞唐？

# 祖席
原：前字
诗：祖席洛桥边，/亲交共黯然。/野晴山簇簇，/霜晓菊鲜鲜。
诗：书寄相思处，/杯衔欲别前。/淮阳知不薄，/终愿早回船。
原：秋字
诗：淮南悲木落，/而我亦伤秋。/况与故人别，/那堪羁宦愁。
诗：荣华今异路，/风雨苦同忧。/莫以宜春远，/江山多胜游。

# 陆浑山火一首和皇甫湜用其韵
诗：皇甫补官古贲浑，/时当玄冬泽干源。/山狂谷很相吐吞，/风怒不休何轩轩，
诗：摆磨出火以自燔。/有声夜中惊莫原，/天跳地踔颠乾坤。/赫赫上照穷崖垠，
诗：截然高周烧四垣。/神焦鬼烂无逃门，/三光弛隳不复暾。/虎熊麋猪逮猴猿，
诗：水龙鼍龟鱼与鼋，/鸦鸱雕鹰雉鹄鹍，/包煨漉孰飞奔。/祝融告休酌卑尊，
诗：错陈齐玫辟华园，/芙蓉披猖塞鲜繁。/千钟万鼓咽耳喧，/攒杂啾嚄沸篪埙。
诗：彤幢绛旃紫纛播，/炎官热属朱冠裈，/髹其肉皮通裈臀，/颓胸垤腹车掀辕，
诗：缇颜抹股豹两鞬，/霞车虹靷日毂幡，/丹蕤盖绯繙。/红帷赤幕罗脉骚，
诗：池波风肉陵屯，/欲呀钜壑颇黎盆，/豆登五山瀛四罇。/熙熙釂酵笑语言，
诗：雷公擘山海水翻，/齿牙嚼韶舌崿龉反，/电光歼磹赦目暖。/顼冥收威避玄根，
诗：斥弃舆马背厥孙，/缩身潜喘拳肩跟，/君臣相怜加爱恩。/命黑螭侦焚其元，
诗：天关悠悠不可援，/梦通上帝血面论，/侧身欲进叱于阍。/帝赐九河湔涕痕，
诗：又诏巫阳反其魂，/徐命之前问何冤。/火行于冬古所存，/我如禁之绝其飧，
诗：女丁妇壬传世婚，/一朝结雠奈后昆。/时行当反慎藏蹲，/视桃著花可小骞，
诗：月及申酉利复怨，/助汝五龙从九鲲，/溺厥邑囚之昆仑。/皇甫作诗止睡昏，
诗：辞夸出真遂上焚。/要余和增怪又烦，/虽欲悔舌不可扪。

# 寄皇甫湜
诗：敲门惊昼睡，/问报睦州吏，/手把一封书，/上有皇甫字。
诗：坼书放床头，/涕与泪垂四。/昏昏还就枕，/惘惘梦相值。
诗：悲哉无奇术，/安得生两翅？

# 崔十六少府摄伊阳以诗及书见投因酬三十韵
诗：崔君初来时，/相识颇未惯，/但闻赤县尉，/不比博士慢。
诗：赁屋得连墙，/往来忻莫间。/我时亦新居，/触事苦难办。
诗：蔬飧要同吃，/破袄请来绽。/谓言安堵后，/贷借更何患！
诗：不知孤遗多，/举族仰薄宦。/有时未朝餐，/得米日已晏，
诗：隔墙闻讙呼，/众口极鹅雁。/前计顿乖张，/居然见真赝。
诗：娇儿好眉眼，/袴脚冻两鼾。/捧书随诸兄，/累累两角帅。
诗：冬惟茹寒齑，/秋始识瓜瓣。/问之不言饥，/饫若厌刍豢。
诗：才名三十年，/久合居给谏。/白头趋走里，/闭口绝谤讪。
诗：府公旧同袍，/拔擢宰山涧。/寄诗杂诙俳，/有类说鹏鷃，
诗：上言酒味酸，/冬衣竟未擐；/下言人吏稀，/惟足彪与；
诗：又言致猪鹿，/此语乃善幻。/三年国子师，/肠肚习藜苋。
诗：况住洛之涯，/鲂鳟可罩汕。/肯效屠门嚼，/久嫌弋者篡。
诗：谋拙日焦拳，/活计似锄铲。/男寒涩诗书，/妻瘦剩腰襻。
诗：为官不事职，/厥罪在欺谩。/行当自劾去，/渔钓老葭乱。
诗：岁穷寒气骄，/冰雪滑磴栈。/音问难屡通，/何由觌清盼？

# 送李翱
诗：广州万里途，/山重江逶迤。/行行何时到，/谁能定归期？
诗：揖我出门去，/颜色异恒时。/虽云有追送，/足迹绝自兹。
诗：人生一世间，/不自张与施。/譬如浮江木，/纵横岂自知。
诗：宁怀别后苦，/勿作别后思。

# 和虞部卢四汀酬翰林钱七徽赤藤杖歌
诗：赤藤为杖世未窥，/台郎始携自滇池。/滇王扫宫避使者，/跪进再拜语嗢咿。
诗：绳桥拄过免倾堕，/性命造次蒙扶持。/途经百国皆莫识，/君臣聚观逐旌麾。
诗：共传滇神出水献，/赤龙拔须血淋漓；/又云羲和操火鞭，/暝到西极睡所遗。
诗：几重包裹自题署，/不以珍怪夸荒夷。/归来捧赠同舍子，/浮光照手欲把疑。
诗：空堂昼眠倚牖户，/飞电著壁搜蛟螭。/南宫清深禁闱密，/唱和有类吹坝箎。
诗：奸辞丽句不可继，/见寄聊且慰分司。

# 送侯参谋赴河中幕
诗：忆昔初及第，/各以少年称。/君颐始生须，/我齿清如冰。
诗：尔时心气壮，/百事谓己能。/一别讵几何？/忽如隔晨兴。
诗：我齿豁可鄙，/君颜老可憎。/相逢风尘中，/相视迭嗟矜。
诗：幸同学省官，/末路再得朋。/东司绝教授，/游宴以为恒。
诗：秋渔荫密树，/夜博然明灯。/雪迳抵樵叟，/风廊折谈僧。
诗：陆浑桃花间，/有汤沸如烝。/三月崧少步，/踯躅红千层。
诗：洲沙厌晚坐，/岭壁穷晨升。/沈冥不计日，/为乐不可胜。
诗：迁满一已异，/乖离坐难凭。/行行事结束，/人马何𫏋腾。
诗：感激生胆勇，/从军岂尝曾。/洸洸司徒公，/天子爪与肱。
诗：提师十万余，/四海钦风棱。/河北兵未进，/蔡州帅新薨。
诗：曷不请扫除，/活彼黎与蒸。/鄙夫诚怯弱，/受恩愧徒弘。
诗：犹思脱儒冠，/弃死取先登。/又欲面言事，/上书求诏征。
诗：侵官固非是，/妄作谴可惩。/惟当待责免，/耕厮归沟塍。
诗：今君得所附，/势若脱韬鹰。/檄笔无与让，/幕谋职其膺。
诗：收绩开史牒，/翰飞逐溟鹏。/男儿贵立事，/流景不可乘。
诗：岁老阴沴作，/云颓雪翻崩。/别袖拂洛水，/征车转崤陵。
诗：勤勤酒不进，/勉勉恨已仍。/送君出门归，/愁肠若牵绳。
诗：默坐念语笑，/痴如遇寒蝇。/策马谁可适？/晤言谁为应？
诗：席尘惜不扫，/残樽对空凝。/信知后会时，/日月屡环。
诗：生期理行役，/欢绪绝难承。/寄书惟在频，/无恡简与缯。
