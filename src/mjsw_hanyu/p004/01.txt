# 将归赠孟东野房蜀客
诗：君门不可入，/势利互相推。/借问读书客，/胡为在京师？
诗：举头未能对，/闭眼聊自思。/倏忽十六年，/终朝苦寒饥。
诗：宦途竟寥落，/鬓发坐差池。/颍水清且寂，/箕山坦而夷，
诗：如今便当去，/咄咄无自疑。

# 赠侯喜
诗：吾党侯生字叔夷，/呼我持竿钓温水。/平明鞭马出都门，/尽日行行荆棘里。
诗：温水微茫绝又流，/深如车辙阔容辀。/虾蟆跳过雀儿浴，/此纵有鱼何足求。
诗：我为侯生不能已，/盘针擘粒投泥滓。/哺时坚坐到黄昏，/手倦目劳方一起。
诗：暂动还休未可期，/虾行蛭渡似皆疑。/举竿引线忽有得，/一寸才分鳞与髻。
诗：是时侯生与韩子，/良久叹息相看悲。/我今行事尽如此，/此事正好为吾规。
诗：半世遑遑就举选，/一名始得红颜衰。/人间事势岂不见，/徒自辛苦终何为？
诗：便当提携妻与子，/南入箕颍无还时。/叔夷君今气方锐，/我言至切君勿嗤。
诗：君欲钓鱼须远去，/大鱼岂肯居沮洳。

# 山石
诗：山石荦确行径微，/黄昏到寺蝙蝠飞。/升堂坐阶新雨足，/芭蕉叶大支子肥。
诗：僧言古壁佛画好，/以火来照所见稀。/铺床拂席置羹饭，/疏粝亦足饱我饥。
诗：夜深静卧百虫绝，/清月出岭光入扉。/天明独去无道路，/出入高下穷烟霏。
诗：山红涧碧纷烂漫，/时见松枥皆十围。/当流赤足蹋涧石，/水声激激风吹衣。
诗：人生如此自可乐，/岂必局束为人靰。/嗟哉吾党二三子，/安得至老不更归！

# 送陆歙州诗
原：贞元十八年二月十八日，祠部员外郎陆君出刺歙州。朝廷夙夜之贤，都邑游从之良，赍咨涕洟，咸以为不当去。歙，大州也。刺史，尊官也。由郎官而往者，前后相望也。当今赋出于天下，江南居十九，宣使之所察，歙为富州。宰臣之所荐闻，天子之所选用，其不轻而重也较然矣。如是而赍咨涕洟，以为不当去者，陆君之道行乎朝廷，则天下望其赐。刺一州，则专而不能。或谓先一州而后天下，岂吾君与吾相之心哉？于是昌黎韩愈道愿留者之心而泄其思，作诗曰：
诗：我衣之华兮，/我佩之光。/陆君之去兮，/谁与翱翔？
诗：敛此大惠兮，/施于一州。/今其去矣，/胡不为留？
诗：我作此诗，/歌于逵道。/无疾其驱，/天子有诏。

# 哭杨兵部凝陆歙州参
诗：人皆期七十，/才半岂蹉跎。/并出知己泪，/自然白发多。
诗：晨兴为谁恸？/还坐久滂沱。/新坟与宿草，/已矣两如何！

# 苦寒
诗：四时各平分，/一气不可兼。/隆寒夺春序，/颛顼固不廉。

诗：炎帝持祝融，/呵嘘不相炎。/而我当此时，/恩光何由沾？
诗：肌肤生鳞甲，/衣被如刀镰。/气寒鼻莫，/血冻指不拈。
诗：浊醪沸入喉，/口角如衔箝。/将持匕箸食，/触指如排签。
诗：侵炉不觉暖，/炽炭屡已添。/探汤无所益，/何况纩与缣。
诗：虎豹僵穴中，/蛟螭死幽潜。/荧惑丧躔次，/六龙冰脱髯。
诗：芒砀大包内，/生类恐尽歼。/啾啾窗间雀，/不知己微纤，
诗：举头仰天鸣，/所顾晷刻淹，/不如弹射死，/却得亲包焊。
诗：鸾皇苟不存，/尔固不在占。/其余蠢动俦，/俱死谁恩嫌。
诗：伊我称最灵，/不能女覆苫，/悲哀激愤叹，/五藏难安恬。
诗：中宵倚墙立，/淫泪何渐渐？/天乎哀无辜！/惠我下顾瞻。
诗：褰旒去耳纩，/调和进梅盐，/贤能日登御，/黜彼傲与𪫺。
诗：生风吹死气，/豁达如褰帘。/悬乳零落堕，/晨光入前簷。
诗：雪霜顿销释，/土脉膏且黏。/岂徒兰蕙荣，/施及艾与蒹。
诗：日萼行铄铄，/风条坐襜襜。/天乎苟其能，/吾死意亦厌。

# 落齿
诗：去年落一牙，/今年落一齿。/俄然落六七，/落势殊未已，
诗：余存皆动摇，/尽落应始止。/忆初落一时，/但念豁可耻，
诗：及至落二三，/始忧衰即死。/每一将落时，/懔懔恒在己。
诗：叉牙妨食物，/颠倒怯漱水，/终焉舍我落，/意与崩山比。
诗：今来落既熟，/见落空相似。/余存二十余，/次第知落矣。
诗：傥常岁落一，/自足支两纪。/如其落并空，/与渐亦同指。
诗：人言齿之落，/寿命理难恃。/我言生有涯，/长短俱死尔。
诗：人言齿之豁，/左右惊谛视。/我言庄周云，/木雁各有喜。
诗：语讹默固好，/嚼废软还美。/因歌遂成诗，/持用诧妻子。

诗：脍成思我友，/观乐忆吾僚。/自可捐忧累，/何须强问鸮。

# 闻梨花发赠刘师命
诗：桃蹊惆怅不能过，/红艳纷纷落地多。/闻道郭西千树雪，/欲将君去醉如何？

# 梨花下赠刘师命
诗：洛阳城下清明节，/百花寥落梨花发。/今日相逢瘴海头，/共惊烂熳开正月。

# 刘生
诗：生名师命其姓刘，/自少轩轻非常俦。/弃家如遗来远游，/东走梁宋暨扬州。
诗：遂凌大江极东陬，/洪涛春天禹穴幽。/越女一笑三年留，/南逾横岭入炎洲。
诗：青鲸高磨波山浮，/怪魅炫耀堆蛟虬。/山掺讙噪猩猩愁，/毒气烁体黄膏流；
诗：问胡不归良有由，/美酒倾水炙肥牛，/妖歌慢舞烂不收；/倒心回肠为青眸，
诗：千金邀顾不可酬，/乃独遇之尽绸缪。/瞥然一饷成十秋，/昔须未生今白头。
诗：五管遍历无贤侯，/回望万里还家羞。/阳山穷邑惟猿猴，/手持钓竿远相投。
诗：我为罗列陈前修，/芟蒿斩蓬利锄耰。/天星回环数才周，/文学穰穰困仓稠，
诗：车轻御良马力优，/咄哉识路行勿休，/往取将相酬恩仇。

# 县斋有怀
诗：少小尚奇伟，/平生足悲咤。/犹嫌子夏儒，/肯学樊迟稼？
诗：事业窥皋稷，/文章蔑曹谢。/濯缨起江湖，/缀珮杂兰麝。
诗：悠悠指长道，/去去策高驾。/谁为倾国媒？/自许连城价。
诗：初随计吏贡，/屡入泽宫射。/虽免十上劳，/何能一战霸。
诗：人情忌殊异，/世路多权诈。/蹉跎颜遂低，/摧折气愈下。
诗：冶长信非罪，/侯生或遭骂。/怀书出皇都，/衔泪渡清灞。
诗：身将老寂寞，/志欲死闲暇。/朝食不盈肠，/冬衣才掩髂。
诗：军书既频召，/戎马乃连跨。/大梁从相公，/彭城赴仆射。
诗：弓箭围狐兔，/丝竹罗酒炙。/两府变荒凉，/三年就休假，
诗：求官去东洛，/犯雪过西华。/尘埃紫陌春，/风雨灵台夜。
诗：名声荷朋友，/援引乏姻娅。/虽陪彤庭臣，/讵纵青冥靶。
诗：寒空耸危阙，/晓色曜修架。/捐躯辰在丁，/铩翮时方惜。
诗：投荒诚职分，/领邑幸宽赦。/湖波翻日车，/岭石坼天罅。
诗：毒雾恒熏昼，/炎风每烧夏。/雷威固已加，/飓势仍相借。
诗：气象杳难测，/声音吁可怕。/夷言听未惯，/越俗循犹乍。
诗：指摘两憎嫌，/睢盱互猜讶。/祗缘恩未报，/岂谓生足藉。
诗：嗣皇新继明，/率土日流化。/惟思涤瑕垢，/长去事桑柘。
诗：厮嵩开云扃，/压颍抗风榭，/禾麦种满地，/梨枣栽绕舍。
诗：儿童稍长成，/雀鼠得驱吓。/官租日输纳，/村酒时邀迓。
诗：闲爱老农愚，/归弄小女姹。/如今便可尔，/何用毕婚嫁。

# 君子法天运
诗：君子法天运，/四时可前知。/小人惟所遇，/寒暑不可期。
诗：利害有常势，/取舍无定姿，/焉能使我心，/皎皎远忧疑。

# 昼月
诗：玉碗不磨著泥土，/青天孔出白石补。/兔入臼藏蛙缩肚，/桂树枯株女闭户，
诗：阴为阳羞固自古。/嗟汝下民或敢侮，/戏嘲盗视汝目瞽。

# 醉后
诗：煌煌东方星，/奈此众客醉。/初喧或忿争，/中静杂嘲戏，
诗：淋漓身上衣，/颠倒笔下字。/人生如此少，/酒贱且勤置。

# 杂诗四首
诗：朝蝇不须驱，/暮蚊不可拍；/蝇蚊满八区，/可尽与相格？
诗：得时能几时，/与汝恣啖咋？/凉风九月到，/扫不见踪迹。
诗：鹊鸣声楂楂，/乌噪声攫，/争斗庭宇间，/持身博弹射。
诗：黄鹄能忍饥，/两翅久不擘，/苍苍云海路，/岁晚将无获。
诗：截橑为横栌，/斫楹以为椽，/束蒿以代之，/小大不相权。
诗：虽无风雨灾，/得不覆且颠？/解辔弃骐骥，/蹇驴鞭使前，
诗：昆仑高万里，/岁尽道苦邅，/停车卧轮下，/绝意于神仙。
诗：雀鸣朝营食，/鸠鸣暮觅群。/独有知时鹤，/虽鸣不缘身。
诗：喑蝉终不鸣，/有抱不列陈。/蛙黾鸣无谓，/合合祗乱人。

# 宿龙宫滩
诗：浩浩复汤汤，/滩声抑更扬。/奔流疑激电，/惊浪似浮霜。
诗：梦觉灯生晕，/宵残雨送凉。/如何连晓语，/只是说家乡？

# 郴州祈雨
诗：乞雨女郎魂，/包羞洁且繁。/庙开鼯鼠叫，/神降越巫言。
诗：旱气期销荡，/阴官想骏奔。/行看五马入，/萧飒已随轩。

# 射训狐
诗：有鸟夜飞名训狐，/矜凶挟狡夸自呼。/乘时阴黑止我屋，/声势慷慨非常粗。
诗：安然大唤谁畏忌，/造作百怪非无须。/聚鬼征妖自朋扇，/摆掉棋桷颓塈涂。
诗：慈母抱儿怕入席，/那暇更护鸡窠雏。/我念乾坤德泰大，/卵此恶物常勤劬。
诗：纵之岂即遽有害，/斗柄行拄西南隅。/谁谓停奸计尤剧，/意欲唐突羲和乌，
诗：侵更历漏气弥厉，/何由侥幸休须臾，/咨余往射岂得已，/候女两眼张睢盱，
诗：枭惊堕梁蛇走窦，/一矢斩颈群雏枯。

# 东方半明
诗：东方半明大星没，/独有太白配残月。/嗟尔残月勿相疑。/同光共影须臾期。
诗：残月晖晖，/太白晱晱。/鸡三号，/更五点。
