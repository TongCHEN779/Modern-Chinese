# 送汴州监军俱文珍
原：今之天下之镇，陈留为大。屯兵十万，连地四州，左淮右河，抱负齐、楚，浊流浩浩，舟车所同。故自天宝以来，当藩垣屏翰之任，有弓矢𫓧钺之权，皆国之元臣，天子所左右。其监统中贵，必材雄德茂，荣耀宠光，能俯达人情，仰喻天意者，然后为之。故我监军俱公，辍侍从之荣，受腹心之寄，奋其武毅，张我皇威，遇变出奇，先事独运，偃息谈笑，危疑以平。天子无东顾之忧，方伯有同和之美。十三年春，将如京师，相国陇西公饮饯于青门之外，谓功德皆可歌之也，命其属咸作诗以铺绎之。
诗：奉使羌池静，/临戎汴水安。/冲天鹏翅阔，/报国剑铑寒。
诗：晓日驱征骑，/春风咏采兰。/谁言臣子道，/忠孝两全难？

诗：乘船下汴水，/东去趋彭城。/从丧朝至洛，/还走不及停。
诗：假道经盟津，/出入行涧冈。/日西入军门，/羸马颠且僵。
诗：主人愿少留，/延入陈壶觞。/卑贱不敢辞，/忽忽心如狂。
诗：饮食岂知味，/丝竹徒轰轰。/平明脱身去，/决若惊凫翔。
诗：黄昏次氾水，/欲过无舟航，/号呼久乃至，/夜济十里黄。
诗：中流上滩弹，/沙水不可详，/惊波暗合沓，/星宿争翻芒。
诗：辕马蹢躅鸣，/左右泣仆童。/甲午憩时门，/临泉窥斗龙。
诗：东南出陈许，/陂泽平茫茫。/道边草木花，/红紫相低昂，
诗：百里不逢人，/角角雉雊鸣。/行行二月暮，/乃及徐南疆。
诗：下马步堤岸，/上船拜吾兄。/谁云经艰难，/百口无夭殇。
诗：仆射南阳公，/宅我睢水阳。/箧中有衣，/盎中有粮。
诗：闭门读书史，/清风窗户凉。/日念子来游，/子岂知我情？
诗：别离未为久，/辛苦多所经。/对食每不饱，/共言无倦听。
诗：连延三十日，/晨坐达五更。/我友二三子，/宦游在西京，
诗：东野窥禹穴，/李翱观涛江，/萧条千万里，/会合安可逢？
诗：淮之水舒舒，/楚山直丛丛，/子又舍我去，/我怀焉所穷？
诗：男儿不再壮，/百岁如风狂。/高爵尚可求，/无为守一乡。

# 赠族侄
诗：我年十八九，/壮气起胸中，/作书献云阙，/辞家逐秋蓬。
诗：岁时易迁次，/身命多厄穷，/一名虽云就，/片禄不足充。
诗：今者复何事？/卑栖寄徐戎，/萧条资用尽，/濩落门巷空。
诗：朝眠未能起，/远怀方郁悰。/击门者谁子？/问言乃吾宗。
诗：自云有奇术，/探妙知天工。/既往怅何及，/将来喜还通。
诗：期我语非佞，/当为佐时雍。

# 龊龊
诗：龊龊当世士，/所忧在饥寒，/但见贱者悲，/不闻贵者叹。
诗：大贤事业异，/远抱非俗观，/报国心皎洁，/念时涕沈澜。
诗：妖姬坐左右，/柔指发哀弹，/酒肴虽日陈，/感激宁为欢？
诗：秋阴欺白日，/泥潦不少干，/河堤决东郡，/老弱随惊湍。
诗：天意固有属，/谁能诘其端？/愿辱太守荐，/得充谏诤官，
诗：排云叫阊阖，/披腹呈琅玕。/致君岂无术，/自进诚独难。

# 汴泗交流赠张仆射
诗：汴泗交流郡城角，/筑场千步平如削。/短垣三面缭逶迤，/击鼓腾腾树赤旗。
诗：新雨朝凉未见日，/公早结束来何为？/分曹决胜约前定，/百马攒蹄近相映。
诗：毬惊杖奋合且离，/红牛缨绂黄金羁，/侧身转臂著马腹，/霹雳应手神珠驰。
诗：超遥散漫两闲暇，/挥霍纷纭争变化。/发难得巧意气粗，/欢声四合壮士呼。
诗：此诚习战非为剧，/岂若安坐行良图。/当今忠臣不可得，/公马莫走须杀贼。

# 忽忽
诗：忽忽乎余未知生之为乐也，/愿脱去而无因。/安得长翮大翼如云生我身，/乘风振奋出六合，
诗：绝浮尘。/死生哀乐两相弃，/是非得失付闲人。

# 鸣雁
诗：嗷嗷鸣雁鸣且飞，/穷秋南去春北归，/去寒就暖识所依。/天长地阔栖息稀，
诗：风霜酸苦稻粱微，/毛羽摧落身不肥。/徘徊反顾群侣违，/哀鸣欲下洲渚非。
诗：江南水阔朔云多。/草长沙软无网罗，/闲飞静集鸣相和，/违忧怀息性匪他。
诗：凌风一举君谓何？

# 雉带箭
诗：原头火烧静兀兀，/野雉畏鹰出复没，/将军欲以巧伏人，/盘马弯弓惜不发。
诗：地形渐窄观者多，/雉惊弓满劲箭加，/冲人决起百余尺，/红翎白镞随倾斜。
诗：将军仰笑军吏贺，/五色离披马前堕。

# 从仕
诗：居闲食不足，/从仕力难任。/两事皆害性，/一生恒苦心。
诗：黄昏归私室，/惆怅起叹音。/弃置人间世，/古来非独今。

# 暮行河堤上
诗：暮行河堤上，/四顾不见人。/衰草际黄云，/感叹愁我神。
诗：夜归孤舟卧，/展转空及晨。/谋计竟何就？/嗟嗟世与身。

# 驽骥赠欧阳詹
诗：驽骀诚龌龊，/市者何其稠？/力小苦易制，/价微良易酬。
诗：渴饮一斗水，/饥食一束刍。/嘶鸣当大路，/志气若有余。
诗：骐骥生绝域，/自矜无匹俦，/牵驱入市门，/行者不为留。
诗：借问价几何？/黄金比嵩丘。/借问行几何？/咫尺视九州。
诗：饥食玉山禾，/渴饮醴泉流。/问谁能为御？/旷世不可求。
诗：惟昔穆天子，/乘之极遐游，/王良执其辔，/造父夹其辀。
诗：因言天外事，/茫惚使人愁。/驽骀谓骐骥，/饿死余尔羞，
诗：有能必见用，/有德必见收，/孰云时与命，/通塞皆自由？
诗：骐骥不敢言，/低徊但垂头。/人皆劣骐骥，/共以驽骀优。
诗：喟余独兴叹，/才命不同谋。/寄诗同心子，/为我商声讴。

# 归彭城
诗：天下兵又动，/太平竟何时？/讦谟者谁子？/无乃失所宜。

诗：言词多感激，/文字少葳蕤。/一读已自怪，/再寻良自疑。

# 幽怀
诗：幽怀不能写，/行此春江浔。/适与佳节会，/士女竞光阴。
诗：凝妆耀洲渚，/繁吹荡人心。/间关林中鸟，/亦知和为音。
诗：岂无一樽酒，/自酌还自吟。/但悲时易失，/四序迭相侵。
诗：我歌君子行，/视古犹视今。

# 海水
诗：海水非不广，/邓林岂无枝，/风波一荡薄，/鱼鸟不可依。
诗：海水饶大波，/邓林多惊风，/岂无鱼与鸟，/巨细各不同。
诗：海有吞舟鲸，/邓有垂天鹏，/苟非鳞羽大，/荡薄不可能。
诗：我鳞不盈寸，/我羽不盈尺，/一木有余阴，/一泉有余泽。
诗：我将辞海水，/濯鳞清泠池；/我将辞邓林，/刷羽蒙笼枝。
诗：海水非爱广，/邓林非爱枝，/风波亦常事，/鳞羽自不宜。
诗：我鳞日已大，/我羽日已修，/风波无所苦，/还作鲸鹏游。

# 送僧澄观

诗：夜复夜，/三年不见汝，/使我鬓发未老而先化。
诗：河之水，/悠悠去，/我不如，/水东注。
诗：我有孤侄在海浦，/三年不见兮，/使我心苦。/采蕨于山，
诗：缗鱼于泉；/我徂京师，/不远其还。
