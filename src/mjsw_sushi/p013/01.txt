# 去年秋偶游宝山上方入一小院阒然无人有一僧隐几低头读书与之语漠然不甚对问其邻之僧日此云阇黎也不出十五年矣今年六月自常润还复至其室则死葬数月矣作诗题其壁
诗：云师来宝山，/一住十五秋。/读书尝闭户，/客至不举头。
诗：去年造其室，/清坐忘百忧。/我初无言说，/师亦无对酬。
诗：今来复扣门，/空房但飕飑。/云已灭无，/薪尽火不留。
诗：却疑此室中，/常有斯人不。/所遇孰非梦，/事过吾何求。

# 听僧昭素琴
诗：至和无攫醳，/至平无按抑。/不知微妙声，/究竟从何出？
诗：散我不平气，/洗我不和心。/此心知有在，/尚复此微吟。

# 僧惠勤初罢僧职
诗：轩轩青田鹤，/郁郁在樊笼。/既为物所縻，/遂与吾辈同。
诗：今来始谢去，/万事一笑空。/新诗如洗出，/不受外垢蒙。
诗：清风入齿牙，/出语如风松。/霜髭茁病骨，/饥坐听午钟。
诗：非诗能穷人，/穷者诗乃工。/此语信不妄，/吾闻诸醉翁。

# 游灵隐高峰塔
诗：言游高峰塔，/蓐食治野装。/火云秋未衰，/及此初旦凉。
诗：雾霏岩谷暗，/日出草木香。/嘉我同来人，/久便云水乡。
诗：相劝小举足，/前路高且长。/古松攀龙蛇，/怪石坐牛羊。
诗：渐闻钟磬音，/飞鸟皆下翔。/人门空有无，/云海浩茫茫。
诗：惟见聋道人，/老病时绝粮。/问年笑不答，/但指穴藜床。
诗：心知不复来，/欲归更彷徨。/赠别留匹布，/今岁天早霜。

# 八月十七日天竺山送桂花分赠元素
诗：月缺霜浓细蕊干，/此花元属玉堂仙。/鹫峰子落惊前夜，/蟾窟枝空记昔年。
诗：破诫山僧怜耿介，/练裙溪女斗清妍。/愿公采撷纫幽佩，/莫遣孤芳老涧边。

# 海会寺清心堂
诗：南郭子綦初丧我，/西来达摩尚求心。/此堂不说有清浊，/游客自观随浅深。
诗：两岁频为山水役，/一溪长照雪霜侵。/纷纷无补竟何事，/惭愧高人闭户吟。

# 捕蝗至浮云岭山行疲余有怀子由弟二首
诗：西来烟障塞空虚，/洒遍秋田雨不如。/新法清平那有此，/老身穷苦自招渠。
诗：无人可诉乌衔肉，/忆弟难凭犬附书。/自笑迂疏皆此类，/区区犹欲理蝗。
诗：霜风渐欲作重阳，/熠熠溪边野菊黄。/久废山行疲荦确，/尚能村醉舞淋浪。
诗：独眠林下梦魂好，/回首人间忧患长。/杀马毁车从此逝，/子来何处问行藏。

# 青牛岭高绝处有小寺人迹罕到
诗：暮归走马沙河塘，/炉烟袅袅十里香。/朝行曳杖青牛岭，/寒泉咽咽干山静。
诗：君勿笑老僧，/耳聋唤不闻，/百年俱是可怜人。/明朝且复城中去，
诗：白云却在题诗处。

# 新城陈氏园次晁补之韵
诗：荒凉废圃秋，/寂历幽花晚。/山城已穷僻，/况与城相远。
诗：我来亦何事，/徙倚望云巘。/不见苦吟人，/清樽为谁满。

# 梅圣俞诗中有毛长官者今於潜令国华也圣俞没十五年而君犹为令捕蝗至其邑作诗戏之
诗：诗翁憔倅老一官，/厌见苜蓿堆青盘。/归来羞涩对妻子，/自比鲇鱼缘竹竿。
诗：今君滞留生二毛，/饱听衙鼓眠黄纳。/更将嘲笑调朋友，/人道猕猴骑土牛。
诗：愿君恰似高常侍，/暂为小邑仍刺史。/不愿君为孟浩然，/却遭明主放还山。
诗：宦游逢此岁年恶，/飞蝗来时半天黑。/羡君封境稻如云，/蝗自识人人不识。

# 与毛令方尉游西菩寺二首
诗：推挤不去已三年，/鱼鸟依然笑我顽。/人未放归江北路，/天教看尽浙西山。
诗：尚书清节衣冠后，/处士风流水石间。/一笑相逢那易得，/数涛狂语不须删。
诗：路转山腰足未移，/水清石瘦便能奇。/白云自占东西岭，/明月谁分上下池。
诗：黑黍黄粱初熟候，/朱柑绿橘半甜时。/人生此乐须天付，/莫遣儿郎取次知。

# 李行中醉眠亭三首
诗：已向闲中作地仙，/更于酒里得天全。/从教世路风波恶，/贺监偏工水底眠。
诗：君且归休我欲眠，/人言此语出天然。/醉中对客眠何害，/须信陶潜未若贤。
诗：孝先风味也堪怜，/肯为周公昼日眠。/枕麴先生犹笑汝，/枉将空腹贮遗编。

# 赠写真何充秀才
诗：君不见潞州别驾眼如电，/左手挂弓横撚箭。/又不见雪中骑驴孟浩然，/皱眉吟诗肩耸山。
诗：饥寒富贵两安在，/空有遗像留人间。/此身常拟同外物，/浮云变化无踪迹，
诗：问君何苦写我真？/君言好之聊自适。/黄冠野服山家容，/意欲置我山岩中。
诗：勋名将相今何限，/往写褒公与鄂公。

# 回先生过湖州东林沈氏饮醉以石榴皮书其家东老庵之壁云西邻已富忧不足东老虽贫乐有白酒酿来因好客黄金散尽为收书西蜀和仲闻而次其韵三首东老沈氏之老自谓也湖人因以名之其子偕作诗有可观者
诗：世俗何知贫是病，/神仙可学道之。/但知白酒留佳客，/不问黄公觅素书。
诗：符离道士晨兴际，/华岳先生尸解。/忽见黄庭丹篆句，/犹传青纸小朱书。
诗：凄凉雨露三年后，/仿佛尘埃数字。/至用榴皮缘底事，/中书君岂不中书。

# 单同年求德兴俞氏聚远楼诗三首
诗：云山烟水苦难亲，/野草幽花各自春。/赖有高楼能聚远，/一时收拾与闲人。
诗：无限青山散不收，/云奔浪卷入帘钩。/直将眼力为疆界，/何啻人间万户侯。
诗：闻说楼居似地仙，/不知门外有尘寰。/幽人隐几寂无语，/心在飞鸿灭没间。

# 润州甘露寺弹筝
诗：多景楼上弹神曲，/欲断哀弦再三促。/江妃出听雾雨愁，/白浪翻空动浮玉。
诗：金山名。/唤取吾家双凤槽，/遣作三峡孤猿号。/与君合奏芳春调，
诗：啄木飞来霜树杪。

# 平山堂次王居卿祠部韵
诗：高会日陪山简醉，/狂言屡发次公醒。/酒如人面天然白，/山向吾曹分外青。
诗：江上飞云来北固，/槛前修竹忆南屏。/六朝兴废丘城，/空使奸雄笑宁馨。

# 次韵陈海州书怀
诗：郁郁苍梧海上山，/东海郁州山，/云自苍梧浮来。/蓬莱方丈有无间。
诗：旧闻草木皆仙药，/欲弃妻孥守市圜，/雅志未成空自叹，/故人相对若为颜。
诗：酒醒却忆儿童事，/长恨双凫去莫攀。/陈曾令乡邑。

# 次韵陈海州乘槎亭
诗：人事无涯生有涯，/逝将归钓汉江槎。/乘桴我欲从安石，/遁世谁能识子嗟。
诗：日上红波浮翠巘潮来白浪卷青沙。/清谈美景双奇绝，/不觉归鞍带月华。

# 次韵孙职方苍梧山
诗：苍梧奇事岂虚传，/荒怪还须问子年。/远托鳌头转沧海，/来依鹏背负青天。
诗：或云灵境归贤者，/又恐神功亦偶然。/闻道新春恣游览，/羡君平地作飞仙。

# 次韵孙巨源寄涟水李盛二著作并以见寄五绝
诗：南岳诸刘岂易逢，/相望无复马牛风。/山公虽见无多子，/社燕何由恋塞鸿。
诗：昔与巨源、刘贡父、刘莘老相遇于广陵，/自尔契阔，/惟巨源近者复相见于京口。
诗：高才晚岁终难进，/勇退当年正急流。/不独二疏为可慕，/他时当有景孙楼。
诗：巨源近离东海，/郡有景疏楼。
诗：漱石先生难可意，/谓巨源。/啮毡校尉久无朋。/自谓。
诗：应知客路愁无奈，/故遣吟诗调李陵。/谓李君也。
诗：云雨休排神女车，/忠州老病畏人夸。/诗豪正值安仁在，/空看河阳满县花。
诗：盛为邑宰。
诗：胶西未到吾能说，/桑柘禾麻不见春。/不羡京尘骑马客，/羡他淮月弄舟人。

# 王莽
诗：汉家殊未识经纶，/人手功名事事新。/百尺穿成连夜井，/千金购得解飞人。

# 董卓
诗：公业平时劝用儒，/诸公何事起相图。/只言天下无健者，/岂信车中有布乎？

# 虎儿
诗：旧闻老蚌生明珠，/未省老免生於菟。/老兔自谓月中物，/不骑快马骑蟾蜍。
诗：蟾蜍爬沙不肯行，/坐令青衫垂白须。/於菟骏猛不类渠，/指挥黄熊驾黑貂。
诗：丹砂紫麝不用涂，/眼光百步走妖狐。/妖狐莫夸智有，/不劳摇牙咀尔徒。

# 铁沟行赠乔太博
诗：城东坡陇何所似？/风吹海涛低复起。/城中病守无所为，/走马来寻铁沟水。
诗：铁沟水浅不容輈，/恰似当年韩与侯。/有鱼无鱼何足道，/驾言聊复写我忧。
诗：孤村野店亦何有，/欲发狂言须斗酒。/山头落日侧金盆，/倒著接罱搔白首。
诗：忽忆从军年少时，/轻裘细马百不知。/臂弓腰箭南山下，/追逐长杨射猎儿。
诗：老去同君两憔倅，/犯夜醉归人不避。/明年定起故将军，/未肯先诛霸陵尉。

# 雪后书北台壁二首
诗：黄昏犹作雨纤纤，/夜静无风势转严。/但觉衾裯如泼水，/不知庭院已堆盐。
诗：五更晓色来书幌，/半夜寒声落画檐。/试埽北台看马耳，/未随埋没有双尖。
诗：城头初日始翻鸦，/陌上晴泥已没车。/冻合玉楼寒起粟，/光摇银海眩生花。
诗：遗蝗入地应千尺，/宿麦连云有几家。/老病自嗟诗力退，/空吟《冰柱》忆刘叉。

# 谢人见和前篇二首
诗：已分酒杯欺浅懦，/敢将诗律斗深严。/渔蓑句好应须画，/柳絮才高不道盐。
诗：败履尚存东郭足，/飞花又舞谪仙檐。/书生事业真堪笑，/忍冻孤吟笔退尖。
诗：九陌凄风战齿牙，/银杯逐马带随车。/也知不作坚牢玉，/无奈能开顷刻花。
诗：得酒强欢愁底事，/闭门高卧定谁家。/台前日暖君须爱，/冰下寒鱼渐可叉。

# 除夜病中赠段屯田
诗：龙钟三十九，/劳生已强半。/岁暮日斜时，/还为昔人叹。
诗：乐天诗云：/行年三十九，/岁暮日斜时。/今年一线在，
诗：那复堪把玩。/欲起强持酒，/故交云雨散。/惟有病相寻，
诗：空斋为老伴。/萧条灯火冷，/寒夜何时旦。/倦仆触屏风，
诗：饥鼯嗅空案。/数朝闭阁卧，/霜发秋蓬乱。/传闻使者来，
诗：策杖就梳盥。/书来苦安慰，/不怪造请缓。/大夫忠烈后，
诗：高义金石贯。/要当击权豪，/未肯觑衰懦。/此生何所似，
诗：暗尽灰中炭。/归田计已决，/此邦聊假馆。/三径粗成资，
诗：一枝有暖。/愿君更信宿，/庶奉一笑粲。
