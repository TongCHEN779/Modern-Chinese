# 送任伋通判黄州兼寄其兄孜
诗：吾州之豪任公子，/少年盛壮日千里。/无媒自进谁识之，/有才不用今老矣。
诗：别来十年学不厌，/读破万卷诗愈美。/黄州小郡夹溪谷，/茅屋数家依竹苇。
诗：知命无忧子何病，/见贤不荐谁当耻。/平泉老令更可悲，/六十青衫贫欲死。
诗：桐乡遗老至今泣，/颍川大姓谁能棰。/因君寄声问消息，/莫对黄鹞矜爪觜。

# 秀州僧本莹静照堂

诗：作堂名静照，/此语子为谁。/江湖隐沦士，/岂无适时资。
诗：老死不自惜，/扁舟自娱嬉。/从之恐莫见，/况瞋从我为。

# 石苍舒醉墨堂

诗：君于此艺亦云至，/堆墙败笔如山丘。/兴来一挥百纸尽，/骏马倏忽踏九州。
诗：我书意造本无法，/点画信手烦推求。/胡为议论独见假，/只字片纸皆藏收。
诗：不减钟张君自足，/下方罗赵我亦优。/不须临池更苦学，/完取绢素充衾裯。

# 涂山
题解：濠州七绝
原：下有鲧庙，山前有禹会村。
诗：川锁支祁水尚浑，/地埋汪罔骨应有。/樵苏已人黄能庙，/乌鹊犹朝禹会村。

# 彭祖庙
原：有云母山，云彭祖所采服也。
诗：跨历商周看盛衰，/欲将齿发斗蛇龟。/空餐云母连山尽，/不见蟠桃著子时。

# 逍遥台
原：庄子祠堂在开元寺，即墓为堂也。
诗：常怪刘伶死便埋，/岂伊忘死未忘骸。/乌鸢夺得与蝼蚁，/谁信先生无此怀。

# 观鱼台
诗：欲将同异较锱铢，/肝胆犹能楚越如。/若信万殊归一理，/子今知我我知鱼。

# 虞姬墓
诗：帐下佳人拭泪痕，/门前壮士气如云。/仓黄不负君王意，/只有虞姬与郑君。

# 四望亭
原：太和中，刺史刘嗣之立。
原：李绅以太子宾客分司东都，过濠为作记，今存而亭废者数年矣。
诗：颓垣破础没柴荆，/故老犹言短李亭。/敢请使君重起废，/落霞孤鹜换新铭。

# 浮山洞
原：洞在淮上，夏潦不能及，而冬不加高，故人疑其浮也。
诗：人言洞府是鳌宫，/升降随波与海通。/共坐船中那得见，/乾坤浮水水浮空。

# 泗州僧伽塔
诗：我昔南行舟系汴，/逆风三日沙吹面。/舟人共劝祷灵塔，/香火未收旂脚转。
诗：回头顷刻失长桥，/却到龟山未朝饭。/至人无心何厚薄，/我自怀私欣所便。
诗：耕田欲雨刈欲晴，/去得顺风来者怨。/若使人人祷辄遂，/造物应须日千变。
诗：今我身世两悠悠，/去无所逐来无恋。/得行固愿留不恶，/每到有求神亦倦。
诗：退之旧云三百尺，/澄观所营今已换。/不嫌俗士污丹梯，/一看云山绕淮甸。

# 龟山
诗：我生飘荡去何求，/再过龟山岁五周。/身行万里半天下，/僧卧一庵初白头。
诗：地隔中原劳北望，/潮连沧海欲东游。/元嘉旧事无人记，/故垒摧颓今在不？
诗：宋文帝遣将拒魏太武，/筑城此山。

# 发洪泽中途遇大风复还
诗：风浪忽如此，/吾行欲安归。/挂帆却西迈，/此计未为非。
诗：洪泽三十里，/安流去如飞。/居民见我还，/劳问亦依依。
诗：携酒就船卖，/此意厚莫违。/醒来夜已半，/岸木声向微。
诗：明日淮阴市，/白鱼能许肥。/我行无南北，/适意乃所祈。
诗：何劳舞澎湃，/终夜摇窗扉。/妻孥莫忧色，/更典篋中衣。

# 十月十六日记所见
诗：风高月暗云水黄，/淮阴夜发朝山阳。/山阳晓雾如细雨，/炯炯初日寒无光。
诗：云收雾卷已亭午，/有风北来寒欲僵。/忽惊飞雹穿户牖，/迅驶不复容遮防。
诗：市人颠沛百贾乱，/疾雷一声如颓墙。/使君来呼晚置酒，/坐定已复日照廊。
诗：恍疑所见皆梦寐，/百种变怪旋消亡。/共言蛟龙厌旧穴，/鱼鳖随徙空陂塘。
诗：愚儒无知守章句，/论说黑白推何祥。/惟有主人言可用，/天寒欲雪饮此觞。

# 刘贡父
题解：广陵会三同舍各以其字为韵仍邀同赋
诗：去年送刘郎，/醉语已惊众。/如今各飘泊，/笔砚谁能弄。
诗：我命不在天，/羿彀未必中。/作诗聊遣意，/老大慵讥讽。
诗：夫子少年时，/雄辩轻子贡。/尔来再伤弓，/戢翼念前痛。
诗：广陵三日饮，/相对恍如梦。/况逢贤主人，/白酒泼春瓮。
诗：竹西已挥手，/湾口犹屡送。/羡子去安闲，/吾邦正喧哄。

# 孙巨源
诗：三年客京辇，/憔倅难具论。/挥汗红尘中，/但随马蹄翻。
诗：人情贵往返，/不报生祸根。/坐令平生友，/终岁不及门。
诗：南来实清旷，/但恨无与言。/不谓广陵城，/得逢刘与孙。
诗：异趣不两立，/譬如王孙猿。/吾侪久相聚，/恐见疑排报。
诗：我褊类中散，/子通真巨源。/绝交固未敢，/且复东南奔。

# 刘莘老
诗：江陵昔相遇，/幕府称上宾。/再见明光宫，/峨冠挹缙绅。
诗：如今三见子，/坎坷为逐臣。/朝游云霄间，/欲分丞相茵。
诗：暮落江湖上，/遂与屈子邻。/了不见愠喜，/子岂真可人。
诗：邂逅成一欢，/醉语出天真。/士方在田里，/自比渭与莘。
诗：出试乃大谬，/刍狗难重陈。/岁晚多霜露，/归耕当及辰。
