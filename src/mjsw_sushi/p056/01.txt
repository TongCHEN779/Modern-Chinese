# 虞美人（落花已作风前舞）
诗：落花已作风前舞，/又送黄昏雨。/晓来庭院半残红，/惟有游丝千丈袅晴空。
诗：殷勤花下重携手，/更尽杯中酒..美人不用敛歌眉，/我亦多情无奈酒阑时。

# 虞美人（冰肌自是生来瘦）
诗：冰肌自是生来瘦，/那更分飞后。/日长帘幕望黄昏，/及至黄昏时候转消魂。
诗：君还知道相思苦，/怎忍抛奴去。/不辞迢递过关山，/只恐别郎容易见郎难。

# 虞美人（深深庭院清明过）
诗：深深庭院清明过，/桃李初红破。/柳丝搭在玉阑干，/帘外潇潇微雨做轻寒。
诗：晚晴台榭增明媚，/已拚花前醉。/更阑人静月侵廊，/独自行来行去好思量。

# 虞美人（持杯遥劝天边月）
诗：持杯遥劝天边月，/愿月圆无缺。/持杯更复劝花枝，/且愿花枝长在莫离披。
诗：持杯月下花前醉，/休问荣枯事。/此欢能有几人知，/对酒逢花不饮待何时。

# 如梦令（为向东坡传语）
诗：为向东坡传语，/人在玉堂深处。/别后有谁来，/雪压小桥无路。
诗：归去，/归去，/江上一犁春雨。

# 如梦令（手种堂前桃李）
诗：手种堂前桃李，/无限绿阴青子。/帘外百舌儿，/惊起五更春睡。
诗：居士，/居士，/莫忘小桥流水。

# 如梦令·题淮山楼
诗：城上层楼叠，/城下清淮古汴。/举手揖吴云，/人与暮天俱远。
诗：魂断，/魂断，/后夜松江月满。

# 阮郎归（绿槐高柳咽新蝉）
诗：绿槐高柳咽新蝉，/薰风初入弦。/碧纱窗下水沉烟，/棋声惊昼眠。
诗：微雨过，/小荷翻，/榴花开欲然。/玉盆纤手弄清泉，/琼珠碎却圆。

# 阮郎归·梅花
诗：暗香浮动月黄昏：堂前一树春。/东风何事入西邻，/儿家常闭门。
诗：雪肌冷，/玉容真，/香腮粉未匀。/折花欲寄岭头人，/江南日暮春。

# 诉衷情（海棠珠缀一重重）
诗：海棠珠缀一重重，/清晓近帘栊。/胭脂谁与匀淡，/偏向脸边浓。
诗：看叶嫩，/惜花红，/意无穷。/如花似叶，/岁岁年年，/共占春风。

# 诉衷情（小莲初上琵琶弦）
诗：小莲初上琵琶弦，/弹破碧云天。/分明绣阁幽恨，/都向曲中传。
诗：肤莹玉，/鬓梳蝉，/绮窗前。/素娥今夜，/故故随人，/似斗婵娟。

# 谒金门（秋帷里）
诗：秋帷里，/长漏伴人无寐。/低玉枕凉轻绣被，/一番秋气味。
诗：晓色又侵窗纸，/窗外鸡声初起。/声断几声还到耳，/已明声未已。

# 谒金门（秋池阁）
诗：秋池阁，/风傍晓庭帘幕。/霜叶未衰吹半落，/半惊鸦喜鹊。
诗：自。/笑浮名情薄，/似与世人疏略。/一片懒心双懒脚，/好教闲处著。

# 谒金门（今夜雨）
诗：今夜雨，/断送一年残暑。/坐听潮声来别浦，/月明何处去。
诗：孤负金尊绿醑，/来岁今宵圆否。/酒醒梦回愁几许，/夜阑还独语。

# 好事近（烟外倚危楼）
诗：烟外倚危楼，/初见远灯明灭。/却跨玉虹归去，/看洞天星月。
诗：当时张范风流在，/况一尊浮雪。/莫问世间何事，/与剑头微映。

# 天仙子（走马探花花发未）
诗：走马探花花发未，/人与化工俱不易。/千回来绕百回看，/蜂作婢，/莺为使，/谷雨清明空屈指。
诗：白发卢郎情未已，/一夜剪刀收玉蕊。/尊前还对断肠红，/人有泪，/花无意，/明日酒醒应满地。

# 翻香令（金炉犹暖麝煤残）
诗：金炉犹暖麝煤残，/惜香更把宝钗翻。/重闻处，/熏在，/这一番、气味胜从前。
诗：背人偷盖小蓬山，/更将沉水暗同然。/且图得，/氤氲久，/为情深、嫌怕断头烟。

# 桃源忆故人（华胥梦断人何处）
诗：华胥梦断人何处，/听得莺啼红树。/几点蔷薇香雨，/寂寞闲庭户。
诗：暖风不解留花住，/片片著人无数。/楼上望春归去，/芳草迷归路。

# 调笑令·效韦应物体
诗：渔父，/渔父，/江上微风细雨。/青蓑黄蒻裳衣，/红酒自鱼暮归。
诗：归暮，/归暮，/长笛一声何处。

# 调笑令（归雁）
诗：归雁，/归雁，/饮啄江南南岸。/将飞却下盘桓，/塞外春来苦寒。
诗：寒苦，/寒苦，/藻荇欲生且住。

# 荷花媚（霞苞电荷碧）
诗：霞苞电荷碧，/天然地、别是风流标格。/重重青盖下，/千娇照水，/好红红白白。
诗：每怅望、明月清风夜，/甚低迷不语，/夭邪无力。/终须放、船儿去，/清香深处住，/看伊颜色。

# 占春芳（红杏了）
诗：红杏了，/夭桃尽，/独自占春芳。/不比人间兰麝，/自然透骨生香。
诗：对酒莫相忘，/似佳人、兼合明光。/只忧长笛吹花落，/除是宁王。

# 一斛珠（洛城春晚）
诗：洛城春晚，/垂杨乱掩红楼半。/小池轻浪纹如篆，/烛下花前，/曾醉离歌宴。
诗：自惜风流云雨散，/关山有限情无限。/待君重见寻芳伴，/为说相思，/目断西楼燕。

# 意难忘（花拥鸳房）
诗：花拥鸳房。/记驼肩髻小，/约鬓眉长。/轻身翻燕舞，/低语啭莺簧。
诗：相见处、便难忘，/肯亲度瑶觞。/向夜阑、歌翻郢曲，/带换韩香。
诗：别来音信难将。/似云收楚峡，/雨散巫阳。/相逢情有在，/不语意难量。
诗：些个事、断人肠，/怎禁得牺惶。/待与伊、移根换叶，/试又何妨。
