# 菩萨蛮·七夕，黄州朝天门上二首
诗：画檐初挂弯弯月，/孤光未满先忧缺。/遥认玉帘钩，/天孙梳洗楼。
诗：佳人言语好，/不愿求新巧。/此恨固应知，/愿人无别离。

# 菩萨蛮（风回仙驭云开扇）
诗：风回仙驭云开扇，/更阑月堕星河转。/枕上梦魂惊，/晓来疏雨零。
诗：相逢虽草草，/长共天难老。/终不羡人间，/人间日似年。

# 菩萨蛮（城隅静女何人见）
诗：城隅静女何人见，/先生日夜歌彤管。/谁识蔡姬贤；/江南顾彦先。
诗：先生那久困，/汤。/沐须名郡。/惟有谢夫人，/从来是拟伦。

# 菩萨蛮（绣帘高卷倾城出）
诗：绣帘高卷倾城出，/灯前潋滟横波溢。/皓齿发清歌，/春愁入翠蛾。
诗：凄音休怨乱，/我已无肠断。/遗响下清虚，/累累一串珠。

# 菩萨蛮·回文
诗：落花闲院春衫薄，/薄衫春院闲花落。/迟日恨依依，/依依恨日迟。
诗：梦回莺舌弄，/弄舌莺回梦。/邮便问人羞，/羞人问便邮。

# 菩萨蛮（火云凝汗挥珠颗）
诗：火云凝汗挥珠颗，/颗珠挥汗凝云火。/琼暖碧纱轻，/轻纱碧暖琼。
诗：晕腮嫌枕印，/印枕嫌腮晕。/闲照晚妆残，/残妆晚照闲。

# 菩萨蛮·回文（二）
诗：峤南江浅红梅小，/小梅红浅江南峤。/窥我向疏篱，/篱疏向我窥。
诗：老人行即到，/到即行人老。/离别惜残枝，/枝残惜别离。

# 菩萨蛮·回文四时闺怨
诗：翠鬟斜幔云垂耳，/耳垂云幔斜鬟翠：春晚睡昏昏，/昏昏睡晚春。/细花梨雪坠，/坠雪梨花细。
诗：颦浅念谁人，/人谁念浅颦。

# 菩萨蛮（柳庭风静人眠昼）
诗：柳庭风静人眠昼，/昼眠人静风庭柳。/香汗薄衫凉，/凉衫薄汗香。
诗：手红冰碗藕，/藕碗冰红手。/郎笑藕丝长，/长丝藕笑郎。

# 菩萨蛮（井桐双照新妆冷）
诗：井桐双照新妆冷，/冷妆新照双桐井。/羞对井花秋，/秋花井对羞。
诗：影孤怜夜永，/永夜怜孤影。/楼上不宜秋，/秋宜不上楼。

# 菩萨蛮（雪花飞暖融香颊）
诗：雪花飞暖融香颊，/颊香融暖飞花雪。/欺雪任单衣，/衣单任雪欺。
诗：别时梅子结，/结子梅时别。/归不恨开迟，/迟开恨不归。

# 菩萨蛮（娟娟侵鬓妆痕浅）
诗：娟娟侵鬓妆痕浅，/双颦相媚弯如剪。/一瞬百般宜，/无论笑与啼。
诗：酒阑思翠被，/特故腾腾地。/生怕促归轮，/微波先泥人。

# 菩萨蛮·咏足
诗：涂香莫惜莲承步，/长愁罗袜凌波去。/只见舞回风，/都无行处踪。
诗：偷穿宫样稳，/并立双跌困。/纤妙说应难，/须从掌上看。

# 菩萨蛮（玉银坠耳黄金饰）
诗：玉银坠耳黄金饰，/轻衫罩体香罗碧。/缓步困春醪，/春融脸上桃。
诗：花钿从委地，/谁与郎为意。/长爱月华清，/此时憎月明。

# 浣溪沙·重九
诗：珠桧丝杉冷欲霜，/山城歌舞助凄凉。/且餐山色饮湖光。
诗：共挽朱幡留半日，/强揉青蕊作重阳。/不知明日为谁黄。

# 浣溪沙（霜鬓真堪插拒霜）
诗：霜鬓真堪插拒霜，/哀弦危柱作《伊》《凉》。/暂时流转为风光。/未遣清尊空北海，/莫因长笛赋山阳。
诗：金钗玉腕泻鹅黄。

# 浣溪沙（傅粉郎君又粉奴）
诗：傅粉郎君又粉奴，/莫教施粉与施朱。/自然冰玉照香酥。/有客能为《神女赋》，/凭君送与雪儿书。
诗：梦魂东去觅桑榆。

# 浣溪沙·咏橘
诗：菊暗荷枯一夜霜，/新苞绿叶照林光，/竹篱茅舍出青黄。/香雾嚷人惊半破，/清泉流齿怯初尝。
诗：吴姬三日手犹香。

# 浣溪沙（道字娇讹语未成）
诗：道字娇讹语未成，/未应春阁梦多情。/朝来何事绿鬟倾。/彩索身轻长趁燕，/红窗睡重不闻莺。
诗：困人天气近清明。

# 浣溪沙（桃李溪边驻画轮）
诗：桃李溪边驻画轮，/鹧鸪声里倒清尊。/夕阳虽好近黄昏。/香在衣裳妆在臂，/水连芳草月连云。
诗：几时归去不销魂。

# 浣溪沙（四面垂杨十里荷）
诗：四面垂杨十里荷，/问云何处最花多？/画楼南畔夕阳过。/天气乍凉人寂寞，/光阴须得酒消磨。
诗：且来花里听笙歌。

# 浣溪沙·彭门送梁左藏
诗：怪见眉间一点黄，/诏书催发羽书忙。/从教娇泪洗红妆。/上殿云霄生羽翼，/论兵齿颊带风霜。
诗：归来衫袖有天香。

# 浣溪沙·送梅庭老赴上党学官
诗：门外东风雪洒裾，/山头回首望三吴。/不应弹铗为无鱼。/上党从来天下脊，/先生元是古之儒。
诗：时平不用鲁连书。

# 浣溪沙·端午
诗：轻汗微微透碧纨，/明朝端午浴芳兰。/流香涨腻满晴川。/彩线轻缠红玉臂，/小符斜挂绿云鬟。
诗：佳人相见一千年。

# 浣溪沙（徐邈能中酒圣贤）
诗：徐邈能中酒圣贤，/刘伶席地幕青天。/潘郎白璧为谁连。/无可奈何新白发，/不如归去旧青山。
诗：恨无人借买山钱。

# 浣溪沙（倾盖相逢胜白头）
诗：倾盖相逢胜白头，/故山空复梦松楸。/此心安处是菟裘。/卖、剑买牛吾欲老，/乞浆得酒更何求。
诗：愿为同社宴春秋。

# 浣溪沙（炙手无人傍屋头）
诗：炙手无人傍屋头，/萧萧晚雨脱梧楸。/谁怜季子敝貂裘？/顾我已无当世望，/似君须向古人求。
诗：岁寒松柏肯惊秋。

# 浣溪沙（画隼横江喜再游）
诗：画隼横江喜再游，/老鱼跳槛识清讴。/流年未肯付东流。/黄菊篱边无怅望，/白云乡里有温柔。
诗：挽回霜鬓莫教休。

# 浣溪沙（入袂轻风不破尘）
诗：入袂轻风不破尘，/玉簪犀璧醉佳辰。/一番红粉为谁新。/团扇不堪题往事，/柳丝那解系行人。
诗：酒阑滋味似残春。

# 浣溪沙（风卷珠帘自上钩）
诗：风卷珠帘自上钩，/萧萧乱叶报新秋。/独携纤手上高楼。/缺月向人舒窈窕，/三星当户照绸缪。
诗：香生雾縠见纤柔。

# 浣溪沙（西塞山边白鹭飞）
原：玄真子《渔父》词极清丽，恨其曲度不传，故加数语，令以《浣溪沙》歌之。
诗：西塞山边白鹭飞，/散花洲外片帆微。/桃花流水鳜鱼肥。/自庇一身青箬笠，/相随到处绿蓑衣。
诗：斜风细语不须归。

# 浣溪沙·方响
诗：花满银塘水漫流，/犀槌玉板奏《凉州》。/顺风环佩过秦楼。/远汉碧云轻漠漠，/今宵人在鹊桥头。
诗：一声敲彻绛河秋。

# 浣溪沙（几共查梨到雪霜）
诗：几共查梨到雪霜，/一经题品便生光。/木奴何处避雌黄。/北客有来初未识，/南金无价喜新尝。
诗：含滋嚼句齿牙香。

# 浣溪沙（山色横侵蘸晕霞）
诗：山色横侵蘸晕霞，/湘川风静吐寒花。/远林屋散尚啼鸦。/梦到故园多少路，/酒醒南望隔天涯。
诗：月明千里照平沙。

# 浣溪沙·重阳
诗：晚菊花前敛翠蛾i接花传酒缓声歌。/《柳枝_》《团扇》别离多。/拥髻凄凉论旧事，/曾随织女度银梭。
诗：当年今夕奈愁何。

# 浣溪沙（风压轻云贴水飞）
诗：风压轻云贴水飞，/乍晴池馆燕争泥。/沈郎多病不胜衣。/沙上不闻鸿雁信，/竹间时有鹧鸪啼。
诗：此情惟有落花知。

# 南歌子（日薄花房绽）
诗：日薄花房绽，/风和麦浪轻。/夜来微雨洗郊垌，/正是一年春好、近清明。
诗：已改煎茶火，/犹调入粥饧。/使君高会有清，/此乐无声无味、最难名。

# 南歌子（师唱谁家曲）
诗：师唱谁家曲，/宗风嗣阿谁？/借君拍板与门槌，/我也逢场作戏、莫相疑。
诗：溪女方偷眼，/山僧莫皱眉。/却愁弥勒下生迟，/不见老婆三五、少年时。

# 南歌子（紫陌寻春去）
诗：紫陌寻春去，/红尘拂面来。/无人不道看花回，/惟见石榴新蕊、一枝开。
诗：冰簟堆云髻，/金尊滟玉醅。/绿阴青子莫相催，/留取红咿干点、照池台。

# 南歌子（笑怕蔷薇胃）
诗：笑怕蔷薇胃，/行忧宝瑟僵。/美人依约在西厢，/只恐暗中迷路、认香。
诗：午夜风翻幔，/三更月到床。/簟纹如水玉肌凉，/何物与侬归去、有残妆。
