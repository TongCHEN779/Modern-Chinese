# 立秋日祷雨宿灵隐寺同周徐二令
诗：百重堆案掣身闲，/一叶秋声对榻眠。/床下雪霜侵户月，/枕中琴筑落阶泉。
诗：崎岖世味尝应遍，/寂寞山栖老渐便。/惟有悯农心尚在，/起占云汉更茫然。

# 病中独游净慈谒本长老周长官以诗见寄仍邀游灵隐因次韵答之
诗：卧闻禅老入南山，/净扫清风五百间。/我与世疏宜独往，/君缘诗好不容攀。
诗：自知乐事年年减，/难得高人日日闲。/欲问云公觅心地，/要知何处是无还。
诗：《楞严经》云：/我今示汝无所还地。

# 病中游祖塔院
诗：紫李黄瓜村路香，/乌纱白葛道衣凉。/闭门野寺松阴转，/敧枕风轩客梦长。
诗：因病得闲殊不恶，/安心是药更无方。/道人不惜阶前水，/借与匏樽自在尝。

# 虎跑泉
诗：亭亭石塔东峰上，/此老初来百神仰。/虎移泉眼趁行脚，/龙作浪花供抚掌。
诗：至今游人盥濯罢，/卧听空阶环块响。/故知此老如此泉，/莫作人间去来想。

# 佛日山荣长老方丈五绝
诗：陶令思归久未成，/远公不出但闻名。/山中只有苍髯叟，/数里萧萧管送迎。
诗：千株玉槊搀云立，/一穗珠旒落镜寒。/何处霜眉碧眼客，/结为三友冷相看。
诗：东麓云根露角牙，/细泉幽咽走金沙。/不堪土肉埋山骨，/未放苍龙浴渥洼。
诗：食罢茶瓯未要深，/清风一榻抵干金。/腹摇鼻息庭花落，/还尽平生未足心。
诗：日射回廊午枕明，/水沉销尽碧烟横。/山入睡觉无人见，/只有飞蚊绕鬓鸣。

# 吊天竺海月辩师三首
诗：欲寻遗迹强沾裳，/本自无生可得亡。/今夜生公讲堂月，/满庭依旧冷如霜。
诗：生死犹如臂屈伸，/情钟我辈一酸辛。/乐天不是蓬莱客，/凭仗西方作主人。
诗：欲访浮云起灭因，/无缘却见梦中身。/安心好住王文度，/此理何须更问人。

# 孤山二咏并引
诗：孤山有陈时柏二株。/其一为人所薪，/山下老人自为儿时，/已见其枯矣，
诗：然坚悍如金石，/愈于未枯者。/僧志诠作堂于其侧，/名之曰柏堂。
诗：堂与白公居易竹阁相连属。/余作二诗以纪之。

# 柏堂
诗：道人手种几生前，/鹤骨龙筋尚宛然。/双干一先神物化，/九朝三见太平年。
诗：忽惊华构依岩出，/乞与佳名到处传。/此柏未枯君记取，/灰心聊伴小乘禅。

# 八月十五日看潮五绝
诗：定知玉兔十分圆，/已作霜风九月寒。/寄语重门休上钥，/夜潮留向月中看。
诗：万人鼓噪慑吴侬，/犹是浮江老阿童。/欲识潮头高几许，/越山浑在浪花中。
诗：江边身世两悠悠，/久与沧波共白头。/造物亦知人易老，/故教江水向西流。
诗：吴儿生长狎涛渊，/冒利轻生不自怜。/东海若知明主意，/应教斥卤变桑田。
诗：是时新有旨禁弄潮。
诗：江神河伯两醯鸡，/海若东来气吐霓。/安得夫差水犀手，/三千强弩射潮低。
诗：吴越王尝以弓弩射潮头，/与海神战，/自尔水不近城。

# 东阳水乐亭
原：为东阳令王都官概作。
诗：君不学白公引泾东注渭，/五斗黄泥一钟水；/又不学哥舒横行西海头，/归来羯鼓打《凉州》。
诗：但向空山石壁下，/爱此有声无用之清流。/流泉无弦石无窍，/强名水乐人人笑。
诗：惯见山僧已厌听，/多情海月空留照。/洞庭不复来轩辕，/至今鱼龙舞钧天。
诗：闻道磬襄东入海，/遗声恐在海山间。/锵然涧谷含宫徵，/节奏未成君独喜。
诗：不须写入薰风弦，/纵有此声无此耳。

# 陌上花三首并引
诗：游九仙山，/闻里中儿歌《陌上花》。/父老云：/吴越王妃，
诗：每岁春必归临安，/王以书遗妃曰：/“陌上花开，/可缓缓归矣。”
诗：吴人用其语为歌，/含思宛转，/听之凄然，/而其词鄙野，
诗：为易之云。
诗：陌上花开蝴蝶飞，/江山犹是昔人非。/遗民几度垂垂老，/游女长歌缓缓归。
诗：陌上山花无数开，/路人争看翠耕来。/若为留得堂堂去，/且更从教缓缓回。
诗：生前富贵草头露，/身后风流陌上花。/已作迟迟君去鲁，/犹教缓缓妾还家。

# 再游径山
诗：老人登山汗如濯，/倒床困卧呼不觉。/觉来五鼓日三竿，/始信孤云天一握。

诗：两足惯曾行荦确。/含晖亭上望东溟，/凌霄峰头挹南岳。/共爱丝杉翠丝乱，
诗：谁见玉芝红玉琢。/白云何事自来往，/明月长圆无晦朔。/山有白云峰、明月庵。
诗：冢上鸡鸣犹忆钦，/山前凤舞远徵璞。/雪窗驯兔元不死，/烟岭孤猿苦难捉。
诗：从来白足傲生死，/不怕黄巾把刀槊。/榻上双痕凛然在，/剑头一映何须角。
诗：以上皆山中故事。/嗟我昏顽晚闻道，/与世龃龉空多学。/灵水先除眼界花，
诗：龙井水，/洗眼有效。/清诗为洗心源浊。/骚人未要逃竞病，
诗：禅老但喜闻剥啄。/此生更得几回来，/从今有暇无辞数。

诗：来诗有“云霄蒲轮”之句。

# 胡穆秀才遗古铜器似鼎而小上有两柱可以覆而不蹶以为鼎则不足疑其饮器也胡有诗答之
诗：只耳兽啮环，/长唇鹅擘喙。/三趾下锐春蒲短，/两柱高张秋菌细。
诗：君看翻覆俯仰间，/覆成三角翻两髻。/古书虽满腹，/有占篆五字不可识。
诗：苟有用我亦随世。/嗟君一见呼作鼎，/才注升合已漂逝。/不如学鸱夷，
诗：尽日盛酒真良计。
