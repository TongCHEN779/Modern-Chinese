# 息壤诗并叙
原：《淮南子》曰：鲧湮洪水，盗帝之息壤，帝使祝融杀之于羽渊。今荆州南门外有状若屋宇，陷入地中，而犹见其脊者。傍有石，记云：不可犯。畚锸所及，辄复如故。又颇以致雷雨，岁大旱，屡发有应。予感之，乃为作诗。其辞曰：
诗：帝息此壤，/以藩幽台。/有神司之，/随取而培。
诗：帝敕下民，/无敢或开。/惟帝不言，/以雷以雨。
诗：惟民知之，/幸帝之恕。/帝茫不知，/谁敢以告。
诗：帝怒不常，/下土是震。/使民前知，/是役于民。
诗：无是坟者，/谁取谁干。/惟其的之，/是以射之。

# 渚宫
诗：渚宫寂莫依古郢，/楚地荒茫非故基。/二王台阁已卤莽，/湘东王、高氏。
诗：何况远问纵横时。/楚王猎罢击灵鼓，/猛士操舟张水嬉。/钓。
诗：鱼不复数鱼鳖，/大鼎千石烹蛟螭。/当时郢人架宫殿，/意思绝妙般与倕。
诗：飞楼百尺照湖水，/上有燕赵千蛾眉。/临风扬扬意自得，/长使宋玉作楚辞。
诗：秦兵西来取钟簾，/故宫禾黍秋离离。/千年壮观不可复，/今之存者盖已卑。
诗：池空野迥楼阁小，/惟有深竹藏狐狸。/台中绛帐谁复见，/台下野水浮清漪。
诗：绿窗朱户春昼闭，/想见深屋弹朱丝。/腐儒亦解爱声色，/何用白首谈孔姬。
诗：沙泉半涸草堂在，/破窗无纸飔飔。/陈公踪迹最未远，/七瑞寥落今何之。
诗：百年人事知几变，/直恐荒废成空陂。/谁能为我访遗迹，/草间应有湘东碑。

# 荆州十首
诗：游人出三峡，/楚地尽平川。/北客随南贾，/吴樯间蜀船。
诗：江侵平野断，/风卷白沙旋。/欲问兴亡意，/重城自古坚。
诗：南方旧战国，/惨澹意犹存。/慷慨因刘表，/凄凉为屈原。
诗：废城犹带井，/古姓聚成村。/亦解观形胜，/升平不敢论。
诗：楚地阔无边，/苍茫万顷连。/耕牛未尝汗，/投种去如捐。
诗：农事谁当劝，/民愚亦可怜。/平生事游惰，/那得怨凶年。
诗：朱槛城东角，/高王此望沙。/江山非一国，/烽火畏三巴。
诗：战骨沦秋草，/危楼倚断霞。/百年豪杰尽，/扰扰见鱼虾。
诗：沙头烟漠漠，/来往厌喧卑。/野市分獐闹，/官船过渡迟。
诗：游人多问卜，/伧叟尽携龟。/日暮江天静，/无人唱《楚辞》。
诗：大守王夫子，/山东老俊髦。/壮年闻猛烈，/白首见雄豪。
诗：食雁君应厌，/驱车我正劳。/中书有安石，/慎勿赋《离骚》。
诗：残腊多风雪，/荆人重岁时。/客心何草草，/里巷自嬉嬉。
诗：爆竹惊邻鬼，/驱傩聚小儿。/故人应念我，/相望各天涯。
诗：江水深成窟，/潜鱼大似犀。/赤鳞如琥珀，/老枕胜玻璃。
诗：上客举雕俎，/佳人摇翠篦。/登庖更作器，/何以免屠剀。
诗：北雁来南国，/依依似旅人。/纵横遭折翼，/感侧为沾巾。
诗：平日谁能挹，/高飞不可驯。/故人持赠我，/三嗅若为珍。
诗：柳门京国道，/驱马及春阳。/野火烧枯草，/东风动绿芒。
诗：北行连许邓，/南去极衡湘。/楚境横天下，/怀王信弱王。

# 荆门惠泉
诗：泉源从高来，/走五随石脉。/纷纷白沫乱，/隐隐苍崖坼。
诗：萦回成曲沼，/清澈见肝膈。/澤深泻为长溪，/奔驶荡蛙烟。
诗：初开不容碗，/渐去已如帛。/传闻此山中，/种物懒遭谪。
诗：不能致雷雨，/滟滟吐寒碧。/遂令山前人，/千古灌稻麦。

# 次韵答荆门张都官维见和惠泉诗
诗：楚人少井饮，/地气常不泄。/蓄之为惠泉，/坌若有所折。
诗：泉源本无情，/岂问浊与澈。/贪愚彼二水，/终古耻莫雪。
诗：只应所处然，/遂使语异别。/泉傍地乎衍，/泉上山崂嵲。
诗：君子慎所居，/此义安可缺。/古人贵言赠，/敢用况高节。
诗：不为冬霜干，/肯畏夏日烈。/冷泠但不已，/海远要当彻。

# 浰阳早发
诗：富贵本无定，/世人自荣枯。/嚣嚣好名心，/嗟我岂独无。
诗：不能便退缩，/但使进少徐。/我行念西国，/已分田园芜。
诗：南来竟何事，/碌碌随商车。/自进苟无补，/乃是懒且愚。
诗：人生重意气，/出处夫岂徒。/永怀江阳叟，/种藕春满湖。

# 夜行观星
诗：天高夜气严，/列宿森就位。/大星光相射，/小星闹若沸。
诗：天人不相干，/嗟彼本何事。/世俗强指摘，/一一立名字。
诗：南箕与北斗，/乃是家人器。/天亦岂有之，/无乃遂自谓。
诗：迫观知何如，/远想偶有似。/茫茫不可晓，/使我长叹喟。

# 汉水
诗：舍棹忽逾月，/沙尘困远行。/襄阳逢汉水，/偶似蜀江清。
诗：蜀江固浩荡，/中有蛟与鲸。/汉水亦云广，/欲涉安敢轻。
诗：文王化南国，/游女俨如卿。/洲中浣纱子，/环佩锵锵鸣。
诗：古风随世变，/寒水空冷泠。/过之不敢慢，/伫立整冠缨。

# 野鹰来
题解：襄阳古乐府三首
诗：野鹰来，/万山下，/荒山无食鹰苦饥，/飞来为尔系彩丝。
诗：北原有兔老且白，/年年养子秋食菽。/我欲击之不可得，/年深免老鹰力弱。
诗：野鹰来，/城东有台高崔巍。/台中公子著皮袖，/东望万里心悠哉。
诗：心悠哉，/鹰何在？/嗟尔公子归无劳，/使鹰可呼亦凡曹，
诗：天阴月黑狐夜嗥。

# 上堵吟
诗：台上有客吟秋风，/悲声萧散飘入空。/台边游女来窃听，/欲学声同意不同。
诗：君悲竟何事，/千里金城两稚子。/白马为塞凤为关，/山川无人空白闲。
诗：我悲亦何苦，/江水冬更深，/鳊鱼冷难捕。/悠悠江上听歌人，
诗：不知我意徒悲辛。

# 襄阳乐
诗：使君未来襄阳愁，/提戈入市裹毡裘。/自从毡裘南渡沔，/襄阳无事多春游。
诗：襄阳春游乐何许，/岘山之阳汉江浦。/使君朱旆来翻翻，/人道使君似羊杜。
诗：道边逢人问洛阳，/中原苦战春田荒。/北人闻道襄阳乐，/目送飞鸿应断肠。

# 岘山
诗：远客来自南，/游尘昏岘首。/过关无百步，/旷荡吞楚薮。
诗：登高忽惆怅，/千载意有偶。/所忧谁复知，/嗟我生苦后。
诗：团团山上桧，/岁岁阅榆柳。/大才固已殊，/安得同永久。
诗：可怜山前客，/倏忽星过罶。/贤愚未及分，/来者当自剖。

# 万山
原：时独不游，问辙而作。
诗：西行度连山，/北出临汉水。/汉水蹙成潭，/旋转山之趾。
诗：禅房久已坏，/古甃含清泚。/下有仲宣栏，/绠刻深容指。
诗：回头望西北，/隐隐龟背起。/传去古隆中，/万树桑柘美。
诗：月炯转山曲，/山上见洲尾。/绿水带子沙，/盘盘如抱珥。
诗：山川近且秀，/不到懒成耻。/问之安能详，/画地费簪棰。

# 隆中
诗：诸葛来西国，/千年爱未衰。/今朝游故里，/蜀客不胜悲。
诗：谁言襄阳野，/生此万乘师。/山中有遗貌，/矫矫龙之姿。
诗：龙蟠山水秀，/龙去渊潭移。/空蜿蜒迹，/使我寒涕垂。

# 竹叶酒
诗：楚人汲汉水，/酿酒古宜城。/春风吹酒熟，/犹似汉江清。
诗：耆旧人何在，/丘坟应已平。/惟竹叶在，/留此千古情。

# 鳊鱼
诗：晓日照江水，/游鱼似玉瓶。/谁言解缩项，/贪饵每遭烹。
诗：杜老当年意，/临流忆孟生。/吾今又悲子，/辍箸涕纵横。

# 食雉
诗：雄雉曳修尾，/惊飞向日斜。/空中纷格斗，/彩羽落如花。
诗：喧呼勇不顾，/投网谁复嗟。/百钱得一双，/新味时所佳。
诗：烹煎杂鸡鹜，/爪距漫槎牙。/谁知化为蜃，/海上落飞鸦。

# 新渠诗并叙
诗：庚子正月，/予过唐州。/大守赵侯，/始复三陂、疏召渠，
诗：招怀远人，/散耕于唐。/予方为旅人，/不得亲执壶浆箪食，
诗：以与侯劝逆四方之来者，/独为么新渠诗》五章，/以告于道路，/致侯之意。
诗：其词曰：/新渠之水，/其来舒舒。/溢流于野，
诗：至于通衢。/渠成如神，/民始不知。/问谁为之？
诗：邦君赵侯。
诗：新渠之田，/在渠左右。/渠来奕奕，/如赴如凑。
诗：如云斯积，/如屋斯溜。/嗟唐之人，/始识粳徐。
诗：新渠之民，/自淮及潭。/挈其妇姑，/或走而颠。
诗：王命赵侯，/宥我新民。/无与王事，/以讫七年。
诗：侯谓新民，/尔既来止。/其归尔邑，/告尔邻里。
诗：良田千万，/尔择尔取。/尔耕尔食，/遂为尔有。
诗：筑室于唐，/孔硕且坚。/生为唐民，/饱粥与饵。
诗：死葬于唐，/祭有鸡豚。/天子有命，/我惟尔安。

# 许州西湖
诗：西湖小雨晴，/滟滟春渠长。/来从古城角，/夜半转新响。
诗：使君欲春游，/浚沼役干掌。/纷纭具畚锸，/闹若蚁运壤。
诗：夭桃弄春色，/生意寒犹快。/惟有落残梅，/标格若矜爽。
诗：游人坌已集，/挈棱三且两。/醉客卧道傍，/扶起尚偃仰。
诗：池台信宏丽，/贵与民同赏。/但恐城市欢，/不知田野怆。
诗：颍川七不登，/野气长苍莽。/谁知万里客，/湖上独长想。

# 双凫观
原：在叶县。
诗：王乔古仙子，/时出观人寰。/常为汉郎吏，/厌世去无还。
诗：双凫偶为戏，/聊以惊世顽。/不然神仙迹，/罗网安能攀。
诗：纷纷尘埃中，/铜印纡青纶。/安知无隐者，/窃笑彼愚奸。

# 颖大夫庙
原：颖考叔也，庙在汝州颍桥。
诗：人情难强回，/天性可微感。/世人争曲直，/苦语费摇撼。
诗：大夫言何柔，/暴主意自惨。/荒祠傍孤冢，/古隧有残坎。
诗：千年惟茅焦，/世亦贵其胆。/不解此微言，/脱衣徒勇敢。

# 阮籍啸台
诗：阮生古狂达，/遁世默无言。/犹胸中气，/长啸独轩轩。
诗：高情遗万物，/不与世俗论。/登临偶自写，/激越荡乾坤。
诗：醒为啸所发，/饮为醉所昏。/谁能与之较，/乱世足自存。

# 大雪独留尉氏有客入驿呼与饮至醉诘旦客南去竟不知其谁
诗：古驿无人雪满庭，/有客冒雪来自北。/纷纷笠上已盈寸，/下马登堂面苍黑。
诗：苦寒有酒不能饮，/见之何必问相识。/我酌徐徐不满觥，/看客倒尽不留涩。
诗：千门昼闭行路绝，/相与笑语不知夕。/醉中不复问姓名，/上马忽去横短策。

# 朱亥墓
原：俗谓屠儿原。
诗：昔日朱公子，/雄豪不可追。/今来游故国，/大冢屈称儿。
诗：平日轻公相，/干金弃若遗。/梁人不好事，/名姓寄当时。
诗：鲁史盗齐豹，/求名谁复知。/慎无怨世俗，/犹不遭仲尼。

# 次韵水官诗并引
原：净因大觉琏师，以阎立本画水官遗编礼公。公既报之以诗，谓轼汝亦作，轼顿首再拜次韵，仍录二诗为一卷献之。
诗：高人岂学画，/用笔乃其天。/譬如善游人，/一一能操船。
诗：阎子本缝掖，/畴昔慕云渊。/丹青偶为戏，/染指初尝鼋。
诗：爱之不自已，/笔势如风翻。/传闻贞观中，/左衽解椎鬟。
诗：南夷羞白雉，/佛国贡青莲。/诏令拟王会，/别殿写戎蛮。
诗：熊冠金络额，/豹袖拥旛旗。/传入应门内，/俯伏脱剑卷。
诗：天姿俨龙凤，/杂沓朝鹏鳢。/神功与绝迹，/后世两莫扳。
诗：自从李氏亡，/群盗窃山川。/长安三日火，/至宝随飞烟。
诗：尚有脱身者，/漂流出东关。/三官岂容独，/得此今已编。
诗：吁嗟至神物，/会合当有年。/京城诸权贵，/欲取百计难。
诗：赠以玉如意，/岂能动高禅。/惟应一篇诗，/皎若画在前。
