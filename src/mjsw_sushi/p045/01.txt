# 次韵王靂郁林
诗：晚途流落不堪言，/海上春泥手自翻。/汉使节空皓首，/故侯瓜在有颓垣。
诗：平生多难非天意，/此去残年尽主恩。/误辱使臣相拉拭，/宁闻老鹤更乘轩。

# 藤州江上夜起对月赠邵道士
诗：江月照我心，/江水洗我肝。/端如径寸珠，/堕此白玉盘。
诗：我心本如此，/月满江不湍。/起舞者谁欤，/莫作三人看。
诗：峤南瘴疠地，/有此江月寒。/乃知天壤间，/何人不清安。
诗：床头有白酒，/盎若白露传。/独醉还独醒，/夜气清漫漫。
诗：仍呼邵道士，/取琴月下弹。/相将乘一叶，/夜下苍梧滩。

# 徐元用使君与其子端常邀仆与小儿过同游东山浮金堂戏作此诗
诗：昔与徐使君，/共赏钱塘春。/爱此小天竺，/时来中圣人。
诗：松如迁客老，/酒似使君醇。/系舟藤城下，/弄月镡江滨。
诗：江月夜夜好，/山云朝朝新。/使君有令子，/真是石麒麟。
诗：我子乃散材，/有如木轮困。/二老白接离，/两郎乌角巾。
诗：醉卧松下石，/扶归江上津。/浮桥半没水，/揭此碧鳞鳞。

# 送鲜于都曹归蜀灌口旧居
诗：笨尽霜须照碧铜，/依然春雪在长松。/朝行犀浦催收芋，/夜渡绳桥看伏龙。
诗：莫叹倦游无驷马，/要将老健敌干钟。/子云三世惟身在，/为向西南说病容。

# 送邵道士彦肃还都峤
诗：乞得纷纷扰扰身，/结茅都峤与仙邻。/少而寡欲颜常好，/老不求名语益真。
诗：许迈有妻还学道，/陶潜无酒亦从人。/相随十日还归去，/万劫清游结此因。

# 书韩幹二马
诗：赤髯碧眼老鲜卑，/回策如萦独善骑。/赭白紫骝俱绝世，/马中湛岳有妍姿。

# 将至广州用过韵寄迈迨二子
诗：皇天遣出家，/临老乃学道。/北归为儿子，/破戒堪一笑。
诗：披云见天眼，/回首失海潦。/蛮唱与黎歌，/音犹杳杳。
诗：大儿收众稚，/四岁守孤峤。/、次子病学医，/三折乃粗晓。
诗：小儿耕且养，/得暇为书绕。/我亦困诗酒，/去道愈茫渺。
诗：纷纷何时定，/所至皆可老。/莫为柳仪曹，/诗书教氓獠。
诗：亦莫事登陟，/溪山有何好。/安居与我游，/闭户净洒扫。

# 和孙叔静兄弟李端叔唱和
诗：病骨瘦欲折，/霜髯笨更疏。/喜闻新国政，/兼得故人书。
诗：秉烛真如梦，/倾杯不敢。/天涯老兄弟，/怀抱几时摅。

# 往年宿瓜步梦中得小绝录示谢民师
诗：吴塞蒹葭空碧海，/隋宫杨柳只金堤。/春风自恨无情水，/吹得东流竟日西。

# 广倅萧大夫借前韵见赠复和答之二首
原：其一
诗：生还粗胜虞，/早退不如疏。/垂死初闻道，/平生误信书。
诗：风涛惊夜半，/疾病送灾。/赖有萧夫子，/忧怀碍少摅。
原：其二
诗：心闲诗自放，/笔老语翻疏。/赠我皆强韵，/知君得异书。
诗：滔滔沮叟是，/绰绰孟生。/一笑沧溟侧，/应无愤可摅。

# 周教授索枸杞因以诗赠录呈广倅萧大夫
诗：邺侯藏书手不触，/嗟我嗜书终日读。/短檠照字细如毛，/怪底昏花悬两目。
诗：扶衰赖有王母杖，/名字于今挂仙录。/荒城古堑草露寒，/碧叶丛低红菽粟。
诗：春根夏苗秋著子，/尽付天随耻充腹。/兰伤桂折缘有用；/尔独何损丹其族。
诗：赠君慎勿比薏苡，/采之终日不盈枭。/外泽中干非尔俦，/敛藏更借秋阳曝。
诗：鸡壅桔梗一称帝，/堇也虽尊等臣仆。/时复论功不汝遗，/异时谨事东篱菊。

# 跋王进叔所藏画五首
原：徐熙杏花
诗：江左风流王谢家，/尽携书画到天涯。/却因梅雨丹青暗，/洗出徐熙落墨花。
原：赵昌四季
诗：倚竹佳人翠袖长，/天寒犹著薄罗裳。/扬州近日红干叶，/自是风流时世妆。
诗：芍药。
诗：枫林翠壁楚江边，/踯躅千层不忍看。/开卷便知归路近，/剑南樵叟为施丹。
诗：踯躅。
诗：轻肌弱骨散幽葩，/真是青裙两髻丫。/便有佳名配黄菊，/应缘霜后苦无花。
诗：寒菊。
诗：游蜂掠尽粉丝黄，/落蕊犹收蜜露香。/待得春风几枝在，/年来杀菽有飞霜。
诗：山茶

# 韦偃牧马图
诗：神工妙技帝所收，/江都曹韩逝莫留。/人间画马惟韦侯，/当年为谁扫骅骝。
诗：至今霜蹄踏长楸，/圉人困卧沙珑头。/沙苑茫茫蒺藜秋，/风駿雾鬣寒飕飕。
诗：龙种尚与驽骀游，/长秸短豆岂我羞。/八銮六辔非马谋，/古来西山与东丘。

# 广州何道士众妙堂
诗：湛然无观古真人，/我独观此众妙门。/夫物芸芸各归根，/众中得一道乃存。
诗：道人晨起开东轩，/跌坐一醉扶桑暾。/光照我玻璃盆，/倒射窗几清而温。
诗：欲收月魄餐日魂，/我自日月谁使吞。

# 和黄秀才鉴空阁
诗：明月本自明，/无心孰为境。/挂空如水鉴，/写此山河影。
诗：我观大瀛海，/巨浸与天永。/九州居其间，/无异蛇盘镜。
诗：空水两无质，/相照但耿耿。/妄云桂兔蟆，/俗说皆可屏。
诗：我游鉴空阁，/缺月正凄冷。/黄子寒无衣，/对月句愈警。
诗：借君方诸泪，/一沐管城颖。/谁言小丛林，/清绝冠五岭。

# 题灵峰寺壁
诗：灵峰山上宝陀寺，/白发东坡又到来。/前世德云今我是，/依稀犹记妙高台。

# 何公桥
诗：天壤之间，/水居其多。/人之往来，/如鹈在河。
诗：顺水而行，/云驰鸟疾。/维水之利，/千里咫尺。
诗：乱流而涉，/过膝则止。/维水之害，/咫尺千里。
诗：沔彼滥觞，/蛙跳修游。/溢而怀山，/神禹所忧。
诗：岂无一木，/支此大坏。/舞于盘涡，/冰折雷解。
诗：坐使此邦，/画为两州。/鸡犬相闻，/胡越莫救。
诗：允毅何公，/甚勇于仁。/始作石梁，/其艰其勤。
诗：将作复止，/更此百难。/公心如铁，/非石则坚。
诗：公以身先，/民以悦使。/老壮负石，/如负其子。
诗：疏为玉虹，/隐为金堤。/直栏横槛，/百贾所栖。
诗：我来与公，/同载而出。/欢呼填道，/抱其马足。
诗：我叹而言，/视此滔滔。/未见刚者，/孰为此桥。
诗：愿公千岁，/与桥寿考。/持节复来，/以慰父老。
诗：如朱仲卿，/食于桐乡。/我作铭诗，/子孙不忘。

# 次韵郑介夫二首
原：其一
诗：一落泥途迹愈深，/尺薪如桂米如金。/长庚到晓空陪月，/太岁今年合守心。
诗：相与啮毡持汉节，/何妨振履出商音。/孤云倦鸟空来往，/自要闲飞不作霖。
原：其二
诗：一生忧患萃残年，/心似惊蚕未易眠。/海上偶来期汗漫，/苇间犹得见延缘。
诗：良医自要经三折，/老将何妨败两甄。/收取桑榆种梨枣，/祝君眉寿似增川。

# 次韵韶守狄大夫见赠二首
原：其一
诗：华发萧萧老遂良，/褚河南帖云：即日遂良，/须发尽白。/盖谪长沙时也。
诗：一身萍挂海中央。/无钱种菜为家业，/有病安心是药方。/才疏正类孔文举，
诗：痴绝还同顾长康。/万里归来空泣血，/七年供奉殿西廊。/迩英阁在延和殿西廊下。
原：其二
诗：森森画戟拥朱轮，/坐咏梁公觉有神。/白傅闲游空诵句，/事见白乐天《吴郡诗右记》。
诗：拾遗穷老敢论亲。/事见子美《赠狄明府诗》。/东海莫怀疏受意，/西风幸免庾公尘。
诗：为公过岭传新唱，/催发寒梅一信春。

# 昔在九江与苏伯固唱和其略曰我梦扁舟浮震泽雪浪横空千顷白觉来满眼是庐山倚天无数开青壁盖实梦也昨日又梦伯固手持乳香婴儿示予觉而思之盖南华赐物也岂复与伯固相见于此耶今得来书知已在南华相待数日矣感叹不已故先寄此诗
诗：扁舟震泽定何时，/满眼庐山觉又非。/春草池塘惠连梦，/上林鸿雁子卿归。
诗：水香知是曹溪口，/眼净同看古佛衣。/不向南华结香火，/此生何处是真依。

# 追和沈辽赠南华诗
诗：善哉彼上人，/了知明镜台。/欢然不我厌，/肯致远公杯。
诗：莞尔无。/心云，/胡为出岫来。/一堂安寂灭，
诗：卒岁扃苍苔。

# 曹溪夜观传灯？录灯花落一僧字上口占
诗：山堂夜岑寂，/灯下看《传灯》。/不觉灯花落，/茶毗一个僧。

# 次韵韶倅李通直二首
原：其一
诗：一篇泷吏可书绅，/莫向长沮更问津。/老去常忧伴新鬼，/归来且喜是陈人。
诗：曾陪令尹苍髯古，/又见郎君白发新。/回首天涯一惆怅，/却登梅岭望枫宸。
原：其二
诗：青山只在古城隅，/万里归来卜筑初。/会见四山朝鹤驾，/更看三李跨鲸鱼。
诗：欲从抱朴传家学，/应怪中郎得异书。/待我丹成驭风去，/借君琼佩与霞裾。
诗：仆昔为开封幕，/先公为赤令，/暇日相与论内外丹，/且出其丹示仆。
诗：今三十年，/而见君曲江，/同游南华，/宿山水间数日；
诗：，道旧感叹，/且劝我卜居于舒，/故诗中皆及之。

# 狄韶州煮蔓菁芦菔羹
诗：我昔在田间，/寒庖有珍烹。/常支折脚鼎，/自煮花蔓菁。
诗：中年失此味，/想像如隔生。/谁知南岳老，/解作东坡羹。
诗：中有芦菔根，/尚含晓露清。/勿；/语贵公子，
诗：从渠嗜膻腥。

# 题冯通直明月湖诗后
诗：老衍清篇墨未枯，/小冯新作语尤殊。/呼儿净洗涵星砚，/为子赓歌堕月湖。
诗：闻道胖江空抱珥，/南诏有西珥河，/即古牂牁江也。/河形如月抱珥，
诗：故名之西珥云。/年来合浦自还珠。/请君多酿莲花酒，/准拟王乔下履凫。

# 李伯时画其弟亮工旧隐宅图
诗：乐天早退今安有，/摩诘长闲古亦无。/五亩自栽池上竹，/十年空看辋川图。
诗：近闻陶令开三径，/应许扬雄寄一区。/晚岁与君同活计，/如云鹅鸭散平湖。

# 书堂屿
诗：苍山古木书堂屿，/北出湘水百步。/谁为往来亏世界，/至今人指安禅处。
诗：岂无惊蛇与飞鸟，/后来那复知其趣。/不知我身今是否，/空记名称在常住。
