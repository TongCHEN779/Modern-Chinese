# 和周正孺坠马伤手
诗：平生学道已神完，/岂复儿童私自怜。/醉坠何曾伤内守，/色忧当为念先传。
诗：书空渐觉新诗健，/把蟹行看乐事全。/卖却老骢为酒直，/大呼乡友作新年。

# 戏周正孺二绝
诗：折臂三公未可知，/会当千镒访权奇。/劝君鬻骆犹闲事，/肠断闺中杨柳枝。
诗：天厩新颁玉鼻骍，/故人共敝亦常情。/相如虽老犹能赋，/换马还应继二生。

# 潘推官母李氏挽词
诗：南浦凄凉老逐臣，/东坡还往尽幽人。/杯柈惯作陶家客，/弦诵尝叨孟母邻。
诗：尚有升堂他日约，/岂知负土一阡新。/今年我欲江湖去，/暮雨连山宰树春。

# 玉堂栽花周正孺有诗次韵
诗：故山桃李半荒榛，/粗报君恩便乞身。/竹簟暑风招我老，/玉堂花蕊为谁春。
诗：纤纤翠蔓诗催发，/皎皎霜葩发斗新。/只有《来禽青李帖》，/他年留与学书人。

# 杜介送鱼

# 送杜介归扬州

诗：万卷明窗小字，/眼花只有斓斑。/一炷烟消火冷，/半生身老心闲。

诗：殷勤与问讯，/爱惜双眉肠。/何以待我归，/寒醅发春缸。

# 次韵三舍人省上

诗：纷纷荣瘁何能久，/云雨从来翻覆手。/怳如一梦堕枕中，/却见三；

诗：独留杞梓扶明堂。

# 次韵子由送家退翁知怀安军
