# 浪淘沙（昨日出东城）
诗：昨日出东城，/试探春情。/墙头红杏暗如倾。/槛内群芳芽未吐，/早已回春。
诗：绮陌敛香尘，/雪霁前村。/东君用意不辞辛。/料想春光先到处，/吹绽梅英。

# 南歌子·八月十八日观潮
诗：海上乘槎侣，/仙人萼绿华。/飞升元不用丹砂，/住在潮头来处、渺天涯。
诗：雷辊夫差国，/云翻海若家。/坐中安得弄琴牙，/写取声归向、水仙夸。

# 行香子·过七里滩
诗：一叶舟轻，/双桨鸿惊，/水天清、影湛波平。/鱼翻藻鉴，/鹭点烟汀。
诗：过沙溪急，/霜溪冷，/月溪明。/重重似画，/曲曲如屏，/算当年、虚老严陵。
诗：君臣一梦，/今古空名。/但远山长，/云山乱，/晓山青。

# 祝英台近（挂轻帆）
诗：挂轻帆，/飞急桨，/还过钓台路。/酒病无聊，/欹枕听鸣舻。
诗：断肠簇簇云山，/重重烟树，/回首望、孤城何处？/间离阻，/谁念萦损襄王，/何曾梦云雨。
诗：旧恨前欢，/心事两无据。/要知欲见无由，/痴心犹自，/倩人谱。
诗：一青传语。

# 瑞鹧鸪·寒食未明至湖上，太守未来，两县令先在
诗：城头月落尚啼乌，/朱舰红船早满湖。/鼓吹未容迎五马，/水云先已漾双凫。
诗：映山黄帽螭头舫，/夹岸青烟鹊尾炉。/老病逢春只思睡，/独求僧榻寄须臾。

# 瑞鹧鸪·观潮
诗：碧山影里小红旗，/侬是江南蹋浪儿。/拍手欲嘲山简醉，/齐声争唱浪婆词。
诗：西兴渡口帆初落，/渔浦山头日未欹。/侬欲送潮歌底曲，/尊前还唱使君诗。

# 临江仙·风水洞作
诗：四大从来都遍满，/此间风水何疑。/故应为我发新诗。/幽花香涧谷，/寒藻舞沦漪。
诗：借与玉川生两腋，/天仙未必相思。/还凭流水送人归。/层巅落日，/草露已沾衣。

# 南乡子（晚景落琼杯）
诗：晚景落琼杯，/照眼云山翠作堆。/认得岷峨春雪浪，/初来，/万顷蒲萄涨渌醅。
诗：春雨暗阳台，/乱洒歌楼湿粉腮。/一阵东风来卷地，/吹回，/落照江天一半开。

# 行香子·丹阳寄述古
诗：携手江村，/梅雪飘裙，/情何限、处处消魂。/故人不见，/旧曲重闻。
诗：向望湖楼，/孤山寺，/涌金门。/寻常行处，/题诗千首，/绣罗衫、与拂红尘。
诗：别来相忆，/知是何人？/有湖中月，/江边柳，/陇头云。

# 昭君怨·金山送柳子玉
诗：谁作桓伊三弄？/惊破绿窗幽梦。/新月与愁烟，/满江天。
诗：欲去又还不去，/明日落花飞絮。/飞絮送行舟，/水东流。

# 醉落魄·一离京口作
诗：轻云微月，/二更酒醒船初发。/孤城回望苍烟合。/记得歌时，/不记归时节。
诗：巾偏扇坠藤床滑，/觉来幽梦无人说。/此生飘荡何时歇？/家在西南，/常作东南别。

# 蝶恋花·京口得乡书
诗：雨后春容清更丽。/只有离人，/幽恨终难洗。/北固山前三面水，/碧琼梳拥青螺髻。
诗：一纸乡书来万里。/问我何年，/真个成归计。/回首送春拼一醉。
诗：东风吹破千行泪。

# 少年游·润州作，代人寄远
诗：去年相送，/杭门外，/飞雪似杨花。/今年春尽，/杨花似雪，/犹不见还家。
诗：对酒卷帘邀明月，/风露透窗纱。/恰似姮娥怜双燕，/分明照、画梁斜。

# 卜算子·自京口还钱塘，道中寄述古太守
诗：蜀客到江南，/长忆吴山好。/吴蜀风流自古同，/归去应须早。
诗：还与去年人，/共藉西湖草。/莫惜尊前子细看，/应是容颜老。

# 江城子（玉人家在凤凰山）
原：陈直方妄嵇，钱塘人也，求新词，为作此。钱塘人好唱《陌上花》缓缓曲，余尝作数绝以纪其事。
诗：玉人家在凤凰山。/水云间，/掩门闲。/门外行人，/立马看弓弯。
诗：十里春风谁指似，/斜日映，/绣帘斑。/多情好事与君还。
诗：闵新鳏，/拭余潸。/明月空江，/香雾著云鬟。
诗：陌上花开春尽也，/闻旧曲，/破朱颜。

# 江城子·湖上与张先同赋，时闻弹筝
诗：凤凰山下雨初晴。/水风清，/晚霞明。/一朵芙蕖，/开过尚盈盈。
诗：何处飞来双白鹭，/如有意，/慕娉婷。/忽闻江上弄哀筝。
诗：苦含情，/遣谁听？/烟敛云收，/依约是湘灵。
诗：欲待曲终寻问取，/人不见，/数峰青。

# 虞美人·有美堂赠述古
诗：湖山信是东南美，/一望弥千里。/使君能得几回来，/便使尊前醉倒更徘徊。
诗：沙河塘里灯初上，/《水调》谁家唱？/夜阑风静欲归时，/唯有一江明月碧琉璃。

# 诉衷情·送述古，迓元素
诗：钱塘风景古今奇，/太守例能诗。/先驱负弩何在？/心已浙江西。
诗：花尽后，/叶飞时，/雨凄凄。/若为情绪，/更问新官，/向旧官啼。

# 菩萨蛮·杭妓往苏迓新守杨元素，寄苏守王规甫
诗：玉童西迓浮丘伯，/洞天冷落秋萧瑟。/不用许飞琼，/瑶台空月明。
诗：清香凝夜宴，/借与韦郎看。/莫便向姑苏，/扁舟下五湖。

# 菩萨蛮·西湖席上代诸妓送陈述古
诗：娟娟缺月西南落，/相思拨断琵琶索。/枕泪梦魂中，/觉来眉晕重。
诗：华堂堆烛泪，/长笛吹新水。/醉客各西东，/应思陈孟公。

# 江城子·孤山竹阁送述古
诗：翠蛾羞黛怯人看。/掩霜纨，/泪偷弹。/且尽一尊，/收泪听《阳关》。
诗：漫道帝城天样远，/天易见，/见君难。/画堂新创近孤山。
诗：曲阑干，/为谁安。/飞絮落花，/春色属明年。
诗：欲棹小舟寻旧事，/无处问，/水连天。

# 菩萨蛮·西湖送述古
诗：秋风湖上萧萧雨，/使君欲去还留住。/今日漫留君，/明朝愁杀人。
诗：佳人千点泪，/洒向长河水。/不用敛双蛾，/路人啼更多。

# 清平乐·送述古赴南都
诗：清淮浊汴，/更在江西岸。/红旆到时黄叶乱，/霜入梁王故苑。
诗：秋原何处携壶？/停骖访古踟蹰。/双庙遗风尚在，/漆园傲吏应无。

# 南乡子·送述古
诗：回首乱山横，/不见居人只见城。/谁以临平山上塔，/亭亭，/迎客西来送客行。
诗：归路晚风清，/一枕初寒梦不成。/今夜残灯斜照处，/荧荧，/秋雨晴时泪不晴。

# 南歌子（苒苒中秋过）
诗：苒苒中秋过，/萧萧两鬓华。/寓身此世一尘沙，/笑看潮来潮去、了生涯。
诗：方士三山路，/渔人一叶家。/早知身世两聱牙，/好伴骑鲸公子、赋雄夸。

# 泛金船·流杯亭和杨元素
诗：无情流水多情客，/劝我如相识。/杯行到手休辞却，/似轩冕相逼。
诗：曲水池上，/小字更书年月。/还对茂林修竹，/似永和节。
诗：纤纤素手如霜雪，/笑把秋花插。/尊前莫怪歌声咽，/又还是轻别。
诗：此去翱翔，/遍上玉堂金阙。/欲问再来何岁，/应有华发。

# 南乡子·和杨元素，时移守密州
诗：东武望杭，/云海天涯两渺茫。/何日功成名遂了，/还乡，/醉笑陪公三万场。
诗：不用诉离觞，/痛饮从来别有肠。/今夜送归灯火冷，/河塘，/堕泪羊公却姓杨。

# 南乡子·和杨元素
诗：凉簟碧纱厨，/一枕清风昼睡。/睡听晚衙无个事，/徐徐，/读尽床头几卷书。
诗：搔首赋归欤，/自觉功名懒更疏。/若问使君才与气，/何如，/占得人间一味愚。

# 南乡子·梅花词，和杨元素
诗：寒雀满疏篱，/争抱寒柯看玉蕤。/忽见客来花下坐，/惊飞，/蹋散芳英落酒卮。
诗：痛饮又能诗，/坐客无毡醉不知。/花谢酒阑春到也，/离离，/一点微酸已著枝。

# 浣溪沙·自杭移密守，席上别杨元素，时重阳前一日
诗：缥缈危楼紫翠间，/良辰乐事古难全。/感时怀旧独凄然。/璧月琼枝空夜夜，/菊花人貌自年年。
诗：不知来岁与谁看？

# 浣溪沙（《白雪》清词出坐间）
诗：《白雪》清词出坐间，/爱君才器两俱全。/异乡风景却依然。/可恨相逢能几日，/不知重会是何年。
诗：茱萸子细更重看。

# 南乡子·沈强辅雯上出犀丽玉作胡琴送元素还朝，同子野各赋一首
诗：裙带石榴红，/却水殷勤解赠侬。/应许逐鸡鸡莫怕，/相逢。
诗：一点灵心必暗通。/何处遇良工，/琢刻天真半欲空。/愿作龙香双凤拨，/轻拢。
诗：长在环儿白雪胸。

# 南乡子（旌旆满江湖）
诗：旌旆满江湖，/诏发楼船万舳舻。/投笔将军因笑我，/迂儒。
诗：帕首腰刀是丈夫。/粉泪怨离居，/喜子垂窗报捷书。/试问伏波三万语，/何如。
诗：一斛明珠换绿珠？

# 定风波·送元素
诗：今古风流阮步兵，/平生游宦爱东平。/千里远来还不住，/归去，/空留风韵照人清。
诗：红粉尊前添懊恼，/休道。/如何留得许多情。/记取明年花絮乱，/看泛，/西湖总是断肠声。

# 减字木兰花（惟熊佳梦）
原：秘阁古《笑林》云：晋元帝生子，宴百官，赐束帛。殷羡谢曰：教育“臣等无功受赏。”帝曰：“此事岂容卿有功乎？”同舍每以为笑。余过吴兴，而李公择适生子。三日会客，求歌辞，乃为作此戏之，举座皆绝倒。
诗：惟熊佳梦，/释氏老君亲抱送。/壮气横秋，/未满三朝已食牛。
诗：犀钱玉果，/利市平分沾四坐。/多谢无功，/此事如何著得侬？

# 河满子·湖州寄南守冯当世
诗：见说岷峨凄怆，/旋闻江汉澄清。/但觉秋来归梦好，/西南自有长城。
诗：东府三人最少，/西山八国初平。/莫负花溪纵赏，/何妨药市微行。
诗：试问当垆人在否？/空教是处闻名。/唱着子渊新曲，/应须分外含情。

# 菩萨蛮·席上和陈令举
诗：天怜豪俊腰金晚，/故教月向松江满。/清景为淹留，/从君都占秋。
诗：身闲惟有酒，/试问遨游首。/帝梦已遥思，/匆匆归去时。

# 鹊桥仙·七夕送陈令举
诗：缑山仙子，/高情云渺，/不学痴牛騃女。/凤箫声断月明中，/举手谢、时人欲去。
诗：客槎曾犯，/银河波浪，/尚带天风海雨。/相逢一醉是前缘，/风雨散、飘然何处。

# 阮郎归（一年三度过苏台）
原：一年三过苏。最后赴密州时，有问：“这回来不来？”其色凄然。太守王规父嘉之，令作此词。
诗：一年三度过苏台，/清尊长是开。/佳人相问苦相猜：这回来不来？
诗：情未尽，/老先催。/人生真可哈。/他年桃李阿谁栽？
诗：刘郎双鬓衰。

# 醉落魄·苏州闾门留别
诗：苍颜华发，/故山归计何时决。/旧交新贵音书绝，/惟有佳人，/犹作殷勤别。
诗：离亭欲去歌声咽，/潇潇细雨凉吹颊。/泪珠不用罗巾囊，/弹在罗衫，/图得见时说。
