# 上巳日与二子迨过游涂山荆山记所见
诗：此生终安归，/还轸天下半。/朅来乘累庙，/复作微禹叹。
诗：昔自南河赴杭州过此，/盖二十二年矣。/从祀及彼呱，/有启庙。
诗：像设偶此粲。/谓涂山氏。/秦祖当侑坐，/谓柏翳。
诗：夏郊亦荐裸。/有鲧庙。/可怜淮海人，/尚记弧矢旦。
诗：淮南人相传，/禹以六月六日生，/是日数万人会山上。/虽传记不载，
诗：然相传如此。/荆山碧相照，/楚水清可乱。/刖人有坑，
诗：美石肖温瓒。/荆山下有卞氏采玉坑，/石色如玉，/不受镶刻。
诗：取出山下，/辄变色不复温莹。/龟泉木杪出，/牛乳石池漫。
诗：龟泉在荆山下，/色白而甘，/真陆羽所谓石池漫流者。/有石记云：
诗：唐贞元中，/随白龟流出。/小儿强好古，/侍史笑流汗，
诗：归时蝙蝠飞，/炬火记远岸。

# 双石并叙
原：至扬州，获二石。其一绿色，冈峦迤逦，有穴达于背。其一正白可鉴。渍以盆水，置几案间。忽忆在颍州日，梦人请住一官府，榜日仇池。觉而诵杜子美诗曰：万古仇池穴，潜通小有天。乃戏作小诗，为僚友一笑。
诗：梦时良是觉时非，/汲井埋盆故白痴。/但见玉峰横太白，/便从鸟道绝峨眉。
诗：秋风与作烟云意，/晓日令涵草木姿。/一点空明是何处，/老人真欲住仇池。

# 和陶饮酒二十首并叙
诗：吾饮酒至少，/常以把盏为乐。/往往颓然坐睡，/人见其醉，
诗：而吾中了然，/盖莫能名其为醉为醒也。/在扬州时，/饮酒过午辄罢。
诗：客去，/解衣盘礴，/终日欢不足而适有。/因和渊明《饮酒》二十首，
诗：庶以仿佛其不可名者，/示舍弟子由、晁无咎学士。
诗：我不如陶生，/世事缠绵之。/云何得一适，/亦有如生时。
诗：寸田无荆棘，/佳处正在兹。/纵心与事往，/所遇无复疑。
诗：偶得酒中趣，/空杯亦常持。
诗：二豪诋醉客，/气涌胸中山。/漼捻似冰释，/亦复在一言。
诗：啬气实其腹，/云当享长年。/少饮得径醉，/此秘君勿传。
诗：道丧士失己，/出语辄不情。/江左风流人，/醉中亦求名。
诗：渊明独清真，/谈笑得此生。/身如受风竹，/掩冉众叶惊。
诗：俯仰各有态，/得酒诗自成。
诗：蠢蠕食叶虫，/仰空慕高飞。/一朝傅两翅，/乃得黏网悲。
诗：啁啾同巢雀，/沮泽疑可依。/赴水生两壳，/遭闭何时归。
诗：二虫竟谁是，/一笑百念衰。/幸此未化间，/有酒君莫违。
诗：小舟真一叶，/下有暗浪喧。/夜棹醉中发，/不知枕几偏。
诗：天明问前路，/已度千重山。/嗟我亦何为，/此道常往还。
诗：未来宁早计，/既往复何言。
诗：百年六十化，/念念竟非是。/是身如虚空，/谁受誉与毁。
诗：得酒未举杯，/丧我固忘尔。/倒床自甘寝，/不择菅与绮。
诗：顷者大雪年，/海派翻玉英。/有士常痛饮，/饿寒见真情。
诗：床头有败榼，/孤坐时一倾。/未能平体粟，/且复浇肠鸣。
诗：脱衣裹冻酒，/每醉念此生。
诗：我坐华堂上，/不改麋鹿姿。/时来蜀冈头，/喜见霜松枝。
诗：心知百尺底，/已结干岁奇。/煌煌凌霄花，/缠绕复何为。
诗：举觞酹其根，/无事莫相羁。
诗：芙蓉在秋水，/时节自阖开。/清风亦何意，/入我芝兰怀。
诗：一随采折去，/永与江湖乖。/断丝不复续，/斗水何足栖。
诗：不如玉井莲，/结根天池泥。/感此每自慰，/吾事幸不谐。
诗：醉中有归路，/了了初不迷。/乘流且复逝，/抵曲吾当回。
诗：篮舆兀醉守，/路转古城隅。/酒力如过雨，/清风消半途。
诗：前山正可数，/后骑且勿驱。/我缘在东南，/往寄白发。
诗：遥知万松岭，/下有三亩居。
诗：民劳吏无德，/岁美天有道。/暑雨避麦秋，/温风送蚕老。
诗：三咽初有闻，/一溉未濡槁。/诏书宽积欠，/父老颜色好。
诗：再拜贺吾君，/获此不贪宝。/颓然笑阮籍，/醉几书谢表。
诗：我梦入小学，/自谓总角时。/不记有白发，/犹诵论语辞。
诗：人间本儿戏，/颠倒略似兹。/惟有醉时真，/空洞了无疑。
诗：坠车终无伤，/庄叟不吾欺。/呼儿具纸笔，/醉语辄录之。
诗：醉中虽可乐，/犹是生灭境。/云何得此身，/不醉亦不醒。
诗：痴如景升牛，/莫保尻与领。/黠如东郭挽，/束缚作毛颖。
诗：乃知嵇叔夜，/非坐虎文炳。
诗：我家小冯君，/天性颇醇至。/清坐不饮酒，/而能容我醉。
诗：归休要相依，/谢病当以次。/岂知山林士，/肮脏乃尔贵。
诗：乞身当念早，/过是恐少味。
诗：去乡三十年，/风雨荒旧宅。/惟存一束书，/寄食无定迹。
诗：每用愧渊明，/尚取禾三百。/颀然六男子，/粗可传清白。
诗：于吾岂不多，/何事复叹息。
诗：晓晓六男子，/弦诵各一经。/复生五丈夫，/戢戢丁欲成。
诗：归田了门户，/与国充践更。/普儿初学语，/玉骨开天庭。
诗：淮老如鹤雏，/破壳已长鸣。/举酒属千里，/一欢愧凡情。
诗：淮海虽故楚，/无复轻扬风。/斋厨圣贤杂，/无事时一中。
诗：谁言大道远，/正赖三杯通。/使君不夕坐，/衙门散刀弓。
诗：何人筑东台，/一郡坐可得。/亭亭古浮图，/独立表众惑。
诗：芜城阅兴废，/雷塘几开塞。/明年起华堂，/置酒吊亡国。
诗：无令竹西路，/歌吹久寂默。
诗：晁子天麒麟，/结交未及仕。/高才固难及，/雅志或类己。
诗：各怀伯业能，/共有丘明耻。/歌呼时就君，/指我醉乡里。
诗：吴公门下客，/贾谊独见纪。/请作《鵬鸟赋》，/我亦得坎止。
诗：行乐当及时，/绿发不可恃。
诗：盖公偶谈道，/齐相独识真。/颓然不事事，/客至先饮醇。
诗：当时刘项罢，/四海疮痍新。/三杯洗战国，/一斗消强秦。
诗：寂寞千载后，/阳公嗣，/前尘。/醉卧客怀中，
诗：言笑徒多勤。/我时阅旧史，/独与三人亲。/未暇餐脱粟，
诗：苦心学平津。/草书亦何用，/醉墨淋衣巾。/一挥三十幅，
诗：持去听坐人。

# 送程德林赴真州
诗：君为县令元丰中，/吏贪功利以病农。/君欲言之路无从，/移书谏臣以自通。
诗：谏臣蹇受之也。/元丰天子为改容，/我时匹马江西东。/问之逆旅言颇同，
诗：老人爱君如刘宠，/小儿敬君如鲁恭。/尔来明目达四聪，/收拾驱骏冀北空，
诗：君为赤令有古风。/政声直人明光宫，/天厩如海养群龙。/并收其子岂不公，
诗：君之子祁举制策，/文学行义，/为时所称。/白沙何必烦此翁。

# 古别离送苏伯固
诗：三度别君来，/此别真迟暮。/白尽老髭须，/明日淮南去。
诗：酒罢月随人，/泪湿花如雾。/后夜逐君还，/梦绕湖边路。

# 谷林堂
诗：深谷下窈窕，/高林合扶疏。/美哉新堂成，/及此秋风初。
诗：我来适过雨，/物至如娱予。/稚竹真可人，/霜节已专车。
诗：老槐苦无赖，/风花欲填渠。/山鸦争呼号，/溪蝉独清虚。
诗：寄怀劳生外，/得句幽梦。/古今正自同，/岁月何必书。

# 予少年颇知种松手植数万株皆中梁柱矣都梁山中见杜舆秀才求学其法戏赠二首
诗：露宿泥行草棘中，/十年春雨养髯龙。/如今尺五城南杜，/欲问东坡学种松。
诗：君方扫雪收松子，/我已开榛得茯苓。/为问何如插杨柳，/明年飞絮作浮萍。

# 行宿泗间见徐州张天骥次旧韵
诗：二年三蹑过淮舟，/款段还逢马少游。/无事不妨长好饮，/著书自要见穷愁，
诗：孤松早偃原非病，/倦鸟虽还岂是休。/更欲河边几来往，/只今霜雪已蒙头。

# 次韵刘景文赠傅羲秀才
诗：幼眇文章宜和寡，/峥嵘肝肺亦交难。/未能飞瓦弹清角，/肯便投泥戏泼寒。
诗：忽见秋风吹洛水，/遥知霜叶满长安。/诗成送与刘夫子，/莫遣孙郎帐下看。

# 在彭城日与定国为九日黄楼之会今复以是日相遇于宋凡十五年忧乐出处有不可胜言者而定国学道有得百念灰冷而颜益壮顾予衰病心形俱倅感之作诗
诗：菊盏萸囊自古传，/长房宁复是臞仙。/应从汉武横汾日，/数到刘公戏马年。
诗：对玉山人今老矣，/见恒河性故依然。/王郎九日诗千首今赋黄楼第二篇。

# 九日次定国韵
诗：朝菌无晦朔，/蟪蛄疑春秋。/南柯已一世，/我眠未转头。
诗：仙人视吾曹，/何异蜂蚁稠。/不知蛮触氏，/自有两国忧。
诗：我观去来今，/未始一念留。/奔驰竟何得，/而起无穷羞。
诗：王郎误涉世，/屡献久不酬。/黄金散行乐，/清诗出穷愁。
诗：俯仰四十年，/始知此生浮。/轩裳陈道路。/往往儿童收。
诗：封侯起大第，/或是君家驺。/似闻负贩人，/中有第一流。
诗：炯然径寸珠，/藏此百结裘。/意行无车马，/倏忽略九州。
诗：邂逅独见之，/天与非人谋。/笑我方醉梦，/衣冠戏沐猴。
诗：力尽病骐骥，/伎穷老伶优。/北山有云根，/寸田自可耰。
诗：会当无何乡，/同作逍遥游。/归来城郭是，/空有累累丘。
