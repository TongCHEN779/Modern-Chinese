# 集禧观开启祈雪道场青词
原：元祐元年二月六日
原：伏以麦将覆块，雪未掩尘；嗣岁之忧，下民安诉。具严法会，祗款閟宫。仰冀同云，溥滋新腊。

# 景灵宫宣光殿奉安神宗皇帝御容日开启道场青词
原：元祐二年三月十四日
原：伏以天鉴不远，诚感则通。方宝构之肇新，宜神游之降格。具严法席，高味灵篇。内安清净之居，外锡烝黎之福。

# 集禧观开启祈雨道场青词
原：元祐二年三月二十五日
原：洞渊龙王，水府圣众。饥馑之患，民流者期年，吁嗟之求，词穷于是日。乃眷阴灵之宅，实为云雨之司。涵濡之功，俄顷而办。罔吝天泽，以答民瞻。

# 集禧观洪福殿等处罢散谢雨道场青词
原：德有愧于动天，敢辞屡请，道无私而应物，岂间微诚。霈一雨以咸周，起三农于既病。仰承灵贶，莫报深仁。

# 太皇太后皇太后皇太妃受册奏告景灵宫等处青词
原：元祐二年七月十九日
原：伏以祗是亲闱，庶几孝治。配德祖考，既务极于推崇；笃生眇冲，亦敢忘于褒显。将奉宝册，率循旧章。徼福于神，先期以告。

# 神宗皇帝御容进发前一日奏告诸宫观等处青词
原：元祐二年九月二十五日
原：嵩洛之间，山陵所在。严道释之净宇，奉衣冠之别祠。恭择良辰，启行仙驭。敢徼福于群圣，庶流祉于含生。仰叩真灵，冀垂昭鉴。

# 隆祐宫设庆宫醮青词
原：元祐二年
原：伏以长乐告成，光动紫宫之像，清都下照，诚通绛阙之仙。祗率多仪，肃陈菲荐。永惟慈孝之本，克享天人之心。介方寿之无疆，锡五福之纯备。

# 西岳庙开启祈雨道场青词
原：元祐三年七月十三日
原：伏以二华之尊，作镇于西极；兆人所急，望岁于秋成。谷既日滋，雨不时霈。敢以病告，于我有抻。闵兹将槁之苗，赐以崇朝之泽。惟神之德，非我敢忘。

# 中太一宫真室殿开启天皇九曜消灾集福道场青词
原：臣以冲眇，嗣承列圣之休，济于艰难，实赖文母之德。临莅四载，勤劳百为。畏天之威，未尝终日而豫怠，视民如子，惟恐一夫之困穷。伏愿上帝降祥，众真垂祐。消禳灾沴，水底寿康。恭陈宝箓之科，仰扣神游之馆。敢祈昭鉴，下察孝心。

# 皇太妃宫阁庆落成开启道场青词
原：伏以良辰袭吉，华构一新。仰荷褒崇之私，得伸鞠育之报。落成告备，法会有严。请命上穹，驰神真圣。庶精诚之必达，锡寿祉于无穷。
