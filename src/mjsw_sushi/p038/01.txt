# 东府雨中别子由
诗：庭下梧桐树，/三年三见汝。/前年适汝阴，/见汝鸣秋雨。
诗：去年秋雨时，/我自广陵归。/今年中山去，/白首归无期。
诗：客去莫叹息，/主人亦是客。/对床定悠悠，/夜雨空萧瑟。
诗：起折梧桐枝，/赠汝千里行。/归来知4健否？/莫忘此时情。

# 谢运使仲适座上送王敏仲北使

诗：幸子遇明主，/陈经入西厢。/归期不可缓，/倚相宜在旁。

# 雪浪石
题解：次韵滕大夫三首
诗：太行西来万马屯，/势与岱岳争雄尊。/飞狐上党天下脊，/半掩落日先黄昏。
诗：削成山东二百郡，/气压代北三家村。/千峰右卷矗牙帐，/崩崖凿断开土门。
诗：朅来城下作飞石，/一炮惊落天骄魂。/承平百年烽燧冷，/此物僵卧枯腕。
诗：画师争摹雪浪势，/天工不见雷斧痕。/离堆四面绕江水，/坐无蜀士谁与论。
诗：老翁儿戏作飞雨，/把酒坐看珠跳盆。/此身自幻孰非梦，/故国山水聊心存。
诗：我顷三章乞越州，/欲寻万壑看交流。/且凭造物开山骨，/已见天吴出浪头。
诗：石中有似海兽形状。/履道凿池虽可致，/玉川卷地若为收。/洛阳泉石今谁主？
诗：莫学痴人李与牛。

# 石芝并引
原：予尝梦食石芝，作诗记之。今乃真得石芝于海上，子由和前诗见寄。予顷在京师，有凿井得如小儿手以献者。臂指皆具，肤理若生。予闻之隐者，此肉芝也。与子由烹而食之。追记其事，复次前韵。
诗：土中一掌婴儿新，/爪指良是肌骨匀。/见之怖走谁敢食，/天赐我尔不及宾。
诗：旌阳远游同一许，/长史玉斧皆门户。/我家韦布三百年，/只有阴功不知数。
诗：跪陈八簋加六瑚，/化人视之真块苏。/肉芝烹熟石芝老，/笑唾熊掌嚬雕胡。
诗：老蚕作茧何时脱，/梦想至人空激烈。/古来大药不可求，/真契当如磁石铁。

# 鹤叹
诗：园中有鹤驯可呼，/我欲呼之立坐隅。/鹤有难色侧睨予，/岂欲臆对如鵬乎？
诗：我生如寄良畸孤，/三尺长胫阁瘦躯。/俯啄少许便有，/何至以身为子娱。
诗：驱之上堂立斯须，/投以饼饵视若无。/戛然长鸣乃下趋，/难进易退我不如。

# 刘丑厮诗
诗：刘生望都民，/病羸寄空窑。/有子曰丑厮，/十二行操瓢。
诗：墦间得粒，/雪中拾堕樵。/饥饱共生死，/水火同焚漂。
诗：病翁恃一褐，/度此积雪宵。/哀哉二暴客，/掣去如饥鸮。
诗：翁既死于寒，/客亦易此龆。/崎岖走亭长，/不惮雪径遥。
诗：我仇祝与苑，/物色同遮邀。/行路为出涕，/二客竟就枭。
诗：浇浇诉我庭，/慷慨惊吾僚。/曰此可名寄，/追配郴之荛。
诗：恨我非柳子，/击节为尔谣。/官赐二万钱，/无家可归娇。
诗：为媾他日妇，/婉然初垂髫。/洗沐作小吏，/裹头束其腰。
诗：笔砚耕学苑，/弓矛战天骄。/壮大随尔好，/忠孝福可微。
诗：相国有折胁，/封侯或吹箫。/人事岂易料，/勿轻此僬侥。

诗：老去此生一诀，/兴来明日重游。/卧闻三老白事，/半夜南风打头。

# 六月七日泊金陵阻风得钟山泉公书寄诗为谢
诗：今日江头天色恶，/炮车云起风欲作。/独望钟山唤宝公，/林间白塔如孤鹤。
诗：宝公骨冷唤不闻，/却有老泉来唤人。/电眸虎齿霹雳舌，/为余吹散干峰云。
诗：南行万里亦何事，/一酌曹溪知水味。/他年若画蒋山图，/为作泉公唤居士。

# 赠清凉寺和长老
诗：代北初辞没马尘，/江南来见卧云人。/问禅不契前三语，/施佛空留丈六身。
诗：老去山林徒梦想，/雨钟鼓更清新。/会须一洗黄茅瘴，/未用深藏白毡巾。

# 予前后守倅杭凡五年夏秋之间蒸热不可过独中和堂东南颊下瞰海门洞视万里三伏常萧然也绍圣元年六月舟行赴岭外热甚忽忆此处而作是诗
诗：忠孝王家千柱宫，/东坡作吏五年中。/中和堂上东南颊，/独有人间万里风。

# 慈湖夹阻风五首
诗：捍索桅竿立啸空，/篙师酣寝浪花中。/故应菅蒯知心腹，/弱缆能争万里风。
诗：此生归路转茫然，/无数青山水拍天。/犹有小船来卖饼，/喜闻墟落在山前。
诗：我行都是退之诗，/真有人家水半扉。/千顷桑麻在船底，/空石发挂鱼衣。
诗：日轮亭午汗珠融，/谁识南讹长养功。/暴雨过云聊一快，/未妨明月却当空。
诗：卧看落月横干丈，/起唤清风得半帆。/且并水村鼓侧过，/人间何处不巉岩。
