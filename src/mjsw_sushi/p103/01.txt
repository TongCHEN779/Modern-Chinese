# 皇帝达太皇太后贺大辽正旦书
原：元祐元年十月二日
原：肇易岁元，发新荣于万物，仰遵慈诲，修旧好于两朝。远饬使轺，肃将礼币。庶迎寿祉，式副愿言。

# 皇帝贺大辽皇帝正旦书
原：元祐元年十丹
原：献岁发春，共讲三朝之庆。宝邻继好，茂膺五福之祥。申饬使车，往陈信币。永言欣颂，曷罄谕陈。

# 皇帝达太皇太后回大辽皇帝贺正旦书
原：元祐二年正月五日
原：百年之好，既讲于春朝；万寿之仪，兼陈于幄殿。恭因省侍，具述来音。感怿之怀，言宣莫罄。

# 皇帝回大辽皇帝贺正旦书
原：元祐二年正月五日
原：东风协应，感徂岁之更新。远使交驰，导欢言而如旧。粲然礼币，申以书词。欣怿之深，敷陈罔究。

# 皇帝达太皇太后回大辽皇帝贺坤成节书
原：元祐二年七月
原：嘉月令辰，笃生寿母，珍函重币，交庆宝邻。已恭致于德音，复钦传于慈旨。其为感怿，未易名言。

# 皇帝回大辽皇帝问候书
原：元祐二年七月
原：四牡载驰，远勤于使介。尺书为问，申讲于邻欢。方履素秋，克膺纯福。益祈保护，式副愿言。

# 皇帝达太皇太后贺大辽皇帝生辰书
原：元祐二年
原：寒律既周，诞辰载纪。恭被慈闱之诲，俾修庆币之仪。永介寿康，式符颂祷。更祈调卫，以副愿言。

# 皇帝贺大辽皇帝生辰书
原：元祐二年
原：大吕还宫，摄提正丑。载协诞弥之庆，永膺寿考之祥。临遣使轺，往陈信币。其为欣祷，莫尽名言。

# 皇帝达太皇太后贺大辽皇帝正旦书
原：元祐三年
原：岁律肇新，邻欢载讲。恭被慈闱之诲，远通庆币之诚。益冀保颐，永绥寿嘏。

# 皇帝贺大辽皇帝正旦书
原：三阳朋来，庆二仪之交泰；两朝继好，纳万民于阜昌。申敕使车，肃将礼币。愿符善祷，永介纯厘。

# 皇帝回大辽皇帝贺兴龙节书
原：元祐二年十月
原：诞日载临，邻欢岁讲。封疆虽远，晷刻不逾。惟信睦之交修，识情文之两至。益深雅好，良极欣悰。

# 皇帝达太皇太后回大辽皇帝问候书
原：元祐二年十月
原：嘉平纪月，震夙惟时。属兹庆使之来，重以慈阉之间。寻因省侍，悉致诚言。欣感之深，敷陈罔究。

# 皇帝回大辽皇帝贺正旦书
原：元祐三年
原：献岁发春，方祝永年之庆；睦邻敦好，益修奕世之欢。信币精华，书词温缛。再维雅契，良极欣惊。

# 皇帝达太皇太后回大辽皇帝贺正旦书
原：元祐三年
原：正岁履端，远勤于华使，慈闱申庆，重领于珍函。省侍之，诚言已达。永惟欣感，莫究言宣。

# 皇帝回大辽皇帝贺兴龙节书
原：世睦宝邻，申以无穷之好，岁驰华使，及兹载夙之辰。阅词币之兼隆，识情文之备至。愿言欣感，难悉究陈。

# 皇帝达太皇太后回大辽皇帝问候书
原：遣使为寿，既欣邻好之修，因书见诚，兼致慈闱之问。侍言有次，来意毕陈。感怿之深，敷陈罔既。

# 皇帝达太皇太后回大辽皇帝贺坤成节书
原：元祐四年七月
原：星火西流，庆慈闱之诞日；皇华北至，讲邻国之诚言。既达来音，俾修报礼。感铭之素，敷述难周。

# 皇帝回大辽皇帝问候书
原：元祐四年七月
原：辐车重币，已修交庆之仪；尺素好音，复讲久要之信。属临素节，允迪纯禧。益冀保颐，式符企咏。
