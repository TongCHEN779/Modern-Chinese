# 新年五首
诗：晓雨暗人日，/春愁连上元。/水生挑菜渚，/烟湿落梅村。
诗：小市人归尽，/孤舟鹤踏翻。/犹堪慰寂寞，/渔火乱黄昏。
诗：北渚集群鹭，/新年何所之。/尽归乔木寺，/分占结巢枝。
诗：生物会有役，/谋生各及时。/何当禁毕弋，/看引雪衣儿。
诗：海国空自暖，/春山无限清。/冰溪纷瘴雨，/雪菌到江城。
诗：更待轻雷发，/先催冻笋生。/丰湖有藤菜，/似可敌莼羹。
诗：小邑浮桥外，/青山石岸东。/茶枪烧后有，/麦浪水前空。
诗：万户不禁酒，/三年真识翁。/结茅来此住，/岁晚有无同。
诗：荔子几时熟，/花头今已繁。/探春先拣树，/买夏欲论园。
诗：居士常携客，/参军许叩门。/明年更有味，/怀抱带诸孙。

# 和陶咏二疏
诗：二疏事汉时，/迹寓心已去。/许侯何足道，/宁识此高趣。
诗：可怜魏丞相，/免冠谢陋举。/中兴多名臣，/有道独两傅。
诗：世途方毂击，/谁肯行此路。/是身如委蜕，/未蜕何所顾。
诗：已蜕则两忘，/身后谁毁誉。/所以遗子孙，/买田岂先务。
诗：我尝游东海，/所历若有素。/神交久从君，/屡梦今乃悟。
诗：渊明作诗意，/妙想非俗虑。/庶几二大夫，/见微而知著。

# 和陶咏三良
诗：此生太山重，/忽作鸿毛遗。/三子死一言，/所死良已微。
诗：贤哉晏平仲，/事君不以私。/我岂犬马哉，/从君求盖帷。
诗：杀身固有道，/大节要不亏。/君为社稷死，/我则同其归。
诗：顾命有治乱，/臣子得从违。/魏颗真孝爱，/三良安足希。
诗：仕宦岂不荣，/有时缠忧悲。/所以靖节翁，/服此黔娄衣。

# 和陶咏荆轲
诗：秦如马后牛，/吕氏非复嬴。/天欲厚其毒，/假手李客卿。
诗：功成志自满，/积恶如陵京。/灭身会有时，/徐观可安行。
诗：沙丘一狼狈，/笑落冠与缨。/太子不少忍，/顾非万人英。
诗：魏韩裂智伯，/肘足本无声。/胡为弃成谋，/托国此狂生。
诗：荆轲不足说，/田子老可惊。/燕赵多奇士，/惜哉亦虚名。
诗：杀父囚其母，/此岂容天庭。/亡秦只三户，/况我数十城。
诗：渐离虽不伤，/陛戟加周营。/至今天下人，/愍燕欲其成。
诗：废书一太息，/可见千古情。

# 和郭功甫韵送芝迫人游隐静

诗：我愿焚囊钵，/不作陈俗具。/会取却归时，/只是而今路。

# 和陶移居二首并引
原：去岁三月，自水东嘉祐寺，迁居合江楼，迨今一年。多病鲜欢，颇怀水东之乐。得归善县后隙地数亩，父老云：此古白鹤观也。意欣然，欲居之，乃和此诗。
诗：昔我初来时，/水东有幽宅。/晨与鸦鹊朝，/暮与牛羊夕。
诗：谁令迁近市，/日有造请役。/歌呼杂闻巷，/鼓角鸣枕席。
诗：出门无所诣，/乐事非宿昔。/病瘦独弥年，/束薪与谁析。
诗：洄潭转碕岸，/我作《江郊》诗。/今为一廛氓，/此邦乃得之。
诗：葺为无邪斋，/思我无所思。/古观废已久，/白鹤归何时。
诗：我岂丁令威，/千岁复还兹。/江山朝福地，/古人不我欺。

# 食荔支二首并引
原：惠州太守东堂，祠故相陈文惠公。堂下有公手植荔支一株，郡人谓之将军树。今岁大熟，尝啖之，下逮吏卒。其高不可致者，纵猿取之。
诗：丞相祠堂下，/将军大树旁。/炎云骈火实，/瑞露酌天浆。
诗：烂紫垂先熟，/高红挂远扬。/分甘遍铃下，/也到黑衣郎。
诗：罗浮山下四时春，/卢橘杨梅次第新。/日啖荔支三百颗，/不辞长作岭南人。

诗：别后与谁同把酒，/客中无日不思家。/田园知有儿孙委，/早晚扁舟到海涯。

# 和陶桃花源并引
诗：世传桃源事，/多过其实。/考渊明所记，/止言先世避秦乱来此，
诗：则渔人所见，/似是其子孙，/非秦人不死者也。/又云杀鸡作食，
诗：岂有仙而杀者乎？/旧说南阳有菊水，/水甘而芳，/民居三十家，
诗：饮其水，/皆寿，/或至百二三十岁。/蜀青城山老人村，
诗：有见五世孙者，/道极险远，/生不识盐醯，/而溪中多枸杞，
诗：根如龙蛇，/饮其水，/故寿。/近岁道稍通，
诗：渐能致五味，/而寿益衰，/桃源盖此此也欤。/使武陵太守得而至焉，
诗：则已化为争夺之场久矣。/尝意矢壤间，/若此者甚众，/不独桃源。
诗：予在颖州，/梦至一官府，/人物与俗间无异，/而山川清远，
诗：有足乐者。/顾视堂上，/榜曰仇池。/觉而念之，
诗：仇池武都氐故地，/杨难当所保，/余何为居之。/明日，
诗：以问客。/客有赵令时德麟者，/曰：/“公何问此，
诗：此乃福地，/小有洞天之附庸也。/杜子美盖云：/万古仇池穴，
诗：潜通小有天。”/他日工部侍郎王钦臣仲至谓余曰：/“吾尝奉使过仇池，/有九十九泉，
诗：万山环之，/可以避世，/如桃源也。”
诗：凡圣无异居，/清浊共此世。/心闲偶自见，/念起忽已逝。
诗：欲知真一处，/要使六用废。/桃源信不远，/杖藜可小憩。
诗：躬耕任地力，/绝学抱天艺。/臂鸡有时鸣，/尻驾无可税。
诗：苓龟亦晨吸，/杞狗或夜吠。/耘樵得甘芳，/龁啮谢炮制。
诗：子骥虽形隔，/渊明已心诣。/高山不难越，/浅水何足厉。
诗：不如我仇池，/高举复几岁。/从来一生死，/近又等痴慧。
诗：蒲涧安期境，/在广州。/罗浮稚川界。/梦往从之游，
诗：神交发吾蔽。/桃花满庭下，/流水在户外。/却笑逃秦人，
诗：有畏非真契。

# 两桥诗并引
原：惠州之东，江溪合流，有桥，多废坏，以小舟渡。罗浮道士邓守安，始作浮桥。以四十舟为二十舫，铁锁石碇，随水涨落，榜日东新桥。州西丰湖上，有长桥，屡作屡坏。栖禅院僧希固筑进两岸，为；飞楼九间，尽用石盐木，坚若秩石，榜曰西新桥。皆以绍圣三年六月毕工，作二诗落之。

# 东新桥

诗：机牙任信缩，/涨落随高低。/辘轳卷巨绠，/青蛟挂长堤。

诗：喜笑争攀跻。/鱼龙亦惊逃，/雷雹生马蹄。/嗟此病涉久，
诗：公私困留稽。/奸民食此险，/出没如凫医。/似卖失船壶，
诗：如去登楼梯。/不知百年来，/几人陨沙泥。/岂知涛澜上，

# 撷菜并引

# 悼朝云并引
原：绍圣元年十一月，戏作《朝云》诗。三年七月五日，朝云病亡于惠州，葬之栖禅寺松林中东南，直大圣塔。予既铭其墓，且和前诗以自解。朝云始不识字，晚忽学书，粗有楷法。盖尝从泗上比丘尼皋冲学佛，亦略闻大义，且死，诵《金刚经》四句偈而绝。
诗：苗而不秀岂其天，/不使童乌与我玄。/驻景恨无千岁药，/赠行惟有小乘禅。
诗：伤心一念偿前债，/弹指三生断后缘。/归卧竹根无远近，/夜灯勤礼塔中仙。

# 纵笔

# 丙子重九二首
诗：三年瘴海上，/越峤真我家。/登山作重九，/蛮菊秋未花。
诗：惟有黄茅浪，/堆城生坳窊。/蜑酒蘖众毒，/酸甜如梨楂。
诗：何以侑一樽，/邻家馈蛙蛇。/亦复强取醉，/欢谣杂悲嗟。
诗：今年吁恶岁，/僵仆如乱麻。/此会我虽健，/狂风卷朝霞。
诗：使我如霜月，/孤光挂天涯。/西湖不欲往：/暮树号寒鸦。
诗：穷途不择友，/过眼如乱云。/子谁复数，/坐阅两使君。
诗：共饮去年堂，/俯看秋水纹。/此水与此人，/相追两沄沄。
诗：老去各休息，/造化嗟长勤。/佳哉此令节，/不惜与子分。
诗：何以娱我客，/游鱼在清溃。/水师三百指，/铁网欲掩群。
诗：获多虽一快，/买放尤可欣。/此乐真不朽，/明年我归耘。

# 和陶乞食

# 和陶和胡西曹示顾贼曹

# 次韵子由所居六咏
