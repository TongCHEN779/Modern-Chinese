# 送李公恕赴阙
诗：君才有如切玉刀，/见之凛凛寒生毛。/愿随壮士斩蛟蜃，/不愿腰间缠锦绦。
诗：用违其才志不展，/坐与胥吏同疲劳。/忽然眉上有黄气，/吾君渐欲收英髦。
诗：立谈左右皆动色，/一语径破千言牢。/我顷分符在东武，/脱略万事惟嬉遨。
诗：尽坏屏障通内外，/仍呼骑曹为马曹。/君为使者见不问，/反更对饮持双螯。
诗：酒酣箕坐语惊众，/杂以嘲讽穷诗骚。/世上小儿多忌讳，/独能容我真贤豪。
诗：为我买田临汶水，/逝将归去诛蓬蒿。/安能终老尘土下，/俯仰随人如桔槔。

# 张寺丞益斋
诗：张子作斋舍，/而以益为名。/吾闻诸夫子，/求益非速成。
诗：譬如远游客，/日夜事征行。/今年适燕蓟，/明年走蛮荆。
诗：东观尽沧海，/西涉渭与泾。/归来闭户坐，/八方在轩庭。
诗：又如学医人，/识病由饱更。/风雨晦明淫，/跛躄喑聋盲。
诗：虚实在其脉，/静躁在其情。/荣枯在其色，/寿天在其形。
诗：苟能阅千人，/望见知死生。/为学务日益，/此言当自程。
诗：为道贵日损，/此理在既盈。/愿言书此诗，/以为益斋铭。

# 虔州八境图八首并引
诗：《南康八境图》者，/太守孔君之所作也。/君既作石城，/即其城上楼观台榭之所见而作是图也，
诗：东望七闽，/南望五岭，/览群山之参差，/俯章贡之奔流，
诗：云烟出没，/草木蕃丽，/邑屋相望，/鸡犬之声相闻。
诗：观此图也，/可以茫然而思，/粲然而笑，/慨然而叹矣。
诗：苏子曰：/此南康之一境也，/何从而八乎？/所自观之者异也。
诗：且子不见夫日乎，/其旦如盘，/其中如珠，/其夕如破壁，
诗：此岂三日也哉。/苟知夫境之为八也，/则凡寒暑朝夕、雨旸晦冥之异，/坐作行立、哀乐喜怒之接于吾目而感于吾心者，
诗：有不可胜数者矣，/岂特八乎？/如知夫八之出乎一也，/则夫四海之外，
诗：诙诡谲怪，/《禹贡》之所书，/邹衍之所谈，/相如之所赋，
诗：虽至千万未有不一者也。/后之君子，/必将有感于斯焉。/乃作诗八章，
诗：题之图上。
诗：坐看奔湍绕石楼，/使君高会百无忧。/三犀窃鄙秦太守，/八咏聊同沈隐侯。
诗：涛头寂寞打城还，/章贡台前暮霭寒。/倦客登临无限思，/孤云落日是长安。
诗：白鹊楼前翠作堆，/萦云岭路若为开。/故人应在干山外，/不寄梅花远信来。
诗：朱楼深处日微明，/皂盖归时酒半醒。/薄暮渔樵人去尽，/碧溪青嶂绕螺亭。
诗：使君那暇日参禅，/一望丛林一怅然。/成佛莫教灵运后，/著鞭从使祖生先。
诗：却从尘外望尘中，/无限楼台烟雨蒙。/山水照人迷向背，/只寻孤塔认西东。
诗：云烟缥缈郁孤台，/积翠浮空雨半开。/想见之罘观海市，/绛宫明灭是蓬莱。
诗：回峰乱嶂郁参差，/云外高人世得知。/谁向空山弄明月，/山中木客解吟诗。

# 读孟郊诗二首
诗：夜读孟郊诗，/细字如牛毛。/寒灯照昏花，/佳处时一遭。
诗：孤芳擢荒秽，/苦语诗骚。/水清石凿凿，/湍激不受篙。
诗：初如食小鱼，/所得不偿劳。/又似煮彭蠕，/竟日持空螯。
诗：要当斗僧清，/未足当韩豪。/人生如朝露，/日夜火消膏。
诗：何苦将两耳，/听此寒虫号。/不如且置之，/饮我玉色醪。
诗：我憎孟郊诗，/复作孟郊语。/饥肠自鸣唤，/空壁转饥鼠。
诗：诗从肺腑出，/出辄愁肺腑。/有如黄河鱼，/出膏以自煮。
诗：尚爱《铜斗歌》，/鄙俚颇近古。/桃弓射鸭罢，/独速短蓑舞。
诗：不忧踏船翻，/踏浪不踏土。/吴姬霜雪白，/赤脚浣白纻。
诗：嫁与踏浪儿，/不识离别苦。/歌君江湖曲，/感我长羁旅。

# 芙蓉城并叙
原：世传王迥子高与仙人周瑶英游芙蓉城。元丰元年三月，余始识子高，问之，信然。乃作此诗，极其情而归之正，亦变风止乎礼义之意也。
诗：芙蓉城中花冥冥，/谁其主者石与丁。/珠帘玉案翡翠屏，/霞舒云卷千娉婷。
诗：中有一人长眉青，/炯如微云淡疏星。/往来三世空炼形，/竟坐误读《黄庭经》。
诗：天门夜开飞爽灵，/无复白日乘云耕。/俗缘干劫磨不尽，/翠被冷落凄馨。
诗：因过缑山朝帝廷，/夜闻笙箫弭节听。/飘然而来谁使令，/皎如明月入窗棂。
诗：忽然而去不可执，/寒衾虚幌风冷冷。/仙宫洞房本不扃，/梦中同蹑凤凰翎。
诗：径度万里如奔霆，/玉楼浮空耸亭亭。/天书云篆谁所铭，/绕楼飞步高蛉飒。
诗：仙风锵然韵流铃，/蘧蘧形开如酒醒。/芳卿寄谢空丁宁，/一朝覆水不返瓶，
诗：罗巾别泪空荧荧。/春风花开秋叶零，/世间罗绮纷膻腥。/此身流浪随沧溟，
诗：偶然相值两浮萍。/愿君收视观三庭，/勿与嘉谷生蝗螟。/从渠一念三千龄，
诗：下作人间尹与邢。

# 起伏龙行并叙
原：徐州城东二十里，有石潭。父老云：“与泗水通，增损清浊，相应不差，时有河鱼出焉。”元丰元年春旱，或云置虎头潭中，可以致雷雨。用其说作《起伏龙行》。
诗：何年白竹千钧弩，/射杀南山雪毛虎。/至今颅骨带霜牙，/尚作四海毛虫祖。
诗：东方久旱千里赤，/三月行人口生土。/碧潭近在古城东，/神物所蟠谁敢侮。
诗：上敧苍石拥岩窦，/下应清河通水府。/眼光作电走金蛇，/鼻息为云擢烟缕。
诗：当年负图传帝命，/左右羲轩诏神禹。/尔来怀宝但贪眠，/满腹雷霆暗不吐。
诗：赤龙白虎战明日，/是月丙辰，/明日庚寅。/倒卷黄河作飞雨。
诗：嗟我岂乐斗两雄，/有事径须烦一怒。

诗：提壶劝酒意虽重，/杜鹃催归声更速。/酒阑人散却关门，/寂历斜阳挂疏木。

# 种德亭并叙
原：处士王复，家于钱塘。为人多技能，而医尤精，期干活人而已，不志于利。筑室候潮门外，治园圃，作亭榭，以与贤士大夫游，惟恐不及，然终无所求。人徒知其接花艺果之勤，而不知其所种者德也，乃以名其亭，而作诗以遗之。
诗：小圃傍城郭，/闭门芝术香。/名随市人隐，/德与佳木长。
诗：元化善养性，/仓公多禁方。/所活不可数，/相逢旋相忘。
诗：但喜宾客来，/置酒花满堂。/我欲东南去，/再观双桧苍。
诗：山茶想出屋，/湖橘应过墙。/木老德亦熟，/吾言岂荒唐。

# 闻辩才法师复归上天竺以诗戏问
诗：道人出山去，/山色如死灰。/白云不解笑，/青松有哀。
诗：忽闻道人归，/鸟语山容开。/神光出宝髻，/法雨洗浮埃。
诗：想见南北山，/花发前后台。/寄声问道人，/借禅以为诙，
诗：何所闻而去，/何所见而回？/道人笑不答，/此意安在哉？
诗：昔年本不住，/今者亦无来。/此语竟非是，/且食白杨梅。

# 和子由送将官梁左藏仲通
诗：雨足谁言春麦短，/城坚不怕秋涛卷。/日长惟有睡相宜，/半脱纱巾落纨扇。
诗：芳草不锄当户长，/珍禽独下无人见。/觉来身世都是梦，/坐久枕痕犹著面。
诗：城西忽报故人来，/急扫风轩炊麦饭。/徐州所出。/伏波论兵初矍铄，
诗：中散谈仙更清远。/南都从事亦学道，/不惜肠空夸脑满。/问羊他日到金华，
诗：应许相将游阆苑。/黄初平之兄，/寻其弟于金华山。

诗：翘关负重君无力，/十年不入纷华域。/故人坐上见君文，/谓是古人吁莫测。
诗：新诗说尽万物情，/硬黄小字临黄庭。/故人已去君未到，/空吟河畔草青青。
诗：谁谓他乡各异县，/天遣君来破吾愿。/一闻君语识君心，/短李髯孙眼中见。

诗：干金敝帚那堪换，/我亦淹留岂长算。/山中既未决同归，/我聊尔耳君其漫。

# 仆曩于长安陈汉卿家见吴道子画佛碎烂可惜其后十年复见之于鲜于子骏家则已装背完好子骏以见遗作诗谢之
诗：贵人金多身复闲，/争买书画不计钱。/已将铁石充逸少，/殷铁石，
诗：梁武帝时人。/今法帖大王书中有铁石字。/更补朱繇为道玄。/世所收吴道子画，
诗：多朱繇笔也。/烟薰屋漏装玉轴，/鹿皮苍璧知谁贤。/吴生画佛本神授，
诗：梦中化作飞空仙。/觉来落笔不经意，/神妙独到秋毫颠。/昔我长安见此画，
诗：叹息至宝空潜然。/素丝断续不忍看，/已作蝴蝶飞联翩。/君能收拾为补缀，
诗：体质散落嗟神全。/志公仿佛见刀尺，/修罗天女犹雄妍。/如观老杜飞鸟句，
诗：脱字欲补知无缘。/问君乞得良有意，/欲将俗眼为洗湔。/贵人一见定羞怍，
诗：锦囊干纸何足捐。/不须更用博麻缕，/付与一炬随飞烟。

诗：飞鸢悔前笑，/黄犬悲晚悟。/自非陶靖节，/谁识此闲趣。

诗：草书妙绝吾所兄，/真书小低犹抗行。/论文作诗俱不敌，/看君谈笑收降旌。
诗：去年逾月方出昼，/予去年留齐月余。/为君剧饮几濡首。/今年过我虽少留，
诗：寂寞陶潜方止酒。/此行公择病酒，/多不饮。/别时流涕揽君须，
诗：悬知此欢堕空虚。/松下纵横屐齿，/门前坂辘想君车。/怪君一身都是德，
诗：近之清润沦肌骨。/细思还有可恨时，/不许蓝桥见倾国。/公择有婢名云英，
诗：屡欲出，/不果。

# 送郑户曹

诗：隆准飞上天，/重瞳亦成灰。/白门下吕布，/大星陨临淮。
诗：尚想刘德舆，/置酒此徘徊。/尔来苦寂寞，/废圃多苍苔。
诗：河从百步响，/山到九里回。/山水自相激，/夜声转风雷。
诗：荡荡清河顷，/黄楼我所开。/秋月堕城角，/春风摇酒杯。

诗：他年君倦游，/白首赋归来。/登楼一长啸，/使君安在哉。

# 次韵黄鲁直见赠古风二首

诗：兹时不少假，/俯仰霜叶黄。/期君蟠桃枝，/千岁终一尝。
诗：顾我如苦李，/全生依路傍。/纷纷不足道，/悄悄徒自伤。

诗：人生当著几纳屐，/定心肯为微物起。/此墨足支三十年，/但恐风霜侵发齿。

# 答范淳甫
诗：吾州下邑生刘季，/谁数区区张与李。/来诗有张仆射、李临淮之句。/重瞳遗迹已尘埃，
诗：惟有黄楼临泗水。/郡有厅事，/俗谓之霸王厅，/相传不可坐，
诗：仆拆之以盖黄楼。/而今太守老且寒，/侠气不洗儒生酸。/犹胜白门穷吕布，
诗：欲将鞍马事曹瞒。

# 次韵答王定国
诗：每得君诗如得书，/宣心写妙书不如。/眼前百种无不有，/知君一以诗驱除。
诗：传闻都下十日雨，/青泥没马街生鱼。/旧雨来人今不来，/悠然独酌卧清虚。
诗：我虽作郡古云乐，/山川信美非吾庐。/愿君不废重九约，/念此衰冷勤呵嘘。

# 和鲜于子骏郓州新堂月夜二首
原：前次韵，后不次。
诗：去岁游新堂，/春风雪消后。/池中半篙水，/池上千尺柳。
诗：佳人如桃李，/胡蝶入衫袖。/山川今何许，/疆野已分宿。
诗：岁月不可思，/驶若船放溜。/繁华真一梦，/寂寞两荣朽。
诗：惟有当时月，/依然照杯酒。/应怜船上人，/坐稳不知漏。
诗：明月入华池，/反照池上堂。/堂中隐几人，/心与水月凉。
诗：风萤已无迹，/露草时有光。/起观河汉流，/步履响长廊。
诗：名都信繁会，/干指调笙簧。/先生病不饮，/童子为烧香。
诗：独作五字诗，/清卓如韦郎。/诗成月渐侧，/皎皎两相望。

# 送将官梁左藏赴莫州
