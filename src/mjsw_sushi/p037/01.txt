诗：刃西屠横海鲲，/应余诗谶是游魂。/归来趁别陶弘景，/看挂衣冠神武门。

# 次韵颖叔观灯
诗：安西老守是禅僧，/到处应然无尽灯。/永夜出游从万骑，/诸羌入看拥千层。
诗：便因行乐令投甲，/不用防秋更打冰。/振旅归来还侍宴，/十分宣劝恐难胜。

# 次韵钱穆父王仲至同赏田曹梅花
诗：寒厅不知春，/独立耿玉雪。/闭门愁永夜，/置酒及明发。
诗：忽惊庭户晓，/未受烟雨没。/浮光风宛转，/照影水方折。
诗：鬓霜未易扫，/眉斧真自伐。/惟当此花前，/醉卧黄昏月。

# 送襄阳从事李友谅归钱塘
诗：居杭积五岁，/自意本杭人。/故山归无家，/欲卜西湖邻。
诗：良田不难买，/静士谁当亲。/髯张既超然，/老潜亦绝伦。
诗：李子冰玉姿，/文行两清淳。/归从三人游，/便足了此身。
诗：公堤不改昨，/姥岭行开新。/幽梦随子去，/松花落衣巾。

# 次韵吴传正枯木歌
诗：天公水墨自奇绝，/瘦竹枯松写残月。/梦回疏影在东窗，/惊怪霜枝连夜发。
诗：生成变坏一弹指，/乃知造物初无物。/古为画师非俗士，/妙想实与诗同出。
诗：龙眠居士本诗人，/能使龙池飞霹雳。/君虽不作丹青手，/诗眼亦自工识拔。
诗：龙眠胸中有千驷，/不独画肉兼画骨。/但当与作少陵诗，/或自与君拈秃笔。
诗：东南山水相招呼，/万象入我摩尼珠。/尽将书画散朋友，/独与长铗归来乎。

# 送黄师是赴两浙宪
诗：世久无此士，/我晚得王孙。/宁非叔度家，/岂出次公门。
诗：白首沉下吏，/绿衣有公言。/哀哉吴越人，/久为江湖吞。
诗：官自倒帑廪，/饱不及黎元。/近闻海上港，/渐出水底村。
诗：愿君五袴手，/招此半菽魂。/一见刺史天，/稍忘狱吏尊。
诗：会稽入吾手，/镜湖小于盆。/比我东来时，/无复疮痍存。

# 送范中济经略侍郎分韵赋诗以元戎十乘以先启行为韵轼得先字且赠以鱼枕杯四马箠一
诗：梁李久乐祸，/自焚岂非天。/两鼠斗穴中，/一胜亦偶然。
诗：谋初要百虑，/善后乃万全。/庙堂选世将，/范氏真多贤。
诗：仁风被宿麦，/绿浪摇晴川。/号令耸毛羽，/先声落虚弦。
诗：我家天一方，/去路城西偏。/投竿困障日，/卖剑行归田。
诗：赠君荆鱼杯，/副以蜀马鞭。/一醉可以起，/毋令祖生先。

# 书晁说之考牧图后
诗：我昔在田间，/但知羊与牛。/川乎牛背稳，/如驾百斛舟。
诗：舟行无人岸自移，/我卧读书牛不知。/前有百尾羊，/听我鞭声如鼓鼙。
诗：我鞭不妄发，/视其后者而鞭之。/泽中草木长，/草长病牛羊。
诗：寻山跨坑谷，/腾趕筋骨强。/烟蓑雨笠长林下，/老去而今空见画。
诗：世间马耳射东风，/悔不长作多牛翁。

# 吕与叔学士挽词
诗：言中谋猷行中经，/关西人物数清英。/欲过叔度留终日，/未识鲁山空此生。
诗：议论凋零三益友，/功名分付二难兄。/老来尚有忧时叹，/此涕无从何处倾。

# 丹元子示诗飘飘然有谪仙风气吴传正继作复次其韵
诗：飞仙亦偶然，/脱命瞬息中。/惟诗不可拟，/如写天日容。
诗：梦中哦七言，/玉丹已入怀。/一语遭绰虐，/失身堕蓬莱。
诗：蓬莱至今空，/护短不养才。/上界足官府，/谪仙应退休。
诗：可怜吴与苏，/肮脏雪满头。/雪满头，/终当却与丹元子，
诗：笑指东海乘桴浮。

# 次韵王定国书丹元子宁极斋
诗：仙人与吾辈，/寓迹同一尘。/何曾五浆馈，/但有争席人。
诗：宁极无常居，/此斋自随身。/人那识郗鉴，/天不留封伦。
诗：误落世网中，/俗物愁我神。/先生忽扣户，/夜呼祁孔宾。
诗：便欲随子去，/著书未绝麟。/愿挂神虎冠，/往卜饮马邻。
诗：王郎濯纨绮，/意与陋巷亲。/南游苦不早，/倘及莼鲈新。

# 王仲至侍郎见惠稚栝种之礼曹北垣下今百日矣蔚然有生意喜而作诗
诗：翠栝东南美，/近生神岳阴。/惜哉不可致，/霜根络云岑。
诗：仙风振高标，/香实陨平林。/偶随樗栎生，/不为樵牧侵。
诗：忽惊黄茅岭，/稍出青玉针。/好事虽力取，/王城少知音。
诗：岂无换鹅手，/但知觅来禽。/高怀独夫子，/一见捐橐金。
诗：得之喜不寐，/赠我意殊深。/公堂开后阁，/凡木愧华簪。
诗：栽培一寸根，/寄予百年心。/常恐樊笼中，/摧我鸾鹤襟。
诗：谁知积雨后，/寒芒晓森森。/恨我迫归老，/不见汝十寻。
诗：苍皮护玉骨，/旦暮视古今。/何人风雨夜，/卧听饥龙吟。

# 次韵钱穆父马上寄蒋颖叔二首
诗：玉关不用一丸泥，/自有长城鸟鼠西。/剩与故人寻土物，/腊糟红麴寄驼蹄。
诗：多买黄封作洗泥，/使君来自陇山西。/高才得兔人人羡，/争欲寻踪觅旧蹄。

# 表弟程德孺生日
诗：仗下干官散紫庭，/微闻偶语说苏程。/长身自昔传甥舅，/寿骨遥知是弟兄。
诗：予与君皆寿骨贯耳，/班列中多指予二人，/不问而知其为中表也。/曾活万人宁望报，
诗：君在楚州，/予在杭州，/皆遇饥岁，/活数万人。
诗：只求五亩却归耕。/四朝遗老凋零尽，/鹤发他年几个迎。

# 七年九月自广陵召还复馆于浴室东堂八年六月乞会稽将去汶公乞诗乃复用前韵三首
诗：乞郡三章字半斜，/庙堂传笑眼昏花。/上人问我迟留意，/待赐头纲八饼茶。
诗：尚书学士得赐头纲龙茶一斤，/今年纲到最迟。
诗：梦绕吴山却月廊，/白梅卢橘觉犹香。/杭州梵天寺，/有月廊数百间，
诗：寺中多白杨梅卢橘。/会稽且作须臾意，/从此归田策最良。
诗：东南此去几时归，/倦鸟孤飞岂有期。/断送一生消底物，/三年光景六篇诗。

# 吴子野将出家赠以扇山枕屏
诗：峨峨扇中山，/绝壁信天剖。/谁知大圆镜，/衡霍入户牖。
诗：得之老月师，/画者一醉叟。/常疑若人胸，/自有云梦薮。
诗：千岩在掌握，/用舍弹指久。/低昂不自知，/恨寄儿女手。
诗：短屏虽曲折，/高枕谢奔走。/出家非今日，/法水洗无垢。
诗：浮游云释峤，/宴坐柳生肘。/忘怀紫翠间，/相与到白首。

# 大行太皇太后高氏挽词二首
诗：至矣吾三后，/功高汉已还。/复推元祐冠，/盖得永昭全。
诗：臣尝于经筵，/论奏仁宗皇帝谥曰明孝：/若明而不仁，/则民畏而不爱，
诗：仁而不明，/则民爱而不畏。/今大行太皇太后，/亦兼此二德，
诗：故天下思慕，/庶几于仁宗也。/有作犹非圣，/无私乃是天。
诗：侍臣谈道要，/家法信家传。/宰相以下，/尝于经筵论奏祖宗以来家法十事，
诗：书于记注。
诗：却狄安诸夏，/先王社稷臣。/固应祠百世，/何止活千人。
诗：定策天知我，/忘家帝念亲。/万方何以报，/得疾为勤民。

# 赠王觏
诗：何人生得宁馨子，/今夜初逢掣笔郎。/莫怪围棋忘瓜葛，/已能作赋继《灵光》。
