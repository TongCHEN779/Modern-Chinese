# 南歌子（寸恨谁云短）
诗：寸恨谁云短，/绵绵岂易裁。/半年眉绿未曾开，/明月好风闲处、是人猜。
诗：春雨消残冻，/温风到冷灰。/尊前一曲为谁回，/留取曲中一拍、待君来。

# 南歌子·楚守周豫出舞鬟
诗：绀绾双蟠髻，/云欹小偃巾。/轻盈红脸小腰身，/叠鼓忽催花拍、斗精神。
诗：空阔轻红歇，/风和约柳春。/蓬山才调更清新，/胜似缠头千锦、共藏珍。

# 南歌子（琥珀装腰佩）
诗：琥珀装腰佩，/龙香入领巾。/只应飞燕是前身，/共看剥葱纤手、舞凝神。
诗：柳絮风前转，/梅花雪里春。/鸳鸯翡翠两争新，/但得周郎一顾、胜珠珍。

# 南歌子（云鬓裁新绿）
诗：云鬓裁新绿；/霞衣曳晓红。/待歌凝立翠筵中，/一朵彩云何事、下巫峰。
诗：趁拍鸾飞镜，/回身燕漾空。/莫翻红袖过帘栊，/怕被杨花勾、嫁东风。

# 南歌子（见说东园好）
诗：见说东园好，/能消北客愁。/虽非吾土且登楼，/形尽江南南岸、此淹留。
诗：短日明枫缬，/清霜暗菊球。/流年回首付东流，/凭仗挽回潘鬓、莫教秋。

# 江城子（银涛无际卷蓬瀛）
诗：银涛无际卷蓬瀛。/落霞明，/暮云平。/曾见青鸾，/紫凤下层城。
诗：二十五弦弹不尽，/空感慨，/惜离情。/苍梧烟水断归程。
诗：卷霓旌，/为谁迎。/空有千红，/流泪寄幽贞。
诗：舞罢鱼龙云海晚，/千古恨，/入江声。

# 江城子（墨云拖雨过西楼）
诗：墨云拖雨过西楼。/水东流，/晚烟收。/柳外残阳，/回照动帘钩。
诗：今夜巫山真个好，/花未落，/酒新雪。/美人微笑转星眸。
诗：月华羞，/捧金瓯。/歌扇萦风，/吹散一春愁。
诗：试问江南诸伴侣，/谁似我，/醉扬州？

# 江城子（腻红匀脸衬檀唇）
诗：腻红匀脸衬檀唇。/晚妆新，/暗伤春。/手撚花枝，/谁会两眉颦。
诗：连理带头双口□，/留待与，/个中人。/淡烟笼月绣帘阴。
诗：画堂深，/夜沉沉。/谁道口□，/□系得人心。
诗：一自绿窗偷见后，/便憔倅，/到如今。

# 蝶恋花（花褪残红青杏小）
诗：花褪残红青杏小。/燕子飞时，/绿水人家绕。/枝上柳绵吹又少，/天涯何处无芳草。
诗：墙里秋千墙外道。/墙外行人，/墙里佳人笑。/笑渐不闻声渐悄，/多情却被无情恼。

# 蝶恋花·代人赠别
诗：一颗樱桃樊素口。/不要黄金，/只要人长久。/学画鸦儿犹未就，/眉间已作伤春皱。
诗：扑蝶西园随伴走。/花落花开，/渐解相思瘦。/破镜重来人在否，/章台折尽青青柳。

# 蝶恋花（春事阑珊芳草歇）
诗：春事阑珊芳草歇。/客里风光，/又过清明节。/小院黄昏人忆别，/落红处处闻啼鸠。
诗：咫尺江山分楚越。/目断魂销，/应是音尘绝。/梦破五更心欲折，/角声吹落《梅花》月。

# 蝶恋花·同安君生日放鱼，取《金光明经》救鱼事
诗：泛泛东风初破五。/江柳微黄，/万万千千缕。/佳气郁葱来绣户！
诗：当年江上生奇女。/一盏寿觞谁与举。/三个明珠，/膝上王文度。
诗：放尽穷鳞看圉圉，/天公为下曼陀雨。

# 蝶恋花（记得画屏初会遇）
诗：记得画屏初会遇。/好梦惊回，/望断高唐路。/燕子双飞来又去，/纱窗几度春光暮。
诗：那日绣帘相见处。/低眼佯行，/笑整香云缕。/敛尽春山羞不语，/人前深意难轻诉。

# 蝶恋花（昨夜秋风来万里）
诗：昨夜秋风来万里。/月上屏帏，/冷透人衣袂。/有客抱衾愁不寐，/那堪玉漏长如岁。
诗：羁舍留连归计未。/梦断魂消，/一枕相思泪。/衣带渐宽无别意，/新书报我添憔倅。

# 蝶恋花（玉枕冰寒消暑气）
诗：玉枕冰寒消暑气。/碧簟纱厨，/向午朦胧睡。/莺舌惺忪如会意，/无端画扇惊飞起。
诗：雨后初凉生水际。/人面桃花的的遥相似。/眼看红芳犹抱蕊，/丛中已结新莲子。

# 蝶恋花（雨霰疏疏经泼火）
诗：雨霰疏疏经泼火。/巷陌秋千，/犹未清明过。/杏子梢头香蕾破，/淡红褪白胭脂涴。
诗：苦被多情相折挫。/病绪厌厌，/浑似年时个。/绕遍回廊还独坐，/月笼云暗重门锁。

# 蝶恋花（蝶懒莺慵春过半）
诗：蝶懒莺慵春过半。/花落狂风，/小院残红满。/午醉未醒红日晚，/黄昏帘幕无人卷。
诗：云鬓霾松眉黛浅。/总是愁媒，/欲诉谁消遣。/未信此情难系绊，/杨花犹有东风管。

# 减字木兰花（云鬟倾倒）
诗：云鬟倾倒，/醉倚阑干风月好。/凭仗相扶，/误入仙家碧玉壶。
诗：连天衰草，/下走湖南西去道。/一舸姑苏，/便逐鸱夷去得无？

# 减字木兰花·西湖食荔支
诗：闽溪珍献，/过海云帆来似箭。/玉坐金盘，/不贡奇葩四百年。
诗：轻红严白，/雅称佳人纤手擘。/骨细肌香，/恰是当年十八娘。

# 减字木兰花·送赵令晦之
诗：春光亭下，/流水如今何在也。/岁月如梭，/白首相看拟奈何。
诗：故人重见，/世事年来千万变。/官况阑珊，/惭愧青松守岁寒。

# 减字木兰花（晓来风细）
诗：晓来风细，/不会鹊声来报喜。/却羡寒梅，/先觉春风一夜来。
诗：香笺一纸，/写尽回纹机上意。/欲卷重开，/读遍千回与万回。

# 减字木兰花（天台旧路）
诗：天台旧路，/应恨刘郎来又去。/别酒频倾，/忍听《阳关》第四声刘郎未老，/怀恋仙乡重得到。
诗：只恐因循，/不见而今劝酒人。

# 减字木兰花（琵琶绝艺）
诗：琵琶绝艺，/年纪都来十一二。/拨弄幺弦，/未解将心指下传。
诗：主人嗔小，/欲向春风先醉倒。/已属君家，/且更从容等待他。

# 减字木兰花（云容皓白）
诗：云容皓白，/破晓玉英纷似织。/风力无端，/欲学杨花更耐寒。
诗：相如未老，/梁苑犹能陪俊少。/莫惹闲愁，/且折江梅上小楼。

# 减字木兰花（玉房金蕊）
诗：玉房金蕊，/宜在玉人纤手里。/淡月朦胧，/更有微微弄袖风。
诗：温香熟美，/醉慢云鬟垂两耳。/多谢春工，/不是花红是玉红。

# 减字木兰花·以大琉璃杯劝王仲翁
诗：海南奇宝，/铸出团团如栲栳。/曾到昆仑，/乞得山头玉女盆。
诗：绛州王老，/百岁痴顽推不倒。/海口如门，/一派黄流已电奔。

# 减字木兰花（神闲意定）
诗：神闲意定，/万籁收声天地静。/玉指冰弦，/未动宫商意已传。
诗：悲风流水，/写-出寥寥千古意。/归去无眠，/一夜音在耳边。。

# 减字木兰花（银筝旋品）
诗：银筝旋品，/不用缠头千尺锦。/妙思如泉，/一洗闲愁十五年。
诗：为公少止，/起舞属公公莫起。/风里银山，/摆撼鱼龙我自闲。

# 减字木兰花（莺初解语）
诗：莺初解语，/最是一年春好处。/微雨如酥，/草色遥看近却无。
诗：休辞醉倒，/花不看开人易老。/莫待春回，/颠倒红英间绿苔。

# 减字木兰花（江南游女）
诗：江南游女，/问我何年归得去。/雨细风微，/两足如霜挽纻衣。
诗：江亭夜语，/喜见京华新样舞。/莲步轻飞，/迁客今朝始是归。

# 行香子·茶词
诗：绮席才终，/欢意犹浓。/酒阑时、高兴无穷。/共夸君赐，/初拆臣封。
诗：看分香饼，/黄金缕，/密云龙。/斗赢一水，/功敌千钟。
诗：觉凉生、两腋清风。/暂留红袖，/少却纱笼。/放笙歌散，/庭馆静，/略从容。

# 行香子（三人承明）
诗：三人承明，/四至九卿。/问儒生、何辱何荣。/金张七叶，/纨绮貂缨。
诗：无汗马事，/不献赋，/不明经。/成都卜肆，/寂寞君平。
诗：郑子真、岩谷躬耕。/寒灰炙手，/人重人轻。/除竺乾学，/得无念，/得无名。

# 行香子（清夜无尘）
诗：清夜无尘，/月色如银。/酒斟时、须满十分。/浮名浮利，/虚苦劳神。
诗：叹隙中驹，/石中火，/梦中身。/虽抱文章，/开口谁亲。
诗：且陶陶、乐尽天真。/几时归去，/作个闲人。/对一张琴，/一壶酒，/一溪云。

# 行香子·病起小集
诗：昨夜霜风，/先入梧桐。/浑无处、回避衰容。/问公何事，/不语书空。
诗：但一回醉，/一回病，/一回慵。/朝来庭下，/飞英如霰，/似无言、有意催侬。
诗：都将万事，/付与千钟。/任酒花白，/眼花乱，/烛花红。

# 点绛唇（闲倚胡床）
诗：闲倚胡床，/庾公楼外峰千朵。/与谁同坐，/明月清风我。
诗：别乘一来，/有唱应须和。/还知么，/自从添个，/风月平分破。

# 点绛唇（红杏飘香）
诗：红杏飘香，/柳含烟翠拖金缕。/水边朱户，/门掩黄昏雨。
诗：烛影摇风，/一枕伤春绪。/归不去，/凤楼何处，/芳草迷归路。

# 皂罗特髻（采菱拾翠）
诗：采菱拾翠，/算似此佳名，/阿谁消得。/采菱拾翠，/称使君知客。
诗：千金买、采菱拾翠，/更罗裙、满把珍珠结。/采菱拾翠，/正髻初合。
诗：真个采菱拾翠，/但深怜轻拍。/一双子、采菱拾翠，/绣衾下、抱著俱香滑。
诗：采菱拾翠，/待到京寻觅。

# 点绛唇（醉漾轻舟）
诗：醉漾轻舟，/信流引到花深处。/尘缘相误，/无计花间住。
诗：烟水茫茫，/千里斜阳暮。/山无数，/乱红如雨，/不记来时路。

# 点绛唇·离恨
诗：月转乌啼，/画堂宫徵生离恨。/美人愁闷，/不管罗衣褪。
诗：清泪斑斑，/挥断柔肠寸。/嗔人问，/背灯偷摄，/拭尽残妆粉。

# 虞美人（定场贺老今何在）
诗：定场贺老今何在，/几度新声改。/怨声坐使旧声阑，/俗耳只知繁手不须弹。
诗：断弦试问谁能晓，/七岁文姬小。/试教弹作辊雷声，/应有开元遗老泪纵横。
