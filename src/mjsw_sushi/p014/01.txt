# 乔太博见和复次韵答之
诗：百年三万日，/老病常居半。/其间互忧乐，/歌笑杂悲叹。
诗：颠倒不自知，/直为神所玩。/须臾便堪笑，/万事风雨散。
诗：自从识此理，/久谢少年伴。/逝将游无何，/岂暇读城旦。
诗：非才更多病，/二事可并案。/愧烦贤使者，/弭节整纷乱。
诗：乔侯瑚琏质，/清庙尝荐盥。/奋髯百吏走，/坐变齐俗缓。
诗：未遭甘鹢退，/并进耻鱼贯。/每闻议论，/凛凛激贪懦。
诗：莫邪当自跃，/岂复烦炉炭。/便应朝秣越，/未暮刷燕馆。
诗：胡为守故丘，/眷恋桑榆暖。/为君叩牛角，/一咏南山粲。

# 二公再和亦再答之

诗：羁孤每自笑，/寂寞谁肯伴。/元达号神君，/晋循吏乔智明，
诗：字元达。/高论森月旦。/纪明本贤将，/段释之，
诗：本将家。/汩没事堆案。/欣然肯相顾，/夜阁灯火乱。
诗：盘空愧不饱，/酒薄仅堪盥。/雍容许著帽，/不怪安石缓。
诗：虽无窈窕人，/清唱弄珠贯。/幸有纵横舌，/说剑起慵懦。
诗：二豪沉下位，/暗火埋湿炭。/岂似草玄人，/默默老儒馆。
诗：行看富贵逼，/炙手借暖。/应念苦思归，/登楼赋王粲。

# 苏州姚氏三瑞堂
原：姚氏世以孝称。
诗：君不见董召南，/隐居行义孝且慈，/天公亦恐无人知。/故令鸡狗相哺儿，
诗：又令韩老为作诗。/尔来三百年，/名与淮水东南驰。/此人世不乏，
诗：此事亦时有。/枫桥三瑞皆目见，/天意宛在虞鳏后。/惟有此诗非昔人，
诗：君更往求无价手。

诗：会当拂衣归故丘，/作书贷粟监河侯。/万斛船中著美酒，/与君一生长拍浮。

# 次韵章传道喜雨
原：祷常山而得。
诗：去年夏旱秋不雨，/海畔居民饮咸苦。/今年春暖欲生蝝，/地上戢戢多于土。
诗：预忧一旦开两翅，/口吻如风那肯吐。/前时渡江人吴越，/布阵横空如项羽。
诗：去岁钱塘，/见飞蝗自西北来，/极可畏。/农夫拱手但垂泣，
诗：人力区区固难御。/扑缘鬃毛困牛马，/啖啮衣服穿房户。/坐观不救亦何心，
诗：秉畀炎火传自古。/荷锄散掘谁敢后，/得米济饥还小补。/常山山神信英烈，
诗：㧑驾雷公呵电母。/应怜郡守老且愚，/欲把疮痍手摩抚。/山中归时凤色变，
诗：中路已觉商羊舞。/夜窗骚骚闹松竹，/朝畦泫泫流膏乳。/从来蝗旱必相资，
诗：此事吾闻老农语。/庶将积润扫遗孽，/收拾丰岁还明主。/县前已窖八干斛，
诗：今春及今，/得蝗子八干余斛。/率以一升完一亩。/更看蚕妇过初眠，
诗：蚕一眠，/则蝗不复生矣。/未用贺客来旁午。/先生笔力吾所畏，
诗：蹴踏鲍谢跨徐庾。/偶然谈笑得佳篇，/便恐流传成乐府。/陋邦一雨何足道，
诗：吾君盛德九州普。/《中和》《乐职》几时作，/试向诸生选何武。

# 惜花
诗：吉祥寺中锦干堆，/钱塘花最盛处。/前年赏花真盛哉。/道人劝我清明来，
诗：腰鼓百面如春雷，/打彻凉州花自开。/沙河塘上插花回，/醉倒不觉吴儿哈，
诗：岂知如今双鬓摧。/城西古寺没蒿莱，/有僧闭门手自栽，/千枝万叶巧剪裁。
诗：就中一丛何所似，/马瑙盘盛金缕杯。/而我食菜方清斋，/对花不饮花应猜。
诗：夜来雨雹如李梅，/红残绿暗吁可哀。/钱塘吉祥寺花为第一。/王子清明，
诗：赏会最盛，/金盘彩篮以献于座者，/五十三人。/夜归沙河塘上，
诗：观者如山，/尔后无复继也。/今年，/诸家园圃花亦极盛，
诗：而龙兴僧房一丛尤奇。/但衰病牢落，/自无以发兴耳。/昨日雨雹，
诗：知此花之存者有几，/可为太息也。

# 寄刘孝叔
诗：君王有意诛骄卤，/椎破铜山铸铜虎。/联翩三十七将军，/走马西来：
诗：各开府。/南山伐木作车轴，/东海取鼍漫战鼓。/汗流奔走谁敢后，
诗：恐乏军兴污质斧。/保甲连村团未遍，/方田讼牒纷如雨。/尔来手实降新书，

诗：众里笙竽谁比数。/忽令独奏《凤将雏》，/仓卒欲吹那得谱。/况复连年苦饥馑，
诗：剥啮草木啖泥土。/今年雪颇应时，/又报蝗虫生翅股。/忧来冼盏欲强醉，
诗：寂寞虚斋卧空。/公厨十日不生烟，/更望红裙踏筵舞。/故人屡寄山中信，
诗：只有当归无别语。/方将雀鼠偷太仓，/未肯衣冠挂神武。/吴兴丈人真得道，
诗：平日立朝非小补。/自从四方冠盖闹，/归作二浙湖山主。/高踪已自杂渔钓，
诗：大隐何曾弃簪组。/去年相从殊未足，/问道已许谈其粗。/逝将弃官往卒业，
诗：俗缘未尽那得睹。/公家只在霅溪上，/上有白云如白羽。/应怜进退苦皇皇，
诗：更把安心教初祖。

# 刘贡父见余歌词数首以诗见戏聊次其韵
诗：十载飘然未可期，/那堪重作看花诗。/门前恶语谁传去，/醉后狂歌自不知。
诗：刺舌君今犹未戒，/灸眉吾亦更何辞。/相从痛饮无余事，/正是春容最好时。

# 和章七出守湖州二首
诗：方丈仙人出淼茫，/高情犹爱水云乡。/功名谁使连三捷，/身世何缘得两忘。
诗：早岁归休心共在，/他年相见话偏长。/只因未报君恩重，/清梦时时到玉堂。
诗：绛阙云台总有名，/应须极贵又长生。/鼎中龙虎黄金贱，/松下龟蛇绿骨轻。
诗：君好炉火而饵茯苓。/霅水未浑缨可濯，/弁峰初见眼应明。/两卮春酒真堪羡，
诗：独占人间分外荣。

# 过旧游
题解：和张子野见寄三绝句
诗：前生我已到杭州，/到处长如到旧游。/更欲洞霄为隐吏，/一庵闲地且相留。

# 见题壁
诗：狂吟跌宕无风雅，/醉墨淋漓不整齐。/应为诗人一回顾，/山僧未忍扫黄泥。

# 竹阁见忆
诗：柏堂南畔竹如云，/此阁何人是主人。/但遣先生披鹤氅，/不须更画乐天真。

# 送赵寺丞寄陈海州
诗：景疏楼上唤蛾眉，/君到应先诵此诗。/若见孟公投辖饮，/莫忘冲雪送君时。

# 和蒋夔寄茶
诗：我生百事常随缘，/四方水陆无不便。/扁舟渡江适吴越，/三年饮食穷芳鲜。
诗：金虀玉脍饭炊雪，/海螯江柱初脱泉。/临风饱食甘寝罢，/一瓯花乳浮轻圆。
诗：自从舍舟人东武，/沃野便到桑麻川。/剪毛胡羊大如马，/谁记鹿角腥盘筵。
诗：厨中蒸粟堆饭瓮，/大杓更取酸生涎。/山东喜食粟饭，/饮酸酱。
诗：柘罗铜碾弃不用，/脂麻白土须盆研。/故人犹作旧眼看，/谓我好尚如当年。
诗：沙溪北苑强分别，/水脚一线争谁先。/清诗两幅寄千里，/紫金百饼费万钱。
诗：吟哦烹噍两奇绝，/只恐偷乞烦封缠。/老妻稚子不知爱，/一半已人姜盐煎。
诗：人生所遇无不可，/南北嗜好知谁贤。/死生祸福久不择，/更论甘苦争蚩妍。
诗：知君穷旅不自释，/因诗寄谢聊相镌。

# 光禄庵二首
诗：文章恨不见文园，/礼乐方将访石泉。/何事庵中著光禄，/枉教闲处笔如椽。
诗：城中太守的何人，/林下先生非我身。/若向庵中觅光禄，/雪中履迹镜中真。
