# 壶中九华诗并引
原：湖口人李正臣蓄异石九峰，玲珑宛转，若窗棂然。予欲以百金买之，与仇池石为偶，方南迁未暇也。名之曰壶中九华，且以诗纪之。
诗：清溪电转失云峰，/梦里犹惊翠扫空。/五岭莫愁千嶂外，/九华今在一壶中。
诗：天池水落层层见，/玉女窗虚处处通。/念我仇池太孤绝，/百金归买碧玲珑。

# 过庐山下并引
诗：予过庐山下，/云物腾涌，/默有祷焉。/未午，
诗：众峰凛然，/故作是诗。
诗：乱云欲霾山，/势与飘风南。/群济相应和，/勇往争骖驒。
诗：可怜荟蔚中，/时出紫翠岚。/雁没失东岭，/龙腾见西龛。
诗：一时供坐笑，/百态变立谈。/暴雨破块扎，/清飙扫浑酣。
诗：廓然归何处，/陋矣安足戡。/亭亭紫霄峰，/窈窈白石庵。
诗：五老数松雪，/双溪落矢潭。/虽云默祷应，/顾有移文惭。

# 望湖亭

诗：许国心犹在，/康时术已虚。/岷峨家万里，/投老得归无。

# 江西一首
诗：江西山水真吾邦，/白沙翠竹石底江。/舟行十里磨九泷，/篙声荦确相春撞。
诗：醉卧欲醒闻淙淙，/直欲一口吸老庞。/何人得隽窥鱼豇，/举叉绝叫尺鲤双。

# 秧马歌并引
原：过庐陵，见宣德郎致仕曾君安止。出所作《禾谱》。文既温雅，事亦详实，惜其有所缺，不谱农器也。予昔游武昌，见农夫皆骑秧马。以榆枣为腹欲其滑，以楸桐为背欲其轻，腹如小舟，昂其首尾，背如覆瓦，以便两髀，雀跃于泥中，系束藁其首以缚秧。日行千畦，较之伛偻而作者，劳佚相绝矣。《史记》：禹乘四载，泥行乘橇。解者曰：橇形如箕，挝行泥上，岂秧马之类乎？作《秧马歌》一首，附于《禾谱》之末云。
诗：春云蒙蒙雨凄凄，/春秧欲老翠剡齐。/嗟我妇子行水泥，/朝分一暮干畦。
诗：腰如箜篌首啄鸡，/筋烦骨殆声酸嘶。/我有桐马手自提，/头尻轩昂腹胁低。
诗：背如覆瓦去角圭，/以我两足为四蹄。/耸踊滑汰如凫医，/纤纤束藁亦可斋。
诗：何用繁缨与月题，/却从畦东走畦西。/山城欲闭闻鼓鼙，/忽作的卢跃檀溪。
诗：归来挂壁从高栖，/了无刍秣饥不啼。/少壮骑汝逮老黧，/何曾蹶轶防颠脐。
诗：锦鞯公子朝金闺，/笑我一生蹋牛犁，/不知自有木駃騠。

# 八月七日初入赣过惶恐滩

# 廉泉

诗：廉者为我廉，/何以此名为。/有廉则有贪，/有慧则有痴。
诗：谁为柳宗元，/孰是吴隐之？/渔父足岂洁，/讳虫耳何淄？

诗：朅来廉泉上，/捋须看鬓眉。/好在水中人，/到处相娱嬉。

# 天竺寺并引
诗：予年十二，/先君自虔州归，/为予言：/“近城山中天竺寺，
诗：有乐天亲书诗云：/一山门作两山门，/两寺原从一寺分。/东涧水流西涧水，

诗：已亡飞鸟失惊蛇。/林深野桂寒无子，/雨浥山姜病有花。/四十七年真一梦，
诗：天涯流落泪横斜。

# 朝云诗并引
原：世谓乐天有鬻骆马放杨柳枝词，嘉其主老病，不忍去也。然梦得有诗云：春尽絮飞留不住，随风好去落谁家。乐天亦云：病与乐天相伴住，春随樊子一时归。则是樊素竟去也。予家有数妾，四五年相继辞去，独朝云者，随予南迁。因读乐天集，戏作此诗。朝云姓王氏，钱唐人。尝有子曰幹儿，未期而夭云。
诗：不似杨枝别乐天，/恰如通德伴伶玄。/阿奴络秀不同老，/天女维摩总解禅。
诗：经卷药炉新活计，/舞衫歌扇旧因缘。/丹成逐我三山去，/不作巫阳云雨仙。

# 白水山佛迹岩
原：罗浮之东麓也，在惠州东北二十里。
诗：何人守蓬莱，/夜半失左股。/浮山若鹏蹲，/忽展垂天羽。
诗：根株互连络，/崖峤争吞吐。/神工自炉鞲，/融液相缀补。
诗：至今隙罅，/流出千斛乳。/方其欲合时，/天匠麾月斧。
诗：帝觞分沥，/山骨醉后土。/峰峦尚开阖，/涧谷犹呼舞。
诗：海风吹未凝，/古佛来布武。/当时汪罔氏，/投足不盖拇。
诗：青莲虽不见，/千古落花雨。/双溪汇九折，/万马腾一鼓。
诗：奔雷溅玉雪，/潭洞开水府。/潜鳞有饥蛟，/掉尾取渴虎。
诗：我来方醉后，/濯足聊戏侮。/回风卷飞雹；/掠面过强弩，
诗：山灵莫恶剧，/微命安足赌。/此山吾欲老，/慎勿厌求取。
诗：溪流变春酒，/与我相宾主。/当连青竹竿，/下灌黄精圃。

# 咏汤泉
原：在白冰山。
诗：积水焚大槐，/蓄油灾武库。/惊然丞相井，/疑浣将军布。
诗：自怜耳目隘，/未测阴阳故。/郁攸火山烈，/觱沸汤泉注。
诗：岂惟渴兽骇，/坐使痴儿怖。/安能长鱼鳖，/仅可燖狐兔。
诗：山中惟木客，/户外时芒屦。/虽无倾城浴，/幸免亡国污。

# 江郊并引
原：惠州归善县治之北数百步，抵江，少西有盘石小潭，可以垂钓，作《江郊》诗云。
诗：江郊葱昽，/云水蒨绚。/碕岸斗入，/洄潭轮转。
诗：先生悦之，/布席闲燕。/初日下照，/潜鳞俯见。
诗：意钓忘鱼，/乐此竿线。/优哉悠哉，/玩物之变。

# 詹守携酒见过用前韵作诗聊复和之
诗：箕踞狂歌老瓦盆，/燎毛燔肉似羌浑。/传呼草市来携客，/洒扫渔矶共置樽。
诗：山下黄童争看舞，/江干白骨已衔恩。/时詹方议葬暴骨。/孤云落日西南望，
诗：长羡归鸦自识村。
