# 王中甫哀辞并叙
原：仁宗朝以制策登科者十五人，轼忝冒时，尚有富彦国、张安道、钱子飞、吴长文、夏公酉、陈令举、钱醇老，并王中甫与家弟辙，九人存焉。其后十有五年，哭中甫于密州，作诗吊之，则子飞、长文、令举殁矣。又八年，轼自黄州量移汝海，与中甫之子沇之相遇于京口，相持而泣，则十五人者，独三人存耳，盖安道及轼与家弟而已。鸣呼悲夫！乃复次前韵，以遗沇之，时沈之亦以罪谪家于钱塘云。
诗：生刍不独比前人，/束藁端能废谢鲲。/子达想无身后念，/吾衰不复梦中论。
诗：已知毅豹为均死，/未识荆凡定孰存？/堪笑东坡痴钝老，/区区犹记刻舟痕。

诗：新落霜两岸隆，/尘埃举袂识西风。/临淮自古多名士，/樽酒相从乐寓公。
诗：半日偷闲歌啸裹，/百年暗尽往来中。/知君不向穷愁老，/尚有清诗气吐虹。

# 泗州南山监仓萧渊东轩二首
诗：偶随樵父采都梁，/南山名都梁山，/山出都梁香故也。/竹屋松扉试乞浆。
诗：但见东轩堪隐几，/不知公子是监仓。/溪中乱石墙垣古，/山下寒蔬匕箸香。
诗：我是江南旧游客，/挂冠知有老萧郎。
诗：北望飞尘苦昼霾，/洗心聊复寄东斋。/珍禽声好犹思越，/野橘香清未过淮。
诗：有信微泉来远岭，/无心明月转空阶。/一官仓庾真堪老，/坐看松根络断崖。

# 蝉
诗：蜕形浊污中，/羽翼便翾好。/秋来间何阔，/已抱寒茎槁。

# 虾蟆
诗：睥目知谁瞋，/皤腹空自胀。/慎勿困蜈蚣，/饥蛇不汝放。

# 蜣螂
诗：洪钟起暗室，/飘瓦落空庭。/谁言转丸手，/能作殷床声。

# 天水牛
诗：两角徒自长，/空飞不服箱。/为牛竟何事，/利吻穴枯桑。

# 蝎虎
诗：跂跂有足蛇，/脉脉无角龙。/为虎君勿笑，/食尽蚤尾虫。

# 蜗牛
诗：腥涎不满壳，/聊足以自濡。/升高不知回，/竟作黏壁枯。

# 鬼蝶
诗：双眉卷铁丝，/两翅晕金碧。/初来花争妍，/忽去鬼无迹。

# 泗州除夜雪中黄师是送酥酒二首
诗：暮雪纷纷投碎米，/春流咽咽走黄沙。/旧游似梦徒能说，/逐客如僧岂有家。
诗：冷砚欲书先自冻，/孤灯何事独生花。/使君夜半分酥酒，/惊起妻孥一笑哗。
诗：关右土酥黄似酒，/扬州云液却如酥。/欲从元放觅拄杖，/忽有麹生来坐隅。
诗：对雪不堪令饱暖，/隔船应已厌歌呼。/明朝积玉深三尺，/高枕床头尚一壶。

# 章钱二君见和复次韵答之二首
诗：黄昏已作风翻絮，/半夜犹惊月在沙。/照汴玉峰明佛刹，/隔淮云海暗人家。
诗：来牟有信迎三白，/薝葡无香散六花。/薝葡，/栀子花也，
诗：与雪花皆六出。/欲唤阿咸来守岁，/林乌枥马斗喧哗。
诗：分无纤手裁春胜，/况有新诗点蜀酥。/醉里冰髭失缨络，/梦回布被起廉隅。
诗：君应旅睫寒生晕，/我亦饥肠夜自呼。/明日南山春色动，/不知谁佩紫微壶。
