诗：汉宫一百四十五，/多下珠帘闭琐窗。/何处营巢夏将半，/茅檐烟里语双双。

# 归燕
诗：画堂歌舞喧喧地，/社去社来人不看。/长是江楼使君伴，/黄昏犹待倚栏干。

# 伤猿
诗：独折南园一朵梅，/重寻幽坎已生苔。/无端晚吹惊高树，/似袅长枝欲下来。

# 还俗老僧
诗：雪发不长寸，/秋寒力更微。/独寻一径叶，/犹挈衲残衣。
诗：日暮千峰里，/不知何处归。

# 斫竹
诗：寺废竹色死，/宦家宁尔留。/霜根渐随斧，/风玉尚敲秋。
诗：江南苦吟客，/何处送悠悠。

# 将赴湖州留题庭菊
诗：陶菊手自种，/楚兰心有期。/遥知渡江日，/正是撷芳时。

# 折菊
诗：篱东菊径深，/折得自孤吟。/雨中衣半湿，/拥鼻自知心。

# 云
诗：尽日看云首不回，/无心都大似无才。/可怜光彩一片玉，/万里晴天何处来？

# 醉后题僧院
诗：离心忽忽复凄凄，/雨晦倾瓶取醉泥。/可羡高僧共心语，/一如携稚往东西。

# 题禅院
诗：觥船一棹百分空，/十岁青春不负公。/今日鬓丝禅榻畔，/茶烟轻飏落花风。

# 哭李给事中敏
诗：阳陵郭门外，/陁陀丈五坟。/九泉如结友，/兹地好埋君。

# 黄州竹径
诗：竹浊蟠小径，/屈折斗蛇来。/三年得归去，/知绕几千回。

# 题敬爱寺楼
诗：暮景千山雪，/春寒百尺楼。/独登还独下，/谁会我悠悠？

# 送刘秀才归江陵
诗：彩服鲜华觐渚宫，/鲈鱼新熟别江东。/刘郎浦夜侵船月，/宋玉亭春弄袖风。
诗：落落精神终有立，/飘飘才思杳无穷。/谁人世上为金口，/借取明时一荐雄。

# 见吴秀才与池妓别因成绝句
诗：红烛短时羌笛怨，/清歌咽处蜀弦高。/万里分飞两行泪，/满江寒雨正萧骚。

# 湖南正初招李郢秀才
诗：行乐及时时已晚，/对酒当歌歌不成。/千里暮山重叠翠，/一溪寒水浅深清。
诗：高人以饮为忙事，/浮世除诗尽强名。/看著白蘋牙欲吐，/雪舟相访胜闲行。

# 赠朱道灵
诗：刘根丹篆三千字，/郭璞青囊两卷书。/牛渚矶南谢山北，/白云深处有岩居。

# 屏风绝句
诗：屏风周昉画纤腰，/岁久丹青色半销。/斜倚玉窗鸾发女，/拂尘犹自妬娇饶。

# 哭韩绰
诗：平明送葬上都门，/绑交横逐去魂。/归来冷笑悲身事，/唤妇呼儿索酒盆。

# 新定途中
诗：无端偶效张文纪，/下杜乡园别五秋。/重过江南更千里，/万山深处一孤舟。

# 题新定八松院小石
诗：雨滴珠玑碎，/苔生紫翠重。/故关何日到？/且看小三峰。
