# 感怀诗一首
诗：高、文会隋季，/提剑徇天意。/扶持万代人，/步骤三皇地。
诗：圣云继之神，/神仍用文治。/德泽酌生灵，/沉酣薰骨髓。
诗：旄头骑箕尾，/风尘蓟门起。/胡兵杀汉兵，/尸满咸阳市。
诗：宣皇走豪杰，/谈笑开中否。/蟠联两河间，/烬萌终不弭。
诗：号为精兵处，/齐、蔡、燕、赵、魏。/合环千里疆，/争为一家事。
诗：逆子嫁虏孙，/西邻聘东里。/急热同手足，/唱和如宫徵。
诗：法制自作为，/礼文争僭拟。/压阶螭斗角，/画屋龙交尾。
诗：署纸日替名，/分财赏称赐。/刳隍歇万寻，/缭垣叠千雉。
诗：誓将付孱孙，/血绝然方已。/九庙仗神灵，/四海为输委。
诗：如何七十年，/汗絶含羞耻？/韩、彭不再生，/英、卫皆为鬼。
诗：凶门爪牙辈，/穰穰如儿戏。/累圣但日吁，/阃外将谁寄？
诗：屯田数十万，/陡防常熠惴。/急征赴军须，/厚赋资凶器。
诗：因隳画一法，/且逐随时利。/流品极蒙龙，/网罗渐离弛。
诗：夷狄日开张，/黎元愈憔悴。/邈矣远太平，/萧然尽烦费。
诗：至于贞元末，/风流恣绮靡。/艰极泰循来，/元和圣天子。
诗：元和圣天子，/英明汤、武上。/茅茨覆宫殿，/封章绽帷帐。
诗：伍旅拔雄儿，/梦卜庸真相。/勃云走轰霆，/河南一平荡。
诗：继于长庆初，/燕、赵终舁襁。/携妻负子来，/北阙争顿颡。
诗：故老抚儿孙，/尔生今有望。/茹鲠喉尚隘，/负重力未壮。
诗：坐幄无奇兵，/吞舟漏疏网。/骨添蓟垣沙，/血涨嘑沧浪。
诗：只云徒有征，/安能问无状。/一日五诸侯，/奔亡如鸟往。
诗：取之难梯天，/失之易反掌。/苍然太行路，/翦翦还榛莽。
诗：关西贱男子，/誓肉虏杯羹。/请数系虏事，/谁其为我听。
诗：荡荡乾坤大，/瞳瞳日月明。/叱起文、武业，/可以豁洪溟。
诗：安得封域内，/长有扈苗征。/七十里百里，/彼亦何常争。
诗：往往念所至，/得醉愁苏醒。/韬舌辱壮心，/叫阍无助声。
诗：聊书《感怀》韵，/焚之遗贾生。

# 杜秋娘诗并序
原：杜秋，金陵女也。年十五，为李锜锖妾，后琦锖叛灭，籍之入宫，有宠于景陵。穆宗即位，命秋为皇子傅姆，皇子壮，封漳王。郑注用事，诬丞相欲去异已者，指王为根，王被罪废削，秋因赐归故乡。予过金陵，感其穷且老，为之赋诗。
诗：京江水清滑，/生女白如脂。/其间杜秋者，/不劳朱粉施。
诗：老濞即山铸，/后庭千双眉。/秋持玉斝醉，/与唱《金缕衣》。
诗：濞既白首叛，/秋亦红泪滋。/吴江落日渡，/灞岸绿杨垂。
诗：联裾见天子，/盼眄独依依。/椒壁悬锦幕，/镜奁蟠蛟螭。
诗：低鬓认新宠，/窈袅复融怡。/月上白璧门，/桂影凉参差。
诗：金阶露新重，/闲捻紫箫吹。/莓苔夹城路，/南苑雁初飞。
诗：红粉羽林仗，/独赐辟邪旗。/归来煮豹胎，/餍饫不能饴。
诗：咸池升日庆，/铜雀分香悲。/雷音后车远，/事往落花时。
诗：燕裸得皇子，/壮发绿矮矮。/画堂授傅姆，/天人亲捧持。
诗：虎睛珠络褓，/金盘犀镇帷。/长杨射熊羆，/武帐弄哑咿。
诗：渐抛竹马剧，/稍出舞鸡奇。/崭崭整冠珮，/侍宴坐瑶池。
诗：眉宇俨图画，/神秀射朝辉。/一尺桐偶人，/江充知自欺。
诗：王幽茅土削，/秋放故乡归。/觚棱拂斗极，/回首尚迟迟。
诗：四朝三十载，/似梦复疑非。/潼关识旧吏，/吏发已如丝。
诗：却唤吴江渡，/舟人那得知。/归来四邻改，/茂苑草菲菲。
诗：清血洒不尽，/仰天知问谁。/寒衣一匹素，/夜借邻人机。
诗：我昨金陵过，/闻之为歔欷。/自古皆一贯，/变化安能推。
诗：夏姬灭两国，/逃作巫臣姬。/西子下姑苏，/一舸逐鸱夷。
诗：织室魏豹俘，/作汉太平基。/误置代籍中，/两朝尊母仪。
诗：光武绍高祖，/本系生唐儿。/珊瑚破高齐，/作婢春黄糜。
诗：萧后去扬州，/突厥为阏氏。/女子固不定，/士林亦难期。
诗：射钩后呼父，/钓翁王者师。/无国要孟子，/有人毁仲尼。
诗：秦因逐客令，/柄归丞相斯。/安知魏齐首，/见断篑中尸。
诗：给丧蹶张辈，/廊庙冠峨危。/珥貂七叶贵，/何妨戎虏支。
诗：苏武却生返，/邓通终死饥。/主张既难测，/翻覆亦其宜。
诗：地尽有何物，/天外复何之？/指何为而捉，/足何为而驰？
诗：耳何为而听，/目何为而窥？/己身不自晓，/此外何思惟。
诗：因倾一樽酒，/题作《杜秋诗》。/愁来独长咏，/聊可以自贻。

# 郡斋独酌
诗：前年鬓生雪，/今年须带霜。/时节序鳞次，/古今同雁行。
诗：甘英穷西海，/四万到洛阳。/东南我所见，/北可计幽荒。
诗：中画一万国，/角角棋布方。/地顽压不穴，/天回老不僵。
诗：屈指百万世，/过如霹雳忙。/人生落其内，/何者为彭、殇？
诗：促束自系缚，/儒衣宽且长。/旗亭雪中过，/敢问当垆娘。
诗：我爱李侍中，/摽摽七尺强。/白羽八札弓，/陛压绿檀枪。
诗：风前略横阵，/紫髯分两傍。/淮西万虎士，/怒目不敢当。
诗：功成赐宴麟德殿，/猿超鹘掠广毬场。/三千宫女侧头看，/相排踏碎双明挡。
诗：旌竿幖幖旗㸌㸌，/意气横鞭归故乡。/我爱朱处士，/三吴当中央。
诗：罢亚百顷稻，/西风吹半黄。/尚可活乡里，/岂唯满困仓。
诗：后岭翠扑扑，/前溪碧泱泱。/雾晓起凫雁，/日晚下牛羊。
诗：叔舅欲饮我，/社瓮尔来尝。/伯姊子欲归，/彼亦有壶浆。
诗：西阡下柳坞，/东陌绕荷塘。/姻亲骨肉舍，/烟火遥相望。
诗：太守政如水，/长官贪似狼。/征输一云毕，/任尔自存亡。
诗：我昔造其室，/羽仪鸾鹤翔。/交横碧流上，/竹映琴书床。
诗：出语无近俗，/尧、舜、禹、武、汤。/问今天子少，/谁人为栋梁？
诗：我曰天子圣，/晋公提纪纲。/联兵数十万，/附海正诛沧。
诗：谓言大义小不义，/取易卷席如探囊。/犀甲吴兵斗弓弩，/蛇矛燕骑驰锋铠。
诗：岂知三载几百战，/钩车不得望其墙。/答云此山外，/有事同胡羌。
诗：谁将国伐叛，/话与钓鱼郎。/溪南重回首，/一迳出修篁。
诗：尔来十三岁，/斯人未曾忘。/往往自抚己，/泪下神苍茫。
诗：御史诏分洛，/举趾何猖狂。/阙下谏官业，/拜疏无文章。
诗：寻僧解幽梦，/乞酒缓愁肠。/岂为妻子计，/未去山林藏。
诗：平生五色线，/愿补舜衣裳。/弦歌教燕、赵，/兰芷浴河湟。
诗：腥膻一扫洒，/凶狠皆披攘。/生人但眠食，/寿域富农桑。
诗：孤呤志在此，/自亦笑荒唐。/江郡雨初霁，/刀好截秋光。
诗：池边成独酌，/拥鼻菊枝香。/醺酣更唱太平曲，/仁圣天子寿无疆。

# 张好好诗并序
原：牧大和三年，佐故吏部沈公江西幕，好好年十三，始以善歌来乐籍中。后一岁，公移镇宣城，复置好好于宣城籍中。后二岁，为沈著作述师以双鬟纳之。后二岁，于洛阳东城重睹好好，感旧伤怀，故题诗赠之。
诗：君为豫章姝，/十三才有余。/翠茁凤生尾，/丹叶莲含跗。
诗：高阁倚天半，/章江联碧虚。/此地试君唱，/特使华筵铺。
诗：主公顾四座，/始讶来踟蹰。/吴娃起引赞，/低徊映长裾。
诗：双鬟可高下，/才过青罗襦。/盼盼乍垂袖，/一声雏凤呼。
诗：繁弦进关纽，/塞管裂圆芦。/众音不能逐，/袅袅穿云衢。
诗：主公再三叹，/谓言天下殊。/赠之天马锦，/副以水犀梳。
诗：龙沙看秋浪，/明月游东湖。/自此每相见，/三日已为疏。
诗：玉质随月满，/艳态逐春舒。/绛唇渐轻巧，/云步转虚徐。
诗：旌旆忽东下，/笙歌随舳舻。/霜凋谢楼树，/沙暖句溪蒲。
诗：身外任尘土，/樽前极欢娱。/飘然集仙客，/讽赋欺相如。
诗：聘之碧瑶珮，/载以紫云车。/洞闭水声远，/月高蟾影孤。
诗：尔来未几岁，/散尽高阳徒。/洛城重相见，/婵卓为当垆。
诗：怪我苦何事，/少年垂白须？/朋游今在否，/落拓更能无？
诗：门馆恸哭后，/水云秋景初。/斜日挂衰柳，/凉风生座隅。
诗：洒尽满衿泪，/短歌聊一书。

# 冬至日寄小蛭阿宜诗
诗：小蛭名阿宜，/未得三尺长。/头圆筋骨紧，/两脸明且光。
诗：去年学官人，/竹马绕四廊。/指挥群儿辈，/意气何坚刚。
诗：今年始读书，/下口三五行。/随兄旦夕去，/敛手整衣裳。
诗：去岁冬至日，/拜我立我旁。/祝尔愿尔贵，/仍且寿命长。
诗：今年我江外，/今日生一阳。/忆尔不可见，/祝尔倾一觞。
诗：阳德比君子，/初生甚微茫。/排阴出九地，/万物随开张。
诗：一似小儿学，/日就复月将。/勤勤不自己，/二十能文章。
诗：仕宦至公相，/致君作尧、汤。/我家公相家，/剑珮尝丁当。
诗：旧第开朱门，/长安城中央。/第中无一物，/万卷书满堂。
诗：家集二百编，/上下驰皇王。/多是抚州写，/今来五纪强。
诗：尚可与尔读，/助尔为贤良。/经书括根本，/史书阅兴亡。
诗：高摘屈、宋艳，/浓薰班、马香。/李、杜泛浩浩，/韩、柳摩苍苍。
诗：近者四君子，/与古争强梁。/愿尔一祝后，/读书日日忙。
诗：一日读十纸，/一月读一箱。/朝廷用文治，/大开官职场。
诗：愿尔出门去，/取官如驱羊。/吾兄苦好古，/学问不可量。
诗：昼居府中治，/夜归书满床。/后贵有金玉，/必不为汝藏。
诗：崔昭生崔芸，/李兼生窟郎。/堆钱一百屋，/破散何披猖。
诗：今虽未即死，/饿冻几欲僵。/参军与县尉，/尘土惊助勷。
诗：一语不中治，/笞箠身满疮。/官罢得丝发，/好买百树桑。
诗：税钱未输足，/得米不敢尝。/愿尔闻我语，/欢喜人心肠。
诗：大明帝宫阙，/杜曲我池塘。/我若自潦倒，/看汝争翱翔。
诗：总语诸小道，/此诗不可忘。

# 李甘诗
诗：大和八九年，/训、注极虓虎。/潜身九地底，/转上青天去。
诗：四海镜清澄，/千官云片缕。/公私各闲暇，/追游日相伍。
诗：岂知祸乱根，/枝叶潜滋莽。/九年夏四月，/天诫若言语。
诗：烈风驾地震，/狞雷驱猛雨。/夜于正殿阶，/拔去千年树。
诗：吾君不省觉，/二凶日威武。/操持北斗柄，/开闭天门路。
诗：森森明庭士，/缩缩循墙鼠。/平生负名节，/一旦如奴虏。
诗：指名为锢党，/状迹谁告诉。/喜无李、杜诛，/敢惮髡钳苦。
诗：时当秋夜月，/日直曰庚午。/喧喧皆传言，/明晨相登注。
诗：予时与和鼎，/官班各持斧。/和鼎顾予云：“我死有处所。/”当庭裂诏书，
诗：退立须鼎俎。/君门晓日开，/赭案横霞布。/俨雅千官容，
诗：勃郁吾累怒。/适属命鄜将，/昨之传者误。/明日诏书下，
诗：谪斥南荒去。/夜登青泥坂，/坠车伤左股。/病妻尚在床，
诗：稚子初离乳。/幽兰思楚泽，/恨水啼湘渚。/悦怳三闾魂，
诗：悠悠一千古。/其冬二凶败，/涣汗开汤罟。/贤者须丧亡，
诗：谗人尚堆堵。/予于后四年，/谏官事明主。/常欲雪幽冤，
诗：于时一裨补。/拜章岂艰难，/胆薄多忧惧。/如何干斗气，
诗：竟作炎荒土。/题此涕滋笔，/以代投湘赋。

# 洛中送冀处士东游
诗：处士有儒术，/走可挟车辆。/檀宇宽帖帖，/符彩高酋酋。
诗：不爱事耕稼，/不乐干王侯。/四十余年中，/超超为浪游。
诗：元和五六岁，/客于幽、魏州。/幽、魏多壮士，/意气相淹留。
诗：刘济愿跪履，/田兴请建筹。/处士拱两手，/笑之但掉头。
诗：自此南走越，/寻山入罗浮。/愿学不死药，/粗知其来由。
诗：却于童顶上，/萧萧玄发抽。/我作八品吏，/洛中如系囚。
诗：忽遭冀处士，/豁若登高楼。/拂榻与之坐，/十日语不休。
诗：论今星璨璨，/考古寒飕飕。/治乱掘根本，/蔓延相牵钩。
诗：武事何骏壮，/文理何优柔？/颜回捧俎豆，/项羽横戈矛。
诗：祥云绕毛发，/高浪开咽喉。/但可感鬼神，/安能为献酬。
诗：好入天子梦，/刻像来尔求。/胡为去吴会，/欲浮沧海舟。
诗：赠以蜀马箠，/副之胡罽裘。/饯酒载三斗，/东郊黄叶稠。
诗：我感有泪下，/君唱高歌酬。/嵩山高万尺，/洛水流千秋。
诗：往事不可问，/天地空悠悠。/四百年炎汉，/三十代宗周。
诗：二三里遗堵，/八九所高丘。/人生一世内，/何必多悲愁。
诗：歌阕解携去，/信非吾辈流。

# 送沈处士赴苏州李中丞招以诗赠行
诗：山城树叶红，/下有碧溪水。/溪桥向吴路，/酒旗夸酒美。
诗：下马此送君，/高歌为君醉。/念君苞材能，/百工在城垒。
诗：空山三十年，/鹿裘挂窗睡。/自言陇西公，/飘然我知己。
诗：举酒属吴门，/今朝为君起，/悬弓三百斤，/囊书数万纸。
诗：战贼即战贼，/为吏即为吏。/尽我所有无，/惟公之指使。
诗：予曰陇西公，/滔滔大君子。/常思抡群材，/一为国家治。
诗：譬如匠见木，/碍眼皆不弃。/大者粗十围，/小者细一指。
诗：摒橛与栋梁，/施之皆有位。/忽然竖明堂，/一挥立能致。
诗：予亦何为者？/亦受公恩纪。/处士常有言，/残虏为犬豕。
