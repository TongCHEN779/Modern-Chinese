# 别集
原：集贤校理裴延翰编次牧之文，号《樊川集》者二十卷，中有古律诗二百四十九首。且言牧始少得恙，尽搜文章，阅千百纸，掷焚之，才属留者十二三，疑其散落于世者多矣。旧传集外诗者又九十五首，家家有之。予往年于棠郊魏处士野家得牧诗九首，近汶上卢讷处又得五十篇，皆二集所逸者。其《后池泛舟宴送王十秀才》诗，乃知外集所亡，取别句以补题。今编次作一卷，俟有所得更益之。熙宁六年三月一日杜陵田概序。

# 寓言
诗：暖风迟日柳初含，/顾影看身又自惭。/何事明朝独惆怅，/杏花时节在江南。

# 猿
诗：月白烟青水暗流，/孤猿衔恨叫中秋。/三声欲断疑肠断，/饶是少年须白头。

# 怀归
诗：尘埃终日满窗前，/水态云容思浩然。/争得便归湘浦去，/却持竿上钓鱼船。

# 边上晚秋
诗：黑山南面更无州，/马放平沙夜不收。/风送孤城临晚角，/一声声入客心愁。

# 伤友人悼吹箫妓
诗：玉箫声断没流年，/满目春愁陇树烟。/艳质已随云雨散，/凤楼空锁月明天。

# 访许颜
诗：门近寒溪窗近山，/枕山流水日潺潺。/长嫌世上浮云客，/老向尘中不解颜。

# 春日古道傍作
诗：万古荣华旦暮齐，/楼台春尽草萋萋。/君看陌上何人墓？/旋化红尘送马蹄。

# 青冢
诗：青冢前头陇水流，/燕山山上暮云秋。/蛾眉一坠穷泉路，/夜夜孤魂月下愁。

# 大梦上人自庐峰回
诗：行脚寻常到寺稀，/一枝藜杖一禅衣。/开门满院空秋色，/新向庐峰过夏归。

# 洛中二首
诗：柳动晴风拂路尘，/年年宫阙锁浓春。/一从翠辇无巡幸，/老却蛾眉几许人？
诗：风吹柳带摇晴绿，/蝶绕花枝恋暖香。/多把芳菲泛春酒，/直教愁色对愁肠。

# 边上闻胡笳三首
诗：何处吹笳薄暮天？/塞垣高鸟没狼烟。/游人一听头堪白，/苏武争禁十九年！
诗：海路无尘边草新，/荣枯不见绿杨春。/白沙日暮愁云起，/独感离乡万里人。
诗：胡雏吹笛上高台，/寒雁惊飞去不回。/尽日春风吹不散，/只应分付客愁来。

# 春日寄许浑先辈
诗：蓟北雁初去，/湘南春又归。/水流沧海急，/人到白头稀。
诗：塞路尽何处？/我愁当落晖。/终须接鸳鹭，/霄汉共高飞。

# 经阖闾城
诗：遗踪委衰草，/行客思悠悠。/昔日人何处？/终年水自流。
诗：孤烟村戍远，/乱雨海门秋。/吟罢独归去，/烟云尽惨愁。

# 并州道中
诗：行役我方倦，/苦吟谁复闻。/戍楼春带雪，/边角暮吹云。
诗：极目无人迹，/回头送雁群。/如何遣公子，/高卧醉醺醺。

# 别怀
诗：相别徒成泣，/经过总是空。/劳生惯离别，/夜梦苦西东。
诗：去路三湘浪，/归程一片风。/他年寄消息，/书在鲤鱼中。

# 渔父
诗：白发沧浪上，/全忘是与非。/秋潭垂钓去，/夜月叩船归。
诗：煙影侵芦岸，/潮痕在竹扉。/终年狎鸥鸟，/来去且无机。

# 秋梦
诗：寒空动高吹，/月色满清砧。/残梦夜魂断，/美人边思深。
诗：孤鸿秋出塞，/一叶暗辞林。/又寄征衣去，/迢迢天外心。

# 早秋客舍
诗：风吹一片叶，/万物已惊秋。/独夜他乡泪，/年年为客愁。
诗：别离何处尽，/摇落几时休？/不及磻溪叟，/身闲长自由。

# 逢故人
诗：故交相见稀，/相见倍依依。/尘路事不尽，/云岩闲好归。
诗：投人销壮志，/徇俗变真机。/又落他乡泪，/风前一满衣。

# 秋晚江上遣怀
诗：孤舟天际外，/去路望中赊。/贫病远行客，/梦魂多在家。
诗：蝉吟秋色树，/鸦噪夕阳沙。/不拟彻双鬓，/他方掷岁华。

# 长安夜月
诗：寒光垂静夜，/皓彩满重城。/万国尽分照，/谁家无此明。
诗：古槐疏影薄，/仙桂动秋声。/独有长门里，/蛾眉对晓晴。

# 云
诗：东西那有碍，/出处岂虚心。/晓入洞庭阔，/暮归巫峡深。
诗：渡江随鸟影，/拥树隔猿吟。/莫隐高唐去，/枯苗待作霖。

# 春怀
诗：年光何太急，/倏忽又青春。/明月谁家主，/江山暗换人。
诗：莺花潜运老，/荣乐渐成尘。/遥忆朱门柳，/别离应更频。

# 逢故人（二）
诗：年年不相见，/相见却成悲。/教我泪如霰，/嗟君发似丝。
诗：正伤携手处，/况值落花时。/莫惜今宵醉，/人间忽忽期。

# 闲题
诗：男儿所在即为家，/百镒黄金一朵花。/借问春风何处好？/绿杨深巷马头斜。

# 金谷园
诗：繁华事散逐香尘，/流水无情草自春。/日暮东风怨啼鸟，/落花犹似堕楼人。

# 重登科
诗：星汉离宫月出轮，/满街含笑绮罗春。/花前每被青娥问，/何事重来只一人？

# 游边
诗：黄沙连海路无尘，/边草长枯不见春。/日暮拂云堆下过，/马前逢着射雕人。

# 将赴池州道中作
诗：青阳云水去年寻，/黄绢歌诗出翰林。/投辖暂停留酒客，/绛帷斜系满松阴。
诗：妖人笑我不相问，/道者应知归路心。/南去南来尽乡国，/月明秋水只沉沉。

# 隋宫春
诗：龙舟东下事成空，/蔓草萋萋满故宫。/亡国亡家为颜色，/露桃犹自恨春风。

# 蛮中醉
诗：瘴塞蛮江人洞流，/人家多在竹棚头。/青山海上无城郭，/唯见松牌出象州。

# 寓题
诗：把酒直须判酩酊，/逢花莫惜暂淹留。/假如三万六千日，/半是悲哀半是愁。

# 送赵十二赴举
诗：省事却因多事力，/无心翻似有心来。/秋风郡阁残花在，/别后何人更一杯？

# 偶呈郑先辈
诗：不语亭亭俨薄妆，/画裙双凤郁金香。/西京才子旁看取，/何似乔家那窈娘？

# 子规
诗：蜀地曾闻子规鸟，/宣城又见杜鹃花。/一叫一回肠一断，/三春三月忆三巴。

# 江楼
诗：独酌芳春酒，/登楼已半醺。/谁惊一行雁，/冲断过江云。

# 旅宿
诗：旅馆无良伴，/凝情自悄然。/寒灯思旧事，/断雁警愁眠。
诗：远梦归侵晓，/家书到隔年。/湘江好烟月，/门系钓鱼船。

# 杜鹃
诗：杜宇竞何冤，/年年叫蜀门？/至今衔积恨，/终古吊残魂。
诗：芳草迷肠结，/红花染血痕。/山川尽春色，/鸣咽复谁论？

# 闻蝉
诗：火云初似灭，/晓角欲微清。/故国行千里，/新蝉忽数声。
诗：时行仍髣髴，/度日更分明。/不敢频倾耳，/唯忧白发生。

# 送友人
诗：十载名兼利，/人皆与命争。/青春留不住，/白发自然生。
诗：夜雨滴乡思，/秋风从别情。/都门五十里，/驰马逐鸡声。

# 旅情
诗：窗虚枕簟凉，/寝倦忆潇湘。/山色几时老？/人心终日忙。
诗：松风半夜雨，/帘月满堂霜。/匹马好归去，/江头橘正香。

# 晓望
诗：独起望山色，/水鸡鸣蓼洲。/房星随月晓，/楚木向云秋。
诗：曲渚疑江尽，/平沙似浪浮。/秦原在何处？/泽国碧悠悠。

# 贻友人
诗：自是东西客，/逢人又送人。/不应相见老，/只是别离频。
诗：度日还知暮，/平生未识春。/倘无迁谷分，/归去养天真。

# 书事
诗：自笑走红尘，/流年旧复新。/东风半夜雨，/南国万家春。
诗：失计抛渔艇，/何门化涸鳞？/是谁添岁月，/老却暗投人。

# 别鹤
诗：分飞共所从，/六翮势催风。/声断碧云外，/影孤明月中。
诗：青田归远路，/丹桂旧巢空。/矫翼知何处？/天涯不可穷。

# 晚泊
诗：帆湿去悠悠，/停桡宿渡头。/乱烟迷野岸，/独鸟出中流。
诗：篷雨延乡梦，/江风阻暮秋。/倘无身外事，/甘老向扁舟。

# 山寺
诗：峭壁引行径，/截溪开石门。/泉飞溅虚楹，/云起涨河轩。
诗：隔水看来路，/疏篱见定猿。/未闲难久住，/归去复何言。

# 早行
诗：垂鞭信马行，/数里未鸡鸣。/林下带残梦，/叶飞时忽惊。
诗：霜凝孤鹤迥，/月晓远山横。/僮仆休辞险，/时平路复平。

# 秋日偶题
诗：荷花兼柳叶，/彼此不胜秋。/玉露滴初泣，/金风吹更愁。
诗：绿眉甘弃坠，/红脸恨飘流。/叹息是游子，/少年还白头。

# 忆归
诗：新城非故里，/终日想柴扃。/兴罢花还落，/愁来酒欲醒。
诗：何人初发白，/几处乱山青？/远忆湘江上，/渔歌对月听。

# 偶见黄州作
诗：朔风高紧掠河楼，/白鼻騧郎白罽裘。/有个当垆明似月，/马鞭斜揖笑回头。

# 醉倒
诗：日晴空乐下仙云，/俱在凉亭送使君。/莫辞一盏即相请，/还是三年更不闻。

# 酬许十三秀才兼依来韵
诗：多为裁诗步竹轩，/有时凝思过朝昏。/篇成敢道怀金璞，/吟苦唯应似岭猿。
诗：迷兴每惭花月夕，/寄愁长在别离魂。/烦君把卷侵寒烛，/丽句时传画戟门。

# 后池泛舟送王十秀才
诗：城日晚悠悠，/弦歌在碧流。/夕风飘度曲，/烟屿隐行舟。
诗：问拍疑新令，/怜香占彩毬。/当筵虽一醉，/宁复缓离愁。

# 书情
诗：谁家洛浦神？/十四五来人。/媚发轻垂额，/香衫软着身。
诗：摘莲红袖湿，/窥渌翠娥频。/飞鹊徒来往，/平阳公主亲。

# 兵部尚书席上作
诗：华堂今日绮筵开，/谁召分司御史来？/偶发狂言惊满坐，/三重粉面一时回。

# 骕骊坂
诗：荆州一万里，/不如蒯易度。/仰首望飞鸣，/伊人何异趣？
