# 在烽火中成长
原：我国最后一个封建王朝——清朝，是由满族贵族建立的。它的建国史可分为前后两个阶段，前段称为后金，后段称为清。前者为努尔哈赤创立，而将后金改为清，并正式建帝号称大清皇帝，却是努尔哈赤的第八个儿子皇太极。
原：皇太极生于明万历二十年(公元1592年)十月二十五日，是努尔哈赤第六位妻子叶赫纳那氏所生。他的名字在书中写法颇不一致，有洪太主、黄台吉、红歹是、黑还勃烈等称。皇太极的母亲是努尔哈赤最喜爱的妻子，故他也倍受父母宠爱。但他的母亲二十九岁就死了，这时皇太极只有十二岁。
原：皇太极从小聪明过人，“一听不忘，一见即识”。家里有专门教师，小时候就受到良好教育，自己又特别喜欢读书，对中国古典小说《三国演义》、《水浒传》等文艺作品以及正史书籍，都读了不少。所以后来他能常常引用中国历史上的帝王得失功过作为统治的借鉴。
原：女真人喜欢打猎。这也是皇太极喜欢的活动，他常年穿甲胄，跃马扬鞭，随同父兄一起围猎，由此练就了一身超群的武艺。他的箭法特别好，“步射骑射，矢不虚发”，膂力也大。他在征讨林丹汗途中，因缺粮打猎，一箭射穿两只黄羊，不一会就射杀五十多只。
原：在管理日常的事务上，他也显示出具有特别的才能。母丧后，父兄长年在外征战，由他主持家务。努尔哈赤是女真的首领，家内除有众多的妻妾、子女、奴仆、财产外，还由于当时是国事家事不分，不少国事亦在家事中，只有十二岁的皇太极主持和管理这样一个大家的政务、事务，都作得很出色。这不但为父兄分劳，而且也锻炼了他的管理才能。
原：在二十岁时，他就同其兄长一样，独立率领一支军队作战，建立下不少战功。明万历四十四年(公元1616年)，努尔哈赤基本统一了女真各部，建立后金国，改年号为天命。这年皇太极才二十五岁，就被任命为四大贝勒之一的四贝勒。努尔哈赤为了锻炼他们的治国才能，实行四大贝勒轮流主持国政的制度。这个从烽火中锻炼成长起来的王子，已成了努尔哈赤征战和治国的得力助手。
原：后金天命十一年(公元1626年)，六十八岁的努尔哈赤病死，没有留下谁是继承人的遗嘱，他的儿子们根据他生前“选取贤者”为继承人的嘱咐，一致拥戴皇太极继位，时年三十五岁。

# 改革内政 巩固权力
原：皇太极上台后，日子并不好过。努尔哈赤时期虽然在军事上取得不少胜利，但还是留下很多问题，如对汉人的仇杀政策，导致满汉民族矛盾十分尖锐；推行的游牧奴隶制，使生产不景气，物价飞涨；由于长期的马上征战，国家制度很不健全；它的四边都有强大的敌人，对女真族的崛起感到不安而企图扼杀它，稍有不慎，就有被消灭的危险。
原：在内部，皇太极也不能随心所欲地行使职权，他在四大贝勒中居第四，大贝勒代善、二贝勒阿敏、三贝勒莽古尔泰年龄都比他大，且都是拥有相当势力的旗主。皇太极登上汗位后只得同他们一同南面坐受朝拜，共同执政，结果事事“掣肘”，他的主张不能顺利进行。
原：皇太极为了打破这种内外交困的局面，进行了一系列的内政改革。这些改革措施主要有：

# 一、废除奴隶制，实行封建化
原：在当时的环境下，奴隶制不仅束缚生产力的发展，而且是女真贵族凭借的力量。贝勒们都是奴隶主贵族。废除奴隶制，就是削弱他们的势力，所以皇太极在八月末继汗位，九月初就作出一项重大决策：释放庄丁为民。“庄”为女真贵族拥有，庄丁是辽沈地区的汉民，处于奴隶地位。皇太极使他们脱离女真贵族的庄而分屯别居，由汉人官吏管理，这样就使大批汉人庄丁从奴隶贵族下解放出来而成为国家的编户民。他又再三下令，对战争的俘虏，不准屠杀，不准降为奴隶。
原：皇太极还颁布《离主条例》，对奴隶主的不法行为加以限制和打击。《条例》规定：奴隶对主人有权控告其罪行，经审讯属实，主人按律治罪，告发者免为自由人。还规定，主人不准擅杀奴隶、仆人，不准奸淫下属妻女。崇德六年（公元1641年)大贝勒代善之子硕托，打死一个有孕的女仆，经司法审讯属实，罚硕托银一百两，赔偿女奴一名，夺去四个牛录的财产.这表明《离主条例》是认真实行的。

# 二、完善统治机构，加强大汗权力
原：努尔哈赤时期，官职的设置比较粗疏，军国大事主要通过八旗旗主“共议”，集体裁决，带有原始军事民主的色彩。皇太极即汗位后，四个贝勒还一同南面坐受朝拜，名为汗实仅一个旗主而已。而且以前八旗旗主“共议”制，旗主皆女真人，排斥其它民族，这对于不断发展的后金国家也是不利的。于是皇太极乃从两个方面对官吏制度进行改革：

# (一)完善统治机构
原：天聪三年(公元1629年)设立文馆，分文臣为两班：一班翻译汉文典籍，以借鉴汉人封建政权的统治经验，一班记注本朝政事，以究其得失。天聪七年(公元1633年)改文馆为三院：内阁院、内秘书院和内弘文院，称为“内三院”，各设大学士一人，学士二人。清沿明制，不设宰相，而代之以大学士，故内三院中大学士的权力很大，直接参加议定国家大事，握国家机要，直接向汗负责。“内三院”的设置取代了八旗旗主“共议国政”的体制。
原：崇德元年(公元1636年)设置都察院，这是一个独立的机构，有权劝谏、弹劾、纠举文武百官过失。都察院的建立，大大加强了汗的权力。
原：天聪五年(公元1631年)设置六部，即吏、户、礼、兵、刑、工六部。每部以一名女真贝勒总理部务，下设女真承政二员(蒙汉承政各一员)。承政下设参政八员，女真、蒙古、汉人皆有，以分散女真贵族的权力。六部主持者必须对汗负责。
原：六部中有蒙、汉人参政，打破了女真贵族垄断的单一局面。这时有个汉人礼部承政叫李佰龙的，奏请按班次排列入朝，皇太极立即同意，四大贝勒南面同受朝拜的格局就由此废除了。不仅如此，皇太极还对他们进行打击，二贝勒阿敏在此前就因违反军令任意屠杀官民被幽禁，其后三贝勒莽古尔泰在大凌河战役中，因持刀威胁皇太极，被降为普通贝勒，大贝勒代善也因罪受到批评。由是皇太极在内部受到的威胁全部解除。
原：崇德三年(公元1638年)建立理藩院，负责对蒙古、西藏方面的事务。
原：内三院、都察院、理藩院、六部合称三院八衙门，形成一套完整的国家机构。它们直接对汗即皇太极负责，皇太极由是真正掌握了军政大权。

# (二)开设科举，选拔官吏
原：由于统治地区的扩大，官吏需要量增加。治事日繁，对官吏的文化要求也提高了，皇太极认识到这种形势，于是设科考试。他在即汗位的那年就开科取士十六名，其中女真四人，蒙古三名，汉人九名。他在天聪二年(公元1628年)下令女真、汉、蒙族所有生员考试，取二百人。天聪八年(公元1634年)三月，专门开科考试汉族生员，分三等录取，共取二百二十七人。接着又取女真、蒙古族举人十六名。所取之人，无论女真、蒙、汉，无论“新归旧附”，一律“量才录用”。官吏制度的改革，不仅完善了国家机器，而且还提高了官吏的文化水平。

# 三、实行“满汉蒙一体”的民族政策
原：努尔哈赤对汉、蒙民族采取打击与排斥的政策，特别是对汉人更是采用仇杀和变为奴隶的方针，故民族矛盾十分尖锐。皇太极一改其父的做法，他说，“满汉人之间，均属一体”，认为只有将满洲、蒙古、汉人视同一体才能使国家兴盛，“譬渚五味，调剂贵得其宜。若满洲庇护满洲，蒙古庇护蒙古，汉官庇护汉人，是犹咸苦酸辛之不得其和”。这是一个极富远见的政治见解，它使后金政权从狭隘的民族主义圈子中跳了出来，从而扩大了统治的基础。
原：对归降的汉人不杀不辱，分给土地房屋，帮助成家。他说过“归降之民，即我之民人”，“皆吾赤子”。还制定保护降民的法律：“凡贝勒大臣有掠归降地方财物者，杀无赦；擅杀降民者抵罪；强取民物者，计所取之数，赔偿其主。”汉族人民生命财产有了保障，于是安居其业。
原：对归来的汉族宫吏，更是加以重用。天聪五年（公元1631年），后金攻破大凌河城，归降明将官达一百几十人，皇太极如获至宝，在宫廷内为他们举行盛大宴会表示欢迎，并赏赐大批财物。有不少明朝官将成了暴发户，由是引起女真贵族的不满。有一个女真贵族抱怨说：“昔太祖(努尔哈赤)诛戮汉人，抚养满洲。今汉人有为王者，有为昂邦、章京矣。至于宗室(女真人)，今有为官者，有为民者，时势颠倒，一至于此。”这说明皇太极对汉人的态度与努尔哈赤有着很大的不同，以致引起女真人的抱怨。由于他实行优礼汉官的政策，汉人官吏多能尽力效劳，并吸引大批明朝官吏不断前来投奔。
原：对蒙古族，他则以习俗相同，衣着相近，建立起婚姻联盟。他鼓励贝勒、大臣娶蒙古族女子为妻，皇太极本人就有三个妻子是蒙古族人。女真贵族女子亦多嫁给蒙古贵族。通过这种婚姻关系，具体实现了“满蒙一体”的政策。皇太极本不信佛教，但蒙古人却笃信喇嘛教，为了巩固与蒙古族的关系，他很快变成喇嘛教的虔诚信徒。在沈阳建实胜寺，供奉喇嘛佛，并亲自带领大臣参拜。皇太极这一作法影响很大，当时地处边陲的西藏达赖五世，在崇德七年(公元1642年)派使节，不远万里到沈阳向皇太极通好。皇太极以极大的热情加以接待。
原：皇太极的民族联合政策是很成功的，经他多年的实施，建立起了以满族为主体的满、汉、蒙族地主阶级的联合政权。

# 四、扩充军队，建立满、汉、蒙古八旗
原：皇太极在满人八旗的基础上，天聪九年(公元1635年)击败蒙古察哈尔部后，将蒙古丁壮编为“蒙古八旗”。后来又逐渐用汉人为士兵，编成汉人八旗，由汉官统领。这样，在皇太极时期就有满、蒙、汉三种民族的八旗组织。
原：皇太极的这些改革，不仅加强了他个人的权力，而且使国家机构完善，民族关系融洽，后金的国力大大加强了.

# 扩张战争的节节胜利
原：后金政权突然崛起于松辽地区，对邻国构成很大威胁，因此，各国时时想将它扼杀。皇太极清醒地认识到，在这“四境逼处”之中的后金只有积极进取，才是生存之保障。由是，在他继位后，继续其父的政策，不断向外征战。皇太极的对外战争主要有四个方面：

# 一、对朝鲜的战争
原：朝鲜与明朝有二百多年的友好关系，是明朝可靠的同盟者，与明朝成东西“犄角之势”，共同打击后金。后金政权的主要敌人当然是明朝，但不解决朝鲜问题，后金就不可能放心南下。天聪元年(公元1627年)一月，借口朝鲜“累世得罪”于后金，派二贝勒阿敏统兵三万，进攻朝鲜，很快深入朝鲜腹地，过大同江，克黄州瑞兴，直达平山。朝鲜国王李倧带着眷属逃到江华岛，派人求和。阿敏要求朝鲜同明朝断绝关系，以李倧弟李觉为人质，与后金结为兄弟之邦。李倧皆一一答应，并签订了“江都和约”。朝鲜按“和约”规定，每年春、秋两季向后金遣使纳贡，两国开放互市。
原：但是，朝鲜与明朝有着长期的友好关系，特别是明对它不象后金那样构成直接的威胁，联明可以减轻后金的压迫，故表面上虽与明断绝关系，暗中却还在通使往来。皇太极想攻占沿海诸岛，向朝鲜要求派大船支援，李倧坚持不派。又向朝鲜征粮，仍不给。1636年2月，皇太极准备称皇帝，朝鲜不遣使称贺，还表示反对。于是皇太极亲统十五万大军征朝鲜。皇太极的军队，连败朝鲜守军，很快攻下朝鲜国都。李倧将妻子送往江华岛，自己率兵退守南汉山城。清军包围了南汉山城，击败前来勤王的朝鲜军。李倧遣使向明求援，明援军亦被清军打败.皇太极派军攻下江华岛，俘李倧王妃、王子及宗室大臣。李倧困于孤城，走投无路，只得出城投降，同皇太极订立了“城下之盟”。朝鲜向清称臣，完全断绝了同明朝的关系，成了清的属国。皇太极征服朝鲜的胜利，不但得到经济上的利益，而且还解除了后顾之忧。

# 二、对蒙古的战争
原：蒙古是一个勇敢善战的民族，它游牧于大漠南北的广大地区，东与后金相连，南与明朝相连。明朝采取优抚的方式，对蒙古各部进行笼络，特别是对其接壤的漠南蒙古(蒙古分三部：喀尔喀蒙古，在今蒙古人民共和国境；额鲁特蒙古，在今新疆北部及苏联哈萨克、吉尔吉斯加盟共和国东部；漠南蒙古，在今内蒙古自治区）。后金要对明用兵，不处理好与蒙古族的关系，就会侧翼受敌。
原：努尔哈赤对蒙古的经营很注意。他采取“顺者以德服，逆者以兵临”的软硬两手策略，收到很好的效果，并以习俗、衣着相同，原本出于同祖等方式与蒙古族联络感情。女真与蒙古贵族间不断通婚，这样就使后金与一些蒙古部建立起密切的关系。
原：蒙古的各部不是一个统一体。但它内部统一事业在明末也已开始，所以后金的争取、拉拢政策，对一些强大的企图统一蒙古的部落收效不大，其中最主要的对手是漠南察哈尔部，其首领林丹汗恃强自傲，依靠明朝在经济上的支持，与后金为敌。
原：林丹汗虽有力量，却对属下各部进行横暴统治，皇太极不失时机地做分化瓦解工作，因而不断有蒙古部脱离林丹汗而转向后金。林丹汗为了巩固势力，于天聪五年(公元1631年)兴兵讨伐叛归后金的阿鲁科尔沁部，进军到西拉木轮河北岸。皇太极闻讯，统兵前往援助，林丹汗后撤返回。
原：第二年(天聪六年，公元1632年)皇太极再统八旗军和降服的蒙古各部大举西征。林丹汗由于部属纷纷叛离，力量削弱，便举部“弃本土西奔”，皇太极率军长驱追至西土默特，烧毁板升城(今内蒙古自治区呼和浩特)。林丹汗从此一蹶不振。天聪八年(公元1634年)林丹汗率残部西越河套，奔青海，出天花死在大草滩。皇太极闻知，急派人招收其残部。天聪九年（公元1635年)二月，多尔衮在托里图招降林丹汗子额哲归顺，漠南蒙古从此统一在后金之下。

# 三、统一黑龙江诸部
原：黑龙江本是努尔哈赤的故乡，但只是下游地区各部被收服，而黑龙江上、中游地区各部的一些部落还处在后金势力控制之外。皇太极即位的当年，便派兵对这里进行征伐，从天聪三年至崇德二年(公元1629一1637年)多次对为首不服的瓦尔喀部落用兵，终使其臣服。后来又对黑龙江中、上游的虎尔哈部和索伦部进行征讨。皇太极用“慑之以兵，怀之以德”的两手策略取得一个接一个的胜利。在平定索伦部的战争中，清军攻克了雅克雅城(今苏联阿尔巴津)、乌库尔城(在乌库尔河与黑龙江会流处附近)、阿萨津城(在黑龙江北岸)、铎陈城(在阿萨津城东南)，直至齐洛台(今苏联赤塔附近)。最后将虎尔哈部和索伦部统一起来。
原：在统一瓦尔喀、虎尔哈和索伦部的大部落过程中，皇太极还派兵征服了黑龙江中上游的卦尔部、乌扎喇部和库尔喀部。致使分布在斡难河(今苏联鄂嫩河)、尼布楚(今苏联涅尔琴斯克)一带的蒙古茂明安部和分布在外兴安岭以南，兀的河（今苏联乌第河)、恨古河(今苏联阿穆贡河)流域的使鹿部也先后臣服于清。从此黑龙江流域全部纳入清的版图。

# 四、对明朝的战争
原：进兵关内，灭亡明朝，建立以满人为主体的新王朝，是努尔哈赤、皇太极父子的共同心愿。皇太极曾说：“取北京如伐大树，从旁砍则大树自仆。”皇太极对明朝的战争都是运用“从旁砍”的策略。明朝对后金的防守，其战略要地是山海关、锦州、宁远等城，驻有重兵，皇太极采取绕道山海关，深入明朝腹地，削弱其力量，再一举将其灭亡的战略。曾六次派兵深入河北、山东、河南，威逼北京，俘获大批人口、牲畜和金银财物，给明朝以沉重打击。崇德四年(公元1639年)在锦州、松山地区歼灭明军精锐十三万，活捉了蓟辽总督洪承畴，全部占领了明朝在关外的防御阵地。灭亡明王朝的时机已经成熟了。

# 大功垂成 溘然长逝
原：皇太极并没有坐上北京的金銮殿。正在他对明朝的战争取得决定性胜利的时候，却在崇德八年（1643年）的八月九日夜，骤然“端坐而崩”，这年他只有五十二岁。一生的操劳与戎马生活，已耗尽了他的精力。
原：皇太极在一六二六年即位为后金国汗，年号天聪。天聪十年(公元1636年)改汗为皇帝，改国号为清，年号为崇德，女真族名也改为满族。清朝的建立，应该说是在皇太极改国号为清，即皇帝位的那一年。
原：皇太极的突然死去，使清统治集团中出现一片混乱，在立谁为新主的问题上，各派力量展开了激烈的斗争，最后在多尔衮的拥戴下，年仅六岁的福临当上了皇帝，由多尔衮和济尔哈朗共同辅政。
原：在皇太极死后的第二年，李自成领导的农民起义军攻占了北京，明崇祯皇帝自杀，朱明王朝灭亡。山海关总兵吴三桂，听说李自成军抄了他在北京的家产，囚禁了他的父亲，特别是她的爱妾陈圆圆被掳，于是投降清朝，并引清军入关。这年五月一日，清军攻进北京城，清朝的首都也随即从沈阳迁到北京，终于实现了皇太极父子入主中原的理想。清朝迁都北京，入主中原之时，离皇太极之死不足十个月。
