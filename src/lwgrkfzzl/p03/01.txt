# 第一部分 五十年人口过程


# 一、人口发展趋势
原：人口发展趋势是指现实人口在某些因素的推动下，将要显示出来的一种态势。对人口发展趋势的说明，实质上是对以某些因素为前提条件所设计的人口发展方案的各个方面进行的预测。历史上从来没有过那一种方案能够完全实现，但这并不说明人口预测不重要，而只说明人口发展过程的复杂性。它除受经济条件的决定性制约以外，还受政治、文化、宗教、生活习惯、社会心理等各方面的影响。即使经济的原因也是通过大量偶然性表现其必然的趋势。因此，别说细节，就是总的趋势也往往与预测有很大出入。但人口预测毕竟可以给人们提供出在某种条件下将要出现的人口状况的大致情况。因此，人们对于自己的前途就不致于那么盲目了。如实地记述某种人口过程或即将出现的人口趋势，是科学工作者的任务。

# 二、必须注重人口年龄结构方面的预测和分析
原：许多人对于人口预测只注重人口总数的变化，而对于将要发生的某一静止状态的人口构成则不予理睬。这是一种误会。某时社会总人数只反映了人口的量的方面，而揭示多种构成则是在说明它的质，特别是年龄构成被揭示出来以后，才算真正了解了这一时期的人口状态。基于这种理由，我在后文主要是想揭示人口的各种构成，特别是年龄构成。但是，我国已有十六年未搞人口普查，无详细和准确的资料，文中数字只能是匡算的结果，可以大致反映各时期的人口状况。

原：1.人口总数：二〇〇〇年当人口增长为零时，全国总人口将达到十点五亿左右。

原：4.经济年龄结构的演变
原：到二〇〇○年，由于出生率已经过了三十年的连续下降。年龄金字塔呈萎缩型。因为六十年代中后期出生的人口这时正当三十多岁，以及围绕这次出生高峰的两个峰坡也正当劳动年龄(五十年代后期大量出生的人口为四十多岁)，这时的经济活动人口是最为旺盛的时期。并且，解放后出生的人口比解放前要多得多，但还未曾到退出劳动年龄的时候。而近二十年出生率又压得最低，故社会负担人口又最少。如果用年龄三区分法表示，0一14岁人口是一点四亿，15—64岁是七点三四亿，65岁以上人口是一点七六亿。
原：5.各种指数及其含义
原：二○○○年社会附属人口指数（%）将分别为：少年人口指数十九，老年人口指数二十三点九七。所以，社会负担指数将是四十二点九七。这也就是说，每一百个劳动年龄的人口负担四十二个附属人口。其中少年人口为十九个，老年人口二十三个。
原：从劳动经济学的观点来说，分析人口状况主要是看劳动人口和其他各种年龄构成的关系。而在一定程度说，二○○○年以前的劳动力已成为既与的条件和事实。因此，它并不与同期内的人口政策有更为密切的内在联系。

# 四、二十一世纪最初三十年人口发展状况
原：倘二○○○年人口增长达到零，在二十一世纪里，人口将向何处发展？那时的人们仍将面临三种抉择，一种是开始减少人口，一是增加人口，其三是人口持平，即每年仍保持零度增长。我们以第三种方案为基础，讨论一下二十一世纪最初三十年人口发展过程。
原：1.人口总数
原：由于人口保持零度增长，每年生死人口数相抵，因此，下一世纪最初三十年的人口将保持在十点五亿左右。
原：2.人口内部的变化与更新
原：虽然人口总数保持不变，从形式上可称之为静止人口。但其实并不静止，内部各年龄层的人口在不断替换与更新着。我们以每五年为一组看一下人口变动三十年。

原：3.人口再生产的特点
原：从表3还可看出，由于二○○〇年以后，二十世纪八十年代以后出生低潮的人口开始进入初婚年龄，而死亡人口却逐年上升，为保持总人口不变，就必须缩小一对夫妇生一个孩子的比例和鼓励每个家庭生二个孩子。二○〇六年开始还将有百分之四十的夫妇生三个孩子，逐年发展到全部新婚夫妇生三个孩子，甚至要求相当一部分夫妇生四个孩子才能满足社会人口不减。从这种为维持社会一定数目的人口再生产来说，可称之为人口过程是简单再生产。

原：6.年龄结构金字塔分析
原：六十年代中后期和七十年代初是我国人口发展史上出生人数最多的时期，从七十年代中期开始出生率就一直处于下降过程中，到九十年代是出生人数最低的时期。到二○二〇年，出生人口最少的年龄组人口已经进入了劳动年龄。二○三○年，这部分人已经成为支撑社会的主要力量。此外，劳动年龄层的特点是劳动年龄高龄化，即劳动年龄的人口中中、老年人口的膨胀。虽然劳动年龄的人口不少，但大都已接近退休年龄。相反，在劳动年龄中具有重要意义的三十岁左右的人口开始有减少的趋势。形成劳动年龄层的人愈来愈少，而两方面的负担人数又都有增长的趋势，特别是老年人口增长势头很猛。

# 五、五十年出生率变动情况
原：考察人口自然变动主要依据有三个数字，即出生率、死亡率及自然增长率。但是，从经济学角度来讲，考察人口变动情况主要是为了分析若干年内人口内部的劳动资源情况。所以，在其中应主要分析出生率的变动。
原：从一九八〇一二〇三〇年共五十年中，出生率总的来说是被压得很低的。具体来讲，一九八○年的起点是在十年急骤下降的基础上开始的。从八○年到二○○○年仍然是下降趋势。二○○○年以后又开始缓慢回升，其中二○○○年为我国出生率最低的年份。从表面上看，本世纪最后二十年的出生率下降幅度好象不大，但却是难度最大和最困难的。因为它已经接近了人类再生产的最低状态。相反，后三十年出生率虽然有所上升，但上升的趋势却是极为缓慢，因为它仍然被压得接近于最低的水平。

# 第二部分 五十年人口变动过程的分析


# 一、为什么要讨论人口发展五十年
原：我在全国第二次人口科学讨论会上指出，二○〇〇年以后，甚至在二○三○年左右将可能出现一些社会问题时，有的同志曾就此提出不同的看法。这些同志认为，我们目前讨论的是现实的人口问题，执行的一些人口政策也是最近若干年的事，为什么要涉及半个世纪？
原：我们认为，人口过程的特点是具有历史的连续性。有些人口现象虽则是现实发生的，但其后果却将潜伏几十年才暴露出来，不讨论可能出现的后果就不足以说明现实问题的历史地位。其次，我在这里讨论的也不是近几年里的人口问题，而是讨论二十年的人口问题。二十年，足以成为一代人的岁月，它已达到可以造成某种社会后果的年月。记得五十年代后期批判马寅初先生“新人口论”到酿成中国建国后第一次人口问题，也就是不到二十年的样子。再次，我们所讨论的现实人口再生产模式在中外历史上都未曾有过，在现实中或许有它的必然性，但从历史发展过程中究竟怎样？应该说明。又次，从现在起五十年内外是我国飞速发展的年代，而这种发展毕竞是中华民族的历史。二十世纪最后二十年应该蓬蓬勃勃，隆隆起飞。二十一世纪最初三十年。不能凄凄惨惨，而应把下一世纪开始就搞成个有希望的年代。为此也有必要讨论人口过程五十年。最后，我是为了说明最近二十年的事情，而必须探究后边的三十年。也即是说，为说明前二十年，必须说明后三十年。说明后三十年的目的在于说明前二十年。因此，必须分析人口变动五十年。
原：讨论后三十年有一个难于处理的，但纯然是形式的难题，即后三十年人口模式取什么？也就是说，二○〇〇年以后人口将采取增长、减少或零增长？这与讨论问题并不发生本质关系。因为，我们讨论的是近二十年的后果或在后三十年中的影响。但它却往往给人以口实：当人们遇到质疑时就会说，那时我们将不采取某种人口政策，而将改变人口政策。这样似乎就摆脱了回答难题的义务。
原：为避免这一麻烦问题，我采取了折中方案，即二○○○年以后选取人口不增不减。这是因为，倘那时采取让人口增长的政策，不但与现今努力相悖，而且很可能形成前功尽弃。二○○○年初婚夫妇每年也不过六百万对，死亡人数却在一千万以上，初婚的育龄妇女是满足不了人口增长要求的。而那时二十岁到四十岁的育龄妇女将在二亿左右，二十年中被压在只准其生一个孩子的限度以内，若稍有变化，来次补偿性生育，总人口必然突破十四亿，造成人类发展史上从来没有过的生育高峰。相反，继续采取一胎化，造成的人口老化等问题会更迅速，这会使一些人在讨论中拒绝回答问题，或把前二十年的问题推诸于后三十年的人口政策。为此，我过去和现在都选用人口持平的方案，即在说明三十年后可能出现的一些问题时，就已经改变了人口政策。

# 二、再谈人口老化问题
原：现在认为我国人口多、不会发生老化的认识不多了，这是因为这些同志已经明白了人口老化是出生率和死亡率持续降低必然产生的结果。人口越多，老化以后的社会问题会越严重。有些同志从造成老化的原因又得出结论，说人口老化并不可怕，或者说是一种历史必然性。这看怎么说，人口一定程度的老化可以说是好事，这是由于社会生产力的发展，人们战胜自然力，战胜一部分死神过早夺去人们生命的标志。平均寿命延长了，所以，一定程度的人口老化出现了。这当然没有什么不好。但这必须放在一定程度之内，是死亡率降低的结果。如果一味把出生率尽量压低，压得低于一般水平以下很多，超越了界限，造成人口严重老化，不一定也是历史的趋势。人口老化问题应该具体来讨论，而不应抽象地说它好与不好。
原：我国目前属于年轻型的人口，六十五岁以上老人在总人口中大约占百分之六、七，一九九○年可能接近百分之十，二○○○年将超过百分之十五，较接近于西方国家的目前老化程度。二一○年以后，人口老化过程越来越快，越来越严重，二○一五年将由前五年的百分之十八发展到百分之二十一，二〇二〇年百分之二十三点八二，二〇二五年为百分之二十七点六一，二〇三〇年为百分之三十二点三八。应该说明，二〇三○年以后的十年，人口老化过程还将以更快速度增长。
原：我国人口老化的这一过程从速度上来说是相当快的，特别是二○○〇年以后，步子越来越快，如果以二○一○年为一百，十年后老化程度增长到百分之一百三十二，二十年后增长到百分之一百八十。高峰时，老年人口将达到四亿左右。也就是说，每十个人口中，将有四个人是六十五岁以上的老年人，老年人口从百分之八提高到百分之十八。法国用了一百七十七年，瑞典用了一百零三年，英国五十六年，日本估计可用四十年。而我国以此推算仅十几年就可以完成了。百分之二十四是日本七十年以后的推测，二十五以上是至今世人难以相信的数字。

# 四、再谈劳动力的资源问题
原：作为社会资源的劳动力既有一个绝对量的问题，又有一个相对量的问题。抽象地谈论劳动力是否充足，如同争论针尖上能站几位天使一样，纯粹是一个经院哲学问题。

# 五、关于经济规律决定人口规律和其他
原：人类自身的生产和再生产是社会生产的一个基本方面。但是，人类自身的生产是社会基本经济规律通过间接地于预和影响的过程。所谓基本经济规律决定人口规律，就是说人类自身的生产和再生产有着自己特殊的规律。它受约于经济规律，但又不等于和直接表现为经济规律。那种认为社会主义经济规律要求计划生育，计划生育就是直接规定每个家庭只准生一个孩子的认识，是一种错觉。我们可以看到，甚至经济规律本身也不直接地和具体地规定各个家庭的经济和生活方式。
原：各种不同的社会形态有其特殊的人口规律。尽管它由该社会的基本经济规律所决定，但经济规律却不能代替人口规律。人口规律是人口过程中内在的和决定性的规律。但影响人口过程也决不只有经济规律及人口规律，还有科学技术、文化、风俗习惯、宗教及社会心理等。某种社会经济规律和其他因素综合地影响着人口过程，总地说决定了人口规模。但也并不是说直接规定了人口规模的数量。比如说，某种社会人口只能达到十亿，多了或少了就不是该社会经济规律和人口规律所要求的。显然不是这样。某种人口规模由该社会经济规律和人口规律所决定，也只是有个大致的幅度，我们不能认为它会增长得无限度，也不能企望它一味地少下去。
原：人口政策就是在这个幅度内调整人口规模。一些同志认为既然过去节制生育可以下降那么多，现在还可以继续下降，而且可以永远下降的认识是不正确的。我们只能在分析现在人口结构的基础上，制定出适用于目前人口特点的人口政策来，这种人口政策只能在某种幅度内起调节作用，超越了这个幅度，它就不会起到预想的作用。比如，一胎化政策的前景可以预言它的两种结果，倘在二十年内实行了或者将造成二○○〇年以后的一些后果；或者在二十年中偶遇波折，就会出现补偿性生育。因为在我国目前经济诸方面，人口构成特点都不允许实行一胎化。
原：除经济上考虑外，其他方面也不允许在农村实行一胎化就。医疗卫生条件来说，农村儿童死亡率要比城市高得多，全国农村婴儿死亡率的资料是难以统计的。但从上海市死亡人口的年龄构成(见表8）可以看出，农村儿童死亡率在目前还是比城市高得多，尽管上海郊区的医疗条件并不比有些城市低。我们在这么差的医疗条件下，有什么理由要求农民只生一个孩子呢？

# 第三部分 中国人口发展战略
原：我们作的以上二部分的分析，绝不是说不同意对我国人口加以控制，而是对我国人口发展的前景作一些实事求是的探讨和说明，希望把我国人口出生率控制在一个适当的水平上。在一定程度内，提倡一对夫妇生一个孩子都是可以的，这有利于控制我国人口增长。但如果要实行一胎化的人口政策，我们就必须认真地考虑上面所提出的一些严重的社会后果。
原：此外，我相信正确解决我国人口问题的办法也是有的，我们并没有发展到必须让每对夫妇生一个孩子才能解决眼前困难的境地。只要人口学界和经济学界真正展开学术争鸣，好的办法总是有的。
原：(写于一九八○年春节)
