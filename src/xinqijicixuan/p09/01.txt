# 宋高宗绍兴十年 金熙宗天眷三年 庚申（1140）
原：五月十一日，稼轩生于山东历城。
原：父文郁早卒，自幼随祖父辛赞。
原：辛赞因累于族众，未随宋室南渡，后仕于金。先后为谯县、开封等地守令。
原：次年十一月，宋金“绍兴和议”成，宋向金称臣。十二月，岳飞遇害。
原：稼轩少受业于亳州（今安徽亳县）刘瞻（字喦老，号樱宁居士），与党怀英同学。

# 宋绍兴二十三年 金海陵王贞元元年 癸酉（1153）
原：稼轩十四岁。
原：金主完颜亮迁都燕京。
原：稼轩领乡举。次年遂有首次燕山之行。

# 宋绍兴二十七年 金正隆二年 丁丑（1157）
原：稼轩十八岁。
原：礼部赴试，始有二次燕山之行。稼轩自谓“大父臣赞尝令臣两随计吏抵燕山，谛观形势。谋未及遂，大父臣赞下世”（《美芹十论》）。辛赞的去世，当在稼轩十八岁至二十一岁间。

# 宋绍兴三十一年 金世宗大定元年 辛巳（1161）
原：稼轩二十二岁。
原：夏，金主完颜亮迁京开封。九月，大举南侵。
原：稼轩聚众二千，归义军耿京部，为掌书记，劝说耿京归宋，以图大计。
原：僧人义端窃印叛逃，稼轩追杀之。
原：十月，金辽阳留守完颜雍发动政变，自立为帝，改元大定。
原：十一月，采石矶一役，完颜亮死于内部兵乱，金军败撤。

# 宋绍兴三十二年 金大定二年 壬午（1162）
原：稼轩二十三岁。
原：正月，领命奉表南归。高宗召见，授右承务郎。
原：闰二月，叛将张安国杀耿降金。稼轩约王世隆等率五十骑生擒张安国，献俘建康。
原：改任江阴（今江苏江阴县）签判，由是宦居南方。
原：夏，孝宗赵眘继位，起用主战名将张浚，准备北伐。

# 宋孝宗隆兴元年癸未（1163）
原：稼轩二十四岁，在江阴签判任上。
原：夏，张浚兵败符离，罢枢密使。
原：七月，汤思退为相，主和议。

# 隆兴二年甲申（1164）
原：稼轩二十五岁，江阴签判任满去职。
原：宋金“隆兴和议”成，宋向金称侄。
原：后此三年，稼轩漫游吴楚，事历不详。或谓次年进《美芹十论》。

# 孝宗乾道四年戊子（1168）
原：稼轩二十九岁，任建康（今江苏南京）通判。
原：与史正志（致道）、叶衡（梦锡）结识。时史知建康兼行宫留守，叶为淮西军马钱粮总领，治所在建康。

# 乾道六年庚寅（1170）
原：稼轩三十一岁。
原：召对延和殿，论及南北形势、攻守之计。
原：迁司农寺主簿，向执政虞允文上《九议》，力陈恢复要略。
原：是年又有《阻江为险须借两淮疏》、《议练民兵守淮疏》。

# 乾道八年壬辰（1172）
原：稼轩三十三岁。
原：春，出知滁州（今安徽滁县）。宽征薄赋，招流散，教民兵，议屯田。未几，荒陋之气，一洗而空。
原：建“奠枕楼”。秋，友人周孚（信道）来会，作《奠枕楼记》。

# 孝宗淳熙元年甲午（1174）
原：稼轩三十五岁。
原：春，辟为江东安抚使参议官。时叶衡知建康兼江东安抚使，稼轩再官建康，当出自叶的引荐。
原：叶衡召赴临安，六月任参知政事，十一月迁右丞相兼枢密使。

# 淳熙二年乙未（1175）
原：稼轩三十六岁。
原：春夏之交，叶衡荐以慷慨有大略，调临安任仓部郎官。登对，上《论行用会子疏》。六月，改任江西提点刑狱，节制诸军，“督捕”茶商军。
原：九月，叶衡罢相。
原：闰九月，稼轩平茶商军，加秘阁修撰。

# 淳熙三年丙申（1176）
原：稼轩三十七岁。
原：秋冬之际，由江西提点刑狱改调京西转运判官，任所在湖北襄阳。

# 淳熙四年丁酉（1177）
原：稼轩三十八岁。
原：春，由京西转运判官差知江陵府（今湖北江陵县），兼湖北安抚使。严治盗之法，奸盗屏迹。
原：冬，改知隆兴府（今江西南昌），兼江西安抚使。

# 淳熙五年戊戌（1178）
原：稼轩三十九岁。
原：正月，陈亮（同甫）至临安，三上书力请废和抗战，未果而归。
原：暮春，召赴临安，任大理寺少卿。与陈亮结识，互引知己。
原：夏秋之交，出为湖北转运副使。

# 淳熙六年己亥（1179）
原：稼轩四十岁。
原：春三月，由湖北转运副使改湖南转运副使，上《论盗贼札子》。
原：秋，改知潭州（今湖南长沙），兼湖南安抚使。

# 淳熙七年庚子（1180）
原：稼轩四十一岁。
原：在湖南安抚使任上，兴修水利，赈济饥民，整顿乡社。更创置湖南飞虎军，为江上诸军之冠。
原：冬，加右文殿修撰，差知隆兴府兼江西安抚使。

# 淳熙八年辛丑（1181）
原：稼轩四十二岁。
原：江西安抚使任上，举办荒政，卓有成效。及秋，朝廷嘉奖，转奉议郎。
原：十一月，改除两浙西路提点刑狱公事。台臣王蔺劾其帅湖南时，“用钱如泥沙，杀人如草芥”，落职罢新任。
原：是年，信州（今江西上饶）带湖新居落成。以“稼”名轩，自号稼轩居士。

# 淳熙九年壬寅（1182）
原：稼轩四十三岁，罢居上饶带湖宅第。
原：是年范开（廓之）始来受学。

# 淳熙十五年戊申（1188）
原：稼轩四十九岁，仍家居上饶。
原：正月，门人范开编刊《稼轩词甲集》成。
原：邸报讹传稼轩以病挂冠，因赋《沁园春》词，以明视听。
原：友人陈亮来访（朱熹爽约未至），同游鹅湖，共酌瓢泉，议时论政，长歌相答。留十日，乃去。

# 光宗绍熙二年辛亥（1191）
原：稼轩五十二岁，仍家居上饶。
原：冬有诏命，起为福建提点刑狱。

# 绍熙三年壬子（1192）
原：稼轩五十三岁。
原：春，离家赴闽任。
原：九月，福建安抚使林枅卒，稼轩兼摄帅事。厉于吏治，并上《论经界钞盐札子》。
原：冬，应诏赴临安。

# 绍熙四年癸丑（1193）
原：稼轩五十四岁。
原：赴临安途中，访朱熹（晦庵）于建阳，晤陈亮于浙东。
原：抵京，光宗召对，奏论加强荆襄上流之军防。迁太府少卿。
原：秋，加集英殿修撰，知福州兼福建安抚使。
原：是年，陈亮举进士，光宗亲擢第一。

# 绍熙五年甲寅（1194）
原：稼轩五十五岁。
原：福建安抚使任上，置“备安库”，积五十万贯。更拟秋后建万人军旅，保境安民。
原：六月，赵汝愚等拥立赵扩（是为宁宗），尊光宗赵惇为上皇。
原：七月，谏官黄艾劾稼轩“残酷贪饕，奸赃狼藉”，遂罢帅任，主管建宁府武夷山冲祐观。九月，又降充秘阁修撰。
原：再至铅山期思卜筑，作《沁园春》词。
原：八月，以赵汝愚为右丞相。十一月，特迁外戚韩侂胄为枢密都承旨。
原：是年陈亮卒。

# 宁宗庆元元年乙卯（1195）
原：稼轩五十六岁。二度罢居上饶。
原：二月，赵汝愚罢相，出知福州。十一月贬永州。
原：十月，稼轩又遭劾，免去秘阁修撰。
原：是年铅山期思新居落成。

# 庆元二年丙辰（1196）
原：稼轩五十七岁。带湖雪楼被焚；举家徙居铅山瓢泉。
原：赵汝愚卒于衡州。韩侂胄加开封府仪同三司，兴“伪学党禁”（亦称“庆元党禁”）。网括赵汝愚、朱熹等五十九人为“逆党”，以朱熹为“伪学之魁”。
原：九月，稼轩以言者论其“赃污恣横，唯嗜杀戮，累遭白简，恬不少悛”，罢宫观。至此，稼轩所有名衔，尽削一空。

# 庆元四年戊午（1198）
原：稼轩五十九岁，家居铅山瓢泉。
原：朝命复集英殿修撰，再主管武夷山冲祐观。稼轩有《鹧鸪天》词，题曰“戊午拜复职奉祠之命”。
原：吴绍古（子似）任铅山尉，与稼轩酬唱颇富。

# 宁宗嘉泰二年壬戌（1202）
原：稼轩六十三岁。仍家居铅山。
原：二月，弛“伪学党禁”。
原：十二月，韩侂胄由太傅而进太师，封平原王。起用士大夫之好言恢复者，谋北伐。

# 嘉泰三年癸亥（1203）
原：稼轩六十四岁。
原：起知绍兴府兼浙东安抚使，六月到任，疏奏州县害农六事。创建“秋风亭”。
原：招刘过（改之）来会。与八十高龄老诗人陆游结识，引为忘年交。十二月，召赴行在。陆游有诗《送辛幼安殿撰造朝》赠行。

# 嘉泰四年甲子（1204）
原：稼轩六十五岁。
原：正月，宁宗召见。力主战，言金国必乱必亡。加宝谟阁待制，提举佑神观，奉朝请。
原：三月，差知镇江府。积极备战，遣谍侦察敌情，复拟招沿江士丁，建万人军旅。
原：五月，朝廷追封岳飞为鄂王。
原：是年，稼轩跋高宗《亲征草书》，抒高宗、孝宗二世不振之慨。

# 宁宗开禧元年（1205）
原：稼轩六十六岁，在镇江守任。
原：三月，以荐人不当，降两官使用。
原：六月，改知隆兴府。七月初，未至新任，臣僚劾其“好色贪财，淫刑聚敛”。遂罢职，与宫观。秋，返铅山家居。
原：七月，韩侂胄进平章军国事，立班丞相上。

# 开禧二年丙寅（1206）
原：稼轩六十七岁，家居铅山。
原：春，朝命差知绍兴府，兼两浙东路安抚使，辞免。
原：四月，追论秦桧主和误国罪，削爵改谥。
原：五月，韩侂胄请伐金诏下，然多败绩。
原：十二月，进稼轩龙图阁待制，知江陵府，并诏令赴京奏事。

# 开禧三年丁卯（1207）
原：稼轩六十八岁。
原：京师奏对，任命兵部侍郎，力请辞免，遂罢。
原：继之叙复朝请大夫、朝议大夫。
原：归居铅山，八月染疾。
原：九月，除枢密院都承旨，令速赴行在奏事。未受命，上奏乞致仕。九月十日卒，特赠四官，葬铅山县南十五里阳原山中。
原：十一月，史弥远杀韩侂胄，并于十二月知枢密院事。

# 宁宗嘉定元年戊辰（1208）
原：稼轩卒后一年。
原：三月，复秦桧王爵赐谥。给事中倪思劾稼轩迎合开边，请追削爵秩，夺从官卹典。
原：九月，宋金“开禧和议”成。

# 恭帝德祐元年乙亥（1275）
原：稼轩卒后六十八年。
原：史馆校勘谢枋得请于朝，追赠少师，谥忠敏。
