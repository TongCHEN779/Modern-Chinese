# 第十五章 人口和经济(续完)
原：马克思和恩格斯把社会生活的生产和再生产，分为物质资料的生产和人的生产两个基本方面，就已经包含了一个重要而合理的命题：两种生产的发展一定要相适应。从物质资料的生产决定人的生产的理论出发，我们可以引出两种生产必然要相适应的结论；从人的生产会对物质资料的生产发生反作用的理论出发，也必然地要引出两种生产应该相适应的结论。
原：但是，马克思主义在这里同样受到困扰。传统的资产阶级人口学搬出势力强大的“适度人口论”，把人的生产和物质资料的生产相适应，也表述为“适度人口”。一些马克思主义人口学家也在这个问题上走上了歧途，把马克思主义两种再生产理论，最后归结到“适度人口论”方面。

# 1.话说“适度人口”
原：资产阶级人口学家把“适度人口”的理论渊源，追溯到柏拉图和亚里士多德。柏拉图曾把他“理想国”里的“优秀公民”和居民的数目，规定在五千零四十人的范围内。为了把人数限制在这个数字以内，他规定男子结婚的年龄为二十五岁，女子为二十岁。他认为生育的最佳年龄，女子是二十岁到四十岁，男子是二十五岁到五十五岁。亚里士多德也认为国家有限定孩子数目的必要，超过国家给每个配偶规定的孩子数目以后，如再怀了孕，就应该在孩子出生前通过流产的方式把胎儿处理掉。
原：但是，资产阶级“适度人口论”的直接鼻祖还是马尔萨斯。自从马尔萨斯提出人口受生活资料的限制以后，资产阶级就把人口学和社会生产方式割裂开来，离开科学的政治经济学讲人口学，开创了人口学上伪科学的先例。同时，马尔萨斯提出人口要受土地生产力的限制的观点，就含有“适度人口论”的命题。二十世纪初，英国经济学家E·坎南在理论上把“适度人口”加以公式化，建立了静态“适度人口”模式，奠定了人口学中的“适度人口论”的理论基础。此后，各种“适度人口论”风靡于世。据一些人口学者所称，人口学的主要任务在于确定适度人口。
原：根据不同的研究对象和标准，资产阶级的“适度人口论”有主张针对国民总收入的，有主张针对人均国民收入的，还有主张针对国力、军力的。所以，关于“适度人口论”的定义，在资产阶级那里也就众说纷纭、各抒已见。试举几例：
原：—“适度人口”就是在一定科学技术水平下，按人口平均计算，能使每人得到最高收入的人口数量。
原：“适度人口”是能保证人种的最大幸福，使资源与人口之间有个最恰当的比例。
原：—“适度人口”也就是一个以最令人满意的方式达到某项特定目标的人口。
原：“适度人口”是能使平均产量达到最大值的人口。
原：目前，资产阶级的“适度人口论”已从静态发展到动态，但从其方法和本质来讲，并没有什么大的突破。这从资产阶级人口学中“适度人口论”的派别林立，相互攻许，就可以得到说明。

# 2.索维的“适度人口”
原：法国著名的人口学家索维建立的各种“适度人口”，是资产阶级“适度人口论”中有很大影响的一个派别。索维的“适度人口”有“经济适度人口”、“实力适度人口”等，其中“经济适变人口”是他的基础。
原：索维是赞成美国的社会学家和人口学家费尔柴耳德的下述意见的：“如果真有所谓人口过剩和人口不足的话，那么，介乎二者之间必定有一个数量恰如其分的人口。”索维画出一个人口生活水平随人口变化而变化的图形。图[6]的ON。是适度人口，达不到ON。为人口不足，超过ON。是人口过剩。钟形曲线S是居民生活水平随人口增长变化的结果。索维认为，只有在适度人口的情况下，居民的生活水平最高（M。N。），而人口不足或人口过剩都将使居民生活水平下降。索维认为，将居民人数ON。乘以平均产值M。N。，也就得下社会总产量。所以，这也是取得最高经济产量的适度人口。

# 3.“适度人口”批判
原：维克塞尔和坎南在上一世纪末和本世纪初就提出了“适度人口”的概念（维克塞尔在1910年就写过《适度人口》）。几十年以后，索维等人在四十年代末、五十年代初又提出了更多的“适度人口”模式，把“适度人口”提练得更为精致、圆滑了。也许就其研究的数学方法来说，其中有可取之处。但就其实质上来讲，“适度人口论”并没有把马尔萨斯的人口论向科学方面推进一步。
原：“适度人口论”同马尔萨斯的人口论一样，都是抛开一定的社会生产方式，离开一定的社会生产关系讨论人的发展的，他们以为仅仅依靠人口的增长或减少，就可以使国民收入得到提高。这本质上还是“人口决定论”。
原：“适度人口论”只是一般地满足于建立静态的、或者动态的人口的数学模式，并不涉及人口问题的社会本质。即使论讨人口的平均福利或社会总福利，也只是以人均国民收入和总的国民收入为限，而不是讨论社会生产的性质。我们知道，恰恰是社会生产的性质决定了国民收入的性质，决定了国民收入分配的性质和方法。分配是生产的结果。“适度人口论”者既不讨论原因，也不讨论结果，而只是抽象的用人口数目去除国民收入。这种讨论无论于生产，或者于分配，并无益处。相反，它还掩盖了资本主义制度下国民收入分配的实质，把资本主义社会的分配问题、劳动人民的贫困以及其它社会问题都归之于人口问题。仍然是玩弄马尔萨斯自然人口的鬼把戏。
原：另外，“适度人口论”在发达国家与发展中国家的交往关系中，还起着一种特殊的作用。帝国主义的殖民统治，以及发达国家对发展中国家经济上的剥削，是大部分发展中国家贫穷的重要原因。以发达国家的人口学家为首制造和宣传的“人口适度论”，既不涉及任何社会制度问题，更不涉及世界经济体系的结构问题，只是把发展中国家贫穷落后的根源统统推到“人口过剩”问题上。并且，从现象上看，凡经济落后的发展中国家，也几乎都是人口严重过剩的国家。这样，发达国家对发展中国家的剩削问题就被“理所当然”地避而不论了。
原：我们知道，决定生产的因素是很多的，一定社会的生产关系是一定社会生产的前提。经济结构稍加调整，生产的效果就大为不同。另外，科学技术的发展，对外贸易，生产领域的扩大等，都会给社会生产造成积极的后果，使某一时刻看来是“适度”，而真正达到这一目标时，经济发展和人口增长又都会超越了“适度”的范围。所以，连一些“适度人口论”的积极鼓吹者也不得不承认，确定适度人口，在实际上是不可能做到的。兰德里在1937年人口学会议的开幕式里就提出，确定人口“怎样才是适度”的问题，只能是主观的、武断的。经济学家蒙贝尔特也说：“适度人口是一种经济理想，这是关于平衡状态的抽象概念，要想确定它实际上是办不到的。”
原：抽象地谈“适度人口”，可以给人以盲目的自我安慰。但是，无论是看来多么“合理”的“适度人口”，只要一接触实际，都会土崩瓦解。比如，有一些人口学家把人均国民收入最高增长的人口，表述为“适度人口”。我们可以讨论一下这种“适度人口”会产生什么后果。
原：假如G为国民收入，P为原有人口，A为使人均国民收入达到最高水平的人口增长数，B为任意正整数。那么，（P+A）就是原意所指的“适度人口”，G/(P+A)就是按人均最高的国民收入值。
原：但是，由于决定生产的因素是极为复杂的，即令在生产的物质条件已经确定的情况下，经济结构、就业结构、管理体制、生产力布局、教育水平等任何一个因素的提高，都可以使国民总收入G有大幅度的增长。这样往往在G/(P+A+B)的情况下，也仍然感到人均国民收入有了很大幅度的增长。如果按照“适度人口”的定义，就很可能把（P+A+B）当作适度人口，而不是把(P+A)当作“适度人口”。
原：相反，在经济停滞、生产不景气的情况下，由于G值很小，要想得到较高的人均国民收入，只有当（P+A-B）的条件下才能成立。因为十分清楚，G/(P+A-B)>G/(P+A)。所以，“适度人口”也不是假定的（P+A），而是，（P+A-B）。
原：即使在一般正常的年份，按照最高人均国民收入的增长速度确定“适度人口”，也会引起荒谬的结论。显然，G/(P+A)<G/P<G/(P-B)是成立的。那么，为要达到最高人均国民收入，适度人口不仅不是(P+A)，也不是零度增长（P），而是负增长(P-B)。并且，好象负增长的幅度越大，人均国民收入才会越高。这样，当一个社会不再生孩子，或者死亡率有所提高的情况下，才能算作“适度人口”。

# 4.两种不同的含义
原：马克思和恩格斯提出物质资料的生产和人的生产相适应的理论，完全不同于资产阶级人口学的“人口适度论”。首先，马克思历来反对离开特定的生产方式抽象地谈人口问题。人口与经济在马克思那里就是指一定生产关系下的人口。马克思在《资本论》中说：“当经济学的智者们向工人说教，要工人使自己的人数去适应资本增殖的需要时，他们是多么愚蠢。资本主义生产和积累的机构在不断地使这个人数适应资本增殖的需要”。这就是说，在资本主义生产方式下，工人人口的增长是由资本决定的，由资本主义生产关系决定的。要说“适度人口”，那个严重“过剩”的人口，就是资本主义生产关系下的“适度人口”。
原：其次，马克思和恩格斯是把人口问题作为社会生活的一个基本方面，当作社会生产的一个基本方面来讨论的。所以，人的生产和物质资料的生产一样，是受生产方式制约的。当作社会生产的运动过程，人的生产过程主要还是劳动力的生产问题。所以，作为社会物质资料生产的一个方面，它同样要受生产规律的支配。这和那些抛开社会经济制度而搞抽象的“适度人口”，是极不相同的。
原：最后，马克思讲的是人口生产服从于物质资料的生产，人口发展与物质资料的生产相适应，是讲生产。而“适度人口论”不仅撇开了生产，而且撇开了具体的分配制度讲人口数量。一个是经济决定人口，一个人口决定经济，两者是截然不同的。不仅理论本身不同，引出的结论也是不同的。

# 5.截然不同的结论
原：马克思和恩格斯指出人的生产和再生产，要受物质资料的生产和再生产的制约，把人的生产和再生产过程纳入到生产方式的矛盾运动中，提出人的生产有其自身的规律性，是由生产方式决定的。这样，人口问题的出现，就不能从生产方式以外去寻找。如果仔细考察，任何人口问题的生产都有其生产方式方面的内在的原因。生产方式的矛盾性质不同，人口问题的性质也不同。同时，人口问题的解决办法也不能从生产方式以外去寻找，人口问题的出路存在于生产方式的矛盾运动之中。任何人口问题的解决，都伴同于当时其他社会问题的最终解决。
原：资本主义人口问题的出现是由资本主义的生产方式决定的，资本主义的人口变动要由资本的变动来决定。马克思说：“对资本主义生产来说，人口自然增长所提供的可供支配的劳动力数量是绝对不够的。为了能够自由地活动，它需要有一支不以这种自然限制为转移的产业后备军。”资本主义相对过剩人口的存在，正是资本主义生产方式的必然表现，它是合乎资本主义人口规律的要求的。如果资本主义竟然没有过剩人口，那才是不可思议的。所以，在资本主义制度下根本不存在人的“不适度”问题。大量的“人口过剩”，这就是资本主义的“人口适度”。这就是为什么在当前一些发达的资本主义国家，人口的增长已经出现负数，但仍存在失业人口的根本原因。如果有谁企图离开社会生产方式对人口的制约而建立什么“适度人口”，如果不是出自欺骗和辩护的目的，那么至少也证明他同空想社会主义者具有相同的思维方法。
原：资本主义相对过剩人口的解决不在于人口本身，而在于生产方式的革命。马克思说，如果把劳动普遍限制在合理的程度，并且，把工人阶级的各个阶层按年龄和性别进行适当安排，那样，要依照原来的生产规模继续进行国民生产，原来的工人人口也将是绝对不够的。原来的非生产工人的大部分都将转变为生产工人才行。消灭了资本主义生产方式，也就消灭了与资本主义制度相联系的相对过剩的人口。可见，如果真正要求解决资本主义人口问题，那就必需实行革命。
原：“适度人口论”连改良的气息都没有。这种理论企图向工人群众说明，整个居民的平均福利的提高，不在社会生产的制度方面，而在于人口的数量上，仅仅通过人口增长水平的调整，就可以使国民收入有大幅度的提高。它把具体的人口问题抽象化，抹煞人口问题的社会本质，转移人们的视线。很难设想，一些发展中国家仅仅通过降低人口数量，就可以使占人口绝大多数的劳动人民摆脱受贫困的处境。也很难设想，发达国家中工人阶级福利的提高不是工人阶级斗争的结果，而是工人降低出生率的结果。同样难以设想，资本主义社会中受奴役的无产阶级的解放，不是通过粉碎旧的社会制度，而是实现资产阶级学者们设计的适度人口模式。

# 6.列宁的实践
原：列宁从马克思的人口学说的原理出发，科学地分析了俄国的人口问题，引出了解决资本主义人口问题的根本出路就是社会主义革命的结论。以列宁为首的苏联共产党领导俄国的工农群众实行武装起义，粉碎资本主义生产方式，选择了社会主义道路，消灭了资本主义的人口问题。
原：十九世纪末二十世纪初，随着资本主义生产方式在俄国进一步的发展，资本主义的人口问题也愈来愈为明显。各种资产阶级和小资产阶级的人口思想在俄国的思想界广泛传播，严重影响着年轻的俄国工人运动。列宁坚持马克思主义的人口理论，同各种错误的人口思想展开了激烈的斗争，正确阐明了俄国人口问题的本质。
原：民粹主义者最先歪曲俄国资本主义人口问题的实质。民粹派无视俄国资本主义在农业方面的发展，否认资本主义生产方式造成了俄国农村贫穷人口的事实，而一味赞美富农经济。民粹派认为，在俄国农业方面存在的过剩人口，是由于农民生孩子多造成的。他们说：“在土地属于大小占有者的农业国家里，只要自愿节育的风气在人民习俗中还没有巩固，希望靠该一地域的产品过活的人手和消费者的经常过剩就是不可避免的。”民粹派反对马克思关于“每一种特殊的、历史的生产方式都有其特殊的历史地起作用的人口规律。抽象人口规律只存在于历史上还没有人干涉过的动植物界”的原理，说俄国的农业人口过剩“不是资本主义的，而是一种简单的、适合自然经济的”人口过剩。
原：列宁认为，绝不能离开一定的社会生产方式谈论人口问题。他站在马克思一边说：“马克思把人和动植物加以对比是根据前者生活在各种不同的、历史地更替的、由社会生产制度因而由分配制度决定的社会机体中。人类的增殖条件直接决定于各种不同的社会机体的结构，因此应当分别研究每个社会机体的人口规律，不应当不管历史上有各种不同的社会结构形式而去抽象地'研究人口规律。”列宁根据资本主义经济制度的特点，指出资本主义生产关系决定了资本主义的人口过剩，而与人民的习俗和节育无关。列宁说：在资本主义俄国，“无论自愿节育的风气在人民习俗中如何巩固，人口‘过剩’的形成总是不可避免的。”
