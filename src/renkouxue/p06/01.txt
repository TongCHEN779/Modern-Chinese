# 第四章 马尔萨斯主义的演变
原：人口学从十八世纪末小资产阶级社会主义发难，马尔萨斯神父抛出《人口论》与之抗衡以后，就开始作为一门单独的学科活跃在社会科学舞台上。由于人口学所涉及对象的广泛性和它代表党派利益的显明性，马尔萨斯的《人口论》把经济学家、社会学家、文学家、政治家以及从事自然科学研究的人们都动员出来参加了争论。论及事业的成就，马尔萨斯根本不可能名列史册。但可以说，历史上任何一个人都没有较马尔萨斯的名字更为人所知者。在马克思主义者看来，马尔萨斯只不过是一个声名狼籍的伪君子。但在对立的营垒中，他却俨然是一位鼎鼎有名的老前辈。将近二百年来，马尔萨斯代代相传，一直是人口学界首屈一指的劲旅。
原：从马尔萨斯时代起，人口学已经经过了五次较大的人口问题的争论。这五次争论，其导因和实质并不单纯是人口问题。马尔萨斯主义总是把粮食或其它资源的危机转嫁到人口方面来。随着争论的发展，马尔萨斯主义也经历了五个阶段。

# 1.马尔萨斯开创了先例
原：即使不从资本主义制度对人口问题的规定来说，马尔萨斯当时挑起人口问题的争论也是犯了极大的错误的。他没有具体分析当时英国粮食供应紧张的原因，而抽象地去谈人口受土地生产力的限制。
原：马尔萨斯在当时的英国，是没有任何道理谈论土地肥力递减规律的。资本主义在英国的工业部门发生之后不久，也开始影响到农业。特别是1688年革命以后，英国农业在作物种植和农具改革方面都取得了较大的进展。仅从1697一1765年半个世纪里粮食向外输出的增长情况，就可以说明当时农业发展的速度。
原：1697——1705年，输出1,160,000夸特
原：1706——1725年，输出5，480,000夸特
原：1726——1745年，输出7,080,000夸特
原：1746——1765年，输出9,515,000夸特
原：十八世纪六十年代粮食输出达到高峰的同时，也就基本上结束了英国向外输出粮食的历史。资本主义的英国在工业方面急需大量的黄金货币，所以，要不断向国际市场抛售工业产品。由于毛织品可以换取殖民地的大量黄金和白银，牧羊成为一本万利的生意。于是，羊在圈地运动中“吃”去了很多种植谷物的耕地。从1780年到1790年，英国每年谷物剩余已经很少。在其后的十年，谷物输出已经完全停止。英国由一个粮食输出国变成输入国。特别是在法国大革命和拿破仑战争中，先是法国革命时期向英国出口的粮食减少，后来拿破仑又下令禁运，切断了英国从波兰和法国等欧洲国家输入粮食的来源。因此，当马尔萨斯的《人口论》处于黄金时代而一版再版的时候，正是英国粮食奇缺和价格飞腾上涨的时候。1800一1813年，在英国国内市场上，小麦的市场价格突破了前后一百年平均价格的二倍半，达到每夸特一百先令以上。
原：793—1815年，当欧洲大陆降临战祸时，海峡另侧的英国在经济结构上却经历着重大变革。历史学家阿·莱·莫尔顿评论说：“英国加入这些战争（指1793—1815年欧洲反法联盟和拿破仑战争——引者）时是个农业国，而当这些战争结束时，它却以一个工业国出现……。”
原：英国由粮食出口国变为粮食进口国，是由于增加出口工业品以换取农产品，比其本国生产粮食对英国资本家更为有利。马尔萨斯看不出或者有意不触及这个根本原因，也不说欧洲战争给英国带来的暂时困难，仅以粮食供应上的表面现象，引出食物增长赶不上人口增长的结论，反对小资产阶级社会主义，开创了把经济和政治问题歪曲为人口问题的先例。

# 2.杰文斯借题发挥
原：第二次人口论争发生在十九世纪六十年代，由还未成名的曼彻斯特欧文学院的讲师W·S·杰文斯挑起。杰文斯用统计资料述说人口增长造成粮食短缺和物价飞涨。
原：实际上，英国十九世纪中期的粮食短缺，是因为美国南北战争影响了对英国的粮食供应。其次，取之于加利福尼亚和澳大利亚的黄金源源不断流入英国，也导致了物价飞涨和工人工资的下降。
原：杰文斯曾经引用被历史学家渲染了的“爱尔兰饥荒”，他认为这是粮食赶不上人口增长的最有力的证明。但是，仔细考察一下所谓“爱尔兰饥荒”，就会发现它同样帮不了杰文斯的忙。
原：爱尔兰从沦为英国殖民地开始，一直是英国的粮食的主要来源。拿破仑战争海上禁运，以及施行谷物法期间，爱尔兰的小麦一直在英国处于垄断地位。但爱尔兰的农民却从中没有得到任何好处。战争期间物价高涨，地租也惊人地飞涨。谷物法废除以后，爱尔兰的谷物受到欧洲和北美小麦的竞争。但地主并没有因谷物跌价遭到什么损失，只是要求农民以更多的小麦缴付地租。爱尔兰的农民一直在贫困中渡生。
原：1835年爱尔兰救贫委员会发表的报告，说明了爱尔兰农民的状况。报告说爱尔兰农产物总值为3,600万镑，其中1,000万镑成了地租。2,000万镑成了赋税、什一税以及经纪人和商人的利润，其余不到600万镑才属于农民。马铃薯在十九世纪初才传入爱尔兰。但十多年后它就成为农民的主食。素以产小麦著称于世的爱尔兰农民，把自己每年收获的全部谷物上缴地租，然后却靠食马铃薯为生。1845一1850年并没有发生大的饥荒，仅仅是爱尔兰的马铃薯发生枯萎病而影响了正常收获，其它谷物没有受到损失。1847年，当爱尔兰几十万人死于饥饿和伤寒病时，却有价值1,700万镑的粮食，由荷枪实弹的英国军队保护运出爱尔兰。正如有些历史学家指出：在这些年代里死亡的150万爱尔兰人，并非是由于饥荒，而是因地租和利润迫害而死。
原：杰文斯接过了马尔萨斯的银样蜡枪。他依据黄金纷扰下的市场情况和呈现在爱尔兰问题上的假象，推测人口的增长将造成消费率按3.5的速度增长，所以，人类的末日很快就要出现。其实，杰文斯的意图不必用许多笔墨去引证。他逝世后出版的《通货与财政之调查》中提供了极好的脚注。既然杰文斯把资本主义周期性的经济危机都用太阳的黑子活动加以解释，那么，人口增长怎么能不为社会丑恶承担责任？

# 3.凯恩斯领会了精神实质
原：十九世纪末到二十世纪初的半个世纪里，西方发达国家里人口出生率呈现的下降趋势曾使一些经济学家懵了头。马尔萨斯提出的人口按几何级数增长的规律不灵了。较多的经济学家机警地绕开了人口学这块阵地。严肃的经济学家最得手的办法，也是在人口问题上缄默不语。一时间，以马尔萨斯“开创”人口学为荣的英国人大都放弃了人口学。倒是美国的一些社会学家在自己的领域里开辟了阵地，开始从事于人口学的调查和研究。不过美国人很少涉及理论问题和令人敏感的政治问题，他们只是注重于人口学的方法和实地调查。
原：当然，也还有少数正统的马尔萨斯主义者在原版抄录马尔萨斯。第一次世界大战前后，书籍报刊经常套用的就是“世界面临着过多的人口”，“只有站脚的地方！”等等。1900一1925年举行过六次国际新马尔萨斯会议，其中五次在欧洲，一次在美国。各次会议的主题仍然是“人口过剩”如何造成国际关系的紧张局势。1919年国际马尔萨斯主义联盟还做出决议，要求国联开除和拒绝接收那些不承认节制生育的国家。
原：英国的凯恩斯是帝国主义时期颇负盛名的大经济学家。他对于马尔萨斯自始至终是推崇备至的。就在他成名以后还说：“如果十九世纪经济学的渊源不是李嘉图，而是马尔萨斯。那么今天的世界该是一个多么明朗和富裕的世界啊。”第一次世界大战前，凯恩斯认为自由贸易、资本积累和人口增加制约着经济的增长。他曾指出影响帝国经济的两个原因：“(1)人口可能增长太快，超过积累的增长；（2）战争可能消耗掉资本的储备。”他十分推崇马尔萨斯下面的这个结论：一定时期资本主义社会中的工资是不变的和有限的，过高的工资会影响较多的人就业。因此，他说，如果工人要求高工资，“马尔萨斯的可怕的恶魔或许是正确的。”
原：一味强调“人口过剩”和人口增加会影响经济发展，无论与现实，还是与理论都很不适宜。一方面，发达国家的人口尽管在增加，但帝国主义经济仍然有了极大的发展。另一方面，从十九世纪中期开始，欧洲发达国家的人口出生率已呈现了下降趋势(那时落后地区的人口迅速增长还没有出现)，而帝国主义的穷兵默武却急需扩大兵源。这时，再过份地提出人口增长造成社会问题，对一些西方国家来说显得不大协调了，所以“双亲的凄凉晚景”和“没有人口的英国”，现在又成为西方某些国家报刊上的通栏标题和畅销书籍了。加之，三十年代震撼整个资本主义世界的经济危机，促使发达国家的出生率进一步下降，更使马尔萨斯主义陷入了窘境。
原：还是凯恩斯首先从正统的马尔萨斯迷网里兜出来。他首先领会了马尔萨斯主义的实质不在于人口增长必然超过食物的增长，而在于人口状况决定社会经济、政治等一切状况。所以，他抛弃马尔萨斯陈旧的和不合时宜的教条，并给马尔萨斯主义披上了时髦的新装。在使凯恩斯名声大振的《就业、利息和货币通论》一书中，他不再说人口增长阻碍居民生活提高，却反过来开始指责人口出生率长期下降造成了帝国主义经济衰退。他鼓吹人口增长能刺激投资，增大有效需求，提高就业水平，给社会经济带来繁荣。和凯恩斯情投意合，并且与之齐名的美国经济学家阿尔文·汉森更明确地说：资本主义能否发生经济危机就在于：“1．新领土和新资源的发现及发展。2.人口的增长。3.各种创造发明。”汉森认为社会总资本中有将近六分之一来自于人口的增长。他们论证说，如果工资和利润率没有下降趋势，人口增长率的下降就会由于新的投资不足而导致经济长期萧条，不充分就业的现象就会长期存在。这种观点从形式上看同马尔萨斯主张相反，但其实质正是马尔萨斯的人口决定论。所不同的只是，过去马尔萨斯把资本主义制度下工人的贫困和失业归之于工人阶级的出生率太高。现在，他们又把资本主义经济危机和萧条归之于工人阶级出生率下降。1937年2月，凯恩斯在英国优生学会的报告中曾向人们解释说，他的观点不仅没有与马尔萨斯的理论相对立，而且没有脱离马尔萨斯的结论。从此，凯恩斯的人口增长可以给资本主义经济带来繁荣的理论，统治了帝国主义经济学界几乎整整一个时代。

# 4.美国人接过了旗帜
原：第二次世界大战以后，一系列殖民地国家相继独立。落后国家民族主权的回归割断了发达国家经济资源的供应，使世界经济结构也发生了变化。国际市场上原料和粮食价格相继提高。更令人不安的是发展中国家的人口开始迅速增长。发达国家认为，发展中国家的人口增长是对自己的一种威胁。所以，主要针对发展中国家的人口增长，马尔萨斯主义又被说成一种颇合时令的理论。
原：早在二十世纪初期，英国人耻于马尔萨斯的信条，连人口学都不屑于一提时，美国人就开始培植人口学并使之成为社会学中的一大热门。当英国的凯恩斯转过弯来以新的面貌维护马尔萨斯时，美国的经济大师汉森也表示不甘落后。战后，发展中国家的人口增长刚露势头，其他发达国家从战争的硝烟中还没有来得及喘息的时候，美国人立即用迅速的行动表明了自己思想的敏捷性。
原：第二次世界大战几乎耗竭了所有国家的物力和人力。特别是被战火燃烧过国土的那些国家，更是精疲力尽了。战争刚一结束，世界经济立即陷入混乱之中。第一，发达国家在大战中建立了以军火等战时需要的经济结构，战争停止后，军火订购立即停止，原来为战争服务的军火工业萧条了，国民经济一下子就瘫痪了；第二，许多发展中国家相继独立，廉价资源的供应被截断了；第三，旧的世界经济关系已被战争粉碎，而新的经济关系由于政治关系的变动还没有建立起来；第四，战争期间劳动力被赶上前线，现在都复员回家，要求工作，要求就业，恰巧为军火服务的国民经济却陷于瘫痪，根本吸收不了那么多的劳动者；第五，战争期间人们背乡离井，投亲靠友，寻找比较落后的地区躲避灾难，战争结束后又都返回家园，流向曾经是经济繁荣的地方，好象一下子从什么地方被呼唤出许多人来；第六，战争中人们为了赢得战争，忍受痛苦，现在则要求生活，要消费；最后，加上发展中国家也要在经济上翻身，要设备、要技术、要资金、要资源。这都显得资源、资金、生活资料不足了。
原：但是，美国的学者把这些情况说成是人口的增长造成的。好象世界大战不是残杀了亿万人的生命，而是又制造出了数十亿的多余的人。一时间，“世界饥饿”、“人类的繁殖是现代的窘境”、“世界人口的危机”、“人们！生存的威胁”……，各种题目的专著相继在美国问世。这些出自于学者手笔，以科学的面目出现的专著立即被翻译成各种文字，畅销世界各大陆。从四十年代末开始，嚷嚷吵吵，一直闹到了六十年代初期。这些学者同新独立的国家争论说，是人口增长酿成了战争，引起了革命，制造了发展中国家的贫穷。
原：在这第四次人口争论中，马尔萨斯主义不是象凯恩斯所说的那样，人口萎缩造成了经济停滞，而是又以新的面目出现，回到了原来的命题：人口增长造成了灾难。这次马尔萨斯主义又前进了一大步，把人口问题的重心转向了发展中国家和地区。并且，事实显示了，美国人不仅在学术上比其他国家的学者略高一筹，而且有能力把越来越多的国家的政府首脑们也卷进人口学争论之中。
原：自从美国人接过了马尔萨斯的旗帜，统治了世界人口学的阵地以后，一次又一次的关于人口问题的强大攻势，如同狂风巨浪一般，越过太平洋和大西洋，几乎把所有的人都卷入到人口论争之中。到了七十年代以后，美国的科学家梅多斯又发表了《增长的极限》，挑起了人口学上第五次大争论。因为《增长的极限》是以现代科学的形式出现，内容几乎涉及一切，所以，这次人口争论又在更为广阔的领域里进行。
原：为了在下面分章评介由梅多斯挑起的第五次人口论争，我们把战后人口学所引起的误会，马尔萨斯主义采取的新形式，先在这里作一介绍。

# 5.历史的误会
原：在整个人口问题的争论中，马尔萨斯主义能够获得“新生”，就在于它能够不断抛弃旧的教条，取得新的形式。在本世纪以前，正统的马尔萨斯主义仅仅说，人口的增长会引起贫困和失业。从凯恩斯以后，马尔萨斯主义把注意力放到了人口增长对于经济发展的决定意义方面。马尔萨斯主义者十分灵活地运用了马尔萨斯的本质思想，把社会问题归结为自然问题。有些人往往以为马尔萨斯就是反对人、反对人口增长，把马尔萨斯主义等同于节制生育。甚至还有人把晚婚、晚育，以及避孕和人工流产等科学技术手段都称之为马尔萨斯主义，这实在是历史的误会。比如刘天予先生说：新马尔萨斯主义“主张生育节制，一方面可以减少人口，一方面又可以满足人类性要求，防止食物压迫。提高生活程度，增加人民幸福……。”其实，主张节制生育和主张人口增殖的观点，自古皆有，而马尔萨斯主义却是近代的产物。倘若仅以主张增殖或节育来划分，马尔萨斯也不成为马尔萨斯主义者了。
原：看来，需要澄清这场误会。晚婚、晚育和科学避孕技术，都是社会进步和科学技术发展的结果，与马尔萨斯并无缘份。工业化要求较为熟练的专业化的劳动力，它把劳动力的再生产周期从过去农业社会的十年左右，提高到平均二十年左右。同时，妇女参加社会化的生产，这都自然地提高和推迟了男女的结婚年龄。其次，如果没有现代化工业和科学技术，当然也不会有避孕方面的现代化学药物及用具。列宁就说过：“……我们拥护传播有关避孕方法的医学著作等等。”但是，“医学宣传的自由和保护男女公民的起码民主权利是一回事。新马尔萨斯主义的社会学说是另一回事。”为了不引起混乱，还是应当在马尔萨斯神父本意上使用马尔萨斯主义，亦即把人口过程纯粹看作自然过程，把人口过程当作社会发展的决定力量的观点，才谓之为马尔萨斯主义。

# 6.马尔萨斯主义在当代
原：如果说，在当今世界上没有什么问题不和人口问题发生联系的话，那末，在当今世界上也没有什么人口问题不存在马尔萨斯的幽灵。
原：在马尔萨斯所处的时代里，人类还没有完全送走中世纪的生活方式。人们的生活资料主要还是粮食和土地生产的其他农产品。这种生活资料的结构决定了马尔萨斯的“人口增长要受土地生产力限制”的理论。但是，工业社会的步伐粉碎了马尔萨斯那个时代的生活方式。马尔萨斯以后的人类生活不仅总的说比过去要好，而且在现代化社会里，工人家庭也把小汽车、电视机、电冰箱等等马尔萨斯根本不曾梦想到的商品，当作必需品配置起来。尽管个别马尔萨斯主义者仍然认为马尔萨斯无隙可击，但是，大多数马尔萨斯主义者总是感到历史在刮马尔萨斯的脸皮。那些不墨守成规的马尔萨斯主义者，把马尔萨斯狭窄的阵地开辟得更为宽阔了一些，以便把马尔萨斯俗气的信条修饰得赋有一点现代化的外貌和形式。老马尔萨斯十分贫乏地复诵人口增长将走向崩溃，新马尔萨斯则提出人口要受自然资源的限制。新马尔萨斯主义只不过是在新的形式下把自已打扮得更乖巧、更圆滑一些罢了。
原：在众多的马尔萨斯主义者中间，值得一提的是美国学者福格特。据说，他发明了一项掌握人类命运的方程式：
原：C = B/E
原：其中：C是土地的“支持能力”，B是土地能提供的衣、食、住等“生物潜能”，E是环境对土地生产能力给予的限制。这个公式实质上是在说，土地提供给人的生活资料要受到环境的限制。人类的食物是有限的，因此，人类不能过多的生殖。
原：还有一位奥斯本先生，比福格特先生的公式更广阔些。被称之为“永恒方程式”：
原：生活水平 = 地球资源/人口数量
原：据说F·奥斯本的方程比马尔萨斯的概念更为完备些，因为这个方程式提出了人口和资源、人口和环境的概念。并且，一些人认为，这个奥斯本提出的方程式是适合于任何地区和任何社会的。但是，正是因为它适合于任何地区和任何社会，所以，它对于任何地区和任何社会都不适合。这些方程式并没有把各个社会的阶级关系、生产关系表现出来。所以它并没有突破马尔萨斯的规定。一位评论家深切要害地指出了这类方程式的弱点是：“过份简单化了人对于环境的作用，低估了人在发展中和利用其环境的资源的智能。”
原：马尔萨斯最初讲的人口问题主要针对发达国家，认为这些地方的肥沃耕地已经垦殖殆尽，收益递减律发生作用，所以有了人满之患。李嘉图也同意收益递减律，但他认为在落后国家里，如果人口太多，那么，可以加快垦荒耕种，使人口问题得到解决。现在则不然，人口问题的主要注意力已转移到落后地区，把马尔萨斯的理论由发达国家挪用到发展中国家。当代颇负盛名的美国经济学家P·萨缪尔森指出：“对于世界不发达地区，由于马尔萨斯所说的收益递减的古老灾祸，限制人口增长是非常重要的。”
原：至于解决人口问题的办法，还有照搬马尔萨斯的。比如郝继隆先生认为，因为地球上土地有限，人口继续增长就可能出现只有站脚之处。他说：“但我们相信，不会有此一日，因为在此之前，战争已将人口调节于适当’程度。”较多的人提出：“减少人口是解决食物问题的最有效的办法。”因为，在马尔萨斯主义者看来，世界上所有的罪恶和过失都应归结于人口问题：
原：——饥饿是储存不足的结果；而储存不足通常是世界上人口过多，生育率太大的结果。
原：——人口过度增殖而产生出一切祸害：失业、饥饿、贫困、住宿恐慌、物价飞涨、官僚主义、革命……。
原：——发展中国家的资源给高速度增长的人吃用光了。——工业国家的人口增长是文化生存的最严重的威胁。——环境污染是人口和生产的增长带来的。
原：——和数量有限的资源比较起来，世界的人口确实是太多了。生活水平根本无法提高。
原：——我们正在大量消耗我们的资源。世界大部分鱼场被过度网捕；当然可以提高农业生产力，但我们无法摆脱马尔萨斯的理论所说，人口增加快过粮食增加的恐慌。
原：——原子弹的发明使解决国际冲突的传统方式——战争成为过去。但人口迅速增长使提高生活水平的努力有全功尽弃的危险。这类谈论，我们可以列举很多，这说明在西方世界里马尔萨斯的幽灵至今不散。
