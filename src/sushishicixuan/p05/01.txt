# 冬至日独游吉祥寺
题解：吉祥寺即后来的广福寺，寺中牡丹最盛，在宋时，是一个名刹。此诗亦熙宁五年作。
诗：井底微阳回未回，/萧萧寒雨湿枯荄。/何人更似苏夫子：/不是花时肯独来？
注原：井底微阳回未回：《月令》：“冬至水泉动”，是说从冬至日起逐渐转暖。《逸周书》：“十有一月，微阳动。”阳，指暖气。
注：荄（gāi该）：草根。

# 将之湖州戏赠莘老
题解：熙宁五年冬，作者将出差到湖州，预先写这诗赠吴兴太守孙觉。
诗：杭自是山水窟，/仄闻吴兴更清绝。/湖中橘林新著霜，/溪上苕花正浮雪。
注：山水窟：谓奇山秀水聚集之处。
注：仄闻：一作侧闻，旁闻、听说的意思。
注：苕（tiáo条）：芦苇。浮雪：言芦花白。
诗：顾渚茶芽白于齿，/梅溪木瓜红胜颊。/吴儿脍缕薄欲飞，/未去先说馋涎垂。
注：顾渚茶芽白于齿：湖州顾渚山产紫笱茶有名。
注：梅溪：即梅溪山，一名东海堰，那儿产木瓜也是有名的。
注：脍：一本作。脍缕，细切成丝，这里指吴人治肴之精，脍制得又细又薄。
诗：亦知谢公到郡久，/应怪杜牧寻春迟。/鬓丝只可对禅榻，/湖亭不用张水嬉。
注：亦知谢公到郡久：晋谢安曾任吴兴太守，这里以“谢公”称孙觉。
注：应怪杜牧寻春迟：唐杜牧初游湖州，刺史崔元亮令举行水戏招待他参观。杜牧看上了一个年轻的女孩子，想娶她，和她相约十年之期。十四年后，杜牧做了湖州刺史，但重来时这女孩子嫁人已三年了。杜牧的《怅诗》就是为此而作的，首二句云：“自是寻春去较迟，不须惆怅怨芳时。”这里作者戏用其意，并戏以杜牧自谓。
注：鬓丝：指年长。禅榻：谓学佛。这里亦借用杜牧“今日鬓丝禅榻畔”诗意。
注：湖亭不用张水嬉：意谓此行虽因公查勘吴兴水利，实私愿想看吴兴山水，用不着像崔元亮那样张水嬉招待杜牧。作者于第九句诗中将孙觉比作谢公，是极有分寸的。

# 赠孙莘老（选三首）
题解：熙宁五年十二月作者奉命出差到湖州测度堤堰时作。但作者对于这一修建是持反对态度的。原七首，选第一、二五共三首。
诗：嗟予与子久离群，/耳冷心灰百不闻。/若对青山谈世事，/当须举白便浮君。
注：举白：犹如今天说干一大杯。浮：罚酒。上二句说对青山不应谈世事，违者罚一大杯。作者反对新法，湖州筑堤事亦其中之一，所以说这样的话。下首“作堤捍水非吾事”，意更鲜明。
诗：天目山前绿浸裾，/碧澜堂上看衔舻。/作堤捍水非吾事，/闲送苕溪入太湖。
注：天目山：在湖州。
注原：碧澜堂：在湖州府治的霅溪馆，唐时所建，是诗人杜牧的旧游处。衔舻：船连着船，极言舟楫之盛。晋郭璞《江赋》：“舳舻相属，万里连樯。”
诗：三年京国厌藜蒿，/长羡淮鱼压楚糟。/今日骆驼桥下泊，/恣看修网出银刀。
注：藜：胭脂菜。蒿：青蒿。厌藜蒿，是说吃野菜吃烦了，言其生活清苦。
注：糟：淹渍的食品；楚糟指江南的腌渍品；当时当地最有名的是糟淮白鱼，连仁宗皇后都最喜欢吃它。
注原：恣：任性、随意。银刀：鱼的一种，颜色形状俱肖银色的刀。杜甫诗：“出网银刀乱。”

# 秀州报本禅院乡僧文长老方丈
题解：熙宁五年年末作。秀州，今浙江嘉兴。报本禅院，唐时所建，宋时改为本觉寺。寺僧文长老方丈是作者的同乡，故称“乡僧”；诗中第三句的“蜀叟”，也指这位方丈。
诗：万里家山一梦中，/吴音渐已变儿童。/每逢蜀叟谈终日，/便觉峨眉翠扫空。
诗：师已忘言真有道，/我除搜句百无功。/明年采药天台去，/更欲题诗满浙东。
注：师：这里是作为对僧人的尊称。忘言真有道：陶渊明《饮酒》诗：“此中有真意，欲辨已忘言。”有道，一本作得道。此句赞师。
注：搜句：指写诗。这句是说我除了写诗以外，什么事都不成。
注原：天台山：浙东的名胜。采药：意为求道，这句应“忘言”说。
注：更欲题诗满浙东：这句应“搜句”意。

# 听贤师琴
题解：熙宁五年年末作。作者诗话云：“昵昵儿女语，恩怨相尔汝；划然变轩昂，勇士赴敌场。此退之（韩愈）听颍师琴诗也。欧阳公（修）尝问仆：琴诗何者最佳？’余以此答之。公曰：此诗固奇丽，然自是听琵琶诗，非琴诗。'余退而作......诗成欲寄公，而公薨。至今以为恨。”
诗：大弦春温和且平，/小弦廉折亮以清。/平生未识宫与角，/但闻牛鸣盎中雉登木。
注：廉折：是商弦，逼仄之音，形容小弦音清而细。与上句大弦对照。
注：宫、角：是五音中的两个调子，略等于今天的C调、E调。
注：闻牛鸣盎中雉登木：《管子·地员》：“凡听宫，如牛鸣窌中”，又“凡听角，如雉登木以鸣，音疾以清”。
诗：门前剥啄谁叩门？/山僧未闲君勿嗔。/归家且觅千斛水，/净洗从前筝笛耳。
注：剥啄：叩门声。
注：归家且觅千斛水：古代以十斗为一斛（hú胡） 。千斛水，言水之多。
注：净洗从前筝笛耳：这句是说从前所听过的筝笛之类的演奏，都不是好音乐，不堪留耳。这里极力形容贤师弹奏技巧之高，琴声之美。

# 法惠寺横翠阁
题解：熙宁六年（1073）正月作。法惠寺在西湖。
诗：朝见吴山横，/暮见吴山纵。/吴山故多态，/转折为君容。
注：朝见吴山横：据《咸淳临安志》：“吴山在城中，吴人祠子胥山上，因名曰胥山。”
注：暮见吴山纵：吴山朝横暮纵，是说它一日之间，你这时看它是这样，另一个时候瞧它又是另一个样子。
注：吴山故多态：朝暮山形有变，故云“多态”。
注：转折：即上面说的纵横多态。容：装饰、打扮。《诗经·卫风·伯兮》：“自伯之东，首如飞蓬；岂无膏沐，谁适为容？”这里“为君容”，是反用其意。
诗：幽人起朱阁，/空洞更无物。/惟有千步冈，/东西作帘额。
诗：春来故国归无期，/人言秋悲春更悲。/已泛平湖思濯锦，/更看横翠忆峨眉。
注：春来故国归无期：这里故国犹如说故乡、老家。
注：濯锦：即锦水，一名岷江。这句说泛西湖想念故乡的水。
注：峨眉：即峨眉山。这句说见吴山更怀念故乡的山。
诗：雕栏能得几时好，/不独凭栏人易老。/百年兴废更堪哀，/悬知草莽化池台。/游人寻我旧游处，/但觅吴山横处来。
注：雕栏：有彩饰的栏杆。
注：不独凭栏人易老：这两句是用南唐李煜《虞美人》“雕栏玉砌应犹在，只是朱颜改”和《浪淘沙》“独自莫凭栏，无限江山”词意。
注：悬知：预想到。
注：但觅吴山横处来：这两句亦设想未来情事。

# 正月二十一日病后，述古邀往城外寻春
题解：熙宁六年作。陈述古，名襄，福建闽侯人，曾官御史，时被徙杭州。
诗：屋上山禽苦唤人，/槛前冰沼忽生鳞。/老来厌伴红裙醉，/病起空惊白发新。
注：生鳞：言水起波纹。
注：红裙：指女性。
诗：卧听使君鸣鼓角，/试呼稚子整冠巾。/曲栏幽榭终寒窘，/一看郊原浩荡春。
注：试呼稚子整冠巾：上句说述古来邀；下句写准备出游。

# 饮湖上初晴后雨（选一首）
题解：熙宁六年正二月间所作。这诗人人传诵，尤其是后二句，一直到现在，还被认为在所有咏西湖的诗中，是给西湖最恰当的评语。原二首，选第二首。
诗：水光潋滟晴方好，/山色空蒙雨亦奇。/欲把西湖比西子，/淡妆浓抹总相宜。
注：潋滟（liàn yàn炼艳）：水满貌。
注：空蒙：形容雨中山色。
注：西子：谓西施，春秋时代越国的美人。

# 往富阳、新城，李节推先行三日，留风水洞见待
题解：熙宁六年作者奉命出巡浙西属县作。李节推名泌，一作佖；“节推”是节度推官的简称。
诗：春山磔磔鸣春禽，/此间不可无我吟。/路长漫漫傍江浦，/此间不可无君语。
注：磔（zhé哲）磔：鸟声。
诗：金鲫池边不见君，/追君直过定山村。/路人皆言君未远：/“骑马少年清且婉。”
注：骑马少年清且婉：《诗经·郑风·野有蔓草》：“有美一人，清扬婉兮。”清婉是形容容貌清秀美好。
诗：风岩水穴旧闻名，/只隔山溪夜不行。/溪桥晓溜浮梅萼，/知君系马岩花落。
诗：出城三日尚逶迤，/妻孥怪骂归何时。/世上小儿夸疾走，/如君相待今安有！
注：出城三日：这两句描写前面说的那“骑马少年”去未远。
注：逶迤（wēi yí威移）：长而曲，指路途。

# 自普照游二庵
题解：熙宁六年正二月间作者巡富阳时作。普照，寺名，建于唐代，五代石晋天福年间重修。作者另有《独游富阳普照寺》诗，未选。二庵，是离普照寺不远的延寿院东庵和西庵。
诗：长松吟风晚雨细，/东庵半掩西庵闭。/山行尽日不逢人，/裛裛野梅香入袂。
注：裛（yì邑）裛：形容香气袭衣。
诗：居僧笑我恋清景：/“自厌山深出无计。”/我虽爱山亦自笑，/幽独神伤后难继。
注：自厌山深出无计：这句是居僧的话。
注：幽独神伤后难继：这两句是说虽然爱山，但要是长处山中，自觉幽独神伤，恐怕难以继续下去的。杜甫《法镜寺》诗“神伤山行深”，这里隐括其意。
诗：不如西湖饮美酒，/红杏碧桃香覆髻。/作诗寄谢采薇翁，/本不避人那避世！
注：作诗寄谢采薇翁：殷周之际，伯夷、叔齐隐于首阳山，采薇而食。这里采薇人指隐士、避世者。谢，辞谢不去。
注：本不避人那避世：孔子说：“贤者辟世，其次辟地，其次辟色，其次辟人。”（见《论语·宪问》）辟，今作避。作者说自己做不到，原也不打算这样做。

# 新城道中二首
题解：唐宋时所置的新城在杭州之西南，是杭的属县。作者熙宁六年春出巡自富阳过此时作。方回《瀛奎律髓》以为第二首系晁端友和作，然苏集诸本均列有，故依苏集选入。
诗：东风知我欲山行，/吹断檐间积雨声。/岭上晴云披絮帽，/树头初日挂铜钲。
注：钲（zhēng征）：古乐器，铃、铎之属。这里铜钲借喻日如圆铃。
诗：野桃含笑竹篱短，/溪柳自摇沙水清。/西崦人家应最乐：/煮芹烧笋饷春耕。
注：西崦（yān淹）：犹如说西山。
诗：身世悠悠我此行，/溪边委辔听溪声。/散材畏见搜林斧，/疲马思闻卷旆钲。
注：委辔：放松马的缰索。
注：卷旆：犹如说收旗，意谓休息。
诗：细雨足时茶户喜，/乱山深处长官清。/人间岐路知多少？/试向桑田问耦耕。
注：乱山深处长官清：长官并非指上级，据冯注：“宋时长官为呼县令之通称。”这句是赞美晁端友的廉洁。晁是新城县令。
注：试向桑田问耦耕：《论语·微子》：“长沮桀溺，耦而耕。”长沮桀溺是孔子所遇见的隐士。这里以耦耕指长沮、桀溺一类的人。

# 山村五绝（选三首）
题解：熙宁六年春作。此诗讥刺新法，语多显露。后来曾受到御史们的纠弹，作者曾因此而被捕入狱。事见后《十二月二十八日，蒙恩责授检校水部员外郎黄州团练副使，复用前韵二首》注。原诗五首，选第二、三、四首。
诗：烟雨蒙蒙鸡犬声，/有生何处不安生！/但令黄犊无人佩，/布谷何劳也劝耕？
注：但令黄犊无人佩：汉龚遂为渤海太守，那里的人民好带剑，龚遂劝他们卖剑买牛，说：“何为带牛佩犊？”
注原：布谷何劳也劝耕：布谷是催耕鸟，这里借以刺官吏。两句大意是：人民有牛，自会耕种，何劳官吏劝农！
诗：老翁七十自腰镰，/惭愧春山笋蕨甜。/岂是闻韶解忘味？/迩来三月食无盐。
注：迩来三月食无盐：《论语·述而》记孔子“在齐闻韶，三月不知肉味”，这里借刺朝廷的盐法太峻，老百姓三月食不到盐，却并不是他们听到了韶乐，三月不知“盐”味。
诗：杖藜裹饭去匆匆，/过眼青钱转手空。/赢得儿童语音好，/一年强半在城中。
注：青钱：当时行青苗法，放“助役钱”、“预买钱”之类。
注：一年强半在城中：两句说农民经常在城市，有误生产。强（qiǎng抢）半，大半。

# 同曾元恕游龙山，吕穆仲不至
题解：熙宁六年在杭州时作。龙山是杭州的名胜。曾元恕，作者的朋友；吕穆仲，作者的同僚，时任杭州观察防御团练推官。
诗：青春不觉老朱颜，/强半销磨簿领间。/愁客倦吟花似酒，/佳人休唱日衔山。
注：簿领：公文。
注：愁客倦吟花似酒：杜甫诗：“花光浓似酒。”此用其意。
注：佳人休唱日衔山：李白《乌栖曲》：“吴歌楚舞歌未毕，青山欲衔半边日。”
诗：共知寒食明朝过，/且赴僧窗半日闲。/命驾吕安邀不至，/浴沂曾点暮方还。
注：命驾：叫人预备车马，意即出行。吕安：晋时人，与嵇康友善，他很佩服嵇康；每一相思，哪怕千里，也要去看嵇康。这里吕安实指吕穆仲。
注原：浴沂曾点暮方还：沂水在山东。曾点：孔子弟子。《论语·先进》上有这样一段记载：某次，孔子向几个弟子问他们的志愿，有的答治国，有的谈足民，有的说想办好国交，意思是一样的。曾点却委宛表示希望“暮春者，春服既成，冠者五六人，童子六七人，浴乎沂，风乎舞雩，咏而归”。孔子独取曾点。这里借曾点指曾元恕。

# 赠别
题解：熙宁六年作。
诗：青鸟衔巾久欲飞，/黄莺别主更悲啼。/殷勤莫忘分携处：/湖水东边凤岭西。
注：青鸟：在我国神话中，是西王母的使者。衔：同含。这句意思是说她有情含巾，无法留住。
注：黄莺别主更悲啼：唐代戎昱有歌妓甚美，被他的上司韩滉要去，昱写了一首诗送她：“好去春风湖上亭，柳条藤蔓系离情。黄莺久住浑相识，欲别频啼四五声。”此用其意。

# 次韵代留别
题解：熙宁六年作。这是前首诗的和韵——答词，代作那将离去的女子留别男子的话。
诗：绛蜡烧残玉斝飞，/离歌唱彻万行啼。/他年一舸鸱夷去，/应记侬家旧住西。
注：绛蜡：即红烛。斝（jiǎ假）：古代饮器，用以盛酒的，后来叫杯子。
注原：舸（gě葛）：船。春秋时代，越国的谋臣范蠡帮助越王勾践灭吴兴越，事前他们曾把越国的美人西施——那住在若耶溪西边姓施的浣纱女—献给吴王；灭吴后范蠡认定越王勾践将会杀戮功臣，他隐去，化名“鸱夷子皮”，泛舟游五湖，传说还带着取回了的西施。这两句诗意是说你若化名远去，别忘记来取我。按：越灭吴，西施死。唐杜牧偶有“西子下姑苏，一舸逐鸱夷”（《杜秋娘诗》）诗句，后世遂以讹传讹。苏轼这样说亦“姑妄言之”耳。

# 于潜令刁同年野翁亭
题解：熙宁六年作。於潜县令刁铸，建野翁亭，作者为他写这首诗，说他有好的政绩。于潜县，今浙江临安县。同年，是同一科考试取录者的称呼。
诗：山翁不出山，/溪翁长在溪。/前二令作二翁亭。/不如野翁来往溪山间，/上友麋鹿下凫鹥。
注：二翁亭：山翁亭、溪翁亭。
注：凫鹥（fú yī符医）：野鸭之类的水鸟。
诗：问翁何所乐？/三年不去烦推挤。/翁言此间亦有乐，/非丝非竹非蛾眉。
诗：山人醉后铁冠落，/溪女笑时银栉低。/我来观政问风谣，/皆云吠犬足生牦。
注：山人：道士之称。
注：栉：古代叫梳子、栊子做栉，今日本犹如此称。
注：皆云吠犬足生牦：《后汉书》记载魏郡人民歌颂太守岑熙的功德：“我有枳棘，岑君伐之；我有蟊贼，岑君遏之；吠犬不惊，足下生牦。含哺鼓腹，焉知凶灾。”牦（lí离），兽的箭毛，长而硬。吠犬足生牦，是说连看家的狗都没有什么事干，终日休息，所以足部长起了牦毛。极言其政事无为而治，使人民得到了休养生息。
诗：但恐此翁一旦舍此去，/长使山人索寞溪女啼！/天目山唐道士常冠铁冠。/于潜妇女皆插大银栉，/长尺许，/谓之蓬沓。

# 于潜女
题解：熙宁六年作。
诗：青裙缟袂于潜女，/两足如霜不穿屦。/赌沙鬓发丝穿杼，/蓬沓障前走风雨。
注：缟：白色织品。袂：袖子，这里指衣。
注原：赌（zhā扎）沙（读suō梭）：两角翘张的样子。韩愈《月蚀》诗：“赤鸟司南方，尾秃翅鳍沙。”这里用来形容于潜女子的鬓。丝穿杼：是指她头上横插着一尺长的大银栉—蓬沓，仿佛是黑丝在织机上一样。
诗：老濞宫妆传父祖，/至今遗民悲故主。/苕溪杨柳初飞絮，/照溪画眉渡谿去。/逢郎樵归相媚妩，/不信姬姜有齐鲁。
注：老濞（bì毕）：汉初的吴王刘濞，这里借指五代的吴越王。这句是说于潜女子这种头部装饰，还是吴越王时代的宫妆，从她的祖代、母代传下来，到今还未改变。
注：故主：指吴越王。
注：不信姬姜有齐鲁：周初，太公姜尚封于齐；周公姬旦的儿子伯禽封于鲁；姜氏、姬氏是齐、鲁的贵族。前二句极言于潜女之美，夫妇间相爱，和从事劳动——渔樵之乐。这一句是设说在这种人物和这样生活里，不省人间还有什么姬姜美女、要什么齐鲁封疆！

# 自昌化双溪馆下步寻溪源，至治平寺二首
题解：二首均熙宁六年游昌化时作者怀乡思归之作。昌化，今浙江临安县。
诗：乱山滴翠衣裘重，/双涧响空窗户摇。/饱食不嫌溪笋瘦，/穿林闲觅野芎苗。
注：双涧：昌化县的溪，南北分流。
诗：却愁县令知游寺，/尚喜渔人争渡桥。/正似醴泉山下路，/桑枝刺眼麦齐腰。
注：醴泉山：在眉州作者的故乡。
诗：每见田园辄自招，/倦飞不拟控扶摇。/共疑杨恽非锄豆，/谁信刘章解立苗。
注：招：谓招隐。
注：倦飞不拟控扶摇：陶渊明《归去来兮辞》：“鸟倦飞而知还。”《庄子·逍遥游》说鹏飞“抟扶摇而上者九万里”。这句诗意说有前者的归志，无后者的雄图。
注原：共疑杨恽非锄豆：汉时杨恽字子幼，华阴人，他是杨敞的孙子，司马迁的外孙；宣帝时，封平通侯。他常爱揭发别人阴秘，和讥弹当代君臣，后获罪被废为庶人，他率妻子从事耕种，作歌：“田彼南山，芜秽不治，种一顷豆，落而为萁。人生行乐耳，须富贵何时！”语含怨刺，被腰斩。（事见《汉书·杨敞传》）据张晏注这首歌说：“山高而在阳，人君之象也；芜秽不治，言朝廷之荒乱也；一顷，百亩，喻百官也；言豆者贞实之物，当在困仓；零落在野，喻已见放弃也；萁，曲而不直，言朝臣皆谄谀也。”苏轼用这个典故，意谓杨恽锄豆，还遭受到人家的猜疑。曲折地慨说自己的处境。
注原：谁信刘章解立苗：汉贵族刘章，封朱虚侯，时吕后执政，吕家的人很得势，有三个封王；刘家的人很失势，许多王被废。刘章有一次为吕后行酒，他要求用军法，吕后许可了他，他在席前歌舞，歌的是：“深耕概种，立苗欲疏；非其种者，锄而去之。”这歌意前两句指刘氏，后两句指诸吕，所以当时吕后听了“默然”。接着他借口以军法治逃酒者杀了一个姓吕的。以后诸吕怕他，刘氏子弟依赖他（事见《史记·齐悼惠王世家》）。作者在这句诗中，意指自己有刘章之心，而未获见信。
诗：老去尚贪彭泽米，/梦归时到锦江桥。/宦游莫作无家客，/举族长悬似细腰。
注原：老去：犹如说老大、有年纪了。陶渊明做彭泽县令，以公田五十亩种粳稻，做粮食；以一百五十亩种秫（糯米），好酿酒。后来辞职归隐，说是不愿见上司派来的督邮（视察地方的小官）：“不能为五斗米折腰见乡里小儿。”这里作者自慨复自嘲做官不过是为了一点点薪俸。
注：锦江桥：在成都。
注：举族长悬似细腰：此用韩愈《孟东野夫子》“细腰不自乳，举族长孤悬”诗意，说谋生无术，全家挨饿。

# 立秋日祷雨，宿灵隐寺，同周徐二令
题解：熙宁六年作。是年秋旱，作者祈雨而未见雨，故末句有茫然之感。
诗：百重堆案掣身闲，/一叶秋声对榻眠。/床下雪霜侵户月，/枕中琴筑落阶泉。
注：百重堆案：极言文牍之多，形容公事之繁。
注：床下雪霜：描写久看月光；枕中琴筑：形容卧听泉声。两句暗示不眠。
诗：崎岖世味尝应遍，/寂寞山栖老更便。/惟有悯农心尚在，/起占云汉更茫然。
注：云汉：天河。占云汉，视天河的情形，卜明日的晴雨，所以说“占”；一本作“瞻”，意同。《诗经·大雅·云汉》一篇，据小序说是歌颂周宣王的，首章“倬彼云汉，昭回于天”，写宣王仰望天河，深惧旱灾；以后各章均以“旱既太甚”起句，写宣王忧心国事。作者意或本此。

# 佛日山荣长老方丈五绝（选三首）
题解：佛日山在杭州东北，五代吴越王建佛日院于此，宋祥符年间改称净慧禅院。据查注引《咸淳临安志》：作者于熙宁六年七月五日来游，留赠长老荣公诗五首。兹选第二四五首。
诗：千株玉槊搀云立，/一穗珠旒落镜寒。/何处霜眉碧眼客，/结为三友冷相看。
注：槊：长矛。搀：刺。此句写竹。
注：珠旒：珠的垂串。镜：形容池水平净。此句写泉。
注：何处霜眉碧眼客：此句写荣长老。
诗：食罢茶瓯未要深，/清风一榻抵千金。/腹摇鼻息庭花落，/还尽平生未足心。
注：还尽平生未足心：言平生未睡足，这一觉补还。
诗：日射回廊午枕明，/水沉销尽碧烟横。/山人睡觉无人见，/只有飞蚊绕鬓鸣。
注：水沉：即沉香，是用一种薰香科植物做成的香。它与佛教有密切的关系，其制造与使用，是由印度传入中国的。

# 有美堂暴雨
题解：有美堂是嘉祐二年（1057）杭州太守梅挚所建，在吴山上；堂名“有美”，是因宋仁宗赐梅挚诗“地有吴山美，东南第一州”而取的。在当时，欧阳修曾为之作记，有许多人作诗、文题咏它。作者也曾屡到，这一次是在熙宁六年的初秋。这诗写暴雨，是苏轼诗中的名篇之一。
诗：游人脚底一声雷，/满座顽云拨不开。/天外黑风吹海立，/浙东飞雨过江来。
诗：十分潋滟金樽凸，/千杖敲铿羯鼓催。/唤起谪仙泉洒面，/倒倾鲛室泻琼瑰。
注：十分潋滟金樽凸：写水势—如同十分满的酒凸过了杯面。
注：千杖敲铿羯鼓催：写雨声像是千锤急下敲响着皮鼓。
注：谪仙：天上谪贬下凡来的仙人，指李白(这称呼是由贺知章说李白是“天上谪仙人”而来）。唐玄宗召李白赋诗，时李白已醉，玄宗以清水洒其面，使他醒来。这句意谓天帝要唤起谪仙李白。
注：倒倾鲛室泻琼瑰：《述异记》说南海之中有鲛人室。鲛室，犹如说龙宫。琼、瑰（这里读huái槐），美玉、美石，这里指好文好诗。

# 八月十五日看潮五绝
题解：熙宁六年中秋节看钱塘江潮之作。
诗：定知玉兔十分圆，/已作霜风九月寒。/寄语重门休上钥，/夜潮留向月中看。
注：定知玉兔十分圆：我国神话：月宫里有白兔（玉兔）捣药，故以玉兔作月的代称。
注：重门：九重天门。钥：锁。
诗：万人鼓噪慑吴侬，/犹是浮江老阿童。/欲识潮头高几许：/越山浑在浪花中。
注原：万人鼓嗓：形容潮势涛声，如同万人鼓噪进军。慑（shè设）：吓唬。吴语称我为“侬”，一般以“吴侬”指吴人。这句是指晋时王濬平吴事。参看下注。
注：犹是浮江老阿童：晋王濬小名阿童，平蜀以后，他就积极造战船练水军，后来顺流东下，消灭了吴国。这句是说像是王濬的军队浮江而至。是，一本作似。
诗：江边身世两悠悠，/久与沧波共白头。/造物亦知人易老，/故教江水向西流。
注：故教江水向西流：钱塘江水因被海潮涌阻而逆流，故云。
诗：吴儿生长狎涛渊，/冒利轻生不自怜。/东海若知明主意，/应教斥卤变桑田。/是时新有旨禁弄潮。
注：狎：亲昵、玩弄。
注：应教斥卤变桑田：这首刺朝廷，前二句言“弄潮之人，贪官中利物，致其间有溺死者”（据《乌台诗案》）。后二句说朝廷好兴水利，可惜海水无知。斥卤，产盐之地，指海。
诗：江神河伯两醯鸡，/海若东来气吐霓。/安得夫差水犀手：/三千强弩射潮低！
注：醯（xī稀）鸡：传说是酒上面的一种小虫，它能使酒发酵。这里把江神、河伯比作水上的醯鸡，他们使江海生潮。
注原：夫差：人名，春秋时代的吴王，这里借指五代时的吴越王。《国语》：“夫差衣水犀之甲者三千。”
诗：吴越王尝以弓弩射潮头，/与海神战，/自尔水不近城。
注：自尔：从此。

# 陌上花三首并引
题解：这是作者据当时民歌加工，颇为后世所传诵的作品。约作于熙宁六年。
原：游九仙山，闻里中儿歌《陌上花》，父老云：吴越王妃每岁春必归临安，王以书遗妃，曰：“陌上花开，可缓缓归矣。”吴人用其语为歌，含思宛转，听之凄然。而其词鄙野，为易之云。
注：妃每岁春必归临安：五代时钱镠据浙，称吴越王，建都临安（杭州）。到了他的孙子钱俶，降宋，国除，移家汴京（开封）。这里吴越王妃是指俶的妻子。
诗：陌上花开蝴蝶飞，/江山犹是昔人非。/遗民几度垂垂老，/游女还歌缓缓归。
注：游女还歌缓缓归：各本作“长歌”。翁方纲手批本云：“长，一作还。还字胜。”
诗：陌上山花无数开，/路人争看翠骈来。/若为留得堂堂去，/且更从教缓缓回。
注：路人争看翠骈来：姘（píng平）：有帏幔的车子，古代贵族妇女所乘。
诗：生前富贵草头露，/身后风流陌上花。/已作迟迟君去鲁，/犹歌缓缓妾还家。
注：已作迟迟君去鲁：《孟子·尽心下》：“孔子之去鲁，曰：迟迟吾行也，去父母国之道也。”这里借喻钱俶离别了他的故国降宋，到宋京汴京去。
注：犹歌缓缓妾还家：各本作“犹教”。此作犹歌，亦据翁校。

# 宿海会寺
题解：海会寺即竹林寺，是杭州的大刹，梁时始建，吴越王时扩大，宋真宗朝重修。据查注引蔡襄《碑记》：“是时吴中浮屠居虽千百数，无是伦者。”熙宁六年秋，作者曾在这里住宿，作此诗。
诗：篮舆三日山中行，/山中信美少旷平。/下投黄泉上青冥，/线路每与猿狖争。
注：篮舆：竹轿。
注：青冥：青天。
注：线路每与猿狖争：言仅此一线之径，形容路极窄，未免与猿狖争道。狖（yòu佑），亦猴类。
诗：重楼束缚遭涧坑，/两股酸哀饥肠鸣。/北渡飞桥踏彭铿，/缭垣百步如古城。
注：彭铿：象声字，脚踏着飞桥发出的音响。
注：缭垣：即绕墙。
诗：大钟横撞千指迎，/高堂延客夜不扃。/杉槽漆斛江河倾，/本来无垢洗更轻。
注：千指：即百人，形容人多。
注：扃：关门。
注：槽：浴池。斛：盛水冲洗之具。江河倾：形容浴室水多。
诗：倒床鼻息四邻惊，/统如五鼓天未明。/木鱼呼粥亮且清，/不闻人声闻履声。
注：统（dǎn胆）：打鼓声。

# 初自径山归，述古召饮介亭，以病先起
题解：熙宁六年作。介亭在杭州凤凰山。
诗：西风初作十分凉，/喜见新橙透甲香。/迟暮赏心惊节物，/登临病眼怯秋光。
注：甲：指果实的皮。
诗：惯眠处士云庵里，/倦醉佳人锦瑟旁。/犹有梦回清兴在，/卧闻归路乐声长。
注：惯眠处士云庵里：唐末，处士方干居云庵。
注：倦醉佳人锦瑟旁：用杜甫《曲江对雨》诗：“暂醉佳人锦瑟旁。”

# 书双竹湛师房（选一首）
题解：熙宁六年作。双竹寺在杭州，湛师是寺的住持。原二首，选第二首。
诗：暮鼓朝钟自击撞，/闭门孤枕对残缸。/白灰旋拨通红火，/卧听萧萧雨打窗。
注：缸：一作缸，灯盏。

# 宝山新开径
题解：熙宁六年作。
诗：藤梢橘刺元无路，/竹杖棕鞋不用扶。/风自远来闻笑语，/水分流处见江湖。
注原：元：通原。此句师杜甫《将赴成都草堂有作》诗：“橘刺藤梢咫尺迷。”
诗：回观佛国青螺髻，/踏遍仙人碧玉壶。/野客归时山月上，/棠梨叶战暝禽呼。
注：回观佛国青螺髻：作者自宝山下来，返顾山上。据《咸淳临安志》，宝山上有广严寺，故借指宝山为佛国。青螺髻，形容山色苍翠，盘耸如髻。
注：踏遍仙人碧玉壶：《神仙传》说费长房曾进入卖药仙人的药壶里去，那壶中别有天地。这里以碧玉壶形容宝山一路，有如仙境。
注原：战：颤。瞑禽：宿鸟。

# 夜至永乐文长老院，文时卧病退院
题解：熙宁六年冬作。永乐乡在秀水县，文长老已见前《秀州报本禅院乡僧文长老方丈》。院即报本禅院。
诗：夜闻巴叟卧荒村，/来打三更月下门。/往事过年如昨日，/此身未死得重论。
注：巴叟：指文长老。前诗亦称“蜀叟”。
注：来打三更月下门：应题“夜至”。借用贾岛《题李凝幽居》“鸟宿池边树，僧敲月下门”诗意。
诗：老非怀土情相得，/病不开堂道益尊。/惟有孤栖旧时鹤，/举头见客似长言。
注：《传灯录》：“长老未开堂，不答话。”前诗说“师已忘言真有道”，现在长老已病，未开堂，不答话，所以说“道益尊”。
