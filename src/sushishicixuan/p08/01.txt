# 泗州僧伽塔
题解：元丰二年春，作者奉调，移知湖州，再过泗州时作。
诗：我昔南行舟系汴，/逆风三日沙吹面。/舟人共劝祷灵塔，/香火未收旗脚转。
诗：回头顷刻失长桥，/却到龟山未朝饭。/至人无心何厚薄，/我自怀私欣所便。
注：却到龟山未朝饭：以上回忆熙宁四年自京赴杭初过此地的情景。
注原：至人：完人，指道德修养达到最高境界的人。此指僧伽。《庄子·逍遥游》：“至人无己，神人无功，圣人无名。”又：“不失其真，谓之至人。”
诗：耕田欲雨刈欲晴，/去得顺风来者怨。/若使人人祷辄遂，/造物应须日千变。
诗：今我身世两悠悠，/去无所逐来无恋。/得行固愿留不恶，/每到有求神亦倦。
诗：退之旧云三百尺，/澄观所营今已换。/不嫌俗士污丹梯，/一看云山绕淮甸。
注：澄观所营今已换：僧伽塔是澄观所建，韩愈《送澄观》诗说：“僧伽后出淮泗上，....突兀便高三百尺。借问经营本何人？道人澄观名籍籍。”今已换：谓不复是唐的模样。
注：甸：田地，疆土。淮甸，指淮河区域。

# 龟山
题解：元丰二年作。龟山在盱眙县北，作者熙宁四年曾过此，故第二句有“再过龟山岁五周”语。
诗：我生飘荡去何求，/再过龟山岁五周。/身行万里半天下，/僧卧一庵初白头。
诗：地隔中原劳北望，/潮连沧海欲东游。/元嘉旧事无人记，/故垒摧颓今在不？
注：元嘉：南北朝时宋文帝年号。旧事：见诗末作者自注。
注：摧颓：破坏、残败、倒塌。
原：宋文帝遣将拒魏太武，筑城此山。

# 舟中夜起
题解：元丰二年途中作。
诗：微风萧萧吹菰蒲，/开门看雨月满湖。/舟人水鸟两同梦，/大鱼惊窜如奔狐。
注：菰：茭白；蒲：水杨：都是水草。
注：开门看雨月满湖：因风吹菰蒲，误以为是雨声。开门一看，原来没有雨，只见满湖的月色。
诗：夜深人物不相管，/我独形影相嬉娱。/暗潮生渚吊寒蚓，/落月挂柳看悬蛛。
注：人物：是说人和物。
注：落月挂柳看悬蛛：上句说水声幽咽如虫鸣。下句说柳条如蛛丝，月亮如悬在丝端的蜘蛛—写月将落时的景象。以上均写有月无雨。
诗：此生忽忽忧患里，/清境过眼能须臾！/鸡鸣钟动百鸟散，/船头击鼓还相呼。
注：能：这里作这么解。能须臾，这么短的时间！

# 大风留金山两日
题解：元丰二年，由徐州赴湖州道中过金山作。
诗：塔上一铃独自语：/“明日颠风当断渡。”/朝来白浪打苍崖，/倒射轩窗作飞雨。
注：杜甫《偪侧行赠毕曜》诗：“晓来急雨春风颠。”颠风，犹言狂风。“颠”、“当”、“断”、“渡”，连用这几个字音来象声“铃语”。
诗：龙骧万斛不敢过，/渔舟一叶从掀舞。/细思城市有底忙，/却笑蛟龙为谁怒？
注：龙骧：大船。万斛：形容船容量之大。
注：有底：有啥有什么。
诗：无事久留童仆怪，/此风聊得妻孥许。/灊山道人独何事，/夜半不眠听粥鼓。
注：灊（qián钱）：同潜。灊山道人即僧人参寥。
注：粥鼓：木鱼声。

# 赠惠山僧惠表
题解：惠山是无锡的名胜，惠表是惠山的住僧。作者曾说：“余昔为钱塘倅，往来无锡，未尝不至惠山。”这诗是元丰二年赴湖州过此重游、赠旧之作。
诗：行遍天涯意未阑，/将心到处遣人安。/山中老宿依然在，/案上《楞严》已不看。
注：将：携带。遣：使得。这句是说惠表所到，必说佛法。
注：老宿：老前辈，这里指惠表及其他老和尚。
注：楞严：即《楞严经》，佛家的经典。
诗：欹枕落花几片，/闭门新竹自千竿。/客来茶室空无有，/卢橘杨梅尚带酸。
注：卢橘：即枇杷。

# 与秦太虚、参寥会于松江，而关彦长、徐安中适至。分韵得“风”字
题解：元丰二年作。秦太虚名观，字少游，宋代著名词人，亦能诗，在宋诗中他也占一席地位。他与张耒（文潜）黄庭坚（鲁直）晁补之（无咎）共称“苏门四学士”，加上李荐（方叔）、陈师道（后山）共称“苏门六君子”。
诗：吴越溪山兴未穷，/又扶衰病过垂虹。/浮天自古东南水，/送客今朝西北风。
注：又扶衰病过垂虹：垂虹桥：在吴江东门外。唐时所建。
注：浮天：形容水多。
诗：绝境自忘千里远，/胜游难复五人同。/舟师不会留连意，/拟看斜阳万顷红。
注：难复：难再有。五人：作者与秦等四人。

# 端午遍游诸寺，得“禅”字
题解：元丰二年三月，作者移知湖州，此诗作于五月，是初到未久时。
诗：肩舆任所适，/遇胜辄流连。/焚香引幽步，/酌茗开净筵。
诗：微雨止还作，/小窗幽更妍。/盆山不见日，/草木自苍然。
注：草木自苍然：这四句作者自谓“非至吴越，不见此景”。
诗：忽登最高塔，/眼界穷大千。/卞峰照城郭，/震泽浮云天。
注：大千：即“大千世界”，佛家语。
注：卞峰：即卞山。
注：震泽：即太湖。
诗：深沉既可喜，/旷荡亦所便。/幽寻未云毕，/墟落生晚烟。
诗：归来记所历，/耿耿清不眠。/道人亦未寝，/孤灯同夜禅。

# 与王郎昆仲及儿子迈，绕城观荷花，登岘山亭，晚入飞英寺。分韵得“月”、“明”、“星”、“稀”四首
题解：元丰二年，在湖州作。王郎昆仲：王适王遹。迈，苏轼的长子。
诗：昨夜雨鸣渠，/晓来风袭月。/萧然欲秋意，/溪水清可啜。
诗：环城三十里，/处处皆佳绝。/蒲莲浩如海，/时见舟一叶。
诗：此间真避世，/青蒻低白发。/相逢欲相问，/已逐惊鸥没。
注：青蒻低白发：是说这里看到一位避世的渔人：青蒻笠帽覆着白发。蒻(ruò弱），蒲草。这里隐用张志和《渔父》“青蒻笠，绿蓑衣，斜风细雨不须归”词意。
注：已逐惊鸥没：逐......没：随着......不见。
诗：清风定何物，/可爱不可名。/所至如君子，/草木有嘉声。
注：不可名：难于称说。
注：所至如君子：孔子曾经说：“君子之德风。”（见《论语·颜渊》）
诗：我行本无事，/孤舟任斜横。/中流自偃仰，/适与风相迎。
诗：举杯属浩渺，/乐此两无情。/归来两溪间，/云水夜自明。
诗：苕水如溪水，/鳞鳞鸭头青。/吴兴胜襄阳，/万瓦浮青冥。
注：鳞鳞：形容水的波纹细皱；鸭头，形容水的颜色青绿。
注：万瓦浮青冥：像是人家都浮在水上。此句极写水乡吴兴之所以胜襄阳。
诗：我非羊叔子，/愧此岘山亭。/悲伤意则同，/岁月如流星。
注：愧此岘山亭：羊叔子，名祜，晋时人，他守襄阳时喜登岘山，死后襄阳百姓就在岘山立庙、竖碑纪念他。恰巧吴兴这儿也有一个岘山，是原名显山改的，晋吴兴太守殷康筑亭于此，叫显亭——后改称岘山亭，凡在这儿做官有德政的，人们也都为他立碑于亭，略如襄阳岘山故事。作者现在这里做官，登临之际，追怀古人，自觉愧对。
注：悲伤意则同：《晋书·羊祜传》：“祜乐山水，每风景佳，必造岘山。尝慨然叹息，顾谓从事中郎邹湛等曰：自有宇宙，便有此山。由来贤达胜士登此远望，如我与卿者多矣，皆湮灭无闻，使人悲伤！，.....”作者同样有这悲伤。
诗：从我两王子，/高鸿插修翎。/湛辈何足道，/当以德自铭。
注：当以德自铭：《晋书·羊祜传》：“湛曰：公德冠四海，道嗣前哲，令闻令望，必与此山俱传。至若湛辈，乃当如公言耳。'......”作者意轻邹湛而立志学习羊祜，不过在后一句里没有明白地说出。
诗：吏民怜我懒，/斗讼日已稀。/能为无事饮，/可作不夜归。
诗：复寻飞英游，/尽此一寸晖。/撞钟履声集，/颠倒云山衣。
诗：我来无时节，/杖屦自推扉。/莫作使君看，/外似中已非。
注：莫作使君看：意谓不要把我当官看待。

# 十二月二十八日，蒙恩责授检校水部员外郎黄州团练副使二首
题解：元丰二年三月，权监察御史里行何正臣，弹劾作者“愚弄朝廷，妄自尊大。又一有水旱之灾盗贼之变，轼必倡言归咎新法，喜动颜色”。到了七月，权监察御史里行舒亶、国子博士李宜之、权御史中丞李定连上弹章纠劾。于是作者被捕到京，八月入御史台狱，至十二月释放，贬黄州。这两首诗是作者出狱后所作。
诗：百日归期恰及春，/年乐事最关身。/出门便旋风吹面，/走马联翩鹊卓人。
注：百日归期恰及春：作者八月十八日入狱，距作此诗时计一百三十日，这里说百日是举其成数。
注：便旋：犹如说徘徊。又意同轻捷。
注：卓（zhuó啄）：这里作众口杂鸣解。卓人，朝着人叫。
诗：却对酒杯浑是梦，/偶拈诗笔已如神。/此灾何必深追咎，/窃禄从来岂有因。
注：窃禄：犹如说尸位素餐。
诗：平生文字为吾累，/此去声名不厌低。/塞上纵归他日马，/城东不斗少年鸡。
注原：平生文字为吾累：这一次被捕入狱，主要是文字之累，尤其是诗闯了祸。舒亶就是这样摘句构成他的罪状的：“陛下发钱以本业贫民，则曰‘赢得儿童语音好，一年强半在城中，；陛下明法以课试群吏，则曰‘读书万卷不读律，致君尧舜知无术’；陛下兴水利，则曰‘东海若知明主意，应教斥卤变桑田，；陛下议盐禁，则曰岂是闻韶解忘味，尔来三月食无盐，。其他触物及事，应口所言，无一不以讥谤为主，小则镂板，大则刻石。…..”
注：此去声名不厌低：作者声名，在当时已很高，即使纠弹他的人也承认，但也借此攻击。何正臣说他“轼所为文字，传于人者甚众”；舒亶说他“传播中外，自以为能”；李定说他“滥得时名”。故作者要“此去声名不厌低”。
注：塞上纵归他日马：用《淮南子》塞翁失马的寓言故事。以“归马”喻出狱。塞翁的失马引了另一匹好马归来，致使他的儿子因骑马而跌伤；作者隐言出狱是福，焉知不另有后祸？
注原：城东不斗少年鸡：用唐人陈鸿小说《东城父老传》：玄宗好斗鸡，长安城中的斗鸡少年贾昌，最得宠荣，封他为“五百小儿长”，天下称为“神鸡童”，当时流传着这样的话：“生儿不用识文字，斗鸡走马胜读书。”斗鸡之徒是皇帝的弄臣，士大夫以文字歌功阿世就如同斗鸡小儿以斗鸡取媚邀宠，作者表示所不愿为。此句须与上句连读：“纵归马，不斗鸡”是本旨；却故意引人看作是“纵他日，不少年”的说法。
诗：休官彭泽贫无酒，/隐几维摩病有妻。/堪笑睢阳老从事：/为予投檄到江西。
注：休官彭泽贫无酒：陶渊明辞去了彭泽令，家贫无酒。这句的意思是：为了家贫，不敢休官。
注：隐几维摩病有妻：佛经：维摩以法喜（见法生喜）为妻。这句意谓将与佛法终老。
注：堪笑睢阳老从事：苏辙时任著作郎，签书应天府（今河南商丘）判官，应天府在唐时为睢阳，故称他“睢阳老从事”。
诗：子由闻予下狱，/乞以官爵赎予罪。/贬筠州监酒。
注：筠州：今江西高安。

# 初到黄州
题解：作者出狱后，被谪为黄州团练副使，元丰三年（1080）二月到职，诗作于此时。
诗：自笑平生为口忙，/老来事业转荒唐。/长江绕郭知鱼美，/好竹连山觉笋香。
注：“口忙”语意双关：指因言事得罪被谪。兼指下文“鱼美”、“笋香”的享受。
注：长江绕郭知鱼美：黄州在长江北岸，三面环水。
注：好竹连山觉笋香：黄州多竹。
诗：逐客不妨员外置，/诗人例作水曹郎。/只惭无补丝毫事，/尚费官家压酒囊。
注：逐客：这里作逐臣解。员外：定额以外的官员，非本制，像作者这时所任就是。自唐以来，历代都有。置：安插。
注：水曹郎：隶属于水部的郎官。梁时何逊、唐时张籍、宋时孟宾于都做过水部郎，他们都是诗人。
原：检校官例折支，多得退酒袋。

# 陈季常所蓄《朱陈村嫁娶图》二首
题解：元丰三年在黄州作。陈季常，名慥，号方山子，蜀眉州人。季常的父亲公弼知凤翔时，作者也在那儿作签书判官，遂与季常相识。后陈氏移家洛阳，作者至黄州后，季常数从之游。蓄，收藏。这是作者为季常题其所藏画的诗。朱陈村仅朱陈二姓，世为婚姻，唐白居易曾有诗咏其事。
诗：何年顾陆丹青手，/画作《朱陈嫁娶图》。/闻道一村惟两姓，/不将门户买崔卢。
注：何年顾陆丹青手：顾恺之陆探微，均晋代有名的画家，二人都善绘人物。
注：不将门户买崔卢：崔姓、卢姓，都是北朝—魏、北周——的豪族。南北朝时，最重门第；一直沿到唐代，仍以崔、卢诸姓为重。和这些门第的人结亲，得花钱，当时叫做“卖婚”。
诗：我是朱陈旧使君，/朱陈村在徐州萧县。/劝农曾入杏花村。/而今风物那堪画：/县吏催钱夜打门。
注：使君：唐宋时对太守的别称。作者曾为官徐州，所以自说是那儿的“旧使君”。
注：劝农曾入杏花村：查注引《名胜志》：“朱陈村距萧县东南百里，杏花村与朱陈村相连。”

# 安国寺寻春
题解：元丰三年作。作者有《黄州安国寺记》云：“城南精舍曰安国寺，有茂林修竹，陂池亭榭。寺僧曰继莲。寺立于伪唐保大二年，始名护国。嘉祐八年，赐今名。堂宇斋阁，莲皆新易之，严丽深稳，悦可人意，至者忘归。”
诗：卧闻百舌呼春风，/起寻花柳村村同。/城南古寺修竹合，/小房曲槛欹深红。
注：百舌：鸟名。这种鸟善于模拟各种鸟的歌唱。
诗：看花叹老忆年少，/对酒思家愁老翁。/病眼不羞云母乱，/鬓丝强理茶烟中。
注：病眼不羞云母乱：唐、宋时尚以云母片饰屏、装窗，云母反光，老人看着眼花。
诗：遥知二月王城外，/玉仙洪福花如海。/薄罗匀雾盖新妆，/快马争风鸣杂珮。
注：王城：指当时的首都汴京即今开封。
注：玉仙洪福花如海：玉仙观、洪福寺，是当时汴京的名刹。
诗：玉川先生真可怜，/一生耽酒终无钱。/病过春风九十日，/独抱添丁看花发。
注：一生耽酒终无钱：唐卢仝《叹昨日三首》之二：“天下薄夫苦耽酒，玉川先生也耽酒；薄夫耽酒有钱恣长乐，先生无钱养淡泊；有钱无钱俱可怜，百年骤过如流川。平生心事消散尽，天上白日悠悠悬。”这里作者以玉川先生自况。
注：独抱添丁看花发：此用卢仝《添丁》诗：“春风苦不仁，呼逐马蹄行人家。惭愧瘴气却怜我，人我憔悴骨中为生涯。数日不食强之行，何忍索我抱看满树花。....”

# 寓居定惠院之东，杂花满山，有海棠一株，土人不知贵也
题解：作者《志林》曾经记有：“黄州定惠院东小山上有海棠一株，特繁茂，每岁开时，必为置酒。”这诗是元丰三年，到黄州不久时初访海棠之作。
诗：江城地瘴蕃草木，/只有名花苦幽独。/嫣然一笑竹篱间，/桃李漫山总粗俗。
诗：也知造物有深意，/故遣佳人在空谷。/自然富贵出天姿，/不待金盘荐华屋。
注：故遣佳人在空谷：杜甫《佳人》：“绝代有佳人，幽居在空谷。”这里作者以花拟人。
诗：朱唇得酒晕生脸，/翠袖卷纱红映肉。/林深雾暗晓光迟，/日暖风轻春睡足。
注：日暖风轻春睡足：唐玄宗见杨贵妃早酒未醒，应召扶来的醉态，说是“海棠睡未足”。这里反用其意。
诗：雨中有泪亦凄怆，/月下无人更清淑。/先生食饱无一事，/散步逍遥自扪腹，/不问人家与僧舍，/拄杖敲门看修竹。
注：先生：作者自称。
诗：忽逢绝艳照衰朽，/叹息无言揩病目。/陋邦何处得此花，/无乃好事移西蜀？
注原：无乃好事移西蜀：这句意思是：莫非是好事之徒把它从西蜀移来？按：西蜀海棠最盛，蜀产香海棠也最名贵，作者的家乡，有“香海棠国”之称。
诗：寸根千里不易致，/衔子飞来定鸿鹄。/天涯流落俱可念，/为饮一樽歌此曲。/明朝酒醒还独来，/雪落纷纷那忍触！
注：俱：指上文“绝艳”与“衰朽”，亦即海棠和作者自己—都是天涯流落。

# 雨晴后，步至四望亭下鱼池上，遂自干明寺前东冈上归二首
题解：元丰三年作。四望亭在黄州。
诗：雨过浮萍合，/蛙声满四邻。/海棠真一梦，/梅子欲尝新。
注：海棠真一梦：言海棠已谢。
诗：拄杖闲挑菜，/秋千不见人。/殷勤木芍药，/独自殿春。
注：木芍药：牡丹的别名。
注：殿：结尾收场。殿春，作春色的殿军。
诗：高亭废已久，/下有种鱼塘。/暮色千山入，/春风百草香。
注：种鱼：即养鱼。
诗：市桥人寂寂，/古寺竹苍苍。/鹳鹤来何处？/号鸣满夕阳！

# 武昌铜剑歌并序
题解：元丰三年，作者获得了一柄古铜剑，作此诗。
原：供奉官郑文，尝官于武昌。江岸裂，出古铜剑，文得之，以遗余。冶铸精巧，非锻炼所成者。
诗：雨江清风卷沙，/雷公蹑云捕黄蛇；/蛇行空中如枉矢，/电光煜煜烧蛇尾；/或投以块铿有声，/雷飞上天蛇入水。
注：雷公蹑云捕黄蛇：《广异记》：唐开元末年，太原人武胜之在广西做官，曾见桂林漓江滩上有雷神驾着云追逐一条小黄蛇，渔民以石投蛇，蛇化为一柄铜剑。
注：枉矢：星名，这星座像一条曲箭。
注：煜煜：火光照耀状。
诗：水上青山如削铁，/神物欲出山自裂；/细看两胁生碧花，/犹是西江老蛟血。
注：神物：指古铜剑。
注：碧花：指古剑上的铜绿——古器物学上所重视的“锈片”。
注：西江：指漓江。武胜之在桂林所获得的剑，上有铭文云：“许旌阳斩蛟第三剑”。
诗：苏子得之何所为：/蒯缑弹铗咏新诗。/君不见：/凌烟功臣长九尺，/腰间玉具高挂颐。
注原：蒯（kuǎi块上声）：草绳。缑（hóu侯）：剑把上的缠物。言以草绳缠于剑把，没有什么金装玉饰。《史记·孟尝君列传》中冯谖的剑，就是这样：“冯先生甚贫，犹有一剑耳，又蒯缑。”铗：剑把。冯谖做了孟尝君的食客，他几次弹铗而歌：“长铗归来乎，食无鱼！”“长铗归来乎，出无车！”“长铗归来乎，无以为家！”（并见《史记》、《战国策》）
注：凌烟功臣长九尺：唐太宗时，绘功臣像于凌烟阁。
注：玉具：指剑饰琫、彘、璲、之属。这里与“蒯缑”相对。挂颐，形容剑长，《战国策》：“大冠若箕，修剑挂颐。”这两句意谓凌烟阁上的功臣虽然神气十足—躯大剑长，而又有剑饰之美，但究竟不是我所羡慕的。隐用李白《答王十二寒夜独酌有怀》“严陵高揖汉天子，何必长剑挂颐事玉阶”诗意。

# 正月二十日往岐亭，郡人潘、古、郭三人送余于女王城东禅庄院
题解：元丰四年（1081）作。潘大临（一说潘彦明）郭遘古耕道，都是作者到黄州后新交的朋友。这些人或开酒店，或卖药，或为流氓无产者。作者《东坡八首》之一有云：“潘子久不调，沽酒江南村；郭生本将种，卖药西市垣；古生亦好事，疑是押牙孙。”
诗：十日春寒不出门，/不知江柳已摇村。/稍闻决决流冰谷，/尽放青青没烧痕。
注：稍：这里义同多、渐。决决：水流动。
注：青青：形容野草新生。烧（读shào绍）：野火。这句是说新草青青掩盖了旧的烧痕。
诗：数亩荒园留我住，/半瓶浊酒待君温。/去年今日关山路，/细雨梅花正断魂。
注：细雨梅花正断魂：暗用杜牧《清明》诗“清明时节雨纷纷，路上行人欲断魂”句意。回忆“去年今日”自己在“关山路”上的情景。

# 侄安节远来，夜坐（选二首）
题解：安节是作者的堂侄，作者在《跋所书摩利支经后》有云：“侄安节于元丰庚申（三年）六月大水中，舟行下峡，明年（四年）十一月至黄州。”此诗当是四年末作，第二首“残年知汝远来情”可证。原三首，选第一、二共二首。
诗：南来不觉岁峥嵘，/夜拨寒灰听雨声。/遮眼文书原不读，/伴人灯火亦多情。
注：南来不觉岁峥嵘：峥嵘二字，作者惯用。本是形容山势的高耸峻险，这里当作岁的顶点、寒的深重。第二首第一句同样是这二字，但却当作瘦得露骨的形容。
注：遮眼文书原不读：作者自写萧闲之状。用药山惟俨禅师看经“我只图遮眼”语意。
诗：嗟予潦倒无归日，/令汝蹉跎已半生。/免使韩公悲世事，/白头还对短灯檠。
注：白头还对短灯檠：韩愈《短灯檠歌》：“长檠八尺空自长，短檠二尺便宜光。黄帘绿幕朱户闭，风露气入秋堂凉。裁衣寄远泪眼暗，搔头频挑灯移床。太学儒生东鲁客，二十辞家来射策。夜书细字缀语言，两目眵昏头雪白。此时提携当案前，看书到晓哪能眠！一朝富贵还自恣，长檠高张照珠翠。吁嗟世事无不然，墙角君看短檠弃！”作者引用其事，而说“免使”，说“还对”，是自嘲也是自傲。檠（qíng情），灯盏的柱。这里概指灯。
诗：心衰面改瘦峥嵘，/相见惟应识旧声。/永夜思家在何处？/残年知汝远来情。
注：永夜：长夜。
诗：畏人默坐成痴钝，/问旧惊呼半死生。/梦断酒醒山雨绝，/笑看饥鼠上灯檠。
注：笑看饥鼠上灯檠：常见画家爱以此句作题材，画烛台上燃着蜡烛，爬着一只老鼠，或题“残年”，或题“饥鼠”，都是用苏轼这句诗意。

# 正月二十日与潘、郭二生出郊寻春，忽记去年是日同至女王城作诗，乃和前韵
题解：元丰五年（1082）作。潘，指开酒店的潘大临；郭，指卖药的郭遘；他们是苏轼到黄州后新交的朋友。前韵指其《正月二十日往歧亭，郡人潘古郭三人送余于女王城东禅庄院》一诗。
诗：东风未肯入东门，/走马还寻去岁村。/人似秋鸿来有信，/事如春梦了无痕。
诗：江城白酒三杯酽，/野老苍颜一笑温。/已约年年为此会，/故人不用赋招魂。
注：酽（yàn验）：浓的口语。
注：已约年年为此会：隐示安于此，乐于此。
注：故人不用赋招魂：这里“招魂”借喻调他回京。说“不用”，表示他的倔强。

# 红梅（选一首）
题解：《红梅》三首，这一首（第一首）最好。第三四句，许多人认为是咏红梅的绝唱，也是许多人画红梅的佳题。此亦元丰五年作。
诗：怕愁贪睡独开迟，/自恐冰容不入时。/故作小红桃杏色，/尚孤瘦雪霜姿。
诗：寒心未肯随春态，/酒晕无端上玉肌。/诗老不知梅格在，/更看绿叶与青枝？
注：玉肌：犹如说玉容。
注：诗老：指他的前辈诗人石延年——就是末句作者自注的石曼卿。格：风格。在：所在。
注：更：岂能。这句是说：怎么能从“绿叶”、“青枝”来看梅花？
诗：石曼卿《红梅》诗云：/“认桃无绿叶，/辨杏有青枝。”

# 寒食雨二首
题解：农历清明节的前一天，是寒食节。此诗元丰五年作。传世作者手书《寒食帖》诗题无“雨”字。
诗：自我来黄州，/已过三寒食。/年年欲惜春，/春去不容惜。
诗：今年又苦雨，/两月秋萧瑟。/卧闻海棠花，/泥污燕脂雪。
注：两月秋萧瑟：此句言两月来雨多春寒，萧瑟如秋。
注：泥污燕脂雪：用杜甫《曲江对雨》“林花著雨燕脂湿”句意。燕脂（胭脂）雪，形容海棠花红中透白。
诗：暗中偷负去，/夜半真有力。/何殊病少年，/病起头已白。
注：夜半真有力：《庄子·大宗师》：“藏舟于壑，藏山于泽，谓之固矣。然夜半有力者负之而走，昧者不知也。”这里用以喻海棠花谢，像是有力者夜半暗中负去。
注：何殊：无异于。
诗：春江欲入户，/雨势来不已。/小屋如渔舟，/蒙蒙水云里。
诗：空庖煮寒菜，/破灶烧湿苇。/那知是寒食？/但见乌衔纸。
注：但见乌衔纸：此句是说见乌衔纸才知道今天是寒食节日。见，一本作感。
诗：君门深九重，/坟墓在万里。/也拟哭途穷，/死灰吹不起！
注：坟墓在万里：王注引次公曰：“此二句含蓄，言欲归朝廷耶？则君门有九重之深；欲返故乡耶？则坟墓有万里之远：皆以谪居而势不可也。”
注：也拟哭途穷：晋阮籍每走到一条路的尽头，就感慨地哭起来。这里隐言拟学阮籍途穷之哭。
注：死灰：在字面上是指上面“乌衔纸”的纸钱灰，实隐用汉韩安国的话，《史记·韩长孺列传》：“安国坐法抵罪，狱吏田甲辱安国，安国曰：‘死灰独不复燃乎？，田甲曰：‘燃则溺之！”作者说“死灰吹不起”，也就是死灰不复燃，以免再被人“溺”。

# 琴诗并序
题解：这一首诗，苏氏集中或载或不载，清纪昀以为“此随手写四句，本不是诗”，所见甚陋，实是好诗。序文似非序本诗之文，姑照旧本录存。
原：武昌主簿吴亮君采，携其友人沈君十二琴之说，与高斋先生空同子之文、太平之颂以示予。予不识沈君，而读其书如见其人，如闻十二琴之声。予昔从高斋先生游，尝见其宝一琴，无铭无识，不知其何代物也。请以告二子：使从先生求观之。此十二琴者，待其琴而后和。元丰五年闰六月。
诗：若言琴上有琴声，/放在匣中何不鸣？/若言声在指头上，/何不于君指上听？

# 正月三日点灯会客
题解：元丰六年（1083）作。各本均作“二月”，冯本作“三月”，王文诰集成本作“正月”。审诗中语，当以王说为是。
诗：江上东风浪接天，/苦寒无赖破春妍。/试开云梦羔儿酒，/快泻钱塘药玉船。
注：无赖：一本作无奈。
注：云梦：江汉之地。羔儿酒：即羊羔酒。
注：快泻：形容满倾。船：船形的酒杯，即羽觞。药玉：用一种药料煮某种石之似玉者来假充古玉，自宋代开始，古董商传此法，所谓“提油”。钱塘药玉船，杭州出品的石质加工仿制古玉杯。
诗：蚕市光阴非故国，/马行灯火记当年。/冷烟湿雪梅花在，/留得新春作上元。
注：蚕市光阴非故国：此句意思是说此时尚非故乡蚕市的日子。—蜀中风俗，以人日（旧历正月初七）作蚕市。这句怀乡。
注：马行灯火记当年：这句回忆在京情景。马行（读háng航）：是汴京城最热闹之处，春节夜市，更是繁华。
注：上元：元宵节—旧历正月十五日。

# 六年正月二十日复出东门，仍用前韵
题解：此诗仍用元丰四、五年两次正月二十日郊游之韵。
诗：乱山环合水侵门，/身在淮南尽处村。/五亩渐成终老计，/九重新扫旧巢痕。
注：五亩渐成终老计：《孟子·梁惠王》：“五亩之宅，树之以桑，五十者可以衣帛矣。”这时作者年四十八，在黄州又垦殖着东坡之地，觉得渐可作终老的打算。
注：九重：指朝廷。这时朝廷废史馆，作者曾做过史官，所以说“新扫旧巢痕”，反用李商隐《越燕》诗“安巢复旧痕”句意。
诗：岂惟见惯沙鸥熟，/已觉来多钓石温。/长与东风约今日，/暗香先返玉梅魂。
注：暗香先返玉梅魂：末句隐含期待朝廷复用他的意思。

# 南堂（选三首）
题解：苏诗中有两“南堂”，这是黄州的南堂。施注引《齐安拾遗记》：“夏澳口之侧，本水驿，有亭曰临皋。郡人以驿之高陂上筑南堂，为先生游息。”诗元丰六年作，原五首，选第一、三、五共三首。
诗：江上西山半隐堤，/此邦台馆一时西。/南堂独有西南向，/卧看千帆落浅溪。
诗：他时夜雨困移床，/坐厌愁声点客肠。/一听南堂新瓦响，/似闻东坞小荷香。
诗：扫地焚香闭阁眠，/簟纹如水帐如烟。/客来梦觉知何处？/挂起西窗浪接天。

# 初秋寄子由
题解：元丰六年作。
诗：百川日夜逝，/物我相随去。/惟有宿昔心，/依然守故处。
诗：忆在怀远驿，/闭门秋暑中。/藜羹对书史，/挥汗与子同。
注：怀远驿：在汴京，嘉祐六年，作者和他的弟弟曾寓此。
注：藜羹：形容饮食之差，生活之苦。
诗：西风忽凄厉，/落叶穿户牖。/子起寻夹衣，/感叹执我手。
诗：“朱颜不可恃”，/此语君莫疑。/别离恐不免，/功名定难期。
注：朱颜不可恃：用欧阳修《会饮圣俞家》“须知朱颜不可恃”语。
诗：当时已凄断，/况此两衰老？/失途既难追，/学道恨不早！
注：凄断：犹凄绝，凄楚之至。
注：此：这时。这时作者四十八岁，苏辙四十五岁。
诗：买田秋已议，/筑室春当成。/雪堂风雨夜，/已作对床声。

# 东坡
题解：元丰六年作。东坡在黄州，是山脚下一片数十亩大小的荒地。作者垦辟躬耕，并以此地名作自己的别号。唐大诗人白居易在忠州有《东坡种花》诗、《步上东坡》诗，作者对白居易是钦佩的，“东坡”之号，实原于此。
诗：雨洗东坡月色清，/市人行尽野人行。/莫嫌荦确坡头路，/自爱铿然曳杖声。
注：荦（luò洛）确：大而多的山石。

# 和秦太虚梅花
题解：这是元丰七年（1084）春，作者和秦观的诗。
诗：西湖处士骨应槁，/只有此诗君压倒。/东坡先生心已灰，/为爱君诗被花恼。
注：西湖处士骨应槁：没有出仕的读书人叫“处士”。西湖处士，指林逋。逋字和靖，名诗人，居西湖孤山，他的《山园小梅》诗“疏影横斜水清浅，暗香浮动月黄昏”，最为人所传诵。骨应槁，言其死已久。
注：只有此诗君压倒：这是作者赞美较过的话，秦观梅花诗未必超过林逋。
诗：多情立马待黄昏，/残雪消迟月出早。/江头千树春欲阁，/竹外一枝斜更好。
诗：孤山山下醉眠处，/点缀裙腰纷不扫。/万里春随逐客来，/十年花送佳人老。
注：裙腰：喻山脚、山腰。
注：逐客：作者自谓。
诗：去年花开我已病，/今年对花还草草。/不知风雨卷春归，/收拾香还畀昊。
注：畀昊（bì hào庇皓）：给天、交与上帝。
