# 赠沈博士歌遵
题解：题下周本、丛刊本校：“一作醉翁吟”。”又此诗周本、丛刊本注云“嘉佑二年”作。
诗：沈夫子，/胡为《醉翁吟》？/醉翁岂能知尔琴。/滁山高绝滁水深，
诗：空岩悲风夜吹林。/山溜白玉悬青岑，/一泻万仞源莫寻。/醉翁每来喜登临，
注：山：周本、丛刊本校：“一作“泉”。”
诗：醉倒石上遣其簪。/云荒石老岁月侵，/子有三尺徽黄金，/写我幽思穷崎嵚。
诗：自言爱此万仞水，/谓是太古之遣音。/泉淙石乱到不平，/指下鸣咽悲人心。
诗：时时弄余声，/言语软滑如春禽。/嗟乎沈夫子，/尔琴诚工弹且止！
诗：我昔被谪居滁山，/名虽为翁实少年。/坐中醉客谁最贤，/杜彬琵琶皮作弦。
注：名虽：周本、丛刊本校：“一作虽名’。”
诗：自从彬死世莫传，/玉连锁声入黄泉。/死生聚散日零落，/耳冷心衰翁索莫。
注：连：原作“练”，周本、丛刊本校：“东坡诗云：新客从翻玉连锁。”练，疑当作“连”。”按宋刊《王状元集百家注分类东坡先生诗》卷十二《宋叔达家听琵琶》“新客翻从玉连锁”句，赵次公注引欧阳诗云：“玉连锁声入黄泉”。李厚注：“玉连锁，今曲名。”作“连”是，今据改。
诗：国恩未报惭禄厚，/世事多虞嗟力薄。/颜摧鬓改真一翁，/心以忧醉安知乐。
注：以：周本、丛刊本校：“一作已’。”
诗：沈夫子谓我：/翁言何苦悲？/人生百年间，/饮酒能几时！
诗：揽衣推琴起视夜，/仰见河汉西南移。

# 和圣俞李侯家鸭脚子
题解：周本、丛刊本注云“嘉佑二年”作。
诗：鸭脚生江南，/名实未相浮。/绛囊因入贡，/银杏贵中州。
诗：致远有余力，/好奇自贤侯。/因令江上根，/结实夷门秋。
诗：始摘才三四，/金奁献凝旒。/公卿不及识，/天子百金酬。
诗：岁久子渐多，/累累枝上稠。/主人名好客，/赠我比珠投。
诗：博望昔所徙，/蒲萄安石榴。/想其初来时，/厥价与此侔。
诗：今也遍中国。/篱根及墙头。/物性久虽在，/人情逐时流。
诗：惟当记其始，/后世知来由。/是亦史官法，/岂徒续君讴。
诗：京师无鸭脚树，/驸马都尉李和文自南方移植于其第
注：于其第：原作“其地”，据衢本、周本、宋刊本、丛刊本、考异、程本、李本改。

# 送吴生南归
题解：题下周本、丛刊本校：“一作送吴孝宗字子京”。”又此诗周本、丛刊本注云“嘉佑五年”作。
诗：自我得曾子，/于兹二十年。/今又得吴生，/既得喜且叹。
诗：古士不并出，/百年犹比肩。/区区彼江西，/其产多材贤。
诗：吴生初自疑，/所拟岂其伦。/我始见曾子，/文章初亦然。
诗：昆仑倾黄河，/渺漫盈百川。/决疏以道之，/渐敛收横澜。
诗：东溟知所归，/识路到不难。/吴生始见我，/袖藏新文篇。
注：篇：周本、丛刊本校：“一作编”。”
诗：忽从布褐中，/百实写我前。/明珠杂玑贝，/磊砢或不圆。
注：写：周本、丛刊本校：“一作泻'。”又“我前”周本、丛刊本卷后校：“一作“在前”。”
诗：问生久怀此，/奈何初无闻？/吴生不自隐，/欲吐羞俯颜：
诗：少也不自重，/不为乡人怜。/中虽知自悔，/学问苦贱贫。
诗：自谓久而信，/力行困弥坚。/今来决疑惑，/幸冀蒙洗湔。
诗：我笑谓吴生，/尔其听我言：/世所谓君子，/何异于众人。
诗：众人为不善，/积微成灭身。/君子能自知，/改过不逡巡。
注：积微：考异作“积聚”。
诗：惟于斯二者，/愚智遂以分。/颜回不贰过，/后世称其仁。
注：颜回：周本、丛刊本卷后校：“一作颜子’。”
诗：孔子过而更，/日月披浮云。/子路初来时，/鸡冠佩豭豚。
注：鸡冠：考异校：“一作“冠鸡’。”〔七〕“祀”，周本、丛刊本卷后校：“一作事”。”
诗：斩蛟射白额，/后卒为名臣。/子既悔其往，/人谁御其新。
诗：丑夫祀上帝，/孟子岂不云。/临行赠此言，/庶可以书绅。

# 乐哉襄阳人送刘太尉从广赴襄阳
题解：题中“从广”下周本、丛刊本校：“一作“景元”。”又此诗周本、丛刊本注云“嘉佑二年”作。
诗：嗟尔乐哉襄阳人，/万屋连甍清漠滨。/语言轻清微带秦，/南通交广西峨岷。
诗：罗毅纤丽药物珍，/枇杷甘橘荐清尊。/磊落金盘烂璘璘，/槎头缩项昔所闻。
诗：黄橙构盏香复辛，/春雷动地竹走根。/锦苞玉笋味争新，/凤林花发南山春。
注：盏香复辛：周本、丛刊本校：“一作橙梼新”。”
注：竹：原误作“行”，据衢本、周本、宋刊本、丛刊本、考异、程本、李本改。
诗：掩映谷口藏山门，/楼台金碧瓦鳞鳞。/岘首高亭倚浮云，/漠水如天泻沄沄。
诗：斜阳返照白鸟群，/两岸桑柘杂耕耘。/文王遣化已寂寞，/千载谁复思其仁。
诗：荆州汉魏以来重，/古今相望多名臣。/嗟尔乐哉襄阳人，/道扶白发抱幼孙。
诗：远迎刘侯朱两轮，/刘侯年少气甚淳。/诗书学问若寒士，/尊俎谈笑多嘉宾。
注：朱两：周本、丛刊本校：“一作望朱”。”
诗：往时邢洺，/至今遣爱留其民。/谁能持我诗以往，/为我先贺襄阳人。
注：洺：周本、丛刊本校：“一作台’。”

# 奉酬扬州刘舍人见寄之作原父
题解：题下周本、丛刊本校：“一作酬刘原父见寄”。”又此诗周本、丛刊本注云“嘉佑二年”作。
诗：别君今几时，/岁月如插羽。/悠悠寝与食，/忽忽朝复暮。
诗：纷纷竟何为，/凛凛还自惧。/朝廷无献纳，/仓廪徒耗蠢。
诗：风霜苦见侵，/衰病日增故。/江湖岂不思，/恳悃布已屡。
诗：美哉广陵公，/风政传道路。/优游侍从臣，/左右天子顾。
诗：君来一何迟，/我请亦有素。/何当两还分，/尚冀一相遇。
诗：把手或未能，/尺书幸时寓。

# 西斋手植菊花过节始开偶书奉呈圣俞
题解：周本、丛刊本注云“嘉佑二年”作。
诗：秋风吹浮云，/寒雨洒清晓。/鲜鲜墙下菊，/颜色一何好。
诗：好色岂能常，/得时仍不早。/文章损精神，/何用觑天巧。
诗：四时悲代谢，/万物惜凋槁。/岂知寒监中，/两鬓甚秋草。
注：监：原误作“槛”，据衢本、周本、宋刊本、丛刊本、考异、程本、李本改。
诗：东城彼诗翁，/学问同少小风尘世事多，/日月良会少。/我有一尊酒，
注：少：周本、丛刊本校：“一作年’。”
诗：念君思共倒。/上浮黄金蕊，/送以清歌袅。/为君发朱颜，/可以却君老。

# 于刘功曹家见杨直讲褒女奴弹琵琶戏作呈圣俞
题解：周本、丛刊本注云“嘉佑二年”作。
诗：大弦声迟小弦促，/十岁娇儿弹啄木。/啄木不啄新生枝，/惟啄槎牙枯树腹。
注：促：考异作“速”。
诗：花繁蔽日锁空园，/树老参天杳深谷。/不见啄木鸟，/但闻啄木声。
诗：春风和暖百鸟语，/山路晓确行人行。/啄木飞从何处来，/花间叶底时丁丁。
诗：林空山静啄愈响，/行人举头飞鸟惊。/娇儿身小指拨硬，/功曹厅冷弦索鸣。
注：行人举头飞鸟惊：。周本、丛刊本卷后校：“一作众鸟啁啾飞且惊’。”
诗：繁声急节倾四坐，/为尔饮尽黄金觥。/杨君好雅心不俗，/太学官卑饭脱粟。
诗：娇儿两幅青布裙，/三脚木床坐调曲。/奇书古画不论价，/盛以锦囊装玉轴。
注：盛以锦囊：周本、丛刊本卷后校：“一作“古锦裁囊”。”
诗：披图掩卷有时倦，/卧听琵琶仰看屋。/客来呼儿旋梳洗。/满额花钿贴黄菊。
诗：虽然可爱眉目秀，/无奈长饥头颈缩。/宛陵诗翁勿诮渠，/人生自足乃为娱，/此儿此曲翁家无。

# 长句送陆子履学士通判宿州
题解：衢本题作：“长句送子履学士赴亳州一首。”又此诗周本、丛刊本注云“嘉佑二年”作。
诗：古人相马不相皮，/瘦马虽瘦骨法奇。/世无伯乐良可嗤，/千金市马惟市肥。
注：马惟市肥：此句后一“市”下周本、丛刊本校：“一作其”。”
诗：骐骥伏枥两耳垂，/夜闻秋风仰秣嘶。/一朝络以黄金羁，/旦刷吴越暮燕陲。
注：刷：周本、丛刊本校：“一作发’。”
诗：丈夫可怜憔悴时，/世俗庸庸皆见遣。/子履自少声名驰，/落笔文章天下知，
诗：开怀吐胸不自疑。/世路迫窄多阱机，/鬓毛零落风霜摧。/十年江湖千首诗，
诗：归来京国旧游非。/大笑相逢索酒卮，/酒酣犹能弄蛾眉。/山川摇落百草腓，
诗：爱君不改青松枝。/念君明当整骖𬴂；/赠以瑶华期早归。/岂惟朋友相追随，/坐使台阁生光辉。

# 送宋次道学士敏求赴太平州
题解：题中“赴”下周本、丛刊本校：“一作知，。”又此诗周本、丛刊本注云“嘉佑三年”作。
诗：古堤老柳藏春烟，/桃花水下清明前。/江南太守见之笑，/击鼓插旗催解船。
注：老柳藏：周本、丛刊本校：“一作杨柳排”。”
注：击鼓插旗催解船：周本、丛刊本校：“一作“打鼓插旗催发船’。”
诗：侍中令德宜有后，/学士清才方少年。/文章秀粹得家法，/笔画点缀多余妍。
注：余：周本、丛刊本校：“一作逾”。”
诗：藏书万卷复强记，/故事累朝能口传。/来居侍从乃其职，/远置州郡谁谓然。
注：谓：周本、丛刊本校：“别本多作为'。”
诗：交游一时尽英俊，/车马两岸来联翩。/船头朝转暮千里，/有酒胡不为留连：。
注：英：周本、丛刊本校：“一作“豪”。”
注：不为：周本、丛刊本校：“一作为不”。”

# 谢观文王尚书举正惠西京牡丹
题解：周本、丛刊本注云“嘉佑三年”作。
诗：京师轻薄儿，/意气多豪侠。/争夸朱颜事年少，/肯慰白发将花插。
注：事：周本、丛刊本卷后校：“一作竟’。”
诗：尚书好事与俗殊，/怜我霜毛苦萧飒。/赠以洛阳花满盘，/斗丽争奇红紫杂。
注：事：考异校：“家本作“士””
注：赠以：周本、丛刊本校：“一作寄赠”。”
诗：两京相去五百里，/几日驰来足何捷。/紫檀金粉香未吐，/绿萼红苞露犹浥。
诗：谓我尝为洛阳客，/颇向此花曾涉猎。/忆昔进士初登科，/始事相公沿吏牒。
诗：河南官属尽贤俊，/洛城池相连接。/我时年才二十余，/每到花开如蛱蝶。
注：池：周本、丛刊本校：“一作“苑”。”
诗：姚黄魏紫腰带鞋，/泼墨齐头藏绿叶。/鹤翎添色又其次，/此外虽妍犹婢妾。
注：紫：丛刊本作“红”
诗：尔来不觉三十年，/岁月才如熟羊胛。/无情草木不改色，/多难人生自摧拉。
诗：见花了了虽旧识，/感物依依几拉睫。/念昔逢花必沽酒，/起坐欢呼屡倾榼。
诗：而今得酒复何为，/爱花绕之空百匝。/心衰力懒难勉强，/与昔一何殊勇怯。
注：复：周本、丛刊本卷后校：“一作亦”。”
注：力懒：周本、丛刊本卷后校：“一作力乏’。”
诗：感公意厚不知报，/墨笔淋漓口徒嗫。

# 送朱职方表臣提举运盐
题解：周本、丛刊本注云“嘉佑三年”作。
诗：齐人谨盐荚，/伯者之事尔。/计口收其余，/登耗以生齿。
注：谨：周本、丛刊本校：“一作建”。”
诗：民充国亦富，/粲若有条理。/惟非三王法，/儒者犹为耻。
诗：后世益不然，/榷夺由漠始。/权量自持操，/屑屑已甚矣。
诗：穴灶如蜂房，/熬波销海水。/岂知戴白民，/食淡有至死。
诗：物艰利愈厚，/令出奸随起。/良民陷盗贼，/峻法难禁止。
诗：问官得几何，/月课烦笞箠。/公私两皆然，/巧拙可知已。
诗：英英职方郎，/文行粹而美。/连年宿与泗，/有政皆可纪。
诗：忽来从辟书，/感激赴知己。/闵然哀远人，/吐策献天子：
诗：治国如治身，/四民犹四体。/奈何窒其一，/无异钛厥趾。
诗：工作而商行，/本末相表里。/臣请通其流，/为国扫泥滓。
注：而商行：周本、丛刊本校：“一作与商贾’。”
诗：金钱归府藏，/滋味饱闾里。/利害难先言，/岁月可较比。
诗：盐官皆谓然，/丞相曰可喜。/适时乃为才，/高论徒谲诡。
诗：夷吾苟今出未以彼易此。/随堤树毵毵，/汴水流弥弥。/子行其勉旃，/吾党方倾耳。
注：今：周本、丛刊本校：“一作复”。”

# 尝新茶呈圣俞
题解：周本、丛刊本注云“嘉佑三年”作。
诗：建安三千里，/京师三月尝新茶。/人情好先务取胜，/百物贵早相矜夸。
注：三月：周本、丛刊本卷后校：“一作二月”。”
诗：年穷腊尽春欲动，/蛰雷未起驱龙蛇。/夜闻击鼓满山谷，/千人助叫声喊呀。
注：雷未起驱龙：周本、丛刊本校：“一作龙未起驱虫。”
诗：万木寒痴睡不醒，/惟有此树先萌芽。/乃知此为最灵物，/宜其独得天地之英华。
注：此为：周本、丛刊本卷后校：“一作草木'。”
注：宜：周本、丛刊本校：“一作疑”。”
诗：终朝采摘不盈掬，/通犀跨小圆复窳。/鄙哉谷雨枪与旗，/多不足贵如刈麻，
诗：建安太守急寄我，/香蒻包里封题斜。/泉甘器洁天色好，/坐中拣择客亦嘉。
诗：新香嫩色如始造，/不似来远从天涯。/停匙侧盏试水路，/拭目向空看乳花可怜俗夫把金锭，
注：空：周本、丛刊本卷后校：“一作檐”。”
注：锭：周本、丛刊本校：二作“挺”一作“铤”《茶录》多用“挺”，字为古。按《集韵》：锭’字去声，训镫，铤’字上声，训铜铁朴。
诗：猛火炙背如虾蟆。/由来真物有真赏，/坐逢诗老频咨嗟。/须臾共起索酒饮，/何异奏雅终淫哇。

# 乐郊诗为刘原甫作
题解：题下周本、丛刊本校：“一本注：“原父郓州东园也。”又此诗周本、丛刊本注云“嘉佑三年”作。
诗：乐郊何所乐？/所乐从公游。/三日公不出，/其民蹙然愁。
诗：一闻车马音，/从者如云浮。/吾问郓之人，/无乃失业不？
诗：云惟安其业。/然后乐其休。/乐郊何所有？/胡不考公诗。
诗：有山在其东，/有水出逶夷。/有台以临望，/有沼以游嬉。
诗：俯仰迷上下，/朱阑映清池。/草木非一种，/青红随四时。
诗：其余虽琐屑，/处置各有宜。/乐郊何以名？/吾为本其意。
诗：自古贤哲人，/所存非一世。/当时偶然迹，/来者因不废。
诗：郓非公久留，/公去民孰赖？/此亭公所登，/此树公所憩。
诗：俾民百年思，/岂取一日醉。

# 洗儿歌为㺄型作
题解：题下周本、丛刊本校：“一本云：前日送酒，遂助洗儿，辄成短歌，更资一笑，呈圣俞。'又此诗周本、丛刊本注云“嘉佑三年”作。
诗：书五色如霓儿，/深山猛虎夜生儿。/虎儿可爱光陆离，/开眼已有百步威。

诗：诗翁虽老神骨秀，/想见娇婴目与眉。/木星之精为紫气，/照山生玉水生犀。

# 鸣鸠
原：崇政殿后考试所作
注：崇政殿：周本、丛刊本注云“嘉佑四年”作。

诗：鸠呼妇归鸣且喜，/妇不亟归呼不已。/遂之其去恨不早，/呼不肯来固其理。
