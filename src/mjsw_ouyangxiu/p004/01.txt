# 啼鸟
题解：周本、丛刊本注云“庆历六年”作。
诗：穷山候至阳气生，/百物如与时节争。/官居荒凉草树密，/撩乱红紫开繁英。
注：撩乱红：周本、丛刊本校：“一作乱红殷”。”
诗：花深叶暗耀朝日，/日暖众鸟皆嘤鸣。/鸟言我岂解尔意，/绵蛮但爱声可听。
注：耀：原作“辉”，据衢本、周本、宋刊本、丛刊本、程本、李本改。
注：日：周本、丛刊本校：“一作一”。”
诗：南窗睡多春正美，/百舌未晓催天明。/黄鹂颜色已可爱，/舌端哑咤如娇婴。
诗：竹林静啼青竹笋，/深处不见惟闻声。/陂田绕郭白水满，/戴胜谷谷催春耕。
注：静啼：周本、丛刊本校：“一作“啼尽”。”
诗：谁谓鸣鸠拙无用，/雄雌各自知阴晴。/雨声萧萧泥滑滑，/草深苔绿无人行。
诗：独有花上提葫芦，/劝我沽酒花前倾。/其余百种各嘲哳，/异乡殊俗难知名。
诗：我遭谗口身落此，/每闻巧舌宜可憎。/春到山城苦寂寞，/把盏常恨无娉婷花开鸟语辄自醉。
注：舌：原作“言”，据衢本、周本、宋刊本、丛刊本、程本、李本改。
注：开：周本、丛刊本卷后校：“一作间”。”
诗：醉与花鸟为交朋。/花能嫣然顾我笑，/鸟劝我饮非无情。/身闲酒美惜光景，
注：交：周本、丛刊本校：“一作友’。”
注：光景：衢本、李本作“花景”。
诗：惟恐鸟散花飘零。/可笑灵均楚泽畔，/离骚憔悴愁独醒。

# 游琅琊山
题解：周本、丛刊本注云“庆历六年”作。
诗：南山一尺雪，/雪尽山苍然。/涧谷深自暖，/梅花应已繁。
诗：使君厌骑从，/车马留山前。/行歌招野叟，/共步青林间。
诗：长松得高荫，/盘石堪醉眠。/止乐听山鸟，/携琴写幽泉。
诗：爱之欲忘返，/但苦世俗牵。/归时始觉远，/明月高峰巅。

# 读徂徕集
题解：周本、丛刊本注云“庆历六年”作。
诗：徂徕鲁东山，/石子居山阿。/鲁人之所瞻，/子与山嵯峨。
诗：今子其死矣，/东山复谁过。/精魄已埋没，/文章岂能磨！
诗：寿命虽不长，/所得固已多。/旧稿偶白录，/沧溟之一蠡。
诗：其余谁付与，/散失存几何！/存之警后世，/古监照妖魔，
注：古：《文鉴》作“若”。
诗：子生诚多难，/忧患靡不罹。/音罗宦学三十年，/六经老研摩。
注：子：原误作“予”，据衢本《文鉴》、周本、宋刊本、丛刊本、考异、程本、李本改。
诗：问胡所专心？/仁义丘与轲扬雄、韩愈氏，/此外岂知他。/尤勇攻佛老，
诗：奋笔如挥戈，/不量敌众寡，/胆大身么公。/往年遭母丧，
诗：泣血走岷峨。/垢面跣双足，/锄犁事田坡。/至今乡里化，
诗：孝悌勤蚕禾。/昨者来太学，/青衫踏朝靴。/陈诗颂圣德，
诗：厥声续猗那。/羔雁聘黄晞，/晞惊走邻家。/施为可怪骇，
诗：世俗安委蛇。/谤口由此起，/中之若飞梭。/上赖天子明，
注：明：原作“圣”，据衢本《文鉴》、周本、宋刊本、丛刊本改。
诗：不挂网者罗；/忆在太学年，/大雪如翻波。/生徒日盈门，
诗：饥坐列雁鹅。/弦诵聒邻里，/唐虞赓咏歌。/常续最高第，
诗：骞游各名科。/岂止学者师，/谓宜国之皤。/夭寿反仁鄙，
诗：谁尸此偏颇。/不知诙诙者，/又忍加诋诃。/圣贤要久远，
诗：毁誉暂喧哗。/生为举世疾，/死也鲁人嗟。/作诗遣鲁社，/祠子以为歌。
注：也：周本、丛刊本校：“一作者”。”

# 大热二首
题解：周本、丛刊本注云“庆历六年”作。
诗：四时成万物，/寒暑迭钧陶。/壮阳当用事，/大夏蒸炎歊。
诗：造化本无情，/怨咨徒尔劳。/身微天地阔，/四颅无由逃。
诗：九门闾阖开，/方仞昆仑高。/积雪寒凛凛，/清风吹寥寥。
诗：嗟我虽欲往，/而身无羽毛。
诗：阳晖烁四野，/万里纤云收。/羲和困路远，/正午当空留。
诗：枝条不动影，/草木皆含愁。/深林虎不啸，/卧喘如吴牛。
诗：蜩蝉一何微，/嗟尔徒啾啾。

# 幽谷泉
题解：周本、丛刊本注云“庆历六年”作。
诗：踏石弄泉流，/寻源入幽谷。/泉傍野人家，/四面深篁竹。
诗：溉稻满春畴，/鸣渠绕茅屋。/生长饮泉甘，/荫泉栽美木。
诗：潺湲无春冬，/日夜响山曲。/自言今白首，/未惯逢朱毂。
诗：顾我应可怪，/每来听不足。

# 憎蚊
题解：周本、丛刊本注云“庆历六年”作。
诗：扰扰万类殊，/可憎非一族。/甚哉蚊之微，/岂足污简牍。
诗：乾坤量广大，/善恶皆含育。/荒茫三五前，/民物交相赎。
注：茫：周本、丛刊本校：“一作荒”。”
诗：禹鼎象神奸，/蛟龙远潜伏。/周公驱猛兽，/人始居川陆。
诗：而来千百年，/天地得清肃。/大患已云除，/细微遣不录。
诗：蝇虻蚤虱虮，/蜂蝎蚖蛇蝮。/惟尔于其间，/有形才一粟。
诗：虽微无奈众，/惟小难防毒。/尝闻高邮间，/猛虎死凌辱哀战露筋女，
诗：万占雠不复。/水乡自宜尔，/可怪穷边俗。/晨飧下帷畴，
诗：盛暑泥驹犊。/我来守穷山，/地气尤卑溽。/官闲懒所便，
诗：惟睡宜偏足。/难堪尔类多，/枕席厌缘扑。/熏檐苦烟埃，
注：檐：周本、丛刊本校：“一作之”。”
诗：燎壁疲照烛。/荒城繁草树，/旱气飞炎熵。/羲和驱日车，
诗：当午不转毂。/清风得夕凉，/如赦脱囚梏。/扫庭露青天，
诗：坐月荫嘉木。/汝宁无他时，/忍此见迫促。/翔翔伺昏黑，
注：时：周本、丛刊本校：“一作日”。”
注：此见：周本、丛刊本校：“一作“见此”。”
诗：稍稍出壁屋。/填空来若翳，/聚隙多可掬。/丛身疑陷围，
注：出：周本、丛刊本卷后校：“一作去”。”
诗：聒耳如遭哭。/猛攘欲张拳，/暗中甚飞镞。/手足不自救，
注：甚：周本、丛刊本校：“一作疑’。”
诗：其能营背腹。/盘飧劳扇拂，/立寐僵僮仆。/端然穷百计，
诗：还坐瞑双目。/于吾固不较，/在尔诚为酷。/谁能推物理，
诗：无乃乖人欲。/驺虞凤皇麟，/千载不一瞩。/思之不可见，/恶者无由逐。

# 重读徂徕集
题解：周本、丛刊本注云“庆历七年”作。
诗：我欲哭石子，/夜开《徂徕》编。/开编未及读，/涕泗已涟涟。
诗：勉尽三四章，/收泪辄欣欢。/切切善恶戒，/丁宁仁义言。
注：切切：周本、丛刊本校：“一作昭昭’一作“昭晰”。”
诗：如闻子谈论，/疑子立我前。/乃知长在世，/谁谓已沉泉。
注：已：周本、丛刊本校：“一作子”。”
诗：昔也人事乖，/相从常苦艰。/今而每思子，/开卷子在颜。
诗：我欲贵子文，/刻以金玉联。/金可烁而销，/玉可碎非坚。
诗：不若书以纸，/六经皆纸传。/但当书百本，/传百以为千。
注：书：周本、丛刊本校：“一作“传”。”
注：但当书百本：周本、丛刊本校：“一作“传十以为百”。”
诗：或落于四夷，/或藏在深山，/待彼谤焰熄，/放此光芒悬。
注：在：周本、丛刊本校：“一作于’。”
注：焰：周本、丛刊本校：“一作“艳’。”
诗：人生一世中，/长短无百年。/无穷在其后，/万世在其先。
诗：得长多几何，/得短未足怜。/惟彼不可朽，/名声文行然。
诗：谗诬不须辨，/亦止百年间。/百年后来者，/憎爱不相缘。
诗：公议然后出，/自然见媸妍。/孔孟困一生，/毁逐遭百端。
诗：后世苟不公，/至今无圣贤。/所以忠义士，/恃此死不难。
注：恃此死：周本、丛刊本校：“一作轻死此”。”
诗：当子病方革，/谤辞正腾喧。/众人皆欲杀，/圣主独保全。
注：圣主：《文鉴》作“圣言”
诗：已埋犹不信，/仅免新其棺。/此事古未有，/每思辄长叹。
诗：我欲犯众怒，/为子记此冤。/下纾冥冥忿，/仰叫昭昭天。
注：欲：考异作“久”。
诗：书于苍翠石，/立彼崔嵬巅，/询求子世家，/恨子儿女顽。
诗：经岁不见报，/有辞未能诠。/忽开子遣文，/使我心已宽。
注：诠：原作“铨”，周本、丛刊本校：“铨”，一作“诠”。”据改。
诗：子道自能久，/吾言岂须镌。

# 汝瘿答仲仪
题解：题下周本、丛刊本校：“一作答王素汝瘿”。”又此诗周本、丛刊本注云“庆历七年”作。
诗：君嗟汝瘿多，/谁谓汝土恶。/汝瘿虽云苦，/汝民居自乐。
诗：乡闾同饮食，/男女相媒妁。/习俗不为嫌，/讥嘲岂知怍。
诗：汝山西南险，/平地犹硗确。/汝树生拥肿，/根株浸溪壑。
注：硗确：衢本作“确荦”。周本、丛刊本卷后校云：“平地犹确”衢本作确荦’吉本作“砚营”，建本作确营”，蜀本、罗氏本作晓确’。”朝佐按：“字书磕’通作境’确’通作瞒’“磬硗确”不平也。荦’駮牛也。管’石相扣声。确荦跷营确营’，字各不同，今从蜀本、罗氏本作硗确”宋刊本校：“恕本作“确营”。”
注：拥：周本、丛刊本校“一作痈”。”
诗：山川固已然，/风气宜其浊。/接境化襄、邓，/余风被伊、维。
诗：思予昔曾游，/所见可惊愕。/喔喔闻语笑，/累累满城郭。
诗：偃妇悬瓮盎，/娇婴包卵毂。/无由辨肩颈，/有类龟缩壳。
诗：噫人禀最灵，/反不如凫鹤。/骈枝虽形累，/小小固可略。
诗：痈疡暂畜聚，/决溃终当涸。/赘疣附支体，/幸或不为虐。
诗：未若此巍然，/所生非所托，/咽喉系性命，/针石难砭削。
诗：农皇古神圣，/为世名百药。/岂不有方书，/顽然莫销铄。
注：铄：原作烁”，周本、丛刊本校：“烁”，一作铄”。”据改。
诗：温汤汝灵泉，/亦不能湔瀹。/君官虽谪居，/政可瘳民瘼。
注：可瘳民瘼：周本、丛刊本校：“一作“疗”。”
诗：奈何不哀怜，/而反恣诃谑。/文辞骋新工，/丑怪极名貌。
注：恣：衢本作“资”。又“诃”，周本、丛刊本校：“一作“嘲”。”
诗：汝士虽多奇，/汝女少纤弱。/翻思太守宴，/谁与唱清角。
注：思：衢本、丛刊本作“愁”
诗：乖离南北殊，/魂梦山陂邈。/握手未知期，/寄诗聊一噱。
注：诗：周本、丛刊本校：“一作书”。”

# 沧浪亭
题解：题下周本、丛刊本校：“一本上云寄题子美'。”又此诗周本、丛刊本注云“庆历七年”作。
诗：子美寄我沧浪吟，/邀我共作沧浪篇。/沧浪有景不可到，/使我东望心悠然。
注：作：。周本、丛刊本校：“一作赋”。”
诗：荒湾野水气象古，/高林翠皋相回环。/新篁抽笋添夏影，/老柟乱发争春妍。
诗：水禽闲暇事高格，/山乌日夕相啾喧。/不知此地几兴废，/仰视乔木皆苍烟。
诗：堪嗟人迹到不远，/虽有来路曾无缘。/穷奇极怪谁似子，/搜索幽隐探神仙。
注：曾：周本、丛刊本校：“一作苦’。”
诗：初寻一径入蒙密，/豁目异境无穷边。/风高月白最宜夜，/一片莹净铺琼田。
注：目：衢本、《文鉴》、考异作“见”。考异“见”下校云：“吉本作“目”，今从家本”
诗：清光不辨水与月，/但见空碧涵漪涟。/清风明月本无价，/可惜只卖四万钱。
注：碧涵漪涟：此句下周本、丛刊本校：“一有姑苏台边人响绝，夜静往往闻鸣船”两句。”
诗：又疑此境天乞与，/壮士憔悴天应怜。/鸱夷古亦有独往，/江湖波涛渺翻天。
注：境：周本、丛刊本校：“一作景”。”
诗：崎岖世路欲脱去，/反以身试蛟龙渊。/岂如扁舟任飘兀，/红蕖绿浪摇醉眠。
诗：丈夫身在岂长弃，/新诗美酒聊穷年。/虽然不许俗客到，/莫惜佳句人间传。
注：新诗美酒：周本、丛刊本校：“一作诗新酒美”。”

# 宝剑
诗：宝剑匣中藏，/暗室夜常明。/欲知天将雨，/铮尔剑有声。

# 菱溪大石
题解：题中“大”下周本、丛刊本校：“一本无大’字。”又此诗周本、丛刊本注云“庆历六年”作。
诗：新霜夜落秋水浅，/有石露出寒溪垠。/苔昏土蚀禽鸟啄，/出没溪水秋复春。
诗：溪边老翁生长见，/疑我来视何殷勤。/爱之远徙向幽谷，/曳以三犊载两轮。
诗：行穿城中罢市看，/但惊可怪谁复珍。/荒烟野草埋没久，/洗以石宝清泠泉朱阑绿竹相掩映，
注：泠：原作“冷”，据衢本、周本、丛刊本改。
诗：选致佳处当南轩。/南轩旁列千万峰，/曾未有此奇嶙峋。/乃知异物世所少，
注：选：考异校：“苏本作“邀”。”
