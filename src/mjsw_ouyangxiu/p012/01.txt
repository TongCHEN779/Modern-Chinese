# 初至夷陵答苏子美见寄
题解：周本、丛刊本注云“景佑三年”作。
诗：三峡倚岧尧，/同迁地最遥。/物华虽可爱，/乡思独无聊。
注：同：周本、丛刊本校：“一作“南”。”
诗：江水流青嶂，/猿声在碧霄。/野篁抽夏笋，/丛橘长春条。
注：青：原作“清”。据周本、宋刊本、丛刊本、考异、程本、李本改。
诗：未腊梅先发，/经霜叶不凋。/江云愁蔽日，/山雾晦连朝。
注：愁：周本、丛刊本校：“一作悬”。”
诗：斫谷争收漆，/梯林斗摘椒。/巴賨船贾集，/蛮市酒旗招。
注：巴賨船贾集：周本、丛刊本校：“一作巴江船贾至’。”
诗：时节同荆俗，/民风载楚谣。/俚歌成调笑，/撩鬼聚喧嚣。
诗：夷陵之俗多淫奔，/又好祠祭。/每遇祠时，/里民数百共饺其余，
诗：里语谓之撩鬼，/因此多成斗讼。/得罪宜投裔，/包羞分折腰。
诗：光阴催晏岁，/牢落惨惊。/白发新年出，/朱颜异域销。
诗：县楼朝见虎，/官舍夜闻鸮。/寄信无秋雁，/思归望斗杓。
诗：须知千里梦，/长绕洛川桥。
注：洛川：李本作“洛阳”。

# 冬至后三日陪丁元珍游东山寺
题解：题中“冬后”，周本、丛刊本卷后校：“石本作冬至后。”又此诗周本、丛刊本注云“景佑三年”作。
诗：幕府文书日已希，/清尊岁晏喜相携。/寒山带郭穿松路，/瘦马寻春踏雪泥。
注：幕府：周本、丛刊本卷后校：“一作下府”。”
诗：翠藓苍崖森古木，/绿萝盘石暗深溪。/为贪赏物来犹早，/迎腊梅花吐未齐。

# 送前巫山宰吴殿丞字照邻

注：枝：周本、丛刊本校：“一作林”。”

# 龙兴寺小饮呈表臣元珍

注：雪云：。李本作“云霓”。
注：氛氲：周本、丛刊本卷后校：“一作“氤氲’。”

# 夷陵岁暮书事呈元珍表臣

诗：萧条鸡犬乱山中，/时节峥嵘忽已穷。/游女髻鬟风俗古，/野巫歌舞岁年丰。
注：忽：周本、丛刊本校：“一作岁”。”
诗：夷陵俗朴陋，/惟岁暮祭鬼，/则男女数百相从而乐饮，/妇女竞为野服以相游嬉。
注：陵俗朴陋：周本、丛刊本校云：“夷陵俗’下一本有古’字。”
诗：平时都邑今为陋，/敌国江山昔最雄。/三国时，/吴蜀战争于此。
诗：荆楚先贤多胜迹，/不辞携酒问邻翁。/处士何参居县舍西，/好学，/多知荆楚故事。

# 夷陵书事寄谢三舍人
题解：题下周本、丛刊本校：“一作代书寄舍人二丈”。”又此诗周本、丛刊本注云“景佑四年”作。
诗：春秋楚国西偏境，/陆羽《茶经》第一州。/紫箨青林长蔽日，/绿丛红橘最宜秋。
诗：道涂处险人多负，/邑屋临江俗善泅。/猎市渔盐朝暂合，/淫祠箫鼓岁无休。
诗：风鸣烧入空城响，/雨恶江崩断岸流。/月出行歌闻调笑，/花开啼鸟乱铭钩辀。
注：乱铭钩辀：句下周本、丛刊本校：“一本有“讼庭画地通人语，邑政观风间俚讴。上俗虽轻人自乐，山川信美客偏愁'四句。
诗：黄牛峡口经新岁，/白玉京中梦旧游。/曾是洛阳花下客，/欲夸风物向君羞。
注：君：周本、丛刊本卷后校：“一作“春”，石本同。”

诗：留滞西山独可嗟，/残春过尽始还家。/落花纵有那堪醉，/何况归时无落花。

诗：闻君屡醉赏红英，/落尽残花酒未醒。/嗟我落花无分看，/莫嫌狼藉扫中庭。

诗：绿树交加山鸟啼，/晴风荡漾落花飞。/鸟歌花舞太守醉，/明日酒醒春已归。

注：晴风荡漾落：周本、丛刊本校：“一作“晚晴斜日杂”。”
注：日：周本、丛刊本校：“一作月’。”又“已”，周本、丛刊本校：“一作“色'。”
诗：春云淡淡日辉辉，/草惹行襟絮拂衣。/行到亭西逢太守，/篮与酩酊插花归。
诗：红树青山日欲斜，/长郊草色绿无涯。/游人不管春将老，/来往亭前踏落花。
注：老：周本、丛刊本校：“一作尽”。”
注：来往：周本、丛刊本校：“一作空绕”。”

# 谢判官幽谷种花

诗：浅深红白宜相间。/先后仍须次第栽。/我欲四时携酒去，/莫教一日不花开。
注：浅深红白：周本、丛刊本卷后校：“一作“深红浅白”。”

# 画眉鸟

注：随：周本、丛刊本校：“一作任’。”

# 怀嵩楼新开南轩与郡僚小饮

诗：解带西风飘画角，/倚阑斜日照青松。/会须乘醉携嘉客，/踏雪来看群玉峰。

# 送张生

注：发：李本作“鬓”。
诗：老骥骨奇心尚壮，/青松岁久色逾新。/山城寂寞难为礼，/浊酒无辞举爵频。
注：礼：周本、丛刊本校：“一作“客”。”

诗：林外鸣鸠春雨歇，/屋头初日杏花繁。

# 别滁

注：且：周本、丛刊本校：“一作只’。”

# 答谢判官独游幽谷见寄
题解：周本、丛刊本注云“庆历八年”作。
诗：闻道西亭偶独登，/怅然怀我未忘情。/新花自向游人笑，/啼鸟犹为旧日声。
诗：因拂醉题诗句在，/应怜手种树阴成。/须知别后无由到，/莫厌频携野客行。

# 招许主客
题解：周本、丛刊本注云“庆历八年”作。
诗：欲将何物招嘉客，/惟有新秋一味凉。/更扫广庭宽百亩，/少容明月放清光。
注：更：周本、丛刊本校：“一作静”。”又“宽”，周本、丛刊本校：“一作‘开’。”
注：放：周本、丛刊本校：“一作咤”。”
诗：楼头破监看将满，/瓮面浮蛆拨已香。/仍约多为诗准备，/共防梅老敌难当。
注：仍：周本、丛刊本校：“一作“更”。”

# 咏雪

# 答通判吕太博
题解：周本、丛刊本注云“皇佑元年”作。
诗：千顷芙蕖盖水平，/郡治荷花，/四望极目。/扬州太守旧多情。

# 祈雨晓过湖上
题解：周本、丛刊本注云“皇佑二年”作。
诗：清晨驱马思悠然，/渺渺平湖碧玉田。/晓日未升先起雾，/绿阴初合自生烟。
注：阴：衢本作“云”。
诗：身闲始觉时光好，/春去犹余物色妍。/更待四郊甘雨足，/相随箫鼓乐丰年。
