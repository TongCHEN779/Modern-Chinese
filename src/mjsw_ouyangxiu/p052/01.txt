# 居士外集卷一　古诗四十七首
题解：此卷诗，周本、丛刊本注云：“西京作。起天圣九年，尽明道二年。”

# 拟玉台体七首
题解：周本、丛刊本注云“明道元年”作。

# 欲眠
诗：行人夜已断，/明河南陌头。/双珰不拟解，/更欲要君留。

# 携手曲
诗：落日堤上行，/独歌携手曲。/却忆携手人，/处处春华绿。

# 雨中归
诗：朝看楼上云，/日暮城南雨。/路远香车迟，/迢迢向何所？

# 别后
诗：连环结连带，/赠君情不忘。/暂别莫言易，/一夕九回肠。

# 夜夜曲
诗：浮云吐明月，/流影玉阶阴。/千里虽共照，/安知夜夜心？

# 落日窗中坐
诗：朝闻惊禽去，/日暮见禽归。/瑶琴坐不理，/含情复为谁？
注：含情复为谁：“为”，周本、丛刊本校：“一作与’。”

# 领边绣
诗：双鸳刺绣领，/粲烂五文章。/暂近已复远，/犹持歌扇障。

# 七交七首
题解：周本、丛刊本注云“天圣九年”作。

# 河南府张推官
诗：尧夫大雅哲，/禀德实温粹。/霜筠秀含润，/玉海湛无际。
诗：平明坐大府，/官事盈案几。/高谈遗放纷，/外物不能累。
诗：非惟席上珍，/乃是青云器。

# 尹书记
诗：师鲁天下才，/神锋凛豪隽。/逸骥卧秋柜，/意在睽睽迅。
诗：乎居弄翰墨，/挥洒不停瞬。/谈笑帝王略，/驱驰古今论。
诗：良工正求玉，/片石胡为韫？

# 杨户曹
诗：子聪江山禀，/弱岁擅奇誉。/盱衡恣文辩，/落笔妙言语。
诗：胡为冉冉趋，/三十滞公府？/美璞思善价，/浮云有夷路。
诗：大雅恶速成，/俟命宜希古。

# 梅主簿
诗：圣俞翘楚才，/乃是东南秀。/玉山高岑岑，/映我觉形陋。
诗：《离骚》喻草香，/诗人识.鸟兽。/城中争拥鼻，/欲学不能就。
诗：平日礼文贤，/宁久滞奔走。

# 张判官
诗：洛城车隆隆，/晓门争道入。/连袂纷如帷，/文者岂无十。
诗：壮矣张太素，/拂羽择其集。/远慕邺才子，/一笑欢相挹。
诗：虽有轩与冕，/攀翔莫能及。/人将孰君子，/盍视其游执？

# 王秀才
诗：几道颜之徒，/沈深务覃圣。/采藻荐良璧，/文润相辉映。
诗：入市羊驾车，/谈道犀为柄。/时时一文出，/往往纸价盛。
诗：无为恋丘樊，/遂滞蒲轮聘。

# 自叙
诗：余本漫浪者，/兹亦漫为官。/胡然类鸱夷，/托载随车辕。
诗：时士不俯眉，/默默谁与言？/赖有洛中俊，/日许相跻攀。
诗：饮德醉醇酎，/袭馨佩春兰。/平时罢军檄，/文酒聊相欢。

# 答杨辟喜雨长句
题解：周本、丛刊本“杨辟”下校：“一作“子静”；又“喜”下校：“一作“祈”。”
诗：吾闻阴阳在天地，/升降上下无时穷。/环回不得不差失，/所以岁时无常丰。
诗：古之为政知若此，/均节收敛勤人功。/三年必有一年食，/九岁常备三岁凶。
注：常备三岁凶：此句中两“岁”字下周本、丛刊本校：“一作“年”。”
诗：纵令水旱或时遇，/以多补少能相通。/今者吏愚不善政，/民亦游惰离於农。
注：水旱或时遇：“或”，周本、丛刊本校：“一作“忽”。”
诗：军国赋敛急星火，/兼并奉养过王公。/终年之耕幸一熟，/聚而耗者多於蠭。
诗：是以比岁屡登稔，/然而民室常虚空。/遂令一时暂不雨，/辄以困急号天翁。
注：比岁屡登稔：“屡”，周本、丛刊本校：“一作累”。”
注：一时暂不雨：“暂”，周本、丛刊本校：“一作“遭”。”
注：困急号天翁：“翁”，周本、丛刊本校：“一作公’。”
诗：赖天闵民不责吏，/甘泽流布何其浓。/农当勉力吏当愧，/敢不酌酒浇神龙！
注：流布何其浓：“泽”，周本、丛刊本校：“一作“澍”。”
原：嵩山十二首
注：嵩山十二首：周本、丛刊本注云“明道元年”作。

# 公路涧
诗：驱马渡寒流，/断涧横荒堡。/槎危欲欹岸，/花落多依草。
诗：击汰肮游鲦，/倒影看飞鸟。/留连爱芳杜，/渐下西峰照。

# 拜马涧
诗：昔闻王子晋，/把袂浮丘仙。/金骏於此堕，/吹笙不复还。
诗：玉蹄无迹久，/涧草但荒烟。

# 二室道
诗：二室对山霓，/群峰耸蝤直。/云随高下起，/路转参差碧。
诗：春晚桂丛深，/日下山烟白。/芝英已可茹，/悠然想泉石。
诗：自峻极中院步登太室中峰系马青松阴，/蹑屣苍崖路。/惊鸟动林花，/空山答人语。
诗：云霞不可揽，/直入冥冥雾。

# 玉女窗
诗：玉女不可邀，/苍崖郁岩直。/石乳滴空宝，/仰见沆寥碧。
注：沆寥：“沆寥”原误作“沈寥”，据周本、宋刊本、丛刊本改。
诗：徙倚难久留，/桂树含春色。

# 玉女捣衣石
诗：玉女捣仙衣，/夜下青松岭。/山深风露寒，/月杵遥相应。
诗：灵踪杳可寻，/片石秋光莹。

# 天门
诗：石径方盘纡，/双峰忽中断。/呀豁青冥间，/畜泄烟云乱。
诗：杉萝试举手，/自可阶天汉。

# 天门泉
诗：旧号救命泉，/恶其名鄙，/因取美名，/书为续命泉，
诗：大书三字立于泉侧。/烟霞天门深，/灵泉吐岩侧。/云湿灏气寒，
注：大书三字：“大书三字”，周本、丛刊本作“人书一字”。按《欧阳文忠公年谱》载，天圣九年，欧阳修至西京洛阳，与尹洙、梅尧臣过从甚密。下《三醉石》诗题下自注亦有“而三人者又各题其姓名而刻之”云云。据此，则嵩山之游，当为三人，“人书一字”可通。
诗：石老林腴碧。/长松暂休坐，/一酌烦心涤。
诗：天池高步登天池，/灵源湛然吐。/俯窥不可见，/渊默神龙护。
诗：静夜天籁寒，/宿客疑风雨。
注：静夜天籁寒：“天”，周本、丛刊本校：“一作松”。”

# 三醉石
诗：三醉石在八仙坛上，/南临巨崖，/峰岫迤逦，/苍烟白云郁郁在下。
诗：物外之适，/相与酣酌，/坐石欹醉、似非人间。/因索笔，
诗：目梅圣俞书三醉字於石上，/而三人者又各题其姓名而刻之。
诗：拂石登古坛，/旷怀聊共醉。/云霞伴酣乐，/忽在千峰外。
诗：坐久还自醒，/日落松声起。

# 峻极寺
诗：路入石门见，/苍苍深霭间。/云生石砌润，/木老天风寒。
诗：客来依返照，/徙倚听山蝉。

# 中峰
诗：望望不可到，/行行何屈盘。/一迳林杪出，/千岩云下看。
诗：烟岚半明灭，/落照在峰端。

# 初秋普明寺竹林小饮饯梅圣俞分韵得亭皋木叶下绝句五首
题解：周本、丛刊本题中无“绝句”二字，且注云“明道元年”作。
诗：临水复欹石，/陶然同醉醒。/山霞坐未敛，/池月来亭亭。
诗：洛城风日美，/秋色满蘅皋。/谁同茂林下，/扫叶酌松醪。
注：秋色满蘅皋：“蘅”，周本、丛刊本卷后校：“一作“衡”。”
诗：野水竹间清，/秋山酒中绿。/送子此酣歌，/淮南应落木。
诗：劝客芙蓉杯，/欲搴芙蓉叶。/垂杨碍行舟，/演漾回轻檝。
诗：山水日已佳，/登临同上下。/衰兰尚可采，/欲赠离居者。

# 和谢学士泛伊川浩然无归意因咏刘长卿佳句作欲留篇之什
题解：周本、丛刊本注云“明道元年”作。
诗：久不见南山，/依然已秋色。/悠哉川上行，/复邀城中客。
诗：木落山半空，/川明潦尤积。/飞鸟监中看，/行云舟中白。
诗：夷犹白苹裹，/笑傲清风侧。/极浦追所远，/回峰高易夕。
注：极浦追所远：“所”下周本校云“疑”。
诗：觞咏共留连，/高怀追昔贤。/惟应谢公兴，/不减向临川。

# 戏书拜呈学士三丈
诗：渊明本嗜酒，/一钱常不持。/人邀辄就饮，/酩酊篮与归。
诗：归来步三径，/索寞绕东篱。/咏句把黄菊，/望门逢白衣。
诗：欣然复坐酌，/独醉卧斜晖。

# 和杨子聪答圣俞月夜见寄
诗：秋露蔼已繁，/迢迢星汉回。/皎洁庭际月，/流光依井苔。
诗：有客爱凉景，/幽轩为君开。/所思不可极，/但慰清风来。

# 谢人寄双桂树子
题解：周本、丛刊本注云“明道二年”作。
诗：有客赏芳丛，/移根自幽谷。/为怀山中趣，/爱此山下绿。
诗：晓露秋晖浮，/清阴药兰曲。/更待繁花白，/邀君弄芳馥。
注：清阴药兰曲：“兰”，周本、丛刊本作“栏”。

# 雨中独酌二首
诗：老大世情薄，/掩关卧郊原。/英英少年子，/谁肯过我门。
注：掩关卧郊原：“卧”，周本、丛刊本作“外”。
诗：宿云屯朝阴，/暑雨清北轩。/逍遥一尊酒，/此意谁与论。
诗：酒味正薰烈，/吾心方浩然。/呜禽时一弄，/如与古人言。
注：酒味正薰烈：“烈”，周本、丛刊本卷后校：“一作冽”。”
诗：幽居草木深，/蒙龙蔽窗户。/鸟语知天阴，/蛙鸣识天雨。
诗：亦复命尊酒，/欣兹却烦暑。/人情贵自适，/独乐非钟鼓。
诗：出门何所之，/闭门谁我顾？

# 庭前两好树
诗：庭前两好树，/日夕欣相对。/风霜岁苦晚，/枝叶常葱翠。
诗：午眠背清阴，/露坐荫高盖。/东城桃李月，/车马倾闱阑。
诗：而我不出门，/依然伴憔悴。/荣华不随时，/寂寞幸相慰。
诗：君子固有常，/小人多变态。

# 绿竹堂独饮
题解：周本、丛刊本注云“明道二年”作。
诗：夏篁解箨阴加樛，/卧斋公退无喧嚣。/清和况复值佳月，/翠树好鸟鸣咬咬。
诗：芳尊有酒美可酌，/胡为欲饮先长谣？/人生暂别客秦楚，/尚欲泣泪相攀邀。
诗：况兹一诀乃永已，/独使幽梦恨蓬蒿。/忆予驱马别家去，/去时柳陌东风高。
诗：楚乡留滞一千里，/归来落尽李与桃。/残花不共一日看，/东风送哭声嗷嗷。
诗：洛池不见青春色，/白杨但有风萧萧。/姚黄魏紫开次第，/不觉成恨俱零凋。
诗：榴花最晚今又拆，/红绿点缀如裙腰。/年芳转新物转好，/逝者日与生期遥。
诗：予生本是少年气，/磋磨牙角争雄豪。/马迁班固洎歆向，/下笔点窜皆嘲嘈。
诗：客来共坐说今古，/纷纷落尽玉尘毛。/弯弓或拟射石虎，/又欲醉斩荆江蛟。
诗：自言刚气贮心腹，/何尔柔软为脂膏？/吾闻庄生善齐物，/平日吐论奇牙聱。
诗：忧从中来不自遗，/强叩瓦缶何谗谗。/伊人达者尚乃尔；/情之所锺况吾曹。
诗：愁填胸中若山积，/虽欲强饮如沃焦。/乃判自古英壮气，/不有此恨如何消。
注：自古英壮气：“判”下周本、丛刊本校云“疑”。
诗：又闻浮屠说生死，/灭没谓若梦幻泡。/前有万古后万世，/其中一世独切蝣。
诗：安得独洒一榻泪，/欲助河水增滔滔？/古来此事无可奈，/不如饮此尊中醪。

# 暇日雨后绿竹堂独居兼简府中诸僚
诗：新晴竹林茂，/日夕爱此君。/佳禽听翠树，/若与幽人亲。
诗：扫径绿苔静，/引流清派分。/开轩见远岫，/欹枕送归云。
诗：桐槿渐秋意，/琴觞怀友文。/浩然沧洲思，/日厌京洛尘。
诗：车骑方开府，/梁王多上宾。/平时罢飞檄，/行乐喜从军。
诗：骑省悼亡后，/漳滨多病身。/南窗若可傲，/方事陶潜巾。

# 江上弹琴
诗：江水深无声，/江云夜不明。/抱琴舟上弹，/栖鸟林中惊。
诗：游鱼为跳跃，/山风助清泠。/境寂听愈真，/弦舒心已平。
诗：用兹有道器，/寄此无景情。/经纬文章合，/谐和雌雄鸣。
注：谐和雌雄鸣：“谐”，周本、丛刊本校：“一作调”。”
诗：飒飒骤风雨，/隆隆隐雷霆。/无射变凛冽，/黄锺催发生。
诗：泳歌文王《雅》，/怨刺《离骚经》。/二《典》意澹薄，/三《盘》语丁宁。
诗：琴声虽可状，/琴意谁可听？

# 送白秀才西归
诗：白子来自西，/投我文与书。/升阶揖让席，/言气温且舒。
诗：万辙走声利，/独趋仁义涂。/仁义荒已久，/斤锄费耕除。
诗：吾常患力寡，/欣子好古徒。/终当竭其力，/划治为通衢。
诗：旗旄待天子，/安驾五路车。/尽驱天子民，/垂白歌其隅。
注：安驾五路车：“路”，周本、丛刊本作“辂”。
注：尽驱天子民：“子”，周本、丛刊本校云“疑”，原校云“疑作下”。
诗：子其从我游，/有志知何如？

# 巩县初见黄河
题解：周本、丛刊本注云“明道二年”作。
诗：河决三门合四水，/径流万里东输海。/巩洛之山夹而峙，/河来啮山作沙觜。
诗：山形迤逦若奔避，/河益汹汹怒而詈。/舟师弭檝不以帆，/顷刻奔过不及视。
诗：舞波渊旋投沙渚，/聚沫倏忽为平地。/下窥莫测浊且深，/痴龙怪鱼肆凭恃。
诗：我生居南不识河，/但见《禹贡》书之记。/其言河状钜且猛，/验河质书信皆是。
诗：昔者帝尧与帝舜，/有子朱商不堪嗣。/皇天意欲开禹圣，/以水病尧民以溃。
诗：尧愁下人瘦若腊，/众臣荐鲧帝曰试。/试之九载功不效，/遂殛羽山惭而毙。
诗：禹羞父罪哀且勤，/天始以书畀於姒。/书曰五行水润下，/禹得其术因而治。
诗：凿山疏流浚畎沧，/分擘枝派有条理。/万邦人贡九州宅，/生人始免生鳞尾。
注：生人：“生人”，周本、丛刊本卷后校：“一作人生”。”
诗：功深德大夏以家，/施及三代蒙其利。/江海淮济洎汉沔，/且不浩渺汪而大？
诗：收波卷怒畏威德，/万古不敢肆凶厉。/惟兹浊流不可律，/历自秦汉尤为害。
诗：崩坚决壅势益横，/斜跳旁出惟其意。/制之以力不以德，/驱民就溺财随弊。
诗：盖闻河源出昆仑，/其山上高大无际。/自高泻下若激箭，/一直一曲一千里。
诗：湍雄冲急乃进溢，/其势不得不然尔。/前岁河怒惊滑民，/浸漱洋洋淫不止。
注：洋洋淫不止：“淫”，周本、丛刊本校：“一作注”。”
诗：滑人奔走若锋骇，/河伯视之以为戏。/呀呀怒口缺若门，/日啖薪石万万计。
诗：明堂天子圣且神，/悼河不仁嗟曰喟。/河伯素顽不可令，/至诚一感惶且畏。
诗：引流辟易趋故道，/闭口不敢烦官吏。/遵涂率职直东下，/咫尺莫可离其次。
诗：尔来岁星行一周，/民牛饱刍邦羡费。/滑人居河饮河流，/耕河之懦浸河渍。
诗：嗟河改凶作民福，/呜呼明堂圣天子！

# 代书寄尹十一兄杨十六王三
诗：并辔登北原，/分首昭陵道。/秋风吹行衣，/落日下霜草。
诗：昔日憩巩县，/信马行苦早。/行行过任村，/遂历黄河奥。
诗：登高望河流，/汹汹若怒闹。/予生平居南，/但闻河浩渺。
诗：停鞍暂游目，/茫洋肆惊眺。/并河行数曲，/山坡亦萦绕。
诗：罂子与山口，/呀险乃天竈。/秤鈎真如鈎，/上下欲颠倒。
诗：虎牢吏当关，/讥问名已告。/荣阳夜闻雨，/故人留我笑。
诗：明朝已高尘，/靖车引旌纛。/传云送主丧，/窀穸诣坟兆。
诗：后乘皆辎饼，/轮毂相辉照。/辟易未及避，/庐儿已呵缴。
诗：午出郑东门，/下马仆射庙。/中牟去郑远，/记里十余堠。
诗：抵牟日已暮，/仆马困米稿。/渐望闾阖门，/崛若中天表。
诗：趋门争道入，/羁鞅不及掉。/浪境游九衢，/风埃叹何浩。
诗：京师天下聚，/奔走纷扰扰。/但闻街鼓喧，/忽忽夜复晓。
诗：追怀洛中俊，/已动思归操。/为别未期月，/音尘一何杳。
诗：因书写行役，/聊以为君导。

# 别圣俞
诗：车马古城隅，/喧喧分晓色。/行人念归涂，/居者徒惨恻。
诗：薄宦共羁旅，/论交喜金石。/荐以朋酒欢，/宁知岁月适。
诗：人事坐云变，/出处俄乖隔。/关山自兹始，/挥袂举轻策。
诗：岁暮寒云多，/野旷阴风积。/征蹄践严霜，/别酒临长陌。
诗：应念同时人，/独为未归客。

# 送刘秀才归河内
诗：落日古京门，/车马动行色。/河上多悲风，/山阳有归客。
诗：朽箧蠹虫篆，/遗文摹鸟迹。/言于有司知，/岂顾时人识。
注：言于有司知：“于”，周本、宋刊本、丛刊本作“干”。
诗：山陂岁始寒，/霰雪密已积。/还家宁久留，/方言事征轭。
