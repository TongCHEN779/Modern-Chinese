# 有赠余以端溪绿石枕与蕲州竹簟皆佳物也余既喜睡而得此二者不胜其乐奉呈原父舍人圣俞直讲
题解：题下宋刊本校：“碑本题作有赠予以端溪石枕蕲竹箪者因呈原父圣俞一首，。”又此诗周本、丛刊本注云“嘉佑四年”作。
诗：端溪琢出缺月样，/蕲州织成双水纹。/呼儿置枕展方簟，/赤日正午天无云。
注：水：周本、丛刊本校：“一作“锦”。”
诗：黄琉璃光绿玉润；/莹净冷滑无埃尘。/忆昨开封暂陈力，/屡乞残骸避烦剧。
注：埃：周本、丛刊本校：“一作“纤’。”
诗：圣君哀怜大臣闵，/察见衰病非虚饰。/犹蒙不使如罪去，/特许迁官还旧职。
注：哀怜：周本、丛刊本卷后校：“一作矜怜”。”
注：如：周本、丛刊本校：“一作加。”
诗：选材临事不堪用，/见利无惭惟苟得。/一从僦舍居城南，/官不坐曹门少客。
注：临事：周本、丛刊本卷后校：“一作任事’。”
注：舍：周本、丛刊本校：“一作屋”。”
注：门：周本、丛刊本校：“一作闲’。”
诗：自然唯与睡相宜，/以懒遭闲何惬适。/从来羸茶苦疲困，/况此烦歊正炎赫。
注：遭：周本、丛刊本校：“一作“投’。”
诗：少壮喘息人莫听，/中年鼻鼾尤恶声。/痴儿掩耳谓雷作，/灶妇惊窥疑釜鸣。
诗：苍蝇虮蠓任缘扑，/蠢书懒架抛纵横。/神昏气浊一如此，/口语思虑何由清。
注：蠢：周本、丛刊本校：“一诗’。”
诗：尝闻李白好饮酒欲与铛杓同生死我今好睡又过之，/身与二物为三尔。/江西得请在旦暮，/收拾归装从此始。
注：尝闻：周本、丛刊本卷后校：“一作昔时”。”又“好饮”，周本、丛刊本卷后校：“一作爱饮”。”
注：生死：周本、丛刊本校：“一作死生”。”
诗：终当卷簟携枕去，/筑室买田清颍尾。

# 夜闻风声有感奉呈原父舍人圣俞直讲
题解：周本、丛刊本注云“嘉佑四年”作：
诗：夜半群动息，/有风生树端。/飒然飘我衣，/起坐为长叹。
诗：苦暑君勿厌，/初凉君勿欢。/暑在物犹盛，/凉归岁将寒。
诗：清霜忽以飞，/零露亦溥溥。/霜露本无情，/岂肯私蕙兰。
注：以：周本、丛刊本卷后校：“一作已’。”
注：霜露：周本、丛刊本校：“一作“四时”。”
诗：不独草木尔，/君形安得完。/栉发变新白，/监容销故丹。
注：销：周本、丛刊本校：“一作无’。”
诗：风埃共侵迫，/心志亦摧残万占一飞隼，/两曜双跳丸。/扰扰贤与愚，
注：共：周本、丛刊本卷后校：“一作‘苦”。”
诗：流沙逐惊湍。/其来固如此，/独久知诚难。/服食为药俣，
诗：此言真不刊。/但当饮美酒，/何必被轻纨。

# 答梅圣俞大雨见寄
题解：周本、丛刊本注云“嘉佑二年”作。
诗：夕云若颓山，/夜雨如决渠。/俄然见青天，/焰焰升蟾蜍。
诗：倏忽阴气生，/四面如吹嘘。/狂雷走昏黑，/惊电照夔魆。
诗：搜寻起龙蛰，/卜击墓与墟。/雷声每轩轰，/雨势随疾徐。
诗：初若浩莫止，/俄收阗无余。/但挂千丈虹，/紫翠横空虚。
诗：顷刻百变态，/晦明谁卷舒。/岂知下土人，/水潦没襟裾。
诗：扰扰泥淖中，/无异鸭与猪。/嗟我来京师，/庇身无弊庐。
诗：闲坊僦古屋，/卑陋杂里闾。/邻注涌沟宝，/街流溢庭除。
诗：出门愁浩渺，/闭户恐为潴。/墙壁豁四达，/幸家无贮储。
诗：虾蟆鸣灶下，/老妇但欷歔。/九门绝来薪，/朝爨欲毁车。
诗：压溺委性命，/焉能顾图书。/乃知生尧时，/未免忧为鱼。
诗：梅子犹念我，/寄声忧我居。/慰我以新篇，/琅琅比琼琚。
注：琅琅：考异作“琅玕”。
诗：官闲行能薄，/补益愧空疏。/岁月行晚矣，/江湖盍归与，
诗：吾居传邮尔，/此计岂踌躇。

# 答圣俞白鹦鹉杂言
题解：周本、丛刊本注云“嘉佑四年”作。
诗：忆昨滁山之人赠我玉兔子，/粤明年春玉兔死。/日阳昼出月夜明，/世言兔子望月生。
诗：谓此莹然而白者，/譬夫水之为雪而为冰，/皆得一阴凝结之纯精。/常恨处非大荒穷北极寒之旷野，
诗：养违其性夭厥龄。/岂知火维地荒绝，/涨海连天沸天热。/黄冠黑距人语言，
注：天沸天热：此句中后一“天”字，周本、丛刊本校：“一作火’，“一作炎’。”
诗：有鸟玉衣尤皎洁。/乃知物生天地中，/万殊难以一理通。/海中洲岛穷人迹，
诗：来市广州才八国。/其间注辇来最稀，/此鸟何年随海舶？/谁能遍历海上峰，
注：稀：周本、丛刊本校：“一作远’。”
诗：万怪千奇安可极。/兔生明月月在天，/玉不能久人间。/况尔来从炎瘴地，
诗：目识中州霜雪寒。/渴虽有饮饥有啄，/羁绁终知非尔乐。/天高海阔路茫茫，
注：路：周本、丛刊本校：“一作终’。”
诗：嗟尔身微羽毛弱。/尔能识路知所归，/吾欲开笼纵尔飞。/俾尔归诧宛陵诗，/此老诗名闻四夷。

# 清明前一日韩子华以靖节斜川诗见招游李园既归遂苦风雨三日不能出穷坐一室家人辈倒残壶得酒数杯泥深道路无人行去市又远索于筐筥得枯鱼干𫚥数种强饮疾醉昏然便寐既觉索然因书所见奉呈圣俞
题解：题中“酒”上考异校：二有浊’字。”周本、丛刊本卷后校：“得酒'。一作“得浊酒”。”又“官”周本、丛刊本校：“一作箧'。”此诗周本、丛刊本注云“嘉佑四年”作。
诗：少年喜追随，/老大厌谊哗。/惭愧二三子，/邀我行看花。
诗：花开岂不好，/时节亦云嘉。/因病既不饮，/众欢独我嗟。
注：我：原作“成”，周本、丛刊本校云“成”一作“我”，据改。
诗：管弦暂过耳，/风雨愁还家。/三日不出门，/堆肿类寒鸦。
诗：妻儿强我饮，/钉饵果与瓜。/浊酒倾残壶，/枯鱼杂干𫚥。
诗：小婢宠禄不知报，/鬓毛今已华。/有田清颍间，/尚可事桑麻。
诗：安得一黄犊，/幅巾驾柴车。

# 奉答原甫见过宠示之作
题解：题中“原甫”，考异、李本作“原父”。又此诗周本、丛刊本注云“嘉佑五年”作。
诗：不作流水声，/行将二十年。/吾生少贱足忧患，/忆昔有罪初南迁。
诗：飞帆洞庭入白浪，/堕泪三峡听流泉。/援琴写得入此曲，/聊以自慰穷山间。
诗：中间永阳亦如此，/醉卧幽谷听潺湲。/自从还朝恋荣禄，/不觉鬓发俱凋残。
注：荣：周本、丛刊本校：“一作宠’。”
诗：耳衰听重手渐颤，/自惜指法将谁传？/偶欣日色曝书画，/试拂尘埃张断弦。
诗：娇儿痴女绕翁膝，/争欲强翁聊一弹。/紫微阁老适我过，/爱我指下声泠然。
诗：戏君此是伯牙曲，/自古常叹知音难。/君虽不能琴，/能得琴意斯为贤。
注：戏：周本、丛刊本校：“一作语”。”
注：琴：周本、丛刊本校：“一作其”。”
诗：自非乐道甘寂寞，/谁肯顾我相留连。/兴阑束带索马去，/却锁尘匣包青毡。

# 会饮圣俞家有作兼呈原父景仁圣从
题解：周本、丛刊本注云“嘉佑四年”作。
诗：忆昨九日访君时，/正见阶前两丛菊。/爱之欲绕行百匝，/庭下不能容我足。
诗：折花却坐时嗅之，/已醉还家手犹馥。/今朝我复到君家，/两菊阶前犹对束。
诗：枯茎槁叶苦风霜，/无复满丛金间绿。/京师谁家不种花，/碧砌朱阑敞华屋。
诗：奈何来对两枯株，/共坐穷檐何局促。/诗翁文字发天葩，/岂比青红凡草木。
诗：凡草开花数日间，/天葩无根长在目。/遂令我每饮君家，/不觉长瓶卧墙曲。
诗：坐中年少皆贤豪，/莫怪我今双鬓秃。/须知朱颜不可恃，/有酒当欢且相属。
注：欢：周本、丛刊本校：“一作饮”。”

# 依韵奉酬圣俞二十五兄见赠之作
题解：周本、丛刊本注云“嘉佑四年”作。
诗：与君结交游，/我最先众人。/我少既多难，/君家常苦贫。
诗：今为两衰翁，/发白面亦皱。/念君怀中玉，/不及市上珉。
诗：珉贱易为价，/玉弃久埋尘。/惟能吐文章，/白虹射星辰。
诗：幸同居京城，/远不隔重闽。/朝罢二三公，/随我如鱼鳞。
诗：君闻我来喜，/置酒留逡巡。/不待主人请，/白脱头上巾。
诗：欢情虽渐鲜，/老意益相亲。/穷达何足道，/古来兹理均。

# 小饮坐中赠别祖择之赴陕府
题解：周本、丛刊本题下有“无择”字。又此诗周本、丛刊本注云“嘉佑四年”作。
诗：明日君当千里行，/今朝始共一尊酒。/岂惟明日难重持，/试思此会何尝有。
诗：京师九衢十二门，/车马煌煌事奔走。/花开谁得屡帽遇，/盏到莫辞频举手。
注：遇：丛刊本作“过”。
诗：欢情落寞酒量减，/置我不须论老朽，/奈何公等气方豪，/云梦正当吞八九。
诗：择之名声重当世，/少也多奇晚方偶。/西州政事蔼风谣，/右掖文章焕星斗。
诗：待君归日我何为，/手把锄犁汝阴叟。

# 奉答圣俞达头鱼之作
题解：周本、丛刊本注云“嘉佑三年”作。
诗：吾闻海之大，/物类无穷极。/虫𫚥浅水间，/赢蚬如山积，
诗：毛鱼与鹿角，/一龠数千百。/收藏各有时，/嗜好无南北。
注：龠：周本、丛刊本校：“一作拾”。”
诗：其微既若斯，/其大行莫测。/波涛浩渺中，/岛屿生顷刻。
注：微：周本、丛刊本校：“一作小’。”
注：大行莫测：周本、丛刊本校：“一作其大固’，一作大者固”。”
诗：俄而没不见，/始悟出背脊。/有时随潮来，/暴死疑遭谪。
注：始悟：周本、丛刊本校：“一作久始”。”
诗：海人相呼集，/刀锯争剖析。/骨节骇专车，/须芒侔剑戟。
注：剖：周本、丛刊本校：“一作“斫”。”
注：芒：周本、丛刊本校：“一作牙”。”
诗：腥闻数十里，/余臭久乃息。/始知百川归，/固有含容德。
诗：潜奇与秘宝，/万状不一识。/嗟彼达头微，/谁传到京国。
注：状：用本、丛刊本校：“一作物”。”
注：谁传到：用本、丛刊本校：“一作“偶传到”一作偶传人”。”
诗：干枯少滋味，/治平声洗费炮炙。/聊兹知异物，/岂足荐佳客。
诗：一旦辱君诗，/虚名从此得。/京师人不摄此鱼，/沧州向防御见寄，
注：辱：周本、丛刊本校：“一作“得”。”
诗：以分圣俞，/辱以持答。

# 送刁纺推官归润州

诗：彼在吾往从，/彼去吾亦退。/与人交若此，/可以言节概。

# 夜坐弹琴有感二首呈圣俞
诗：吾爱陶靖节，/有琴常自随。/无弦人莫听，/此乐有谁知。
诗：君子笃自信，/众人喜随时。/其中苟有得，/外物竟何为。
诗：寄谢伯牙子，/何须钟子期。
诗：锺子忽已死，/伯牙其已乎。/绝弦谢世人，/知音从此无。
诗：瓠巴鱼自跃，/此事见于书。/师旷尝一鼓，/群鹤舞空虚。
注：见于书：周本、丛刊本卷后校：“一作载诸书”。”
诗：吾恐二三说，/其言皆遇欤。/不然古今人，/愚智邈已殊。
诗：奈何人有耳，/不及鸟与鱼。

# 二月雪
题解：周本、丛刊本注云“嘉佑五年”作。
诗：宁伤桃李花，/无损杞与菊。/杞菊吾所嗜，/惟恐食不足。
注：伤：周本、丛刊本卷后校：“一作“损”。”
诗：花开少年事，/不入老夫目。/老夫无远虑，/所急在口腹。

# 归田四时乐春夏二首秋冬二首命圣俞分作
题解：周本、丛刊本注云“嘉佑三年”作。
诗：春风二月三月时，/农夫在田居者稀。/新阳晴暖动膏脉，/野水泛滟生光辉，
诗：鸣鸠聒聒屋上啄，/布谷翩翩桑下飞。/碧山远映丹杏发，/青草暖眠黄犊肥。
诗：田家此乐知者谁，/吾独知之胡不归？/吾已买田清颖上，/更欲临流作钓矶。
诗：南风原头吹百草，/草木丛深茅舍小，/麦穗初齐稚子娇，/桑叶正肥蚕食刨。
诗：老翁但喜岁年熟，/饷妇安知时节好。/野棠梨密啼晚莺，/海石榴红啭山鸟。
注：晚：周本、丛刊本卷后校：“一作晓”。”
诗：田家此乐知者谁，/我独知之归不早。/乞身当及强健时，/顾我蹉跎已衰老。

# 明妃曲和王介甫作
题解：此诗周本、丛刊本注云“嘉佑四年”作。
诗：胡人以鞍马为家，/射猎为俗。/泉甘草美无常处，。/鸟惊兽骇争驰逐。
注：无常处：周本、丛刊本卷后校：“石本作随山川’。”
诗：谁将漠女嫁胡儿，/风沙无情貌如玉。/身行不遇中国人，/马上自作思归曲。
诗：推手为琵却手琶，/胡人共听亦咨嗟。/玉颜流落死天涯，/琵琶却传来汉家。
注：琵琶：周本、丛刊本校：“一作此曲”。”
诗：汉宫争按新声谱，/遗恨已深声更苦。/纤纤女手生洞房，/学得琵琶不下堂。
注：宫：周本、丛刊本卷后校：“一作家”。”
诗：不识黄云出塞路，/岂知此声能断肠！

# 盆池
题解：周本、丛刊本注云“嘉佑四年”作。
诗：西江之水何悠哉，/经历赣石险且回。/余波拗怒犹涵去澹，/奔涛击浪常喧泜。
注：犹：周本、丛刊本校：“一作“独”。”
注：击浪：考异作“惊浪”。
诗：有时夜上滕王阁，/月照净练无纤埃。/杨澜左里在其北，/无风浪起传古来。
注：练：周本、丛刊本校：“一作“绿’。”
诗：老蛟深处厌窟穴，/蛇身微行见者猜。/呼龙沥酒未及祝，/五色粲烂高崔嵬。
诗：忽然远引千丈去，/百里水面中分开。/收踪灭迹莫知处，/但有雨雹随风雷。
诗：干奇万变聊一戏，/且顾溺死为可哀。/轻人之命若蝼蚁，/不止山岳将倾颓。
注：死为可哀：周本、丛刊本校：“一作肯”。”
注：轻人：周本、丛刊本卷后校：“石本作奈何’。”
诗：此外鱼𫚥何足道，/厌饫但觉腥盘杯。/壮哉岂不快耳目，/胡为守此空墙限。
诗：陶盆斗水仍下漏，/四岸久雨生莓苔。/游鱼拨拨不盈寸，/泥潜日炙愁暴鳃。
注：拨拨：考异作“泼泼”
诗：鱼诚不幸此局促，/我能决去反徘徊。
注：鱼诚不幸此：周本、丛刊本卷后校：“石本作鱼生不幸遭”。”
注：能决去反：周本、丛刊本卷后校：“石本作可决去犹'。”

# 再和明妃曲
题解：《文鉴》题作“明妃曲”。又此诗周本、丛刊本注云“嘉佑四年”作。
诗：汉宫有佳人。/天子初未识。/一朝随汉使，/远嫁单于国。
注：佳：周本、丛刊本校：“一作美’。”
诗：绝色天下无，/一失难再得。/虽能杀画工，/于事竟何益。
诗：耳目所及尚如此，/万里安能制夷狄！/汉计诚已拙，/女色难自夸。
注：女：周本、丛刊本校：“一作美'。”
诗：明妃去时泪，/洒向枝上花。/狂风日暮起，/飘泊落谁家。
诗：红颜胜人多薄命，/莫怨春风当自嗟。

# 奉送原甫侍读出守永兴
题解：题中“原甫”二字，考异、李本作“原父”。题下周本、丛刊本校：“一作奉送永兴安抚刘侍读”。”又此诗周本、丛刊本注云“嘉佑五年”作。
诗：酌君以荆州鱼枕之蕉，/赠君以宣城鼠须之管。/酒如长虹饮沧海，/笔若骏马驰平坂。
诗：爱君尚少力方豪，/嗟我久衰欢渐鲜。/文章惊世知名早，/意气论交相得晚。
注：尚：周本：丛刊本校：“一作年”。”
注：知：周本、丛刊本校：“一作“闻”。”
诗：鱼枕蕉，/一举十分当覆盏；/鼠须管，/为物虽微情不浅。
诗：新诗醉墨时一挥，/别后寄我无辞远。

# 哭圣俞
题解：周本、丛刊本注云“嘉佑五年”作。
诗：昔逢诗老伊水头，/青衫白马渡伊流。/滩声八节响石楼，/坐中辞气凌清秋。
注：清：周本、丛刊本校：“一作“高”。”
诗：一饮百盏不言休，/酒酣思逸语更遒。/河南丞相称贤侯，/后车日载枚与邹。
诗：我年最少力方优，/明珠白璧相报投。/诗成希深拥鼻讴，/师鲁卷舌藏戈矛。
诗：三十年间如转眸，/屈指十九归山丘。/凋零所余身百忧，/晚登玉墀侍珠旒。
诗：诗老苔盐太学愁，/乖离会合谓无由，/此会天幸非人谋。/颔须已白齿根浮，
诗：子年加我貌则不。/欢犹可强闲屡偷，/不觉岁月成淹留。/文章落笔动九州，
诗：釜甑过午无馈馏。/良时易失不早收，/箧椟瓦砾遣琳璆荐贤转石古所尤，/此事有职非吾羞。
注：椟：周本、丛刊本校：“一作“柜”。”
诗：命也难知理莫求，/名声赫赫掩诸幽。/翩然素旐归一舟，/送子有泪流如沟。
