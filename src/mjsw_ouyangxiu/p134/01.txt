# 南歌子一首
题解：《乐府雅词》此词牌下注云：“《草堂》云僧仲殊作，实误。”
诗：凤髻金泥带，龙纹玉掌梳。/走来窗下笑相扶。/爱道画眉深浅、入时无。/弄笔偎人久，描花试手初。/等闲妨了绣功夫。/笑问双鸳鸯字、怎生书。

# 御街行一首
题解：此词又见吴讷本、侯文灿本“张子野词”。
诗：夭非华艳轻非雾，来夜半，天明去。/来如春梦不多时，去似朝云何处。/乳鸡酒燕，落星沉月，统统城头鼓。/参差渐辨西池树，朱阁斜欹户。/录苔深径少人行，苔上屐痕无数。/遗香余粉，剩衾闲枕，天把多情赋。

# 桃源忆故人二首
题解：“桃源忆故人”，周本、丛刊本、影宋本《近体乐府》、《六一词》校：“一名“虞美人影’。”
诗：梅梢弄粉香犹嫩，欲寄江南春信。/别后寸肠萦损，说与伊争稳。/小炉独守寒灰烬，忍泪低头画尽，眉上万重新恨，竟日无人问。
注：欲寄江南春信：“春”，周本、影宋本《近体乐府》，丛刊本校：“一作芳”。”
注：别后寸肠萦损：“萦”，周本、影宋本《近体乐府》、丛刊本校：“一作愁”。”
注：忍泪低头画尽：“低头”，《乐府雅词》作“无言”。
诗：莺愁燕苦春归去，寂寂花飘红雨。/碧草录杨歧路，况是长亭暮。/少年行客情难诉，泣对东风无语。/目断两三烟树，翠隔江淹浦。

# 临江仙二首
诗：柳外轻雷池上雨，雨声滴碎荷声。/小楼西角断虹明。/阑干倚处，待得月1040。/华生。/燕子飞来窥画栋，玉钩垂下帘旌。/凉波不动簟纹平。/水精双枕，傍有堕横。
注：柳外轻雷池上雨：“柳”，《醉翁琴趣外篇》作“池”。
注：水精双枕：“精”，《乐府雅词》作“晶”。
诗：记得金銮同唱第，春风上国繁华。/如今薄宦老天涯。/十年歧路，空负曲江花。/闻说阆山通阆苑，楼高不见君家。/孤城寒日等闲斜。/离愁难尽，红树远连霞。

# 圣无忧一首
诗：世路风波险，十年一别须臾。/人生聚散长如此，相见且欢娱。/好酒能消光景，春风不染髭须。/为公一醉花前倒，红袖莫来扶。

# 浪淘沙五首
诗：把酒祝东风，且共从容。/垂杨紫陌洛城东。/总是当时携手处，游遍芳丛。/聚散苦忽忽，此恨无穷。/今年花胜去年红。/可惜明年花更好，知与谁同。
注：可惜明年花更好：“可惜”，周本、丛刊本、影宋本《近体乐府》卷后校：“一作料得”。”
诗：花外倒金翘，饮散无惨。/柔桑蔽日柳迷条。/此地年时曾一醉，还是春朝。/今日举轻桡，帆影飘飘。/长亭回首短亭遥。/过尽长亭人更远，特地魂销。
原：三
诗：五岭麦秋残，荔子初丹。/绛纱囊裹水晶丸。/可惜天教生处远，不近长安。/往事忆开元，妃子偏怜。/一从魂散马嵬关。/只有红尘无驿使，满眼骊山。
注：五岭麦秋残：“残”，周本、丛刊本卷后校：“一作寒”。”按“残”是。
注：绛纱囊裹水晶丸：“裹”，周本、丛刊本卷后校：“一作裹”。”
注：一从魂散马嵬关：“一从”，周本、丛刊本卷后校：“一作自从'。”又“关”，上引二本校：“一作前”。”
原：四
诗：万恨苦绵绵，旧约前欢。/桃花溪畔柳阴间。/几度日高春睡重，绣户深关。/楼外夕阳闲，独自凭阑。/一重水隔一重山。/水阔山高人不见，有泪无言。
原：五
诗：今日北池游，漾漾轻舟。/波光潋艳柳条柔。/如此春来春又去，白了人头。/好妓好歌喉，不醉难休。/劝君满满酌金瓯。/纵使花时常病酒，也是风流。

# 定风波六首
诗：把酒花前欲问他，对花何吝醉颜酷。/春到几人能烂赏，何况，无情风雨等闲多。/艳树香丛都几许，朝暮，惜红愁粉奈情何。/好是金船浮玉浪，相向，十分深送一声歌。
注：对花何吝醉颜酷：“吝”，周本、丛刊本校：“一作惜。”《醉翁琴趣外篇》作“惜”。
注：好是金船浮玉浪：“船”，《醉翁琴趣外篇》作“杯”。
诗：把酒花前欲问伊，忍嫌金盏负春时。/红艳不能旬日看，宜算，须知开谢只相随。/蝶去蝶来犹解恋，难见，回头还是度年期。/莫候饮阑花已尽，方信，无人堪与补残枝。
原：三
诗：把酒花前欲问公，对花何事诉金锺。/为问去年春甚处，虚度，莺声撩乱一场空。/今岁春来须爱惜，难得，须知花面不长红。/待得酒醒君不见，千片，不随泫水即随风。
注：把酒花前欲问公：“公”，《醉翁琴趣外篇》作“翁”。
原：四
诗：把酒花前欲问君，世间何计可留春。/纵使青春留得住，虚语，无情花对有情人。/任是好花须落去，自古，红颜能得几时新。/暗想浮生何事好，唯有，清歌一曲倒金尊。
原：五
诗：过尽韶华不可添，小楼红日下层檐。/春睡觉来情绪恶，寂寞，杨花缭乱拂珠帘。/早是闲愁依旧在，无奈，那堪更被宿醒兼。/把酒送春惆怅甚，长恁，年年三月病厌厌。
注：过尽韶华不可添：“华”，《乐府雅词》作“光”。
原：六
诗：对酒追欢莫负春，春光归去可饶人。/昨日红芳今录树，已暮，残花飞絮两纷纷。/粉面丽姝歌窈窕，清妙，尊前信任醉醺醺。/不是狂心贪燕乐，自觉，年来白发满头新。
注：春光归去可饶人：“可”，《醉翁琴趣外篇》作“肯”。

# 蓦山溪一首
诗：新正初破，三五银蟾满。/纤手染香汆，剪红莲、满城开遍。/楼台上下，歌管咽春风，驾香轮，停宝马，只待金乌晚。/帝城今夜，汆绮谁为伴。/应卜紫姑神，问归期、相思望断。/天涯情绪，对酒且开颜，春宵短，春寒浅，莫待金杯暖。
注：歌管咽春风：“歌管”，周本、影宋本《近体乐府》、丛刊本卷后校：“一作歌吹”。”

# 浣溪沙九首
题解：《浣溪沙》九首，其中第二首“堤上游人逐画船”，《草堂诗余隽》卷二误作黄庭坚词。第五首“青杏园林煮酒香”，又见晏殊《珠玉词》又误入吴文英《梦窗词集》，《类编草堂诗余》又误作秦观词。
诗：云曳香绵彩柱高，绛旗风刮出花梢。/一梭红带往来抛。/束素美人羞不打，却嫌裙慢褪纤腰。/日斜深院影空摇。
诗：堤上游人逐画船。/拍堤春水四垂天。/录杨楼外出秋千。/白发戴花君莫笑；六么催拍盏频传。/人生何处似尊前。
注：录杨楼外出秋千：“楼”，周本、丛刊本卷后校：“一作梢”。”
原：三
诗：湖上朱桥响画轮。/溶溶春水浸春云。/碧瑠璃滑净无尘。/当路游丝萦醉客，隔花啼鸟唤行人。/日斜归去奈何春。
注：碧瑠璃滑净无尘：“滑”，影宋本《近体乐府》校：“一作影”。”
原：四
诗：叶底青青杏子垂。/枝头薄薄柳绵飞。/日高深院晚莺啼。/堪恨风流成薄幸，断无消息道归期。/托腮无语翠眉低。
原：五
诗：青杏园林煮酒香，佳人初着薄汆裳。/柳丝摇曳燕飞忙。/乍雨乍晴花自落，闲愁闲闷书偏长。/为谁消瘦损容光。
注：青杏园林煮酒香：“林”，《全芳备祖》作“中”。
注：佳人初着薄汆裳：“着”，周本、丛刊本卷后校：“一作试”。《珠玉词》作“试”。
注：柳丝摇曳燕飞忙：“摇曳”，《珠玉词》作“无力”。
注：闲愁闲闷书偏长：“书”，《乐府雅词》作“日”。
原：六
诗：红粉佳人白玉杯。/木兰船稳棹歌催。/录荷风裹笑声来。/细雨轻烟笼草树，斜桥曲水绕楼台。/夕阳高处画屏开。
原：七
诗：翠袖娇鬟舞《石州》。/两行红粉一时羞。/新声难逐管弦愁。/白发主人年未老，清时贤相望偏优。/一尊风月为公留。
原：八
诗：灯烬垂花月似霜，薄帘映月两交光。/酒醺红粉自生香。/双手舞余拖翠袖，一声歌已酬金觞。/休回娇眼断人肠。
原：九
诗：十载相逢酒一厄。/故人才见便开眉。/老来游旧更同谁。/浮世歌欢真易失，宦途离合信难期。/尊前莫惜醉如泥。

# 御带花一首
题解：“御带花”词牌，《醉翁琴趣外篇》作“御戴花”。
诗：青春何处风光好，帝里偏爱元夕。/万重缯彩，构一屏峰岭，半空金碧。/宝檠银釭，汆绛幕龙虎腾掷。/沙堤远，雕轮绣毂，争走五王宅。/雍容熙熙作书，会乐府神姬，海洞仙客。/拽香摇翠，称执手行歌，锦街天陌。/月淡寒轻，渐向晓，漏声寂寂。/当年少狂心未已，不醉怎归得。
注：构一屏峰岭：“岭”，《醉翁琴趣外篇》作“顶”。

# 虞美人一首。
题解：此词又见杜安世《寿域词》。
诗：炉香书永龙烟白，风动金鸾额。/画屏寒掩小山川，睡容初起枕痕圆，坠花钿。/楼高不及烟霄半，望尽相思眼。/艳阳刚爱挫愁人，故生芳草碧连云，怨王孙。

# 鹤冲天一首
诗：梅谢粉，柳拖金，香满旧园林。/养花天气半晴阴，花好却愁深。/花无数，愁无数，花好却愁春去。/戴花持酒祝东风，千万莫忽忽。

# 夜行船二首
诗：忆昔西都欢纵，自别后有谁能共。/伊川山水洛川花，细寻思旧游如梦。/今日相逢情愈重，愁闻唱画楼钟动。/白发天涯逢此景，倒金尊殊谁相送。/满眼东风飞絮，催行色短亭春暮。/落花流水草连云，看看是断肠南浦。/檀板未终人去去，扁舟在录杨深处。/手把金尊难为别，更那听乱莺疏雨。
注：落花流水草连云：“云”，影宋本《近体乐府》校：“一作天”。”
注：檀板未终人去去：“人去去”，周本、丛刊本、影宋本《近体乐府》卷后校：“一作人又去”。”

# 洛阳春一首
诗：红纱未晓黄鹏语，蕙炉销兰炷。/锦屏汆幕护春寒，昨夜三更雨。/绣帘闲倚吹轻絮，敛眉山无绪。/看花拭泪向归鸿，问来处逢郎否？

# 一丛花一首
题解：周本、宋刊本、影宋本《近体乐府》、丛刊本于词牌下注云：“此篇世传张先子野词。”《全宋词》按云：据《月河所闻集》、《画墁录》、《过庭录》，此词实为张先作。
诗：伤春怀远几时穷，无物似情浓。/离愁正恁牵丝乱，更南陌飞絮蒙蒙。/归骑渐遥，征尘不断，何处认郎踪。/双鸳池沼水溶溶，南北小桥通。/梯横画合黄昏后，又还是新月帘拢。/沉恨细思，不如桃李，还解嫁春风。

# 雨中花一首
诗：千古都门行路，能使离歌声苦。/送尽行人，花残春晚，又到君东去。/醉藉落花吹暖絮，多少曲堤芳树。/且携手留连，良辰美景，留作相思处。
注：又到君东去：“到”原作“别”，据周本、宋刊本及影宋本、明刻《近体乐府》改。

# 千秋岁一首
题解：宋刊本、影宋本《近体乐府》于词牌下注云：“《蓝畹》作张子野词。”《乐府雅词》卷上，亦录为张先词。《全宋词》按云此词为张先作。
诗：数声题鸠，又报芳菲歇。/惜春更把残红折。/雨轻风色暴，梅子青时节。/永丰柳，无人尽日花飞雪。/莫把丝弦拨，怨极弦能说。/天不老，情难绝。/心似双丝网，终有千千结。/夜过也，东窗未白残灯灭。

# 越溪春一首
诗：三月十三寒食日，春色遍天涯。/越溪阆苑繁华地，傍禁垣、珠翠烟霞。/红粉墙头，秋千影裹，临水人家。/归来晚驻香车。/银箭透窗纱，有时三点两点雨霁，朱门柳细风斜。/沉麝不烧金鸭冷，笼月照梨花。

# 贺圣朝影一首
诗：白雪梨花红粉桃，露华高。/垂杨慢舞录丝绦，草如袍。/风过小池轻浪起，似江皋。/千金莫惜买香醪，且陶陶。

# 洞天春一首
诗：莺啼录树声早，槛外残红未扫。/露点真珠遍芳草，正帘帏清晓。/秋千宅院悄悄。/又是清明遇了。/燕蝶轻狂，柳丝撩乱，春心多少。

# 忆汉月一首
诗：红艳几枝轻袅，新被东风开了。/倚烟啼露为谁娇，故惹蝶怜蜂恼。/多情游赏处，留峦向录丛千绕。/酒阑欢罢不成归，肠断月斜春老。

# 清平乐二首
题解：《清平乐》第一首“雨晴烟晚”，又见《阳春集》，《全宋词》云为冯延巳词。
诗：雨晴烟晚，录水新池满。/双燕飞来垂柳院，小阁画帘高卷。/黄昏独倚朱阑，西南初月眉弯。/砌下落花风起，汆衣特地春寒。
诗：小庭春老，碧砌红萱草。/长忆小阑闲共绕，携手缘丛含笑。/别来音信全乖，旧期前事堪猜。/门掩日斜人静，落花愁点青苔。

# 应天长三首
诗：一弯初月临鸾镜，云鬓凤钗慵不整。/珠帘净，重楼迥，惆怅落花风不定。/录烟低柳径，何处辘轳金井。/昨夜更阑酒醒，春愁胜却病。
诗：石城山下桃花绽，宿雨初晴云未散。/南去棹，北飞雁，水阔山遥肠欲断。/倚楼情绪懒，惆怅春心无限。/燕度蒹葭风晚，欲归愁满面。
注：燕度蒹葭风晚：“燕度”，周本、丛刊本卷后校：“一作忍泪”。”
原：三
诗：录槐阴裹黄莺语，深院无人日正午。/绣帘垂，金凤舞，寂寞小屏香一炷。/碧云凝合处，空役梦魂来去。/昨夜录窗风雨，问君知也否[一《应天长》第一首“一弯初月临鸾镜”，《全宋词》云为南唐李璟作，见《南唐二主词》所录。/第二首“石城山下桃花绽”，又见《阳春集》，《全宋词》云为冯延巳词。/第三首“录槐阴裹黄莺语”，又见《花间集》，署韦庄作，其中词句多有不同。/“一弯初月”，周本、丛刊本卷后校：“一作一钩新月”。”/“山”，周本、丛刊本卷后校：“一作天’。”
注：深院无人日正午：“日正午”；《花间集》作“春书午”。
注：绣帘垂：“绣”，《花间集》作“画”。
注：寂寞小屏香一炷：“小屏”，《花间集》作“绣屏”。

# 圣节五方老人祝寿文
题解：《乐语》七首，诸本载《近体乐府》卷一之首。按其第七首《西湖念语》，当是欧阳修晚年退居颖州西湖于聚会时所作，观其文意，似置于《诗余》卷一《采桑子》前为是。
原：东方老人
原：但某太山老叟，东海真仙。溜穿石而曾究初终，松避雨而备知岁月。羲氏定三百六日，尝守寅宾之官；夷吾纪七十二君，尽睹登封之事。遇安期而遗枣，笑方朔之偷桃。风入律而来自岩前，斗指春而光临洞口。昔汉武帝尝怀三岛之胜游，有羡门生欲谒巨公于昭代。今则紫庭降圣，华渚开祥，远离朝日之方，来展望云之恳。千八百国咸归至治之风，亿万斯年共祷无疆之寿。遥望天庭，敢进祝圣之颂：
注：溜穿石而曾究初终：“溜”上周本、丛刊本校：“一有一”字。”
注：松避雨而备知岁月：“松”上周本、丛刊本校：“一有五”字。”
诗：东海蓬莱第一仙，/遥瞻西北祝尧天。/愿皇长似东君寿，/与物为春亿万年。
原：西方老人
原：但某秦川故老，华岳幽人。询仙掌之遗踪，咸知始末；恋莲峰之绝顶，不记岁时。漱流玉乳之泉，枕石云阳之洞。消遥物外，笑傲林间。奉王母之蟠桃，尝延汉帝；指老聃之仙李，永佑康基。掌中五色之丸，世上千年之寿。欣逢圣代，来至尘寰。当洪河澄九曲之时，是甲观诞一人之日。祥麟游于泰时，天马来于大宛。景星见而朱草生，瑞露九而赤乌集。既遇无为之化。宜歌有道之君。是以驾青牛而度函关，指丹凤而趋魏阙。唯愿庆源流远，齐河海以无穷；睿算绵长，等乾坤而不老。遥望天庭，敢进祝圣之颂：
诗：华岳峰头万叶莲，/开花今古世相传。/愿皇长似莲峰久，/结实盘根不记年。
原：中央老人
原：但某栖心嵩极，振迹伊川，年高而可等松椿，气粹而尝飧芝术。洞裹之烟霞不老，壶中之日月偏长。当圣主之盛时，居天心之奥壤。但见璇玑运而寒暑正，土圭测而阴阳和。冠带被于百蛮，玉帛来于万国。龙在沼而麟在薮，河出图而洛出书。民跻寿域之中，俗乐春台之上。今则尧眉诞秀，舜目开祥。远离王屋之间，来入帝畿之内。仰瞻天表，莫非岳降之神；上祝皇图，岂止山呼之岁。遥望天庭，敢进祝圣之颂：
诗：嵩高维岳镇中天，/王气盘基降寿仙。/准愿吾皇等嵩岳，/三灵齐祝万斯年。
注：三灵齐祝万斯年：“祝”，周本、丛刊本校：“一作寿”。”
原：南方老人
原：但某托迹炎洲，游神衡岳。非海滨之野叟，乃星极之老人。当火德为治之朝，是离明继照之日。里社鸣而圣人出，泰阶正而王道平。百蛮向风，重译来贡。屡睹丰年之上瑞，故知百姓之欢心。鼓腹而歌，治世之音安以乐；曲肱而枕，化国之日舒以长。斯可谓唐、虞之民，又岂止成、康之俗！今则流虹诞圣，绕电开祥。来趋北阙之前，上祝南山之永。云翔雾集，既余仙籍之班；地久天长，以祷皇家之祚。遥望天庭，敢进祝圣之颂：
诗：南极星中一老人，/南山为寿祝吾君，/愿君永奏南薰曲，/当使淳音万国闻。
原：北方老人
原：但某修真北岳，常倾葵藿之心；混俗幽都，不避草茅之迹。潜神自得，味道为娱。易水歌风，曾识荆轲于往岁；燕山勒石，亲逢窦宪于当年。仙家之景物常春，人世之光阴易老。华表之鹤未久还来，莲叶之龟于时屡见。但处积阴之境，每输就日之诚。望干吕之青云，庆流虹于华渚。当万域来王之际，是千龄诞圣之初。是以历上汉而朝宗，叩天阎而祝颂。惟愿庆基不朽，永齐金石之坚，宝祚无疆，更等山河之固。遥望天庭，敢进祝圣之颂：
诗：北岳神仙九转丹，/特来北阙献君前。/愿将北极齐君寿，/万国陶陶共戴天。

# 会老堂致语
题解：题下周本、丛刊本注：“熙宁壬子，赵康靖公自南京访公于颖，时吕正献公为守。”
原：某闻安车以适四方，礼典虽存于往制；命驾而之千里，交情罕见于今人。伏惟致政少师一德元臣，三朝宿望。挺立始终之节，从容进退之宜。谓青衫早并于俊游，白首各谐于归老。已释轩裳之累，却寻鸡黍之期。远无惮于川涂，信不渝于风雨。幸会北堂之学士，方为东道之主人。遂令颖水之滨，复见德星之聚。里闾拭目，觉陋巷以生光；风义耸闻，为一时之盛事。敢陈口号，上赞清欢：
诗：欲知盛集继荀陈，/请看当筵主与宾。/金马玉堂三学士，/清风明月两闲人。/红芳已尽莺犹啭，/青杏初尝酒正醇。/美景难并良会少，/乘欢举白莫辞频。

# 西湖念语
原：昔者王子猷之爱竹，造门不问于主人；陶渊明之卧与，遇酒便留于道士况西湖之胜概，擅东颍之佳名。虽美景良辰，固多于高会；而清风明月，幸属于闲人。并游或结于良朋，乘兴有时而独往。鸣蛙暂听，安问属官而属私；，曲水临流，自可一觞而一咏。至欢然而会意，亦傍若于无人。乃知偶来常胜于特来，前言可信；所有虽非于己有，其得已多。因翻旧阕之辞，写以新声之调，敢陈薄伎，聊佐清欢。
注：遇酒便留于道士：“道士”，宋刊本作“道上”。
