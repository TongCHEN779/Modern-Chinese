# 居士外集卷三　古诗三十首
题解：此卷诗，周本、丛刊本注云：“自乾德至滁州作。起实元元年，尽庆历八年。”

# 南獠
题解：周本、丛刊本注云“宝元元年”作。
诗：洪宋区夏广，/恢张际四维。/狂孽久不耸，/民物含春熙。
诗：耆稚适所尚，/游泳光华时。/遽然摄提岁，/南獠掠边陲。
诗：予因叩村叟，/此事曷如斯？/初似却人问，/未语先涕垂。
诗：收涕谢客问，/为客陈始基：/抚水有上源，/水浅山山险巇。
诗：生民三千室，/聚此天一涯。/狠勇复轻脱，/性若鹿与麋。
诗：男夫不耕凿，/刀兵动相随。/宜融两境上，/杀人取其赀。
诗：因斯久久来，/此寇易为羁。/鼠窃及蚁聚，/近裹焉敢窥？
诗：势亦不久住，/官军来即驰。/景德祥符后，/时移事亦移。
诗：四辅哲且善，/天子仁又慈。/将军称招安，/兵非羽林儿。
诗：龙江一牧拙，/逻骑材亦非。/威惠不兼深，/徒以官力欺。
诗：智略仍复短，/从此难羁縻。/引兵卸甲岭，/部阵自参差。
诗：锋镝殊未接，/士卒心先离。/奔走六吏死，/初在怀远军卸甲岭；
诗：杀伤范礼宾、王崇班等，/六人落阵死。/明知国挫威。/自兹贼声震；
诗：直寇融州湄。/县宇及民庐，/毁荡无子遗。/利镞淬诸毒，
诗：中肤无药医。/长刀断人股，/横尸满通逵。/妇人及孳产，
诗：驱负足始归。/堂堂过城戍，/何人敢正窥！/外计削奏疏，
诗：一一闻宸闱。/赫尔天斯怒，/选将兴王师。/精甲二万余，
诗：猛毅如虎貔。/剑戟凛秋霜，/旌棨闪朝曦。/八营与七萃，
诗：岂得多于兹。/外统三路进，/小敌胡能为。/前驱已压境，
诗：后军犹未知。/逶迤至蛮域，/但见空稻畦。/搜罗一月余，
诗：不战帅自罢。/荷戈莫言苦，/负粮深可悲。/哀哉都督邮，
诗：无辜遭屠糜。/昭州都曹皇甫仅三人部粮入洞，/遭蛮贼掩杀，/及害夫力千余。
诗：晓咋计不出，/还出招安辞。/半降半来拒，/蛮意犹狐疑。
诗：厚以缯锦赠，/狙心诈为卑。/戎帐草草起，/贼戈蹑背挥。
诗：我聆老叟言，/不觉颦双眉。/吮毫兼叠简，/占作南獠诗。
诗：愿值采诗官，/一敷于彤墀。

# 寄圣俞
诗：西陵山水天下佳，/我昔谪官君所嗟。/官闲憔悴一病叟，/县古潇洒如山家。
诗：雪消深林自斯笋，/人响空山随摘茶。/有时携酒探幽绝，/往往上下穷烟霞。
诗：岂荪绿缛软可藉，/野卉青红春自华。/风余落蕊飞回旋，/日暖山鸟鸣交加。
诗：贪追时俗玩岁月，/不觉万里留天涯。/今来寂寞西冈口，/秋尽不见东篱花。
诗：市亭插旗鬬新酒，/十千得斗不可赊。/材非世用自当去，/一舸聱牙挥钩车。
诗：君能先往勿自滞，/行矣春洲生获芽。

# 答梅圣俞寺丞见寄
题解：周本、丛刊本注云“宝元二年”作。
诗：忆昔识君初，/我少君方壮。/风期一相许，/意气曾谁让。
诗：交游盛京洛，/尊俎陪丞相。/录骥日相追，/鸾凰志高飏。
诗：词章尽崔蔡，/论议皆歆向。/文会忝予盟，/诗坛推子将。
诗：谈精锋愈出，/饮剧欢无量。/贾勇为无前，/余光谁敢望！
诗：兹来五六岁，/人事堪凄怆。/南北顿睽乖，/相离独飘荡。
注：兹来：“兹来”原作“兹年”，周本、丛刊本卷后校云“疑为兹来”，是，今据改。
诗：失杯由画足，/伤手因代匠。/移书虽激切，/拙语非欺诳。
诗：安知乃心愚，/而使所言妄。/权豪不自避，/斧质诚为当。
诗：仓皇得一邑，/奔走踰千嶂。/楚峡听猿鸣，/荆江畏蛟浪。
诗：蛮方异时俗，/景物殊气象。/绿发变风霜，/丹颜侵疾痒。
诗：常忧鹏鸟窥，/幸免江鱼葬。/今兹荷宽宥，/迁徙来汉上。
诗：憔悴戴囚冠，/驱驰嗟俗状。/王事多倥偬，/学业差遗忘。
诗：未能解绶去，/所恋寸禄养。/举足畏逢仇，/低头惟避谤。
诗：欣闻故人近，/岂惮驱车访？/一别各衰翁，/相见问无恙。
诗：交情宛如旧，/欢意独能强。/幸陪主人贤，/更值芳洲涨。
诗：菱荷乱浮泛，/水竹涵虚旷。/清风满谈席，/明月临歌舫。
诗：已见洛阳人，/重开画楼唱。/怡然壹郁写，/踅尔累囚放。
诗：自从还邑来，/会此骄阳亢。/神灵多请祷，/租讼烦笞榜。
诗：犹须新秋凉，/汉水临清漾。/野稼荡浮云，/晴山开叠障。
注：汉水临清漾：“临”，周本、丛刊本校：“一作泻”。”
诗：聊以助吟咏，/亦可资酣畅。/北辕如未驾，/幸子能来贶。

# 酬圣俞朔风见寄
诗：因君朔风句，/令我苦寒吟。/离别时未几，/峥嵘岁再阴。
诗：惊飙击旷野，/余响入空林。/客路行役远，/马蹄冰雪深。
诗：瞻言洛中旧，/期我高阳岑。/故馆哭知己，/新年伤客心。
诗：相逢岂能饮，/惟有涕沾襟！
注：惟有涕沾襟：周本、丛刊本卷后校：“此诗押两吟字，一本第一韵作吟寒’，乃别韵。”

# 送琴僧知白
题解：周本、丛刊本注云“实元二年”作。
诗：吾闻夷中琴已久，/常恐老死无其传。/夷中未识不得见，/岂谓今逢知白弹。
诗：遗音仿佛尚可爱，/何况之子传其全。/孤禽晓警秋野露，/空涧夜落春山泉。
诗：二年迁谪寓三峡，/江流无底山侵天。/登临探赏久不厌，/每欲图画存於前。
诗：岂知山高水深意，/久以写此朱丝弦。/酒酣耳热神气王，/听之为子心肃然。
诗：嵩阳山高雪三尺，/有客拥鼻吟苦寒。/负琴北走乞其赠，/持我此句为之先。

# 听平戎操
诗：西戎负固稽天诛，/勇夫战死智士谟。/上人知白何为者，/年少力壮逃浮屠。
诗：自言平戎有古操，/抱琴欲进为我娱。/我材不足置廊庙，/力弱又不堪戈殳。
诗：遭时有事独无用，/偷安饱食与汝俱。/尔知平戎竞何事，/自古无不由吾儒。
注：平戎竞何事：“竟”，周本、丛刊本卷后校：“疑是竟”字。”
诗：周宣六月伐猃狁，/汉武五道征匈奴。/方叔召虎乃真将，/卫青去病诚区区。
诗：建功立业当盛日，/后世称咏於诗书。/平生又欲慕贾谊，/长缨直请系单于。
诗：当衢理检四面启，/有策不献空踟蹰。/惭君为我奏此曲，/听之空使壮士吁。
诗：推琴置酒恍若失，/谁谓子琴能起予！
注：置酒恍若失：“置”，周本、丛刊本校：“一作耽”

# 书宜城修水渠记后奉呈朱寺丞
题解：周本、丛刊本卷后校云：“朱名纮，字仪甫，治平中为宜城令，修水渠有功。熙宁二年冬，吴充荐改大理寺丞。郑獬为作渠记。公诗当在三年，合入《外集》第四卷，误置第三。”
诗：因民之利无难为，/使民以说民忘疲。/乐哉朱君鄣灵堤，/导鄢及蛮兴众陂。
诗：古渠废久人莫知，/朱君三月而复之。/沃土如膏瘠土肥，/百里岁岁无凶灾。
诗：鄢蛮之水流不止，/襄人思君无时已。

# 谷正至始得先所寄书及诗不胜喜慰因书数韵奉酬圣俞
题解：周本、丛刊本注云“康定元年”作。
诗：寒日照深巷，/柴门朝尚闭。/有客自江来，/尺书千里至。
诗：启书复何云，/但言南北.异。/南方地常暖，/风物称佳丽。
诗：梅蘸入新年，/兰皋动芳气。/乐哉登临兴，/岂厌江湖滞。
诗：伊予方寂寞，/刻苦穷文字。/万国会王州，/群英驰隽轨。
诗：方朔常苦饿，/子云非官意。/岁暮惨风尘，/官闲倦朝市。
诗：出处一云别，/所思宁可冀？/春江有归雁，/但使音书继。

# 答梅圣俞
诗：寒日照穷巷，/荆扉晨未开。/惊闻远方信，/有客渡江来。
诗：开缄复何喜，/宛若见琼瑰。/一尔乖出处，/未尝持酒杯。
诗：官闲隐朝市，/岁暮惨风埃。/音书日可待，/春雁暖应回。
注：春雁暖应回：周本、丛刊本卷后校：“《奉酬圣俞》、《答梅圣俞》二诗多同而韵异，故两存之。”

# 病中闻梅二南归
诗：闻君解舟去，/秋水正沄沄。/野岸旷归思，/都门辞世纷。
诗：稍逐商帆伴，/初随征雁群。/山多淮甸出，/柳尽汴河分。
诗：楚色芜尚绿，/江烟日半曛。/客意浩已远，/离怀宁复云。
注：楚色芜尚绿：“尚”，周本、丛刊本校：“一作上”。”
注：江烟日半曛：“半”，周本、丛刊本校：“一作“畔”。”
诗：宣城好风月，/归信几时闻？

# 送智蟾上人游天台
题解：题中“智”字原脱，据周本、丛刊本目录补。按《居士集》卷十有《智蟾上人游南岳》诗，亦可证。
诗：昔年在伊洛，/林壑每相从。/对扫竹下榻，/坐思湖上峰。
诗：自言伊洛波，/每起沧洲忆。/今兹道行游，/千里东南国。
诗：都门汴河上，/柳色入青烟。/流水向淮浦，/归人随越船。
诗：东南遍林山献，/万壑新流满。/小桂绿应芳，/江春行已晚。
诗：蔼蔼赤城阴，/依依识古岑。/一去谁复见，/石桥云雾深。

# 送徐生秀州法曹
诗：一笑暂相从，/结交方恨晚。/犹兹簿领困，/况尔东南远。
诗：落帆淮口暮，/采石江洲暖。/黄鸽可寄书，/惟嗟双翅短。

# 读山海经图
诗：夏鼎象九州，/《山经》有遗载。/空濛大荒中，/杳霭群山会。
诗：炎海积歌蒸，/阴幽异明晦。/奔趋各异种，/倏忽俄万态。
诗：群伦固殊禀，/至理宁一概？/骇者自云惊，/生兮孰知怪？
诗：未能识造化，/但尔披圃绘。/不有万物殊，/岂知方与大？

# 依韵和圣俞见寄
诗：与君结交深，/相济同水火。/文章发春葩，/节行凛筠笥。
诗：吾才已愧君，/子齿又先我。/君恶予所非，/我许子云可。
诗：厥趣共乖时，/畏涂难转果。/道肥家所穷，/身老志弥果。
诗：每嗟游从异，/有甚樊笼锁！/天匠染青红，/花腰呈袅娜。
诗：苟能杯酌同，/直待冠巾堕。/无欺校雠贫，/盐米尚余颗。

# 晏太尉西园贺雪歌
题解：周本、丛刊本注云“庆历元年”作。
诗：阴阳乖错乱五行，/穷冬山谷暖不冰。/一阳且出在地上，/地下谁发万物萌？
诗：太阴当用不用事，/盖由奸将不斩亏国刑。/遂令邪风伺间隙，/潜中瘟疫於疲氓。
诗：神哉陛下至仁圣，/忧勤恳祷通精诚。/圣人与天同一体，/意未发口天已听。
诗：忽收寒威还水官，/正时肃物凛以清。/寒风得势猎猎走，/瓦乾霰急落不停。
诗：恍然天地半夜白，/群鸡失晓不及鸣。/清晨拜表东上阁，/郁郁瑞气盈宫庭。
诗：退朝骑马下银阙，/马滑不惯行瑶琼。/晚趋宾馆贺太尉，/坐觉满路流欢声。
诗：便开西园扫径步，/正见玉树花凋零。/小轩却坐对山石，/拂拂酒面红烟生。
诗：主人与国共休戚，/不惟喜悦将丰登。/须怜铁甲冷彻骨，/四十余万屯边兵！

# 送吴照邻还江南
诗：霜前江水磨碧铜，/岸背菱叶翘青虫。/吴郎鬓丝生几缕，/不羞月上扶桑东。
诗：羞见清波照人景，/去时黑发吹春风。/五年归来妇应喜，/从此不问西飞鸿。

# 答朱寀捕蝗诗
题解：周本、丛刊本注云“庆历二年”作。
诗：捕蝗之街世所非，/欲究此语兴於谁？/或云丰凶岁有数，/天孽未可人力支。
诗：或言蝗多不易捕，/驱民入野践其畦。/因之奸吏恣贪扰，/户到头敛无一遗。
诗：蝗灾食苗民自苦，/吏虐民苗皆被之。/吾嗟此语祇知一，/不究其本论其皮！
诗：驱虽不尽胜养患，/昔人固已决不疑。/秉蟊投火况旧法，/古之去恶犹如斯。
诗：既多而捕诚未易，/其失安在常由迟。/诜诜最说子孙众，/为腹所孕多鲲柢。
诗：始生朝亩暮已顷，/化一为百无根涯。/口含锋刃疾风雨，/毒肠不满疑常饥。
诗：高原下隰不知数，/进退整若随金鼙。/嗟兹羽孽物共恶，/不知造化其谁尸？
诗：大凡万事悉如此，/祸当早绝防其微。/蝇头出土不急捕，/羽翼已就功难施。
诗：只惊群飞自天下，/不究生子由山陂。/官书立法空太峻，/吏愚畏罚反自欺。
诗：盖藏十不敢申一，/上心虽恻何由知。/不如宽法择良令，/合蝗不隐捕以时。
诗：今苗因捕虽践死，/明岁犹免为蝝苗。/吾尝捕蝗见其事，/较以利害曾深思。
诗：官钱二十买一斗，/示以明信民争驰。/敛微成众在人力，/顷刻露积如京坻。
注：明信民争驰：“示”，周本、丛刊本校：“一作亦”。”
诗：乃知孽虫虽甚众，/嫉恶苟锐无难为。/往时姚崇用此议，/诚哉贤相得所宜。
诗：因吟君赠广其说，/为我持之告采诗。

# 答苏子美离京见寄
题解：“子美”，周本、丛刊本卷后校：“《庆历文粹》作倩仲”，盖舜钦旧字，后篇同。”
诗：众奇子美貌，/堂堂千人英。/我独疑其胸，/浩浩包沧溟。
诗：沧溟产龙蜃，/百怪不可名。/是以子美辞，/吐出人辄惊。
诗：其於诗最豪，/奔放何纵横！/众弦排律吕，/金石次第鸣。
诗：间以险绝句，/非时震雷霆。/两耳不及掩，/百痾为之醒。
诗：语言既可骇，/笔墨尤其精。/少虽尝力学，/老乃若天成。
诗：濡毫弄点画，/信手不自停。/端庄杂丑怪，/群星见搀枪。
诗：烂然溢纸幅，/视久无定形。/使我终老学，/得一已足矜。
诗：而君兼众美，/磊落犹自轻。/高冠出人上，/谁敢揖其膺？
诗：群臣列丹陛，/几位缺公卿。/使之束带立，/可以重朝廷。
诗：况令参国议，/高谕吐峥嵘。/惜哉三十五，/白发今已生。
诗：近者去江淮，/作诗寄离情。/口诵不及写，/一日传都城。
诗：退之序百物，/其鸣由不平。/天方苦君心，/欲使发其声。
诗：嗟我非惊惊，/徒思和嘤嘤。/因风幸数寄，/警我聋与盲。

# 立秋有感寄苏子美
诗：庭树忽改色，/秋风动其枝。/物情未必尔，/我意先已悽。
诗：虽恐芳节谢，/犹欣早凉归。/起步云月暗，/顾瞻星斗移。
诗：四时有大信，/万物谁与期？/故人在千里，/岁月令我悲。
诗：所嗟事业晚，/且惜颜色衰。/庙谋今谓何，/胡马日以肥！

# 喜雪示徐生
诗：清穹凛冬威，/旱野渴天泽。/经旬三尺雪，/万物变颜色。
注：清穹凛冬威：“穹”，周本、丛刊本校：“一作“空”。”
诗：愁云嘘不开，/惨惨连日夕。/寒风借天势，/豪忽肆陵。
诗：空枝冻鸟雀，/痴不避弹弋。/长河寂无声，/厚地若龟坼。
诗：階阶夜自照，/缺瓦晨复积。/贮洁莹冰壶，/量深埋玉尺。
诗：凝阴反穷剥，/阳九兆初画。/春回百草心，/气动黄泉脉。
诗：坚冰虽未破，/土润已潜释。/常闻老农语，/一腊见三白。
诗：是为丰年候，/占验胜蓍策。/天兵血西陲，/万辙走供亿。
诗：嗟予愧疲俗，/奚术肥尔瘠？/惟幸岁之穰，/兹惠岂人力。
诗：非徒给租调，/且可销盗贼。/从今洁廪，/期共饱牟麦。

# 赋竹上甘露
题解：周本注云“庆历三年”作。
诗：梢梢两竹枝，/甘露叶间垂。/草木有灵液，/阴阳凝以时。
诗：深山与穷谷，/往往尝有之。/幸当君子轩，/得为众人知。
诗：物生随所托，/晦显各有宜。/聊以助歌咏，/兼堪饮童儿。

# 和对雪忆梅花
诗：昔官西陵江峡间，/野花红紫多斓斑。/惟有寒梅旧所识，/异乡每见心依然。
注：每见心依然：“心”，周本、丛刊本校：“一作必”。”
诗：为怜花自洛中看，/花上蜀鸟啼绵蛮。/当时作诗谁唱和？/粉蕊自折清香繁。
诗：今来把酒对残雪，/却忆江上高楼山。/群花四时媚者众，/何独此树令人攀？
诗：穷冬万木立枯死，/玉艳独发凌清寒。/鲜妍皎如镜裹面，/绰约对若风中仙。
诗：惜哉北地无此树，/霰雪漫漫平沙川。/徐生随我客此郡，/冰霜旅舍逢新年。
诗：忆花对雪晨起坐，/清诗宝铁裁琅玕。/长河风色暖将动，/即看绿柳含春烟。
诗：寒斋寂寞何以慰，/卯杯且醉酣午眠。

# 归雁亭
题解：周本注云“庆历三年”作。
诗：荒蹊腊雪春尚埋，/我初独与徐生来。/城高树古禽鸟野，/声响格磔寒稻毸。
诗：颓垣败屋巍然在，/略可远眺临倾台。/高株唯有柳数十，/夹路对立初谁栽？
诗：渐诛榛莽辨草树，/颇有桃李当墙限。/欣然便拟趁时节，/斤锄日夕劳耘培。
诗：新年风色日渐好，/晴天仰见雁已回。/枯根老脉冻不发，/透之百匝空徘徊。
诗：顽姿野态烦造化，/勾芒不肯先煦吹。/酒酣几欲掏大鼓，/惊起龙蛰驱春雷。
诗：偶然不到才数日，/颜色一变由谁催。/翠芽红粒迸条出，/纤跌嫩萼如剪裁。
诗：卧槎烧卉亦强发，/老朽不避众艳哈。/姹然出杏开最早，/其余红白各自媒。
诗：初开盛发与零落，/皆有意思牵人怀。/众芳勿使一时发，/当令一落续一开。
注：勿使一时发：“发”，周本、丛刊本、程本卷后校：“《庆历文粹》作“歇”。”
诗：毕春应须酒万斛，/与子共醉三千杯。

# 送韩子华
诗：嗟我久不见韩子，/如读古书思古人。/忽然相逢又数日，/笑语反不共一尊。
诗：谏垣尸居职业废，/朝事汲汲劳精神。/子华笔力天马足，/驽骀千百谁可群？
诗：嗟予老钝不自笑，/尚欲疾走追其尘。/子华有时高谈骇我听，/荣枯万物移秋春。
诗：所以不见令我思，/见之如饮玉醴醇。/叩门下马忽来别，/高帆得风披飞云，
诗：离怀有酒不及写，/别后慰我寓於文。

# 送李太傅端懿知冀州
诗：吾慕李汉超，/为将勇无俦。/养士三千人，/人人百貔貅。
诗：关南三十年，/天子不北忧。/吾爱李允则，/善砚多计筹。
诗：虏动静寝食，/皎如在双眸。/出入若变化，/谈笑摧敌谋。
诗：恩信浃南北，/声名落燕幽。/二公材各异，/战守两堪尤。
诗：天下不用兵，/尔来三十秋。/今其继者谁？/守冀得李侯。
诗：李侯年尚少，/文武学彬彪。/河朔一尺雪，/北风暖貂裘。
诗：上马擘长弓，/白羽飞金镞。/临行问我言，/我惭本儒鲰。
诗：汉超虽已久，/故来尚歌讴；/允则事最近，/犹能想风流。
诗：将此聊为赠，/勉哉行无留！

# 石篆诗并序
题解：周本、丛刊本注云“庆历五年”作。
诗：某启。/近蒙朝恩守此州，/州之西南有琅琊山唐李幼卿庶子泉者。/某在馆阁时，
诗：方国家诏天下求古碑石之文，/集于阁下，/因得见李阳冰篆《庶子泉铭》。/学篆者云：
诗：“阳冰之迹多矣，/无如此铭者。”/常欲求其本而不得，/于今十年矣。
诗：及此来，/已获焉。/而铭石之侧，/又阳冰别篆十余字，
诗：尤奇於铭文，/世罕传焉。/山僧惠觉指以示予，/予徘徊其下，
诗：久之不能去。/山之奇迹，/古今纪述详矣，/而独遗此字。
诗：梅圣俞、苏子美也。/因为诗一首，/并封题墨本以寄二君，/乞诗，/刻于石。
诗：梅圣俞、苏子美也。/因为诗一首，/并封题墨本以寄二君，/乞诗，/刻于石。
诗：寒岩飞流落青苔，/旁断石篆何奇哉！/其人已死骨已朽，/此字不灭留山隈。
注：飞流落青苔：“流”周本、丛刊本校“一作溜”，原校“一作洒”。
诗：山中老僧忧石泐，/印之以纸磨松煤。/欲令留传在人世，/持以赠客比琼瑰。
诗：我疑此字非笔画，/又疑人力非能为。/始从天地胚浑判，/元气结此高崔嵬。
诗：当时野鸟踏山石，/万古遗迹於苍崖。/山祇不欲人屡见，/每吐云雾深藏埋。
诗：群仙飞空欲下读，/常借海月清光来。/嗟我岂能识字法，/见之但觉心眼开。
诗：辞惺语鄙不足记，/封题远寄苏与梅。

# 题滁州醉翁亭
题解：周本、丛刊本注云“庆历六年”作。
诗：四十未为老，/醉翁偶题篇。/醉中遗万物，/岂复记吾年。
诗：但爱亭下水，/来从乱峰间。/声如自空落，/泻向雨檐前。
注：泻向雨檐前：“雨”，丛刊本作“两”。
诗：流入岩下溪，/幽泉助涓涓。/响不乱人语，/其清非管弦。
诗：岂不美丝竹，/丝竹不胜繁。/所以屡携酒，/远步就潺湲。
诗：野鸟窥我醉，/溪云留我眠。/山花徒能笑，/不解与我言。
诗：惟有岩风来，/吹我还醒然。

# 赠学者
诗：人禀天地气，/乃物中最灵。/性虽有五常，/不学无由明。
诗：轮曲揉而就，/木直在中绳。/坚金砺所利，/玉琢器乃成。
诗：仁义不远躬，/勤勤入至诚。/学既积於心，/犹木之敷荣。
诗：根本既坚好，/蓊郁其干茎。/尔曹宜勉勉，/无以吾言轻。

# 春寒效李长吉体
诗：东风吹云海天黑，/饥龙冻云雨不滴。/嗔雷隐隐愁烟白，/宿露无光瑶草寂。

# 幽谷晚饮
题解：题中“幽谷”下周本、丛刊本校：“一作“丰乐亭”。”
诗：一径入蒙密，/已闻流水声。/行穿翠筱尽，/忽见青山横。
诗：山势抱幽谷，/谷泉含石泓。/旁生嘉树林，/上有好鸟鸣。
诗：鸟语谷中静，/树凉泉影清。/露蝉已嘒嘒，/风溜时泠泠。
诗：渴心不待饮，/醉耳倾还醒。/嘉我二三友，/偶同丘壑情。
诗：环流席高荫，/置酒当峥嵘。/是时新雨余，/日落山更明。
