# 赠无为军李道士二首
题解：“蹭无为军李道士”，周本、丛刊本卷后校：“石本作赠宗教李尊师名景仙’。”按名景仙”三字应是题注。又此诗周本、丛刊本注云“庆历七年”作。
原：名景仙。
诗：无为道士三尺琴，/中有万古无穷音。/音如石上泻流水，/泻之不竭由源深。
诗：弹虽在指声在意，/听不以耳而以心。/心意既得形骸忘，/不觉天地白日愁云阴。
诗：李师琴纹如卧蛇，/弹使我三咨嗟。/五音商羽主肃杀，/飒飒坐上风吹沙。
注：纹：周本、丛刊本校：[一作形”。”
诗：忽然黄钟回暖律，/当冬草木皆萌芽。/郡齐日午公事退，/荒凉树石相交加。
诗：李师一弹凤凰声，/空山百鸟停呕哑。/我怪李师年七十，/面目明秀光如霞。
诗：问胡以然笑语我，/慎勿辛苦求丹砂。/惟当养其根，/自然烨其华。
注：问胡以然：周本、丛刊本校：“一作试问胡以”，一作试问胡然”。”
注：惟当养其根：下周本、丛刊本校：“一本无上二句”。又“烨”原作“煜”，当是清人避康熙帝讳所改。今据衢本、周本、宋刊本、丛刊本、考异、程本、李本改正。
诗：又云理身如理琴，/正声不可干以邪。/我听其言未云足，/野鹤何事还思家。
诗：抱琴揖我出门去，/猎猎归袖风中斜。

# 拜赦
题解：题中“赦”下周本、丛刊本校：[一作敕”。”又此诗周本、丛刊本注云“庆历七年”作。
诗：拜赦古州南，，/山火明烈烈。/州人共喧喧，/两卯扶白发。
注：赦：周本、丛刊本校：“一作“敕”。”
诗：丁宁天语深，/旷荡皇恩阔。/乃知天地施，/幽远无间别。
诗：欣欣草木意，/喜气消残雪。

# 弹琴效贾岛体
诗：古人不可见，/古人琴可弹。/弹为古曲声，/如与古人言。
注：弹为：周本、丛刊本校：“一作“琴闻”。”
注：与：周本、丛刊本校：“一作“闻”。”
诗：琴声虽可听，/琴意谁能论。/横琴置床头，/当午曝背眠。
诗：梦见一丈夫，/严严古衣冠。/登床取之坐，/调作南风弦。
注：取之坐：衢本、考异作“取我琴”
诗：一奏风雨来，/再鼓变云烟。/鸟兽尽嘤鸣，/草木亦滋蕃。
注：雨：衢本作“南”
诗：乃知太古时，/未远可追还。/方彼梦中乐，/心知口难传闻既觉失其人，/起坐涕氿澜。
注：口难：周本、丛刊本校：“一作“难口”。”

# 酬学诗僧惟晤
诗：诗三百五篇，/作者非一人。/骄臣与弃妾，/桑濮乃淫奔。
注：弃：周本、丛刊本校：“一作贱”。”
诗：其言苟可取，/杂不全纯。/子虽为佛徒，/未易废其言。

注：虽：周本、丛刊本校：“一作之”。”

注：虽：周本、丛刊本校：“一作已’。”
注：徒自苦骸筋：周本、丛刊本校：“一作“自远涉江津’。”
诗：惟求一言荣，/归以耀其伦。/与夫荣其肤，/不若启其源。

注：耀：考异校：“家本作辉’。”
注：不若启：周本、丛刊本校：“一作岂若习”。”

# 别后奉寄圣俞二十五兄
题解：题下周本、丛刊本校：二本作叙别寄圣俞兼酬进道堂夜话见寄之什'。”又此诗周本、丛刊本注云“庆历七年”作。
诗：长河秋雨多，/夜插寒潮人。/岁暮孤舟迟，/客心飞鸟急，
注：潮：周本、丛刊本校：“一作湖”。”
诗：君老忘卑穷，/文字或缀缉。/余生苦难厄，/世险蹈已习。

诗：离合二十年，/乖暌多聚集。/常时饮酒别，/今别辄饮泣。
诗：君曰吾老矣，/不觉两袖湿。/我年虽少君，/白发已揖揖即人反。
诗：忆初京北门，/送我马暂立。/自兹遭槛阱，/一落谁引汲。
诗：颠危偶脱死，/藏窜甘自萦。/但令身尚在，/果得手重执。
注：窜甘自萦：周本、丛刊本校：“一作“蛰”。”
注：尚：衢本、考异作“幸”。考异“幸”下校云：“吉本作“尚”。”
诗：闻来喜迎前，/貌改惊乍揖。/别离才几时，/旧学废百十。
诗：残章与断稿，/草草各收拾。/空窗语青镫，/夜雨听霞露。
注：章：周本、丛刊本校：“一作编”。”
注：窗：周本、丛刊本校：“一作堂”。”
诗：明朝解舟南，/归翼纵莫戢。/还期明月饮，/幸此中秋及。
诗：酒酣弄篇章，/四坐困供给。/欢言正喧哗，/别意忽于邑。
诗：日暮北亭上，/浊醪聊共挹轻桡动翩翩晚水明熠熠。/行心去虽迫“一○”，/诀语出犹涩。
注：聊：周本、丛刊本校：“一作犹’。”
注：轻：周本、丛刊本校：“一作归”。”
注：行心：周本、丛刊本校：“一作“贪前”。”
诗：归来录君诗，/卷轴多织织。/谁云已老矣，/意气何案岌惜哉方壮时，
注：谁：衢本作“虽”。
诗：千里足常毕。/知之莫予深，/力不足呼吸。/叹吁偶成篇，/聊用缀君什。

# 紫石屏歌
题解：题下周本、丛刊本校：“一本作月石砚屏歌寄苏子美”。”《文鉴》此题作紫石屏歌寄苏子美”。又此诗周本、丛刊本注云“庆历七年”作。
诗：月从海底来，/行上天东南。/正当天中时，/下照千丈潭。
注：丈：《文鉴》作“尺”
诗：潭心无风月不动，/倒影射入紫石岩。/月光水洁石莹净，/感此阴魄来中潜。
注：净：周本、丛刊本校：“一作“彻’。”
诗：自从月入此石中，/天有两曜分为三。/清光万古不磨灭，/天地至宝难藏缄。
诗：天公呼雷公，/夜持巨斧隳崭岩。/隳此一片落千仞，/皎然寒镜在玉奁。
诗：虾蟆白兔走天上，/空留桂影犹杉杉。/景山得之惜不得，/赠我意与千金兼。
注：杉杉：周本、丛刊本校：“一作“毵毵”。”
注：景山得之：周本、丛刊本校：“一作虢州刺史”。”
注：与：周本、丛刊本校：“一作“比”。”
诗：自云每到月满时，/石在暗室光出檐。/大哉天地间，/万怪难悉谈。
诗：嗟予不度量，/每事思穷探。/欲将两耳目所及，/而与造化争毫纤。
诗：煌煌三辰行，/日月尤尊严。/若令下与物为比，/去声扰扰万类将谁瞻？
诗：不然此石竟何物，/有口欲说嗟如钳。/吾奇苏子胸，/罗列万象中包含。
注：奇：周本、丛刊本校：“一作知’。”
诗：不惟胸宽胆亦大，/屡出言语惊愚凡。/自吾得此石，/未见苏子心怀惭。
诗：不经老匠先指决，/有手谁敢施镌馋。/呼工画石持寄似，/幸子留意其无谦。
注：似：周本、丛刊本校：“一作“此”。”

# 聚星堂前紫薇花
题解：周本、丛刊本注云“皇佑二年”作。
诗：亭亭紫薇花，/向我如有意。/高烟晚溟蒙，/清露晨点缀。
诗：岂无阳春月，/所得时节异。/静女不争宠，/幽姿如自喜音戏。
诗：将期谁顾眄，/独伴我憔悴。/而我不强饮，/繁英行亦坠。
诗：相看两寂寞，/孤咏聊自慰。

# 获麟赠姚辟先辈
题解：周本、丛刊本注云“皇佑元年”作。
诗：世已无孔子，/获麟意谁知？/我尝为之说，/闻者未免非。
诗：而子独曰然，/有如坝应篪。/惟麟不为瑞，/其意乃可推。
诗：《春秋》二百年，/文约义甚夷。/一从圣人没，/学者白为师。
注：文：周奉、丛刊本校：“一作“辞”。”
诗：峥嵘众家说，/平地生睑帜。/相沿益迂怪，/各合出新奇。
诗：尔来千余岁，/举世不知迷。/焯哉圣人经，/照耀万世疑。
注：千余岁：周本、丛刊本、程本、李本校：“一作千载余气一作干岁余”。”
诗：自从蒙众说，/日月遭蔽亏。/常患无气力，/扫除浮云披。
诗：还其自然光，/万物皆见之。/子昔已好古，/此经手常持。
诗：超然出众见，/不为俗牵卑。/近又脱赋格，/飞黄摆衔羁。
诗：圣门开大道，/夷路肆腾嬉。/便可剿众说，/旁通塞多歧。
注：旁通：周本、丛刊本校：“一作异端’。”
诗：正途趋简易，/慎勿事岖崎。/著述须待老，/积勤宜少时。
注：趋：周本、丛刊本校：“一作常”。”
注：须：考异作“虽”，且校云“吉本作须’”。
诗：苟思垂后世，/大禹尚胼胝。/顾我今老矣，/两瞳蚀昏眵。
注：瞳：周本、丛刊本校：“一作“目”，一作“眼”。”
诗：大书难久视，/心在力已衰。/因思少自弃，/今纵悔何追！
注：何：衢本《文鉴》、周本、宋刊本、丛刊本、考异、程本、李本作“可”。
诗：戒我以勉子，/临文但吁嘻。

# 竹间亭
题解：此诗周本、丛刊本注云“皇佑二年”作。
诗：啾啾竹间鸟，/日夕相嘤鸣。/悠悠水中鱼，/出入藻与萍。
诗：水竹鱼鸟家，/伊谁作斯亭？/翁来无车马，/非与弹弋并。
诗：潜者入深渊，/飞者散纵横。/奈何翁屡来，/浪使飞走惊。
诗：忘尔荣与利，/脱尔冠与缨。/还来寻鱼鸟，/傍此水竹行。
诗：鸟语弄苍翠，/鱼游玩清澄。/而翁乃何为，/独醉还自醒。
诗：三者各自适，/要归亦同情。/翁乎知此乐，/无厌日来登。

# 青松赠林子国华
题解：题中“赠林子国华”下周本、丛刊本校：“一本作赠国华秘校’。”衢本此题作：“青松一首赠林子。”又此诗周本、丛刊本注云“庆历八年”作。
诗：青松生而直，/绳墨易为功。/良玉有天质，/少加磨与聋。

注：加：周本、丛刊本校：“一作假”。”

# 鹦鹉螺
诗：大哉沧海何茫茫，/天地百宝皆中藏。/牙须甲角争光，/腥风怪雨洒幽荒。

注：沙夜生光：自“腥风怪雨洒幽荒”至“红螺行沙夜生光”五句，周本、丛刊本校：“一本作“珠官贝阙烂煌煌。泥居壳室细莫详，珊瑚玲珑巧缀妆。腥风怪雨洒幽荒，红螺行沙夜生光'。”

注：浓沙剥蚀隐文章：下周本、丛刊本校：“一本注：“胡人谓碉砂为浓沙，出《本草》。”

注：回：周本、丛刊本校：“一作为”。”
