# 奉使契丹道中答刘原父桑干河见寄之作
题解：周本、丛刊本注云“至和二年”作。
诗：忆昨初受命，/同下紫宸朝。/问君当何之，/笑指北斗杓。
诗：共念到几时，/春风约回镳。/所持既异事，/前后忽相辽。
诗：岁月坐易失，/山川行知遥。/回头三千里，/双阙在紫霄。
注：易：周本、丛刊本校：“一作若”。”
诗：我老倦鞍马，/安能事吟嘲。/君才绰有余，/新句益飘飘。
注：益：周本、丛刊本校：“一作亦”。”
诗：前日逢吕郭，/解鞍憩山腰。/僮仆相问喜，/马鸣亦萧萧。
诗：出君《桑干》诗，/寄我慰寂寥。/又喜前见君，/相期驻征轺。
诗：虽知不久留，/一笑乐亦聊。/归路践冰雪，/还家脱狐貂。
诗：君行我即至，/春酒待相邀。

# 书素屏
题解：周本、丛刊本注云“至和二年”作。
诗：我行三千里，/何物与我亲。/念此尺素屏，/曾不离我身。
诗：旷野多黄沙，/当午白日昏。/风力若牛弩，/飞砂还射人。
诗：暮投山椒馆，/休此车马勤。/开屏置床头，/辗转夜向晨。
诗：卧听穹庐外，/北风驱雪云。/勿愁明日雪，/且拥狐貂温。
诗：君命固有严，/羁旅诚苦辛。/但苟一夕安，/其余非所云。

# 马啮雪

诗：马饥啮雪渴饮冰，/北风卷地来峥嵘。/马悲踯躅人不行，/日暮涂远千山横。
注：渴饮：周本、丛刊本校：“一作行踏”。”
注：来：周本、丛刊本校：“一作寒”。”

注：五里长：周本、丛刊本校：“一作长亭与”。”
诗：腊雪销尽春风轻，/火烧原头青草生。/远客还家红袖迎，/乐哉人马归有程。
诗：男儿虽有四方志，/无事何须勤远征
注：须：周本、丛刊本校：二作烦’。”

# 风吹沙
题解：周本、丛刊本校：“一本题上有北’字。”又此诗周本、丛刊本注云“至和二年”作。
诗：北风吹沙千里黄，/马行确荦悲摧藏。/当冬万物惨颜色，/冰雪射日生光芒。
注：当：周本、丛刊本校：“一作穷’。”又“颜”，周本、丛刊本校：二作‘无’。”

注：揽鞍鞭：周本、丛刊本校：“一作“起鞭归”。”

# 重赠刘原父
题解：题下周本、丛刊本校：“一作“忆昨呈刘原父”。”又此诗周本、丛刊本注云“嘉佑元年”作。
诗：忆昨君当使北时，/我往别君饮君家。/爱君小鬟初买得，/如手未触新开花。
诗：醉中上马不知夜，/但见九陌灯火人喧哗。/归来不记与君别，/酒醒起坐空咨嗟。
诗：自言我亦随往矣，/行即逢君何恨邪。/岂知前后不相及，/岁月匆匆行无涯古北岭口踏新雪，
注：岁：周本、丛刊本校：“一作日”
诗：马盂山西看落霞。/风云暮惨失道路，/碉谷夜静闻鏖厅。/行迷方向但看日，
注：云：周本、丛刊本校：“一作雪”
诗：度尽山险方逾沙。/客心渐远诚易感，/见君虽晚喜莫加。/我后君归只十日，
注：逾：周本、丛刊本校：“一作行”
注：只：周本、丛刊本校：“一作才”
诗：君先跃马未足夸。/新年花发见回雁，/归路柳暗藏娇鸦。/而今春物已烂漫，
注：而今：周本、丛刊本校：“一作今来”
诗：念昔草木冰未芽。/人生每苦劳事役，/老去尚能怜物华。/从今有暇即相遇，/安得载酒长盈车。

# 赠沈遵
题解：题下周本、丛刊本校：“一作“赠沈博士歌并序”。”考异校：“苏本以有序者题作赠沈博土歌并序”。”又此诗周本、丛刊本注云“嘉佑元年”作。
原：予昔于滁州作醉翁亭于琅琊山，有记刻石，往往传人间。太常博士沈遵，好奇之士也，闻而往游焉。
诗：爱其山水，/归而以琴写之，/作《醉翁吟》一调，/惜不以传人者五六年矣。
诗：去年冬，/予奉使契丹，/沈君会予恩冀之间。/夜阑酒半，
诗：出琴而作之。/予既嘉君之好尚，/又爱其琴声，/乃作歌以赠之。
注：歌以赠之：此序前原注“一本序云”四字，序乃异文。今删此注，序亦入正文。
诗：群动夜息浮云阴，/沈夫子弹《醉翁吟》。/《醉翁吟》，/以我名，
诗：我初闻之喜且惊。/宫声三叠何泠泠，/酒行暂止四坐倾。/有如风轻日暖好鸟语，
注：酒行暂止四坐倾：句下周本、丛刊本校：“一本有为君屏百虑，各以两耳听，两句。”
诗：夜静山响春泉鸣。/坐思千岩万壑醉眠处，/写君三尺膝上横。/沈夫子，
诗：恨君不为醉翁客，/不见翁醉山间亭。/翁欢不待丝与竹，/把酒终日听泉声。
注：翁醉：周本、丛刊本校：“一作醉翁”。”
诗：有时醉倒枕溪石，/青山白云为枕屏。/花间百鸟唤不觉，/日落山风吹自醒。
注：日落山风吹自醒：句下周本、丛刊本校：“一本有沈夫子，君过滁阳今几时？滁人皆喜醉翁醉，至今人人能道之。长记山间逢太守，篮黎酩酊插花归’六句。”
诗：我时四十犹强力，/自号醉翁聊戏客。/尔来忧患十年间，/鬓发未老嗟先白。
注：自号醉翁聊戏客：下周本、丛刊本校：“一本“客”字下作尔来才十年，遇酒饮不得。轩裳外饰诚可荣”。”
诗：滁人思我虽未忘，/见我今应不能识。/沈夫子，/爱君一尊复一琴，
诗：万事不可干其心。/自非曾是醉翁客，/莫向俗耳求知音。
注：自非曾是醉翁客：下周本、丛刊本校：“一本末两句作：高怀所得贵自适，俗耳何用求知音。可笑人生不饮酒，惟知白首恋黄金。”

# 答圣俞
题解：周本、丛刊本校：“一本题下有高车见过”。”又此诗周本、丛刊本注云“嘉佑元年”作。
诗：人皆喜诗翁，/有酒谁肯一醉之？/嗟我独无酒，/数往从翁何所为？
注：从：；周本、丛刊本校：“一作就’。”
诗：翁居南方我北走，/世路离合安可期。/汴渠千艘日上下，/来及水门犹未知。
诗：五年不见劳梦寐。/三日始往何其迟。/城东赚河有名字，/万家弃水为污池。
诗：人居其上苟贤者，/我视此水犹涟漪。/入门下马解衣带，/共坐习习清风吹。
诗：湿薪荧荧煮薄茗，/四顾壁立空无遗。/莴钱方丈饱则止，/一飘饮水乐可涯。
注：可：周本、丛刊本校：“一作何”。”
诗：况出新诗数十首，/珠玑大小光陆离。/他人欲一不可有，/君家筐箧满莫持。
注：有：周本、丛刊本校：“一作“得”。”
诗：才大名高乃富贵，/岂比金紫包愚痴。/贵贱同为一丘土，/圣贤独如星日垂。
注：大：周本、丛刊本校：“一作多”。”
注：独：周本、丛刊本校：“一作长’。”
诗：道德内乐不假物，/犹须朋友并良时。/蝉声渐已变秋意，/得酒安问醇与醨。
注：犹：周本、丛刊本校：”一作所’。”
诗：玉堂官闲无事业，/亲旧幸可从其私。/与翁老矣会有几，/当弃百事勤追随。

# 感兴五首
原：斋于醴泉宫作
注：斋于醴：周本、丛刊本注云“嘉佑元年”作。
诗：奉祠严秘馆，/摄事罄精诚。/岁晏悲木落，/天寒闻鹤鸣。
诗：念昔丘壑趣，/岂知朝市情。/弱龄婴仕宦，/壮节慕功名。
诗：多病惭厚禄，/早衰叹余生。/未知犬马报，/安得遂归耕。
诗：怀禄不知惭，/人虽不吾责。/贫交重意气，/握手犹感激。
注：犹：原校：“一作“独”。”
诗：煌煌腰间金，/雨鬓飒已白。/有生天地间，/寿考非金石。
诗：古人报一饭，/君子不苟得。/忧来自悲歌，/涕泪下沾臆。
诗：清夜虽云长，/白日亦易晚。/循环百刻中，/势若丸走坂。
诗：盈亏自相补，/得失何足算。/餐霞可延年，/饮酒诚自损。
诗：未知辛苦长，/孰若适意短。/二者一何偷，/百年皆不免。
诗：颜回不著述，/后世存愈远。/圣贤非虚名，/惟善为可勉。
诗：仕宦希寸禄，/庶无饥寒迫。/读书事文章，/本以代耕织。
注：事：周本、丛刊本校：“一作为’。”
诗：学成颇自喜，/禄厚愈多责。/挟山以超海，/事有非其力。
诗：君子贵量能，/无轻食人食。
诗：唧唧复唧唧，/夜叹晓未息。/虫声急愈尖，/病耳闻若刺。
诗：壮士易为老，/良时难再得。/日月相随东，/天行自西北。
诗：二者不相谋，/万古无穷极。/安知人间世，/岁月忽已易。

# 吴学士石屏歌
题解：题下周本、丛刊本校：“一作和张生鸦树屏”，一无和”字。”又此诗周本、丛刊本注云“嘉佑元年”作。
诗：晨光入林众鸟惊，/膈膊群飞鸦乱鸣。/穿林四散投空去，/黄口巢中饥待哺。
诗：雌者下啄雄高盘，/雄雌相呼飞复还。/空林无人鸟声乐，/古木参天枝屈蟠。
诗：下有怪石横树间，/烟埋草没苔藓斑。/借问此景谁图写？/乃是吴家石屏者。
注：树：周本、丛刊本校：“一作‘其”。”
诗：号工刳山取山骨。/朝馋暮断非一日，/万象皆从石中出。/吾嗟人愚不见天地造化之初难，
注：造化：周本、丛刊本校：“一作造物”。”衢本“造化造物”连作四字。考异校：“苏州本叠出“造化造物'四字，作十五言一句”
诗：乃云万物生自然。/岂知镌馋刻画丑与妍，/千状万态不可弹，/神愁鬼泣昼夜不得闲。
注：昼：周本、丛刊本校：“一作日”。”
诗：不然安得巧工妙手惫竭思不可到，/若无若有缥缈生云烟。/鬼神功成天地惜，/藏在虢山深处石。
诗：惟人有心无不获，/天地虽神藏不得。/又疑鬼神好胜憎吾侨，/欲极奇怪穷吾才，
注：惟人有心无不获：周本、丛刊本校：“一作乃知人为天地贼”。”
注：地虽神：周本、丛刊本校：“一作“公有物'。”
诗：乃传张生自西来，/吴家学士见且哈，/醉点紫毫淋墨煤。/君才自与鬼神鬬，/嗟我老矣安能陪。
注：乃：周本、丛刊本校：“一作故”。”

# 初食车螯
题解：周本、丛刊本校：“一本题上云京师”。”又此诗周本、丛刊本注云“嘉佑元年”作。
诗：累累盘中蛤，/来自海之涯。/坐客初未识，/食之先叹嗟。
诗：五代昔乖隔，/九州如剖瓜。/东南限淮海。/邈不通夷华。
诗：于时北州人，/饮食陋莫加。/鸡豚为异味，/贵贱无等差。
诗：自从圣人出，/天下为一家。/南产错交广，/西珍富邛巴。
诗：水载每连舳，/陆输动盈车。/溪潜细毛发，/海怪雄须牙。
诗：岂惟贵公侯，/闾巷饱鱼𫚥。/此蛤今始至，/其来何晚邪。
诗：螯蛾闻二名，/车螯一名车蛾。/久见南人夸。/璀璨壳如玉，
诗：斑烂点生花。/含浆不肯吐，/得火遽已呀。/共食惟恐后，
诗：争先屡成哗。/但喜美无厌，/岂思来甚遐。/多惭海上翁，/辛苦靳泥沙。
注：喜：周本、丛刊本卷后校：“一作知’。”

# 送裴如晦之吴江
题解：题下周本、最刊本校：“一本无下三字，注云席上分得已字”。”考共校同此，惟“注云”上有“苏本”三字。又此诗周本、丛刊本注云“嘉佑元年”作。
诗：、鸡鸣车马驰，/夜半声未已。/皇皇走声利，/与日争寸晷。
诗：而我独何为，/闲宴奉君子。/京师十二门，/四方来万里。
诗：顾吾坐中人，/暂聚浮云尔。/念子一扁舟，/片帆如鸟起。
诗：文章富千箱，/吏禄求斗米。/白玉有时沽，/青衫岂须耻。
诗：人生足忧患，/合散乃常理。/惟应当欢时，/饮酒如饮水。

# 盘车图
题解：题下周本、丛刊本校：“一本上题和圣俞”，下注呈杨直讲’。”又此诗周本、丛刊本注云“嘉佑元年”作。
诗：浅山嶙嶙，/乱石矗矗，/山石硗聱车碌碌。/山势盘斜随涧谷，
诗：侧辙倾辕如欲覆。/出乎两崖之隘口，/忽见百里之平陆。/坡长坂峻牛力疲，
诗：天寒日暮人心速，/杨褒忍饥官太学，/得钱买此才盈幅。/爱其树老石硬，
注：褒：周本、丛刊本校：“一作“生”。”
诗：山回路转，/高下曲直，/横斜隐见，/妍媸向背各有态，
诗：远近分毫皆可辨。/自言昔有数家笔，/画古傅多名姓失。/后来见者知谓谁？
注：昔：周本、丛刊本校：“一作古”。”又“有”，李本作“存”。
注：古：周本、丛刊本校：“一作“久”。”
诗：乞诗梅老聊称述。/古画画意不画形，/梅诗咏物无隐情。/忘形得意知者寡，
诗：不若见诗如见画。/乃知杨生真好奇，/此画此诗兼有之。/乐能自足乃为富，
注：乃：周本、丛刊本校：“一作即”。”
诗：岂必金玉名高资。/朝看画，/暮读诗，/杨生得此可不饥。

# 答梅圣俞莫登楼
题解：题中“答梅”下周本、丛刊本校：“一作和”，无梅”字。”又此诗周本、丛刊本注云“嘉佑二年”作。
诗：在礼部贡院锁试进士上元夜作。
诗：莫登楼，/乐哉都人方竞游，/楼阙夜气春烟浮。/玉轮东来从海陬，
诗：纤霭洗尽当空留。/灯光月色烂不收，/火龙衔山祝千秋。/缘竿踏索杂幻优，
诗：鼓喧管咽耳欲咻。/清风袅袅夜悠悠，/莹蹄文角车如流。/娅姹扶阑车两头，
注：莹蹄文：周本、丛刊本校：“一作轮蹄交’。”
诗：凳髦垂鬟娇未羞。/念昔年少追朋俦，/轻衫骏马今则不。/中年病多昏两眸，
诗：夜视曾不如鸺鹠。/足虽欲往意已休，/惟思睡眠拥衾裯。/人心利害两不谋，
诗：春阳稍愆天子忧。/安得四野阴云油，/甘泽以时丰麦麸，/游骑踏泥非我愁。

# 答圣俞莫饮酒
题解：周本、丛刊本注云“嘉佑二年”作。
诗：一此已下皆贡院中作。
诗：子谓莫饮酒，/我谓莫作诗。/花开木落虫鸟悲，/四时百物乱我思。
诗：朝吟摇头暮蹙眉，/雕肝琢肾闻退之。/此翁此语还自违，/岂如饮酒无所知。
注：雕肝琢肾：周本、丛刊本卷后校：“一作雕琢肝肾”。”
诗：自古不饮无不死，/惟有为善不可迟。/功施当世圣贤事，/不然文章千载垂。
注：迟：周本、丛刊本校：“一作“遣”。”
注：然：考异作“愁”
诗：其余酩酊一尊酒，/万事峥嵘皆可齐。/腐肠糟肉两家说，/计较屑层何其卑。
诗：死生寿夭无足道，/百年长短才几时。/但饮酒，/莫作诗，/子其听我言非痴。

# 思白兔杂言戏答公仪忆鹤之作
题解：周本、丛刊本注云“嘉佑二年”作。
诗：君家白鹤白雪毛，/我家白兔白玉毫。/谁将赠两翁，/谓此二物皎洁胜琼瑶。
注：白鹤白雪毛：周本、丛刊本卷后校：“石本作双鹤轻霜毛’。”
诗：已怜野性易驯扰，/复爱仙格何孤高。/玉兔四蹄不解舞，/不如双鹤能清嗥。
诗：低垂两翅趁节拍，/婆娑弄影夸娇娆。/两翁念此二物者，/久不见之心甚劳。
注：节拍：考异校：“苏本作“拍节”。”
诗：京师少年殊好尚，/意气横出争雄豪。/清尊美酒不辄饮，/千金争买红颜韶。
诗：莫令少年闻我语，/笑我乖僻遭讥嘲。/或被偷开两家笼，/纵此二物令逍遥。
诗：兔奔沧海却入明月窟，/鹤飞玉山千仞直上青松巢。/索然两衰翁，/何以慰无戮？
诗：纤腰绿鬓既非老者事，/玉山沧海一去何由招。

# 戏答圣俞
题解：周本、丛刊本注云“嘉佑二年”作。
诗：鹤行而啄，/青玉觜，/枯松脚；/兔蹲而累，
诗：尖两耳，/攒四蹄。/往往于人家高堂净屋曾见之，/锦装玉轴挂壁垂。
注：屋：衢本作“室”，考异校：“家本作“室”。”
诗：乍见拭目犹惊疑，/羽毛掺枞眼睛活，/若动不动如风吹。/主人矜夸百金买，
诗：云此绝笔人间奇。/画师画生不画死，/所得百分三二尔，/岂如玩物玩其真。
诗：凡物可爱惟精神，/况此二物物之珍。/月光临净夜，/雪色凌清晨。
诗：二物于此时，/莹无一黠纤埃尘。/不惟可醒醉翁醉，/能使诗老诗思添清新。
诗：醉翁谓诗老，/子勿诮我愚；/老弄兔儿怜鹤雏，/与子俱老其衰乎！
诗：奈何反舍我，/欲向东家看舞姝。/须防舞姝见客笑，/白发苍颜君自照。
注：向：周本、丛刊本校：“一作去”。”

# 和梅龙图公仪谢鹇
题解：衢本此题无“公仪”二字。又此诗周本、丛刊本注云“嘉佑二年”作。
诗：有诗鹤勿喜，/无诗鹇勿悲。/人禽固异性，/所趣各有宜。
诗：朝戏青竹林，/暮栖高树枝。/咿呦山鹿鸣，/格磔野鸟啼。
诗：声音不相通，/各以类自随。/使鹤居笼中，/垂头以听诗。
注：以：周本、丛刊本校：“一作似”。”
诗：鹞鹧享钟鼓，/鱼鸟见西施。/鹏鹤不宜争，/所争良可知。
诗：蚍蜉与蚁子，/为物固已微。/当彼两交斗，/勇如闻鼓鼙。
诗：有心皆好胜，/未免争是非。/于我一何薄，/于彼一何私。
诗：阑槛啄花卉，/叫号惊睡儿，/跳踉两脚长，/落泊双翅垂。
诗：何足充玩好，/于何定妍媸。/鹇口不能言，/夜梦以告之。
诗：主人起谢鹂，/从我今几时。/僮奴谨守护，/出入烦提携。
诗：逍遥遂栖息，/饮啄安雄雌。/花底弄日影，/风前理毛衣。
诗：岂非主人恩，/报效尔宜思。/主人今白发，/把酒无翠眉。
诗：养鹤鹂又妬，/我言堪解颐。

# 和圣俞感李花
题解：周本、丛刊本注云“嘉佑二年”作。
诗：昨日摘花初见桃，/今日摘花还见李。/晴风暖日苦相催，/春物所余知有几。
注：花：周本、丛刊本卷后校：“一作桃’。”
诗：中年多病壮心衰，/对酒思归未得归。/不及墙根花与草，/春来随处自芳菲。

# 折刑部海棠戏赠圣俞二首
题解：周本、丛刊本注云“嘉佑二年”作。
诗：摇摇墙头花，/笑笑弄颜色。/荒凉众草间，/露此红的烁。
诗：草木本无情，/及时如自得。/青春不可恃，/白日忽已昃。
诗：绕之重吟哦，/归坐成叹息。/人生浪自苦，/得酒且开释。
诗：不见宛陵翁，/作诗头早白。/摇摇墙头花，/艳艳争青娥。
诗：朝见开尚少，/暮看繁已多。/不惜花开繁，/所惜时节过。
诗：昨日枝上红，/今日随流波。/物理固如此，/去来知奈何达人但饮酒，/壮士徒悲歌。
注：去：考异校：“家本作“古”。”

# 刑部看竹效孟郊体
题解：周本、丛刊本注云“嘉佑二年”作。
诗：花妍儿女姿，/零落一何速。/竹色君子德，/猗猗寒更绿。
诗：京师多名园，/车马纷驰逐。/春风红紫时，/见此苍翠玉。
诗：凌乱进青苔，/萧疏拂华屋。/森森日影闾，/濯濯生意足。
诗：幸此接清赏，/宁辞荐芳酥。/黄昏人去锁空廊，/枝上月明春鸟宿
注：黄昏人去：周本、丛刊本校：“一作黄昏寂寂”，一作寂寂人去’。”
