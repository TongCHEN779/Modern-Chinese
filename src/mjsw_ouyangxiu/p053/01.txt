# 居士外集卷二　古诗二十七首
题解：此卷诗，周本、丛刊本注云：“自西京至夷陵作。起明道□年，尽景祐四年。”

# 数诗
诗：一室曾何扫，/居闲俗虑平。/二毛经节变，/青监不须惊。
诗：三复磨圭戒，/深防悔吝生。/四愁宁敢拟，/高咏且陶情。
诗：五鼎期君禄，/无思死必烹。/六奇还自秘，/海寓正休兵。
诗：七日南山雾，/彪文幸有成。/八门当鼓翼，/凌厉指霄程。
诗：九德方居位，/皇猷日月明。/十朋如可问，/从此卜嘉亨。

# 答钱寺丞忆伊川
诗：之子问伊川，/伊川已春色。/绿芷杂芳浦，/青溪含白石。
诗：山阿昔留赏，/屐齿无遗迹。/惟有崑桂花，/留芳待归客。

# 书怀感事寄梅圣俞
题解：周本、丛刊本注云“景佑元年”作。
诗：相别始一岁，/幽忧有百端。/乃知一世中，/少乐多悲患。
诗：平声。/每忆少年日，/未知人事艰。/颠狂无所阂，
注：平声：自注“平声”二字原脱，据周本、丛刊本补。
诗：落魄去羁牵。/三月入洛阳，/春深花未残。/龙门翠郁郁，
诗：伊水清潺潺。/逢君伊水畔，/一见已开颜。/不暇谒大尹，
诗：相携步香山。/自兹惬所适，/便若投山猿。/幕府足文士，
诗：相公方好贤。/希深好风骨，/迥出风尘间。/师鲁心磊落，
诗：高谈羲与轩。/子渐口若讷，/诵书坐千言。/彦国善饮酒，
诗：百盏颜未丹。/几道事闲远，/风流如谢安。/子聪作参军，
诗：常跨破虎鞯。/子野乃秃翁，/戏弄时脱冠。/次公才旷奇，
诗：王霸驰笔端。/圣俞善吟哦，/共嘲为闾仙。/惟予号达老，
诗：醉必如张颠。/洛阳古郡邑，/万户美风烟。/荒凉见宫阙，
诗：表裹壮河山。/相将日无事，/上马若鸿翩。/出门尽垂柳，
诗：信步即名园。/嫩箨筠粉暗，/渌池萍锦翻。/残花落酒面，
诗：飞絮拂归鞍。/寻尽水与竹，/忽去嵩峰巅。/青苍缘万仞，
诗：杳霭望三川。/花草窥涧宝，/崎岖寻石泉。/君吟倚树立，
诗：我醉欹云眠。/子聪疑日近，/谓若手可攀。/共题三醉石，
诗：留在八仙坛。/水云心已倦，/归坐正杯盘。/飞琼始十八，
诗：妖妙犹双环。/寒篁暖凤觜，/银甲调雁弦。/自制《白云曲》，
注：妖妙犹双环：“环”，周本、丛刊本校云“疑”，原校云“当作“鬟”。
诗：始送黄金船。/珠帘卷明月，/夜气如春烟。/灯花弄粉色，
诗：酒红生脸莲。/东堂榴花好，/点缀裙腰鲜。/插花云髻上，
诗：展簟绿阴前。/乐事不可极，/酣歌变为叹。/平声。
注：平声：自注“乎声”二字原脱，据周本、丛刊本补。
诗：诏书走柬下，/丞相忽南迁。/送之伊水头，/相顾泪潜潜。
诗：腊月相公去，/君随赴春官。/送君白马寺，/独入柬上门。
诗：故府谁同在，/新年独未还。/当时作此语，/闻者已依然。

# 杂言答圣俞见寄兼简东京诸友
诗：昔君居洛阳，/乐事无时有。/宝府富文章，/谢墅从亲友。
诗：丰年政颇简，/命驾时为偶。/不问竹林主，/仍携步兵酒。
诗：芬芳弄嘉月，/翠绿相森茂。
注：芬芳弄嘉月：“芳”，周本、丛刊本校：“一作“菲”。”

# 闻梅二授德兴令戏书
题解：题中“令”字原缺，据周本、丛刊本目录补。
诗：君家小谢城，/为客洛阳裹。/绿发方少年，/青衫喜为吏。
诗：重湖乱山绿，/归梦寄千里。/洛浦见秋鸿，/江南老芳芷。
诗：自言北地禽，/能感南人耳。/京国本繁华，/驰逐多英轨。
诗：争歌《白雪》曲，/取酒西城市。/朝逢油壁车，/暮结青聪尾。
诗：岁月倏可忘，/行乐方未已。/忽尔畏简书，/翻然浩归思。
诗：江山故国近，/风物饶阳美。/楚柚烟中黄，/吴荨波上紫。
诗：还乡问井邑，/上堂多庆喜。/离别古所难，/更畏秋风起。

# 戏赠
诗：莫愁家住洛川傍，/十五纤腰闻四方。/堂上金尊邀上客，/门前白马系垂杨。
诗：春风满城花满树，/落日花光争粉光。/城头行人莫驻马，/一曲能令君断肠。

# 寄左军巡刘判官
诗：遥听洛城钟，/独渡伊川水。/绿树郁参差，/行人去无已。
诗：因高望京邑，/驱马沿山趾。/落日乱峰多，/龙门何处是？
注：驱马沿山趾：“趾”原作“址”，据周本、宋刊本、丛刊本改。

# 罢官后初还襄城弊居述怀十韵回寄洛中旧寮
诗：路尽见家山，/欣然望吾庐。/陋巷叩柴扉，/迎候遥惊呼。
诗：儿童戏竹马，/田里邀篮与。/春桑郁已绿，/岁事催农夫。
诗：朝日飞雉雊，/东皋新雨余。/植杖望远林，/行歌登故墟。
诗：夙志在一壑，/兹焉将荷锄。/言谢洛社友，/因招洛中愚。
诗：马卿已倦客，/严安犹献书。/行矣方于役，/岂能遂归欤！

# 和圣俞聚蚊
诗：颓阳照穷巷，/暑退凉风生。/夫子卧环堵，/振衣步前楹。
诗：愁烟四邻起，/鸟雀喧空庭。/余景蔼欲昏，/众蚊复薨薨。
注：众蚊复薨薨：“复”，周本、丛刊本校：“一作聚”。”
诗：群飞岂能数，/但厌声营营。/抱琴不暇抚，/挥麈无由停。
诗：散帙复归卧，/咏言聊写情。/覆载无巨细，/善恶皆生成。
诗：朽木出众蠢，/腐草为飞萤。/书鱼长阴湿，/醯鸡由郁蒸。
诗：豕鬣固多虱，/牛间常聚蝱。/元气或壹郁，/播之为孽腥。
诗：卑臭乃其类，/清虚非所经。/华堂敞高栋，/绮疏仍藻扃。
诗：金釭莹椒壁，/玉壶含夜冰。/终朝事薰祓，/岂敢近檐甍。
诗：富贵非苟得，/抱节居茅衡。/阴墙百虫聚，/下偃众秽盈。
诗：何尝曲肱乐，/但苦聚雷声。/江南美山水，/水木正秋明。
诗：自古佳丽国，/能助诗人情。/喧嚣不可久，/片席何时征？

# 送刘学士知衡州
诗：扬子懒属书，/平居惟嗜酒。/一沐或弥旬，/解醒须五斗。
诗：淡尔轻荣利，/何尝问无有。/忍忆四马归，/行为一麾守。
注：忍忆四马归：“四”，周本、丛刊本校：“一作回’。”
诗：湘酎自古醇，/水闻名久。/簿领但盈几，/圣经不离口。
诗：湖田赋稻蟹，/民讼争珑亩。/兀尔即沈冥，/安能知可否？
诗：聊为寄情乐，/岂与素怀偶。/藏器思适时，/投刃宁烦手。
诗：行当考官绩，/勿复困罂缶！

# 送张屯田归洛歌
题解：周本、丛刊本注云“景佑二年”作。
诗：昔年洛浦见花落，/曾作悲歌歌落花。/愁来欲遗何可奈？/时向金河寻杜家。
诗：杜家花虽非绝品，/犹可开颜为之饮。/少年意气易成欢，/醉不还家伴花寝。
诗：一来京国两伤春，/憔悴穷愁九陌尘。/红房苓紫处处有，/骑马欲寻无故人。
诗：黄河三月入隋河，/河水多时怅望多。/为怜此水来何处，/中有伊流与洛波。
注：何处：“何处”周本、丛刊本校：“一作处远”。”
诗：忽闻君至自西京，/洗眼相看眼暂明。/心衰面老畏人间，/惊我瘦骨清如冰。
诗：今年七月妹丧夫，/稚儿孀女啼呱呱。/季秋九月予丧妇，/十月厌厌成病躯。
诗：端居移病新城下，/日不出门无过者。/独行时欲强高歌，/一曲未终双涕洒。
诗：可怜明月与春风，/岁岁年年事不同。/暂别已嗟非旧态，/再来应是作衰翁。
诗：感时惜别情无已，/无酒送君空有泪。/西归必有问君人，/为道别来今若此。

# 述怀送张总之
题解：“张总之”，周本、丛刊本作“张惣之”。
诗：郁郁河堤绿树平，/送君因得到东城。/落花已尽莺犹啭，/垂柳初长蝉欲鸣。
诗：去年送客亦曾到，/正值杨花乱芳草。/人心不复故时欢，/景物自随时节好。
诗：感今怀昔复伤离，/别相逢知几时？/莫辞今日一尊酒，/明日思君难重持。
注：怀昔复伤离：“复”，周本、丛刊本卷后校：“一作“更”。”
诗：东吴山水天下秀，/羡君轻舟片帆逗。/江城月下夜闻歌，/淮浦山前朝放溜。
诗：乐哉此行时未晚，/万壑千岩不知远。/可怜病客厌京尘，/寂寞淹留已再春。
诗：扁舟待得东南下，/犹更河桥送几人！

# 送子野
诗：四时惨舒不可调，/冬夏寒暑易郁陶。/春阳著物大软媚，/独有秋节最劲豪。
诗：金方坚刚屏炎瘴，/兑气高爽清风飙。/烟霞破散灏气豁，/山河震发地脉摇。
诗：天开实监露寒月，/海拍积雪卷怒潮。/光辉通透夺星耀，/蟠潜惊奋鬬蜃蛟。
诗：高楼精爽毛发竦，/壮怀直恐冲斗杓。/欲飞轻衣上拂汉，/拟乘二气戏鹭涛。
诗：念时文法密於织，/羁縻束缚不自聊。/岂无策议献人主，/扼持舌在口已胶。
诗：当秋且幸际轩豁，/谁能儿女听螗蜩。/君方壮岁襟宇快，/名声乐与家声高。
诗：轻舟从游山川底，/诗酒合兴皆翘翘。/堪嗟宋玉自悲搅，/可并张翰同逍遥。
诗：功名富贵有时到，/忍把壮节良辰消。

# 送刘十三南游
诗：决决汴河流，/橹声过晚浦。/行客问吴山，/舟人多楚语。
诗：春深紫兰泽，/夏早黄梅雨。/时应赋登眺，/聊以忘羇旅。

# 与李献臣宋子京春集东园得节字
诗：绿野秀可餐，/游黪喜初结。/芸局苦寂寥，/禁署隔清切。
诗：欢言得幽寻，/况此及嘉节。/鸟弄已关关，/泉流初决决。
诗：紫萼繁若缀，/翠苕柔可撷。/屡期无后时，/芳物畏题鳩。

# 晚泊岳阳
诗：卧闻岳阳城裹钟，/系舟岳阳城下树。/正见空江明月来，/云水苍茫失江路。
诗：夜深江月弄清辉，/水上人歌月下归。/一阕声长听不尽，/轻舟短楫去如飞。

# 新开棋轩呈元珍表臣
诗：竹树日已滋，/轩窗渐幽兴。/人闲与世远，/鸟语知境静。
诗：春光蔼欲布，/山色寒尚映。/独收万虑心，/於此一枰竞。

# 代赠田文初
题解：周本、丛刊本注云：“景佑四年”作。
诗：感君一顾重千金，/赠君白璧为妾心。/舟中绣被薰香夜，/春雪江头三尺深。
诗：西陵长官头已白，/憔悴穷愁愧相识。/手持玉学唱《阳春》，/江上梅花落如积。
注：穷愁愧相识：“愁”，周本、丛刊本校：“一作颜”。”
诗：津亭送别君未悲，/梦阑酒解始相思。/须知巫峡闻猿处，/不似荆江夜雪时。

# 惠泉亭
题解：题下周本、丛刊本校：“一本序云：“某启。伏睹知军学士丈丈新理惠泉，谨为拙诗十六句，伏惟采览。”
诗：翠壁刻孱颜，/烟霞跬步间。/使君能爱客，/朝夕弄山泉。
诗：春岩雨过春流长，/置酒来听山溜响。/监中楼阁俯清池，/雪裹峰峦开晓幌。
诗：须知清兴无时已，/酒美宾嘉自相对。/席间谁伴谢公吟，/日暮多逢山简醉。
诗：淹留桂树几经春，/野鸟岩花识使君。/使君今是尊前客，/谁与山泉作主人？

# 过张至秘校庄
诗：田家何所乐，/薹笠日相亲。/桑条起蚕事，/菖叶候耕辰。
诗：望岁占风色，/宽徭知政仁。/樵渔逐晚浦，/鸡犬隔前村。
诗：泉溜塍间动，/山田树杪分。/鸟声梅店雨，/野色柳桥春。
诗：有客问行路，/呼童惊候门。/焚鱼酌白醴，/但坐且欢欣。

# 行次叶县
诗：朝渡汝河流，/暮宿楚山曲。/城阴日下寒，/野气春深绿。
诗：征车倦长道，/故国有乔木。/行行渐乐郊，/东风满平陆。

# 将至淮安马上早行学谢灵运体六韵
诗：晴霞煦东浦，/惊鸟动烟林。/曙河兼斗没，/沓嶂隐云深。
注：沓嶂隐云深：“沓”，周本、丛刊本校：“一作杳”。”
诗：寒鸡隔树起，/曲坞留风吟。/征夫倦行役，/秋兴感登临。
诗：衡皋积涂迥，/江蘸香露沈。/行矣岁华晚；/归与劳叹音。
注：衡皋积涂迥：“衡”，周本、丛刊本校：“一作蘅”。”又“涂”，周本、丛刊本校“一作‘滁”；原校“一作除’”。

# 自枝江山行至平陆驿五言二十四韵
题解：“枝”原作“岐”，周本、丛刊本“岐”下校云：“一作枝”。”按历代《地理志》均载“枝江”而无“岐江”，查《宋史·地理志》，“枝江”属江陵府，自枝江至平陆驿于诗义正合，故据改。诗中首句“枝江”亦据此改。
诗：枝江望平陆，/百里千余岭。/萧条断烟火，/莽苍无人境。
诗：峰峦互前后，/南北失壬丙。/天秋云愈高，/木落岁方冷。
诗：水涉愁蜮射，/含沙也。/林行忧虎猛。/万仞悬岩崖，
诗：一约履枯梗。/缘危类猨猱，/陷淖若龜龟。/腰与惧倾扑，
诗：烦马倦鞭警。/攀跻诚畏涂，/习俗羡蛮犷。/度隘足虽豌，
诗：因高目还骋。/九野画荆衡，/群山乱巫郢。/烟岚互明减，
诗：点缀成图屏。/时时度深谷，/往往得佳景。/翠树郁如盖，
注：点缀成图屏：“成”，周本、丛刊本校：“一作若”。”
诗：飞泉溜垂绞。/幽花乱黄紫，/蓓粲弄光影。/山鸟啭成歌，
诗：寒蜩嘻如哽。/登临虽云劳，/巨细得周省。/晨装趁徒旅，
注：登临虽云劳：“劳”，周本、丛刊本校：“一作广”。”
诗：夕宿访闾井。/村暗水茫茫，/鸡鸣星耿耿。/登高近佳节，
诗：归思时引领。/溪菊荐山尊，/田驾佑烹鼎。/家近梦先归，
诗：夜寒衾屡整。/崎岖念行役，/昔宿已为永。/岂如江上舟，
诗：棹歌方酩酊。/初泛舟荆江，/棋酒甚欢，/故有此句。

# 春日西湖寄谢法曹歌
诗：西湖春色归，/春水绿於染。/群芳烂不收，/东风落如糁。
诗：西湖者，/许昌胜地也。/参军春思乱如云，/白发题诗愁送春。
诗：谢君有“多情未老已白发，/野思到春如乱云”之句。/遥知湖上一尊酒，/能忆天涯万里人。
诗：万里思春尚有情，/忽逢春至客心惊。/雪消门外千山绿，/花发江边二月晴。
注：思春尚有情：“春”，周本、丛刊本卷后校：“一作君”。”
诗：少年把酒逢春色，/今日逢春头已白。
诗：异乡物态与人殊，/惟有东风旧相识。

# 答谢景山遗古瓦砚歌
诗：火数四百炎灵销，/谁其代者当涂高。/穷奸极酷不易取，/始知文景基扃牢。
诗：坐挥长喙啄天下，/豪杰竞起如蛔毛。/董吕催汜相继死，/绍术权备争咆咻。
诗：力强者胜怯者败，/岂较才德为功劳。/然犹到手不敢取，/而使螟蝗生蝮蝎。
诗：子丕当初不自耻，/敢谓舜禹传之尧。/得之以此失亦此，/谁知三马食一槽。
诗：当其盛时争意气，/叱咤雷雹生风飙。/干戈战罢数功阀，/周蔑方召尧无皋。
诗：英雄致酒奉高会，/巍然铜雀高山岩。/圆歌宛转激清徵，/妙舞左右回纤腰。
注：致酒：“致酒”，周本、丛刊本、程本卷后校云：“疑是置酒”。”
诗：一朝西陵看拱木，/寂寞总帐空萧萧。/当时凄凉已可叹，/而况后世悲前朝。
诗：高台已倾渐平地，/此瓦一坠埋蓬蒿。/苔文半减荒土蚀，/战血曾经野火烧。
诗：败皮弊网各有用，/谁使锦馋成凸凹。/景山笔力若牛弩，/句遒语老能挥毫。
诗：嗟予夺得何所用，/簿领朱墨徒纷淆。/走官南北未尝舍，/缇袭三四勤缄包。
诗：有时属思欲飞洒，/意绪轧轧难抽缲。/舟行屡备水神夺，/往往冥晦遭风涛。
注：屡备水神夺：“备”，周本、丛刊本校：“一作被”。”
诗：质顽物久有精怪，/常恐变化成灵妖。/名都所至必传玩，/爱之不换鲁宝刀。
诗：长歌送我怪且伟，/欲报惭愧无琼瑶。

# 古瓦砚
诗：砖瓦贱微物，/得厕笔墨间。/於物用有宜，/不计丑与妍。
诗：金非不为实，/玉岂不为坚。/用之以发墨，/不及瓦砾顽。
诗：乃知物虽贱，/当用价难攀。/岂惟瓦砾尔，/用人从古难！
注：乃知物虽贱：“虽”，周本、丛刊本校：“一作微”。”
注：用人从古难：“难”，周本、丛刊本校：“一作然”。”

# 新营小斋凿地炉辄成五言三十九韵
诗：霜降百工休，/居者皆入室。/土堇户畏初寒，/开炉代温律。
诗：规模不盈丈，/广狭足容膝。/轩窗共幽窳，/竹柏助蒙密。
诗：辛勤惭巧官，/穷贱守卑秩。/无街政奚为，/有年秋屡实。
诗：文书少期会，/租讼省鞭扶。/地僻与世疏，/官闲得身佚。
诗：荆蛮苦卑陋，/气候常壹郁。/天日每阴翳，/风飘多凛溧。
诗：衰颜惨时晚，/病骨知寒疾。/蛮牀倦晨兴，/篮与厌朝出。
诗：南山近樵采，/僮仆免呵叱。/御岁畜蹲鹃，/馈客荐包橘。
诗：霜薪吹晶荧，/石鼎沸啾唧。/披方养丹砂，/候节煎去声秋术。
诗：西邻有高士，/撼轲卧蓬摹。/鹤发善高谈，/鲐背便炙熨。
诗：披裘屡相就，/束缇亦时乞。/传经伏生老，/爱酒扬雄吃。
诗：晨灰暖余杯，/夜火爆山栗。/无言两忘形，/相对或终日。
诗：微生慕刚毅，/劲强去声早难屈。/自从世俗牵，/常恐天性失。
诗：仰兹微官禄，/养此多病质。/省躬由一言，/无枉慕三黜。
诗：因知吏隐乐，/渐使欲心窒。/面壁或僧禅，/倒冠聊酒逸。
诗：螟蜢轻二豪，/一马齐万物。/启期为乐三，/叔夜不堪七。
诗：负薪幸有瘳，/旧学颇思述。/兴亡阅今古，/图籍罗甲乙。
注：负薪幸有瘳：“有”，周本、丛刊本校：“一作自'。”
注：今古：“今古”，周本、丛刊本校：“一作“古今”。”
诗：鲁册谨会盟，/周公彖凶吉。/详明左丘辩，/驰骋马迁笔。
注：详明：“详明”，周本、丛刊本校“或作鲜明”，卷后校云“众本皆作鲜明”，唯薛齐谊编年引此诗作详明”。
诗：金石互铿錡，/风云生倏忽。/豁尔一开卷，/慨然时掩帙。
诗：浮沈恣其间，/适若遂聱孔。/吾居谁云陋，/所得乃非一。
注：适若遂聱孔：“聱乳”，周本、丛刊本校：“一作“遨佚”。”
诗：五斗岂须惭，/优游岁将毕。
