# 答原父
题解：题下周本、丛刊本校：“一作答刘廷评”。”又此诗周本、丛刊本注云“皇佑二年”作。
诗：炎歊郁然蒸，/午景炽方焰。/子来清风兴，/萧萧吹几簟。
诗：又如沃琼浆，/遽饮不知厌。/嗟予学苦晚，/白首困铅椠。
诗：危疑奚所质，/孔孟久已窆。/群儒窒自私，/惟子通且赡。
注：奚：周本、丛刊本校：“一作何”。”
诗：幸时丐嬴余，/屡得饱饥歉。/严严《春秋》经，/大法谁敢觇。
注：严严：周本、丛刊本校：“一作“落落”。”
注：大法谁敢觇：句下周本、丛本本校：“一本有譬犹天之苍，乃欲学而染’两句”
诗：三才失纲纪，/五代极昏垫。/盗窃恣肤箧，/英雄争奋剑。
注：纲纪：周本、丛刊本校：“一作纪纲”。”
注：肤：周本、丛刊本校：“一作发”。”
诗：兴亡两仓卒，/事迹多遣欠。/才能纪成败，/岂暇诛奸僭。
注：欠：周本、丛刊本校：“一作贬’。”
诗：闻见患孤寡，/是非谁证验。/尝欣同好恶，/遂乞指瑕玷。
注：寡：周本、丛刊本校：“一作陋”。”
诗：反蒙华衮褒，/如誉嫫母艳。/救非当在早，/已暴何由敛苟能哀废痼，
注：已暴：周本、丛刊本校：“一作暴恶”。”
诗：其可惜针砭。/风舲或许邀，/湖绿方滥滥。

# 虫鸣
诗：叶落秋水冷，/众鸟声已停。/阴气入墙壁，/百虫皆夜鸣。
诗：虫鸣催岁寒，/唧唧机杼声。/时节忽已换。/壮心空自惊。
诗：平明起照镜，/但畏白发生。

# 奉答子华学士安抚江南见寄之作
题解：题中“奉答子华学上”下周本、丛刊本校云“一作答韩绛”见寄之作”下校云“一本无下四字”。又此诗周本、丛刊本注云“皇佑二年”作。
诗：百姓病已久，/一言难遽陈。/良医将治之，/必究病所因。
诗：天下久无事，/人情贵因循。/优游以为高，/宽纵以为仁。
注：高：周本、丛刊本校：“一作政’。”
诗：今日废其小，/皆谓不足论。/明日坏其大，/又云力难振。
诗：旁窥各阴拱，/当职自逡巡。/岁月侵隳颓，/纪纲遂纷纭。
诗：坦坦万里疆，/蚩蚩九州民。/昔而安且富，/今也迫以贫。
诗：疾小不加理，/浸淫将遍身。/汤剂乃常药，/未能去深根。
诗：针艾有奇功，/暂痛勿吟呻。/痛定支体胖，/乃知针艾神。
诗：猛宽相济理，/古语六经存。/蠢弊革侥幸，/滥官绝贪昏。
注：官：周本、丛刊本校：“一作“庸”。”
诗：牧羊而去狼，/未为不仁人。/俊父沉下位，/恶去善乃伸。
诗：贤愚各得职，/不洽未之闻。/此说乃其要，/易知行每艰。
诗：迟疑与果决，/利害反掌间。/舍此欲有为，/吾知力徒烦。
诗：家至与户到，/饱饥而衣寒。/三王所不能，/岂特今所难，
注：特今所难：周本、丛刊本校：“一作独今为'。”
诗：我昔忝谏列，/日常趋紫宸。/圣君尧舜心，/闵闵极忧勤。
诗：子华当来时，/玉音耳尝亲。/上副明主意，/下宽斯人屯。
注：宽：周本、丛刊本卷后校：“一作哀”。”；
诗：江南彼一方，/巨细到可询。/谕以上恩德，/当冬反阳春。
注：询：周本、丛刊本校：“一作‘论’。”
诗：吾言乃其概，/岂止一方云。
注：岂：周本、丛刊本校：“一作非”。”

# 送张洞推官赴永兴经略司
题解：题下周本、丛刊本校：“一本云送张推官掌机宜”。”又此诗周本、丛刊本注云“皇佑二年”作。
诗：自古天下事，/及时难必成。/为谋于未然，/聪者或莫听。
诗：患至而后图，/智者有不能。/未远前日悔，/可为来者铭。
诗：熙熙彼西人，/老死织与耕。/狂氐一朝叛，/烽火四面。
注：氐：原作“羝”，周本、丛刊本校云羝”，一作氐”，据改。
诗：用兵五六年，/首恶竟逃刑。/仰赖天子圣，/乾坤量包并。
诗：苗顽不率德，/舜羽舞于庭。/谓此虽异类，/有生亦含情。
诗：藩篱被触突，/譬若稀与孺。/驯扰以刍豢，/可呼随指令。
诗：称藩效臣职，/冠带复人形。/四海得休息，/疮痍肉新生。
诗：敢问前孰失，/恃安而弛兵。/酒肴为善将，/循默乃名卿。
诗：虑患谓生事，/高谈笑难行。/一方兵遽起，/愚智共营营。
诗：上烦天子仁，/旰食忧吾氓。/谋议及台皂，/幽栖访岩扃。
诗：小利不足为。/涓流助沧溟。/大功难速就，/仓卒始改更。
诗：徒自益纷扰，/何由集功名。/乃知深远画，/施设在安平。
诗：今也实其时，/监前岂非明。/严严经略府，/尊俎集豪英。
诗：千营饱而嬉，/莴马牧在垌。/相公黄阁老，/与国为长城。
诗：张子美而秀，/文章博群经。/从军古云乐，/知己土所荣。
诗：感激报恩义，/当来请长缨。

# 寄圣俞
题解：题下周本、丛刊本校：“一作因马察院至云见圣俞于城东辄书长韵奉寄”。”又此诗周本、丛刊本注云“皇佑二年”作。
诗：凌晨有客至自西，/为问诗老来何稽。/京师车马曜朝日，/何用扰扰随轮蹄。
诗：面颜憔悴暗尘土，/文字光彩垂虹霓。/空肠时如秋蚓叫，/苦调或作寒蝉嘶。
诗：语言虽巧身事拙，/捷径耻蹈行非迷。/我今俸禄饱余剩，/念子朝夕勤盐。
注：俸禄：周本、丛刊本卷后校：“一作禄俸”。”
诗：舟行每欲载米送，/汴水六月干无泥。/乃知此事尚难必，/何况仕路如天梯。
注：天：周本、丛刊本校：“一作丹”。”
诗：朝廷乐善得贤众，/台阁俊彦联簪犀。/朝阳鸣凤为时出，/一枝岂惜容其栖。
诗：古来磊落材与知，/穷达有命理莫齐。/悠悠百年一瞬息，/俯仰天地身醯鸡。
诗：其间得失何足校，/况与凫骛争稗稀。/忆在洛阳年各少，/对花把酒倾玻璃。
注：年各：周本、丛刊本校：“一作“各年”。”
诗：二十年间几人在，/在者忧患多乖暌。/我今三载病不饮，/眼眵不辨蜗与骊。
诗：壮心销尽忆闲处，/生计易足才蔬畦。/优游琴酒逐渔钓，/上下林壑相攀跻。
诗：及身强健始为乐，/莫待衰病须扶携。/行当买田清颖上，/与子相伴把锄犁。
注：强：周本、丛刊本校：“一作壮”。”

# 有马示徐无党
题解：周本、丛刊本注云“至和元年”作。
诗：吾有千里马，/毛骨何萧森。/疾驰如奔风，/白日无留阴。
诗：徐驱当大道，/步骤中五音。/马虽有四足，/迟速在吾心。
诗：六辔应吾手，/调和如瑟琴。/东西与南北，/高下山与林。
诗：惟意所欲适，/九州可周寻。/至哉人与马，/两乐不相侵。
诗：伯乐识其外，/徒知价千金。/王良得其性，/此术固已深。
诗：良马须善驭，/吾言可为箴。

# 天辰
诗：天形如车轮，/昼夜常不息。/三辰随出没，/曾不差分刻。
注：曾不差分刻：句下周本、丛刊本校：“一本有“其行一何勤，干健贵于易’两句”。
诗：北辰居其所，/帝座严尊极。/众星拱而环，/大小各有职。
注：大小：周本、丛刊本校：“一作小大’。”
诗：不动以临之，/任德不任力。/天辰主下土，/万物由生殖。
诗：一动与一静，/同功而异域。/惟王知法此，/所以治万国。

# 再和圣俞见答
题解：周本、丛刊本注云“皇佑二年”作。
诗：两畿相望东与西，/书来三日犹为稽。/短篇投子譬瓦砾，/敢辱报之金里蹄。
诗：文章至宝被埋没，/气象往往干云霓。/飞黄伯乐不世出四顾骧首空长嘶。/嗟哉我岂敢知子论诗赖子初指迷子言古淡有真味，
注：世：周本、丛刊本校：“一作并”。”
注：敢：考异校：“苏本作能”。”
注：诗：周本、丛刊本校：“一作经”。”
诗：太羹岂须调以兹。/怜我区区欲强学，/跛鳖曾不离污泥。/问子初何得臻此，
诗：且能直到无阶梯。/如其所得自勤苦，/何惮入海求灵犀。/周旋二纪陪唱和，
诗：凡翼每并鸾皇栖。/有时争胜不量力，/何异弱鲁攻强齐。/念子京师苦憔悴，
诗：经年陋巷听朝音潮鸡。/儿啼妻噤午未饭，/得米宁择秕与稀。
注：朝：周本、丛刊本校：“一作“晨’。”
注：噤：周本、丛刊本校：“一作“嘻”。”
诗：石上紫豪家故有，/剡藤莹滑如玻璃。/追惟平昔念少壮，/零落生死嗟分睽。
诗：一挥累纸恣奔放，/骏若驾骆仍骖骊。/腹虽枵虚气豪横，/犹胜谄笑病夏畦。
注：骏：周本、丛刊本校：“一作有”。”
诗：名声不朽岂易得，/仕宦得路终当跻。/年来无物不可爱，/花发有酒谁周携。
诗：问我居留亦何事，/方春苦旱忧民犁。

# 感春杂言
题解：周本、丛刊本校：“一本题下有和吕公著”。”又此诗周本、丛刊本注云“皇佑二年”作。
诗：鸠鸣兮屋上，/雀噪兮檐间。/百鸟感春阳，/有如动机关。
诗：雄雌相呼和，/日夕聒聒不得闲。/砌下两株树，/枯条有谁攀。
诗：春风一夜来，/花叶何班班。/乃知天巧
诗：直夺人力，/能使枯木生红颜。/奈何人为万物灵，/不及草木与飞翱。
诗：自从春来何所觉，/但怪睡美不觉白日高南山。/行逢百花不着眼，/岂念四气如回环。
诗：却思年少忆前事，/虽有驵骏难追还。/奈何来日尚可乐，/曾不勉强相牵扳。
注：扳：李本作“攀”。
诗：渌酒如春波，/黄金为谁悭。/人生一世中，/一步百险艰。
注：渌：原误作“绿”据衢本、周本、宋刊本、丛刊本、考异、程本、李本改。
注：步：周本、丛刊本校：“一作笑”。”
诗：俟河之清不可得，/聊自歌此讥愚顽。

# 庐山高赠同年刘中允归南康
题解：周本、丛刊本注云“皇佑三年”作。
诗：庐山高哉，/几千仞兮，/根盘几百里，/嵌然屹立乎长江。
诗：长江西来走其下，/是为扬澜左里兮，/洪涛巨浪日夕相春撞。/云消风止水镜净，
诗：泊舟登岸而远望兮，/上摩青苍以晻随霭，/下压后土之鸿庞。/试往造乎其间兮，
注：青苍：周本、丛刊本校：“一作云霄”。”
注：后：原作“厚”，据衢本、《文粹》、《文鉴》周本、丛刊本改。
诗：攀缘石磴窥空硿。/千岩万壑响松桧，/悬崖巨石飞流淙。/水声聒聒乱人耳，
注：耳：《文鉴》作“语”。考异校：“家本作语”。”
诗：六月飞雪洒石矼。/仙翁释子亦往往而逢兮，/吾尝恶其学幻而言咙。/但见丹霞翠壁远近映楼阁，
诗：晨钟暮鼓杳霭罗幡幢。/幽花野草不知其名兮，/风吹露湿香涧谷，/时有白鹤飞来双。
诗：幽寻远去不可极，/便欲绝世遣纷。/羡君买田筑室老其下，/插秧盈畴兮，
诗：酿酒盈缸。/欲令浮岚暖翠千万状，/坐卧常对乎轩窗。/君怀磊砢有至宝，
诗：世俗不辨珉与丑。/策名为吏二十载，/青衫白首困一邦。/宠荣声利不可以苟屈兮，
诗：自非青云白石有深趣，/其气兀确何由降？/丈夫壮节似君少，/嗟我欲说安得巨笔如长杠！

# 送徐生之渑池
题解：题中“徐生”下周本、丛刊本校：“一作徐无党”。”又此诗周本、丛刊本注云“至和元年”作。
诗：河南地望雄西京，/相公好贤天下称。/吹嘘死灰生气焰，/谈笑暖律回严凝。
诗：曾陪尊俎被顾盼，/罗列台合皆名卿。/徐生南国后来秀，/得官古县依崤陵。
注：名卿：周本、丛刊本校：“一作才能”。”
诗：脚靴手板实卑贱，/贤隽未可吏事绳。/携文百篇赴知己，/西望未到气已增。
诗：我昔初官便伊、洛，/当时意气尤骄矜。/主人乐士喜文学，/幕府最盛多交朋。
注：府：周本、丛刊本卷后校：二作“下气”
诗：园林相映花百种，/都邑四顾山千层。/朝行绿槐听流水，/夜饮翠幕张红灯。
诗：尔来飘流二十载，/鬓发萧索垂霜冰。/同时并游在者几？/旧事欲说无人应。
注：应：衢本作“膺”
诗：文章无用等画虎，/名誉过耳如飞蝇。/荣华万事不入眼，/忧患百虑来填膺。
诗：羡子年少正得路，/有如扶桑初日升。/名高场屋已得隽，/世有龙门今复登。
注：年少：周本、丛刊本校：“一作“少年”。”
诗：出门相送亲与友，/何异篱鹦瞻云鹏。/嗟吾笔砚久已格，/感激短章因子兴。
注：短章：周本、丛刊本校：“一作章句”。”

# 葛氏鼎
题解：“葛氏鼎”，下周本、丛刊本校：“一本有‘歌”字”
诗：大河昔决东南流，/萧条东郡今遣湫。/我从故老问其由，/云古五鼎藏高丘。
诗：地灵川秀草木稠，/郁郁佳气蒸常浮。/惟物伏见数有周，/秘藏奇怪神所搜。
诗：天昏地惨鬼哭幽，/至宝欲出风云愁。/荡摇山川失维陬，/九龙大战驱蛟虬。
诗：剖然岸裂轰云骉，/滑人夜惊鸟嘲啁。/妇走抱儿扶白头，/苍生仰叫黄屋忧。
注：云：周本、丛刊本卷后校：“一作雷”。”
诗：聚徒百万如蚍蜉，/千金一扫随浮沤。/天旋海沸动九州，/此鼎始出人间留。
诗：滑人得之不敢收，/奇模古质非今侔。/器大难用识者不，/以示世俗遭揶揄。
诗：明堂会朝飨诸侯，/饔官百品供王羞。/调以五味烹全牛，/时有用舍吾无求。
注：官：考异校：“宣和本作食’。”
诗：二三子学雕琳球，/见之始惊中叹愀。/披荒斯古争穷搜，/苦语难出声咿暖。
诗：马图出河龟负畴，/自古怪说何悠悠。/嗟吾老矣不能休，/勉强作诗惭效尤。
注：龟：周本、丛刊本校：“一作龙'。”

# 太白戏圣俞
题解：题下周本、丛刊本校：“一作读李白集效其体”。”考异题作“效太白戏圣俞”。
诗：开元无事二十年，/五兵不用太白闲。/太白之精下人间，/李白高歌《蜀道难》。
注：无事：周本、丛刊本校：“一作“太平”。”
诗：蜀道之难难于上青天，/李白落笔生云烟。/千奇万险不可攀，/却视蜀道犹平川。
诗：宫娃扶来白已醉，/醉里诗成醒不记。/忽然乘兴登名山，/龙咆虎啸松风寒。
注：然：周本、丛刊本校：“一作‘来”。”
诗：山头婆娑弄明月，/九域尘土悲人寰。/吹笙饮酒紫阳家，/紫阳真人驾云车。

# 边户
诗：家世为边户，/年年常备胡。/儿僮习鞍马，/妇女能弯弧。
诗：胡尘朝夕起，/虏骑蔑如无。/邂逅辄相射，/杀伤两常俱。
诗：自从澶州盟，/南北结欢娱。/虽云免战斗，/两地供赋租。
注：供：原作“共”，据周本、丛刊本改。
诗：将吏戒生事，/庙堂为远圃。/身居界河上，/不敢界河渔。

# 与子华原父小饮坐中寄同州江十学士休复

# 述怀
题解：周本、丛刊本注云“至和元年”作。
诗：岁律忽其周，/阴风惨辽复。/孤怀念时节，/朽质惊衰病。
诗：忆始来京师，/街槐绿方映。/清霜一以零，/众木少坚劲。
诗：物理固如此，/人生宁久盛？/当时不树立，/后世犹讥评。
诗：愿我实孤生，/饥寒谈孔孟。/壮年犹勇为，/刺口论时政。
诗：中间蒙选擢，/官实居谏诤。/岂知身愈危，/惟恐职不称。
诗：十年困风波，/九死出槛阱。/再生君父恩，/知报犬马性。
诗：归来见亲识，/握手相吊庆。/丹心皎虽存，/白发生已进。
注：生：周本、丛刊本校：“一作日'。”
诗：惭无羽毛彩，/来与鸾皇并。/铩翮追群翔，/孤唳惊众听。
诗：严严玉堂署，/清禁肃而静。/职业愧论思，/文章惭诰命。
诗：厚颜难久居，/归计无荒迳。/偷闲就朋友，/笑语杂嘲咏。

# 和刘原父澄心纸
题解：题下周本、丛刊本校：“一作奉赋澄心堂纸气”又此诗周本、丛刊本注云“至和二年”作。
诗：君不见曼卿子美真奇才，/久已零落埋黄埃。/子美生穷死愈贵，/残章断稿如琼瑰。
诗：曼卿醉题红粉壁，/壁粉已剥昏烟煤。/河倾昆仑势曲折，/雪压太华高崔嵬。
诗：自从二子相继没，/山川气象皆低摧。/君家虽有澄心纸，/有敢下笔知谁战？
诗：宣州诗翁饿欲死，/黄鹄折翼鸣声哀。/有时得饱好言语，/似听高唱倾金累。
注：饿：周本、丛刊本校：“一作饥’。”
诗：二子虽死此翁在，/老手尚能工翦裁。/奈何不寄反示我，/如弃正论求俳诙。
诗：嗟我今衰不复昔，/空能把卷阖且开。/百年干戈流战血，/一国歌舞今荒台。
注：空能：周本、丛刊本卷后校：“一作徒能”。”
诗：当时百物尽精好，/往往遗弃沦蒿莱。/君从何处得此纸，/纯坚莹腻卷百枚。
诗：官曹职事喜闲暇，/台阁唱和相追陪。/文章自古世不乏，/间出安知无后来。
注：喜：周本、丛刊本校：“一作乐”。”
