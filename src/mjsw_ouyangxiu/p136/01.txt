# 后汉沛相杨君碑建宁元年
题解：周本、丛刊本卷后注：“元第十一。”
原：右汉《沛相杨君碑》在阌乡杨震墓侧，碑首尾不完，失其名字。按《后汉书》震及中子秉，秉子赐，赐子彪，皆有传。又云震长子牧富波相，牧孙奇侍中，奇子亮阳成亭侯。又云少子奉，奉子敷，敷子众汆亭侯，又有彪，彪子修。杨氏子孙载于史传者止此尔，不知沛相为何人也？碑云“孝顺皇帝西巡，以掾史召见，拜郎中，迁常山长史，换犍为府丞。宰司累辟，应于司徒。州察茂才，迁嗣阳侯相，后拜议郎、五官中郎将、沛相。年五十六，建宁元年六月癸丑遘疾而卒”。其终始尚可见，而惜其名字亡矣。治平元年六月十日书。
注：六月十日书：周本、丛刊本文末注云“右真迹”，并於卷后附录此文另本作：“右汉《杨君碑》者，其名字皆已摩灭，惟其铭云明明杨君，其姓尚可见尔。其官阀、始卒，则粗可考，云孝顺皇帝西巡，以掾史召见。帝嘉其忠臣之苗，器其璞璠之质，诏鲖拜郎中，迁常山长史，换犍为府丞。非其好也，乃翻然轻举。宰司累辟，应於司徒。州察茂才，迁鲷阳侯相、金城太守。南蛮蠢迪，王师出征，拜车骑将军从事。军还，策勋，复以疾辞。后拜议郎、五宫中郎将、沛相。年五十六，建宁元年五月癸丑遘疾而卒。其终始颇可详见，而独其名字泯灭，为可惜也。是故余尝以谓君子之垂乎不朽者，顾其道如何耳，不托於事物而传也。颜子穷卧陋巷，亦何施於事物邪？而名光后世。物莫坚於金石，盖有时而敝也。治平元年闰五月二十八日书。”

# 后汉郭先生碑
题解：此文诸本载《集古录跋尾》卷三，卷后注“元第五十一”。
原：右汉《郭先生碑》云“讳辅，字辅成。其先出於王季之中子，为文王卿士，食菜於号，后世谓之郭。历战国、秦、汉子孙流分，来居荆上。先生其少也，孝友而悦学；其长也，宽舒如好施。是以宗亲归怀，乡敞高尚。年五十有二，遇疾而终”。其以“而”为“如”，及用“乡敞”字，与《娄寿碑》同，盖汉人如此尔。治平元年六月二十日书。

注：辅成：“辅成”，周本、丛刊本卷后校：“古碑作甫成”。”
注：、秦、汉：“历”，周本、丛刊本卷后校：“一作□。”
注：娄寿碑：“娄寿碑”上周本、丛刊本卷后校：“一有汉’字。”
注：月二十日书：周本、丛刊本卷后校：“二十日，一作二十二日”。”又於文末注云“右真迹”，并收集本此文於后：“右不见书撰人名氏。碑在襄州谷城县界中，其辞云“先生讳辅，字辅成。其先出自有周，王季之中子，为文王卿士，食菜於虢。至於武王，锡而封之，后世谓之郭。春秋之时，为晋所并。历战国、秦、汉，子孙派分，来居荆土，氏国立姓焉。《传》云：圣贤之后，必有达者。先生应焉。孝友而说学，其长也宽舒如好施，是以宗亲归怀，乡尚高尚。年五十有二，遇疾而终。其文字古质，盖汉之碑也。其用乡尚”字，与汉《娄寿碑》同。其曰宽舒如好施，盖以如’字为而’也。《春秋》书星陨如雨，释者曰如，而也。然施於文章以如’为而’，始见於此也。”

# 后汉俞乡侯季子碑
题解：此文诸本载《集古录跋尾》卷三，卷后注“元第九百三十一”。
原：右汉《俞乡侯季子碑》，云“君讳熊，字孟”，下阙一字，“广陵海西人也。·厥祖天皇大帝垂精接感，笃生圣明。子孙享之，分源而流，枝叶扶疏，出王别胤，受爵列土，封侯载德。君，光武皇帝之玄、广陵王之孙、俞乡侯之季子也”。由是而后，文字缺灭。其稍稍可读者，时得其一二，云“六籍五典，如源如泉。既练州郡，卷舒委随，化流南城，政犹北辰。三祀有成，来臻我邦。仁恩如冬日，威猛烈夏日。吏民爱若慈父，畏如神明”。其后又云“采摭谣言，作诗三章。”据碑文无卒葬年月，而其辞若此，似是德政碑。按《后汉书》，光武皇帝子曰广陵思王荆，荆子元寿等四人皆封乡侯，史略而不载其名。俞乡侯者，不知为谁也，思王荆之第几子也。“天皇大帝”之语，自汉以来有矣。治平元年六月五日书。

注：出王别胤：“胤”原作“允”，乃清人避雍正讳所改，据周本、丛刊本改回。按周本避宋太祖讳作“胤”。
注：侯之季子也：“玄”原作“元”，乃清人避讳所改，据周本、丛刊本改回。
注：夏日：“夏日”，周本、丛刊本卷后校：“一作“炎夏”。”
注：天皇：“天皇”至“有矣”十二字，周本、丛刊本校：“一本无此十二字。”
注：六月五日书：周本、丛刊本文末注：“右集本。”

# 后汉杨震碑阴题名
题解：周本、丛刊本卷后注：“元第八百七十一。”
原：右汉《杨震碑》阴题名者一百九十人，其余摩灭不完者又十余人。余家所录汉碑阴题名颇多，或称故吏、门生、弟子，或称从事、曹掾之类，其人皆著州县、邑里、名字甚详。独此碑所书简略，直云“河间贾伯錡、博陵刘显祖”之类，凡百九十人者皆然，疑其所书皆是字尔。盖后汉时人见於史传者，未尝有名两字者也。汉隶世所难得，幸而在者多残灭不完，独此碑刻画完具，而隶法尤精妙，甚可喜也。治平元年中伏日书。

# 后汉碑阴题名一
题解：周本、丛刊本卷后注：“元第八百一。”
原：右汉碑阴题名，不知为何人碑？余家集录古文既多，或失其所得之自。然汉碑存於今者，惟华岳与孔子庙最多，其阴往往列修庙人姓名，并记其所出钱数，不过三百至五百。今斯碑所题文字缺灭，而中间有“钱各五百”四字，则似是修庙人所记。其人可见者，有济阴定陶蔡颢子盛、山阳金乡张谚季德、河南宛陵赵堂世苌、南阳南乡邓升升远、济阴成武周凤季节，而其余人姓名邑里多不完。又时时有“故吏”字，不知为何人祠庙？第以汉隶难得录之尔。治平元年闰五月八日书。
注：武周凤季节：“苌”，周本、丛刊本卷后校：“一作长”。”
注：五月八日书：文末周本、丛刊本注：“右真迹。”

# 后汉公昉碑
题解：周本、丛刊本题下校：“一作《仙人唐君碑》。”卷后注：“元第五百七十一。”
原：右汉《公昉碑》者，乃汉中太守南阳郭芝为公昉修庙记也。汉碑今在者类多摩灭，而此记文字仅存，可读。所谓公昉者，初不载其姓名，但云“君字公昉”尔。又云“耆老相传，以为王莽居摄二年，君为郡吏，啖瓜。旁有真人，左右莫察。君独进美瓜，又从而敬礼之。真人者遂与期谷口山上，乃与君神药曰：服药以后，当移意万里，知鸟兽言语。'是时府君去家七百余里，休谒往来，转景即至。阖郡惊焉，白之府君，徙为御史。鼠啮被具，君乃画地为狱，召鼠诛之，视其腹中果有被具。府君欲从学道，顷无所进，府君怒，敕尉部吏收公昉妻子。公昉呼其师告以厄，其师以药饮公昉妻子，曰：可去矣。'妻子恋家不忍去。於是乃以药涂屋柱，饮牛马六畜。须臾，有大风云来迎公昉妻子，屋宅、六畜修然与之俱去”。其说如此，可以为怪妄矣。呜呼！自圣人殁而异端起，战国、秦、汉以来，奇辞怪说纷然争出，不可胜数。久而佛之徒来自西夷，老之徒起於中国，而二患交攻，为吾儒者往往牵而从之。其卓然不惑者，仅能自守而已，欲排其说而黜之，常患乎力不足也。如公昉之事，以语愚人竖子，皆知其妄矣，不待有力而后能破其惑也。然彼汉人乃刻之金石，以传后世，其意惟恐后世之不信，然后世之人未必不从而惑也。治平元年四月二十二日，以旱开宫寺祈雨五日，中一日休务假书。
注：真人：“真人”下《文粹》有一“居”字。
注：御史：“御史”，周本、丛刊本校：“一作御吏”。”
注：以来：“以来”，《文粹》作“之际”
注：日休务假书：文末周本、丛刊本注：“右真迹。”

# 后汉人阙铭
题解：周本、丛刊本卷后注：“元第七百八十一。”

# 后汉武班碑建和元年
题解：此文诸本载《集古录跋尾》卷三，卷后注云“元第五百五十一”。
原：右汉班碑者，盖其字画残灭，不复成文，其氏族、州里、官阀、卒葬皆不可见，其仅见者曰“君讳班”尔。其首书云“建元年太岁在丁亥”，而“建”下一字不可识。以《汉书》考之，后汉自光武至献帝，以“建”名元者七，谓建武、建初、建光、建康、建和、建宁、建安也。以历推之，岁在丁亥乃章帝章和元年，后六十一年，桓帝即位之明年，改奉初二年为建和元年，又岁在丁亥。则此碑所缺一字当为“和”，字，乃建和元年也。碑文缺灭者十八九，惟亡者多而存者少，尤为可惜也，故录之。治平元年四月二十日书。
注：和”，字：“一字当为和字”，周本、丛刊本校：“真迹无此六字。”按集本有此六字是。
注：建和元年也：“乃”字原脱，据周本、宋刊本、丛刊本补。
注：月二十日书：前段文末周本、丛刊本注：“右集本。”
原：后得别本，摹拓粗明，始辨其一二，云“武君讳班”，乃易去前本。熙宁二年九月朔日记。

# 后汉中常侍费亭侯曹腾碑建元年
题解：此文诸本载《集古录跋尾》卷三，卷后注云“元第一百七十一”。
原：右汉《中常侍费亭侯曹腾碑》文字摩灭，其粗可见者云“维建和元年七月二十二日己巳，皇帝若曰其遗费亭侯之国”，其余不可识也。建和，桓帝即位之元年也。后三十七年，献帝中平元年，腾养子操始为骑都尉，击黄巾矣。治平元年六月十日书。
注：击黄巾矣：“击”上周本、丛刊本校：“集本有‘领兵’二字。”
注：六月十日书：文末周本、丛刊本注：“右真迹。”

# 后汉司隶杨君碑建和二年
题解：此文诸本载《集古录跋尾》卷三，卷后注云“元第六百九十一至六百九十二”。
原：右汉《司隶校尉杨厥碑》，云“惟《灵定位，川泽攸同。泽有所注，川有所通。余谷之川，其泽南隆。八方所达，益城为充。高祖受命，兴於汉中。道由子午，出散入秦。建定帝位，以汉诋焉。后以子午，塗路涩难，更随围谷，复通堂光。凡此四道，垓鬲允艰。至於永平，其有四年，诏书开余，凿通石门。中遭元二，西夷虐残，桥梁断绝，子谷复循。於是故司隶校尉、犍为武阳杨厥，字孟文，深执忠伉，数上奏请，废子由斯，得其度经。至建和二年，汉中太守王升，字稚纪，嘉君明知，美其仁贤，勒石颂德，以明厥勋”。其辞大略如此，其刻画尚完可读，大抵述厥修复斜谷路尔。但其用字简省，复多舛缪，惟以“《”为“坤”，以“余”为“斜”，汉人皆尔，独“诋”字未详。永平，明帝；建和，桓帝年号也。
注：司隶校尉：“司隶校尉”上周本、丛刊本卷后校：“一有故”字。”
注：攸同：“攸同”，周本、丛刊本卷后校：“一作股躬”。”
注：益城为充：“城”，周本、丛刊本卷后校：“一作域’。”
注：桓帝年号也：文末周本、丛刊本注：“右集本。”

# 后汉张公庙碑和平元年
题解：周本、丛刊本卷后注：“元第八百二十一。”
原：右汉《张公庙碑》，在黎阳，而碑无题首，又其文字残灭不可考究，莫知为何碑。第时时得其字之可识而仅成文者曰“惟和平元年正月丙寅”。和平，桓帝年号，以此知为汉碑也。又曰“丰碑庙堂之前”，又曰“於穆张公”，则又知为张公庙碑矣。又曰“国无灾祲，屡获丰年，作歌九章，颂公德芳”。其辞有云：“公与守相驾蜚鱼，往来倏忽远熹娱，佑此兆民宁厥居。”其余字画尚完者甚多，但不成文尔。治平元年闰五月九日书。是日奏事垂拱，退，召赴延和，阅谢契丹礼物，遂归休。
注：国无灾祲：“祲”，周本、丛刊本卷后校：“一作寇’。”
注：遂归休：文末周本、丛刊本注：“右真迹。”

# 后汉鲁相置孔子庙卒史碑元嘉二年
题解：周本、丛刊本卷后注：“元第三百九十一。”
原：右汉《鲁相置孔子庙卒史碑》，云：“司徒臣雄、司空臣戒稽首言：鲁前相瑛书言，诏书崇圣道，孔子作《春秋》，制《孝经》，演《易·系辞》，经纬天地，故特立庙，褒成侯四时来祠，事已即去。庙有礼器，无常人掌领，请置百石卒史一人，典主守庙。谨问。太常祠曹掾冯牟、史郭玄辞对：故事，辟雍祠先圣，太宰、太祝各一人备爵，太常丞监祠，河南尹给牛羊豕，大司农给米。臣愚以为如瑛言可许。臣雄、臣戒愚戆，诚惶诚恐，顿首顿首，死罪死罪，臣稽首以闻。'制曰可。”按《汉书》，元嘉元年吴雄为司徒，二年赵戒为司空，即此云“臣雄、臣戒”是也。鲁相瑛者，据碑言姓乙，字仲卿。汉碑在者多摩灭，此幸完可读，录之以见汉制三公奏事如此，与群臣上尚书者小异也。又见汉祠孔子，其礼如此。治平元年六月二十日书。
注：史郭玄辞对：“玄”原作“元”，乃清人避讳所改，今据周本、宋刊奉、丛刊本改回。
注：月二十日书：文末周本、丛刊本注：“右真迹。”

# 后汉孔德让碑永兴二年
题解：周本、丛刊本题中“碑”下校：“一作碣”。”卷后注：“元第八百五十一。”
原：右汉《孔德让碑》盖其名已摩灭，但云“字德让者，宣尼公二十世孙，都尉君之子也。仕历郡诸曹史，年二十，永兴二年七月遭疾不禄”，碑在今兖州孔子墓林中。永兴，孝桓帝年号也。其人早卒，无事迹可考。余《集录》所藏独阙孔林中汉碑，最后得此，遂无遗者。盖以其文字简少，无事实，故世人遗而不取，独余家有之也。治平元年闰正月二十日书。

注：其人：“其人”，周本、丛刊本校：“一作“德让”。”
注：独阙：“独阙”二字原脱，据周本、宋刊本、丛刊本所校异文补。又汉下周本、丛刊本校：“一无此字。”
注：月二十日书：文末周本、丛刊本注：“右真迹。”

# 后汉修孔子庙器碑永寿二年
题解：周本、丛刊本题中“碑”下校：“一作表”。”卷后注：“元第三百五十一。”
原：右汉《韩明府修孔子庙器碑》，云“永寿二年，青龙在涒滩，霜月之灵，皇极之日”。永寿，桓帝年号也。按《尔雅》云：“岁在申曰君滩。”桓帝永兴三年正月戊申大赦，改元永寿，明年丙申曰“岁在君滩”是矣。云“霜月之灵，皇极之日”，莫晓其义，疑是九月五日。前汉文章之盛，庶几三代之纯深，自建武以后，顿尔衰薄。崔、蔡之徒，擅名当世，然其笔力辞气非出自然，与夫杨、马之言，醇异味矣。及其末也，不胜其弊，“霜月”、“皇极”，是何等语？韩明府者，名敕，字叔节。前世见於史传，未有名敕者，岂自余学之不博乎？《春秋左氏传》载古人命名之说，不以为名者颇多，故以敕为名者少也。治平元年二月晦日书。
注：孔子庙器碑：“汉”下周本、丛刊本校：“一有朝’字。”
注：青龙：“青龙”下周本、丛刊本校：“二字一作岁”。”
注：明年：“明年”下周本、丛刊本校：“一有岁次”二字。”
注：之日：“之日”下，周本、丛刊本卷后校：“一有者”字。”
注：二月晦日书：文末周本、丛刊本注：“右真迹。”

# 后汉樊常侍碑永寿四年
题解：此文诸本载《集古录跋尾》卷三，卷后注“元第一百四十二”。
原：右汉《樊常侍碑》，云“君讳安，字子佑，南阳湖阳人也。君幼学，治《韩诗》、《论语》、《孝经》。历中黄门，拜小黄门、小黄门右史，迁藏府令、中常侍。年五十有六，永寿四年四月甲辰卒”。其先为中黄门，后为小黄门，又为小黄门右史，盖汉官之制今不详其次序也。余少家汉东，天圣四年举进士，赴尚书礼部，道出湖阳见此碑立道左，下马读之，徘徊碑下者久之。后三十年，始得而入《集录》。盖初不见录於世，自予集录古文，时人稍稍知为可贵，自此古碑渐见收采也。嘉佑八年十月十四日书。

注：详其次序也：周本、丛刊本卷后校：“自右汉’至次序也'九十四字，一本无。”
注：湖阳：“湖阳”，周本、丛刊本校：“一本作湖间”。”
注：予集录古文：周本、丛刊本卷后校：“本无录’字。”
注：渐见收采也：周本、丛刊本卷后校：“一无古碑’二字。”

# 后汉孙叔敖碑延熹三年
题解：此文诸本载《集古录跋尾》卷三，卷后注“元第二百八十一”。
原：右汉《孙叔敖碑》，云“名饶，字叔敖”，而《史记》不著其名，而见於他书者亦皆曰“叔敖”而已。微斯碑，后世遂不复知其名“饶”也。此碑世亦罕传，余以《集录》，二十年间，求之博且勤，乃得之。然则世之未见此碑者，犹不知为名“饶”也。谓余集古为无益，可乎？
注：碑世亦罕传：周本、丛刊本校：“集本无此’字。‘亦’，集本作所”。”
注：可乎：周本、丛刊本校：“一本无谓余’至可乎’九字。”文末注：“右真迹。”

# 后汉西岳华山庙碑延熹四年
题解：此文诸本载《集古录跋尾》卷一，卷后注“第八百四十一。”
原：右汉《西岳华山庙碑》，文字尚完可读。其述自汉以来云“高祖初兴，改秦淫祀，太宗承循，各诏有司，其山川在诸侯者，以时祠之。孝武皇帝修封禅之礼，巡省五岳，立宫其下。宫曰集灵宫，殿曰存仙殿，门曰望仙门。中宗之世，使者持节岁一祷而三祠。后不承前，至於亡新，寖用丘虚。建武之元，事举其中，礼从其省，但使二千石岁时往祠。自是以来，百有余年，所立碑石文字摩灭。延禧四年，弘农太守袁逢修废起顿，易碑饰阙。会迁京兆尹，孙府君到，钦若嘉业，遵而成之。孙府君讳谬”。其大略如此。所谓集灵宫者，他书皆不见，惟见此碑，则余之《集录》不为无益矣。治平元年闰五月十六日书。

注：此碑：“此碑”下周本、丛刊本校：“一有尔”字。”
注：不为无益矣：“则余之集录不为无益矣”，周本、丛刊本校：“一无此十字。”

# 后汉郎中郑固碑延熹年间
题解：此文诸本载《集古录跋尾》卷三○题中“固”下校：“一作宣”卷后注：“元第五百四十一。”
原：右汉《郎中郑固碑》，文字摩灭，其官阀、卒葬年月皆莫可考。其仅可见者云“君讳固，字伯坚。孝友著於闺门，至行立乎乡党。初授业於欧阳，仕郡诸曹掾、史、主簿、督邮、五官掾、功曹”，又曰“忠以卫上，清以自修”，其余残缺不复成文。又云“延熹元年二月诏拜”，而不见其官，惟其碑首题云“汉故郎中郑君之碑”，以此知其官至郎中尔。汉隶刻石存於今者少，惟余以集录之勤，所得为独多。然类多残缺不完，盖其难得而可喜者，其零落之余，尤为可惜也。治平元年四月十二日书。
注：功曹：“仕”原误作“住”据周本、宋刊本、丛刊本改。
注：年二月诏拜：周本、丛刊本校：“延熹元年二月，之下，一本云：诏拜郎中。非其好也，以疾锢辞。年四十二，遭命硕身。'而中间又有逡遁退让'之语。遁’当作‘循’，锢’当作固’，疑汉人用字多假借。又疑以疾锢辞’谓疾已坚固，若云以疾笃辞。览者详之。”
注：多残缺不完：“缺”，周本、丛刊本校：“一作减’。”
注：治平元年四月十二日书：“治平元年四月十二日书”十字原脱，据周本、丛刊本卷后所校异文补。

# 后汉桐柏庙碑延熹六年
题解：此文诸本载《集古录跋尾》卷一，卷后注“元第一百九十一”。
原：右汉《桐柏庙碑》，摩灭虽不甚，而文字断续，粗可考次，盖南阳太守修庙碑也。其辞云“延熹六年正月乙酉，南阳太守中山卢奴口君”，“奴”下正阙一字，当是其姓。又云“尊神敬祀，立庙桐柏，春秋宗荣，灾异告变，水旱请求，位比诸侯，圣汉所尊。太守奉祀，二十余年，不复身至，遗承行事，简略不敬，明神弗欧，灾害以生。五岳四渎，与天合德。仲尼慎祭，常若神在。君准则大圣，亲之桐柏，来见庙祠，崎岖逼狭。开拓神门，立阙四望，增广坛场”。又云“执玉以沉，为民祈福，灵只报佑，天地清和”。其大意止於如此。其后有颂，亦可读，第不见太守姓名尔。然不著他事，惟修庙祀神尔。桐柏，淮渎庙也。治平元年六月十三日书。
注：山卢奴口君：“□”缺文，原校：“《文苑》作张”字。”
注：宗荣：“宗荣”，原校：“一作宗奉”
注：圣汉所尊：“尊”，周本、丛刊本校：“一作宗”。”
注：灾害以生：“害”，周本、丛刊本卷后校：“一作异”。
注：立阙四望：“望”，原校：“一作达”。”
注：月十三日书：“日”字原脱，据周本、宋刊本、丛刊奉补。又文末注：“右真迹。”

# 后汉祝睦碑延熹七年
题解：此文诸本载《集古录跋尾》卷三，卷后注“元第三百一十一”。
原：右汉《祝睦碑》，云“君讳睦，字元”，其下遂缺灭，不能成文。惟其官寿年月可见，云“宾于王庭，除北海长史、颖川圆令，辟司空府，北军中候，拜大尚书、尚书仆射，迁常山相、山阳太守。年六十有八，延熹七年八月丁巳卒”。睦有二碑，皆在今南京虞城县。此碑不见世次，而隐隐有云“其先高辛”尔。其后碑则颇完，故录于次也。治平元年六月立秋日书。
注：皆在今：“皆在今”，周本、丛刊本卷后校：“一作“今皆在”。”
注：月立秋日书：文末周本、丛刊本注：“右真迹。”

# 后汉祝睦后碑
题解：此文诸本载《集古录跋尾》卷三，卷后注“元第三百二十一”。
原：右汉《祝睦后碑》其前碑不知所立人名氏，两碑所载官阀、寿考年月悉同。而此碑有立碑人名氏及睦世次，云“故吏王堂等窃闻下有述上之功，臣有叙君之德”，又曰“君兆自黎辛，祝融苗胄，郑有祝聃，君其胤也”。其余文字亦完，可读。二铭皆以三言为文，而后铭尤完，云“穆我君，邦之阳。资五就，阖道纲”，“纲”下灭一字，“□表微，准枢衡。稽列宿，览四方。德合乾，道应皇。领二郡，曜重光。化流治，绲豳昌。性天约，元用长。颂声作，谣令香。功烈著，遗椒芳。存觌荣，沦弗忘”。其后二句摩灭难详。故录其成文，以见其雅质，亦可佳也。治平元年六月立秋日书。
注：君其胤也：“胤”原作“裔”，乃清人避讳所改，今据周本、宋刊本、丛刊本改回。
注：□表微：“表”上原无阙文符号，今据文意补。
注：月立秋日书：文末周本、丛刊本注：“右真迹。”

# 后汉老子铭延熹八年
题解：周本、丛刊本卷后注：“元第一百六十一。”
原：右汉《老子铭》按《桓帝本纪》云：延熹八年正月，遗中常侍左倌之苦县祠老子。至十一月，又遗中常侍管霸祠之。而此碑云“八月梦见老子而祠之”。世言碑铭蔡邕作，今检邕集无此文，皆不可知也。
注：皆不可知也：文末周本、丛刊本注：“右真迹。”

# 后汉尧祠祈雨碑延熹十年
题解：周本、丛刊本卷后注：“元第九百六十一。”
原：右汉《尧祠祈雨碑》，首尾残灭，其仅可识者有云“股肱贤良，广祈多福，虔虔夙夜”又云“常以甲子日，诏太常陈上古之礼，舞先王之乐”，又云“延熹十年仲春二月，阳气侵阴”，又云“享祀群神，仰瞻云汉”，又曰“嘉澍优沾，利茂万物”，又云“孟府君知尧精灵，与天通神，修治大殿”。以此知为祈雨於尧祠也。尧祠在汉济阴郡。孟府君者，当是济阴郡太守也。其余隶字完者颇多，亦往往成句，但断续不可次序尔。治平元年六月六日书。
注：又曰：“曰”，周本、丛刊本卷后校：“一作“云”。”
注：六月六日书：文末周本、丛刊本注：“右集本。”
