# 远山
诗：山色无远近，/看山终日行。/峰峦随处改，/行客不知名。

# 宋宣献公挽词三首
题解：周本、丛刊本注云“康定元年”作。
诗：望系朝廷重，/文推天下工。/清名畏杨绾，/故事问胡公。
诗：物议垂为相，/风流顿已穷。/仁言博哉利，/献替有遣忠。
诗：识度推明哲，/风猷蔼缙绅。/何言止中寿，/遂不秉洪钧。
诗：翰墨时争宝，/词章晚愈新。/哭哀文伯母，/悲感路傍人。
诗：结发逢明主，/驰声著两朝。/奠楹先有梦，/升屋岂能招。
注：发：周本、丛刊本校：“一作“绶”。”
诗：赠服三公衮，/兼荣七叶貂。/春风笳鼓咽，/松柏助萧萧。

# 初出真州泛大江作
题解：周本、丛刊本注云“景佑三年”作。
诗：孤舟日日去无穷，/行色苍茫杳霭中。/山浦转帆迷向背，/夜江看斗辨西东。
诗：滤田渐下云间雁，/霜日初丹水上枫。/尊菜鲈鱼方有味，/远来犹喜及秋风。

# 江行赠雁
题解：周本、丛刊本注云“景佑三年”作。
诗：云间征雁水间栖，/矰缴方多羽翼微。/岁晚江湖同是客，/莫辞伴我更南飞。
注：征：周本、丛刊本卷后校：“一作秋”。”

# 松门
题解：“松门”，题下周本、丛刊本校：“以下五首一本属夷陵九咏”。”又自“松门”至“黄溪夜泊”五首，周本、丛刊本注云“景佑四年”作。
诗：岛屿松门数里长，/悬崖对起碧峰双。/可怜胜境当穷塞，/翻使留人恋此邦。
注：境：周本、丛刊本校：“一作景”。”
注：留：周本、丛刊本校：“一作流”。”
诗：乱石惊滩喧醉枕，/浅沙明月入船窗。/因游始觉南来远，/行尽荆江见蜀江。

# 下牢津
诗：依依下牢口，/古戍郁嵯峨。/入峡江渐曲，/转滩山更多。
诗：白沙飞白鸟，/青障合青萝。/迁客初经此，/愁词作楚歌。
注：障：周本、丛刊本校：“一作“嶂’。”
注：初：衢本作“多”。周本、丛刊本校：“一作“尝”。”

# 龙溪
诗：潺潺出乱峰，/演漾绿萝风。/浅濑寒难涉，/危槎路不通。
诗：朝云起潭侧，/飞雨遍江中。/更欲寻源去，/山深不可穷。
注：去：衢本作“上”。

# 劳停驿
诗：孤舟转山曲，/豁尔见平川。/树杪帆初落，/峰头月正圆。
诗：荒烟几家聚，/瘦野一刀田。/行客愁明发，/惊滩鸟道前。

# 黄溪夜泊
诗：楚人自古登临恨，/暂到愁肠已九回。/万树苍烟三峡暗，/满川明月一猿哀。
诗：非乡况复惊残岁，/慰客偏宜把酒杯。/行见江山且吟咏，/不因迁谪岂能来。
注：江山：李本作“山河”。

# 望州坡
题解：周本、丛刊本注云“景佑三年”作。
诗：闻说夷陵人为愁，/共言迁客不堪游。/崎岖几日山行倦，/却喜坡头见峡州。
注：为：原作“易”，据周本、丛刊本、程本、李本改。
