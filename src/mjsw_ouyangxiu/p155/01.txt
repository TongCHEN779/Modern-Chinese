# 天爵诗
诗：茂哲时皆仰，/荣名世所传。/为仁勤在己，/列爵贵在天。
诗：舜德行无倦，/颜贫乐自全。/达尊非以位，/生德乃推贤。
注：舜德行无倦：“德”，宋刊本原校：“一作智”。”
诗：且异诸侯赐，/高居百行先。/孟轲思劝善，/深旨著遗篇，
注：深旨著遗篇：宋刊本原注：“见仙梯省题诗。嘉佑六年，江南郭祥正作序。”
原：宋刊本《欧阳文忠公集》卷七十四后续添。

# 诗一首
题解：《敬斋古今黈拾遗》载：欧阳永叔戏为诗……小儿初作字，点画稍多即难措笔，必简易则为力。欧公此诗，当为儿辈设也。
诗：文出升平世，/禾生大有年。/四克今日月，/六合古山川。
诗：反朴次三五，/古文丁一千。/王功因各定，/大作不相沿。
诗：主化布于下，/人心孚自天。/上方求士切，/公亦立仁先。
诗：才行苟并至，/位名尤两全。/末由弓冶手，/安比父兄肩。
诗：幸及布衣仕，/宜希守令先。/尺刀元并用，/丹白具同研。
诗：去吏多甘老，/休兵坐力田。/干戈包已久，/永卜本支延。
原：清陆心源辑《敬斋古今黈拾遗》卷一。

诗：文章自古无凭据，/唯愿朱衣一点头。
原：宋吕祖谦《诗律武库》卷四。

题解：周本、丛刊本卷五十七后续校云：“嘉佑三年二月，公馆伴北使在都亭驿，有《戏寄梅圣俞绝句》。圣俞集中次韵云：去年锁宿得联华，二月墙头始见花。今日都亭公感物，明朝太学我辞家。'公诗无之。”

# 词

# 渔家傲十二首
题解：此《渔家傲》十二首，续添於宋刊本《近体乐府》卷二后，并於词牌下注云：京乐本《时贤本事曲子后集》云：欧阳文忠公，文章之宗师也。其於小词，尤脍炙人口。有十二月词，寄《渔家傲》调中，本集亦未尝载。“列之於此。前已有十二篇鼓子词，此未知果公作否’。”

# 一
诗：正月新阳生翠琯，/花苞柳线春犹浅。/帘幕千重方半卷，/池水泮，
诗：东风吹水琉璃软。/渐好凭阑醒醉眼，/陇梅暗落芳英断。/初日已知长一线，
诗：清宵短，/梦魂怎奈珠宫远。

# 二
诗：二月春期看已半，/江边春色青犹短。/天气养花红日暖，/深深院，/真珠帘额初飞燕。
诗：渐觉衔杯心绪懒，/酒侵花脸娇波慢。/一捻闲愁无处遗，/牵不断，/游丝百尺随风远。

# 三
诗：三月芳菲看欲暮，/胭脂泪洒梨花雨。/宝马绣轩南陌路，/笙歌举，/踏青鬬草人无数。
诗：强欲留春春不住，/东皇肯信韶容故。/安得此身如柳絮，/随风去，/穿帘透幕寻朱户。

# 四
诗：四月芳林何悄悄，/录阴满地青梅小。/南陌采桑何窈窕，/争语笑，/乱丝满腹吴蚕老。
诗：宿酒半醒新睡觉，/雏莺相语匆匆晓。/惹得此情萦寸抱，/休临眺，/楼头一望皆芳草。

# 五
诗：五月薰风才一信，/初荷出水清香嫩。/乳燕学飞帘额峻，/谁借问，/东邻期约尝佳酝。
诗：漏短日长人乍困，/裙腰减尽柔肌损。/一撮眉尖千累恨，/慵整顿，/黄梅雨细多闲闷。

# 六
诗：六月炎蒸何太盛，/海榴灼灼红相映。/天外奇峰千掌迥，/风影定，/汉宫圆扇初成咏。
诗：珠箔初褰深院静，/绛绡衣窄冰肤莹。/睡起日高堆酒兴，/厌厌病，/宿酲和梦何时醒。

# 七
诗：七月芙蓉生翠水，/明霞拂脸新妆媚。/疑是楚宫歌舞妓，/争宠丽，/临风起舞夸腰细。
诗：乌鹊桥边新雨霁，/长河清水冰无地。/此夕有人千里外，/经年岁，/犹嗟不及牵牛会。

# 八
诗：八月微凉生枕簟，/金盘露洗秋光淡。/池上月华开宝监，/波潋艳，/故人千里应凭槛。
诗：蝉树无情风苒苒，/燕归碧海珠帘拚。/沉臂冒霜潘鬓减，/愁黯黯，/年年此夕多悲感。
注：冒霜潘鬓减：“沉”下原校云“疑”。

# 九
诗：九月重阳还又到，/东篱菊放金钱小。/月下风前愁不少，/谁语笑，/吴娘捣练腰肢袅。
诗：槁叶半轩慵更扫，/凭阑岂是闲临眺。/欲向南云新雁道，/休草草，/来时觅取伊消耗。

# 十
诗：十月轻寒生晚暮，/霜华暗卷楼南树。/十二阑干堪倚处，/聊一顾，/乱山衰草还家路。
诗：悔别情怀多感慕，/胡笳不管离心苦。/犹喜清宵长数鼓，/双绣户，/梦魂尽远还须去。

# 十一
诗：律应黄钟寒气苦，/冰生玉水云如絮。/千里乡关空倚慕，/无尺素，/双鱼不食南鸿渡。
诗：把酒遗愁愁已去，/风摧酒力愁还聚。/却忆兽炉追旧处，/头懒举，/炉灰剔尽痕无数。

# 十二
诗：腊月年光如激浪，/冻云欲折寒根向斗。/谢女雪诗真绝唱，/无比况，/长堤柳絮飞来往。
注：折寒根向斗：“向”下原校云“疑”。
诗：便好开尊夸酒量，/酒阑莫遗笙歌放。/此去青春都一饷，/休怅望，
诗：瑶林即日堪寻访。/以上宋刊本《近体乐府》卷二。

# 千秋岁二首

# 一
诗：汆衫满袖，/尽是忆伊泪。/残妆粉，/余香被。
诗：手把金尊酒，/未饮先如醉。/但向道，/厌厌成病皆因你。
诗：离思迢迢远，/一似长江水。/去不断，/来无际。

诗：一去音书歇。/到而今，/高梧冷落西风切。/未语先垂泪，
诗：滴尽相思血。/魂欲断，/情难绝。/都来些子事，
诗：更与何人说。/为个甚，/心头见底多离别。

# 看花回

诗：春思无托。/追想少年，/何处青楼贪欢乐。/当媚景，

# 蝶恋花四首

# 一
诗：几度兰房听禁漏。/臂上残妆，/印得香盈袖。/酒力融融香汗透，/春娇人眼横波溜。
诗：不见些时眉已皱。/水阔山遥，/乍向分飞后。/大抵有情须感旧，/肌肤拚为伊销瘦。

# 二　咏枕儿
诗：宝琢珊瑚山样瘦。/缓髻轻拢，/一朵云生袖。/昨夜佳人初命偶，/论情旋旋移相就。
诗：几叠鸳衾红浪皱。/暗觉金钗，/磔磔声相扣。/一自楚台人梦后，/凄凉暮雨沾祸绣。

# 三
题解：《全芳备祖》有题作《荷花》。
诗：一掬天和金粉腻，/莲子心中，/自有深深意。/意密莲深秋正媚，/将花寄恨无人会。
注：一掬天和：“一掬天和”，《全芳备祖》作“一曲天香”。
诗：桥上少年桥下水。/小棹归时，/不语牵红袂。/浪溅荷心圆又碎，/无端欲伴相思泪。

# 四
诗：百种相思千种恨。/早是伤春，/那更春醪困。/薄幸辜人终不愤，/何时枕畔分明问。
诗：懊恼风流心一寸。/强醉偷眠，/也即依前闷。/此意为君君不信，/泪珠滴尽愁难尽。

# 武陵春
诗：宝幄华灯相见夜，/妆脸小桃红。/斗帐香檀翡翠笼，/携手恨忽忽。
诗：金泥双结同心带，/留与记情浓。/却望行云十二峰，/肠断月斜钟。/以上《醉翁琴趣外篇》卷一。

# 梁州令
诗：红杏墙头树，/紫萼香心初吐。/新年花发旧时枝，/徘徊千绕，
诗：独共东风语。/阳台一梦如云雨，/为问今何处。/离情别恨多少，/条条结向垂杨缕。
诗：此事难分付，/初心本谁先许。/窃香解佩两沉沉，/知他而今，
诗：记得当初否。/谁教薄幸轻相误，/不信道相思苦。/如今却恁空追悔，/元来也会忆人去。

# 渔家傲五首

# 一
题解：此首《花草粹编》卷七误作颖上陶生词。《全芳备祖》有题作《荷花》。
诗：为爱莲房都一柄，/双苞双蕊双红影。/雨势断来风色定，/秋水静，/仙郎彩女临鸾镜。
注：秋水：“秋水”，《全芳备祖》作“池水”。
诗：妾有容华君不省，/花无恩爱犹相并。/花却有情人薄倖，/心耿耿，/因花又染相思病。
注：恩爱犹相并：“无”《全芳备祖》作》“今”。

# 二
诗：昨日采花花欲尽，/隔花闻道潮来近。/风猎紫荷声又紧，/低难奔，/莲茎刺惹香腮损。
诗：一缕艳痕红隐隐，/新霞点破秋蟾晕。/罗细挹残心不稳，/羞人间，/归来剩把胭脂衬。

# 三
诗：一夜越溪秋水满，/荷花开过溪南岸。/贪采嫩香星眼慢，/疏回眄，
诗：郎船不觉来身畔。/罢采金英收玉腕，/回身急打船头转。/荷叶又浓波又浅，
诗：无方便，/教人只得抬娇面。

# 四
题解：此首《花草粹编》误作颖上陶生词。
诗：近日门前溪水涨，/郎船几度偷相访。/船小难开红斗帐，/无计向。/合欢影裹空惆怅。

# 水调歌头和苏子美沧浪亭词
题解：宋刊本於《近体乐府》卷三后续添此词，并注云：“此词截《兰畹集》第五卷，重押“凉”字，疑。”《全宋词》列此词於尹洙名下，且按云：“此首原作欧阳修词，见《近体乐府》卷三引《兰畹集》。龚鼎臣《东原录》引吴王去后四字句，云是尹师鲁和苏子美《水调歌头》。今从之。”按尹洙（师鲁）除此署名有争之词外，别无一词传世。
诗：万顷太湖上，/朝暮浸寒光。/吴王去后、台榭千占镇悲凉。/谁信蓬山仙子，
诗：天与经纶才器，/等闲厌名韁。/敛翼下霄汉，/雅意在沧浪。
诗：晚秋裹，/烟寂静，/雨微凉。/危亭好景、佳树修竹遶回塘。
诗：不用移舟酌酒，/自有青山录水，/掩映似潇湘。/莫问平生意，/别有好思量。
原：宋刊本及影宋本《近体乐府》卷三。
