# 居士外集卷五　律诗五十八首
题解：此卷诗，周本、丛刊本注云：“未第时及西京作。天圣、明道间。”

# 汉宫
诗：桂馆神君去，/甘泉辇道平。/翠华飞盖下，/豹尾属车迎。
诗：晓露寒浮掌，/光风细转旌。/廊回偏费步，/珮远尚闻声。
诗：玉树人间老，/珊瑚海底生。/金波夜夜意，/偏照影娥清。

# 送刘半千平阳簿假道归故里
诗：岭梅归驿路迢迢，/越鸟巢倾木半乔。/松径就荒聊应召，/桂丛留隐定相招。
诗：家庭噪鹊争谊树，/夜帐惊猿自拥条。/何处秋风催客鬓，/青丝恐逐物华凋。
注：恐逐物华凋：“凋”，周本、丛刊本校：“一作“销”。”

# 楼头
诗：百尺楼头万叠山，/楚江南望隔晴烟。/云藏白道天垂幕，/帘卷黄昏月上弦。
诗：桑落蒲城催熟酒，/柳衰章陌感凋年。/发光如葆宁禁恨，/不待为郎已飒然。

# 夕照
诗：夕照留歌扇，/余辉上桂丛。/霞光晴散锦，/雨气晚成虹。
诗：燕下翻池草，/乌惊傍井桐。/无僇照湘水，/丹色映秋枫。

# 送张学士知郢州
诗：汉郎清晓赤墀趋，/楚老西来望隼旗。/侍史护衣薰蕙草，/辘轳要剑从骊驹。
诗：阳春绕雪歌低扇，/油幕连云水泛渠。/千里修门对涔浦，/好寻遗玦吊三闾。

# 晓咏
诗：帘外星辰逐斗移，/紫河声转下云西。/九雏乌起城将曙，/百尺楼高月易低。
诗：露鸭兰苕惟有泪，/秋荒桃李不成蹊。/西堂吟思无人助，/草满池塘梦自迷。

# 禁火
诗：火禁开何晚，/春芳半已凋。/柳风兼絮坠，/榆雨带钱飘。
诗：泪翦兰膏尽，/弦亏桂魄消。/祓兰流水曲，/游禊一相招。

# 送赵山人归旧山
诗：屈贾江山思不休，/霜飞翠葆忽惊秋。/吟抛楚畹兰苕老，/归有淮山桂树留。
诗：聒耳春池蛙两部，/比封秋坞橘千头。/嗔条怒颖真堪愧，/莫染衣尘更远游。

# 闲居即事
诗：巷有容车陋，/门无载酒过。/池喧蛙怒雨，/客去雀惊罗。
诗：握臂如枝骨，/哀弦系箸歌。/无僇漳浦卧，/还似咏中阿。
注：哀弦系箸歌：“系”，周本、丛刊本校：“一作“击”。”

# 伤春
诗：蕙兰蹊径失芳期，/风雨春深怯减衣。/卷箔高楼惊燕入，/挥弦远目送鸿归。
诗：蜂催酿蜜愁花尽，/絮扑暄条妬雪飞。/欲识伤春多少恨，/试量衣带忖腰围。

# 公子
诗：黄山开苑腊初回，/绛树分行舞递来。/下马春场鸡鬬距，/鸣弦初日雉惊媒。
诗：犀投博齿呼成白，/桥隔车音听似雷。/不问春蚕眠未起，/更寻桑陌到秦台。

# 夜意
诗：蕙炷炉薰断，/兰膏烛艳煎。/夜风多起籁，/晓月渐亏弦。
诗：鹊去星低汉，/鸟啼树暝烟。/惟应墙外柳，/三起复三眠。

# 寄张至祕校
诗：关山一里一重愁，/念远伤离两未休。/南陌望穷云似帐，/西楼吟断月如鈎。
诗：柳绵飞后春应减，/兰径荒时客倦游。/拟寄东流问沟水，/亦应沟水更东流。
注：飞后春应减：“后”，周本、丛刊本校：“一作处’。”

# 寄徐巽秀才
诗：瑶花飞雪荡离愁，/鸭鸠惊风下绿畴。/睢苑树荒谁共客，/楚江枫老独悲秋。
诗：千重锦浪翻如箭，/万叠春山翠入楼。/章陌柳条今在否，/定临沟水拂东流。

# 寄刘昉秀才
诗：丝路萦回细入云，/离怀南陌草初薰。/茂林修竹谁同禊，/明月春萝定勒文。
诗：燕忆铜鞮来不定，/鸿归碣石信难分。/东风莺友应相望，/懊恼孤飞不及群。

# 送客回马上作
诗：南浦空波绿，/西陂夕照寒。/瑶华伤远道，/芳草送归鞍。
诗：翠敛遥山叠，/氛收古泽宽。/衰容畏秋色，/不及楚枫丹。

# 西征道中送陈舅秀才北归
诗：棋墅风流谢舅贤，/发光如葆惜穷年。/人随黄鹄飞千里，/酒满栖乌送一弦。
诗：望驿早梅迎远使，/拂鞍衰柳拗归鞭。/越禽胡马相逢地，/南北思归各黯然。
诗：送目送目衡皋望不休，/江高下遍汀洲。/长堤柳曲妨回首，/小苑花深碍倚楼。
注：衡皋望不休：“衡”，周本、丛刊本校：“一作“蘅”。”
诗：楚径蕙风消病渴，/洛城花雪荡春愁。/流杯三日佳期过，/掷度兰波负胜游。

# 春晓
诗：小阁回残梦，/开帘转晓辉。/露寒风不定，/花落鸟惊飞。
诗：病渴偏思柘，/朝寒怯减衣。/无钱将谢雪，/持底送春归？
注：病渴偏思柘：“柘”，周本、丛刊本校：“一作蔗”。《楚辞》、《汉志》作柘”，《晋书》、《杜诗》作“蔗”。”按“柘”、“蔗”两通。

# 刘秀才昉宅对弈
诗：乌巷招邀谢墅中，/紫囊香珮更临风。/尘惊野火遥知猎，/目送云罗但听鸿。
注：野火遥知猎：“野”，周本、丛刊本校：“一作烽”。”
诗：六着比犀鸣博胜，/百娇柘矢捧壶空。/解衣对子欢何极，/玉井移阴下翠桐。
注：百娇：“百娇”，丛刊本卷后校：“疑用《西京杂记》百骁事。”

# 送李实
诗：几幅归帆不暂停，/吴天遥望斗牛横。/香薰翠被乘青翰，/波暖屏风咏紫茎江水自随潮上下，
诗：月轮闲与蚌亏盈。/河桥折柳伤离后，/更作南云万里行。

# 早夏郑工部园池
诗：夜雨残芳尽，/朝辉宿雾收。/兰香才馥径，/柳暗欲翻沟。
诗：夏木繁堪结，/春蹊翠已稠。/披襟楚风快，/伏槛更临流。
注：春蹊翠已稠：“蹊”，周本、丛刊本校：“一作畦’。”

# 舟中寄刘昉秀才
诗：东南天阔漾归流，/西北云高断寸眸。/明月随人来远浦，/青山答鼓送行舟。
诗：归心逐梦成鱼鸟，/夜汉看星识斗牛。/酿酒开尊谁共醉，/清江聊且玩游鯈。
注：开尊谁共醉：“酿”，丛刊本作“严”。
注：聊且玩游鯈：“游修”，周本、丛刊本校：“一作“修游”。”

# 月夕
诗：月气初升海，/屏光半隐扉。/寒消觉春尽，/漏永送筹稀。
诗：兰烛风惊烬，/烟帘雾湿衣。/清羸急宽带，/频减故时围。

# 奉送叔父都官知永州
诗：虎头盘绶贵垂绅，/青组名郎领郡频。/画鹉千艘随下濑，/听鸡五鼓送行人。
诗：楚波漾楫萍如日，/淮月开蛉蚌有津。/千里壶浆民咏溢，/墙乌旗隼下汀。
诗：绿树低昂不自持，/河桥风雨弄春丝。/残黄浅约眉双敛，/欲舞先夸手小垂。
诗：快马折鞭催远道，/落梅横笛共余悲。/长亭送客兼迎雨，/费尽春条赠别离。

# 舟中望京邑
诗：东北归川决决流，/泛艎青渚暂夷犹。/遥登灞岸空回首，/不见长安但举头。
诗：挥手嵇琴空堕睫，/开尊鲁酒不忘忧。/青门柳色春应遍，/犹自留连杜若洲。

# 小圃
诗：桂树鸳鸯起，/兰苕翡翠翔。/风高丝引絮，/雨罢叶生光。
诗：蝶粉花沾紫，/蜂茸露湿黄。/愁醒与消渴，/容易为春伤。

# 即目
诗：李径阴森接翠畴，/押帘风日澹清秋。/晚乌藏柳栖残照，/远燕伤风失故楼。
诗：星汉经年虽可望，/云波千叠不缄愁。/平居革带频移孔，/谁问无惨沈隐侯。

# 南征道寄相送者
诗：楚天风雪犯征裘，/误拂京尘事违游。/谢墅人归应作咏，/灞陵岸远尚回头。
诗：云含江树看迷所，/目逐归鸿送不休。/欲借高楼望西北，/亦应西北有高楼。

# 楚泽
诗：宿莽湘累怨，/幽兰楚俗谣。/紫屏空自老，/翠被岂能招？
诗：欲就苍梧诉，/愁迷澧浦遥。/哀猿羌昼晦，/悲鸠众芳凋。
诗：红壁丹砂板，/琼鈎翡翠翘。/如何搴香杜，/江上独无僇。
注：香杜：“香杜”，周本、丛刊本校：“一作“杜若”。”
诗：题金山寺地接龙宫涨浪赊，/鹫峰岑绝倚云斜。/岩披宿雾三竿日，/路引迷人四照花。
诗：海国盗牙争起塔，/河童施鉢但惊沙。/春萝攀倚难成去，/山谷疏钟落暮霞。

# 送窦秀才
诗：晴原高下细如鳞，/树转城回路欲分。/望月西楼人共远，/跃鞍南陌草初薰。
诗：短亭山翠偏多叠，/送目鸿惊不及群。/一驿赋成应援笔，/好凭飞翼寄归云。

# 旅思
诗：调苦歌非乐，/歧多泪始零。/羞弹长铗剑，/终恋五侯鲭。
诗：陌草薰沙绿，/江枫照岸青。/南陔动归思，/兰叶向春馨。

# 仙意
诗：孤桐百尺拂非烟，/凤去鸾归夜悄然。/沧海风高愁燕远，/扶桑春老记蚕眠。
诗：槎流千里才成曲，/桂魄经旬始下弦。/独有金人寄遗恨，/晓盘云泪冷涓涓。

# 闻朱祠部罢浔州归阙
诗：汉柱题名墨未乾，/南州坐布政条宽。/岭云路隔梅欹驿，/使驯秋归柳拂鞍。
诗：建礼侵晨趋冉冉，/明光赐对佩珊珊。/颖川此召行闻拜，/冠颊凝尘俟一弹。

# 倦征
诗：沈约伤春思，/嵇含倦久游。/帆归黄鹤浦，/人滞白洲。
注：帆归黄鹤浦：“鹤”，周本、丛刊本校：“一作“苇”。”
诗：乳燕差池远，/江禽格磔浮。/物华真可玩，/黑鬓恐逢秋。

# 郑驾部射圃
诗：梦草西堂射圃连，/兰苕初日露华鲜。/晕含画的弦开月，/牙算行筹酒满船。
诗：镂管思催吟韵剧，/妓帘阴薄舞衣翩。/当筵独愧探牛炙，/俭府芙蓉客尽贤。

# 甘露寺
诗：云树千寻隔翠微，/给园金地敞仁祠。/讲花飘雨诸天近，/春漏欹莲白日迟。
诗：引鉢当空时取露，/残灰经劫自成池。/危阑徙倚吟忘下，/九子铃寒塔影移。

# 送友人南下
诗：河桥别柳减春条，/隔浦挐音听已遥。/千里羹夸敌酪，/满池虎稻欲鸣蜩。
诗：东风楚岸神灵雨，/残月吴波上下潮。/如吊湘累搴香若，/秋江斜日驻兰桡。
注：湘累搴香若：“香”，周本、丛刊本校：“一作“杜”。”

# 高楼
诗：六曲雕阑百尺楼，/帘波不定瓦如流。/浮云已映楼西北，/更向云西待月鈎。

# 榴花
诗：絮乱丝繁不自持，/蜂黄蝶紫燕参差。/榴花最恨来时晚，/惆怅春期独后期。

# 宿云梦馆
诗：北雁来时岁欲昏，/私书归梦杳难分。/井桐叶落池荷尽，/一夜西窗雨不闻。

# 郸鹉
题解：“鹉”，周本、丛刊本校：“一作鳩”。”
诗：花残如霰落纷纷，/紫陌空遗翠幰尘。/鸭鹉枉缘催节物，/年华不信有伤春。
诗：银蒜钩帘宛地垂，/桂丛乌起上朝辉。/枉将玳瑁雕为押，/遮掩春堂碍燕归。

# 行云
诗：叠叠烟波隔梦思，/离愁几日减腰围。/行云自亦伤无定，/莫就行云托信归。

# 琵琶亭上作
诗：九江烟水一登临，/风月清含古恨深。/湿尽青衫司马泪，/琵琶还似雍门琴。
诗：雨阔堤长走画辕，/絮兼梨雪坠春烟。/东风苑外千丝老，/犹伴吴蚕尽日眠。
注：梨雪坠春烟：“坠”，丛刊本作“堕”。

# 井桐
诗：檐欹碧瓦拂倾梧，/玉井声高转辘鲈轳。/肠断西楼惊稳梦，/半留残月照啼乌。

# 雪中寄友人
诗：楚岸梅香半入衣，/冻云银铄晓光飞。/遥应便面逢人处，/走马章街失路归。

# 与谢三学士绛唱和八首
题解：周本、丛刊本注云“明道元年”作。

# 和国庠劝讲之什
诗：春尽沂风暖，/芹生泮水清。/双旌荣照路，/博带俨盈庭。
诗：函丈师临席，/锵金壁有经。/诸生拜玉衮欣识象丘形。
注：诸生拜玉衮：“玉”周本、丛刊本校：“一作王”。”

# 和游午桥庄
诗：晓坛初毕祀，/弭盖共寻幽。/鸟弄林中出，/泉声冰下流。
诗：攀条惊雪尽，/翻袂爱风柔。/好驻城南马，/春桑遍陌头。
注：春桑遍陌头：“春”，周本、丛刊本校：“一作秦”。”

# 和龙门晓望
诗：水雾濛濛晓望平，/悠然驱马独吟行。/烟岚明灭川霞上，/凌乱空山百鸟惊。

# 除夜偶成拜上学士三丈
诗：万瓦青烟夕霭生，/斗杓迎岁转东城。/隋宫守夜沉香燎，/楚俗驱神爆竹声玉树罗阶家宴盛，
诗：羽觞称寿彩衣荣。/九门朝客思公甚，/向晓天风舞雪灵。

# 陪饮上林院后亭见樱桃花悉已披谢因成七言四韵
诗：寻芳长恨见花迟，/岂意看花独后期。/试藉落英聊共醉，/为怜残萼更攀枝。
诗：清香肯以无人减，/幽艳惟应有蝶知。/开谢两堪成怅望，/伤春不到柳丝时。

# 昨日偶陪后骑同适近郊谨成七言四韵兼呈圣俞
诗：堤柳才黄已落梅，/寻芳弭盖共徘徊。/桑城日暖蚕催浴，/麦龙风和雉应媒。
诗：别浦人嬉遗翠羽，/弋林春废锁歌台。/归鞍暮逼宫街鼓，/府吏应惊便面回。

# 和八月十五日斋宫对月
诗：皓月三川静，/晴氛万里销。/灵光望日满，/寒色入波摇。
诗：灏气成山雾，/浮云蔽珑苗。/庙荒阴燐出，/苑废露萤飘。
诗：斋馆心方寂，/秋城夜已遥。/清谈对元亮，/琼彩映萧萧。

# 送学士三丈
题解：题下原注：“此首已载《居士集》第十卷，今并存之。”周本於诗后注云：“已上八篇，《居士集》只载后一篇，其不同者五字，而题云送谢希深”按即《送谢学士归阙》。今诸本皆作送王学士’疑希深第“三'，讹为王'耳。”
诗：供帐洛城边征辕去莫攀人醒风外酒，/马度雪中关。/故府谁同在，/新年独未还。
注：洛城边：“洛城边”，另首作“拂朝烟”，丛刊本校：“一作“拂云烟”。”
注：征辕去莫攀：“辕”另首作“鞍”。
注：故府谁同在：“故”，另首作“旧”。
诗：遥应行路者，/偏识彩衣斑。
