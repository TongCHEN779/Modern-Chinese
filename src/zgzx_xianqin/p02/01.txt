# 古代无神论和唯物主义的萌芽
原：我国最早的无神论和唯物主义的史料，保存在古代流传下来的典籍《诗经》《书经》《左传》和《国语》中，这此典籍也是研究我国奴隶制社会的重要资料。
原：《诗经》是我国最古的一部诗歌总集，它产生的年代大约是西周初期到春秋末期，约当公元前一○六六年到前五四一年前后。《诗经》流传到现在的有三百零五篇，分风（十五国风）、雅（大雅、小雅）、颂（周颂、鲁颂、商颂）三部分。这些诗篇不仅是我国古代最优美的文艺作品，并且也广泛地反映了当时的社会状况，其中也包含了很多古代哲学思想资料。这里所节选的几篇，反映了奴隶制时期无神论思想的萌芽，以及对暴君和奴隶主贵族的抗议。在《瞻卬》《云汉》《荡》《节南山》《雨无正》《十月之交》等诗篇中，咒骂了上天和上帝，指出上帝是不仁慈的、不公正的，甚至是暴虐的；人们从灾荒、社会政治的黑暗等痛苦遭遇中，否定了“天命”信仰的权威，甚至认为社会的混乱只是人自己造成的。在《大东》《伐檀》《硕鼠》等诗篇中，控诉了贵族对人民的压迫，谴责了奴隶主不劳而获的剥削生活，要求摆脱剥削和压迫，向往一种自由幸福的世界。这些诗篇是我国思想史上最早的富有人民性和革命性的宝贵文献。
原：《左传》是解释鲁国史籍《春秋》的一部编年史书，汉代的历史学家刘向、班固都认为是鲁太史左丘明写的，唐宋的学者如赵匡、王安石都否认这种说法，清末学者康有为更武断地认定是西汉末年刘歆所伪造。关于《左传》的作者和成书的年代，一直成了争论未决的问题，但大体说来，这部史书是陆续形成的；全书完成可能在战国时代。这部书除了记载春秋时期的历史事件而外，还记述了当时人物的言论，保存了有关当时哲学思想的一此片段材料。这里所选的几段，标志着奴隶制动摇时期无神论观点的萌芽和发展。在“季梁论祀神”一节中，指出人民是鬼神所凭依的，鬼神所享的丰美祭物是人民劳动生产的结果，所以统治者必须首先使人民能够过着美好的生活，然后才有资格事奉鬼神，认为人民比鬼神更重要，这实际上反映了奴隶制时期神权政治的动摇和没落。在“臧文仲论巫尪”一节中，认为只要人们努力于节约增产，就可以减轻干旱所造成的灾害，而神巫是无能为力的。臧文仲是当时比较开明的贵族，从他的言论中可以看出，古代无神论观点的产生是和当时生产力的发展有着一定的联系。在“子产论天道”一节中，提出了“天道远，人道迩”的说法。当时所谓“天道”一是指占星术者依据天体的运行推测人事的吉凶祸福。子产怀疑“天道”，重视人事，实际上否定了占星术和福善祸淫的迷信。子产是郑国的大政治家，他的许多政治措施反映了当时新兴的土地占有者和工商业者的利益。从这段材料中可以看出，古代无神论思想的产生和发展，也是和奴隶制社会中进步的新兴势力联系在一起的，也可以看出古代天文科学知识的发展促进了迷信神秘主义的动摇。
原：《国语》也是先秦时期的一部史书，按司马迁的说法是左丘明编纂的，这部书大概也是战国时代形成的。它的特点在于按国家分别地记述了春秋时期的历史情况，而且着重地记载了当时人物的言论。这部史书也包含着有关古代哲学思想的材料。这里所选“伯阳父论地震”一段，是我国历史上最早的关于阴阳学说的文献，里面指出地震是由于阴阳两种对立势力失调而引起的，实际上企图用自然界本来所固有的两种物质势力的互相排挤和消长来说明自然现象变化的原因，这是一种原始的唯物主义观点。伯阳父的言论中还夹杂着一些天人感应的迷信，这表明当时的唯物主义的观点尙处在萌芽的状态。“史伯论五材”一段，是关于古代五行学说的较早的文献，在这段材料中，比较明确地提出了事物是由水、火、木、金、土五种物质组合而成的说法，并且认为只有不同性质的东西相结合，事物才能得到生长和发展，这同样是一种原始的唯物主义观点。从史伯的谈话中可以看出，当时讲五行学说的人还没有摆脱“天命”信仰的影响。在伯阳父和史伯的论点中，也都含有一些自发的辩证法因素的萌芽。
原：《书经》是我国奴隶制时代统治者讲话、告示等官方文件的一部总集，其中包括着夏、商、周三个王朝的政治文献，是研究中国奴隶社会的政治制度和神权政治思想的重要资料。这部书也是陆续形成的，其中有此篇出于后人的假托，但商书和周书大部分是可靠的。周书《洪范》保存了古代五行学说的一此片断材料，从这些材料可以看出，“五行”就是人们日常生活中常见的和不可缺少的五种物质形态，“五行”一观念的形成和生产实践有着密切的联系。《洪范》的作者还依据“五行”的观点，对某些自然现象和社会现象进行了分类，企图说明世界的构成是有秩序的，但其中也夹杂了神秘主义的成份。

# 瞻卬
题解：诗经　大雅　选三章　节录　据阮刻十三经注疏本
诗：（一章）瞻卬昊天，/则不我惠。/孔塡不宁，/降此大厉。/邦靡有定，/士民其瘵。/蟊贼蟊疾，/靡有夷届。/罪罟不收，/靡有夷瘳。
注：诗经：分风、雅、颂三部分，这种分法大约和音乐的区分有关。风有十五国风，是各地方的民歌；雅是正的意思，是周人所认为的正声，是周王朝京师附近的乐歌，大雅的时代比小雅早；颂是周代祭祀用的舞曲。这些作品除了少数是出自贵族文人之手外，大都是民歌。
注：卬：同“仰”。
注：昊：音皓。昊天，天之泛称，犹如说上天、苍天。
注：孔：甚，很。塡音尘，久。孔塡，很久。
注：瘵：音际。病敌。
注：夷：助词，没有实际意义。届，止境。
注：罪罟：害人的罗网。
注：瘳：音抽，病好了。
诗：（二章）人有土田，/女反有之。/人有民人，/女复夺之。/此宜无罪，/女反收之。/彼宜有罪，/女复说之。
注：女：同“汝”。
注：说：同“脱”，赦免，逃脱于刑罚。
诗：（六章）天之降罔！/维其优矣。/人之云亡！/心之忧矣！/天之降罔！/维其几矣。/人之云亡！/心之悲矣！
注：罔：同“网”。
注：优：宽。
注：几：危险。

# 瞻卬（译文）
诗：（一章）我抬起头来瞻望苍天，/老天爷，你对我们没有一点恩惠！/人民长时期不安定，/老天爷降下了大灾害；/国中到处不安静，/士民都在活受罪。/你们就像一群损害庄稼的害虫，/这样的损害一直没有停止；/你们又遍地撒下了害人不浅的罗网，/这样的罗网一直没有收起。
诗：（二章）别人有土地，/你反把它占有；/别人有民人，/你反把他刼走；/这些人应该无罪，/你倒把他拘留；/那些人应该有罪，/你倒把他放走。
诗：（六章）老天撒下网罗，/这么多的网罗呀，/好人全都逃走！/好教人心里忧愁！/老天撒下网罗，/好危险的网罗啊，/好人全都跑光！/好教人心里悲伤！

# 云汉
题解：诗经　大雅　选一章
诗：（二章）旱既大甚！/蕴隆虫虫，/不殄禋祀，/自郊徂宫。/上下奠瘗，/靡神不宗。/后稷不克，/上帝不临。/耗斁下土，/宁丁我躬！
注：大：同“太”。
注：蕴隆：郁闷的样子。虫虫，暑热的样子。
注：殄：音塡上声，尽，绝。不殄，没有间断。
注：奠：把祭物摆在神前。瘗，音意，把祭物埋在土里。这里“奠瘗”都指祭祀而言。
注：斁：音亦，败坏。

# 云汉（译文）
诗：（二章）旱哪！早呀！旱得太厉害，/闷热！闷热！热气腾腾往上冲。/祭祀嘛我一直没有间断过，/从郊外直到老祖宗的庙堂中；/对上我祭祀了天，对下我又祭祀了地；/没有那一位神我没尊崇。/老祖宗后稷不管事，/老天爷的神灵也不降下来。/下方的土地都干坏了！/为什么在我身上竟遇到这样大的灾？

# 十月之交
题解：诗经　小雅　选一章
诗：（七章）黾勉从事，/不敢告劳。/无罪无辜，/谗口嚣嚣。/下民之孽，/匪降自天。/噂沓背憎，/职竞由人！

# 大东
题解：诗经　小雅　选二章
诗：（一章）有饛簋飧，/有捄棘匕。/周道如砥，/其直如矢。/君子所履，/小人所视。/睠言顾之，/潸焉出涕。
注：饛：音蒙，器皿盛物满满的样子。“有”字在这里作虚词，和形容词、副词连用，下“有”字同。
注：捄：音求，长长的样子。
诗：（四章）东人之子，/职劳不来。/西人之子，/粲粲衣服。/舟人之子，/熊罴是裘；/私人之子，/百僚是试。
注：东人：东方诸国的人。
注：来：慰劳。
注：舟：假借为“周”。
注：私人：家臣。
注：百僚：百官。试，试用。

# 伐檀
题解：诗经　魏风　选一章
诗：（一章）坎坎伐檀兮，/寘之河之干兮，/河水清且涟猗。/不稼不穑，/胡取禾三百廛兮？/不狩不猎，/胡瞻尔庭有县貆兮？/彼君子兮，/不素餐兮！
注：坎坎：斧头砍树木的声音。
注：廛：孔颖达《毛诗正义》说，周朝的田制，农夫一户从官家领受一百亩田和在田里的住宅，通叫做“尘”。马瑞辰《毛诗传笺通释》说，三百廛就是下大夫向三百户农夫收取的产品。
注：狩：郑玄《毛诗笺》说，冬天打猎叫做狩，夜里打猎叫做猎，这是相对的提法，一般狩猎也常常通用，没有区别。
注：貆：音喧，兽名，与貛同。

# 季梁论祀神
题解：左传　据阮刻十三经注疏本
原：楚武王侵随，使远章求成焉，军于瑕以待之，随人使少师董成。
原：鬬伯比言于楚子曰：“吾不得志于汉东也，我则使然。我张吾三军而被吾甲兵，以武临之，彼则惧而协以谋我，故难间也。汉东之国，随为大。随张，必弃小国，小国离，楚之利也。少师侈，请羸师以张之。”熊率且比曰：“季梁在，何益？”鬬伯比曰：“以为后图，少师得其君。”
原：王毁军而纳少师。少师归，请追楚师。随侯将许之，季梁止之曰：“天方授楚，楚之羸，其诱我也，君何急焉？臣闻小之能敌大也，小道大淫。所谓道，忠于民而信于神也。上思利民，忠也；祝史正辞，信也。今民馁而君逞欲，祝史矫举以祭，臣不知其可也。”公曰：“吾牲轻肥腯，粢盛丰备，何则不信？”对曰：“夫民，神之主也，是以圣王先成民而后致力于神。故奉牲以告曰‘博硕肥腯’，谓民力之普存也，谓其畜之硕大蕃滋也，谓其不疾瘊蠡也，谓其备腯咸有也。奉盛以告曰‘絜粢丰盛’，谓其三时不害而民和年丰也。奉酒醴以告曰‘嘉栗旨酒’，谓其上下皆有嘉德而无违心也。所谓馨香，无谗慝也。故务其三时，修其五教，亲其九族，以致其禋祀，于是乎民和而神降之福，故动则有成。今民各有心，而鬼神乏主，君虽独丰，其何福之有？君姑修政而亲兄弟之国，庶免于难。”
注：肥腯：牷音全。牲牷，纯色而完整的猪牛羊。肥，指牛羊肥；腯音钝，指猪肥。
注：粢盛：盛在祭器里的供神的谷物。
注：音触：蠡，瘰之借字，音裸。瘰，皮肤病。
原：随侯惧而修政，楚不敢伐。（桓公六年）

# 季梁论祀神（译文）
原：楚武王将要侵犯随国，先派大夫远章假装去修好，把军队驻禁在瑕的地方，等着随国派大夫少师去主持这修好的事情。
原：鬬伯比向楚王说：“我们所以不能在汉水以东一带达到我们的目的，是由我们自己造成的。我们夸耀我们的军力，配备上武装，拿武力去压迫他们，他们害怕，只好团结起来对付我们，所以我们很难找到下手的机会。汉水以东的国家，随国最大，要是随国骄傲自大，一定会撇开那此小国，小国跟它分裂，对楚国是有利的。少师这人相当骄傲，我们可以把军队假装成衰弱的样子，让他见了更助长他的骄气。”熊率且比说：“随国有个季梁在那儿，这样作有什么用呢？”鬬伯比说：“这是为将来打算，因为这位少师比季梁更得他们国君的信呢！”
原：楚王就把军队假装成衰弱无能的样子接见了少师。少师回到随国，就请求追击楚国的军队，随侯快要答应了，季梁拦阻他，说：“天意正在帮助楚国，他们军队的疲弱无用，是假装出来诱惑我们的，您何必急急忙忙呢？我听说小国所以能够对抗大国，由于小国能守正义，大国却暴虐。所谓正义，是对百姓能够忠诚，对神祇能够信实。在上边的君主常常想怎样使人民有利，才算是忠诚；管祭祀的祝官和史官，宣读的祝词真实不欺，才算是信实。现在我们的人民挨饿，而君上却尽情享乐，祝官和史官的祝词全是编造的诳话，我不知道我们怎么能够抵抗大国！”随侯说：“我们祭祀用的牛、羊、猪三牲完整肥大，黍稷丰满整齐，怎能说不信实呢？”季梁回答说：“人民是神祇的依靠，所以好的君主必须首先完成对于人民有利的大事，才虔诚地去祭祀神祇。在他献三牲的时候，祝告神祇说：‘谨献又完整又肥大的三牲。’这是表明人民的经济力量普遍充实，所以牲口繁殖，而且长得肥大，没有生过一点毛病，又有各式各样的好品种。献黍稷的时候，祝告神祇说：‘谨献清洁丰盛的黍稷。’这是表明春夏秋三季都没有受到灾害，人民和睦，年成丰收。献酒的时候，祝告神祇说：‘诚心恭敬地献甜美芳香的酒。’这是表明君臣上下各级官员都有完善的德行，没有不良的心思。所谓酒物等的丰美芳香，不单是说祭品的美好，更是指我们这里没有一个坏人。所以君上必须管好人民的三季农事，整顿好五教（父义、母慈、兄友、弟恭、子孝），亲睦自己的亲族，然后尽力敬祀神祇，才能够使人民都和睦，神祇也会赐福，因而干什么都可以成功。现在呢，人民各有各的打算，鬼神失去了依靠，您的祭品虽然特别丰盛，怎能求到什么福？您应该先整顿好国内的政治，跟兄弟国家互相亲善，或者可以避免灾难的到来。”
原：随侯感到本国的情形确实可怕，赶紧整顿国内的政治，楚国也就不敢来侵犯。（桓公六年）

# 臧文仲谏焚巫尪
题解：左传　据阮刻十三经注疏本
原：夏，大早，公欲焚巫一。
注：巫：《礼·檀弓》：“岁早，穆公召县子而问焉，曰：‘天久不雨，吾欲暴迂。’又曰：‘然则吾欲暴巫。’”巫是女巫；尪音汪，是面向天的残疾人。
注：节俭：。
原：臧文仲曰：“非旱备也。修城郭，贬食，省用，务穑三，劝分，此其务也。巫尪何为？天欲杀之，则如勿生；若能为旱，焚之滋甚。”
注：如：应当。
原：公从之。是岁也，饥而不害。（僖公二十一年）

# 臧文仲谏焚巫尪（译文）
原：夏天大旱，鲁僖公为了要消灭旱灾，打算把女巫和面向天的残疾人烧死。
原：臧文仲说：“这不是消灭旱灾的办法。修治城郭，省吃俭用，厉行节俭，劝大家有无相济，才是正当的事。女巫和残疾人能够做些什么呢？如果天要杀他们，那应当不生他们；如果他们能够造成旱灾，那么用火烧他们，会逼得他们更加作怪，旱灾会更加厉害。”
原：僖公听从了臧文仲的话，这一年粮食收成虽然不好，人民却没有受到大害。（僖公二十一年）

# 子产论天道
题解：左传　据阮刻十三经注疏本
原：冬，有星孛于大辰，西及汉…郑裨灶言于子产曰：“宋、衞、陈、郑将同日火。若我用瓘斝玉瓒，郑必不火。”子产弗与。
注：大辰：星的位次，代表大火。
注：汉：银河，在箕斗之间。
注：瓘：音贯，玉珪。斝音贾，玉杯。瓒，玉勺。
注：见同：“现”。
原：夏五月，火始昏见四。丙子，风。
原：梓慎曰：“是谓融风，火之始也。七日，其火作乎！”
注：融风：东北风。
原：戊寅，风甚。壬午，大甚。宋、衞、陈、郑皆火。梓愼登大庭氏之库以望之，曰：“宋、衞、陈、郑也。”数日，皆来告火。
注：告火：这是说四国都到鲁国报告火灾，乃鲁史记事之词。
原：裨灶曰：“不用吾言，郑又将火。”郑人请用之，子产不可。
原：子大叔曰：“宝以保民也。若有火，国几亡，可以救亡，子何爱焉？”
注：有：同“又”。
原：子产曰：“天道远，人道迩，非所及也，何以知之？灶焉知天道？是亦多言矣，岂不或信！”遂不与，亦不复火。（昭公十八年）

# 子产论天道（译文）
原：鲁昭公十七年冬天，有一个彗星扫射到代表大火的大辰星位上，向西直射到银河边。郑国的裨灶对子产说道：“宋国、衞国、陈国、郑国将在同一天发生火灾。如果让我拿祭祀用的玉珪、玉杯、玉勺来解除邪气，郑国一定可以不发生火灾。”可是子产没有把这些宝物给他。
原：十八年夏五月，火星开始在傍晚出现。丙子日，飚起风来了。
原：鲁国的大夫梓愼说：“这叫融风，是火灾的开始。七天之后，恐怕要发生大火灾吧！”
原：戊寅日，风飚的很厉害，到壬午日，风更厉害了，这天宋、衞、陈、郑四国都发生火灾。梓慎登上了大庭氏的仓库去瞭望，说道：“这是在宋国、衞国、陈国、郑国。”过了几天，四国果然都到鲁国来报告发生火灾的事。
原：郑国的大夫裨灶说：“如果还不肯听从我的话，郑国怕还要发生第二次的大火灾。”郑国的人都请求子产采用裨灶的意见，可是子产还是不答应。
原：子大叔说：“宝物原是为了要保衞人民，假如再遭一次火灾，国就差不多要亡了，既然可以救亡，你又何必舍不得这宝物呢？”
原：子产说：“天道太远了，人道却是近的，远的我们捉摸不到，怎么能够知道呢？神灶那里真晓得天道，只是他连说了好多次，难道不会偶然被他说中一次吗？”一终不把宝物给他，郑国也没有发生第二次火灾。（昭公十八年）

# 伯阳父论地震
题解：国语　据黄丕烈仿宋本
原：幽王二年，西周三川二皆震。伯阳父曰：“周将亡矣！夫天地之气，不失其序；若过其序，民乱之也。阳伏而不能出，阴迫而不能烝，于是有地震。今三川实震，是阳失其所而镇阴也。阳失而在阴，川源必塞；源塞，国必亡。夫水土演而民用也，水土无所演，民乏财用，不亡何待！昔伊洛竭而夏亡，河竭而商亡。今周德若二代之季矣，其川源又塞，塞必竭。夫国必依山川，山崩川竭，亡之征也。川竭，山必崩。若国亡，不过十年，数之纪二也。夫天之所弃，不过其纪。”
注：三川：指泾、渭、洛三水。
注：数：从一起算，到十而重，自一起，故十为一纪。
原：是岁也，三川竭，岐山崩。十一年，幽王乃灭，周乃东迁。（《周语》）

# 伯阳父论地震（译文）
原：周幽王二年，西周泾水、渭水、洛水三川流域都发生地震。
原：伯阳父说：“周朝将要亡了！天气在上，地气在下，本来各有一定的位置，不能错乱的，如果错乱了位置，那是被人搅乱的。阳气伏在下面，不能透露，被阴气压迫得不能蒸发，这就要发生地震。现在三川流域发生了地震，就是由于阳气错乱了位置，被阴气压住了的缘故。阳气不在上面，却处在阴气的下面，水源一定会被阻塞，水源阻塞，国家一定会灭亡。水本来可以浸润着土，让人民用来生产，土得不到水的浸润，不能生产，人民就要缺乏物资的供给，国家怎么不要灭亡呢？从前伊水、洛水干枯了，夏朝就灭亡；黄河的水干枯了，商朝就灭亡。如今周朝的政治，也正和夏、商两朝的末年差不多了，又因地震阻塞了水源；水源一阻塞，河流就一定要干枯。国家本来一定要依靠山岳河流供给物资，山岳倒塌，河流干枯，正是亡国的预兆。到了河流干枯的时候，山岳一定要倒塌。周朝的灭亡，大约不出十年了，因为满十年就是一纪，天要灭亡一个国，不会让它超过一纪的。”
原：正是这一年，三川的水干枯了，岐山倒塌了。十一年，幽王被犬戎所杀，西周灭亡，周朝就东迁到洛邑。（《周语》）

# 史伯论五材
题解：国语　据黄丕烈仿宋本
原：桓公为司徒……问于史伯曰：“周其弊乎？”
原：对曰：“殆于必弊者也。《泰誓》曰：‘民之所欲，天必从之。’今王弃高明昭显，而好谗慝暗昧；恶角犀丰盈二，而近顽童穷固二；去和而取同。夫和实生物，同则不继。以他平他谓之和，故能丰长而物生之；若以同裨同，尽乃弃矣。故先王以土与金、木、水、火杂，以成百物。是以和五味以调口，刚四支以衞体，和六律以聪耳，正七体以役心，平八索以成人，建九纪以立纯德，合十数以训百体。出千品，具万方，计亿事，材兆物，收经七入，行极。故王者居九咳之田，收经入以食兆民，周训而能用之，和乐如一。夫如是，和之至也。于是乎先王聘后于异姓，求财于有方，择臣取谏工，而讲以多物，务和同也。声一无听，色一无文，味一无果，物一不讲。王将弃是类也，而与剸同，天夺之明，欲无弊得乎？”（《郑语》）
注：角犀：额角宽朗，有角度；丰盈，两颊丰满。古人认为这是贤能者的相貌。
注：顽：顽固。童，幼稚。固，固陋。
注：七体：就是耳、目、口、鼻七窍。
注：八索：首、腹、足、股、目、口、耳、手。
注：九纪：水、火、金、木、土、谷六府，加上正德、利用、厚生三事。
注：材：同“裁”。
注：经：同“京”，十亿为兆，十兆为经；一曰万亿为兆，万兆为经。
注：周训：训之以忠信。
注：妓音：该十经为妓；一曰万经为。

# 史伯论五材（译文）
原：郑桓公作周的司徒……询问周太史史伯道：“周将要衰落了吧？”
原：史伯答道：“周恐怕定要衰落的。《泰誓》说：‘人民所愿望的，天一定会依从它。’现在周王舍弃明智开朗的人，而喜欢奸邪阴险的人；厌恶俊伟英明的人，而接近幼稚鄙陋的人；离开了和谐的原则，而选取同一的原则。和谐才是创造事物的原则，同一是不能连续不断、永远常有的。结合许多不同的东西在一起，而使它们得到平衡，这叫做和谐，所以能够使物丰盛起来，成长起来，而产生出新的东西。假如一定要在相同的东西上再添加相同的东西，那加到不可再加的时候，便会被抛弃了。所以先王用土跟金、木、水、火相互结合起来，造成百样东西。从此调和五味来适合胃口，锻炼四肢来保卫身体，调和六律使耳更加聪敏，整饬七窍来运用心思，平衡八体来完成人格，建成九纪（水、火、金、木、土、谷六府，正德、利用、厚生三事）来树立纯粹的德性，会合十等的人们（王、公、大夫、士、皂、舆、隶、僚、仆、台）来调整百官的统属。定出千种品位，具备万种方式，总计亿数的事情，裁制兆类的物体，取得万兆的收入，采取了万万兆的行动。所以王者据有九州极其广大的土地，取得万兆极其丰足的收入，来养活广大的人民，普遍教导人民而加以任用，和谐安乐有如一体。像这样才是和谐的极度。因此先王向不同姓的部族聘娶王后，到不同的地方探索财富，任用大臣，选取敢直言的人士，采用多种事物作比较衡量，这都是在求取和谐。同一的声音没有什么可听，同一的色素不能配成文彩，同一的味道不能引得人爱吃，同一的事物就无从较量。周王舍弃了和谐而专求同一，上天将剥夺掉他的智慧，想要不衰落，怎能做得到呢？”（《郑语》）

# 洪范节录
题解：周书　据阮刻十三经注疏本
原：惟十有三祀，王访于箕子二。
注：十有三祀：就是十三年，指文王受命的第十三年。
注：王：周武王。箕子，殷纣时的太师。
原：王乃言曰：“呜呼！箕子，惟天阴骘下民，相协厥居，我不知其彝伦攸敍四。”
注：骘：音陟，定。阴鬻，暗中安定。
注：彝：常。伦，伦理。敍，次序。
原：箕子乃言曰：“我闻在昔，鲧陲洪水，汨陈其五行，帝乃震怒，不畀洪范九畴，彝伦攸斁八。鲧则殛死，禹乃嗣兴，天乃锡禹洪范九畴，彝伦攸敍。”
注：陲：音因，堵塞。鲧音滚，相传为夏禹之父，治洪水，因用堵塞的方法而失败。
注：畀：给与。洪，大。范，法。畴，类。洪范九畴，九种治理天下的大法。
注：斁：音亦，又音妒，败坏。彝伦攸斁，正常的伦理次序遭到破坏。
注：锡：赐。
注：大汨：音骨，乱。
原：初一日五行，次二曰敬用五事，次三曰农用八政，次四曰协用五纪，次五曰建用皇极三，次六曰又三用三德，次七曰明用稽疑，次八曰念用庶征，次九曰向言用五福，威四用六极。
注：农：勉。
注：皇：王，君。极，准则。皇极，做君主的准则。
注：向：同“享”，受。
注：威：借为“畏”。
原：一、五行：一日水，二日火，三日木，四日金，五曰土。水曰润下，火日炎上，木日曲直，金曰从革，土爰吾稼穑。润下作咸，炎上作苦，曲直作酸，从革作辛，稼穑作甘。
注：爰：用法与“曰”同。
原：二、五事：一曰貌，二曰言，三曰视，四曰听，五曰思。貌曰恭，言曰从，视曰明，听曰聪，思曰睿。恭作肃，从作乂，明作哲，聪作谋，睿作圣。
注：乂：音刈，养治。
原：………
原：四、五纪：一曰岁，二曰月，三曰日，四曰星辰，五曰历数。
原：……………
原：八、庶征：曰雨，曰旸，曰燠，曰寒，曰风，曰时。五者来备，各以其敍，庶草蕃庑。一极备，凶；一极无，凶。
注：旸：音阳，日出。
原：曰休征：曰肃，时雨若；曰又，时旸若；曰晢，时燠若；曰谋，时寒若；曰圣，时风若。曰咎征：曰狂，恒雨若；曰僭，恒旸若；曰豫，恒燠若；曰急，恒寒若；曰蒙，恒风若。曰：王省惟岁，卿士惟月，师尹惟日。岁月日时无易，百谷用成，又用明，俊民用章，家用平康。日月岁时易，百谷用不成，乂用昏不明，俊民用微，家用不宁。
注：卿士：君王属下最高级的官。
注：师尹：比卿士次一等的官。

# 洪范节录（译文）
原：十三年，武王访问箕子。武王就说：“唉！箕子，上天暗中保佑下界人民，协助他们获得安定的生活，我不知道它是怎样把人民安乐生活的秩序安排得这样有条有理的。”
原：箕子就说：“我听说从前鲧因用堵塞方法治理洪水，搅乱了五行，上帝大为震怒，不把九类大法传给他，因而他不懂得怎样安排人民安居乐业的大道理，秩序弄得很混乱。鲧被流放到远方而死以后，禹继承了他的职位，上天才把九类人法赐给了禹，因此他把人民安居乐业的秩序作了很好的安排。”
原：九类大法：第一是五行，第二是要严肃地运用身体上的五种行事，第三是努力作好八项政务，第四是依靠五种纪时的算法调和天时，第五是建立无过无不及的大中至正的君主准则，第六是治民要依靠三种德行，第七是明察地运用卜筮来解决疑难，第八是考虑问题要依靠各种天气的征验，第九是用五种幸福鼓励人民和用六种困苦警戒人民。
原：第一类五行：一是水，二是火，三是木，四是金，五是土。水的性质润物而向下，火的性质燃烧而向上，木的性质可曲可直，金的性质可以镕铸改造，土的性质可以耕种收获。润物而向下的性质产生咸味，燃烧而向上的性质产生苦味，可曲可直的性质产生酸味，可以镕铸改造的性质产生辛味，可以耕种收获的性质产生甜味。
原：第二类五事：一是容貌，二是言语，三是看，四是听，五是思虑。容貌要恭敬，言语要有条理，看要看得清楚，听要听得明白，思虑要通达。容貌恭敬才能严肃，言语有条理才能办得了事，看得清楚才能辨明一切，听得明白才能计谋得当，思虑通达才能做到万事无不成功。

原：第八类庶征（各种天气的征验）：一是雨，二是晴，三是煖，四是寒，五是风。这五种天气能够均匀调顺，农作物自然长得茂盛。这五种天气之中，某一种过多了是不利的，某一种欠缺了也是不利的。
原：美行的征验有五种：做事严肃，就能有适时的雨水；处事得当，就能有适时的阳光；见事明白，就能气候和煖适时；谋事合理，就能气候寒冷适时；事理通达，就能有适时的风。恶行的征验有五种：做事狂暴，就霪雨不止；办事僭妄，就长久干早；贪图逸豫，就久热不凉；心情急躁，就久寒不暖；迷蒙不悟，就长久风。所以说：王管的事好比是年，卿士管的事好比是月，师尹管的事好比是日。一年、一月乃至一日的时刻都没有差错，百谷就能成长，政治就会清明，优秀的人才得到任用，国家也就安宁；一日、一月乃至一年的时刻有了差错，百谷就不能长成，政治就紊乱不明，优秀的人才就得不到任用，国家就不安宁。
原：人民群众好比众星：箕星好风，毕星好雨。日月运行，既有冬天，又有夏天。月亮走错了路，走近箕星就多风，走近毕星就多雨。君王和官员做错了事，国家也会发生风暴。
