# 杨朱
原：杨朱（约公元前三九五—前三三五年）可能是战国时期的一位隐士，关于他的事迹已无可考查了。《庄子·寓言篇》说他曾学于老聃；刘向《说苑·政理篇》说他曾见过梁王（《艺文类聚》九十四引作梁惠王），讨论治理天下的道理。据《孟子》说，杨朱的学说在当时曾起了很大的影响：“天下之言不归杨，则归墨。”（《孟子·滕文公下》）杨朱没有什么著作流传下来，现在流传下来的《列子·杨朱篇》是魏晋时期的人伪托的。这里所选的有关杨朱学说的材料，是从《孟子》《韩非子》《淮南子》等著作中摘录出来的。
原：就现在流传下来的一些片断的材料看，杨朱的基本思想是主张“轻物重生”，认为个人的生命是最宝贵的东西。照韩非的理解，杨朱一派不愿意拔掉自己身上一根毫毛去换取天下国家，意思是说保护自己身上的毫毛比做统治国家的帝王还重要；照孟子的理解，杨朱主张极端的个人利己主义，即不愿意拔掉自己身上一根毫毛去做对天下人有利的事情。《淮南子》的理解和韩非的理解基本上是一致的。可能孟子对杨朱的学说作了片面的歪曲。据《淮南子》的记载，杨朱的学说是和墨家对立的，他不仅反对兼爱、尙贤，而且反对迷信鬼神，他可能是一个无神论者。从孟子对杨朱的攻击看，他的学说又是和儒家对立的，孟子骂杨朱“不要君主”，同禽兽一样，可见他的学说在客观上破坏了君权和等级制度的尊严。从以上几方面看，杨朱的学说中是有积极的因素的，他不愿意替当权贵族服务从而取得富贵的地位。但是这种“明哲保身”的个人主义思想，也含有对社会不关心和漠视群众利益的倾向，孟子对杨朱的攻击也有一些合理的因素。
原：这里节录的两段附录，是有关战国时期杨朱学派的材料，保存在战国末年的《吕氏春秋》一书中。从这两段材料中可以看出，杨朱一派的基本思想是轻物重生，跟《韩非子》和《淮南子》对杨朱一派学说的理解是一致的。据这两篇材料，杨朱一派也是提倡制欲、反对纵欲主义的。

# 泛论训
题解：淮南子
原：兼爱、尙贤、右鬼、非命，墨子之所立也，而杨子非之；全性保真，不以物累形，杨子之所立也，而孟子非之。

# 泛论训（译文）
原：兼爱、尙贤、明鬼、非命，这是墨子所提出来的学说，而杨子加以反对；保全生命，保全本性，不肯为了追求本身以外的事物而累坏自己的身体，这是杨子所提出来的学说，而孟子加以反对。

# 显学
题解：韩非子
原：今有人于此，义一不入危城，不处军旅，不以天下大利易二其胫一毛，世主必从而礼之，贵其智而高其行，以为轻物重生之士也。
注：义：据梁启雄说，在这里是指那个人在行动上的主张。
注：易：交易，换取。
注：照这：段文字所说，这个人大概就是杨朱。

# 显学（译文）
原：现在有一个人在这里，他的主张是不肯进入被围困的城市，不肯参加军队，不肯为了天下的巨大利益来换取他腿上的一根毫毛，国君们总是有礼貌地接待他，尊重他的智慧，推崇他的行为，认为他是轻视外物而重视生命的人士。

# 尽心节录
题解：孟子
原：孟子曰：“杨子取为我，拔一毛而利天下，不为也。”

# 尽心节录（译文）
原：孟子说：“杨子主张为我，那怕是拔掉一根毫毛就可以对天下的人有利益，他也是不干的。”

# 滕文公下节录
题解：孟子
原：圣王不作，诸侯放恣，处士横议，杨朱墨翟之言盈天下。天下之言，不归杨则归墨。杨氏为我，是无君也；墨氏兼爱，是无父也。无父无君，是禽兽也。

# 滕文公下节录（译文）
原：圣王还不出现，诸侯们专横放肆，不在官位的知识分子随便发议论，杨朱、墨翟的学说传遍了天下各处。天下各处的言论，不属于杨朱一派就属于墨翟一派。杨氏主张“为我”，那就是无君；墨家主张“兼爱”，那就是无父；无君无父，就是禽兽。

# 重己节录
题解：附录　吕氏春秋中有关杨朱学派的文献
原：今吾生之为我有，而利我亦大矣。论其贵贱，爵为天子不足以比焉；论其轻重，富有天下不可以易之；论其安危，一曙失之，终身不复得。此三者，有道者之所愼也。有愼之而反害之者，不达乎性命之情也。
注：一曙：晓，早晨。

# 重己节录（译文）
原：现在我的生命为我所有，对我的好处也太大了。从贵贱来说，天子这样尊贵的爵位也比不上我的生命；从轻重来说，整个世界的财富也换不了我的生命；从安危来说，一朝丧失了生命就永远不能再得到了。这三种情形，懂得真理的人是时常注意着的。也有时常注意着却反而伤害了生命的，那是因为不曾透澈了解性命的实质的缘故。

# 贵生节录
题解：附录　吕氏春秋中有关杨朱学派的文献
原：世之人主，多以富贵骄得道之人，其不相知，岂不悲哉！故曰：道之真，以持身；其绪余，以为国家；其土苴一以治天下。由此观之，帝王之功，圣人之余事也，非所以完身养生之道也。
注：土：粪，苴草，这里指糟粕。

# 贵生节录（译文）
原：世上的君主很多依仗着权势财富就看不起懂得真理的人，那种不能认识懂得真理的人的情形，难道不可悲吗？所以说：真理的本身，用来保持生命；真理的残余，用来治理国家；真理的糟粕，用来治理天下。从这看来，帝王的功业，不过是圣人顺手带过的小事，并不是保全身体、养好生命的大道理！
