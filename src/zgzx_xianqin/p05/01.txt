# 杨朱
原：杨朱约公元前三九五前三三五年可能是战国时期的一位隐士关于他的事迹已无可考查了庄子寓言篇说他曾学于老聃刘向说苑政理篇说他曾见过梁王艺文类聚九十四引作梁惠王讨论治理天下的道理据孟子说杨朱的学说在当时曾起了很大的影响天下之言不归杨则归墨孟子滕文公下杨朱没有什么著作流传下来现在流传下来的列子杨朱篇是魏晋时期的人伪托的这里所选的有关杨朱学说的材料是从孟子韩非子淮南子等著作中摘录出来的
原：就现在流传下来的一些片断的材料看杨朱的基本思想是主张「轻物重生认为个人的生命是最宝贵的东西照韩非的理解杨朱一派不愿意拔掉自己身上一根毫毛去换取天下国家意思是说保护自己身上的毫毛比做统治国家的帝王还重要照孟子的理解杨朱主张极端的个人利己主义即不愿意拔掉自己身上一根毫毛去做对天下人有利的事情淮南子的理解和韩非的理解基本上是一致的可能孟子对杨朱的学说作了片面的歪曲据淮南子的记载杨朱的学说是和墨家对立的他不仅反对兼爱尙贤而且反对迷信鬼神他可能是一个无神论者从孟子对杨朱的攻击看他的学说又是和儒家对立的孟子骂杨朱不要君主同禽兽一样可见他的学说在客观上破坏了君权和等级制度的尊严从以上几方面看杨朱的学说中是有积极的因素的他不愿意替当权贵族服务从而取得富贵的地位但是这种「明哲保身的个人主义思想也含有对社会不关心和漠视群众利益的倾向孟子对杨朱的攻击也有一些合理的因素。
原：这里节录的两段附录是有关战国时期杨朱学派的材料保存在战国末年的吕氏春秋一书中从这两段材料中可以看出杨朱一派的基本思想是轻物重生跟韩非子和淮南子对杨朱一派学说的理解是一致的据这两篇材料杨朱一派也是提倡制欲反对纵欲主义的

# 泛论训
题解：淮南子
原：兼爱尙贤右鬼非命墨子之所立也而杨子非之全性保真不以物累形杨子之所立也而孟子非之。

# 泛论训（译文）
原：兼爱尙贤明鬼非命这是墨子所提出来的学说而杨子加以反对保全生命保全本性不肯为了追求本身以外的事物而累坏自己的身体这是杨子所提出来的学说而孟子加以反对。

# 显学
题解：韩非子
原：今有人于此义一不入危城不处军旅不以天下大利易二其胫一毛世主必从而礼之贵其智而高其行以为轻物重生之士也
注：义：据梁启雄说在这里是指那个人在行动上的主张
注：易：交易换取。
注：照这：段文字所说这个人大概就是杨朱

# 显学（译文）
原：现在有一个人在这里他的主张是不肯进入被围困的城市不肯参加军队不肯为了天下的巨大利益来换取他腿上的一根毫毛国君们总是有礼貌地接待他尊重他的智慧推崇他的行为认为他是轻视外物而重视生命的人士

# 尽心节录
题解：孟子
原：孟子曰杨子取为我拔一毛而利天下不为也

# 尽心节录（译文）
原：孟子说杨子主张为我那怕是拔掉一根毫毛就可以对天下的人有利益他也是不干的。」

# 重己节录
题解：附录　吕氏春秋中有关杨朱学派的文献
原：今吾生之为我有而利我亦大矣论其贵贱爵为天子不足以比焉论其轻重富有天下不可以易之论其安危一曙失之终身不复得此三者有道者之所愼也有愼之而反害之者不达乎性命之情也
注：一曙：晓早晨

# 重己节录（译文）
原：现在我的生命为我所有对我的好处也太大了从贵贱来说天子这样尊贵的爵位也比不上我的生命；从轻重来说整个世界的财富也换不了我的生命从安危来说一朝丧失了生命就永远不能再得到了这三种情形懂得真理的人是时常注意着的也有时常注意着却反而伤害了生命的那是因为不曾透澈了解性命的实质的缘故

# 贵生节录
题解：附录　吕氏春秋中有关杨朱学派的文献
原：世之人主多以富贵骄得道之人其不相知岂不悲哉！故曰道之真以持身其绪余以为国家其土苴一以治天下由此观之帝王之功圣人之余事也非所以完身养生之道也。
注：土：粪苴草这里指糟粕

# 贵生节录（译文）
原：世上的君主很多依仗着权势财富就看不起懂得真理的人那种不能认识懂得真理的人的情形难道不可悲吗？所以说真理的本身用来保持生命；真理的残余用来治理国家真理的糟粕用来治理天下从这看来帝王的功业不过是圣人顺手带过的小事并不是保全身体养好生命的大道理！
