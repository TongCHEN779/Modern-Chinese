# 蝴蝶
原：两个黄蝴蝶，双双飞上天。
原：不知为什么，一个忽飞还。
原：剩下那一个，孤单怪可怜；
原：也无心上天，天上太孤单。
原：五年八月二十三日。

# 赠朱经农
原：经农自美京来访余于纽约，畅谈极欢。
原：三日之留，忽忽遂尽。别后终日不乐，作此寄之。
原：六年你我不相见，见时在赫贞江边；握手一笑不须说：你我于今更少年。
原：回头你我年老时，粉条黑板作讲师；更有暮气大可笑，喜作丧气颓唐诗。
原：那时我更不长进，往往喝酒不顾命；有时尽日醉不醒，明朝醒来害酒病。
原：一日大醉几乎死，醒来忽然怪自己：父母生我该有用，似此真不成事体。
原：从此不敢大糊涂，六年海外颇读书。幸能勉强不喝酒，未可全断淡巴菰。
原：年来意气更奇横，不消使酒称狂生。头发偶有一茎白，年纪反觉十岁轻。
原：旧事三天说不全，且喜皇帝不姓袁，更喜你我都少年，“辟克匿克”来江边，赫贞江水平可怜，树下石上好作筵，黄油面包颇新鲜，家乡茶叶不费钱，吃饱喝胀活神仙，唱个“蝴蝶儿上天”！
原：五年八月三十一日。

# 中秋
原：九月十一夜，为旧历八月十五夜。
原：小星躲尽大星少，果然今夜清光多！
原：夜半月从江上过，一江江水变银河。

# 江上
原：十一月一日大雾，追思夏间一景，因成此诗。
原：雨脚渡江来，
原：山头冲雾出。
原：雨过雾亦收，
原：江楼看落日。

# 黄克强先生哀辞
原：当年曾见将军之家书，
原：字迹娟逸似大苏。
原：书中之言竟何如？
原：“一欧爱儿，努力杀贼：”—
原：八个大字，读之使人慷慨奋发而爱国。
原：呜乎将军，何可多得！
原：五年十一月九日。

# 十二月五夜月
原：明月照我床，卧看不肯睡。窗上青藤影，
原：随风舞娟媚。
原：我爱明月光，更不想什么。月可使人愁，
原：定不能愁我。
原：月冷寒江静，心头百念消。欲眠君照我，
原：无梦到明朝！

# 沁园春二十五岁生日自寿
原：五年十二月十七日，是我二十五岁的生日。独坐江楼，回想这几年思想的变迁，
原：又念不久即当归去，因作此词，并非自寿，
原：只可算是一种自誓。
原：弃我去者，二十五年，不可重来。看江明雪霁，吾当寿我，且须高咏，不用衔杯。种种从前，都成今我，莫更思量更莫哀。从今后，要那么收果，先那么栽。
原：忽然异想天开，似天上诸仙采药回。有丹能却老，鞭能缩地，芝能点石，触处金堆。我笑诸仙，诸仙笑我。敬谢诸仙我不才，葫芦里，也有些微物，试与君猜。

# 病中得冬秀书
原：病中得他书，不满八行纸，全无要紧话，颇使我欢喜。
原：二
原：我不认得他，他不认得我，我总常念他，这是为什么？
原：岂不因我们，分定长相亲，由分生情意，所以非路人？
原：海外“土生子”，生不识故里，终有故乡情，其理亦如此。
原：三
原：岂不爱自由？此意无人晓：情愿不自由，也是自由了。
原：六年一月十六日。

# “赫贞旦”答叔永
原：叔永昨以五言长诗寄我，有“已见赫贞夕，未见赫贞旦。何当侵晨去，起君从枕畔”之句。作此报之。
原：“赫贞旦”如何？听我告诉你。昨日我起时，东方日初起，返照到天西，彩霞美无比。赫贞平似镜，红云满江底。江西山低小，倒影入江紫。朝霞渐散了，剩有青天好。江中水更蓝，要与天争姣。休说海鸥闲，水冻捉鱼难，日日寒江上，飞去又飞还。何如我闲散，开窗面江岸，清茶胜似酒，面包充早饭。老任倘能来，和你分一半。更可同作诗，重咏“赫贞旦”。
原：六年二月十九日。

# 生查子
原：前度月来时，
原：仔细思量过。
原：今度月重来，
原：独自临江坐。
原：风打没遮楼，
原：月照无眠我。
原：从来没见他，
原：梦也如何做？
原：六年三月六日。

# 景不徙篇
原：《墨经》云，“景不徙，说在改为。”说曰，
原：“景。光至景亡。若在，尽古息。”《庄子·天下篇》云，“飞鸟之影未尝动也。”此言影已改为而后影已非前影。前影虽不可见而实未尝动移也。
原：飞鸟过江来，投影在江水。鸟逝水长流，
原：此影何尝徙？
原：风过镜平湖，湖面生轻约。湖更镜平时，
原：毕竟难如旧。
原：为他起一念，十年终不改。有召即重来，
原：若亡而实在。
原：六年三月六日。

# 朋友篇寄怡荪，经农
原：(将归诗之一)
原：粗饭还可饱，破衣不算丑。人生无好友，如身无足手。吾生所交游，益我皆最厚。少年恨污俗，反与污俗偶。自视六尺躯，不值一杯酒。倘非朋友力，吾醉死已久。从此谢诸友，立身重抖擞。去国今七年，此意未敢负。新交遍天下，难细数谁某。所最敬爱者，也有七八九。学理互分剖，过失赖弹纠。清夜每自思，此身非吾有：一半属父母，一半属朋友。便即此一念，足鞭策吾后。今当重归来，为国效奔走。可怜程(乐亭)郑(仲诚)张(希古)，少年骨已朽。作歌谢吾友，泉下人知否？
原：六年六月一日。

# 文学篇别叔永，杏佛，觐庄
原：(将归诗之二)
原：吾将归国，叔永作诗赠别。有“君归何人劝我诗”之句。因念吾数年来之文学的兴趣，多出于吾友之助。若无叔永，杏佛，
原：定无《去国集》。若无叔永，觐庄，定无《尝试集》。感此作诗别叔永，杏佛，觐庄。
原：我初来此邦，所志在耕种。文章真小技，救国不中用。带来千卷书，一一尽分送。种菜与种树，往往来入梦。
原：匆匆复几时，忽大笑吾痴。救国千万事，何事不当为？而吾性所适，仅有一二宜。逆天而拂性，所得终希微。
原：从此改所业，讲学复议政。故国方新造，纷争久未定。学以济时艰，要与时相应。文章盛世事，今日何消问？
原：明年任与杨，远道来就我。山城风雪夜，枯坐殊未可。烹茶更赋诗，有倡还须和。诗炉久灰冷，从此生新火。
原：前年任与梅，联盟成劲敌。与我论文学，经岁犹未歇。吾敌虽未降，吾志乃更决。暂不与君辩，且著《尝试集》。
原：回首四年来，积诗可百首。做诗的兴味，大半靠朋友：佳句共欣赏，论难见忠厚。如今远别去，此乐难再有。
原：暂别不须悲，诸君会当归。请与诸君期：明年荷花时，春申江之湄，有酒盈清卮，无客不能诗，同作归来辞！
原：六年六月一日。

# 百字令
原：六年七月三夜，太平洋舟中，见月，有怀。
原：几天风雾，险些儿把月圆时孤负。待得他来，又还被如许浮云遮住！多谢天风，吹开明月，万顷银波怒！孤舟载月，海天冲浪西去！
原：念我多少故人，如今都在明月飞来处。别后相思如此月，绕遍地球无数！几颗疏星，长天空阔，有湿衣凉露。低头自语：“吾乡真在何许？”
