# 朱自清生平著作编年简表
原：朱乔森

# 一八九八年一岁（虚岁）
原：十一月二十二日，生于江苏省东海县。祖父名则余，当时在东海做承审官；父名鸿钧，母亲姓周。朱自清原籍浙江绍兴，由于全家后来搬到扬州，同扬州的关系，够得上“生于斯，死于斯，歌哭于斯”了，所以他自称“我是扬州人”。

# 一九〇一年四岁
原：父朱鸿钧从东海到高邮的邵伯镇做小官，跟随父亲到了邵伯。

# 一九〇二年五岁
原：开始由父母启蒙课读。

# 一九〇三年六岁
原：祖父将全家搬到扬州。朱自清开始上私塾，读经书、古文、诗词；后又上初等小学，未毕业。此后数年内，朱鸿钧到江西做盐务官，朱自清也曾去过江西一年。

# 一九一一年十四岁
原：辛亥革命爆发。在此之前的一年多，朱自清曾因陪父亲养病，住在扬州史公祠内，多次听到史可法领导扬州人民英勇抗清，坚持民族气节，宁死不屈的历史故事，并对这位民族英雄深为崇敬。直到上中学时，他还常去史可法的衣冠冢，写过多首凭吊的诗歌，可惜都已经散佚了①。
原：辛亥革命后，在戴子秋家上夜塾，跟这位老先生学着做通了文言文②。

# 一九一二年十五岁
原：祖父朱则余逝世。
原：毕业于安徽旅扬公学高等小学，考入扬州两淮中学（后改名为江苏省立第八中学）。

# 一九一六年十九岁
原：毕业于江苏省立第八中学，校方给予品学兼优奖状。
原：暑期，考入北京大学预科。
原：寒假回扬州，遵父母命与武钟谦女士结婚，婚后感情甚好。

# 一九一七年二十岁
原：考入北京大学本科哲学门（后改为哲学系）。他本名自华，号实秋，这时，感于家庭经济境况不好，为了惕励自己不随流俗而合污，改名自清；又为了勉励自己加紧学习，奋发图强，借用《韩非子》中“性缓，故佩弦以自急”的典故，改字佩弦。他终于只用三年时间，学完了北大哲学系四年的课程。
原：冬天，父亲丢了官，祖母又去世。父亲朱鸿钧虽然做过小官，但一直以廉洁自守，又不喜积蓄，这时两手空空，借钱才办了丧事。朱自清奔丧回家，后又回到北京去上学，父亲则去南京谋事。散文《背影》写的就是他们这次在浦口车站分别的情景。

# 一九一九年二十二岁
原：五四运动爆发。朱自清积极参加了五四爱国运动。他在学生联合会的一个股中做过具体工作③，还参加了由邓中夏发起组织、并在五四运动中起过很大作用的平民教育讲演团④。
原：二月二十九日，写《睡吧，小小的人》白话诗一首，后收入上海商务印书馆出版的文学研究会丛书《雪朝》，这是他在新文化运动影响下创作新诗的开始。这一年，还写了《光明》《新年》等白话新诗，发表于十二月二十五日《晨报》副刊和《北京大学学生周刊》第一号。

# 一九二〇年二十三岁
原：春天，加入北京大学部分师生组织的“新潮社”⑤，并在《新潮》二卷三号发表译文《心理学的范围》，后又在三卷一号发表《怅惘》、《小草》等新诗。
原：一月，还在《北京大学学生周刊》发表了《满月之光》等新诗。
原：三月下旬，当选为平民教育讲演团第四组书记⑥。四月六日，和第四组团员共八人到通县演讲。他首先讲了《平民教育是什么》。五月二日，又在城区讲《我们为什么纪念五一劳动节呢》⑦。在此期间，他和邓中夏建立了友谊。
原：五月，在北京大学提前毕业。
原：暑假后，到杭州第一师范教书，夫人武钟谦偕往。同来这里教书的，还有俞平伯先生。俞先生也是北大毕业生和“平民教育讲演团”、“新潮社”的成员。
原：十一月，郑振铎、沈雁冰、叶圣陶发起成立文学研究会。朱自清是这研究会的早期会员之一。
原：年底作新诗《送韩伯画往俄国》，后收入上海亚东图书馆出版的《踪迹》一书。

# 一九二一年二十四岁
原：暑假后，到扬州江苏省立第八中学任教务主任，不久辞职，去吴淞任中国公学国文教员。当时，同是“新潮社”成员的叶圣陶也在该校教国文，不过他们先前并不相识，这是他们订交的开始。朱自清这时也认识了郑振铎等。
原：秋，中国公学大学部闹风潮波及中学部，叶圣陶、朱自清等教员决定中学部停课，支持大学部的风潮。风潮结束后，因遭旧派人物攻击，朱自清又回杭州一师任教。十一月，叶圣陶也应邀到了这里。
原：下半年，潘漠华、汪静之、魏金枝、赵平复（柔石）、冯雪峰等杭州一师同学和其他几个中学的学生二三十人成立“晨光文学社”，朱自清与叶圣陶同被聘为顾问⑧。
原：这年，朱自清写了《转眼》、《星火》、《沪杭道上的暮》、《静》等新诗近二十首及散文《歌声》、小说《别》等。后分别收入《雪朝》、《踪迹》及《笑的历史》等书。

# 一九二二年二十五岁
原：一月十五日，与刘延陵、叶圣陶、俞平伯创办《诗》月刊，这是我国新文学运动史上的第一个诗刊。在创刊号上发表诗四首（《转眼》及《杂诗》三首）。因为创办者都是文学研究会会员，月刊自一卷四号起改为文学研究会的刊物，总共出了七期，后停刊。
原：本月二十一日写《民众文学的讨论》一文，发表于《时事新报》附刊《文学旬刊》。
原：春，应浙江省立第六师范之聘去台州任教。四月底又应一师同学要求回杭；七月下旬回扬州，九月间才携眷到台州六师。
原：三月二十八日，写成散文诗《匆匆》，发表于四月十一日《时事新报》附刊《文学旬刊》三十四期。
原：四月初，应修人、潘漠华、冯雪峰、汪静之组成湖畔诗社，并出版四人的诗选集《湖畔》。朱自清积极支持这个诗社。同月，作《短诗与长诗》，发表于《诗》第一卷第四号。
原：五月十八日，写《读〈湖畔>诗集》一文，发表于六月十一日《时事新报》附刊《文学旬刊》，并于其后参加了湖畔诗社。
原：六月，和周作人、俞平伯、徐玉诺、郭绍虞、叶圣陶、刘延陵、郑振铎等八人的诗合集《雪朝》，由上海商务印书馆印行，其第一集为朱自清诗十九首。
原：暑假，开始写长诗《毁灭》，这首著名的诗曾以当时的一种所谓“刹那主义”为指导思想。五月间，他在杭州听到一个人谈自己的刹那主义，那是“只求刹那的享乐”，认为“别的都是可笑的”。他颇不以为然，开始酝酿着一种完全相反的刹那主义。十一月七日在给俞平伯先生的信中说：“弟虽潦倒，但现在态度却颇积极；丢去玄言，专崇实际，这便是我所企图的生活。”“我第一要使生活底各个过程都有它独立之意义和价值—每一刹那有每一刹那的意义和价值！”“我的刹那主义，实在即是平凡主义。”

# 一九二三年二十六岁
原：春，到温州任浙江省立第十中学（兼师范部）国文教员。
原：三月十日，《毁灭》发表于《小说月报》第十四卷第三号。这是新诗运动以来运用我国传统诗歌技巧的第一首白话长诗，发表后即引起了诗坛的注意。
原：四月二十八日，写完以夫人武钟谦女士为主角的小说《笑的历史》，六月十日发表于《小说月报》第十四卷第六号。
原：暑假，回扬州，不久去南京。八月，与到南京出席社会主义青年团第二次代表大会的邓中夏相遇。这就是次年他在《赠A.S·》一诗中所写的：“去年一个夏天大早我见着你：你何其憔悴呢？你的眼还涩着，你的发太长了！但你的血的热加倍的熏灼着！在灰泥里辗转的我，仿佛被焙炙着一般！”
原：十月十一日，《桨声灯影里的秦淮河》一文写成，于次年一月二十五日出版的《东方杂志》第二十一卷第二号发表后，曾被时人评为“白话美术文的模范”。
原：十一月十七日，《文艺的真实性》一文写成，发表于次年一月十日出版的《小说月报》第十五卷第一号。

# 一九二四年二十七岁
原：二月，写成《温州的踪迹》中《月朦胧，鸟朦胧，帘卷海棠红》和《绿》两篇，七月，收入上海亚东图书馆出版的《我们的七月》。
原：三月初，到宁波任浙江省立第四中学国文教员，并在上虞白马湖春晖中学兼课。家属仍留温州。十月二日，在给马公愚的信中说：“半年来，弟仍碌碌两校，火车生活，竟习以为常矣。⑨”
原：同月，诗《别后》发表于《小说月报》第十五卷第六号。
原：三月十六日和四月九日，在宁波写成《温州的踪迹》中的后两篇：《白水漈》、《生命的价格——七毛钱》，后收入《我们的七月》。
原：四月十二日，作《春晖的一月》。
原：同月十五日，写成《赠友》一诗，二十六日发表于《中国青年》第二十八期，七月，《我们的七月》转载，改题为《赠A.S.》，后收入《踪迹》一书。
原：五月十四日，论文《正义》作完。二十八日，作诗《风尘》。
原：七月初，经上海到南京列席旁听中华教育改进社第三届年会，著有《旅行杂记》记载此事。会后，回温州家中。
原：同月，他主编的《我们的七月》出版。这是他和俞平伯、叶圣陶以及潘训等青年作家的诗与散文的合集。
原：九月五日，乘船去宁波，因大风，泊于楚门，九日晚始达。十三日为中秋，大雨。作有绝句诗：“万千风雨逼人来，世事都成劫里灰，秋老干戈人老病，中天皓月几时回？”这是他第一次学写旧诗。
原：同月，直皖军阀混战，直系军阀自福建出师平阳，拟取道温州攻皖系军阀后方，温州全城震动。朱自清于二十七日自宁波乘船回温州，三十日晚到达，其时直系闽军已至，并在城内拉伏。十月二日晚，全家乘船去宁波，但宁波无住处，十二日又乘车携眷往白马湖。此后，继续往来于白马湖和宁波，在春晖和浙江四中两校教书。
原：十二月，诗与散文集《踪迹》由上海亚东图书馆印行。

# 一九二五年二十八岁
原：年初，夏丐尊、丰子恺、匡互生、朱光潜等因春晖中学于去年年底发生风潮，在风潮结束后离开春晖。朱自清仍被留这个学校，但他决定半年后离去。
原：二月十五日，散文《女人》写毕。
原：五月九日，散文《“海阔天空”与“古今中外”》写成，六月，发表于《我们的六月》。
原：六月十日，为五卅惨案作《血歌》一诗，载于七月出版的《小说月报》十六卷七号。六月十九日，散文《白种人—一上帝的骄子》写成。同月，他主编的《我们的六月》由上海亚东图书馆出版。
原：七月二十日，散文《飘零》写成。
原：这年暑假后，清华学校开始从留美预备班改革成为一所大学，增设了学习研究中国传统文化的课程。朱自清就在这时经俞平伯介绍去清华任教，讲授李杜诗和国文。从此，他以研究中国古典文学作为毕生的事业之一。
原：十月，写成著名散文《背影》，十一月二十二日发表于《文学周报》第二百期。
原：十月二十日，诗《我的南方》发表于《语丝》第四十八期。
原：同月，写成散文《梦》。
原：十一月二十日，所作《子恺漫画代序》一文发表于《语丝》第五十四期。

# 一九二六年二十九岁
原：一月，写散文《阿河》。
原：三月，亲历了三一八惨案，并作文两篇：一篇悼念惨案中牺牲的清华学生韦杰三烈士；另一篇就是为被害群众进行血泪控诉的《执政府大屠杀记》，三月二十九日在《语丝》第二卷第七十二期上发表。
原：七月，由海路南下，回到白马湖家中，成《海上杂记》一文。
原：八月二十七日，论文《白采的诗》写成。
原：暑假后，仍独自到清华任教。过上海，写《白采》一文。
原：十一月十日，写成《子恺画集跋》。
原：十二月二十二日，写完论文《熬波图》。

# 一九二七年三十岁
原：一月，自白马湖接眷北来，住清华园西院。
原：二月五日，论文《新诗》发表，载《一般》第二卷第二号。十日，论文《熬波图》发表，载《小说月报》第十八卷第二号。
原：五月三十一日，作《和李白<菩萨蛮>》，这虽是一首拟古词，却表明了作者对“四一二”政变后反革命倒行逆施的谴责和愤慨，以及自己的徬徨心情。
原：六月，作拟古诗《行行重行行》、《青青河畔草》、《西北有高楼》、《迢迢牵牛星》等。这一时期，他曾专心模拟唐五代词及汉魏六朝古诗，写了许多拟古诗词，并收入自题的《敝帚集》。他坚持白话文学的方向，从未将这些作品发表或示人。模拟，只是作为了解、研究中国旧诗词的一种方法。
原：七月，写成散文《荷塘月色》，载七月《小说月报》十八卷七号。
原：九月二十七日，作《一封信》一文。
原：暑假以后，教普通国文与古今诗选两门课程。
原：十月，担任清华学生组织的文学团体“终南社”顾问。经常参加学生的文学和讲演等活动。
原：十一月五日，与李健吾合译的《为诗而诗》一文发表，载《一般》第三卷第三号。

# 一九二八年三十一岁
原：二月七日，写成《那里走》一文，三月发表于《一般》四卷三号。其中说：“衰颓与骚动使得大家惶惶然”，自己也“正感着这种被追逼，被围困的心情”，“觉得心上的阴影越来越大”。作者明白“只有参加革命或反革命，才能解决这惶惶然”，但又摆脱不了小资产阶级的“情调，嗜好，思想，伦理，与行为的方式”；“况且妻子儿女一大家都指着我活，也不忍丢下了走自己的路”，因此想着“还是暂时超然的好”。由于“国学比文学更远于现实……这是个更安全的逃避所”，他决定以国学作自己的职业，此后若干年，他走到书斋里专心致志做学问去了。
原：三月十一日，写《悼王善瑾君》一文，载《清华周刊》第二十九卷第六号。
原：五月二十五日，写《怀魏握青君》一文。
原：六月二十四日，写成散文《儿女》，载十月《小说月报》十九卷十期。
原：八月十七日，清华学校改为国立清华大学。暑假后，杨振声任清华大学中文系主任，曾说“系中一切计划朱先生和我商量规定者多”。
原：十月，第一本散文集《背影》由开明书店印行。
原：十一月二十二日，写清朝李绿园著《歧路灯》一书的书评，载《一般》第六卷第四号。
原：十二月四日，作《给<一个兵和他的老婆>的作者——李健吾先生》一文。七日，在中国文学会成立大会上讲《杂体诗》。十九日，为俞平伯的《燕知草》作序。

# 一九二九年三十二岁
原：春，开始讲授“中国新文学研究”。
原：七月十四日，有《白马湖》一文，载《清华周刊》第三十二卷第三期。
原：暑假后，开始讲授“歌谣”，它与“中国新文学研究”都是新课程，“引起学生浓厚的兴味”。
原：十一月二十六日，夫人武钟谦病逝于扬州。

# 一九三〇年三十三岁
原：四月，作《看花》一文。
原：七月，作《我所见的叶圣陶》和《叶圣陶的短篇小说》各一篇。
原：暑假后，杨振声就任青岛大学校长，朱自传代理清华大学中文系主任，并在燕京大学兼课。
原：九月二十八日，《论中国文学选本与专集》一文写成。

# 一九三一年三十四岁

# 一九三二年三十五岁

# 一九三三年三十六岁

# 一九三四年三十七岁

原：二月，开始讲授李贺诗。
原：三月，作《择偶记》一文。
原：四月一日，书评《子夜》一文发表于《文学季刊》第二期，认为这本书是当时“真能表现时代”的极少著作之一。同月，作《欧游杂记》一书自序。
原：五月，为夏丐尊、叶圣陶合著的《文心》作序。又成《陶渊明年谱中的问题》一文，发表于《清华学报》第九卷第二期。

原：同月，《欧游杂记》一书由开明书店出版。
原：十月十三日，写《内地描写》一文，载《太白》第一卷五期。同月，评《郭绍虞中国文学批评史上卷》一文发表，载《清华学报》第九卷第四期；散文《南京》发表，载《中学生》第四十八号。

# 一九三五年三十八岁

原：七月中，着手编选《中国新文学大系》丛书中的《诗集》。八月，为这本诗集写了“导言”，其中说，自“五四”前后以来的诗坛，“若要强立名目……就不妨分为三派：自由诗派，格律诗派，象征诗派。”《诗集》共选五十九家的新诗四百零八首。
原：在北平学生反对日本进一步侵略华北的一二·九爱国运动中，与清华学生一同进城参加了游行。

# 一九三六年三十九岁
原：二月二十九日，反动军警特务到清华搜捕学生竟日。在自己家中掩护学生六人。
原：三月，杂文集《你我》由商务印书馆出版。
原：五月二十八日，母亲逝世，七月回扬州。
原：暑假后，又开始讲授“中国文学批评”这门新课程。
原：十月二十四日，与闻一多一同出席清华学生为鲁迅先生逝世举行的追悼会，并作演讲。
原：十一月十七日，去绥远百灵庙慰问抗日部队，“向前线抗敌官兵致吾人之赞扬与敬意”④。

# 一九三七年四十岁
原：六月，在《语言与文学》（闻一多主编、清华中文系师生合办）创刊号上发表论文《诗言志说》，这是后来出版的《诗言志辨》一书中的一篇。

原：十一月三日，自长沙赴当时临大文学院所在地南岳。

# 一九三八年四十一岁
原：一月，作《日本语的欧化》一文。
原：二月，临时大学迁往昆明。朱自清从长沙到桂林，经南宁、龙州出镇南关经河内，于三月十四日抵达昆明。
原：三月二十七日，中华全国文艺界抗敌协会成立，被推为理事。
原：四月四日，去蒙自，因为临大文学院暂时设在这里。
原：五月四日，长沙临时大学改名为西南联合大学。应邀出席北大学生纪念“五四”的集会，并作讲演。
原：六月四日，夫人陈竹隐带着孩子从北平来到蒙自。
原：暑假后，因西南联大文学院迁至昆明，九月三日，由蒙自赴昆明。
原：十一月八日，联大开始上课，讲文学批评。

# 一九三九年四十二岁
原：二月六日，《蒙自杂记》一文写成，发表于《新云南》第三期。
原：六月六日，《论“以文为诗”》一文写成，发表于二十九日《大公报·文艺副刊》。
原：七月七日，参加七七抗战二周年纪念会，并写了短文《这一天》，热烈地歌颂抗战。他说：“东亚病夫居然奋起了，睡狮果然醒了。从前只是一大块沃土，一大盘散沙的死中国，现在是有血有肉的活中国了。从前中国在若有若无之间，现在确乎是有了。……我们不但有光荣的古代，而且有光荣的现代；不但有光荣的现代，而且有光荣的将来无穷的世代。新中国在血火中成长了。”在人民的奋起中，他看到了力量；对抗战的前途，中国的前途，充满了信心。
原：九月三日，移居昆明北郊的黎院村。
原：暑假后，开始讲授“宋诗”。
原：十月二十日，《中国散文的发展》一文在《中学生》战时半月刊第十期发表。
原：寒假，因健康关系，辞去联大中文系主任职务。

# 一九四〇年四十三岁
原：春，由于家庭负担重和物价飞涨，为生活所迫，夫人陈竹隐不得不带着孩子去物价比较便宜的成都，于端午节前到达。
原：六月十六日，《文字改革》一文发表，载《今日评论》第三卷第二十四期。
原：暑假，赴成都家中休假。这是清华大学教授每七年一次，为期一年的例假。全家住在成都东门外一所尼庵的三间草屋内；几个孩子连续生病，食米常靠亲友接济，生活十分困苦。朱自清曾有《近怀示圣陶》一诗，生动地叙述了国民党统治下当时的困苦情形。
原：休假期间，写成《经典常谈》一书。这是概括而又比较系统地介绍中国古代文化的一个尝试，它力求采择新的观点，又力求通俗化，为青年和一般读者了解我国古代文化提供了便利。他和叶圣陶合著的《精读指导举隅》、《略读指导举隅》两书以及《国文教学》一书的部分篇章，也是这个时候完成的。

# 一九四一年四十四岁
原：这年天旱，米粮大涨价。夏天，正是青黄不接的时候，成都一般贫苦市民已经没有饭吃，被迫一群一群地起来“吃大户”。朱自清目睹了这幅饥民求食图，受到强烈震动。后来他在《论吃饭》一文中描绘了当时的情景，字里行间，对“吃大户”的贫民表示深切地同情。
原：八月二十八日，开始写《外东消夏录》。
原：暑假，从厉歌天那里借阅许多杂志、诗刊和诗集，因而引起了谈论新诗的兴味。九月二日有信给厉歌天，讨论新诗问题。
原：十月，在叙永联大分校，同李广田几次交谈对于新诗的看法，越发引起了谈论新诗的兴趣，后来，写成了《新诗杂话》一书。
原：十月八日，乘木船顺岷江而下，经乐山、宜宾、纳溪、叙永，月底回到昆明。同月，清华大学文科研究所在昆明东北郊龙泉镇司家营成立。
原：十一月三日，自黎院村移居文科研究所；每星期二至星期五，步行约二十里去西南联大授课。
原：十一月十日，有《重庆一瞥》一文，载《抗战文艺》七卷四、五期合刊。

# 一九四二年四十五岁
原：一月一日，《三祝报章文学》一文发表于昆明《中央日报》。
原：二月二日，写《经典常谈》一书自序，载四月五日《中学生》战时半月刊五十四期。
原：二月十六日，所著《古诗十九首释》在《国文月刊》第一卷第六期开始连载。
原：三月，与叶圣陶合著《精读指导举隅》一书出版。
原：暑假后，讲授“文辞研究”这门新课。听课学生只有一二人。但他仍按时上讲堂，认真授课，一丝不苟。
原：这年冬天，昆明奇寒。朱自清远离家人，穷得连御寒的棉衣也添置不起，只好在集市上买了一件赶马人用的披风，披着从乡下进城去上课。加之营养不良，又得了严重的胃病，他日见消瘦，突然衰老了。

# 一九四三年四十六岁
原：一月，与叶圣陶合著《略读指导举隅》一书由商务印书馆出版。

# 一九四四年四十七岁
原：五月四日，联大学生举办文艺晚会，请朱自清等演讲，因三青团分子捣乱，未开成。八日，朱自清等在“五四”文艺晚会上作了演讲。
原：七月八日，以卖碑帖款购飞机票返成都。十月一日，飞返昆明。
原：暑期开学后，除在西南联大授课外，又在五华中学兼任国文教员。
原：十月十九日，出席联大学生举行的鲁迅先生逝世八周年纪念晚会，并作讲演。
原：十月，作《新诗杂话》自序，载十二月《抗战文艺》九卷五、六合刊。
原：十二月，作《诗言志辨》自序，载一九四五年六月《国文月刊》第三十六期。

# 一九四五年四十八岁
原：四月九日，父朱鸿钧病逝于扬州。同月，与叶圣陶合著《国文教学》一书由开明书店出版。
原：六月二十五日，参加全国文艺界抗敌协会昆明分会举行的庆祝茅盾五十寿辰纪念会。月底，飞成都度暑假，八月十五日，日本无条件投降的消息于深夜传到成都，他兴奋地到大街上去和老百姓狂欢了一整夜。回到家里，却带着沉重的心情对夫人说：“胜利了，可千万不能起内战。不起内战，国家的经济可以恢复得快点，老百姓可以少受些罪。”月底，从成都飞回昆明。
原：十一月二十五日晚，昆明学生在联大举行时事晚会，国民党军警竟包围会场，并开机枪、小钢炮进行威胁。二十六日，昆明学生联合会宣布总罢课。十二月一日，国民党军警、特务数百人用棍棒、短刀、手榴弹分头袭击联大、云大、联大附中等校，死师生四人，伤二十五人，这就是震惊中外的“一二·一”惨案。九日，朱自清到灵堂向死难的四烈士默哀致敬。

# 一九四六年四十九岁
原：四月四日，重任清华大学中文系主任。同月，《经典常谈》一书由文光书店出版。
原：同月，联大奉命结束，学生分批复员。
原：六月十四日，自昆明飞重庆，十六日，乘车去成都，十八日到家。
原：七月十一日和十五日，李公朴、闻一多接连在昆明被国民党特务暗杀，闻先生是他多年的同事和朋友，闻先生的死，特别使他悲愤和激动。
原：同月二十一日，参加西南联大校友会主办的闻一多追悼会，并致词。在此期间，还写了《中国学术的大损失》一文，悼念闻先生。
原：同月，整理抗日战争以来旧诗稿成一集，题为《犹贤博弈斋诗抄》。这些旧诗的风格虽近宋诗，但语言清新朴素，自成一格，与《敝帚集》专心模拟不同。本月，并为《犹贤博弈斋诗抄》作骈文《自序》一篇，载一九四八年《文学杂志》三卷五期。
原：八月四日晚，参加清华校友聚餐会，并致词悼念闻先生。十六日，成《挽闻一多先生》诗一首，这是他在新诗方面搁笔二十年后的一首，其中歌颂闻一多是“一团火”，“照彻了深渊”，“照见了魔鬼”，相信在这火的“遗烬里”，必将“爆出个新中国”！
原：同月十八日，成都各界人士举行李、闻追悼大会。事先就传闻特务将捣乱会场，但他仍毅然出席并作报告、提抗议，全场为之动容。次日，携夫人子女离成都去重庆。
原：同月二十六日，出席全国文协重庆分会欢迎他和李广田的.聚餐会。
原：十月七日，偕眷自重庆飞返北平。当时的北平，“物价象潮水一般涨，整个的北平也象在潮水里晃荡着”，他觉得“北平到底不和从前一样了。穷得没办法的人似乎也更多了”，“手头不宽心头也不宽了”⑤。
原：同月十八日，与《新生报》社长谈《语言与文学》副刊发刊事，并允诺主编这个副刊，准备为它每周写一篇“周话”。十九日，写了第一篇“周话”，即该刊发刊词，题为《语言与文学》。
原：十一月，清华大学组成“整理闻一多遗著委员会”，他是召集人。
原：十二月，开始整理闻一多遗著。十六日，《现代人眼中的古代——介绍郭沫若新著：<十批判书>》一文在《大公报》发表。

# 一九四七年五十岁
原：二月二十一日，写成《文学的标准与尺度》一文（载三月九日《大公报》副刊《星期文艺》），运用新的观点，论述文学的标准和尺度是随着社会生活与阶级关系的变化而变化的，并认为现在应使新的民主的尺度，成为文学的新标准。
原：同月二十三日，签名于抗议北平当局任意逮捕人民宣言（当时被称为十三教授宣言），由于在报上发表时，他的名字是第一个，国民党发动各家反动报纸对他进行攻击和诽谤，住所也被国民党特务三次滋扰。
原：四月九日，在清华新诗社作题为《闻一多与诗》的讲演（本月十四日《燕京新闻》十三卷二十一期），指出“闻一多先生在新月时期就是爱国诗人，现实的诗人，《死水》诗集就是显明的例子”。
原：同月十一日，在清华通识学社讲演《论气节》，充分肯定了五四以来青年知识分子用正义的斗争行动代替消极的“气节”这种“新的做人的尺度”。五月一日，这篇讲演发表于《知识与生活》。
原：四月二十八日，发表《论通俗化》一文，载《燕京新闻》副刊，文中肯定了解放区作家与人民共同生活、打成一片的新的文艺方向，认为人民需要这样的代言人。
原：五月二日，参加北大新诗社举办的诗歌晚会。五日，参加清华五四文艺晚会，讲《论严肃》（载十月一日《中国作家》创刊号），认为新文学运动从一开始就是严肃的，批判了中途出现的玩世派，肯定了抗战胜利后，文学强调人民性，是“势有必至，理有固然”。
原：同月十九日，写成《论标语口号》一文，认为当时的标语口号是要唤醒人民起来行动，而且要帮助他们组织起来，往往就是集体行动的纲领。中年以上的知识分子应改变厌恶标语口号的态度。但标语口号要避免落套子，公式化。“古人说‘修辞立其诚’，标语口号要发生领导群众的作用……有一丝一毫的不诚都是遮掩不住的。”二十日，北平三万学生举行反饥饿反内战示威游行。二十四日，他签名于呼吁和平宣言。
原：六月一日，《古文学的欣赏》一文发表于《文学杂志》复刊号。
原：七月一日，《编者问八题（关于散文创作）》载《文艺知识》第一集之三。
原：同月，写《闻一多全集》编后记。
原：八月，写《闻一多全集》序，全集出版前，曾发表于十月的《文学杂志》二卷五期，再次表示对于闻一多的死，“是我们不能甘心的”！
原：同月，《诗言志辨》一书由开明书店出版。这是他多年来对我国古代诗歌研究的结晶。
原：十月二十四日，参加清华大学中文系的迎新大会，和学生一道学扭秧歌。
原：十二月十日，写《论不满现状》，载本月二十七日《观察》三卷十八期。
原：十二月十二日，去通县潞河中学讲演。“学生对大众文学，发问甚多；又问解放区作品之内容及语言问题。”
原：同月，写《标准与尺度》一书自序。其中说：“复员以来，事情忙了，心情也变了，我得多写些，写得快些，随便些，容易懂些。”
原：同月，《新诗杂话》一书由作家书屋印行。

# 一九四八年五十一岁
原：一月一日，扶病参加清华中文系师生举办的新年同乐晚会，再次和学生一道扭秧歌。二十三日，写《论雅俗共赏》一书自序，说明这本书各篇论文，都是在朝着“近于人民的立场”这个方向说话。
原：二月二十四日，答复吴景超，不拟加入中间路线的刊物《新路》。
原：三月，写《语文影及其他》一书自序。
原：四月，编注开明书店国文教本。
原：四月十一日，为抗议国民党军警特务逮捕和毒打北师大、北大学生，捣毁学生自治会和教授宿舍，北大师生员工宣布罢教、罢课、罢工。次日，清华教授会决定十三日为“反饥饿、反迫害”罢教一天。朱自清被推为宣言起草人之一。十四日晚，他出席清华鲁迅研究会举办的文艺讨论会，并讲了话。
原：四月二十二日，签名于抗议国民党北平市党部吴铸人谈话宣言。
原：同月，《标准与尺度》、《语文零拾》两书分别由文光书店和名山书局出版。
原：五月四日，进城参观“五四”史料展览并参加“五四”新文化晚会。
原：同月，《论雅俗共赏》一书由观察社出版。
原：六月十八日，签名于《抗议美国扶日政策并拒绝领取美援面粉宣言》。当时，他虽是教授中薪水最高的，但每月所得仅可买三袋多面粉，家庭人口又多，生活十分困难。而他的胃病已极其严重，自一月二日以来即经常剧烈呕吐，不能进食，痛苦不堪，六月十一日体重减至三十八·八公斤，急需营养和治疗。但他仍毅然决然地在宣言上签了名，并让孩子立刻把配给证退回去。这一天，他在日记里写道：“此事每月需损失六百万法币，影响家中甚大，但余仍决定签名。因余等既反对美国之扶日政策，自应直接由己身做起。此虽只为精神上之抗议，但决不应逃避个人责任。”
原：七月三日，彻夜胃痛不止。九日，签名抗议北平当局“七五枪杀东北学生。
原：同月十五日，“闻一多全集整理委员会”最后一次集会，他报告全集整理和出版的经过。晚上，又出席闻一多遇难二周年纪念会，报告全集编辑经过。
原：同月二十三日，扶病参加《中建》半月刊在清华举行的“知识分子今天的任务”座谈会。他拄着手杖，脸色苍白，在发言中说，知识分子的道路有两条：一条是帮闲帮凶，向上爬；一条是向下去，到人民中去，同人民一起争取解放。对这条道路，许多知识分子理性上是知道该接受的，但是习惯上变不过来。“所以我对学生说，要教育我们得慢慢地来。”发言稿载八月五日《中建》一卷二期。
原：八月六日晨四时，突然胃部剧痛，十时送北大医院，下午二时手术。十日并发肾炎，病情严重，仍谆谆嘱咐夫人；“有件事要记往：我是在拒绝美援面粉宣言上签过名的，我们家以后不买国民党配给的美国面粉！”十二日八时昏迷，十一时四十分，在贫病交迫下与世长辞。
原：十月二十四日，遗骨葬于北平西郊万安公墓。
原：一九八二年三月。
原：（本表的部分条目，在编写时参考了季镇淮先生的《朱自清先生年谱》以及陈孝全、陈锡岳编的《朱自清著作系年目录》）
