# 和李白《菩萨蛮》
原：（一九二七年五月三十一日）
原：烟笼远树浑如幂，青山一行无颜色。日暮倚楼头，暗惊天下秋！
原：半庭黄叶积，阵阵鸦啼急。踯躅计征程，嘶骢何处行？

# 重过清华园西院（三首）
原：月余断行迹，重过夕阳残。
原：他日轻离别，兹来侧肺肝。
原：居人半相识，故宇不堪看。
原：向晚悲风起，萧萧枯树寒。
原：三年于此住，历历总堪悲。
原：深浅持家计，恩勤育众儿。
原：生涯刚及壮，沉病竟难支。
原：俯仰幽明隔，白头空自期。
原：相从十余载，耿耿一心存。
原：恒值姑嫜怨，频经战伐掀。
原：靡他生自矢，偕老死难谖。
原：到此羁孤极，谁招千里魂？

# 除夕书感
原：又看一岁尽，生事逐飙尘。
原：精力中年异，情怀百种新。
原：孤栖今似客，长恨不如人。
原：马齿明朝长，回头愧此身！

# 有感
原：垂髻逢鼎革，逾壮尚烟尘。
原：翻覆云为雨，疮痍越共秦。
原：坐看蛇豕突，未息触蛮瞋。
原：沉饮当春日，行为离乱人。

# 昔游（二首）
原：听风听水梦微醒，漠漠长天昼欲暝。
原：六翮浮沉云外影，一山涌现眼中青。
原：娉婷应惜灵肩瘦，飘拂微闻翠发馨。
原：廿载别来无恙否，两髦今已渐凋零。
原：——《小孤山》
原：笋舆伊轧入山城，鸡犬无声巷陌清。
原：漠漠春阴寒未改，微微风力梦初成。
原：九天上下随烟雾，一局盈亏任子秤。
原：何似长安万人海，年年辛苦骛浮名。
原：——《台州》

# 盛年
原：盛年今已尽蹉跎，游骑无归可奈何。
原：转眼行看四十至，无闻还畏后生多。
原：前尘项背遥难望，当世权衡苦太苛。
原：剩欲向人贾余勇，漫将顽石自磋磨。

# 无题
原：五载闻声思渺绵，一从相见意难捐。
原：亭亭寒菊秋风里，漠漠飞鸿白日边。
原：伫苦停辛频阅世，微颦浅笑亦随缘。
原：沉吟莫测君心曲，泣路悲丝只自怜。

# 竹隐以红叶见寄，赋此奉答（三首）
原：文书不放此身闲，秋叶空教红满山。
原：片片逢君相寄与，始知天意未全悭。
原：薜荔丹枫各自妍，缤纷更看锦丝缠。
原：遥思素手安排处，定费灵心几折旋。
原：经年离索黯萦魂，飒飒西风昼掩门。
原：此日开缄应自诧，些须秋色胜春温。

# 漓江绝句（二首）
原：廿七年南宁作
原：龟行蜗步百丈长，蒲伏压篙黄头郎。
原：上滩哀响动山谷，不是猿声也断肠。
原：《上水船》
原：皮鼓蓬蓬彻九幽，百夫争扛木龙头。
原：齐心高唱祈年曲，自听劳歌自送愁。
原：——《龙门夜泊观赛神》

# 得逖生书作，次公权韵（二首录一）
原：里巷愔愔昼掩扉，狂且满市共君违。
原：沐猴冠带心甘死，逐鹿刀锥色欲飞。
原：南朔纷纷丘貉聚，日星炳炳爝光微。
原：沉吟曩昔欢娱地，犹剩缁尘染敝衣。

# 近怀示圣陶
原：少小婴忧患，老成到肝腑。
原：欢娱非我分，顾影行踽踽。
原：所期竭驽验，黾勉自建树。
原：人一己十百，遑计犬与虎。
原：涉世二十年，仅仅支门户。
原：多谢天人厚，怡然嚼脩脯。
原：山崩溟海沸，玄黄战大宇。
原：健儿死国事，头颅掷不数。
原：弦诵幸未绝，竖儒犹仰俯。
原：累迁来锦城，萧然始环堵。
原：索米米如珠，敝衣余几缕。
原：老父沦陷中，残烛风前舞。
原：儿女七八辈，东西不相睹。
原：众口争嗷嗷，娇婴犹在乳。
原：百物价如狂，距骧孰能主！
原：不忧食无肉，亦有菜园肚。
原：不忧出无车，亦有健步武。
原：只恐无米炊，万念日旁午。
原：况复三间屋，蹙如口鼻聚。
原：有声岂能聋，有影岂能瞽。
原：妇稚逐鸡狗，攫人若网罟。
原：况复地有毛，卑湿丛病蛊。
原：终岁闻呻吟，心裂脑为盬。
原：赣鄂频捷音，今年驱丑虏。
原：天不亡中国，微忱寄干橹。
原：区区抱经人，于世百无补。
原：死生等蝼蚁，草木同朽腐。
原：蝼蚁自贪生，亦知爱吾土。
原：鲋鱼卧涸辙，尚以沫相呴。
原：勿怪多苦言，喋喋忘其苦。
原：不如意八九，可语人三五。
原：惟子幸听我，骨鲠快一吐。

# 夏夜次公权韵
原：电舌破天时一吐，望穿万眼无滴雨。
原：抛书分得农圃忧，敢言肥瘠非吾土。
原：挥汗还沾葛衣透，摇篷难驱众蚊语。
原：一身辛苦何足道，所忧衣食民父母。
原：忆昔浙中山映水，举家矮屋听更鼓。
原：绕屋水田热比汤，昼夜熏蒸那逭暑。
原：田中蚊蚋伸长喙，噜人辄病十之五。
原：呛鼻浓烟徒木屑，遮风斗帐枉绵纻。
原：蚊阵长驱可奈何，任凭宰割肉登俎。
原：天地不仁古所叹，喋喋何当穷墨楮。
原：侵肤溽热生创痏，彻旦呻吟摩臂股。
原：当时眼孔如豆大，切齿蹙眉不胜苦。
原：自从移家入旧都，蕞尔丑类莫余侮。
原：名园暑夕清风生，促坐不劳挥玉尘。
原：灯明夜静独摊书，片语会心色飞舞。
原：窗外婀娜摇细竹，壁间窸窣鸣饥鼠。
原：解渴已办冰梅汤，沁人齿颊一丝。
原：平生知慕马少游，此情合入无双谱。
原：读倦开门自盘桓，高树微凉侵肺腑。
原：相逢不寐人两三，娓娓清谈忘夜午。
原：苦乐相形只及身，庶民饥寒岂关汝？
原：御侮今知赖众擎，匹妇匹夫宜得所。
原：足衣足食安危系，奈何连年成饥阻。
原：但愿人定回雨旸，千仓万箱盈天府。

# 寄三弟叙永
原：同生四兄弟，汝最与我亲。
原：念汝生不若，吾家方患贫。
原：弱冠执教鞭，三载含酸辛。
原：不耻恶衣食，锱铢黾朝昏。
原：辞家就闽学，读律期致身。
原：学成厕下僚，有志未得申。
原：兄弟天一方，劳苦仅相闻。
原：军兴过汉上，执手展殷勤。
原：相视杂悲喜，面目侵风尘。
原：小聚还复别，临歧久谆谆。
原：我旋客天南，汝亦事骏奔。
原：长沙付一炬，命与悬丝均。
原：历劫得相见，不怨天与人。
原：奔走助我役，玩好与我分。
原：终始如一日，感汝性情真。
原：铁鹫肆荼毒，邻室无遗痕。
原：赖汝移藏书，插架今纷纶。
原：辗转陪都去，旅食春复春。
原：陪都两见汝，日日来相存。
原：啖我饼饵香，馈我烟丝醇。
原：去岁官叙永，法曹人所尊。
原：宿愿一朝副，当思惠吾民。
原：亦当思中馈，及时缔良姻。
原：极目千里外，寸心托飞云。

# 市肆见三希堂山谷尺牍，爱不忍释，而力不能致之
原：诗爱髯苏书爱黄，不妨妩媚是清刚。
原：摊头蹀躞涎三尺，了愿终悭币一囊。

# 夜不成寐，忆业雅《老境》一文，感而有作，即以示之
原：卅七年北平作
原：中年便易伤哀乐，老境何当计短长。
原：衰疾常防儿辈觉，童真岂识我生忙。
原：室人相敬水同味，亲友时看星坠光。
原：笔妙启予宵不寐，羡君行健尚南强。
