# 梁启超《夏威夷游记》
原：余虽不能诗，然尝好论诗。以为诗之境界，被千余年来鹦鹉名士余尝戏名词章家为鹦鹉名士，自觉过于尖刻。占尽矣，虽有佳章佳句，一读之，似在某集中曾相见者，是最可恨也。故今日不作诗则已，若作诗，必为诗界之哥伦布、玛赛郎然后可。犹欧洲之地力已尽，生产过度，不能不求新地于阿米利加及太平洋沿岸也。欲为诗界之哥伦布、玛赛郎，不可不备三长：第一要新意境，第二要新语句，而又须以古人之风格入之，然后成其为诗。不然，如移木星金星之动物以实美洲，瑰伟则瑰伟矣，其如不类何！若三者具备，则可以为十世纪支那之诗王矣宋、明人善以印度之意境语句入诗，有三长俱备者，如东坡之“溪声便是广长舌，山色岂非清净身”，“夜来八万四千偈，他日如何举似人”之类，真觉可爱。然此境至今日又已成旧世界。今欲易之，不可不求之于欧洲。欧洲之意境语句，甚繁富而玮异，得之可以陵轹千古，涵盖一切，今尚未有其人也。时彦中能为诗人之诗，而锐意欲造新国者，莫如黄公度。其集中有《今别离》四首，又《吴太夫人寿诗》等，皆纯以欧洲意境行之然新语句尚少，盖由新语句与古风格常相背驰；公度重风格者，故勉避之也。

原：《感事和邱仲阙诗》：“流离苦语传黄蘖，盗窃迷香幻白莲。”黄蘖白莲，运用俗事能雅。麦孺博孝廉句：“圣军未决蔷薇战，党祸惊闻瓜蔓抄”。“微闻黄祸锄非种，欲为苍生赋《大招》。”偶作游戏则可，译语满纸，诗道一厄矣。

# 汪国垣《光宣诗坛点将录》
原：天伤星行者武松。黄遵宪。李详《题黄公度人境庐诗草》云：“甘载无人继硬黄，贵筑黄琴坞有硬黄之称，袁忠节昶复举以赠漱兰先师，公度亦可谓硬黄矣。如君合署此堂堂。凤鸾接翼罹虞网，蝼蚁先驱待景皇。诗草墨含醇鸩味，英灵名破海天荒。试看生气如廉、蔺，孰与吴儿论《辨亡》？”
原：公度有改革诗体之志，其成就虽未能副其所期，然一时巨手矣。天巧星浪子燕青。夏曾佑。别士诗喜用哲理入诗，名篇颇多。梁卓如尝举与公度、观云并推为新诗界三杰。其实三人皆取法古人，并未能脱然自立。黄气体较大，波澜较宏。蒋、夏皆喜摭用新理西事人诗，风格固规抚前人也。

# 吴宓《跋人境庐诗草自序》
原：谨按嘉应黄公度先生，为中国近世大诗家。《人境庐集》，久已流传，脍炙人口。二十余年前，梁任公尝称其最能以新思想新事物镕铸入旧风格，推为诗界革新之导师。然先生不特以诗见长，其人之思想学识，怀抱志趣，均极宏伟，影响于当时者甚大。细读先生之诗，可以知之。而先生之工为诗，亦未始不由于此也。岁丙寅，编者始因李君沧萍得识先生之文孙延凯，遂获见先生晚年所手定之诗稿钞本，中并有当时知交名士诗人手写之眉批旁注，商榷评赞，朱墨重重，而卷首有先生所撰《自序》一篇，尤可珍贵拟之西土作者，其重要殆不下于威至威斯之《诗集再版自序》。不知当日《人境庐诗》刊印之时，此序何未列人？序中虽云有志未逮，然先生之作此序，实在其逝世之前十五年，序中既明言作诗之方法及旨趣，其诗自必遵照兹所言者作成。是诗与序，实相得而益彰。故亟请于延凯，刊登本志。案：为《学衡杂志》。海内外之好读先生诗者，当更以先睹此序为快也。
原：吴芳吉《四论吾人眼中之新旧文学观》
原：新诗之历程有五：始以能用新名词者为新诗，如黄公度《人境庐诗》是也；次以能用白话者为新诗，如留美某博士之集是也；次以无韵律者为新诗，如留东某学士之集是也；次以谈哲理者为新诗，如教会某女士之集是也；再次以欧化者为新诗，如京、沪诸名士之集是也。以能用新名词者为新诗，是诗之本体徒为新名词蔽，不知诗之真伪，无关新旧名词者也。以能用白话者为新诗，是诗之本体，又为白话所蔽，不知诗之真伪，无关白话文言者也。以废弃韵律高谈哲理者为新诗，是诗之本体，又为哲理韵律之成见所蔽，不知诗之真伪，仍无关于哲理韵律之有无者也。至以字句之欧化者为新诗，何不直用欧文为之，是诗之本体，又为欧化所蔽，不欧化者转不以为是诗，亦未知诗之真伪尤无关于此也。新派所以有此误者，盖其用工不直向诗之本体是求，而于末技是竞。犹之看花雾里，以雾为花，扣盘扪烛，翻笑人眇，宜其无是处矣。
原：黄公度《今别离》，气象薄俗，失之时髦。
原：古直《黄公度先生诗笺自序》
原：诗至晚清，疲茶益甚，曹蜍、李志，厌厌欲绝。风雅不亡，是在善作。黄公度先生于是崛起其间焉。先生一代霸才，逢时之厄，郁勃之气，一发于诗。观其镕钧百家，斟酌乐府，有语皆铸，无能不新，屹乎如华岳倚天，浩乎如百川赴海，阳开阴阖，千汇万状。虽不遽云上薄《风》《骚》，下掩杜、韩，盖棺论定，则固旷世独立，绝于等伦矣。予夙嗜先生《人境庐诗》，尝取所尤爱者，别为编，间有所得，即注其上。朱墨已满，更为掌录，闷诸箧衍，未以示人。去冬粤海归舟，友人黄枯桐适卧下床，琐屑谈谐，偶然及此。枯桐作而起曰：有是哉！“诗家总爱《西昆》好，独恨无人作郑笺。”吾于先生之诗，每有此感。子既为之，曷不布之？予漫应之。已归山中，风雪时作，围炉枯坐，忽忆前言，启箧出稿，比而次之，题曰《黄公度先生诗笺》。其间疏密，初不一律，笔颤墨冻，增益未遑。然重加检视，奇词奥旨，则亦略已宣露矣。庄生有言：“作始虽简，其终将巨。”求全责备，且有待于将来。中华民国十五年正月，嘉应古直记于庐山太乙峰下隅楼斗室中。

# 诸祖耿《天放楼诗续集序》
原：间尝读清季诸贤之诗，内籀者莫工于渐西，外籀者莫侈于人境。人境不免乎粗放，而渐西微嫌其细碎。然二子没而嗣音又绝。

原：近五十年中，以诗名家者，不下十余人，而胡君独赏金和与黄遵宪。则以二家之诗，浅显易解，与其主张相近似故也。实则晚清诗家，高出金、黄之上者，不知凡几，胡君不知，甚或竟未之见耳。
原：五十年中以诗名家者甚众，决不止如胡君所推之金和、黄遵宪二人。然胡君一概抹煞，非见之偏，即学之浅，或则见闻之隘故也。黄氏本邃于旧学，其才气横溢，有足多者。然其创新体诗，实与其时之政治运动有关。盖戊戌变法，实为一种浪漫运动。张文襄《学术》一绝句自注云：“二上年来，都下经学讲《公羊》，文章讲龚定盦，经济讲王安石，皆余出都以后风气也。”可见当时风气，务以新奇相尚。康有为孔子改制之说，谭嗣同之《仁学》，梁启超《时务报》、《新民丛报》之论说，《新民丛报》派模仿龚定盦之诗，与黄遵宪之新体诗皆是也。黄之旧学根柢深，才气亦大，故其新体诗之价值，远在谭嗣同、梁启超诸人之上。然彼晚年，亦颇自悔，尝语陈三立：天假以年，必当敛才就范，更有进益也。

# 夏敬观《呋庵臆说》
原：近数十年诗人，能直言眼前事直用眼前名物，莫如黄公度遵宪。公度有《人境庐诗草》十一卷。其《番客篇》，为南洋华侨作。诗云：“吹烟出菸叶，消食分槟榔，旧藏淡巴菰，其味如詹唐，倾壶挑鼻烟，来自大西洋，一灯阿芙蓉，吹气何芬芳。分光然石油，次第辉银釭。”其言冠服，有云：“簇新好装束，争来看新郎：头上珊瑚顶，碎片将玉壤；背后红丝绦，交辫成文章；新制绀绫袿，衣补亦宝装；平头鹅顶靴，学步工趋跄。”其言新人之门庭，有云：“插门桃柳枝，叶叶何相当。垂红结彩毬，绯绯数尺长，上书大夫第，照耀门楣光。中庭寿星相，新菥供中央，隐囊班丝细，坐褥棋局方，两旁螺钿椅，有如两翼张。丹楹缀锦联，掩映蛎粉墙，某某再拜贺，其语多吉祥。”此诗铺叙一华侨之豪富景象，最妙是写其冠服，显非仕宦之家，而学之不似者。又《聂将军歌》云：“阿师黄马袿，车前鸣八驺；大兄翠雀翎，衣冠如沐猴；亦有红灯照，巾帼赢兜鍪。”盖言义和团也，二诗之病，惟菸即淡巴菰，犯重；花翎不应言翠雀翎，嫌于用代替字耳。
原：公度又有《乌之珠歌》。乌之珠者，穆宗所御马。穆宗上宾，马悲鸣不食毙。诗中言清时帝服云：“银花佩蚡露黄带，红绒结顶飘朱缨”。又贝勒之称，亦译音也。诗中言扈从，有云：“十五善射作前导，亲王贝勒相追随”。又有《冯将军歌》云：“江南十载战功高，黄袿色映花翎飘。”凡此皆为实写当世名物。至其诗集中所写外国之事，及用译音名词，不胜枚举。特惜其诗，大率皆趋于雄放，以铺叙为长，乏于韵味。尝自称其诗曰：“人各有面目，正不必与古人相同。吾欲以古文家抑扬变化之法作古诗，取《骚》《选》乐府歌行之神理入近体诗。其取材：以群经三史诸子百家及许郑诸注为词赋家不常用者。其述事：以官书会典方言俗谚及古人未有之物未辟之境，举吾耳目所亲历者，皆笔而书之，要不失以我之手，写我之口”云云。余以为其言甚是。古人写当时事，曷尝不如此。至以文为诗，取材避熟就生，皆是旧法。即写目前之事，目前之名物，亦理所当然。今人但能貌古，不能写实，自是本领不够。公度殁，距今将四十年矣。其诗自今日视之，犹觉其不甚顺眼，则以胆量有余，而机组欠缺，不足以为后人模楷耳。

# 林庚白《今诗选凡例》
原：遵宪不工近体诗，而其五七言古体，多百年来罕觏之作。如《锡兰岛卧佛》《八月十五夜太平洋舟中望月作歌》诸篇，皆前无古人，且为今之学诗者开辟一径，真乃今诗也。

# 钱锺书《谈艺录》
原：近人论诗界维新，必推黄公度。《人境庐诗》奇才大句，自为作手。五古议论纵横，近随园、瓯北，歌行铺比翻腾处似舒铁云，七绝则龚定庵，取径实不甚高。语工而格卑，伧气尚存，每成俗艳。尹师鲁论王胜之文曰：赡而不流。公度其不免于流者乎。大胆为文处亦无以过其乡宋芷湾，差能说西洋制度名物，掎摭声光电化诸学，以为点缀，而于西人风雅之妙，心性之微，实少解会，故其诗有新事物，而无新理致。譬如《番客篇》，不过胡稚威《海贾诗》；《以莲菊桃杂供一瓶作歌》，不过《淮南子·俶真训》所谓：“槐榆与橘柚，合而为兄弟；有苗与三危，通而为一家。”查初白《菊瓶插梅诗》所谓：“高士累朝多合传，佳人绝代少同时。”公度生于海通之世，不曰“有苗三危通一家”，而曰“黄白黑种同一国”耳。新学而稍知存古，与夫旧学而强欲趋时者，皆好公度。盖若辈之言诗界维新，仅指驱使西故，亦犹参军蛮语作诗，仍是用佛典梵语之结习而已。
