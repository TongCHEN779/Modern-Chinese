# 梁启超《饮冰室诗话》
原：近世诗人，能镕铸新理想以入旧风格者，当推黄公度。丙申、丁酉间，其《人境庐诗》稿本留余家者两月余，余读之数过。然当时不解诗，故缘法浅薄，至今无一首能举其全文者，殊可惜也。近见其七律一首，亦不记全文，惟能诵两句云：“文章巨蟹横行日，世界群龙见首时。”案：此诗题为《酬曾重伯编修》，见本《诗草》卷八，“世界”作“世变”。余甚爱之。
原：希腊诗人荷马，旧译作和美耳。古代第一文豪也。其诗篇为今日考据希腊史者独一无二之秘本，每篇率万数千言。近世诗家如莎士比亚、弥儿敦、田尼逊等，其诗动亦数万言。伟哉！勿论文藻，即其气魄，固已夺人矣。中国事事落他人后，惟文学似差可颉顽西域。然长篇之诗，最传诵者，惟杜之《北征》，韩之《南山》，宋人至称为日月争光。然其精深盘郁，雄伟博丽之气，尚未足也。古诗《孔雀东南飞》一篇，千七百余字，号称古今第一长篇诗。诗虽奇绝，亦只儿女子语，于世运无影响也。中国结习，薄今爱古，无论学问文章事业，皆以古人为不可几及。余生平最恶闻此言，窃谓自今以往，其进步之远轶前代，固不待蓍龟，即并世人物，亦何遽让于古所云哉！生平论诗，最倾倒黄公度，恨未能写其全集。顷南洋某报，录其旧作一章，乃煌煌二千余言，真可谓空前之奇构矣。荷、莎、弥、田诸家之作，余未能读，不敢妄下比骘。若在震旦，吾敢谓有诗以来所未有也。以文名名之，吾欲题为印度近史，欲题为佛教小史，欲题为地球宗教论，欲题为宗教政治关系说。然是固诗也，非文也。有诗如此，中国文学界足以豪矣。因亟录之，以饷诗界革命军之青年。案：诗为《锡兰岛卧佛》，见本《诗草》卷六，兹略。以下凡引诗全首见本《诗草》者皆不录。

# 出军歌
原：四千余岁古国古，是我完全土。二十世纪谁为主？是我神明胄。君看黄龙万旗舞，鼓鼓鼓！
原：一轮红日东方涌，约我黄人捧。感生帝降天神种，《新小说》载此诗，“感生帝降”作“海王之祖”。今有亿万众。《新小说》此句，作“足踏全球动。”地球蹴踏六种动，《新小说》此句，作“并力一心万万众。”勇勇勇！
原：南蛮北狄复西戎，泱泱大国风。《新小说》此句，作“我居中央中”。蜿蜓海水环其东，拱护中央中。《新小说》此句，作“拱护九天重”。称天可汗万国雄，同同同！绵绵翼翼万里城，中有五岳撑。黄河浩浩流水声，能令海若惊。东西禹步横庚庚，行行行！怒搅海翻喜山撼，万鬼同一胆。弱肉磨牙争欲啖，四邻虎眈眈。今日死生求出险，敢敢敢！剖我心肝挖我眼，勒我供贡献。计口缗钱四万万，民实何仇怨！国势衰微人种贱，战战战！国轨海王权尽失，无地画禹迹。病夫睡汉不成国，却要供奴役。雪耻报仇在今日，必必必！一战再战曳兵遁，三战无余烬。八国旗飏笳鼓竞，张拳空冒刃。打破天荒决人胜，胜胜胜！

# 军中歌
原：堂堂堂堂好男子，最好沙场死。艾炙眉头瓜喷鼻，谁实能逃死？死只一回毋浪死，死死死！阿娘牵裾密缝线，语我毋恋恋。我妻拥髻代盘辫，濒行手指面：败归何颜再相见。战战战！戟门乍开雷鼓响，杀贼神先王。前敌鸣笳呼斩将，擒王手更痒。千人万人吾直往，向向向！探穴直探虎穴先，何物是险艰！攻城直攻金城坚，谁能漫俄延！马磨马耳人磨肩，前前前！弹丸激雨刃旋风，油溅征衣红。敌军昨屯千黑熊，今日空营空。万旗一色盘黄龙，纵纵纵！层台高筑受降城，诸将咸膝行。降奴脱剑鞠躬迎，单于颈系缨。四围鼓吹铙歌声，横横横！秃发万头缠黑索，多少戎奴缚。绯红十字张油幕，处处夷伤药。军令如山禁残虐，莫莫莫！不喜封侯虎头相，铸作功臣像。不喜《燕然碑》百丈，表示某家将。所喜军威莫敢抗，抗抗抗！

原：去年闻学生某君入东京音乐学校，专研究乐学，余喜无量。盖欲改造国民之品质，则诗歌音乐为精神教育之一要件，此稍有识者所能知也。中国乐学，发达尚蚤。自明以前，虽进步稍缓，而其统犹绵绵不绝。前此凡有韵之文，半皆可以入乐者也。《诗三百篇》皆为乐章，尚矣。孔子称“诵《诗》三百，歌《诗》三百，弦《诗》三百，舞《诗》三百。”如《楚辞》之《招魂》、《九歌》，汉之《大风》、《柏梁》，皆应弦赴节，不徒乐府之名如其实而已。下至唐代绝句，如“云想衣裳、”“黄河远上，”莫不被诸弦管。宋之词，元之曲，又其显而易见者也。盖自明以前，文学家多通音律。而无论雅乐剧曲，大率皆由士大夫主持之。虽或衰靡，而俚俗犹不至太甚。本朝以来，则音律之乐，士大夫无复过问；而先王乐教，乃全委诸教坊优伎之手矣。读泰西文明史，无论何代，无论何国，无不食文学家之赐，其国民于诸文豪亦顶礼而尸祝之。若中国之词章家，则于国民岂有丝毫之影响耶？推原其故，不得不谓诗与乐分之所致也。郑夹漈有言：“古之诗曰歌行，后之诗曰古近二体。歌行主声，二体主文。诗为声也，不为文也。浩歌长啸，古人之深趣。今人既不尚啸，而又失其歌诗之旨，所以无乐事也。凡律其辞则谓之诗，声其诗则谓之歌，诗未有不歌者也。中略。呜呼，诗在于声，不在于义。孔子曰：《关睢》乐而不淫，哀而不伤。亦谓《关睢》之声和平，能令闻者感发而不失其度耳。若诵其文，习其理，能有哀乐之事乎？二体之作，失其诗矣。”《通志·乐略》。其言可谓特识。夹漈时已然，輓近乃益甚。至于今日，而诗、词、曲三者，皆成为陈设之古玩，而词章家真社会之虱矣。顷读杂志《江苏》，屡陈中国音乐改良之义，其第七号已谱《出军歌》、《学校歌》数阕，读之拍案叫绝。此中国文学复兴之先河也。惜余亦一门外汉，仅如夹漈所谓诵其文，习其理而已。寄语某君，自今以往，更委身于祖国文学，据今所学，而调和之以渊懿之风格，微妙之辞藻，苟能为索士比亚、弥儿顿，其报国民之恩者，不已多乎！近年以来，爱国之士，注意此业者，渐不乏人，而黄公度其尤也。公度所制《军歌》二十四章，《幼稚园上学歌》若干章，既行于世。今复得见其近作《小学校学生相和歌》十九章，亦一代妙文也。其歌以一人唱。章末三句，诸生合唱。今亟录如下：案：本《诗草》未收。

# 高旭愿《无尽庐诗话》
原：世界日新，文界诗界当造出一新天地，此一定公例也。黄公度诗独辟异境，不愧中国诗界之哥伦布矣。近世洵无第二人。然新意境新理想新感情的词，终不若守国粹的用陈旧语句为愈有味也。林少泉往时以书寄我，所言可谓先得我心矣。

# 徐世昌《晚晴簃诗话》
原：公度负经世才，少游东西各国，所遇奇景异态，一写之以诗。其笔力识见，亦足以达其旨趣。子美集开诗世界，为古今诗家所未有也。

# 杨香池《偷闲庐诗话》
原：广东黄公度使美，航行海中诗云：案：为《海行杂感》之第十二首，见本《诗草》卷四。海洋飘泊，朝东暮西，迄无定所。诗中情况，读者无不以为入我意中。公度，名遵宪，清末人。著有《人境庐诗集》。尚有《今别离》四首，首首俱以新思想入诗。惜太长，未录。

# 王蘧常《国耻诗话》
原：冯子材谅山之捷，法人溃不成军，西人自入中国以来，未有如此次之受巨创者，亦可以稍雪国耻矣。按察有《冯将军歌》纪其事。其辞云。案：诗见本《诗草》卷四。刻画将军，虎虎如生。连叠十六将军字，盖效史公《魏公子无忌列传》。将军，字翠亭，广东钦州人。初从提督向荣，改隶张国樑，积勋至副将。国樑没，代领其众。取溧水，擢总兵。同治初，将三千人守镇江。时江北诸将，多自置榷厘税，将军曰：此何与武人事？请上级遣官司之。所部可二万，馕恒绌，无怨言。莅镇六载，待士有纪纲，士亦乐为所用。事宁，擢广西提督。赏黄马褂，予世职。故诗有“将军少小能杀贼”云云。越事起，将军被命佐广西边外军事。其时苏元春为督办，将军以其新进出已右，恒悒悒。广西巡抚潘鼎新又屡电不以冯军为得力，将军益愤，遂有致死之谋。故诗有“将军剑光初出匣，将军谤书忽盈箧”云云。谅山之役，彭玉麟《详报谅山大破法虏疏》，述之最详，《清史列传》、《清史稿》皆据为蓝本者也。兹综合各文，叙之于下，为本诗注脚。初，法人争越南，与吾国肇衅。广西巡抚徐延旭调兵防边，败于越南。潘鼎新代之，又挫于谅山。至是将军暨总兵王孝祺军来援，先后抵龙州。孝祺甫出关，而谅山防兵已溃。将军亲率一营，先至南关，鼎新令统十营，回驻关外东路。及闻警，复西援。法兵已入镇南关，统将杨玉科战殁，总兵董履高受重伤，诸军多溃。法兵焚关退，广西大震。时光绪十一年正月十一日也。翌日，将军至南关，建议于关内十里之关前隘，跨东西两岭间，督所部筑长墙三里余，外掘深堑，为扼守计。营于半岭，令孝祺军屯于后半里为犄角。当是时，苏元春、陈嘉军屯幕府，在关前隘后五里；蒋宗汉、方友升军屯凭祥，在幕府后三十里；潘鼎新军屯海村，在幕府后六十里；魏纲军屯艾瓦，防艽封，在关西百里；王德榜军屯油隘，防人关旁路，在关东三十里。独将军一军当中路前敌，全甲蓄锐已久。越人密报，法将出扣波，袭艽封，攻牧马，绕出南关以北，且断唐景崧、马盛治两军归路。元春率军暨魏纲军趋艽封以待。将军遣五营扼扣波以邀之。二十七日，法数十骑率教匪至艽封，官军先在，惊走。将军所部，突出奋击，败遁，获其驮军火大象一，禽匪党一。二月初二日，法军又争扣波，遇冯军而遁，遂无西犯意。将军请于鼎新，调苏军还中路。法扬言将以初八、九日犯关，将军逆料其必将先期于初七日至，乃决先发制敌。鼎新止之，群议亦不欲战，将军力争，率孝祺军于初五夜出关袭敌。山有敌垒三，安巨炮。我军已入街心，自五鼓战至初六日午，敌益盛。孝祺马中炮毙，易骑战，率死十由山后攀崖而上，破其二垒，毙敌甚多，遂败走。我亦还。至初七，法果悉起谅山之众，并力入关，直扑关前隘长墙。将军告诸将军士曰：敌再人关，有何面目见粤民？必死拒之。士气皆奋，誓与长墙俱死。法以开花炮队循东西两岭互进，向下轰击，以枪队扑中路。法谓越人皆冯内应，以法兵列前茅，次黑兵，次西贡洋匪，次教匪客匪。炮声震数十里，山谷皆鸣，枪弹积阵前厚寸许。吾军殊死战。东岭新筑五垒未成，为敌攻踞其三。孝祺自率小队掩敌后，仰攻，敌少却。日加申，元春援兵至，德榜亦自油隘夹击，踞文渊之对山，断其辐重，彻夜鏖战不已。翌晨，复大战，敌来益众，炮益密。将军居中，元春为承，孝祺将右，嘉、宗汉将左。右即东岭敌，炮尤烈。将军与诸将约，设卡于各路后，退者手刃之。敌殊致死，已薄长墙。将军短衣草屦，持矛率二子相荣、相华，大呼跃出搏战。诸军以将军年七十，奋身陷阵，皆感奋，争开壁死斗。关外游兵千余，亦闻警助战。将军驻扣波五营，自关外西路拊敌背。于是诸军合力蚁附，短兵火器杂进。孝祺将潘瀛部皆袒臂樱锋，战尤苦。陈嘉争东岭三垒，宗汉继之。七仆七起，嘉四创不退。及酉末，孝祺已败西路，掩敌后，与嘉等合击。而德榜之军，亦自关外掩东岭之后，遂破三垒，并断敌援。部将张春发、萧德龙战最力。敌外援既绝，辐重亦断，遂大溃。教匪先奔，法兵失道，被歼尤多，死者填塞溪谷，斩法酋数十，追奔逐北二十里而后止。将军以法既大创，遂益兵进规失土。初十日，率十营出攻文渊州，敌望风溃遁，斩红衣法酋一，克之。十二日，以三路攻谅山，法据城固守，并扼对河北岸之驱驴墟。有德榜旧垒，甚固。德榜军仰攻多死，斩法六画兵总一。向午，诸军继至，潘瀛执旗先登，众从之，遂夺其垒。敌涉水遁，为城守。十三日五鼓，杨瑞山、刘汝奇等潜渡攻城，又克之。获其军实无算，军无私焉。十五日，陈嘉、德榜克谷松，斩三画法酋一。麦凤标追敌至观音桥，复克屯梅，禽法酋五画一，斩三画一。复进克拉木，逼郎甲。孝祺亦进贵门关。将军乃定规复北宁之计，越南义民，闻风响应。越南吏黄廷经纠北宁义民立忠义五大团，建将军旗号，愿具浆食为前导。河内、海阳、太原等处，皆密受约信，纷纷叛法，西贡亦通款。已令莫善喜一军，由钦州袭广安。唐景崧一军，亦由牧马进窥太原。将军将于二十五日率全军攻郎甲，并分兵袭北宁。而法人请和，朝命撤兵，乃止。是役克复越南一省一府一州，禽斩法酋至数十。法提督尼忌理亚重伤，法之精锐尽歼，客教离散，全越惊扰。法人自谓入中国以来，未有如此次之惨败者。时滇军亦获大捷。于是法都震，举国嗟怨，将其外部长花利罢黜，仓卒乞款。可知是役所关之大矣。惟枢府习于苟安，不能乘胜立威，可胜悲愤。余尝谓吾国盛衰之机，实伏于鸦片、谅山两役。鸦片之役，林文忠能始终其事，则英可就范，不致有咸丰以后之辱。谅山之役，宿将犹在，国势未夷，能乘诸军积忾之气，使狡者不敢有所逞，效尤者不敢有所谋，则不至有甲午以后之辱。悲夫！故所述不厌详尽，不独欲振已隳之士气，且为今日谋国求苟安者戒焉。将军躯干不逾中人，而朱颜鹤发，健捷虽少壮不如。生平不解作欺人语，发饷躬自监视，少短即罪司糈者。治军四十余年，寒素如故。卒年八十有六，谥勇毅。
原：甲午之役，我陆军一败于牙山，再败于平壤；海军一败于大东沟，再败于旅顺，三败于威海；遂至一蹶不振，铸成今日之大错。黄公度按察于牙山外皆有长歌当哭。《悲平壤》云。案：诗见本《诗草》卷八。案：我既失牙山，时我叶志超、聂士成、丰升阿、左宝贵、卫汝贵、马玉昆诸军皆在平壤，而志超实为总统。志超素庸懦，不足服诸将，汝贵尤贪纵，惟左宝贵、聂士成皆忠勇善战。然志超漫无布置，终为敌乘。宝贵扼玄武门岭，敌大至，志超将冒围北归，宝贵不从，以兵守志超，防其逸去。敌军猛扑，宝贵军酣战久，卒不敌，宝贵矢必死，盛服瓴顶，登陴指麾，连中炮堕地，犹能言，及城下始殒。诗“翠翎鹤顶”云云两语，即谓宝贵，盖纪实也。宝贵既殉，志超遂悬白旗。汝贵已遁，敌来议降，未果。志超率诸将弃平壤北走，敌邀于半涂，复丧其大半，军储器械公牍密电尽委之而去。至是朝鲜境内，我军绝迹矣。其后志超逮问，汝贵正法。诗“一将拘囚一将诛”即谓此。宝贵，字冠廷，山东费县人。由行伍游升至总兵。其殉也，天下哀之。《东沟行》云。案：诗见本《诗草》卷八。案：近人《清史纪事本末》云：“八月十七日，海军提督丁汝昌，率全师抵大东沟。十八日午，遥见西南方有烟东来，知日舰将至，汝昌传令列阵作人字形，镇远、定远两舰为人字之首，致远、靖远、经远、来远、济远、广甲、超勇、扬威及水雷船张人字之两翼。既接战，平远、广丙始来会。敌舰十二艘驶近，列阵作一字形，鱼贯猛扑。俄易而为太极阵，裹人字于其中。汝昌令诸舰先开炮以示威，炮声未绝，敌船已庸至，遂为所困。阵中经远、致远、扬威、超勇先后被击沈，济远、广甲逃，余如镇远、定远、来远、靖远、平远、广丙，受创甚，遂不能成军。”与按察所言皆合，疑当时官报如此，故他笔记亦有同此者，按察亦据官报与？《哀旅顺》云。案：诗见本《诗草》卷八。《哭威海》云。案：诗见本《诗草》卷八。以上两诗于两地及当时形势，如指诸掌。昔人谓杜老将略同李邺侯，按察又岂在杜老下哉！是役论者谓我陆军之败，败于不能战，海军之败，败于能战而不尽能战。当时海军之力实倍于敌，惟以将校骄淫，结党以胁其帅。丁汝昌又非习海军，不足统驭；平时训练不力，临战不能调度，竟至一战而熠。旅顺、威海皆天险，经营十余年，敌至皆委之以去。其后日、俄之战，殒士卒十余万，攻四阅月，仅乃克之。而是役失旅顺仅数日。威海相继陷，军心先变，汝昌仅以一死免生降之辱，可恨亦复可哀。按察又有《降将军歌》咏其事云。案：诗见本《诗草》卷八。或云：当时汝昌已决死，令开足汽机赴敌，与船同殉。而洋员司机者持之，左右亦有欲降者，遂与洋员纠合，私赍降书约降。汝昌知为所卖，遂仰阿芙蓉死。疑莫能明也。

# 屈向邦《粤东诗话》
原：近代诗人，尚意境者宗黄、陈；主神韵者师大历；鎚幽凿险，则韩、孟尚焉；范水模山，则谢、柳尊矣。其有豪杰之士，不欲步趋前贤，如南海康广厦有为，能入能出，一片神行；如镇平丘仙根逢甲，矜才使气，自出机轴；如嘉应黄公度遵宪，突破前人范围，一新诗界面目。之三子者，皆一时巨手，而公度为尤著。

# 钱萼孙《梦苕庵诗话》
原：《人境庐诗》，论者毁誉参半。如梁任公、胡适之辈，则推之为大家。如胡步曾诸君，则又以过欠剪裁瑕累百出卑格俗艳少之。予以为论公度诗，当着眼于其人民性现实性之深度如何，其反帝爱国精神，能反映出近百年来中国史上之主要矛盾，公度诗之真价即在此，不当于小节处作吹毛之求。即就其诗之形式论，天骨开张，大气包举，亦能于古人外独辟町畦。抚时感事之作，悲壮激越，传之他年，足当诗史。至论功力之深浅，则晚清诗人，尽有胜之者，公度之长处，固不在此也。
