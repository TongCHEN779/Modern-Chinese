# 纪事
原：贯索星连熠熠光，
原：穹庐天盖暮苍苍。
原：秋风鼓吹妃呼豨，
原：夜雨铃声劬秃当。
原：《十七史》从何处说，
原：百年债看后来偿。
原：森森画戟重围柝，
原：坐觉今宵漏较长。

# 放归
原：绛帕焚香读道书，
原：屡烦促报讯何如。
原：佛前影怖栖枝鸽，
原：海外波惊涸辙鱼。
原：此地可能容复壁？
原：无人肯就问篌舆。
原：玉关杨柳辽河月，
原：却载春风到旧庐。

# 九月朔日启程由上海归舟中作
原：月黑霜凝点客衣，
原：寥天雁影乍南飞。
原：一池水问干何事，
原：万里风劳远送归。
原：测镜回看星贯索，
原：解装待问石支机。
原：旁人莫误三能望，
原：遥指银潢望紫微。

# 到家
原：处处风波到日迟，
原：病身憔悴尚能支。
原：少眠易醒藏蕉梦，
原：多难仍逢剪韭时。
原：大海走鳗寻有迹。
原：老翁失马卜难知。
原：援琴欲鼓《拘幽操》，
原：月在中天天四垂。

# 感事　其一
原：授受元辰纪上仪，
原：帝尧训政典留贻。
原：谁知高后垂簾事，
原：又见成王负扆时。
原：九鼎齐鸣惊雉雊，
原：千金悬格购龙医。
原：白头父老纷传说，
原：上溯乾嘉泪欲垂。

# 感事　其二
原：上变飞腾赤白囊。
原：两端首鼠疾奔忙。
原：刚闻赤板连名奏，
原：便召长枪第六郎。
原：驰骑锁门谋大索，
原：屯桥阻水伺非常。
原：珠襦武帐诸臣侍，
原：亟诏明晨幸未央。

# 感事　其三
原：推车弄顶看文康，
原：变态真如傀儡场。
原：五百控弦谋劫制，
原：一丸进药失先尝。
原：传书信口诃西母，
原：改制称尊托素王。
原：九死一生仍脱走，
原：头颅声价重天亡。

# 感事　其四
原：金瓯亲卜比公卿，
原：领取冰衔十日荣。
原：东市朝衣真不测，
原：南山铁案竟无名。
原：芝焚蕙叹嗟僚友，
原：李代桃僵泣弟兄。
原：闻道诟天兼骂贼。
原：好头谁斫未分明。

# 感事　其五
原：父子相从泣狱扉，
原：老翁七十荷征衣。
原：一家草索看生缚，
原：三寸桐棺待死归。
原：凿空虚槎疑汉使，
原：涉江奇服怨湘妃。
原：可怜时俊才无几，
原：瓜蔓抄来摘更稀。

# 感事　其六
原：下诏曾宣母子离，
原：初闻逐谏后笞儿。
原：心肝谁奉藏衣诏，
原：骨肉难征对簿词。
原：一网打余高鸟尽，
原：九泉曲处蛰龙知。
原：恩牛怨李原无与，
原：莫误忠奸读党碑。

# 感事　其七
原：师未多鱼遂漏言，
原：如何此事竟推袁？
原：佰人谁白孱王罪？
原：改子终伤慈母恩。
原：金玦庞凉含隐痛，
原：杯弓蛇影负奇冤。
原：五洲变法都流血，
原：先累维新案尽翻。

# 感事　其八
原：太白星芒月色寒，
原：五云缥缈望长安。
原：忍言赤县神州祸，
原：更觉黄人捧日难。
原：压己真忧天梦梦，
原：穷途并哭海漫漫。
原：是非新旧纷无定，
原：君看寒蝉噤众官。

# 人境庐之邻有屋数间余购取其地葺而新之有楼岿然独立无壁南武山人为书一联曰陆沈欲借舟权住天问翻无壁受呵因足成之
原：半世浮槎梦里过，
原：归来随地觅行窝。
原：陆沈欲借舟权住，
原：天问翻无壁受呵。
原：偶引雏孙问初月，
原：且容时辈量汪波。
原：湾湾几曲青溪水，
原：可有人寻到钓蓑？

# 寒夜独坐卧虹榭
原：今时何时我非我，
原：中夜起坐心旁皇。
原：风声水声乌乌武，
原：日出月出团团黄。
原：层阴压屋天四盖，
原：寒云入户山两当。
原：回头下视九州窄，
原：高飞黄鹄今何方？

# 小饮息亭醉后作
原：斜日江波听鹧鸪，
原：鹧鸪啼处是吾庐。
原：酒酣仍作思乡梦，
原：径仄难为《益地图》。
原：偶约故人同茗芋，
原：居然丈室坐莲须。
原：朝朝捧牍应官去，
原：忽忆吴江老钓徒。

# 仰天
原：仰天击缶唱乌乌，
原：拍遍阑干碎唾壶。
原：病久忍摩新髀肉，
原：劫余惊抚好头颅。
原：箧藏名士株连籍，
原：壁挂群雄豆剖图。
原：敢托鸩媒从凤驾，
原：自排阊阖拨云呼。

# 雁
原：汝亦惊弦者，
原：来归过我庐。
原：可能沧海外，
原：代寄故人书？
原：四面犹张网，
原：孤飞未定居。
原：匆匆还不暇，
原：他莫问何如。

# 酬刘子岩同年瑛
原：铁汉楼高天四垂，
原：岭云愁护党人碑。
原：看花每溅啼鹃泪，
原：绕树难安飞鸟枝。
原：何地可名清净土？
原：思君忽到太平时。
原：一家乐寿兼文福，
原：呼聿吟书买写诗。
