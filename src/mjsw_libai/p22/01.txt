# 安州应城玉女汤作
题解：旧注：《荆州记》云：常有玉女，乘车投此泉。
题解：《元和郡县志》：淮南道安州有应城县，东北至州八十里。《艺文类聚》：盛弘之《荆州记》曰：新阳县惠泽中有温泉，冬月，未至数里，遥望白气浮蒸如烟，上下采映，状若绮疏。又有车轮双辕形，世传：音有玉女，乘车自投此泉。今人时见女子，姿仪光丽，往来倏忽。《一统志》：玉女泉，在湖广德安府应城县西五十五里，其泉热沸，野老相传：玉女炼丹之地。
诗：神女殁幽境，/汤池流大川。/阴阳结炎炭，/造化开灵泉。
诗：地底烁朱火，/沙旁歊素烟。/沸珠跃明月，/皎镜涵空天。
注原：底烁：音铄
注原：旁歊：音嚣
注原：沙旁歊素烟：古诗：朱火然其中，门烟飏其间。《说文》：歊，气出貌。
注原：明：缪本作“晴”
注原：皎镜涵空天：沈约诗：洞彻随清浅，皎镜无冬春。吕向注：皎镜，清明如镜也。
诗：气浮兰芳满，/色涨桃花然。/精览万殊入，/潜行七泽连。
注原：精览万殊入：《淮南子》：承天地之和，形万殊之体。
注原：潜行七泽连：《子虚赋》：楚有七泽。
诗：愈疾功莫尚，/变盈道乃全。/濯缨掬清泚，/晞发弄潺湲。
注原：愈疾功莫尚：《水经注》：温泉能瘥百病。
注原：变盈道乃全：《周易》：地道变盈而流谦。
注原：濯缨掬：萧本作“濯濯气”
注原：濯缨掬清泚：《楚辞》：沧浪之水清兮，可以濯吾缨。谢眺诗：寒流自清泚。《说文》：泚，清也。
注原：晞发弄潺湲：《楚辞》：与汝沐兮咸池，晞汝发兮阳之阿。王逸注；晞，乾也。谢灵运诗：且申独往意，乘月弄潺湲。
诗：散下楚王国，/分浇宋玉田。/可以奉巡幸，/奈何隔穷偏。
注原：分浇宋玉田：宋玉《小言赋》：楚襄王登阳云之台，令诸大夫景差、唐勒、宋玉等曰：“有能为《小言赋》者，赐之云梦之田。”宋玉曰“无内之中，微物潜生，比之无象，言之无名”云云。王曰：“善。”赐以云梦之田。
原：独随朝宗水，赴海输微涓。·贾谊《鹏赋》：天地为炉兮，造化为工。
注原：独随朝宗水：《禹贡》：江汉朝宗于海。孔安国传：二水入海，有似于朝。百川以海为宗。宗，尊也。孔颖达《正义》：《周礼·大宗伯》：诸侯见天子之礼：春见曰朝，夏见曰宗。郑云：朝，犹朝也，欲其来之早也。宗，尊也，欲其尊王也。朝宗是人事之名，水无性识，非有此义。以海大而江汉小，以小就大，似诸侯归于天子，假人事而言之也。
诗：阴阳为炭兮，/万物为铜。
注原：万物为铜：张正见诗：康衢飞驶羽，大海滴微涓。
原：萧士赞曰：寄兴谓亡不幸居于僻远之乡，虽抱王佐之才；而无由白达。身在江湖，心存魏阙而已，悲夫！

# 下途归石门旧居
题解：题注：题下似缺“别人”字按《太平府志》：横望山，在当涂县东六十里。春秋楚子重伐吴，至于横山，即此山也。实为金陵朝对之山。《真诰》称其石形瓌奇，洞穴盘纡，陶隐居尝栖迟此地炼丹，故有陶公读书堂、石门、古祠、灰井、丹炉诸遗迹。书堂今为澄心寺。石门山水尤奇，盘道屈曲，沿磴而入，峭壁二里，夹石参天，左拥右抱，罗列拱揖，高者抗层霄，下者入衍奥。中有玉泉嵌空，渊渊而来，春夏霖潦奔驰，秋冬澄流一碧，萦绕如练。观诗中所称隐居山寺。“陶公链液”、“石门流水”诸句，知石门旧居，盖在其处矣。
诗：吴山高，/越水清，/握手无言伤别情。/将欲辞君挂帆去，
诗：离魂不散烟郊树。/此心郁怅谁能论，/有愧叨承国士恩。/云物其倾三月酒，
注原：离魂不散烟郊树：虞炎诗：聚学从烟郊，楼遁事环摹。
诗：岁时问饯五侯门。/羡君素书常满案，/含丹照白霞色烂。/余尝学道穷冥筌,梦中往往游仙山。
注原：五侯：见十一卷注。
注原：含丹照白霞色烂：《神仙传》：王烈入河东抱犊山中，见一石室，中有素书两卷。琦按：古人以绢素写书：故谓书曰“素书”。含丹者，书中之字，以朱写之，白者绢色，丹白相映，烂然如霞矣。
注原：冥筌：音诠
注原：余尝学道穷冥筌,：江淹诗：一时排冥筌。闵赤如注：冥，理也。筌，迹也。言理、迹双遣也。一说：冥，幽也。筌，迹也。冥筌，道中幽冥之迹也。
诗：何当脱屣谢时去，/壶中别有日月天。/俛仰人间易凋朽，/钟峰五云在轩牖。
注原：何当脱屣谢时去：《汉书·郊祀志》：天子曰：“诚得如黄帝，吾视去妻子如脱屣耳。”颜师古注：屣，小履。脱屣者，言其便易无所顾也。《列仙传》：王子乔乘白鹤驻山头，举手谢时人，数日而去。
注原：壶中别有日月天：《灵台治中录》：施存，鲁人，学大丹之道三百年，十链不成，唯得变化之术。后遇张申为云台治官。常悬一壶，如五升器大，变化为天地，中有日月如世间，夜宿其内，自号壶天，人谓曰壶公。
注原：钟：缪本作“鑪”
注原：钟峰五云在轩牖：《名山洞天福地记》：钟山，周回一百里，名朱湖太生之天，在润州上元县。五云，五色云也。见七卷注。
诗：惜别愁窥玉女窗，/归来笑把洪崖手。
注原：玉女窗：在嵩山。见十六卷注。洪崖，三皇时伎人得仙者。《广博物志》：青城山洞，周回二千里，音洪崖先生服琅玕之华而隐，代为青城真人。
诗：隐居寺，/隐居山，/陶公链液栖其间。/灵神闭气音登攀，
注原：陶公链液栖其间：《因话录》：宣州当涂隐居山岩，即陶贞白炼丹所也。炉迹犹在，后为佛舍。
诗：恬然但觉心绪闲。/数人不知几甲子，/昨来犹带冰霜颜。/我离虽则岁物改，
注原：数人不知几甲子：《左传》：晋悼夫人食与人之城杞者。绛县人或年长矣，无子，而往与于食，有与疑年，使之年。曰：一臣，小人也，不知纪年。臣生之岁，正月甲子朔，四百有四十五甲子矣。其季于今，三之一也。”
注原：来：萧本作“夜”，误
诗：如今了然识所在。/别君莫道不尽欢，/悬知乐客遥相待。
注原：识：许本作“失”，误
诗：石门流水徧桃花，/我亦曾到秦人家。/不知何处得鸡豕，/就中仍见繁桑麻。
注原：就中仍见繁桑麻：桃花流水、鸡豕桑麻，比之秦人之桃源也。详见二卷注。
诗：脩然远与世事间，/装鸾驾鹤又复远。/何必长从七贵游，/劳生徒聚万金产。
注原：脩然远与世事间：《庄子》：脩然而往，脩然而来。陆德明《音义》：脩，音萧。徐音叔。李音悠。向云：脩然，自然无心而自尔之义。郭、崔云：往来不难之貌。
注原：复：缪本作“服”
注原：装鸾驾鹤又复远：江淹《别赋》：驾鹤上汉，骖鸾腾天。
注原：七贵：见十一卷注。庾信诗：惜无万金产，东求沧海君。
诗：挹君去，/长相思，/云游雨散从此辞。/欲知怅别心易苫，/向暮春风杨柳丝。
注原：挹：即揖也。古字通用。

# 客中作
题解：题注：萧本作《客中行》
诗：蔺陵美酒郁金香，/玉椀盛来琥珀光。/但使主人能醉客，/不知何处是他乡？
注原：蔺陵美酒郁金香：唐时沂州之承县，春秋时鄫国也。后魏于此置兰陵郡，隋废郡为兰陵县，唐武德四年改口承县，在沂州西一百八十里。《元和郡县志》：兰陵县城，在沂州承县东六十里。《史记》：荀卿适楚，春申君以为兰陵令。《正义》云：兰陵县，属东海郡，今沂州承县有兰陵山。《梁书》：郁金出罽宾国，花色正黄而细，与芙蓉花、裹被莲者相似。国人先取以上佛寺，积日香槁，乃粪去之。贾入从寺中征顾，以转卖与他国也。《香谱》：郁金香，《魏略》云：生大秦国，二三月花，如红蓝，四五月采之。其香十二叶，为百草之英。

# 太原早秋
题解：太原郡，即并州也，唐时隶河东道。
诗：岁落众芳歇，/时当大火流。/霜威出塞早，/云色渡河秋。
注原：时当大火流：张衡《定情歌》：大火流兮草虫鸣。《图书编》：大火，心星也。以六月之昏，加于地之南，至七月之昏，则下而西流矣。
注原：出塞：音赛
诗：梦远边城月，/心飞故国楼。/思归若汾水，/无日不悠悠。
注原：思归若汾水：《唐六典注》：汾水出忻州，历太原、汾、晋绛、蒲五州，入河。《太平寰字记》：汾水，出静乐县北管涔山，东流入太原郡界。

# 奔亡道中五首
诗：苏武天山上，/田横海岛边。/万重关塞断，/何日是归年？
注原：苏武天山上：《唐书·地理志》：伊州伊吾县，在大碛外，南去玉门吴八百里，东去阳关二千七百三十里，有折罗漫山，亦曰天山。刘删《苏武诗》：食雪天山近，思归海路长。盖以天山为匈奴地耳，其实苏武啮雪及牧羊之处，不在天山也。
注原：田横海岛边：《史记》：汉灭项籍，汉王立为皇帝，田横惧诛，与其徒属五百余人人海，居岛中。韦昭曰：海中山曰岛。《正义》曰：按海州东海县有岛山，去岸八十里。

# 奔亡道中五首·其四
诗：函谷如玉关，/几时可生还？/洛阳为易水，/嵩岳是燕山。
注原：函谷：详见五卷注。《后汉书》：班超久在绝域，年老思土，上疏曰：“臣不敢望到酒泉郡，但愿生入玉门关。”帝乃征超还。章怀太子注：玉门关，属敦煌郡，今沙州也。去长安三千六百里，关在敦煌县西北。
注原：阳：缪本作“川”
注原：洛阳为易水：《通志·地理略》：洛水，出商州上洛县，经号州、河南入河。《史记正义》：易水出易州易县，东流过幽州归义县，东与滹沱河合。
注原：嵩岳是燕山：《通志·地理略》：中岳嵩山，在河南告成县。《隋书》：渔阳郡无终县有燕山。《太平御览》：《隋图经》云：燕山，在易县东南七十里。
诗：俗变羌、胡语，/人多沙塞颜。/申包惟恸哭，/七日鬓毛斑。
注原：七日鬓毛斑：《左傅》：吴入郢，昭正在随，申包胥如秦乞师曰：“吴为封豕长蛇，以荐食上国，虐始於楚。寡君失守社稷，越在草莽，使下臣告急。”秦伯使辞焉，曰：“子姑就馆，将图而告。”对曰：“寡君越在草莽，未获所伏，下臣何敢即安？”立依於庭墙而哭，日夜不绝声，勺饮不入口七日，秦哀公为之赋《无衣》。九顿首而坐。秦师乃出。
诗：太白意谓函谷之地，/已为禄山所据，/未知何日平定，/得能生入此关。
原：洛川、嵩岳之间，不但有同边界，而风俗人民，亦且渐异华风。
原：己之所以从永王者，欲效申包恸哭乞师，以救国家之难耳，自明不敢有他志也，其心亦可哀矣。

# 郢门秋怀
题解：郢门，即荆门也。唐时为峡州夷陵郡，其地临江，有山曰荆门，上合下开，有若门象。故当时文士概称其地曰荆门，或又谓之郢门。西通巫、巴，东接云梦，历代常为重镇。
诗：郢门一为客，/巴月三成弦。/朔风正摇落，/行手愁归旋。
注原：巴月三成弦：吴均诗：别离未几日，高月二成弦。
注原：朔风正摇落：《楚辞·九辩》：萧瑟兮草木摇落而变衰。
诗：杳杳山外日，/茫茫江上天。/人迷洞庭水，/雁度潇湘烟。
注原：杳杳山外日：刘向《九叹》：日杳杳以西颓。
诗：清旷谐宿好，/缁磷及此年。/百龄何荡漾，/万化相推迁。
注原：清旷谐宿好：《后汉书》：仲长统欲卜居清旷，以乐其志。
注原：百龄何荡漾：梁昭明太子《陶靖节集序》：处百龄之内，居一世之中。
注原：万化相推迁：《庄子》：若人之形，万化而未始有极也。

# 西施
诗：西施越溪女，/出自苎萝山。/秀色掩今古，/荷花羞玉颜。
注原：出自苎萝山：《吴越春秋》：越王谓大夫种曰：“孤闻吴王淫而好色，惑乱沉湎，不领政事，因此而谋可乎？”乃使相者於国中，得苎萝山鬻薪之女曰西施、郑旦，饰以罗縠，教以容步，习於上城，临於都巷，三年学服，而献於吴。吴王大悦。施宿《会稽志》：苎萝山在诸暨县南五里。《与地志》云：诸暨县苎萝山，西施、郑旦所居，其方石乃晒纱处。《十道志》云：句践索美女以献吴王，得之诸暨绊箩山卖薪女西施，山下有浣纱石。《一统志》：浣浦，在诸暨县治东南，一名浣渚，俗传西子浣纱於此。

注原：皓齿信难开：曹植诗：时俗薄朱颜，谁为发皓齿。
诗：句践徵绝艳，/扬蛾入吴关。/提携馆娃官，/杳渺讵可攀。

# 苏台览古
题解：范成大《吴郡志》：姑苏台，旧图经云在吴县西三十里，续图经云三十五里，一名姑胥，一名姑余。《史记正义》云：在吴县西南三十里横山西北麓姑苏山上。《山水记》云：阖闾作，春秋游焉。又云：夫差作台，三年不成，积材五年乃成，造九曲路，高见三百里。《越绝书》云：阖庐造九曲路，以游姑胥之台。《吴越春秋》言：阖庐画游苏台。盖此台始基於阖庐，而成於夫差，庶可以合传记之说。
诗：旧苑荒台杨柳新，/菱歌清唱不胜春。/只今惟有西江月，/会照吴王官里人。
注原：清：缪本作“春”，误
注原：西江：霏玉本、缪本作“江西”
