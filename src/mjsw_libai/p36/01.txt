# 瀑布
诗：断岩如削瓜，/岚光破崖绿。/天河从中来，/白云涨川谷。
诗：玉案赤文字，/落落不可读。/摄衣凌青吞，/松风吹我足。
原：《二老堂诗话》：司空山，在舒州太湖县界，初经重报寺，过马玉河，至金轮院，有僧本净肉身塔及不受叶连花池，连理山茶。白塔院乃上山，至本净坐禅岩，精巧天成，中途断崖绝壑，旁临万仞，号“牛背石”。宗室善修者言石如剑脊中起，侧足覆身而过，危险之甚。度此步步皆佳。上有一寺及李太白读书堂，一峰玉立，有太白《瀑布诗》，云：“断岩如削瓜，岚光破崖绿。天河从中来，白云涨川谷。玉案赤文字，落落不可读。摄衣凌清霄，松风吹我足。”予兄子中守舒日，得此于宗室公霞，今胡仔《渔隐丛话》载蔡绦《西清诗话》不言此山，但云太白仙去，后人有见其诗，略云：“断崖如削瓜，岚光破崖绿。天河从中来，白云涨川谷。玉案敕文字，世眼不可读。摄身凌青霄，松风吹我足。”又云：“举袖露条脱，招我饭胡麻。”真烟云中语也。既误以“断岩”为“断崖”与第二句相重，“赤文”作“敕文”，“落落”作“世眼”，“摄衣”作“摄身”，皆浅近，与前句大相远。当涂《太白集》本原无此诗，因子中录寄郡守，遂刻于后。然皆从蔡绦误本，子中争之不从，仅能改“敕”为“赤”而巳。《唐诗纪事》：近世传白诗云：“断崖如削瓜，岚光破崖绿。
诗：天河从中来，/白云涨川谷。/玉案赤文字，/落落不可读。
原：摄衣凌清云，松风拂我足。”又不同者数字。

# 断句
原：举袖露条脱，招我饭胡麻。
注原：举袖露条脱：《太平广记》：条朓，似指环而大。《唐诗纪事》：文宗问宰臣：“古诗云轻衫衬眺脱’。眺脱'是何物？”宰臣未对，上曰：“即今之腕钏也。”《真诰》言：安妃有断粟金朓脱，是臂饰。朓脱，即条脱也。《唐诗纪事》亦载此句，“举袖”作“举手”。
注原：招我饭胡麻：《太平广记》：刘晨、阮肇入天台采药，有二女子邀还家，其馔有胡麻饭、山羊脯。按：胡麻，即今之芝麻也。相传张骞自大宛得其种以归，以其出自胡中，故曰胡麻。
原：野禽啼杜字，山蝶舞庄周。
注原：杜字：杜鹃也。见三卷注。
注原：山蝶舞庄周：《渔隐丛话》：《法藏碎金》云：予记太白有诗云：“野禽啼杜字，山蝶舞庄周。”后又见潘佑有《威怀诗》：“幽禽唤杜字，宿蝶梦庄周。席地一樽酒，思与元化浮。但莫孤明月，何必秉烛游。”予谓才思暗合，古今无殊，不可怪也。
原：右三首见《渔隐丛话》诸书。

# 阳春曲
题解：沈约作《江南弄》四曲，其三曰《阳春曲》。
诗：芣苡生前径，/含桃落小园。/春心自摇荡，/百舌更多言。
注原：芣：音浮
注原：芣苡：音以，一作莒
注原：芣苡生前径：陆玑《草木疏》芣苡，一名马舄，一名车前，一名当道喜。在牛马迹中生，故曰车前、当道，今药中“车前子”是也。幽州人谓之牛舌草，可鬻作茹，大滑，其子治妇人难产。
注原：含桃落小园：《埤雅》：樱桃，为木多阴，其果先熟，一名含桃。许惧曰：莺之所含食，故曰含桃也。谓之莺桃，则亦以莺之所含食，故谓之莺桃也。《尔雅翼》：樱桃，朱实，甘美。飞鸟所含，故又名含桃。《尔雅》谓之荆桃，其花在梅后，至果熟则最先。
注原：百舌更多言：《本草纲目》：百舌，处处有之，居树孔窟穴中，状如鹤鹄而小，身略长，灰黑色，微有斑点，喙亦尖黑，行则头俯，好食蚯蚓，立春后鸣啭不已，夏至后则无声，十月后则藏蛰。《月令》“仲夏反舌无声”即此。

# 舍利佛

诗：金绳界宝地，/珍木荫瑶池。/云间妙音奏，/天际法蠡吹。
注原：金绳界宝地：《法华经》：时娑婆世界即变清净，琉璃为地，宝树荘殿，黄金为绳，以界八道。
注原：天际法蠡吹：又云：雨大法雨，吹大法螺。《文献通考》；贝之为物，其大可容数升，蠡之大者也。南蛮之国取而吹之，所以节乐也。今之梵乐用之，以和铜钹。释氏所谓法螺，赤土国吹螺以迎隋使是也。法蠡，即法螺也。古“螺”字一作“蠡”，通用。

# 钓台
诗：磨尽石岭墨，/寻阳钓赤鱼。/霭峰尖似笔，/堪画不堪书。
注原：磨尽石岭墨：《方与胜览》：钓台在徽州黟县南十八里，亦名寻阳台。相传李白尝钓于此，有诗云“磨尽石岭墨”云云。《太平寰字记》；墨岭山，在黟县南十八里，岭上石如墨色，岭有穴，中有墨石软腻，土人取为墨，色碧甚鲜明，可以记文字。
注原：霭峰尖似笔：《方与胜览》：霭峰，在黟县南十五里，孤峭如削。
原：《九域志》《锦绣万花谷》、《一统志》皆引“霭峰尖似笔”之句，以为太白诗。罗愿《新安郡志》曰：太白常称金华五百滩之胜，而思为新安之游，又尝自回溪十六渡至黄山汤泉之下，则吾上山川胜概，颇已寄于逸想。其赠许宣平诗，沈汾述以为传，当不虚也。又有《答山中人》，所谓桃花流水杳然去，别有天地非人间”、相传以为入黟所作，而俗又有《石墨岭》与《水西兴唐寺》诗，语不类太白。东坡尝疑《富阳》、《国清》、《彭泽》、《兴唐》诗及《姑熟十咏》非太白所作，而王平甫疑《十咏》出于李赤。按：南唐自有一翰林学士李白，曾子固以为《十咏》是此人所为，然则此间《墨岭》、《兴唐》诗，岂亦此类耶？

# 小桃源

注原：黟县小桃源：《方与胜览》：樵贵谷，在徽州黟县北。音土人入山，行七日，至一穴，豁然周三十里，中有十余家，云是秦人避入此地。按：邑圃有潜村，至今有数十家，同为一村，或谓之小桃源，李白诗“黟县小桃源”云云。

原：类书中多摘引太白诗句，然不能无错缪。《海录碎事》、《锦绣万花谷》二编，学士家以其出自宋人，尤珍尚之。其所引太白断句甚多，亦有误者。如“雨吟春破碎，贫钦客凋零”，“山含红树随时老，天带黄昏一例愁”。“茶褐园林新柳色，鹿胎田地落梅香”，“江边石上谁知处，绿战红酣别是春”。“只有人间闲妇女，一枚煎饼补天穿”，皆是李觏诗（因觏字太伯，遂譌作太白）。“上有万仞山，下有千丈水。苍苍两崖间，阔狭各一苇”，是白乐天诗。“晚花红艳静，高树绿阴初。亭午清无比，溪山画不如”，是杜牧诗。“虬须顦羽林即，曾人甘泉侍武皇。鵰没夜云知御苑，马随仙仗识天香”，是李郢诗。而皆以为太白诗矣。又若“霜结梅尚玉，阴凝竹千银”，“竹粉千腰白，桃皮半颊红”。“心为杀人剑，泪是报恩珠”，“绮楼何氛氲，朝日正杲杲”，“玉颜上哀啭，绝耳非世有”，“佳人微醉玉颜酡，笑倚妆楼澹小蛾”，“借问单楼与同穴，可能银汉胜重泉”，“露暗烟浓草色新，一番流水满汉春。可怜渔父重来访，只见桃花不见人”，“昔日狂秦事可嗟，直驱鸡犬人桃花。至今不出烟峦口，万古潺湲一水斜”，“庭中繁树乍含芳，红锦重重翦作囊。还合炎蒸留烁景，题来淌得好篇章”诸句，未详为谁氏之作，其句法皆与太白不相似，亦皆以为太白诗矣。罗鄂州《新安郡志》谓南唐时另有一翰林学士李白，《姑熟十咏》是其所作。然则后人所传李白诸逸诗及断句之为诸书所误引而其名莫可考者，乌知非斯人之作耶？昔人论杜诗真伪，谓“人才之不同如其面焉，耳目口鼻相去亦无几，谛视之，未有不差殊者。诗至少陵，固不可得而乱也”。斯言良是。夫学力如少陵，其诗不可得而乱；天才若青莲，其诗固可得而乱耶！然知其不可乱，而犹彙之编之，而附之於本集之后，岂曰务博，良欲存此以为后人辨其真赝，而知所取法焉耳。

# 断句（二）
原：焰随红日去，烟逐暮云飞。令一日赋山火诗，思轧不属，太白从旁缀其下句。令诗云：“野火烧山去，人归火不归。”太白继云。

# 北斗延生经注解序
原：原夫太素未分，无光无象，混黄成化，有始有终，则升清而滞秽，辅善而贬凶。置百二十曹局，列於冥府；造三十六部经，秘於琼官。度天人之有道，启含识之不矇。余叹曰：莫非三界十方，天地人伦，斯所以为道之纪也。今窃见圣世，幸逢丰年，得遇皇恩。将道德而安家邦，效勋华而育黎庶，而况天下晏然，太元彰耀。今即启有道之心者，扶风氏等志奉日新，慕真岁久。祷天佑而制凶魔，求师训而传道要。遂得遇崆峒山元真人，明龙汉之元文，演赤文之妙奥。教符十洞三乘，化列万机一义，注解《北斗廷生经》一卷。上则有飞神金阙，中则有保国宁家，次则有延龄益寿。普度有情之品，同登无碍之门，於是谨作斯文，用题经首。李白谨序。
原：录自《全唐文》卷三四九
