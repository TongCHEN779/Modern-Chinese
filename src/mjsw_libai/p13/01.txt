# 庐山谣寄卢侍御虚舟
题解：《太平寰宇记》：庐山，在江州南，高二千三百六十丈，周回二百五十里。其山九叠，川亦九派。《郡国志》云：庐山叠嶂九层，崇岩万仞。《山海经》所谓三天子鄣，亦曰天子都也。周武王时，匡俗字子孝，兄弟七人，皆有道术，结庐于此。仙去，空庐尚存，故曰庐山。李华《三贤论》：范阳卢虚舟幼真，质方而清。贾至有授卢虚舟殿中侍御史制，云：勅大理司直卢虚舟，闲邪存诚，逊世颐养。操持有清廉之誉，在公推干蛊之才。可殿中侍御史，云云。殆其人也。
诗：我本楚狂人，/凤歌笑孔丘。/手持绿玉杖，/朝别黄鹤楼。
注原：歌笑：一作“哭”，非
注原：凤歌笑孔丘：《高士传》：陆通，字接舆，楚人也。好养性，躬耕以为食。楚昭王时，通见楚政无常，乃佯狂不仕，时人谓之楚狂。孔子适楚，接舆游其门，曰：“凤兮凤兮，何如德之衰也。来世不可待，往世不可追也。天下有道，圣人成焉。天下无道，圣人生焉。方今之时，仅免刑焉。顽轻乎羽，莫之知载。祸重乎地，莫之知避。已乎已乎，临人以德。殆乎殆乎，画地而趋。迷阳迷阳，无伤吾行。却曲却曲，无伤吾足。山木自寇也，膏火自煎也。桂可食，故伐之。漆可用，故割之。人皆知有用之用，而不知无用之用也。”孔子下车欲与之言，趋而避之，不得与之言。楚王闻陆通贤，遣使者持金百镒，车马二驷，往聘，曰：“王请先生治江南。”通笑而不应。使者去，夫负釜甑，妻戴器，变名易姓，游诸名山。食桂幢实，服黄精子，隐蜀峨眉山，寿数百年，俗传以为仙云。
注原：玉杖：一作“枝”
注原：朝别黄鹤楼：《湖广通志》：黄鹤楼在武昌府城西南隅黄鹤矶上。
诗：五岳寻仙不辞远，/一生好入名山游。/庐山秀出南斗旁，/屏风九叠云锦张，/影落明湖青黛光。
注原：屏风九叠云锦张：周省斋曰，宋陈舍举《庐山记》：旧志云；汉武帝过九江，筑羽章馆于屏风叠，下临相思涧。今五老一峰，叠石如屏嶂，盖其故地。
诗：金阙前开二峰长，/银河倒挂三石梁，/香炉瀑布遥相望，/回崖沓嶂凌，/缪本作“峻”苍苍。
注原：峰长：缪本作“帐”
注原：金阙前开二峰长：《水经注》：庐山之北有石门水，水出岭端，有双石高竦，其状若门，因有石门之目焉。水导双石之中，悬流飞瀑，近三百步许，散漫数十步。上望之连天，若曳飞练于霄中矣。
注原：倒挂：一作“泻”
注原：银河倒挂三石梁：《荨阳记》曰：庐山上有三石梁，长数十丈，广不盈尺，杳然无底。查悔余曰：元李涧言，三石梁在开先寺西，黎崱言在五老峰上，或云在筒寂观及上霄、紫霄二峰间。桑乔《庐山纪事》则竟以为无如竹林之幻境。众说纷然，莫知所指。今三叠泉在九叠屏之左，水势三折而下，如银河之挂石梁，与太白诗句正相脗合，非此外别有三石梁也。后人必欲求共地以实之，失之凿矣。
注原：瀑：音仆
注原：香炉瀑布遥相望：释慧远《庐山记》：其山大岭凡七重，圆基周回垂五百里。其南岭临宫亭湖，下有神庙。七岭会同，莫有升之者。东南有香炉峰，游气笼其上，氤氲若香烟。西南有石门山，其形似双阙，壁立千余仞，而瀑布流焉。其中鸟兽草木之美，灵药芳林之奇，所称名代。杨齐贤曰：《庐山记》：山南、山北瀑布无虑十余处。香炉峰与双剑峰在瀑布之旁，水源在山顶，人未有穷者。或曰，西入康王谷为水帘，东为开元禅院之瀑布。
注原：嶂凌：一作“何”
注原：缪本作“峻”苍苍：杨炯诗：重岩窅不极，叠嶂凌苍苍。
诗：翠影红霞映朝日，/鸟飞不到吴天长。/登高壮观天地间，/大江茫茫去不还。
注原：朝日：一作“照千里”
诗：黄云万里动风色，/白波九道流雪山。/好为庐山谣，/兴因庐山发。
注原：白波九道流雪山：《尚书》：九江孔殷。孔安国注：江于此州界分为九道。《街书音释》：九江，《寻阳记》云：一曰鸟白江，二日蝽江，三曰乌江，四曰嘉靡江，五曰畎江，六日源江，七曰廪江，八曰提江，九曰箘江。张须元《缘江图》云：一日三里江，二曰五州江，三日嘉靡江，四日乌土江，五曰白蚌江，六曰白乌江，七曰箘江，八曰沙堤江，九日禀江。参差随水长短，或百里，或五十里。始于鄂陵，终于江口，会于桑落洲。《太康地记》曰：九江，刘歆以为湖汉九水，入彭蠡泽也。《太平寰宇记》：《寻阳记》云：九江在浔阳，去州五里，名白马江，是大禹所疏。会于桑落洲上下三百余里合流。昔秦皇汉武并登庐山，以望九江也。琦按：太史公曰：予南登庐山，观禹疏九江。《淮南子》曰：禹凿江，而通九路。应劭曰：江自寻阳分为九。郭璞《江赋》曰：流九派于寻阳。自西汉迄东晋，皆言大江至寻阳分为九江。《寻阳记》、《缘江图》又备列其名，而朱子《九江辩》独辟之，不从其说。林少颖曰：九江之名与地势，久远不可强通，然各自别源，而下流入江，则可以意臆也。当由水道通塞离合，古今各异之故。斯言当矣。
诗：闲窥石镜清我心，/谢公行处苍苔没。/早服还丹无世情，/琴心三叠道初成。
注原：闲窥石镜清我心：《艺文类聚》：宫亭湖边，旁山间，有石数枚，形圆若镜，明可以鉴人，谓之石镜。《太平寰宇记》：石镜在东山悬屋之上，其状团圆，近之则照见形影。《一统志》：石镜峰在南康府西二十六里，有一员石悬崖，明净照人见影，隐见无时。谢灵运诗：攀崖照石镜。即此。
注原：苔没：一作“绿萝开处悬明月”
注原：谢公行处苍苔没：谢灵运有《登庐山绝顶望诺娇》诗。
注原：早服还丹无世情：《抱朴子》：还丹，服一刀圭，百日仙也。朱鸟凤凰，翔覆其上，玉女至旁。《广弘明集》：烧，丹成水银，还水银成丹，故曰还丹。
注原：琴心三叠道初成：《黄庭内景经》：琴心三叠舞胎仙。梁丘子注：琴，和也。叠，积也。存三丹田，使和积如一。
诗：遥见仙人彩云裹，/手把芙蓉朝玉京。/先期汗漫九垓上，/愿接卢敖游太清。
注原：手把芙蓉朝玉京：《枕中书》：元始天王在天中心之上，名日玉京山。山中宫殿，并金玉饰之。
注原：愿接卢敖游太清：《淮南子》：卢敖游于北海，经乎太阴，入乎玄阙，至于蒙谷之上。见一士焉，深目而玄鬓，泪注而鸢肩，丰上而杀下，轩轩然，方迎风而舞。顾见卢敖，慢然下其臂，遯逃乎碑下。卢敖就而视之，方倨龟壳而食蛤梨。卢敖与之语，曰：“惟敖为背群离党，穷观于六合之外者，非敖而已乎？敖幼而好游，至长不渝，周行四极，惟北阴之未闚，今卒观夫子于是，子殆可与敖为友乎？”若士者，啬然而笑，曰：“吾与汗漫期于九垓之外，吾不可以久驻。”若士举臂而竦身，辽入云中。高诱注；卢敖，燕人。秦始皇召以为博士，使求神仙，亡而不反。汗漫，不可知之也。九垓，九天之外。

# 下寻阳城，泛彭蠡，寄黄判官
题解：唐时浔阳郡，即江州也，隶江南西道。《元和郡县志》：彭蠡湖，在江州都昌县西六十里。按彭蠡湖，今江西之鄱阳湖是也。在南昌府城东北一百五十里，饶州府城西四十里，南康府城东五里，九江府城东南九十里，四州诸水皆入焉。周围四百五十里，春水涨时，茫无涯畔，足配洞庭。又北历星子、都昌、德化、湖口，注于大江。
诗：浪动灌婴井。/寻阳江上风。/开帆入天镜，/直向彭湖东。
注原：寻阳：一作“吾知”
注原：寻阳江上风：《元和郡县志》：江州城，古之湓口城也。汉高帝六年，灌婴所筑。建安中，孙权经此城，自标井地，令工掘之，正得古井。铭曰：“汉六年，颍阴侯开。卜云三百年当塞，塞后不满百年，当为应运者所开。”权以为已瑞。井极深，大江中风浪，井水辄自动。
注原：开帆入天镜：陆放翁《入蜀记》：泛彭蠡口，四望无际，乃知太白“开帆入天镜”之句为妙。
注原：彭湖：彭湖，即彭蠡湖也。
诗：落影转疏雨，/晴云散远空。/名山发佳兴，/清赏亦何穷。
注原：佳兴：三句一作“返影照疏雨，轻烟潜远空，中流得佳兴”
诗：石镜挂遥月，/香炉灭彩虹。/相思俱对此，/举目与君同。
注原：彩虹：一作“瀑布洒青壁，遥山挂彩虹”
注原：香炉灭彩虹：石镜、香炉，俱见上首注。

# 书情寄从弟邠州长史昭
题解：《唐书·地理志》：关内道邠州新平郡，义宁二年析北地郡之新平、三水置。邠故作“豳”，开元十三年以字类“幽”，改。长史，详见七卷注。
诗：自笑客行久，/我行定几时。/绿杨已可折，/攀取最长枝。
诗：翩翩弄春色，/延伫寄相思信。/谁言贵此物，/意愿重琼蕤。
注原：翩翩：一作“翻翻”
注原：延伫寄相思信：《楚辞》：结幽兰以延伫。延伫，长立也。
注原：意愿：一作“厚”
注原：意愿重琼蕤：陆机诗：玉颜侔琼蕤。张铣注：琼蕤，玉花也。
诗：昨梦见惠连，/朝吟谢公诗。/东风引碧草，/不觉生华池。
注原：朝吟谢公诗：锺嵘《诗品》：《谢氏家录》：康乐每对惠连，辄得佳语。后在永嘉西堂，思诗竟日不就。寤寐间，忽见惠连，即得“池塘生春草”，故常云此诗有神助，非吾语也。
注原：不觉生华池：《楚辞》：蛙黾游乎华池。王逸注：华池，芳华之池也。
诗：临玩忽云夕，/杜鹃夜鸣悲。/怀君芳岁歇，/庭树落红滋。
注原：杜鹃夜鸣悲：《埤雅》：杜鹃，一名子规，苦啼，啼血不止。一名怨鸟，夜啼达旦，血渍草木。凡鸣皆北向，啼苦则倒悬于树。《说文》所谓蜀王望帝化为子嵩，今谓之子规，是也。《华阳风俗录》：杜鹃大如鹊而羽鸟，声哀而吻有血，春至则鸣。《临海异物志》：杜鹃至三月鸣。书夜不止。
注原：芳岁：芳岁，犹芳春也。鲍照诗：泉涸甘井竭，节徙芳岁残。

# 寄王汉阳
题解：唐时江南西道有汉阳县，隶沔州汉阳郡。
诗：南湖秋月白，/王宰夜相邀。/锦帐郎官醉，/罗衣舞女娇。
注原：锦帐郎官醉：此诗是泛沔州城南郎官湖之后所作。王宰，谓汉阳令王公。郎官，谓尚书郎张谓。详见二十卷诗序。《后汉书》：郎官上应列宿，出宰百里。
注原：女娇：缪本作“骄”
诗：笛声諠、鄂，/歌曲上云霄。/别后空愁我，/相思一水遥。
注原：笛声諠、鄂：唐之沔州，即汉阳郡，今为汉阳府。唐之鄂州，印江夏郡，今为武昌府。二郡相对，中间隔江七里。

# 春日归山寄孟浩然
题解：缪本“孟八浩然”
题解：胡震亭曰：玩诗意，乃偕一显者游禅寺和诗，疑题有误。琦按：孟六浩然恐是孟赞府之讹。
诗：朱绂遗尘境，/青山谒梵筵。/金绳开觉路，/宝筏度迷川。
注原：朱绂遗尘境：朱线，详见十一卷注。
注原：青山谒梵筵：陈子昂诗：山水开精舍，琴歌列梵筵。
注原：金绳开觉路：《法华经》：国名离垢，琉璃为地，有八交道，黄金为绳，以界其侧。《法苑珠林》：涉迷津于曩识，微尘之数易穷；返觉路于初心，僧只之期难满。
注原：宝筏度迷川：《翻译名义》：《功德施论》云：如欲济川，先应取筏，至彼岸已，舍之而去。《韵会》：筏，《说文》：海中大船。《广韵》：大曰筏，小曰桴。《方言》：算谓之筏，编竹木浮河以运物，南土名算，北土名筏。
诗：岭树攒飞棋，/嵒花覆谷泉。/塔形标海日，/楼势出江烟。
注原：海日：萧本作“月”
诗：香气三天下，/钟声万壑连。/荷秋珠已满，/松密盖初圆。
注原：三天：三天，即三界也，谓欲界、色界、无色界。
注原：松密盖初圆：《玉策记》：千岁松，四边披起，上秒不长，望而视之，有如偃盖。
诗：鸟聚疑闻法，/龙参若护禅。/媿非流水韵，/叨人伯牙弦。
注原：鸟聚疑闻法：《法苑珠林》：舍衞国只树精舍，众集之时，弥猴、飞鸟，群类数千，悉来听法，寂寞无声。事竟即去，各还所止。犍椎适鸣，已复来集。
注原：叨人伯牙弦：《吕氏春秋》：伯牙鼓琴，锺子期听之。志在流水，锺子期曰：“善哉乎鼓琴，汤汤乎若流水。”骆宾王诗：“成风郢匠斲，流水伯牙弦。”
原：《瀛奎律髓》云：太白负不羁之才，乐府大篇，翕忽变化，而律诗工夫缜密如此，与杜审言、宋之问相伯仲。别有《赠浩然诗》曰：“醉月频中圣，迷花不事君。”虽飘逸，不如此诗之端整。

# 流夜郎，永华寺寄浔阳群官

注原：写意寄庐岳：湛方生诗：彭蠡纪三江，庐岳主众阜。

# 流夜郎，至西塞驿寄裴隐

# 泾溪南蓝山下有落星潭，可以卜筑，余泊舟石上，寄何判官昌浩
题解：《江南通志》：泾溪，在宁国府泾县西南一里，一名赏溪。其源有三，一出石埭县舒姑泉，一出太平黄山，一出绩溪。下有赏溪桥、沙堤。其西为新河。蓝山，在泾县西五十里，高千仞。李白诗“蓝岑耸天壁，突兀如鲸额”，即此。落星潭，在泾县西五十里蓝山下。晋有陈霸兄弟捕鱼于此，见一星落潭中，故名。

# 三山望金陵寄殷淑
题解：《太平寰宇记》：三山，在升州江宁县西南五十七里，周回四里。其山孤绝，面东西，绝大江。《舆地志》云：共山积石，滨于大江。有三峰，南北接，故曰三山。旧为吴津所。谢玄晖《晚登三山还望京邑》诗云：灞涣望长安，河阳视京县。白日丽飞甍，参差皆可见。余霞散成绮，澄江静如练。即此地也。
诗：三山怀谢朓，/水澹望长安。/芜没河阳县，/秋江正北看。
注原：水澹：一作“绿水”
诗：卢龙霜气冷，/鸡鹊月光塞。/耿耿忆琼树，/天涯寄一欢。
注原：卢龙霜气冷：《太平寰宇记》：卢龙山，在升州上元县西北二十里，周回五里，西临大江。按旧经，晋元帝初渡江，北地尽为虏寇所有。以其山连石头，为固关塞，以卢龙名焉。《六朝事迹》：卢龙山，图经云，在城西北十六里，周回五里，高三十六丈。东有水下注平陆，西临大江。旧经云，晋元帝初渡江，到此，见岭山连绵，接石头城，真江上之关塞，似北地卢龙，因以为名。《一统志》：狮子山，在应天府西二十里，与马鞍山接。晋元帝初渡江，见此山绵连，以拟北地卢龙山，故易名卢龙山。
注原：鸡鹊月光塞：鸟鹊，楼名，详见八卷《永王东巡歌》注。
注原：琼树：琼树，已见前二首注。

# 自金陵诉流过白壁山玩月，逢天门，寄句容王主簿
题解：《江南通志》：白壁山，在太平府城北三十里。有三峰，中峰最峻。赤壁在其北。《一统志》无白壁山，而有白壁水，盖字误也。《太平府志》：白壁山，一名石壁，在郡治北二十五里化洽乡。滨江三峰，中拔起如垩。有石似龟状，俗名龟山。传言上有白玉，采之者众，遂绝。李白与崔宗之乘舟，月夜自金陵诉流过白壁山玩月。白衣宫锦袍，坐舟中，两岸观者如堵，白笑傲自若，旁若无人。今按白诗“秋月照白壁，皓如山阴雪”十字，殆不可方，真兴会所到也。《一统志》：天门山，在太平府城西南三十里。二山夹大江，东曰博望，西曰梁山，对峙如门，亦名蛾眉山，又日东梁山、西梁山。《唐书·地理志》江南东道升州江宁郡有句容县。唐制，每县设主簿一人，九品官。京县则二人，八品官。
诗：沧江诉流归，/白壁见秋月。/秋月照白壁，/皓如山阴雪。
注原：沧江诉流归：《广韵》：诉，逆流而上也。
注原：皓如山阴雪：《世说》：王子猷居山阴，夜大雪，眠觉，开室命酌酒，四望皎然。
诗：幽人停宵征，/贾客忘早发。/进帆天门山，/回首牛渚没。
注原：幽人停宵征：《诗·国风》：肃肃宵征。
注原：回首牛渚没：《一统志》：牛渚山，在太平府城北二十五里，下有矶，曰牛渚矶，去采石矶近一里。旧为险要备御之地，亦名燃犀浦。
诗：川长信风来，/日出宿雾歇。/故人在咫尺，/新赏成胡、越。
注原：日出宿雾歇：鲍照诗：洲回风正悲，江寒雾未歇。陶弘景《答谢中书书》：晓雾将歇，猿鸟乱鸣。
注原：新赏成胡、越：胡地在北，越地在南，成胡、越，盖言共隔远而不能相见之意。《后汉纪》：形神不接，虽兄弟亲戚，可同之于吴、越。
诗：寄君青兰花，/惠好庶不绝。

# 寄上吴王三首
题解：按《唐书》：吴王只，太宗第三子吴王恪之孙，张掖郡王琨之子，袭封嗣吴王，出为东平太守。安禄山反，河南陈留、荣阳、灵昌相继陷，只募兵拒战，玄宗壮之。累迁陈留太守，持节河南道节度采访使，历太仆、宗正卿。其为庐江太守无考，盖史失载也。
诗：淮王爱八公，/携手绿云中。/小子忝枝叶，/亦攀丹桂丛。
注原：淮王爱八公：《神仙传》：淮南王刘安，好方术之士，于是有八公诣门，皆须眉皓白。门吏先密以白王，王使阍人自以意难问之，曰：“我王上欲求延年长生不老之道，今先生年已耆矣，似无驻衰之术。”八公笑曰：“闻王尊礼贤士，故远致其身，何以年老而逆见嫌耶？王必若见年少则谓之有道，皓首则谓之庸叟，薄吾老，今则少矣。”言未竟，八公皆变为童子，年可十四五，角髻青丝，色如桃花。门吏大惊，走以白王。王闻之，足不履，跣而迎，登思仙之台，执弟子之礼，北面叩首，八童子乃复为老人。后雷被、伍被诬告称安谋反，天子使宗正持节治之，八公曰：“可以去矣。”即白日升天。八公与安所踏山石皆陷成迹。
注原：小子忝枝叶：《左传》：公族，公室之枝叶也。杨齐贤曰：太白，兴圣皇帝九世孙，与唐同出，故云忝枝叶。
注原：亦攀丹桂丛：淮南王《招隐士》：攀援桂枝兮聊淹留。沈约诗：岸侧青莎被，岩间丹桂丛。《南方草木状》：桂有三种，叶如柏叶，皮赤者，为丹桂。叶似柿叶者，为菌桂。叶似枇杷叶者，为牡桂。
诗：谬以词赋重，/而将枚、马同。/何日背淮水，/东之观土风。
注原：何日背淮水：邹阳《谏吴王书》：臣所以历数王之朝，背淮千里而自致者，非恶臣国而乐吴民也。窃高下风之行，尤说大王之义。
