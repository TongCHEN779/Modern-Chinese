# 一
原：不违反众人之所信奉，
原：如是众人信奉了诗人为他们而创造的英雄。

# 二
原：普罗米修斯盗取了火，交给人间；
原：诗人盗取了那些使宙斯震怒的语言。

# 三
原：有英雄吗？
原：有的。
原：他们最坚决地以自己的命运给万人担戴痛苦；他们的灵魂代替万人受着整个世代所给予的绞刑。
原：却不是你们万人尸骨上的舞蹈者，不是戴着血腥的冠冕的刽子手，不是啊！

# 四
原：没有群众的英雄：
原：没有水的鱼，
原：没有泥土的树。

# 五
原：永远和人民群众在一起，了解他们灵魂的美，只有他们才能把世界从罪恶中拯救出来。
原：不要避开他们，即使他们要来驱赶你。
原：只有他们在这世界上是最可信赖的。

# 六
原：信任他们
原：信任一切为人类创造财富的人们，他们对世界怀有希望，对人怀有梦想。
原：他们说：我们是人类从今天到明天的桥梁；我们从现在带记忆给未来，又从未来带消息给现在；我们是人类的镜子，从我们，人类可以看见自己的悲哀；我们也是人类的鞭子，我们的存在，可以鞭策人类向辉煌的远方，美好的彼岸……

# 七
原：祝福你们——旧世界正直而不幸的；
原：坚强不屈而被砍倒者；
原：满怀悲愤而被禁锢者……

# 八
原：诗人啊
原：但愿那些你们为他们祈祷、为他们祝福的众人，不致向你们的身上投掷石块，这样就好了；
原：至于彼拉多的愤恨，祭司长和长老们的嫉妬，法利赛人的污蔑，那算得了什么呢？

# 九
原：我不知道人类能否有一天离开诗而生活……
原：这实在是不可想像的：人类会有一天失去了思想感情的最高的活动……匍匐着，匍匐着，将是怎样的一种鳄鱼啊。

# 十
原：假如人生仅是匆匆的过客，在世界上徬徨一些时日……
原：假如活着只求一身的温饱，和一些人打招呼、道安……
原：不曾领悟什么，也不曾启示过什么……
原：没有受人毁谤，也没有诋骂过人……
原：对所看见的、所听见的、所触到的，没有发表过一点意见……
原：临死了，对永不回来的世界，没有遗言……
原：能不感到空虚与悲哀吗？

# 十一
原：因旧世界充满欺诈、倾轧、迫害，而对它注目；
原：因生之历程是无限的颠簸与坎坷而爱生命。

# 十二
原：把我们放进人世的熔炉烧成赤红的溶液吧！
原：再取出，搁在铁砧上，用生活的千斤的重锤猛烈地抨打！我们的肉体是生铁，
原：痛苦呀，疾病呀，不自由的岁月呀，
原：不住地打击在我们的身上，
原：我们的诗，就是铁与铁的抨击
原：所发出的铿锵……

# 十三
原：他们能向世界要求什么呢——
原：旧世界的最主要的是发言的自由，——而这些常常得不到，因为任何暴君都知道：一个自由发言的，比一千个群众还可怕。

# 十四
原：一刻也不能丧失审视生活的勇气啊！
原：你看着世界，必须把世界映进你深不可测的瞳仁之底。

# 十五
原：我们既被社会指配为“诗人”，就象畜生之被我们指配为“牛”或“马”一样，该永无止息地为人类开垦智慧的处女地，劳役于艺术形象的生产。

# 十六
原：每个诗人有他自己的一个诗神
原：惠特曼和着他的诗神散步在工业的美利坚的民众里……
原：马雅可夫斯基和着他的诗神以口号与示威运动欢迎“十六年”的到来……
原：叶赛宁的诗神驾着雪橇追赶着镰刀形的月亮……
原：凡尔哈仑的诗神则徬徨在佛拉芒特的原野，又忙乱地出入于大都市的银行、交易所、商场，又在烦器的夜街上，象石块般滚过……

# 十七
原：膜拜“美”吗？
原：不。
原：“美”之不守贞操，比娼妇还不如。任何时代的生活的新的观念，都可把她奸淫；
原：而她永远盲目地领受赞叹，象那些最善于恋爱的女人，让男子们在她们的心上，弹出各种不同的曲调来……
原：而她竟以膜拜者为俘虏品……

# 十八
原：“生不用封万户侯，
原：但愿一识韩荆州。”
原：你们真是何等看重情操，当你们去追索那些可能给你们的生命以最崇高的喜悦的事物时，你们是从来也不会想起那事物本身的价值的。

# 十九
原：一切事物的价值，在诗人的国度里，是以他们能否提高人类的崇高的情操为标准的。

# 二十
原：“问客何为来？
原：采山因买斧。”
原：你们的语言真可怕，竟常常如此地因生活的美而成为永久。

# 二十一
原：诗人以形象使一切抽象的变成具体，
原：诗人是语言的艺术家，
原：诗人的财富是语言。

# 二十二
原：给一切以性格，
原：给一切以生命。

# 二十三
原：不是选民，是自选者；
原：没有从任何帝王领得采邑；
原：只为最大的意志而成为顺奴。

# 二十四
原：必须首先是自我的觉醒者，
原：才不致污渎了集团；
原：集团的终极目的不是取消意志，而是扩大意志至无限止。诗人应该是自我觉醒的先驱，
原：意志的无厌倦的歌手。

# 二十五
原：为全体而斗争；
原：个人只有不离叛全体时才发生了力量。

# 二十六
原：以热情点燃着生命；
原：生命借热情表现。

# 二十七
原：从生命感受了悲与喜、荣与辱，
原：以至诚的话语报答生命。

# 二十八
原：健康的灵魂不需遮蔽，
原：他们比肉体的祖露更美。

# 二十九
原：诗人的剑是语言
原：能遣使语言，才能和敌人争斗；
原：有了丰富的语言，才能战胜敌人。

# 三十
原：因为诗人最勇于发言，
原：他们常常成了自己所亲近的人群的代言人。

# 三十一
原：诗人不仅应该是社会的斗士，同时也必须是艺术的斗土
原：和恶俗斗争，和无意义的喧吵斗争，和同时代的坏的倾向、低级趣味、一切不健康的文字风格斗争……

# 三十二
原：诗人为什么常常瞧不起市侩呢？
原：因为市侩只能凭着现成的法则去衡量一切的事物，他们对于任何自己所不能理解的说：“这要不得。”他们贫困于想象，他们永远是知识的守财奴，他们看百科全书超过一切；他们由于吝啬，而能温饱自得；
原：他们不知道，一切知识在没有被公众承认之前，都被看作异端邪说，一样有市侩在说：“这要不得。”

# 三十三
原：终日沉默，为了猎获那些偶然在脑际闪过的句子与形象；
原：接着，须通过编辑老爷与检查官的眼睛；
原：而火、霉雨与批评家都在等着你们的本子的出现……
原：而时间又成了你们最可怕的敌人……

# 三十四
原：诗人应该是典型事物之敏锐的直观者。

# 三十五
原：服从历史的法则，服从自然的法则，因此拂逆了不合理的制度与时间以及地点的制限。

# 三十六
原：最高的理智的结果，使诗人们爱上了自然与坦白。

# 三十七
原：天才不是精神的贵族，
原：天才只是特定环境里成功了的人。

# 三十八
原：不求为自己所蔑视的人们的谅解；愿在犯罪的旧世界做一个诋毁这世界的罪犯。

# 三十九
原：为了努力使艺术与生活之间取得统一与调和，诗人们常把自己搁置在现实与理想之间，象顺水的船与那反逆的风所作的抗御一样，使自己的生命在不安定与颠簸中前进……

# 四十
原：不是宣教者，诗人的神不是任何统治者利用来迷惑人的偶像；
原：自然既是永不停止它的变化，诗人即不再有固定的神了。

# 四十一
原：为什么你们永远不安？
原：风、雨永在摇撼你们；
原：太阳、月光和星，循环地
原：在你们的心中徬徨；
原：一种比什么都更强烈的爱情，
原：在你们的胸中汹涌；
原：而那像黑夜一样深的仇恨，
原：又像流水似的回旋在你们的血管里，
原：因此，你们的声音
原：永远带着可怕的震颤……

# 四十二
原：只有在诗人的世界里，自然与生命有了契合，旷野与山岳能日夜喧谈，岩石能沉思，河流能絮语……
原：风，土地，树木，都有了性格。

# 四十三
原：好像你们所负的债很重，你们老是终日惶惶，不安于享受一粟半缕的人群的恩赐，羞愧于在劳力者以血汗铺成的道上散步。你们的存在，比影子更萎缩，比落叶更不敢惊动人；而你们的话语终于如此凄惶，使一切天良未泯者闻之坠泪……

# 四十四
原：以自己的两颊之晕红与丰盈，交给了深思与哀感，为了揭示众生之苦恼
原：换得了执鞭者的嫌忌，持有刀枪者的愤恨，彼拉多的喝叱，法利赛人的咒诅——甚至说：把他钉死——
原：还有，两颊苍黄、瘦削、衰弱，两只宁静的眼睛，凝视着世界，昼与夜，生长与死灭，繁华与凋零……而有所激奋，有所感受，有所发言的

# 四十五
原：他们常常鄙视人所珍贵、珍视人所唾弃，向君王怒视，又向行乞者致礼……
原：我相信他们可能奉灵感为至圣，以露水与花瓣为餐，以草叶为衣冠；
原：他们行吟；他们永远地流浪……

# 四十六
原：他们以世界为客栈，
原：以生命为旅行，
原：痛苦、烦恼、欢乐，像日、月、星辰在他们的头顶迎送着他们……

# 四十七
原：他们使年老的都要叹息，少女都要垂颈；一切接触到他们的声音的人，为他们而不得宁静……

# 四十八
原：如不曾把你们灵魂的门禁闭，
原：如不曾以偏见守卫你们的心，
原：如你们还保留着一丝婴孩的天真，
原：愿你们能接受一种语言，
原：它的来访如久别的挚友，絮述真诚，
原：它别无用心，只愿你们不在利欲之榻上睡眠，
原：它也别无礼物，只愿你们的灵魂常常清醒……

# 四十九
原：他们的话，比黄昏时情人所说的更温柔，比孩子所说的更天真，比农夫所说的更纯朴……
原：却又恳切如老人的劝告，善良如母亲的责备，深沉如智者的启示……

# 五十
原：在生命所交给他的日子当中，他们惊愕于每个日子的新的发现；他们专劳于探索形象的语言；他们猎取人世与自然林中的隐藏；他们天真如小孩，在智慧的沙滩上，捡取螺贝……

# 五十一
原：人类可骄傲的是：它能以不断的创造来辉煌自己的历史；它能把谷粒所维系的生命，升华出不断地提高自己的理想的文化
原：“科学——理智的诗，艺术——情感的诗。”

# 五十二
原：使人类有别于其它一切动物的是：
原：人类能知道自己是怎样生活过来的，正在怎样生活着，将要怎样生活下去……
原：而使人类能具体地看到自己的生活的是艺术——音乐、雕塑、绘画、诗篇。

# 五十三
原：给思想以翅膀，
原：给情感以衣裳，
原：给声音以彩色，给颜色以声音；
原：使流逝幻变者凝形，
原：顽木者有梦，
原：屈服者反抗，
原：咽泣者含笑，
原：绝望的重新有了理想……

# 五十四
原：更富有狂热，更善于冷静，憎恨得更深，爱得更固执……具有感情之最宽伸缩度，而非优伶。

# 五十五
原：灵魂之最倔强者—
原：不控诉向自己的心以外的，
原：不求宽恕向自己的心以外的，
原：不因困厄而向同情伸手，
原：在一切的逆境到来时高歌……

# 五十六
原：如果说“冬天既到，春天还会远吗？”是预言，诗人的预言是最天真的—
原：说要来的必然要来；
原：不隐瞒陈腐之将死亡；
原：夜的尽头是黎明；
原：如地球不停止旋转，世界不会永远黑暗。

# 五十七
原：啊，要是你们能听见深夜还有哭声；
原：看见垃圾桶边还有若干探索的眼；
原：年轻人的尸体还暴露在道旁……
原：你们的呼吸能不感到困苦吗？
原：你们的嘴还能缄默吗？

# 五十八
原：但愿爱人散步的道上不会躺着饿殍，
原：但愿账簿和算盘都将放在博物馆，
原：但愿监狱都将改成动物园，
原：但愿勤劳的都将得到幸福，
原：但愿人民是国家真正的主人……

# 五十九
原：如果未来有那么一天——
原：统治者把镣铐铸成花瓶，
原：立法者与乞丐散步谈天，
原：流浪者找到了家，妓女有了丈夫，
原：军火商不再鼓动战争，
原：棺材店老板不希望瘟疫流行，
原：一切都言归于好—
原：自由、艺术、爱情、劳动，
原：每个都是诗人。
原：一九三九年冬完稿
