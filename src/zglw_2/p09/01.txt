# 诗式（选录）
题解：〔唐〕皎然
题解：唐人诗歌理论，主要有两派：其一重视诗歌的现实内容与社会意义，由陈子昂发展到白居易、元稹，一直到皮日休；其一则比较重于诗歌艺术，发挥了较多的创见，并且写成了专书，由皎然的《诗式》，发展到司空图的《二十四诗品》。
题解：诗式，即是诗的法则。全书标举论诗宗旨，也品评了具体作品。品评的等第，即以书中所标举的五种诗格做准则。精华部分，在于理论，它接触到诗歌的风格、意境、内容形式的关系、复古与通变等问题。
题解：《诗式》在诗歌原则上，确认了诗的崇高地位，以为“夫诗者众妙之华实，六经之菁英”，因此，他又提出了诗体论与诗德论，以见诗道之所以可尊。诗体有十九字，其中有属于思想内容的贞、忠、节、志、德、诫、悲、怨、意，所以为“六经之菁英”；有属于艺术风格的高、逸、气、情、思、闲、达、力、静、远，所以为“众妙之华实”。认为这样是“风律外彰，体德内蕴”，“其一十九字，括文章德体风味尽矣。”所谓诗德，即是诗的准则。七德之中，高古、典丽、风流、精神，也都属于风格的范畴。艺术上达到了这样的境地，才算是“高手述作”，“造其极妙”，“虽非圣功，妙均于圣”。为了阐明“众妙”之所以为妙，于是在“四不”“四深““二要”“二废”“四离”“六至”等口诀中，对各个艺术问题，作了阐说，把露、疎、苦涩、怒张、迂远、轻浮、虚诞、缓漫、诡怪、僻、弱等等扩斥于艺术美的领域之外。而皎然所特别强调的最高艺术标准，则是要做到“真于情性，尙于作用，不顾词彩，而风流自然”，“但见情性，不覩文字”，才真是“发皆造极”，“诗道之极”。后来司空图所谓“不着一字，尽得风流”，严羽所谓“羚羊挂角，无迹可求”，与皎然的说法有一定的联系。
题解：要达到如上的诗歌艺术标准，《诗式》提出了取境问题。皎然在《秋日遥和卢使君游何山寺宿敭上人房论涅槃经义》一诗中曾说过：“诗情缘境发。”他把诗歌的基本因素情和境有机地统一了起来。皎然所说的境，即后人所谓意境。他以为“诗人之思初发，取境偏高，则一首举体便高；取境偏逸，则一首举体便逸。”又以为“静，非如松风不动，林狖未鸣，乃谓意中之静。远，非如渺渺望水，杳杳看山，乃谓意中之远。”这样阐说意境，在古典诗论中，可说是一个开端，最后发展为王国维《人间词话》的境界说。诗中的意境既不等同於单纯属于客观世界的境，因此，要“气象氤氲”，“意度盘礴”。诗中的意必须通过“象”来表现，所以要“假象见意”，要“采奇于象外”（见附录《评论》），“情在言外”，“旨冥句中”。象、言、句、文，只是用以显示奇、情、旨的形迹。情文并茂，意境双融，才是诗家的极诣。与意境相联系，皎然解释比兴，也赋予它以新的含义。他以为“取象曰比，取义曰兴。义即象下之意。凡禽鱼草木人物名数万象之中义类同者，尽入比兴。”所以他所说比兴，实际是属于意境的范畴。有比兴即是有象外之奇，文外之旨，言外之情，以此区别於单纯取象作比喻而不能融境于情的属于修辞范畴的比。陶潜《咏贫士》诗的取兴于孤云，正是融境入情的例子。江淹《咏扇》诗的取象于秦女乘鸾（见附录《诗式：团扇二篇》），也正是“兴生于中，无有古事”的说明。这在一定程度上已接触到诗歌创作运用形象思维的问题，有一定的合理因素。
题解：由取境而进一步说到如何取境，皎然主张要站得高，看得远，“如登衡、巫，觌三湘、鄢、郢山川之盛”；要“绎虑于险中”（见附录《评论》），“不入虎穴，焉得虎子”，“放意须险，定句须难，虽取由我衷，而得若神表”。他特别强调了诗人神思的作用，却并不认为这种神思是神秘的，他说到：“有时意静神王，佳句纵横，若不可遏，宛若神助。”接着又说：“不然，盖由先积精思，因神王而得乎？”“神思”是长期思想酝酿的结果，因精神状态高昂而激发，并不是无所依傍的灵感。
题解：有关诗歌创作问题，皎然所论，虽注意到内容，但也重视形式。他以为“无盐阙容而有德，曷若文王太姒有容而有德”。反对“酷裁八病，碎用四声”的偏尚形式，但在重内容的前提下，又以为“韵合情高，此未损文格”，“作者措意，虽有声律，不妨作用”，“用律不滞，由深于声类”。主张“不用事第一”，又以为“用事不直，由深于义类”。并且说“虽欲废巧尚直，而思致不得置；虽欲废言尚意，而典丽不得遗”。而《诗式》一书，较多论述的还是在艺术方面。
题解：在继承与创新的问题上，皎然强调的是“变”。他以为“反古曰复，不滞曰变。若惟复不变，则陷于相似之格。”“后辈若乏天机，强效复古，反令思扰神沮”。因此，他主张自立新意，“无有依傍”，要复古而能“通于变”。这些见解，也有可取之处。但同时也应指出，他更多的是从诗歌形式的发展角度看问题，肯定了“沈、宋复少而变多”，批评了“陈子昂复多而变少”，忽视了诗歌社会内容的重要，因而又是片面的。而在写诗技巧方面，他又嘲讽了诗家的“三同”，对“偷语”“偷意”，绝不容恕，只有“才巧意精，若无朕迹”的“偷势”，才是“诗人偷狐白裘于阃域中之手”。
题解：《诗式》文字简约，其精蕴往往含而未申，有待于后人的探索。这一类型的诗论，有所谓李峤的《评诗格》，王昌龄的《诗格》，白居易的《金针诗格》，齐已的《风骚旨格》等等，大都出于宋以后人伪托，不能与《诗式》相提并论。
原：夫诗者，众妙之华实，六经之菁英，虽非圣功，妙均于圣。彼天地日月，玄（《诗学指南》本作光）化之渊奥，鬼神之微冥，精思一搜，万象不能藏（《诗学指南》本作职）其巧。其作用也，放意须险，定句须难，虽取由我衷，而得若神表。至如天真挺拔之句，与造化争衡，可以意冥，难以言状，非作者不能知也。洎西汉以来，文体四变。将恐风雅寖泯，辄欲商较以正其源。今从两（《诗学指南》本作西）汉已降，至于我唐，名篇丽句，凡若干人，命曰《诗式》，使无天机者坐致天机。若君子见之（原注：一作知），庶有益于诗数矣。
注：诗式：唐人皎然所作的诗论，有五卷本与一卷本。《唐宋丛书》《学海类编》《历代诗话》所收，都只有一卷，至“辨体有一十九字”而止，“中序”以后缺。惟清末陆心源《十万卷楼丛书》所收，为五卷足本。（《诗学指南》所收，与一卷本、五卷本又互有详略，次第亦不同，有若干条列于《评论》中。）第一卷总论诗歌原理及五格中的第一格；第二卷至末卷，分别论五格中的第二格至第五格，各摘录两汉至中唐诗人名篇丽句为例。书中内容，偶有与他书相雷同处，如三偷亦见于托名唐人李淑的《诗苑类格》，故或有疑其为后人所依托。然《新唐书·艺文志》郎已著录为画公所撰，《直斋书录解题》《诗人玉屑》《唐诗纪事》亦皆认为皎然作。
注：皎然：中唐时代诗僧，本名谢清画，又称画，谢灵运十世孙，湖州长城人。生卒年不详。主要活动于大历、贞元时代。童年即随法侣，一生居吴兴东溪草堂，与当时士大夫如颜真卿、韦应物、李阳冰、顾况等互相唱和，时号“江东名僧”。贞元中，湖州刺史于颙编其诗文为《杼山集》，并为之序。临诗著作，于《诗式》外，又有《诗议》《评论》等。辛文房《唐才子传》载其事。
注：其作用：作用指艺术构思。
注：可以意冥：意冥冥谓契合于无形。
注：文体四变：文体，指诗体。按照《诗式》所论，似以苏、李的自然天成，《十九首》的始见作用，魏、晋、六朝的雕绘偶俪，唐人的律诗为四变。

# 明势
原：高手述作，如登衡（《诗学指南》《历代诗话》本俱作荆）、巫，觌三湘、鄢、郢山川（《历代诗话》本无山川二字）之盛，萦回盘礴，千变万态（文体开阖作用之势）：或极天高峙，崒焉不群，气腾势飞，合沓相属（奇势在工）；或修江耿耿，万里无波，欻（原作淡，据《历代诗话》本改）出高深重复之状（奇势牙发）；古今逸格，皆造其极妙（《历代诗话》本无妙字）矣。
注：巫：衡巫—衡山，五岳中的南岳，在湖南。巫山，在四川、湖北两省边境。
注：郢：三湘湘水发源与滩水合流后称滩湘，中游与潇水合流后称潇湘，下游与蒸水合流后称蒸湘，总称三湘。一般用以泛指湖南全省。鄢郢—都是春秋时楚国都名。鄢，在今湖北省宜城县。郢，在今湖北省江陵县。
注：或修江：修江一长江。

# 明作用
原：作者措（《诗学指南》本作旨）意，虽有声律，不妨作用。如壶公瓢中，自有天地日月，时时抛铁掷线，似断而复续。此为诗中之仙，拘忌之徒，非所（原作可，据《诗学指南》本改）企及矣。
注：壶公：《后汉书·方术传》载：汝南市中有老翁宝药，悬一壶于肆，市罢则跳入壶中。又《云笈七签》载，施存为云台治官，夜宿壶中，壶中自有日月。自号壶天，人号为壶公。

# 明四声
原：乐章有宫商五音之说，不闻四声。近自周颙、刘绘流出，宫商畅于诗体，轻重低昂之节，韵合情高，此（原衍之字，据《历代诗话》本删）未损文格。沈休文酷裁八病，碎用四声，故风雅殆尽。后之才子，天机不高，为沈生弊法所媚；懵然随流，溺而不返。
注：乐章有宫商五音：宫商五音一宫、商、角、徽、羽为五音。
注原：刘绘：周顺刘绘一—周颙（公元？—四八五年），字彦伦，汝南安城人。与沈约都是四声说的创始人，参看本书第一册《诗品序》注[136]。《南齐书》卷四十一有传。刘绘（公元四五八年——五○二年），字士章，彭城人。《南齐书》卷四十入有传称：“永明（南齐武帝年号，公元四八三年到四九三年）末，京邑人士盛为文章谈义，皆凑竟陵王西邸。绘为后进领袖，机悟多能。时张融、周顺并有言工，融音旨缓韵，顺辞致绮捷，绘之言吐，又顿挫有风气。”
注：轻重低昂之节：轻是清音，即平声；重是浊音，即仄声。
注：八病：见本书第一册《宋书·谢灵运传验》附录。
注：媚：惑。

# 诗有四不
原：气高而不怒，怒则失于风流；力劲而不露，露则伤于斤斧；情多而不暗，暗则陟（原作伤，据《诗学指南》本改）于拙钝；才胆而不疎，疎则损于筋脉。

# 诗有四深
原：气象氤氲，由深于体势；意度盘礴，由深于作用；用律不滞，由深于声对；用事不直，由深于义类。
注：声对：声律对偶。
注：义类：事义与事类，见本书第一册《文心雕龙·知音》注[44]。

# 诗有二要
原：要力全而不苦涩，要气足而不怒张。

# 诗有二废
诗：虽欲废巧尚直，/而思致不得置；/虽欲废言（《历代诗话》本作词）尚意，/而典丽不得遗。

# 诗有四离
诗：虽有（《诗学指南》本作欲，《历代诗话》本作期）道情，/而离深僻；/虽用（《诗学指南》本作欲）经史，/而离书生；
诗：虽尚（《诗学指南》本作欲）高逸，/而离迂远；/虽欲飞动，/而离轻浮。

# 诗有六迷
原：以虚诞而为高古，以缓慢而为澹宁，（慢，原作缦，据《诗学指南》本改。《历代诗话》本此句作“以缓漫而为冲澹”。）以错用意而为独善，以诡怪而为新奇，以烂熟而为稳约，以气少力弱而为容易。

# 诗有六（《诗学指南》本作七）至
原：至险而不僻，至奇而不差，至丽而自然，至苦而无迹，至近而意远，至放而不迂。（《诗学指南》本此句下有“至难而状易”句。）

# 诗有七德（原注：一作得）
原：一、识理，二、高古，三、典丽，四、风流，五、精神，六、质干，七、体裁。

# 诗有五格
原：不用事第一，作用事第二，（其有不用事而措意不高者，黜入第二格。）直用事第三，（其中亦有不用事而格稍下，贬居第三。）有事无事第四，（比于第三格中稍下，故入第四。）有事无事情格俱下第五。（情若俱下〔《历代诗话》本下字下有“有事无事”四字]可知也。）

# 文章宗旨
原：评曰：康乐公早岁能文，性颖神澈（原作彻，据《历代诗话》本改），及通内典，心地更精，故所作诗，发皆造极，得非空王之道助邪？夫文章天下之公器，安敢私焉。彞者尝与诸公论康乐为文，真于情性，尚于作用，不顾词彩，而风流自然。彼清景当中，天地秋色，诗之量也；庆云从风，舒卷万状，诗之变也。不然，何以得其格高，其气正，其体贞，其貌古，其词深，其才婉，其德宏，其调逸，其声谐哉（原无哉字，据《历代诗话》本补）？至如《述祖德》一章、《拟邺中》八首、《经庐陵王墓》、《临池上楼》，识度高明，盖诗中之日月也，安可攀援哉！惠休所评，谢诗如芙蓉出水，斯言颇近矣，故能上蹑风骚，下超魏、晋，建安制作，其椎轮乎？
注：康乐公：谢灵运，谢玄之孙，晋时袭封康乐公。灵运通佛学，主顿悟，曾整理《大般涅槃经》为南本。故下文云“及通内典，心地更精”。
注原：空王：佛。道助——《摩诃般若波罗蜜经》：“三十七助道法，是菩萨摩诃萨道。”这里是说谢灵运诗的高超成就，是由于得到佛学之助。
注：惠休所评：钟嵘《诗品》：“汤惠休曰：谢诗如芙蓉出水，颜（延之）如错采镶金。'颜终身病之。”
注：椎轮：见本书第一册《文选序》及其注[4]。

# 用事
原：评曰：诗人皆以征古为用事，不必尽然也。今且于六义之中，略论比兴。取象曰比，取义曰兴，义即象下之意。凡禽鱼草木人物名数，万象之中义类同者，尽入比兴，《关雎》即其义也。如陶公以孤云比贫士，鲍照（原作昭，据《历代诗话》本改）以直比朱纹，以清比冰壶。时人呼比为用事，祀（疑字误，《历代诗话》本作呼，亦非）用事为比。如陆机《齐讴行》（此三字原无，只作诗，据《历代诗话》本改）：“鄙哉牛山叹，未及至人情，爽鸠苟已徂，吾子安得停！”此规谏之中（原作忠，据《诗学指南》本改），是比非用事（原作是用事非比，据《诗学指南》本改）也。如康乐公《还旧园作》（此四字原无，只作诗，据《历代诗话》本改）：“偶与张邴合，久欲归东山。”此敍志之中（原作忠，据《诗学指南》本改），是比非用事也。详味（原无此二字，据《历代诗话》本补）可知。
注：六义：见《毛诗序》。
注：陶公以孤云比贫士：〕陶公句——陶潜《咏贫士》诗首四句：“万族各有托，孤云独无依；暖暖空中灭，何时见余晖。”无依无靠的孤云，在天空中暗然消散，什么时候也看不见它的光辉。在这孤云的形象中，雕然有陶潜自己的身影在内。这里出现的是人与物统一的完整的艺术境界，不单纯是把孤云作比喻。

# 重意诗例
原：评曰：两重意已上，皆文外之旨。若遇高手如康乐公，览而察之，但见情性，不覩文字，盖诗（原作诣，据《诗学指南》本改）道之极也。向使此道尊之于儒，则冠六经之首；贵之于道，则居众妙之门；崇之于释，则彻空王之奥；但恐徒挥其斤而无其质，故伯牙所以叹息也。畴昔国朝协律郎吴兢，与越僧玄监集秀句，二子天机素少，选又不精，多采浮浅之言，以诱蒙俗，特入瞽夫偷语之便，何异借贼兵而资盗粮，无益于诗教矣。
注原：故伯牙所以叹息也：伯牙句——伯牙叹息钟子期死后无知音，见本书第一册《文心雕龙·知音》住[52]。[85]畴昔国朝协律耶吴兢二句——唐人吴兢选《古今诗人秀句》，其书已佚，存序文于《文镜秘府论》南卷中，见本书第一册《诗品序》附录。序中未提到与越僧玄监集秀句事，皎然当有所本，今不详。[86]借贼兵而资盗粮——《史记·范睢蔡泽传》：“故齐所以大破者，以其伐楚而肥韩魏也。此所谓借贼兵而斋盗粮者也。”[87]如车之有谷——《老子》：“三十辐，共一谷。”毅是车轮中心的圆木，周国与车辐（车轮上一条一条的直木）的一端相接，中有圆孔，用以插轴。[88] 如易之有彖辞为——象辞，郎《易》卦下的卦辞，传说为局文王所作，总论这一卦的主要意义。如“干”卦下面的“元、亨、利、贞”四字就是。[39]造父——人名，周穗王时人，替御。见《史记·赵世家》。。[40]宋人二句——《战国策·秦策》：“郑人谓玉未理者璞，周人谓鼠未腊者朴。周人怀朴[璞]过郑贾曰：‘欲买朴乎？’郑贾曰：‘欲之。’出其朴。视之，乃鼠也，因谢不取。”按：疑本文“宋”字为“郑”字之讹。一说，古代常以宋人指愚人，这里的宋人也即愚人的意思。嘘啦，即卢胡，喉间的笑声。《后汉书·应劭传》：“宋愚夫亦宝燕石，霜缇十重，夫覩之者掩口卢胡而笑。”[41]膏肓之疾——《左传》成公十年：“疾不可为也，在宵之上，膏之下，攻之不可，达之不及，药不至焉，不可为也。”膏，心尖脂肪或心下面的部位，育，心脏和隔膜之间。膏肓之疾，谓不可医治的病。[42]顿教——佛家分顿、渐二教，以速疾证悟真理者为顿教。[43]陈于昂复多而变少——谓陈子昂五言古诗，复阮籍《咏仪》之古，在诗歌形式方面，未能创新写律体诗。《诗式》卷三《论卢藏用陈子昂集序》有云：“子昂《感寓》（按：当作遇）三十首，出自阮（原作此，误）公《咏怀》。《咏怀》之作，难以为传。子昂诗日：‘荒哉穆天子，好与白云期。宫女多怨旷，历城（在昆仑）蔽蛾眉。曷若阮公三楚（南楚、东楚、西楚）多秀士，朝云（宋玉《高唐赋》载巫山神女自云“妾旦为朝云”）进荒淫。朱华振芬芳，高蔡（楚地名。蔡圣侯在此行猎，不顾国事。见《战国策》）相追寻。一为黄雀哀（黄雀栖茂树，不知人挟弹在后弹之。见《战国策》），涕下谁能禁。”可与此语相发明。[44]沈未复少而变多——沈佺期、宋之间多写律诗，在唐代五律与七律诗的形成上，有一定功绩，故云。[45]方便——《维摩诘所说经》：“以无量方便，饶益众生。”方便，佛家语，犹云权宜。[46]弹抚干将太阿之缺—弹，击。干将，春秋时吴人，与其妻莫邪所铸之剑，即名干将、莫邪。太阿，吴瞰冶子、干将所铸剑名。铗，剑把，手所把持处。[47]伤手之患——《老子》：“夫代大匠断者，希有不伤其手矣。”

# 复古通变体所谓通于变也
原：评曰：作者须知复变之道，反古曰复，不滞曰变。若惟复不变，则陷于相似之格，其状如驽骥同廐，非造父不能辨，能知复变之手，亦诗人之造父也。以此相似一类，置于古集之中，能使弱手视之眩目，何异宋人（疑夺以字）死鼠为玉璞，岂知周客嘘嘲而笑哉！又复变二门，复忌太过，诗人呼为膏肓之疾，安可治也。如释氏顿数学者，有沈性之失，殊不知性起之法，万象皆真。夫变若造微，不忌太过，苟不失正，亦何咎哉！如陈子昂复多而变少，沈、宋复少而变多。今代作者不能尽举，吾始知复变之道，岂惟文章乎？在儒为权，在文为变，在道为方便。后辈若乏天机，强效复古，反令思扰神沮。何则？夫不工剑术，而欲弹抚干将太阿之铗，必有伤手之患，宜其诫之哉！

# 团扇二篇
原：评曰：江则假象见意，班则貌题直书。至如“出入君怀袖，摇动微风发，常恐秋节至，凉夺炎热。”旨婉词正，有洁妇之节，但此两对，亦足以揜映。江生诗曰：“画作秦王女，乘鸾向烟雾。”兴生于中，无有古事。假使佳人玩之在手，乘鸾之意，飘然莫偕。虽荡如夏姬，自忘情改节。吾许江生情远辞丽，方之班女，亦未可减价。

# 王仲宣七哀

# 池塘生春草明月照积雪
原：评曰：客有问予：谢公二句优劣奚若？予因引梁征远将军评为隐秀之语。且钟生非诗人，安可辄议，徒欲聋瞽后来耳目。且如“池塘生春草”，情在言外，“明月照积雪”，旨冥句中，风力虽齐，取兴各别。古今诗中，或一句见意，或多句显情。王昌龄云：日出而作，日入而息，谓一句见意为上。事殊不尔。夫诗人作用，势有通塞，意有盘礴。势有通塞者，谓一篇之中，后势特起，前势似断，如惊鸿背飞，却顾俦侣，即曹植诗云“浮沉各异势，会合何时谐？愿因（原注：一作为）西南风，长逝入君怀”是也。意有盘礴者，谓一篇之中，虽词归一旨，而兴乃多端，用识与才，蹂践理窟，如卞子探玉，徘徊荆岑，恐有遗璞。其有二义，一情一事。事者，如刘越石诗曰“邓生何感激，千里来相求，白登幸曲逆，鸿门赖留侯，重耳用五贤，小白相射钩，苟能隆二伯，安问党与雠”是也。情者，如康乐公“池塘生春草”是也。抑由情在言外，故其辞似淡而无味，常手览之，何异文侯听古乐哉！谢氏传》曰：吾尝在永嘉西堂作诗，梦见惠连，因得“池塘生春草”，岂非神助乎！
原：（以上卷二）

# 齐梁诗
原：评曰：夫五言之道，惟工惟精。论者虽欲降杀齐、梁，未知其旨。若据时代，道丧几之矣。沈约诗（疑当作说）诗，人不用此论，何也。如谢吏部诗：“大江流日夜，客心悲未央。”柳文畅诗：“太液沧波起，长杨高树秋。”王元长诗：“霜气下孟津，秋风度函谷。”亦何减于建安。若建安不用事，齐梁用事，以定优劣，亦请论之。如王筠诗：“王生临广陌，潘子赴（原注：一作赋）黄河。”庾肩吾诗：“秦王观大海，魏帝逐飘风。”沈约诗：“高楼切思妇，西园游上才。”格虽弱，气犹正。远比建安，可言体变，不可言道丧。大历中，词人多在江外，皇甫冉、严维、张继素、刘长卿、李嘉祐、朱放，窃占青山白云、春风芳草，以为已有。吾知诗道初丧，正在于此，何得推过齐、梁作者。迄今余波尙寖，后生相效，没溺者多。大历末年，诸公改辙，盖知前非也。……

# 诗议（选录）
题解：〔唐〕皎然
原：……夫境象非一，虚实难明。有可覩而不可取，景也；可闻而不可见，风也。虽系乎我形，而妙用无体，心也；义贯众象，而无定质，色也。凡此等，可以偶虚，亦可以偶实。

# 评论（选录）
题解：〔唐〕皎然
原：或曰：今人所以不及古者，病于丽词。予曰：不然。先正诗人，时有丽词。“云从龙，风从虎”，非丽邪？“昔我往矣，杨柳依依；今我来思，雨雪霏罪”，非丽邪？但古人后于语，先于意。
原：或曰：诗不要苦思，苦思则丧于天真。此甚不然。固当绎虑于险中，采奇于象外，状飞动之趣，写真奥之思。夫希世之珍，必出骊龙之颔，况通幽名变之文哉！

# 诗格（选录）
题解：〔唐〕王昌龄
原：诗有三境：一曰物境。欲为山水诗，则张泉石云峰之境，极丽绝秀者，神之于心，处身于境，视境于心，莹然掌中，然后用思，了然境象，故得形似。二曰情境。娱乐愁怨，皆张于意而处于身，然后驰思，深得其情。三曰意境。亦张之于意而思之于心，则得其真矣。
诗：诗有三格：一曰生思。/久用精思，/未契意象，/力疲智竭，
诗：放安神思，/心偶照境，/率然而生。/二曰感思。
诗：寻味前言，/吟讽古制，/感而生思。/三曰取思。
诗：搜求于象，/心入于境，/神会于物，/因心而得。

# 送灵澈上人庐山回归沃洲序
题解：〔唐〕权德舆
原：昔庐山远公、钟山约公皆以文章广心地，用赞后学，俾学者乘理以诣，因言而悟，得非元津之一派乎？吴兴长老画公（按：即皎然）掇六义之清英，首冠方外，入其室者，有沃洲灵澈上人。上人心冥空无而迹寄文字，故语甚夷易，如不出常境，而诸生思虑，终不可至。其变也，如松风相韵，冰玉相叩，层峰千仞，下有金碧，耸鄙夫之目，初不敢胝。三复则淡然天和，晦于其中，故睹其容览其词者，知其心不待境静而静。况会稽山水，自古绝胜，东晋逸民多遗身世于此。夏五月，上人自𬬻峰言旋，复于是邦。予知夫拂方袍，坐轻舟，溯沿镜中，静得佳句，然后深入空寂，万虑洗然，则向之境物，又其梯稗也。鄙人方景慕企尙之不暇，焉敢以离群为叹。

# 董氏武陵集纪（节录）
题解：〔唐〕刘禹锡
原：片言可以明百意，坐驰可以役万景，工于诗者能之；风雅体变而兴同，古今调殊而理异（原作冥，据上海人民出版社《刘禹锡集》校改），达于诗者能之。工生于才，达生于明，二者还相为用，而后诗道备矣。……一且得董生之词，杳如搏翠，屏浮层澜，视听所遇，非风尘间物。亦犹明金綷羽，得于遐裔，虽欲勿宝，可乎？生名侹，字庶中，幼恃属诗者，晚而不衰。心源为𬬻，笔端为炭，锻炼元本，雕砻群形，纠纷舛错，逐意犇走，因故沿浊协为新声。……余不得让而著于篇，因系之曰：诗者其文章之蕴邪？义得而言丧，故微而难能，境生于象外，故精而寡和。千里之缪不容秋毫，非有的然之姿可使户晓，必俟知者然后鼓行于时。自建安距永明已还，词人比肩，唱和相发。有以朔风零雨高视天下，蝉噪鸟鸣蔚在史策，国朝因之，粲然复兴。

# 澈上人文集纪（节录）
题解：〔唐〕刘禹锡
原：初上人在吴兴，居何山，与画公为侣（皎然字画，时以字行）。时予方以两髦执笔砚，陪其吟咏，皆曰孺子可教。后相遇于京洛，与友许之契焉。上人殁后十七年，予为吴都，其门人秀峰捧先师之文来乞词以志，且曰：“师尝在吴，赋诗仅二千首。今删取百篇，勒为十卷，自大历至元和凡五十年间，接词客闻人训唱别为十卷。今也思行乎昭世，求一言羽翼之。”因为评曰：世之言诗僧多出江左，灵一导其源，护国袭之；清江扬其波，法振沿之。如玄弦孤韵瞥入人耳，非大乐之音。独吴兴画公能备众体，昼公后，澈公承之。至如《芙蓉园新寺诗》云：“经来白马寺，僧到赤乌年。”《谪汀洲》云：“青蝇为吊客，黄犬寄家书。”可谓入作者闽域，岂独雄于诗僧间邪！
