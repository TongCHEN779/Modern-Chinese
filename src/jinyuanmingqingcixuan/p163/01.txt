# 纳兰性德
原：纳兰性德（1654—1685），原名成德，字容若，号楞伽山人，满洲正黄旗人。太学士明珠长子。康熙进士，官一等侍卫。善骑射，好读书，作词主情致，工小令，宗李煜。风格清新婉丽，不事雕饰，颇多感伤情调。所交游皆一时隽异，与顾贞观、陈维崧等尤契厚。吴江吴兆骞久徙绝域，性德闻其才名，助其赦还关内。坎坷失职之士，走访性德，生馆死殡，于赀财无所计惜。杨芳灿序纳兰词，谓其“骚情古调，侠肠俊骨，隐隐奕奕，流露于毫楮间”。又曰：“先生貂珥朱轮，生长华膴，其词则哀怨骚屑，类憔悴失职者之所为。盖其三生慧业，不耐浮尘，寄思无端，抑郁不释，韵淡疑仙，思幽近鬼，年之不永，即兆于斯。”有《饮水词》。

# 浣溪沙(六首选一)
题解：这首是悼亡词。上片写丧偶后的孤单。下片“被酒”、“赌书”一联是回忆往事。他们夫妇诗情画意的生活，简直和赵明诚、李易安夫妇一个样。结句从黄东甫《眼儿媚》“当时不道春无价，幽梦费重寻”句中化出。它是说，生活里常常有这么一种情况：当时以为是极其寻常的事，到了事后追忆起来，才觉得它是多么值得珍视！
原：谁念西风独自凉？/萧萧黄叶闭疏窗。/沉思往事立残阳。/被酒莫惊春睡重，/赌书消得泼茶香。/当时只道是寻常。
注原：赌书消得泼茶香：李清照《金石录后序》：“余性偶强记，每饭罢，坐归来堂烹茶，指堆积书史，言某事在某书某卷第几页第几行，以中否角胜负，为饮茶先后。中，即举杯大笑，至茶倾覆怀中，反不得饮而起。”

# 菩萨蛮
原：催花未歇花奴鼓，/酒醒已见残红舞。/不忍覆觞，/临风泪数行。/粉香看又别，/空剩当时月。/月也异当时，/凄清照鬓丝。
注原：花奴鼓：《杨妃外传》：“汝阳王琎，小名花奴，尤善羯鼓。帝尝谓侍臣曰：召花奴将羯鼓来为我解秽。”
注原：粉香：指妇女。

# 蝶恋花
题解：这是一首情词，也可能是悼亡词。上片说，爱情如同月亮那样，圆满的时间短，缺损的时间长。下两句说，爱情如能像月亮那样始终皎洁，即使你在冰雪之中，我也要用爱情之火来温暖你。下片写伤逝者的悲伤。双燕在帘间呢喃软语，反衬人的孤单。结语把永恒的爱情寄托在化蝶上。
原：辛苦最怜天上月。/一昔如环，/昔昔都成玦。/若似月轮终皎洁，/不辞冰雪为卿热。/无那尘缘容易绝。/燕子依然，/软踏帘钩说。/唱罢秋坟愁未歇，/春丛认取双栖蝶。
注原：一昔如环：谓一夜满月如环。一昔，一夜。《左传》：“为一昔之期。”环，圆形玉璧。昔昔都成玦（jué决）：谓夜夜都如玉玦。玦，玉佩，半环曰玦。
注原：冰雪：谓月轮中很冷。苏轼《水调歌头》：“只恐琼楼玉宇，高处不胜寒。”
注原：秋坟：李贺诗：“秋坟鬼唱鲍家诗。”双栖蝶：东晋会稽梁山伯，以病死。相传山伯尝与上虞祝英台同学，祝适马氏，过山伯墓，大号恸，地忽自裂，遂与山伯同葬，后来化为双飞蝴蝶。

# 浣溪沙
题解：这是伤离伤别的词。极言离别对于人的摧残，有如风雪。下片“青雀”一联是说春天到了，她的书信写了没有呢？他连夜在灯花下等待着。赵师秀诗：“有约不来过夜半，闲敲棋子落灯花。”“闲敲棋子”和“翦春幡”同一意境。结语说，怀人很辛苦，何况她是他相关的人呢！
原：记绾长条欲别难，/盈盈自此隔银湾。/便无风雪也摧残。/青雀几时裁锦字，/玉虫连夜翦春幡。/不禁辛苦况相关。
注原：记绾长条欲别难：谓两情相悦，如柳条系住，不易分离。绾，钩系。长条，指柳条。《唐诗纪事》：“雍陶典阳安，送客至情尽桥，问其故，左右曰：送迎之情止此，故名。陶命笔为一诗云：从来只有情难尽，何事名为情尽桥？自此改名为折柳，任他离恨一条条。”《三辅黄图》：“霸桥在长安东，跨水为桥，汉人送客至此桥，折柳赠别。”盈盈自此隔银湾：谓情人离别，如牛郎织女，隔了一条银河。盈盈，清浅貌。《古诗》：“盈盈一水间，脉脉不得语。”银湾，银河。
注原：青雀：《洞冥记》：“有女人爱悦于帝（汉武帝），名曰巨灵。帝傍有青珉唾壶，巨灵出入其中。东方朔望见，目之，因飞去，化成青雀。帝乃起青雀台，时见青雀来，不见巨灵也。”锦字：苏蕙织锦回文诗，见吴兆骞《念奴娇》注〔6〕。玉虫连夜翦春幡：谓连夜在灯花下翦春幡。玉虫，指灯花。范成大诗：“今朝合有家书到，昨夜灯花缀玉虫。”春幡，《梦华录》：“立春日，..士大夫家，翦彩为小幡，谓之春幡，或悬于家人之头，或缀于花枝之下，或翦春蝶、春钱、春胜以为戏。”

# 台城路·塞外七夕
题解：写塞外七夕的词，向来少见。七夕佳期，天上牛女相会，而人间尚有伤离之儿女，此正如结语所谓“今夜天孙，笑人愁似许”也。
原：塞外七夕
注原：七夕：阴历七月七日为七夕。《荆楚岁时记》：“天河之东，有织女，天帝之子也。年年织杼劳役，织成云锦天衣。天帝怜其独处，许嫁河西牵牛郎。嫁后，遂废织维。天帝怒，遂令归河东，惟每年七月七日夜，渡河一会。”
原：白狼河北秋偏早，/星桥又迎河鼓。/清漏频移，/微云欲湿，/正是金风玉露。/两眉愁聚。/待归踏榆花，/那时才诉。/只恐重逢，/明明相视更无语。/人间别离无数。/向瓜果筵前，/碧天凝伫。/连理千花，/相思一叶，/毕竟随风何处？/羁栖良苦！/算未抵空房，/冷香啼曙。/今夜天孙，/笑人愁似许！
注原：白狼河：辽宁的大凌河。星桥：银河上的桥。李商隐《七夕诗》：“鸾扇斜分凤幄开，星桥横过鹊飞回。”陆游诗：“一年又见星桥近，未信仙家日月长。”河鼓：星名，古谓之黄姑。《古乐府》：“黄姑织女时相见。”黄姑即河鼓。《尔雅》谓河鼓即牵牛。此句谓牛郎渡过星桥，与织女相会。
注原：金风玉露：金风，秋天的风，秋天在五行中属金。李商隐《辛未七夕》诗：“由来碧落银河畔，可要金风玉露时。”秦观《鹊桥仙》词：“金风玉露一相逢，便胜却人间无数。”
注原：归踏榆花：曹唐《织女怀牛郎》诗：“欲将心就仙郎说，借问榆花早晚秋。”
注原：瓜果筵前：《荆楚岁时记》：“七夕，妇人结彩缕穿七孔针，陈瓜果于庭中以乞巧。”凝伫：等待。
注原：连理千花：《晋中兴祥征记》：“连理，仁木也。或异枝还合，皆两树共合。”词章家每以连理喻夫妇之相爱。白居易诗：“在地愿为连理枝。”相思一叶：《青琐高议》：“唐僖宗时，于祐于御沟中拾一叶，上有诗。祐亦题诗于叶，置沟上流，宫人韩夫人拾之。后值帝放宫女，韩氏嫁祐成礼，各于笥中取红叶相示曰：可谢媒矣。”
注原：算未抵空房，冷香啼曙：谓夫在塞外未归，妻独居空房，香也冷了，哭到天明。
注原：天孙：星名。织女星之别名。

# 金缕曲·赠梁汾
题解：纳兰性德在清初做了不少团结知识分子的工作。他以满族贵公子兼词家的身份，结交许多汉族知名人士，徐干学为纳兰性德撰墓志铭，谓：“君所交游，皆一时俊异，于世所称落落难合者，若无锡严绳孙、顾贞观、秦松龄、宜兴陈维崧、慈溪姜宸英尤所契厚。吴江吴兆骞，久徙绝域，君闻其才名，赎而还之。坎轲失职之士，走京师，生馆死殡，于赀财无所计惜。”这首词中“有酒唯浇赵州土”句，是引用李贺的诗句。李诗上联是“买丝绣作平原君”，平原君是战国时赵国的贤公子，《史记》称他“喜宾客，宾客盖至者数千人”。有名的毛遂，就出在他的门下。纳兰性德引用李贺原句，说明他服膺平原君之为人。他延揽当时许多文人才士，不仅为文坛生色，抑且对清初政局起了稳定的作用。
原：赠梁汾
注原：梁汾：顾贞观号。
原：德也狂生耳！/偶然间、缁尘京国，/乌衣门第。/有酒惟浇赵州土，/谁会成生此意？/不信道、遂成知己。/青眼高歌俱未老，/向尊前、拭尽英雄泪。/君不见，/月如水。/共君此夜须沉醉。/且由他、蛾眉谣诼，/古今同忌。/身世悠悠何足问，/冷笑置之而已！/寻思起、从头翻悔。/一日心期千劫在，/后身缘恐结他生里。/然诺重，/君须记！
注原：德也狂生耳：纳兰性德自谓。缁尘京国：谓在京城奔走供职，衣裳为风尘染黑。乌衣门第：谓生在贵族之家。乌衣巷在南京，晋贵族王导、谢安居此，其子弟皆乌衣，故名。
注原：有酒惟浇赵州土：李贺《浩歌》诗：“买丝绣作平原君，有酒惟浇赵州土。”这是因为平原君是赵国的贤公子，还因为燕赵自古多慷慨悲歌之士。成生：性德自指。性德原名成德，后因避讳改性德。不信道、遂成知己：“不信道”，表示惊怪之意。“遂成知己”，谓与顾贞观遂成知己朋友。
注原：青眼：眼睛色青，喜时正视，则见青处。晋阮籍能为青白眼，见俗士，以白眼对之。嵇康赍酒挟琴来访，籍大悦，乃见青眼。此句亦翻用杜甫诗“青眼高歌望吾子，眼中之人吾老矣”语意。尊前：樽前。
注原：蛾眉谣诼：谓美女遭人妒忌。《离骚》：“众女嫉余之蛾眉兮，谣诼谓余以善淫。”杨芳灿序纳兰词：“或者谓（性德）高门贵胄，未必真嗜风雅，或当时贡谀者代为操觚耳。今其词具在，骚情古调，侠肠俊骨，隐隐奕奕，流露于毫楮间，斯岂他人所能摹拟乎？且先生所与交游，皆词坛名宿，刻羽调商，人人有集，亦正少此一种笔墨也。嗟乎！蛾眉谣诼，没世犹然。真赏难逢，为可累息。”
注原：一日心期千劫在：谓一日心期相许，成为知己，其情感虽经历千劫，仍然存在。劫，佛经言天地之一成一坯为一劫。后身缘：即身后因缘。因缘之说，乃是佛家思想。这句话的意思是：到来生还要成为知己朋友。
注原：然诺重：答允了的话，不再食言。《唐书·哥舒翰传》：“家富于财，任侠重然诺。”

# 南乡子·为亡妇题照
原：为亡妇题照
注原：亡妇：徐干学撰《纳兰君墓志铭》，谓性德“配卢氏，两广总督兵部尚书都察院右副都御史兴祖之女，赠淑人。先君卒”。
原：泪咽却无声，/只向从前悔薄情。/凭仗丹青重省识，/盈盈，/一片伤心画不成。/别语忒分明，/午夜鹣鹣梦早醒。/卿自早醒侬自梦，/更更，/泣尽风檐夜雨铃。
注原：丹青：画。画上著颜色，故称画为丹青。盈盈：形容美女之辞。《古诗》：“盈盈楼上女。”一片伤心画不成：元遗山《十日作》：“重阳拟作登高赋，一片伤心画不成。”
注原：忒：太。鹣鹣：古称比翼鸟。似凫，青赤色，一目一翼，相得乃飞。《尔雅》：“南方有比翼鸟焉，不比不飞，其名谓之鹣鹣。”午夜梦早醒，喻夫妻好梦不长。
注原：夜雨铃：用“雨淋铃”故事。《碧鸡漫志》：“帝（唐玄宗)幸蜀，霖雨弥旬，栈道中，闻铃声，帝方悼念贵妃，采其声为《雨淋铃》曲，以寄恨。”
原：前人评语：陈维崧《词评》：“饮水词哀感顽艳，得南唐二主之遗。”顾贞观《通志堂词序》：“容若天资超逸，翛然尘外，所为乐府小令，婉丽凄清，使读者哀乐不知所主。”《箧中词》引周之琦评语：“容若长调多不协律，小令则格高韵远，极缠绵婉约之致。能使残唐坠绪，绝而复续，第其品格，殆叔原、方回之亚乎？”王国维《人间词话》：“纳兰容若以自然之眼观物，以自然之舌言情，此由初入中原，未染汉人风气，故能真切如此，北宋以来，一人而已。”丁药园曰：“容若填词，有《饮水》、《侧帽》二本，大约于尊前马上得之，读之如名花美锦，郁然而新。又如太液波澄，明星皎洁。”聂晋人曰：“容若为相国才子，少工填词，香艳中更觉清新，婉丽处又极逸俊，真所谓笔花四照，一字动移不得者也。”
