# 黄景仁
原：黄景仁（1749—1783），字汉镛，一字仲则，号鹿菲子，江苏常州人。家贫，早岁奔走四方，以谋生计。曾应乾隆东巡粘试，列丁等，后募资为县丞，未补官而卒。其诗学李白，在当时诗坛负盛名，多抒发穷愁不遇寂寞凄怆的情怀，亦有愤世嫉俗之作。亦工词。有《竹眠词》二卷，一名《悔存词钞》，又名《两当轩诗》。

# 丑奴儿慢·春日
题解：这是一首惋惜春光迅速流逝之作。开头四句尤佳。“者似卷如流春日”，是对古人“春日迟迟”的诗句作翻案文章。“日日登楼，一日换一番春色”二句，是“似卷如流”的佐证。“小桃放了，没个人知”，是作者寂寞凄怆心情的反映。下片追叙徘徊花下，曾看见春光正好时，犹如年满十五岁的女孩子那样可爱。可是曾几何时，春也去了，花也憔悴了。结语谓春的归路，就在落花深处。劝人“莫惹相思”，正说明他对春去的相思。
原：日日登楼，/一日换一番春色，/者似卷如流春日，/谁道迟迟？/一片野风吹草，/草背白烟飞。/颓墙左侧，/小桃放了，/没个人知。/徘徊花下，/分明记得，/三五年时。/是何人、挑将竹泪，/黏上空枝。/请试低头，/影儿憔悴浸春池。/此间深处，/是伊归路，/莫惹相思。
注原：者：即“这”字。迟迟：《诗经》：“春日迟迟。”
注原：三五年时：即十五岁。此谓春光好时，如同十五岁的女孩子。
注原：竹泪：相传舜崩苍梧之野，娥皇、女英哭帝，泪染于竹，即湘妃竹。
注原：伊：指春。

# 沁园春·壬辰生日自寿，时年二十四
题解：黄景仁这首二十四岁作的自寿词，已见其才气横溢。他自觉“丁时已过，一寒至此”，功名事业没有成就，借邓禹二十四岁拜大司徒、周瑜二十四岁拜建威中郎将的史事为比，抒发自己不得志和寂寞凄怆的心情。其中“似水才名，如烟好梦”、“寿岂人争，才非尔福”等句，透露作者过分消极的思想。
原：壬辰生日自寿，时年二十四
注原：壬辰：是乾隆三十七年，公历1772年。
原：苍苍者天，/生我何为？/令人慨慷。/叹其年难及，/丁时已过；/一寒至此，/辛味都尝。/似水才句，/如烟好梦，/断尽黄齑苦笋肠。/临风叹，/只六旬老母，/苦节宜偿。/男儿堕地堪伤。/怪二十、何来镜里霜？/况笑人寂寂，/邓曾拜衮；/所居赫赫，/周已称郎。/寿岂人争，/才非尔福，/天意兼之忌酒狂。/当杯想，/想五湖三亩，/是我行藏。
注原：苍苍者天：《诗经》：“苍天苍天，视彼骄人，矜此劳人。”慨慷：意气愤激。
注原：其年难及：谓年光流逝，难以追及。丁时已过：已过丁壮之年。汉以男子年二十为丁，历代之制不同，明清以十六岁为成丁。
注原：一寒至此：《史记·范雎列传》写秦相范雎敝服去见须贾，须贾曰：“范叔一寒至此哉！”寒，穷窘不得志。辛味：悲苦、酸辛之味。
注原：如烟好梦：谓才名像流水那样容易消逝，好梦像飞烟那样容易消散。这都是作者的感伤、消极的话。“黄齑（jī机）”句：齑，盐菜。朱松诗：“读书有味齑盐好。”黄齑苦笋，都是贫苦人所食之物。
注原：六旬：六十岁。苦节宜偿：谓老母守节把他抚养成人，此恩应该报答。
注原：堕地：谓出生。镜里霜：指白发。李白诗：“不知明镜里，何处得秋霜。”
注原：笑人寂寂：《晋书·桓温传》：“温以雄武专朝，窥觎非望，或卧对亲僚曰：为尔寂寂，将为文景所笑。'众莫敢对。”《南史·王融传》：“融自恃人地，三十内望为公辅，及为中书郎，尝抚案叹曰：为尔寂寂，邓禹笑人。”邓曾拜衮：邓，指东汉邓禹。禹为光武所信任，与定计议。光武即位，禹年二十四，拜大司徒。衮是官服。古代三公服衮。拜衮即拜官之意。《宋书·宗室传》：“袁淑尝诣义康，义康问其年，答曰：邓仲华拜衮之岁。”邓禹字仲华。
注原：所居赫赫：《汉书·何武传》：“武为人仁厚，其所居亦无赫赫名，去后常见思。”周已称郎：指三国时吴国周瑜。瑜与孙策同年，相友善，推道南大宅以舍策。建安间策授瑜建威中郎将，时瑜年二十四。吴中皆呼为周郎。后事孙权，败曹操于赤壁。
注原：酒狂：《汉书·盖宽饶传》：“宽饶曰：无多酌我，我乃酒狂。”温庭筠诗：“越溪渔客贺知章，任达怜才爱酒狂。”
注原：五湖三亩：王维诗：“五湖三亩宅，万里一归人。”行藏：指出处。《论语》：“用之则行，舍之则藏。”

# 迈陂塘·白纻山
题解：这是一首游白纻山吊桓温的词。词中对桓温有所褒贬。“尚解登山作赋”、“一时裙屐原潇酒”，是褒，意谓桓温懂得任用文人，他身边有一批翰墨之士如孙盛、孟嘉等。“笑作贼匆匆”，是贬，意谓他野心勃勃，准备篡夺帝位。“谁料转头黄土”到最后一段，与苏轼《前赤壁赋》“固一世之雄也，而今安在哉”用意相同。
原：白纻山
注原：白纻山：在安徽当涂县东五里。本名楚山，桓温领妓游山为乐，好为《白纻》之歌，因改今名。白纻，乐府名，吴之舞曲。
原：冷清清、荒台败瓦，/日斜来吊宣武。/如云宾从当年事，/对面青山歌舞。/飞盖举，/下拥着、猬须石眼人如虎。/南州雄据，/笑作贼匆匆，/更何情绪，/来顾曲中误？/休相笑，/尚解登山作贼，/此儿终有佳处。/一时裙屐原潇洒，/谁料转头黄土。/江月苦，/把一片歌声，/悄悄沉将去。/雄心认取，/听漠漠苍林，/非丝非竹，/打起佛楼鼓。
注原：宣武：指桓温。温为东晋明帝婿，官至大司马。温以雄武专朝，欲立功河朔，还受九锡。征燕败绩，名实顿减，乃废帝奕而立简文帝，准备夺取政权，未及实现而死。
注原：如云宾从：谓桓温当年游白纻山，随从者甚多。青山：即当涂山。
注原：飞盖：指伞盖或车盖，古代大臣仪仗中多有之。猬须石眼人如虎：写桓温相貌雄武。《晋书·桓温传》：“温豪爽有风概，姿貌甚伟，面有七星。少与沛国刘惔善，惔尝称之曰：温眼如紫石棱，须作猬毛磔，孙仲谋、晋宣王之流亚也。”
注原：南州雄据：东晋建都建康（今南京）。作贼匆匆：谓桓温阴谋夺取东晋政权。来顾曲中误：谓桓温好为《白纻》之歌。《三国志·吴书·周瑜传》：“曲有误，周郎顾。”
注原：尚解登山作：尚解登山作赋：谓桓温不是一介武夫，还懂得文学。孟嘉为桓温参军，温甚重之。九月九日温宴龙山，风吹嘉帽落地，嘉不觉，温命孙盛作文嘲嘉，嘉即答之，其文甚美，四座嗟叹。此儿终有佳处：谓桓温有可取之处。
注原：一时裙屐原潇洒：谓桓温幕僚中有许多文人雅士。《北史·邢峦传》：“峦表曰：萧深藻是裙屐少年，未洽政务。”谓只能自修饰，非任重之器。转头黄土：谓很快死去。杜甫《阁夜》诗：“卧龙跃马终黄土。”谓诸葛亮、公孙述这些历史人物，终归于尽。
注原：一片歌声：当指《白纾》之歌。
注原：认取：认是看的意思，取是虚字。丝竹：谓音乐。丝是弹奏乐器，竹是吹奏乐器。

# 卖花声·立春
题解：这首词写立春节独饮时的感想。“楼窗今夜且休关”，是为了迎候燕子归来。他不仅把燕子看作故交，而且希望燕子衔回去年流逝的落红，由此可见词人的念旧深情和丰富联想。“春比人顽”二句是哲理性的名言。
原：独饮对辛盘，/愁上眉弯。/楼窗今夜且休关。/前度落红流到海，/燕子衔还。/书贴更簪欢，/旧例都删。/到时风雪满千山。/年去年来常不老，/春比人顽。
注原：辛盘：《风土记》：“元旦以葱、蒜、韭、蓼蒿、芥杂和而食之，名五辛盘，取迎新之意也。”
注原：书贴：《荆楚岁时记》：“立春日，悉剪彩为燕以戴之，贴‘宜春，二字。”簪欢：当指立春日簪幡胜为欢。《梦华录》：“立春日，...士大夫家剪彩为小幡，谓之春幡，或悬于家人之头，或缀于花枝之下，或剪为春蝶、春钱、春胜以为戏。东坡立春日亦簪幡胜过子由，诸子侄笑指云：伯伯老人亦簪幡胜耶。”
注原：到时风雪满千山：此谓立春节候，天气尚冷，尚有风雪。

# 贺新郎·太白墓，和稚存韵
题解：这是一首吊李白墓的词。李白墓与谢朓宅是近邻。黄景仁诗学李白，在当时（乾隆年间）诗坛负盛名。“只为先生名在上，问青天、有句何能好”？此从李白“眼前有景道不得，崔颢题诗在上头”诗句中化出。意谓：只因为李白诗名大，才使自己的诗句相形逊色。下片写梦中与李白相遇的情景和对话。“更问后来谁似我”，是李白问。“我道：才如君少。有亦是寒郊瘦岛”，是黄景仁答。词中运用对话，不乏先例。如刘过有《沁园春》一首，乃用白居易、林逋、苏轼三人的对话所组成。
原：太白墓，和稚存韵
注原：太白墓：即李白墓，在安徽当涂采石矶。稚存：洪亮吉字。黄景仁与洪亮吉是同乡，又是好友。
原：何事催人老？/是几处、残山剩水，/闲凭闲吊。/此是青莲埋骨地，/宅近谢家之朓。/总一样文人宿草。/只为先生名在上，/问青天、有句何能好？/打一幅，/思君稿。/梦中昨夜逢君笑。/把千年、蓬莱清浅，/旧游相告。/更问看君长揖去，/顿身轻、一叶如飞鸟。/残梦醒，/鸡鸣了。
注原：青莲：李白号青莲居士。谢家之朓：指南北朝南齐著名诗人谢朓。采石矶有谢公山。李白诗：“宅近青山同谢朓，门垂碧柳似陶潜。”
注原：文人宿草：指文人之墓。宿草，隔年之草。《礼记》：“朋友之墓，有宿草而不哭焉。”
注原：先生名在上：采石矶太白楼有楹联云：“我辈此中惟饮酒，先生在上莫题诗。”此数句中所谓“先生”、“君”，都指李白。
注原：蓬莱：仙山名。《史记》：“蓬莱、方丈瀛洲，此三神山者，在渤海中。”旧游：谓老朋友。韦庄诗：“客过当涂县，停车访旧游。”
注原：旧游相告：寒郊瘦岛：指唐代诗人孟郊、贾岛，论者评他们的诗为“郊寒岛瘦”。

# 摸鱼子·归鸦
题解：这是一首咏物词。它展现出的画面，就像倪云林的枯木归鸦图。下片以栖息朱门贵宅和上林苑囿的鸟儿来对比枯木归鸦，展示得意、失意之间，判若云泥。作者还以倦飞的归鸦来自喻。你看，惨惨柴门，天寒岁暮，真是无限辛酸。词的结尾指出：更加值得同情的，是一些他乡游子，他们此时此刻奔波在画角声中（战争气氛）和暝烟堆里，比归鸦还要可怜！
原：倚柴门、晚天无际，/昏鸦归影如织。/分明小幅倪迂画，/点上米家颠墨。/看不得。/带一片斜阳，/万古伤心色。/暮寒萧淅。/似卷得风来，/还兼雨过，/催送小楼黑。/曾相识。/谁傍朱门贵宅？/上林谁更栖息？/几丛枯木惊霜重，/我是归飞倦翮。/飞暂歇。/却好趁、渔船小坐秋帆侧。/旧巢应忆。/笑画角声中，/暝烟堆里，/多少未归客！
注原：柴门：以柴为门，朴陋的意思。杜甫诗：“相送柴门月色新。”
注原：倪迂：指元名画家倪瓒。瓒号云林，善画山水。初师董源，晚年一变古法，以天真幽淡为宗。详见本书元词倪瓒简介。米家颠墨：指宋名画家米芾。芾字元章，号鹿门居士。为文奇险，特妙于翰墨，画山水人物，自成一家。世人因为他不羁，称为米颠。
注原：上林：苑名。在陕西长安县西，原是秦旧苑，汉武帝更增广之，周袤三百里，离宫七十所。
注原：倦翮：倦飞的鸟。《尔雅》：“羽本谓之翮。”
