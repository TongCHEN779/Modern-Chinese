# 朱孝臧
原：朱孝臧（1857—1931），原名祖谋，字古微，号沤尹，又号彊村，浙江湖州人。光绪九年（1883）进士，改庶吉士，授编修，屡擢至侍讲学士，礼部侍郎。辛亥革命后寓居上海，颇有怀恋清室之作。其词委婉致密，音律和谐，初近似吴文英。晚年融化苏轼豪放词风于沉抑绵邈之中，形成他自己独特的风格。有《彊村语业》，并辑刻唐宋金元人词为《彊村丛书》。

# 鹧鸪天·九日，丰宜门外过裴邨别业
题解：此为刘光第被杀后，朱孝臧过其别业，有感而作。“野水斜桥”，点明郊外景色。“又一时”，说明作者过裴邨别业，并非首次。只是这次来时，情况发生变化，别业主人已惨遭杀害。“凄迷南郭”、“清苦西峰”一联写景又兼抒情，语极含蓄。“垂鞭”是不忍急驰而过，含有凄恻之意。“侧帽窥”写出祸事之惨，作者事后经过，尚心有悸。下片作者抚今追昔，想起从前裴邨别业中有弹琴咏诗之乐，现在，红萸白菊依然开放，而物在人亡，门馆凄凉，令人低徊不已。
原：九日，丰宜门外过裴邨别业
注原：丰宜门：《日下旧闻》：“丰宜门为金之南门，金时建有拜郊台。”裴邨别业：裴邨，刘光第字。光第是清末“戊戍六君子”之一，四川富顺人，进士出身。历任刑部主事、军机章京。1898年参加保国会。提升为四品卿衔军机章京，参预变法。政变失败后被捕，与谭嗣同等五人同时被害。别业，田园之别置于他地者。《南史·谢灵运传》：“移籍会稽，修营别业。”
诗：野水斜桥又一时，/愁心空诉故鸥知。/凄迷南郭垂鞭过，/清苦西峰侧帽窥。/新雪涕，/旧弦诗，/愔愔门馆蝶来稀。/红萸白菊浑无恙，/只是风前有所思。
注原：南郭：南郭；城之南门。《南史·宋·王僧祐传》：“僧祐雅为从兄俭所重，谢病不与公卿游，赠俭诗云：汝家在市门，我家在南郭。汝家饶宾侣，我家多鸟雀。”垂鞭：李白诗：“平明拂剑朝天去，薄暮垂鞭醉酒归。”清苦西峰：姜夔《点绛唇》：“数峰清苦，商略黄昏雨。”此西峰，当指京郊西山。侧帽：《北史》：“周独孤信在秦州，尝因猎日暮，驰马入城，其帽微侧。诘旦，吏人有戴帽者，咸慕信而侧帽焉。”
注原：雪涕：拭泪。弦诗：弹琴咏诗。愔（yīn阴）愔：静寂无哗。
注原：红萸白菊：《风土记》：“以重阳相会，登山饮菊花酒，谓之登高会，又云茱萸会。”杜甫诗：“明年此会知谁健，醉把茱萸子细看。”茱萸，乔木名。

# 乌夜啼·同瞻园登戒坛千佛阁
题解：这首词以写景名。特别是下片“吹不断，黄一线，是桑干”，寥寥三句，形象地勾画出桑干河流域的风貌，气象阔大。桑干河不是小河，它源出山西，流经河北，跨越两省。说它像一条线，造句已奇；在“黄一线”前面加“吹不断”三字，句子更奇！这样写，极言戒坛寺千佛阁地势之高，作者和他的游伴，登临远望，只见那桑于河从群山万壑中出来，奔流在莽莽苍苍的河北原野上，在夕阳映照下，发出黄色的闪光。这样一幅北方特有的图景，作者轻而易举地把它容纳在一首小令的六个字的句子中，真是大家手笔！南宋陆游有一首《过灵石三峰》的七绝，也有这样的魄力和艺术概括力。诗云：“奇峰迎马骇衰翁，蜀岭吴山一扫空。拔地青苍九千仞，劳渠蟠屈小诗中。”
原：同瞻园登戒坛千佛阁
注原：瞻园：张仲炘号次珊，有《瞻园词》。戒坛：寺名。在北京西郊门头沟区。
诗：春云深宿虚坛，/磬初残，/步绕松阴双引出朱阑。/吹不断，/黄一线，/是桑干。/又是夕阳无语下苍山。
注原：磬：僧徒所用的乐器。引：相牵曰引。双引，两人携手同行。
注原：桑干：河名。源出山西省北部，流经河北西北部，注入官厅水库。

# 鹧鸪天·庚子岁除
题解：晚清庚子年，八国联军入侵北京，洗劫全城，慈禧太后那拉氏偕光绪帝逃往西安。当时作者与王鹏运等词人困居围城中，在宣武门外校场头条胡同王鹏运的寓庐“四印斋”中，同赋《庚子秋词》。此阕《鹧鸪天》是作者在庚子年除夕所作。“酒肠芒角森如戟，吟笔冰霜惨不花”、“烛花红换人间世”等句，含蓄地对庚子世变有所反映。此词另外一个内容，即对家乡的怀念。《鹧鸪天》最后两句用对句，也是这首词的一个特点。
原：庚子岁除
注原：庚子岁除：庚子，光绪二十六年（1900）。岁除，即除夕。
诗：似水清尊照鬓华，/尊前人易老天涯。/酒肠芒角森如戟，/吟笔冰霜惨不花。/抛枕坐，/卷书嗟，/莫嫌啼煞后栖鸦。/烛花红换人间世，/山色青回梦里家。
注原：尊：酒樽。鬓华：两鬓华白。高适诗：“节物惊心两鬓华。”天涯：天之涯，谓在很远的地方作客的人是容易老去的。苏轼诗：“学道无成鬓已华，更携书剑客天涯。”
注原：芒角：苏轼《醉画竹石》诗：“空肠得酒芒角出，肝肺槎牙生竹石。”
注原：后栖鸦：最后归栖的乌鸦。杜甫诗：“夜来归鸟尽，啼煞后栖鸦。”
注原：人间世：亦《庄子》篇名。大意言处人间之宜，居乱世之理，惟无心而不自用者，为能随变所适而自全。

# 声声慢·辛丑十一月十九日，味聃赋“落叶词”见示，感和
题解：此词咏落叶，实指珍妃。词以寒落叶起兴，开头即是一片衰飒气氛。光绪帝于庚子八国联军之役，随那拉氏仓皇西走。次年辛丑，寇退还京，“鸣”、“吹蝶”二句，是乱后宫廷荒凉景色的再现。“飘蓬人意相怜”，隐约逗出珍妃。“离魂”二句，写光绪帝还宫后对珍妃的怀念。“禁花憔悴”二句，写珍妃不见容于那拉氏，憔悴堪怜。“神宫”三句，用汉武帝思念李夫人的故事，喻光绪思念珍妃。下片“飞霜金井”三句，直接写那拉氏下令推堕珍妃于宫井一事，使她和光绪帝的缠绵恩爱之情，从而中断。“恩怨无端”二句，帝对珍妃是恩，那拉氏对珍妃是怨。“洞庭波阔”二句，又以湘夫人思念帝舜之事，喻珍妃和光绪帝生离死别，遗恨千古。结语空灵，似乎是在对落叶发言。实际上，说它是指光绪帝和珍妃，亦无不可。
原：辛丑十一月十九日，味聃赋“落叶词”见示，感和
注原：辛丑：光绪二十七年（1901）。八国联军入侵北京的第二年。味聃（dān丹）：洪汝冲字。
诗：鸣颓城，/吹蝶空枝，/飘蓬人意相怜。/一片离魂，/斜阳摇梦成烟。/香沟旧题红处，/拼禁花、憔悴年年。/寒信急，/又神宫凄奏，/分付哀蝉。/终古巢鸾无分，/正飞霜金井，/抛断缠绵。/起舞回风，/才知恩怨无端。/天阴洞庭波阔，/夜沉沉、流恨湘弦。/摇落事，/向空山、休间杜鹃。
注原：鸣颓：，蝉。颓城，坏了的阶齿。《三辅黄图》：“未央前殿左右平。”注：“天子殿高九尺，阶为九级，中分左右。左有齿，人行之。右则平之。”吹蝶空枝：谓树叶被风吹下，如蝴蝶飞舞，树上只剩空枝。飘蓬：喻不幸的人的命运。蓬，草名。秋枯根拔，风卷而飞，故叫飞蓬、飘蓬。
注原：离魂：陈玄祐《离魂记》载：张倩娘许配王宙，后，父镒又以倩娘别字。宙愤而买舟赴京。倩娘忽至，挈与俱遁。居蜀五年，生二子，始共归衡州。镒大惊，以倩娘病数年，未尝离闺闼也。两女相见，翕然合为一体。
注原：题红：香沟题红：《唐诗纪事》：“卢渥应举之岁，偶临御沟，见一绝句，置于巾箱。.....卢后任范阳日，获其退宫人，睹红叶，验其书，无不惊讶。诗曰：流水何太急？深宫尽日闲。殷勤谢红叶，好去到人间。”禁花：宫禁中之花，指珍妃。
注原：寒信：寒冷的信息，指秋风。神宫：《雅乐歌》：“神宫肃肃，天仪穆穆。”此指光绪帝所居的宫殿。哀蝉：《拾遗记》：“汉武帝思李夫人，因赋‘落叶哀蝉之曲’。”
注原：巢鸾：巢居之鸾。《禽经》：“凤翥鸾举，百鸟从之。”故世以凤鸾喻后妃。金井：指珍妃井。西太后那拉氏庚子年逃离北京前，下令推堕珍妃于宫井中。曹邺《金井怨》诗：“西风吹急景，美人照金井。不见面上花，却恨井中影。”
注原：回风：回旋的风。《楚辞》：“悲回风之摇蕙兮，心冤结而内伤。”
注原：洞庭波阔：《楚辞·九歌·湘夫人》：“帝子降兮北渚，目眇眇兮愁予。袅袅兮秋风，洞庭波兮木叶下。”

# 浣溪沙·一
诗：独鸟冲波去意闲，/坏霞如赭水如笺。/为谁无尽写江天。/并舫风弦弹月上，/当窗山髻挽云还。/独经行处未荒寒。
注原：坏霞如赭水如笺：坏霞即断霞。赭是赤色。水如笺，水如纸平。
注原：风弦：谓琴声。山髻：谓山的形状像女人的发髻。

# 浣溪沙·二
诗：翠阜红厓夹岸迎，/阻风滋味暂时生。/水窗官烛泪纵横。
注原：官烛：公家的蜡烛。谢承《后汉书》：“巴祗为扬州刺史，与客暗饮，不燃官烛。”黄庭坚诗：“风檐官烛泪纵横。”
诗：禅悦新耽如有会，/酒悲突起总无名。/长川孤月向谁明。
注原：禅悦：谓耽心于禅理。《华严经》：“若饭食时，当愿众生禅悦为食，法喜充满。”酒悲：白居易诗：“谁料平生狂酒客，如今变作酒悲人。”

# 洞仙歌·丁未九日
题解：此是重九登高时的咏怀之作。朱孝臧自光绪甲辰出为广东学政，与总督龃龉，托病去官。所谓“无名秋病，已三年止酒”，或亦兼指此事。下片的主题是“思君”。杜甫诗“每依北斗望京华”，望京华是寄托其对故国的思念。此词的“回指长安”，亦是此意。“故国霜多，怕明日、黄花开瘦”，表达了作者虽身居湖海，仍然有忧念国事的一片耿耿之心。
原：丁未九日
注原：丁未九日：光绪三十三年（1907）九月九日。
诗：无名秋病，/已三年止酒，/但买萸囊作重九。/亦知非吾土，/强约登楼，/闲坐到、淡淡斜阳时候。/浮云千万态，/回指长安，/却是江湖钓竿手。/衰鬓侧西风，/故国霜多，/怕明日、黄花开瘦。/问畅好、秋光落谁家？/有独客徘徊，/凭高双袖。
注原：萸囊：古人于九月九日作绛囊，盛茱萸系臂，登高饮菊酒，谓可避灾。见《续齐谐记》。
注原：非吾土：王粲《登楼赋》：“虽信美而非吾土兮，曾何足以少留？”
注原：浮云：见前沈曾植《临江仙》注〔2〕。长安：指京城北京。
注原：黄花开瘦：李清照《醉花阴》：“莫道不消魂，帘卷西风，人比黄花瘦。”
注原：畅好：大好、很好。

# 好事近·灵隐夜归蒋氏湖庄作
题解：此词上片写月夜自湖上至灵隐寺，下片写自灵隐寺归湖庄，得情景交融之妙。
原：灵隐夜归蒋氏湖庄作
注原：灵隐：寺名。为杭州西湖名胜之一。蒋氏湖庄：在苏堤南端的“花港观鱼”。
诗：湖气郁衣巾，/步入宝坊林月。/耐得山亭泉冷，/信肝肠如雪。/出山十里蟪蛄声，/闻根甚时歇？/据槁安心随地，/又南邻钟发。
注原：宝坊：僧寺。此指灵隐寺。《鸡跖集》：“给孤长者，以黄金布地为伽蓝，故号宝坊。”
注原：山亭泉冷：指灵隐寺前的冷泉亭。《西湖志纂》：“冷泉即石门涧之源，一名灵隐浦，汉志所称‘武林山出武林水，是也。”
注原：出山十里蟪蛄声：《吕氏春秋》：“孔子曰：违山十里，蟪蛄之声，犹尚在耳。”《本草》：“蝉类甚多，四、五月鸣而小紫青色者，蟪蛄也。”闻根：指耳。佛经以眼、耳、鼻、舌、心、意六者为六根。眼为视根，耳为闻根，鼻为嗅根，舌为味根，身为触根，意为念虑根。
注原：据槁：《庄子》：“据槁梧而瞑。”注：“据琴而睡也。”南邻钟发：指静慈寺钟声。静慈寺与蒋氏湖庄为邻。

# 南乡子
题解：此词由伤春而念衰老，末数句“一去不回成永忆，看看，唯有承平与少年”，感叹深沉，颇耐寻味。
诗：病枕不成眠，/百计湛冥梦小安。/际晓东窗韪鸠唤，/无端，/一度残春一惘然。/歌底与尊前，/岁岁花枝解放颠。/一去不回成永忆，/看看，/唯有承平与少年。
注原：湛冥：昏晦不明。
注原：放颠：纵恣不受检束。
注原：承平：言相承太平之世。《汉书》：“累世承平。”
原：前人评语：王国维《人间词话》：“近人词如复堂词之深婉，彊村词之隐秀，皆在半塘老人上。彊村学梦窗，而情较梦窗反胜，盖有临川、庐陵之高华，而济以白石之疏越者，学人之词，斯为极则。然古人自然神妙处，尚未见及。”
原：叶恭绰《广箧中词》：“彊村翁词，集清季词学之大成，公论翕然，无待扬摧。余意词之境界，前此已开拓殆尽，今兹欲求于声家特开领域，非别寻途径不可。故彊村翁或且为词学之一大结穴，开来启后，应有继起而负其责者，此今日论文学者所宜知也。”
