# 屈大均
原：屈大均（1630—1697），初名绍隆，字翁山，又字介子，广东番禺人。明末诸生，明亡后出家，名今种，字一灵，又字骚。曾北走燕赵，有复明之志。中年返初服，改今名。尝读书祁氏寓山园，不下楼者五月。工诗，尤长于描写山林边塞景物。与陈恭尹、梁佩兰齐名，号”岭南三大家“。著有《九歌草堂集》。

# 紫萸香慢·送雁
题解：这首词名为送雁，实以自喻，包蕴甚深。上片“向并门少待，白首牧羝人，正海上，手携李卿”，是借喻自己天涯漂泊的身世。下片“跨羊小儿争射，恁能到，白苹汀”，是暗喻担心被敌人残害，而不能南返故园。流露出无限的凄怆。
诗：恨沙蓬、偏随人转，/更怜雾柳难青。/问征鸿南向，/几时暖返龙庭。/正有无边烟雪，/与鲜千里，/送度长城。/向并门少待，/白首牧羝人，/正海上，/手携李卿。/秋声，/宿定还惊。/愁里月，/不分明。/又哀笳四起，/衣砧断续，/终夜伤情。/跨羊小儿争射，/恁能到，/白苹汀。/尽长天遍排人字，/逆风飞去，/毛羽随处飘零，/书寄未成。
注原：沙蓬：蓬，草名，茎高尺，花甚小，色白，秋枯根拔，风沙卷而飞，故以蓬转蓬飘以喻人的行踪飘泊。纪唐夫《骢马曲》：“连钱出塞踏沙蓬。”
注原：龙庭：古代称匈奴的王庭为龙庭。李白《古风》诗：“昔到雁门关，今戍龙庭前。”
注原：鲜：暴风叫。鲜，指大风。谢朓《夏始》诗：“对窗斜日过，洞幌鲜入。”孙光宪《玉蝴蝶》词：“鲜暖，牵游伴，飞去立残芳。”
注原：牧羝人：牧羊人。指苏武。羝，公羊。李卿：指汉将李陵，后降匈奴。汉使苏武到匈奴，被扣，曾牧羝海上，后释归，行前曾与此前已降匈奴的李陵握别。
注原：衣砧：捣衣石。
注原：跨羊小儿争射：句：《汉书·匈奴传》：“儿能骑羊引弓射鸟鼠。”这句是隐喻胡儿将要伤害大雁的意思。

# 长亭怨·与李天生冬夜宿雁门关作
题解：这首词上片写与李天生宿雁门，灯前夜话，饮乳和词的情况；下片“问长城旧主......那能使口北关南，重作并州门户”等句，是慨叹长城一带已被清军占据；“沙飞”几句，是表示作者对敌极端仇恨的心情。末尾“收拾秦弓归去”句，表明了继续斗争的决心。此词纵横排荡，神似稼轩。明代词人，罕有其匹。
原：与李天生冬夜宿雁门关作
注原：李天生：即李因笃。富平人，明季诸生。
诗：记烧烛雁门高处。/积雪封城，/冻云迷路。/添尽香煤，/紫貂相拥夜深语。/苦寒如许。/难和尔，/凄凉句。/一片望乡愁，/饮不醉，/垆头驼乳。/无处。/问长城旧主。/但见武灵遗墓。/沙飞似箭，/乱穿向草中狐兔。/那能使口北关南，/更重作并州门户。/且莫吊沙场，/收拾秦弓归去。
注原：香煤：古代妇女画眉用品。词句借用做煤炭解。
注原：武灵遗墓：战国时赵武灵王，名雍，胡服骑射以教百姓，扩地北至燕、代，西至云中、九原，在位二十七年。其墓当在沙丘，今为河北省平乡县东北。
注原：秦弓：相传秦地（今陕、甘一带）有南山檀柘，可做弓干。《楚辞·国殇》：“带长剑兮挟秦弓。”

# 梦江南·一
诗：悲落叶，/叶落落当春。/岁岁叶飞还有叶，/年年人去更无人。/红带泪痕新。
注原：落当春：是说落叶应当在秋天，但因树受了病，叶子在春天就已落了。

# 梦江南·二
诗：悲落叶，/叶落绝归期。/纵使归来花满树，/新枝不是旧时枝。/且逐水流迟。

# 梦江南·三
诗：清泪好，/点点似珠匀。/蛱蝶多情元凤子，/鸳鸯恩重是花神，/恁得不相亲。
注原：凤子：崔豹《古今注》：“蝶一名凤子，一名凤车。”韩偓《深院》诗：“凤子轻盈腻粉腰。”
注原：恁：怎么。

# 梦江南·四
诗：红茉莉，/穿作一花梳。/金缕抽残蝴蝶茧，/钗头立尽凤凰雏。/肯忆故人姝。
注原：穿作一花梳：句：用茉莉花穿贯成串，插在头上。姜夔《好事近·赋茉莉》词有“朝来碧缕放长穿，钗头罣层玉”句，即其例。
注原：钗头：句：把钗饰做成小凤凰式样。于渍《古宴曲》：“凤凰钗一只。”
注原：肯忆：句：肯忆，问辞，还想到么？女之美者曰姝。《古乐府》：“新人虽云好，未若故人姝。”
原：前人评语：况周颐《蕙风词话》云：“且逐水流迟'五字，含有无限凄惋，令人不忍寻味，却又不容已于寻味。第三、四首哀感顽艳，亦复可泣可歌。”

# 潇湘神·一·零陵作
原：零陵作
注原：零陵：今为湖南省零陵县。
诗：潇水流。/湘水流。/三闾愁接二妃愁。/潇碧湘蓝虽两色，/鸳鸯总作一天秋。
注原：三闾：屈原做楚国三闾大夫。《小学绀珠》：“三闾：昭、屈、景。”是楚国当时三大贵族。二妃：娥皇、女英，尧之二女，嫁为舜妃。《博物志》：“舜二妃曰湘夫人，舜崩，二妃啼，以涕挥竹，竹尽斑。”
诗：潇水深。/湘水深。/双双流水逐臣心。/潇水不如湘水好，/将愁送去洞庭阴。
注原：洞庭：湖南有洞庭湖、湘江等四条水，都汇合入洞庭湖。水南为阴，水北为阳。洞庭阴就是洞庭湖的南面。
