# 贺雨
诗：皇帝嗣宝历，/元和三年冬。/自冬及春暮，/不雨旱烛烛。
诗：上心念下民，/惧岁成灾凶。/遂下罪己诏，/殷勤告万邦。
诗：帝曰予一人，/继天承祖宗。/忧勤不遑宁，/夙夜心忡忡。
诗：元年诛刘闢，/一举靖巴邛。/二年戮李锜。/不战安江东。
诗：顾惟眇眇德，/遽有巍巍功。/或者天降沴，/无乃儆予躬？
诗：上思答天戒，/下思致时邕。/莫如率其身，/慈和与俭恭。
诗：乃命罢进献，/乃命赈饥穷。/宥死降五刑，/已责宽三农。
诗：宫女出宣徽，/厩马减飞龙。/庶政靡不举，/皆出自宸衷。
诗：奔腾道路人，/伛偻田野翁。/欢呼相告报，/感泣涕沾胸。
诗：顺人人心悦，/先天天意从。/诏下才七日，/和气生冲融。
诗：凝为悠悠云，/散作习习风。/昼夜三日雨，/凄凄复蒙蒙。
诗：万心春熙熙，/百谷青芃芃。/人变愁为喜，/岁易俭为丰。
诗：乃知王者心，/忧乐与众同。/皇天与后土，/所感无不通。
诗：冠珮何锵锵，/将相及王公，/蹈舞呼万岁，/列贺明庭中。
诗：小臣诚愚陋，/职忝金銮宫。/稽首再三拜，/一言献天聪：
诗：君以明为圣，/臣以直为忠；/敢贺有其始，/亦愿有其终。

# 读张籍古乐府
诗：张君何为者？/业文三十春。/尤工乐府诗，/举代少其伦。
诗：为诗意如何？/六义互铺陈。/风雅比兴外，/未尝著空文。
诗：读君学仙诗，/可讽放佚君。/读君董公诗，/可诲贪暴臣。
诗：读君商女诗，/可感悍妇仁。/读君勤齐诗，/可劝薄夫敦。
诗：上可裨教化，/舒之济万民；/下可理情性，/卷之善一身。
诗：始从青衿岁，/迨此白发新。/日夜秉笔吟，/心苦力亦勤。
诗：时无采诗官，/委弃如泥尘。/恐君百岁后，/灭没人不闻。
诗：愿藏中秘书，/百代不湮沦；/愿播内乐府，/时得闻至尊。
诗：言者志之苗，/行者文之根。/所以读君诗，/亦知君为人。
诗：如何欲五十，/官小身贱贫？/病眼街西住，/无人行到门。

# 哭孔戡
诗：洛阳谁不死？/戡死闻长安。/我是知戡者，/闻之涕泫然。
诗：戡佐山东军，/非义不可干。/拂衣向西来，/其道直如弦。
诗：从事得如此，/人人以为难。/人言明明代，/合置在朝端。
诗：或望居谏司，/有事戡必言。/或望居宪府，/有邪戡必弹。
诗：惜哉两不谐，/没齿为闲官。/竟不得一日，/謇謇立君前。
诗：形骸随众人，/敛葬北邙山。/平生刚肠内，/直气归其间。
诗：贤者为生民，/生死悬在天。/谓天不爱人，/胡为生其贤？
诗：为天果爱民，/胡为夺其年？/茫茫元化中，/谁执如此权？

# 凶宅
诗：长安多大宅，/列在街西东。/往往朱门内，/房廊相对空。
诗：枭鸣松桂枝，/狐藏兰菊丛。/苍苔黄叶地，/日暮多旋风。
诗：前主为将相，/得罪窜巴庸。/后主为公卿，/寝疾殁其中。
诗：连延四五主，/殃祸继相钟。/自从十年来，/不利主人翁。
诗：风雨坏檐隙，/蛇鼠穿墙墉。/人疑不敢买，/日毁土木功。
诗：嗟嗟俗人心，/甚矣其愚蒙。/但恐灾将至，/不思祸所从。
诗：我今题此诗，/欲悟迷者胸。/凡为大官人，/年禄多高崇。
诗：权重持难久，/位高势易穷。/骄者物之盈，/老者数之终。
诗：四者如寇盗，/日夜来相攻。/假使居吉土，/孰能保其躬？
诗：因小以明大，/借家可谕邦。/周秦宅崤函，/其宅非不同；
诗：一兴八百年，/一死望夷宫。/寄语家与国，/人凶非宅凶。

# 梦仙
诗：人有梦仙者，/梦身升上清。/坐乘一白鹤，/前引双红旌。
诗：羽衣忽飘飘，/玉鸾俄铮铮。/半空直下视，/人世尘冥冥。

诗：须臾群仙来，/相引朝玉京。/安期羡门辈，/列侍如公卿。
诗：仰谒玉皇帝，/稽首前致诚。/帝言汝仙才，/努力勿自轻。
诗：却后十五年，/期汝不死庭。/再拜受斯言，/即寤喜且惊。
诗：秘之不敢泄，/誓志居岩扃。/恩爱舍骨肉，/饮食断膻腥。
诗：朝餐云母散，/夜吸沆瀣精。/空山三十载，/日望辎軿迎。
诗：前期过已久，/鸾鹤无来声。/齿发日衰白，/耳目减聪明。
诗：一朝同物化，/身与粪壤并。/神仙信有之，/俗力非可营。
诗：苟无金骨相，/不列丹台名。/徒传辟谷法，/虚受烧丹经。
诗：只自取勤苦，/百年终不成。/悲哉梦仙人，/一梦误一生。

# 观刈麦
原：时为盩厔县尉
诗：田家少闲月，/五月人倍忙。/夜来南风起，/小麦覆陇黄。
诗：妇姑荷箪食，/童稚携壶浆。/相随饷田去，/丁壮在南岗。
诗：足蒸暑土气，/背灼炎天光。/力尽不知热，/但惜夏日长。
诗：复有贫妇人，/抱子在其傍。/右手秉遗穗，/左臂悬弊筐。
诗：听其相顾言，/闻者为悲伤。/家田输税尽，/拾此充饥肠。
诗：今我何功德，/曾不事农桑。/吏禄三百石，/岁晏有粮。
诗：念此私自愧，/尽日不能忘。

诗：无声但呀呀，/以气相煦濡。/倾篮写地上，/拨刺长尺。
诗：岂唯刀机忧。/坐见蝼蚁图。/脱泉虽已久，/得水犹可苏。
诗：放之小池中，/且用救干枯。/水小池窄狭，/动尾触四隅。
诗：一时幸苟活，/久远将何如？/怜其不得所，/移放于南湖。
诗：南湖连西江，/好去勿踟蹰。/施恩即望报，/吾非斯人徒。
诗：不须泥沙底，/辛苦觅明珠。

# 文柏床
诗：陵上有老柏，/柯叶寒苍苍。/朝为风烟树，/暮为宴寝床。
诗：以其多奇文，/宜升君子堂。/刮削露节日，/拂拭生辉光。
诗：玄斑状狸首，/素质如截肪。/虽充悦目玩，/终乏周身防。
诗：华彩诚可爱，/生理苦已伤。/方知自残者，/为有好文章。

# 浔阳三题并序
原：庐山多桂树，湓浦多修竹，东林寺有白莲华，皆植物之贞劲秀异者，虽宫囿省寺中，未必能尽有。夫物以多为贱，故南方人不贵重之。至有蒸爨其桂，剪弃其竹，白眼于莲花者。予惜其不生于北土也，因赋三题以唁之。

# 庐山桂
诗：偃蹇月中桂，/结根依青天。/天风绕月起，/吹子下人问。
诗：飘零委何处？/乃落匡庐山。/生为石上桂，/叶如剪碧鲜。
诗：枝干日长大，/根荄日牢坚。/不归天上月，/空老山中年。
诗：庐山去咸阳，/道里三四千。/无人为移植，/得人上林园。
诗：不及红花树，/长栽温室前。

# 湓浦竹
诗：浔阳十月天，/天气仍温燠。/有霜不杀草，/有风不落木。
诗：玄冥气力薄，/草木冬犹绿。/谁肯湓浦头，/回眼看修竹？
诗：其有顾眄者，/持刀斩且束。/剖劈青琅玕，/家家盖墙屋。
诗：吾闻汾晋间，/竹少重如玉。/胡为取轻贱？/生此西江曲。

# 东林寺白莲
诗：东林北塘水，/湛湛见底清。/中生白芙蓉，/菡萏三百茎。
诗：白日发光彩，/清飙散芳馨。/泄香银囊破，/泻露玉盘倾。
诗：我惭尘垢眼，/见此琼瑶英。/乃知红莲华，/虚得清净名。
诗：夏萼敷未歇，/秋房结才成。/夜深众僧寝，/独起绕池行。
诗：欲收一颗子，/寄向长安城。/但恐出山去，/人间种不生。

# 大水
诗：浔阳郊郭间，/大水岁一至。/间阎半漂荡，/城堞多倾坠。
诗：苍茫生海色，/渺漫连空翠。/风卷白波翻，/日煎红浪沸。
诗：工商彻屋去，/牛马登山避。/况当率税时，/颇害农桑事。
诗：独有佣舟子，/鼓枻生意气。/不知万人灾，/自觅锥刀利。
诗：吾无奈尔何，/尔非久得志。/九月霜降后，/水涸为平地。
