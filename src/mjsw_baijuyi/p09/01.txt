# 长庆二年七月自中书舍人出守杭州路次蓝溪作
诗：太原一男子，/自顾庸且鄙。/老逢不次恩，/洗拔出泥滓。
诗：既居可言地，/愿助朝廷理。/伏阁三上章，/戇愚不称旨。
诗：圣人存大体，/优贷容不死。/凤诏停舍人，/鱼书除刺史。
诗：置怀齐宠辱，/委顺随行止。/我自得此心，/于兹十年矣。
诗：杭乃名郡，/郡郭临江汜。/已想海门山，/潮声来入耳。
诗：昔予贞元初，/羁旅曾游此。/甚觉太守尊，/亦谙鱼酒美。
诗：因生江海兴，/每羡沧浪水。/尚拟拂衣行，/况今兼禄仕。
诗：青山峰峦接，/白日烟尘起。/东道既不通，/改辕遂南指。
诗：自秦穷楚越，/浩荡五千里。/闻有贤主人，/而多好山水。
诗：是行颇为惬，/所历良可纪。/策马度蓝溪，/胜游从此始。

# 初出城留别
诗：朝从紫禁归，/暮出青门去；/勿言城东陌，/便是江南路。
诗：扬鞭簇车马，/挥手辞亲故。/我生本无乡，/心安是归处。

# 过骆山人野居小池
原：骆生弃官居此二十年
诗：茅覆环堵亭，/泉添方丈沼。/红芳照水荷，/白颈观鱼鸟。
诗：拳石苔苍翠，/尺波烟杳渺。/但问有意无，/勿论池大小。
诗：门前车马路，/奔走无昏晓。/名利驱人心，/贤愚同扰扰。
诗：善哉骆处士，/安置身心了。/何乃独多君？/丘园居者少。

# 宿清源寺
诗：往谪浔阳去，/夜憩辋溪曲。/今为钱塘行，/重经兹寺宿。
诗：尔来几何岁？/溪草二八绿。/不见旧房僧，/苍然新树木。
诗：虚空走日月，/世界迁陵谷。/我生寄其间，/孰能逃倚伏？
诗：随缘又南去，/好住东廊竹。

# 宿蓝桥对月
诗：昨夜凤池头，/今夜蓝溪口。/明月本无心，/行人自回首。
诗：新秋松影下，/半夜钟声后。/清影不宜昏，/聊将茶代酒。

诗：去乡徒自苦，/济世终无益。/自问波上萍，/何如涧中石！

# 秋蝶

# 自蜀江至洞庭湖口有感而作

# 自杭归宿淮口作
诗：为郡已多暇，/犹少勤吏职。/罢郡更安闲，/无所劳心力。
诗：舟行明月下，/夜泊清淮北。/岂止吾一身，/举家同燕息。
诗：三年请禄俸，/颇有衣食。/乃至僮仆间，/皆无冻馁色。
诗：行行弄云水，/步步近乡国。/妻子在我前，/琴书在我侧。
诗：此外吾不知，/于焉心自得。

# 舟中李山人访宿
诗：日暮舟悄悄，/烟生水沉沉。/何以延宿客？/夜酒与秋琴。
诗：来客道门子，/来自嵩高岑。/轩轩举云貌，/豁豁开清襟。
诗：得意言语断，/入玄滋味深。/默然相顾哂，/心适而忘心。

# 洛下卜居
诗：三年典郡归，/所得非金帛。/天竺石两片，/华亭鹤一只。
诗：饮啄供稻梁，/苞裹用茵席。/诚知是劳费，/其奈心爱惜。
诗：远从杭郭，/同到洛阳陌。/下担拂云根，/开笼展霜翮。
诗：贞姿不可杂，/高性宜其适。/遂就无尘坊，/仍求有水宅。
诗：东南得幽境，/树老寒泉碧。/池畔多竹阴，/门前少人迹。
诗：未请中庶禄，/且脱双骖易。/买履道宅价不足，/因以两马偿之。
诗：岂独为身谋？/安吾鹤与石。

# 洛中偶作
原：自此后在东都作
诗：五年职翰林，/四年莅浔阳。/一年巴郡守，/半年南宫郎。
诗：二年直纶阁，/三年刺史堂。/凡此十五载，/有诗千章。
诗：境兴周万象，/土风备四方。/独无洛中作，/能不心恨恨。
诗：今为春宫长，/始来游此乡。/徘徊伊涧上，/睥睨嵩少傍。
诗：遇物辄一咏，/一咏倾一觞。/笔下成释憾，/卷中同补亡。
诗：往往顾自哂，/眼昏须鬓苍。/不知老将至，/犹自放诗狂！

# 赠苏少府
诗：籍甚二十年，/今日方款颜。/相送嵩洛下，/论心杯酒间。
诗：河亚懒出人，/府寮多闭关。/苍发彼此老，/白日寻常闲。
诗：朝欲携手出，/暮思联骑还。/何当挈一榼，/同宿龙门山。

# 移家入新宅
诗：移家人新宅，/罢郡有资。/既可避燥湿，/复免忧寒饥。
诗：疾平未还假，/官闲得分司。/幸有禄俸在，/而无职役羁。
诗：清旦盥漱毕，/开轩卷帘帏。/家人及鸡犬，/随我亦熙熙。
诗：取兴或寄酒，/放情不过诗。/何必苦修道，/此即是无为。
诗：外累信已遣，/中怀时有思。/有思一何远，/默坐低双眉。
诗：十载囚窜客，/万里征戍儿。/春朝锁笼鸟，/冬夜支床龟。
诗：驿马走四蹄，/痛酸无歇期。/硙牛封两目，/阎闭何人知？
诗：谁能脱放去？/四散任所之。/各得适其性，/如吾今日时。

# 琴
诗：置琴曲机上，/慵坐但含情。/何烦故挥弄，/风弦自有声。

# 鹤
诗：人各有所好，/物固无常宜。/谁谓尔能舞，/不如闲立时。

# 自咏
诗：夜镜隐白发，/朝酒发红颜。/可怜假年少，/自笑须臾间。
诗：朱砂贱如土，/不解烧为丹。/玄鬓化为雪，/未闻休得官。
诗：咄哉个丈夫，/心性何堕顽？/但遇诗与酒，/便忘寝与餐。
诗：高声发一吟，/似得诗中仙。/引满饮一盏，/尽忘身外缘。
诗：昔有醉先生，/席地而幕天。/于今居处在，/许我当中眠。
诗：眠罢又一酌，/酌罢又一篇。/回面顾妻子，/生计方落然。
诗：诚知此事非，/又过知非年。/岂不欲自改？/改即心不安。
诗：且向安处去，/其皆老闲。

# 林下闲步寄皇甫庶子
诗：扶杖起病初，/策马立未任。/既懒出门去，/亦无客来寻。
诗：以此遂成闲，/闲步绕园林。/天晓烟景淡，/树寒鸟雀深。
诗：一酌池上酒，/数声竹间吟。/寄言东曹长，/当知幽独心。

# 晏起
诗：鸟鸣庭树上，/日照屋檐时。/老去慵转极，/寒来起尤迟。
诗：厚薄被适性，/高低枕得宜。/神安体稳暖，/此味何人知？
诗：睡足仰头坐，/兀然无所思。/如未凿七窍，/若都遗四肢。
诗：缅想长安客，/早朝霜满衣。/彼此各自适，/不知谁是非。

# 池畔二首
诗：结构池西廊，/疏理池东树。/此意人不知，/欲为待月处。
诗：持刀间密竹，/竹少风来多。/此意人不会，/欲令池有波。

# 春葺新居
诗：江州司马日，/忠州刺史时。/栽松满后院，/种柳荫前墀。
诗：彼皆非吾土，/栽种尚忘疲。/况兹是我宅，/葺執固其宜。
诗：平旦领仆使，/乘春亲指挥。/移花夹暖室，/洗竹覆寒池。
诗：池水变渌色，/池芳动清辉。/寻芳弄水坐，/尽日心熙熙。
诗：一物苟可适，/万缘都若遗。/设如宅门外，/有事吾不知。

# 赠言
诗：捧赢献千金，/彼金何足道。/临觞赠一言，/此言真可宝。
诗：流光我已晚，/适意君不早。/况君春风面，/柔促如芳草。
诗：二十方长成，/三十向衰老。/镜中桃李色，/不得十年好。
诗：胡为坐脉脉，/不肯倾怀抱？

# 泛春池
诗：白蘋湘渚曲，/绿案剡溪口。/各在天一涯，/信美非吾有。
诗：何如此庭内，/水竹交左右。/霜竹百千竿，/烟波六七亩。
诗：泓澄动阶砌，/淡泞映户牖。/蛇皮细有文，/镜面清无垢。
诗：主人过桥来，/双童扶一叟。/恐污清冷波，/尘缨先抖擞。
诗：波上一叶舟，/舟中一樽酒。/酒开舟不系，/去去随所偶。
诗：或绕蒲浦前，/或泊桃岛后。/未拨落杯花，/低冲拂面柳。
诗：半酣迷所在，/倚榜兀回首。/不知此何处，/复是人寰否？
诗：谁知始疏凿，/几主相传受。/杨家去云远，/田氏将非久。
诗：天与爱水人，/终焉落吾手。/此池始杨常侍开凿，/中间田家为主，
诗：予今有之。/蒲浦、桃岛，/皆池上所有。
