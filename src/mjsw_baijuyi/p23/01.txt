# 郡斋旬假命宴呈座客示郡寮
原：自此后在苏州作
诗：公门日两衙，/公假月三旬。/衙用决簿领，/旬以会亲宾。
诗：公多及私少，/劳逸常不均。/况为剧郡长，/安得闲宴频？
诗：下车已三月，/开筵始今晨。/初点军厨突，/一拂郡榻尘。
诗：既备献酬礼，/亦具水陆珍。/萍醅箬溪醋，/水脍松江鳞。
诗：侑食乐悬动，/佐欢妓席陈。/风流吴中客，/佳丽江南人。
诗：歌节点随袂，/舞香遗在茵。/清奏凝未阕，/配颜气已春。
诗：众宾勿遽起，/郡寮且逡巡。/无轻一日醉，/用犒九日勤。
诗：微彼九日勤，/何以治吾民？/微此一日醉，/何以乐吾身？

# 题西亭
诗：朝亦视簿书，/暮亦视簿书。/簿书视未竟，/蟋蟀鸣座隅。
诗：始觉芳岁晚，/复嗟尘务拘。/西园景多暇，/可以少踌躇。
诗：池鸟澹容与，/桥柳高扶疏。/烟蔓袅青薛，/水花披白蕖。
诗：何人造兹亭？/华敞绰有。/四檐轩鸟翅，/复屋罗蜘蛛。
诗：直廊抵曲房，/窜窿深且虚。/修竹夹左右，/清风来徐徐。
诗：此宜宴嘉宾，/鼓瑟吹笙竽。/荒淫即不可，/废旷将何如？
诗：幸有酒与乐，/及时欢且娱。/忽其解郡印，/他人来此居。

# 郡中西园
诗：闲园多芳草，/春夏香靡靡。/深树足佳禽，/旦暮鸣不已。
诗：院门闭松竹，/庭径穿兰芷。/爱彼池上桥，/独来聊徙倚。
诗：鱼依藻长乐，/鸥见人暂起。/有时舟随风，/尽日莲照水。
诗：谁知郡府内，/景物闲如此。/始悟喧静缘，/何尝系远迩？

# 北亭卧
诗：树绿晚阴合，/池凉朝气清。/莲开有佳色，/鹤唳无凡声。
诗：唯此闲寂境，/惬我幽独情。/病假十五日，/十日卧兹亭。
诗：明朝吏呼起，/还复视黎甿。

# 一叶落
诗：烦暑郁未退，/凉飙潜已起。/寒温与盛衰，/递相为表里。
诗：萧萧秋林下，/一叶忽先委。/勿言微摇落，/摇落从此始。

# 崔湖州赠红石琴荐焕如锦文无以答之以诗酬谢
诗：赪锦支绿绮，/韵同相感深。/千年古涧石，/八月秋堂琴。
诗：引出山水思，/助成金玉音。/人间无可比，/比我与君心。

# 九日宴集醉题郡楼兼呈周殷二判官
诗：前年九日杭郡，/呼宾命宴虚白堂。/去年九日到东洛，/今年九日来吴乡。
诗：两边蓬鬓一时白，/三处菊花同色黄。/一日日知添老病，/一年年觉惜重阳。
诗：江南九月未摇落，/柳青蒲绿稻樾香。/姑苏台榭倚苍霭，/太湖山水含清光。
诗：可怜假日好天色，/公门吏静风景凉。/榜舟鞭马取宾客，/扫楼拂席排壶觞。
诗：胡琴铮拟指拨刺，/吴娃美丽眉眼长。/笙歌一曲思凝绝，/金钿再拜光低昂。
诗：日脚欲落备灯烛，/风头渐高加酒浆。/觥盏滟翻菡萏叶，/舞鬟摆落茱萸房。
诗：半酣凭槛起四顾，/七堰八门六十坊。/远近高低寺间出，/东西南北桥相望。
诗：水道脉分棹鳞次，/里闾棋布城册方。/人烟树色无隙罅，/十里一片青茫茫。
诗：自问有何才与政？/高厅大馆居中央。/铜鱼今乃泽国节，/刺史是古吴都王。
诗：郊无戎马郡无事，/门有棨戟腰有章。/盛时倘来合惭愧，/壮岁忽去还感伤。
诗：从事醒归应不可，/使君醉倒亦何妨。/请君停杯听我语，/此语真实非虚狂。
诗：五旬已过不为夭，/七十为期盖是常。/须知菊酒登高会，/从此多无二十场。

# 同微之赠别郭虚舟炼师五十韵
诗：我为江司马，/君为荆判司。/俱当愁悴日，/始识虚舟师。
诗：师年三十，/白皙好容仪。/专心在铅汞，/力工琴棋。
诗：静弹弦数声，/闲饮酒一危。/因指尘土下，/蜉蝣良可悲。
诗：不闻姑射上，/千岁冰雪肌。/不见辽城外，/古今冢累累。
诗：嗟我天地间，/有术人莫知。/得可逃死籍，/不唯走三尸。
诗：授我《参同契》，/其辞妙且微。/六一閟扃鐍，/子午守雄雌。
诗：我读随日悟，/心中了无疑。/黄牙与紫车，/谓其坐致之。
诗：自负因自叹，/人生号男儿。/若不佩金印，/即合翳玉芝。
诗：高谢人间世，/深结山中期。/泥坛方合矩，/铸鼎圆中规。
诗：炉橐一以动，/瑞气红辉辉。/斋心独叹拜，/中夜偷一窥。
诗：二物正诉合，/厥状何怪奇。/绸缪夫妇体。/狎猎鱼龙姿。
诗：简寂馆钟后，/紫霄峰晓时。/心尘未净洁，/火候遂参差。
诗：万寿觊刀圭，/千功失毫厘。/先生弹指起，/姹女随烟飞。
诗：始知缘会间，/阴隲不可移。/药灶今夕罢，/诏书明日追。
诗：追我复追君，/次第承恩私。/官虽小大殊，/同立白玉墀。
诗：我直紫微闼，/手进赏罚词。/君侍玉皇座，/口含生杀机。
诗：直躬易媒孽，/浮俗多瑕疵。/转徙今安在？/越峤吴江湄。
诗：一提支郡印，/一建连帅旗。/何言四百里，/不见如天涯。
诗：秋风旦夕来，/白日西南驰。/雪霜各满鬓，/朱紫徒为衣。
诗：师从庐山洞，/访旧来于斯。/寻君又觅我，/风驭纷逶迤。
诗：帔裾曳黄绢，/须发垂青丝。/逢人但敛手，/问道亦颔颐。
诗：孤云难久留，/十日告将归。/款曲话平昔，/殷勤勉衰羸。
诗：后会杳何许？/前心日磷缁。/俗家无异物，/何以充别资？
诗：素笺一百句，/题附元家诗。/朱顶鹤一只，/与师云间骑。
诗：云间鹤背上，/故情若相思。/时时摘一句，/唱作步虚辞。

# 霓裳羽衣歌
原：和微之
诗：、我昔元和侍宪皇，/曾陪内宴宴昭阳。/千歌百舞不可数，/就中最爱《霓裳舞》。
诗：舞时寒食春风天，/玉钩栏下香桉前。/桉前舞者颜如玉，/不著人家俗衣服。
诗：虹裳霞帔步摇冠，/钿璎累累佩珊珊。/娉婷似不任罗绮，/顾听乐悬行复止。
诗：磬箫筝笛递相搀，/击抚弹吹声逦迤。/凡法曲之初，/众乐不齐，
诗：唯金石丝竹次第发声。/《霓裳》序初亦复如此。/散序六奏未动衣，/阳台宿云慵不飞。
诗：散序六遍无拍，/故不舞也。/中序擘初入拍，/秋竹竿裂春冰坼。
诗：中序始有拍，/亦名拍序。/飘然转旋回雪轻，/嫣然纵送游龙惊。
诗：小垂手后柳无力，/斜曳裾时云欲生。/四句皆《霓裳舞》之初态。/烟蛾敛略不胜态，
诗：风袖低昂如有情。/上元点鬟招萼绿，/王母挥袂别飞琼。/许飞琼、萼绿华，
诗：皆女仙也。/繁音急节十二遍，/跳珠撼玉何铿铮。/《霓裳曲》十二遍而终翔鸾舞了却收翅，
诗：唳鹤曲终长引声。/凡曲将毕，/皆声拍促速；/唯霓裳之末，
诗：长引一声也。/当时乍见惊心目，/凝视谛听殊未足。/一落人间八九年，
诗：耳冷不曾闻此曲。/湓城但听山魈语，/巴峡唯闻杜鹃哭予自江州司马转忠州刺史。/移领钱唐第二年；
诗：始有心情问丝竹。/玲珑箜篌谢好筝，/陈宠莆篥沈平笙。/清弦脆管纤纤手，
诗：教得《霓裳》一曲成。/自玲珑已下，/皆杭之妓名。/虚白亭前湖水畔，
诗：前后只应三度按。/便除庶子抛却来，/闻道如今各星散。/今年五月至苏州，
诗：朝钟暮角催白头。/贪看案牍常侵夜，/不听笙歌直到秋。/秋来无事多闲闷，
诗：忽忆《霓裳》无处问。/闻君部内多乐徒，/问有《霓裳》舞者无？/答云七县十万户，
诗：无人知有《霓裳舞》。/唯寄长歌与我来，/题作《霓裳羽衣谱》。/四幅花笺碧间红，
诗：《霓裳》实录在其中。/千姿万状分明见，/恰与昭阳舞者同。/眼前仿佛睹形质，
诗：昔日今朝想如一。/疑从魂梦呼召来，/似著丹青图写出。/我爱《霓裳》君合知，
诗：发于歌咏形于诗。/君不见我歌云：/惊破《霓裳羽衣曲》《长恨歌》云。/又不见我诗云：
诗：曲爱《霓裳》未拍时钱唐诗云。/由来能事皆有主，/杨氏创声君造谱。/开元中，
诗：西凉府节度杨敬述造。/君言此舞难得人，/须是倾城可怜女。/吴妖小玉飞作烟，
诗：夫差女小玉死后，/形见于王，/其母抱之，/霏微若烟雾散空。
诗：越艳西施化为土。/娇花巧笑久寂寥，/娃馆苎萝空处所。/如君所言诚有是，
诗：君试从容听我语。/若求国色始翻传，/但恐人间废此舞。/妍蚩优劣宁相远？
诗：大都只在人抬举。/李娟张态君莫嫌，/亦拟随宜且教取。/娟、态，
诗：苏妓之名。

# 小童薛阳陶吹觱篥歌
原：和浙西李大夫作
诗：剪削乾芦插寒竹，/九孔漏声五音足。/近来吹者谁得名？/关璀老死李衮生。
诗：衮今又老谁其嗣？/薛氏乐童年十二。/指点之下师授声，/含嚼之间天与气。
诗：润州城高霜月明，/吟霜思月欲发声。/山头江底何悄悄？/猿鸟不喘鱼龙听。
诗：翕然声作疑管裂，/诎然声尽疑刀截。/有时婉软无筋骨，/有时顿挫生棱节。
诗：急声圆转促不断，/轹轹辚辚似珠贯。/缓声展引长有条，/有条直直如笔描。
诗：下声乍坠石沉重，/高。/声忽举云飘萧。/明旦公堂陈宴席，
诗：主人命乐娱宾客。/碎丝细竹徒纷纷，/宫调一声雄出群。/众音锁缕不落道，
诗：有如部伍随将军。/嗟尔阳陶方稚齿，/下手发声已如此。/若教头白吹不休，
诗：但恐声名压关李。

# 啄木曲
诗：莫买宝剪刀，/虚费千金直。/我有心中愁，/知君剪不得。
诗：莫磨解结锥，/虚劳人气力。/我有肠中结，/知君解不得。
诗：莫染红丝线，/徒夸好颜色。/我有双泪珠，/知君穿不得。
诗：莫近红炉火，/炎气徒相逼。/我有两鬓霜，/知君销不得。
诗：刀不能剪心愁，/锥不能解肠结。/线不能穿泪珠，/火不能销鬓雪。
诗：不如饮此神圣杯，/万念千忧一时歇。

# 题灵岩寺
原：寺即吴馆娃宫，鸣屐廊、砚池、采香径，遗迹在焉。
诗：娃宫屐廊寻已倾，/砚池香径又欲平。/二三月时但草绿，/几百年来空月明。
诗：使君虽老颇多思，/携觞领妓处处行。/今愁古恨入丝竹，/一曲《凉州》无限情。
诗：直自当时到今日，/中间歌吹更无声。

# 双石
诗：苍然两片石，/厥状怪且丑。/俗用无所堪，/时人嫌不取。
诗：结从胚浑始，/得自洞庭口。/万古遗水滨，/一朝入吾手。
诗：担异来郡内，/洗刷去泥垢。/孔黑烟痕深，/罅青苔色厚。
诗：老蛟蟠作足，/古剑插为首。/忽疑天上落，/不似人间有。
诗：一可支吾琴，/一可贮吾酒。/峭绝高数尺，/坳泓容一斗。
诗：五弦倚其左，/一杯置其右。/洼樽酌未空，/玉山颓已久。
诗：人皆有所好，/物各求其偶。/渐恐少年场，/不容垂白叟。
诗：回头问双石，/能伴老夫否？/石虽不能言，/许我为三友。

# 宿东亭晓兴

诗：窗声渡残漏，/帘影浮初旭。/头痒晓梳多，/眼昏春睡足。

# 日渐长赠周殷二判官
诗：日渐长，/春尚早。/墙头半露红萼枝，/池岸新铺绿牙草。
诗：蹋草攀枝仰头叹，/何人知此春怀抱。/年颜盛壮名未成，/官职欲高身已老。
诗：万茎白发直堪恨，/一片绯衫何足道。/赖得君来劝一杯，/愁开闷破心头好。

# 花前叹
诗：前岁花前五十二，/今年花前五十五。/岁课年功头发知，/从霜成雪君看取。
诗：五年前，/在杭州有诗云：/“五十二人头似霜”。/几人得老莫自嫌，
诗：樊李吴韦尽成土。/樊绛州宗师、李谏议景俭、吴饶州丹、韦侍郎凯，/皆旧往还，/相次丧逝。
诗：南州桃李北州梅，/且喜年年作花主。/花前置酒谁相劝？/容坐唱歌满起舞。
诗：容、满，/皆妓名也。/欲散重拈花细看，/争知明日无风雨？

# 自咏五首
诗：朝亦随群动，/暮亦随群动。/荣华瞬息间，/求得将何用？
诗：形骸与冠盖，/假合相戏弄。/何异睡著人，/不知梦是梦。
原：又
诗：一家五十口，/一郡十万户。/出为差科头，/人为衣食主。
诗：水旱合心忧，/饥寒须手抚。/何异食蓼虫，/不知苦是苦。
原：又
诗：公私颇多事，/衰惫殊少欢。/迎送宾客懒，/鞭笞黎庶难。
诗：老耳倦声乐，/病口厌杯盘。/既无可恋者，/何以不休官？
原：又
诗：一日复一日，/自问何留滞？/为贪逐日俸，/拟作归田计。
诗：亦须随丰约，/可得无限剂。/若待足始休，/休官在何岁？
原：又
诗：官舍非我庐，/官园非我树。/洛中有小宅，/渭上有别墅。
诗：既无婚嫁累，/幸有归休处。/归去诚已迟，/犹胜不归去。

# 和微之听妻弹别鹤操因为解释其义依韵加四句
诗：义重莫若妻，/生离不如死。/誓将死同穴，/其奈生无子。
诗：商陵迫礼教，/妇出不能止。/舅姑明旦辞，/夫妻中夜起。
诗：起闻双鹤别，/若与人相似。/听其悲唳声，/亦如不得已。
诗：青田八九月，/辽城一万里。/徘徊去住云，/鸣咽东西水。
诗：写之在琴曲，/听者酸心髓。/况当秋月弹，/先入忧人耳。
诗：怨抑掩朱弦，/沉吟停玉指。/一闻无儿叹，/相念两如此。
诗：无儿虽薄命，/有妻偕老矣。/幸免生别离，/犹胜商陵氏。
