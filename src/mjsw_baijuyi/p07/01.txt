# 自题写真
原：时为翰林学士
诗：我貌不自识，/李放写我真。/静观神与骨，/合是山中人。
诗：蒲柳质易朽，/麋鹿心难驯。/何事赤墀上，/五年为侍臣？
诗：况多刚狷性，/难与世同尘。/不惟非贵相，/但恐生祸因。
诗：宜当早罢去，/收取云泉身。

# 遣怀
原：自此后诗在渭村作
诗：寓心身体中，/寓性方寸内。/此身是外物，/何足苦忧爱。
诗：况有假饰者，/华簪及高盖。/此又疏于身，/复在外物外。
诗：操之多惴栗，/失之又悲悔。/乃知名与器，/得丧俱为害。
诗：颓然环堵客，/萝蕙为巾带。/自得此道来；/身穷心甚泰。

# 渭上偶钓
诗：渭水如镜色，/中有鲤与鲂。/偶持一竿竹，/悬钓至其傍。
诗：微风吹钓丝，/袅袅十尺长。/谁知对鱼坐，/心在无何乡。
诗：昔有白头人，/亦钓此渭阳。/钓人不钓鱼，/七十得文王。
诗：况我垂钓意，/人鱼又兼亡。/无机两不得，/但弄秋水光。
诗：兴尽钓亦罢，/归来饮我觞。

# 隐几
诗：身适忘四支，/心适忘是非。/既适又忘适，/不知吾是谁。
诗：百体如槁木，/兀然无所知。/方寸如死灰，/寂然无所思。
诗：今日复明日，/身心忽两遗。/行年三十九，/岁暮日斜时。
诗：四十心不动，/吾今其庶几？

# 春眠
诗：新浴支体畅，/独寝神魄安。/况因夜深坐，/遂成日高眠。
诗：春被薄亦暖，/朝窗深更闲。/却忘人间事，/似得枕上仙。
诗：至适无梦想，/大和难名言。/全胜彭泽醉，/欲敌曹溪禅。
诗：何物呼我觉？/伯劳声关关。/起来妻子笑，/生计春茫然。

# 闲居
诗：空腹一盏粥，/饥食有味。/南檐半床日，/暖卧因成睡。
诗：绵袍拥两膝，/竹几支双臂。/从旦直至昏，/身心一无事。
诗：心足即为富，/身闲乃当贵。/富贵在此中，/何必居高位？
诗：君看裴相国，/金紫光照地。/心苦头尽白，/才年四十四。
诗：乃知高盖车，/乘者多忧畏。

# 夏日
诗：东窗晚无热，/北户凉有风。/尽日坐复卧，/不离一室中。
诗：中心本无系，/亦与出门同。

# 适意二首
诗：十年为旅客，/常有饥寒愁。/三年作谏官，/复多尸素羞。
诗：有酒不暇饮，/有山不得游。/岂无平生志？/拘牵不自由。
诗：一朝归渭上，/泛如不系舟。/置心世事外，/无喜亦无忧。
诗：终日一蔬食，/终年一布裘。/寒来弥懒放，/数日一梳头。
诗：朝睡足始起，/夜酌醉即休。/人心不过适，/适外复何求？
诗：早岁从旅游，/颇谙时俗意。/中年忝班列，/备见朝廷事。
诗：作客诚已难，/为臣尤不易。/况予方且介，/举动多忤累。
诗：直道速我尤，/诡遇非吾志。/胸中十年内，/消尽浩然气。
诗：自从返田亩，/顿觉无忧愧。/蟠木用难施，/浮云心易遂。
诗：悠悠身与世，/从此两相弃。

# 首夏病间
诗：我生来几时？/万有四千日。/自省于其间，/非忧即有疾。
诗：老去虑渐息，/年来病初愈。/忽喜身与心，/泰然两无苦。
诗：况兹孟夏月，/清和好时节。/微风吹夹衣，/不寒复不热。
诗：移榻树阴下，/竟日何所为？/或饮一瓯茗，/或吟两句诗。
诗：内无忧患迫，/外无职役羁。/此日不自适，/何时是适时？

# 晚春沽酒
诗：百花落如雪，/两鬓垂作丝。/春去有来日，/我老无少时。
诗：人生待富贵，/为乐常苦迟。/不如贫贱日，/随分开愁眉。
诗：卖我所乘马，/典我旧朝衣。/尽将沽酒饮，/酩酊步行归。
诗：名姓日隐晦，/形骸日变衰。/醉卧黄公肆，/人知我是谁？

# 兰若寓居
诗：名宦老慵求，/退身安草野。/家园病懒归，/寄居在兰若。
诗：薛衣换簪组，/藜杖代车马。/行止辄自由，/甚觉身萧洒。
诗：晨游南坞上，/夜息东庵下。/人间千万事，/无有关心者。

# 麴生访宿
诗：西斋寂已暮，/摘摘。/知是君宿来，/自拂尘埃席。
诗：村家何所有？/茶果迎来客。/贫静似僧居，/竹林依四壁。
诗：厨灯斜影出，/檐雨声滴。/不是爱闲人，/肯来同此夕？

# 闻庾七左降因咏所怀
诗：我病卧渭北，/君老谪巴东。/相悲一长叹，/薄命与君同。
诗：既叹还自哂，/哂叹两未终。/后心诮前意，/所见何迷蒙？
诗：人生大块间，/如。/鸿毛在风。/或飘青云上，
诗：或落泥涂中。/衮服相天下，/傥来非我通。/布衣委草莽，
诗：偶去非吾穷。/外物不可必，/中怀须自空。/无令快快气，
诗：留滞在心胸。

# 答卜者
诗：病眼昏似夜，/衰鬓飒如秋。/除却须衣食，/平生百事休。
诗：知君善易者，/问我决疑不？/不卜非他故，/人间无所求。

# 归田三首
诗：人生何所欲？/所欲唯两端：/中人爱富贵，/高士慕神仙。
诗：神仙须有籍，/富贵亦在天。/莫恋长安道，/莫寻方丈山。
诗：西京尘浩浩，/东海浪漫漫。/金门不可人，/琪树何由攀？
诗：不如归山下，/如法种春田。
诗：种田计已决，/决意复何如？/卖马买犊使，/徒步归田庐。
诗：迎春治耒耜，/候雨辟菑畬。/策杖田头立，/躬亲课仆夫。
诗：吾闻老农言：/为稼慎在初，/所施不卤莽，/其报必有。
诗：上求奉王税，/下望备家储。/安得放慵惰，/拱手而曳裾？
诗：学农未为鄙，/亲友勿笑。/更待明年后，/自拟执犁锄。
诗：三十为近臣，/腰间鸣珮玉。/四十为野夫，/田中学锄谷。
诗：何言十年内，/变化如此速？/此理固是常，/穷通相倚伏。
诗：为鱼有深水，/为鸟有高木。/何必守一方，/窘然自牵束。
诗：化吾足为马，/吾因以行陆。/化吾手为弹，/吾因以求肉。
诗：形骸为异物，/委顺心犹足。/幸得且归农，/安知不为福？
诗：况吾行欲老，/瞥若风前烛。/孰能俄顷间，/将心系荣辱？

# 秋游原上
诗：七月行已半，/早凉天气清。/清晨起巾栉，/徐步出柴荆。
诗：露杖筇竹冷，/风襟越蕉轻。/闲携弟侄辈，/同上秋原行。
诗：新枣未全赤，/晚瓜有馨。/依依田家叟，/设此相逢迎。
诗：自我到此村，/往来白发生。/村中相识久，/老幼皆有情。
诗：留连向暮归，/树树风蝉声。/是时新雨足，/禾黍夹道青。
诗：见此令人饱，/何必待西成？

# 九日登西原宴望
原：同诸兄弟作
诗：病爱枕席凉，/日高眠未辍。/弟兄呼我起，/今日重阳节。
诗：起登西原望，/怀抱同一豁。/移座就菊丛，/糕酒前罗列。
诗：虽无丝与管，/歌笑随情发。/白日未及倾，/颜酶耳已热。
诗：酒酣四向望，/六合何空阔！/天地自久长；/斯人几时活？
诗：请看原下村，/村人死不歇。/一村四十家，/哭葬无虚月。
诗：指此各相勉，/良辰且欢悦。

# 寄同病者
诗：三十生二毛，/早衰为沉疴。/四十官七品，/拙宦非由他。
诗：年颜日枯槁，/时命日蹉跎。/岂独我如此？/圣贤无奈何。
诗：回观亲旧中，/举目尤可嗟。/或有终老者，/沉贱如泥沙。
诗：或有始壮者，/飘忽如风花。/穷饿与夭促，/不如我者多。
诗：以此反自慰，/常得心平和。/寄言同病者，/回叹且为歌。

# 游蓝田山卜居
诗：脱置腰下组，/摆落心中尘。/行歌望山去，/意似归乡人。
诗：朝蹋玉峰下，/暮寻蓝水滨。/拟求幽僻地，/安置疏慵身。
诗：本性便山寺，/应须旁悟真。

# 村雪夜坐
诗：南窗背灯坐，/风霰暗纷纷。/寂寞深村夜，/残雁雪中闻。

# 东园玩菊
诗：少年昨已去，/芳岁今又阑。/如何寂寞意，/复此荒凉园。
诗：园中独立久，/日淡风露寒。/秋蔬尽芜没，/好树亦凋残。
诗：唯有数丛菊，/新开篱落间。/携觞聊就酌，/为尔一留连。
诗：忆我少小日，/易为兴所牵。/见酒无时节，/未饮已欣然。
诗：近从年长来，/渐觉取乐难。/常恐更衰老，/强饮亦无欢。
诗：顾谓尔菊花，/后时何独鲜？/诚知不为我，/借尔暂开颜。

# 观稼
诗：世役不我牵，/身心常自若。/晚出看田亩，/闲行旁村落。
诗：累累绕场稼，/啧啧群飞雀。/年丰岂独人，/禽鸟声亦乐。
诗：田翁逢我喜，/默起具樽杓。/敛手笑相延，/社酒有残酌。
诗：愧兹勤且敬，/藜杖为淹泊。/言动任天真，/未觉农人恶。
诗：停杯问生事，/夫种妻儿获。/筋力苦疲劳，/衣食长单薄。
诗：自惭禄仕者，/曾不营农作。/饱食无所劳，/何殊卫人鹤？

# 闻哭者
诗：昨日南邻哭，/哭声一何苦！/云是妻哭夫，/夫年二十五。
诗：今朝北里哭，/哭声又何切！/云是母哭儿，/儿年十七八。
诗：四邻尚如此，/天下多夭折。/乃知浮世人，/少得垂白发。
诗：今过四十，/念彼聊自悦。/从此明镜中，/不嫌头似雪。

# 新构亭台示诸弟侄
诗：平台高数尺，/台上结茅茨。/东西疏二牖，/南北开两扉。
诗：芦帘前后卷，/竹簟当中施。/清冷白石枕，/疏凉黄葛衣。
诗：开衿向风坐，/夏日如秋时。/啸傲颇有趣，/窥临不知疲。
诗：东窗对华山，/三峰碧参差；/南檐当渭水，/卧见云帆飞。
诗：仰摘枝上果，/俯折畦中葵。/足以充饥渴，/何必慕甘肥？
诗：况有好群从，/旦夕相追随。

# 自吟拙什因有所怀
诗：懒病每多暇，/暇来何所为？/未能抛笔砚，/时作一篇诗。
诗：诗成淡无味，/多被众人嗤。/上怪落声韵，/下嫌拙言词。
诗：时时自吟咏，/吟罢有所思。/苏州及彭泽，/与我不同时。
诗：此外复谁爱？/唯有元微之。/趁向江陵府，/三年作判司。
诗：相去二千里，/诗成远不知。

# 东陂秋意寄元八
诗：寥落野陂畔，/独行思有。/秋荷病叶上，/白露大如珠。
诗：忽忆同赏地，/曲江东北隅。/秋池少游客，/唯我与君俱。
诗：啼蛩隐红蓼，/瘦马蹋青芜。/当时与今日，/俱是暮秋初。
诗：节物苦相似，/时景亦无。/唯有人分散，/经年不得书。

# 闲居
诗：深闭竹间扉，/静扫松下地。/独啸晚风前，/何人知此意？
诗：看山尽日坐，/枕帙移时睡。/谁能从我游，/使君心无事？

# 咏拙
诗：所禀有巧拙，/不可改者性。/所赋有厚薄，/不可移者命。
诗：我性拙且意，/我命薄且屯。/问我何以知？/所知良有因。
诗：亦曾举两足，/学人踏红尘。/从兹知性拙，/不解转如轮。
诗：亦曾奋六翮，/高飞到青云。/从兹知命薄，/摧落不逡巡。
诗：慕贵而厌贱，/乐富而恶贫。/同出天地间，/我岂异于人？
诗：性命苟如此，/反则成苦辛。/以此自安分，/虽穷每欣欣。
诗：葺茅为我庐，/编蓬为我门。/缝布作袍被，/种谷充盘飧。
诗：静读古人书，/闲钓清渭滨。/优哉复游哉，/聊以终吾身。

# 咏慵
诗：有官慵不选，/有田慵不农。/屋穿慵不葺，/衣裂慵不缝。
诗：有酒慵不酌，/无异樽长空。/有琴慵不弹，/亦与无弦同。
诗：家人告饭尽，/欲炊慵不春。/亲朋寄书至，/欲读慵开封。
诗：常闻嵇叔夜，/一生在慵中。/弹琴复锻铁，/比我未为慵。

# 冬夜
诗：家贫亲爱散，/身病交游罢。/眼前无一人，/独掩村斋卧。
诗：冷落灯火暗，/离披帘幕破。/策策窗户前，/又闻新雪下。
诗：长年渐省睡，/夜半起端坐。/不学坐忘心，/寂寞安可过。
诗：兀然身寄世，/浩然心委化。/如此来四年，/一千三百夜。

# 村中留李三固言宿
诗：平生早游宦，/不道无亲故。/如我与君心，/相知应有数。
诗：春明门前别，/金氏陂中遇。/村酒两三杯，/相留寒日暮。
诗：勿嫌村酒薄，/聊酌论心素。/请君少踟蹰，/系马门前树。
诗：明年身若健，/便拟江湖去。/他日纵相思，/知君无觅处。
诗：后会既茫茫，/今宵君且住。

# 友人夜访
诗：檐间清风簟，/松下明月杯。/幽意正如此，/况乃故人来！

# 游悟真寺诗一百三十韵
诗：元和九年秋，/八月月上弦。/我游悟真寺，/寺在王顺山。
诗：去山四五里，/先闻水潺湲。/自兹舍车马，/始涉蓝溪湾。
诗：手拄青竹杖，/足蹋白石滩。/渐怪耳目旷，/不闻人世喧。
诗：山下望山上，/初疑不可攀。/谁知中有路，/盘折通岩巅。
诗：一息幡竿下，/再休石龛边。/龛间长丈，/门户无扃关。
诗：俯窥不见人，/石发垂若鬟。/惊出白蝙蝠，/双飞如雪翻。
诗：回首寺门望，/青崖夹朱轩。/如擘山腹开，/置寺于其间。
诗：入门无平地，/地窄虚空宽。/房廊与台殿，/高下随峰峦。
诗：岩崿无撮土，/树木多瘦坚。/根株抱石长，/屈曲虫蛇蟠。
诗：松桂乱无行，/四时郁芊芊。/枝梢袅清吹，/韵若风中弦。
诗：日月光不透，/绿阴相交延。/幽鸟时一声，/闻之似寒蝉。
诗：首憩宾位亭，/就坐未及安。/须臾开北户，/万里明豁然。
诗：拂檐虹霏微，/绕栋云回旋。/赤日间白雨，/阴晴同一川。
诗：野绿蔟草树，/眼界吞秦原。/渭水细不见，/汉陵小于拳。
诗：却顾来时路，/萦纡映朱栏。/历历上山人，/一一遥可观。
诗：前对多宝塔，/风铎鸣四端。/栾栌与户牖，/袷恰金碧繁。
诗：云昔迦叶佛，/此地坐涅槃。/至今铁钵在，/当底手迹穿。
诗：西开玉像殿，/白佛森比肩。/抖擞尘埃衣，/礼拜冰雪颜。
诗：叠霜为袈裟，/贯雹为华鬘。/逼观疑鬼功，/其迹非雕镌。
诗：次登观音堂，/未到闻栴檀。/上阶脱双履，/敛足升净筵。
诗：六楹排玉镜，/四座敷金钿。/黑夜自光明，/不待灯烛燃。
诗：众宝互低昂，/碧珮珊瑚幡。/风来似天乐，/相触声珊珊。
诗：白珠垂露凝，/赤珠滴血殷。/点缀佛髻上，/合为七宝冠。
