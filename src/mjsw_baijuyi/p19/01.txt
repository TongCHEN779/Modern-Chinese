# 别桥上竹
诗：穿桥进竹不依行，/恐碍行人被损伤。/我去自惭遗爱少，/不教君得似甘棠。

# 发白狗峡次黄牛峡登高寺却望忠州
诗：白狗次黄牛，/滩如竹节稠。/路穿天地险，/人续古今愁。
诗：忽见千花塔，/因停一叶舟。/畏途常迫促，/静境暂淹留。
诗：巴曲春全尽，/巫阳雨半收。/北归虽引领，/南望亦回头。
诗：昔去悲殊俗，/今来念旧游。/别僧山北寺，/抛竹水西楼。
诗：郡树花如雪，/军厨酒似油。/时时大开口，/自笑忆忠州。

# 棣华驿见杨八题梦兄弟诗
诗：遥闻旅宿梦兄弟，/应为邮亭名棣华。/名作棣华来早晚，/自题诗后属杨家。

# 商山路有感
诗：万里路长在，/六年身始归。/所经多旧馆，/太半主人非。

# 商山路驿桐树昔与微之前后题名处
诗：与君前后多迁谪，/五度经过此路隅。/笑问中庭老桐树，/这回归去免来无？

# 恻恻吟
诗：恻侧复侧恻，/逐臣返乡国。/前事难重论，/少年不再得。
诗：泥涂绛老头斑白，/炎瘴灵均面黎黑。/六年不死却归来，/道著姓名人不识。

# 德宗皇帝挽歌词四首
诗：执象宗玄祖，/贻谋启孝孙。/文高柏梁殿，/礼薄灞陵原。
诗：宫仗辞天阙。/朝仪出国门。/生成不可报。/二十七年恩。
原：又
诗：虞帝南巡后，/殷宗谅闇中。/初辞铸鼎地，/已闭望仙宫。
诗：晓落当陵月，/秋生满旆风。/前星承帝座，/不使北辰空。
原：又
诗：业大承宗祖，/功成付子孙。/睿文诗播乐，/遗训史标言。
诗：节表中和德，/方垂广利恩。/悬知千载后，/理代数贞元。
原：又
诗：梦减三龄寿，/哀延七月期。/寝园愁望远，/宫仗哭行迟。
诗：云日添寒惨，/笳箫向晚悲。/因山有遗诏，/如葬汉文时。

# 昭德王皇后挽歌词
诗：仙去逍遥境，/诗留窈窕章。/春归金屋少，/夜入寿宫长。
诗：凤引曾辞辇，/蚕休昔采桑。/阴灵何处感？/沙麓月无光。

# 太平乐词二首
原：已下七首，在翰林时奉敕撰进。
诗：岁丰仍节俭，/时泰更销兵。/圣念长如此，/何忧不泰平？
原：又
诗：湛露浮尧酒，/薰风起舜歌。/愿同尧舜意，/所乐在人和。

# 小曲新词二首
诗：霁色鲜宫殿，/秋声脆管弦。/圣明千岁乐，/岁岁似今年。
原：又
诗：红裾明月夜，/碧簟早秋时。/好向昭阳宿，/天凉玉漏迟。

# 闺怨词三首
诗：朝憎莺百啭，/夜妒燕双栖。/不惯经春别，/唯知到晓啼。
原：又
诗：珠箔笼寒月，/纱窗背晓灯。/夜来巾上泪，/一半是春冰。
原：又
诗：关山征戍远，/闺阁别离难。/苦战应憔悴，/寒衣不要宽。

# 残春曲
原：禁中口号
诗：禁苑残莺三四声，/景迟风慢暮春情。/日西无事墙阴下，/闲踏宫花独自行。

# 长安春
诗：青门柳枝软无力，/东风吹作黄金色。/街东酒薄醉易醒，/满眼春愁销不得。

# 长乐坡送人赋得愁字
诗：行人南北分征路，/流水东西接御沟。/终日坡前恨离别，/谩名长乐是长愁。

# 独眠吟二首
诗：夜长无睡起阶前，/寥落星河欲曙天。/十五年来明月夜，/何曾一夜不孤眠？
诗：独眠客夜夜，/可怜长寂寂。/就中今夜最愁人，/凉月清风满床席。

# 期不至
诗：红烛清樽久延伫，/出门入门天欲曙。/星稀月落竟不来，/烟柳昵昽鹊飞去。

# 长洲苑
诗：春入长洲草又生，/鹧鸪飞起少人行。/年深不辨娃宫处，/夜夜苏台空月明。

# 忆江柳
诗：曾栽杨柳江南岸，/一别江南两度春。/遥忆青青江岸上，/不知攀折是何人。

# 南浦别
诗：南浦凄凄别，/西风袅袅秋。/一看肠一断，/好去莫回头。

# 三年别
诗：悠悠一别已三年，/相望相思明月天。/肠断青天望明月，/别来三十六回圆。

# 伤春词
诗：深浅檐花千万枝，/碧纱窗外啭黄鹂。/残妆含泪下帘坐，/尽日伤春春不知。

# 后宫词
诗：泪湿罗巾梦不成，/夜深前殿按歌声。/红颜未老恩先断，/斜倚薰笼坐到明。
