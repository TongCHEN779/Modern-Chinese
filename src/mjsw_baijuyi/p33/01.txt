诗：鱼佩葺鳞光照地，/鹘衔瑞带势冲天。/莫嫌鬓上些些白，/金紫由来称长年。

# 蓝田刘明府携酎相过与皇甫郎中卯时同饮醉后赠之
诗：腊月九日暖寒客，/卯时十分空腹杯。/玄晏舞狂乌帽落，/蓝田醉倒玉山颓。
诗：貌偷花色老暂去，/歌蹋《柳枝》春暗来。/不为刘家贤圣物，/愁翁笑口大难开。

# 刘苏州以华亭一鹤远寄以诗谢之
诗：老鹤风姿异，/衰翁诗思深。/素毛如我鬓，/丹顶似君心。
诗：松际雪相映，/鸡群尘不侵。/殷勤远来意，/一只重千金。

# 早春忆苏州寄梦得
诗：吴苑四时风景好，/就中偏好是春天。/霞光曙后殷於火，/水色晴来嫩似烟。
诗：士女笙歌宜月下，/使君金紫称花前。/诚知欢乐堪留恋，/其奈离乡已四年。

# 尝新酒忆晦叔二首
诗：樽里看无色，/杯中动有光。/自君抛我去，/此物共谁尝？
原：二
诗：世上强欺弱，/人间醉胜醒。/自君抛我去，/此语更谁听？

# 负春
诗：病来道士教调气，/老去山僧劝坐禅。/辜负春风杨柳曲，/去年断酒到今年。

# 池上闲吟二首
诗：高卧闲行自在身，/池边六见柳条新。/幸逢尧舜无为日，/得作羲皇向上人。
诗：四皓再除犹且健，/三川罢守未全贫。/莫愁客到无供给，/家酝香浓野菜春。
诗：非庄非宅非兰若，/竹树池亭十亩。/非道非僧非俗吏，/褐裘乌帽闭门居。
诗：梦游信意宁殊蝶？/心乐身闲便是鱼。/虽未定知生与死，/其间胜负两何如？

# 早春招张宾客
诗：久雨初晴天气新，/风烟草树尽欣欣。/虽当冷落衰残日，/还有阳和暖活身。
诗：池色溶溶蓝染水，/花光焰焰火烧春。/商山老伴相收拾，/不用随他年少人。

# 营闲事
诗：自笑营闲事，/从朝到日斜。/浇畦引泉脉，/扫径避兰芽。
诗：暖变墙衣色，/晴催木笔花。/桃根知酒渴，/晚送一瓯茶。

# 感春
诗：老思不禁春，/风光照眼新。/花房红鸟觜，/池浪碧鱼鳞。
诗：倚棹谁为伴？/持杯自问身。/心情多少在？/六十二三人。

# 春池上戏赠李郎中
诗：满池春水何人爱？/唯我回看指似君。/直似接蓝新汁色，/与君南宅染罗裙。

# 玩半开花赠皇甫郎中
原：八年寒食日，池东小楼上作。
诗：勿讶春来晚，/无嫌花发迟。/人怜全盛日，/我爱半开时。
诗：紫蜡粘为蒂，/红苏点作蕤。/成都新夹缬，/梁汉碎燕脂。
诗：树杪真珠颗，/墙头小女儿。/浅深妆驳落，/高下火参差。
诗：蝶戏争香朵，/莺啼选稳枝。/好教郎作伴，/合共酒相随。
诗：醉玩无胜此，/狂嘲更让谁。/犹残少年兴。/未似老人诗。
诗：西日凭轻照，/东风莫杀吹。/明朝应烂熳，/后夜更离披。
诗：林下遥相忆，/樽前暗有期。/衔杯嚼蕊思，/唯我与君知。

# 池边
诗：柳老香丝宛，/荷新钿扇圆。/残春深树里，/斜日小楼前。
诗：醉遣收杯杓，/闲听理管弦。/池边更无事，/看补采莲船。

# 家酿新熟每尝辄醉妻侄等劝令少饮因成长句以谕之
诗：君应怪我朝朝饮，/不说向君君不知。/身上幸无疼痛处，/瓮头正是撇尝时。
诗：刘妻劝谏夫休醉，/王侄分疏叔不痴。/六十三翁头雪白，/假如醒黠欲何为？

# 送常秀才下第东归
诗：东归多旅恨，/西土少知音。/寒食看花眼，/春风落第心。
诗：百忧当二月，/一醉直千金。/到处公卿席，/无辞酒盏深。

# 且游
诗：手里一杯满，/心中百事休。/春应唯仰醉，/老更不禁愁。
诗：弄水回船尾，/寻花信马头。/眼看筋力减，/游得且须游。

# 题王家庄临水柳亭
诗：弱柳缘堤种，/虚亭压水开。/条疑逐风去，/波欲上阶来。
诗：翠羽偷鱼入，/红腰学舞回。/春愁正无绪，/争不尽残杯？

# 题令狐家木兰花
诗：腻如玉指涂朱粉，/光似金刀剪紫霞。/从此时时春梦里，/应添一树女郎花。

# 拜表回闲游
诗：玉佩金章紫花绶，/定夺纻衫藤带白纶巾。/晨兴拜表称朝士，/晚出游山作野人。
诗：达磨传心令息念，/玄元留语遣同尘。/八关净戒斋销日，/一曲狂歌醉送春。
诗：酒肆法堂方丈室，/其间岂是两般身？

# 西街渠中种莲叠石颇有幽致偶题小楼
诗：朱槛低墙上，/清流小阁前。/雇人栽菡萏，/买石造潺谖。
诗：影落江心月，/声移谷口泉。/闲看卷帘坐，/醉听掩窗眠。
诗：路笑淘官水，/家愁费料钱。/是非君莫问，/一对一翛然。

# 晚春闲居杨工部寄诗杨常州寄茶同到因以长句答之
诗：宿醒寂寞眠初起，/春意阑珊日又斜。/劝我加餐因早笋，/恨人休醉是残花。
诗：闷吟工部新来句，/渴饮毗陵远到茶。/兄弟东西官职冷，/门前车马向谁家？

# 玉泉寺南三里涧下多深红踯躅繁艳殊常感惜题诗以示游者
诗：玉泉南涧花奇怪，/不似花丛似火堆。/今日多情唯我到，/每年无故为谁开？
诗：宁辞辛苦行三里，/更与留连饮两杯。/犹有一般辜负事，/不将歌舞管弦来。

# 早服云母散
诗：晓服云英漱井华，/寥然身若在烟霞。/药销日晏三匙饭，/酒渴春深一碗茶。
诗：每夜坐禅观水月，/有时行醉玩风花。/净名事理人难解，/身不出家心出家。

# 三月晦日日晚闻鸟声
诗：晚来林鸟语殷勤，/似惜风光说向人。/遣脱破袍劳报暖，/催沽美酒敢辞贫？
诗：声声劝醉应须醉，/一岁唯残半日春。

# 早夏游平原回

诗：紫蕨行看采，/青梅旋摘尝。/疗饥兼解渴，/一盏冷云浆。

# 宿天竺寺回
诗：野寺经三宿，/都城复一还。/家仍念婚嫁，/身尚系官班。
诗：萧洒秋临水，/沉吟晚下崇山。/长犹未得，/逐日且偷闲。

# 侍中晋公欲到东洛先蒙书问期宿龙门思往感今辄献长句
诗：昔蒙兴化池头，/大和三年春，/居易授宾客公司东来，/特侍中於兴化里池上宴送。
诗：今许龙门潭上期。/聚散但惭长见念，/荣枯安敢道相思？/功成名遂来虽久，
诗：云卧山游去未迟。/闻说风情筋力在，/只如初破蔡州时。

# 奉和晋公侍中蒙除留守行及洛师感悦发中斐然成咏
诗：鸾凤翱翔在寥廓，/貂蝉萧洒出埃尘。/致成尧舜升平代，/收得夔龙强健身。
诗：抛掷功名还史册，/分张欢乐与交亲。/商山老皓虽休去，/终是留侯门下人。

# 送刘吾司马赴任硖州兼寄崔使君

诗：笔砚莫抛留压案，/箪飘从陋也销钱。/郡丞自合当优礼，/何况夷陵太守贤。

# 菩提寺上方晚眺
诗：楼阁高低树浅深，/山光水色瞑沉沉。/嵩烟半卷青绡幕，/伊浪平铺绿绮衾。
诗：飞鸟灭时宜极目，/远风来处好开襟。/谁知不离簪缨内，/长得逍遥自在心。

# 杨柳枝词八首
诗：《六么》《水调》家家唱，/《白雪》《梅花》处处吹。/古歌旧曲君休听，/听取新翻《杨柳枝》。
诗：陶令门前四五树，/亚夫营里百千条。/何似东都正二月，/黄金枝映洛阳桥。
诗：依依袅袅复青青，/勾引清风无限情。/白雪花繁空扑地，/绿丝条弱不胜莺。
诗：红板江桥青酒旗，/馆娃宫暖日斜时。/可怜雨歇东风定，/万树千条各自垂。
诗：苏州杨柳任君夸，/更有钱塘胜馆娃。/若解多情寻小小，/绿杨深处是苏家。
诗：苏家小女旧知名，/杨柳风前别有情。/剥条盘作银环样，/卷叶吹为玉笛声。
诗：叶含浓露如啼眼，/枝袅轻风似舞腰。/小树不禁攀折苦，/乞君留取两三条。
诗：人言柳叶似愁眉，/更有愁肠似柳丝。/柳丝挽断肠牵断，/彼此应无续得期。

# 浪淘沙词六首
诗：一泊沙来一泊去，/一重浪灭一重生。/相揽相淘无歇日，/会教山海一时平！
诗：白浪茫茫与海连，/平沙浩浩四无边。/暮去朝来淘不住，/遂令东海变桑田。
诗：青草湖中万里程，/黄梅雨里一人行。/愁见滩头夜泊处，/风翻暗浪打船声。
诗：借问江潮与海水，/何以君情与妾心？/相恨不如潮有信，/相思始觉海非深！
诗：海底飞尘终有日，/山头化石岂无时？/谁道小郎抛小妇，/船头一去没回期。
诗：随波逐浪到天涯，/迁客生还有几家？/却到帝乡重富贵，/请君莫忘《浪淘沙》！
