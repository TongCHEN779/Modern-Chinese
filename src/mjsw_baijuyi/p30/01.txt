# 府斋感怀酬梦得
原：时初丧崔儿，梦得以诗相安。
诗：云：/“从此期君比琼树，/一枝吹折一枝生。”/故有此落句以报之。
诗：府伶呼唤争先到，/家酝提携动辄随。/合是人生开眼日，/自当年老敛眉时。
诗：丹砂炼作三铢土，/玄发看成一把丝。/劳寄新诗远安慰，/不闻枯树更生枝。

# 斋居
诗：香火多相对，/荤腥久不尝。/黄耆数匙粥，/赤箭一瓯汤。
诗：厚俸将何用？/闲居不可忘。/明年官满后，/拟买雪堆庄。

# 与诸道者同游二室至九龙潭作
诗：喜逢二室游仙子，/厌作三川守土臣。/举手摩挲潭上石，/开襟抖擞府中尘。
诗：他日终为独往客，/今朝未是自由身。/若言尹是嵩山主，/三十六峰应笑人。

# 履道池上作
诗：家池动作经旬别，/松竹禽鱼好在无？/树暗小巢藏巧妇，/渠荒新叶长慈姑。
诗：不因车马时时到，/岂觉林园日日芜。/犹喜春深公事少，/每来花下得踟蹰。

# 六十拜河南尹
诗：六十河南尹，/前途足可知。/老应无处避，/病不与人期。
诗：幸遇芳菲日，/犹当强健时。/万金何假藉，/一盏莫推辞。
诗：流水光阴急，/浮云富贵迟。/人间若无酒，/尽合鬓成丝。

# 重修府西水亭院
诗：因下疏为沼，/随高筑作台。/龙门分水入，/金谷取花栽。
诗：绕岸行初匝，/凭轩立未回。/园西有池位，/留与后人开。

# 与诸公同出城观稼
诗：老尹醉醺醺，/来随年少群。/不忧头似雪，/但喜稼如云。
诗：岁望千箱积，/秋怜五谷分。/何人知帝力？/尧舜正为君。

# 水堂醉卧问杜三十一
诗：闻君洛下住多年，/何处春流最可怜？/为问魏王堤岸下，/何如同德寺门前？
诗：无妨水色堪闲玩，/不得泉声伴醉眠。/那似此堂帘幕底。/连明连夜碧潺湲。

# 岁暮言怀
诗：职与才相背，/心将口自言。/磨铅教切玉，/驱雁遣乘轩。
诗：只合居岩窟，/何因人府门？/年终若无替，/转恐负君恩。

# 座中戏呈诸少年
诗：衰容禁得无多酒，/秋鬓新添几许霜。/纵有风情应淡薄，/假如老健莫夸张。
诗：兴来吟咏从成癖，/饮后酣歌少放狂。/不为倚官兼挟势，/因何入得少年场？

# 雪后早过天津桥偶呈诸客
诗：官桥晴雪晓峨峨，/老尹行吟独一过。/紫绶相辉应不恶，/白须同色复如何。
诗：悠扬短景凋年急，/牢落衰情感事多。/犹赖洛中饶醉客，/时时泥我唤笙歌。

# 新制绫袄成感而有咏
诗：水波文袄造新成，/绫软绵匀温复轻。/晨兴好拥向阳坐，/晚出宜披蹋雪行。
诗：鹤氅毳疏无实事，/木绵花冷得虚名。/宴安往往欢侵夜，/卧稳昏昏睡到明。
诗：百姓多寒无可救，/一身独暖亦何情。/心中为念农桑苦，/耳里如闻饥冻声。
诗：争得大裘长万丈，/与君都盖洛阳城。

# 早春雪后赠洛阳李长官长水郑明府二同年
诗：献岁晴和风景新，/铜驼街郭暖无尘。/府庭共贺三川雪，/县道分行百里春。
诗：朱绂洛阳官位屈，/青袍长水俸钱贫。/有何功德污金紫，/若比同年是幸人。

# 醉吟
诗：醉来忘渴复忘饥，/冠带形骸杳若遗。/耳底斋锺初过后，/心头卯酒未消时。
诗：临风朗咏从人听，/看雪闲行任马迟。/应被众疑公事慢，/承前府尹不吟诗。

# 变法
原：府酒五绝
诗：自惭到府来周岁，/惠爱威棱一事无。/唯是改张官酒法，/渐从浊水作醍醐。

# 招客
诗：日午微风旦暮寒，/春风冷峭雪乾残。/碧毡帐下红炉畔，/试为来尝一盏看。

# 辨味
诗：甘露太甜非正味，/醴泉虽洁不芳馨。/杯中此物何人别？/柔旨之中有典刑。

# 自劝
诗：忆昔羁贫应举年，/脱衣典酒曲江边。/十千一斗犹赊饮，/何况官供不著钱？

# 谕妓
诗：烛泪夜粘桃叶袖，/酒痕春污石榴裙。/莫辞辛苦供欢宴，/老后思量悔煞君。

# 晚归早出
诗：筋力年年减，/风光日日新。/退衙归逼夜，/拜表出侵晨。
诗：何处台无月？/谁家池不春？/莫言无胜地，/自是少闲人。
诗：坐厌推囚案，/行嫌引马尘。/几时辞府印，/却作自由身。

# 南龙兴寺残雪
诗：南龙兴寺春晴后，/缓步徐吟绕四廊。/老趁风花应不称，/闲寻松雪正相当。
诗：吏人引从多乘舆，/宾客逢迎少下堂。/不拟人间更求事，/些些疏懒亦何妨。

# 天宫阁早春
诗：天宫高阁上何频，/每上令人耳目新。/前日晚登缘看雪，/今朝晴望为迎春。
诗：林莺何处吟筝柱，/墙柳谁家晒麴尘。/可惜三月虚作主，/风光不属白头人。

# 履道居三首
诗：莫嫌地窄林亭小，/莫厌贫家活计微。/大有高门锁宽宅，/主人到老不曾归。
诗：东里素帷犹未彻，/南邻丹旒又新悬。/衡门蜗舍自惭愧，/收得身来已五年。
诗：世事平分众所知，/何尝苦乐不相随。/唯耽酒狂歌客，/只有乐

# 和梦得冬日晨兴
诗：漏传初五点，/鸡报第三声。/帐下从容起，/窗间昽明。
诗：照书灯未灭，/暖酒火重生。/理曲弦歌动，/先闻唱《渭城》。

# 雪夜对酒招客
诗：帐小青毡暖，/杯香釀新。/醉怜今夜月，/欢忆去年人。
诗：暗落灯花烬，/闲生草座尘。/殷勤报弦管，/明日有嘉宾。

# 赠晦叔忆梦得
诗：自别崔公四五秋，/因何临老转风流。/归来不说秦中事，/歇定唯谋洛下游。
诗：酒面浮花应是喜，/歌眉敛黛不关愁。/得君更有无厌意，/犹恨樽前欠老刘。

# 醉后重赠晦叔
诗：老伴知君少，/欢情向我偏。/无论疏与数，/相见辄欣然。
诗：各以诗成癖，/俱因酒得仙。/笑回青眼语，/醉并白头眠。
诗：岂是今投分，/多疑宿结缘。/人间更何事，/携手送衰年。

# 睡觉
诗：星河耿耿漏绵绵，/月暗灯微欲曙天。/转枕频伸书帐下，/披裘箕踞火炉前。
诗：老眠早觉常残夜，/病力先衰不待年。/五欲已销诸念息，/世间无境可勾牵。
