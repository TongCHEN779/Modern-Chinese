诗：久阴新霁宜丝管，/苦热初凉入绮罗。/家酝瓶空人客绝，/今宵争奈月明何？

# 南塘暝兴
诗：水色昏犹白，/霞光暗渐无。/风荷摇破扇，/波月动连珠。
诗：蟋蟀啼相应，/鸳鸯宿不孤。/小僮频报夜，/归步尚踟蹰。

# 小宅
诗：小宅里闾接，/疏篱鸡犬通。/渠分南港水，/窗借北家风。
诗：庾信园殊小，/陶潜屋不丰。/何劳问宽窄？/宽窄在心中。

# 谕亲友
诗：适情处处皆安乐，/大底园林胜市朝。/烦闹荣华犹易过，/优闲福禄更难销。
诗：自怜老大宜疏散，/却被交亲叹寂寥。/终日相逢不相见，/两心相去一何遥！

# 龙门送别皇甫泽州赴任韦山人南游
诗：隼旟归洛知何日？/鹤驾还嵩莫过春。/惆怅香山云水冷，/明朝便是独游人。

# 刘苏州寄酿酒糯米李浙东寄杨柳枝舞衫偶因尝酒试衫辄成长句寄谢之
诗：《柳枝》慢踏试双袖，/桑落初香尝一杯。/金屑醅浓吴米酿，/银泥衫稳越娃裁。
诗：舞时已觉愁眉展，/醉后仍教笑口开。/惭愧故人怜寂寞，/三千里外寄欢来。

# 诏授同州刺史病不赴任因咏所怀
诗：同州慵不去，/此意复谁知？/诚爱俸钱厚，/其如身力衰？
诗：可怜病判案，/何似醉吟诗？/劳逸悬相远，/,行藏决不疑。
诗：徒烦人劝谏，/只合自寻思。/白发来无限，/青山去有期。
诗：野心唯怕闹，/家口莫愁饥。/卖却新昌宅，/聊充送老资。

# 寄杨六侍郎
原：时杨初授户部，予不赴同州。
诗：西户最荣君好去，/左冯虽稳我慵来。/秋风一箸鲈鱼脍，/张翰摇头唤不回。

# 韦七自太子宾客再除秘书监以长句贺而饯之
原：往年尝与予同为秘监
诗：离筵莫怆且同欢，/共贺新恩拜旧官。/屈就商山伴麋鹿，/好归芸阁狎鸾。
诗：落星石上苍苔古，/画鹤厅前白露寒。/老监姓名应在壁，/相思试为拂尘看。

# 酒熟忆皇甫十
诗：新酒此时熟，/故人何日来？/自从金谷别，/不见玉山颓。
诗：疏索柳花碗，/寂寥荷叶杯。/今冬问毡帐，/雪里为谁开？

# 九年十一月二十一日感事而作
原：其日独游香山寺
诗：祸福茫茫不可期，/大都早退似先知。/当君自首同归日，/是我青山独往时。
诗：顾索素琴应不暇，/忆牵黄犬定难追。/麒麟作脯龙为醢，/何似泥中曳尾龟？

# 即事重题
诗：重裘暖帽宽毡履；/小阁低窗深地炉。/身稳心安眠未起，/西京朝士得知无？

# 将归渭村先寄舍弟
诗：一年年觉此身衰，/一日日知前事非。/咏月嘲花先要减，/登山临水亦宜稀。
诗：子平嫁娶贫中毕，/元亮田园醉里归。/为报阿连寒食下，/与吾酿酒扫柴扉。

# 看嵩洛有叹
诗：今日看嵩洛，/回头叹世间。/荣华急如水，/忧患大於山。
诗：见苦方知乐，/经忙始爱闲。/未闻笼里鸟，/飞出肯飞还。

# 咏怀
诗：随缘逐处便安闲，/不住朝廷不入山。/心似虚舟浮水上，/身同宿鸟寄林间。
诗：尚平婚嫁了无累，/冯翊符章封却还。/时阿罗初嫁，/及同州官吏放归。
诗：处分贫家残活计，/匹如身后莫相关。

# 咏老赠梦得
诗：与君俱老也，/自问老何如？/眼涩夜先卧，/头慵朝未梳。
诗：有时扶杖出，/尽日闭门居。/懒照新磨镜，/休看小字书。
诗：情於故人重，/迹共少年疏。/唯是闲谈兴，/相逢尚有馀。
