# 新乐府并序
原：序曰：凡九千二百五十二言，断为五十篇。篇无定句，句无定字，系于意，不系于文。首句标其目，卒章显其志，《诗》三百之义也。其辞质而径，欲见之者易谕也。其言直而切，欲闻之者深诫也。其事核而实，使采之者传信也。其体顺而肆，可以播于乐章歌曲也。总而言之，为君、为臣、为民、为物、为事而作，不为文而作也。元和四年为左拾遗时作。
原：《七德舞》，美拨乱陈王业也。《法曲》，美列圣正华声也。《二王后》，明祖宗之意也。《海漫漫》，戒求仙也。《立部伎》，刺雅乐之替也。《华原磬》，刺乐工非其人也。《上阳白发人》，愍怨旷也。《胡旋女》，戒近习也。《新丰折臂翁》，戒边功也。《太行路》，借夫妇以讽君臣之不终也。《司天台》，引古以儆今也。《捕蝗》，刺长吏也。《昆明春水满》，思王泽之广被也。《城盐州》，美圣谟而诮边将也。《道州民》，美贤臣遇明主也。《驯犀》，感为政之难终也。《五弦弹》，恶郑之夺雅也。《蛮子朝》，刺将骄而相备位也。《骠国乐》，欲王化之先迩后远也。《缚戎人》，达穷民之情也。《骊宫高》，美天子重惜人之财力也。《百炼镜》，辨皇王鉴也。《青石》，激忠烈也。《两朱阁》，刺佛寺寝多也。《西凉伎》，刺封疆之臣也。《八骏图》，戒奇物、惩佚游也。《涧底松》，念寒俊也。《牡丹芳》，美天子忧农也。《红线毯》，忧蚕桑之费也。《杜陵叟》，伤农夫之困也。《缭绫》，念女工之劳也。《卖炭翁》，苦宫市也。《母别子》，刺新间旧也。《阴山道》，疾贪虏也。《时世妆》，警戒也。《李夫人》，鉴嬖惑也。《陵园妾》，怜幽闭也。《盐商妇》，恶幸人也。《杏为梁》，刺居处奢也。《井底引银瓶》，止淫奔也。《官牛》，讽执政也。《紫毫笔》，讥失职也。《隋堤柳》，悯亡国也。《草茫茫》，惩厚葬也。《古冢狐》，戒艳色也。《黑潭龙》，疾贪吏也。《天可度》，恶诈人也。《秦吉了》，哀冤民也。《鸦九剑》，思决壅也。《采诗官》，鉴前王乱亡之由也。

原：朔已后，诏郊庙享宴，皆先奏之。

# 法曲歌
诗：法曲法曲歌大定，/积德重熙有庆。/永徽之人舞而咏。/永徽之思，
诗：有贞观之遗风，/故高宗制《一戎大定》乐曲也。/法曲法曲舞霓裳，/政和世理音洋洋。
诗：开元之人乐且康。/《霓裳羽衣曲》起于开元，/盛于天宝也。/法曲法曲歌堂堂，
诗：堂堂之庆垂无疆。/中宗肃宗复鸿业，/唐祚中兴万万叶。/永隆元年，
诗：太常丞李嗣真善审音律，/能知兴衰，/云：/近者乐府有《堂堂》之曲，
诗：再言之者，/唐祚再兴之兆。/法曲法曲合夷歌，/夷声邪乱华声和。
诗：以乱干和天宝末，/明年胡尘犯宫阙。/法曲虽似失雅音，/盖诸夏之声也，
诗：故历朝行焉。/玄宗虽雅好度曲，/然未尝使蕃汉杂奏。/天宝十三载，
诗：始诏道调法曲与胡部新声合作，/识者深异之。/明年冬，/而安禄山反也。
诗：乃知法曲本华风，/苟能审音与政通。/一从胡曲相参错，/不辨兴衰与哀乐。
诗：愿求牙旷正华音，/不令夷夏相交侵。

# 二王后
诗：二王后，/彼何人？/介公酅公为国宾，/周武隋文之子孙。
诗：古人有言天下者，/非是一人之天下。/周亡天下传于隋，/隋人失之唐得之。
诗：唐兴十叶岁二百，/介公酅公世为客。/明堂太庙朝享时，/引居宾位备威仪。
诗：备威仪，/助郊祭，/高祖太宗之遗制。/不独兴灭国，
诗：不独继绝世，/欲令嗣位守文君，/亡国子孙取为戒。

# 海漫漫
诗：海漫漫，/直下无底旁无边；/云涛烟浪最深处，/人传中有三神山。
诗：山上多生不死药，/服之羽化为天仙。/秦皇汉武信此语，/方士年年采药去。
诗：蓬莱今古但闻名，/烟水茫茫无觅处。/海漫漫，/风浩浩，
诗：眼穿不见蓬莱岛。/不见蓬莱不敢归，/童男女舟中老。/徐福文成多诳诞，
诗：上元太一虚祈祷。/君看骊山顶上茂陵头，/毕竟悲风吹蔓草。/何况玄元圣祖五千言，

# 立部伎
原：太常选坐部伎无性识者，退入立部伎。又选立部伎绝无性识者，退入雅乐部。则雅声可知矣。
诗：立部伎，/鼓笛喧。/舞双剑，/跳七丸。
诗：袅巨索，/掉长竿。/太常部伎有等级，/堂上者坐堂下立。
诗：堂上坐部笙歌清，/堂下立部鼓笛鸣。/笙歌一声众侧耳，/鼓笛万曲无人听。
诗：立部贱，/坐部贵。/坐部退为立部伎，/击鼓吹笙和杂戏。
诗：立部又退何所任？/始就乐悬操雅音。/雅音替坏一至此，/长令尔辈调宫徵。
诗：圆丘后土郊祀时，/言将此乐感神祗。/欲望凤来百兽舞，/何异北辕将适楚。
诗：工师愚贱安足云，/太常三卿尔何人！

# 华原磬
原：天宝中，始废泗滨磬，用华原石代之。询诸磬人，则曰：故老云：泗滨磬下调不能和，得华原石考之乃和；由是不改。
诗：华原磬，/华原磬，/古人不听今人听。/泗滨石，
诗：泗滨石，/今人不击古人击。/今人古人何不同，/用之舍之由乐工。
诗：乐工虽在耳如壁，/不分清浊即为聋。/梨园弟子调律吕，/知有新声不如古。
诗：古称浮磬出泗滨，/立辩致死声感人。/宫悬一听华原石，/君心遂忘封疆臣。
诗：果然胡寇从燕起，/武臣少肯封疆死。/始知乐与时政通，/岂听铿锵而已矣。
诗：磬襄入海去不归，/长安市人为乐师。/华原磬与泗滨石，/清浊两声谁得知？

# 上阳白发人
原：天宝五载已后，杨贵妃专宠，后宫人无复进幸矣。六宫有美色者，辄置别所，上阳是其一也。贞元中尚存焉。
诗：上阳人，/红颜暗老白发新。/绿衣监使守宫门，/一闭上阳多少春。
诗：玄宗末岁初选人，/入时十六今六十。/同时采择百人，/零落年深残此身。
诗：忆昔吞悲别亲族，/扶人车中不教哭；/皆云入内便承恩，/脸似芙蓉胸似玉。
诗：未容君王得见面，/已被杨妃遥侧目。/妒令潜配上阳宫，/一生遂向空房宿。
诗：秋夜长，/夜长无寐天不明。/耿耿残灯背壁影，/萧萧暗雨打窗声。
诗：春日迟，/日迟独坐天难暮。/宫莺百啭愁厌闻，/梁燕双栖老休妒。
诗：莺归燕去长悄然，/春往秋来不记年。/唯向深宫望明月，/东西四五百回圆。
诗：今日宫中年最老，/大家遥赐尚书号。/小头鞋履窄衣裳，/青黛点眉眉细长。
诗：外人不见见应笑，/天宝末年时世妆。/上阳人，/苦最多，
诗：少亦苦，/老亦苦。/少苦老苦两如何？/君不见昔时吕向《美人赋》，
诗：天宝末，/有密采艳色者，/当时号花鸟使。/吕向献《美人赋》以讽之。
诗：又不见今日上阳白发歌。

# 胡旋女
原：天宝末康居国献之
诗：胡旋女，/胡旋女，/心应弦，/手应鼓。
诗：弦鼓一声双袖举，/回雪飘飘转蓬舞。/左旋右转不知疲，/千匝万周无已时。

诗：五十年来制不禁。/胡旋女，/莫空舞；/数唱此歌悟明主。

# 新丰折臂翁
诗：新丰老翁八十八，/头鬓眉须皆似雪。/玄孙扶向店前行，/左臂凭肩右臂折。
诗：问翁臂折来几年？/兼问致折何因缘？/翁云贯属新丰县，/生逢圣代无征战。
诗：惯听梨园歌管声，/不识旗枪与弓箭。/无何天宝大征兵，/户有三丁点一丁。
诗：点得驱将何处去，/五月万里云南行。/闻道云南有泸水，/椒花落时瘴烟起。
诗：大军徒涉水如汤，/未过十人二三死。/村南村北哭声哀，/儿别爷娘夫别妻。
诗：皆云前后征蛮者，/千万人行无一回。/是时翁年二十四，/兵部牒中有名字。
诗：夜深不敢使人知，/偷将大石锤折臂。/张弓簸旗俱不堪，/从兹始免征云南。
诗：骨碎筋伤非不苦，/且图拣退归乡土。/臂折来来六十年，/一肢虽废一身全。
诗：至今风雨阴寒夜，/直到天明痛不眠。/痛不眠，/终不悔，
诗：且喜老身今独在。/不然当时泸水头，/身死魂飞骨不收。/应作云南望乡鬼，
诗：万人冢上哭呦呦。/云南有万人冢，/即鲜于仲通、李宓曾覆军之所也。/老人言，
诗：君听取。/君不闻开元宰相宋开府，/不赏边功防黩武。/开元初，
诗：突厥数寇边，/时天武军子将郝云岑出使，/因引特勒回鹘部落，/斩突厥默啜，
诗：献首于阙下，/自谓有不世之功。/时宋璟为相，/以天子年少好武，
诗：恐徼功者生心，/痛抑其党。/逾年，/始授郎将。
诗：云岑遂恸哭呕血而死也。/又不闻天宝宰相杨国忠，/欲求恩幸立边功。/边功未立生人怨，
诗：请问新丰折臂翁。/天宝末，/杨国忠为相，/重结阁罗凤之役，
诗：募人讨之，/前后发二十万众，/去无返者。/又捉人连枷赴役，
诗：天下怨哭，/人不聊生，/故禄山得乘人心而盗天下。/元和初，
诗：而折臂翁犹存，/因备歌之。

# 太行路
诗：太行之路能摧车，/若比人心是坦途。/巫峡之水能覆舟，/若比人心是安流。
诗：人心好恶苦不常，/好生毛羽恶生疮。/与君结发未五载，/岂期牛女为参商。
诗：古称色衰相弃背，/当时美人犹怨悔。/何况如今鸾镜中，/妾颜未改君心改。
诗：为君薰衣裳，/君闻兰麝不馨香。/为君盛容饰，/君看金翠无颜色。
诗：行路难，/难重陈。/人生莫作妇人身，/百年苦乐由他人。
诗：行路难，/难于山，/险于水。/不独人间夫与妻，
诗：近代君臣亦如此。/君不见，/左纳言，/右纳史，
诗：朝承恩，/暮赐死。/行路难，/不在水，
诗：不在山；/只在人情反覆间。

# 司天台

诗：昔闻西汉元成间，/上陵下替谪见天。/北辰微暗少光色，/四星煌煌如火赤。
诗：耀芒动角射三台，/上台半灭中台坼。/是时非无太史官，/眼见心知不敢言。
诗：明朝趋入明光殿，/唯奏庆云寿星见。/天文时变两如斯，/九重天子不得知。
诗：不得知，/安用台高百尺为？

# 捕蝗
诗：捕蝗捕蝗谁家子？/天热日长饥欲死。/兴元兵久伤阴阳，/和气蛊蠹化为蝗。
诗：始自两河及三辅，/荐食如蚕飞似雨。/雨飞蚕食千里间，/不见青苗空赤土。
诗：河南长吏言忧农，/课人昼夜捕蝗虫。/是时粟斗钱三百，/蝗虫之价与粟同。
诗：捕蝗捕蝗竟何利，/徒使饥人重劳费。/一虫虽死百虫来，/岂将人力竞天灾。
诗：我闻古之良吏有善政，/以政驱蝗蝗出境。/又闻贞观之初道欲昌，/文皇仰天吞一蝗。
诗：一人有庆兆民赖，/是岁虽蝗不为害。/贞观二年，/太宗吞蝗虫，
诗：事具《贞观实录》。

# 昆明春水满

诗：贫人又获菰蒲利。/诏以昆明近帝城，/官家不得收其征。/菰蒲无租鱼无税，
诗：近水之人感君惠。/感君惠，/独何人？/吾闻率土皆王民，
诗：远民何疏近何亲？/愿推此惠及天下，/无远无近同欣欣。/吴兴山中罢榷茗，
诗：鄱阳坑里休封银。/天涯地角无禁利，/熙熙同似昆明春。

# 城盐州
原：贞元壬申岁特诏城之
诗：城盐州，/城盐州，/城在五原原上头。/蕃东节度钵阐布，
诗：忽见新城当要路。/金鸟飞传赞普闻，/建牙传箭集群臣。/君臣赭面有忧色，
诗：皆言勿谓唐无人。/自筑盐州十载，/左衽毡裘不犯塞。/昼牧牛羊夜捉生，
诗：长去新城百里外。/诸边急警劳戍人，/唯此一道无烟尘。/灵夏潜安谁复辨？
诗：秦原暗通何处见？/鄜州驿路好马来，/长安药肆黄蓍贱。/城盐州，
诗：盐州未城天子忧。/德宗按图自定计，/非关将略与庙谋。/吾闻高宗中宗世，
诗：北虏猖狂最难制。/韩公创筑受降城，/三城鼎峙屯汉兵。/东西亘绝数千里，
诗：耳冷不闻胡马声。/如今边将非无策，/心笑韩公筑城壁。/相看养寇为身谋，
诗：各握强兵固恩泽。/愿分今日边将恩，/褒赠韩公封子孙。/谁能将此盐州曲，
诗：翻作歌词闻至尊。

# 道州民
诗：道州民，/多侏儒，/长者不过三尺。/市作矮奴年进送，
诗：号为道州任土贡。/任土贡，/宁若斯？/不闻使人生别离，
诗：老翁哭孙母哭儿。/一自阳城来守郡，/不进矮奴频诏问。/城云臣按六典书，
诗：任土贡有不贡无。/道州水土所生者，/只有矮民无矮奴。/吾君感悟玺书下，
诗：岁贡矮奴宜悉罢。/道州民，/老者幼者何欣欣！/父兄子弟始相保，
诗：从此得作良人身。/道州民，/民到于今受其赐，/欲说使君先下泪。
诗：仍恐儿孙忘使君，/生男多以阳为字。

# 驯犀
原：贞元丙子岁，南海进驯犀，诏纳苑中。至十三年冬，大寒，驯犀死矣。
诗：驯犀驯犀通天犀，/躯貌骇人角骇鸡。/海蛮闻有明天子，/驱犀乘传来万里。
诗：一朝得谒大明宫，/欢呼拜舞自论功。/五年驯养始堪献，/六译语言方得通。
诗：上嘉人兽俱来远，/蛮馆四方犀入苑。/铢以瑶萏锁以金，/故乡迢递君门深。
诗：海鸟不知钟鼓乐，/池鱼空结江湖心。/驯犀生处南方热，/秋无白露冬无雪。
诗：一人上林三四年，/又逢今岁苦寒月。/饮冰卧霰苦跪局，/角骨冻伤鳞甲缩。
诗：驯犀死，/蛮儿啼，/向阙再三颜色低。/奏乞生归本国去，
诗：恐身冻死似驯犀。/君不见建中初，/驯象生还放林邑？/建中元年，
诗：诏尽出苑中驯象，/放归南方也。/君不见贞元末，/驯犀冻死蛮儿泣？
诗：所嗟建中异贞元，/象生犀死何足言！

# 五弦弹
诗：五弦弹，/五弦弹，/听者倾耳心寥寥。/赵璧知君入骨爱，
诗：五弦一一为君调。/第一第二弦索索，/秋风拂松疏韵落。/第三第四弦泠泠，
诗：夜鹤忆子笼中鸣。/第五弦声最掩抑，/陇水冻咽流不得。/五弦并奏君试听，
诗：凄凄切切复铮铮。/铁击珊瑚一两曲，/水写玉盘千万声。/杀声人耳肤血寒，
诗：惨气中人肌骨酸。/曲终声尽欲半日，/四座相对愁无言。/座中有一远方士，
诗：唧唧咨咨声不已。/自叹今朝初得闻，/始知孤负平生耳。/唯忧赵璧白发生，
诗：老死人间无此声。/远方士，/尔听五弦信为美，/吾闻正始之音不如是。
诗：正始之音其若何？/朱弦疏越清庙歌。/一弹一唱再三叹，/曲淡节稀声不多。
诗：融融曳曳召元气，/听之不觉心平和。/人情重今多贱古，/古琴有弦人不抚。
诗：更从赵璧艺成来，/二十五弦不如五。

# 蛮子朝
诗：蛮子朝，/泛皮船兮渡绳桥，/来自巂州道路遥。/人界先经蜀川过，
诗：蜀将收功先表贺。/臣闻云南六诏蛮，/东连样柯西连蕃。/六诏星居初琐碎，
诗：合为一诏渐强大。/开元皇帝虽圣神，/唯蛮倔强不来宾。/鲜于仲通六万卒，
诗：征蛮一阵全军没。/至今西洱河岸边，/箭孔刀痕满枯骨。/天宝十三载，
诗：鲜于仲通统兵六万讨云南王阎罗凤于西洱河，/全军覆殁也。/谁知今日慕华风，/不劳一人蛮自通。
诗：诚由陛下休明德，/亦赖微臣诱谕功。/德宗省表知如此，/笑令中使迎蛮子。
诗：蛮子导从者谁何？/摩挲俗羽双隈伽。/清平官持赤藤杖，/大将军系金哒嗟。
诗：异牟寻男寻阁劝，/特敕召对延英殿。/上心贵在怀远蛮，/引临玉座近天颜。
诗：冕旒不垂亲劳保，/赐衣赐食移时对。/移时对，/不可得，
诗：大臣相看有羡色。/可怜宰相拖紫佩金章，/朝日唯闻对一刻。

# 骠国乐
原：贞元十七年来献之
诗：骠国乐，/骠国乐，/出自大海西南角。/雍羌之子舒难陁，
诗：来献南音奉正朔。/德宗立仗御紫庭，/蛀纩不塞为尔听。/玉螺一吹椎髻耸，
诗：铜鼓千击文身踊。/珠缨炫转星宿摇，/花鬘斗薮龙蛇动。/曲终王子启圣人，
诗：臣父愿为唐外臣。/左右欢呼何翕习，/皆尊德广之所及。/须臾百辟诣阁门，
诗：俯伏拜表贺至尊。/伏见骠人献新乐，/请书国史传子孙。/时有击壤老农父，
诗：暗测君心闲独语。/闻君政化甚圣明，/欲感人心致太平。/感人在近不在远，
诗：太平由实非由声。/观身理国国可济，/君如心兮民如体。/体生疾苦心憯凄，
诗：民得和平君恺悌。/贞元之民若未安，/骠乐虽闻君不欢。/贞元之民苟无病，
诗：骠乐不来君亦圣。/骠乐骠乐徒喧喧，/不如闻此刍尧言。

# 缚戎人
诗：缚戎人，/缚戎人，/耳穿面破驱入秦。/天子矜怜不忍杀，
诗：诏徙东南吴与越。/黄衣小使录姓名，/领出长安乘递行。/身被金疮面多瘠，
诗：扶病徒行日一驿。/朝餐饥渴费杯盘，/夜卧腥臊污床席。/忽逢江水忆交河，
诗：垂手齐声鸣咽歌。/其中一虏语诸虏，/尔苦非多我苦多。/同伴行人因借问，
诗：欲说喉中气愤愤。/自云乡管本凉原，/大历年中没落蕃。/一落蕃中四十载，
诗：遣著皮裘系毛带。/唯许正朝服汉仪，/敛衣整巾潜泪垂。/誓心密定归乡计，
诗：不使蕃中妻子知。/有李如暹者，/蓬子将军之子也。/尝没蕃中，
诗：自云：/蕃法，/唯正岁一日，/许唐人之没蕃者，
诗：服唐衣冠，/由是悲不自胜，/遂密定归计也。/暗思幸有残筋力，
诗：更恐年衰归不得。/蕃候严兵鸟不飞，/脱身冒死奔逃归。/昼伏宵行经大漠，
诗：云阴月黑风沙恶。/惊藏青冢寒草疏，/偷渡黄河夜冰薄。/忽闻汉军鼙鼓声，
诗：路傍走出再拜迎。/游骑不听能汉语，/将军遂缚作蕃生。/配向江南卑湿地，
诗：定无存恤空防备。/念此吞声仰诉天，/若为辛苦度残年！/凉原乡井不得见，
诗：胡地妻儿虚弃捐。/没蕃被囚思汉土，/归汉被劫为蕃虏。/早知如此悔归来，
诗：两地宁如一处苦！/缚戎人，/戎人之中我苦辛。/自古此冤应未有，
诗：汉心汉语吐蕃身。
