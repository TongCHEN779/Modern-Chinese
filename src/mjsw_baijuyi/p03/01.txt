# 续古诗十首
诗：戚戚复戚戚，/送君远行役。/行役非中原，/海外黄沙碛。
诗：伶俜独居妾，/迢递长征客。/君望功名归，/妾忧生死隔。
诗：谁家无夫妇？/何人不离拆？/所恨薄命身，/嫁迟别日迫。
诗：妾身有存殁，/妾心无改易。/生作闺中妇，/死作山头石。
诗：掩泪别乡里，/飘飘将远行。/茫茫绿野中，/春尽孤客情。
诗：驱马上丘城，/高低路不平。/风吹棠梨花，/啼鸟时一声。
诗：古墓何代人，/不知姓与名。/化作路傍土，/年年春草生。
诗：感彼忽自悟，/今我何营营。
诗：朝采山上薇，/暮采山上薇。/岁晏薇亦尽，/饥来何所为。
诗：坐饮白石水，/手把青松枝。/击节独长歌，/其声清且悲。
诗：枥马非不肥，/所苦长紫维。/豢豕非不饱，/所忧竟为牺。
诗：行行歌此曲，/以慰常苦饥。
诗：雨露长纤草，/山苗高入云。/风雪折劲木，/涧松摧为薪。
诗：风摧此何意？/雨长彼何因？/百丈涧底死，/寸茎山上春。
诗：可怜苦节士，/感此涕盈巾。
诗：窈窕双鬟女，/容德俱如玉。/昼居不逾阈，/夜行常秉烛。
诗：气如含露兰，/心如贯霜竹。/宜当备嫔御，/胡为守幽独。
诗：无媒不得选，/年忽过三六。/岁暮望汉宫，/谁在黄金屋。
诗：邯郸进倡女，/能唱黄花曲。/一曲称君心，/恩荣连九旗。
诗：栖栖远方士，/读书三十年。/业成无知己，/徒步来入关。
诗：长安多王侯，/英俊竞攀援。/幸随众宾末，/得厕门馆间。
诗：东阁有旨酒，/中堂有管弦。/何为向隅客，/对此不开颜？
诗：富贵无是非，/主人终日欢。/贫贱多悔尤，/客子中夜叹。
诗：归去复归去，/故乡贫亦安。
诗：凉风飘嘉树，/日夜减芳华。/下有感秋妇，/攀条苦悲嗟。
诗：我本幽闲女，/结发事豪家。/豪家多婢仆，/门内颇骄奢。
诗：良人近封侯，/出入鸣玉珂。/自从富贵来，/恩薄谗言多。
诗：冢妇独守礼，/群妾互奇邪。/但信言有玷，/不察屯、无瑕。
诗：容光未销歇，/欢爱忽蹉跎。/何意掌上玉，/化为眼中砂。
诗：盈盈一尺水，/浩浩千丈河。/勿言小大异，/随分有风波。
诗：闺房犹复尔，/邦国当如何？
诗：心亦无所迫，/身亦无所拘。/何为肠中气，/郁郁不得舒。
诗：不舒良有以，/同心久离居。/五年不见面，/三年不得书。
诗：念此令人老，/抱膝坐长吁。/岂无盈樽酒，/非君谁与娱。
诗：揽衣出门行，/游观绕林渠。/澹澹春水暖，/东风生绿蒲。
诗：上有和鸣雁，/下有掉尾鱼。/飞沉一何乐，/鳞羽各有徒。
诗：而我方独处，/不与之子俱。/顾彼自伤己，/禽鱼之不如。
诗：出游欲遣忧，/孰知忧有。
诗：春旦日初出，/瞳瞳耀晨辉。/草木照未远，/浮云已蔽之。
诗：天地黯以晦，/当午如昏时。/虽有东南风，/力微不能吹。
诗：中园何所有？/满地青青葵。/阳光委云上，/倾心欲何依。

# 秦中吟十首并序
原：贞元、元和之际，予在长安，闻见之间，有足悲者。因直歌其事，命为《秦中吟》。

# 议婚
诗：天下无正声，/悦耳即为娱。/人间无正色，/悦目即为姝。
诗：颜色非相远，/贫富则有殊。/贫为时所弃，/富为时所趋。
诗：红楼富家女，/金缕绣罗襦。/见人不敛手，/娇痴二八初。
诗：母兄未开口，/已嫁不须臾。/绿窗贫家女，/寂寞二十。
诗：荆钗不直钱，/衣上无真珠。/几回人欲聘，/临日又踟蹰。
诗：主人会良媒，/置酒满玉壶。/四座且勿饮，/听我歌现歌途：
诗：富家女易嫁，/嫁早轻其夫；/贫家女难嫁，/嫁晚孝于姑。
诗：闻君欲娶妇，/娶妇意何如？

# 重赋
诗：厚地植桑麻，/所要济生民。/生民理布帛，/所求活一身。
诗：身外充征赋，/上以奉君亲。/国家定两税，/本意在忧人。
诗：厥初防其淫，/明敕内外臣。/税外加一物，/皆以枉法论。
诗：奈何岁月久，/贪吏得因循。/浚我以求宠，/敛索无冬春。
诗：织绢未成匹，/缲丝未盈斤。/里胥迫我纳，/不许暂逡巡。
诗：岁暮天地闭，/阴风生破村。/夜深烟火尽，/霰雪白纷纷。
诗：幼者形不蔽，/老者体无温。/悲端与寒气，/并入鼻中辛。
诗：昨日输残税，/因窥官库门。/缯帛如山积，/丝絮似云屯。
诗：号为羡物，/随月献至尊。/夺我身上暖，/买尔跟前恩。
诗：进入琼林库，/岁久化为尘。

# 伤宅
诗：谁家起甲第，/朱门大道边。/丰屋中栉比，/高墙外回环。
诗：累累六七堂，/栋宇相连延。/一堂费百万，/郁郁起青烟。
诗：洞房温且清，/寒暑不能忏。/高堂虚且迥，/坐卧见南山。
诗：绕廊紫藤架，/夹砌红药栏。/攀枝摘樱桃，/带花移牡丹。
诗：主人此中坐，/十载为大官。/厨有臭败肉，/库有贯朽钱。
诗：谁能将我语，/问尔骨肉间。/岂无穷贱者，/忍不救饥寒。
诗：如何奉一身，/直欲保千年。/不见马家宅，/今作奉诚园。

# 伤友
原：又云伤苦节士
诗：陋巷孤寒士，/出门苦栖栖。/虽云志气在，/岂免颜色低。
诗：平生同门友，/通籍在金闺。/曩者胶漆契，/迩来云雨睽。
诗：正逢下朝归，/轩骑五门西。/是时天久阴，/三日雨凄凄。
诗：蹇驴避路立，/肥马当风嘶。/回头忘相识，/占道上沙堤。
诗：昔年洛阳社，/贫贱相提携。/今日长安道，/对面隔云泥。
诗：近日多如此，/非君独惨凄。/死生不变者，/唯闻任与黎。
诗：任公叔、黎逢。

# 不致仕
诗：七十而致仕，/礼法有明文。/何乃贪荣者，/斯言如不闻。
诗：可怜八九十，/齿堕双眸昏。/朝露贪名利，/夕阳忧子孙。
诗：挂冠顾翠绥，/悬车惜朱轮。/金章腰不胜，/伛偻入君门。
诗：谁不爱富贵？/谁不恋君恩？/年高须告老，/名遂合退身。
诗：少时共嗤诮，/晚岁多因循。/贤哉汉二疏，/彼独是何人？
诗：寂寞东门路，/无人继去尘。

# 立碑
诗：勋德既下衰，/文章亦陵夷。/但见山中石，/立作路旁碑。
诗：铭勋悉太公，/叙德皆仲尼。/复以多为贵，/千言直万资。
诗：为文彼何人？/想见下笔时。/但欲愚者悦，/不思贤者嗤。
诗：岂独贤者嗤，/仍传后代疑。/古石苍苔字，/安知是愧词。
诗：我闻望江县，/麴令抚惸嫠。/麴令名信陵。/在官有仁政，
诗：名不闻京师。/身殁欲归葬，/百姓遮路歧。/攀辕不得归，
诗：留葬此江湄。/至今道其名，/男女涕皆垂。/无人立碑碣，
诗：唯有邑人知。

# 轻肥
诗：意气骄满路，/鞍马光照尘。/借问何为者？/人称是内臣。
诗：朱绂皆大夫，/紫绶或将军。/夸赴军中宴，/走马去如云。
诗：樽罍溢九酝，/水陆罗八珍。/果擘洞庭橘，/绘切天池鳞。
诗：食饱心自若，/酒酣气益振。/是岁江南旱，/衢州人食人。

# 五弦
诗：清歌且罢唱，/红袂亦停舞。/赵叟抱五弦，/宛转当胸抚。
诗：大声粗若散，/飒飒风和雨。/小声细欲绝，/切切鬼神语。
诗：又如鹊报喜，/转作猿啼苦。/十指无定音，/颠倒宫徵羽。
诗：坐客闻此声，/形神若无主。/行客闻此声，/驻足不能举。
诗：嗟嗟俗人耳，/好今不好古。/所以绿窗琴，/日日生尘土。

# 歌舞
诗：秦中岁云暮，/大雪满皇州。/雪中退朝者，/朱紫尽公侯。
诗：贵有风云兴，/富无饥寒忧。/所营唯第宅，/所务在追游。
诗：朱轮车马客，/红烛歌舞楼。/欢酣促密坐，/醉暖脱重裘。
诗：秋官为主人，/廷尉居上头。/日中为一乐，/夜半不能休。
诗：岂知阌乡狱，/中有冻死囚。

# 买花
诗：帝城春欲暮，/喧喧车马度。/共道牡丹时，/相随买花去。
诗：贵贱无常价，/酬直看
诗：花数。/灼灼百朵红，/戈戈五束素。/上张幄幕庇，
诗：旁织笆篱护。/水洒复泥封，/移来色如故。/家家习为俗，
诗：人人迷不悟。/有一田舍翁，/偶来买花处。/低头独长叹，
诗：此叹无人谕。/一丛深色花，/十户中人赋。

# 赠友五首并序
原：吾友有王佐之才者，以致君济人为己任，识者深许之，因赠是诗，以广其志云。
诗：一年十二月，/每月有常令。/君出臣奉行，/谓之握金镜。
诗：由兹六气顺，/以遂万物性。/时令一反常，/生灵受其病。
诗：周汉德下衰，/王风始不竞。/又从斩晁错，/诸侯益强盛。
诗：百里不同禁，/四时自为政。/盛夏兴土功，/方春剿人命。
诗：谁能救其失？/待君佐邦柄。/峨峨象魏门，/悬法彝伦正。
诗：银生楚山曲，/金生鄱溪滨。/南人弃农业，/求之多苦辛。
诗：披砂复凿石，/砣矻无冬春。/手足尽皴胝。/爱利不爱身。
诗：畲田既慵斫，/稻田亦懒耘。/相携作游手，/皆道求金银。
诗：毕竟金与银，/何殊泥与尘？/且非衣食物，/不济饥寒人。
诗：弃本以趋末，/日富而岁贫。/所以先圣王，/弃藏不为珍。
诗：谁能反古风？/待君秉国钧。/捐金复抵璧，/勿使劳生民。
诗：私家无钱炉，/平地无铜山。/胡为秋夏税，/岁岁输铜钱？
诗：钱力日已重，/农力日已弹。/贱粜粟与麦，/贱贸丝与绵。
诗：岁暮衣食尽，/焉得无饥寒？/吾闻国之初，/有制垂不刊。
诗：佣必算丁口，/租必计桑田。/不求土所无，/不强人所难。
诗：量入以为出，/上足下亦安。/兵兴一变法，/兵息遂不还。
诗：使我农桑人，/憔悴畎亩间。/谁能革此弊？/待君秉利权。
诗：复彼租佣法，/令如贞观年。
诗：京师四方则，/王化之本根。/长吏久于政，/然后风教敦。
诗：如何尹京者，/迁次下、逡巡。/请君屈指数，/十年十五人。
诗：科条日相矫，/吏力亦以勤。/宽猛政不一，/民心
诗：安得淳？/九州雍为首，/群牧之所遵。/天下率如此，
诗：何以安吾民？/谁能变此法？/待君赞弥纶。/慎择循良吏，
诗：令其长子孙。
诗：三十男有室，/二十女有归。/近代多离乱，/婚姻多过期。
诗：嫁娶既不早，/生育常苦迟。/儿女未成人，/父母已衰羸。
诗：凡人贵达日，/多在长大时。/欲报亲不待，/孝心无所施。
诗：哀哉三牲养，/少得及庭闱。/惜战万钟粟，/多用饱妻儿。
诗：谁能正婚礼？/待君张国维。/庶使孝子心，/皆无风树悲。

# 寓意诗五首
诗：.豫樟生深山，/七年而后知。/挺高二百尺，/本末皆十围。
诗：天子建明堂，/此材独中规。/匠人执斤墨，/采度将有期。
诗：孟冬草木枯，/烈火燎山陂。/疾风吹猛焰，/从根烧到枝。
诗：养材三十年，/方成栋梁姿。/一朝为灰烬，/柯叶无子遗。
诗：地虽生尔材，/天不与尔时。/不如粪上英，/犹有人掇之。
诗：已矣勿重陈，/重陈令人悲。/不悲焚烧苦，/但悲采用迟。
诗：赫赫京内史，/炎炎中书郎。/昨传征拜日，/恩赐颇殊常。
诗：貂冠水苍玉，/紫绶黄金章。/佩服身未暖，/已闻窜遐荒。
诗：亲戚不得别，/吞声泣路旁。/宾客亦已散，/门前雀罗张。
诗：富贵来不久，/倏如瓦沟霜。/权势去尤速，/瞥若石火光。
诗：不如守贫贱，/贫贱可久长。/传语宦游子：/且来归故乡。
诗：促织不成章，/提壶但闻声。/嗟战虫与鸟，/无实有虚名。
诗：与君定交日，/久要如弟兄。/何以示诚信？/白水指为盟。
诗：云雨一为别，/飞沉两难并。/君为得风鹏，/我为失水鲸。
诗：音信日已疏，/恩分日已轻。/穷通尚如此，/何况死与生。
诗：乃知择交难，/须有知人明。/莫将山下松，/结托水上萍。
诗：翩翩两玄鸟，/本是同巢燕。/分飞来几时？/秋夏炎凉变。
诗：一宿蓬荜庐，/一栖明光殿。/偶因衔泥处，/复得重相见。
诗：彼矜杏梁贵，/此嗟茅栋贱。/眼看秋社至，/两处俱难恋。
诗：所托各暂时，/胡为相叹羡？
诗：婆娑园中树，/根株大合围。/蠢尔树间虫，/形质一何微。
诗：孰谓虫至徽，/蛊蠹无已期。/孰谓树至大，/花叶有衰时。
诗：花衰夏未实，/叶病秋先萎。/树心半为土，/观者安得知？
诗：借问虫何在？/在身不在枝。/借问虫何食？/食心不食皮。
诗：岂无啄木鸟，/觜长将何为。

# 读史五首
诗：楚怀放灵均，/国政亦荒淫。/彷徨未忍决，/绕泽行悲吟。
诗：汉文疑贾生，/谪置湘之阴。/是时刑方措，/此去难为心。
诗：士生一代间，/谁不有浮沉。/良时真可惜，/乱世何足钦？
诗：乃知汨罗恨，/未抵长沙深。
诗：涡患如棼丝，/其来无端绪。/马迁下蚕室，/嵇康就囹圄。
诗：抱冤志气屈，/忍耻形神沮。/当彼戮辱时，/奋飞无翅羽。
诗：商山有黄绮，/颍川有巢许。/何不从之游，/超然离网罟。
诗：山林少羁鞅，/世路多艰阻。/寄谢伐檀人，/慎勿嗟穷处。
诗：汉日大将军，/少为乞食子。/秦时故列侯，/老作锄瓜士。
诗：春华何眭晔，/园中发桃李。/秋风忽萧条，/堂上生荆枳。
诗：深谷变为岸，/桑田成海水。/势去未须悲，/时来何足喜。
诗：寄言荣枯者：/反复殊未已。
诗：含沙射人影，/虽病人不知。/巧言构人罪，/至死人不疑。
诗：掇蜂杀爱子，/掩鼻戮宠姬。/弘恭陷萧望，/赵高谋李斯。
诗：阴德既必报，/阴祸岂虚施？/人事虽可罔，/天道终难欺。
诗：明则有刑辟，/幽则有神祗。/苟免勿私喜，/鬼得而诛之。
诗：季子憔悴时，/妇见不下机。/买臣负薪日，/妻亦弃如遗。
诗：一朝黄金多，/佩印衣锦归。/去妻不敢视，/妇嫂强依依。

原：下内直归，而微之已即路，邂逅相遇于街衢中，自永寿寺南，抵新昌里北，得马上语别；语不过相勉保方寸，外形骸而已，因不暇及他。是夕，足下次于山北寺。仆职役不得去，命季弟送行，且奉新诗一轴，致于执事。凡二十章，率有兴比，淫文艳韵无一字焉。意者：欲足下在途讽读，且以遣日时，销忧懑，又有以张直气而扶壮心也。及足下到江陵，寄在路所为诗十七章，凡五六千言，言有为，章有旨，迨于宫律体裁，皆得作者风。发缄开卷，且喜且怪。仆思牛僧孺戒，不能示他人，唯与杓直、拒非及樊宗师辈三四人，时一吟读，心甚贵重。然窃思之：岂仆所奉者二十章，遽能开足下聪明，使之然耶？抑又不知足下是行也，天将屈足下之道，激足下之心，使感时发愤，而臻于此耶？若两不然者，何立意措辞，与足下前时诗，如此之相远也？仆既羡足下诗，又怜足下心，尽欲引狂简而和之；属直宿拘牵，居无暇日，故不即时如意。旬月来，多乞病假，假中稍闲，且摘卷中尤者，继成十章，亦不下三千言。其间所见，同者固不能自异，异者亦不能强同。同者谓之和，异者谓之答；并别录《和梦游春诗》一章，各附于本篇之末，未和者，亦续致之。顷者，在科试间，常与足下同笔砚；每下笔时，辄相顾，共患其意太切而理太周。故理太周则辞繁，意太切则言激。然与足下为文，所长在于此，所病亦在于此。足下来序，果有词犯文繁之说。今仆所和者，犹前病也。待与足下相见日，各引所作，稍删其烦而晦其义焉。具书白。

诗：为长社坛下，/无人敢芟斫。/几度野火来，/风回烧不着。
诗：有木香苒苒，/山头生一茇。/主人不知名，/移种近轩闼。
诗：爱其有芳味，/因以调曲蘖。/前后曾饮者，/十人无一活。
诗：岂徒悔封植，/兼亦误采掇。/试问识药人，/始知名野葛。
诗：年深已滋蔓，/刀斧不可伐。/何时猛风来？/为我连根拔。
诗：有木名水柽，/远望青童童。/根株非劲挺，/柯叶多蒙笼。
诗：彩翠色如柏，/鳞皴皮似松。/为同松柏类，/得列嘉树中。
诗：枝弱不胜雪，/势高常惧风。/雪压低还举，/风吹西复东。
诗：柔芳甚杨柳，/早落先梧桐。/唯有一堪赏，/中心无蠹虫。
诗：有木名凌霄，/擢秀非孤标。/偶依一株树，/遂抽百尺条。
诗：托根附树身，/开花寄树梢。/自谓得其势，/无因有动摇。
诗：一旦树摧倒，/独立暂飘。/疾风从东起，/吹折不终朝。
诗：朝为拂云花，/暮为委地樵。/寄言立身者，/勿学柔弱苗。
诗：有木名丹桂，/四时香馥馥。/花团夜雪明，/叶剪春云绿。
诗：风影清似水，/霜枝冷如玉。/独占小山幽，/不容凡鸟宿。
诗：匠人爱芳直，/裁截为厦屋。/干细力未成，/用之君自速。
诗：重任虽大过，/直心终不曲。/纵非梁栋材，/犹胜寻常木。

# 叹鲁二首
诗：季桓心岂忠，/其富过周公。/阳货道岂正，/其权执国命。
诗：由来富与权，/不系才与贤。/所托得其地，/虽愚亦获安。
诗：彘肥因粪壤，/鼠稳依社坛。/虫兽尚如是，/岂谓无因缘？
诗：展禽胡为者，/直道竟三黜。/颜子何如人？/屡空聊过日。
诗：皆怀王佐道，/不践陪臣秩。/自古无奈何，/命为时所屈。
诗：有如草木分，/天各与其一。/荔枝非名花，/牡丹无甘实。

# 反鲍明远白头吟
诗：炎炎者烈火，/营营者小蝇。/火不热真玉，/蝇不点清冰。
诗：此苟无所受，/彼莫能相仍。/乃知物性中，/各有能不能。
诗：古称怨报死，/则人有所惩。/惩淫或应可，/在道未为弘。
诗：譬如蜩鷃徒，/啾啾卓龙鹏。/宜当委之去，/寥廓高飞腾。
诗：岂能泥尘下，/区区酬怨憎。/胡为坐自苦，/吞悲仍抚膺。

# 青冢
诗：上有饥雁号，/下有枯蓬走。/茫茫边雪里，/一掬沙培楼。
诗：传是昭君墓，/埋闭蛾眉久。/凝脂化为泥，/铅黛复何有。
诗：唯有阴怨气，/时生坟左右。/郁郁如苦雾，/不随骨销朽。
诗：妇人无他才，/荣枯系妍否。/何乃明妃命，/独悬画工手？
诗：丹青一诖误，/白黑相纷糺。/遂使君眼中，/西施作嫫母。
诗：同侪倾宠幸，/异类为配偶。/祸福安可知，/美颜不如丑。
诗：何言一时事，/可戒千年后。/特报后来姝，/不须倚眉首。
诗：无辞插荆钗，/嫁作贫家妇。/不见青冢上，/行人为浇酒。

# 杂感
诗：君子防悔尤，/贤人戒行藏。/嫌疑远瓜李，/言动慎毫芒。
诗：立教图如此，/抚事有非常。/为君持所感，/仰面问苍苍。
诗：犬啮桃树根，/李树反见伤。/老龟烹不烂，/延祸及枯桑。
诗：城门自焚热，/池鱼罹其殃。/阳货肆凶暴，/仲尼畏于匡。
诗：鲁酒薄如水，/邯郸开战场。/伯禽鞭见血，/过失由成王。
诗：都尉身降虏，/宫刑加子长。/吕安兄不道，/都市杀嵇康。
诗：斯人死已久，/其事甚昭彰。/是非不由己，/祸患安可防。
诗：使我千载后，/涕泗满衣裳。
