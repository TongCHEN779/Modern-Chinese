诗：一条邛杖悬龟榼，/双角吴童控马衔。/晚入东城谁识我？/短靴低帽白蕉衫。

# 与梦得沽酒闲饮且约后期
诗：少时犹不忧生计，/老后谁能惜酒钱？/共把十千沽一斗，/相看七十欠三年。
诗：闲征雅令穷经史，/醉听清吟胜管弦。/更待菊黄家酝熟，/共君一醉一陶然。

# 与牛家妓乐雨夜合宴
诗：玉管清弦声旖旎，/翠钗红袖坐参差。/两家合奏洞房夜，/八月连阴秋雨时。
诗：歌脸有情凝睇久，/舞腰无力转裙迟。/人间欢乐无过此，/上界西方即不知。

# 和杨六尚书喜两弟汉公转吴兴鲁士赐章服命宾开宴用庆恩荣赋长句见示
诗：华筵贺客日纷纷，/剑外欢娱洛下闻。/朱绂宠光新照地，/彤檐喜气远凌云。
诗：荣联花萼诗难和，/乐助埙簏酒易醺。/感羡料应知我意，/今生此事不如君。

# 自咏
诗：须白面微红，/醺醺半醉中。/百年随手过，/万事转头空。
诗：卧疾瘦居士，/行歌狂老翁。/仍闻好事者，/将我画屏风。

# 梦得相过援琴命酒因弹秋思偶咏所怀兼寄继之待价二相府
诗：闲居静侣偶相招，/小饮初酣琴欲调。/我正风前弄秋思，/君应天上听《云韶》。
诗：《云韶》雅曲，/上多与宰相同听之。/时和始见陶钧力，/物遂方知盛圣朝。
诗：双凤栖梧鱼在藻，/飞沉随分各逍遥。

# 九月八日酬皇甫十见赠
诗：君方对酒缀诗章，/我正持斋坐道场。/处处追游虽不去，/时时吟咏亦无妨。
诗：霜蓬旧鬓三分白，/露菊新花一半黄。/惆怅东篱不同醉，/陶家明日是重阳。

# 慕巢尚书书云室人欲为买置一歌者非所安也以诗相报因而和之
诗：东川已过二三春，/南国须求一两人。/富贵大都多老大，/欢娱太半为亲宾。
诗：如愁翟黛应堪重，/买笑黄金莫诉贫。/他日相逢一杯酒，/樽前还要落梁尘。

# 杪秋独夜
诗：无限少年非我伴，/可怜清夜与谁同？/欢娱牢落中心少，/亲故凋零四面空。
诗：红叶树飘风起后，/白须人立月明中。/前头更有萧条物，/老菊衰兰三两丛。

# 凭李睦州访徐凝山人
原：凝，即睦州之民也。
诗：郡守轻诗客，/乡人薄钓翁。/解怜徐处士，/唯有李郎中。

# 苏州故吏
诗：江南故吏别来久，/今日池边识我无？/不独使君头似雪，/华亭鹤死白莲枯。
诗：莲、鹤，/皆苏州同来。

# 得杨湖州书颇夸抚民接宾纵酒题诗因以绝句戏之
诗：岂独爱民兼爱客，/不唯能饮又能文。/白蘋洲上春传语，/柳使君输杨使君。

# 天宫阁秋晴晚望
诗：洛城秋霁后，/梵阁暮登时。/此日风烟好，/今秋节候迟。
诗：霞光红泛滟，/树影碧参差。/莫虑言归晚，/牛家有宿期。

# 酬梦得暮秋晴夜对月相忆
诗：霁月光如练，/盈庭复满池。/秋深无热后，/夜浅未寒时。
诗：露叶团荒菊，/风枝落病梨。/相思懒相访，/应是各年衰。

# 同梦得和思黯见赠来诗中先叙三人同宴之欢次有叹鬓发渐衰嫌孙子催老之意因继妍唱兼吟鄙怀
诗：醉伴腾腾白与刘，/何朝何夕不同游？/留连灯下明犹饮，/断送樽前倒即休。
诗：催老莫嫌孙稚长，/加年须喜鬓毛秋。/教他伯道争存活，/无子无孙亦白头。

# 听歌
诗：管妙弦清歌入云，/老人合眼醉醺醺。/诚知不及当年听，/犹觉闻时胜不闻。

# 三年冬随事铺设小堂寝处稍似稳暖因念衰病偶吟所怀
诗：小宅非全陋，/中堂不甚卑。/聊堪会亲族，/足以贮妻儿。
诗：暖帐迎冬设，/煴炉向夜施。/裘新青兔褐，/褥软白猿皮。
诗：似鹿眠深草，/如鸡宿稳枝。/逐身安枕席，/随事有屏帷。
诗：病致衰残早，/贫营活计迟。/由来蚕老后，/方是茧成时。

# 初冬即事呈梦得
诗：青毡帐暖喜微雪，/红地炉深宜早寒。/走笔小诗能和否？/泼醅新酒试尝看。
诗：僧来乞食因留宿，/客到开樽便共欢。/临老交亲零落尽，/希君恕我取人宽。

# 自罢河南已换七尹每一入府怅然旧游因宿内厅偶题西壁兼呈韦尹常侍
诗：每人河南府，/依然似到家。/杯尝七尹酒，/七尹酒味不同，
诗：备尝之矣。/树看十年花即府中新果园。/且健须欢喜，/虽衰莫叹嗟。
诗：迎门无故吏，/侍坐有新娃。/暖阁谋宵宴，/寒庭放晚衙。
诗：主人留宿定，/一任夕阳斜。

# 天寒晚起引酌咏怀寄许州王尚书汝州李常侍
诗：叶覆冰池雪满山，/日高慵起未开关。/寒来更亦无过醉，/老后何由可得闲。
诗：四海故交唯许汝，/十年贫健是樊蛮。/相思莫忘樱桃会，/一放狂歌一破颜。

# 四年春
诗：柳梢黄嫩草芽新，/又入开成第四春。/近日放慵多不出，/少年嫌老可相亲？
诗：分司吉傅频过舍，/致仕崔卿拟卜邻。/时辈推迁年事到，/往还多是白头人。

# 白发
诗：白发生来三十年，/而今须鬓尽皤然。/歌吟终日如狂叟，/衰疾多时似瘦仙。
诗：八戒夜持香火印，/三元朝念《蕊珠》篇。/其便被春收拾，/不作闲游即醉眠。

# 追欢偶作
诗：追欢逐乐少闲时，/补帖平生得事迟。/何处花开曾后看？/谁家酒熟不先知？
诗：石楼月下吹芦管，/金谷风前舞《柳枝》。/十听春啼变莺舌，/三嫌老丑换蛾眉。
诗：乐天一过难知分，/犹自咨嗟两鬓丝。/芦管、《柳枝》已下，/皆十年来洛中之事。

# 公垂尚书以白马见寄光洁稳善以诗谢之
诗：翩翩白马称金羁，/领缀银花尾曳丝。/毛色鲜明人尽爱，/性灵驯善主偏知。
诗：免将妾换惭来处，/试使奴牵欲上时。/不蹶不惊行步稳，/最宜山简醉中骑。

# 西楼独立
诗：身著白衣头似雪，/时时醉立小楼中。/路人回顾应相怪，/十一年来见此翁。

# 书事咏怀
诗：官俸将生计，/虽贫岂敢嫌？/金多输陆贾，/酒足胜陶潜。

# 酬梦得比萱草见赠

# 送苏州李使君赴郡二绝句
