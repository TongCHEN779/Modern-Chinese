# 咏兴五首并序
诗：七年四月，/予罢河南府，/归履道第。/庐舍自给，
诗：衣储自充，/无欲无营；/或歌或舞，/颓然自适，
诗：盖河洛间一幸人也。/遇兴发咏，/偶成五章，/各以首句，
诗：命为题目。

# 解印出公府
诗：解印出公府，/斗擞尘土衣。/百吏放尔散，/双鹤随我归。
诗：归来履道宅，/下马入柴扉。/马嘶返旧枥，/鹤舞还故池。
诗：鸡犬何忻忻，/邻里亦依依。/年颜老去日，/生计胜前时。
诗：有帛御冬寒，/有谷防岁饥。/饱于东方朔，/乐于荣启期。
诗：人生且如此，/此外吾不知。

# 出府归吾庐
诗：出府归吾庐，/静然安且逸。/更无客干谒，/时有僧问疾。
诗：家僮十人，/枥马三四匹。/慵发经旬卧，/兴来连日出。
诗：出游爱何处？/嵩碧伊瑟瑟。/况有清和天，/正当疏散日。
诗：身闲自为贵，/何必居荣秩？/心足即非贫，/岂唯金满室。
诗：吾观权势者，/苦以身徇物。/炙手外炎炎，/履冰中栗栗。
诗：朝饥口忘味，/夕惕心忧失。/但有富贵名，/而无富贵实。

# 池上有小舟
诗：池上有小舟，/舟中有胡床。/床前有新酒，/独酌还独尝。
诗：薰若春日气，/皎如秋水光。/可洗机巧心，/可荡尘垢肠。
诗：岸曲舟行迟，/一曲进一觞。/未知几曲醉，/醉入无何乡。
诗：寅缘潭岛间，/水竹深青苍。/身闲心无事，/白日为我长。
诗：我若未忘世，/虽闲心亦忙。/世若未忘我，/虽退身难藏。
诗：我今异于是，/身世交相忘。

# 四月池水满
诗：四月池水满，/龟游鱼跃出。/吾亦爱吾池，/池边开一室。
诗：人鱼虽异族，/其乐归于一。/且与尔为徒，/逍遥同过日。
诗：尔无羡沧海，/蒲藻可委质。/吾亦忘青云，/衡茅足容膝。
诗：况吾与尔辈，/本非蛟龙匹。/假如云雨来，/只是池中物。

# 小庭亦有月
诗：小庭亦有月，/小院亦有花。/可怜好风景，/不解嫌贫家。
诗：菱角执笙簧，/谷儿抹琵琶。/红绡信手舞，/紫绡随意歌。
诗：菱、谷、紫、红，/皆小臧获名也。/村歌与社舞，/客哂主人夸。
诗：但问乐不乐，/岂在钟鼓多？/客告暮将归，/主称日未斜。
诗：请客稍深酌，/愿见朱颜酡。/客知主意厚，/分数随口加。
诗：堂上烛未秉，/座中冠已峨。/左顾短红袖，/右命小青娥。
诗：长跪谢贵客，/蓬门劳见过。/客散有兴，/醉卧独吟哦。
诗：幕天而席地，/谁奈刘伶何！

# 秋凉闲卧
诗：残暑昼犹长，/早凉秋尚嫩。/露荷散清香，/风竹含疏韵。
诗：幽闲竟日卧，/衰病无人问。/薄暮宅门前，/槐花深一寸。

# 酬思黯相公见过弊居戏赠
诗：轩盖光照地，/行人为徘徊。/呼传君子出，/乃是故人来。
诗：访我入穷巷，/引君登小台。/台前多竹树，/池上无尘埃。
诗：贫家何所有？/新酒三两杯。/款曲语上马，/从容复迟回。
诗：留守不外宿，/日斜宫漏催。/但留金刀赠，/未接玉山颓。
诗：家酝不敢惜，/待君来即开。/村妓不辞出，/恐君輾然哈。

# 再授宾客分司
诗：优稳四皓官，/清崇三品列。/伊予再尘忝，/内愧非才哲。
诗：俸钱七八万，/给受无虚月。/分命在东司，/又不劳朝谒。
诗：既资闲养疾，/亦赖慵藏拙。/宾友得从容，/琴觞恣怡悦。
诗：乘篮城外去，/系马花前歇。/六游金谷春，/五看龙门雪。
诗：吾若默无语，/安知吾快活？/吾欲更尽言，/复恐人豪夺。
诗：应为时所笑，/苦惜分司阙。/但问适意无，/岂论官冷热！

# 把酒
诗：把酒仰问天，/古今谁不死？/所贵未死间，/少忧多欢喜。
诗：穷通谅在天，/忧喜即由己。/是故达道人，/去彼而取此。
诗：勿言未富贵，/久忝居禄仕。/借问宗族间，/几人拖金紫？
诗：勿忧渐衰老，/且喜加年纪。/试数班行中，/几人及暮齿？
诗：朝餐不过饱，/五鼎徒为尔。/夕寝止求安，/一衾而已矣。
诗：此外皆长物，/于我云相似。/有子不留金，/何况兼无子？

# 首夏
诗：林静蚊未生，/池静蛙未鸣。/景长天气好，/竟日和且清。
诗：春禽哢在，/夏木新阴成。/兀尔水边坐，/翛然桥上行。
诗：自问一何适？/身闲官不轻。/料钱随月用，/生计逐日营。
诗：食饱惭伯夷，/酒足愧渊明。/陶潜诗云：/“饮酒常不足。”
诗：寿倍颜氏子，/富百黔娄生。/有一即为乐，/况吾四者并？
诗：所以私自慰，/虽老有心情。

# 代鹤
诗：我本海上鹤，/偶逢江南客。/感君一顾恩，/同来洛阳陌。
诗：洛阳寡族类，/皎皎唯两翼。/貌是天与高，/色非日浴白。
诗：主人诚可恋，/其奈轩庭窄？/饮啄杂鸡群，/年深损标格。
诗：故乡渺何处？/云水重重隔。/谁念深笼中，/七换摩天翮。

# 立秋夕有怀梦得
诗：露簟获竹清，/风扇蒲葵轻。/一与故人别，/再见新蝉鸣。
诗：是夕凉飙起，/闲境人幽情。/回灯见栖鹤，/隔竹闻吹笙。
诗：夜茶一两杓，/秋吟三数声。/所思渺千里，/云外长洲城。

# 哭崔常侍晦叔
诗：顽贱一拳石，/精珍百炼金。/名价既相远，/交分何其深！
诗：中诚一以合，/外物不能侵。/逶迤二十年，/与世同浮沉。
诗：晚有退闲约，/自首归云林。/垂老忽相失，/悲哉口语心。
诗：春日嵩高阳，/秋夜清洛阴。/丘园共谁卜？/山水共谁寻？
诗：风月共谁赏？/诗篇共谁吟？/花开共谁看？/酒熟共谁斟？
诗：惠死庄杜口，/锺殁师废琴。/道理使之然，/从古非独今。
诗：吾道自此孤，/我情安可任？/唯将病眼泪，/一洒秋风襟。

# 新秋晚兴
诗：浊暑忽已退，/清宵未全长。/晨釭耿残焰，/宿阁凝微香。
诗：喔喔鸡下树，/辉辉日上梁。/枕低茵席软，/卧稳身入床。
诗：睡足景犹早，/起初风乍凉。/展张小屏障，/收拾生衣裳。
诗：还有惆怅事，/迟迟未能忘。/拂镜梳白发，/可怜冰照霜。

# 秋日与张宾客舒著作同游龙门醉中狂歌凡二百三十八字
诗：秋天高高秋光清，/秋风袅袅秋虫鸣。/嵩峰霞锦绮卷，/伊水细浪鳞甲生。
诗：洛阳闲客知无数，/少出游山多在城。/商岭老人自追逐，/蓬丘逸士相逢迎。
诗：南出鼎门十八里，/庄店逦迤桥道平。/不寒不热好时节，/鞍马稳快衣衫轻。
诗：并辔踟蹰下西岸，/扣舷容与绕中汀。/开怀旷达无所系，/触目胜绝不可名。
诗：荷衰欲黄荇犹绿，/鱼乐自跃鸥不惊。/翠藻蔓长孔雀尾，/彩船橹急寒雁声。
诗：家酝一壶白玉液，/野花数把黄金英。/昼游四看西日暮，/夜话三及东方明。
诗：暂停杯觞辍吟咏，/我有狂言君试听。/丈夫一生有二志，/兼济独善难得并。
诗：不能救疗生民病，/即须先濯尘土缨。/况吾头白眼已暗，/终日戚促何所成？
诗：不如展眉开口笑，/龙门醉卧香山行。

# 履信池樱桃岛上醉后走笔送别舒员外兼寄宗正李卿考功崔郎中
诗：樱桃岛前春，/去春花万枝。/忽忆与宗卿闲饮日，/又忆与考功狂醉时。
诗：岁晚无花空有叶，/风吹满地乾重叠。/踏叶悲秋复忆春，/池边树下重殷勤。
诗：今朝一酌临寒水，/此地三回别故人。/樱桃花，/来春千万朵。
诗：来春共谁花下坐？/不论崔李上青云，/明日舒三亦抛我。

# 秋池独泛
诗：萧疏秋竹篱，/清浅秋风池。/一只短舫艇，/一张斑鹿皮。
诗：皮上有野叟，/手中持酒卮。/半酣箕踞坐，/自问身为谁？
诗：严子垂钓日，/苏门长啸时。/悠然意自得，/意外何人知？

# 冬日早起闲咏
诗：冰塘耀初旭，/风竹飘霰。/幽境虽目前，/不因闲不见。
诗：晨起对炉香；/道经寻两卷。/晚坐拂琴尘，/秋思弹一遍。
诗：此外更无事，/开樽时自劝。/何必东风来，/一杯春上面。

# 岁暮
诗：惨澹岁云暮，/穷阴动经旬。/霜风裂人面，/冰雪摧车轮。
诗：而我当是时，/独不知苦辛。/晨炊廪有米，/夕炊厨有薪。
诗：夹帽长覆耳，/重裘宽裹身。/加之一杯酒，/煦妪如阳春。
诗：洛城士与庶，/比屋多饥贫。/何处炉有火？/谁家甑无尘？
诗：如我饱暖者，/百人无一人。/安得不惭愧？/放歌聊自陈。

# 南池早春有怀
诗：朝游北桥上，/晚憩南塘畔。/西日雪全销，/东风冰尽泮。
诗：蓰蓰鱼尾掉，/瞥瞥鹅毛换。/泥暖草芽生，/沙虚泉脉散。
诗：晴芳冒苔岛，/宿润侵蒲岸。/洛下日初长，/江南春欲半。
诗：时光共抛掷，/人事堪嗟叹。/倚棹忽寻思。/去年池上伴。

# 古意
诗：脉脉复脉脉，/美人千里隔。/不见来几时，/瑶草三四碧。
诗：玉琴声悄悄，/鸾镜尘幂幂。/昔为连理枝，/今作分飞翮。
诗：寄书多不达，/加饭终无益。/心肠不自宽，/衣带何由窄！

# 山游示小妓
诗：双鬟垂未合，/三十才过半。/本是绮罗人，/今为山水伴。
诗：春泉共挥弄，/好树同攀玩。/笑容花底迷，/酒思风前乱。
诗：红凝舞袖急，/黛惨歌声缓。/莫唱《杨柳枝》，/一无肠与君断。

# 神照禅师同宿
诗：八年二月晦，/山梨花满枝。/龙门水西寺，/夜与远公期。
诗：晏坐自相对，/密语谁得知？/前后际断处，/一念不生时。

# 张常侍相访
诗：西亭晚寂寞，/莺散柳阴繁。/水户帘不卷，/风床席自翻。
诗：忽闻车马客，/来访蓬蒿门。/况是张常侍，/安得不开樽？

# 早夏游宴
诗：虽慵兴犹在，/虽老心犹健。/昨日山水游，/今朝花酒宴。
诗：山榴艳似火，/玉蕊飘如霰。/荣落逐瞬迁，/炎凉随刻变。
诗：未收木绵褥，/已动蒲葵扇。/且喜物与人，/年年得相见。

# 感白莲花
诗：白白芙蓉花，/本生吴江渍，/不与红者杂，/色类自区分。
诗：谁移尔至此？/姑苏白使君。/初来苦憔悴，/久乃芳氛氲。
诗：月月叶换叶，/年年根生根。/陈根与故叶，/销化成泥尘。
诗：化者日已远，/来者日复新。/一为池中物，/永别江南春。
诗：忽想西凉州，/中有天宝民。/埋殁汉父祖，/孳生胡子孙。
诗：已忘乡土恋，/岂念君亲恩。/生人尚复尔，/草木何足云！

# 咏所乐
诗：兽乐在山谷，/鱼乐在陂池。/虫乐在深草，/鸟乐在高枝。
诗：所乐虽不同，/同归适其宜。/不以彼易此，/况论是与非。
诗：而我何所乐？/所乐在分司。/分司有何乐？/乐哉人不知。
诗：官优有禄料，/职散无羁縻。/懒与道相近，/钝将闲自随。
诗：昨朝拜表回，/今晚行香归。/归来北窗下，/解巾脱尘衣。
诗：冷泉灌我顶，/暖水濯四支。/体中幸无疾，/卧任清风吹。
诗：心中又无事，/坐任白日移。/或开书一篇，/或引酒一卮。
诗：但得如今日，/终身无厌时。

# 思旧
诗：闲日一思旧，/旧游如目前。/再思今何在？/零落归下泉。
诗：退之服流黄，/一病讫不痊。/微之炼秋石，/未老身溘然。
诗：杜子得丹诀，/终日断腥膻。/崔君夸药力，/经冬不衣绵。
诗：或疾或暴天，/悉不过中年。/唯予不服食，/老命反迟延。
诗：况在少壮时，/亦为嗜欲牵。/但耽荤与血，/不识汞与铅。
诗：饥来吞热物，/渴来饮寒泉。/诗役五藏神。/酒汨三丹田。
诗：随日合破坏，/至今粗完全。/齿牙未缺落，/支体尚轻便。
诗：已开第七秩，/饱食仍安眠。/且进杯中物，/其皆付天。

# 寄卢少卿
诗：老诲心不乱，/庄诫形太劳。/生命既能保，/死籍亦可逃。
诗：嘉肴与旨酒，/信是腐肠膏。/艳声与丽色，/真为伐性刀。
诗：补养在积功，/如裘集众毛。/将欲致千里，/可得差一毫？
诗：心不乱、形太劳至差一毫，/皆出老庄及诸道书仙方禁诫。/颜回何为者？/箪瓢才自给。
诗：肥不到口，/年不登三十。/张苍何为者？/染爱浩无际。
诗：妾媵填后房，/竟寿百岁。/苍寿有何德？/回夭有何辜？
诗：谁谓具圣体，/不如肥瓠躯。/遂使世俗心，/多疑仙道书。
诗：寄问卢先生，/此理当何如？

# 池上清晨候皇甫郎中

# 咏怀
诗：我知世无幻，/了无干世意。/世知我无堪，/亦无责我事。
诗：由兹两相忘，/因得长自遂。/自遂意何如？/闲官在闲地。
诗：闲地唯东都，/东都少名利。/闲官是宾客，/宾客无牵累。
诗：嵇康日日懒，/毕卓时时醉。/酒肆夜深归，/僧房日高睡。
诗：形安不劳苦，/神泰无忧畏。/从官三十年，/无如今气味。
诗：鸿虽脱罗弋，/鹤尚居禄位。/唯此未忘怀，/有时犹内愧。

# 北窗三友
诗：今日北窗下，/自问何所为？/欣然得三友，/三友者为谁？
诗：琴罢辄举酒，/酒罢辄吟诗。/三友递相引，/循环无已时。
诗：一弹惬中心，/一咏畅四支。/犹恐中有间，/以醉弥缝之。
诗：岂独吾拙好？/古人多若斯。/嗜诗有渊明，/嗜琴有启期；
诗：嗜酒有伯伦，/三人皆我师。/或乏担石储，/或穿带索衣。
诗：弦歌复觞咏，/乐道知所归。/三师去已远，/高风不可追。
诗：三友游甚熟，/无日不相随。/左掷白玉卮，/右拂黄金徽。
诗：兴酣不叠纸，/走笔操狂词。/谁能持此词，/为我谢亲知。
诗：纵未以为是，/岂以我为非？

# 吟四虽
