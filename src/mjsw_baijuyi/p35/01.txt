诗：暖怜炉火近，/寒觉被衣轻。/枕上酬佳句，/诗成梦不成。

# 初冬月夜得皇甫泽州手札并诗数篇因遣报书偶题长句
诗：清泠玉韵两三章，/落泊银钩七八行。/心逐报书悬雁足，/梦寻来路绕羊肠。
诗：水南地空多明月，/山北天寒足早霜。/履道所居在水南，/泽州在太行之北地也。
诗：最恨泼醅新熟酒，/迎冬不得共君尝！

# 雪中酒熟欲携访吴监先寄此诗
诗：新雪对新酒，/忆同倾一杯。/自然须访戴，/不必待延枚。
诗：《雪赋》云：/“延枚叟。”/陈榻无辞解，/袁门莫懒开。
诗：笙歌与谈笑，/随事自将来。

# 酬令公雪中见赠
原：讶不与梦得同相访
诗：雪似鹅毛飞散乱，/人披鹤氅立徘徊。/邹生枚叟非无兴，/唯待梁王召即来。

# 题酒瓮呈梦得
诗：若无清酒两三瓮，/争向白须千万茎？/麴糵销愁真得力，/光阴催老苦无情。
诗：凌烟阁上功无分，/伏火炉中药未成。/更拟共君何处去？/且来同作醉先生。

# 迂叟
诗：一辞魏阙就商宾，/散地闲居八九春。/初时被目为迂叟，/近日蒙呼作隐人。
诗：冷暖俗情谙世路，/是非闲论任交亲。/应须绳墨机关外，/安置疏愚钝滞身。

# 洛下闲居寄山南令狐相公
诗：已收身向园林下，/犹寄名于禄仕间。/不锻嵇康弥懒静，/无金疏傅更贫闲。
诗：支分门内生计，/谢绝朝中旧往还。/唯是相君未忘得，/时思汉水梦巴山。

# 惜春赠李尹
诗：春色有时尽，/公门终日忙。/两衙但不阙，/一醉亦何妨？
诗：芳树花团雪，/衰翁鬓扑霜。/知君倚年少，/未苦惜风光。

# 对酒劝令公开春游宴
诗：时泰岁丰无事日，/功成名遂自由身。/前头更有忘忧日，/向上应无快活人。
诗：自去年来多事故，/从今日去少交亲。/宜须数数谋欢会，/好作开成第二春。

# 与梦得偶同到敦诗宅感而题壁
诗：山东才副苍生愿，/《汉书》云：/“山东出相。”/川上俄惊逝水波。
诗：履道凄凉新第宅，/敦诗宅在履道，/修造初成。/宣城零落旧笙歌。
诗：崔家妓乐，/多归宣州也。/园荒唯有薪堪采，/门冷兼无雀可罗。
诗：今日相随偶同到，/伤心不是故经过。

# 杨六尚书新授东川节度使代妻戏贺兄嫂二绝
诗：刘纲与妇共升仙，/弄玉随夫亦上天。/何似沙哥领崔嫂，/碧油幢引向东川。
诗：金花银碗饶兄用，/罨画罗衣尽嫂裁。/觅得黔娄为妹婿，/可能空寄蜀茶来？

# 闲游即事
诗：郊野游行熟，/村园次第过。/蓦山寻浥涧，/踏水渡伊河。
诗：寒食青青草，/春风瑟瑟波。/逢人共杯酒，/随马有笙歌。
诗：胜事经非少，/芳辰过亦多。/还须自知分，/不老拟如何？

# 六十六
诗：七十欠四岁，/此生那足论？/每因悲物故，/还且喜身存。
诗：安得头长黑？/争教眼不昏。/交游成拱木，/婢仆见曾孙。
诗：瘦觉腰金重，/衰怜鬓雪繁。/将何理老病？/应付与空门。

# 池上早春即事招梦得
诗：老更惊年改，/闲先觉日长。/晴薰榆荚黑，/春染柳梢黄。
诗：雪破山呈色，/冰融水放光。/低平稳船舫，/轻暖好衣裳。
诗：白角三升榼，/红茵六尺床。/偶游难得伴，/独醉不成狂。
诗：我有中心乐，/君无外事忙。/经过莫慵懒，/相去两三坊。

# 因梦得题公垂所寄蜡烛因寄公垂
诗：照梁初日光相似，/出水新莲艳不如。/却寄两条君领取，/明年双引入中书。
诗：宰相入朝举双烛，/官各一。

# 令公南庄花柳正盛欲偷一赏先寄二篇
诗：最忆楼花千万朵，/偏怜堤柳两三株。/拟提社酒携村妓，/擅入朱门莫怪无？
诗：映楼桃花、拂堤垂柳，/是庄上最胜绝处，/故举以为对。
诗：可惜亭台闲度日，/欲偷风景暂游春。/只愁花里莺饶舌，/飞入宫城报主人。

# 春夜宴席上戏赠裴淄州
诗：九十不衰真地仙，/裴年九十，/不衰羸。/六旬犹健亦天怜予自谓也。
诗：今年相遇莺花月，/此夜同欢歌酒筵。/四座齐声和丝竹，/两家随分斗金钿。
诗：留君到晓无他意，/图向君前作少年。

# 赠梦得
诗：年颜老少与君同，/眼未全昏耳未聋。/放醉卧为春日伴，/趁欢行人少年丛。
诗：寻花借马烦川守，/弄水偷船恼令公。/闻道洛城人尽怪，/呼为刘白二狂翁。

# 晚春欲携酒寻沈四著作先以六韵寄之
诗：病容衰惨澹，/芳景晚蹉跎。/无计留春得，/争能奈老何？
诗：篇章慵报答，/杯宴喜经过。/顾我酒狂久，/负君诗债多。
诗：沈前后惠诗十首，/春来多醉，/竟未酬答，/今故云尔。
诗：敢辞携绿蚁？/只愿见青娥。/最忆阳关唱，/真珠一串歌。
诗：沈有讴者，/善唱“西出阳关无故人”词。

# 开成二年三月三日河南尹李待价以人和岁稔将禊于洛滨前一日启留守裴令公公明日召太子少傅白居易太子宾客萧籍李仍叔刘禹锡前中书舍人郑居中国子司业裴恽河南少尹李道枢仓部郎中崔晋司封员外郎张可绩驾部员外郎卢言虞部员外郎苗情和州刺史裴俦淄州刺史裴洽检校礼部员外郎杨鲁士四门博士谈弘谟等一十五人合宴于舟中由斗亭历魏堤抵津桥登临溯沿自晨及暮簪组交映歌笑间发前水嬉而后妓乐左笔砚而右壶觞望之若仙观者如堵尽风光之赏极游泛之娱美景良辰赏心乐事尽得于今日矣若不记录谓洛无人晋公首赋一章铿然玉振顾谓四座继而和之居易举酒抽毫奉十二韵以献座上作
诗：三月草萋萋，/黄莺歇又啼。/柳桥晴有絮，/沙路润无泥。
诗：禊事修初毕，/游人到欲齐。/金钿耀桃李，/丝管骇凫鹭。
诗：转岸回船尾，/临流簇马蹄。/闹于杨子渡，/踏破魏王堤。
诗：妓接谢公宴，/诗陪荀令题。/舟同李膺泛，/醴为穆生携。
诗：水引春心荡，/花牵醉眼迷。/尘街从鼓动，/烟树任鸦栖。
诗：舞急红腰凝，/歌迟翠黛低。/夜归何用烛？/新月凤楼西。

# 同梦得寄贺东西川二杨尚书
诗：龙节对持真可爱，/雁行相接更堪夸。/两川风景同三月，/千里江山属一家。
诗：鲁卫定知联气色，/潘杨亦觉有光华。/予与二公，/皆忝姻戚。
诗：应怜洛下分司伴，/冷宴闲游老看花。

# 喜小楼西新柳抽条
诗：一行弱柳前年种，/数尺柔条今日新。/渐欲拂他骑马客，/未多遮得上楼人。
诗：须教碧玉羞眉黛，/莫与红桃作麴尘。/为报金堤千万树，/饶伊未敢苦争春。

# 晚春酒醒寻梦得
诗：料合同惆怅，/花残酒亦残。/醉心忘老易，/醒眼别春难。
诗：独出虽慵懒，/相逢定喜欢。/还携小蛮去，/诚觅老刘看。
原：小蛮，酒榼名也。

# 感事
诗：服气崔常侍晦叔，/烧丹郑舍人居中。/常期生羽翼，/那忽化灰尘？
诗：每遇凄凉事，/还思潦倒身。/唯知趁杯酒，/不解炼金银。
诗：睡适三尸性，/慵安五藏神。/无忧亦无喜，/六十六年春。

# 和裴令公南庄一绝
原：裴诗云：“野人不识中书令，唤作陶家与谢家。”
诗：陶庐僻陋那堪比？/谢墅幽微不足攀。/何似嵩峰三十六，/长随申甫作家山！

# 宅西有流水墙下构小楼临玩之时颇有幽趣因命歌酒聊以自娱独醉独吟偶题五绝
诗：伊水分来不自由，/无人解爱为谁流。/家家抛向墙根底，/唯我栽莲起小楼。
诗：水色波文何所似？/麴尘罗带一条斜。/莫言罗带春无主，/自置楼来属白家。

# 三
诗：日滟水光摇素壁，/风飘树影拂朱栏。/皆言此处宜弦管，/试奏《霓裳》一曲看。

# 四
诗：《霓裳》奏罢唱《梁州》，/红袖斜翻翠黛愁。/应是遥闻胜近听，/行人欲过尽回头。

# 五
诗：独醉还须得歌舞，/自娱何必要亲宾？/当时一部清商乐，/亦不长将乐外人。

# 偶作
诗：篮舁出即忘归舍，/柴户昏犹未掩关。/闻客病时惭体健，/见人忙处觉身闲。
诗：清凉秋寺行香去，/和暖春城拜表还。/木雁一篇须记取：/致身才与不才间。

# 同梦得酬牛相公初到洛中小饮见赠
原：时牛相公辞罢扬州节度，就拜东都留守。
诗：淮南挥手抛红旆，/洛下回头向白云。/政事堂中老丞相，/制科场里旧将军。
诗：宫城烟月饶全占，/关塞风光请中分。/诗酒放狂犹得在，/莫欺白叟与刘君。

# 幽居早秋闲咏
诗：幽僻嚣尘外，/清凉水木间。/卧风秋拂簟，/步月夜开关。
诗：且得身安泰，/从他世险艰。/但休争要路，/不必入深山。
诗：轩鹤留何用？/泉鱼放不还。/谁人知此味？/临老十年间。

# 和令狐仆射小饮听阮咸
诗：掩抑复凄清，/非琴不是筝，/还弹乐府曲，/别占阮家名。
诗：古调何人识？/初闻满座惊。/落盘珠历历，/摇珮玉琤琤。
诗：似劝杯中物，/如含林下情。/时移音律改，/岂是昔时声？

# 烧药不成命酒独醉
诗：白发逢秋王，/丹砂见火空。/不能留姹女，/争免作衰翁？
诗：赖有杯中绿，/能为面上红。/少年心不远，/只在半酣中。

# 送卢郎中赴河东裴令公幕
诗：别时暮雨洛桥岸，/到日凉风汾水波。/荀令见君应问我，/为言秋草闭门多。

# 送李滁州
诗：君於觉路深留意，/我亦禅门薄致功。/未悟病时须去病，/已知空后莫依空。
诗：白衣卧疾嵩山下，/皂盖行春楚水东。/谁道三年千里别？/两心同在道场中。

# 长斋月满寄思黯
诗：一日不见如三月，/一月相思如七年。/似隔山河千里地，/仍当风雨九秋天。
诗：明朝斋满相寻去，/挈榼抱衾同醉眠。

# 冬夜对酒寄皇甫十
诗：霜杀中庭草，/冰生后院池。/有风空动树，/无叶可辞枝。
诗：十月苦长夜，/百年强半时。/新开一瓶酒，/那得不相思？

# 岁除夜对酒
诗：衰翁岁除夜，/对酒思悠然。/草白经霜地，/云黄欲雪天。
诗：醉依香枕坐，/慵傍暖炉眠。/洛下闲来久，/明朝是十年。
