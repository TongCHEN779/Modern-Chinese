# 戊申岁暮咏怀三首
诗：穷冬月末两三日，/半百年过六七时。/龙尾趁朝无气力，/牛头参道有心期。
诗：荣华外物终须悟，/老病傍人岂得知？/犹被妻儿教渐退，/莫求致仕且分司。
诗：唯生一女才十二，/只欠三年未六旬。/婚嫁累轻何怕老，/饥寒心惯不忧贫。
诗：紫泥丹笔皆经手，/赤绂金章尽到身。/更拟踟蹰觅何事，/不归嵩洛作闲人？
诗：七年囚闭作笼禽，/但愿开笼便入林。/幸得展张今日翅，/不能辜负昔时心。
诗：人间祸福愚难料，/世上风波老不禁。/万一差池似前事，/又应追自悔不抽簪。

# 赠梦得
诗：心中万事不思量，/坐倚屏风卧向阳。/渐觉咏诗犹老丑，/岂宜凭酒更粗狂。
诗：头垂自发我思退，/脚蹋青云君欲忙。/只有今春相伴在，/花前剩醉两三场。

# 想东游五十韵并序
原：大和三年春，予病免官后，忆游浙右数郡，兼思到越，一访微之。故两浙之间，一物已上，想皆在目，吟且成篇，不能自休，盈五百字，亦犹孙兴公想天台山而赋之也。
诗：海内时无事，/江南岁有秋。/生民皆乐业，/地主尽贤侯。
诗：郊静销戎马，/城高逼斗牛。/平河七百里，/沃壤二三州。
诗：自常及杭，/凡三百里。/坐有湖山趣，/行无风浪忧。
诗：食宁妨解缆，/寝不废乘流。/泉石谙天竺，/烟霞识虎丘。
诗：天竺、虎丘寺，/皆领郡时旧游最熟处。/芳认兰泽，/遗咏思蘋洲。
诗：古诗云：/“兰泽多芳革。”/又，/柳恽诗云：
诗：“汀洲采白蘋。”/菡萏红涂粉，/菰蒲绿泼油。/鳞差渔户舍，
诗：绮错稻田沟。/紫洞藏仙窟，/玄泉贮怪湫。/精神昂老鹤，
诗：姿彩媚潜虯。/大谢诗云：/“潜虯媚幽姿。”/静阅天工妙，
诗：闲窥物状幽。/投竿出比目，/掷果下猕猴。/味苦莲心小，
诗：浆甜蔗节稠。/橘苞从自结，/藕孔是谁锼？/逐日移潮信；
诗：随风变棹讴。/递夫交烈火，/候吏次鸣驺。/梵塔形疑踊重玄阁，
诗：阎门势欲浮吴阊门。/客迎携酒榼，/僧待置茶瓯。/小宴闲谈笑，
诗：初筵雅献酬。/稍催朱蜡炬，/徐动碧牙筹。/圆盏飞莲子，
诗：长裾曳石榴。/柘枝随画鼓，/调笑从香球。/幕飏云飘槛，
诗：帘褰月露钩。/舞繁红袖凝，/歌切翠眉愁。/弦管宁容歇，
诗：杯盘未许收。/良辰宜酩酊，/卒岁好优游。/脍缕鲜仍细，
诗：莼丝滑且柔。/饱餐为日计，/稳睡是身谋。/名愧空虚得，
诗：官知止足休。/自嫌犹屑屑，/众笑大悠悠。/物表疏形役，
诗：人寰足悔尤。/蛾须远灯烛，/兔勿近置罘。/幻世春来梦，
诗：浮生水上沤。/百忧中莫入，/一醉外何求？/未死痴王湛，

诗：昔在杭州别微之，/微之留诗云：/“明朝又向江头别，/月落潮平是去时。”
诗：珠玉传新什，/念故俦。/悬旌心宛转，/束楚意绸缪。
诗：驿舫妆青雀，/官槽铢紫骝。/镜湖期远泛，/禹穴约冥搜。
诗：预扫题诗壁，/先开望海楼。/饮思亲履舄，/宿忆并衾稠。
诗：志气吾衰也，/风情子在不？/应须相见后，/别作一家游。
诗：吾衰、子在，/并出《家语》。

# 不如来饮酒七首
诗：莫隐深山去，/君应到自嫌。/齿伤朝水冷，/貌苦夜霜严。

原：又
诗：莫作农夫去，/君应见自愁。/迎春犁瘦地，/趁晚喂羸牛。
诗：数被官加税，/稀逢岁有秋。/不如来饮酒，/相伴醉悠悠。
原：又
诗：莫作商人去，/栖惶君未谙。/雪霜行塞北，/风水宿江南。
诗：藏镪百千万，/沉舟十二三。/不如来饮酒，/仰面醉酣酣。
原：又
诗：莫事长征去，/辛勤难具论。/何曾画麟阁？/只是老辕门。
诗：虮虱衣中物，/刀枪面上痕。/不如来饮酒，/合眼醉昏昏。
原：又
诗：莫学长生去，/仙方误杀君。/那将薤上露，/拟待鹤边云。
诗：矻矻皆烧药，/累累尽作坟。/不如来饮酒，/闲坐醉醺醺。
原：又
诗：莫上青云去，/青云足爱憎。/自贤夸智慧，/相纠斗功能。
诗：鱼烂缘吞饵，/蛾燋为扑灯。/不如来饮酒，/任性醉腾腾。
原：又

诗：且灭嗔中火，/休磨笑里刀。/不如来饮酒，/稳卧醉陶陶。

诗：细水涓涓似泪流，/日西惆怅小桥头。/衰杨叶尽空枝在，/犹被霜风吹不休。

# 哭微之二首
诗：八月凉风吹自幕，/寝门廊下哭微之。/妻孥朋友来相吊，/唯道皇天无所知。
诗：文章卓荦生无敌，/风骨英灵殁有神。/哭送咸阳北原上，/可能随例作灰尘？

# 马上晚吟
诗：人少街荒已寂寥，/风多尘起重萧条。/上阳落叶飘宫树，/中渡流澌拥渭桥。
诗：出早冒寒衣校薄，/归迟侵黑酒全消。/如今不是闲行日，/日短天阴坊曲遥。

# 醉中重留梦得
诗：刘郎刘郎莫先起，/苏台苏台隔云水。/酒盏来从一百分，/马头去便三千里。

# 雪夜喜李郎中见访兼酬所赠
诗：可怜今夜鹅毛雪，/引得高情鹤氅人。/红蜡烛前明似画，/青毡帐里暖如春。
诗：十分满盏黄金液，/一尺中庭白玉尘。/对此欲留君便宿，/诗情酒分合相亲。

# 任老
诗：不愁陌上春光尽，/亦任庭前日影斜。/面黑眼昏头雪白，/老应无可更增加。

# 劝欢
诗：火急欢娱慎勿迟，/眼看老病悔难追。/樽前花下歌筵里，/会有求来不得时。

# 答王尚书问履道池旧桥
诗：虹梁雁齿随年换，/素板朱栏逐日修。/但恨尚书能久别，/莫愁川守不频游。
诗：重移旧柱开中眼，/乱种新花拥两头。/李郭小船何足问，/待君乘过济川舟。

# 晚归府
诗：晚从履道来归府，/街路虽长尹不嫌。/马上凉于床上坐，/绿槐风透紫蕉衫。

# 从龙潭寺至少林寺题赠同游者
诗：山屐田衣六七贤，/搴芳蹋翠弄潺湲。/九龙潭月落杯酒，/三品松风飘管弦。
诗：强健且宜游胜地，/清凉不觉过炎天。/始知驾鹤乘云外，/别有逍遥地上仙。

# 夜从法王寺下归岳寺
诗：双刹夹虚空，/缘云一径通。/似从忉利下，/如过剑门中。
诗：灯火光初合，/笙歌曲未终。/可怜师子座，/异出净名翁。

# 宿龙潭寺
诗：夜上九潭谁是伴？/云随飞盖月随杯。/明年尚作三川守，/此地兼将歌舞来。

# 嵩阳观夜奏霓裳
诗：开元遗曲自凄凉，/况近秋天调是商。/爱者谁人唯白尹，/奏时何处在嵩阳。
诗：回临山月声弥怨，/散入松风韵更长。/子晋少姨闻定怪，/人间亦便有《霓裳》。

# 过元家履信宅
诗：鸡犬丧家分散后，/林园失主寂寥时。/落花不语空辞树，/流水无情自入池。
诗：风荡宴船初破漏，/雨淋歌阁欲倾欹。/前庭后院伤心事，/唯是春风秋月知。

# 和杜录事题红叶
诗：寒山十月旦，/霜叶一时新。/似烧非因火，/如花不待春。
诗：连行排绛帐，/乱落剪红巾。/解驻篮舆看，/风前唯两人。

# 题崔常侍济上别墅
原：时常侍以长告罢归，今故先报泉石。
诗：求荣争宠任纷纷，/脱弃金貂只有君。/散员疏去未为贵，/小邑陶休何足云。
诗：山色好当晴后见，/泉声宜向醉中闻。/主人忆尔尔知否？/抛却青云归白云。

# 过温尚书旧庄
诗：白石清泉抛济口，/碧幢红旆照河阳。/村人都不知时事，/犹自呼为处士庄。

# 天坛峰下赠杜录事
诗：年颜气力渐衰残，/王屋中峰欲上难。/顶上将探小有洞，/小有洞，
诗：在天坛顶上。/喉中须咽大还丹时杜方炼伏火砂次。/河车九转宜精炼，/火候三年在好看。
诗：他日药成分一粒，/与君先去扫天坛。

# 钵塔院如大师
原：赠僧五首
原：师年八十三，登坛秉律凡六十年。每岁于师处授八关戒者九度。
诗：百千万劫菩提种，/八十三年功德林。/若不秉持僧行苦，/将何报答佛恩深。
诗：慈悲不瞬诸天眼，/清净无尘几地心。/每岁八关蒙九授，/殷勤一戒重千金。

# 神照上人
原：照以说坛为佛事
诗：心如定水随形应，/口似悬河逐病治。/曾向众中先礼拜，/西方去日莫相遗。

# 自远禅师
原：远以无事为佛事
诗：自出家来长自在，/缘身一衲一绳床。/令人见即心无事，/每一相逢是道场。

# 宗实上人
原：实即樊司空之子，舍官位妻子出家。
诗：荣华恩爱弃成唾，/戒定真如和作香。/今古虽殊同一法，/瞿县抛却转轮王。

# 清闲上人
原：自蜀入洛，于长寿寺说法度人。
诗：梓潼眷属何年别？/长寿坛场近日开。/应是蜀人皆度了，/法轮移向洛中来。

# 弹秋思
诗：信意闲弹秋思时，/调清声直韵疏迟。/近来渐喜无人听，/琴格高低心自知。

# 自咏
诗：随宜饮食聊充腹，/取次衣裘亦暖身。/未必得年非瘦薄，/无妨长福是单贫。
诗：老龟岂羡牺牲饱？/蟠木宁争桃李春？/随分自安心自断，/是非何用问闲人。

# 分司初到洛中偶题六韵兼戏呈冯尹
诗：相府念多病，/春宫容不才。/官衔依口得，/俸禄逐身来。
诗：白首林园在，/红尘车马回。/招呼新客旅，/扫掠旧池台。
诗：小舫宜携乐，/新荷好盖杯。/不知金谷主，/早晚贺筵开？

# 春风
诗：春风先发苑中梅，/樱杏桃梨次第开。/荠花榆荚深村里，/亦道春风为我来。
