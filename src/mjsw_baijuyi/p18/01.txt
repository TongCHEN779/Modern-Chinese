# 题诗屏风绝句并序
原：十二年冬，微之犹滞通州，予亦未离溢上，相去万里，不见三年，郁郁相念，多以吟咏自解。前后辱微之寄示之什，殆数百篇，虽藏于箧中，永以为好；不若置之座右，如见所思。由是掇律句中短小丽绝者，凡一百首，题录合为一屏风，举目会心，参若其人在于前矣。前辈作事，多出偶然。则安知此屏，不为好事者所传，异日作九江一故事尔？因题绝句，聊以奖之。相忆采君诗作鄣，自书自勘不辞劳。鄣成定被人争写，从此南中纸价高。

# 答元八郎中杨十二博士
诗：身觉浮云无所著，/心同止水有何情？/但知萧洒疏朝市，/不要崎岖隐姓名。
诗：尽日观鱼临涧坐，/有时随鹿上山行。/谁能抛得人间事？/来共腾腾过此生。

# 湖亭与行简宿
诗：浔阳少有风情客，/招宿湖亭尽却回。/水槛虚凉风月好，/夜深唯共阿怜来。

# 八月十五日夜湓亭望月
诗：昔年八月十五夜，/曲江池畔杏园边。/今年八月十五夜，/湓浦沙头水馆前。
诗：西北望乡何处是？/东南见月几回圆！/临风一叹无人会，/今夜清光似往年。

# 赠江客
诗：江柳影寒新雨地，/塞鸿声急欲霜天。/愁君独向沙头宿，/水绕芦花月满船。

# 残暑招客
诗：云截山腰断，/风驱雨脚回。/早阴江上散，/残热日中来。
诗：却取生衣著，/重拈小簟开。/谁能淘晚热？/闲饮两三杯。

# 浔阳秋怀赠许明府
诗：霜红二林叶，/风白九江波。/暝色投烟鸟，/秋声带雨荷。
诗：马闲无处出，/门冷少人过，/卤莽还乡梦，/依俙望阙歌。
诗：共思除醉外，/无计奈愁何。/试问陶家酒，/新答得几多？

# 九日醉吟
诗：有恨头还白，/无情菊自黄。/一为州司马，/三见岁重阳。
诗：剑匣尘埃满，/笼禽日月长。/身从渔父笑，/门任雀罗张。
诗：问疾因留客，/听吟偶置觞。/叹时论倚伏，/怀旧数存亡。
诗：奈老应无计，/治愁或有方。/无过学王绩，/唯以醉为乡。

# 问韦山人山甫
诗：身名身事两蹉跎，/试就先生问若何。/从此神仙学得否？/白须虽有未为多。

# 送萧炼师步虚诗十首卷后以二绝继之
诗：欲上瀛洲临别时，/赠君十首步虚词。/天仙若爱应相问，/向道江州司马诗。
诗：花纸瑶缄松墨字，/把将天上共谁开？/试呈王母如堪唱，/发遣双成更取来。

# 赠李兵马使
诗：身得贰师气概，/家藏都尉旧诗章。/江南别有楼船将，/燕颔虬须不姓杨。

# 题遗爱寺前溪松
诗：偃亚长松树，/侵临小石溪。/静将流水对，/高共远峰齐。
诗：翠盖烟笼密，/花幢雪压低。/与僧清影坐，/借鹤稳枝栖。
诗：笔写形难似，/琴偷韵易迷。/暑天风槭槭，/晴夜露凄凄。
诗：独憩依为舍，/闲行绕作蹊。/栋梁君莫采，/留著伴幽栖。

# 庐山草堂夜雨独宿寄牛二李七庾三十二员外
诗：丹霄携手三君子，/白发垂头一病翁。/兰省花时锦帐下，/庐山雨夜草庵中。
诗：终身胶漆心应在，/半路云泥迹不同。/唯有无生三昧观，/荣枯一照两成空。

# 闻杨十二新拜省郎遥以诗贺
诗：文昌新人有光辉，/紫界宫墙白粉闱。/晓日鸡人传漏箭，/春风侍女护朝衣。
诗：雪飘歌句高难和，/鹤拂烟霄老惯飞。/官职声名俱入手，/近来诗客似君稀。
诗：顷曾有赠杨诗，/落句云：/“不用更教诗过好，/折君官职是声名。”
诗：今故云“俱入手”。

# 三月三日怀微之
诗：良时光景长虚掷，/壮岁风情已暗销。/忽忆同为校书日，/每年同醉是今朝。

# 赠韦八
诗：辞君岁久见君初，/白发惊嗟两有。/容鬓别来今至此，/心情料取合何如？
诗：曾同曲水花亭醉，/亦共华阳竹院居。/岂料天南相见夜，/哀猿瘴雾宿匡庐。

# 春江闲步赠张山人
诗：江景又妍和，/牵愁发浩歌。/晴砂金屑色，/春水麴尘波。
诗：红簇交枝杏，/青含卷叶荷。/藉莎怜软暖，/憩树爱婆娑。
诗：书信朝贤断，/知音野老多。/相逢不闲语，/争奈日长何？

# 春听琵琶兼简长孙司户
诗：四弦不似琵琶声，/乱写真珠细撼铃。/指底商风悲飒飒，/舌头胡语苦醒醒。
诗：如言都尉思京国，/似诉明妃厌虏庭。/迁客共君相劝谏，/春肠易断不须听。

# 吴宫词
诗：.一入吴王殿，/无人睹翠蛾。/楼高时见舞，/宫静夜闻歌。
诗：半露胸如雪，/斜回脸似波。/妍蚩各有分，/谁敢妒恩多？

# 送韦侍御量移金州司马
原：时予官独未出
诗：春欢雨露同沾泽，/冬叹风霜独满衣。/留滞多时如我少，/迁移好处似君稀。
诗：卧龙云到须先起，/蛰燕雷惊尚未飞。/莫恨东西沟水别，/沧溟长短拟同归。

# 自到浔阳生三女子因诠真理用遣妄怀
诗：宦途本自安身拙，/世累由来向老多。/远谪四年徒已矣，/晚生三女拟如何？
诗：预愁嫁娶真成患，/细念因缘尽是魔。/赖学空王治苦法，/须抛烦恼入头陀。

# 江西裴常侍以优礼见待又蒙赠诗辄叙鄙诚用伸感谢
诗：一从簪笏事金貂，/每借温颜放折腰。/长觉身轻离泥滓，/忽惊手重捧琼瑶。
诗：马因回顾虽增价，/桐遇知音已半燋。/他日秉钧如见念，/壮心直气未全销。

# 自江州司马授忠州刺史仰荷圣泽聊书鄙诚
诗：炎瘴抛身远，/泥涂索脚难。/网初鳞拨刺，/笼久翅摧残。
诗：雷电颁时令，/阳和变岁寒。/遗簪承旧念，/剖竹授新官。
诗：乡觉前程近，/心随外事宽。/生还应有分，/西笑问长安。

# 除忠州寄谢崔相公
诗：提拔出泥知力竭，/吹嘘生翅见情深。/剑锋缺折难冲斗，/桐尾烧燋岂望琴？
诗：感旧两行年老泪，/酬恩一寸岁寒心。/忠州好恶何须问，/鸟得辞笼不择林。

# 初除官蒙裴常侍赠鹘衔瑞草绯袍鱼袋因谢惠贶兼抒离情

诗：鱼缀白金随步跃，/鹘衔红绶绕身飞。/明朝恋别朱门泪，/不敢多垂恐污衣。

# 洪州逢熊孺登

# 初著刺史绯答友人见赠
诗：故人安慰善为辞；/五十专城道未迟。/徒使花袍红似火，/其如蓬鬓白成丝。
诗：且贪薄俸君应惜，/不称衰容我自知。/银印可怜将底用？/只堪归舍吓妻儿。

# 又答贺客
诗：银章暂假为专城，/贺客来多懒起迎。/似挂绯衫衣架上，/朽株枯竹有何荣？

# 别草堂三绝句
诗：正听山鸟向阳眠，/黄纸除书落枕前。/为感君恩须暂起，/炉峰不拟住多年。
诗：久眠褐被为居士，/忽挂绯袍作使君。/身出草堂心不出，/庐山未要动《移文》。
诗：三间茅舍向山开，/一带山泉绕舍回。/山色泉声莫惆怅，/三年官满却归来。

# 钟陵饯送

# 浔阳宴别此后忠州路上作

诗：暮景牵行色，/春寒散醉颜。/共嗟炎瘴地，/尽室得生还。

# 戏赠户部李巡官
诗：好去民曹李判官，/少贪公事且谋欢。/男儿未死争能料，/莫作忠州刺史看。

# 行次夏口先寄李大夫
诗：连山断处大江流，/红旆逶迤镇上游。/幕下翱翔秦御史，/军前奔走汉诸侯。
诗：曾陪剑履升鸾殿，/欲谒旌幢入鹤楼。/假著绯袍君莫笑，/恩深始得向忠州。

# 重赠李大夫
诗：早接清班登玉陛，/同承别诏直金銮。/凤巢阁上容身稳，/鹤锁笼中展翅难。
诗：流落多年应是命，/量移远郡未成官。/惭君独不欺憔悴，/犹作银台旧眼看。

# 对镜吟

诗：三殿失恩宜放弃，/九宫推命合漂沦。/如今所得须甘分，/腰佩银龟朱两轮。

# 题岳阳楼
诗：岳阳城下水漫漫，/独上危楼凭曲栏。/春岸绿时连梦泽，/夕波红处近长安。
诗：猿攀树立啼何苦？/雁点湖飞渡亦难。/此地唯堪画图障，/华堂张与贵人看。

# 入峡次巴东
诗：不知远郡何时到？/犹喜全家此去同。/万里王程三峡外，/百年生计一舟中。
诗：巫山暮足沾花雨，/陇水春多逆浪风。/两片红旌数声鼓，/使君髅上巴东。
