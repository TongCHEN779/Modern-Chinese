# 作者小传
原：阿卜杜·拉赫曼·麦吉德·拉比伊（1939—），伊拉克作家。生于纳西里亚城。曾就读于高等学院绘画系。毕业后从事教学工作。后专事文学创作。著有短篇小说集《黥墨》、《水的秘密》及中、长篇小说《剑与船》、《河流》、《月亮与篱笆》、《巢穴》等。早期用象征主义手法，表现知识分子的苦闷与彷徨。七十年代后，以现实主义为创作方法。近期小说有诗化和散文化倾向。他是伊拉克有代表性的当代作家之一。

# 水的秘密
原：（李琛 译）
原：自从那日将你追赶，
原：哪一夜我不盼着你。
原：莫以为笛子是我喜嗜的消遣，
原：只因心儿将你刻在眼帘。
原：杰米勒·布塞那

# 一
原：他脸露畏惧，坐在我面前，极其缓慢地诉说着。不时停顿下来，又现出另一张哑然伤感的脸。
原：狂风在小岛茅屋间肆虐。位于礁湖中的这只小岛有个“小丸子”的昵称。我们围坐在火边，躺在苇席上，不敢靠近茅屋的墙壁，以防蛇虫从冬眠中苏醒。
原：他叫哈蒂姆，是我们在茫茫水面上遇到的第一个人。向导早已谈起他的情况：声音、情人、对水和芦苇的热爱。
原：他从一叶小舟上轻轻跳起，苍白的脸上露出惊喜后的热情。他迅速取来带有图案的毛织小毯，铺在席上，又站起来忙乎着烧咖啡。
原：我至今记忆犹新。他已置身在朋友中间，他的声音排除了我们远在水乡的孤寂。但是，我感到他依然孤单单距我们很远。
原：我还记得，我们谈起民歌和乡村音乐的特色时，他谈兴很浓，隔壁茅屋传来男孩的哭叫，他中断谈话走出来，抱回一个男孩哄着。
原：他把堆放在屋里的几块牛粪搬过来，投入火堆，浇上瓶里的石油。火苗窜起来，照亮了众人的面孔。干完这些，他才又继续说话。
原：“这是我的儿子。”
原：“他在情人出嫁后，立即与表妹成婚。”向导解释说。
原：他打断向导的话。
原：“我不能和表妹过，我的心容不下她。夜里，我想不起和她亲热。离开她以后，我才知道她怀孕了，就是这个孩子。”
原：他用手抚摸着孩子的头，亲了亲。出去取来几块干粪，接下去说：
原：“我和妻子离了婚，她把儿子给了我，准备再婚。”
原：“后来她真的结婚了。”
原：他手指着沉睡的礁湖，从茅屋敞开的门能望见波光粼粼的湖面。“我的心病在那儿。”

# 二
原：他俩住在希贾兹与麦地那之间的各地。人们传说他爱上了姑娘，不过他的爱始终是纯洁的……
原：摘自杰·布塞那生平

# 三
原：黑沉沉的夜。一叶小舟划破水面，在芦苇和高高的莎草间穿行。
原：小舟上的渔火似城里的汽车灯在远方一闪一闪。
原：“你们知道这水上通道也有个称呼？”向导问。
原：“道儿在哪儿？”我说。
原：向导笑了。
原：“只有湖上的人知道。他们从太阳星星的高度、波浪的运动、水禽鱼类的聚散，甚至从对礁湖水面的直觉中知道的。”
原：我低下头沉吟片刻。然后抬起头，望着漫漫无际的水面。波光弄影，清新的空气溢满胸间。
原：哈蒂姆请我们观看夜间捕鱼的盛况。那是礁湖最美好的节日，达到它奉献的顶峰。渔民在这个季节里，手握带有锋利箭头的铁枪。（相传那是苏美尔人的器具。据此，历史学家认为礁湖人是苏美尔人的后代，礁湖岛使这些人与世隔绝，从而保留了祖先的习俗。）石油灯放在船头，用以吸引鱼儿浮上水面。他们手疾眼快熟练地扎起鱼儿，扔到船后，再接着捕捉另一条。
原：渔猎从黄昏时分开始，持续一夜，直到东方泛白。然后，满载的渔舟驶向渔贩子的茅屋，开始迅速的交易。鱼贩子把鱼运到大船上，从杰巴耶什市用汽车装运至伊拉克各城市。
原：那夜，小舟划破水面的惬意至今难以忘怀。一个在我附近捕鱼的小伙子说：
原：“哈蒂姆不唱一个，怎么能尽兴！”
原：我请求哈蒂姆唱上一曲，他唱了。
原：他的声音圆润亲切，发自内心的清凉和爱意，给人温馨和欢悦。那是水和爱的和声，它浇灌干枯的心田，令泪水欢快地涌动。我们心醉神迷。他的声音令多愁善感的人为之动容，唏嘘不已。

# 四
原：诗人的爱在善良人的口中流传。姑娘的家人从他的诗中品出了味道，便不准姑娘与他来往。阻止适得其反，倒煽起了爱火。爱情令姑娘迷狂，致使家人决意让她立刻嫁人。最后把她嫁给了一个品行不端的男人。
原：摘自杰·布塞那生平

# 五
原：“哈蒂姆，你让我伤心了。”
原：他面无表情地凝视着我。我递给他一支烟，给他点上。他重重地吸了一口，说：
原：“这是我的命。我属于这儿，我不能到别处去。我长年和鱼打交道，变得和鱼差不多，我从未想过礁湖以外的生活。一旦跨出礁湖，我肯定会死，像鱼儿离开水一样活不了。”
原：“那儿会杀死我，一切就全结束了。唱歌是我在呼救，迟早我为此所累，永远闭上嘴。”
原：“你知道我为什么到这儿来？”我笑着问。
原：“你对我们感兴趣，想向外介绍我们，把我们变成满足他人好奇心的东西。我们怎么能生活在茅屋之上，而让来自美国、澳大利亚、印度的游客参观呐。”
原：“这不是我的目的，我是社会学家，我来此为准备一篇此地人生活和健康的报告。”
原：“你以前不知道？”
原：“我知道过去的情况。现在，我想了解过去遗留在你们身上的痕迹。”
原：他大声笑起来，郑重其事地说：
原：“你已亲眼见到了。不过，你别忘了，我们唯一的区别是你们为生活奔波，我们不是。我们卖给你们鱼芦苇席子鸟儿，只从城里换回糖和衣服。我们得到的只是我们付出的一小部分。

# 六
原：向导道了晚安，转身去睡。他拔出腰间的左轮枪放在枕下，躺在离我们不远的地方，合上眼之前又说：
原：“我困极了。一天又说又跑真够累的。”
原：哈蒂姆出去，带进几块干粪。他把咖啡壶放在一边，吹灭了火，把火种埋进灰堆。
原：“你知道我已上完了小学？”
原：“看来是这样。”
原：“现在，我把字母忘了个一干二净，已经不会写字了，我不需要写字，没人需要我写信给他。”
原：“学校就在礁湖边上。有一天，我发觉背着书包上学毫无意义。我问自己，上学会有什么结果？我想当一个戴官帽，穿分腿西装裤的职员？我可不愿意，生活就在这儿。”
原：他用食指在地下戮了一下，又说：
原：“渔季快要结束了。以后，我们准备割芦苇、垛草。”他给我解释编草席的过程：先用刀直着把苇子剖开，再分细。一般这活由妇女来做。然后，男女开始编席，进展很快。
原：“我们就这样生活，只发生过一次重大事件。男人去朝拜侯赛因墓地，大火吞没了岛上的茅屋和动物牲口。火从一间茅屋燃起。当时风势很猛，把火星带到其他住处。女人控制不了火势，只好跳进水里，等待大火自己媳灭。”
原：那夜，我们谈了很久。他问我想不想睡，我说：
原：“不想。这里的蚊子真厉害，快钻进我的皮肤里。”
原：“夏天来，你一小时也呆不住。我们的皮肤早已结茧子了，蚊子咬一口不算回事儿。”
原：“几年前，曾有一种小鱼光顾了这个岛子，它吞吃蚊虫，明天，我指给你看这种鱼，它不能吃，而且还咬人。可是，我们欢迎它。到现在，它起码已吃掉四分之三的蚊虫，岛民称它为苏联鱼，也有人直呼其为‘苏联人。政府将其引进，他们这么告诉我们的。”
原：我认真地听他讲话。他向我敞开了心扉，我们把他当成主人，让他高兴。向导告诉我，岛民都很嫉妒他，因为我们给他而没给别人待客的荣耀，岛民慷慨好客，他们选择路边而居，为的是先于他人招待远方的来客。
原：哈蒂姆接着又说：
原：“蛇是我们的大敌。很多人被蛇咬死了，去年最后一个死鬼是我的表弟。”
原：然后，他讲了表弟被咬的经过。
原：“表弟捕鱼时，感到身体困倦，便躺在船上休息。蛇从水里爬到船上，咬了他一口，又钻回水中。天黑了，我们发现他不在，到处寻找，那时，毒液已扩散到全身，他中毒而死。”

# 七
原：青蛙在礁湖岛的四面八方不停地鸣唱。不时还传来水禽的叫声。这声音令外来人坐立不安，难以入眠。
原：哈蒂姆笑着对我说：
原：“你知道，我是这儿唯一喝酒的人？”
原：“从哪弄来的酒？”
原：“我让每周去休假的士兵带来的。”
原：“早知道我给你带上两瓶。”
原：“这儿没人知道酒醉有多舒坦。一次我喝醉了，岛上的人以为我疯了。醒来时发现我被绳子绑住，护身符系在脖子上。我以所有圣人的名义起誓，才使他们相信我已恢复正常。我父亲在不远处哭泣，他奔至最壮的一头牛跟前，宰了它，放声说：
原：“主呀，你听见了我的祈祷，这个宰牲是为报答你的，请吧！”

# 八
原：他对我详细讲了他的爱情故事。
原：“那是一种每天都发生的故事。我爱她，她也爱我。我想娶她，可她父亲不同意。我答应把自己拥有的一切都给他，他还是拒绝。他说，他要嫁女儿给儿子换回个女人。我说，我没有妹妹，但我可以为他找一个。他就是不肯。后来有一个男人来了，把妹妹留下，带走了她。他们就住在东边的茅屋里。”
原：“你听说过诗人杰米勒·布塞那的故事吗？”
原：“好像听说过，我记性不好。”
原：然后，我就和他唠叨起杰米勒的爱情故事。他很想听他的诗，哪怕一句也好。我搜肚刮肠，终于记起这么一句：假若你被召去为我送葬，我将在男人手里还阳。
原：哈蒂姆大声叫好。
原：“说得好，主呀，太棒了。”
原：“这样的诗句在民歌里也能找到。”
原：“说说看。”
原：他非常用心地唱了起来。
原：“假若你经过墓地，我的尸骨会跳动起来。”

# 九
原：我翻开笔记本，记下了一个家庭每月的收入，他们的生活环境，诸如蛇、苏联鱼、蚊虫、芦席等等。不过，我怎么也写不出哈蒂姆的事。我几次无意识地写下他的名字，每次的笔迹都不相同。一次把字母拉长，一次把字母变成圆形，一次又把每个字母分开。我问他：
原：“我请你进城，你去吗？”
原：“不。”
原：“为什么？”
原：“二三年，我离开礁湖岛一次。我去纳贾夫、克尔巴拉朝拜圣人墓地。每次回来，我都觉得不舒服。我的脑袋受不了城市的吵闹，特别是汽车马达声。我讨厌城里的味道，也不习惯城里的饭食。”
原：我写下自己的地址，把字条递给他。
原：“说不定哪天你会进城。”

# 十
原：我们醒来时，东方已经破晓。礁湖岛呈现出一派肃穆、清凉、壮观的景色。湖上消尽了渔舟的歌声笑声，变得空空旷旷。远远的天边飘散着朵朵白云，预示着夏日的临近。鸪鹚鸟拍打着翅膀，发出欢快的叫声，从水中啄出小鱼带到高处。
原：我们的小舟滑过水面，哈蒂姆伫立舟头，不紧不慢地摇着长桨，哗哗的水声好似他在水面上弹奏出的美妙乐曲。
原：向导向我们介绍这个水域：
原：“这里的茅屋称作小毛驴”。
原：“为什么叫这么个名字？”我笑着问。
原：“不知道。”
原：我又问哈蒂姆，他答道：
原：“自从我记事起就叫这名字。不知是谁取的，也许是个玩笑话或者是哪个居民有头小毛驴。”
原：离开小毛驴，又见一处人口密集的茅屋群，哈蒂姆举起手中的桨，指着说：
原：“这个叫大毛驴。”
原：我立即开怀大笑。
原：“我再不问你为什么了啦。”
原：向导挪揄地说：
原：“也许是小毛驴他妈。”
原：他的评论愈发引起我的笑声，我们的船绕着浮于水面、随风缓缓飘荡的茅屋转了一圈。
原：哈蒂姆望着满载的鱼船，将我们的小舟泊在茅屋门前。“在礁湖岛上最重要的是没有贼。”
原：“肯定是这么回事。贼从哪来，又怎么出去。”
原：哈蒂姆转到茅屋的东边。
原：“所以，我们不用养狗。没人弄条狗来养。”
原：“几个月前，我看见哈吉的儿子哈希姆从杰巴依什带回来一只狗，他挺高兴的。”
原：哈蒂姆像是记起了这件事，补充道：
原：“对，不过小狗给淹死了。”
原：他反问向导：
原：“你知道他为什么带狗回来？”
原：“不知道。”
原：“因为他想去哈费兹。”
原：向导口中念念有词，然后说：
原：“安拉饶恕这个可怕的魔鬼。”
原：哈蒂姆给我解释说：
原：“人说魔鬼怕黑狗。只要他带上条黑狗，就可以到达哈费兹，魔鬼听到狗吠，拔腿便跑，他就乘机窃得魔鬼看守的宝藏。”
原：“也许是魔鬼掐死了小狗，把它扔到了水里。”
原：“什么事都有可能。不过，我不知道哈费兹在哪儿，恐怕没人知道。我没想到过要去那儿，因为我什么也不缺。感谢安拉。”

# 十一
原：我取出记事簿，想记上点什么。我把哈费兹写了几遍，这个地名与原先写的哈蒂姆的名字混在一起。我想尽快记下哈费兹故事的详细内容，以便将来从城里返回时，脑子里已经有了我的解释和推断。
原：纸上只有哈费兹和哈蒂姆两个名字。我反反复复地审视着，然后取出另一张白纸，坐在地上，艰难地书写。这样子既不利于我记下资料也不利于我冷静思考。
原：我记下，哈费兹对礁湖岛居民是个恐怖的疑团，每当我问起它，居民会陷于恐惧的沉默之中，或不停地默念安拉的名号。
原：我记下我该阅读的西方旅行家的著述，他们在此地的经历无疑给我补充了许多材料。
原：我又记下，哈费兹可以满足我的好奇心。
原：在另外一处，我写道：
原：哈费兹是两者之一：在礁湖岛上被水淹没了的一块高地。所以，上面有动物、蛇和受伤的鸟类，它们不堪忍受而想离开，或许长期居住习惯已成自然，这是其一。
原：其二，哈费兹是不可言状的力量，是诸如死亡、失踪等岛上居民解释不了的现象的依据，恐惧阻止他们不愿再去想它。
原：我写道：假若哈费兹是已知的地方，神话就不复存在。我深深地吸了一口烟，又拿起第一张纸，读着上面的哈蒂姆和哈费兹两个名字。
原：我写上：
原：哈蒂姆=哈费兹
原：哈费兹=哈蒂姆
原：哈蒂姆≠哈费兹
原：哈费兹≠哈蒂姆
原：我厌烦地合上了本子。

# 十二
原：哈蒂姆说：
原：“你知道，杰米勒的故事很像我的故事。”
原：“我知道。”
原：你告诉过我，人们传诵他的诗，最后也传到姑娘的耳朵里。我不用写诗，我唱歌。歌声不需要人去传诵。她离我很近，你知道吗？昨夜，我在礁湖岛深处唱歌，觉得我是唱给她听，她能听见。即使她躺在丈夫的怀抱里，接受她的爱抚，也会哭出来的。
原：他沉默了好一会儿，对自己的举动颇为得意。
原：“你想在你的报告里写进情人的约会吗？好，我讲给你听。情人的幽会处在芦苇和莎草之间的水道上。男女青年给牛吃上点鸦片，一出村牛群便走散。他们迅速到约定的地点会面。男人的小舟靠在情人的舟旁。
原：我们来到满载鱼和席子的大船旁，大船将带我们去巴士拉。哈蒂姆弯腰拎起我装着没有用过的睡衣和牙刷的小箱子，递给我。
原：我紧紧握着他的手。
原：“哈蒂姆，你想从城里带点什么？”
原：他喃喃地答道：
