# 一
原：繁星闪烁着——
原：深蓝的太空，
原：何曾听得见他们对语？
原：沉默中，
原：微光里，
原：他们深深的互相颂赞了。

# 一〇
原：嫩绿的芽儿，
原：和青年说：
原：“发展你自己！”
原：淡白的花儿，
原：和青年说：
原：“贡献你自己！”
原：深红的果儿，
原：和青年说：
原：“牺牲你自己！”

# 一六
原：青年人呵！
原：为着后来的回忆，
原：小心着意的描你现在的图画。

# 二三
原：心灵的灯，
原：在寂静中光明，
原：在热闹中熄灭。

# 二八
原：故乡的海波呵！
原：你那飞溅的浪花，
原：从前怎样一滴一滴的敲我的磐石，
原：现在也怎样一滴一滴的敲我的心弦。

# 三〇
原：光阴难道就这般的过去么？
原：除却缥缈的思想之外，
原：一事无成！

# 三四
原：创造新陆地的，
原：不是那滚滚的波浪，
原：却是他底下细小的泥沙。

# 四五
原：言论的花儿
原：开的愈大，
原：行为的果子
原：结得愈小。

# 四八
原：弱小的草呵！
原：骄傲些罢，
原：只有你普遍的装点了世界。

# 四九
原：零碎的诗句，
原：是学海中的一点浪花罢；
原：然而他们是光明闪烁的，
原：繁星般嵌在心灵的天空里。

# 五三
原：我的心呵！
原：警醒着，
原：不要卷在虚无的漩涡里！

# 五五
原：成功的花。
原：人们只惊慕她现时的明艳！
原：然而当初她的芽儿，
原：浸透了奋斗的泪泉，
原：洒遍了牺牲的血雨。

# 六四
原：聪明人！
原：要提防的是：
原：忧郁时的文字，
原：愉快时的言语。

# 六七
原：渔娃！
原：可知道世人羡慕你？
原：终身的生涯，
原：是在万顷柔波之上。

# 七七
原：小磐石呵，
原：坚固些罢，
原：准备着前后相催的波浪！

# 八八
原：冠冕？
原：是暂时的光辉，
原：是永久的束缚。

# 九四
原：我知道了，
原：时间呵！
原：你正一分一分的，
原：消磨我青年的光阴！

# 九五
原：人从枝上折下花儿来，
原：供在瓶里—
原：到结果的时候，
原：却对着空枝叹息。

# 一二五
原：蜜蜂，
原：是能溶化的作家；
原：从百花里吸出不同的香汁来，
原：酿成他独创的甜蜜。

# 一三一
原：大海呵，
原：哪一颗星没有光？
原：哪一朵花没有香？
原：哪一次我的思潮里
原：没有你波涛的清响？

# 一五六
原：清晓的江头，
原：白雾濛濛，
原：是江南天气，
原：雨儿来了—
原：我只知道有蔚蓝的海，
原：却原来还有碧绿的江，
原：这是我父母之乡！
原：一，一九二二
