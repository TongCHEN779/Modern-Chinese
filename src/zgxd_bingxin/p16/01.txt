# 一八
原：冰雪里的梅花呵！
原：你占了春先了。
原：看遍地的小花
原：随着你零星开放。

# 二三
原：平凡的池水
原：临照了夕阳，
原：便成金海！

# 二四
原：小岛呵！
原：何处显出你的挺拔呢？
原：无数的山峰
原：沉沦在海底了。

# 三二
原：渔舟归来了，
原：看江上点点的红灯呵！

# 三三
原：墙角的花！
原：你孤芳自赏时，
原：天地便小了。

# 五一
原：鸡声
原：鼓舞了别人了！
原：它自己可曾得到慰安么？

# 七六
原：寂寞增加郁闷，
原：忙碌铲除烦恼——
原：我的朋友！
原：快乐在不停的工作里！

# 八七
原：青年人！
原：只是回顾么？
原：这世界是不住的前进呵。

# 九四
原：什么是播种者的喜悦呢？
原：倚锄望
原：到处有青青之痕了！

# 一〇〇
原：当青年人肩上的重担
原：忽然卸去时，
原：他勇敢的心
原：便要因着寂寞而悲哀了！

# 一一二
原：浪花愈大，
原：凝立的磐石
原：在沉默的持守里，
原：快乐也愈大了。

# 一二五
原：修养的花儿
原：在寂静中开过去了，
原：成功的果子
原：便要在光明里结实。

# 一三四
原：命运如同海风—
原：吹着青春的舟，
原：飘摇的，
原：曲折的，
原：渡过了时光的海。

# 一五三
原：笠儿戴着，
原：牛儿骑着，
原：眉宇里深思着——
原：小牧童！
原：一般的沐着大地上的春光呵，
原：完满的无声的赞扬，
原：诗人如何比得你！

# 一六七
原：绿水边—
原：几双游鸭，
原：几个浣衣的女儿，
原：在诗人驴前
原：展开了一幅自然的图画。

# 一七四
原：青年人，
原：珍重的描写罢，
原：时间正翻着书页，
原：请你着笔！
原：三，一九二二
