# 王沂孙
原：沂孙，字圣与，号碧山，又号中仙，又号玉笥山人，会稽人。至元中为庆元路学正，有《碧山乐府》，又名《花外集》，有《知不足斋丛书》本，又有四印斋刊本。
原：张炎云：碧山能文工词，琢句峭拔，有白石意度。（《词源》）
原：周济云：碧山餍心切理，言近指远，声容调度，一一可循。又云：碧山胸次恬淡，故《黍离》、《麦秀》之感，只以唱叹出之，无剑拔弩张习气。又云：咏物最争托意，隶事处以意贯串，浑化无痕，碧山胜场也。（《四家词选序论》）又云：中仙最多故国之感，故著力不多，天分高绝，所谓意能尊体也。又云：中仙最近叔夏一派，然玉田自逊其深远。（《介存斋论词杂著》）
原：邓廷桢云：王圣与工于体物，而不滞色香。（《双砚斋随笔》）
原：戈载云：予尝谓白石之词，空前绝后，匪特无可比肩，抑且无从入手，而能学之者，则惟中仙。其词运意高远，吐韵妍和，其气清、故无懑之音，其笔超、故有宕往之趣，是真白石之入室弟子也。（《七家词选》)
原：陈廷焯云：王碧山词，品最高、味最厚、意境最深、力量最重，感时伤世之言，而出以缠绵忠爱，诗中之曹子建、杜子美也。词人有此，庶几无憾。又云：词法之密，无过清真；词格之高，无如白石；词味之厚，无过碧山；词坛三绝也。又云：碧山词，观其全体，固自高绝；即于一字一句间求之，亦无不工雅，琼枝寸寸玉，旃檀片片香；吾于词见碧山矣，于诗则未有所遇也。（《白雨斋词话》）
原：王鹏运云：碧山词颉颃双白，揖让二窗，实为南宋之杰。(《碧山词跋》)

# 天香·龙涎香
原：孤峤蟠烟，/层涛蜕月，/骊宫夜采铅水。/汛远槎风，/梦深薇露，/化作断魂心字。/红磁候火，/还乍识、冰环玉指。/一缕萦帘翠影，/依稀海天云气。
注：峤（qiáo乔）：山锐而高。
注：骊宫：骊龙所居之处。
注：汛（xùn迅）：水盛。
注：槎（chá察）：水中浮木。
注：心字：香名。番禺人作心字香，见范成大《骖鸾录》。
注：候火：及时之火。
注：冰环玉指：香饼形状如环如指。
原：几回帶娇半醉，/剪春灯、夜寒花碎。/更好故溪飞雪，/小窗深闭。/荀令如今顿老，/总忘却尊前旧风味。/漫惜薰，/空篝素被。
注原：荀令：荀彧字文若，为汉侍中，守尚书令，曹公与筹军国大事，称之为荀令君。习凿齿《襄阳记》：“荀令君至人家，坐幙三日，香气不歇。”
注：空篝素被：见前周邦彦《花犯》注。
原：【评笺】许昂霄云：诸香龙涎为最，出大食国，近海傍，常有云气罩山间，即知有龙睡其下。半载或一二载，土人更相守视，俟云散龙去，往必得龙涎。又一说大洋海中，龙在其下，涌出之涎，为日所烁成片，风漂至岸，人得取之。（《词综偶评》)
原：《岭南杂记》云：龙枕石而睡，涎沫浮水，积而能坚，鲛人采之，以为至宝，新者色白，久者色紫，甚久则黑，其气近于臊；形如浮石而轻，腻理光泽，入香焚之，则翠烟浮空，结而不散；又云和众香焚之，能聚香烟，缕缕不散，盖龙能兴云，亦蜃气楼台之例也。
原：《乐府补题》云：宛委山房赋“龙涎香”，调《天香》；浮翠山房赋“白莲”，调《水龙吟》；紫云山房赋“莼”，调《摸鱼儿》；闲书院赋“蝉”，调《齐天乐》；天柱山房赋“蟹”，调《桂枝香》。倡和者为玉笥王沂孙圣与、蘋州周密公谨、天柱王易简理得、友竹冯应瑞祥父、瑶翠唐艺孙英发、紫云吕同老和父、筼房李彭老商隐、宛委陈恕可行之、菊山唐珏玉潜、月洲赵汝钠真卿、五松李居仁师吕、玉田张炎叔夏、山村仇远仁近，皆宋遗民也。
原：蔡绦云：奉宸库者，祖宗之珍藏也。政和中，太上于库中得龙涎香二，分锡大臣近侍，其模制甚大而质古，外视不大佳，每以一豆大爇之，辄作异花气，芬郁满座，终日累不歇。于是太上大奇之，命藉被赐者随数多寡，复收以归中禁，因号曰古龙涎，为贵也。诸大珰争取一瓶，可直百缗，金玉穴而以青丝贯之，挂于颈，时于衣领间摩挲以相示，坐此遂作佩香焉。今佩香，盖因古龙涎始也。（《铁围山丛谈》）
原：蔡绦又云：旧说蔷薇水，乃外国采蔷薇花上露水；殆不然。实用白金为甑，采蔷薇花蒸气成水，则屡采屡蒸，积而为香，此所以不败。但异域蔷薇花气馨烈非常，故大食国蔷薇水虽贮琉璃缶中，蜡密封其外，然香犹透彻，闻数十步。洒著人衣袂。经十数日不歇。至五羊效外国造香，则不能得蔷薇，第取素馨茉莉花为之，亦足袭人鼻观。但视大食国真蔷薇水犹奴尔。（《铁围山丛谈》)
原：周尔墉云：密栗是极用力之作。（周评《绝妙好词》)

# 眉妩·新月
原：渐新痕悬柳，/淡彩穿花，/依约破初暝。/便有团圆意，/深深拜，/相逢谁在香径？/画眉未稳，/料素娥、犹带离恨。/最堪爱、一曲银钩小，/宝奁挂秋冷。
注：深深拜：李端《新月诗》：“开帘见新月，即便下阶拜。细语人不闻，北风吹裙带。”
注：银钩：喻新月。
原：千古盈亏休问，/叹慢磨玉斧，/难补金镜。/太液池犹在，/凄凉处、何人重赋清景？/故山夜永，/试待他窥户端正。/看云外山河，/还老桂花旧影。
注：玉斧：相传汉吴刚曾以斧伐月中桂，见《酉阳杂俎》。
注：太液池：卢多逊《新月诗》：“太液池边看月时。”
原：【评笺】陈廷焯云：千古句忽将上半阕意一笔撇去，有龙跳虎卧之奇，结更高简。（《白雨斋词话》)
原：谭献云：圣与精能以婉约出之。律以诗派，大历诸家，去开、宝未远，玉田正是劲敌，但士气则碧山胜矣，“便有”三句，则寓意自深，音辞高亮，欧晏如兰亭真本，此仅一翻。（《谭评词辨》）
原：张惠言云：碧山咏物诸篇，并有君国之忧，此喜君有恢复之志，而惜无贤臣也。(张惠言《词选》)

# 齐天乐·蝉
原：一襟恨宫魂断，/年年翠阴庭树。/乍咽凉柯，/还移暗叶，/重把离愁深诉。/西窗过雨，/怪瑶佩流空，/玉筝调柱。/镜暗妆残，/为谁娇鬓尚如许?
注：宫魂断：齐王后怨王而死，尸变为蝉，见《古今注》。
原：铜仙铅泪似洗，/叹移盘去远，/难贮零露。/病翼惊秋，/枯形阅世，/消得斜阳几度？/音更苦，/甚独抱清商，/顿成凄楚。/漫想薰风，/柳丝千万缕。
注原：清商：即清商曲，古乐府之一种。曹丕《燕歌行》：“援琴鸣弦发清商，短歌微吟不能长。”
原：【评笺】周济云：此家国之恨。（《宋四家词选》)
原：谭献云：此是学唐人句法、章法；“庾郎先自吟愁赋”，逊其蔚跂。（《谭评词辨》)
原：陈廷焯云：字字凄断，却浑雅不激烈。（《白雨斋词话》)
原：端木埒云：详味词意，殆亦黍离之感耶！宫魂字点出命意，乍咽还移，慨播迁也。“西窗”三句，伤敌骑暂退，燕安如故。“镜暗”二句，残破满眼，而修养饰貌，侧媚依然，衰世臣主，全无心肝，千古一辙也。“铜仙”三句，宗器重宝，均被迁败，泽不下究也。“病翼”二句，是痛哭流涕，大声疾呼，言海岛栖流，断不能久也。“音”三句，遗臣孤愤，哀怨难论也。“漫想”二句，责诸臣到此，尚安危利灾，视若全盛也。(张惠言《词选》评)

# 长亭怨慢·重过中庵故园
原：泛孤艇东皋过遍，/尚记当日，/绿阴门掩。/屐齿莓苔，/酒痕罗袖事何限？/欲寻前迹，/空惆怅成秋苑。/自约赏花人，/别后总、风流云散。
注：泛孤艇东：中庵：元刘敏中号中庵，有《中庵乐府》。
注：屐齿：木履施两齿，可以践泥。
原：水远，/怎知流水外，/却是乱山尤远。/天涯梦短，/想忘了绮疏雕槛。/望不尽冉冉斜阳，/抚乔木年华将晚。/但数点红英，/犹识西园凄婉。
原：【评笺】周尔墉云：后半阕一片神行，笔墨到此俱化。（周批《碧山词》）

# 高阳台·和周草窗《寄越中诸友》韵
原：残雪庭阴，/轻寒帘影，/霏霏玉管春葭。/小帖金泥，/不知春是谁家？/相思一夜窗前梦，/奈个人水隔天遮。/但凄然、满树幽香，/满地横斜。
注：春葭：见前卢祖皋《宴清都》注。
注：小帖金泥：唐进士及第，以泥金书帖附家中，报登科之喜。见《卢氏杂记》。
原：江南自是离愁苦，/況游骢古道，/归雁平沙。/怎得银笺，/殷勤说与年华。/如今处处生芳草，/纵凭高不见天涯。/更消他，/几度东风，/几度飞花。
原：【评笺】周密原词云：小雨分江，残寒迷浦，春容浅入蒹葭，雪霁空城，燕归何处人家。梦魂欲渡苍茫去，怕梦轻还被愁遮。感流年，夜汐东还，冷照西斜。凄凄望极王孙草，认云中烟树，沤外平沙。白发青山，可怜相对苍华。归鸿自趁潮回去，笑倦游犹是天涯。问东风，先到垂杨，后到梅花？（《草窗词》）
原：张惠言云：此伤君臣晏安，不思国耻，天下将亡也。（张惠言《词选》)
原：周尔墉云：莫两山词，“直饶明日便春晴，已是一春闲过了”；与此收笔用意相反，而一用进笔，一用缩笔，洵为异曲同工。（周批《草窗词》)
原：况周颐云：结笔低徊掩抑，荡气回肠。（《蕙风词话》)
原：陈廷焯云：上半阕是叙其远游未还，悬揣之词；下半阕是言其他日归后情事，逆料之词。（《白雨斋词话》）
原：谭献云：“相思”句点逗清醒，换头又是一层钩勒；《诗品》云：返虚入浑，如今二句是也。（《谭评词辨》）
原：王闿运云：此等伤心语，词家各自出新，实则一意，比较自知文法。（《湘绮楼词选》）

# 法曲献仙音·聚景亭梅次草窗韵
原：层绿峨峨，/纤琼皎皎，/倒压波痕清浅。/过眼年华，/动人幽意，/相逢几番春换。/记唤酒寻芳处，/盈盈褪妆晚。/已消黯，/况凄凉近来离思，/应忘却明月，/夜深归辇。/荏苒一枝春，/恨东风人似天远。/纵有残花，/洒征衣、铅泪都满。/但殷勤折取，/自遣一襟幽怨。
注：层绿：指绿梅。
注：纤琼：细玉，指白梅。
原：【评笺】周密原词云：松雪飘寒，岭云吹冻，红破数枝春浅，衬舞台荒，浣妆池冷，凄凉市朝轻换，叹花与人凋谢，依依岁华晚。共凄黯，问东风几番吹梦，应惯识当年，翠屏金辇。一片古今愁，但废绿平烟空远。无语销魂，对斜阳衰草泪满。又西泠残笛，低送数声春怨。（《草窗词》)
原：董嗣杲云：聚景园在清波园外，阜陵致养北宫，拓圃西湖之东，斥浮屠之庐九，曾经四朝临幸，继以谏官陈言，出郊之令遂绝，园今芜圮，惟柳浪桥花光亭存。（《西湖百咏》注)
原：吴自牧云：高似孙《过聚景园诗》云，翠华不向苑中来，可是年年惜露台；水际春风寒漠漠，官梅却作野梅开。（《梦粱录》)
原：张宗棣云：按此阕和草窗原韵，但草窗题是香雪亭，此云聚景亭，异。（《词林纪事》)
