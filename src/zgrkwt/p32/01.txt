# 积极实验　大胆摸索　进一步完善计划生育工作具体政策
原：晚婚晚育加间隔的生育办法，是对过去我国计划生育政策的进一步完善和具体化，这从以下几个方面可以得到说明。

# （一）提出晚婚晚育加间隔的依据
原：翼城县试行晚婚晚育加间隔的生育办法，是根据中央书记处108次会议和中央1984年7号文件精神提出来的。这一方面考虑到党的12大提出的人口控制指标，在2000年将我国人口控制在12亿左右另一方面又兼顾到我国经济社会发展水平，根据我国人口构成特点和广大农民家庭的实际困难。通过这种办法．我们试图如中央7号文件上所讲的，把计划生育政策建立在“合情合理，群众拥护，干部好做工作”的基础上，从而摸索出一条符合中国国情，适应中国特点的中国式的计划生育道路来。

# （二）晚婚晚育加间隔的具体内害仍然是过去计划生育的基本内容
原：晚婚晚育加间隔的涵义和我们制定的规定、细则都充分说明，它所强调的仍然是提倡和鼓励每对夫妇只生1个孩子，提倡晚婚、晚育、少生、优生，说明我们仍然是进行过去意义上的计划生育工作。晚婚晚育加间隔的生育办法，不过是对提倡生1个孩子和晚婚、晚育、少生、优生等计划生育内容的具体化。认为提出晚婚晚育加间隔的生育办法，就否定了原来的计划生育内容，这是一种误解。比如，允许农民生2个孩子，但这是有条件的，是建立在晚婚晚育和延长生育间隔基础之上的。允许有困难的农民家庭生2个孩子，并不是要求农民必须生2个。我们知道，现在的农民平均还是生2个以上的孩子，实行晚婚晚育加间隔的生育办法，农民家庭的2个孩子都要比现在生的晚。同时，因为计划管理更严了，妇女生第一个孩子更晚了，会促进出生率的降低，总的说少生了孩子。所以，这是把过去的计划生育工作进一步向深的方面发展了。

# （三）晚端晚育加间隔的办法没有否定过去的政策
原：从晚婚晚育加间隔的涵义到规定和细则，都没有否定过去的具体政策，相反，我们总是强调过去政策的作用，重申过去有关提倡和鼓励每对夫妇只生一个孩子的政策仍然有效。这种规定说明，晚婚晚育加间隔的办法并不否定多年来行之有效的计划生育政策。

# （四）晚婚晚青加间隔的生育办法是过去政策的延续
原：当然，不仅仅是没有否定过去的有关政策，同时，因为把过去的政策经过调整后，进一步把它落到了实处，所以成为过去政策的一种必然延续。比如说，过去的生育政策是通过奖惩条例贯彻计划生育的内容，希望引导群众只生1个孩子，减少计划外生育。但是，因为它把奖励定在只准生1个上，把处罚定在生了2个及2个以上的孩子上，出现了政策无法兑现的现象。几年来，在计划生育先进地区和先进单位，因为独生子女家庭比例比较高，人人受奖励：奖不起：而在大多数地区，因为做不到只生1个，大部分家庭生2个或2个以上的孩子，人人受罚，这都起不到政策应起的作用。把政策按晚婚晚育加间隔的办法调整之后，奖罚的面都是少数，就使过去的政策落到了实处。

# （五）比过去政策更切合实际了
原：如我们所看到的，过去的政策规定是一回事，农民的实际生育又是一回事。尽管要求农民家庭只生1个孩子。承认我国经济发展的现实，照顾到农民的实际困难，既鼓励和提倡生一个孩子，又根据农民的要求允许生2个，这就符合实际了。

# （六）比过去的计划生育内容更具体化和系统化
原：通过我们对规定和细则的学习不难看出，晚婚晚育加间隔的生育办法，是把提倡生1个、晚婚、晚育、少生、优生等内容联系在一起，并赋于特定的地位和作用在晚婚晚育加间隔的生育办法里，提倡和鼓励每对夫妇生1个孩子是前提，没有这个前提，就没有少生、优生。因为，杜绝多胎是同只生一个来讲有质的不同才能实行的。否则，同生2个孩子比，生3个仅仅是量上的差别。我们仍然提出提倡、鼓励只生1个，生3个就成为不合情理的事情了。
原：晚婚在这种生育办法中有很重要的意义。如果没有社会上大多数人的晚婚，在目前节制生育的技术条件下，就没有晚育。没有晚育，也就难做到少生。
原：晚育是少生的前提条件。妇女推迟生育，就意味着在育龄时期少生了孩子。
原：间隔是晚育，少生的条件。农民家庭生2个孩子之间的间隔时间越长，说明农民夫妇的避孕效果越好，这样，既推迟了生育第二个孩子的时间，又减少了生多胎的危险性。如果不是这样，农民夫妇生2个孩子间隔小，很早就生完了第二个孩子，而育龄时间还很长，就可能因各种原因生3个或3个以上的孩子。
原：每对夫妇只生1个孩子，以及晚婚、晚育、延长间隔、少生，都有利于优生，而优生又是我们实行计划生育的基本目的之一。
原：可见，晚婚晚育加间隔的生育办法，是把过去提出的计划生育内容都系统化了。

# （七）是向计划生育工作的正规化与科学管理的过渡和发展
原：过去我们因为人口构成和分布的底子不清，加上我们的政策离实际情况较远一些，人口控制指标总是由上而下的逐级下达.这样的指标往往形成“打快牛”，不科学。现在以实际的人口构成为基础，生育指标由下而上形成，接近实际，这就为计划生育工作的科学管理奠定了基础。

# （八）保护了计划生育干部和积极分干的积极性
原：晚婚晚育加间隔的生育办法在肯定过去计划生育工作的基础上，更符合实际了，向前发展了。执行这样的政策，可以允许过去因响应我们的号召而晚婚晚育、没有生第二个孩子的家庭生第二胎，继续处罚不实行计划生育的家庭，既维护了积极分子的利益，又保护了我们的干部，从而避免了因政策的变动而可能出现的被动局面，使我们作基层计划生育工作的同志可以更好地工作。
原：总之，晚婚晚育加间隔的生育办法，是我国计划生育工作发展的必然趋势，是进一步完善我国计划生育工作的具体政策。所以，我们应该积极实践，大胆摸索，不断总结经验，为完善我国计划生育工作的具体政策，做出应有的贡献。
