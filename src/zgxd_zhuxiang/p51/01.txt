# 二
原：我情愿拿海阔天空扔掉，
原：只要你肯给我一间小房——
原：象仁子蹲在果核的中央，
原：让我来躲避外界的强暴；
原：让我来领悟这生之大道，
原：脱胎换骨，变成松子清香。
原：核桃内丰外啬，杏仁润凉……
原：有的去给世人越吃越要；
原：有的，趁阳春飞越过山巅
原：那时候，生根著叶起来，慢，
原：很慢的……百年后他伸手爪
原：（他高呼，低唤在黑夜，白天）
原：要抓住那青，成年不变换，
原：与那硬，任风在四边骚扰。

# 三
原：我把过去摔在地上，教它：
原：你泥沼里去罢！本来泥沼
原：是你的老家；你不要再吵
原：闹在耳边……它却仍旧哇哇
原：作癞虾蟆的笑声；它紧抓，
原：紧抓住我的脚，两目奸狡
原：如蛇的钉住我。我不能跑。
原：我不是懦夫；我也咬起牙，
原：歪下头去看……我一阵寒噤：
原：因为这个丑物已经变作
原：我的模样，正在一套，一套，
原：变着各种的形……这时，遍身
原：我出汗，怒抖，整颗心象割；
原：我晕了……它又钻进了心窍……

# 九
原：我有一颗心，她受不惯幽闭，
原：屡次逃了出来，向过路的人
原：歌唱，好象孩童，在欢乐撞门
原：那时候，遇了人便倾吐喜气。
原：大了，她明白了，当时的失意
原：与恼怒都是稚态，别个那能
原：不拿这异样之物，来得无因，
原：抱起来耍，或是闪了身躲避？
原：从此，她守着幽室，一一笑
原：只让自家看见，也只让自家
原：听见梦中的呓语……要知道，她
原：原是生物，有时免不了要叫
原：喊出狱中的痛苦；她却不容
原：这心声送到陌生人的耳中。

# 一〇
原：辜负了这园林中的清气，
原：从前只有麻雀，力竭声嘶，
原：依然唱不出佳妙的歌词，
原：与鹊鸟，流俗般披着俏丽……
原：今天你来了这枝头，黄鹂，
原：只是矜持的将你那调子
原：唱了，并不曾拿尾端的紫，
原：身上的黄来卖弄着梳齐。
原：在翠氛中，你如今是想念
原：什么？可是那凤凰的国土，
原：你离开不久的？诗歌之友，
原：你要知道，这里有那飞舞
原：在半空的鹰，将战声高吼，
原：威吓着，不容你在此留连！

# 一四
原：有一首诗怀在这颗心里，
原：教我甘心输引春的滋长
原：与秋的成熟来拿她培养，
原：培养着她的天真与美丽。
原：一直到生命连成了周期，
原：为了她，我不能容许思想，
原：行为的高位上坐着寻常……
原：我的孱弱要扶持呀，上帝！
原：你给我的生命，等到悔悟，
原：已经被稚性蹂躏得无遗
原：如今又给我诗，你的恩惠！
原：放心；那无从补救的前非，
原：它在提醒我，只有一条路
原：在前面了……我不能再自弃！

# 一五　冻疮
原：不见十多年了，我们又重会，
原：这切肤的亲热还一似当先；
原：不同的是，如今我知道留恋，
原：在冷落中留恋着你的相偎，
原：这其间，有许多热已经高飞：
原：有许多希望已经遮起笑脸……
原：剩下我一人，在这空的冬天，
原：想着抛去的半生，忧伤，懊悔。
原：春天我不要瞧见它：那暖风
原：会来搔我的脸皮，低声嘲弄，
原：说，青春，幸福，如今去了那里t
原：还是你多情，又温暖，又凄凉，
原：不忘记我，悄然的来到身旁，
原：将沉滞挑动了，点燃起记忆。

# 一六　情感与理智
原：在一场奇特的梦里，我瞧见
原：躯壳中化出来了一双自我——
原：美丽，天真，左边的她正唱歌；
原：右边的，光芒绕体，他舞宝剑。
原：那护身的白光关照到四面，
原：不容烦恼洒的水丝毫透过，
原：同时，烦恼浇上了音乐的波，
原：那情调更丰富，节律更庄严
原：这一架的残剩我毫不关怀：
原：尽由你们去分了，“人生”，“破败”！
原：你们抓不住那永恒的一双……
原：虽说他们的途径各自东西，
原：唯有在天空上，唯有在梦里，
原：歌声才叫得应那剑影低昂。

# 一九　Hawthorne
原：如其我能有你的那座苔屋，
原：日里在廊前看暖色逗清幽；
原：晚上读书，或许，陪伴着朋友，
原：听栗子与柴薪对语在墙炉……
原：如其我能有你的深沉双目，
原：与但丁的一样，在蜂翼，花头
原：看见死去的蜂，花裸裎，颤抖，
原：又看苗条在已朽的根株……
原：如其我能象你那样，看人生
原：象看晚景，知道那光华，形象
原：只是日神在天上故弄狡狯；
原：只是一霎那的，那虫声似海……
原：等到他去了，唯有云气茫茫，
原：或许，好些，有一轮皓日东升。

# 二六
原：如其有一天我不再作小鸟，
原：回旋在溷浊的最下层空气，
原：只听到人类惹是非，话柴米，
原：只看见人头上茂生有烦恼！
原：如其有一天我能化作鹰，高
原：飞入清冷的天；在云内涤翼；
原：追陨星；对太阳把眼睛瞪起，
原：要那无上的光明向里面跳……
原：下边，我看见有洋海在呼吸；
原：大江，小河一齐蜿蜒去心脏；
原：山峰挺着她的奶，孳育群生
原：也偶尔自人境飞上有风筝，
原：向着天与日发出销声嘹亮，
原：在生机蓬勃的时候，春天里。

# 三六
原：哼着，电车来了，好象是埋怨
原：兜了一天的圈子还不休息；
原：它走过去，好象是哄在锅底
原：一灶光明的火，炒菜，煮晚饭。
原：汽车好象是舞女滑过地板，
原：身披着光泽；透明的，在车里
原：安坐有行旅，富庶或是游戏，
原：照了他们的话，车开驶，停站。
原：火车，在夜里，呼声特别的高
原：玄秘，朦胧的时候，虽是奔走
原：于刻板的轨道，也觉得上劲
原：好象是打哈欠，偶尔叫一叫，
原：轮船，蹲伏在水面，伸出舌头
原：向了高飞的月亮，向了众星。

# 三七
原：给我一个浪漫事！不论是“凶狠”
原：与“罪恶”安排起圈套等候“理想”
原：还是漂泊在远处，没有人，异常，
原：只有原始的“破坏”，“创造”在混沌；
原：还是神仙，未来，希望者的乾坤……
原：只要一个浪没事，给我，好阻挡
原：这现实，戕害生机的；我好宣畅
原：这勇气，这感情的块垒，这纠纷！
原：树木，空虚了，还是紧抓着大地，
原：盲日的等候着一声雷，一片热
原：给与它们以蓬勃，给与以春天……
原：自然不是来享福的，活在地面，
原：“淡漠”之领域；不过，这心在旅舍
原：要住六十年呀！那么，给它勇气！

# 四四
原：搀着自家的孩子，在这春天，
原：一同去晒太阳，吸花香，草息……
原：他抽条，长叶在温和的气里；
原：我作山，带着他，开朗了容颜。
原：又笑又说话，他是鸟声的尖，
原：是石卵的圆润，是溪水的急……
原：康健洒上了身来，一点，一滴；
原：还有快乐，它验荡着在身前。
原：循环的生长着，时与人与物。
原：云不见了，忧虑也已经消散……
原：我仰起头来，歌颂圆的苍苍。
原：不用知道，他自己便是“生长”！
原：到将来，又一遭的，他也要搀
原：他的孩子，在春天，走这条路！

# 四五
原：这一颗种子，天用手指拿住；
原：除去扁圆而外更没有形象，
原：渺小，轻——一下抛落了在地上，
原：深棕色便吞进了深色的土……
原：土壤要是膏腴的，拿这微物
原：来培养，要是有春雨，有太阳，
原：它便会膨胀，会发育……那时光，
原：便是天的意旨，也不能拦阻！
原：有许多的伟大蕴藏在渺小。
原：五谷是神工，花儿肌理细腻，
原：喷出了浓香将人，蝶给醉迷，
原：树木纷披着亮品品的绿袍：
原：或是，塔一般，它的株柯十抱
原：将生欲高举到天的视，听里。

# 五一
原：横越过空问的山，时间的水，
原：向你我们呼出了最后的一声……
原：从此我们是依然分道而行，
原：象从前那样，没有温柔，陶醉。
原：你受祝福了！……只须登涉崔巍，
原：月明人静的时候，你能实认
原：这真的我，何以到今日才肯
原：喊出来这最先，最后的一回！
原：悭吝的命运，人怎么去埋怨？
原：这百纪的馈受中并无美满——
原：何况是他拿这美妙的形象

# 五三
原：云霾升起于太空了。水面
原：有蜻蜓低舞；喧噪着，乌鸦
原：象树叶在深秋旋绕而下；
原：草坪在风内急剧的骗跃。
原：我的太阳已经行到中天——
原：可是，阴沉着，并没有光华，
原：苍白的，好象睡眠在床榻，
原：悄然无语的病人那张脸。
原：过去是一个悠久的晨间，
原：同时又短促；也听见鸟啼，
原：也看见太阳蜗行在窗上。
原：在如今这时候，正能默想
原：已逝的温柔，成灰的友谊，
原：以及将临的暴风雨，来年。
