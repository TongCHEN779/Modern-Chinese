# 一九〇四年
原：生于湖南沅陵县。祖父原居湖北，后转入安徽太湖县，家居湖南长沙。父亲朱延熙为前清翰林，做过江西学台。父亲去世后，家道中落。兄弟多人，聚居不睦，几个哥哥视他为路人。

# 一九〇七年三岁
原：母亲去世。

# 一九一〇年六岁
原：入私塾启蒙。教师为清代举人，第一部课本是《龙文鞭影》。后又读《诗经》、《史记》等。七、八岁时开始学着作文。

# 一九一四年十岁
原：曾回太湖老家，由家庭延师专教。

# 一九一五年十一岁
原：考入高小一年级读书

# 一九一七年十三岁
原：三月，就读于南京江苏省立第四师范学校附属小学三年级。
原：下半年，入南京工业学校预科读书一年。后又在青年会学习英语。
原：这时，受《新青年》上刘半农《复王敬轩书》的影响，开始赞助支持新文学。

# 一九一九年十五岁
原：秋天，考入清华学校。他的学习费用，多得力于寡嫂薛琪瑛女士的帮助。薛为童话《杨柳风》的译者。

# 一九二一年十七岁
原：开始写新诗，并参加清华文学社活动。

# 一九二二年十八岁
原：一月，在《小说月报》上发表处女作新诗《废园》。此后，在该刊陆续发表诗作和翻译的罗马尼亚民歌。
原：此期，加入文学研究会。

# 一九二三年十九岁
原：冬，因旷课逾章，被开除，离开清华学校。

# 一九二四年二十岁
原：春天，离开清华后，到上海某大学代授英文课。
原：三月，翻译诗集《路曼尼亚民歌一斑》由上海商务印书馆出版，为《文学研究会丛书》。
原：十月，开始在《文学周报》上用“天用”的笔名开辟《桌话》栏，先后发表了评论《呐喊》、《红烛》，《流云》等文章多篇。

# 一九二五年二十一岁
原：一月，第一部新诗集《夏天》由上海商务印书馆出版，为《文学研究会丛书》。
原：三月，在南京与刘霓君女士结婚。刘父也是清代翰林，做过江西盐运使，与朱湘父亲是朋友。这门亲事是指腹为婚。
原：四月，作《哭孙中山》一诗，发表于同年八月《猛进》周刊。
原：五卅惨案发生后，朱湘离开上海去北平。五月三十日，作《雌夜啼》，为朱湘最早的格律诗作。
原：夏天，在南京清凉山初识刘梦苇，结为好友。
原：七月，作拟清华学校校歌《大树辞》，发表于十二日《京报副刊上。
原：暑假前后，与饶孟侃在北京适存中学教书。
原：九月，作《适存中学校歌》，发表于《京报副刊》，后改题为《少年歌》，收入《草莽集》。
原：十月，在《小说月报》上发表寓言讽刺长诗《猫谐》。

# 一九二六年二十二岁
原：四月，参加闻一多徐志摩主办的《晨报副刊·诗镌》的活动。在该刊发表新诗《采莲曲》及诗评《评郭君沫若的诗》等。不久与徐志摩闹翻，退出“诗镌”活动。
原：七月，在《小说月报》上发表长篇叙事诗《王娇》。这年秋天，为了取得出国留学机会，得朋友帮助，重新入清华学校学习。参加清华文学社活动，并在《清华文艺》上撰稿。

# 一九二七年二十三岁
原：一月，出版自办的专登自己著译稿件的文艺刊物《新文》。创刊号上发表了散文《咬菜根》。出两期后停刊。
原：五月，在《小说月报》的“中国文学研究号”上发表有关中国古代文学研究论文多篇。
原：七月，于清华学校毕业。
原：八月，第二部新诗集《草莽集》由上海开明书店出版，为作者自编的“新文丛书第一种”。
原：八月末，同柳无忌一起，由上海乘船赴美留学。
原：九月初，入美国威斯康星州劳伦斯大学插入四年级，修西洋文学、古英文、拉丁语和高级班法语、
原：十二月，因法文教科书里把中国人称为“猴子”，气愤地退出课堂，于二十五日离开劳伦斯大学。

# 一九二八年二十四岁
原：一月初，转入芝加哥大学三年级，读高级班德文和古希腊文等。学习之余，从事翻译世界名诗的工作，后来编入《番石榴集》。同时将自己的诗作《摇篮曲》及中国古代诗歌译成英文，发表于该校刊物《长生鸟》上。

# 一九二九年二十五岁
原：春天，因为一位教授疑心他借书未还，愤而离校，于三月二十五日转入俄亥俄大学。
原：九月，应武汉大学闻一多先生邀请回国，到上海后，经朋友推荐，应聘到安庆安徽大学执教，任英文文学系主任。
原：是年，所译《英国近代小说集》由上海北新书局出版，列为《欧洲名家小说丛刊》之一。

# 一九三〇年二十六岁
原：大量写作格律诗，后来多收入《石门集》。
原：支持安徽大学晓风社的文学活动，在他们办的周刊《绿洲》（附《皖报》）、月刊《沙漠》上撰稿。

# 一九三一年二十七岁
原：一月，在新月诗派创办的《诗刊》创刊号发表诗作《镜子》，后改题《美丽》收入《石门集》和陈梦家编的《新月诗选》。
原：七月，罗念生，柳无忌、罗皑岚、陈林率筹办刊物，以柳亚子为主编名义出版《文艺杂志》。朱湘应约为该刊撰稿。
原：暑假间，到上海约赵景深到安徽大学教书未成。
原：十一月，徐志摩遇难，作《悼徐志摩》诗，发表于《诗刊》纪念专号。

# 一九三二年二十八岁
原：五月，暑假前再到上海，约赵景深、戴望舒和方光焘同到安徽大学任教，为校方拒绝。他拟不再回安大教书，经友人劝说，答应回校。但只去索欠薪，并不上课，此时患了脑充血病；又因为校方将他定的“英文文学系”改为“英文学系”，他执拗而气愤地辞去教职，于夏秋间离开安庆到北平。
原：八月，在施蛰存主编的《现代》杂志上发表新格律诗。
原：十一月至十二月，在《青年界》发表新体格律诗，撰文评介诗集《银铃》。
原：十二月，为生活奔波，曾回家乡长沙。

# 一九三三年二十九岁
原：四月，赴上海。撰写长篇文学散论《文学闲谈》，连载于四月五日至十月一日《青年界》。
原：六月，返回北平，住西郊达园。
原：是年夏秋间，写作大量诗文，发表于《青年界》等刊物。
原：十一月，由北平经天津去上海、杭州。经天津时受到柳无忌的款待。托柳无忌在南开大学，闻一多，饶孟侃在河南大学谋寻教职，均未果。
原：十二月一日，在上海向薛琪瑛女士借钱。此时经济窘困，身患疾病。家庭不睦，精神陷于十分绝望与痛苦中。
原：十二月五日，晨六时在上海开往南京的“吉和轮”上投江自杀。

# 一九三四年
原：六月，第三本诗集《石门集》由上海商务印书馆出版，为《文学研究会丛书》。
原：十月，散文与评论集《中书集》由上海生活书店出版。
原：十二月，书信集《海外寄霓君》由上海北新书局出版。
原：是年，文艺评论《文学闲谈》由上海北新书局出版。
原：十二月五日，《天津益世报·文学周刊》出《朱湘纪念号》。《编后》说：“诗人朱湘死后，身世很萧条，留下一子·女，因家没有钱教育他们，尚在南京孤儿院内住着。现朱湘的友人们，不忍见他的遗孤失学，特发起筹募诗人朱湘遗孤教育基金委员会’，在京、沪、平、津等，捐募基金。委员共十五人，有郑振铎、杜衡、闻一多、苏雪林、施蛰存、黄翼、徐霞村、饶孟侃、傅东华、黄自、余文伟、赵景深、罗念生、罗皑岚、柳无忌。”

# 一九三六年
原：三月，译诗集《番石榴集》由上海商务印书馆出版。《朱湘书信集》由天津“人生与文学”社出版，罗念生编。
原：四月，第四本诗集《永言集》由上海时代图书公司出版，赵景深编。
