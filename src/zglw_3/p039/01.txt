# 聊斋志异自序
题解：著名的小说《聊斋志异》的作者蒲松龄，以愤世嫉俗的笔触，揭露了封建社会的无比黑暗，又用饱含热情的语言歌颂了敢于反抗敢于鬬争的人们。他处于封建制度的统治之下，满腔悲愤，不可能直抒胸臆，而不得不寄托微言。“集腋为裘，妄续幽冥之录；浮白载笔，仅成孤愤之书。”这说明《聊斋》一书，充沛着“孤愤”的情绪。这种“孤愤”之所以产生，是因为“仕途黑暗，公道不彰，非袖金输璧，不能自达于圣明，真令人愤气填胸，欲望望然哭向南山而去。”（《与韩刺史樾依书》）它是现实生活的反映。同时，从文学传统说，则有鉴于“三闾氏感而为骚”，“长爪郎吟而成癖”，是积极浪漫主义精神的进一步发扬。正因为如此，人们感到《聊斋》所写花妖狐魅，别具寄托。王渔洋说：“料应厌作人间语，爱听秋坟鬼唱时。”（《聊斋志异》题辞）余集说：“神灵怪物，琦玮侨仇，以泄愤懑，抒写愁思。”（《聊斋志异》序）都道出了《聊斋志异》的旨意。
题解：《聊斋志异》不仅具有进步的思想内容，而且在艺术上也达到高度的成就。其艺术成就来自对小说创作优良传统的继承，也由于民间文学的哺育。“才非干宝，雅爱搜神；情类黄州，喜人谈鬼。闻则命笔，遂以成篇。久之，四方同人，又以邮筒相寄，因而物以好聚，所集益伙。”这说明《聊斋》的作者，是从人民口头文学中吸取题材学习技巧的。
题解：《聊斋志异序》短短几百字，却包含了小说创作必须具有进步的思想内容，继承优良的文学传统，学习民间口头创作等重要内容。这几点，是《聊斋志异》取得杰出成就的基本经验，也是小说创作的一般规律。
原：〔清〕蒲松龄
注原：蒲松龄：聊斋志异自序——《聊斋志异》，文言短篇小说集。清蒲松龄著。共十二卷，收四百九十一篇作品。作者从民间故事中吸取了丰富的营养，并继承了“传奇”与“志怪”的传统，经过了二十年左右时间的辛勤劳动，积累而成。这篇序文，是康熙十入年春所作，时作者年四十岁。
注原：蒲松龄：蒲松龄(公元一六四○年——一七一五年)——字留仙，一字剑臣，号柳泉居士，山东淄川人。长期贫困不得意，除出外游学和在江苏宝应县作了一年多幕宾外，在家乡为塾师。七十一岁才补上岁贡生。著作有《聊斋志异》及收有诗、文、俚曲等的《蒲松龄集》，长篇小说《醒世姻缘传》相传也是他所著。张元有《柳泉先生墓表》。
原：披萝带荔，三闾氏戚而为《骚》；牛鬼蛇神，长爪郎吟而成癖。自鸣天籁，不择好音，有由然矣。松，落落秋萤之火，魑魅争光；逐逐野马之尘，魍魉见笑。才非干宝，雅爱搜神；情类黄州，喜人谈鬼。闻则命笔，遂以成篇。久之，四方同人，又以邮筒相寄，因而物以好聚，所积益伙。甚者，人非化外，事或奇于断发之乡；睫在眼前，怪有过于飞头之国。遄飞逸兴，狂固难辞；永托旷怀，痴且不讳。展如之人，得勿向我胡卢耶？然五父衢头，或涉滥听；而三生石上，颇悟前因。放纵之言，有未可概以人废者。松悬弧时，先大人梦一病瘠瞿昙，偏祖入室，药膏如钱，圆粘乳际，寤而松生，果符墨志。且也，少羸多病，长命不犹。门庭之凄寂，则冷淡如僧；笔墨之耕耘，则萧条似钵。每搔头自念，勿亦面壁人果吾前身耶？盖有漏根因，未结人天之果；而随风荡堕，竟成藩溷之花；茫茫六道，何可谓其无理哉！独是子夜荧荧，灯昏欲蕊；萧斋瑟瑟，案冷疑冰。集腋为裘，妄绪（续）幽冥之录；浮白载笔，仅成孤愤之书；寄托如此，亦足悲矣！嗟乎！惊霜寒雀，抱树无温；吊月秋虫，偎栏自热。知我者，其在青林黑塞间乎！柳泉自题。
注原：披萝带荔：披萝带荔二句—屈原《九歌·山鬼》：“若有人兮山之阿，被薛荔兮带女萝。”若有人，指山鬼。阿，角落。被，同披。薛荔，即木莲，香草名，常绿蔓生植物。女罗，一名松萝，地衣类植物。句意谓以薛荔为衣女萝为带。王逸《离骚经序》：“《雕骚经》者，屈原之所作也。屈原与楚同姓，仕于怀王，为三闾大夫。三间之职，掌王族三姓，曰昭、屈、景。……屈原执履忠贞，而被谗邪，忧心烦乱，不知所愬，乃作《离骚经》。”
注原：牛鬼蛇神：牛鬼蛇神二句——杜牧《李长吉歌诗叙》：“牛鬼蛇神，不足为其虚荒诞幻也。”李商隐《李贺小传》：“长吉细瘦，通眉，长指爪。能苦吟疾书。”
注原：天籁：《庄子·齐物论》：“女闻人籁而未闻地籁，女闻地籁而未闻天籁夫！”人籁，谓人所吹者，如乐孔所发之声。地籁，谓地所吹者。天籁，谓天然所吹者。籁原训为篇，此引申为吹。陆德明《庄于音义》引崔(譔)云：“吹犹籁也。”
注原：好音：《诗·泮水》：“怀我好音。”
注原：落落秋萤之火：秋莹之火—《晋书·车胤传》：“胤博学多通，家贫，不常得油，夏月则练囊盛数十肇火以照书。”按：杨缙有《秋辇照帙》诗。
注原：魑魅争光：魑魅，古代传说中山泽的鬼怪。《灵鬼记》：“嵇康灯下弹琴，忽有一人长丈余，著黑单衣，革带。康熟视之，乃吹火灭之曰：耻与魑魅争光。”
注原：逐逐：急驱的样子。《易·颐》：“其欲逐逐。”野马之座——《庄子·逍迤游》：“野马也，座埃也，生物之以息相吹也。”陆德明《音义》引司马彪曰：“野马，春日泽中游气也。”又引崔譔曰：“天地间气如野马驰也。”
注原：魍魉见笑：魍魉，古代传说中的山川精怪名。《南史·刘损传》：“损宗人伯龙为武陵太守，贫宝尤甚，慨然将营什一之利，一鬼在旁拊掌大笑。伯龙曰：贫富固有命，乃复为鬼所笑也！遂止。”
注原：才非干宝：才非干宝二句——干宝，字令升，新蔡人。是晋代著名的经学家、史学家，又是小说家。《晋书》卷八十二有传。本传载：“宝博学多才，……撰《搜神记》三十卷，集古今神祗灵异诸变幻状甚悉。”
注原：情类黄州：情类黄州二句—苏轼贬调在黄州时候，常与客该谐放荡，有不能谈的，则强之使说鬼。事见《佩文韵府》引《避暑录》。今叶梦得《避暑录话》不载。
注原：又以邮筒：邮简——《唐语林》载：“白居易为杭州刺史时，吴兴守钱徽，吴郡守李穰，悉平生旧交，日以诗相寄赠。后元积守会稽，参其酬唱，多以竹简盛诗往来，谓之邮筒。”
注原：物以好聚：欧阳修《集古录目序》：“物常聚于所好，而常得于有力之彊。”
注原：人非化外：封建统治者称政令教化所达不到的地方为“化外”。《唐律疏议》：“化外人，谓蕃夷之国，别立君长者，各有风俗，制法不同。”
注原：事或奇于断发：断变——《庄子·逍遥游》：“宋人资章甫而适诸越，越人断变文身无所用之。”
注原：睫在眼前：见本册袁宏道《雪涛阁集序》注[9]。
注原：飞头之国：干宝《搜神记》：“秦时南方有落民，其头能飞。”段成式《酉阳杂俎》：“岭南溪洞中往往有飞头者，故有飞头獠子之号。”
注原：遄飞逸兴：王勃《秋日登洪府滕王阁钱别序》：“迤吟俯畅，逸兴遄飞。”
注原：展如之人：《诗·鄘风·君子偕老》：“展如之人兮，邦之媛也。”毛传：“展，诚也。美女为媛。”此处即作美女解。
注原：胡卢：《后汉书·应劭传》：“掩口卢胡而笑。”
注原：五父衢头：《礼记·檀弓》：“殡于五父之衢。”郑玄注：“五父，衢名。”
注原：三生石上：唐李源与僧圆观为友，圆观临死前对李源说：后十二年，可往天竺寺外相见。李源如期赴约，有牧童歌竹枝词而来，即是圆观。歌曰：“三生石上旧精魂，赏月吟风不要论。惭愧情人远相访，此身虽异性长存。”详见袁郊《甘泽谣》。
注原：放纵之言：放纵之言二句——《论语·卫灵公》：“子曰：君子不以言举人，不以人废言。”从，同纵。
注原：悬弧：《礼记·内则》：“子生，男子设弧于门左。”表示志在四方的意思。弧，写。
注原：大人梦一病瘠瞿昙：彞释迦车尼之姓。此作为僧的代称。
注原：长命不犹：《诗·召南·小星》：“实命不犹。”毛传：“犹，若也。”
注原：笔墨之耕耘：任昉《为萧扬州作荐士表》：“前晋安郡侯官令东海王僧孺，年三十五，理尙栖约，思致恬敏，既笔耕为养，亦佣书成学。”
注原：面壁人：《传灯录》：“(达摩)师寓止于嵩山少林寺，面壁而坐，终日默然。”此处面壁人只作僧之代称，即指上文其父梦中所见者。
注原：有漏根因：有漏根因二句——《传灯录》：“(梁武)帝问(达摩)日：朕造寺写经度价，不可胜纪，有何功德？师曰：并无功德。帝曰：何无功德？师曰：此但人天小果，有漏之因。”有漏为佛学术语，漏是烦恼的异名，含有烦恼的事物，称为有漏。善恶等招三界果报的业因，名为有漏因。有漏业因所招的果报，如人间、天上乃至地狱等，称有漏果。
注原：竟成藩溷之花：随风荡随二句——《南史·范续传》：“竟陵王子良精信佛教，而颖盛称无佛。子良问日：君不信因果，何得富贵贫贱？缉答曰：人生如树花同发，随风而坠，自有拂帘幌坠于茵席之上，自有开藩触落于粪溷之中。”

注原：子夜：夜十一时到次晨一时为子时，故称半夜为子夜。
注原：萧斋：李肇《国史补》：“梁武帝造寺，命萧子云飞白大书一萧’字。后寺毁，惟此字独存。李约见之，买归东洛，建小室以玩之，号日萧斋。”后来文人用萧斋作为书室的泛称。
注原：集腋为裘：王褒《四于讲德论》：“千金之裘，非一狐之腋。”
注原：幽冥之录：一《幽冥录》，三十卷，南朝宋刘义庆撰。原书已佚，《古小说钩沈》辑其佚亡。

注原：孤愤：《韩非子》第十一篇。

# 拙叟行
原：〔清〕蒲松龄
诗：生无逢世才，/一拙心所安。/我自有故步，/无须美邯郸。
诗：世好新奇矜聚稿，/我惟古钝（别本作拙）仍峨冠。/古道不应途泯没，/自有知己与我同咸酸。
诗：何况世态原无定，/安能俯仰随人为悲欢？/君不见：衣服妍媸随时眼，/我欲学长世已短。
原：中华书局本《蒲松龄集·聊斋诗集》卷四

# 聊斋志异序（高珩）
原：〔清〕高珩
原：志而曰异，明其不同于常也。然而圣人曰：“君子以同而异。”何耶？其义广矣、大矣。夫圣人之言，虽多主于人事，而吾谓三才之理，六经之文，诸圣之义，可一以贯之。则谓异之为义，即易之冒道，无不可也。夫人但知居仁由义，克己复礼，足为善人君子矣。而陟降而在帝左右，祷祝而感召风雷，乃近于巫祝之说者，何耶？神禹创铸九鼎，而山海一经，复垂万世，岂上古圣人而喜语怪乎？抑争子虚乌有之赋心，而预为分道扬镳者地乎？后世拘墟之士，双瞳如豆，一叶迷山，目所不见，率以仲尼“不语”为辞，不知鹆飞石陨，是何人载笔尔尔也？倘概以左氏之诬蔽之，无异掩耳者高语无雷矣。引而申之，即“闻阁九天，衣冠万国”之句，深山穷谷中人，亦以为欺我无疑也。余谓：欲读天下之奇书，须明天下之大道，盖以人伦大道，淑世者圣人之所以为木铎也。然而天下有解人，则虽言孔子之不语者，皆足辅功令教化之所不及，而诺皋、夷坚，亦可与六经同功。苟非其人，则虽日述孔子之所常言，而皆足以佐慝，如读南子之见，则以为淫辟皆可周旋；泥佛肸之往，则以为叛逆，不妨共事，不止诗书发冢，周官资篡已也。彼拘墟之士多疑者，其言则未尝不近于正也。一则疑曰：政教自堪治世，因果无乃渺茫乎？曰：是也。然而阴隲上帝，幽有鬼神，亦圣人之言否乎？彼彭生觌面，申生语巫，武曌宫中，田蚡枕畔，九幽斧钺，严于王章多矣。而世人往往多疑者，以报应之或爽，诚有可疑。即如圣门之士，贤隽无多，德行四人，二者天亡，一厄继母，几乎同于伯奇，天道情愤，一至此乎！是非远洞三世，不足消释群憾。释迦马麦，袁盎人疮，世亦安能知之？故非天道情愦，人自情愤故也。或再疑曰：报应示戒可矣，妖邪不宜黜乎？曰：是也。然而天地大矣，无所不有；古今变矣，未可舟胶。人世不皆君子，阴曹反皆正人乎？岂夏姬谢世，便锴共姜；荣公撤瑟，可参孤竹乎？有以知其必不然矣。且江河日下，人鬼颜多，不则幽冥之中，反是圣贤道场，日日唐虞三代，有是理乎？或又疑而且规之曰：异事，世间固有之矣，或亦不妨抵掌；而竟驰想天外，幻迹人区，无乃为齐谐滥觞乎？曰：是也。然子长列传，不厌滑稽；巵言寓言，蒙庄嚆矢。且二十一史果皆实录乎？仙人之议李郭也，固有遗憾久矣。而况勃窣文心，笔补造化，不止生花，且同炼石。佳狐佳鬼之奇俊也，降福以孔皆，敦伦更复无斁，人中大贤，犹有愧焉。是在解人不为法缚，不死句下可也。夫中郎帐底，应饶子家之异味；邺侯架上，何须兔册之常诠？余愿为婆娑艺林者，职调人之役焉。古人著书，其正也，则以天常民彝为则，使天下之人，听一事，如闻雷霆，奉一言，如亲日月。外此而书或奇也，则新鬼故鬼，鲁庙依稀；内蛇外蛇，郑门踯躅，非尽矫诬也。倘尽以“不语”二字奉为金科，则萍实、商羊、羊、楛矢，但当摇首闭目而谢之足矣。然乎否耶？吾愿读书之士，揽此奇文，须深慧业，眼光如电，墙壁皆通，能知作者之意，并能知圣人或雅言、或罕言、或不语之故，则六经之义，三才之统，诸圣之衡，一一贯之。异而同者，忘其异焉可矣。不然，痴人每苦情深，入耳便多濡首。一字魂飞，心月之精灵冉冉；三生梦渺，牡丹之亭下依依。檀板动而忽来，桃莉遣而不去，君将为魍魉曹丘生，仆何辞齐谐鲁仲连乎？
原：康熙己未春日谷且，紫霞道人高珩题。
原：上海古籍出版社会校会注会评本《聊斋志异》一

# 聊斋志异序（唐梦赉）
原：〔清〕唐梦赉
原：谚有之云：“见橐驼谓马肿背”。此言虽小，可以喻大矣。夫人以目所见者为有，所不见者为无。曰，此其常也；倏有而倏无则怪之。至于草木之荣落，昆虫之变化，倏有倏无，又不之怪；而独于神龙则怪之。彼万窍之刁刁，百川之活活，无所持之而动，无所激之而鸣，岂非怪乎？又习而安焉。独至于鬼狐则怪之，至于人则又不怪。夫人，则亦谁持之而动，谁激之而鸣者乎？莫不曰：我实为之。夫我之所以为我者，目能视而不能视其所以视，耳能闻而不能闻其所以闻，而况于见闻所不及者乎？夫见闻所及以为有，所不及以为无，其为见闻也几何矣。人之言曰：“有形形者，有物物者”，而不知有以无形为形，无物为物者。夫无形无物，则耳目穷矣，而不可谓之无也。有见蚊睫者，有不见泰山者，有闻蚁斗者，有不闻雷鸣者。见闻之不同者，聋瞽未可妄论也。自小儒为“人死如风火散”之说，而原始要终之道，不明于天下；于是所见者愈少，所怪者愈多，而“马肿背”之说昌行于天下。无可如何，辄以“孔子不语”一词了之，而齐谐志怪、虞初记异之篇，疑信之者参半矣。不知孔子之所不语者，乃中人以下不可得而闻者耳，而谓春秋尽删怪神哉！留仙蒲子，幼而颖异，长而特达，下笔风起云涌，能为载记之言。于制艺举业之暇，凡所见闻，辄为笔记，大要多鬼狐怪异之事。向得其一卷，辄为同人取去；今再得其一卷阅之。凡为余所习知者，十之三四，最足以破小儒拘墟之见，而与夏虫语冰也。余谓事无论常怪，但以有害于人者为妖。故日食星陨，鸡飞鸽巢，石言龙斗，不可谓异；惟土木甲兵之不时，与乱臣贼子，乃为妖异耳。今观留仙所著，其论断大义，皆本于赏善罚淫与安义命之旨，足以开物而成务，正如扬云《法言》，桓谭谓其必传矣。
原：康熙壬戌仲秋望，豹岩樵史唐梦赉题。
原：上海古籍出版社会校会注会评本《聊斋志异》一

# 题聊斋文集后
原：〔清〕王士旗
原：八家古文辞，日趋平易，于是沧溟、弇州辈起而变之以古奥；而操觚家论文正宗，谓不若震川之雅且正也。聊斋文不斤斤宗法震川，而古折奥峭，又非拟王、李而得之，卓乎成家，其可传于后无疑也。
原：渔洋老人王士旗拜题。
原：中华书局本《蒲松龄集·聊斋文集》附录

# 聊斋志异序（余集）
原：〔清〕余集
原：乙酉三月，山左赵公奉命守睦州，余假馆于郡斋。太守公出淄川蒲柳泉先生《聊斋志异》，请予审定而付之梓。严陵环郡皆崇山，郡斋又多古木奇石。时当秋飙怒号，景物睄窕，狐鼠画跳，枭猿夜嗥，把卷坐斗室中，青灯谈睽，已不待展读，而阴森之气，偪人毛发。呜呼，同在光天化日之中，而胡乃沉冥抑塞，托志幽遐，至于此极！余盖卒读之而悄然有以悲先生之志矣。按县志称先生少负异才，以气节自矜，落落不偶，卒困于经生以终。平生奇气，无所宣渫，悉寄之于书。故所载多涉诹诡荒忽不经之事，至于惊世松俗，而卒不顾。嗟夫！世固有服声被色，俨然人类；叩其所藏，有鬼蜮之不足比，而豺虎之难与方者。下堂见姜，出门触蠡，纷纷沓沓，莫可穷诘。惜无禹鼎铸其情状，镯镂决其阴霾，不得已而涉想于杳冥荒怪之域，以为异类有情，或者尚堪晤对；鬼谋虽远，庶其警彼贪淫。呜呼！先生之志荒，而先生之心苦矣！昔者三闾被放，彷徨山泽，经历陵庙，呵壁问天，神灵怪物，琦玮儒危，以泄愤懑，抒写愁思。释氏悯众生之颠倒，借因果为筏喩，刀山剑树，牛鬼蛇神，罔非说法，开觉有情。然则是书之恍惚幻妄，光怪陆离，皆其微旨所存，殆以三闾侘际之思，寓化人解脱之意败？使第以媲美齐谐，希踪述异相诧嫩，此井蠡之见，固大整于作者；亦岂太守公传刻之深心哉！夫易筮载鬼，传纪降神，妖祥灾异，炳于经籍。天地至大，无所不有；小儒视不越几席之外，履不出里巷之中，非以情揣，即以理格，是总总者又甚于井蠢之见也。太守公曰：“子之说，可以传先生矣。”遂书以为序。
原：乾隆三十年，岁次乙酉十一月，仁和余集撰。
原：上海古籍出版社会校会注会评本《聊斋志异》一

# 春在堂随笔（选录）
原：〔清〕俞樾
原：纪文达公尝言：聊斋志异一书，才子之笔，非著书者之笔也。先君子亦云：“蒲留仙才人也。其所藻绩，未脱唐宋人小说窠臼。若纪文达阅微草堂五种》，专为劝惩起见，叙事简，说理透，不屑屑于描头画角，非留仙所及。”余著<右台仙馆笔记》，以《阅微》为法，而不袭《聊斋》笔意，秉先君之训也。然<聊斋》藻绩不失为古艳，后之继<聊斋》而作者，则俗艳而已，甚或庸俗不堪入目，犹自诩为步武聊斋》，何留仙之不幸也。
原：光绪十五年重定本《春在堂全书·春在堂随笔》入
