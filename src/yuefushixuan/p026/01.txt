# 临高台
题解：《临高台》：本为《汉铙歌》十八曲中的第十六曲。原文云：“临高台以轩，下有清水清且寒。江有香草目以兰，黄鹄高飞离哉翻。关弓射鹄，令我主寿万年。收中吾。”曹丕此诗前半首（“宜居此宫”以前），大致都是改写《汉铙歌》的歌辞原意。“鹄欲南游”以下，则大部分取自《相和歌辞·艳歌何尝行》的“古辞”。《乐府诗集》卷三十九引《古今乐录》曰：“王僧虔《技录》云：《艳歌何尝行》，歌文帝《何尝》、古《白鹄》二篇，。”这说明曹丕此诗虽用《汉铙歌》曲名，实已依《相和歌辞》来演唱。同时从这首诗中也可看出乐府诗中切割、拼凑的情况。
题解：曹丕（187—226）：即魏文帝。字子桓，曹操次子，沛国谯(今安徽亳县）人。建安时代曾任五官中郎将，魏国太子。曹操死后继承王位，不久代汉自立。曹丕实际上是建安时代邺下文人集团的中心人物。他的《燕歌行》二首，是较早的成熟的七言诗；他的书信等骈文亦多名作；《典论·论文》尤为文学批评史上重要著作。明人辑有《魏文帝集》。
诗：临台（行）高，/高以轩。/下有水，/清且寒。
注：行：据闻一多说为衍文，当删。高以轩：据高处以为轩槛。
诗：中有黄鹄往且翻。/行为臣，/当尽忠。/愿令皇帝陛下三千岁，/宜居此宫。
注：行为臣：即“既为臣”。这几句虽与“铙歌”原文有相同的意思，但文气不接，疑另有来处。
诗：鹄欲南游，/雌不能随。/我欲躬衔汝，/口噤不能开，/欲负之，/毛衣摧颓。/五里一顾，/六里徘徊。
注原：口噤不能开：噤(jìn禁）：口闭。
注：摧颓：凋零。
注：“五里”二句：据古辞《艳歌何尝行》，可知为雌鹄不能相随，所以雄鹄南游时，恋恋不舍，以致“五里一顾，六里徘徊”。

# 善哉行（四首选三）
题解：《善哉行》：这是曹丕的拟作，本四首，其中五言二首，四言二首。今选录的是其中的第二、三、四首；第一首除“长笛吹清气”一句在南朝曾被视为名句而当作诗题外，全篇的内容和艺术成就似较一般，故未入选。
诗：其二　上山采薇，/薄暮苦饥。/溪谷多风，/霜露沾衣。
诗：野雉群雊，/猿猴相追。/还望故乡，/郁何累累。
注：雊（gòu够）：雉鸣。
注：郁：深远。累累：山冈重叠。
诗：高山有崖，/林木有枝。/忧来无方，/人莫之知。
注：“高山”二句：用《说苑·善说篇》载《越人歌》中“山有木兮木有枝”句意，借以表达自己思乡而被山林所遮蔽，远望不见之苦。
诗：人生如寄，/多忧何为。/今我不乐，/岁月其驰。
注：驰：很快流失。此句用《诗经·唐风·蟋蟀》“今我不乐，日月其迈”语意。
诗：汤汤川流，/中有行舟。/随波转薄，/有似客游。
注：汤汤（shāng商）：大水流得很快的样子。
诗：策我良马，/披我良裘。/载驰载驱，/聊以忘忧。
诗：其三　朝游高台观，/夕宴华池阴。/大酋奉甘醪，/狩人献嘉禽。
注：大酋：主管造酒的官长。醪（1áo劳）：带糟滓的醇酒。狩人：掌管狩猎的官员。
诗：齐倡发东舞，/秦筝奏西音。/有客从南来，/为我弹清琴。
诗：五音纷繁会，/拊者激微吟。/淫鱼乘波听，/踊跃自浮沉。
注：拊（fǔ府）：一种形似鼓的乐器。这句说击了拊，歌者就唱起来。
注：“淫鱼”句：《荀子·劝学篇》：“昔者瓠巴鼓瑟而沉鱼出听。”“沉鱼”，《淮南子·说山训》作“淫鱼”。
诗：飞鸟翻翔舞，/悲鸣集北林。/乐极哀情来，/寥亮摧肝心。
注：寥亮：清澈之声。这句说清澈的乐声使人引起悲哀。
诗：清角岂不妙，/德薄所不任。/大哉子野言，/弭弦且自禁。
注原：“清角”二句：“角”为五音之一。据《韩非子·十过篇》载，清角是最悲的音乐。春秋晋平公曾要求师旷奏清角，师旷说：“恐主君德薄，不足以听之。”平公坚持要听，引来灾异。
注：子野：师旷的字。
注：弭弦：停止演奏。
诗：其四　有美一人，/婉如清扬。/妍姿巧笑，/和媚心肠。
注：“有美”二句：本《诗经·郑风·野有蔓草》中诗句。婉：美好。清扬：指眉目之间很漂亮。
注原：妍：美。巧笑：笑得很美。《诗经·卫风·硕人》：“巧笑倩兮”。媚：使人喜悦。
诗：知音识曲，/善为乐方。/哀弦微妙，/清气含英。
注：乐方：演奏音乐的方法。
诗：流郑《激楚》，/度宫中商。/感心动耳，/绮丽难忘。
注：郑：本指《诗经》中的《郑风》，因孔子说过“郑声淫”的话，后来就把“郑声”代指俗乐。《激楚》：古代音乐名。枚乘《七发》：“于是乃发《激楚》之《结风》，扬郑卫之皓乐。”“宫”和“商”都是古代五音之一。
诗：离鸟夕宿，/在彼中洲。/延颈鼓翼，/悲鸣相求。
诗：眷然顾之，/使我心愁。/嗟尔昔人，/何以忘忧。
注：眷：留恋。眷然顾之：语出《诗经·小雅·大东》：“睠言顾之。”
注：“嗟尔”二句：王夫之认为是说这种忧愁“古来有之”。

# 短歌行
题解：《短歌行》：这是曹丕哀悼曹操之死而作。据《乐府诗集》卷三十所引《古今乐录》记载，王僧虔《技录》讲到魏代规定遇到节日及月朔要奏此曲，曲辞由曹丕作，他还曾“弹筝和歌”，声调最美。现在看来这首诗文字也凄婉动人，对后人一些哀伤的诗文有一定影响。
诗：仰瞻帷幕，/俯察几筵。/其物如故，/其人不存。
注：帷幕：室内所挂帐幕。几筵：几和席。这两句是说曹丕在曹操居室中看到曹操平生所用的物品和陈设。
诗：（一解)神灵倏忽，/弃我遐迁。/靡瞻靡恃，/泣涕连连。
注：“神灵”句：指曹操的神灵迅速离去。遐：远。迁：离去。
注：靡：没有。这两句说自己见不到父亲，无所依靠，因此哭泣，泪水不断。
诗：（二解)呦呦游鹿，/衔草鸣麑。/翩翩飞鸟，/挟子巢栖。
注：麑（ní泥）：小鹿。“呦呦”四句：以鹿和鸟之爱育其子，比喻曹操对自己的养育之恩。
诗：（三解）我独孤茕，/怀此百离。/忧心孔疚，/莫我能知。
注原：茕（qióng穷）：孤苦。离：同“罹”（lí黎），苦难。《诗经·王风·兔爰》：“我生之后，逢此百罹。”
诗：（四解）人亦有言，/忧令人老。/嗟我白发，/生一何早。
诗：（五解）长吟永叹，/怀我圣考。/日仁者寿，/胡不是保。/(六解)
注：圣考：圣明的父亲，（古人把死去的父亲称“考”）。胡：为什么。这四句是说自己怀念死去的父亲，人们都说仁者可以长寿，父亲却为什么不能长保生命。

# 饮马长城窟行
题解：《饮马长城窟行》：这是曹丕借用旧调来写他伐吴的事。黄初三年（222），他曾出兵讨伐孙权。
诗：泛舟横大江，/讨彼犯荆虏。/武将齐贯甲，/征人伐金鼓。
注：犯荆虏：侵犯荆州的敌人，指孙权。
注：贯：穿着。
诗：长戟十万队，/幽冀百石弩。/发机若雷电，/一发连四五。
注：石：重量名。古人以三十斤为钧，四钧为石。百石弩：指威力有百石之强的弓弩。
注：发机：古代武器，用以发射石块。这两句说发石的机具威力强大，可以连发四五块石块。

# 丹霞蔽日行
题解：《丹霞蔽日行》：属《相和歌辞·瑟调曲》，《乐府诗集》卷三十六引《古今乐录》所述王僧虔《技录》中《瑟调》曲名有三十六曲，无《丹霞蔽日行》。《乐府诗集》所录，仅曹丕、曹植各一首。此首全文几乎全部见于魏明帝（曹睿）“步出夏门行”一首，而诗又较曹植之作为短，疑非全篇。
诗：丹霞蔽日，/采虹垂天。/谷水潺潺，/木落翩翩。
注：翩翩：落叶飞舞的样子。
诗：孤禽失群，/悲鸣云间。/月盈则冲，/华不再繁。/古来有之，/嗟我何言。
注：冲：原指“虚”，《老子》：“道冲而用之。”此指月亮亏缺。

# 折杨柳行
题解：《折杨柳行》：这首曹丕的拟作共分四解，前两解讲游仙；后两解却是对神仙之说表示怀疑。黄节先生说：“《古今乐录》曰：《十五》歌文帝辞，后解歌《西山一何高》、《彭祖称七百》篇。'则《西山》、《彭祖》原分二篇。”黄先生还从音韵角度论证了一、二两解与三、四两解之别。陈祚明则认为“茫茫非所识，，正使果尔，亦复何欢？此意含蓄，校下文所辨尤深。”因此认为曹丕“言神仙，则妄言也。”据曹植《辨道论》，曹丕、曹植都不信神仙，则此诗三、四解似更能代表曹丕真实思想。
诗：西山一何高，/高高殊无极。/上有两仙童，/不饮亦不食。/与我一丸药，/光耀有五色。
诗：服药四五日，/身体生羽翼。/轻举乘浮云，/倏忽行万亿。/流览观四海，/茫茫非所识。
注：“茫茫”句：指在天上下视世界，但觉面目全非，茫然自失。
诗：彭祖称七百，/悠悠安可原。/老聃适西戎，/于今竟不还。/王乔假虚辞，/赤松垂空言。
注：彭祖：传说中殷代的贤人，活了七百岁。原：推究。这两句说彭祖号称活了七百岁，但传说纷纭，哪能测其真假。
注：老聃（dān丹）：老子名聃。这两句是说老子骑牛到西戎之地去，至今并未回来，意为未必真成了仙。
注原：赤松垂空言：王乔赤松：见前古辞《善哉行》注〔3〕及古辞《步出夏门行》注〔5〕。这两句说关于仙人的传说均为虚妄。
诗：达人识真伪，/愚夫好妄传。/追念往古事，/愦愦千万端。/百家多迂怪，/圣道我所观。
注：愦愦：昏乱。
注：圣道：指孔子的学说。曹丕于黄初二年（222）曾下诏敕认为不应尊老子于孔子之上。

# 燕歌行（二首）
题解：《燕歌行》：《相和歌辞·清商三调歌诗·平调曲》之一。《宋书·乐志》和《玉台新咏》所载，都为二首。但前者为“晋乐所奏”，后者则为“本辞”。《文选》则只取第一首。《乐府诗集》所载此曲，第二首（“别日”）歌辞，有“晋乐所奏”和“本辞”两种，字句颇有不同。看来第一首在晋代入乐时，对文字未作改动，所以各书所录，仅有个别文字出入；第二首则出入较大。近人丁福保《全汉三国晋南北朝诗》认为：“按入乐之词，率皆增损，本不足以为据。”余冠英先生《三曹诗选》所录，也据《玉台新咏》所载“本辞”，今从之。据《乐府诗集》卷三十二引《乐府解题》等书说，这首诗是用妇女口吻，写她丈夫行役到燕地，她因时节变换，出行者不归而引起的怨旷思念之情。这首诗是文人七言诗中较早且较成熟之作，为历来所传诵。
诗：其一　秋风萧瑟天气凉，/草木摇落露为霜。/群燕辞归雁南翔，/念君客游多思肠。
注：“秋风”二句：“秋风萧瑟”原出曹操《步出东西门行·观沧海》诗。“草木摇落”原出《楚辞·九辩》：“萧瑟兮，草木摇落而变衰。”“露为霜”原出《诗经·秦风·蒹葭》：“白露为霜。”这两句是写思妇在节令变换之际更加深了对行人的思念。这种袭用古人辞藻的手法，在魏晋六朝以后文人诗中经常使用，这二句显得颇为突出，所以特予指出，以下不一一详注。
注：雁：一作“鹄”。按：雁本是秋天避寒南飞，更令人想起行役北方（燕地）的丈夫不能南归，故从《文选》、《玉台新咏》取“雁”不作“鹄”。“君”，《乐府诗集》作“吾”，疑误。思肠：同“思心”。
诗：慊慊思归恋故乡，/君何淹留寄他方。/贱妾茕茕守空房，/忧来思君不可忘。
注：慊（qiàn欠）慊：怨恨。这两句是思妇想象行人在他方也在想念家乡。
注：茕茕：孤独无依。
诗：不觉泪下沾衣裳，/援琴鸣弦发清商。/短歌微吟不能长，/明月皎皎照我床。
注原：清商：曲调名，其声清切急促。《古诗·西北有高楼》：“清商随风发。”
注：皎皎：明亮。
诗：星汉西流夜未央，/牵牛织女遥相望，/尔独何辜限河梁。
注原：星汉：银河。夜未央：夜还未尽。语出《诗经·小雅·庭燎》：“夜如何其，夜未央。”“牵牛”、“织女”：都是星名。这里暗用牛郎、织女不能相聚的故事自喻。
注：尔：你，指行人。辜：罪。《玉台新咏》作“幸”，误。今从《宋书·乐志》及《文选》。河梁：山河关梁。这里似暗用托名李陵《与苏武诗》中“携手上河梁”句意。
诗：其二　别日何易会日难，/山川悠远路漫漫。/郁陶思君未敢言，/寄声浮云往不还。
注：漫漫：长的意思。
注原：郁陶：心中忧虑。《孟子·万章》：“郁陶思君尔。“寄声”句：指思妇想托浮云带信给征夫，而浮云飘去不返。
诗：涕零雨面毁形颜，/谁能怀忧独不叹。/展诗清歌仰自宽，/乐往哀来摧肺肝。
注原：“展诗”二句：意思说翻开诗卷加以吟唱来自我宽慰，但吟毕悲愁重来使内脏惨痛如裂。按：“晋乐所奏”曲辞，“耿耿”、“披衣”二句在“展诗”句之前；又“乐往哀来摧肺肝”句下多“悲风清厉秋气寒，罗帷徐动经秦轩”二句。
诗：耿耿伏枕不能眠，/披衣出户步东西，/仰看星月观云间。/飞鸧晨鸣声可怜,留连顾怀不能存。
注：耿耿：心中不安的样子。
注：“仰看”句：意思是说举头望天，盼望天快亮。“看”，“晋乐所奏”作“戴”，丁福保认为“看”与“观”重复，作“戴”稍胜。
注原：飞鸧晨鸣声可怜：鸽（cāng仓）：鸟名。即鸽鸹，大如鹤，青苍色或灰色，长颈，高脚。
注：“留连”句：意思是说触景伤情，涕泣留连，心怀悲伤不能自慰。“能”，“晋乐所奏”作“自”。“自存”，当即自我存慰。

# 秋胡行（三首选一）
题解：《秋胡行》：《相和歌辞·清调曲》之一。“秋胡”本人名。据《列女传》、《西京杂记》等书记载，都说秋胡是鲁人，娶妻后不久即出门做官，回来时已不认得自己妻子，正遇她在郊外采桑，竟加以调戏。到家后妻子对他的轻佻极为反感，竟出门投河而死。古辞今佚，现存作品以曹操父子之作为最早。但曹操所作二曲，都讲求仙；曹丕之作，亦与秋胡故事无关。只有后来傅玄、颜延之之作与秋胡故事有关并留存至今。现在选录曹丕《秋胡行》三首的第二首，以便大家对曹氏父子之作有所了解。此诗对后来江淹《杂体诗》三十首中的《休上人怨别》中名句“日暮碧云合，佳人殊未来”有明显的影响。
诗：其二　朝与佳人期，/日夕殊不来。/嘉肴不尝，/旨酒停杯。
诗：寄言飞鸟，/告余不能。/俯折兰英，/仰结桂枝。
诗：佳人不在，/结之何为。/从尔何所之，/乃在大海隅。
诗：灵若道言，/贻尔明珠。/企予望之，/步立踌躇。/佳人不来，/何得何须。
注：灵：指海神。
注：企予望之：同《诗经·卫风·河广》“跂予望之”，意为我踮起脚来望她。

# 见挽船士兄弟辞别诗
题解：《见挽船士兄弟辞别诗》：此诗《乐府诗集》卷三十七作刘宋谢灵运的《折杨柳行》第二首，显然是错的。逯钦立先生根据《北堂书钞》卷一百三十八、《初学记》卷十八和《白帖》卷六等引的诗句，考定为曹丕之作，题名也从《初学记》。这是完全正确的。但既然误为《折杨柳行》，此诗当亦为乐府诗。
诗：郁郁河边树，/青青野田草。/舍我故乡客，/将适万里道。
诗：妻子牵衣袂，/抆泪沾怀抱。/还拊幼童子，/顾托兄与嫂。
注：抆（wěn刎）：擦去。
诗：辞诀未及终，/严驾一何早。/负笮引文舟，/饥渴常不饱。/谁令尔贫贱，/咨嗟何所道。
注：严驾：下令出发。
注原：饥渴常不饱：“负笮（zuó昨）”二句：牵着竹篾制的绳子拉船，时常挨饥渴。

# 上留田行
题解：《上留田行》：这首曹丕的拟作是感叹人间贫富的苦乐悬殊。但最后归结为“禄命悬在苍天”，有宿命论思想。
诗：居世一何不同，/上留田。/富人食稻与粱，/上留田。
注：上留田：这里似与古辞《董逃行》的“董逃”二字一样，为每句末和声之字，并无实意。
诗：贫子食糟与糠，/上留田。/贫贱亦何伤，/上留田。
诗：禄命悬在苍天，/上留田。/今尔叹息将欲怨谁，/上留田。

# 钓竿
题解：《钓竿》：此曲本是《汉铙歌》中曲名，在十八曲以外，据《乐府诗集》卷十六引《古今乐录》说歌辞已佚。但“钓竿”二句，亦见《相和歌辞·白头吟》（“珊珊”作“袅袅”），疑即取自该曲。
诗：东越河济水，/遥望大海涯。/钓竿何珊珊，/鱼尾何蓰。/行路之好者，/芳饵欲何为。
注原：珊珊：《白头吟》作“袅袅”。按：司马相如《子虚赋》：“磐珊勃窣，上乎金堤。”韦昭注：“嫳珊，匍匐上下也。”疑“珊珊”即形容钓竿抖动的样子，与“袅袅”同义。蓰蓰：同“蓰蓰（xǐ徙）”，鱼尾摆动的样子。
注原：芳饵欲何为：这二句是质问喜钓鱼的人用鱼饵去诱钓鱼是为什么。

# 十五
题解：《十五》：《相和歌辞·相和曲》之一。据《乐府诗集》卷二十六引《古今乐录》载：南朝宋张永《元嘉伎录》记《相和》有十五曲，第六曲叫《十五》。同书卷二十七引《古今乐录》曰：“《十五》歌，（魏）文帝辞。”按：《梁鼓角横吹曲·紫骝马歌辞》中有“十五从军征”一首，《古今乐录》说是“古诗”（见《乐府诗集》卷二十五）。不知《十五》的古辞，是否即那首。此首显然是曹丕根据这一声调另作的歌辞。
诗：登山而远望，/溪谷多所有。/楩楠千尺，/众草之盛茂。
注：“登山”二句：写登山所见溪谷中动植物品类繁多。
注：楩（pián骈）：树木名。楠（nǎn南）：常绿乔木。
诗：华叶耀人目，/五色难可纪。/雉雊山鸡鸣，/虎啸谷风起。/号罴当我道，/狂顾动牙齿。
注：华：同“花”。这两句说草木的花叶色彩繁多，难于详述。
注：雊（gòu够）：雄雉鸣叫。谷风：山谷中的大风。
注：号罴：嚎叫的人熊。这两句说熊罴挡住道路，发怒要吃人。

# 陌上桑
题解：《陌上桑》：《宋书·乐志》又名《弃故乡》，又云：“亦在瑟调《东西门行》。”这首诗写从军远行，道路艰险之状，较能反映汉末三国时的现实，与古辞及曹操拟作很不相同。
诗：弃故乡，/离室宅。/远从军旅万里客。/披荆棘，/求阡陌。
注：“远从”句：是说从军远行客居万里之外。
注：“披荆棘”二句：指在荆棘丛中找寻道路。
诗：侧足独窘步，/路局笮。/虎豹嗥动，/鸡惊禽失，/群鸣相索。
注：侧足：谨慎地插足。窘步：行道受困。笮（zhǎi窄）：狭隘。《篇海》云：“答，狭也。”
注原：“虎豹”三句：写荒野中恐怖景象。语出淮南小山《招隐士》：“虎豹斗兮熊罴咆，禽兽骇兮亡其曹。”
诗：登南山，/奈何蹈盘石。/树木丛生郁差错。/寝蒿草，/荫松柏。
注：“登南山”二句：是说怎样才能踩着安稳的大石。
注：郁差错：是说茂密地丛生交错，无从寻路。
注：“寝蒿草”二句：是说露宿于树下草丛中。
诗：涕泣雨面沾枕席。/伴旅单，/稍稍日零落。/惆怅窃自怜，/相痛惜。
注：雨面：形容流泪之多。
注：单：稀少。“稍稍”句：指同行的人渐渐死亡逃散。
注原：“惆怅”二句：说既自怜，又痛惜同伴。上句语出《楚辞·九辩》：“惆怅兮私自怜。”
