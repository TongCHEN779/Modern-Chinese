# 横吹曲辞·梁鼓角横吹曲
题解：《梁鼓角横吹曲》：南北朝时代的《横吹曲》。这些乐曲大抵为十六国及北魏时代产生的乐曲，其中有不少是少数民族的民歌。后来流传到南朝，被梁代的乐官们加以翻译或润饰，成为今天的样子。这些歌辞中，虽不免有南方乐官加工甚至添加的文字，但基本上产生于北方，表现了北方少数民族质朴、粗犷的特色，与南朝民歌大异其趣。所以现在常以北朝乐府歌辞来称呼它们。

# 企喻歌辞（四首）
题解：《企喻歌辞》：这些乐曲据《乐府诗集》卷二十五引《古今乐录》说，第四首“男儿可怜虫”是苻融（前秦苻坚之弟）诗，那么应为前秦时流行的民族歌谣。清张玉谷在《古诗赏析·凡例》中曾举此诗题目为例，以为是无法对“企喻”二字索解，只能“就诗以论诗”。确实，像这样的例子，在乐府诗中还有一些。
原：其一　男儿欲作健，/结伴不须多。/鹞子经天飞，/群雀两向波。
注：欲作健：要当好汉。
注：鹞（yào要）子：鹞鹰，一种猛禽。两向波：分散逃开。波，同“播”。这二句写鹞子一出现，群雀就四散逃命，比喻好汉“结伴不须多”。
原：其二　放马大泽中，/草好马著膘。/牌子铁裲裆，/𫓴鹳尾条。
注：膘：肥肉。
注原：牌子：不详。余冠英先生认为可能指盾。祸裆（liǎng dāng两当）：背心、马甲，前当心，后当背，故称“两当”。古人作战时防护所穿。
注原：𫓴鹳尾条：（hù户）：一本作“铉”。钜𫓴：头盔。鹳（dí笛）：长尾山雉。此句当指用雉尾羽毛装饰的头盔。
原：其三　前行看后行，/齐着铁裲袖珍裆。/前头看后头，/齐着铁钜锋o
原：其四　男儿可怜虫，/出门怀死忧。/尸丧狭谷中，/白骨无人收。
注：“男儿”四句：意谓战争频繁，出门即可能战死。据《乐府诗集》引《古今乐录》说苻融本诗作“深山解谷口，把（当作白）骨无人收”。

# 琅琊王歌辞（八首选五）
题解：《琅琊王歌辞》：《梁鼓角横吹曲》名之一。《琅琊王》曲名起源不详。从第五曲和第八首看，当属长安一带羌族所建后秦政权的产物。但瑯琊系今山东一带地名。此处疑指南朝侨设的瑯琊，在今江苏南京附近。梁代乐官在加工时因“瑯琊王”之名而加入这些内容。如第六首“孟阳三四月，移铺逐阴凉”，颇似南方气候。第二首的“阳春二三月，单衫绣裲裆”亦然。第七首和第八首的内容也很不一样。所以这些诗当非一时一地之作。
原：其一　新买五尺刀，/悬着中梁柱。/一日三摩娑，/剧于十五女。
注：摩娑：抚弄。剧：甚。这二句说刀比少女更可爱。
原：其三　东山看西山，/水流盘石间。/公死姥更嫁，/孤儿甚可怜。
原：其五　长安十二门，/光门最妍雅。/渭水从垄来，/浮游渭桥下。
注：光门：长安城北边西头第一门称横门，亦称“光门”，“光”、“横”古同音。妍雅：庄丽。
注：垄：当即“陇”，指陇山。渭桥：渭水上古有渭桥。
原：其七　客行依主人，/愿得主人强。/猛虎依深山，/愿得松柏长。
注：客：十六国时代北方汉人往往在山泽间结成坞堡，以防侵扰。“客”，指依附于坞堡的人，他们有些来自外地，故称“客”。主人：指坞堡的首领。
原：其八　侩马高缠鬃，/遥知身是龙。/谁能骑此马，/唯有广平公。
注：马：当即“快马”。龙：比喻好马。
注：广平公：指后秦主姚兴之子姚弼，封广平公，后以作乱被杀。

# 紫骝马歌辞（三首）
题解：《紫骝马歌辞》：《梁鼓角横吹曲》之一。此曲在《汉横吹曲》中也有，可能在音乐上有一定的继承关系。此曲共三首，前两首产生于北朝，反映的是北朝的现实。最后一首“十五从军征”据《乐府诗集》卷二十五引《古今乐录》说是“古诗”。余冠英先生《乐府诗选》把它另编入“汉魏乐府古辞”，作为“杂曲”看待。
原：其一　烧火烧野田，/野鸭飞上天。/童男娶寡妇，/壮女笑杀人。
注：“烧火”句：指古人打猎时放火焚烧野草，使隐藏的禽兽逃出来，以便捕杀。所以下句说“野鸭飞上天”。
注：“童男”二句：描写北朝战乱频仍，男子死亡的多，寡妇改嫁童男，受人讥笑。
原：其二　高高山头树，/风吹叶落去。/一去数千里，/何当还故处。
注：“高高”四句：这首写离乡背井者的痛苦。十六国时期，由于战乱频仍，许多人离开家乡，投奔坞堡以求庇护，无法回家乡安居乐业，故有这种悲叹。
原：其三　十五从军征，/八十始得归。/道逢乡里人，/家中有阿谁?遥看是君家，/松柏冢累累。
注：“家中”句：意谓家中还有什么人。
注：冢：坟。累累：是说数量多。这句是说出征者家人均已死去。
原：兔从狗窦入，/雉从梁上飞。/中庭生旅谷，/井上生旅葵。
注：窦：孔，洞。
注：旅：未经播种而生，即野生。
原：舂谷持作饭，/采葵持作羹。/羹饭一时熟，/不知贻阿谁。/出门东向看，/泪落沾我衣。

# 紫骝马歌
题解：《紫骝马歌》：这是《紫骝马歌辞》的又一种歌辞，写的是女子的相思之情。《乐府诗集》卷二十五引《古今乐录》云：“与前曲不同。”
原：独柯不成树，/独树不成林。/念郎锦裲裆，/恒长不忘心。
注原：恒长不忘心：锦祸裆：用锦做的背心。这二句写相思之情，说的是衣饰，其实是说人。

# 黄淡思歌辞（四首选二）
题解：《黄淡思歌辞》：《梁鼓角横吹曲》之一。曲名含义不详。《乐府诗集》卷二十五引《古今乐录》曰：“思，音相思之思。按：李延年造《横吹曲》二十八解，有《黄覃子》，不知与此同否。”又《晋书·五行志》载：东晋海西公初年，荆州民间曾流行“黄昙子”之歌中有“黄昙英，扬州大佛来上明”之句，文体与此不同。这几首诗似都属南朝民歌的风格，与北朝民歌颇不相同。
原：其二　心中不能言，/复作车轮旋。/与郎相知时，/但恐旁人闻。
注：复：疑当作“腹”。是说回想过去“与郎相知时”情景，心潮起伏。
原：其三　江外何郁拂，/龙洲广州出。/象牙作帆樯，/绿丝作帏。
注：江外：指江以南。古人称“江”不一定是长江。江淹《待罪江南思北归赋》之“江”，即指闽江一带。此处似指珠江水系。郁拂：当即“郁沸”，繁盛而接连不断的样子。
注：龙洲：一说当作“龙舟”。意谓龙舟来自广州。
注原：帏（wéi违）：船上的帐帏。蟀（lù律）：大绳。

# 地驱歌乐辞（四首）
题解：《地驱歌乐辞》：《梁鼓角横吹曲》之一。曲名含义不详。《乐府诗集》卷二十五引《古今乐录》曰：“侧侧力力，以下八句是今歌有此曲。最后云‘不可与力’，或云‘各自努力。”那么前二首与后二首当产生于不同时间。又：“不可与力”和“各自努力”，文义不同，未知孰是。
原：其一　青青黄黄，/雀石颓唐。/槌杀野牛，/押杀野羊。
注原：“青青”句：按“青”、“仓”古时同属一个声部，又古音“庚”“青”与“阳”“唐”同韵，当即“仓仓惶惶”，也就是说发生了突然而恐怖的事。雀石：当是山名或石名。颓唐：崩塌，坠落。按：《水经注·河水》记鸟鼠山一带的“陇坻”，“其山岸崩落者，声闻数百里”。此诗或即写此景象。
注：槌杀：击毙。押：通“压”，韩愈《游太平公主山庄》诗：“故将台榭压城阐”，一本作“押”。
原：其二　驱羊入谷，/白羊在前。/老女不嫁，/蹋地唤天。
注：“蹋地”句：即顿足呼天。“蹋”通“踏”。
原：其三　侧侧力力，/念君无极。/枕郎左臂，/随郎转侧。
注：“侧侧”句：叹息的声音，和《木兰诗》的“唧唧”相近。念君无极：是说想念你没有穷尽。
原：其四　摩捋郎须，/看郎颜色。/郎不念女，/不可与力。
注：“不可”句：即不可相强。一作“各自努力”，为决绝之词。

# 地驱乐歌
题解：《地驱乐歌》：按：《乐府诗集》卷二十五将本诗与《地驱歌乐辞》分列两题，引《古今乐录》曰：“与前曲不同。”可能为另一种曲调。此诗似是女子对情人说的话。
原：月明光光星欲堕，/欲来不来早语我。
注：星欲堕：即群星将消失，指天快亮了。

# 雀劳利歌辞
题解：《雀劳利歌辞》：《梁鼓角横吹曲》之一。曲名不详。余冠英先生认为“劳利”是雀的喧叫声。
原：雨雪霏霏雀劳利，/长嘴饱满短嘴饥。
注：“雨雪”二句：这是用雀来比人。下了雪，食物覆盖在雪下，长嘴的鸟可以吃到，短嘴的就吃不到。比喻有权势、有手段的人可以富贵，而无权势及不会钻营的人只能受穷。

# 慕容垂歌辞（三首）
题解：《慕容垂歌辞》：《梁鼓角横吹曲》之一。慕容垂（326—396）：鲜卑族人，后燕的创立者。慕容垂曾于晋孝武帝太元十年(385）进攻前秦的邺城，东晋大将刘牢之率兵救邺城，打败了慕容垂。慕容垂因此退屯新城。一般认为此诗即指这一事件。但这次战役，慕容垂只是小败，也未被围困，不久即将刘牢之打败。因此“垂”字恐为衍文。“慕容”可能指南燕的慕容超。晋安帝义熙五年（409），刘裕率兵讨伐南燕，围困慕容超于广固（今山东益都西北），南燕遂亡。此诗疑指这一史实。
原：其一　慕容攀墙视，/吴军无边岸。/我身分自当，/枉杀墙外汉。
注：吴军：当即刘牢之或刘裕所率的军队。
注：墙外汉：当指在城墙外抵抗晋军的人。
原：其二　慕容愁愤愤，/烧香作佛会。/愿作墙里燕，/高飞出墙外。
原：其三　慕容出墙望，/吴军无边岸。/咄我诸臣佐，/此事可惋叹。
注：咄（duō多）：叹气声。

# 陇头流水歌辞（三首选二）
题解：《陇头流水歌辞》：《梁鼓角横吹曲》之一。“陇头”指今陕西省陇县附近横亘陕西、甘肃二省间的陇山。山顶有泉水，水声幽咽，行人经过此地，常有思乡之念。
原：其一　陇头流水，/流离西下。/念吾一身飘旷野。
注：流离西下：按：《水经注·渭水》：“渭水又东与新阳崖水合，即陇水也。东北出陇山，其水西流。”当即指此。
原：其二　西上陇坂，/羊肠九回。/山高谷深，/不觉脚酸。
注：羊肠九回：“羊肠”是喻其崎岖曲折。“九回”是说转折的地方多。古人说“九”，不一定是实数，而是说多。（详见清汪中《释三九》。)

# 隔谷歌（二首）
题解：《隔谷歌》：《梁鼓角横吹曲》之一。似为被围困的士兵所作。
原：其一　兄在城中弟在外，/弓无弦，/箭无栝，/食粮乏尽若为活。/救我来，/救我来。
注：栝（guā瓜）：箭的末梢扣弦处。这二句是说城中的人已到了矢穷弦绝的地步。
注：若为活：即怎样才能生存。
原：其二　兄为俘虏受困辱，/骨露力疲食不足。/弟为官吏马食粟，/何惜钱刀来我赎。
注原：兄为俘虏受困辱：隔谷歌：此诗内容与前面的《隔谷歌》类似，或是同一时期的产物。
注：钱刀：即钱。古代货币有铸成刀形的，故称“钱刀”。

# 淳于王歌（二首选一）
题解：《淳于王歌》：《梁鼓角横吹曲》之一。“淳于”本是姓，含义不详。
原：其一　肃肃河中育，/育熟须含黄。/独坐空房中，/思我百媚郎。
注：肃肃：形容植物在风中发出的声音。育：不详。当是一种植物。这二句是起兴，说植物成熟时会变黄。
注：百媚郎：有许多好处的郎君。

# 捉搦歌（四首）
题解：《捉搦歌》：《梁鼓角横吹曲》之一。“捉搦（nuò诺）”有捕捉之意。但从诗的内容看，似多为男女之情。
原：其一　粟谷难舂付石臼，/弊衣难护付巧妇。/男儿千凶饱人手，/老女不嫁只生口。
注：护：调护，这里似指缝补。这二句是说粟谷只有放进石臼才能舂；破衣服只有巧妇才能补。
注：千凶：遭受种种灾难。饱人手：备受别人殴打。只生口：只添了一个吃饭的人。
原：其二　谁家女子能行步，/反着袂禅后裙露。/天生男女共一处，/愿得两个成翁妪。
注：袂（jiá夹）：夹衣。禅（dān丹）：单衣。
注：成翁妪：即成夫妇。
原：其三　华阴山头百丈井，/下有流水彻骨冷。/可怜女子能照影，/不见其见斜领。
注：华阴：地名，今属陕西。可怜：可爱。这首诗是写山中女子顾影自怜，但井水太深，照影只见其衣领。
原：其四　黄桑柘屐蒲子履，/中央有系两头系。/小时怜母大怜婿，/何不早嫁论家计。
注：柘（zhè浙）：柘树，它的木质可以提取黄色染料。形状与桑树相似，故亦称“黄桑”。履：鞋。中央有系：指鞋或木屐都有绳贯穿连结，这里指绳或带。两头系：连结两头。
注：论家计：考虑怎样过好日子。

# 折杨柳歌辞（五首选四）
题解：《折杨柳歌辞》：《梁鼓角横吹曲》之一。按：《汉横吹曲》已有此名。又据《庄子·天地篇》已有《折杨》的曲名。但从这首歌辞来看，可能产生于少数民族，如“我是虏家儿”即其明证。这里入选的四首，前二首似是情人送别之辞。后二首则更多地表现了少数民族生活习惯。
原：其一　上马不捉鞭，/反折杨柳枝。/蹀座吹长笛，/愁杀行客儿。
注：“上马”二句：写行者虽上了马，却不马上出发，反身折下柳枝与送者道别。因为古人送别时，常常折下柳枝以相赠别。
注：蹀（dié蝶）：即“蹀躞（xiè蟹）”，小步行走的样子。座：同“坐”。这两句说走走又坐下吹长笛，以抒别离之情，所以“愁杀行客儿”。
原：其二　腹中愁不乐，/愿作郎马鞭。/出入擐郎臂，/蹀座郎膝边。
注：擐（guān官）：原意为“穿”，此处引申为“系结”。
原：其四　遥看孟津河，/杨柳郁婆娑。/我是虏家儿，/不解汉儿歌。
注：孟津河：孟津是地名，在今河南省黄河边上。郁：茂盛。婆娑：枝叶下垂的样子。
注：虏家儿：这是汉人对少数民族的蔑称，尤多用于鲜卑。此处疑为翻译者所用的词。
原：其五　健儿须快马，/快马须健儿。/跋黄尘下，/然后别雄雌。
注原：然后别雄雌：秘跋（bì bá壁拔）：马奔驰的声音。这是说以骑马驰骋决赛高下。

# 幽州马客吟歌辞（五首选四）
题解：《幽州马客吟歌辞》：《梁鼓角横吹曲》之一。据《艺文类聚》卷十九引《陈武别传》：休屠（匈奴别支）族人陈武，曾于边境学唱《幽州马客吟》等曲。则此曲在西晋前后，当已出现。这五首歌辞，第一首写到了社会问题；第二首似只是及时行乐的意思；第三首以下（包括未入选的第五首）均为情歌。因此这些诗大约非一时一地之作。
原：其一　侩马常苦瘦，/剿儿常苦贫。/黄禾起羸马，/有钱始作人。
注：马：当即快马，与《琅琊王歌》中“侩马高缠鬃”同。剿：劳苦。
注：羸：瘦弱。这两句是用马得到好料才能强壮来比喻“有钱始作人”的现象。
原：其二　荧荧帐中烛，/烛灭不久停。/盛时不作乐，/春花不重生。
注：荧荧：明亮的样子。这两句说烛灭后不久又点上。表示夜游之久。
注：“盛时”二句：意谓春天一过，花不重生，所以要及时行乐。
原：其三　南山自言高，/只与北山齐。/女儿自言好，/故入郎君怀。
原：其四　郎着紫袴褶，/女着彩袂裙。/男女共燕游，/黄花生后园。
注：袴褶（xí习）：骑马时所穿的裤子。袴：同“裤”。彩袂裙：彩色的夹裙。

# 折杨柳枝歌（四首）
题解：《折杨柳枝歌》：《梁鼓角横吹曲》之一。这一组诗第一首与前《折杨柳歌辞》基本相同。第三、四两首，又与《木兰诗》近似。疑亦非一时之作。
原：其一　上马不捉鞭，/反拗杨柳枝。/下马吹长笛，/愁杀行客儿。
原：其二　门前一株枣，/岁岁不知老。/阿婆不嫁女，/那得孙儿抱。
注：枣：余冠英先生以为与“早”谐音，取早嫁之意。这两句似指虽说早嫁，却一年年过去，未能嫁成。
注：阿婆：母亲。
原：其三　敕敕何力力，/女子临窗织，/不闻机杼声，/只闻女叹息。
注：敕敕、力力：都是悲叹的声音。何：语助辞。
原：其四　问女何所思，/问女何所忆。/阿婆许嫁女，/今年无消息。

# 慕容家自鲁企由谷歌
题解：《慕容家自鲁企由谷歌》：《梁鼓角横吹曲》之一。“慕容家”当指南燕慕容氏。（公元398年，慕容德占领今山东一带，都广固，即今益都，至410年为刘裕所灭。）“企由谷”当是地名。此曲或出鲜卑族，但歌辞是情歌，是否后来乐官配曲难于确考。
原：郎在十重楼，/女在九重阁。/郎非黄鹞子，/那得云中雀。
注：黄鹞子：鹞鹰一类猛禽。云中雀：女子自比。这两句说各自远隔，难于成亲。

# 陇头歌辞（三首）
题解：《陇头歌辞》：这和前面的《陇头流水歌辞》当系同一种歌曲。第一首与前者相同。余冠英先生认为这些歌辞“风格和一般北歌不大同，或是汉魏旧辞”。《乐府诗集》卷二十一引《通典》：“天水郡有大阪，名曰陇坻，亦曰陇山，即汉陇关也。”又引《三秦记》曰：“其阪九回，上者七日乃越，上有清水四注下，所谓陇头水也。”
原：其一　陇头流水，/流离山下。/念吾一身，/飘然旷野。
原：其二　朝发欣城，/暮宿陇头。/寒不能语，/舌卷入喉。
注：欣城：当是地名，不详为何处。近来有人认为是离陇地较远的内地，但据《三秦记》所载，恐非。
注：“寒不能语”二句：极写苦寒的情况。沈德潜、张玉谷均极赞二句为奇语。
原：其三　陇头流水，/鸣声幽咽。/遥望秦川，/心肝断绝。
注：秦川：指关中，即今西安一带。

# 高阳王乐人歌（二首）
题解：《高阳王乐人歌》：《梁鼓角横吹曲》之一。高阳王元雍是北魏献文帝之子，孝文帝之弟，北魏后期曾执掌朝政。此曲是他家的乐人们所唱，歌辞可能出于民间。诗中所写的是一些市井少年在酒店中狂饮的情况。温子升有一首《白鼻蜗》称：“少年多好事，揽辔向西都。相逢狭邪路，驻马诣当垆。”内容与此相似。
原：其一　可怜白鼻蜗，/相将入酒家。/无钱但共饮，/画地作交赊。
注：白鼻蜗（guā瓜）：一种黄色黑嘴鼻上呈白色的马。相将：互相跟随。
注：画地：未详。交赊：余冠英先生认为“交”是交现钱，“赊”是欠账，“似是偏义复辞”。这句当指少年们饮酒后向酒店暂欠酒钱。这是市井无赖常有的行为。
原：其二　何处碟觞来，/两颊色如火。/自有桃花容，/莫言人劝我。
注原：碟（tè特）：《类篇》：“歠（chuò辍）也”，“歠”是喝的意思。碟觞：即喝酒。这两句是一个酒徒向另一个说：“你在哪儿喝了酒，脸这样红？”
注：“自有”二句：当是被问者回答：“我脸色本红，更不用说有人敬我酒了。”

# 木兰诗
题解：《木兰诗》：北朝乐府民歌，始见《乐府诗集》，归入《梁鼓角横吹曲》。近代以来关于此诗的创作时代，有北朝和隋唐二说。从诗的内容看来，曾多次提到“可汗”，根据《旧唐书·乐志》的记载，北朝乐歌中有一部分本属鲜卑语，意思不可解，其中多“可汗”二字，是“燕魏之际”的鲜卑歌。这与本诗情况相似。那么本诗当也是北朝乐歌。但流传到南方后，经过乐官们翻译加工，因此有些诗句的风格及诗中提到的某些名称等则颇似隋唐以后人加工的结果。诗中的主人公“木兰”，历来有种种传说，如清人张玉谷认为她是今湖北黄冈附近人，显然是错误的。“木兰”当系虚构的人物，但诗的内容当以北朝和库莫奚、契丹等族的战争为背景。
原：唧唧复唧唧，/木兰当户织。/不闻机杼声，/唯闻女叹息。
注：唧唧：叹息的声音。当户织：对着门织布。
原：问女何所思，/问女何所忆。/女亦无所思，/女亦无所忆。
原：昨夜见军帖，/可汗大点兵。/军书十二卷，/卷卷有爷名。
注：军帖：征发士兵的公文或名册。
注：可汗（kè hán克寒）：古代北方少数民族如鲜卑、柔然、突厥等族对君主或首领的称呼。点兵：征发军人。
注：军书：即“军帖”。爷：父亲。
原：阿爷无大儿，/木兰无长兄。/愿为市鞍马，/从此替爷征。
注：市：购买。
原：东市买骏马，/西市买鞍鞯，/南市买辔头，/北市买长鞭。
注原：西市买鞍鞯：鞍鞯(jiān煎）：马鞍子和垫马鞍的用具。
注：辔（pèi配）头：驾驭牲口用的嚼子和缰绳。
原：旦辞爷娘去，/暮宿黄河边，/不闻爷娘唤女声，/但闻黄河流水鸣溅溅。
注：旦：天明。爷娘：父母。南北朝时已有此称呼。
原：旦辞黄河去，/暮至黑山头。/不闻爷娘唤女声，/但闻燕山胡骑鸣啾啾。
注：黑山：山名，一说即今呼和浩特东南的杀虎山；一说为今北京昌平的军都山，恐以后说为妥。
注：燕山：一说指燕然山（今蒙古的杭爱山），恐非。当指横亘今北京及河北、辽宁间的燕山山脉。鸣啾啾：远处传来的敌骑鸣叫声。
原：万里赴戎机，/关山度若飞。/朔气传金柝，/寒光照铁衣。
注：戎机：军事行动。度：越过。
注：朔气：北方的寒气。金柝（tuò拓）：金属所制的打更梆子，即“刁斗”。
注：寒光：冰雪的反光。铁衣：铠甲。
原：将军百战死，/壮士十年归。/归来见天子，/天子坐明堂。
注：天子：从诗中看来天子似指中原皇帝，与“可汗”非一人。
注：明堂：皇帝祭祀天地、祖宗及朝见群臣、诸侯之处。
原：策勋十二转，/赏赐百千强。/可汗问所欲，/木兰不用尚书郎，/愿驰千里足，/送儿还故乡。
注：策勋：论功。十二转：古代朝廷把功勋分为若干等级，每升一级为“一转”。“十二转”言其多。
注：强：意为更多。
注：“可汗”句：当是天子叫可汗去问木兰有何要求。据此，木兰当是附属于中原天子的某一少数民族的女子。尚书郎：汉代以来，尚书分领各种事务，号为“分曹”，任各“曹”事务的官员叫尚书郎。北魏时，尚书郎位从五品中。
注：千里足：从这句看来，当是快马。但唐段成式《酉阳杂俎》引作“愿驰明驼千里足”，又似指骆驼。
原：爷娘闻女来，/出郭相扶将。/阿姊闻妹来，/当户理红妆。
注：郭：外城。扶将：“将”也是扶的意思，当指木兰的父母互相扶着来迎接。
原：小弟闻姊来，/磨刀霍霍向猪羊。/开我东阁门，/坐我西间床。
注：霍霍：快速的样子。
原：脱我战时袍，/着我旧时裳。/当窗理云鬓，/挂镜帖花黄。
注：鬓（bìn膑）：贴近耳朵的头发。云鬓：以云来形容头发的柔美。花黄：南朝和隋唐间妇女的一种脸部装饰手段，主要用金黄色纸剪成星月花鸟等形贴于额上，或用粉黛在额上涂成黄色的半月形。
原：出门看火伴，/火伴皆惊慌。/同行十二年，/不知木兰是女郎。
注：火伴：同在军营中服务的人。
原：雄兔脚扑朔，/雌兔眼迷离。/双兔傍地走，/安能辨我是雄雌。
注：扑朔：扑腾，乱动的样子。一说是兔走缩脚之状。迷离：朦胧，捉摸不定。
注：“双兔”二句：清人张玉谷《古诗赏析》云：“言雄兔雌兔脚眼虽殊，然当其走，实是难辨也。”

# 李波小妹歌
题解：《李波小妹歌》：李波是北魏时广平（今属河北）人，宗族强盛，在地方上劫掠，屡败官兵，后被刺史李安世所诱杀。
原：李波小妹字雍容，/褰裳逐马如卷蓬。/左射右射必叠双。/妇女尚如此，/男子安可逢。
注：卷蓬：飞蓬，形容其敏捷。
注：叠双：一箭刺中两个人或物。

# 咸阳王歌
题解：《咸阳王歌》：“咸阳王”指北魏孝文帝弟元禧，因谋反逃亡，后被捕杀害。他宫中的人作此歌。
原：可怜咸阳王，/奈何作事误。/金床玉几不能眠，/夜起踏霜露。/洛水湛湛弥岸长，/行人那得度。
注：湛湛：水深的样子。

# 敕勒歌
题解：《敕勒歌》：敕（chì赤）勒：北朝时住在今内蒙一带的少数民族名，一说即维吾尔族。据说北齐高欢进攻北周玉壁，被周将韦孝宽所败。高欢受了伤，为了安定军心，召集诸将宴饮，令部将斛律金(铁勒〔即敕勒〕族人）唱这首歌。此歌本鲜卑语，被人译为汉语。
原：敕勒川，/阴山下。/天似穹庐，/笼盖四野。
注：敕勒川：敕勒族居住的地方。阴山：在今内蒙古境，即阴山山脉。
原：天苍苍，/野茫茫，/风吹草低见牛羊。

# 隋炀帝时挽舟者歌
题解：《隋炀帝时挽舟者歌》：隋炀帝杨广屡次发动侵略高丽的战争，又开运河，造龙船出游江都（今扬州市），沿途由民夫拉纤使船前进，百姓怨苦作歌。
原：我兄征辽东，/饿死青山下。/今我挽龙舟，/又困隋堤道。
注：青山：当在今辽宁境内。按：辽宁西部有黑山县。北周因宇文泰小字“黑獭”，讳“黑”为“青”，隋人仍之，其地正当医巫闾山脉地区（今阜新至锦州一带），疑即此地。
注：隋堤道：隋炀帝在运河两岸曾筑堤种柳。
原：方今天下饥，/路粮无些小。/前去三千程，/此身安可保。
原：寒骨枕荒沙，/幽魂泣烟草。/悲损门内妻，/望断吾家老。
原：安得义男儿，/焚此无主尸。/引其孤魂回，/负其白骨归。

# 大业长白山谣
题解：《大业长白山谣》：此诗见《古今风谣》，逯钦立先生收入《先秦汉魏晋南北朝诗》中。《乐府诗集》卷八十六另有一首《长白山歌》，不如此首奋发昂扬。
原：长白山前知世郎，/纯着红罗绵背裆。/长肴侵天半，/轮刀耀日光。
注：长白山：隋末长白山在今山东章丘县东。知世郎：通晓世情的青壮年。
注原：绵背裆：丝绵背心。稍（shuò朔）：马上用的矛。
原：上山吃獐鹿，/下山吃牛羊。/忽闻官军至，/提刀向前荡。/譬如辽东死，/斩头何所伤。
注：荡：冲击。
注：“譬如”二句：这两句是说譬如被征发去讨伐辽东（侵略高丽）战死，还不如造反而被杀。
