# 清商曲辞·西曲歌
题解：《西曲歌》：南朝乐府民歌的一种，流行于今湖北襄阳、江陵等地。歌曲声调和口音都和长江下游的江浙一带流行的《吴声歌》不同。这两种曲调出现时间未必有什么先后，但《西曲歌》受到士大夫们重视，似在《吴声歌》之后。在《西曲歌》中也有一些歌辞与《吴声歌》相同，如《杨叛儿》与《读曲歌》第七十六首相同，当是用不同音调来唱。

# 石城乐（五首选三）
题解：《石城乐》：《西曲歌》的一种。“石城”在竟陵。据《旧唐书.乐志》说是刘宋臧质所作，臧质在城上望见一群少年唱歌，就作此曲。据此，此曲至少产生在刘宋中叶以前。
诗：其一　生长石城下，/开窗对城楼。/城中诸少年，/出入见依投。
注：依投：依托、投宿。这诗疑为城旁小旅店中女子作，竟陵郡治在今湖北钟祥一带，西边是汉水，为水路交通要道，沿江当有旅舍。
诗：其三　布帆百幅，/环环在江津。/执手双泪落，/何时见欢还。
注：环环：形容布帆之多。“环”是“还”的谐音。
诗：其五　闻欢远行去，/相送方山亭。/风吹黄檗藩，/恶闻苦离声 。
注：方山亭：按《文选》谢灵运《邻里相送至方山》诗注引《丹阳郡图经》，方山在江宁县东五十里。据此，这首诗或本是《吴声歌》，后改用《西曲歌》演唱。
注：苦离声：双关语。以“苦”指上句“黄檗”；以“篱”（即“藩”）的谐音“离”指“藩”字。

# 乌夜啼（八首选三）
题解：《乌夜啼》：《西曲歌》之一。旧说以为是宋临川王刘义庆或衡阳王刘义季作，说是与彭城王刘义康被贬事有关，不可信。此曲当是民歌。
诗：其二　长樯铁鹿子，/布帆阿那起。/诧侬安在间，/一去数千里 。
注：铁鹿子：指铁鹿轳，是起重用的工具。
注：阿那：即“婀娜”（ēnuó阿挪），柔软美好的样子。
注：诧（chà岔）：惊讶。这两句是说使我惊讶他在那里时，他已离去几千里了。形容船驶得快。
诗：其四　可怜乌臼鸟，/强言知天曙。/无故三更啼，/欢子冒阍去。
注：乌臼鸟：见前《读曲歌》第五十五首注〔1〕。
注：阍：同“暗”。
诗：其八　巴陵三江口，/芦荻齐如麻。/执手与欢别，/痛切当奈何。
注：巴陵：在今湖南岳阳市一带。

# 莫愁乐（二首）
题解：《莫愁乐》：莫愁，传说中美人名。宋洪迈《容斋三笔》卷十《两莫愁》：“莫愁者，郢州石城人，今郢有莫愁村。”古辞《河中之水歌》：“洛阳女儿名莫愁”，洪迈认为与《莫愁乐》非一人。其实“莫愁”只是传说中人物。
诗：其一　莫愁在何处，/莫愁石城西。/艇子打两桨，/催送莫愁来。
诗：其二　闻欢下扬州，/相送楚山头。/探手抱腰看，/江水断不流。

# 襄阳乐（九首选三）
题解：《襄阳乐》：《西曲歌》之一。据《乐府诗集》卷四十八引《古今乐录》以为是南朝宋随王刘诞在文帝元嘉时所作。但《古今乐录》说到刘诞“夜闻诸女歌谣”，恐此曲声调在元嘉前已有。今入选诸诗，当是民歌。
诗：其一　朝发襄阳城，/暮至大堤宿。/大堤诸女儿，/花艳惊郎目。
诗：其四　人言襄阳乐，/乐作非侬处。/乘星冒风流，/还侬扬州去。
诗：其八　女萝自微薄，/寄托长松表。/何惜负霜死，/贵得相缠绕。
注：女萝：植物名，有藤，攀缠树枝。

# 雍州曲（三首选一）
题解：《雍州乐》：《西曲歌》之一。传为梁萧纲作。襄阳是南朝雍州治所，因此此曲疑即《襄阳乐》。
诗：其二　岸阴垂柳叶，/平江含粉蝶。/好值城旁人，/多逢荡舟妾。/绿水溅长袖，/浮苔染轻楫。
注：“平江”句：指江面平静，粉蝶在上飞舞。
注：“浮苔”句：指青苔附着在船桨上。

# 三洲歌（三首）
题解：《三洲歌》：据《乐府诗集》卷四十八引《古今乐录》，说是商人游巴陵三江口而作。
诗：其一　送欢板桥弯，/相待三山头。/遥见千幅帆，/知是逐风流。
诗：其二　风流不暂停，/三山隐行舟。/愿作比目鱼，/随欢千里游。
诗：其三　湘东酃𫘧酒，/广州龙头铛。/玉樽金镂椀，/与郎双杯行。
注原：湘东酃𫘧酒：酃酒：即“（líng lù陵鹿）酒”，古代美酒名。
注：龙头铛（chēng撑）：饰有龙头形状的锅子一类器具，这里指温酒的器具。

# 江陵乐（四首选二）
题解：《江陵乐》：《西曲歌》之一。江陵即今湖北江陵。南朝时是重镇，梁元帝曾建都于此。
诗：其三　阳春二三月，/相将蹋百草。/逢人驻步看，/扬声皆言好。
诗：其四　暂出后园看，/见花多忆子。/乌鸟双双飞，/侬欢今何在。

# 青阳度（三首选一）
题解：《青阳度》：《西曲歌》之一。《乐府诗集》卷四十九引《古今乐录》说《青阳度》是“倚歌”，演奏时用铃和鼓，无弦乐，有吹奏乐器。
诗：其二　碧玉捣衣砧，/七宝金莲杵。/高举徐徐下，/轻捣只为汝。

# 采桑度（七首选四）
题解：《采桑度》：《西曲歌》之一，一名《采桑》。《旧唐书·乐志》认为是因《三洲歌》而产生的。
诗：其一　蚕生春三月，/春桑正含丝。/女儿采春桑，/歌唱当春曲。
诗：其五　春月采桑时，/林下与欢俱。/养蚕不满百，/那得罗绣襦。
注：襦（rú如）：短袄。
诗：其六　采桑盛阳月，/绿叶何翩翩。/攀条上树表，/牵坏紫罗裙。
诗：其七　伪蚕化作茧，/烂熳不成丝。/徒劳无所获，/养蚕持底为。
注：伪蚕：疑指有病的蚕。烂熳：同“烂漫”，意为破碎不坚实。

# 青骢白马（八首选四）
题解：《青骢白马》：《西曲歌》之一。《乐府诗集》卷四十九引《古今乐录》说是旧舞用十六人。
诗：其二　汝忽千里去无常，/愿得到头还故乡。
诗：其三　系马可怜着长松，/游戏徘徊五湖中。
诗：其四　借问湖中采菱妇，/莲子青荷可得否?
注：莲子：“怜子”的谐音。
诗：其七　问君可怜下都去，/何得见君复西归。
注：下都：指从荆襄到都城建康，是从上游到下游，故称“下都”。

# 安东平（五首）
题解：《安东平》：《西曲歌》之一。按：《汉横吹曲》有《刘生》，《梁鼓角横吹曲》有《东平刘生》。此曲第五首有“东平刘生”句，疑出一源。
诗：其一　凄凄烈烈，/北风为雪。/船道不通，/步道断绝。
诗：其二　吴中细布，/阔幅长度。/我有一端，/与郎作袴。
诗：其三　微物虽轻，/拙手所作。/有三丈，/为郎别厝。
注：厝（cuò措）：安置。
诗：其四　制为轻巾，/以奉故人。/不持作好，/与郎拭尘。
诗：其五　东平刘生，/复感人情。/与郎相知，/当解千龄。

# 女儿子（二首选一）
题解：《女儿子》：《西曲歌》之一。《乐府诗集》卷四十九引《古今乐录》说是“倚歌”。
诗：其一　巴东三峡猿鸣悲，/夜鸣三声泪沾衣。

# 来罗（四首选一）
题解：《来罗》：《西曲歌》之一。《乐府诗集》卷四十九引《古今乐录》说是“倚歌”。
诗：其一　郁金黄花标，/下有同心草。/草生日已长，/人生日就老。
注：标：高枝。这里引伸为郁金香的花枝高处。

# 那呵滩（六首选三）
题解：《那呵滩》：《西曲歌》之一。多叙江陵及扬州事。“那呵滩”是滩名。此曲演奏时伴以舞蹈。
诗：其三　江陵三千三，/何足持作远。/书疏数知闻，/莫令信使断。
诗：其四　闻欢下扬州，/相送江津弯。/愿得篙橹折，/交郎到头还。
注：交：同“教”。到：同“倒”。
诗：其五　篙折当更觅，/橹折当更安。/各自是官人，/那得到头还。
注：官人：为官府服役的人。

# 孟珠（十首选四）
题解：《孟珠》：《西曲歌》之一，又称《丹阳孟珠歌》。据第一首“人言孟珠富”看来，当是人名。从第三首“后湖”、第四首“扬州”、第十首“景阳山”看，当是客居建康的荆襄一带人所作。此曲据《古今乐录》云：“《孟珠》十曲，二曲，倚歌八曲。旧舞十六人，梁八人。”
诗：其二　阳春二三月，/草与水同色。/攀条摘香花，/言是欢气息。
诗：其三　人言春复著，/我言未渠央。/暂出后湖看，/蒲菰如许长。
注：春复著：意为春色已经很明显。
注：未渠央：还没有完全到一半。
注：后湖：在建康城北。
诗：其五　阳春二三月，/草与水同色。/道逢游冶郎，/恨不早相识。
注：游冶郎：修饰华美的行游少年。
诗：其九　适闻梅作花，/花落已成子。/杜鹃绕林啼，/思从心下起。

# 翳乐（三首选一）
题解：《翳乐》：《西曲歌》之一。据《乐府诗集》卷四十九引《古今乐录》云：“《翳乐》一曲，倚歌二曲。”
诗：其三　人言扬州乐，/扬州信自乐。/总角诸少年，/歌舞自相逐。

# 夜黄
题解：《夜黄》：《西曲歌》之一。据《乐府诗集》卷四十九引《古今乐录》说是“倚歌”。
诗：湖中百种鸟，/半雌半是雄。/鸳鸯逐野鸭，/恐畏不成双。

# 夜度娘
题解：《夜度娘》：《西曲歌》之一。据《乐府诗集》卷四十九引《古今乐录》说是“倚歌”。此曲据一些研究者说是妓女的歌，但从全诗看，恐亦是女子与情人相约之辞。
诗：夜来冒霜雪，/晨去履风波。/虽得叙微情，/奈侬身苦何。

# 长松标
题解：《长松标》：《西曲歌》之一。据《乐府诗集》卷四十九引《古今乐录》说是“倚歌”。“标”即高枝。
诗：落落千丈松，/昼夜对长风。/岁暮霜雪时，/寒苦谁与双。

# 黄督
题解：《黄督》：题名不详。《西曲歌》之一。据《乐府诗集》卷四十九引《古今乐录》说是“倚歌”。
诗：乔客他乡人，/三春不得归。/愿看杨柳树，/已复藏班骓。
注：乔客：即“侨客”。
注：班骓（zhuī追）：班鸠，鸟名。

# 白附鸠
题解：《白附鸠》：《西曲歌》之一。据《乐府诗集》卷四十九引《古今乐录》说是“倚歌”。此曲又名《白浮鸠》，本是《拂舞曲》。据《乐府诗集》卷五十四所言，晋代有《拂舞》。《晋书》和《南齐书》的《乐志》都说是江南吴地的舞曲。但所载曲辞均非吴歌，不知所起。
诗：石头龙尾弯，/新亭送客者。/酤酒不取钱，/郎能饮几许。
注：石头：当即石头城，在今南京。新亭：地名，在今南京市西。

# 拔蒲（二首）
题解：《拔蒲》：《西曲歌》之一。据《乐府诗集》卷四十九引《古今乐录》说是“倚歌”。
诗：其一　青蒲衔紫茸，/长叶复从风。/与君同舟去，/拔蒲五湖中。
注：“青蒲”句：语出谢灵运《于南山往北山经湖中瞻眺》诗“新蒲含紫茸”句。
注：五湖：即今江浙二省间的太湖。
诗：其二　朝发桂兰渚，/昼息桑榆下。/与君同拔蒲，/竟日不成把。
注：“与君”二句：写与情人一起拔蒲，因欢乐而心不在拔蒲，所以“竟日不成把”。

# 作蚕丝（四首选二）
题解：《作蚕丝》：《西曲歌》之一。据《乐府诗集》卷四十九引《古今乐录》说是“倚歌”。这里所录二首，都是借蚕丝来暗喻自己。
诗：其二　春蚕不应老，/昼夜常怀丝。/何惜微躯尽，/缠绵自有时。
诗：其四　素丝非常质，/屈折成绮罗。/敢辞机杼劳，/但恐花色多。

# 杨叛儿（八首选二）
题解：《杨叛儿》：《西曲歌》之一。《乐府诗集》卷四十九引《古今乐录》说是此曲有送声云“叛儿教侬不复相思”，故名。此曲第二首与《读曲歌》第七十六全同。
诗：其四　送郎乘艇子，/不作遭风虑。/横篙掷去桨，/愿倒逐流去。
诗：其六　欢欲见莲时，/移湖安屋里。/芙蓉绕床生，/眠卧抱莲子。

# 西乌夜飞（四首选二）
题解：《西乌夜飞》：《西曲歌》之一。《宋书·乐志》认为是沈攸之作。《乐府诗集》卷四十九引《古今乐录》更认为此曲“和声”云“白日落西山，归去来”，“送声”云“折翅乌，飞何处，被弹归”，故名。但从现存歌辞看，似均为民间情歌。
诗：其一　日从东方出，/团团鸡子黄。/夫归恩情重，/怜欢故在旁。
诗：其四　感郎崎岖情，/不复自顾虑。/臂绳双人结，/遂成同心去。

# 月节折杨柳歌（十三首选二）
题解：《月节折杨柳歌》：《西曲歌》之一。每月一歌，末附《闰月歌》，共十三首。
原：八月歌
诗：迎欢裁衣裳，/日月流如水，/白露凝庭霜。/折杨柳。/夜闻捣衣声，/窈窕谁家妇。
注：窈窕（yǎo tiǎo咬挑）：美好。
原：十一月歌
诗：素雪任风流，/树木转枯悴，/松柏无所忧。/折杨柳。/寒衣履薄冰，/欢讵知侬否。
