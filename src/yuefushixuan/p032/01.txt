# 豫章行苦相篇
题解：《豫章行苦相篇》：《相和歌辞·清调曲》之一。据《乐府诗集》卷三十四引《古今乐录》载王僧虔语，谓“《荀录》所载古《白杨》一篇，今不传”。疑不传者是曲调，但“晋乐所奏”《豫章行·白杨》一首，虽文字残缺，当载《乐府诗集》中。《白杨》内容为树木生豫章山中，为人砍伐，建造舟船、宫室，使枝叶与根分离。其后曹植曾拟作两首，讲古人穷达的事。傅玄这首则写封建社会妇女受歧视的情况及其悲惨命运。文字质朴，多用白描手法。
题解：傅玄（217—278）：字休奕，北地泥阳（今陕西耀县）人。三国时仕魏为郎中，历弘农太守、典农校尉等官，封鹑觚男。司马炎代魏，进封子爵，官至太仆、司隶校尉，曾多次上奏政事，著有《傅子》及《傅子集》五十卷，今佚。明人辑有《傅鹑觚集》。他擅长乐府，拟作乐府诗甚多，诗风较质朴，多保存民歌色彩，内容偏于哀惋，反映的社会现实较广。
原：苦相身为女，/卑陋难再陈。/男儿当门户，/堕地自生神。
注：苦相：作者虚拟的人名，借此表示妇女的苦难。卑陋：当指地位卑微。
原：雄心志四海，/万里望风尘。/女育无欣爱，/不为家所珍。
注原：不为家所珍：“男儿”六句：写当时男子出生时即被重视，父母就希望他能立下大志，建功万里。这种重男轻女的思想，早在《诗经·小雅·斯干》中就有男子生下来即望其“朱芾斯皇，室家君王”；生了女子却只说“无非无仪，唯酒食是议，无父母诒罹”的思想。傅玄生在魏晋时代对此表示不满，颇具卓见。
原：长大逃深室，/藏头羞见人，/垂泪适他乡，/忽如雨绝云。
注：“垂泪”句：指长大后远嫁到异地。“忽如”句：比喻女子出嫁后，像雨滴从云层中落下，从此成了别家的人。
原：低头和颜色，/素齿结朱唇。/跪拜无复数，/婢妾如严宾。
注：“素齿”句：写女子出嫁后不敢随便说话。牙齿藏在唇内，形容其不敢启齿。
原：情合同云汉，/葵藿仰阳春。/心乖甚水火，/百恶集其身。
注：云汉：银河。这里借喻天上的牛郎织女星。这两句比喻女子如和丈夫情投意合，也如牛郎织女，不能常聚，而且女子之对丈夫，也只是如葵藿的仰望阳光，尊卑悬绝。
注：心乖：指男子变了心。这两句是说一旦男子变心，各种罪名都强加到女子身上。
原：玉颜随年变，/丈夫多好新。/昔为形与影，/今为胡与秦。/胡秦时相见，/一绝逾参辰。
注原：胡：北方少数民族。秦：指汉族。胡与秦言地域种族不同。参辰：指天上的参星和商星。这两个星一个升起时，另一个就降落，不能同时见于天空。故以此比喻不相见。《文选》陆士龙（云）《答兄机诗》五臣吕向注：“商，辰星也。”

# 董逃行历九秋篇
题解：《董逃行历九秋篇》：《董逃行》，本《相和歌辞·清调曲》。《后汉书·五行志》云：“灵帝中平中，京都歌曰：承乐世董逃，游四郭董逃，蒙天恩董逃，带金紫董逃，行谢恩董逃，整车骑董逃，垂欲发董逃，与中辞董逃，出西门董逃，瞻宫殿董逃，望京城董逃，日夜绝董逃，心摧伤董逃。案：‘董’谓董卓也，言虽跋扈纵其残暴，终归逃窜至于灭族也。”李贤注引《风俗通》还讲到了董卓禁绝此歌的事。黄节先生《汉魏乐府风笺》卷三引吴旦生说，以为“乐府原题谓《董逃行》，作于汉武之时。盖武帝有求仙之兴，董逃者，古仙人也”。但后人所作《董逃行》，内容各各不同，今存古辞《董逃行》（“吾欲上谒从高山”）一首，内容为求仙，或与吴旦生说相近。至于以“董逃”为指董卓事，当出附会，不可信。至于傅玄的《历九秋篇》，写的是妇女自恐年老色衰，被丈夫遗弃的心情。与求仙及董卓事皆无关系。
题解：傅玄：逯钦立《先秦汉魏晋南北朝诗》云：“《诗纪》作《董逃行历九秋篇》十二首。六言。并注云：《玉台新咏》以前十首作梁简文帝。今从乐府并为玄诗。，《选诗拾遗》曰：《乐录》云傅玄作。据《文选注》引之，以为汉古辞也。”但今所见各本《玉台新咏》均未将前十首与后二首分开；亦不言前十首为梁简文帝作。吴兆宜注谓“一本以前十首作简文帝”，疑是明代有此种版本。又，《选诗拾遗》据《文选注》谓汉代古辞说。按：《文选》卷二十二沈约《宿东园》诗注引《古董逃行》云：“年命冉冉我遒。”与此诗“良时冉冉代征”文字不同，且“征”字与上文“盈”字为韵，恐《文选注》所引佚句，并非出于本诗。故仍作傅玄诗。
原：历九秋兮三春，/遗贵客兮远宾，/顾多君心所亲。/乃命妙妓才人，/炳若日月星辰。
注：九秋、三春：皆指较长的时间，“九”与“三”皆非确数，详见清汪中《释三九》。遗：一作“分遣”。按：“遗”一音“随（suí）”，作“谦以下人”解，似与文义较近。
注：“乃命”二句：意谓“妙妓才人”容貌艳丽，光彩照人，如同“日月星辰”。
原：（其一）序金罍兮玉觞，/宾主递起雁行，/杯若飞电绝光。/交觞接卮结裳，/慷慨欢笑万方。
注：“宾主”二句：意谓宾主在宴会上依次起身敬酒，彼此都很快地喝干，酒壶（罍）和酒杯（觞）传递得飞快，犹如闪电一样。“雁行”：谓有次序而行。
原：(其二）奏新诗兮夫君，/烂然虎变龙文，/浑如天地未分。/齐讴楚舞纷纷，/歌声上激青云。
注：“奏新诗兮”句：奏，进献。这句说向夫君进献新诗。“烂然”句：《周易·革卦·象传》：“大人虎变，其文炳也。”班固《东都赋·宝鼎诗》：“焕其炳兮被龙文。”这句是说“新诗”的文采绚烂。“浑如”句：这句是说夫君浑然不悟。
原：（其三）穷八音兮异伦，/奇声靡靡每新，/微披素齿丹唇。/逸响飞薄梁尘，/精爽眇眇入神。
注：逸响：飘逸超群的乐声。薄：迫，近。飞薄梁尘：形容乐声美妙动人。《艺文类聚》卷四十三引刘向《别录》云：“汉兴以来，善雅歌者，鲁人虞公，发声清哀，盖动梁尘。”精爽：这里指音乐的神妙。眇眇：指精微。
原：（其四）坐咸醉兮沾欢，/引樽促席临轩，/进爵献寿翻翻。/千秋要君一言，/愿爱不移若山。
注：促席：古人席地而坐，把坐席互相移近。曰“促席”。翻翻：意同“翩翩”，往来的样子。
注：要：约的意思。这句说要求你永久记住一句话。
原：（其五）君恩爱兮不竭，/譬若朝日夕月，/此景万里不绝。/长保初醮结发，/何忧坐生胡越。
注原：初醮结发：醮（jiào较），古代婚礼时，双方父亲各自给新郎和新娘斟酒。结发：古人成年时要结发。相传为苏武所作的《留别妻》诗：“结发为夫妻”。这句是说希望丈夫长保新婚时的感情。胡越：本指远在南方（越）和北方（胡）的少数民族地区。这里代指恩情隔绝。
原：（其六）携弱手兮金环，/上游飞阁云间，/穆若鸳凤双燕。/还幸兰房自安，/娱心乐意难原。
注：穆：和好。
注：原：推究、测度。
原：（其七）乐既极兮多怀，/盛时忽逝若颓，/寒暑革御景回。/春荣随风飘摧，/感物动心增哀。
注：革御：指改变节令。景：指太阳。回：转向。
原：（其八）妾受命兮孤虚，/男儿堕地称姝，/女弱难存若无。/骨肉至亲更疏，/奉事他人托躯。
注：孤虚：古代人迷信某些时日出生的人，命属“孤”、“虚”，就命运不好。
注原：姝：各本一作“珠”，一作“殊”。按此诗文义，似作“殊”为佳。《诗经·小雅·斯干》写到“乃生男子”时云“其泣喤喤，朱芾斯皇，家家君王”，正指“男儿堕地称殊”。“殊”，有特出之意。《乐府古辞·陌上桑》：“皆言夫婿殊”。
原：（其九）君如影兮随形，/贱妾如水浮萍，/明月不能常盈。/谁能无根保荣，/良时冉冉代征。
原：（其十）顾绣领兮含辉，/皎日回光则微，/朱华忽示渐衰。/影欲舍形高飞，/谁言往思可追。
注：“顾绣领”二句：是说绣衣领子上被阳光照射发出光辉，但太阳下山后光彩就减弱，形容年光消逝，容貌即随着衰歇。
注：“影欲”二句：这两句承上“君如影兮随形”而来，以“影”喻夫，以“形”自喻。往思，指往日情义。
原：(其十一）荠与麦兮夏零，/兰桂践履逾馨，/禄命悬天难明。/妾心结意丹青，/何忧君心中倾。/(其十二)
注：丹青：指女子的心意如图画（丹青）一样清楚明白。倾：倾斜。这里指变心。

# 秋胡行（二首选一）
题解：《秋胡行》：《相和歌辞·清调曲》之一。此曲大约即由“秋胡戏妻”故事得名，但古辞已佚。曹操、曹丕等人所作，只是仿其曲调，内容与秋胡无关。现今所见乐府诗中咏秋胡故事的，以傅玄此首为最早。此诗据《乐府诗集》卷三十六所载，凡二首，但《玉台新咏》只采第二首（题为《和班氏诗》），其实傅诗确以第二首为好，所以选取此首。此诗与后来颜延之的《秋胡行》各有所长，但颜诗似更细致而华丽，所以《文选》仅取颜作，而颜诗传诵程度也超过了此诗。
原：其二　秋胡纳令室，/三日官他乡。/皎皎洁妇姿，/泠泠守空房。
注：令：善，美好。室：妻室。
注：皎皎：洁白。洁妇：贞洁的妇女。泠泠（líng铃）：清凉。这里引申为寂寞凄凉。
原：燕婉不终夕，/别如参与商。/忧来犹四海，/易感难可防。
注：燕婉：指夫妻恩爱。参与商：天上的两颗星，参星出现时，商星就见不到，反之亦然。古人常用此表示阔别。
原：人言生日短，/愁者苦夜长。/百草扬春华，/攘腕采柔桑。
注原：攘腕：伸出手腕。柔桑：柔嫩的桑叶。《诗经·豳风·七月》：“爰求柔桑。”
原：索手寻繁枝，/落叶不盈筐。/罗衣翳玉体，/回目流采章。
注原：不盈筐：不满筐。《诗经·周南·卷耳》：“不盈倾筐。”
注：翳（yì益）：遮盖。采章：文采。此处形容目光的娟好。
原：君子倦仕归，/车马如龙骧。/精诚驰万里，/既至两相忘。
注：龙骧（xiāng襄）：像龙飞腾一样快。
原：行人悦令颜，/借息此树旁。/诱以逢卿喻，/遂下黄金装。
注：逢卿喻：据《列女传》载，秋胡曾对妻子说“力田不如逢少年，力桑不如见公卿”。遂下黄金装：指取下行装中的黄金相赠。
原：烈烈贞女忿，/言辞厉秋霜。/长驱及居室，/奉金升北堂。
原：母立呼妇来，/欢情乐未央。/秋胡见此妇，/惕然怀探汤。
注：惕（tì替）：小心谨慎。探汤：手伸进烫水中。比喻戒惧之意。
原：负心岂不渐，/永誓非所望。/清浊为异源，/凫凤不并翔。
注：“永誓”句：誓称不敢抱这希望。
注：“凫凤”句：清吴兆宜《玉台新咏注》以为“凫”当作“枭”，其实不必改字。“凫”是野鸭，不足与凤凰相比。
原：引身赴长流，/果哉洁妇肠。/彼夫既不淑，/此妇亦太刚。
注：长流：河水。

# 饮马长城窟行
题解：《饮马长城窟行》：这首傅玄的拟作，显然是取古辞《饮马长城窟行》的用意，与陈琳之作不同。在《乐府诗集》所录的后人拟作中，效法古辞的较少。傅玄的乐府诗中，写妇女生活的较多，此诗亦属这一类。诗中“旷如参与商”下面，《玉台新咏》卷二所录，多出“梦君结同心，比翼游北林；既觉寂无见，旷如商与参”四句。但意思与前四句重复。今从《乐府诗集》。
原：青青河边草，/悠悠万里道。/草生在春时，/远道还有期。
原：春至草不生，/期尽叹无声。/感物怀思心，/梦想发中情。
注原：期尽叹无声：“远道”句：去远处的人本来约定归期。声：音讯。这四句是说正如春天一到，草就会生长，到了约定的日期本想征人就会归来。谁知征人到期不归；正如春天到了草不生长一样不可理解。
注：“梦想”句：因心中想念而发于梦想。
原：梦君如鸳鸯，/比翼云间翔。/既觉寂无见，/旷如参与商。
注：参与商：见前《豫章行苦相篇》注〔9〕。
原：河洛自用固，/不如中岳安。/回流不及反，/浮云往自还。
注：“河洛”二句：河洛指黄河与洛水，这两条河虽长存不变，但水还是流动的，不及中岳（嵩山）这样安稳不变。
注：回流：旋转的流水。反：同“返”。这两句说旋涡的水虽回转仍流去不归，倒不如浮云，飘走了有时还能飘回来。
原：悲风动思心，/悠悠谁知者。/悬景无停居，/忽如驰驷马。
注：悬景：挂在天上的太阳。忽如驰驷马：像奔驰的马那样迅速流逝。
原：倾耳怀音响，/转目泪双堕。/生存无会期，/要君黄泉下。
注：怀音响：怀念其人的声音，实即想念他。
注：黄泉下：指死后。这四句说侧着耳朵听征人归来的音讯，却无所闻，伤心落泪。预料活着无法相见，只能期待死后相见。

# 放歌行
题解：《放歌行》：《相和歌辞·瑟调曲》之一。据《乐府诗集》引《歌录》，则此曲实即《孤儿行》的别名。这首傅玄的拟作是哀叹人生短促，对死者表示哀悼，与《孤儿行》不大一样。至于后来鲍照等人的《放歌行》，写的又是仕途中人对待官爵的问题，与此诗也不相同。
原：灵龟有枯甲，/神龙有腐鳞。/人无千载寿，/存质空相因。
注：“灵龟”句：指卜筮用的灵龟已只剩枯甲，言其已死。“神龙”句：也是说龙亦有死。腐鳞就是死的意思。
注原：质：指躯体。司马迁《报任安书》：“若仆大质已亏损矣。”因：依也。这句说躯体虽暂时存在，也只是徒然寄托着一样。
原：朝露尚移景，/促哉水上尘。/丘冢如履綦，/不识故与新。
注：移景：日光移动。这两句说朝露尚待太阳移照到那里才消失，而人生却如水上的尘土一样瞬间就落入水中。
注：履：鞋。綦（qí其）：鞋带。这两句说冢墓相连，如同鞋与鞋带那样紧挨着，分辨不出新坟与旧坟。
原：高树来悲风，/松柏垂威神。/旷野何萧条，/顾望无生人。
注：“松柏”句：松柏本是古人种在坟地上的树木，大风吹来，更显出死亡的恐怖。
原：但见狐狸迹，/虎豹自成群。/孤雏攀树鸣，/离鸟何缤纷。
注：离鸟：离群的鸟。缤纷：繁乱。
原：愁子多哀心，/塞耳不忍闻。/长啸泪雨下，/太息气成云。
注：太息：同“叹息”。这两句写心怀愁思的人见此景象十分伤心。

# 白杨行
题解：《白杨行》：《相和歌辞·瑟调曲》之一。这首诗是借千里马不为人知之苦暗喻不得志。此诗取义自贾谊《吊屈原赋》“骥垂两耳服盐车兮”典。
原：青云固非青，/当云奈白云。/骥从西北驰来吾何忆。/骥来对我悲鸣，/举头气凌青云，/当奈此骥正龙形。
原：豌足蹉跎长坡下。/蹇驴慷忾，/敢与我争驰。/踯躅盐车之中，/流汗两耳尽下垂。
注：跎（wǎn宛）：屈曲。
注：慷忾（kài慨）：同“慷慨”，这里指激昂。
注：我：指骥。
注：踯躅（zhí zhú职烛）：徘徊不进。
原：虽怀千里之逸志，/当时一得施。/白云剽剽，/舍我高翔。
注：剽剽（piāo飘）：同“飘飘”。
原：青云徘徊，/戢我愁啼。/上眄增崖，/下临清池。
注原：戢我愁啼：戢(jí集）：停止。
注：眄（miàn面）：看。增崖：同层崖，即高的山崖。
原：日欲西移，/既来归君，/君不一顾。/仰天太息，/当用生为青云乎。/飞时悲当奈何耶！/青云飞乎！

# 怨歌行朝时篇
题解：《怨歌行朝时篇》：此诗显然取班婕妤《怨歌行》而加以发挥。但写的是民间弃妇的生活。“朝时篇”当取首句中二字作为篇名。
原：昭昭朝时日，/皎皎最明月。/十五入君门，/一别终华发。
注：朝时：早上。这两句用日月的光明形容自己的心迹。
注：华发：同“花发”，即初生白发。
原：同心忽异离，/旷如胡与越。/胡越有会时，/参辰辽且阔。
注：旷：远隔。
注：参辰：指参星与辰星，两星此升彼落，永不相遇。
原：形影无仿佛，/音声寂无达。/纤弦感促柱，/触之哀声发。
注：纤弦：纤细的琴弦。这两句意指弹琴时扣动接近琴柱处，声音显得急促，因此使人悲怆。
原：情思如循环，/忧来不可遏。/涂山有恨，/诗人咏《采葛》。
注：涂山：据说禹娶于涂山氏，禹因出门治水，涂山氏想念他，派妾在涂山之阳等他，作歌云：“候人兮猗。”见《吕氏春秋·音初》。
注：采葛：语出《诗经·王风·采葛》：“被采葛兮，一日不见，如三月兮。”
原：蜻蜊吟床下，/回风起幽闼。/春荣随路落，/芙蓉生木末。
注原：蜻蜊吟床下：蜻蜊(jīng liè精列）：蟋蟀。
注：回风：旋转的风。
注原：春荣：春天的花。芙蓉：荷花。木末：树顶上。屈原《九歌·湘君》：“搴芙蓉兮木末。”
原：自伤命不遇，/良辰永乖别。/已尔可奈何，/譬如纨素裂。
注：已尔：完了。
原：孤雌翔故巢，/星流光景绝。/魂神驰万里，/甘心要同穴。
注：要：约。同穴：死后合葬。

# 秦女休行
题解：《秦女休行》：这是傅玄拟左延年《秦女休行》之作，疑庞娥是当时实有其人，因与秦女休故事相似，所以傅玄仿左诗另作此篇加以歌颂。
原：庞氏有烈妇，/义声驰雍凉。/父母家有重怨，/仇人暴且强。
注：雍凉：古代的州名，即雍州和凉州。在今陕西、甘肃一带。
原：虽有男兄弟，/志弱不能当。/烈女念此痛，/丹心为寸伤。
注：丹心：红心。寸伤：伤心而寸断，形容痛苦。
原：外若无意者，/内潜思无方。/白日入都市，/怨家如平常。
注：无方：形容思虑之深。如平常：不防备，像往时一样。
原：匿剑藏白刃，/一奋寻身僵。/身首为之异处，/伏尸列肆旁。
注：奋：勇猛一击。寻：马上。这句指庞娥奋身挺剑，怨家立即倒毙。
注：肆：店铺。
原：肉与土合成泥，/洒血溅飞梁。/猛气上干云霓，/仇党失守为披攘。
注：干：犯，直冲。披攘：同披靡，惊惶奔乱。
原：一市称烈义，/观者收泪并慨忼。/百男何当益，/不如一女良。
原：烈女直造县门，/云父不幸遭祸殃。/今仇身以分裂，/虽死情益扬。
原：杀人当伏法，/义不苟活隳旧章。/县令解印绶，/令我心伤不忍听。
注：隳（huī挥）：破坏。
注：绶：印带。这两句说县令解去印绶，自称不忍听此事，表示不愿把庞娥治罪。
原：刑部垂头塞耳，/令我吏举不能成。/烈著希代之绩，/义立无穷之名。
注：举：举发犯人罪行。
注：希代：即“希世”，世所少有。
原：夫家同受其祚,子子孙孙，/咸享其荣。/今我弦歌，/吟咏高风，/激扬壮发悲且清。
注：祚（zuò作）：福佑。

# 吴楚歌
题解：《吴楚歌》：《玉台新咏》卷九作《燕人美篇》；《乐府诗集》卷八十三作《吴楚歌》，以为是《杂歌谣辞》。
原：燕人美兮赵女佳，/其室则迩兮限层崖。/云为车兮风为马，/玉在山兮兰在野。/云无期兮风有止，/思心多端兮谁能理。
注：其室则迩：语出《诗经·郑风·东门之掸（shàn善）》：“其室则迩，其人则远。”层崖：高的山崖。

# 明月篇
题解：《明月篇》：这首诗写妇女担心年老色衰。
原：皎皎明月光，/灼灼朝日晖。/昔为春蚕丝，/今为秋女衣。
原：丹唇列素齿，/翠彩发蛾眉。/娇子多好言，/欢合易为姿。
注：翠彩：青色颜料，古人用以画眉。
原：玉颜盛有时，/秀色随年衰。/常恐新间旧，/变故兴细微。
注：“变故”句：因小事而引起变故。
原：浮萍本无根，/非水将何依。/忧喜更相接，/乐极还自悲。
