# 宿青溪驿奉怀张员外十五兄之绪
诗：漾舟千山内，/日人泊枉渚。/我生本飘飘，/今复在何许？
诗：石根青枫林，/猿鸟聚俦侣。/月明游子静，/畏虎不得语。
诗：中夜怀友朋，/乾坤此深阻。/浩荡前后问，/佳期付荆楚。

# 敬寄族弟唐十八使君
诗：与君陶唐后，/盛族多其人。/圣贤冠史籍，/枝派罗源津。
诗：在今气磊落，/巧伪莫敢亲。/介立实吾弟，/济时肯杀身。
诗：物自讳受玷，/行高无污真。/得罪永泰末，/放之五溪滨。
诗：鸾凤有铩翮，/先儒曾抱麟。/雷霆霹长松，/骨大却生筋。
诗：一失不足伤，/念子孰自珍。/泊舟楚宫岸，/恋阙浩酸辛。
诗：除名配清江，/厥土巫峡邻。/登陆将首途，/笔札枉所申。
诗：归朝局病肺，/叙旧思重陈。/春风洪涛壮，/谷转颇弥旬。
诗：我能泛中流，/搪突鼍獭瞋。/长年已省拖，/慰此贞良臣。

# 忆昔行
诗：忆昔北寻小有洞，/洪河怒涛过轻舸。/辛勤不见华盖君，/艮岑青辉惨么麽。
诗：千崖无人万壑静，/三步回头五步坐。/秋山眼冷魂未归，/仙赏心违泪交堕。
诗：弟子谁依白茅室？/卢老独启青铜锁。/巾拂香余捣药尘，/阶除灰死烧丹火。
诗：玄圃沧洲莽空阔，/金节羽衣飘婀娜。/落日初霞闪余映，/倏忽东西无不可。
诗：松风碉水声合时，/青兕黄熊啼向我。/徒然咨嗟抚遗迹，/至今梦想仍犹佐。
诗：秘诀隐文须内教，/晚岁何功使愿果。/更讨衡阳董炼师，/南浮早鼓潇湘桅。

# 魏将军歌
诗：将军昔着从事衫，/铁马驰突重两衔。/被坚执锐略西极，/昆仑月窟东崭岩。
诗：君门羽林万猛士，/恶若哮虎子所监。/五年起家列霜戟，/一日过海收风帆。
诗：平生流辈徒蠢蠢，/长安少年气欲尽。/魏侯骨耸精爽紧，/华岳峰尖见秋隼。
诗：星缠宝校金盘陁，/夜骑天驷超天河。/欃枪荧惑不敢动，/翠蕤云旃相荡摩。
诗：吾为子起歌《都护》，/酒阑插剑肝胆露，/钩陈苍苍风玄武。/万岁千秋奉明主，/临江节士安足数！

# 北风
诗：北风破南极，/朱凤日威垂。/洞庭秋欲雪，/鸿雁将安归？
诗：十年杀气盛，/六合人烟稀。/吾慕汉初老，/时清犹茹芝。

# 客从
诗：客从南溟来，/遗我泉客珠。/珠中有隐字，/欲辨不成书。
诗：缄之箧笥久，/以俟公家须。/开视化为血，/哀今征敛无。

# 白马
诗：白马东北来，/空鞍贯双箭。/可怜马上郎，/意气今谁见？
诗：近时主将戮，/中夜商于战。/丧乱死多门，/鸣呼泪如霰！

# 白凫行
诗：君不见黄鹄高于五尺童，/化为白凫似老翁。/故畦遗穗已荡尽，/天寒岁暮波涛中。
诗：鳞介腥膻素不食，/终日忍饥西复东。/鲁门鹦剧亦蹭蹬，/闻道如今犹避风。

# 朱凤行
诗：君不见潇湘之山衡山高，/山巅朱凤声嗷嗷。/侧身长顾求其群，/翅垂口噤心甚劳。
诗：下愍百鸟在罗网，/黄雀最小犹难逃。/愿分竹实及蝼蚁，/尽使鸱枭相怒号。

# 惜别行送向卿进奉端午御衣之上都
诗：肃宗昔在灵武城，/指挥猛将收咸京。/向公泣血洒行殿，/佐佑卿相乾坤平。
诗：逆胡冥寞随烟烬，/卿家兄弟功名震。/麒麟图画鸿雁行，/紫极出入黄金印。
诗：尚书勋业超千古，/雄镇荆州继吾祖。/裁缝云雾成御衣，/拜跪题封向端午。
诗：向卿将命寸心赤，/青山落日江潮白。/卿到朝廷说老翁，/漂零已是沧浪客。

# 醉歌行赠公安颜少府请顾八题壁
诗：神仙中人不易得，/颜氏之子才孤标。/天马长鸣待驾驭，/秋鹰整翮当云霄。
诗：君不见东吴顾文学，/君不见西汉杜陵老。/诗家笔势君不嫌，/词翰升堂为君扫。
诗：是日霜风冻七泽，/乌蛮落照衔赤壁。/酒酣耳热忘头白，/感君意气无所惜，/一为歌行歌主客。

# 夜闻篥
诗：夜闻篥沧江上，/衰年侧耳情所响。/邻舟一听多感伤，/塞曲三更欲悲壮。
诗：积雪飞霜此夜寒，/孤灯急管复风湍。/君知天地干戈满，/不见江湖行路难。

# 发刘郎浦
诗：挂帆早发刘郎浦，/疾风飒飒昏亭午。/舟中无日不沙尘，/岸上空村尽豺虎。
诗：十日北风风未回，/客行岁晚晚相催。/白头厌伴渔人宿，/黄帽青鞋归去来。

# 别董颋
诗：穷冬急风水，/逆浪开帆难。/士子甘旨阙，/不知道里寒。
诗：有求彼乐土，/南适小长安。/到我舟械去，/觉君衣裳单。
诗：素闻赵公节，/兼尽宾主欢。/已结门庐望，/无令霜雪残。
诗：老夫缆亦解，/脱粟朝未餐。/飘荡兵甲际，/几时怀抱宽？
诗：汉阳颇宁静，/岘首试考槃。/当念著白帽，/采薇青云端。

诗：安能陷粪土，/有志乘鲸鳌。/或骖鸾腾天，/聊作鹤鸣皋。

诗：南为祝融客，/勉强亲杖屦。/结托老人星，/罗浮展衰步。

诗：骅骝入穷巷，/必脱黄金辔。/一论朋友难，/迟暮敢失坠！
诗：古来事反复，/相见横涕温。/向者玉珂人，/谁是青云器？
诗：才尽伤形体，/病渴污官位。/故旧独依然，/时危话颠踬。
诗：我甘多病老，/子负忧世志。/胡为困衣食，/颜色少称遂。
诗：远作辛苦行，/顺从众多意。/舟檝无根蒂，/蛟鼍好为祟。
诗：况兼水贼繁，/特戒风飙驶，/崩腾戎马际，/往往杀长吏。
诗：子干东诸侯，/劝勉防纵恣。/邦以民为本，/鱼饥费香饵。
诗：请哀疮痍深，/告诉皇华使。/使臣精所择，/进德知历试。
诗：恻隐诛求情，/固应贤愚异。/列士恶苟得，/俊杰思自致。
诗：赠子《猛虎行》，/出郊载酸鼻。

诗：羸骸将何适？/履险颜益厚。/庶与达者论，/吞声混瑕垢。
