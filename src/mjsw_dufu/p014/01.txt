诗：牢落官军速，/萧条万事危。/鬓毛元自白，/泪点向来垂。
诗：不是无兄弟，/其如有别离。/巴山春色静，/北望转逶迤。
诗：日月还相斗，/星辰屡合围。/不成诛执法，/焉得变危机。
诗：大角缠兵气，/钩陈出帝畿。/烟尘昏御道，/耆旧把天衣。
诗：行在诸军阙，/来朝大将稀。/贤多隐屠钓，/王肯载同归？
诗：再有朝廷乱，/难知消息真。/近传王在洛，/复道使归秦。
诗：夺马悲公主，/登车泣贵嫔。/萧关迷北上，/沧海欲东巡。
诗：敢料安危体，/犹多老大臣。/岂无嵇绍血，/沾洒属车尘。
诗：闻说初东幸，/孤儿却走多。/难分太仓粟，/竞弃鲁阳戈。
诗：胡虏登前殿，/王公出御河。/得无中夜舞，/谁忆《大风歌》，
诗：春色生烽燧，/幽人泣薜萝。/君臣重修德，/犹足见时和。

# 寄李十四员外布十二韵
原：新除司议郎兼万州别驾，虽尚伏枕，已闻理装名
诗：参汉望苑，/职述景题舆。/巫峡将之郡，/荆门好附书。
诗：远行无自苦，/内热比何如。/正是炎天阔，/那堪野馆疏。
诗：黄牛平驾浪，/画鹢上凌虚。/试待盘涡歇，/方期解缆初。
诗：闷能过小径，/自为摘嘉蔬。/渚柳元幽僻，/村花不扫除。
诗：宿阴繁素柰，/过雨乱红蕖。/寂寂夏先晚，/泠泠风有余。
诗：江清心可莹，/竹冷发堪梳。/直作移巾几，/秋帆发弊庐。

# 归来
诗：客里有所过，/归来知路难。/开门野鼠走，/散帙壁鱼干。
诗：洗杓开新酝，/低头拭小盘。/凭谁给曲蘖，/细酌老江干。

# 王录事许修草堂赀不到聊小诘
诗：为嗔王录事，/不寄草堂赀。/昨属愁春雨，/能忘欲漏时。

# 寄邛州崔录事
诗：邛州崔录事，/闻在果园坊。/久待无消息，/终朝有底忙。
诗：应愁江树远，/怯见野亭荒。/浩荡风尘外，/谁知酒熟香？

# 过故斛斯校书庄二首
原：老儒艰难时病于庸蜀，叹其没后方授一官
诗：此老已云殁，/邻人嗟亦休。/竟无宣室召，/徒有茂陵求。
诗：妻子寄他食，/园林非昔游。/空堂總帷在，/渐渐野风秋。
诗：燕入非傍舍，/鸥归只故池。/断桥无复板，/卧柳自生枝。
诗：遂有山阳作，/多惭鲍叔知。/素交零落尽，/自首泪双垂！

# 立秋雨院中有作
诗：山云行绝塞，/大火复西流。/飞雨动华屋，/萧萧梁栋秋。
诗：穷途愧知己，/暮齿借前筹。/已费清晨謁，/那成长者谋。
诗：解衣开北户，/高枕对南楼。/树湿风凉进，/江喧水气浮。
诗：礼宽心有适，/节爽病微瘳。/主将归调鼎，/吾还访旧丘。

# 军城早秋严武
诗：昨夜秋吼入汉关，/朔云边雪满西山。/更催飞将遗追骄虏，/莫遣沙场匹马还。

# 奉和
诗：秋风袅袅动高旌，/玉帐分弓射虏营。/已收滴博云间戍，/更夺蓬婆雪外城。

# 院中晚晴怀西郭茅舍
诗：幕府秋风日夜清，/澹云疏雨过高城。/叶心朱实看时落，/阶面青苔先自生。
诗：复有楼台衔暮景，/不劳钟鼓报新晴。/浣花溪里花饶笑，/肯信吾兼吏隐名。

# 到村
诗：碧涧虽多雨，/秋沙先少泥。/蛟龙引子过，/荷芰逐花低。
诗：老去参戎幕，/归来散马蹄。/稻粱须就列，/榛草即相迷。
诗：蓄积思江汉，/疏顽惑町畦。/稍酬知己分，/还入故林栖。

# 宿府
诗：清秋幕府井梧寒，/独宿江城蜡炬残。/永夜角声悲自语，/中天月色好谁看。
诗：风尘荏苒音书绝，/关塞萧条行路难。/已忍伶娉十年事，/强移栖息一枝安。

# 遣闷奉呈严公二十韵
诗：白水鱼竿客，/清秋鹤发翁。/胡为来幕下，/只合在舟中。
诗：黄卷真如律，/青袍也自公。/老妻忧坐痹，/幼女问头风。
诗：平地专欹倒，/分曹失异同。/礼甘衰力就，/义忝上官通。
诗：畴昔论诗早，/光辉仗钺雄。/宽容存性拙，/剪拂念途穷。
诗：露裛思藤架，/烟霏想桂丛。/信然龟触网，/直作鸟窥笼。
诗：西岭纡村北，/南江绕舍东。/竹皮寒旧翠，/椒实雨新红。
诗：浪簸船应坼，/杯干瓮即空。/藩篱生野径，/斤斧任樵童。
诗：束缚酬知己，/蹉跎效小忠。/周防期稍稍，/太简遂匆匆。
诗：晓入朱扉启，/昏归画角终。/不成寻别业，/未敢息微躬。
诗：乌鹊愁银汉，/驽骀怕幪。/会希全物色，/时放倚梧桐。

# 送舍弟频赴齐州三首
诗：岷岭南蛮北，/徐关东海西。/此行何日到，/送汝万行啼。
诗：绝域惟高枕，/清风独杖藜。/危时暂相见，/衰白意都迷。
诗：风尘暗不开，/汝去几时来？/兄弟分离苦，/形容老病催。
诗：江通一柱观，/日落望乡台。/客意长东北，/齐州安在哉！
诗：诸姑今海畔，/两弟亦山东。/去傍干戈觅，/来看道路通。
诗：短衣防战地，/匹马逐秋风。/莫作俱流落，/长瞻碣石鸿。

# 严郑公阶下新松得沾字
诗：弱质岂自负，/移根方尔瞻。/细声闻玉帐，/疏翠近珠帘。
诗：未见紫烟集，/虚蒙清露沾。/何当一百丈，/欹盖拥高檐。

# 严郑公宅同咏竹得香字
诗：绿竹半含箨，/新梢才出墙。/色侵书帙晚，/阴过酒樽凉。
诗：雨洗娟娟净，/风吹细细香。/但令无剪伐，/会见拂云长。

# 奉观严郑公厅事岷山沱江画图十韵得忘字
诗：沱水流中座，/岷山到此堂。/白波吹粉壁，/青嶂插雕梁。
诗：直讶杉松冷，/兼疑菱荇香。/雪云虚点缀，/沙草得微茫。
诗：岭雁随毫末，/川蜺饮练光。/霏红洲蕊乱，/拂黛石萝长。
诗：暗谷非关雨，/丹枫不为霜。/秋成玄圃外，/景物洞庭旁。
诗：绘事功殊绝，/幽襟兴激昂。/从来谢太傅，/丘壑道难忘。

# 晚秋陪严郑公摩诃池泛舟得溪字
诗：湍驶风醒酒，/船回雾起堤。/高城秋自落，/杂树晚相迷。
诗：坐触鸳鸯起，/巢倾翡翠低。/莫须惊白鹭，/为伴宿青溪。
诗：垂老戎衣窄，/归休寒色深。/渔舟上急水，/猎火著高林。
诗：日有习池醉，/愁来《梁甫吟》。/干戈未偃息，/出处遂何心。

# 至后
诗：冬至至后日初长，/远在剑南思洛阳。/青袍白马有何意，/金谷铜驼非故乡。
诗：梅花欲开不自觉，/棣萼一别永相望。/愁极本凭诗遣兴，/诗成吟咏转凄凉。

# 正月三日归溪上有作简院内诸公
诗：野外堂依竹，/篱边水向城。/蚁浮仍腊味，/鸥泛已春声。
诗：药许邻人厮，/书从稚子擎。/白头趋幕府，/深觉负平生。

# 敝庐遣兴奉寄严公
诗：野水平桥路，/春沙映竹村。/风轻粉蝶喜，/花暖蜜蜂喧。
诗：把酒且深酌，/题诗好细论。/府中瞻暇日，/江上忆词源。
诗：迹忝朝廷旧，/情依节制尊。/还思长者辙，/恐避席为门。

# 春日江村五首
诗：农务村村急，/春流岸岸深。/乾坤万里眼，/时序百年心。
诗：茅屋还堪赋，/桃源自可寻。/艰难贱生理，/飘泊到如今。
诗：迢递来三蜀，/蹉跎有六年。/客身逢故旧，/发兴自林泉。
诗：过懒从衣结，/频游任履穿。/藩篱无限景，/恣意买江天。
诗：种竹交加翠，/栽桃烂熳红。/经心石镜月，/到面雪山风。
诗：赤管随王命，/银章付老翁。/岂知牙齿落，/名玷荐贤中。
诗：扶病垂朱绂，/归休步紫苔。/郊扉存晚计，/幕府愧群材。
诗：燕外晴丝卷，/鸥边水叶开。/邻家送鱼鳖，/问我数能来。
诗：群盗哀王粲，/中年召贾生。/登楼初有作，/前席竟为荣。
诗：宅入先贤传，/才高处士名。/异时怀二子，/春日复含情。

# 绝句六首
诗：日出篱东水，/云生舍北泥。/竹高鸣翡翠，/沙舞鹍鸡。
诗：蔼蔼花蕊乱，/飞飞蜂蝶多。/幽栖身懒动，/客至欲如何。
诗：凿井交棕叶，/开渠断竹根。/扁舟轻袅缆，/小径曲通村。
诗：急雨捎溪足，/斜晖转树腰。/隔巢黄鸟并，/翻藻白鱼跳。
诗：舍下笋穿壁，/庭中藤刺檐。/地晴丝冉冉，/江白草纤纤。
诗：江动月移石，/溪虚云傍花。/鸟栖知故道，/帆过宿谁家？

# 绝句四首
诗：堂西长笋别开门，/堑北行椒却背村。/梅熟许同朱老吃，/松高拟对阮生论。
诗：欲作鱼梁云复湍，/因惊四月雨声寒。/青溪先有蛟龙窟，/竹石如山不敢安。
诗：两个黄鹂鸣翠柳，/一行白鹭上青天。/窗含西岭千秋雪，/门泊东吴万里船。
诗：药条药甲润青青，/色过棕亭入草亭。/苗满空山惭取誉，/根居隙地怯成形。
