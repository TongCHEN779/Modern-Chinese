# 哭长孙侍御
原：他集互见四首
诗：道为谋书重，/名因赋颂雄。/礼闱曾擢桂，/宪府旧乘骢。
诗：流水生涯尽，/浮云世事空。/唯余旧台柏，/萧瑟九原中。

# 虢国夫人
诗：虢国夫人承主恩，/平明上马入宫门。/却嫌脂粉涴颜色，/淡扫蛾眉朝至尊。

# 军中醉饮寄沈八刘叟
诗：酒渴爱江清，/余甘漱晚汀。/软沙欹坐稳，/冷石醉眠醒。
诗：野膳随行帐，/华音发从伶。/数杯君不见，/醉已遣沉冥。

# 杜鹃行
诗：古时杜宇称望帝，/魂作杜鹃何微细。/跳枝窜叶树木中，/抢佯瞥捩雌随雄。
诗：毛衣惨黑貌憔悴，/众鸟安肯相尊崇。/隳形不敢栖华屋，/短翮唯愿巢深丛。
诗：穿皮啄朽觜欲秃，/苦饥始得食一虫。/谁言养雏不自哺？/此语亦足为愚蒙。
诗：声音咽咽如有谓，/号啼略与婴儿同。/口干垂血转迫促，/似欲上诉于苍穹。
诗：蜀人闻之皆起立，/至今教学传遗风。/乃知变化不可穷，/岂知昔日居深宫，/嫔嫱左右如花红。

# 闻惠二过东溪特一送
原：吴若本逸诗七首
诗：惠子自驹瘦，/归溪惟病身。/皇天无老眼，/空谷滞斯人。
诗：崖蜜松花熟，/山杯竹叶新。/柴门了无事，/黄绮未称臣。
原：李祁萧远校书云：陈恬叔易传东坡记此诗云，右一篇刘斯立得于管城人家册子叶中，题云《工部员外诗集》。名甫，字东甫。其余诸篇，语多不同，如“故园桃李今摇落，安得愁中却尽生”也。

# 舟泛洞庭
诗：蛟室围青草，/龙堆拥白沙。/护江盘古木，/迎棹舞神鸦。
诗：破浪南风正，/收帆畏日斜。/云山千万叠，/底处上仙槎。
原：右洪玉甫云：有人得之江中石刻。

# 李盐铁二首
原：（后一首题云《李监宅》在第九卷中）
诗：落叶春风起，/高城烟雾开。/杂花分户映，/娇燕入檐回。
诗：一见能倾产，/虚怀只爱才。/盐官虽绊骥，/名是汉庭来。

# 长吟
诗：江渚翻鸥戏，/官桥带柳阴。/江飞竞渡日，/草见踏春心。
诗：已拨形骸累，/真为烂熳深。/赋诗歌句稳，/不免自长吟。

# 绝句九首
原：（前六首在十三卷中）
诗：闻道巴山里，/春船正好行。/都将百年兴，/一望九江城。
诗：水槛温江口，/茅堂石笋西。/移船先主庙，/洗药浣沙溪。
诗：设道春来好，/狂风大放颠。/吹花随水去，/翻却钓鱼船。
原：右谢克家任伯题云：右五诗，得盛文肃家故书中，犹是吴越钱氏时人所传，格律高妙，其为少陵不疑。

# 瞿唐怀古
原：草堂诗笺逸诗拾遗
诗：西南万壑注，/勍敌两崖开。/地与山根裂，/江从月窟来。
诗：削成当白帝，/空曲隐阳台。/疏凿功虽美，/陶钧力大哉。

# 送司马入京
诗：群盗至今日，/先朝忝从臣。/叹君能恋主，/久客羡归秦。
诗：黄阁长司谏，/丹墀有故人。/向来论社稷，/为话涕沾巾。

# 惜别行送刘仆射判官
诗：闻道南行市骏马，/不限匹数军中须。/襄阳幕府天下异，/主将俭省忧艰虞。
诗：只收壮健胜铁甲，/岂因格斗求龙驹。/而今西北自反胡，/骐驎荡尽一匹无。
诗：龙媒真种在帝都，/子孙永落西南隅。/向非戎事备征伐，/君肯辛苦越江湖？
诗：江湖凡马多憔悴，/衣冠往往乘蹇驴。/梁公富贵于身疏，/号令明白人安居。
诗：俸钱时散士子尽，/府库不为骄豪虚。/以兹报主寸心赤；/气却西戎回北狄。
诗：罗网群马籍马多，/气在驱驰出金帛。/刘侯奉使光推择，/滔滔才略沧溟窄。
诗：杜陵老翁秋系船扶病相识长沙驿。/强梳白发提胡卢，/手把菊花路旁摘。/九州兵革浩茫茫，
诗：三叹聚散临重阳。/当杯对客忍流涕，/君不觉老夫神内伤！

# 呀鹘行
诗：病鹘孤飞俗眼丑，/每夜江边宿衰柳。/清秋落日已侧身，/过雁归鸦错回首。
诗：紧脑雄姿迷所向，/疏翮稀毛不可状。/强神迷复皂雕前，/俊才早在苍鹰上。
诗：风涛飒飒寒山阴，/熊罴欲蛰龙蛇深。/念尔此时有一掷，/失声溅血非其心。

# 狂歌行赠四兄
诗：与兄行年校一岁，/贤者是兄愚者弟。/兄将富贵等浮云，/弟切功名好权势。
诗：长安秋雨十日泥，/我曹鞴马听晨鸡。/公卿朱门未开锁，/我曹已到肩相齐。
诗：吾兄睡稳方舒膝，/不袜不巾踏晓日。/男啼女哭莫我知，/身上须缯腹中实。
诗：今年思我来嘉州，/嘉州酒重花绕楼。/楼头吃酒楼下卧，/长歌短咏还相酬。
诗：四时八节还拘礼，/女拜弟妻男拜弟。/幅巾攀带不挂身，/头脂足垢何曾洗。
诗：吾兄吾兄巢许伦，/一生喜怒长任真。/日斜枕肘寝已熟，/啾啾唧唧为何人。
原：右五篇，乃苏州太守裴煜如晦所收，见旧集补遗。

# 逃难
诗：五十头白翁，/南北逃世难。/疏布缠枯骨，/奔走苦不暖。
诗：已衰病方入，/四海一涂炭。/乾坤万里内，/莫见容身畔。
诗：妻孥复随我，/回首共悲叹。/故国莽丘墟，/邻里各分散。
诗：归路从此迷，/涕尽湘江岸。

# 寄高适

诗：北阙更新主，/南星落故园。/定知相见日，/烂熳倒芳尊。

# 阆中行
诗：豺狼当路，/无地游从。
原：《云溪友议》卷上《严黄门》。

# 石文诗附存
诗：诗王本在陈芳国，/九夜扪之麟篆熟，/声振扶桑享天福。
原：见冯贽《云仙杂记》卷一引《文览》。

# 句
诗：狨掷寒条马见惊。
原：见《增修诗话总龟前集》卷二引《杨文公谈苑》。上三首及逸句见《全唐诗续拾》
