# 儆庐诗选
原：孙世伟字俶仁，号儆庐。民国四五年间，俶仁官福建漳州，余亦需次于榕城，邮筒往来，唱和略多。今录诗九首。

# 次韵答小柳赠诗
原：官爱漳滨山水州，惊人佳句苦难酬。犹从北地追前别，忽喜南天接胜流。一榻琴书安客梦，四时花木拱吟楼。眼中尘俗伊谁语？煮酒迟君日日游。

# 病瘧初愈，得小柳《遣闷》诗次韵
原：热瘧无端困夏阳，岑岑昏眩似旋樯。裁诗遣鬼摹韩愈，感遇临歧泣子昂。病后切思平日健，心闲欲赎此身忙。何当万竹浓阴里，棋酒同消一日长。

# 次小柳和朴庵见贻韵兼柬朴庵
原：南游同是苦蓬征，杯酒何堪话此生？满地沧浪随濯足，暂时风雨过无声。百川东到天涯远，五岳归来山意平。回首素心人已去，瑶华端不隔诗盟。

# 次小柳和朴庵韵以抒近感
原：行行却曲怯前征，歧路多歧误半生。不道寸长兼尺短，惊心渊默有雷声。依巢危燕飞何去？感物秋虫诉不平。冰雪竟难消内热，且逃东海结鸥盟。

# 七夕叠征字韵答小柳
原：奋飞身欲逐云征，一寸心容百感生。良夜向阑秋有恨，微波可托汉无声。风凄露冷经年别，天上人间此意平。闻道金针堪度巧，急拈柔翰乞诗盟。

# 克庵寄示莅闽以来诗稿，哀时感物，忧谗畏讥，赋此以志同声之感，并呈朴庵
原：欲从劫后识天心，人事猖披叵耐寻。君有哀声振金石，谁怜苦语托铭箴？西维星象离离变，南海秋潮暗暗沉。阊阖九门风雨急，一篇《梁父》费长吟。

# 访黄石斋先生读书石室，和静初先生韵
原：先生不负高皇帝，先生临刑过东华门，坐不起，曰：“此与高皇帝陵寝近，可死矣。”悍将孱王洒泪观。欲仗偏师回北虏，悔将杯酒失南安。思文帝赐宴，南安侯郑芝龙位先生上，众议抑芝龙，由是文武不和，国事乃不可为。十年读《易》天靡定，先生疏云：“臣自幼学《易》。”孤岛先秋露未寒。我访遗书伤笔削，清乾隆谕谓先生遗集应改易违碍字句。藏山大业亦艰难。

# 和多字韵，答小柳、允公并呈朴庵
原：堕地一声盘古泣，逼人忧患至今多。全凭道力扶心力，任尔千魔引万魔。斗蚁成雷惊蛰起，腾虹飞剑踏天磨。年来醒醉都无例，漫叱狂奴酒色酡。

# 中秋望月感怀，和小柳韵并柬朴庵
原：明月窥人又此宵，隔年心绪伴烟消。倚栏历落瞻南斗，绕树彷徨动暗焱。万里仰天思不极，一身顾影感分飘。城隅咫尺成离阔，遥夜何堪怨玉箫？
