# 兰史诗选
原：潘飞声字兰史，广东番禺人。今录诗六十四首。

# 抵津门
原：津门重到感平生，两度仓皇问北征。塞外节旄期属国，江南词赋有芜城。何人天下关忧乐？一范胸中负甲兵。客夜闻鸡惊起舞，老来髀肉不胜情。

# 渡黄河
原：莽莽中原尽战尘，沧桑残局又翻新。卅年吾道其南意，今日黄河以北人。贾谊终惭虚席语，王通留得著书身。黄冠来去携琴客，弹向空山独自春。

# 威海卫
原：不战何能守？仓皇委敌舟。整齐惊刺眼，收拾待重头。何地寻天险？无人泣楚囚。鱼龙成寂寞，凄绝此神州。

# 辛亥九秋送蒋万里从军
原：汉上旌旗梦里过，苍凉横槊大风歌。一灯午夜闻鸡起，谁识诗人旧枕戈？
原：功名肯向马前休？一剑霜寒第几州。四万万人齐仰首，才人那得不封侯？

# 壬子新岁作
原：重悬日月照山河，新岁新晴入醉歌。一笑陈抟堕驴背，唐虞世界说共和。
原：武汉泱泱咏《大风》，斩蛇手段足英雄。先忧后乐何人识？老阮狂来酒正中。

# 甘露寺
原：天阔钟撞应响遥，江心一柱出松寮。荒苔佛座参三乘，老树僧房坐六朝。虎据石头终失险，龙归钵底漫言骄。帝图霸业苍凉尽，只有经声慰寂寥。

# 走马冈
原：走马陟冈岭，孙刘阅几年。大江悬肘下，我欲一投鞭。

# 试剑石
原：盖世俨重瞳，剑痕山腹中。只能分鼎足，石亦笑英雄。

# 北固
原：远树连江合，轻波漾雨。风帆张北固，天堑界南徐。石上寻遗剑，山中想异书。且中京口酒，何必武昌鱼？

# 多景楼
原：凉翠到天边，余心方洒然。与谁携海月？倚槛定飞仙。鸾凤尊前曲，烟波江上船。便思移棹去，采石酹青莲。

# 江天寺
原：久识江天胜，金焦忽眼前。且登浮玉塔，如立阆风巅。坡老重来地，中泠第一泉。名山才阅劫，犹是太平年。

# 佛印山房
原：东坡或再来，一语禅机破。四大本来空，何必山房坐？

# 袁仲濂判官招集第一楼

原：湖光潋滟浸金牛，忆放追凉六柱舟。一水正如天上坐，三更浑似月中游。针楼瓜果逢良会，镜槛菱芡媚晚秋。词赋姜张成雅集，笑他银汉有离愁。
原：笔力看谁敌万牛，琴樽重泛范蠡舟。卅年见惯星双别，七夕还期月导游。潭水千灯流梦影，湖山一笛叫凉秋。西泠松柏同心咏，胜向秦淮话莫愁。

# 陶拙存以先世元晖中丞公遗集见示，敬题一律

# 瓜洲

# 露筋祠

# 登百石
原：侵晨入山深，迂回出怪石。见石不见天，一线路逼仄。初疑西方国，昏荒古未辟。穆王所不到，谁唤巨灵擘？蒸岚互濒洞，浓绿化幽墨。朝曦况迈寒，渐上畏巉崱。陡见高台宽，结构倚苍壁。下视王石岭，众峰伏肘腋。石门拖修眉，雪山敛一发。始识置身高，天外快登陟。铁桥卧云海，松翠展瑶席。群山喜我至，晴朗助颜色。行将驾飙骖，不借王乔舄。

# 鸟啼径看瀑布泉
原：越石下山脚，径僻藤萝封。将酌石上泉，汗漫投云松。两崖束青岳，拥掩山凹空。已见雪色瀑，飞出岚翠丛。石床坐高处，以手探白龙。珠玑落我袖，足底酣笙钟。茅屋酒家胡，饮我玻璃钟。怪我异裳服，更叩来何从。我言自东海，西摄王母踪。荒外得酒泉，得非神瀵同。朝饥易成醉，酒面禁凉风。绿云出涧侧，壁立森千峰。惟闻啼鸟声，吹落山花红。

# 由牛房洞至大冬岭
原：山道至云林，奇石不可数。石势欲塞天，神哉此鬼斧。牛房更破破，积铁自太古。帝怜八夤外，荒昧弃西土。震旦来夸娥，破石作洞户。至今坌蔽气，白昼嘘冷雨。忆昔布法争，蛮触哄幽圉。天厌东胡骄，狼戾罔知怙。阴霾闭峦谷，牛匿迷处所。犹草木兵，百战惊角鼓。小冬蔽天来，大冬出天宇。青天在平地，再上更何许？颇疑此西极，流至蓬莱股。巨鳌载不住，群圣赫然怒。我欲借秦鞭，鞭石西溟屿。洪荒配德运，来贡涂山禹。内附狼居胥，永作神州辅。

# 题披秘石门
原：群山郁幽闷，巉绝排天阊。天为凿石门，蜿嬗通穷荒。想当施刃时，破碎惊雷硍。垠崖划轩豁，巨壁争开张。至今斧削迹，凸若青玉瓢。侧峰作关键，后峰撑屏障。大石虎豹蹲，悚峙森边防。日色耀古铁，闪烁银火光。腾身上门顶，广袤如桥梁。其时洒飞雨，吹落冲风长。云海浩一气，敛白铺青苍。频年堕尘蓋，览胜愿未偿。此来发奇秘，宇外高颉颃。群灵忽感通，凿空出毫芒。飞楼想风驭，得酒疑天浆。题诗满石坂，墨渾垂琳琅。百怪读不得，讶我字汉唐。或恐太阴黑，六丁下取将。

# 高姬眉子见过

# 夏夜赠高姬眉子
原：月明携手水仙祠，湖上年年与梦期。吹笛试教乾撰子，拗莲还惜达磨支。情愁百叠笺吴语，才福三生礼楚辞。冰玉清凉无汗处，风鬟偏觉夏相宜。

# 碧云寺题石台上

# 二闸泛舟至听水处啜茗放歌
原：出城渺渺水如天，隔堤隐隐花作烟。尘襟乍拂叹奇绝，咫尺坐我江南船。长安两度挥玉鞭，载酒只爱登陶然。驱车作艇入芦苇，万绿成海张华筵。那知此地富烟水，飘飘疑乘太乙莲。菱叶蘸波游鱼聚，柳丝掠影惊鸿翩。倘寻李贺唱月出，定见神女弄珠圆。谁携玉管偕韩嫣？我意洛浦来飞仙。通词何必微波藉，独惭华发非少年。此地远胜十刹海，水调度曲歌扣舷。此地又胜万生园，石阑展簟卧听泉。洗耳已在风涛际，振衣直据松树巅。茶客谁为卢玉川？词客谁是张玉田？西风破屋洛城里，何似烟波画舫西湖边。我所私淑惟二贤，思归沧海心先还。清响犹闻五百载，未许游尘一点飞上衍波笺，山水要待传人传。
