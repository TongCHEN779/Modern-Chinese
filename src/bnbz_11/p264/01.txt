# 巢南诗选
原：陈去病字佩忍，号巢南，江苏吴江人。今录诗一百零四首。

# 初夏越中杂诗
原：冠履一倒置，中原百事非。生无依汉腊，死亦采周薇。落日终成晦，阳戈孰可挥？茫茫票骑绩，长与壮心违。
原：我已无家久，奚须赋卜居？飘零随断梗，苍莽识旧墟。堂背赢萱草，江东结敝庐。双鱼来远道，谓可托楹书。时沈太君有移家东江之举。
原：淮海无消息，关山旷岁年。有谁歌哭意？来诉酒樽前。白日青春晚，梅花纸帐眠。徒然感髀肉，不复据征鞯。
原：时平壮士贱，世乱烈魂怀。意气凌荆聂，声名振海淮。报仇多称意，雪耻亦良佳。伟矣越勾践，登车式怒蛙。

# 有怀刘三、钝剑、亚子，并苦念西狩、无畏
原：吾有数同好，性行皆轶伦。其一为刘季，豪宕生风云。长才擅三绝，写作何玢璘。掉头竟不顾，独饮曹参醇。其二有渐离，生来耻帝秦。报仇志不遂，往往多哀呻。要我结南社，谓可张一军。最少独屯田，儒雅尤恂恂。韩亡知自奋，留侯岂妇人？缔交逾十载，意气侔雷陈。所憾落拓士，江海多沉沦。譬如尺蠖屈，终古无一伸。又如骄阳虐，宁怪蛟龙嗔？去去一长啸，其人真悲辛。所以发慨叹，嘘气摧星辰。我歌且未了，我悲今更多。出门结朋友，所贵心气和。况荷世衰乱，交道常参差。相期胶与漆，犹苦生离狐。奚为君子士？立行多偏颇。不知金石好，学术相磋磨。徒矜洙泗习，断断空龃龉。所志卒未成，同室先挺戈。知己纵或谅，忌者将如何？成连空知音，徒闻海上波。管邴并良士，割席乃纷拏。思之独泫涕，欲乘沧浪槎。终教廉蔺好，毋贻钟吕嗟。不见耳事，千古资谯诃。

# 四月二十五日偕刘三谒苍水张公墓，并吊永历帝

# 岁暮杂感
原：南行不得志，东望徒淹滞。块焉返故乡，寂寞衡门闭。愍念平生交，磊落半长逝。子虽幸存，精气悉颓敝。而我独耿耿，奔走未忘世。彷徨策治安，何者非匡济？山高不厌攀，水深不厌厉。涉江采夫容，谁能待晴霁？
原：时穷壮士见，世乱腐儒毙。达识有高怀，无从形迹泥。况当厄运年，胡汉一衰替。洞势倾舟，何暇怨操枻。应与振奇危，乱流同急济。庶几系长缨，略可傲荒裔。功高吝其赏，长揖返江滋。聊以表深衷，自不同缪戾。
原：我有同心人，淹滞曲江澨。岁岁不相逢，相思各流涕。何计使之并，昕宵对姝丽。灯烛共填词，更阑还拥髻。如此度长年，亦足忘昏曀。天意阻长涂，徒令日侘傺。文君信妙妍，临邛怅迢递。难言诉征鸿，音书莫迟滞。
原：贫士百不欢，著书亦幽滞。鬼伯日揶揄，长年半疲弊。所以雄奇文，霾藏不出世。长门莫与仇，鹴裘辄隳敝。衰病复穷途，由来阮生涕。顾惟欢愉人，漠然不关系。譬如南冠囚，宁邀北胡契？荆璞且自珍，瞬晤重华帝。

# 恻惻
原：恻恻中原遍霨罗，侧身天地一婆娑。图南此去舒长翮，逐北何年奏凯歌？愧杀须眉逊巾帼，耍将儿女属猫蛾。补天填海终须仗，岂谓徐陵彩笔多？
原：脉脉秋心暗带愁，沉沉长夜共登楼。归鸿几处惊罹网，月影中宵怕似钩。惜别只令诗思塞，当筵惟有酒樽酬。相怜去住浑无准，看杀平湖不系舟。

# 久病不痊有作
原：不堪多病废尊罍，几见名花次第开？草草光阴梁下水，沉沉心事劫灰。苍茫四海无家感，潦倒中原绝代才。只合蒲团了身世，万缘删尽息悲哀。

# 疾起还吴有感
原：金阊亭下寄侬家，侠客高人墓已赊。要离、梁鸿二墓在专诸巷者，今皆不存。只有专诸门巷在，明珠穿遍女儿花。巷多珠宝铺。
原：五噫吟罢曜初暾，省识皋家庑尚存。底事齐眉人影远？苍凉梅福隐吴门。

# 有悼

原：金风凄侧殒芳枝，憔悴潘郎两鬓丝。不尽青春怀夙昔，欲裁红豆寄相思。蚕心已死空成茧，蝶梦方酣总带痴。肠断中秋犹记省，朦胧月色漫填词。

# 宝鼎
原：宝鼎沉沉袅篆烟，高堂华烛乍开筵。虎头戴胜西王母，凤帔凝妆萼绿仙。醇酒殷勤亲劝酢，玉容羞涩愈鲜妍。憎他青鸟频来去，未许东方一放颠。

# 金屋
原：凄清金屋困文鸳，芳草池塘漫涉园。烧尽绿章空有泪，数残红豆总无言。痴人说事休嫌尽，旧病怜余未共论。叹息昌羊有同嗜，落梅如雨尽销魂。

# 夜过昆陵驿

# 焦山中流遇急湍

# 梨花里留别亚子
原：谁家水杨柳？秋末尚青青。倒影自娟媚，临风亦娉婷。人方怀远道，舟暂泊旗亭。向晚扬舲去，萦情入杳冥。

# 酬钝根醴陵山中
原：再难海上遇成连，常使湘灵系旧缘。小别几同龙汉劫，幽居奚啻竹林贤。时危合共名山老，秋尽谁为病骨怜？惟有新培桃李盛，聊垂绛帐送华年。

# 哭梦逋老友
原：同甫当年负盛名，挥毫惊起攘夷声。破家不已重亡命，万死何曾剩一生？惟有威丹知己感，空枚叔故人情。介推无禄真堪愤，欲按心头总未平。
原：十年一别老陈琳，未信归来雪鬓侵。诗酒谁令逐年少？文章依旧断知音。西湖有约偏难主，南社无君忍重寻。最是楚魂招未得，鹃啼猿啸激哀吟。君长女擷芬嫁四川某君，在巴蜀未返。

# 哀陈勒生

# 趵突泉一首

# 出塞望蒙古
原：我欲登崇冈，石骨何峋鳞。我欲度沙碛，陷马且没人。驱车怅徘徊，临发复逡巡。朔风蓦地来，扑面惊胡尘。胡氛日以恶，剿抚费因循。防边阅二载，卫霍功谁陈？兵增不征讨，苦哉塞下氓。
原：平生有奇策，悉开诸边屯。繁盛为郡县，旷土移流民。耕农兼畜牧，富庶期先臻。间乃列横舍，文化推无垠。非徒鹜鞮译，将使明彝伦。庶知天汉威，努力倾葵忱。誓词戴中国，弗复私强邻。谋忠地位微，耿耿谁与陈？发箧仍自缄，抚髀徒悲呻。

# 陋巷
原：忆昔颜子渊，乐道恒守贫。箪飘处陋巷，其陋应无伦。畴知今不然，里闸俱一新。即投逆旅息，鸡黍纷焉陈。讵同石门宿，俨逢荷荼人。所嗟末俗敝，淫葩充城闽。昔也弦歌地，今藏莺花春。东鲁尚如此，奚况天下民？逆旅主人酷嗜鸦片，故及之。

# 去鲁
原：驱车渡泗水，泗水不盈咫。我既漫褰裳，车亦讵濡轨。鲁风杂淳浇，别去尚可揣。匪若郑卫间，淫声辄靡靡。治鲁先于齐，东邦庶有豸。

# 丰镇见雪
原：胡天一夜雪，四望尽无垠。万树枝凝蜡，千家瓦匿鳞。边军纷出塞，笳吹总惊人。愿作丰年瑞，时危好指困。时胡匪侵犯包头镇。

# 自居庸关南骑行入口，漫成
原：从容一骑蹴平沙，崱男群山夹道遮。岁晚晴云烘笠屐，西风黄叶露槎桠。漫矜驴背饶诗思，直欲龙堆卜住家。多少刍尼频报喜，碛中多鹊。防秋应莫动悲笳。

# 孟秋朔日初度
原：塞上鸿飞气欲秋，天南长自赋离忧。惊心白发催人老，回首青春逝水悠。小叙亲朋聊自慰，独饶杯榼许相酬。鲈鱼味美鹏图倦，极目莼乡羡去舟。是日供鱼，殷佩六大令谓颇似故乡之鲈，会其夫人欲还，因及之。

# 天貺节为亡妇生日
原：撒手黄埃又一年，魂兮缥缈落何边？当时生日浑闲事，此际寻思转惘然。独客天涯谁与伴？买山归去竟无钱。眠牛未卜频惆怅，半夜踌躇月正弦。
