# 影庐诗选
原：汪洋字子实，号影庐，安徽旌德人。寄寓扬州。满清时在奉天主持《言论》，常出西伯利亚而至圣彼德堡。辛亥，关外革命成功，子实之鼓吹与有力焉。民国元年来沪上，与余同事于《中华民报》，一见相得，遂定交焉。淞滨共话，闽海赋诗，朋辈之中，踪迹最密，惟子实一人。天乎不吊，子实竟以疾逝。遗稿拟为编印，困于人事，卒卒未能。读影庐诗，涔涔泪下矣。今录诗七十六首。

# 敬题《安重根先生传》
原：一弹无恨，千秋享令名。侧身瞻故国，含笑送平生。英气常如在，江流夜有声。松滨试回顾，凭吊不胜情。

# 过马江
原：游踪又到天南际，闲趁轻航试嫩波。一路江山无限意，淡云微雨此经过。

# 沈阳客舍遇王涛松
原：昨宵老友窗前唤，恍见婆娑执酒卮。晓起相逢成一笑，忆来真欲锁双眉。君从何处耽歌舞？我在天涯唱竹枝。回首旧游应若梦，连床风雨话当时。

# 辛亥秋八月夜渡贝加尔湖
原：偶从林际见湖光，道是滔滔北海长。贝加尔湖亦称北海，又名菊海，即苏武牧羊地。绝域何人谈往事？中原有客老斯乡。数声汽笛惊栖鸟，几点渔灯落晓霜。欲借扬州二分月，凌波微步水中央。

# 过乌拉山
原：同俦饭罢起徘徊，到此营营百念灰。山涧悄从车底出，崖花笑向枕边开。万松落日涛声息，剩雪参天暮色回。买得画图置行篋，卧游常对此崔嵬。

# 车中即事
原：万松拱立车窗外，为有诗人过此间。野马驻蹄观止水，懒云垂首卧深山。玻璃受雪冰纹见，襟袖欺风屈戍闲。笑看比邻人似玉，阿侬家住爱而兰。

# 渡叶森河桥
原：伤时有客赋长征，到眼河山次第更。风雪一天饶画意，江湖满地惹闲情。贫儿拾芥归窝集，宿鸟冲寒入太清。极目叶森桥上望，苍烟如幕不分明。

# 长春
原：长春惯夺离人去，恼煞长春春不长。谁分天涯有芳草？更从何处觅欢场？悲凉古驿迟寒月，凄绝名花戴晓霜。相见何如不相见，前因后果总荒唐。

# 开原道中
原：晚霞红紫斗芳菲，夕照盈盈人翠微。却怪轻尘太多事，缘何辗转扑征衣。

# 长春杂感
原：今夜月明何处秋？秋风无语独登楼。年光不再悲流水，锦瑟无端织暮愁。大漠风沙孤雁叫，津门歌吹玉笙柔。辽天万里音书绝，自掩残灯被拥头。

# 哈尔滨中秋
原：每从客里度中秋，烟雨松江处处愁。出塞琵琶同感慨，泥人歌舞自温柔。千家爆竹闲中听，一寸河山眼底收。老泪纵横乡梦切，可怜王粲独登楼。

# 中秋雨后得月
原：中秋何故偏无月？玉宇琼楼意不平。偶拨浓云呈素面，顿教大地涌金城。一天风雨垂头去，无数儿郎拍掌迎。笑问吴刚知也未，去年花下结深盟。

# 琼林别墅晚眺
原：登楼望秋水，水色远连天。暮雨随风舞，江鱼入网鲜。片帆云树外，浊酒管弦边。无限沧桑感，相思一黯然。

# 夜过鄂穆斯克驿
原：大地皤然白，江山一望平。孤松矜瘦影，寒月挂新城。泛滥离人泪，低回故国情。鬓丝嗟已老，何处觅长生？

# 送小柳兼怀津门诸友
原：沪江春水愁如许，又送离人事北征。箫鼓一庭牵旧恨，头颅千载误虚名。津沽老伴欣无恙，湖海狂生忒有情。为问菊花安适否？夜凉莫漫舞衣轻。

# 送王厚斋之云南
原：数年相慕不相识，才得相逢又别离。始信江湖多遇合，莫将黍菽误年时。鼓山寒月催归思，马尾清流浣泪丝。却笑一天风雨急，有人鹬蚌正相持。

# 苍霞洲梅生席上
原：隔岸山光入几筵，主人好客客如仙。水夫俯汲愁新涨，野鸟翻飞羡晚鲜。静坐顿忘身外事，笑言莫悟意中禅。诗情酒债都无赖，一人欢场一惘然。

# 题亚子《分湖旧隐图》
原：寄语松陵旧钓徒，每从梦里说分湖。烟波浩淼幽深处，省识人间柳亚卢。
原：生小湖乡独占春，晓风残月忆前因。何时买得扁舟去？愿与诗人结比邻。
原：一幅云烟墨未干，春风无赖百花残。陆郎颜色分湖水，都作模糊涕泪看。

原：晓起出城郭，肃焉如早秋。市人揉睡眼，榜女尚蓬头。拂袖怜新绿，登高忆旧游。山灵应笑我，何事作浮鸥？
原：东际桥边水，殷勤作咽声。此行天上路，应少世间情。石磴穿云出，松楸夹道生。笑言一回顾，缥缈是江城。
原：佛殿鸣钟鼓，山深四月寒。开堂谈圣箭，喝水忆回澜。苔藓侵碑字，烟云绝羽翰。颇闻登大顶，男崱有奇观。
原：重来期后约，归路思绵绵。飞瀑依人落，山花着意妍。双轮分逝水，急雨洒平川。又入尘嚣里，诗成自惘然。

# 浣纱
原：浣纱小妹艳如花，结伴归来笑语哗。生怕旁人知住处，故留邻舍不还家。

# 无题
原：入门一笑便心倾，眼角眉梢百态生。欲使红笺留姓氏，似闻小语隔帘旌。花间携手娇无那，袖底传书忒有情。回首在山泉水意，十年不字女儿贞。

# 马江晚泊
原：一幅天然画，沧江晚泊船。波光随鸟逝，暮色与山连。处处烟生灶，声声浪打舷。隔舟争未息，为数卖鱼钱。

# 和霁青
原：无限悲凉意，都归一笑中。大江流日夜，飞羽落晴空。客况催华发，孤怀掠晚风。劝君莫於邑，斯世本飘蓬。

# 病中感事
原：百忧身世感浮沙，四海修罗啖月华。相斫一书成笑史，合欢双蒂证空花。情天漫握兜绵手，浊世犹存古德家。倚杖狂吟天地窄，白莲峰上听频伽。

# 西湖即事
原：石栏绕水自凄清，几点荷钱任意生。远岫暮烟笼晚翠，隔湖娇鸟报初晴。飞虹桥畔轻舟系，大梦山头夕照明。一望平畴新绿遍，天南白傅有贤声。

# 寿静仁先生四十三初度，即步原韵
原：谢公霖雨苍生望，失笑东山处士多。白傅流风犹想像，紫阳遗爱未销磨。好将春酒歌眉寿，愿把精诚却众魔。长揖登堂献诗句，不须痛饮已颜酡。

# 感事，即用前韵
原：无端哀乐缘何事？如此江山感慨多。老我风尘同啸傲，输他人海尽销磨。低回旧雨牵心曲，检点残书逐睡魔。回首少年豪气尽，酒痕梦影记微配。

# 伤瓶
原：爱知名产出安藤，记否离宫玉手承。人梦奇花香欲活，照人秋色艳于冰。豆萁相煮卿何罪？桃叶同归我未能。留得爪痕见贞固，此心犹是水波澄。

# 和克安《西湖》原韵
原：出郭无心逢好景，款秋有约订前朝。落花绕屐僧归寺，夕照衔山人渡桥。一笑未能容出世，此乡大可送无聊。遥知今夜西泠畔，小柳临风舞瘦腰。

# 寄蹇公钟祥，即步原韵
原：美人天末相思苦，远道书来认转疑。残月晓风怀旧梦，湘兰沅芷有同悲。韶华易逝惊弹指，世事如斯懒皱眉。记否西窗听夜雨，商量险韵斗春词？

# 白露黃粱熟，和静仁先生
原：白露黄粱熟，开眸识大诬。群阴随日化，老干出云孤。汉将常餐苡，唐生不买珠。升沉都一笑，归钓四腮鲈。

# 和克安《题赠雅集梅枝山馆小影》
原：不事铅华自有真，好将明月证前身。去年今日闽江上，风雨同舟此四人。

# 送汝川归皖
原：闻道莼鲈美，秋风送客归。惊心成小别，握手已相违。墨翟悲丝染，渊明识昨非。辞官应是福，朋辈总依依。

# 克安暂去榕城，赋此志别
原：衰朽残年感盛时，记从江上订归期。何堪风急舟先发，吹破离亭笛一枝。
原：客里秋光又一年，此乡何处着缠绵？西湖风月都无价，辜负旁人作浪传。
原：遥知冠盖满京华，沉醉钧天未有涯。人事仓皇谁管得？东篱为我问黄花。
原：秋老江湖白浪低，论交十载自东西。何时携手黄山顶？细数平生一笑啼。

# 静仁先生命和《送克安之京》原韵
原：送客河梁怜小别，苍霞洲畔月轮高。凄凉野色迷三县，憔悴年时上二毛。并世交情谁落落？遣生文酒得陶陶。临歧不作辛酸语，且和新诗写薛涛。

# 月夜渡海，寄怀春申诸子
原：海上看明月，秋光到眼频。吐吞宏有量，梳洗净无尘。樯影遮灯塔，波光上锦茵。只离索感，枯坐不知晨。

# 碧水
原：碧水无情甚，滔滔送客行。微云接天海，初日作阴晴。一发山痕在，孤舟别意生。故人应念我，为数去时程。

# 藤榻谣
原：由沪之闽，趁大阪会社之湖北丸，船桥甲板置藤榻数事，为一等船客设也。船客某君畏浪，方卧，奴来逐客，谓船长将至。客置不理，奴亦逡巡自去。作《藤榻谣》记之，不必示大阪主人也。
原：昔闻大阪重船客，今知湖北重船员。船客苦晕不复顾，船员醉饱只知眠。奴来逐客让藤榻，意谓不让船长嗔。须知船长所食肉，亦是船客所出钱。

# 闽口待潮
原：维舟近陆待潮生，到眼青山总不平。帆与野鸥争上下，身随孤棹卧沧溟。船人聚语诸方集，估客思归一梦成。湖海十年飘泊惯，今宵又喜宿榕城。

# 重来闽海，见市政修明，蘭圖喧溢，奉寄前巡按使秋浦许公
原：一时兴筑怨嶔崎，千载康庄任对驰。民可图成难与始，治能知本不须疑。煦涵声教文公化，灌溉湖田白傅思。更向名园看手泽，清明植树已垂枝。

# 观闽侯农产共进会
原：万人空巷岂荒嬉？贤宰临民苦费思。立国以农探治本，相观责善合天宜。搜来嘉谷占丰岁，采得新茶备赋诗。除却此州知稼穑，群儿只解弄旌旗。

# 林惠亭招饮宛在堂，即席口占
原：宛在堂前酒一卮，蒹葭秋水寄遥思。故人情重殷勤问：风景何如君去时？

# 过省立第四小学访蒋博如
原：到门方踯躅，堂上有弦歌。树木已初长，积书比昔多。声名因实至，教学得天和。孟晋无涯涘，先生意若何？

# 许翘谦招饮双骖轩，即席口占
原：在昔曾游此，开轩多好风。卜居无热客，结伴有寒松。扑地人家远，连天竹树丛。重来一临眺，不觉夕阳红。

# 贈梁挚龢
原：去来江上送迎忙，故旧情深感不忘。一别惊心两惆怅，桃潭风义让君长。

# 闽海舟中寄怀王叔梅
原：一粟浮沧海，飘零已半生。不消游子感，难受故人情。风暖归帆稳，秋高白浪平。寄书贤令尹，犹忆劝农声。

# 归途奉怀闽中诸友，用去岁《留别闽中诸友》韵
原：海南重见又相离，我本天涯唱竹枝。十日平原留不醉，予不能饮。一帘飞瀑看何时？与陈荔庭有游方广崖之约，未果。秋风东郭寻幽径，夜雨西窗涨曲池。莫怪此乡能恋客，江山如画落花迟。
