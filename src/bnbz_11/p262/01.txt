# 石子诗选
原：姚光字石子，江苏金山人。今录诗十五首。

# 丙辰上元节，舅氏吹万招集梅花香窟，分韵得花字
原：佳节恣清饮，寻梅意兴赊。疏枝寒澈骨，老干冷飞花。酒气腾香窟，吟声满洞崖。香窟适当秦山南崖洞天之下。归途犹缓缓，月印柳梢斜。

# 饯春
原：者番花事匆匆甚，回首天涯又绿阴。葬罢落红因久立，丝丝情泪湿衣襟。

# 听雨
原：小楼春雨听声声，恻恻愁生梦不成。最是系侬心事处，碧桃满树溷风尘。

# 题龙丁、华书伉俪《春愁秋怨词》一首
原：浩荡情怀不可收，英雄迟暮住温柔。双飞双宿如鹣鹈，底事愁春又怨秋？

# 春尽
原：艳阳天气落花风，一度韶光转眼空。闭户深山不出去，芒鞋为恐蹈残红。

# 初夏晚眺
原：万绿沉沉着意妍，天涯芳草自芊芊。树间历历莺啼老，柳色斜阳最惘然。

# 夜起一首次钝根
原：婆娑花影上窗棂，月色朦胧点点星。悄步中庭群籁寂，惟闻蛙鼓似谈经。

# 初秋
原：萧萧落叶又惊秋，百感茫茫怕上楼。衰柳临风看不得，一重烟雨一重愁。

# 伤心
原：为虺弗摧终贻戚，我谋不用复奚论？伤心往事都成梦，晦冥乾坤且闭门。

# 春寒
原：朔风凛冽起萧晨，二月春寒剧闷人。满地绿红都惨澹，雨丝云墨不成春。
原：花须柳眼无聊赖，漠漠重阴郁不开。最是令人愁绝处，南枝乍动又摧残。

# 本事诗
原：徙倚闲窗月上初，仙霞朗润托明珠。银屏华鬓人如玉，红袖添香夜读书。
原：皓魄横斜夜漏迟，重重花影上帘时。梦中占得销魂句，唤醒卿卿索和诗。

# 秋夜
原：一叶梧桐金井下，江山绵渺起埃尘。冷萤照夜如愁梦，秋蟀啼阶诉苦辛。芳草经霜凄欲死，黄花着雨冷堪珍。悄然步上高楼望，盼尽霜鸿思杀人。

# 题钝剑《词人听秋图》
原：玉露空阶落叶声，寒蛩四壁若为情。万般并人秋消息，和雨和风听不清。
