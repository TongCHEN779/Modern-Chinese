# 曼殊诗选
原：苏玄瑛字子穀，号曼殊，广东香山人。今录诗七十五首。

# 耶婆提病中，末公见示新作，伏枕奉答，兼呈旷处士
原：君为塞上鸿，我是华亭鹤。遥念旷处士，对花弄春爵。良讯东海来，中有游仙作。劝我加餐饭，规我近绰约。炎蒸困羁旅，南海何辽索。上国亦已芜，黄星向西落。青骊逝千里，瞻乌止谁屋？江南春已晚，淑景付冥莫。建业在何许？胡尘纷漠漠。佳人不可期，皎月照罗幕。九关日已远，肝胆竟谁托？愿得趋无生，长作投荒客。竦身上须弥，四顾无崖崿。我马已玄黄，梵土仍寥廓。恒河去不息，悲风振林薄。袖中有短书，思寄青飞雀。远行恋俦侣，此志常落拓。

# 西班牙雪鸿女诗人过存病榻，亲持玉照一幅、拜轮遗集一卷、曼陀罗花共含羞草一束见贻，且殷殷勖以归计。嗟夫！余早岁披剃，学道无成，思维身世，有难言之恫。爱扶病书二十八字于拜轮卷首，此意惟雪鸿大家心知之耳
原：秋风海上已黄昏，独向遗编吊拜轮。词客飘蓬君与我，可能异域为招魂？

# 本事诗十章
原：无量春愁无量恨，一时都向指间鸣。我亦艰难多病日，那堪更听八云筝？
原：丈室番茶手自煎，语深香冷涕潸然。生身阿母无情甚，为向摩耶问夙缘。
原：丹顿斐伦是我师，才如江海命如丝。朱弦休为佳人绝，孤愤酸情欲语谁？
原：慵妆高阁鸣筝坐，羞为他人工笑颦。镇日欢场忙不了，万家歌舞一闲身。
原：桃腮檀口坐吹筝，春水难量旧恨盈。华严瀑布高千尺，未及卿卿爱我情。
原：乌舍凌波肌似雪，亲持红叶索题诗。还卿一钵无情泪，恨不相逢未剃时。
原：相怜病骨轻于蝶，梦入罗浮万里云。赠尔多情书一卷，赠以梵本沙恭达罗。他年重检石榴裙。
原：碧玉莫愁身世贱，同乡仙子独销魂。袈裟点点疑樱瓣，半是脂痕半泪痕。
原：春雨楼头尺八箫，何时归看浙江潮？芒鞋破钵无人识，踏过樱花第几桥。
原：九年面壁成空相，持锡归来悔晤卿。我本负人今已矣，任他人作乐中筝。

# 代柯子简少侯
原：小楼春尽雨丝丝，孤负添香对语时。宝镜有尘难见面，妆台红粉画谁眉。

# 淀江道中口占
原：孤村隐隐起微烟，处处秧歌竞种田。羸马未须愁远道，桃花红欲上吟鞭。

# 题《师梨集》
原：谁赠师梨一曲歌？可怜心事正蹉跎。琅玕欲报从何报，梦里依稀认眼波。

# 落日
原：落日沧波绝岛滨，悲笳一动剧伤神。谁知北海吞毡日，不爱英雄爱美人。

# 为调筝人绘像
原：收拾禅心侍镜台，沾泥残絮有沉哀。尝作《风絮美人图》寄晦公广州，晦公寄余诗有“向人风絮有沉哀”句。湘弦洒遍胭脂泪，香火重生劫后灰。
原：淡扫蛾眉朝画师，同心华髻结青丝。汉元帝时有同心髻，顶发相缠，束以绛罗，今日本尚有此风。一杯颜色和双泪，写就梨花付与谁？

# 寄调筝人
原：生憎花发柳含烟，东海飘零二十年。忏尽情禅空色相，琵琶湖畔枕经眠。
原：禅心一任蛾眉妒，佛说原来怨是亲。雨笠烟蓑归去也，与人无爱亦无嗔。
原：偷尝天女唇中露，几度临风拭泪痕。日日思卿令人老，孤窗无那正黄昏。

# 寄晦闻
原：忽闻邻女艳阳歌，南国诗人近若何？欲寄数行相问讯，落花如雨乱愁多。

# 译师梨诗
原：孤鸟栖寒枝，悲鸣为其曹。河水初结冰，冷风何萧萧。荒林无宿叶，瘠土无卉苗。万籁尽寥寂，唯闻喧挈皋。

# 过若松町有感示仲兄
原：契阔死生君莫问，行云流水一孤僧。无端狂笑无端哭，纵有欢肠已似冰。

# 调筝人将行，属绘《金粉江山图》，题赠二绝
原：乍听骊歌似有情，危弦远道客魂惊。何心描画闲金粉，枯木寒山满故城。
原：送卿归去海潮生，点染生绡好送行。五里徘徊仍远别，未应辛苦为调筝。

# 译拜轮《答美人赠束发带诗》示弹筝人
原：何以结绸缪？文纰持作绲。曾用系卷发，贵与仙蜕伦。
原：系著曩衣里，魂魄还相牵。共命到百岁，殉我归重泉。
原：朱唇一相就，汋液皆芬香。相就不几时，何如此意长。
原：以此俟偕老，见当念旧时。挚情如根荄，勾萌无绝期。
原：参发乃如铣，波文映珍鬘。颚首一何佼，举世无与易。
原：锦带约鬣髻，朗如炎精敫。赤道无云，光景何鲜卓。

# 住西湖白云禅院作此
原：白云深处拥雷峰，几树寒梅带雪红。斋罢垂垂浑入定，庵前潭影落疏钟。

# 吴门依易生韵
原：江南花草尽愁根，惹得吴娃笑语频。独有伤心驴背客，暮烟疏雨过阊门。
原：碧海云峰百万重，中原何处托孤踪？春泥细雨吴趋地，又听寒山夜半钟。
原：月华如水浸瑶阶，环珮声声扰梦怀。记得吴王宫里事，春风一夜百花开。
原：姑苏台畔夕阳斜，宝马金鞍翡翠车。一自美人和泪去，河山终古是天涯。
原：万户千门尽劫灰，吴姬含笑踏青来。今日已无天下色，莫牵麋鹿上苏台。
原：水驿山城尽可哀，梦中衰草凤凰台。春色总怜歌舞地，万花撩乱为谁开？
原：年华风柳共飘萧，酒醒天涯问六朝。猛忆玉人明月下，悄无人处学吹箫。
原：万树垂杨任好风，斑骓西向水田东。莫道碧桃花独艳，淀山湖外夕阳红。
原：平原落日马萧萧，剩有山僧赋《大招》。最是令人凄绝处，垂虹亭畔柳波桥。
原：碧城烟树小彤楼，杨柳东风系客舟。故国已随春日尽，鹧鸪声急使人愁。
原：白水青山未尽思，人间天上两霏微。轻风细雨红泥寺，不见僧归见燕归。

# 无题
原：绿窗新柳玉台傍，臂上微闻菽乳香。毕竟美人知爱国，自将银管学南唐。
原：软红帘动月轮西，冰作栏杆玉作梯。寄语麻姑要珍重，凤楼迢递燕应迷。
原：水晶帘卷一灯昏，寂对河山叩国魂。只是银莺羞不语，恐防重惹旧啼痕。
原：空言少据定难猜，欲把明珠寄上才。闻道别来餐事减，晚妆犹待小鬟催。
原：绮陌春寒压马嘶，落红狼藉印苔泥。庄辞珍贶无由报，此别愁眉又复低。
原：棠梨无限忆秋千，杨柳腰肢最可怜。纵使有情还有泪，漫从人海说人天。
原：罗幕春残欲暮天，四山风雨总缠绵。分明化石心难定，多谢云娘十幅笺。
原：星裁环珮月裁珰，一夜秋寒掩洞房。莫道横塘风露冷，残荷犹自盖鸳鸯。

# 东居杂诗十九首
原：却下珠帘故故羞，浪持银蜡照梳头。玉阶人静情难诉，悄向星河觅女牛。
原：流萤明灭夜悠悠，素女婵娟不耐秋。相逢莫问人间事，故国伤心只泪流。
原：罗襦换罢下西楼，豆蔻香温语未休。说到年华更羞怯，水晶帘下学箜篌。
原：翡翠流苏白玉钩，夜凉如水待牵牛。知否去年人去后，枕函红泪至今留。
原：异国名香莫浪偷，窥帘一笑意偏幽。明珠欲赠还惆怅，来岁双星怕引愁。
原：碧阑干外夜沉沉，斜倚云屏烛影深。看取红酥浑欲滴，凤文双结是同心。
原：秋千院落月如钩，为爱花阴懒上楼。露湿红蕖波底袜，自拈罗带淡蛾羞。
原：折得黄花赠阿娇，暗抬星眼谢王乔。轻车肥犊金铃响，深院何人弄碧箫？
原：碧沼红莲水自流，涉江同上木兰舟。可怜十五盈盈女，不信卢家有莫愁。
原：灯飘珠箔玉筝秋，几曲回阑水上楼。猛忆定庵哀怨句，三生花草梦苏州。
原：人间天上结离忧，翠袖凝妆独倚楼。凄绝蜀杨丝万缕，替人惜别亦生愁。
原：六幅潇湘曳画裙，灯前兰麝自氤氲。扁舟容与知无计，兵火头陀泪满樽。
原：银烛金杯映绿纱，空持倾国对流霞。酡颜欲语娇无力，云髻新簪白玉花。
原：蝉翼轻纱束细腰，远山眉黛不能描。谁知词客蓬山里，烟雨楼台梦六朝。
原：胭脂湖畔紫骝骄，流水栖鸦认小桥。为向芭蕉问消息，朝朝红泪欲成潮。
原：珍重嫦娥白玉姿，人天携手两无期。遗珠有恨终归海，睹物思人更可悲。
原：谁怜一阕断肠词？摇落秋怀只自知。况是异乡兼日暮，疏钟红叶坠相思。
原：槭槭秋林细雨时，天涯飘泊欲何之？空山流水无人迹，何处蛾眉有怨词？
原：兰蕙芬芳总负伊，并肩携手纳凉时。旧厢风月重相忆，十指纤纤擘荔枝。

# 汽车中隔座女郎言其妹氏怀仁仗义，年仅十三，乘摩多车冒风而殁，余怜而慰之，并示湘痕、阿可
原：人间花草太匆匆，春未残时花已空。自是神仙沦小谪，不须惆怅忆芳容。

# 憩平原别邸贈玄玄
原：狂歌走马遍天涯，斗酒黄鸡处士家。逢君别有伤心在，且看寒梅未落花。

# 东行别仲兄
原：江城如画一倾杯，乍合仍离倍可哀。此去孤舟明月夜，排云谁与望楼台？

# 饮席贈歌者
原：一曲凌波去，红莲礼白莲。江南谁得似？犹忆李龟年。
