# 滨虹文选
原：黄质字朴存，号滨虹，安徽歙县人。深于金石书画之学，余与同事于《国粹学报》，朝夕谈心，获益颇巨。尤癖印，臧周秦古录，为海上之冠。屡次被人盗窃，卒展转以复旧观。客岁，所臧精品因邻居失火，又为人窜去。朋辈为之悼惜，宾虹殊为坦然。余谓滨虹之印，必可再复旧观，盖不以失之而灰心，则得之必有日也。今录文十一首。

# 论上古三代图画之本原
原：莽莽神皋，自喜马拉雅山以东，太平洋海以西，绵亘数万里，积阅四千年，声明文物之盛，焜耀寰宇，古今史册，流传美且备矣。圣作巧述，学术相承，授受心源，虽或有时代之变迁，支派之区别，忽显忽晦，为异为同，不可殚究；而穷流竟委，各有端绪。其精思奥义，皆自卓立不群，足以留垂万世，厘然昭晰，而未可以或废也。古者自伏羲氏始画八卦，造书契，以代结绳，为开万古文字之祖，即开万古图象之先。仓颉之初作书，盖依类象形，故谓之文。其后形声相益，即谓之字。字者，言孳乳而浸多也。著于竹帛谓之书。书者，如也。六书之义，首曰象形，画已滥觞于此。有虞氏言：“余欲观古人之象，日、月、星辰、山、龙、华虫，作会；宗彝、藻、火、粉米、黼、黻、缔绣，以五采彰施于五色，作服汝明。”夏后氏之远方图物，贡金九牧，铸鼎象物，百物为之备，使民知神奸。《史记》称伊尹从汤言素王及九主之事。刘向《别录》谓凡九品，图画其形。《尚书·说命》云：“恭默思道，梦帝赍予良弼，其代予言。乃审厥象，俾以形旁求于天下。说筑傅岩之野，惟肖。”是虞、夏、殷商之际，民风简朴，而画事所著，已综天地、山水、人物、禽鱼、鸟兽、神怪百物而兼有之。逮于周室尚文，郁郁彬彬，粲然可睹。地官大司徒职掌建邦土地之图，若今之郡国舆地图是也。古之九邱，或言纪载九州土地，其来已久，惟图至周而大备矣。《家语》记孔子观乎明堂，睹四门墉，有尧舜之容，桀纣之象；又有周公相成王，抱之负斧扆，南面以朝诸侯之图焉。此又善恶之状，兴废之诫之大旨也。至如春官掌九旗之物名，以待国事。日月为常，交龙为旗，龟蛇为旐，全羽为旞，析羽为旌。郑注言：旗画成物之象，王画日月象天明。诸侯画交龙，一象其升朝，一象其下复。孤卿不画，言奉政教而已。画熊虎者，乡遂出军赋，象其守莫敢犯也。乌隼象其勇健，龟蛇象其扞难避害也。此因所画各异，则物亦因之异名也。他若王日视朝于路寝门外，画虎以明勇猛于守宜也。扆画斧形，盾画龙饰，饰羔雁者以绩，画布为云气，以覆羔雁为饰而相见，故设色之工，画绩之事，详于冬官。画绩二者，别官同职。共其事者，画绩相须故也。画绩之事，杂五色者，东方谓之青，南方谓之赤，西方谓之白，北方谓之黑，天谓之玄，地谓之黄。青与白相次也，玄与黄相次也。此又言画绩六色所象，及布采之第次也。其后画事之见于列国间者，鲁公输班之水见蠡曰：“见汝形。”蠡迩出头，班以足图之。燕太子丹使荆轲献督亢地图于秦。楚有先王之庙，及公卿祠堂，图天地山川，神灵琦玮璃伧及古贤圣怪物行事。秦每破诸侯，写放其宫室，作之咸阳北阪上。载籍可稽，不胜枚举。代远年湮，今已莫觏。所可知者，而惟吉金款识。其文字与图画，纠错参差，往往联属。庾肩吾《书品》，论夏雕戈之书，谓为蛟脚旁舒，鹄首仰立。论钩带书曰：“鱼犹舍凤，鸟已分虫。仁义起于麒麟，威刑发于龙虎。”读者已可想见古人书画同源，非特其言语形容之妙已耳。而趸鼎象尊、鹰父癸彝之类，直作物形，持刀立戈执爵拱日之象，尤其显者。许叔重言：“郡国山川得鼎彝，其铭即前代古文，皆自相似，虽叵复见远流，其详可得略说也。”余于上古图画亦云。

# 论两汉之石刻图画
原：汉去商周既远，由古文籀书小篆，降为隶书，书法递变。时至后世，人事繁多，日趋简易，此其一端。图画制作，又与文字显分。吉金流传，每多阳识。迹象昭著，仅类雕饰。其视三代，迥不侔已。汉器洗铭三字，旁有蟾蜍双鱼之形；灯铭七言，式详龙虎鹿庐之制。即如铜镜带钩，铃铎染棓，虽或纤悉成纹，金缕纠错，不可名状；要之古者义存彰瘅，功资劝惩，进德行仁，有事图画。汉文帝三年，于未央宫承明殿，画屈轶草进善旌、诽谤木、敢谏鼓、獬荐。宣帝之时，画图汉列士。或不在于画上者，子孙耻之。后汉顺烈梁皇后，常以列女图置于左右，以自监戒。明王法古，详稽制度，尤多援据典礼，博证经传，著之于画。武帝中令奉高作明堂汶上如带图，又作甘泉宫中为台室，画天地太一诸鬼神，而置其祭具，以致天神。明帝别立画官，诏博洽之士班固、贾逵辈，取诸经史事，命尚方画工图之。其后若《禹贡图》之成书于阮谌，《三礼图》之见赐于王景，其远且大，可与天文、兵家诸图并重。比之图列仙者，仅明其道术；图功臣者，不及于椒房，犹其事之近而微者耳。独惜载籍所详，今皆不存。而杜陵毛延寿、安陵陈敞、新丰刘白、洛阳龚宽之伦，并工牛马飞鸟众势，人形好丑老少，为得其真。然亦徒著姓氏，艺事不可复睹。今所习见，而惟石刻留存，显然易知，传者尤夥。武帝元狩中，有凤皇刻石，画笔古劲，无异作书，当为画家写意鼻祖。嵩岳太室少室开母庙，世称三阙，所镌诸画，意态纵横，古拙特甚。前后数幅，若出一手。其中角抵蹋鞠之戏，走马猎犬之娱，螭龙蟾兔，独角兽类，与人之坐者、跪者、持钩者，亘相回应。而所图螭龙，一龙入于窗中，一龙逐而衔其尾；又猎犬逐兔，趯趯然可及者。此尤见天机之洋溢，意趣之横生者也。永建中孝堂山石室三间，画象十幅，旧传为郭巨葬母处，又云即巨墓。其刻有岑楼阿阁，营帐数重；其人峨冠盛服，左右执版与简策而立；兵士乘骑出射，作战马交驰，戈刀击刺。或高坐堂皇，有反缚若鞫讯状者。而逐鹿搏虎，牵舟捕鱼，曳绳升鼎，设筵授几，种种可观。岸侧之树，花叶相交，禽鸟飞翔，颇极闲暇。亦有长桥蹶马，衣冠者与御者，堕入河中，多人举篙，向上援救。舟旁群鱼绕之，而南越北胡，驼象之属，莫不咸备。举凡人世可惊可乐之事，状其难显之容，一一毕现，有如此者。若夫文之工细，错综如簟，列钱青琐，相间贯成，鳞瓦栉比，皆作曲笔，此又开后来界画之渐也。至武氏祠堂，自伏戏至丁兰十四幅，仅载故事。李翕《黾池五瑞图》，左龙右鹿，二树交枝，树旁一人奉器承露，一禾九茎，直祥瑞图之类而已。其餘如周公之负成王，汉武以赐霍光，孔子之见老子，济宁流于宝应，画本传世，后人祖述，多所摹翻。诸如此类，不可胜数。朱长舒墓石，或谓其人物衣冠，萧疏生动，颇类唐人。王浚颖《乘马时图》，称为友人严统所书，而考订金石之书，亦不详于著录。拓本今藏庞君芝阁家，后有近人汪彦份题跋，谓为陕中出土。事有可疑，未可以臆断也。然其古意槃礴，神妙各臻，必非庸史所能拟议。胪举大略，亦可知名画昭垂，焜耀艺林，有自来矣。

# 论画法之宗唐上
原：古来以绘事名者，动曰法唐。画之宗唐，如周有史籀，秦有斯篆，汉有隶草，晋有真行，体制宏创，允为学书者所祖，虽百世而下，不能出其范围。唐画真迹，后人所未习见，或因有无学之说，而伪托者又多凿空杜撰，大失本来面目，遂谓唐画皆极粗率。此未睹真龙，叶公却步；徒炫赝鼎，乐正难期。是非溷淆，疑信颠倒，皆扣盘扪烛者，鼓其盲论，聚讼虽多，何以异之？大抵唐世画法，工妍秀润，虽斤斤规矩，而意趋生动。有明张平父谓唐人去古未远，风气淳庞，其笔如木鸢楮叶，数年而成，绝非后世所得梦见，亦非临摹所得仿佛。又言唐画蹊径，上接六朝，往往以精妍为尚，以深远为宗。其最著者，厥有数人，术艺相承，足垂千古。吴道玄者，初学书于张颠、贺知章。久之不成，去而学画。见张孝师画地狱相，因效为地狱变相。早年行笔差细，中年行笔磊落如莼菜条。人物有八面，生意活动。其傅采于焦墨痕中，略施微染，自然超出缣素，世称吴装。其徒翟琰、杨庭光、卢楞伽，均学于道玄，时谓吴生体。阎立德、立本昆季，画法皆纯重雅正，性出天然。吴生之作，独为万世法，故号曰画圣。阎立德，父毗，在隋以丹青得名，与弟立本，家学俱造其妙。贞观中，画东蛮谢元深入朝图，鸟章卉服，庄正恢奇，端簪奉笏之仪，鼻饮头飞之俗，理该毫末，备得精神。立本有文学，善应务。时虢王元凤射获猛兽，太宗命图其真，见者无不惊服。又尝与侍臣泛春苑池中，有异鸟随波容与，太宗击赏数四，召立本写之。有《秦十八学士》、《凌烟阁功臣图》，及为群僧作《醉道士图》，并传于世，尤甚著名。固已技擅众美，非独超越寻常也。至若张萱画贵公子，鞍马屏帷宫苑子女等，冠绝一时。周古言、周昉诸人，时亦专工人物，或画岁时行乐之胜，形貌贵以神传；或多丰肥秾艳之容，贵游本于目见。诣之所至，各极其精。虽仅偏长，无伤大雅矣。所以韩干专画马，不欲师陈闳，而师曹霸。王维一见其画，遂推奖之。弟子孔荣，称得其妙。戴嵩工画牛，能尽野性，过于韩滉。其弟峄画牛亦擅名。后有张符宗其派。论者谓为气韵骨法，皆出意表。此画佛道人物士女牛马者，技能卓跞，推为独步，后人学古，终莫能到。乃唐代名人，尚多画壁。楮素遗世，虽或珍若球璜，鉴藏之家，尤不数觏。人所习见，班班可考者，净域寺有皇甫轸画鬼神，资圣寺有吴道子画高僧，老君庙有杨惠之画神仙，信果观有厉归真画飞鹞。笔之记载，咸以为奇。其他图画专精，姓氏不显，流传后世，犹复脍炙人口，称颂弗衰。诚以一技之工，千秋共仰。如云花寺有圣画殿，长安中谓之七圣画，相传殿宇既制，寺僧召画工，将命施彩饰。有二少年诣寺，兄弟共七人，各掣彩绘。后启其门，化鸽飞去。鲁人廉广，采药泰山，逢隐士授五色笔，而画通灵。至中都县，于李令署及赵尉廨壁上，画鬼兵有出战之异，又画大鸟有免祸之方。语多不经，事尤无据，未可遽信为真。要亦肥遁君子，不得志于时者之所为，托物寓言，故神其技。然其必有过人之能，足以惊世骇俗，而非庸众所可企及，因不屑于末技，稍留其身后之名。以视世之攘夺他人之功，博取富贵于一时，有忝面目，而不知返，其为人之贤不肖，抑又远已。

# 论画法之宗唐下
原：唐画上承晋魏六朝，下启宋元明清，精妍深远，其法大备。山水林石，花竹禽鱼，穷神尽变，恒多创格。王维家于蓝田玉山，游止辋川，兄弟以科名文学冠绝当代，其画山水松石，踪似吴生，而风标特出。相传长安千福寺西塔院有掩障，一画枫戌，一图辋川，山谷郁盘，云水飞动，意出尘外，怪生笔端。又慈恩寺东院，与毕庶子宏、郑广文虔各画一小壁，时号三绝。毕宏当大历二年为给事中，画松石于左省厅。树石擅名于代，树木改步变古，实自宏始。郑虔居郑州荥阳，山水墨色深厚，树木浓重，老干枯枝，无不沉著。又好工书，尝自写其诗并画，献之明皇，因赐书其尾曰“郑虔三绝”。杜子美与之交善，作诗赠之。其画传世不多，宣和御府藏有数幅。时以山水得名，足与王维分道扬镳，别为南北二宗者，有李思训。本唐宗室，弟侄五人，皆妙丹青，独思训之画尤著。山水林泉，笔格遒劲，恒得湍濑潺湲、烟霞缥缈难写之状，用金碧辉映，为一家法。其子昭道，作法佳妙，山水鸟兽，精细繁巧；层楼叠阁，俱事界画；豆人寸马，须眉毕具，稍变其父之势。虽才思笔力，均若不逮，而翩翩公子，不徇时趋，唯以妍弄翰墨，继美家风，世称大小李将军，固其宜矣。王默师项容，又师郑虔，画多泼墨山水，或疑即为王洽。然洽以戛戛独造之诣，开百代云山之祖，南宫房山，转相摹仿，可谓形神俱肖。项容尝作《松风泉石图》，挺特巉削，自成一派。河内荆浩尝语人曰：“吴道子画有笔而无墨，项容有墨而无笔。吾采二子所长。”其自负可见也。所撰《山水诀》一卷，开先启后，厥功甚伟。画之皴钩布置，后学观摩，得有行径。故关同北面事之，不独为唐末之冠，而实百世之宗焉。至若边鸾精于设色，譬若良工制器，妙无斧凿之痕。黄筌兼擅众长，称其画雉如神，极有生动之致。此又技呈花鸟，足为学者津梁。所由强颖、陈庶之伦，同在当时，多得师资，名已大显。况有本源家学，断制心裁，一如居宝、居实诸贤，其为蜚声艺苑，良非偶尔。他或术类颛门，争长片技：张璪手操双管，能为一生一枯；王宰家居蜀山，尽作玲珑窳窆；滕王蜂蝶，曲擅精微；杨宁写真，独传风骨。固不仅孙位画水，南本画火，足诩神妙，世所共推。而唐画流传宗尚各异，虽有真迹，历代收藏之家，不可概见。名公巨卿，互有评骘，著之简册，不为不夥。宋元而后，作家士习，靡不依傍唐人门户，始抒己见，以臻神妙。故吴匏庵、文衡山，皆云赵松雪画摹仿唐法。衡山遥接衣钵，艺事相承，不绝如线。前贤矩，犹可想见。至于后世，每多向壁虚造，妄訾古人。或见倪迂取法荆关，遂云荆关似倪。是何异喻日于盲人之前，其不揣圆而为镜，误明而为烛者，亦已鲜矣。今欲追踪往哲，景慕芳型，世代既遐，遗传莫诘，不特楮素之留存有限，而兵燹阅历，良多沦失。守成之子，不忍弃置先世簪履之遗，时深匹夫怀璧之惧，每有过访之者，辄自秘匿，惟恐势家豪夺，往往贮之衍箧，或一二百年，不与人接。名笔传世，因此寥寥。惟精于鉴识者，溯厥源流，辨其真赝，若止水之鉴须眉，纤毫不爽。搜罗所获，与见闻之所及，皆足取以为证，殊难为师心自用者道也。

# 滨虹草堂集古玺印谱序
原：昔者子云拟《易》，不为雕虫；嵇生善琴，又工锻灶。厌忻之故，人事殊焉。余自胜衣就傅，窥乎九流；游屐啸俦，壮而万里。舟还渐水，信宿绵上，过汪讱庵飞鸿堂，见各种印谱，低徊久之。风徽未沫，雪泥已消，鼎鼎百年，觥觥大集。询其所存古印，散佚尽矣。乃复江淮作客，岁得一归，退耕缮渠，眴延十稔。力之能致，缘尚不悭，窃自喜耳。性与俗迕，来于海滨；时有古欢，萃此吴会。三千珠履，愿怀春申之风；十六金符，如读延陵之碣。侯门昼冷，神物夜飞，入市肆以惊人，典征衣而易我，则孙卿所佩秦斯之篆，尤足珍也。矧夫三仓出玺，百琲量珠。楼均宝燕，姬姜之宠斯专；匣启蟠螭，清闷之珍可数。而是册者，缀腋狐白，岂诩千金？耀手猩红，将裒十卷。亦以史籀遗篆，有历劫而不磨；屈到嗜芰，藉相饷于同好云尔。

# 叙印谱
原：余尝浏览班史，至《楚元王传》赞，称“孟轲、孙况、董仲舒、司马迁、刘向、扬雄，此数公者，皆博物洽闻，通达古今，其言有补于世。”唐颜师古注：“孙况即荀卿。”顾亭林言荀之为孙，如孟卯之为芒卯，司徒之为申徒，语音转耳，是为塙证。既而余得孙况印，鼻钮铜质，土花辩驳，翠泽犹新，而文字秀劲，颇类李斯小篆。因悟秦政封禅诸碣，若琅邪台、泰山石刻，其体制皆无以异，为之狂喜。拟以宝荀名楼，师龚定庵宝燕楼意也。夫定庵论印，于官私二者，有欲其史不史之殊。自来藏印之夥，无如汪讱庵。余族聚居新安之潭上，去讱庵飞鸿堂故址，廑六七十里。往来江淮间，舟行必经其地。至则裴回瞻望，未尝不怀想其遗风。询所藏印，则归西溪汪氏已久矣。洎客游归里门，与西溪汪宅衡宇相望，又获交其贤士大夫，始稍得窥其所存印谱。不数年间，又得其印谱中所有之印。盖庚申兵乱，新安罹劫最毒，印故散失，事平而家人或收其耳。然存亡得半，尚以千计。近年宇内藏印诸家，所及见者，如仁和许迈孙、桐城马莪园、湘中吴芷生诸君，得讱庵藏印，皆数百钮。余生最晚，而得印存之印亦较鲜。讱庵印谱流传近世者，人人目为瑰宝，东瀛士女，尤艳称之。余搜辑有年，自忘黯陋，择其精者，曾订成帙。近来海上，友人之索观余所得印者益多。惟是古文籀篆，风雨磨灭，传世浸稀。而铩印之文，朱白累累，新发土中，方日出而不可穷诘，则通儒之名字，爵官之封号，其未纪载于史臣与谱录于先哲者，不胜枚举。缪篆虽微，苟繇是以溯文字之源，而探经传之赜，周秦两汉之学术，且蕲大明于天下，而岂徒雕虫小技，夸耀今古哉！至今吊春申之往迹，感荀卿之不遇，悲其被谗放废，终老兰陵，而仅推儒墨道德之行事，兴坏序列，著数万言，授其弟子李斯于相秦之日，斯不能用，而卒无补于秦之亡。《诗》曰：“民之贪乱，宁为荼毒。”士君子不幸而丁危乱，欲拯斯民之荼毒，益令人载稽往籍，景慕前贤于不置也。余集古人官私铩印，因述其得印之颠末而著于篇。

# 荀屡画谈序
原：董香光著《画禅室随笔》，详言画旨，归其要于用笔用墨，学者宗之，垂三百年。至秦缃业作《桐阴论画》，推崇董氏，褒然首举，摈斥北宗，辍而非录，岂弗思翁《画诀》所称，一落画师魔界，不复可救药之说，为之入主出奴哉！顾画禅衣钵，如卞花龛、沈子居，皆能浑厚浓古，不堕宋元矩镬，而识者犹以华亭习尚薄之。白套山人阎尔梅以胜国孤忠，矢怀高洁，评骘古今，谓黄子久画法，本之董北苑，而遒险过之，不似而似，乃为其所独造，后惟沈石田最为入室。董思白酷临北苑，而骨薄姿纤，似而不似，优孟衣冠矣。洵乎其知言也！娄东王逊之，刻意摹拟思翁，未能脱其窠白。王清晖虽取法唐宋，已开乾嘉画手松懈之渐。刘、李、马、夏，无复过问之者。王新城《蚕尾集》，言画者多习南宗，少北派，因喜其灵秀，而惮其雄悍。宋商邱论画，尤赏心于北宗之二公者，去思翁未远，多见古今名迹，又富于收藏，故其所言如此。昔邓完白工书，肆力北碑，一洗前人南帖柔靡之习。包安吴、吴攘之扬波助澜，学风所扇，家汉魏而户齐梁，虞欧而下，皆以为不足观。而独画学一途，积弊相沿，去古愈远。近罹庚子之厄，大内旧藏，流入异域，碧眼紫髯人，共知缣墨之可宝，犹不靳兼金白璧之价，搜求于劫灰故纸之。旷代瑰宝，恒集都市，目论之士，若无甚轩轻于其间，神皋美术，终以不振，非学者之耻乎？余不自揣，因摅所见，笔之简端。持论踌驳，不无与世乖迕；然寻源溯流，当亦不囿于时者之所许也。于是乎书。

# 与柳亚子书
原：近惠赐《南社》诗文集，阅悉。采辑宏多，猥以下走恶札，羼刊其间，滥竽之惧，前函本非饰词。先生顾不见谅，且重下走之愆。君子爱人以德，果如是耶？窃以学问、道德、文章，三者皆不可假以虚誉。故古人寻常酬应之作，取入刊集过多，已足损品；况以瓦缶之鸣，而杂笙璈，其必不能动人清听，明矣。鄙意文字贵于精美，以关道德学问为归。非此宁阙毋滥，宁鲜毋秽可也。下走学植荒落，无由进德，惟蜷缩尘市中，岑寂如崖谷，仅摩挲古金石书画，间与一二鸥友相研求，稍剖前人拘泥穿凿之惑以为快。自谓古人之道与艺，皆于是乎存，而不知其僻隘也。益以世氛日嚣，人生靡乐，故交之士遭戮辱、罹祸乱者，不可偻计，伤何如之？然成务而偾踣，立异而触冒，此非尽庸人，而沉几未深，豪杰与有责焉耳。邦之兀臬，来日大难，先生其何以拯救之？亚子先生道安。质启。

# 分湖旧隐图书后
原：“凿池畜水鱼千里，叠石为峰蚁百盘。肯信有人行汗漫，云山无际海波寒。”此灵芬山馆题《万里浪游图》句也。亚卢先生自撰《分湖旧隐记》，飘零湖海，与郭灵芬同有身世之感。仆亦羁旅人，游踪萍梗，遥望故山，因写斯图，不禁为之累欷已。滨虹黄朴存。
