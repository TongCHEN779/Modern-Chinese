# 天民诗选
原：吕志伊字天民，云南思茅人。今录诗三十一首。

# 昆池舟中
原：海风吹透锦衾寒，月照波心蜡炬残。一夜扁舟无个梦，菊花枕畔浪花攒。

# 滇南胜境
原：先鞭策马度雄关，两地阴晴片石间。到此更增离别恨，那堪回首望家山？

# 青龙洞
原：乾坤俯仰感经年，万里岩疆一洞天。冬岭白飞千树雪，春江青绕五溪烟。疏灯照水渔舟泊，峭壁穿云鸟道旋。忧乐此身天下寄，岳阳风月渺无边。

# 清溪道中
原：鸡鸣关竞渡，风雨满江洲。山态随云变，河声挟石流。浪花欺雀舫，露草逼羊裘。饮尽杯中月，乾坤一水鸥。

# 过黔楚界喜晴
原：天教黔楚判鸿沟，风日新晴宿雨收。六诏乡关常恨别，三湘春水无情流。山连烟树青围幄，船逐浪花白打球。既倒狂澜难遽挽，上书徒抱贾生忧。

# 雨后晚行
原：连朝阴雨满春城，万里羁人苦晚行。山绕寒烟昏树影，滩撐危石咽江声。萤飞草岸星疏落，犬吠花村月半明。暂困泥涂何所辱？为霖志在济苍生。

# 梦后有感
原：梦里还家觉竟虚，悲欢交集泪沾裾。无情最是衡阳雁，不自云天寄纸书。

# 镇山楼远眺
原：登临行远几悲秋，大好湖山百尺楼。江上碧波吞落日，村边红树系归舟。墓门草短哀齐女，井里槐高慕子游。怕向彩云深处望，西南半壁杞天忧。

# 破山寺
原：寒云古寺说南朝，金粉飘零劫未消。远树朝笼山涧雾，大江秋涨海门潮。栖云鸟静闻僧磬，咽露蛩吟答市箫。记取当年龙斗处，春雷隐隐雨萧萧。

# 东瀛道中
原：直挂云帆赋远游，东瀛奇景豁双眸。山苍有骨横秋老，海碧无情亘古流。怒浪掀天驰万马，阴霾匝地斗群虬。太平洋岸风潮急，孰起陆沉四百州？

# 虎丘
原：海涌峰头立马呼，剑池失色憨泉枯。虎丘宝气销沉尽，孰起吴王问霸图？

# 冬夜围炉
原：钧天胡此醉？漫空云爱叇。迟日淡无光，朔风送寒气。暮泊石门湾，烟树昏无既。积雪埋远山，寒江起微济。扁舟夜围炉，醉言足清味。谈兵鬼神哭，拭剑蛟龙畏。慨我生不辰，忧国心如沸。客星据帝座，腥膻非我类。陆沉神州裂，天骄白种贵。欲寒西贼胆，军无韩太尉。欲会孟津师，野遗姜钓渭。东海泣鱼枯，南山隐豹蔚。忍为汗漫游，登高每歔欷。凭栏发冲冠，拔刀须如蝟。更深眠不得，狂歌聊自慰。

# 嘉兴阻雪
原：满天风雪阻轻航，信宿嘉兴客怅长。千里云山征雁杳，万象烟树晚鸦藏。谢庭柳絮娇无力，王店梅花冷愈香。怪底钧天胡此醉，阴云久合闭朝阳。

# 读史感赋
原：奸雄治世亦能臣，负我毋宁我负人。统一功成司马帝，石缄金匮有传薪。
原：自负雄才特忌才，桓邵边让赵彦孔融许攸娄圭崔琰。祢衡死匪由江夏，鹦鹉洲前草变衰。
原：承资跋扈行凶忒，鹰犬居然被虎文。爵赏由心刑在口，摸金发冢半将军。
原：闻雷箸失刘玄德，避地榻穿管幼安。天下英雄恶凶狡，人中鸾凤远贪残。
原：檄医头疾陈琳辈，翻作美新莽大夫。走狗飞鹰游荡子，居然受禅应当涂。
原：冬春射猎夏秋书，岩穴知名士不如。归去谯东精舍在，胡于逃赏叹申胥。
原：南飞乌鹊怅无枝，未静江湖亦自疑。狐媚奚能取天下？欺人寡妇与孤儿。
原：拒狼进虎岂良谟？亡国图存犹大夫。云扰中原追祸始，渡湟入塞许羌胡。
原：欢娱苦短忧愁多，旁眺八维奈老何？岁在大梁天亦醉，犁牛似虎莠如禾。
原：踞吾炉上骂孙权，虎视龙骧亦可怜。岂被夏侯盲语误，翻含遗恨到重泉。
原：建始承明起洛阳，梨根血出恨非祥。将军墓道休题汉，至德周文谥武皇。
原：威武能骄富贵淫，冢中枯骨亦天神。预争皇后怜诸妇，终作分香卖履人。
原：晋臣秽史尚贻讥，直道斯民有是非。妻妾难传心事遍，知心况只一青衣。
原：夺取人妻为子妇，然萁煮豆种前因。石磨公干犹平视，枕荐陈思竟感甄。
原：横槊赋诗一世雄，二乔未虏恨东风。而今立马西陵望，铜雀台荒穗帐空。
原：作伪心劳死不瞑，水汹崖黯漆灯青。漳滨七二皆疑冢，暮雨秋磷草亦腥。
原：休争正统与偏安，国贼曹操论不刊。衮冕彤弓膺九锡，空贻尘谤沐猴冠。
原：降幡纵出石城隈，霸气西南尚未衰。梁甫吟成身许国，卧龙十倍子桓才。
