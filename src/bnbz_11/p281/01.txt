# 瘦坡诗选
原：方廷楷字瘦坡，安徽太平人。今录诗十五首。

# 寄寄尘
原：湖山意气归词苑，兄弟文章入选楼。千里订交悭一面，徒从纸上识荆州。
原：我已十年甘隐遁，君犹千里事遨游。桃潭水与赋溪水，余家赋溪与君家桃花潭一水相通。何日相携共泛舟。

# 贈孙悠斋先生
原：焚琴煮鹤矜心计，吉网罗钳逞诡谋。我数古来忠义士，不遭人害是庸流。
原：经济文章第一流，闻名几度欲依投。相望百里未相识，惭说交游遍九州。

# 年来
原：百宝栏中歌短曲，沉香亭畔制新诗。年来亦有飘零感，灯下重题十美词。

# 感春航事寄亚子
原：飘零一例老江乡，忍作寻常歌舞场。难得多情柳亚子，苦挥热泪说冯郎。

# 题亚子《陆郎曲》
原：新诗一曲沥心肝，苦劝歌坛换杏坛。绝胜当时袁简老，只知泪别陆才官。

# 题郭频伽手写徐江庵遗诗
原：徐诗郭字重兼金，一卷君谟燕市寻。此书社友蔡寒琼君得于燕市。流转百年终出世，神州光怪岂销沉。社长柳亚子君正谋费刊行。

# 题《蜕庵集》
原：蜕庵一集足千秋，万丈光芒笔底收。海内共传狂与侠，谁知此老亦风流？

# 重过南园访肖黄山长
原：半年两度过山庄，小小园林足徜徉。笑语主人花事换，牡丹开后芰荷香。
