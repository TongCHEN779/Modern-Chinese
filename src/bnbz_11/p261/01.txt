# 天梅诗选
原：高旭字天梅，江苏金山人。今录诗四十三首。

# 五月十九日和巢南韵即寄越中
原：鬼哭天愁冷雨斜，黄龙晋酒恨徒赊。伤心法物飘零尽，闲向天南吊落花。
原：痛拉巫咸招帝魂，黄炎一脉要图存。会稽霸气今何似？回首凄凉怅国门。
原：相将干死蠹鱼腹，何日天骄会剪除？枉说儒生关国运，几曾仗剑为先驱？

# 送巢南之粤
原：君自言愁我亦愁，奇情历历荡难收。未除北虏千年恨，又割西泠一段秋。画里关山新杜宇，客中香雪旧罗浮。城南酒伴应相忆，料得斜阳倦倚楼。

# 自题《花前说剑图》
原：提三尺剑可灭虏，栽十万花堪一顾。人生如此差足奇，真风流亦真雄武。男儿不作可怜虫，唾壶敲缺光焰红。图中人兮别怀抱，花魂剑魄时相从。要离死去侠风歇，一杯酒洒冢中骨。青衫红粉两无聊，指掌高谭古荆聂。东风浩荡催花开，红颜从古解怜才。誓洗清谈名士习，顿生迟暮美人哀。美人应比花常好，万紫千红天不老。一室犹秋孤剑鸣，四海皆春群花笑。月明吹彻玉箫声，锦绣湖山大有情。前拥貔貅后莺燕，长驱漠北索虏平。手中之铁心中血，以斗浇之恨难灭。海风著意吹不凉，冷铁千秋化成热。天生我才竟何用？匣里光芒雪华冻。时至终酬知己恩，数奇枉作封侯梦。封侯梦醒泪长流，闲看鸳鸯绣并头。金闺国士知多少，寂寞鱼龙江海秋。人间冷落好匕首，心肝争向路人呕。爱国无妨兼爱花，屠龙不成盍屠狗。愤来拔剑肝胆粗，银屏画烛歌鸣鸣。可怜马上杀贼手，题写《花前说剑图》。

# 读实丹所作《棠隐小传》
原：回首当年事更非，海棠消瘦牡丹肥。秋魂飘泊招难得，愿化墙东蛱蝶飞。
原：渠侬侠骨果崚嶒，别凤离鸾恨不胜。敲碎珊瑚歌一阕，四条弦上泪如冰。

# 赠沈孝则
原：诗笔高华忆右丞，秋风病骨料难胜。小旗亭畔人如玉，黄叶题诗感不禁。
原：天涯冰雪奈愁何？贮息停消隔绛河。惆怅佳人留片影，愿将心事托微波。

# 怀实丹白门
原：滚滚长江彻底浑，天涯谁与替温存？晓风残月新诗本，浊酒高楼旧泪痕。铁马嘶惊杨柳梦，杜鹃啼断海棠魂。不堪再读悲秋集，黄叶萧疏冷闭门。

# 怀巢南武林
原：最是消魂黯淡天，诉将往事恨绵绵。可怜慷慨多无补，渐觉萧条近暮年。雨后残花羞照影，秋深疏柳怕成烟。知音尚有西湖长，每一相思辄惘然。

# 怀蜕庵长沙
原：采霞片片忽飞来，击节沉吟把卷开。为问梅村几知己，恰逢同甫是仙才。题成说剑三生感，咏到听秋七字哀。一寸灵犀暗惆怅，北风天末正徘徊。

# 怀红冰当湖
原：索居浇酒意茫然，痛读《离骚》廿五篇。事已沧桑谁与说？文经忧患始能传。高吟采石大江水，阔别梅花小雪天。料识美人怨遥夜，一声哀雁落筝弦。

# 怀亚子海上
原：所思不见夕阳深，万绪千愁怅独寻。世变要除名士气，岁寒应识故人心。百篇深恐飘金粉，孤愤终看碎玉琴。患难订交须护惜，四条弦上证微音。

# 怀太一北京
原：京洛尘污未可论，文章屈宋与招魂。生犹同世未寥寂，别已经年梦痕。道义交深肝胆进，党人碑倒姓名尊。漫漫长夜何时旦？扣角羞过将相门。

# 怀朴人海上
原：谁肯荒江伴钓竿？一书犹自问平安。无情红树催人老，有味青灯逼岁寒。亡国可能天外住？痴怀聊向画中看。怜侬未历黄山胜，吮笔题诗一字难。

# 怀道一嘉兴
原：一弹指顷去来今，回忆前尘尚可寻。党锢例于衰世见，道根偏自静中深。神州残局伤心史，夜雨空山抱膝吟。愿伴鸳鸯湖上住，联床把酒话冬心。

# 壬子旧除夕感赋
原：老大伤怀却为谁？不关谣诼到娥眉。万千壮志归淘浪，三十封侯已过期。直以大儿呼北海，拟将高隐载西施。只怜浩荡无归处，赢得秋风两鬓丝。

# 癸丑元旦
原：新朝甲子旧神州，老子心期算略酬。摇笔动关天下计，倾樽长抱古人忧。剧怜肝胆存屠狗，失笑衣冠尽沐猴。满地江湖容放浪，明朝持钓弄扁舟。

# 偕海印上人、顾九一、李经舆游十刹海，车中偶成
原：一种心期未可传，长堤浅草整归鞭。芙蓉开落人如梦，杨柳萧疏月化烟。十刹幻成无量海，众香围住有情天。人间聚散原无定，他日思量定惘然。

# 苦问一首寄亚君
原：宣南门外柳如丝，客子思家莫怨迟。志士不忘在沟壑，佳人自古解声诗。调莺曲院秋双鬓，跨马雄关酒一卮。苦问行程须记取，桂香花里我归时。

# 次韵答太一狱中见枉之作
原：篋中血泪燕游草，今日何堪持赠君？狐兔纵横天鬼啸，此生端合绝人群。

# 次太一武昌狱中作韵
原：沿江烽火为谁忙？张角称兵犯建康。南北岂真天作堑，英雄不合酒为乡。裹尸马革怀宗国，被妒蛾眉怨夕阳。白纻歌中声变徵，不堪肠断此啼妆。

# 重九南社雅集沪江，席上赋此
原：良燕今番却怅神，坠欢重拾渺如尘。铜琵乐府声犹壮，金粉斜阳迹又陈。招隐秋深吟桂树，论文海上证兰因。不须更觅登高处，已觉风光恼煞人。
原：新知旧雨一时兼，无限心情到笔尖。小雅诗人工怨悱，大千世界要庄严。香销豆蔻狂名减，秋老芙蓉客思添。惆怅交游应刘感，死生疑信信迟淹。

# 檗子以诗见怀，次韵答之
原：读曲风流愧不如，落梅将尽杏花初。君才肯让云间陆？臣美原输城北徐。为解声诗心独苦，但工饮啖计殊疏。只怜累屈愁无那，日暮空山赋卜居。

# 闻成琢如来沪赋寄
原：灯下无端忆旧游，两都赋就泪横流。君近著南北京赋。工愁词客生花笔，对酒春风小李楼。曾同饮小李纱帽胡同。法界华严笑弹指，欢场弦索怕回头。江湖放浪浑闲事，不合生才似此休。

# 哭张伯纯先生
原：夷吾江左再来身，国士无双入幕频。同乡曾、左诸人许为国士无双。麻木风痹究何世？勤劳忠实要斯人。联吟明月梅花梦，每得一诗，必寄其配君索和。交谊空山杜若春。不信老成遽凋谢，摩挲遗墨泪沾巾。
原：卓绝东南天放楼，自号天放楼主。抗怀稷契尽堪俦。自饶儒者千秋业，不屑人间万户侯。有以苏督相属者，君一笑去之。欧九表阡新纪念，哲嗣昭汉为撰行略。孟光举案旧风流。君尝云：“幸妻如孟光，可与适道。”入秋风雨凄凉甚，国瘁人亡满眼愁。
原：犁庭夙抱感精灵，民军起义，君屡屡条画方略。赢得他年照汗青。贾傅多才难救国，伏生有女始传经。谓默君女士。欲从天上依南斗，忽叹湘中落大星。转痛酒徒空后死，悄磨宝剑带龙腥。
原：撒手人天志不灰，龙颠虎倒莽尘埃。一朝水火玄黄血，百劫河山操莽才。我自临风歌当哭，公应骑日去还来。即今丧乱真难料，感逝伤时倍可哀。
