# 吹万诗选
原：高燮字吹万，江苏金山人。今录诗二十六首。

# 己酉九日
原：如此新亭空对泣，不堪旧绪怕登高。荒村寂寞逢佳节，落叶凄迷诵楚骚。看菊故应呼酒饮，哀时宁得借诗逃？闭门我愿无闻睹，风雨何当夜似涛。

# 己酉秋结寒隐社，作诗述意
原：人海丛中怅独行，不成避世转愁生。暂凭寤寐留清梦，聊托音声寄远情。窗下晚风闻病蟀，草间凉月见残萤。年年寂寞吾能惯，忍把浮名与俗争？
原：芳草斜阳剧可哀，全荒兰蕙长蒿莱。经秋文字丝丝泪，人2世心肝寸寸灰。只觉愁多窥古镜，不妨情重伺妆台。商量欲辟东篱地，更觅黄花烂漫栽。
原：出门惘惘欲何之？谁赠心香慰所思？身外烟云殊未定，眼中人物竟如斯。霜寒三匝乌飞急，木落千山雁到迟。却爱今宵风月好，荒唐第一莫谈时。
原：说着论诗道已微，相思绵渺故人稀。风飘坠叶甘侵帽，尘起污人欲浣衣。林密山深心独往，天回地转愿终违。鸣条解与梧桐语，为报今年秋更非。

# 庚戌元旦偶成
原：椒花颂里试微吟，暂屏诗书思不禁。只觉苦闲殊寂寂，未须中酒亦沉沉。频年寤寐忧天压，厌世肝肠与岁深。坐对一行寒雁过，江山绵渺起商音。

# 陈君巢南、柳君亚子来简，均劝余刊印拙集，答之以诗
原：辛苦雕肝计总差，不祥文字未宜夸。感君盛意怜桑蠖，愧我微吟似井蛙。落笔徒教存废什，工愁谁说是名家。寸心得失真虚语，传到千秋事尚赊。

# 送钝剑之武林，兼赠石子
原：此去吟诗定未休，莫凭胜地便言愁。南屏荒冢知谁问？西泠新阡不可求。潭静月明天在水，堤空风起树成秋。圣湖我是曾来惯，今夜随君一梦游。

# 柬曼殊大师并乞画《寒隐图》
原：曼殊大师耽禅癖，画法精能巨然敌。昔年寸箑赐丹青，箧底珍藏如拱璧。一别申江消息稀，芒鞋破钵远皈依。祗园鹫岭搜求遍，佛国归来香满衣。众生未度添悲哽，原来我佛皆平等。百万华黎孰噢咻，海邦掌教兼摩顶。如此神州夕照寒，袈裟拭泪向空弹。有时写出悲荒意，拨墨离披不忍看。愧余未解画中境，荡胸灵气成云并。趺坐无言镇日闲，秋光忽幻蒹葭影。残山剩水莽榛芜，天末怀人不可呼。聊寄缣缃盈尺幅，愿言偕隐是吾徒。凭君妙笔生奇趣，料知不吝挥毫素。返视红尘清梦遥，相将携手图中去。

# 寄实丹金陵
原：述阳却曲我行迟，世网重重孰主持？别有情怀非好隐，百无聊赖遂能诗。参来佛性当如是，淡到名心他可知。谁识杜陵哀乐意？万方一概欲何之？

# 题蔡哲夫所绘沈孝则《冰雪庐图》，即步哲夫韵
原：虱我其间良非夫，独行不与世争驱。雀罗可设门无车，寻梅索句未跨驴。嗟哉蚌病乃生珠，诗渐可读消雄图。寂然吾亦爱吾庐，相与鱼鸟忘江湖。别耽冷癖天下无，人嗤待兔徒守株。块独无闷心安舒，若有人兮俟城隅。洁清不数臞仙臞，谁知闻声有彼姝。怀抱竟不与我殊，心香一掬堪相娱。几时握手其乐且，天涯消息今何如？千里慕悦形神俱，恍似一室饮屠苏。从今吾道始不孤，山深林密足隐居。已而愿言从接舆，时衰俗薄甘遁虚。俯仰炎浊胡为乎？谁绘此图意有。雪窗展玩一轩渠，冰心映入白玉壶。偕隐会向图中趋，饮冰齧雪休自袴。

# 石子抄《幽梦影》一通，余既为弁语，并系以诗
原：一编奇趣盎然留，造化精微笔底收。具至性情能感动，是真道学总风流。肯令花月闲中过，爱向人天冷处游。多少腐儒齐咋舌，愿君珍重莫轻投。此书语妙绝伦，不可方物，字字出人意表，而却字字人人意中。所以者其何？言曰：“情必近于痴而始真，才必兼乎趣而始化。”嘻，尽之矣！吹万赘记。

# 题《变雅楼三十年诗征》
原：深夜无人灯似粟，雨声淅沥戛寒玉。案头忽起光作作，五色灿烂天能烛。借问何物动瞻瞩？中有精气森芒角。诗城浩大谁所筑？按兵待之那可蹴？欲攻未攻又瑟缩，迷茫万象难更仆。纷陈光怪离以绿，世界开辟此变局。近三十年一结束，郑声雅乐并追逐。以伪乱真恣惶惑，何人辨析荡清廓？奇蛇巨虯兼收蓄，千流万派同归宿。拣得明珠三百斛，不容一二混鱼目。功在艺林权在握，胸中斗血常漉漉。我读此选不敢熟，世乱亟矣败亡续。大横百怪相吞伏，四夷交侵辱莫辱，诗人忧国歌当哭。开卷忍痛更三复，若有戈矛撑我腹。狂风窗外震林木，一笑且饮杯中碌。

# 吊陈蜕庵
原：如此天涯酒共斟，鬓丝憔悴费沉吟。江湖拓笔高节，风雨论交见素心。诗思苦随羁病进，愁怀沁入落花深。元龙豪气销磨尽，竟谢风尘泪不禁。君以去年来海上，遂以客死。
原：当年久振春秋笔，君曾主持《苏报》，首倡民族主义。文字收功著定评。张俭破家犹有止，介推死隐竟无名。策勋昔等羊头烂，谋利今同狗骨争。谁似先生无我相？萧然穷老若忘情。
原：布笠青鞋何所投？凄凉身世梦悠悠。高文宛在名终显，奇痛偏尝报未酬。君曾以革命事，父子同系狱者经年。有女才华能咏絮，君令媛撷芬女史早以文学蜚声。无家飘泊类浮沤。沪云望断灵先圮，空奠苍茫酒一瓯。

# 吊周烈士实丹
原：南都握手甫经年，蓦地惊闻恶耗传。遗札尘封盈半箧，时时相对一潸然。
原：男儿已分沙场死，用烈士句。讵料横罹惨毒深。赖有孟公持大义，指陈英士君。不然冤狱久销沉。
原：难得书生举义旗，巍峨行见矗丰碑。他年若过淮阴道，第一先瞻双烈祠。南社诸人近为烈士暨阮烈士梦桃请建专祠，以崇报称。
原：杀人不死法何存？刑律能平人道尊。民贼今犹稽显戮，九原那得慰忠魂？

# 怀柳亚子
原：沧海尚漫漫，狂歌且自宽。群龙无首吉，一鹤独鸣难。阅世多新感，论文记旧欢。暮云看万叠，猛想偶凭阑。

# 闻苏曼殊归国，奉柬一首
原：一别东坡今五载，相思应念我如何。住心常觉众生苦，冷眼犹嫌热泪多。奴子未容悉平等，天堂变相即修罗。茫茫十丈红尘底，欢乐声中但寤歌。

# 索黄滨虹治印，先寄以诗
原：人生何者足可耻？穷年读书不识字。邕冰已远书契湮，书籍往往混真伪。是谁博考鉴别精？字体源流知所自。因之上溯秦汉遥，典坟丘索得穷治。泽古既厚方奏刀，刻划一一具深思。至诚凝固腠理微，承蜩解牛本一致。黄子静者吾所师，郑虔三绝人共知。图成寒隐昔相赠，明窗相对情为移。旁及摹印尤入妙，蜗匾篆刻盘神螭。抱残守缺不求赏，落落自挹荪荃姿。徘徊抚鉴有味，古情郁结念在兹。或言玩物足丧志，腐儒见解真堪嗤。我亦粗知事书史，故纸堆中闷欲死。望古沉沉浩劫灰，搜残蠹简皆无是。聿稽文字创造初，差见微言与奥旨。可知大义一线传，金石之中具鸿秘。遗闻万古蕴不宣，寥落龟寿四千祀。当世能文识字人，眼中我见滨虹子。吁嗟假学何其多，数典忘祖圣所呵。原本训诂不可磨，妄云大义非由他。乃以空论相操戈，儒林道学遂分科。以谬袭谬讹传讹，仓斯地下应滂沱。我持此论良非苛，安得篆杰挽颓波？一反积习无偏颇。愿携顽石烦切嗟，行当一日三摩挲。

# 题姚石子所得明遗民傅青主画山水尺页
原：纸上发光怪，黝然见古春。只此尺幅间，云气郁纷纶。若非富丘壑，状写安能真？至今三百年，拂素陈复陈。姚生好事者，爱好比奇珍。终日坐相对，倾倒明遗民。索我题一言，温温肺腑亲。我亦有同癖，感慨多缘因。缅想下笔时，天地皆胡尘。河山非我有，拨墨泪酸辛。兹逢庆再造，作者应含颦。吉光与片羽，万古留精神。

# 闻曼殊将重译《茶花女遗事》，集定公句，成两绝寄之
原：震旦狂禅沸不支，本无一字是吾师。天花岂用灵幡护？下笔情深不自持。
原：回肠荡气感精灵，肯向渠依侧耳听？今日不挥闲涕泪，茶花凝夜吐芳馨。
