# 醉庵诗选
原：龚尔位字醉庵，湖南湘乡人。今录诗十三首。

# 已酉三月送春麓山作
原：春来若有踪，春去原无迹。年年相送迎，一如远行客。人生亦复尔，奚事重叹惜？扰攘尘世间，徒然为形役。荣辱乱其心，悲欢夺其魄。穷年而不已，鬓发忽焉白。一朝委泥土，俯仰竟何获？以此达观者，视之如朝夕。悠悠南山云，去来常自适。浃旬苦风雨，闭户不知春。今日送春去，春亦为酸辛。众绿惨无言，百花娇欲颦。泉鸣深涧里，相应发哀呻。隔江有高士，脱然世外身。提壶沽美酒，来我古渡滨。相携登绝献，饯此艳阳辰。谱以相思字，泼墨留天真。尽日看不足，一卷藏其神。归来开樽饮，千钟未辞贫。谈笑小宇宙，拟为葛天民。

# 闻韩事有感，和钝根韵
原：仲连去后英风息，无复衣冠见汉家。一片降幡沧海静，千年碧血夕阳斜。鹤归应起山河感，狐死空传鬓发华。来日潮流愈澎湃，怕看大地走兵车。

# 春兴
原：平芜芳草正萋萋，隔岸垂杨已拂堤。好趁新晴乘健马，百花丛里听莺啼。

# 古意二首
原：秋月何娟娟，照人窗与户。秋虫何唧唧，终夜自劳苦。唧唧可奈何，娟娟照今古。
原：烈士忘死生，光阴分冷暖。人匪生而知，安得事疏懒？穷达何足云？聊复惜日短。

# 开岁述怀，用渊明《游斜川》韵，示钝公
原：日月转轮至，天行无时休。良辰动众欢，驱车恣遨游。矧予独何人，而不与同流。顾彼百年内，飘忽若浮鸥。随遇已云安，岂必寻丹丘？岁新人惟旧，抗言多良俦。嘉会难常得，既饮还唱酬。他事非所期，但知有酒不。饥寒纵我驱，未足增烦忧。苟为热中者，何妨执鞭求？

# 钝公既和余开岁感怀诗，复次韵答之
原：柔肠百转煎忧患，可奈敲残腊鼓声。吾道欲穷终凤隐，斯人不出怪雷鸣。春归大地胡尘满，马立吴山剑气横。毕竟兴亡谁负责？匹夫似我亦多情。

# 己酉九日麓山待钝庵不至，书寄，用渊明《九日闲居》韵
原：昏人累尘想，服食不长生。渊明卧丛菊，欲隐偏留名。吾亦爱丘山，寸心未能明。清商发林际，飒飒动秋声。哀彼涧边草，莫抵孤松龄。伊人隔秋水，浊醪期共倾。呼僮扫萝径，脱然忘枯荣。日夕而不至，焦桐起离情。世事岂其然，嘉会多难成。

# 情诗，次钝庵韵
原：依依堂前柳，莹莹窗下雪。记得初相逢，两情明如月。幽欢未终极，不谓远离别。彼美无还期，念此郁难说。折柳著相思，对雪怀高洁。悠悠阻风波，转欲妒鹣鲽。览镜长太息，回尽中肠血。欲济河无梁，会将成永诀。永诀可奈何？孤影随幽屎。终夜不能寐，忧思同胶结。
