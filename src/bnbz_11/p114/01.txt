# 萝庵诗选
原：郑泽字叔容，湖南长沙人。今录诗三十九首。

# 杂诗五首答钝庵
原：晚蝉鸣高林，络纬啼庭树。百虫竞炎候，繁响彻昏曙。霜露何凄清，荡子恒宵征。修名惧不立，前路徒冥冥。冥冥复奚慕，春荣秋已零。万物更变幻，至道无虚盈。荆棘弥道周，阴霾蔽天地。借问湘累子，魂往将安寄？猿啾狖夜鸣，寤歌悲独寐。清筝不终弹，旨酒未能醉。我心怀隐忧，世路多歧异。芜城偶行游，莓苔滑人屐。会当凌风飞，日月任淹逝。
原：高楼有思妇，所思在远道。道远不可致，幽思令人老。凭楼望湘江，江波漫皓皓。芙蓉媚幽渚，芳菲散清晓。采之赠远人，窅然丧尘扰。结想在冥漠，精神自环绕。终伤然疑作，翩来阻行潦。
原：胡风吹沙碛，猎猎翳千里。郊野澹斜晖，权火忽宵起。君子远于役，空房泪如泚。迢迢河汉星，耿耿轩窗里。新婚冀永欢，遽罢鸳文绮。不念多乖离，但伤乱未已。增此灵修怨，孤芳泛兰茝。
原：结庐金花巅，幽室聊延伫。灵气郁青苍，白云在庭户。烟敛朝晖升，帘动松风度。翠筱喧寒泉，紫芝溉晨露。象罔得真诠，岩扃守元素。良友时经过，啸吟慰迟暮。大化有推迁，神人自来去。

# 登楼叹
原：按剑登高楼，望远纾烦忧。高楼不可登，忽忽烦忧增。凭栏望东方，东方何茫茫。不见若木娇榑桑，但见虾蟹变作长鲸长。嘘将洪涛巨浪空冥翔，令我望望心惊伤。凭栏望北极，北极何屹屹。胡沙惊飞眯我目，胡风觱发寒我臆。猰偷狰狞道旁立，千夫万夫齐辟易，令我望望心胆栗。凭栏望南溟，南溟何冥冥。飓风呼呼天地惊，海若荡魄珠崖崩。毒泷恶雾纷相乘，令我望望心惺惺。凭栏望西域，西域何局局。天山南北履如阈，葡萄空向汉宫植。更有老僧清净忘尘物，今也困若台城佛，令我望望心欲哭。噫吁嘻，高楼不可登。噫吁嘻，登高楼兮烦忧增。何当淬我湛卢剑，乘风涛兮斩长鲸，绝大幕兮驱猰偷之狰狞。一挥定西域，再挥安南溟。使我登楼远望心怀清，东西南北夷以平。

# 夏夜作一首
原：霁夕天气清，凉雨散热。露华沾人衣，闲庭粲星月。开轩聊容与，境适神超越。尘虑倏已寂，物役如可绝。烦暑不我蒸，灵宫自澄澈。慕彼逍遥游，庄义洞幽赜。

# 晚眺，次钝根韵
原：澹澹远村烟，菀菀前溪林。鳞鳞夕云景，依依归鸟心。郊坰倏将暝，凉鬓风露侵。端居惜幽胜，单袷事追寻。湖山虽信美，暮色忽已深。谅无鲁阳贤，回戈非所任。众星争光辉，微月照我襟。览物增悲思，安暇计升沉。

# 夏日感兴，次钝根韵，即以奉寄
原：朱华媚瑶沼，微风芬以清。炎羲正埃郁，池馆远烦蒸。闲居成独静，逸响舒高情。惧兹南音寂，时作天籁鸣。园葵湛晨露，林日翳圆晶。帝天信仁慈，锡我溪山青。乘暇且徘徊，欢侣壶觞倾。毋唯事尘劳，歧路徒营营。
原：大楚雄南服，势勒秦与齐。披荆羡熊绎，竿路翩来栖。如何时代迁，坐令蔡速飞。接子知已而，三户不可追。予心惮隆暑，念此将谁嗤？
原：圣智日栖栖，沮溺讵自外。托命唯长镵，田歌发清籁。炎威催稻熟，亭午花争晒。但得仓箱盈，子弟或多赖。齐封惧东亩，亦可惩骄泰。耕莘有其时，之垄何须喟？
原：物类非可齐，穷达异所任。予情信芳菲，啸歌怀苦心。搴芬幽涧曲，取荫乔松林。伊人在天末，参差流远音。屏居爱新什，吟管纷如森。愿偕采三秀，由来本同岑。

# 答钝根诗二首
原：盛夏宜林泉，幽居菱清景。之子归章龙，樵斤碧云隐。余家金华麓，徂暑悲分影。炎嚣信两忘，但惜长途梗。未别早知愁，临歧预超引。瑶篇因风来，增人中夜耿。
原：诗亡叹迹熄，雅废来夷侵。求声遍空谷，相彼嘤鸣禽。春明见颜色，不异双南金。论诗已爽然，况识江海心。达人贵特立，清响绵南音。芳情唱予和，千载讵侵寻。迹远神匪遥，湘波泛微吟。

# 《嘤求草》题词
原：庭桂露华滋，虚寮素辉上。新诗偶披诵，中夜襟怀爽。秋士每多悲，憭栗动哀响。魏晋纵辽远，高咏蹑畴曩。幽谷嘤鸣清，大汉天声莽。枪榆我自嗤，海运君怀敞。聆兹下问及，未作孤芳赏。皋兰散芬菲，纫佩崇心尚。

# 赠钝根游海上
原：长帆翼金风，驾言拾海月。懿兹南溟徙，倾酿送将别。伊余性幽窈，篇什相朋俦。新知正多乐，远道重增愁。海上丛奇英，兹游讵寥寂。眷言湘滨人，奚慰苦吟戚？芙蓉初作华，梁燕行将归。归期准如燕，颜色当华滋。征途多风尘，倘惜青衫袖。海绿摇空冥，时因传尺素。临歧且徘徊，短歌犹琼瑶。乘桴虽适愿，聊舒痛脰劳。

# 七夕赴城
原：灵夕征期戒，新凉别思宜。天人殊聚散，魂梦与追随。从来笑牛女，今夜转相嗤。嫁钱能十万，桃实讵千年。自昔悲尘世，由来有上仙。武丁亦多事，输与恨缠绵。

# 偶作
原：心如顽石未能神，底事人间有众因。自挟坚诚轻毁誉，间从儿戏守元真。湖山偶著形骸我，贫贱教成澹雅身。敢谓生来能怪特，何劳邑犬吠狺狺？

# 长沙谒烈士祠
原：灵雨飘东风，祠堂载瞻仰。花纸依帘垂，松针逼檐上。篆兹新龙香，拂彼旧蛛网。绿钱罢幽径，华采辉吾党。仿佛从文狸，英灵尽来往。士女纷如云，纵览逾畴曩。致礼雍复穆，陈词慨以慷。歌声飞楚云，恻侧成悲响。感此凄肺肝，雄心增飒爽。讵唯百世兴，浩气凌苍莽。季叶绵哀荣，羞彼众生罔。会见兰宇旁，猗猗竹林长。

# 短歌行
原：青青湘岸柳，飞絮湘江里。江里蔚蘋花，浮沉漫相倚。相倚未崇朝，各泛东流水。流水无时休，蘋絮无时已。无已其如何？愿作红莲蕊。莲蕊根玲珑，弥弥蔓中沚。中沚风波恶，荡此清香起。香起增高华，双情堪乐只。

# 暮秋见雪
原：南中地气暖，初冬未重衣。今兹方暮秋，寒霏霏微。猎猎朔风遒，嗷嗷中泽啼。胡笳正悲壮，东菑叹年饥。如何人事迁，天时与推移。清夜怀无温，闭门聊息机。

# 横塘
原：重向横塘驻玉鞍，更无人倚赤阑干。翠尘凄涴帘烟静，蛛网愁萦镜月寒。江渚琵琶音已断，秦楼箫凤去无端。曾知旧日隋堤柳，怨线愁丝一例残。

# 秋日书怀
原：紫塞萧条画角鸣，寒衾倍觉梦魂惊。怕因落魄居人后，竟把佣书误我生。投笔追怀班定远，哀时谁似庾兰成？请君试上湘楼望，万一瑶空天气清。

# 无题
原：魂断江郎愁赋别，梦回杜牧暗伤春。记曾金管吹秋月，强解双蛾一笑颦。
原：金笺小叠讯朝霞，何处卢家更谢家？闲向赤阑桥上望，万丝春雨葬梨花。

# 有寄
原：昨夜春风归帝乡，杏花依约出东墙。与君同唱江南好，多恐檀槽未断肠。
原：牡丹亭下几曾过，偏向人前戏述多。解识君才同谢女，可能拈管咏湘娥？

# 壬子秋日，钝庵尊翁润荄先生来城，泽与痴萍、醉庵、梦蘧、葵生、钝庵侍饮义园，钝庵邀摄影象，作诗奉呈
原：煌煌丘与索，渊粹惟耆旧。先生守遗经，清风澹儒素。悲哉余小子，英年茕在疚。出门怅何之，尘埃污衣袖。学殖坐荒落，恻恻楹书觏。自与贤嗣游，私淑获益厚。尚有老成人，岿存浇薄候。追陪揽秋色，群彦适邂逅。共餐秋菊英，且饮清凉酬。摄影纪盛游，或左亦或右。先生中不倚，聊作平原绣。文化纵迁递，先生长寿者。

# 题钝庵侍其尊翁摄影
原：秋芳庭闱，父坐子侍立。和恭重肃雍，天伦乐无极。

# 题画，钝庵属为觉子作
原：落花芳草影迷离，绣蝶蹁跹入画宜。为怕春光付流水，嫩寒间勒小乌丝。

# 佩忍初来长沙，游麓山返，夜与钝庵、梦蘧、痴萍、醉庵邀饮云泉，即席奉贈
原：浮江泛洞庭，扬灵戾湘州。吴楚共称雄，由来盟好修。高咏久冥契，新见犹旧俦。衡湘秋气清，识子翩来游。验彼骚经奇，探兹林壑幽。清夜游云泉，追随尽风流。灵均餐落英，燕席聊绸缪。长沙乃山国，古意涵悠悠。幽兰散芬芳，搴为空谷酬。

# 读钝庵《红薇感旧记》作一首
原：金风吹素节，阴曀幔层霄。侯兹雕与隼，奋翮抟扶摇。丛驱怆黄雀，枝借从鹪鹩。亦有冥冥鸿，背负秋昊高。言掠银汉过，载戾琼宫遥。琼宫闷仙子，颜若玉华娇。忘我中泽哀，袭此天香飘。乘风偶回顾，中心恒以忉。城郭异畴昔，原野何萧条。还与姮娥期，窅然丧尘劳。

# 壬寅春日谒屈子祠
原：绿湘无际向东流，一段忠魂尚此留。犀甲吴戈悲战国，女萝山鬼怨灵修。蘼芜仅得罗堂下，兰芷终难蔚楚州。手把琼芳闲礼拜，江城春雨更增愁。

# 侵晓自城还山
原：月斜星亚海天红，万户无声好梦浓。幸我回翔平旦气，还从山寺听晨钟。

# 山斋即景
原：为爱青山拓小窗，半帘松影静无庞。黄昏一阵廉纤雨，冷翠重重射玉缸。

# 病起
原：东风容易倩魂消，花里柔丝带蝶飘。最是恹恹人病起，杜鹃啼过赤阑桥。
原：嫩日晶莹曲槛边，暖风吹散药炉烟。道心了悟春心现，世界浑浑有万千。

# 春雨
原：楼外春寒透绿纱，楼中春恨人谁家？东皇亦有千行泪，洒遍人间桃李花。

# 桃花
原：嫩寒新上小桃花，笑倚东风意欲赊。莫问长干旧时事，半弯眉月印天涯。

# 杏花
原：绿杨烟雨罢溟濛，紫燕双飞掠碧空。闲策玉骢游暖昼，春风红到宋家东。
