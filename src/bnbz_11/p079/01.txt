# 西神文选
原：王蕴章字莼农，号西神，江苏无锡人。工诗文词，兼擅小说家言。丰采翩翩，有太原公子褐裘而来气象，文亦似之。今录文六首。

# 天香石砚室奕选序
原：钱子南亭辑《天香石砚室奕选》既成，邮书问序于余。余受而读之，曰：博哉钱子之用心也！夫奕谱之作众矣：曰《奕理指归》，黄河之水，探源星海，布局之扼要属之。曰《血泪篇》，钩心头角，花八持七，全局之制胜属之。曰《宫子谱》，手专杀活，目无全牛，收局之能事属之。今钱子斯集，多甄录于施范徐黄各名谱，与夫零纨断素，如仙机武库之不经见者，撷华存粹，蔚为大观。博哉钱子之用心也！复何藉余之一言以为重？虽然，余尝窃论夫奕之盛衰矣。奕盛莫于有清一代，而其衰也，亦于有清一代为最。极盛于施范，中衰于陈周。非施范能盛之，陈周能衰之也。施范生丁国家全盛之秋，民丰物阜，心无外骛。一枰黑白，若将终身，其以奕名世也固宜。降至陈周，世变稍稍亟矣。士或怀才不得一逞，则奔走为衣食计，手谈坐隐，事蓄之。有能与陈周敦槃玉帛狎主齐盟者，已视为登峰造极，而不可复进。若更责以施范之绝诣，则骇且走耳。其在陈周壮盛有为之日，宜若可一蹴几矣。达摩西去，无佛称尊。并世之士，顾已揭国手二字相推许，于是为陈周者，亦遂沾沾自喜，曰：“苟能是，是亦足矣。”此奕学之所以每下愈况。挽近以还，且并陈周视为广陵散也。抑余又闻日本人之治奕矣，争雄于坛坫，受成于天府，给廪以养之，设官以宠之，高髻广袖之效，遂有遗弃一世之务而为之者。论奕于今日，吾道东矣。一二翘秀岸异之士，乃嚣嚣然谓吾国无人焉，无人焉。甚且谓起陈周而与之角，亦在子碌碌之数。呜呼！奕学之不振，岂第世运隆污之所由分，抑亦国民强弱之所由判也！今得钱子是书，以为之先驱，镕万冶于一炉，续垂绝之绪，希踪施范，方驾东瀛，皆将于是乎在。花韵晴初，瓶笙月午，隐囊塵尾而外，清簟疏帘之侧，橘中其果有天地乎！余亦褰裳从钱子游矣。

# 然脂韵序
原：吾宗西樵有《然脂集》之选，为部四，为类六十四，为卷二百三十。其自序称历十五寒暑，始克就绪。时则繇皇古以迄当代，人则繇宫闺以迄风尘，文则繇风雅以迄杂著。虽考订未悉，不无谬，而按部就班，较为具体矣。书阙有间，《四库全书》仅采其例于诗文评中。观其条目，远出沈宛君《伊人思》、苏竹浦《胭脂玑》、邹流绮《红蕉集》、方夫人《宫闺诗史》、郦琥《彤管遗编》诸书之上。茫茫数百年，竟成绝响。尝有意续之而未逮。今春佣书于涵芬楼，楼中富藏书，戢香所及，不加诠次，断自清初，以迄近祀，断章零句录之，或无所表禄，而玉情瑶韵，蔚成佳话者，亦录之。传姓氏，志梗概，存什一于仟伯也。得若干家，共若干言，名曰《然脂韵》。非敢纂西樵之坠绪，聊以阐闺襜之馨逸耳。尝谓诗词之作，本乎性情，忽然而来，神与古会，空山无人，水流花放。臻斯境者，厥云上乘。女子之作，于金戈铁马之风，豪肉哀丝之奏，或稍稍漓矣。至若幽花媚春，子规叫血，赋景独绝，言愁已芜。班之香耶，宋之艳耶，美人香草，要为天地间必不可少之一境。梅月画窗，兰风入座，迷迭濯魄，银蒜约魂，鹦鸩怨其不芳，桐丝抚而寡韵。试展是编读之，余怀渺渺，其犹成连海上时乎！阏逢摄提格花生日，无锡王蕴章识于梅魂菊影室。

# 绿绮台传奇序
原：土司秦良玉，瑶女云亸娘，遥遥两女子，一黔一桂，奇气独钟。良玉事揭史册，弦管声歌。云亸娘顾鲜所称述。微独云郭娘，彼邝湛若者，非世所称嵚崎磊落之男子乎！上元忤令，只身走万山中。以无家张俭，作王粲依刘。蛮花笑客，莲幕倦游，举其抑塞悲愤之致，一发之于书。飞头勾漏，一《山海经》也；寨结相思，一《孙吴兵法》也；槃瓠禋祀，蝶绡凤裘，一《西京杂记》也。明季国事蜩螗，一二握政柄者，竞为门户之争，既视珠崖之弃为不足惜，更视遗贤在野而屏之惟恐稍后。遂使芦笙吹梦，仅传结队之天姬；铜柱铭勋，不数遁荒之畸逸。遭遇既殊，名之隐晦亦异焉。余览之而忽忽若有所感，秋灯坐雨，寒虫诉愁，日援笔为作长短句乐府，共得若干出。昔河东序《赤雅》曰“因病致妍”，余病于文，妍乎云尔！抑海雪堂中佳话，不可听其湮没而已。至于书斥怀宁，门完节义，一本于吴桐萼、鲍夕阳两家所纪载，读者勿因史阙有间，而疑余故曼衍其说也。甲寅七月七日，莼农识于梅魂菊影室。

# 菊影楼话堕自序
原：菊影梁姓，名兰。庚戌之春，薢菪于福裕里。淡妆绀袖，眉黛间隐隐有恨意。为诵“帘卷西风，人比黄花瘦”句，拥髻凄然，盈盈欲涕。因戏之曰：“兰为国香，当门而锄；如卿之风尘憔悴，独秀傲霜，殆东篱之逸韵，非三湘七泽间之小影也。”兰再拜受教。翌日，榜其楼曰“菊影”，且曰：“梅魂菊影，影事商量，羽先诏我矣。”余为之粲然。清谈既浃，樵苏不爨。怜红玉之前身，藏绿珠于内第。虽有成议，未遑践也。绿波春水，别绪连番。一过吴趋，再游白下。迨余乘骄海外，小劫归来，兰已命薄桃花，彩云飞去。一树马缨，遂等于华鬘天上。琼思瑶想，亦随君苗之砚而俱焚矣。顾双心一禄，独茧缫愁。追溯楼中一席话，有不忍付诸湮没者，存什一于千百，拉杂记之，颜曰《菊影楼话堕》。以有涯之生，作无谓之事，当夫花影窥帘，心香袅梦，望美人兮一方，思微波而谁托？明明如月，亭亭者魂，苟有擅鸿都术者，呼之乎或出。阏逢旃蒙人日，鹊脑词人书于海山仙龛。

# 十年说梦图自叙
原：削绢一尺，移山四围。泼眼成翠，游心入玄。危楼欲堕，扶以云气；虬松将飞，乃作龙怒。鹤梦自瘦，睇山鬼以何之？梅魂不肥，咏硕人其在寐。客有见而问曰：“杜陵茅屋，秋风破乎？玉谿无题，锦瑟托乎？何视天之梦梦，驱烟墨而无说也？”余曰：“唯唯，否否。仆之为是，固将以作无声之诗史，诉遥怨于灵修也。酒边说剑，自写其性情；劫外披图，不关夫风物。揆其旨趣，可得详焉。仆乾荫早倾，书城幸托。箧无昌黎之三书，怀灭祢生之半刺。乃有采以虚声，强居记室，系马大功坊底，寻秋小姑祠中。红莲参幕，时接胜流；青门种瓜，言逢故将。渌饮秦淮之水，都是愁痕；红烧钟阜之霞，全消王气。是曰觭梦，其说一也。三秋赋别，江淹因以销魂；九州可谈，邹衍从而立说。仆招隐无山，游仙有愿。荷衣蕙带，草木徒志夫南方；椰酒蛮花，竹枝曾赓乎西域。悬崖百仞而题句及之，骇浪千重而酬酒赋之。红鸳瓦冷，访荷兰之故宫；白足禅参，拜缅甸之金塔。鸿影犹雪，沤心自波。是曰客梦，其说二也。士贵知己，虞翻所以兴嗟；时不与我，冯唐叹其晚遇。仆择异荆栖，厄同杨闰。学贾则舞愧袖长，献策则主惮薪徙。遂乃送张俭于亡命，赋仲宣之登楼。归辽有鹤，吊铩羽之令威；望帝问鹃，泣低头之臣甫。感灵旗以告梦，死友谓何；思麈尾以招魂，生平已矣。是曰哀梦，其说三也。急难居闲，人所时有。蛾眉谣诼，或谓善淫。仆因肺腑之亲，遂有怀刑之惧。轻裘缓带，羊叔子或且鸩人；薏苡明珠，马将军不妨好货。蓬心自苦，看萋菲之成章；葵足难违，痛珠崖之尚在。障西风而终污，干春水以无端。臣质之死，匠石伤焉。是曰噩梦，其说四也。嗟乎！万感郁于轮困，百年惊其弹指。犬马之齿，忽过三旬；龙蛇之变，焉知来日。亦可谓将陨之泣，无假回波之吹；已断之肠，不烦命骚之写矣。抑仆于斯，重有说焉。昔王筠之集，不止一官；白傅之诗，亦分五本。而溯丛书于笠泽，雪纂为劳；拟酬和于西崑，风流未歇。珠非纪事，自成乙乙之穿；竹可篇年，聊引乌乌之唱。盖自庚戌岁为涵芬楼草创《小说月报》，中间离合不常，一为前马，再使续貂，聿至今兹，适届十稔。夫虞初九百，嗣响云遥；孔甲二十，杂家竞进。事不道于荐绅，贤或愈于博弈。而况青毡是吾家故物，白衣识吴下阿蒙。卖痴未尽，怜西华之单寒；衒嫁无媒，许东邻之颦笑。往往驿骑纷来，订神交于尺素；邪许相应，托微波于寸心。蠹食而求神仙，鸡鸣而思风雨。遂得因兹一说，慰彼四愁。尚留身外之身，更作梦中之梦。则斯图也，其诸飘风之箫，过时而在林；皱水之面，观河以自镜者乎！说梦命名，夫何间然？”余言未终，客弥而起。娥月窥景，如来笑人。寒飙振吟，若助叹息。援笔累欷，书之图耑。后有览者，其谓之何？戊午岁不尽三日，莼农王蕴章。

# 剑霜龛诗跋
原：秦子剑霜，殁三稔矣。黄垆时过，意邈于山河；玄文未镌，魂踦于泉壤。顾牵人事，卒未就也。今秋倪子恂生、徐子薇臣，复相与邮书睡诿，属竟椠绨，并为雠校。墓草已宿，墨痕未干。江郎才谢，犹留五色之花；李母哀深，长抚一囊之锦。故人手泽，良友心期，因付剞雕，兼任排比。起庚子讫甲辰为一卷，得诗凡若干首。时则春袍草妒，已饮香名；灵几檀成，俄霏艳采。感乡关之栖屑，十斛量愁；悲京洛之风尘，一升贮泪。又或菉蓝采去，芍药赠将，望美人兮一方，醉烟花于三月。未免郁青霞而为抱，托金错以言怀。凡所述作，悉付牢愁。又起乙巳上讫乙巳下为二卷，得诗复若干首。一声笛落，句必色飞；几处砧敲，思为情缚。盖其时方诸缘悉屏，一意于诗。镂心鸟迹之中，织辞鱼网之上。所谓积玉玄圃，莫非夜光；披金泥沙，乃胜祥冶者也。斯皆正集。别著外篇，都为《鸿影楼诗记》一卷，而以诗、祭文若干首，缀于其后。高柔玩妇，孙楚悼亡。闻屐响而莫寻，怅帘旌之易断。锦织龙梭之字，峡唳声声；丝抽雁柱之吟，羁愁叠叠。斯为情至，亦曰遇穷。奉倩因以神伤，武子览而陨涕。而君之诗亦止于此矣。嗟乎！无五百车欢喜之丸，情何能已？继卅六体鸳鸯之作，生也有涯。河梁之赠，方载于集中；玉谿之序，俄成于身后。昔黄两当谓洪北江曰：“余不幸早死，集经君定，必乖余之志趣矣。”情比曩贤，词惭荒翰，每一展卷，怆然不知涕之何从也。乙巳而后，君已疾作。虽鹤忘戒露，犹恋寒号；而蟫垂成矣，渐将字蚀。徐子薇生，乃复裒辑成编，为丙午补遗一卷，附于卷末。是又竟荀郎之后事，义薄云天；而传元相之遗文，感均今古者哉！
