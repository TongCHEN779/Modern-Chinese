# 寄尘诗选
原：胡怀琛字寄尘，余季弟。今录诗七十四首。

# 咏史
原：金粉楼台付劫灰，寻思往事有哀。贪欢梦梦人如醉，种祸沉沉此是胎。因果要无半毫爽，盛衰长作一轮回。欲除世上兵戈惨，先划胸中杀气来。
原：繁华一梦已成尘，风露沙场最苦辛。烽火世争传浩劫，戮屠谁早见微因？可怜人意难忘杀，未必天心太不仁。待与众生参妙谛，眼前时事试披陈。

# 杂诗
原：美人怨遥夜，起坐弹鸣琴。一唱再三叹，惜哉无知音。啼蜇知天寒，落木知秋深。对此感迟暮，凄恻伤我心。

# 答钝根
原：一纸三年事，能知别泪多。秋残吴淞雨，木落洞庭波。避世计亦得，怀人意若何？孤灯昏病眼，此简几摩挲。

# 贈旦平
原：一病颓唐卧晚秋，劳君亲自慰予愁。何当一棹同君去，分付幽忧与白沤。

# 病中至徐家花园
原：如何戚戚抱离忧，分付膏轮半日游。垂柳数行黄晚照，孤花一蕊瘦深秋。暂来曝病意亦适，偶此成吟诗自幽。眼见园林有衰盛，愚园已易主。当知身世是浮沤。

# 题亚子《分湖旧隐图》
原：寂寞荒江一病未，故人有字慰愁躯。十年我作离家客，惆怅分湖尺幅图。

# 题董小宛小影
原：李香侠义真奇绝，如是眉生亦特行。指劝钱、龚殉国事。万口沧桑传艳事，《沧桑艳》传奇谱陈圆圆事。谁知铜雀锁双成。近人引吴梅村诗，证顺治董妃即小宛，盖当日实未死，乃被掳人清官也。

# 题马小进《居庸关秋望图》
原：绝壁悬崖扼形胜，乱鸦衰草阅兴亡。居庸关上悲秋客，匹马西风意莽苍。

# 杂诗
原：明月无老少，万古常如兹。皎皎当中天，夜夜扬清辉。忽被大地妒，才盈便使亏。虽曰有圆时，常圆不可期。借问此缺恨，茫茫何时弥？
原：太白久已死，子美今不生。空留一卷诗，寂寞身后名。悲哉郊岛辈，三年两句成。苦吟岂不劳？各以宣其情。秋虫与春鸟，安能已其鸣？
原：暮秋寒信至，长空悲风号。浮云何惨淡，落叶亦萧萧。行役一万里，游子岂不劳？中夜思故乡，涕泪沾巾袍。

# 示善之
原：心地痴顽词旨凄，搜神志怪未为奇。要知史亦参疑信，底事文成杂笑啼。落拓孤心岂终没？苦辛旧事莫重提。千家争说虞初志，别有艰难谁识之？

# 蒋万里以近作见示，多慷慨激昂之作。予学诗不善此，今效其体，为二章赠之
原：蒋子名万里，前途何其长。何为久郁郁，蛰居穷愁乡？有时独悲歌，意壮词激昂。有时夜起舞，神剑吐光芒。立功志未死，揽镜鬓未霜。朔方正有事，班张毋久藏。会当靖边尘，声名播八方。
原：隆冬气萧杀，萧萧北风寒。易水终古流，不见荆轲还。慷慨独长征，策马越关山。坚冰凝狐裘，积雪没雕鞍。回忆江南乐，岂不心悲酸？丈夫有怀抱，志在斩可汗。不然仗神剑，慷慨诛阿瞒。安得守故乡，蹉跎凋朱颜？

# 宝剑篇
原：宝剑有奇气，敛之不能藏。化为一丈虹，耿耿夜有光。我曰剑负汝，不能用所长。曷去化铁砚，静默而宁康。不然化金钏，绚烂助明妆。剑曰岂不知，天性难更张。况复恩与怨，朝朝不能忘。十年吾事成，飞去投洪荒。

# 送亚子归梨里
原：江乡木落晚秋寒，送客江头泪暗弹。十日匆匆成聚散，两人各各有悲欢。商量偕隐谋非错，谓君检点逃禅事亦难。自谓风雨潇骚天意恶，劝君归去强加餐。

# 贈陈蜕庵先生
原：先生买棹作南旋，我为饥驱困市廛。羁旅相逢多难日，盛衰深话晚凉天。捻须觅句得佳趣，忘齿论交到少年。一局残棋未堪问，感时伤别各凄然。时先生令媛将入蜀。

# 海上雪
原：天上群龙战斗狂，玉鳞瑶甲乱飞扬。万家息动归闲寂，一鸟冲寒入渺茫。冷压楼台危欲堕，皓欺灯火薄无光。披裘独往为何事？赢得诗添长吉囊。

# 书感，追送亚子归梨里
原：文将纾困计全非，酒以排愁力已微。孤愤待喧还自寂，故人难聚況今稀。谓亚云、蜕庵。天涯黯黯看春尽，海上年年送汝归。此去知君足消遣，秋山十幅列屏帏。

# 春夜
原：绿纱窗外雨潇潇，独拥重衾睡不牢。万斛春愁夜如水，隔墙谁弄一枝箫。

# 贈莼农
原：阿侬性灵巧，姊妹称针神。吴市买绫罗，亲裁六幅裙。双双绣蝴蝶，不惮夙夜勤。缕缕是心血，爱护如宝珍。一朝厨灶冷，含羞出示人。君道罗裙好，千金价不论。君知罗裙好，知否依苦辛？

# 暮春野行
原：宿雨昨宵霁，万木净如洗。远山含朝曦，绿入书窗里。折柬招良朋，出门着芒履。莫坐斗室中，悲怀无时巳。
原：野行多佳趣，风光随处好。桑麻绿成阴，丛竹碍飞鸟。着雨麦苗垂，入夏菜荚老。断石谁家坟？一半埋芳草。人去独碑存，碑亦难长保。俯首有所思，孤怀不能道。

# 八月三日屏子昆季同日结婚，摄影命题，为缀一绝
原：疏雨微风菡萏香，未寒天气恰初凉。一奁秋水澄如许，印出鸳鸯双复双。

# 雨平招饮，忆亚子
原：葡萄美酒色深红，银杓晶盘炙鲤熊。灯火管弦欢未已，凄然忽忆柳河东。

# 春薯集朴学斋，和巢南
原：不定阴晴日易斜，江南三月落樱花。残英片片飞红雨，一盏深深泛碧霞。小叙故人聊自乐，且供春笋未为奢。谁知冷醉闲吟辈，别抱伤心未有涯。

# 亚子嘱题子美集
原：苦辛写此春痕集，沖淋漓到陆郎。一样听歌各情绪，眼前人事有沧桑。春航集成于去年夏初，子美集成于今年春暮。相去一年，世事已变幻如许矣。

# 寄楚伦
原：飞觞市楼有人醉，闭户病榻无客过。酒盏药铛各狼藉，残春一例够消磨。

# 题蒋万里《振素庵诗稿》后
原：足迹半中国，栖身地竟无。可怜无俗骨，宜汝作寒儒。耿耿寸心苦，茫茫吾道孤。短诗题卷尾，珍重话歧途。

# 清愁
原：清愁来何方？夜半袭我怀。披衣起踯躅，谁知肝肠摧？皎皎孤月明，萧萧北风哀。岁月一何速？逝者不复回。蹉跎复蹉跎，坐使朱颜衰。

# 贈孟硕
原：天地一囚狱，万古闭不开。岂必君至此，始为缧继羁？一自国政乱，谁念小民哀？中州患烽火，四方苦馑饥。老弱多死亡，少壮亦流离。化日不可睹，但见风雨凄。迎君囹圄外，欲言已无辞。

# 春日寄家兄闽中
原：薄酒成孤坐，轻寒怅远离。潮生残梦白，日落暮愁低。海扇占春信，《闽小记》曰：海中有物，形如扇，文如瓦屋，惟三月三日潮尽乃见，名曰海扇。仙芽问武夷。芳兰倘能遗，相答寄杨枝。闽中少柳。

# 春柳
原：去年见汝凋零日，转眼枯枝已向荣。双鬓镜中更憔悴，低徊对此感劳生。

# 贈亚子
原：海角重逢已隔年，偶谈往事一凄然。风流销歇何须说？谓春航远游，子美去世。地覆天翻在眼前。

# 贈王均卿
原：东晋风流数大家，至今子弟擅才华。兰亭笔写通明奏，乞借春阴为护花。
原：斗方绛帕写柔毫，一种风怀自可豪。不减君家当日事，旗亭画壁郁轮袍。

# 乙卯杂诗
原：蜗角潜居事底干，楼台一寸且偷安。滔天风浪从东至，草阁难支五月寒。“五月江深草阁寒”，前人句。五月者，吾人所谓五月九日也。
原：眼前景物已荒凉，一夜清霜百草黄。莺粟万花还满地，西风低首礼中郎。“万朵红莲礼白莲”，昔人句。中郎，指蔡伯浩也。中国百政不振，惟禁烟差有可观，而伯浩乃议行鸦片印花税，是众芳消歇之而莺粟犹盛也。
原：当时万紫与千红，毕竟春华过眼空。底事东皇归去后，孤花还不避狂风。指沈佩贞事。当民国建设之初，正女权发达之日，毕竟只有春华而无秋实，宜乎千红万紫，过眼成空。而春餘孤花，犹自与风姨为敌。花固不量，而风亦无情哉！
原：西来象教几千年，出世何人了万缘？往事风流说东晋，十方名士听谈禅。指都门士大夫欢迎缔闲显珠事。
原：孤竹清风记往年，古今谁比伯夷贤？痴呆名士轻天子，一任人嗤值几钱。某二公子有言：“吾本名士，岂有作天子之想？”“名士是何物，值几文钱耶？”秦淮妓女语。见《板桥杂记》。
原：有人揽古一登楼，历历兴亡满目秋。千古美新留话柄，西京才子说扬刘。按晋人清谈，持廛尾，名曰谈柄。后人遂假借为故实之称，亦曰话柄。扬雄、刘歆，指皙子、申叔也。

# 美人
原：六寸圆肤双绾髻，大家踏步岂寻常？若非吴越钟灵秀，一种丰神已过刚。

# 荻花枫叶
原：荻花枫叶只寻常，美酒葡萄亦激昂。第一婀娜龙女笔，最难莽苍上声写钱唐。

# 为高吹万题《寒隐图》
原：幽人无俗怀，厌世每独往。结庐在山邱，地僻志疏广。虚室绝尘嚣，泠泠竹露响。户枢苍苔封，浮月窥书幌。秋花能耐寒，元音只自赏。枯极灵性现，静至道心长。此中有清福，微君谁得享？嗟我长征人，何时超尘网？

# 为汤磷石题《鸳湖垂钓图》
原：超然绝尘想，寄怀水云乡。垂竿钓落叶，一蓑披斜阳。天机静自悟，所志非鲤鲂。笑彼垂纶叟，逐逐为鱼忙。

# 简蜕庵老人
原：记得探梅曾有约，偶然睽隔又旬盈。不知听雪围炉坐，捻断吟髭第几茎？

# 赠王漱岩
原：不见王摩诘，于今已两年。市楼一日聚，话旧倍凄然。但有人如酒，用如饮醇醪故事。何妨屋似船？明朝便分手，珍重赠斯篇。

# 次韵和漱岩，并示坚白
原：文字东南剩此坛，零篇断句付谁看？同羁湖海三千里，难话兴衰一万端。姓氏存亡他日事，琴樽征集此时欢。市楼不识炎天热，自笑平生诗骨寒。

# 观雨
原：高楼纵远目，雨势在东方。秋意飒然至，尘襟为一凉。天光青黯黯，海气白茫茫。安得双羽翼？便欲凌风翔。

# 佳人
原：佳人来何许？道是邯郸倡。粉艳花无色，珠明月敛光。短歌自苍老，细语最凄凉。肠断不能饮，谁教汝侑觞？

# 和鹑雏韵学宋人
原：一灯延月入深廊，曾觉秋宵渐渐长。寒蟀悲风心万里，败荷凉雨劫千场。已憎硬饭侵衰胃，况耐艰诗苦涩肠。敢道诸缘都忏尽，难言深意只微茫。

# 题孙阿瑛《清宦秘史》
原：清初故事《红楼梦》，清末遗闻《孽海花》。一卷兴亡魑魅董，宋人有书曰《鬼董》。阿瑛当是第三家。

# 与仲兄夜话
原：兄弟相看羁旅日，秃毫短烛写残诗。隔江依约闻丝竹，往事凄辛话乱离。黄浦月明万营肃，自吴淞至炮台湾，遍地营帐，皆北来兵队。白门秋老一城危。苟有事者，金陵必当其冲。茫茫大劫无终始，轮转兴亡到几时？

# 题《武林游草》寄石子
原：君言此是新游草，示我低徊读一回。对景怀人还感事，管教哀乐一齐来。
原：哀青岛用十四寒至一先韵。此三韵，古相通。
原：浩浩渤海水，悠悠胶州湾。林木何葱郁，山峦亦藐绵。乃有木屐客，见之长流涎。便将一角地，夺入囊橐间。世无鲁仲连，谁复争之还？郁郁泰岱青，沉沉夕照殷。怅望田横岛，烟水空迷漫。

# 拟钱允辉《过江》诗
原：明钱允辉晔有《过江》诗云：“三国旧愁春草碧，六朝遗恨晚山青。”哀而不伤，最为可诵。惟两句只是一意，稍不足耳。余于己未三月亦渡瓜州，至维扬，因作此诗，写示傅君君剑、高君吹万、家兄朴庵，时三君方自金、焦归也。
原：扣舷何事费低吟？举目苍茫感喟深。六代江山留画本，一天风雨入诗心。眼前已见金瓯缺，指镇江租界。水底难寻铁锁沉。怕是蛟龙听诗出，浪花如雪湿衣襟。

# 中央公园
原：金瓦琼楼旧帝乡，当年春梦付残阳。至今能与民同乐，到此方知尘不扬。一角春明聚裙屐，春明馆。四朝老柏识兴亡。园中老柏婆娑，元、明物也。园林曲折寻常事，落落如斯自大方。

# 小病一首
原：偶然卧雨守胡床，一病萧萧鬓已苍。衣角纹生千缕皱，砚凹霉积一分长。脾伤渐畏新茶烈，脑损能教熟字忘。强为驱饥出门去，吾行何往亦茫茫。

# 闻李定夷言校书王小莲事，且云欲撰为说部，命予题词，感而賦此，即调定夷
原：柳毅杨娼有定评，樊南才调旧知名。《柳毅传》、《杨娼传》，唐小说名，以比定夷诸作。底缘春水干卿事，一传凄凉续小青。小莲事略与小青相类。

# 题《昭容集》，为太侔老兰赋
原：大千色相本来空，笔墨偏多点缀功。留与后人谈剧故，风华相像陆昭容。

# 初秋闻雨
原：两鬓萧萧雨一窗，病眸强敛背银缸。太空浩漫浑疑海，大地浮沉便是艘。

# 寄仲兄都门
原：短笔寥寥语已稀，欲言无尽暗相依。应时略写江南景，黄浦秋潮蟹正肥。

# 早春野行
原：早春犹是怯寒，寂寞林峦睡未残。此语本“冬山如睡”。绝爱静中有闲意，枯枝冻雀耐人看。

# 归梦
原：莫道火轮速，归梦犹过之。不作同方行，而作背道驰。梦魂几往还，车行犹迟迟。日出泰山曙，天寒燕草衰。车行何时已，客愁无尽期。

# 集陶渊明句

# 集李长吉句
原：莎老莎鸡泣，闭门感秋风。秋风吹小绿，细露湿团红。灯青兰膏歇，宵寒药气浓。三年去乡国，神剑断青铜。
