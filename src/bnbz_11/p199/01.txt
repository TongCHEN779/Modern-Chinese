# 小柳诗选
原：陶牧字伯荪，号小柳，江西南昌人。今录诗十三首。

# 将赴广州，答友人赠别之作
原：故人为我折将离，别绪真成理乱丝。去日松鲈方可荐，到时桂蠹定相贻。西华单帔寒如昨，南海明珠事尚疑。鲁酒待醒孤客送，夫容日暮此心期。

# 广州光孝寺为虞仲翔谪居时旧宅，有诃子树一株，相传仲翔手植也。余儿时家近寺旁，恒嬉戏树下。丙午十月，重至广州，此树犹存，怅然有作
原：迢递诃林百尺枝，簸钱此下忆儿时。亭亭四荫还如盖，无无双髦易变丝。重堕炎荒元不悔，逆推尘劫固难知。劳生赢得芳华感，岁晏攀条索语谁？

# 偕吴门诸寓公探梅邓尉作
原：十年水国寒生袂，著眼繁华意自殊。未有文章侪宋赋，且携脂蠡拜吴姝。东坡咏梅词：“他年欲识吴姝面，秉烛三更对此花。”如闻唳鹤增遐感，乍喜蟠螭山名涉胜途。便欲乞祠从邓尉，落英长与荐氍毹。

# 季夏忆吴门景物寄内
原：差池短翼年时恨，雨霁无端忆水乡。戈渚杨梅才过市，里语谓物之后时为过市。吉祠菡萏未生房。愁边节物知难遣，别久吴音渐欲忘。瞑坐支颐成好梦，梦为浴横塘。

# 贻朴庵
原：与君把酒话平生，不铸黄金错铸情。断梗长飘填恨海，著书无分剩诗名。此心似水灰同冷，白眼看人烛太明。最是春风吹又到，绿杨深处鹧鸪声。

# 和子实《西湖》原韵
原：孤城烟柳万丝清，桥外朱栏白水生。叶小荷翻风送暖，萍开艇过日初晴。山光入座与眉接，云意浮天照眼明。缓缓花驄归陌上，树禽都作嬉春声。

# 题季樵玉照并送其归皖
原：春满河阳花满城，锦衣归去送君行。飞来凫舄多陈迹，踏遍鸥波话旧盟。歌舞红灯怀牡牧，料量金屋待云英。华颠相见犹年少，莫向淮流照影惊。

# 和朴庵见答韵
原：秋虫苦热事宵征，杯酒期君遣此生。两地月明心共印，一窗波寂影无声。沙虫吾辈归何用？风鹤人间郁不平。除却春江鸥可狎，鸡坛仍在剩诗盟。

# 七夕和儆庐，仍用征字韵
原：浮沉瘴海共南征，老我河阳白发生。倦鸟依人思振翮，寒蝉在树噤无声。道高魔重文驱瘧，海涸桑枯路未平。只有星桥仍可渡，天孙日守岁寒盟。

# 和儆庐题允公诗原韵
原：各有天涯岁暮心，十年萍梗苦能寻。藏身人海浮如芥，放酒尊罍悔不箴。诗动乾坤言慷慨，天多荆棘夜深沉。荣枯万古回潮汐，莫共秋虫绕砌吟。

# 写感示朴庵
原：难得云山数日晴，窗前好鸟弄新声。雄谈绿酒三杯醉，破镜苍颜一笑惊。芳草江南哀未已，名驹冀北梦无成。飘流瘴海同为梗，恰与先生共此情。

# 寄怀菜佣有所询
原：歌板空回别后肠，此中岁月更嫌长。应怜客为田横死，未得人知叔夜狂。梁燕最防逢旧识，车龙惊见眩新妆。淘金挑菜皆陈迹，剩有刘公醉里乡。

# 次韵答朴庵
原：同在三山外，凄凉雨满城。梦随芳草远，心与乱更倾。相对唯思睡，终贫只误名。胡公最高迈，长揖事为兄。
