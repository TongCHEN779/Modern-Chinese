# 寒碧诗选
原：林景行字亮奇，号寒碧，福建闽侯人。今录诗二十首。

# 宋碑酹后，得真长书，闻佩忍已归松陵，感寄一首
原：斗酒来过敢欠期？生存华屋亦含悲。乡山桂老吾难隐，江国莼寒子可思。似许流人仍跌宕，竟成残客尚猜疑。平生独往寻碑地，一诺应孤挂剑时。宋尝约北来，未竟。

# 日夕睡起，绕篱怆念，归而有作
原：篱落花已黄，病虫带寒意。北来客亦秋，刺景满凄异。眼中数旧游，一一皆哲萎。独余孱藐躬，岂为天所畀。江山亘故版，此命殆谁寄？觉来却失笑，不揽范生辔。勤民庶云教，划地可求治。能穷竟年力，自接四海气。寓书与刘子，措答应不贰。昏灯且校篇，蛮语待强记。造成巴哲谈，吾学或足试。

# 重过鬯春堂感旧
原：北府论文事已非，西山载酒约仍违。写忧只剩黄垆在，感旧难任向笛悲。一去湘波怜赋鹏，再来松树飒成祠。凉风天末今谁语？霜叶林梢又及时。

# 江亭瞑过偕浚南
原：初赚暝月上烟芜，渐觉寒声出败芦。钟响忽收天外寂，僧形如向物边孤。但凭目力千鸿尽，偶吐丝情二客无。徙倚樊川真一笑，鬓丝禅榻定谁吾。

# 楚伦属题《分堤吊梦图》，额竟署分湖，盖认作词仙旧院也，因系两绝
原：不见垂杨下有堤，浪猜图记浪标题。为耽湖水年年绿，道是词仙旧院栖。
原：不是词仙旧院栖，能寻芳冢也应题。后生笔记后人画，招怅重来已隔堤。

# 题亚子《分湖旧隐图》
原：冥心孤往不知还，几曲秋芦水几湾。安得从君借渔具，一家棹月去潺潺。
原：未是风尘抛我时，君曾隐处我题诗。奚山倘许旁人污，猿鹤还应倦客疑。

# 听永见视新篇，次韵却答
原：昔人高饿显，西山采薇诗。此义久已湮，士林嗟式微。感子豪杰怀，四海犹凌迟。我吟匪箪壶，何以迎王师？正雅止不作，反骚兹为宜。百篇自风发，读之凄肝脾。作者日以衰，亡羊遭路歧。指导固无辙，步趋安可离。君笔有神助，辛苦将焉辞。向来拟谢柳，愤懑过韩非。有学乃不用，何物当刑笞。况非治乱才，敢与圣任期？

# 斋中读书二首
原：独游渡浑水，读书常闭户。近乃宅傍域，况有家人聚。云壑既绝想，灯帘亦垂妩。夙悲经世心，得此养疴古。憨儿渐持杯，细婢嗜修脯。新熏出龙焙，嘉食荐冰乳。兴来我吟哦，书际君鼓舞。浮庵近临子敬行草，甚得其妙。两生如有得，一室任何许。囊丰时寄传，签满可倾赌。想见城南人，悠然讨双谱。
原：结念游柏林，长怀终弗释。晶晶夜灯光，切切秋虫客。钩沉时未能，汲短每见绌。篇行穷张罗，意会苦寻绎。百练岂为刚？千金良不易。平生力行志，死友忏悔夕。亡友黄远庸《忏悔录》。猝然忽一通，勿使幽灵隔。用知归子赞。

# 独归
原：寂寂寒阴苦闭春，江阡刺眼属芳尘。但令不饮沉长夜，谁信弥天了此身。故隐独归惟涕泪，苍冥无睽是精神。正愁风雨崩腾夕，难访成连到海滨。

# 黄鹄山石台，偕王文东暝天话旧，慨然有作
原：向来与子登临意，缅付秋风作一吹。海上耽吟人亦老，阑前对立客还稀。李郎才气殊吾羡，叶女风流未可思。懒唤红巾摄新泪，稼轩凄侧绝哀时。

# 闻方沚亭丈卒于海上，哭之以诗
原：苦从愤世说安贫，独许离居敌作辛。渺渺神州归此老，滔滔江汉待何人？一生仁行殊为贵，今后狂言孰与亲？别有无穷告祭意，海天儿女暗沾巾。

# 归西湖賦像生牵牛花感旧
原：北眷寒星收冉冉，南瞻芳露泫垂垂。眼中携手凭栏处，年事凝妆向瞑时。

# 铸夫、味生、雨樵诸君子召燕图书馆，楼背山面湖，极饶草树之盛
原：枕棹赴嘉招，对楼资小凭。层峰俯深眇，宏宇罗青冥。结构岂造就，逍遥自姈娉。朝云凝不散，夏羽矫还轻。连漪扬轻飔，嘉树当列屏。玫瑰溢芳气，素馨送微酲。虽无肌鬓香，亦动簧丝情。按序已逾届，宿意还当醒。

# 篮舆长行数里，草径裏湖，花篁入岫
原：俯郭趋十里，回湖俄已晴。午阴郁无喧，蒸日时漏明。峰出朝霭戢，泉迷乱香生。草径往无际，篮舆疑未行。绯花淫滴滴，翠案垂盈盈。意会异探讨，耳目殊经营。惜余病微质，未足当炎兵。稍触暄燠气，便苦拘墟情。强振释形倦，静趺培神经。还思早春际，徐接群芳清。

# 五月十二日薄晓泛湖，憩北亭，凝感有纪
原：凌晨溯团流，展棹觅清异。连陂径蜿蜒，蔽筑林罗绮。遥峰隐凝思，滑磴阻洊至。涧曲越潜响，桥回满空翠。须臾光景开，弥觉山水腻。宿雾破参差，新日出明媚。凉煦虽倏迁，升沉岂异企。傲情总在坟，丽想愧人寺。暝如苔藓光，静得钟梵气。仙藏不可寻，悠然假梦寐。

# 从北高峰下韬光庵，外憩石桥，倚栏看竹
原：阴峰千转此凭栏，万竹参天俯一寒。绝忆扶桥悄无语，当时犹作画中看。

# 湖泛口占，示贞壮
原：晚风翼翼浪吹衣，凉水鳞鳞翠入微。借与诗人随一舸，枕流看树憺忘归。
