# 中泠词选
原：叶玉森字中泠，江苏丹徒人。今录词十二首。

# 卜算子用鹜翁韵
原：心似未灰檀，眼似将舒柳。腊鼓谁家赛细腰，喧得春魂透。酒是瓮头新，泪是襟边旧。拚醉翻愁梦易成，梦里江山瘦。

# 点绛唇原用梦窗韵
原：前度芳时，雾航晓泊枫桥路。蒙蒙春树。揩眼听钟处。携酒重来，目送花飞去。闲愁贮。谁家筝缕。苦苦牵云絮。

# 相见欢用沤尹韵
原：数星凉似秋萤。故吹灯。暗觉心光一穗、吐微明。宵来雨。江头树。嫩青生。只恐杨丝牵出、乱莺声。

# 鹧鸪天用鹜翁韵
原：高枕龙渊尽醉眠。梦闻汉武敕开边。蛮夷大长须如猬，都护将军臂似猿。逾瀚海，出祁连。幕南都属汉山川。会当痛饮蒲桃酒，更促阏氏替拂弦。

# 踏莎行用沤尹韵
原：春草牵裙，夕阳兜扇。花开陌上清游遍。乱山处处有啼鹃，闹红未信芳华变。酒半回肠，灯初揩眼。蘼芜颜色罗敷怨。鸾咽欲转不成声，输他软语双飞燕。

# 太常引用忍庵韵
原：狗屠燕市筑声高。块垒酒难消。醉眼对花摇。记门巷、胭脂那条。分明影事，归车缓缓，残月虎坊桥。飞梦托兰桡。莫漫唱、天风海涛。

# 燕归梁用忍庵韵，梦窗体
原：雨后春山笑靥开。携泪上苏台。衔花麋鹿几时回。问斜阳、有哀。吴宫自昔饶芳草，惨碧乱莺催。翠颦香屎梦多违。唤西施、醉金杯。

# 夜游宫用鹜翁韵
原：干了湘妃泪雨。怕重倚、竹枝愁诉。常子金蚪去何处？恼宫鹦，日沉吟，断肠句。莫放春风去。长相忆、琼楼珠树。听罢霓裳羽衣舞。又花梢，雨淋铃，暗凝伫。

# 霜天晓角用沤尹韵
原：苍岩老木。春满狂花屋。曾记幽居苦独。开门款、野云宿。灭烛。离绪触。旧游邀梦续。招得山中猿鹤，和明月、踏新绿。

# 极相思用沤尹韵
原：冰奁圆影新磨。紫凤簇轶过。华鬘天上，客星都醉，鹊汉无波。莫话清虚宫外事，怕无端、蹙损秋蛾。未知今夕，琼楼高处，可觉寒多。

# 夜行船用鹜翁韵
原：冷语芦花辞已费。掬肝胆、与鸥同洗。雨细风斜烟寒日，短兀地、做成憔悴。欲向桃源通一纸。问今日、山中何世。只恐桃花，一般沦落，肠断武陵春水。

# 眉妩赋河东君妆镜拓本
原：怅桃花啼泪，锦树埋琴，淮水故凄哽。红豆庄何在，蛾眉死，菱盘千古冰炯。绛云烬冷。便翠奁、微带烟晕。算修到，星靥霜丝并，艳帘下风韵。撞破金瓯谁省。剩一规明月，依旧清迥。不尽蘼芜怨，新妆罢，当时青鬓羞映。麝笺泪隐。
