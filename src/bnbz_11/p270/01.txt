# 大觉诗选
原：王德钟字大觉，江苏吴江人。今录诗三十八首。

# 月夜渡淀湖歌
原：我被石尤妒，屡把归期误。今朝贾勇挽舟去，今宵未卜宿何处。打头之风吹不住，遥指湖干锁烟树。烟树沉沉日渐低，欲泊不泊沿湖堤。举酒篷窗聊遣闷，身虽在东心已西。忽闻榜人笑不止，芦边簌簌东风起。东风吹出月珑玲，一轮照耀平湖平。我行原不惮宵征，挂起蒲帆十幅轻。三千世界放光明，卅六里路飘然行。乌鹊惊飞飞且鸣，鱼龙欲睡睡未成。浑疑身忽来沧瀛，金光璧彩眩双睛。又疑张骞今复生，乘槎直犯牛女星。前望后望天如晶，中央独自扬孤舲。似此奇景从未经，恍如魄濯冰壶清。洗盏更酌倒玉瓶，豪饮不让吸川鲸。隔浦遥闻渔歌声，忽然引起沧浪情。瞬息渡湖近二更，回头一派水盈盈。乘兴还家诗思发，腕底清词来汨泪。一片性灵何活泼，胸头朗印湖心月。

# 落花篇
原：东风吹到曲栏曲，簇遍千红与万绿。参差池馆闲春声，满目云霞香万斛。绮情丽绪百花中，今日徒怜昨日红。无数繁华春九十，莺花老去何匆匆。回首花容未憔悴，烟条露叶尽增媚。紫燕帘中羞见影，郁金堂上总输态。一自飘零逐幻尘，眼中都是可怜春。别有佳人年最少，满目芳菲对花恼。今岁花开颜色好，来岁花开颜色老。落花落花可奈何？满目香尘别绪多。华林金谷复何有？长江汨汨山峨峨。

# 十九岁述怀十章
原：落拓浮沉十九年，头颅如许总堪怜。忍看亡国剜双目，夙愿匡时仔一肩。未溺死灰仍帝制，难将热血换民权。床头三尺龙吟夜，忽梦沙场枕月眠。
原：欲把文章救国魂，毫端铁骑似雷奔。平生适意书千卷，万古牢骚酒一尊。得失浑忘隍下鹿，餐眠应笑栅中豚。潇潇风雨秋灯碧，夜半文成是放猿。
原：愿把雄心付狗屠，穷途志士似狂奴。读骚饮酒由名士，击剑吹箫是丈夫。笔墨已成空议论，江山未许恋莼鲈。深宵悄向龙泉誓，沧海横流敢惜躯。
原：检点青衫血泪盈，匣中夜夜作龙鸣。亡羊往事嗟何补？历鹿孤踪感易生。中酒讵应销傲骨，惜花聊藉寄闲情。如何一近弹棋局，便觉中心有不平。
原：自分微躯沟壑填，男儿那肯老青毡。百年谁料此身后，万事难堪是眼前。国难方殷抛蠹简，民仇未报祝龙泉。等闲忍却沧桑泪，来种要离冢畔田。
原：匡时挥尽鲁阳戈，天意如斯奈若何？愿逐独夫抛性命，但教汉胄保山河。只愁四海英雄少，漫恨一身涕泪多。落日苍茫酒欲醒，高歌击筑说荆轲。
原：狂生孤愤总难平，且向陇头效辍耕。北路方骄人得意，南风不竞我无名。未施掌上三分策，辜负胸中九伐兵。夜半纷披亡国史，腥风血雨哭神京。
原：男儿忧国不忧贫，尝胆卧薪志未申。岂信苍天终覆汉，还期楚士或亡秦。当为效死沙场鬼，忍作偷生歧路人？悄问宝刀兼自问，杀身何日始成仁？
原：年来王粲怕登楼，剩水残山满目愁。大错已成添国恥，宝刀未试为余羞。愧无才力惊时辈，犹有豪情结酒俦。杀尽民仇痛饮日，敞筵饮器是人头。
原：偷生草野学行尸，潦倒新亭酒一卮。去国那堪多事日？还山偏在少年时。批龙探虎知无我，投笔荷戈更有谁？中夜闻鸡含泪起，濡毫狂写述怀诗。

# 亚子以酒后之作见示，谨步原韵报之
原：少年意气薄诗奴，结尽江湖游侠徒。竖子偷功成将相，英雄屈志老菰芦。平生断送书千卷，万事安排酒一壶。曾约梨村明月夜，狂歌痛饮与君俱。屡蒙函招，余期以六月中旬。

# 和悼秋醉后之作
原：醉后狂歌吊落日，梦梦天地我清醒。伤时壮士剑花灿，死国英雄磷火荧。不少哀吟寄楚泽，尽多奇泪洒新亭。书生曾把《阴符》读，亦愿荷戈出井陉。

# 奉和朱剑芒《述怀》两律，即用原韵
原：寒笳惊听月中吹，难向鹪鹩觅一枝。尔我倡酬亡国日，江湖歌泣少年时。羞看东壁雄鸣剑，忍读西台痛哭诗？泽畔行吟自憔悴，茫茫心事有谁知？
原：神州古国羯羊窥，会见中原剩兔葵。不信江山终破碎，奈无人物定安危。读书万卷宁甘隐？磨剑十年大有为。天意苍茫我独醒，头颅一抚一心悲。

# 书感十章
原：独向尊前唱恼公，蹉跎髀肉意何穷？气豪击剑吹箫里，才尽埋香葬玉中。莫道青衫多落拓，果然红粉识英雄。美人肥马俱辜负，忍听萧萧易水风。
原：深宵塌頞拜轩辕，叱起神州古国魂。历劫难销壮士骨，穷途易感美人恩。千杯浊酒同卿醉，一卷《阴符》为我论。牢记闺中赠别语，血花去换好乾坤。
原：青萍夜吼不堪闻，未策沙场汗马勋。卿自倾心怜皂帽，我应低首拜红裙。浇愁须饮刘伶酒，埋骨愿傍苏小坟。侍婢传来书一幅，蝇头密字劝从军。
原：谢汝箴言字字真，闲来一读一伤神。试妆窗下频延月，击剑花前又送春。愧我未为殉国鬼，怜卿待作坠楼人。他年斩得单于首，来博红颜一笑颦。
原：忍把中原袖手看，此身输与钓屠宽。搴兰纫蕙肠先断，中酒伤春泪未干。绿蜡高烧拟露布，红裙膜拜祝吴干。玉门关上生还日，纤手烦卿解绣鞍。
原：悄对江山泪不干，谢卿慰藉杂悲欢。典钗何惧黄金尽？看剑忍教绿鬓残？紫塞浩歌庆虏馘，红楼美酒赏刀瘢。少年未遂澄清志，那许怜渠翠袖寒？
原：忍泪狂吟自讼诗，酬恩报国尚无期。风尘未试诛奸剑，绮阁先裁起义旗。豪士朝成侠女传，吴姝暮列党人碑。闲征古史求同调，卿爱木兰我渐离。
原：谁识吴中侠少年？豪情奇气酒尊前。醉且枕美人膝，醒后还持祖国权。倘得沙场马革葬，应如绮闼绣衾眠。一腔热血千行泪，去博贞珉十字镌。
原：歌哭年来鬓欲霜，累卿红泪日淋浪。讹传骏骨沽燕市，喜得蛾眉出玉房。金错刀如能杀敌，凯旋歌便作催妆。须知彼得城头鬼，方是兰闺梦里郎。
原：感卿为我说荆轲，不许男儿被墨磨。绳案抛残招隐赋，琼箫吹作出军歌。未曾人海舒眉宇，忍向妆台伺眼波。昨夜闺中有异梦，玉郎仗剑渡黄河。

# 柬陈巢南
原：寄问申江陈百尺，论词征献近如何？想君客里有佳趣，扫地焚香写勘书。
原：琴言遗稿谢相贻，古谊如君信可师。绝似云间张畹史，踵门慨借百愚诗。
原：校雠考据惟君谙，妄事丹铅愧不堪。王俭集传须程昉，引端鸿著待巢南。

# 渔村消夏四绝
原：水榭风亭夏亦凉，黄庭闲写两三行。摘将茉莉循檐，几树蝉声噪夕阳。
原：镇日偷闲书乱堆，芦帘悄下睡魔催。叩门惊破蘧蘧梦，知有邻童送酒来。
原：傍溪小筑避威炎，水映云窗竹映檐。晚雨乍停风又寂，敲棋催月上疏帘。
原：衔杯笑对篆烟斜，醉后诗成写扇纱。悄听一番新雨过，疏篱扁豆吐秋花。

# 楔湖登中立阁
原：钟声缥缈夕阳斜，几处楼台锁晚霞。笑我登临中立阁，只看落叶不看花。

# 中秋泛灯词
原：花香酒雾度中宵，姊妹成行举手招。灯影歌喉明月下，画船刚出太平桥。
原：十五盈盈两髻丫，窗间徙倚细腰斜。看人毕竟防人看，粉面罗巾一半遮。
原：宵深月淡露华浮，薄袖禁寒无限愁。欲弄玉箫还放却，有人倚扇在船头。
原：去岁邻舟侧帽人，背灯授意赠罗巾。为郎憔悴腰支损，怪底秋衫不称身。
