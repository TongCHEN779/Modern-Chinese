# 公愚诗选
原：古直字公愚，广东梅县人。今录诗二十六首。

# 感事二律
原：三月红棉底样骄，美人意气欲干霄。无情风雨拚摧折，入望云霓又寂寥。化碧剧怜啼杜宇，冬青生怕溷鸱鸮。越王台上悲歌日，竹石敲残作楚骚。
原：滚滚珠江水尽冤，巫阳不下复何言？亡胡天意终宜验，思汉人心信不谖。有限遗民谈往事，无多老泪洒中原。黄花消息教谁问？死抱枝头为国魂。

# 山居暑夜
原：愁思不能寐，倾耳听四野。草虫何唧唧，松涛急如泻。哀蝉抗高音，山歌发咿哑。感此为长嗟，殷忧曷由写？揽见起彷徨，怅然明月下。

# 哀朝鮮
原：滔滔大同江，茫茫箕子封。川原郁惭色，中野多蜚鸿。曹社久成谋，作伥有元凶。壮士发上指，萧萧生悲风。一击聊快意，身死国亦从。降王迎轵道，哀哉彼狡童。三韩日黯淡，倭儿意气雄。女萝附松柏，妄谓可始终。松柏不自庇，女萝复何庸？渐渐麦秀歌，百世有恫。

# 亚子书来问冷圃风景，赋此答之
原：多君问冷圃，贱子试言诸。近市异晏宅，面城同潘居。门前玉池水，亭亭发芙蕖。右有疏树林，左有稻蟹区。夹路长草木，萧萧悲黄芦。遥遥对兰若，钟声时有无。行行临荒原，高坟互相逾。日暮苍烟合，茫茫满平芜。主人爱此地，邀友结吾庐。手艺百盆兰，复聚千卷书。啸傲南窗下，栖迟常多娱。悲来发浩歌，往往缺唾壶。方将招梅鹤，何期竟兰枯。门巷长依然，风景将无殊。感此用长叹，吾怀良难舒。

# 惜哉行
原：愁云蔽天天亦惨，珠江江水红于染。不是商君曾论囚，云是将军夸勇敢。将军诚勇敢，吾民抑何辜？严霜飞六月，巫阳欲问冤模糊。魂飞茫茫归不得，月黑风凄鬼夜呼。侧然动听勃然怒，壮士心肝世所无。誓判一死救民痛，探囊出物物绝殊。非椎非剑何区区，将军扬扬来通衢。材官百人马前趋，一击不中天也夫，惜哉惜哉呼髯苏。将军之臂猿猱同，将军之胁惊曹共。将军之臂将军胁，顾盼自觉生雄风。从今一领黄马褂，溅上燕支几点红，更开明堂来论功。

# 忆亡友朝露，次残梦韵
原：数尺孤坟草自青，白云原上恸严陵。庚戌春，君与余等数人游南汉千佛塔，顺道至下岗，叹曰：“死葬此足矣。”君殁，同人即买其地，为营兆域。此事颇与皋羽相类，故云。西台争似凌风阁，文文山在燕狱集杜句忆梅州，有“楼阁凌风迥”句，后人因刺取“凌风”二字建阁祀之。君尝与余乘夜登楼，慨然有作。汐社当成许剑亭。君与余等结冷圃，会友以道义相期，故云。此日精魂依蜀帝，君又号杜鹃，尝自镌一象牙印，甚精美。他时腐草吊隋萤。君尝作萤火诗以吊隋。天荒地变心难折，借义山句。其奈沉沉梦未醒。
原：忧心乙乙似抽丝，且自挑灯读楚词。芳杜离离谁与采？荷衣叶叶总相思。绕弦风雨号长夜，触笔沧桑记异时。慧业只今论不朽，一编珍重护遗诗。君殁后，遗诗零落，余因收其遗稿，编次为《泣楼集》一卷。

# 吊杨笃生先生
原：曾把心香爇到君，亡秦三户识雄文。洞庭秋色连天暮，沧海哀涛匝地闻。含石岂忘精卫恨？怀沙空怅楚江云。故山何处堪埋骨？未忍生还入国门。

# 杂感寄楚伧、一厂
原：天醉沉沉若未醒，个中消息问君平。碧云叙散佳人遇，芳草迷离知己情。扪虱有时谈景略，封侯无分望班生。穷年笔砚今何世？孤负胸中十万兵。
原：大地茫茫不载愁，夜来有梦落沧洲。蹉跎岁月闲屠狗，颠倒衣冠笑沐猴。痛哭几回穷处辙，消忧曾上客中楼。平原落日无边好，匹马嘶风控玉鞘。
原：海外微闻翻日车，中原王气近何如？欢娱不信来擒虎，喜怒依然学豢狙。名士新亭空涕泪，斜阳故国见丘墟。只愁野哭荒凉夜，抉目城头怒伍胥。
原：湖海难容五石觚，古愁莽莽怒春潮。莼鲈不分因秋起，块垒生憎借酒浇。怀古伤今兼怨别，谈兵击剑更吹箫。夜深灯火樊楼上，偷听红儿谱绿幺。

# 吊赵伯先先生
原：当径谁歼白帝子？临风我恸赵王孙。淮南落木秋无迹，漠北横戈梦有痕。不信精魂成杜宇，只应毅魄傍轩辕。出师未捷身先死，一例声吞五丈原。

# 简亚子、钝剑
原：少日才名敌孔融，文章声价重河东。一时瑜亮称高旭，十载神交拜下风。何限黍离悲故国，几回酒美酌新丰。竹林我亦追随后，青眼其能见阮公。

# 得亚子书却寄，即用其和剑华梦作韵
原：不应巢许是尧臣，梨里高眠遗世尘。尺素书来双跃鲤，满梁月落尽传神。《诗话总龟》云：“太白风神超迈，少陵落月满屋梁’句为太白传神。”君所作亡友传，传神亦云。茫茫笠泽闻星聚，落落襟怀见性真。何日天涯相握手，吴淞一水易为因。渊明诗：“山川千里外，谈笑难为因。”此反之。

# 重展亡友朝露墓
原：咫尺山河恨可知，白杨荒草欲依依。何因再证三生石，无奈重摩幼妇碑。地角天涯终幻梦，春风秋雨寄相思。夕阳亭上多时立，一树冬青杜宇归。

# 秋兴，和草堂韵四首
原：秋风槭槭振平林，回首西川杀气森。仗策几人随邓禹？登坛诸将拜淮阴。巫峰十二天戈指，君子三千国士心。枕畔频惊刘太尉，恶声和梦落寒砧。
原：旌旗指日耀褒斜，万里山河气自华。莫道胡儿不战胆，何当汉水与浮槎。军前号令如山岳，马上铙歌杂暮笳。雪耻除凶遭此会，燕南迎遍有香花。
原：喜见中天日再晖，角声动地晓霜微。一条栈道排云出，万里军书似雪飞。楚谶亡秦应复验，人心思汉岂相违？王师及早巡南服，紫蟹鲈鱼此际肥。
原：一着争先似弈棋，宵奔胡马正鸣悲。云霓万众欢腾日，风雨诸陵拜罢时。率土遗民奉禹贡，怜封使节竞星驰。炎黄列祖应含笑，九世春秋大孝思。

# 送人之闽
原：江山如此可怜生，若个中宵仗剑行。杯酒天涯魂已断，倩他鸥梦送鹏程。
原：男儿二十不侯封，横海乘风亦自雄。舟过台澎烦一哭，八闽无地可疆戎。

# 送楚伦
原：白眼高歌意气雄，叶郎才调擅江东。当年市上寻屠狗，此日隆中起卧龙。韬略久征髯客问，功名合与燕山封。伫看扫穴犁庭日，薄海欢声动大风。

# 冷圃曲
原：东风绿遍梅州路，杜宇声声啼不住。白头老母泣路旁，痛彻心肝泪如注。天涯有客更烦冤，芳草花时独闭门。肠断西园蝴蝶梦，纸钱尊酒为招魂。忆昔结交少年日，意气相倾在胸臆。风景山河感慨多，摩挲宝剑思投笔。有时冥坐类枯禅，中心怒怒如忧煎。被径迷阳行不得，江头岁岁撷芳荃。飘零桃李春无主，百年大计将人树。梅州桂里启宗风，河汾可有房与杜？小雅式微夷狄横，人耳宫商非汉声。欲以身为百川障，远步皋父寻汐盟。二月梅江波滟滟，黄冠野服期许剑。车辙寥寥仅数人，共推我公主坛坫。谁知转眼便沧桑，白杨衰草两茫茫。岂真作记求长吉，且叩天关问彼苍。彼苍无语成终古，斜阳惨照一角圃。芙蓉憔悴不胜秋，寒波瑟瑟寒鸦舞。即今怕闻蒿里歌，依稀人在山之阿。梅水东流日千里，魂兮不归将奈何？

# 虬髯客
原：万丈红光海外起，坐拥扶作天子。绝世男儿惟有尔，中原且让河北李。虬髯戟张目怒视，当前猛见红拂妓。称兄道妹声未已，酒酣拂衣吾行矣，匹马驰风道万里。重过长安邸，王侯疑不是。赠讫黄金与慧婢，出门忽灭惊人鬼。楼船千艘相逦迤，鲸波翻风不见尾，使人闻之魂魄褫。吁嗟乎！杨花落尽李花死，大陆河山寸寸圮，安得斯人兮诛封豕。
