# 楚伧文选
原：叶叶字楚伧，号小凤，江苏吴江人。喜饮酒。为小说家言，一尊酒，一枝笔，终日不休。人谓楚伧之小说，皆酒话。楚伧笑曰：“酒话固绝妙小说也。”貌魁梧，有幽燕气，文则秀丽如吴中软水柔山也。余尝戏语曰：“以貌求之，不愧楚伧；以文求之，不愧小凤。”今录文七首。

# 青箱集序
原：吾母王孺人，伯瀛公长女，生余十一岁而卒，育余于母姨家。母姨暨其家人，恒称余性肖吾母。哀哉！母弃余早，二十年前事，杳不可纪。人称余肖，而余今守正以穷，平易近物，幸不旦暮死，当不致沦为异类，是庸非受诸吾母者乎？余继读《青箱集》，其传伯瀛公，所谓守正以穷、平易近物者，则余所受于母者，渊流可溯已。集凡若干卷，吾表弟青浦王大觉辑其高祖宾竹公、曾祖静波公、祖伯瀛公所著者。王氏世居乡野，其地非通都名邑、声闻相应者也。诸公服农力田，屏绝轩冕，其人非朝市标榜、援引近誉者也。《青箱集》行歌坐哦，适性以出，其文非酬酢颂祷、为世显著者也。宜可以不传。今竟赖贤子孙以传，传且或不朽，是非正谊所存，虽掩不湮，树德务本，足警薄俗者乎？大觉能述祖德，好文章，称道不遗先则，余因有眷眷焉。夫人贵有文以明理耳，君子行以践文，非文以饰行。诸公敦朴廉正，使人读其文，慨然景企其行。不然，世之能文者众矣，大觉视之，为何如哉！大觉早孤，其所成就，先泽为多。余亦自幸略肖吾母，然则《青箱集》之成，非特表彰幽德，规范文字而已焉矣。东江叶叶。

# 民国野史序
原：惟士能夺千钧万乘之欲，以继所志。后世论人之规，岂不本诸此乎？余谓革命之役，当始自己庚，其终则吾不敢知。孟子曰“民为贵”，使此义长在，俾多闻博识之彦，雍雍纪一代兴废，岂非吾人大幸哉！志士杀身不顾，以应一时之急。汉萍之役，犹夫桂粤，桂粤亦犹夫武汉焉。苟不建其极，斯志不达，则后之视武汉，焉知不与汉萍、桂粤同哉！然则《民国野史》，殆亦有憾乎！士君子识仁与义，不得志，不能行其道，慨然入著述之林，宁得已哉！顾世之事，恒不相从焉。试譬诸水，昆仑以下，碣石、龙门之险，或折之，或回之，然千里奔放，至东海而止矣。贤人君子之爱其国，所百蹶百起以赴难者，庸有异乎？《野史》之辑，今或在龙门、碣石间乎？是在识之者而已。

# 龟年清语序
原：菊仙少好拳武，京东子弟，交识殆遍。后列戎伍，走两粤。不得志，乃归隶陈国瑞。国瑞癖于酒，饮非菊仙不怡。一代悍将，屈于寄人，菊仙必有奇术縻之已。继归京师，益蜚其誉。宫庭之内，狎事天子，谐谑尽美，有敬新磨、黄幡绰风。世以孙谭并名，谭犹沈宋应制之作，孙则几于沉香亭畔山东李白矣。甲寅之春，为余言陈国瑞满庭芳遗事，故将当年，雄姿矍铄，言外怒然，有龟年江南之感。余慨然曰：“有清声色之侈，逸于前代，国瑞何足道？咸同以后，迄今四朝，珍秘之闻，实导近史。礼失之求，其在子乎？”孙瞿然如觉，曰：“不文之辞，不久不远。倘借藻饰，请自今始。”乃约每夕相过，作《龟年清语》一编。其间孙病暑五六日，余病疖半月许，则萤灯蝉笛，未间一夕焉。秦庭之经，诵于伏生；柱下之史，传自李聃。德徽虽遥，意犹在斯。稗野之存，其庶几乎？小凤序。

# 落花梦传奇引
原：情海多波，落花有梦。鸩媒成敌，凤侣终凶。一树冬青，碑蚀小青之迹；三关烽火，地铭铜柱之雄。红粉剸仇，天上原成眷属；青衫渍泪，人间未没芳踪。则有浣花女子，翡玉为神；磨砖郎君，琼蕤作骨。托宋玉于西家，坐羲之于东壁。誓言世世，灵鸾采凤之俦；私祝生生，并蒂合欢之叶。固已报李成章，包有吉已。尔乃煮豆燃萁，陈思膺其恶德；铤野走险，李渊起自嫌疑。赤帜竞登，苍头突起。危城夜半，羽檄星驰。边圻云垂，将军鼓死。郎原徇义，邂逅灭亲；侬自多愁，崎岖入梦。遂令良夜锄奸，祭秦庭之剑；乱妆去国，绝太真之裾。风雨四山，泣孤鸾于万里；云天一角，识鸣凤于穷途。燕子三春，似曾相识；鸳鸯卅六，盟未尝渝。何期荒草残碑，孤坟三尺；新恩旧怨，惟予一人。昔谐鹣鲽，今比枭獍。天辟艳情之局，谁为圆缺之神？于是惨殉恩仇，同归切利。托遗事于残碑，结双魂于连理。鹤归千载，感抔土之松楸；鹃老三春，餘野人之箪食已。

# 中萃宫传奇序
原：春殿千官，香浮仙仗；玉阶秋月，歌咽琼台。一代盛衰，千秋金鉴哉！清室艳史，陈隋比踪。月窟仙人，镂香作屎；春堤宫女，缠彩为丝。彼何人斯，粤乎尚已。今圆明草衰，颐和花落。佛香如梦，玉泉不波。独听江南龟年，泣诉故宫旧事。悲哉！老伶工孙菊仙谓小凤曰：“翳惟珍妃，六宫之秀，姱容葩发，修淑人范。文节娴达，词旨婉娈。既移长门，乃亲玄觉。思君未忘，时撷芬于蘅若；与花同命，恒寄慨乎芙蓉。”又曰：“中萃宫深，翠华恩在。葵忱恋主，如闻宛转之歌；锦牒通辞，略比断肠之句。洎夫胭脂井畔，魂断一朝；纸陌坟头，碑埋三尺。玉钩隋苑，无此悲凉；梨树马嵬，损其幽恨已。”又曰：“妃子玄衣缟裳，宝箓天锡。白云观外，云旌乍驻；玉京宫前，响屎时过。今则岁时寒食，谁簟酒于新坟？禾黍西郊，飞纸灰于旧梦耳。”小凤曰：吁！昔帝女花残，词传逸韵；长生盟拆，文擅奇华。不有艳踪，畴成令作哉！三年冬，小凤序。

# 说诗上
原：诗之作古已。击壤之颂，于古已著；濩夏继作，光国有章。然六诗之义，旨未修焉。《周礼·春官·大师》：“教六诗：曰风，曰赋，曰比，曰兴，曰雅，曰颂。”用体既殊，风、雅、颂为体，兴、赋、比为用。制裁斯别。《关雎》、《鹿鸣》，兴体所著；然《鸱鸮》、《鹳鸣》、《东门》、《伐木》诸章，毛、郑之义，不可不知焉。古者行人，必习于诗。孔子曰：“不学诗，无以言。”赵孟《常棣》之答，《左传》昭公二年。季武《甘棠》之咏，昭公二年。折冲尊俎，喻志睦邻，诗为尚已。洎乎周季，孙卿、屈原，离谗忧国，作赋以风。《前汉·艺文志》。隐怀悲恻，上绍三百篇之绪。然炎汉而后，赋颂先鸣，比体云构，《文心雕龙》。诗系所缵，因时别矣。姬周以上，宗于四言。后有作者，居文辞之要，谓四言文约意广，取效风骚，便可多得。又苦文烦意少，钟嵘《诗品》序。故三用之义，世或未违；择辞之习，因时渐异，而五言兴焉。夏歌曰：“郁陶乎予心。”《楚辞》曰：“名余曰正则。”直为滥觞。李都尉李陵。以下，建安、陈思、公幹、仲宣诸子。太康、陆机、潘岳诸子。元嘉谢朓、颜延年诸子。诸子，实树其风。云间抒其芬芳，庾鲍蜚其新俊。不特东南之美，亦且国家之秀。五言冠冕，于斯为盛。辞旨渐移，南北复异。江左发越，河朔贞刚，《隋书·文学传》。翩翩词流，遂多得失。然掇彼清音，芟其芜秽，洵乎斌斌尽美之作。而江、淹沈、约任、昉温，子昇。凤翥鸾翔，亦一世之俊也。陈、隋之主，习为靡丽，淫词荒政，君子少之。一时逸响，有空梁薛隶，庭草王郎，遇虽不淑，要亦未足与世主处耳。李唐一代，词藻郁郁，精深宏博，各尽其术。《新唐书·艺文志》。虞监扬其清响，沈佺期宋之问摛其芳华，岑参高适嗣韵于宸陛，李白杜甫树则于谪居。英英岳岳，蔚然可范。然之问曲阿昌宗，少陵倨见严武，狂易之渐，识者于是有忧矣。比近论诗，不恕中晚，而南山一什，炳灵百叶，非元白狷俗可掩。自唐以后，体制一变。论者言杜韩以下，风骚渐远。后有作者，非其比矣。

# 说诗下
原：有唐既熄，海内扰攘。五代十国，朝夕相替。士夫视朝廷如传舍，无气节之可言，而诗道亦衰矣。即有作者，亦患靡曼。潘佑、李昊，唐蜀之彦，然其人不足称焉。李煜、王衍，才藻焕发，皇帝误人，斯近蝶冶。香阶划袜，愁水东流，诗道拙而词语盛，靡然亡国之音也。虽然，诗文之所以变，亦有不得已者。顾亭林语。炎宋既兴，大而朝廷，微而草野，所作赋咏，动成卷帙。《宋史·文苑传》。庆历、元祐，群俊淑发，西昆缛丽之风，于焉渐息。欧、苏扬其清徽，梅、石驰其逸响。炎宋一代，炳然有文已。继以起者，贺铸之似宣城，鲁直之模少陵，江西一脉，遂孕其胎。今世学者，宗尚綦盛。是亦尚论诗文者所当知也。靖康以后，华采渐汨，翳惟范成大陆游东南之秀，然思力艰涩，实启元词，君子于此不能不叹去古之渐远矣。至于文山正气，则忠义之元，要未可与词林比论者。辽金创建北胡，人文惟杀，虽有王鼎庭筠，又何足称？蒙古入帝，缵继宋绪，所谓通经能文，当世彬彬者，《元史·儒学列传》序。稽首异族，曲媚国仇，姚、枢许、衡金、履祥吴，澄君子羞称焉。洪武一叶，初摈强胡。以诗鸣者，有刘基、袁凯，然气体萎疲，以媲盛唐，弥多惭色。至于永、宣以后，二李竞作，东阳、梦阳。上绍汉唐；而王世贞、归震川之徒，各立门户，以为低昂。至启、祯之际，东林诸彦，郁然华发，矩濩汉唐，以召学者。明覆其社，声光彪炳，轶于前古。用知诗之得失，密尔风化，不仅扬葩发藻已矣。清室初创，山水遗彦，抗居不屈，乃设为鸿辞，以诱士类。声闻相引，间有硕彦，牧斋、梅村，幽然去国之思，世论比于庾信，而船山、午梦诸公，雄姿英发，不忘恢复，非初清所得而有。然则虽谓清初无文，又何不可乎？同光体兴，好为奇僻。今世作者，类宗于此。而华采繁缛者，亦翔步中晚唐间。虽不足称，以视裨贩东西，驳不成章者，亦差善已。嗟乎！余考历代诗道之兴废，而有所感矣。后生小子，不能并辔屈宋，联镳鲍庾，而生于群籍充栋毕生莫穷之世，固将何所择哉！亭林曰：“近代文章之病，全在摹仿。”然则吾将尽弃古人以自树耶？语曰：“道可致而不可求。”诗亦有道焉，在人自致之耳。苟得其道，莫或不彰，又矩濩进退何为？
