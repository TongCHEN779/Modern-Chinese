# 匪石词选
原：陈世宜字匪石，江苏江宁人。今录词十六首。

# 贺新凉吊史阁部墓
原：廿四桥边路。黯魂销、疏烟淡月，岭梅千树。汉代衣冠今在否，付与寒蛩自语。更几辈、芜城能赋。一水弯环山下过，共江潮、鸣咽声如诉。禾黍恨，一抔土。残旗旧日临江浒。痛南都、松楸不老，河山非故。石上遗书琳琅字，万古云霄一羽。问华屋、生存何处。《燕子》《春灯》歌舞歇，废园亭、门掩风和雨。争似此，百灵护。

# 六幺令
原：薄寒侵幕，钿阁暗云积。春心逗成微雨，望里乱丝织。柳眼才舒又倦，惘惘楼头色。露桥尘陌。东风绿遍，甚处天涯万山隔。犹忆催花座上，羯鼓曾亲击。却怕归雁声中，锦字难寻绎。依样年华似水，门掩梨花寂。古欢追觅。探芳人老，静倚阑干手空拍。

# 沁园春槟屿赠莼农
原：历历关河，万里投荒，强说壮游。任歌成锦瑟，独弹古调；吹残玉笛，暗寄清愁。法曲飘零，文章羁旅，何处骚坛盟订鸥。帆风利，喜足音空谷，送到扁舟。夷犹。鸿爪痕留。况一例吴歙能唱酬。念词人花外，新歌迭奏；游踪海漩，奇迹穷搜。片片蛮云，声声犹鸟，写入蛮荒志异不？君须记，是仙山有主，气食朝牛。

# 浣溪纱和孟硕狱中韵
原：枫冷霜凄月落时。西风吹老玉参差。危阑烟锁夕阳迟。片片愁云迷雁塞，丝丝泪雨洗燕支。几人解道是相思。

# 摸鱼儿重九
原：叹秋风、者般容易，一年一度重九。沧桑人世烟云幻，三径黄花依旧。还剩有。那带病枯蝉，几个嘶残柳。柔肠转又。在百尺台荒，千峰树秃，风雨满城后。登临处，一片悲笳迭奏。西风险被吹瘦。惊寒梦与声俱断，北雁南来时候。休送酒。听郭索声声，闲却持鳌手。愁丝织就。况念远伤高，牛山竟夕，红泪染枫透。

# 蝶恋花和中垒韵，即以为赠
原：淡月侵帘寒拥袖。剑胆箫心，为甚年来负。点点泪痕襟上旧。纱窗影贴灯如豆。不是黄花魂也瘦。写人秋心，摇落江潭候。展得愁眉眉又皱。填词老去闲清昼。
原：沉醉钧天高尺五。花事阑珊，不与春为主。银烛烧红深夜语。高丘零落嗟无女。血泪斑斑啼杜宇。梵呗无聊，帘底教鹦鹉。沦落天涯心共许。西窗同听芭蕉雨。

# 卜算子
原：记得冶春时，燕子双双语。寂寞帘栊燕又来，帘外丝丝雨。愁共暗鸦啼，梦逐归鸿去。白日无情解笑人，悔劝驹光住。

# 烛影摇红 久滞瘴海，归期屡讹，倚此写怨
原：草色无情，绿窗永日深深护。炎云净卷换新凉，一枕啼秋雨。笔底都无秀句。客愁深、年华暗度。倚阑遥望，一发神州，家山何处。鹤冷猿孤，小园红萼谁为主。玉珰空有别来书，掩泪和鹃语。底事将春系住。怅归期、而今间阻。可怜依旧，梦里乡关，天涯羁旅。

# 好事近 题娄东某夫人《红情绿意图》
原：灿烂玉交枝，腕底破寒犹力。一幅鸳鸯春软，绣金针神得。双声敲与翠禽听，孤山漫相忆。临镜额妆自写，透南枝消息。

# 声声慢 题秦特臣《淮海诗词丛话》
原：微云情绪，小石宗风，虫丝夜吐秋深。月冷钩残，天涯无限伤心。潇湘带愁流后，剩黄鹂、长伴孤吟。寥落感，是人和天瘦，又到而今。重把珍闻收拾，对飞花片片，独吊藤阴。劫火灰干，人间享帚千金。淮海文字，曾罹元祐党禁之厄。方回一般肠断，更西河、墨泪盈襟。芳草恨，算江南、幽梦未沉。

# 霜花腴菊花，和梦窗韵，依四声
原：泪丛怨色，仗晚香，重来恋取衰冠。霜影愁孱，月痕疑碎，秋心替写仍难。故园地宽。劝素英、休落风前。向孤松、旧约追寻，径荒秋老倚天寒。闻说露枝犹见，甚惊飙一夕，又蜕枯蝉。才得黄回，依然金散，斑斑恨墨题笺。泛觥作船。倩滟波、留住婵娟。怕无言、淡了伊人，卷帘相对看。

# 瑞龙吟淞滨久客，游赏多在徐园。离合悲欢，事乃万状。乙卯立秋前一日，春音词社又集于此，檗子和清真此调见示，率同其韵
原：长堤路。还见冷翠侵苔，暝烟笼树。枝头声咽残蝉，院槐自老，新凉处处。漫回伫。前度绽桃春晚，笑窥帘户。年年换却秋风，旧时燕子，西窗倦语。重鼓探芳兴，采菱低唱，垂杨慵舞。桑海泪中相看，人半新故。冰弦掩抑，无限伤心句。凭谁话、江皋佩影，幽廊屎作平步。过眼繁华去。题襟剩有，诗情酒绪。平翦愁千缕。偏又是，纷纷梧桐吹雨。梦痕暗结，一天云絮。

# 甘州送重由二弟之京师
原：正潇潇暮雨做清秋，西风动江城。灯窗双影，绳床碎语，浊醑深擎。别绪千丝未理，津鼓促征程。昨夜微霜雁，寒阵初惊。莫重话飘蓬身世，渺故园一角，梦委荒荆。况风尘催老，华发渐星星。望长安、浮云轻蔽，幻古愁、桑入海波腥。叮咛语、有宫驼泪，休洒新亭。

# 桃源忆故人遁初三周忌日賦感
原：青青堤柳窥人眼。昙梦三春犹短。鹃血枝头红溅泪，点荆驼满。花城低祝香魂返。津鼓桃源谁唤。日绕画梁千转。几个衔泥燕。

# 浣溪纱三月二十一日同檗子作
原：听彻当筵定子歌。杨花带雨舞嗟嗟。梦回九九夜寒多。化骨错疑丹药换，孤琴痴盼素弦和。羞红强说醉颜酡。
