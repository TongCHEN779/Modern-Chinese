# 漱岩诗选
原：王葆桢字漱岩，浙江黄岩人。今录诗三十九首。

# 醉后看弄乌古刀
原：短袖拂吴刀，古金时一陶。土花青似发，酒气怒于涛。安用毛锥子？何如屠狗豪？摩挲三眦眇，长啸霜天高。

# 孤檠
原：孤檠耿遥夜，无梦亦无诗。沧海渺一粟，须臾生万期。愿人庸且福，是我癖成痴。破籁天鸡唱，神来隐几时。

# 枫香驿题壁，驿在宿松
原：十里枫香路，深林傍晚车。孤村悬树杪，野火出岩岈。独有采樵者，而无卖酒家。西风吹马首，山影一灯斜。

# 宿凉亭河
原：村抱溪流曲，松多觉晚凉。半林茶雨老，十里麦风香。草活长蛇路，苔生牡蛎墙。田翁归山市，灯火近昏黄。

# 岁暮送友归湘
原：日落沧江晚，客愁生岁阑。洞庭八百里，直上几回滩。灯向谁人语？云留独树看。南枝恋越鸟，烟岛路漫漫。

# 杨哲商烈士悼歌七章
原：三台星宿光落离，应精杰出杨飞儿。十三众以神童目，峥嵘头角才不羁。丈夫当学万人敌，一书一剑将何为？甲兵罗胸见文字，呼风吸雨神鬼悲。曾靖吕留良再见，恐罹杀身师戒之。鸣呼一歌兮歌迟迟，万八峰头日出时。
原：黄衫年少真英雄，赤脚踏海海水空。歇浦滩头遇秋侠，秋侠识为人中龙。浙江潮接皖江起，寡姥谣传陈涉通。军储潜遣五丁运，狐鸣篝火期相从。中道忽闻轩亭败，钱塘欲渡不得东。草间偷活忍饥走，缇骑大索党人同。鸣呼二歌兮歌未终，途穷一哭生悲风。
原：轩轩郁起赤城霞，匈奴未灭何为家？鬼薪奇书读密室，含沙射影来幺么。秋风吹散耀梓校，补天呼石呼灵娲。满腔热血向谁洒？龙泉挂壁鸣哑哑。鸣呼三歌兮生有涯，踯躅乡里长咨嗟。
原：大熊飞起皖公山，麒麟以外见一斑。博浪锥逃十日索，荆天棘地危乎艰。一例党人艰插足，匡庐山下蛇蝎顽。天生健儿好身手，禽王禽贼权等闲。请于伯氏答曰可，乌容郁郁居此间。不如归去啼杜宇，楼兰未斩羞生还。鸣呼四歌兮歌欲闲，大江东去流潺潺。
原：七二黄花战骨霜，遥挥涕泪瞻高冈。马革裹尸原不辱，生虎口多逃亡。河山本我汉家物，难容虏焰恣披猖。春秋大复仇九世，同志寥落谁商量？一夜哀猿动三峡，同胞惨杀天无光。鸣呼五歌兮歌声长，引领蜀道摧刚肠。
原：风云莽荡武昌城，大陆龙蛰雷一声。豪杰蜂起天下走，江山半壁东南倾。侨沪覆壁学张俭，裹铁手弄一丸轻。金汤儿跪颠扑破，石头铁瓮徒虚名。喜闻直捣黄龙府，拍案惊落灯花明。飞电流丹触导线，大化真火还无生。鸣呼六歌兮火纵横，海上夜夜怒涛鸣。
原：姑苏台下麋鹿游，鬼雄夜啸声啾啾。髑髅提还八百里，西湖湖水空悠悠。香涕一龛配徐社，陶坟沈墓峙一丘。咫尺西泠桥畔路，满天风雨空亭收。生前等隶党人籍，死后好共湖山游。鸣呼七歌兮歌且休，民国万岁魂自由。

# 送邵次公之日本
原：钱塘生春水，严濑下孤舟。书剑东南客，风云西北愁。呼天同一醉，入世等于囚。便欲扶桑去，相随狎浪鸥。

# 赠徐公孟
原：落落徐公孟，青年多苦吟。湖山话春雨，人海见秋心。杜牧痴无梦，嵇康贫有琴。愿言赠之子，珍重作元音。

# 题不系舟轩，为陈慎登作
原：天地一虚舟，吾生真个浮。神州同过渡，沧海正横流。风利不得泊，陆沉无尽愁。拦江矶有石，漫放洞庭沤。

# 子夜歌，海上楼外楼作
原：怕损鸳鸯履，随欢蹑电梯。凌虚怯小胆，素手索欢携。
原：今夜侬无事，请欢来吃茶。渴中须择饮，记取雨前芽。
原：蝉翼纱衫薄，脂香袖底过。劝欢莫久座，风露夜凉多。
原：小立哈哈亭，镜中看欢面。欢面有时改，侬心还未变。
原：亍喷水池，水喷如散珠。还家裙子湿，偷换合欢襦。

# 遮天
原：遮天只手大如斯，覆雨翻云不可思。东海药寻徐福去，北山文待稚圭移。有人猿臂封侯易，几个鱼头参政迟。夜静中原一望气，星辰明灭是京师。

# 张星伯席上呈徐班侯先生
原：六九雄心尚未销，天荒地老总无聊。狂歌慢骂非关醉，独向东瓯负大瓢。
原：龙虎须眉入画图，南江潮落月轮孤。黄公垆畔思风雨，三老于今不可无。班老曾与家子裳师、吴兴沈子培先生作《南江三老图》，余有题句。三老昔在都下，日与黄漱兰前辈文酒之会。
原：一代经师孙仲容，名山大藏辟洪濛。蟹行文字来瀛海，六籍笙簧白虎空。
原：少年喜读《郁离子》，低首青田是国师。六百年来兴废事，一尊拇战夜谈时。
原：天保城头汉将飞，江山两道浙军旗。主人别咽同袍泪，磅礴尊前解血衣。星伯籍青田，去年曾与其同邑叶仰高各领一支队攻进天保城。席次谈叶阵亡事，闻者咸悲壮。
原：浮生诗梦自瞢腾，侠武儒文两不能。人海中藏一我在，残书古剑短檠灯。

# 自杭归台，取道海门，有友征歌劝饮，六潭老人同坐，作此赠凤仙、桂花、韵仙、红玉诸校书
原：解语筵开四照花，玉山人比玉无瑕。诸校书皆玉山人。少年悔被多情误，游骑何堪问狭邪？
原：海天归思正茫茫，除却温柔不是乡。那解信陵醇酒意，合欢杯满泥亲尝。
原：欢场如梦梦如痴，镜里河阳鬓已丝。我惜惺惺重自惜，天涯沦落得归迟。
原：弹破莺花五万春，乔装娇带女郎嗔。琵琶漫谱浔阳曲，恐有尊前老大人。

# 与胡寄尘同话海上茶楼，介绍赵坚白入南社，作此纪念
原：南天文宿聚词坛，如此中原缩手看。谁信骚愁真可祓？许多歌泪总无端。不磨傲骨生今世，添个新知结古欢。大雅扶轮吾辈事，秦灰历劫未曾寒。

# 白云庵访谢印山不值
原：南屏访兰若，白云在天际。幽人去未还，空斋锁寒翠。僧问客何来，题壁作留刺。才子见佛易，合踪三摩地。惭予羁尘鞅，云山失所寄。诗成僧点头，三昧证游戏。

# 周六介招饮，即席有作
原：烂泥新擘瓮头春，越醴浓斟醉杀人。天上枭壶方角戏，时雷电大作。尊前诗胆独轮困。朋簪偶合今宵雨，拇战传喧一席宾。豪矣周侯监酒政，襟痕狼籍廿年尘。

# 春夜同沈半峰、杨畏九、陈简文饮半斋
原：买得春如海，斋闲恰四人。乡心萦六岳，齐巨山游记：合天台为六岳。潮信警三神。尊合愁边雨，花飞劫外尘。我生无尽醉，何用问来因？

# 嘲半峰
原：一笑哦诗沈半峰，苍蝇声与六经同。昌黎死后禅关闭，任尔推敲耳已聋。

# 集饮湖楼，次半峰韵
原：湖上题襟认酒痕，典裘春买一垆温。感花独洒东坡泪，种柳还招苏小魂。世外樵风何日便？尊前旧雨几人存？凭阑别有伤心事，北望浮云蔽日昏。

# 西湖品茗
原：西湖春色浩无边，楼外青山楼下船。明镜有情留客影，与友人照相。软帘何意护茶烟。风谣吹到都成警，诗谛参来即是禅。不问麻姑东海事，新声同唱鹧鸪天。

# 清明后一日，叶子布集饮宝石山
原：江声湖色落尊前，跌荡鸳花又一年。亭废尚歌来凤曲，有来凤亭。石顽谁着祖龙鞭？山下有始皇缆舟石。四围烟散诸天暝，绝顶风盘一塔圆。铁弩挽强望公等，海潮东啸正无边。
