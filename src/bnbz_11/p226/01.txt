# 无尽诗选
原：周实字实丹，号无尽，江苏淮安人。今录诗十四首。

# 哭洗醒
原：中夜起长号，生离复死别。生离冀重逢，死别长隔绝。呼天吁地两无灵，谁令陈死人重热？噫嘻朝菌蟪蛄本无常，庄生达者齐彭殇。等无返魂香，等无续命汤，几人寿比高松长？吾侪后顾前百代，悠悠尽是蜉蝣辈。蜉蝣变化朝夕间，感此群生重有慨。何况平生刎颈交，恶耗骤闻珠玉碎。枫青月黑为招魂，天涯欲祭还疑在。哀哉秋澄方死亦吾之契友，亡于九月间。洗醒丧，悲伤未了增惆怅。尘寰从此知音稀，剑气箫心谁与抗？剩得区区后死人，七尺残躯亦可葬。溯昔扁舟淮上游，一灯风雨秋复秋。卧时抵足坐并头，自诩祖刘李郭未足俦。其时狂奴负狂名，少年眼底隘沧瀛。纫兰搴杜更多情，年年佳耦求云英。哀哉古来益友今无多，笑我骂我纷则那。独有洗酲莞尔言，抉子病源子毋冤。谓子毋骄矜，嘉言懿行当服膺。谓子毋愤嫉，种危国弱当太息。谓子毋激烈，党锢东林惩往辙。谓子毋呆痴，岂是妇人醇酒时？谓子毋缠绵，终有飞花落絮天。蒙君热心苦口相挚爱，棒喝钟警极感戴。无端劳燕忽分投，云树苍茫寝食废。嗟嗟南船更北马，相背时多相见寡。乌飞兔走换春秋，博得深宵杯重把。酒杯未放骊歌起，与君欢会从今止。君住袁江作寓公，我滞秣陵号游子。寓公游子两相望，山水迢遥多阻障。恨无两翼御风行，仅恃尺书悉佳况。尺书千里相砥砺，更勖寒喧善保卫。知我时忧管仲贫，呼天屡雪长沙涕。哀哉深情尽付相思字，所惜飞鸿不时至。每遇射湖黄浦人，殷勤问讯到风致。朝问讯，暮问讯，聊取寸心相印证。讵知霹雳一声惊，君遽弃我归九京。请将胸中血与泪，尽向死友坟前倾。吁嗟乎！洗酲洗醒不复作，何时重化归辽鹤？思量往事都成尘，只有音容宛如昨。安得旅馆重联床？安得春宵重举爵？安得花时同宴游？安得月下重谐谑？安得风雪重牵襟？安得河梁重订约？一言一语渺难闻，碧落黄泉何处索？吁嗟乎！照不见故人地下骨，愤欲碎天边月。听不得故人地下语，怒欲骂窗前雨。雨声月色两无情，只有四壁秋虫诉不平。不平枉向人间诉，梦魂才是相逢处。魂来梦往纵可期，又恐错认人天路。此作为无尽庵集外逸诗。洗醒姓陈，名友徐，能诗文，与君曾同学数年。编者附记。

# 岁暮杂感
原：风霜不改岁寒姿，灯火沉沉似昔时。千古朝廷悬北极，一春消息在南枝。蟠桃熟后初开宴，芳草吟成煞费词。勋业文章俱未就，男儿心力敢辞疲？
原：堂堂白日苦相催，烂醉狂歌且莫哀。紫玉烟消人不见，黄金台峻士羞来。安能跨凤寻仙侣？未必椎牛尽将才。杨柳成围无限意，苗条独记昔时栽。
原：文采风流晋右军，罪言还拟杜司勋。人民城郭年年異，环佩笙歌处处闻。豹隐山南成遁世，马空冀北感离群。卖文未合为生计，一夕都将笔砚焚。
原：莫任乔松诩大年，且邀司命共醺然。野萝山鬼愁人世，成句。瑶草琪花宴众仙。不卖痴呆甘守拙，但求寂灭未逃禅。小姑独处无郎惯，那用悲歌相府莲？

# 公园看牡丹
原：敢将颜色说倾城，雒下无端擅盛名。岂必风流皆没骨？还愁富贵易薰心。清平古调知难继，专制群芳未可任。别有回肠风物外，碧阑干畔几沉吟。

# 赠钝剑
原：少陵身世一沙鸥，深恐蹉跎便白头。我剑无灵君剑钝，人间何处托恩仇？旧号剑灵。
原：千年荆聂骨成尘，谁是擒蛟射虎人？与子消沉文字海，野萝山鬼泣灵均。

# 长亭曲
原：江北江南别路遥，旗亭酒熟脱金貂。引人无限缠绵意，不赠梅花赠柳条。

# 痛哭四章
原：腥风血雨误归期，痛哭江头杜拾遗。弩末已无穿缟力，刀头休作赐环思。狰狞猛虎磨牙日，夭矫神龙见首时。虏运将衰炎运在，南阳会睹汉旌旗。
原：瘴雨蛮烟路几千，楝花落尽一潸然。三年化碧心难灭，九转成丹目已穿。誓起鲁阳麾赤日，忍教胡月犯黄天？匣中夜夜青锋啸，愿作人豪不羡仙。
原：日暮归来泪满襟，钟期去后判椎琴。春花寥落无生气，夏木凄凉有死心。遗恨千年秦殿柱，招魂三月楚江浔。长缨枉说擒南越，年少终军不可寻。
原：直将刍狗视人群，无限苍凉日暮云。壮志未酬填海岛，痴心枉作负山蚊。荒烟孤岛田横客，夜月悲笳翟义军。猿鹤沙虫同一烬，累累七十二荒坟。

# 玄武湖观荷，用人菊《射阳湖观荷》韵
原：悄立湖水滨，喜与鸳鸯熟。娟娟湖中花，千顷漾一白。日落微风兴，触鼻皆芳馥。翩然若登仙，转惜形骸俗。淡泊能宁神，繁华本非福。花花互相语，毋使红尘渎。物我两庄严，睪然怀茂叔。
