# 屯艮词选
原：傅熊湘字屯艮，湖南醴陵人。今录词八首。

# 江城子己酉五月五日与牧豨、葛生、约真携酒饮太一狱中，太一赋词见示，次韵酬之
原：南幽沉怨夏飞霜。梦荒唐。最堪伤。偏是愁时、岁月逐人忙。细柳新蒲饶节物，听叠鼓，闹端阳。且图欢聚慰相望。意茫茫。酒行行。漫写填胸、万恨唱伊凉。此会此时今世少，人五个，愿无忘。

# 鹊踏枝
原：老我年华驱我苦。世事如棋，著著都成误。两字穷愁天付与。不堪持向人间诉。谁是谁非难计取。春去花残，一例随尘土。料理扁舟湖上去。钓竿斜日蓑衣雨。

# 如梦令
原：见也匆匆如梦。别也匆匆如梦。来是梦中来，去是梦魂相送。如梦。如梦。肠断魂销心痛。

# 罗敷媚
原：灵均天问无消息，纵有难凭。况是无灵。叫尽重阎未必应。朔风苦助寒威虐，已过霜零。早又坚冰。只合长眠睡莫醒。

# 天仙子送别
原：春欲归时春不语。零乱春愁何处诉。愿春莫听子规啼，春且住。春休去。肠断天涯芳草路。

# 点绛唇
原：小院冬残，映窗衰柳摇疏影。旧愁难定。新恨还相进。倦旅恹恹，霜色催寒瞑。孤衾冷。夜长人病。未睡先妨醒。

# 浪淘沙
原：孤馆夜灯昏。静掩重门。残冬作客倍销魂。便说今宵寒透骨，谁与温存。旧事不堪论。枉负新恩。年年芳草送王孙。别也寻常离也惯，梦也无痕。

# 浣溪纱别长沙诸友
原：欲写离愁一万重。可堪流水自西东。三更残雨五更风。
原：未办白头终有约，即抛红豆更何从。浮生踪迹似飘蓬。
