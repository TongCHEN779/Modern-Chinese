# 一厂诗选
原：林百举字一厂，广东梅县人。今录诗二十九首。

# 即席贈天健
原：吹箫茧足走趣，又见蜩螗世不堪。差喜粤华楼上望，一宵风雨满江南。

# 观冯春航演《儿女英雄传》新剧赋赠
原：余素不善观剧，当场只觉有声有色、有舞者有跳者而已，一切管弦节奏，剧本神情，咸格格然，不终席辄去。月来社友啧啧称冯春航不置，心窃讶其或必有异于常流者，稍向慕之。而亚子适见邀，喜往焉。及冯出，果大有异，廿年来眼帘脑海，几若为之变易，绝不格格；而入声入心，通情与神往矣。岂以揄扬之词，先动于中故耶？抑冯之感人，真若是其深耶？爰因所触，成四绝句，俚鄙不计也。敢质亚子，以为何如？
原：翩翩乍睹若惊鸿，矫健偏含妩媚中。几度挟弹凝不发，此时玉树正临风。初出，遇安龙媒遭难时。
原：红潮颊上泛朝霞，气斩幺么数叱咤。细认往来灯火下，六郎步亦似莲花。人能仁寺击杀众僧时。
原：红氍毹倏变修罗，谁向幽宫出素娥？侠骨柔肠真切处，泪痕应暗透微波。入寺地室救张金凤，烈女引其父女相见时。
原：嫣然一笑显情痴，也算姻缘合满时。只惹旁人翻妒煞，妒他扑朔又迷离。在寺为安龙媒与张金凤指婚时。

# 观冯春航演阴阳界悲剧
原：相宜缟素艳巾哀，天上霓裳别样裁。一幕偶然装鬼子，销魂可识贺梅来。

# 述事
原：好兴冲冲忽惘然，彩云一散奈何天。羊车碧碾行原疾，凤尾红拖影可怜。未敢轻呼空脉脉，只对舞亦娟娟。归来细数灯花落，可有芳魂梦里牵？

# 无题四首，为冯春航作
原：黄梅时节雨连宵，天启琼楼列女朝。羯鼓三声惊碧玉，桃花半面出红绡。迷离满眼皆幺凤，动颤全身似翠翘。惭我近来愁病里，无多魂也为伊消。
原：真个人疑到广寒，玉神花样世曾看。压他粉黛千丛绿，沁入灵犀半点丹。笑比樱桃开更小，颦将西子效犹难。唐宫隋苑朝和夜，怪得江山一曲阑。
原：鼙鼓烽烟且漫惊，而今四域正升平。俳文应废伶官传，诙语原传曼倩名。卿自散花神说法，我因遇物惯留情。红牙幸莫成商徵，南海鲛珠泪已倾。
原：谁是瀛州太白才？清腔妙拍费新裁。英雄儿女情非幻，血泪双碑剧可哀。云外游龙刚舞罢，月中皓兔入怀来。从今春浦人归去，红豆添抛梦一回。

# 次韵和鹑、楚伧、朴庵岭南楼即席之作
原：年年绮绪荡成春，芳草天涯倍觉亲。蝶过蘧然身外我，燕来飙若幕中宾。沾花著絮都随意，刻笑摹颦最入神。如此闲情虱人世，自怜自语醉时真。

# 梦作诗数首，醒记“鼓吹诗肠砭俗耳”、“听卿一曲胜黄鹂”、“生成美目顾横波”三句，足成二绝
原：油云幕幕雨丝丝，正近江城梅落时。鼓吹诗肠砭俗耳，听卿一曲胜黄鹂。
原：生成美目顾横波，比较豪情亦若何。岂止魂销柳三变，青衫我已泪痕多。

原：灌婴井动大江风，海水群飞直撼空。万丈猪龙麟甲解，三秋雕鹗羽毛丰。玄黄血战端开始，黑白横弹局遽终。此处分明有公论，谁将成败定英雄？

原：万古降幡出石头，而今主将更无谋。八千项羽江边泣，五百田横岛上羞。借问陆沉谁任责？遂令瓦解负同仇。龙蟠虎踞空城在，弃甲于思一去休。
原：赌命男儿竞要钱，横磨十万化腰缠。是谁妙计朝三四？只恐交征日万千。天下民穷鸿雁唳，西来宝气蝮蛇涎。从知吊伐原徒侩，赤帜纷纷汉赵搴。

# 樵妇
原：嘹亮山歌隔岭闻，采樵士女自成群。红衫浃汗疑行雨，黑帕蓬头映乱云。半世艰虞薪臼惯，梅县方言称媳妇为薪白。一肩家计藁砧分。炊烟起处催归急，憔悴谁能惜此君？

# 山村妇人刈稻
原：最苦田家是岭南，拮据胼胝女如男。严霜烈日六十月，岭南农事六月、十月二次收获。碎谷残禾三五担。椎髻沾泥云乱叠，腰镰蘸水月初函。稚儿一榼塍边饭，犹向新登未忍啖。

# 宿长乐县城
原：衰草凄迷满地霜，平添诗料在荒凉。千峰势合山城迥，几处烟昏村落藏。西上蓝关怀马迹，即昌黎谪潮所经，有“雪拥蓝关马不前”句。南流琴水叹沧桑。水名琴江，水涨时，城内外民房冲塌大半。斯人恶听东迁说，日指周王咒汉皇。自光复后，邑人议迁县治，附城居民不愿，争持甚烈。

# 过兴宁，忆亡友刘节膺、何公博
原：宁溪一泻众山沉，萧瑟堪悲二士心。名氏当时编党籍，风流到此杳人琴。潇潇夜雨鸡鸣嶂，兴邑山名。黯黯荒烟枫树林。纵使吴门展悬眼，麟伤凤死恨犹深。

# 山中见孤柳
原：无花无酒更无莺，不傍江堤不近城。此地居然半书室，不知何许一先生。风流莫问添萧飒，眠起应知失性情。最是月明休顾影，满山烟露太凄清。
