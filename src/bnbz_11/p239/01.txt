# 蜕庵诗选
原：陈蜕字蜕庵，江苏阳湖人。今录诗四十三首。

# 怀灵隐寺
原：少年几载住西湖，双桨芙蓉兴不孤。乐水未如苏白智，入林曾与阮嵇俱。笋香远透千竿竹，饭熟偏甘一味蔬。自落尘埃过五十，清游以外总模糊。
原：前生疑是此山僧，一入山中涤万尘。岂为桃源能避世？更非勾漏可修真。林峦乍看如曾到，猿鸟无情亦与亲。太息当时轻作别，白头终隔似湘秦。
原：寻僧访腊说东坡，壁上题诗未尽磨。远谪还能偕慧婢，行吟尚自感春婆。嗟余一失湖山趣，去日全从愁病过。浪说游踪遍海岳，西泠旧约总蹉跎。

# 悟情
原：此乡谁与号温柔？一到情深便是愁。谁使微之托修道？可怜小杜苦求州。是真并蒂花无一，能了今生世有不？怨绿啼红因底事？白头还自说风流。

# 原病
原：情愁积久都成病，病去情愁又别生。绿满池塘雨后草，碧荧帏幕梦回灯。茂陵笑尔捐秋扇，垓下何人作越声？欲待饮冰销内热，侍臣昨日赐金茎。

# 怀古
原：人间何处是吾乡？只有温柔未易忘。淘尽胭支江是泪，著些粉黛墨都香。玉钩梦觅横斜路，响屎愁过宛转廊。锦瞫绣褫千万卷，个中检点几情场。

# 秋帘
原：晚凉日日上钩时，纨扇生纱见过伊。消得几天风共雨，更休隐约著想思。

# 最愁两首
原：分明颦黛隔河看，欲诉离愁却是难。屈指秋期秋已尽，最愁心地到冬寒。
原：销魂还是有魂时，更不销魂事可知。佛说色空真浅义，最愁空处著相思。

# 欹枕挑灯，雨声点滴到耳，如僧寮揽鬓，回念罗帐江天，铃语断续，吟情往来，宜其诗有梦境也
原：右军一作誓，遂若神鬼知。已逝万情水，悉被回风吹。今愿宁不实？往事非足嗤。寸心有根柢，掩覆何所施？行行入曲径，幽邃非所期。乍觉所期左，旋忆曾来时。花丛隔层障，不目而已窥。此中久风雨，秾华非故姿。关心最手植，一一同仳。坠蒂罥丛网，霏英辞荣枝。憔悴岂伊劫？摧败皆我为。无声亦於邑，对影增凄其。忘身阻奔救，乐死迟追随。吁嗟情海波，汨没乃至斯。天倪欲飞跃，形神浑接离。处真莫忘幻，入梦非言疲。燃犀久无力，内照无所持。安能息外物，转以滋群疑。百年亦已半，双鬓亦已丝。所思不可即，宁惜身奔驰。奔驰恐歧误，冥想无因依。身魂两无就，不死亦相遗。窗前雨如语，断续谁为之？天问久无益，何况代以诗？

# 述梦
原：有梦都为累，无情未是空。佛言因一念，我欲证双通。自古都言幻，斯人未发蒙。残灯亦如病，相对怯秋风。

# 足疾一百日，九月廿三始杖行室中
原：竞渡偏教足不前，以五月五日得病。登高节过尚高眠。一朝喜免人推挽，十步能随杖转旋。早已达观忘四体，无如生世赖双趼。头头俗事来心上，莫去尘根是得天。
原：悟彻玄微息息通，此身原在有无中。用陈梦棠女士句意。飞尘满眼悲欢过，逝水流年得失空。便礼如来何世出，只除太上尽天蒙。启衾知免不消说，诚到忘形是始终。
原：我见从今未可除，不言无我是真无。钟情莫漫区人己，大道由来浑实虚。当日未曾生使独，后来终信德非孤。七情淡尽身何倚？内念全凭外物扶。
原：解腕从来称壮士，断头尚且有将军。不堪胫大逾于股，岂为臣强失在君。锋试倭刀将见骨，力支叩杖与同群。屈伸非比无名指，便有秦医孰使闻？
原：南尽交循北大都，岂惟安步可当车。一从寝疾呼门弟，久废徒行僭大夫。失屦何曾惊豕立，携竿权用代鸠扶。无杖，以竹代。问年未及杖乡国，莫便指麾傲里闾。
原：危则相持颠则扶，此君原自不能无。桄榔未乞花猪换，筱荡今先竹马驱。漫笑空心同老树，谅因错节免枝梧。皇娥若肯偕游戏，便结芳茅作相乌。

# 上红拂墓四首
原：巨眼当年识俊才，可儿不共此间埋。锦衾角枕青山久，细骨轻躯马上来。环佩魂归阏氏冢，钗钿梦断玉妃嵬。红颜命薄终如此，愁绝南征独凯回。
原：寂寂春原土一抔，鸟啼花放尽堪愁。便无名字还惆怅，况忍才容竟死休。当日知卿除是侠，可怜得婿只封侯。山前空勒征南像，不画天人恨虎头。
原：忆昔沉吟苏小坟，西湖鸳水两难分。苏小坟一在西湖，一在鸳湖。或言皆出附会。征南道出留遗迹，西山有磨崖卫公像，其下永福寺，为追荐而建。扶病军行补阙闻。只借汝南传碧玉，肯教阳羡葬朝云？风流最是人间少，华表休题开国勋。
原：文推房社武褒鄂，难定萧何第一功。丞相堂前有天子，美人见惯似司空。春心自为前因动，浊世谁堪侍者通？若说早知专节钺，本来节钺属杨公。

# 忽念汉史人彘事，惨然久之，賦此自嘲
原：芒砀山下匹夫耳，何事天教得美人？东海降封应不忍，昭仪僭礼早宜均。易储积议徒招忌，少子偏怜未是真。笑煞安刘借箸者，几令吕氏代赢秦。
原：生前歌舞博君欢，种祸遗殃线代安。但令周昌傅如意，竟忘吕雉嫉明纨。戚夫人小名明纨。处分后事能明见，忍使佳人为爱残？世界烟云今久渺，笑侬几度为汎澜。

# 自椽曹不辟而无贤吏，自采赠为诟而多荡姬，上流所讳，趋度有归，理固如是也。偶感此意，率题两律，有知罪者矣
原：灵香飞去几何年？只说吹笙鹤背仙。还幸瑶池有王母，可知忉利是情天？英华不列班家表，政彻都无神女缘。我梦钧台曾尽醉，蛾眉曼緑半长筵。
原：书史犹存秦汉前，西风未许柳全偏。可怜渐渐臻蛾瘦，但见沉沉员屃眠。情海千年成涸浊，化城弹指幻腥膻。飞琼绿萼存高趣，懶到人间只住天。

# 侠少年
原：紫锦新裁短后衣，轻弓匹马去如飞。金丸不惜抛千弹，粉镜同看杀一围。滟滪滩前浮急水，燕支山上立斜晖。归来自带幽并气，不用奚囊贮翠微。

# 咏李广
原：下中李蔡已封侯，猿臂将军早合休。射虎北平今石在，犹龙老子继风流。数奇幸免淮阴醢，力战难酬宣室求。卫霍本因胡虏重，肯教一箭落旄头？

# 春雨
原：冰雪消融万木晞，商量正好典寒衣。天心不放花开早，土脉初添雨后肥。山客分兰蓑半掩，船娘趁渡桨双飞。莫愁一夜惊残梦，已隔重帘况细霏。

# 梦棠陈女士往岁晤于西山，承以诗相质，许列弟子行。别来逾年，闻以病归，顷传逝世，赋此遥奠
原：愁来身在有无中，用君句。早识伤心怀抱同。曾吊孤坟嗟命薄，同至红拂墓，己酉三月事也。竟移噩谶到棠红。“乞种红棠当篱落，开时便见泪和魂。”予吊红拂后，赋呈史君采崖、李君少塘、刘君今希、罗君涤三句也。丐诸君护惜古艳，不期谶人君名。生前尚隔死何在？梦里如逢意待通。切嘱云尘都莫著，著时便是可怜虫。

# 听雨有感
原：罗帐灯昏不觉春，借他点滴数前因。常时生怕惊人梦，此夜谁为入梦人？芳草定知存泪种，落花何处托香尘？风风雨雨年年似，只异山河不异身。

# 断肠
原：断肠情事断肠诗，比似春蚕宛转丝。铁箧缄藏终出井，瓢瓜飘泊岂分歧？欲教思妇今生见，直待吟窗将晓时。最是丛残须检点，寒蝉咽断夕阳枝。

# 十年
原：十年烂醉泪痕多，涴遍人间凤尾罗。灯雨赚醒孤枕梦，旗亭谁付曼声歌？缄藏铁匣休郑重，裹入天风暂荡摩。陶谢飘零郊岛死，此中精气不轻磨。

# 精魂
原：已瘗精魂傍美人，情根休更出埋尘。思量终有蟾蜍在，检点浑疑脉望真。垂老枯枝生意尽，回流潴水荡心频。从知绝大如来力，第一先忘过去因。

# 次韵答钝根
原：到处新知接古欢，循环纠墨两无端。菩提慧可知非树，媱席阿难异达观。自得风流忘物竞，不求寂灭是居安。云蓝写寄相思字，春镜何年倚手看？

# 自题画梅
原：我闻孤山之麓有一亭，都种梅花围作屏。客来呼鹤鹤解迎，自许醉世能独醒。独有一语令我嗔，乃敢先我呼夫人。此翁一卧数百春，此花岁岁犹芳辰。为此我愿改姓林，不然便改林逋名。媚花爱花与花亲，一日百拜不厌频。花神感我愚且诚，梦中诲我言谆谆。林逋呼妻非其真，售子一树用一旬。三十六树供饔飧，旨畜御冬妻御贫。无子锄旧更艺新，对客高卧恣啁吟。何逊东阁遂延宾，广平自许铁石心。狂者狎我如风尘，矜者交我如相荣。惟君能妒为至精，妒不相怒能知心。我岂草木遂忘情？与君誓共死与生。折枝归供宣磁瓶，非君所折息睹闻。魂从君去君何颦？明年非复今年魂。我闻花言泪满襟，一生所遇皆如卿。见时辜负别分明，才见开花又落英。波迎风卷分溷茵，傀然剩我飘零身。吁嗟乎！傀然剩我飘零身。

# 吴门访钝根不值
原：酒狂词艳傅文渠，别后曾来一卷书。空向沧浪亭畔问，脚跟无线是吾徒。
原：残荷删尽剩枯茎，烟水凄迷负好晴。到处酒帘招客饮，却愁醉后独诗成。

# 梅生三兄相见海上，出诗三巨册见示赋赠
原：与君兄弟五十载，聚合今为第五回。家有大苏诗乍见，客中二陆意同开。一春正好听莺柳，此地聊堪话鹤梅。寄讯少游还忆否？谓秦子质妹丈。海天吟啸挟风来。廿年前，与子质同看日出于海舶赋诗。

# 亚子以久思乍见，彼此欢然，承邀饮酒楼，归赋两首奉柬
原：清湘迟佇久，今挈早春来。风物惜衰老，客心靳转回。拂襟尘乍尽，含意语多裁。此是曾经处，新知共故杯。宴杏花楼，昔常饮此。
原：最有相逢感，难忘未见时。悬心随月落，人梦逐云移。一寸春晖过，三更灯火知。翻疑暂聚散，说有亦名痴。

# 赠亚子
原：自是词人有别肠，相逢相合复相忘。君多含意因成吃，我惜情未忍狂。拚为河山通梦寐，况今编简共文章。记当醉看湘枫处，往秋偕傅、王、龚三君。自笑浮生又一方。
原：先读君词后读诗，才情肝胆两能知。转旋天马行空力，料量春蚕化叶丝。玉手携从挥尘罢，花奴催为隔栏迟。君两宴予，不召紫云，殆深知杜扬州今昔殊矣。两峰清瘦人谁及？想见吟窗并倚时。“修到身为才子妇，不辞清瘦伴梅花。”罗夫人诗也。君俪佩宜有诗才。

# 赠曼殊
原：人间无地著相思，划海分风杖一枝。那悉密花簪帽日，贝多罗叶写经时。诗中早见维摩病，无法难消大士慈。君自沉吟侬自笑，不同哀乐只同痴。

# 海上送太一入粤
原：君行常万里，一顾逌云别。人生如飞尘，聚散非足惜。但怨华年催，临歧意相诀。回念去此时，惘惘无所适。十载仍生还，朋侣悉遥集。后岂殊前观，挥手又倏忽。
