# 檗子诗选
原：庞树柏字檗子，江苏常熟人。今录诗四十七首。

# 九月二十七日游西山至小云栖寺
原：前游真隔世，秋老独重来。坐觉衣衫古，行防猿鸟猜。清霜木叶秃，初日山容开。孤寺无僧影，经幢绣鬼苔。

# 寒夜卧病听雨达旦
原：灯穗寒多落复生，虚堂拥被梦难成。十年惯听江南雨，不及今宵枕上清。

# 木渎寓楼晚眺
原：孤楼跨溪上，天贶此胜地。四山迤逦开，一一贡席几。东南揖尧峰，浓青扑衣袂。西北指灵岩，浅黛上眉际。稍远有天平，竹外露双髻。相对弄妍姿，宛宛更予媚。野云薄日光，水阴吹雨气。瞬息此凭阑，群峰忽失翠。乃知天地间，变灭无定理。吾生何有哉？自嚼孤寒味。

# 秋晚同稼翁、跂韩野外散步有作
原：招人山色拥烟螺，日晚寻幽踏浅莎。细岸疏花临水媚，小桥残柳着秋多。声来野冢群鸦集，影上村墙一犊过。却忆五湖三亩宅，耦耕心事悔蹉跎。

# 十月初八日游天平，同稼秋、公茇、镜若、梦柳
原：溪水媚嫩晴，菰根出瘦橹。有客携壶觞，相与唤沤侣。溯流达南浜，登岸访茶邬。村童争拊掌，山鸟亦惊语。度林客如雁，一一疏可数。松翠时坠空，衣色忽古。晚枫初著霜，靓于越溪女。何处憩巾屐？危径通故墅。小阁额兼山，清谭捉僧麈。茶力健诗脾，酒香养病腑。幽赏斯渐惬，禅味澹堪咀。看山欲忘归，暮云翳复吐。

# 张市至阑干桥
原：新涨悠悠阔，轻帆故故斜。晨光动杨柳，春色在桃花。水竹孤村静，鱼蔬小市哗，漫怜风物美，三亩足为家。

# 舟中夜闻笛声
原：春尽横塘雨又风，昏灯短被卧孤篷。梦回何处数声笛，却忆枫桥半夜钟。

# 偕陈伯韬丈暨龙慧、蛻庵、致禾诸子游破山寺、三峰寺遂达拂水岩，探剑门
原：秋色澹天地，霜气润林麓。三五挈吟俦，寻幽不厌数。笋舆度斜磴，一一鸟飞逐。名蓝访破山，赐额易兴福。拨藓扪残碑，常建句重读。通幽有曲径，犹植千竿竹。叶底透微阳，影上眉宇绿。踞石试山茗，寒泉清可掬。隔涧过樵子，避人如野鹿。相将造三峰，入门且憩足。松间午饭香，瓮头新酿熟。聊尝世外味，匪但事饮啄。终输佛供养，孤龛对瓶菊。谈禅心易寂，登高兴复触。穷探越前岗，奇境豁游目。巉岩高百尺，危石屹然矗。苍碧间丹赭，恍若剑华簇。霸图问何在？烟霭渺难属。剑门相传为吴王阖庐试剑处。东西望澄湖，蔽天起雁鹜。偃仰一啸歌，空响答深谷。晚风催人归，萧萧振落木。

# 祝潮家兄招饮，席间潘质斋先生出示新诗，依韵奉和
原：侧帽孤吟气不春，朅来尊底认衣尘。岁寒兄弟能相过，灰死文章尚有神。腊鼓惊心催老大，盆枝照眼愧清贫。酒怀空阅残年尽，起视悠悠世态新。

# 吴门梁谿纪游杂诗
原：麋台梦影尚堪描，一日清游不寂寥。断碣野烟五人墓，短篷春月半塘桥。吴门佳胜萃于山塘，侠士、丽人均足为山水生色。
原：花草三生住虎丘，药炉茗碗证双修。看山且上长离阁，休问盈盈一水楼。家兄携姬人赁居宝园街，地近虎丘，自额妆楼曰“小长离阁”。
原：香水谿边听棹歌，虎山桥外晓寒多。无端孤负梅花约，檀板金尊唤奈何？拟刺舟游邓尉，以事未果。
原：梁谿清丽似琴川，瑟瑟春波载画船。人在四围晴翠里，石桃松火品新泉。惠山泉为天下名泉之一。
原：碧嶂回环石径斜，丹青古庙暮烟遮。如何五里香塍路，吹杀春风不见花。近惠山有坊，题“五里香塍”四字。
原：风物销魂又一春，渡头柳比酒痕新。今番侧帽行吟去，忽忆当年顾舍人。顾梁汾贞观，无锡人，能诗，工乐府。

# 游惠山过张睢阳庙
原：遗庙千秋在，丹青夕照中。地知经几劫，天遣作双忠。草木孤城泪，江淮绝代功。莫谈南八事，爱妾亦英雄。

# 鹣鹣行，为邑中贞烈严毛氏作
原：南方有鹣鹣，锦翼何离)。千年誓共命，千里不分飞。东海有毛女，十五颜如脂。生小俭梳妆，绮罗都不知。十七愈窈窕，天缘托良媒。郎君貌英英，门户复相宜。甘龄失阿母，对壁长号啼。邻家姊妹行，入门来呼携。轻衫杏子色，低鬟花朵垂。殷勤牵女袖，劝女勿伤悲。女心更惨切，女身谁护持？终朝泪洗面，不出中间闺。守身洁于玉，居处无人窥。夫家闻女贤，央媒前致辞。六礼灿然备，聘钱穿青丝。佳期正三五，催妆可结缡。母尸犹未寒，玳梁忍双栖？遂为待年妇，低头羞不支。藁砧虽未识，慈姑如母慈。上堂拜慈姑，伶仃得所依。宛宛学新妇，进退有容仪。朝来入中厨，为姑治晨炊。向夕汲升泉，为姑洗裙袿。黄昏一室内，篝灯寒气围。姑坐作针黹，郎读声透扉。何声助郎读？轧轧鸣鸳机。漏尽不得息，往往闻晓鸡。茹荼兼啖檗，荼檗甘如饴。慈姑暗叹息，里党同嗟咨。严氏福未艾，自此光门楣。人事有不测，郎病忽濒危。裁我机上布，为郎延高医。拔我髻上钗，为郎换参蓍。医药总无灵，沉忧终身罹。慈姑怜女忧，掩泪遣女归。女归亦无家，姑命不可违。此心似磐石，去住终难移。凄凄对孤影，怅怅忘朝饥。中宵得哀耗，纤趺遽奔驰。拊棺一恸哭，自恸来何迟？誓死不复去，血泪斑麻衣。昔日各衾枕，今朝共灵帏。一尊奠清醑，尚得称齐眉。黄泉路匪遥，早晚相追随。哀怨填胸臆，二旬进勺糜。女颜昔如脂，枯瘠今成黧。九十有二日，簪笄未尝施。自怜薄命人，与世久若遗。含笑入地下，夫妇如初期。双魂化鹣鸟，长住西山隈。

# 石梅讲舍坐雨
原：山馆自幽寥，邻院梵初歇。隐几学苦吟，禅味胜茶悦。砚色流寒云，茶乳沸瑶雪。时闻疏雨响，竹石共清绝。

# 澄塘烟雨，属伽庵作图
原：水荭花发新涨足，䴔鹊自飞逐。河阳山色青如烟，浪澄塘水碧于玉。细雨斜风时断续，白蘋香里一蓑绿。好借南村放鸭船，去唱东湖采莼曲。

# 雨舟偶成
原：濛濛水云里，一棹过湖滨。空翠浮吟袖，微风稳钓纶。鸭鸣村外雨，鱼唼岸边蘋。满眼沧洲趣，牵茅好卜邻。

# 夜泊刘神庙前大风雨
原：湖气夜冥冥，孤篷此暂停。风雷趋大壑，山雨泻前汀。古庙神弦寂，幽篁鬼火青。船窗灯早灭，水面有龙腥。

# 读《陈涉世家》
原：博士宫中称寿日，佣夫垄上辍耕时。无端一段风云气，燕雀纷纷那得知？
原：篝火狐鸣大泽中，沉沉夥涉志非雄。世家莫诧龙门笔，要是亡秦第一功。

# 上巳雨中社集愚园
原：啼鸠声中上已过，天涯一样奈愁何？重来草草流觞地，谁倚潇潇暮雨歌？襟上十年交酒泪，花前几辈邈山河。休言佳兴销磨尽，如此风光恐不多。

# 西泠杂咏八首
原：一角湖山劫外支，重来杨柳尚如丝。鹃啼鹤去年年恨，还咏尚书杂感诗。钱蒙叟《西湖杂感》诗有“孤山鹤去花如雪，葛岭鹃啼月似霜”句。
原：香钿暖翠未飘零，花路争传玉辇经。旧日雄风又何在？夕阳红上御碑亭。旧行宫改建公园，春来游事甚盛。
原：塔影亭亭似美人，谁怜无语傍东邻。我来别有樊川感，绿叶成阴又一春。
原：故山香火至今存，碧草离离带夕曛。休道英雄输老佛，美人多上岳王坟。光复后，岳鄂王祠墓修葺一新。
原：三烈名题三尺碑，莫将穿冢比要离。此行携得山阴酒，两度风云奠一卮。徐伯荪烈士墓，陈、马二烈士附焉。
原：春社初添五柳陶，新封抔土隔花高。年年寒食宋园路，一样归魂不可招。陶焕卿先生墓，近始竣工，经营葬事者为陶社中人。
原：鉴湖灵气在人间，一棹西泠载恨还。风雨秋家亭子下，落花哭罢哭江山。鉴湖女侠墓，东有风雨亭，为秋侠绝命诗纪念也。
原：果然浓澹总相宜，山雨湖晴一霎时。万岁千秋谁识我？水明楼上独题诗。在张公祠水明楼遇风雨，已而放晴。

# 寄怀俞养浩先生
原：别来云物起相思，回首沧桑又一时。劫外别添新涕泪，花前想见古须眉。逃名傥悔才为累，畏俗无如酒最宜。老去虞山多勘破，未应还作桂殇诗。先生近丧一孙，颇伤悼，故云。

# 楚伧招饮，以病咯血谢之
原：年光终自好，销向药烟青。花落寒难忍，楼空雨可听。呕心输李贺，荷锸愧刘伶。甚日搴裳去，春风醉绿。

# 雨中见桃花零落有感
原：花落花开事本微，休将病眼惜芳菲。只愁一片春光好，雨里无端惘惘归。

# 甲寅清明
原：乱花堕絮阻游行，悔向东风祝晓晴。大地即今还逐鹿，荒台何处有啼莺？国殇欲哭应无泪，乡梦初醒不计程。自问闲愁堪几许？人间三十度清明。

# 寒食思故乡风景
原：柳条垂绿草初齐，寒食湖亭酒价低。谁更摇鞭入山去，蘼芜坟上听鹃啼。吾乡西山有蘼芜君墓，即葬柳如是处也。

# 别馆即事四首
原：别馆重逢更漏长，从前辛苦可能偿？温云柔雨情方切，浊水污泥恨岂忘？软语夜阑如有会，纤腰春后不禁量。生来娇小吴宫种，只许轻怜未许狂。
原：冲烟犯月桂堂东，几度幽期独过从。为试娇嗔轻戏谑，偶思好梦易朦胧。颈痕羞被回灯见，颊晕犹胜薄酒烘。自笑书生贫病久，痴情除却百无功。
原：海北欢踪一夕疏，累他拥髻守灯孤。心坚自佩连环玉，歌好谁偿百琲珠？检点浅深新泪迹，较量肥瘦旧眉图。温存半晌相偎处，怕问宵深去也无。
原：百就千阑为钿盟，几曾真个解逢迎。猜疑尽灭关恩分，忧患能通见性情。不敢怨郎还怨命，相要呼妹莫呼名。他年无分藏金屋，纸阁芦帘过一生。

# 病鹤避暑小云栖寺，拏舟访之，留贈一首
原：大火流金苦久晴，招凉地僻有谁争？象于幻处看云物，心到虚时听水声。猿鹤山中犹未老，风波世上不能惊。十年秋梦三生石，知隔蓬莱第几程。病鹤有《石屋寻梦图》。

# 甲寅人日寄沈丈石友
原：最难此日不阴时，雁后花前系所思。犹见末光驰北陆，时尚未立春。早传春意动南枝。图翻破阵空劫，饼说薰天未疗饥。遥想家山风信至，登高望寄草堂诗。

# 君磐于岁暮赴湘，不及送别，赋此寄之，步前韵
原：人生几见别离时，日短天寒发远思。鸣北杜鹃空有血，巢南越鸟岂无枝？随身竿木原逃世，撑腹诗书不救饥。此去烟波千里阔，何妨投赠汨罗诗？

# 立春，和匪石韵
原：江乡春到不禁寒，劫外风光上笔端。欲动葭灰回帝律，争夸彩胜挂臣冠。鱼龙作戏终归幻，鸡犬升天本未难。只惜年华催老大，南枝乍发半摧残。

# 朱舜水祠落成征题敬賦
原：连遭天步遘阳九，朱明痛失皇纲纽。降表纷纷向虏投，奇节铮铮问谁守？卓惟姚江舜水翁，国亡家破更途穷。避来风雨舟山下，弘光元年，诏征舜水不就。授江西按察使司副使兼兵部职方清吏司郎中，监方国安军，复不拜。被劾，避于舟山。历尽波涛沧海东。崎岖九死欲何事？慷慨书生能好义。击楫常存士雅心，乞师独洒包胥泪。舜水尝三至日本，欲乞外援，以图光复，而援兵竟不可得。回天无力心不灰，求贤有梦复归来。鲁王尝欲召还舜水，监国九年三月，敕谕玺书。永历十一年一月，始达越南。书中有“予梦寐求贤，延伫以待”云云。苍云越峤空埋恨，白骨金陵又作堆。郑成功金陵之役，舜水寄书规之。责备延平，词旨极悲峻。毕竟此生耻秦帝，忍学鲁连蹈海计。薇蕨谁怜劫后身？搏桑別有人间世。清既荡一中土，舜水仍至日本，遂终身焉。德川藩主称礼贤，水户群趋作杏坛。居陋自开新学派，待终犹保旧衣冠。水藩主德川光国聘舜水为宾师，东人多执资事之。舜水平居讲学，是非程朱陆王而不失其衡，贵有作用。后世所谓水户学者，实渊源于此。舜水尝谓德川曰：“吾藉公眷顾，养志守节，以保明室衣冠，感恩浴德莫大焉。”于今胡运已迁改，瑞龙山麓丰碑在。舜水没，以儒礼葬于常陆瑞龙山下，至今完存。故国应招化鹤魂，远人尚仰凌云采。山阴有老慕前修，磊落孤怀为阐幽。谓汤蛰老。争看丹青崇庙貌，共陈笾豆荐寒羞。同志艰贞知有几？客星山人曰张斐。允堪配食到千秋，顽夫以廉懦夫起。张斐字非文，自号客星山人，慕舜水高义，追踪至长崎，闻其死，为文祭之。又乞援德川，亦不获命而去，不知所终。

# 邀寒琼、滨虹、蜕公晚酌
原：三士连翩至，萧斋接古欢。瓶花如影瘦，江雨入春寒。话旧堪消醉，逃时且抱残。明朝远行客，衣上酒痕看。寒琼明日赴山左。
