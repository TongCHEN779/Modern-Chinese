# 汉元诗选
原：陈家鼎字汉元，湖南宁乡人。今录诗十二首。

# 洞庭湖舟中感唐希陶见赠，原韵酬之
原：临舟一笑楚云开，韩信当年有钓台。百战驱胡成底事？洞庭波送我回来。
原：民权容易女权难，一叶危舟渡此关。姊妹欣逢巾帼长，英皇迎尔过君山。

# 哭刘敬庵、朱松坪两烈士
原：汉上风云震天下，只今谁与忆前功？何当寻得刘朱墓，大哭当年两鬼雄。
原：过后重经倍可哀，诸公长逝我归来。伤心黄鹤楼前路，一去刘郎竟不回。
原：血雨腥风几断魂，八年前事怕重论。不堪再过高升巷，宿草斜阳独闭门。

# 登岳阳楼有感
原：自别湖山枉断肠，多情云树迓归航。萦萦江海今还棹，莽莽乾坤一纵觞。十载亡人怀楚宝，三回狂醉羡纯阳。洞庭湖上波如血，犹送生返故乡。

# 麓山吊烈士墓并赠钝初
原：万丈风云撼太虚，流光容易八年。予自事败出亡，迄今八年。可怜黄土埋忠骨，安得名山著政书？予以宪法问题系民国根本之存亡，拟潜往麓山寺中，以其所主张著一书介绍吾民。日为客多所阻，奈何！今日若秦谁御虎？谓俄国。当年微禹我其鱼。谓禹烈士与予倡葬陈、姚者。桃花源上波千尺，与尔偕归作老渔。宋钝哥与予约：时局稍定，归隐桃源。

# 五月四日重游万牲园，有痛宋钝初老友，即用钝初去年九月招饮园中鬯春堂赠余元韵一首吊之
原：青山有约悲今昔，碧血同盟誓死生。百尺楼台知已痛，“百尺楼头一汉元”句，钝初一月十九长沙麓山联句赠我者，予因刻此七字为小印纪念之。十年沧海故人情。予与钝初为十年来共患难交，去岁九月，钝初饮次赠予元韵云“十年久识陈惊座”。放歌渔父今何处？衔石精禽事竟成。此日鬯春堂下路，不堪回首忆生平。

# 病中张红玉来访，即题其篷
原：修路驱驰我马陨，空山听雨独徘徊。坡庵镇日无人到，惟有朝云问病来。
原：宋玉魂归不可招，江东人物莽萧萧。何当谢病携红玉，同过西湖第几桥。
原：雨后轻尘拂陌头，夕阳歌管散新愁。香车宝马多情甚，来叩深山百尺楼。

# 壬子旧历九月廿七日寄禅大诗僧偕永光、道阶二禅师见访余寓，蒙贈大偈，原韻酬之
原：大地沧桑甚，诗僧亦老苍。重逢八指日，回首十霜。我句惭无己，赐句首云“不见陈无己”君朋有永光。无餐供活佛，留与饮寒汤。

# 喜吴稚晖先生来访夜谈即赠
原：大道沦亡久，吾生重感伤。独于吴季子，犹见鲁灵光。京国迎司马，群英肃老庞。每逢长者过，骤起视心香。
原：落木萧萧夜，深山访病禅。开门成一笑，握手话三边。二老江南至，谓段、孟老同临。孟老年六十三，先生同里友也。五君天下贤。先生与溥泉、精卫、梅九、石曾诸同志，天下号五君子。愿随云外履，踏破万山烟。
