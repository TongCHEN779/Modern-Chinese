原：柳弃疾字亚子，江苏吴江人。今录诗八十二首。

# 题钱剑秋《秋灯剑影图》

# 哭仲穆
原：闻笛山阳痛未忘，临风又哭此周郎。伯仁再世终无命，张角称兵敢跳梁。纵敌当年徒有恨，成仁此日亦何伤？白门劫后遗文烬，愿共侯芭仔细商。谓忏华。
原：相逢乍忆过江年，狂狷殊途笑我颠。论学不妨所见异，著书要与后人传。陆沉世界沦禽兽，忧国心期在简编。一掬嗣宗广武泪，芒砀几处有烽烟？

# 恶耗两章
原：恶耗遥传涕未收，似君真个与天仇。孤行一意宁论命？盛气谁言未可谋？摇笔文章动五岳，成仁姓氏已千秋。海风惨淡田横岛，叹息人间少一头。
原：汉贼宁容并立时？和戎误国至今悲。吾谋不用关天意，君见能同信可儿。偷活草间空有日，复仇地下尚无期。艰难一恸何人识？鹑首钧天梦醒迟。恶耗嗣知不实，然诗固未容泯灭也，爱过而存之。编者记。

# 玉娇曲，为钝根赋
原：连鸡已失东南局，降幡夜树君山麓。痛哭当年识贾生，变名此日同张禄。烽火仓皇走避兵，株连钩党梦魂惊。谁知覆地翻天际，别有盟山誓海情。佳人少小生南国，玉娇小字传乡邑。一自天钟第一流，湘花湘草无颜色。佳侠含光本性成，桃花剑底独关情。红颜别擅凌云气，素手能弹变徵声。望门投止文章伯，一见无端情脉脉。本来苏小是乡亲，何况香君重逋客。枇杷门巷受恩身，好作桃源暂避秦。金屋翻教营复壁，玉钗亲典为留宾。贾生年少工词赋，宾从翩翩各殊度。明灯华烛屡寻欢，檀板银尊不知数。一度温磨几度愁，念家山破唱梁州。从来青史千年恨，都付红裙一哭休。红裙着意相怜惜，争奈柔乡难托迹。折尽门前杨柳枝，明朝又作关山客。后约难留啮臂盟，五湖天际若为情。空怜辜负婵娟子，霸越亡吴计未成。失时豪俊仍肥遁，蛾眉别去长恨。传闻绿叶已成阴，差幸名花免堕溷。侠骨柔肠自古难，红妆季布拟湘兰。玳梁紫燕营巢去，祝汝双栖岁岁安。君不见伍相穷途濑女逢，王孙漂母各英雄。独怜红拂天涯老，惆怅他年李卫公。

# 与颖若夜话，意有未尽，别后追寄一律
原：大睨高谭肯息机？寒蛩四壁一灯微。更从何地衡功罪？忍信人间有是非。论世未妨中晚恕，求全自昔圣贤稀。低徊别具沧桑泪，才说开天已满衣。

原：浅斟低唱尽名家，独秀江东合自夸。一卷新词弹墨泪，销魂底事为梅花。

原：度曲居然玉茗风，壮夫何敢薄雕虫？只怜菊影成飘泊，输与姜夔载小红。

# 足疾就医吴门有作
原：迷阳却曲恨如何？翻为求医一棹过。莫动王尼沧海叹，江湖随路有风波。先一日阻风，不果行。
原：见时相错别相忆，用钝根悼太一句。宁傅交情不可攀。移作闺房离合谱，临歧蹙损小眉弯。

# 题大觉《乡居百绝》

原：我亦先人有敝庐，百年门巷未荒芜。何当合作还乡梦，依占分湖汝淀湖。

# 钝根以崂山四景词见示，为题一绝
原：楚尾吴头德未孤，崂山灵气胜分湖。几时得领嵚崎趣？身是烟波旧钓徒。

# 阴霾
原：万里阴霾事可怜，那堪举目望幽燕？尧天舜日匆匆尽，已是穷新闰位年。
原：冢中枯骨不须论，紫色蛙声敢自尊？会见亡秦三户士，一麾黄钺定中原。

# 题《天荒画报》，为阿瑛作
原：地老天荒此尽头，且凭琐屑耗穷愁。研朱滴粉成何用？说鬼谈玄苦未休。谁遣流民图郑侠？空教绝技擅僧繇。烦君画出神皋景，立马昆仑一览收。

# 纪梦二什
原：夜梦客游燕市，天寒风雪，伤时忧愤，呕血几死。忽有效红拂之就卫公者，然其人固非杨家妓也。缠绵歌泣，悲喜万状。晨鸡一鸣，恍然若失，爰为赋此。聆痴之诮，知弗免焉。
原：禅心空遣逐芳尘，又惹陈王感赋甄。累汝缠绵缘底事？怜依憔悴不如人。鹃啼已尽相思血，蝶化能为顷刻春。是想是因谁辨得？难忘横翠上眉颦。
原：绝代佳人在北方，貂裘茸帽健儿妆。自甘卓女奔司马，谁肯佣奴嫁外黄？九死尚烦怜病骥，三生何意化文鸯？无端说梦君休讶，便有前尘亦渺茫。

# 题芷畦《水村》第五图
原：王孙墨妙洒云烟，恰似分湖一角天。便筑新居招隐士，高风南陆至今传。赵子昂作《水村图》赠钱德钧。后十四年，德钧客分湖陆季道家。季道为卜筑于其别墅之旁。景物处所，宛然与图中不异。见德钧所撰《水村隐居记》。南陆者，季道家庵名。
原：枫江渔父文章伯，自写新图付禹平。点缀湖山不岑寂，丹青重见李南溟。徐虹亭、李南溟为魏禹平作《水村》第二、第三图。
原：移家归棹总风流，郭灵芬有《魏塘移家》、《山阴归棹》两图。湖海漂零未白头。一代风骚题咏遍，几人佳句似宜秋？“深闺未识诗人宅，昨夜分明梦水村。却与图中浑不似，万梅花树一柴门。”汪宜秋女士题灵芬《水村》第四图句也，灵芬因更作《万梅花树一柴门》图。
原：梦鸥小阁已成尘，第六村居静掩门。输与君家夸好事，直将衣钵接灵芬。芦墟梦鸥阁主许竹溪铨有《水村》第五图，未征题咏，故知者甚鲜。莘塔凌敏之宝树著《第六水村居集》，则并未绘图画也。
原：争墩故事有还无，分北分南只一湖。我亦廿年称旧隐，会须重绘水村图。

# 次韵分寄康弼、大觉
原：二士堂堂信美哉，飘零鸾凤可胜哀？君看世事如棋局，我已经年负酒杯。莽荡乾坤回涕泪，槎桠肺腑走风雷。学书学剑成何济？闲煞屠龙倚马才。

# 宵来
原：宵来一枕忽朦胧，起视残檠焰尚红。剑底因缘神女雨，樽前鼓吹大王风。强台再上人如玉，易水初寒日贯虹。莫讶荒唐沦万幻，沉沉心事本无穷。

# 哭英士
原：披发呼天那可闻？从知人世有烦冤。十年薪胆关青史，一夕风雷怒白门。建业未下，知君死不瞑也。生负霸才原不忝，死留残局更何言？苌弘化碧宗周烬，忍向黄垆检断魂。

# 酒边一首为一瓢题扇
原：酒边拨触动牢愁，万恨峥嵘苦未休。祈死已烦宗祝请，偷生忍为稻粱谋？栖栖桑海无多泪，落落乾坤剩几头。一盏醇醪三斗血，可能词笔换兜鍪？

# 王道民挽诗
原：抵死终悭一面缘，读君遗简意茫然。魂归淞口三春树，泪洒浔阳九派烟。鹏赋有灵怜命短，豹皮无恙要人传。伤心最是鸽原客，谓哲兄邀汝。梦断池塘哭惠连。

# 哭龚铁铮烈士
原：君讳炼百，湖南湘乡人。奔走革命十年。余一晤之海上辛园，再晤之南都白宫，三晤之吴门植园。每晤，必殷勤问讯，如晨夕交焉。今年春，率众攻长沙伪将军行署。事败，为汤芗铭所捕，剖腹而死，烹心肝以絢士云。
原：屠肠侪聂政，把袖失荆卿。成败空天问，精诚贯日明。哭君今夕泪，知我旧时情。衡岳荒荒峙，湘波怒岂平？

# 哭顾锡九烈士
原：君讳振黄，江苏阜宁人。虬髯绕颊，觥觥如武夫。辛亥山阳周阮之狱，虏令姚荣泽跳走南通，南通有大猾张詧昆季实卵翼之。君率江淮子弟，痛哭来海上，颂冤于陈吴兴麾下，狱始平反焉。滇黔事起，日夕从韩恢谋举义江北。会张詧者，复谬为通款，书来招，君驰往，伏龙辈十八人与俱至，则骈戮之，伤已！
原：一斛包胥泪，秦庭泣鬼雄。如何苌叔血，终遣洒南通？乱世无人道，群凶有狗功。凭谁问遗恨？呜咽大江东。

# 哭杨伯谦同学
原：华泾同吊慰丹坟，急雨孤舟荡夕氛。纪丙午海上读书健行公学时事。首七字借巢南句。一别蹉跎成永诀，半生涕泪感斯文。春风桃李天原妒，大地荆榛鬼亦辛。哭过沪西城外路，云间宿草恐全湮。公学旧址在沪西门外。云间赵拜一，亦同学中年少早夭者。

# 哭华子翔同社
原：赵生厚生去国冯生沼清死，独向吴门哭此人。余始识君于沼清座上，其订交则厚生为介。一传迟回犹待草，十年交谊奈成尘。姚江已信文堪继，君夙慕黄姚之学，手辑《南雷文钞》若干卷，有叙，见南社集中。贾傅终伤命不辰。凄绝梁溪归骨地，挽歌才尽只长呻。

# 春航将去杭州，诗以招之，兼柬小云、天声
原：枨触离怀我未休，匆匆君又别杭州。十年萍梗关天命，三月箫韶与俗仇。已分贤豪同末路，即论歌舞岂长谋？龙生范子都无恙，倘放分湖一叶舟。

# 寄少华甬上四首，即效其体
原：虎步龙行属寄奴，伯先。一时瑜亮有黄须。秋叶。论才自合空子，荐士何由到腐儒？标榜声华原忝窃，死生交谊敢模糊？劳君缄札殷勤赠，翻遣撑肠百感俱。
原：交臂相期失虎丘，己酉冬，南社雅集虎丘，君约厚生偕来，已而不果。六年旧恨絮从头。江东孙策终无命，竹丹。淮海元龙尚有楼。稚兰。击筑人从座上散，吹箫客向市中留。新亭痛哭成何济？铸错徒闻更六州。
原：素车白马语悲凉，文字因缘水一方。秋叶出示君诗，有素车白马一联，是为吾两人订交之始。沧海横流新涕泪，中原传檄旧词章。西泠风月娱残客，秋叶、稚兰并客杭州。北府松楸冷夕阳。伯先归葬京口，已四稔矣。越角吴根千里远，一回凝望一思量。
原：男儿举足系安危，三十成名倘未迟。起陆龙蛇终有日，处堂燕雀欲何为？狂奴故友刘文叔，髯客新交李药师。拔剑为君遥起舞，海天如墨雨如丝。

# 寄白丁、不识、展庵杭州
原：仲季难兄弟，元方况大贤。三张应减价，两到敢争妍？酬酢劳君瘁，猖狂解我怜。西泠拚一恸，热泪洒樽前。
原：嘉惠堂中籍，琳琅重百城。楚弓虽得失，窦桂自峥嵘。好客倾刘酿，传经凿晏楹。清门兼硕学，气类感平生。
原：十日同游地，能寻旧梦无？南湖经别墅，雷峰塔下，旧名小南湖，君姑氏有恒居在焉。宝石瞰浮图。未立吴山马，难忘曲渚芦。西溪歌欸乃，烟水两模糊。
原：异代陈颐道，当年冯小怜。谁携一片石，来树墓门前？好事君无匹，题名我有缘。遥知风雨夕，灵爽拜婵娟。余以春航题名事立石孤山小青墓前，君家昆季实始终之。

# 哭子美
原：生死经年别，幽明两黯然。生天原诞妄，堕地有悲欢。菊影翻新谱，梨云剩旧编。素车悭一吊，泉下倘相宽。

# 哭勇忱
原：十载知名姓，重逢及此辰。笑谈方款洽，罗网已弥纶。口吃怜同病，名高竟杀身。昭苏如有日，庙祀在湖滨。
原：桃梗去不复，箜篌怨渡河。十年剩皮骨，一夕死风波。亦有南冠士，重悲北道罗。茫茫仇与吕，微命又如何？时闻冥鸿、天民咸被逮。

# 少年一首
原：少年书剑纵横意，老矣浮名安用之？逃世岂真甘落莫，佯狂聊以慰妻儿。嵇生柳下曾无锻，杨恽南山尚有诗。十斛醇醪浇不尽，填胸块垒一行尸。

# 哭冥鸿
原：娘子关前气吐虹，石家庄畔哭秋风。九原若遇吴云梦，新鬼烦冤故鬼雄。
原：识荆说项未蹉跎，草草尊前一放歌。宁戚天亡杨恽死，旧人今日已无多。元年春识君于太一席上，时性恂亦在座，今三人咸以国难死矣。
