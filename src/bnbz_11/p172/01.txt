# 孟硕诗选
原：邓家彦字孟硕，广西桂林人。民国元年与予及子实同办《中华民报》，力持正谊，为袁氏所侧目。民国二年，孟硕为袁氏构陷入狱，予与子实竭力支持，卒以经济困难停版。孟硕出狱即赴日本，转至美国。袁氏既殂，孟硕回国，郁抑不得志，尝译书自给。今子实作古，孟硕又远赴德国，患难之友，死亡离散，不觉泫然。今录诗八首。

# 答匪石
原：婴身世网吾何决？第决樊笼说武陵。自失鸣条追凤翥，每因泽国悟龙升。黑风雪浪飘然去，红泪青衫总不胜。吟到恩仇天欲绝，几人豪气逼峻嶒。

# 有怀
原：铁栏杆外马蹄忙，回首园门最断肠。秋叶秋风翻入梦，天南天北渺何方。愿乘灵鹤证仙迹，只恐寒鸦噪夕阳。赢得销魂笺一束，不堪重展旧行囊。

# 有忆
原：音尘渺渺乍疑无，望断天涯泪与俱。秋菊春兰华未落，朝云暮雨化来殊。低徊往事心如醉，振触新愁貌亦癯。过客光阴半销歇，梦中人语镜中图。

# 狱中感事
原：一角炊烟半暝中，四围秋色夕阳红。登楼有客非吾故，走马何人傲乃公。草檄至今空愈疾，著书俟后总雕虫。却怜归雁无消息，隔绝云山十万重。
原：独立苍茫有所思，几番憔悴到蛾眉。年华似水流何疾，身世如云不自持。羞以文章遭鬼击，敢将心事吁天知。避秦只恐乾坤窄，为觅桃源日已迟。
原：落落孤怀絮语谁，东南金粉梦耶非。苍生无地藏香骨，赤帝横天识杀机。六月系囚心未死，十年去国愿俱违。沉沉浩劫知何极，话到沧桑安所归？

# 吊邹容
原：天道今如此，邹生大可哀。鸿文沟满汉，壮志策风雷。黑狱鹃魂泪，青山侠骨灰。只今遗憾在，王气未全摧。

# 郊行
原：繁星粲碧落，流光接素波。飘飘南亩风，采采东篱华。山树澹涵烟，泉石激清歌。归雁绕吾巅，啸侣渺无多。蟋蟀鸣我侧，唧唧诉伊何。人生如萍水，又如松与萝。浮寄安可量？造物良不磨。去去勿复言，有酒欣颜酡。
