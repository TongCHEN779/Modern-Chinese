# 瞿安诗选
原：吴梅字瞿安，江苏吴县人。今录诗三十四首。

# 题《天香石砚室棋谱》
原：我生三十无一奇，止能饮酒不能棋。楠庭嗜棋兼嗜酒，示我图谱邀我诗。颇闻棋诀在善守，心细如发才如斗。敛边丰腹审四隅，布局落子无其偶。就中变化千万殊，难索解人只自娱。方四聚五虚心法，图经散佚传书无。近来此技等捐弃，制谱行世谈何易？四大家法半沦亡，棘门灞上真儿戏。楠廷嗜棋二十年，镂肝钵肾不论钱。前生定是刘仲甫，巾角弹棋赛谪仙。乌乎世间万事皆有癖，使尽心兵书成册。长安时局正纷纭，懒向人前分黑白。逢场莫作不平鸣，当局者迷旁观清。兔起鹘落龙蛇走，千古河山战一枰。我欲去寻橘中叟，力学三年便国手。他时一棹指梁溪，与君赌棋再赌酒。

# 马鞍山麓吊刘龙洲墓
原：彘肩斗酒渡江人，南部莺花每怆神。老去相如容易倦，可堪重唱沁园春？
原：狂心醉哭壮心酸，绝调欣逢辛幼安。故国谁怜天水碧？玉山佳处几盘桓。

# 检点四首
原：紫鲸怖鸽有微温，自拜情天忏绮魂。白纻三千才谱曲，碧城十二未开门。云封桂窟秋无际，月晕梨涡夜有痕。检点平生惆怅事，不须芳草怨王孙。
原：烛龙弹泪彻阶除，帘押银葱卷未舒。熙载心怀宁乞食，樊南词赋尚佣书。情场窈渺匆匆过，法界华严了了如。九曲屏山人不寤，一庭深露湿蟾蜍。
原：荆卿匕首竟通灵，雪愤鱼肠恨血腥。吉网罗钳开阁纳，斧声烛影隔江听。爰书莒烈魂何壮，钧党株连事忍经。独上东皋怀故邑，皖公山色尚青青。
原：窄窄银河又暮秋，不情风雨苦淹留。天寒易水何曾渡？日落娥江悔不投。劫忏红情工写怨，艳飞碧血惨埋愁。风波亭下冤霜急，一笑昙花悟得不？

# 莫更二首，和小洲
原：烛烬香消共一舟，绮窗如墨絮春愁。惊心夜月窥人小，瞥眼秋波进雨流。浊世文章增涕泪，中年丝竹动朋俦。阮咸莫更当筵唱，孤负萧娘记曲筹。
原：碧纱帘下暗香浮，梦影微茫散未收。孔雀东南才避地，顽云西北又高楼。雕笼不许藏鹦鹉，珊枕何妨碎蚍蜉。便是相逢成隔世，荒唐镜誓几生休。

# 偕小洲过明故宫
原：一抹青山认故家，丝丝衰柳尚栖鸦。洛阳风雨燕台月，并作金陵顷刻花。明祖都南，长陵都北，而由崧又继祖武于南，同此顷刻耳。
原：桃花扇底诉飘零，禾黍高低蔓草青。试向通天台上表，不关恩怨孔云亭。

# 步北城獅子山访阅江楼遗址不得
原：六龙曾此驻云车，何处重寻帝子家？千载长江流别泪，不应憔悴宋金华。

原：青衫似草可怜生，独自崎岖上帝京。莫怪年来头易白，愤王庙下泪如倾。

# 读朱素臣《秦楼月》乐府
原：旧家词客数吴郎，哀乐中年鬓易霜。记取玉箫来世约，虎山山下碧鸡坊。

# 信阳题《何大复集》
原：列地联京洛，雄城控义阳。中州文物尽，子态郎当。正始流风沫，奇才吾道光。平生忧乐念，不独在词章。
原：射策承明日，兰成最少年。文章超北地，旌节壮南天。控疏风雷稿，传书内外篇。海峰凭吊处，凄绝玉郎泉。
原：一代名山业，成弘据上游。宗风思历下，后起孕弇州。大雅今难作，斯人不可求。蜉蝣争撼树，公论足千秋。
