# 精卫诗选
原：汪兆铭字精卫，广东番禺人。今录诗三十一首。

# 寄小隐
原：向晚微风和，斜日明天边。流云受艳，漾作晴霞妍。长空舒霁碧，光景涵清鲜。感此春气好，闲阶自流连。众鸟相往还，飞鸣时翩翩。如何我与君，离思徒缠绵。相去不咫尺，邈隔如云烟。娟娟明月影，故故向人圆。何当若流星，一闪至君前。

# 春日晚眺
原：斜阳如胭脂，林木尽煊染。华色妙天然，桃李失其艳。白云亦融洽，娟娟作霞片。晴空净如拭，著此两三点。春光如故人，醇醉醪深浅。感此太和心，临风相缱绻。

# 答小隐
原：孱躯敌忧患，深情伤别离。相逢不可期，魂梦常依依。愿我魂来日，适君梦我时。黯然尽所怀，握手有悲。梦亦不可到，愁亦不可扫。不如各努力，此心常相照。

# 读小隐诗感赋
原：忧来如病亦绵绵，一读君诗一惘然。瓜蔓已都无可摘，豆萁何苦更相煎？笳中霜月凄无色，画里江城黯自怜。莫过金台回首望，荆榛零落尽寒烟。

# 庭前偶见新绿，口占一绝
原：初日枝头露尚涵，春光如酒亦。青山绿水知何似？愁绝风前郑所南。

# 为小隐题读书图
原：西风无地著兰根，未读黄书已断魂。暮雨潇潇梦何处？江南红叶一孤村。

# 感事
原：强将诗思乱离愁，却惹茫茫感不收。九死形骸惭放浪，十年师友负绸缪。寒灯难续残更梦，归雁空随欲断眸。最是月明邻笛起，伶俜吟影淡于秋。
原：珠江难觅一双鱼，永夜愁人惨不舒。南浦离怀虽易遣，枫林噩梦漫全虚。鹃魂若化知何处？马革能酬愧不如。凄绝昨宵灯影里，故人颜色渐模糊。

# 狱中有赠
原：煤山云树总凄然，荆棘铜驼几变迁。行去已无干净土，忧来徒唤奈何天。瞻乌不尽林宗恨，赋鹏知伤贾傅年。一死心期殊未了，此头须向国门悬。
原：落叶空庭秋籁微，故人梦里两依依。风萧易水今如昨，魂度枫林是也非。入地相逢终不愧，擘山无路欲何归？记从共洒新亭泪，忍使啼痕又满衣。

# 感事
原：血钟英响满天涯，不数当年博浪沙。石虎果然能没羽，城狐知否悔磨牙。须衔剑底情何暇，犀照矶头语岂夸。长记越台春欲暮，女墙红遍木棉花。

# 口占
原：衔石成痴绝，沧波万里愁。孤飞终不倦，羞逐海鸥浮。

原：慷慨歌燕市，从容作楚囚。引刀成一快，不负少年头。

# 赠小隐
原：小谪蓬莱别有天，素心人共话缠绵。五更残梦应相唤，莫负鸡声到枕边。

# 西风
原：西风庭院夜深沉，彻耳秋声感不禁。伏枥骅骝千里志，经霜乔木百年心。南冠未改支离态，画角中多激楚音。幸有青磷慰岑寂，残宵犹自伴孤吟。

# 杨忠愍祠前树
原：树犹如此况生平，动我苍茫思古情。千里不堪闻路哭，一鸣岂为令人惊？参天老干无蟠节，振叶西风有恨声。寥寂阶前坐相对，南枝留得夕阳明。

# 答小隐
原：寒芜衰柳不胜情，别恨频从梦里惊。同病忧怜相尔汝，论交肝胆共分明。敢因幻影悲离合，愿守良知彻死生。咫尺天涯犹可慰，隔墙时听读书声。

# 杂咏
原：风雨鸡鸣夜，残灯焰不明。头颅看自厌，髀肉叹重生。北固名空拥，东封事已成。更阑作奇梦，涉海射秋鲸。
原：草没轵深井，烟寒豫让桥。秦宫一击筑，吴市数声箫。骏骨朽谁市？湘魂黯未招。悲风答长啸，落叶响萧萧。
原：刀锯一何吝，生慨以慷。鸿毛微命贱，马革腐尸香。丧乱今方亟，恫瘰未忍忘。悠悠过岁月，中夜起彷徨。
原：众生沦地狱，踽踽欲何之？羑里艰贞日，龙场悟澈时。山河枯涕泪，风雨涤襟期。自觉心如水，高歌日已移。
原：忘却形骸累，灵台自旷然。狷怀得狂趣，新理出陈编。霜鬓侵何易，冰心抱自坚。举头成一笑，云净月华妍。

# 寒夜背诵古诗，至“波澜誓不起，妾心古井水”，叹为妙句，而以其意未尽也，诗以足之
原：止水既无滓，流水亦无颇。涵为百丈潭，漾为千层波。娟娟月自永，习习风微和。冷然识此意，欲和沧浪歌。

# 辛亥狱中述怀
原：形骸有死生，性情有哀乐。此生何所为？此情何所托？嗟余少孤露，学殖苦硗确。蓼莪怀辛酸，菜根甘澹泊。心欲依坟茔，身欲栖岩壑。忧患来薄人，其势疾如扑。一朝出门去，万里惊寥落。感时积磊块，顿欲忘疏略。锋芒未淬厉，持以试盘错。苍茫越关山，暮色照行橐。瘴雨黯蛮荒，寒云蔽穷朔。山川气凄怆，华采亦销铄。愀然不敢顾，俯仰有怍。遂令新亭泪，一洒已千斛。回头望故乡，中情自惕若。尚忆牵衣时，谬把归期约。萧条坟前树，上有慈乌啄。孤侄襁褓中，视我眸灼灼。儿乎其已喻，使我心凝雹。沉沉此一别，剩有梦魂噩。哀哉众生病，欲救无良药。歌哭亦徒尔，搔爬苦不著。针砭不见血，痿痹何由作？驱车易水旁，鸣咽声如昨。渐离不可见，燕市成凄寞。悲风天际来，惊尘暗城郭。万象刺心目，痛苦甚炮烙。恨如九鼎压，命似一毛擢。大雄飞博浪，比户十日索。初心虽不遂，死所亦已获。此时神明静，肃然临汤镬。九死诚不辞，所失但躯壳。悠悠槛阱中，师友亦云邈。我书如我师，对越凛矩矮。昨夜我师言，孺子颇不恶。但有一事劣，昧昧无由觉。如何习静久，辄尔心跃跃。骇如怒马驰，飞尘恣腾踔。又如秋飙动，鸷鸟耸以愕。百感纷相乘，至道终隔膜。悚息闻师言，愧汗骇如濯。平生慕慷慨，养气殊未学。哀乐过剧烈，精气潜摧剥。生何足论，魂魄亦已弱。恫瘰耿在抱，涵泳归冲漠。琅琅读《西铭》，清响动寥廓。

# 雪
原：冻云沉沉作天幕，直令万象沉寥廓。晓来开户忽大笑，琼楼玉宇来相照。昙空白漠四野何茫茫，飘如扁舟凌沧浪，寒涛万丈摇光芒。又如花时归故乡，玉田蔼蔼素馨香。六花霏霏已奇绝，绚以朝霞弄明灭。千里一镜无纤尘，直与冰轮争皎洁。王母琼浆真可拟，谢公屐齿应知惜。如何弃置道路隅，遂令泥土同狼籍。吁嗟乎！莫怨雪成泥，雪花入土土膏肥，孟夏草木待尔而繁滋。

# 雪中偶见梅花，折枝感賦
原：家在岭之南，见梅不见雪。时将皴玉姿，虚拟飞琼色。只今雪窖中，却断梅消息。忽逢一枝开，相对叹奇绝。乃知雨雪来，端为梅花设。烟尘一扫尽，皎皎出寒洁。清辉妙相映，秀色如可掇。香随心共澹，影与神俱寂。蔼蔼含春和，棱棱见风烈。侠士蕴冲抱，美人负奇节。孤根竟何处？念此残枝折。忽忆珠江头，花时踏寒月。

# 见人折车轮为薪，感而作歌
原：年年颠蹶关山路，不向崎岖叹劳苦。只今困顿尘埃间，硬质依然耐刀斧。轮兮轮兮生非徂徕新甫之良材，莫辞一旦为寒灰。君看拨尽红炉中，火光如血摇熊熊。待得蒸腾荐新稻，要使苍生同一饱。

# 梦中得诗，醒而遗其半，追摹梦境，足而成之
原：朅来荒岛上，极目海天明。心与孤帆远，身如一叶轻。浪花溅日影，石笋咽湍声。一抹平烟外，翛然白鹭横。

# 入狱一年矣，慨然赋此
原：士为天下生，亦为天下死。当其未死时，怦怦终不已。宵来魂跃跃，一鹙八千里。山川如我忆，相见各含睇。愿言发清音，一为洗尘耳。醒来思如何？斜月澹如水。
