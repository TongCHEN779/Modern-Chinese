# 少华诗选
原：李光字少华，安徽太湖人。今录诗四十七首。

# 贈稚兰
原：立国二年四月十日，稚兰投我长书，血泪模糊，不知是字非字，有字无字。通夜视之，为之不寝。早起忽忽若有所失，欣欣若有所得。走笔作歌报之，亦不知是字非字，有字无字也。稚兰见之，或亦若有所失，若有所得乎？
原：交臂失君龙江楼，倾心遇我虎林道。湖海新怜邂逅迟，风尘旧愧交游早。为君一笑脱形骸，为君两泪落怀抱。君之意气何轩昂，君之颜色何枯槁。君之头角何峥嵘，君之情绪何悼佬。知君不屑伍绛灌，知君不屑师郊岛。知君不为鲁二生，知君不为汉四皓。知君肠断君犹回，知君心碎君犹捣。神憎鬼瞰知君忘，人亡邦瘁知君恼。我为君献破酒飘，我为君献剩诗稿。祝君莫使书剑废，祝君莫负身手好。英雄宁受时势羁？时势原仗英雄造。龙江之龙龙已颠，虎林之虎虎已倒。边氛愿君投笔扫，逆虏愿君飞檄讨。踏天割云日杲杲，时利雅逝风偃草。君乎君乎慎勿等闲老，寤寐求之香花祷。

# 感事寄秋叶，用原韵
原：侘傺君犹怜正则，升沉我不问君平。传闻易水高歌事，想见昭陵恸哭情。骂座人惟赢一死，叫阍客亦误三生。素车白马纷纭甚，寥落云天范巨卿。

# 贈邹剩庵，兼质若虛、子昶诸子
原：记取春头腊尾时，寒梅孤屿结交迟。青衫憔悴曾怜我，红豆缠绵却赠谁？万劫忍谈翻覆手，十年羞画浅深眉。江关萧瑟君知否？人赋招魂鬼唱诗。
原：欧梅韩孟几参商，一见艰难尽十觞。心血君怜唐李贺，文章我爱汉邹阳。白门说梦灯无焰，青岛谈兵剑有芒。老大健儿成倦客，徘徊帷帐负疆场。

# 闻亚子、秋叶、稚兰诸子燕集杭州西园有作
原：分湖隐逸圣湖游，秋叶近有题亚子《分湖旧隐图》诗。一笑登临百尺楼。南社文章传烈士，亚子于南社集中述吾友孙竹丹被祸事甚详。西泠歌哭集名流。唱酬有作题龙井，梦寐无聊记虎丘。南社创于吴门虎丘。宾主贤豪山水好，未能抛去且勾留。
原：偷闲偶觅骑驴路，吊古聊登立马峰。血泪春航新乐府，稚兰于春航有故旧之好，日昨书来，谓观所演《血泪碑》，赔泪不少。钟情者，固应尔尔。海天秋叶旧词宗。秋叶著有《海天横涕楼诗文集》。柳州身世书千卷，林社年华酒一钟。文事武功零落甚，乾坤意气想元龙。

# 题亚子分湖旧隐图》
原：低徊松菊感榆枌，夏屋秋坟记见闻。结社何如孙孟朴？移家竟似郭灵芬。云天寥落能怜我，骚雅陵夷幸识君。莫向新交夸旧隐，分湖风景要平分。
原：珠帘金粟都零落，芳雪疏香几变更。曲唱竹枝思粥粥，诗题桃叶吊卿卿。浮家泛宅梨川梦，寻壑经邱栗里情。我亦欲归归未得，江南啼尽鹧鸪声。

# 友人刘竞生续学保定，诗以送之
原：新亭旧院夜模糊，君太飘零我太孤。缟纻惯交屠狗客，摴蒲忍逐牧猪奴。千秋人物谈燕赵，万劫河山吊越吴。意气飞扬身手好，勉之行矣莫踟躇。
原：道路艰难阻且长，探丸击剑少年场。狂奴未屑夸三户，猛士犹能守四方。收拾邯郸新枕席，摩挲丰沛旧壶觞。玉关风雨今闺夜，不梦渔阳梦保阳。

# 赠別稚兰，即次其贈別春航原韻
原：三叠歌残劝一觞，栖皇出处怕思量。掉头湖海心犹壮，举目邯郸梦正长。匹马西泠辞故旧，只鸡南国吊徐常。生剩泪须珍重，莫洒筝琶粉墨场。

原：海天涕泪几淋漓，载酒停骖又一时。生自呕心从李贺，死当埋骨傍要离。宅桑门柳归田约，白草黄沙出塞诗。记得玉箫惆怅曲，断肠不止悼亡诗。
原：回肠荡气可怜身，孤负湖山断送春。鸿爪西泠新旧梦，马蹄北道别离人。沧桑吊古传无赖，生死论交剑有神。两点金焦双血泪，悠悠胶漆说雷陈。
