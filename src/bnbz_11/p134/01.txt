# 栩园诗选
原：黄钧字梦蘧，号栩园，湖南醴陵人。今录诗二十二首。

# 落梅
原：三十六宫春意满，梅花处处寄行踪。半帘疏影三更雨，二月江城一笛风。阁部衣冠温玉骨，寿阳粉黛艳残红。清华不受东皇宠，飞入春山春雨中。

# 次韵和钝根《闻韩事有感》
原：旧臣箕子今何在？故园萧萧靡所家。枫落牙山秋色冷，璧衔汉水夕阳斜。晓霜欲作漫天霰，蔓草翻滋遍地华。休道鸱夷甘乐国，须知螳臂不胜车。

# 自成都归舟中作
原：久客三巴事可哀，锦江七月放船回。西风日暮水流急，万叠秋山人眼来。

# 夜泊嘉定，望东坡读书楼有感
原：肠断当年水调歌，音犹自泣蛟鼍。乘风我亦欲归去，天上寒温近若何？

# 涂山咏怀
原：破碎河山不可支，渝城险峻至今夷。鼓鼙江上声悲壮，万国衣冠异昔时。

# 九日候钝庵不至
原：钝庵胡不来？益我心头闷。人秋风雨多，游人颇困顿。闲却满篱花，未了登临愿。江间风波恶，帆力亦云健。不信一水间，诚如千里远。渐渐鲤鱼风，日暮添离恨。
原：九日不登高，常恐山灵怒。山亦恐我愁，旭日当前吐。清风飘然至，引我云间路。松涧响流泉，枝头滴宿露。昨夜小桥霜，染尽千株树。秋风爱晚亭，上有题红句。小立望潇湘，怦怦不能语。盈盈秋水平，谁唱公无渡？
原：行行陟云麓，愈高愈生悲。朔风卷地来，木叶脱南枝。南枝有栖鸟，更向南方飞。我家南山南，苦不望见之。路旁有茱萸，婷婷美其姿。游子悲故乡，对此双泪垂。日暮懒下山，惆怅自吟诗。

# 新年感事
原：重理屠苏旧酒杯，心情历乱百堪哀。雨草木饶新泪，劫后英雄半死灰。傀儡登场终是戏，珊瑚树海不成材。试看歌舞欢腾地，又见胡儿策马来。
原：残灯明灭动星辰，夜气沉沉集此身。万窍风生闻鬼语，一山松老作龙鳞。渐知世运多磨蝎，颇觉胸怀贮古春。桃梗土人原一例，江湖十载孰为亲？

# 落梅二首
原：东风一夜吐繁芳，万树官梅尽解妆。春暖绣闱人弄笛，月铺疏影土眠香。未随云雨沉巫峡，应有仙魂返帝乡。此日花开复花落，江南江北马蹄忙。
原：风雨潇潇满玉堂，诗吟东阁倍神伤。冰心懒与争春色，素手曾经点晓妆。梦断罗浮空有月，歌成艳曲不闻香。此身好向瑶台去，休伴红泥护众芳。

# 夜雨读老庄书竟，感而有作
原：读罢南华道德经，万缘俱寂一灯青。惟听岳麓峰头雨，席卷残花下洞庭。
