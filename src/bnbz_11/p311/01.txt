# 小柳词选
原：陶牧字小柳，江西南昌人。今录词三十首。

# 多丽简病倩论词
原：夜灯浮。期君话雨帘钩。共商取、填词情事，樽前唱破珠喉。最魂销、晓风残月，又断肠、玉宇琼楼。不薄三唐，何讥两宋，略工感慨亦温柔。打叠起，酒旗歌扇，一例付闲鸥。而今叹，江湖渺邈，镇日东流。折花枝、有谁寄赠，添来旧恨新愁。写伤春、青袍如故，抱孤愤、白发空酬。归雁飘零，寒虫雕琢，频劳歌板几时休。只留得、登场面目，冠带沐顽猴。低徊遍，琵琶弹折，莫怨江州。

# 莺啼序为蔡哲夫题汉六花鉴
原：荒苔绣开玉匣，记尊前醉舞。六花折、香透芙蓉，可识羞影鸾去。认斜日、茂陵草色，东风几度抛烟雨。说沉埋多少，英雄岁华磨处。雾散潮青径晕黑，付千秋万古。鉴流水、肝胆俱寒，劫灰敲落棋谱。只江湖、依然一梦，画楼远、垂杨何许。想当时，粉黛无颜，汉宫春聚。赏心蔡子，挂杖钱多，定歌得宝句。独赖汝、锦囊收拾，螺光纽凝，篆额痕浅，屈刀轻举。摩挲已遍，装潢如静，西京迢递谁相托，问知音、尚在人间否。清吟伴我，休怜对此须眉，照眼共数朝暮。关河瑟瑟，旧恨新愁，缬鬓丝系住。莫再话、龟年天宝，酒后·茶。雀瓦空留，兽砖空拊。红颜薄幸，重圆难再，尘污扰乱随吾老，说兴亡、泪染千条组。期君除夕携来，不用金簪，偷听吉语。

# 菩萨蛮对雪
原：湿云一夜吹成雪。东风日暖全消歇。依旧做轻寒。棉衣尚觉单。银灯光欲冻，处处残更送。零落是残更，关心第几声。
原：萋萋草绿闲庭宇。春来可是当年路。春早莫归迟。江南三月时。子规啼不住。花落无人处。楼外有青山。山山夕照间。

# 春风袅娜偶感
原：怨东风苦苦，做尽春阴。吹已遍，竟难寻。任杨枝、牵起闲情叠叠，梨花落去，曲院深深。眼底斜阳，樽前绛蜡，不是平常杯酒心。最怕清歌几惆怅，那堪残漏欲消沉。江上又逢商妇，琵琶泪湿衣襟。底事动狂吟。怜归燕，失青禽。因妨后夜，却负而今。新恨云山，依然无路，旧愁尘海，默少知音。相思何处，托西窗月影，年年照出，一抹疏林。

# 渡江云久客燕京，得遇高钝剑、陈去病，填此志之
原：好春归去也，踏残绿草，又开落红花。遇君同一笑，对酒言欢，仍旧是天涯。沧桑笛里，吹绉了、衣上风沙。吹未尽、断肠诗句，窗外夕阳斜。无家。等闲双燕，可惯飘零，问堂前王谢，寻叠叠、行云相送，多少年华。泪痕只向青衫染，惹客愁、弹折琵琶。愁几许、阑干曲曲难遮。

# 菩萨蛮
原：隔墙绿树笼新月。朦朦犹觉春云薄。何处觅残春。春归不见人。去年今日里。入梦空相忆。深锁十三楼。清歌荡昔愁。
原：鹃啼枝上禽填石。相思端赖明珠织。宛转说相思。量珠粒粒痴。幽兰空谷渺。陌上萧郎老。却莫怨萧郎。闲情比陌长。
原：好花只被春耽误。春归正在花深处。底事负春花。怀人曲槛遮。芳尘劳目送。尘压罗衣重。依旧是罗衣。门前路转迷。
原：路迷更觉天涯远。盈阶芳草风吹乱。草落怨王孙。琵琶泪痕。江流都化泪。可解人憔悴。欲问那人心。殷勤托绮琴。
原：海枯必到桑耕尽。浮萍色与天桃绽。萍绿间桃红。应知色本空。烛灰同话劫。鬓影羞惊雪。雪与劫俱销。谁能慰寂寥。

# 满江红与慧僧同摄小影，时客滨江
原：一笑相逢，回首在、关山何处。同证此、三生灯火，半帘风雨。老我青衫长剑落，依人白发清樽误。说狂名、收拾已嫌迟，贫如故。怜旧梦，闲鸥去。传新恨，闲虫苦。问门前垂柳，斜阳几度。沧海苍茫抛热泪，秋花萧瑟迷归路。听征鸿、万里和残更，声声诉。

# 琵琶仙沪上征歌，近无弹琵琶者，凄然占此
原：回想当年，可听取、怨曲琵琶凄绝。谁料抛却青衫，歌声顿消歇。休坐洗、檀槽泪迹，算闲了、几番风月。轴转情移，更阑酒漉，愁共啼鸠。又还在、银烛秋堂，想怀抱、香浓绉衣褶。曾伴绿鬟低唱，苦凉州哀彻。留万古、兴亡叹赏，盼夕阳、眼底相识。鼓断弦索樽前，细堪重说。

# 菩萨蛮哭子美并简亚子
原：招魂怅隔靡芜路。清歌零落风前絮。天上又人间。春归不等闲。相妨才命薄。命比才还恶。小宋最风流。空一斛愁。

# 三姝媚题天梅《变雅楼三十年诗征》
原：夕阳依旧好，照如此江山，几多恨事。独坐高楼，与破书残酒，料量诗史。歌哭无端，思拔剑、闻鸡而起。三十年来，眼底沧桑，尽随流水。早识流风消靡。赖小有闲吟，寄予情味。一样清狂，指名姬骏马，绿杨阴里。怕听催归，却又到、杜鹃啼死。收拾奚囊，写遍相思满纸。

原：暮鸟声催细雨迟。湿云压损海棠枝。者般怜惜却因谁。未到黄昏人约后，竟成红落絮飞时。一番惊恐一番疑。

# 撲鱼儿中秋
原：知秋光、等闲又到，西风凉入窗户。不堪愁对团困月，丛桂几经香聚。灯畔语。只诉尽、阶前黄叶飘零苦。梦归无路。见叠叠遥水，潺潺流山，黯黯望边树。孤客里，剩有伤心词句。刘郎怕说前度。千生万劫人间恨，碧海青天何处。啼雁住。谁却忆、长安车马衣尘土。相思成缕。怨来日幽长，今宵凄绝，旧事匆忙去。

# 前调和剑华见赠韵
原：说相逢、正秋风到，行踪愁聚萍水。一生几坠天涯梦，归梦被虫惊起。蛩咽地。却莫共、匆忙燕子思乡里。剪灯眠未。苦漏短宵长，新寒衣薄，窗幕层层闭。征鞍卸，满眼尘沙世事。一枝残柳谁倚。绝怜我辈头将白，都在扁舟浪里。歌未已。算只听、盲词谈笑兴亡史。墙边树底。知木叶飘零，闲花淡泊，刚又重阳是。

# 菩萨蛮重九并简剑华
原：秋风思酿重阳雨。层阴锁尽庭前树。佳节又重阳。哀鸿未到家。年年添旧梦。梦与闲愁送。愁也不能多。将愁织薄罗。

# 人事飘零逐露华。秋也无涯。愁也无涯。重阳风雨湿蝉
原：纱。愁到闲花。秋到闲花。天外声催落叶斜。屋角翻鸦。鬓角堆鸦。思归渺渺碧江赊。鬓角霜遮。屋角云遮。

# 摸鱼儿 约朴庵游西湖归作并简剑华
原：绕孤城、夕阳烟柳，东风吹绿湖水。小桥一曲红墙远，怕听晓莺啼起。芳草地。已踏遍、软尘陌上人千里。庭花开未。睹阁启澄澜，堂开宛在，灯火重帘闭。西湖好，多少兴亡旧事。阑干思与共倚。渔舟一叶，春山外、处处棹歌声里。歌不已。知几辈、沉埋功罪归青史。浮云眼底。问骏马名姬，征衫杯酒，鸥鹭更谁是。
