# 屯艮诗选
原：傅尃字屯艮，号君剑，湖南醴陵人。今录诗一百二首。

# 阁夜
原：高阁灯残夜悄然，澄江如练水连天。不堪细数人间事，菡萏香消柳作绵。
原：百无聊赖作词人，尽许闲愁集一身。只是悲秋太萧瑟，自挥珠泪自酸辛。

# 夜吟寄钝剑
原：霜华两鬓渐相侵，短句驱愁苦自吟。九死尚生难化骨，万缘俱寂静观心。风云只手开天地，道义双肩并古今。写寄东南旧常侍，应知情竭为知音。

# 故园
原：未断空山歌哭想，故园久住亦多情。新凉六月有秋气，危溜三更知雨声。坐看芳流成寂寞，不应衰世话升平。清宵百感多哀思，吟罢还搔短发拳。

# 夜步庭中
原：万籁寂无声，空天见月明。阑干斜欲坠，知已第三更。

# 奉酬太一怀人之作，四章，章四句
原：海水涸且枯，浮云聚复散。蛟龙蟠泥中，忽被群魔瞰。
原：天阴夜作云，云薄难为雨。龙曰吾苟生，岂无三尺水？
原：海水倏腾啸，一龙飞上天。龙子驱群魔，投魔大海填。
原：龙咋语群龙，潜之毋见首。勿为凤兮嗟，且作狮子吼。

# 丁未生日述怀
原：蝶梦千年谁是觉？伤心斯世我犹生。古愁莽莽成长恨，人事频频付薄情。报国只应痛哭，问天苦为较阴晴。深秋欲尽留无计，愁听萧萧万木声。
原：中年哀乐寄筝琶，守骏其如马齿加。已分浮名等刍狗，不妨吾道系匏瓜。百忧佗傺知何世，四顾苍茫靡所家。泡影浮生犹未了，著书且自惜年华。

# 过汨罗
原：灵均怀石去不返，过客千年吊汨罗。我亦铺糟啜醨者，独醒终古奈君何？

# 落日辛亥四月感事
原：何自能挥落日戈，时衰宁复感山何。茫茫且作无边想，已觉吾生涕泪多。
原：我马玄黄我仆痛，登高南望一长吁。苍天聩聩斯何世，知是谁家屋上乌？
原：良药医云须瞑眩，大雄佛以济慈悲。摧枯自此移山易，争奈人间有不为。
原：落日西沉逝水东，壮年心事托冥鸿。微吟不必关家国，自古诗人有命穷。

# 哭杨笃生
原：时艰蒿目国才亡，痛哭神州事可伤。何必虫沙逊猿鹤？终无枳棘集鸾凰。鬼雄入梦二三辈，竖子成名千百场。叹息芳馨摧折尽，转怜葵麦太凄凉。

# 长沙寄妇
原：安排生事供牛马，分付灵心与剑箫。眼底英雄如虱大，胸中块磊要才消。东风柳色春三月，细雨檐花此一宵。所不能忘负红粉，封侯无分到班超。

# 湘城坐雨
原：阴云幂幂雨垂垂，宴会登临两未宜。似揭吾忧幕寥廓，散与大地俱淋漓。门稀屐齿故人少，秋入琴心孤调悲。转赖檐花破岑寂，终嫌悬溜太孤危。

# 梦蘧方从蜀归，未至家，复应余邀往沪，舟中阅所为《蜀道吟草》，率题二首
原：蜀道苦行役，念君亲见之。归来翻旧稿，赠我有新诗。风雨扁舟夜，江湖独往时。吟怀故不浅，寥落使谁知？
原：共我飘零者，如君亦慨然。西行双屐足，东去一帆船。天地容长啸，糟醨任独贤。名山他日事，即此已千年。

# 八月十八夜望月有感
原：忽动天涯无限情，推窗遥见月华生。清辉未减芳容在，犹向中宵分外明。
原：露重风多微觉寒，更深人倚玉阑干。多应久负团圆意，故向嫦娥缺处看。

# 龙飞
原：龙飞已卜黄天立，蛇斩先知赤帝成。一夜惊雷轰兽窟，武昌城接汉阳城。

# 九日书感
原：万里辞家成独往，百钱买菊作重阳。不成痛饮偏防醉，欲敛深悲转觉狂。生事十年犹汗漫，人间一息有沧桑。西风已自惊心极，数遍归鸿又几行。

# 金樽歌
原：春风吹花生繁香，金樽绿酒森满堂。美人妙好世无双，回风起舞翱且翔。使君延年永乐康，铜壶漏迟夜未央。西风一夜吹秋霜，漫天飞絮随风狂。乐不可极忧毋忘，愿君北进驱虎狼。吁嗟乎！愿君北进驱虎狼，千秋万岁为君长。行矣努力事戎行，何为忧思怀故乡？

# 中秋望月不见，赋此怅然
原：人间佳节寻常过，盼到重圆又一年。待扫浮云见明月，还将杯酒问青天。阴晴万态成今古，歌哭无端付管弦。玉宇琼楼渺何处？高寒应许照孤眠。

# 感事，集放翁句
原：久矣儒冠误此身，壮图空负胆轮困。西风落叶秋萧瑟，如此江山坐付人。

# 题自书“精神一到，何事不成”横卷
原：我闻阿尔魄山高于天，鸟垂双翼飞不前。壮士一呼万军振，汉尼拔与拿破仑兮相后先。地绝东西限南北，航绕阿非绕阿墨。苏彝士河巴拿马峡一朝齐洞开，造物无功天失色。思之思之思无穷，精气之极鬼神通。至诚不动未是有，孟王管霸斯语将毋同。豪杰能兴可作圣，惟志帅气气生性。不然六极弱居终，心死大哀风不竞。千年士气溯中摧，秦皇汉武罪之魁。销兵锄强风所被，直使生灵终古形如槁木心如灰。东汉诸公颇奋迅，清谈一误亡于晋。北宋复起继以明东林，更自颜黄顾王以后存无廑。精神兮精神，精神兮国魂。疾则速兮行则至，一脉暖兮宙合皆为春。精神兮无死，国魂兮归只。愚公之力可使山为移，纵然我身未竟厥功还更付之孙与子。天有日月星，惟精神之健兮运不停。地有河海岳，匪精神之固兮奚以托？君不闻死诸葛能走生仲达，千古奇事真堪诧。适生适死何足论？精神长在无时灭。懿夫伊川道学世无双，一言实践可兴邦。毕士马克惕然悟，译词偶合言无庞。只今故国山河改，造时应有英雄在。百丈滩头挽急流，狂澜既倒安能待？吁嗟乎！精神一到何事不可成，人定胜天天亦难与争。读吾诗者可以勃然兴，闻斯言者可以终身行。

# 今古
原：今古牢骚一腹收，闲来把酒看吴钩。眼中所见都如我，人世徒闻有莫愁。作赋贾生休问鹏，伤时王粲强登楼。漫惊柳絮随风舞，未抵儿童笑白头。

# 五日山居即事
原：柴扉昼掩静无喧，高树扶疏鸟自言。微有清风飏修竹，尚岚气逼朝暾。狂名减尽疏歌哭，骨肉凋残冷梦魂。今日灵均正愁绝，嗟余何事更烦冤？

# 为高钝剑求陈蜕庵不可得，刘今希书来，道蜕庵相念甚，因得告钝剑事于蜕庵，作此为笑
原：早岁海上识高生，去年醴陵接陈子。不见高生如昔狂，且喜蜕庵穷不死。西风吹人何时休？繁霜凄凄白上头。各有人事扰且累，暂聚复散如凫鸥。我书告高生，长道蜕庵好。高生书来词殷勤，欲致蜕庵如致宝。长沙斗大城，蜕庵去何处？菡萏香销开菊花，芭蕉碎撼连宵雨。放头只有眠，张口不得语。愁肠回环如辘轳，日百千万亿难数。刘郎刘郎真可人，一纸飞来满室春。道是蜕庵近相见，似君善病如君贫。乃识蜕庵状，乃寄蜕庵诗。未知蜕庵作何语，且尽吾情慰所思。

# 感秋八首，用夜饮联句韵，寄亚子梨里有序
原：癸丑九月十二日长沙集梦蘧、醉庵、痴萍、迈南、约真诸人夜饮，因为联句八首。未尽之意，复援次其韵和之，并促诸人同作。自蜕庵老死，宁戚惨戮，晨星朋旧，落落天涯。余也何心，不复欲弄笔为诗以道其萧瑟矣。然固有不能自已者，因粗写一通，遥寄梨里与亚子观之，并唏为我一和也，亚子其谓我何？
原：秋老弥深摇落悲，西风吹梦亦多时。尚哀乐供词笔，凭遣骚愁入酒卮。帘外黄花惊瘦早，镜中白发怨添迟。行吟未解旁人意，已分成顽转说痴。
原：仙字初封墨未干，明知下界有悲欢。女娲炼石天难补，精卫衔冤海已宽。银汉几曾通尺素？金铃谁与系雕栏？芳菲渐觉飘零尽，为撷秋英办夕餐。
原：欲写沉忧付壮歌，江山眼底认摩娑。海疆南北悬风马，图画青苍点黛螺。歧路不因伤却曲，老怀宁惜与委佗。河清人寿君持较，强更为欢复几何。
原：秋风减鬓又经年，世虑徒闻莽万千。不道神工难凿空，倘凭日驭竟回天。人言智慧须乘势，佛说皈依待有缘。誓愿众生终度尽，几时稳放大悲船。
原：匡时百念及时休，未报恩多忍说仇。肯溷尘埃随野马，暂容湖海寄浮鸥。种蒲种柳年年大，听雨听风处处秋。自有情怀谁遣得？悔将身世作天囚。
原：拥衾高卧掩重门，唧唧寒蛩似诉冤。红豆频年抛逝水，青山何处认中原？沙虫猿鹤终同命，南北东西待返魂。客子未归行役苦，伤心夜月听哀猿。
原：黯黯河山澹落晖，大江东去鹊南飞。边风扑朔寒侵甲，海气沉冥月上扉。叹逝已伤朋旧尽，观心应念死生微。揭来一息无穷世，独有空王可慰饥。
原：茹荼知苦蓼知辛，悲喜相乘各有因。春去春来原是梦，花开花落不关秦。欲为鹏徙风斯下，待得桑肥海已尘。多谢故人频问讯，繁霜依旧岁寒身。

# 避地二首
原：瓜蔓黄台一再摘，杨柳白门三四围。焚琴煮鹤垂垂尽，打鸭惊鸳事事非。千古嬴刘成嬗代，并时王寇有从违。长空雁唳风声急，避缴衔芦何处飞？
原：此身石火光中寄，世事浮云眼底看。那意书空成咤怪，转因避地得偷闲。宾朋此日差相倚，丝竹中年强自宽。秋雨秋风只如许，未应重累鬓毛斑。

# 辛亥夏日述怀一首，集陶句
原：朱明方扬，幽斋无营，日讽陶诗，借忘烦署。中有所郁，触绪纷来。口诵既娴，举词易袭，故竟集其句，用述吾情。取貌遗神，聊自观览云尔。
原：春秋多佳日，林园无俗情。寝迹衡门下，聊复得此生。时还读我书，游好共六经。在昔余多师，缅焉起深情。春风扇微和，夜景澄虚明。或有数斗酒，杯尽壶自倾。赋诗颇能工，清歌散新声。歌竟长叹息，晨鸡不肯鸣。少时壮且厉，猛气冲长缨。深得固穷节，饥寒饱所更。世短意常多，孰是都不营。终日驰车走，中宵尚孤征。误落尘网中，淹流遂无成。似为饥所驱，但愿世间名。荣华诚足贵，举世少复真。人生似幻化，飘如陌上尘。所说圣人篇，忧道不忧贫。诗书复何罪？行者无问津。慨然念黄虞，我欲观其人。千载乃相关，益复知为亲。有志不获骋，一日难再晨。逝将不复疑，聊为陇亩民。

# 拟城南读书
原：山花散幽芳，晴光媚遥渚。尘羁偶愒息，栏槛暂容与。杰阁峙崔嵬，风摇铃铎语。贤圣虽递嬗，芬芳自今古。乐静可言仁，大化浩穹宇。胞与扩无际，岂必在濡泃？长途暑烁金，役夫汗挥雨。众寂定群喧，渊然此庭庑。多士集时英，健翮同高举。怀哉风浴归，即兹胜沂舞。

# 为亡友宁太一辑武昌狱中诗竟，因题其后述哀
原：如君已死更安归？风景河山举目非。传志未成应有待，母妻何托竟无依。并时功罪千秋在，惊世文章知音稀。从此西山一抔土，年年凭吊涕沾衣。
原：生同里闰业同门，卢后王前有旧恩。癸卯，受学吴偁三师，同见期许。十载忧患两囹圄，丙午，君以《洞庭波》杂志系长沙狱三年。一时师友各阡原。茂陵遗草伤零落，叔夜诸孤重抚存。高义我输刘季子，谓约真负柩归葬事。丛残收拾恨难论。

# 感怀四首
原：高楼徙倚对斜晖，肠断无言泪暗挥。身世自看同豹隐，网罗今已逐鸿飞。从知顶踵能人利，安用形骸与世违？除暴可堪终易暴？即论生死事轻微。
原：枉劳奔走十年身，兴汉谁知竟帝秦？党祸钩连天未悔，霸才消歇乱方真。可怜赌国粤孤注，忍见操戈厚四邻。从此止乌定谁屋，藐余何惜作逋臣。
原：平居百念计匡时，忧愤危言未敢辞。拯乱几曾逢国手，嫉余早分到蛾眉。文章九命宁天意，功罪千秋许世知。芳草至今应独玩，名山亦幸有鸱夷。
原：天翻地覆纷危涕，岁尽冬寒赋索居。戈在尚堪挥落日，辙横犹及认前车。龛灯回向期皈佛，蠹简飘零且著书。便欲南山看射虎，问天生我复何如。

# 山寺
原：山寺稀人迹，僧闲昼掩扉。犬团红叶睡，鸟乱白云飞。钟磬静弥永，莓苔古愈微。不因成避世，即此是初衣。

# 岁尽
原：岁尽常为客，时危屡弃家。避人如避虎，涂字当涂鸦。庵居，日惟作书自遣。薇长殷顽粟，桃开秦洞花。饥乌解相慰，镇日自咿哑。

# 癸丑除夕
原：百念弥漫拚岁尽，此身寥落欲何之？沧桑世变窥天意，风雨鸡鸣慰所思。息影未伤穷独善，迷津但觉佛长悲。挑灯看剑都无奈，闲礼梅花自祭诗。

# 甲寅元旦
原：岁历勤更又此元，渐看啼笑有新痕。忧患肯付残年老？功罪犹为斯世喧。宁惜卮言托孤愤，忍挥兵气望中原。深杯自倒无妨醉，屠狗当时几辈存？

# 后园观桃花
原：故庐久寄真成困，老树春回盛著花。初拟石榴红似火，乍看朝日烂如霞。秾华自信多才思，薄命从来有怨嗟。为召东风一相问，吹开吹落底由他。

# 三月三日梦蘧见访
原：倜傥黄君世所稀，乍能相访到荆扉。一春坐困令人病，众绿争荣各自肥。稍极郊原快遥目，乍临苍莽惜春衣。芳兰自在无须赠，为约西山共采薇。

# 情诗
原：昔梦渺如烟，今颜艳如雪。欢情娇若云，侬意皎犹月。悲思各纷纭，踪迹久离别。所怀未由展，欲语焉可说？在远情日亲，处垢行逾洁。何必谐鸾凰，乃谓同鹣鹈。流波转含怨，继泪还成血。倩笑不再逢，佳会此终诀。疏寮压春灯，回廊响虚屎。独坐心未宁，永念中怀结。

# 钓诗一首
原：遁世屏嚣秽，抗怀慕诗书。闲事游钓，匪为羡渊鱼。时亦得修鳞，春塘鲜可茹。或乃仅偿饵，眇如巨指粗。隈潭既失用，钩距竟成虚。归庐对妻子，不谓免揶揄。至人讳侵物，相与忘江湖。小持大盈，何异祝篝车？世事每如此，非徒渔者愚。收纶语初志，吾钓但为娱。

# 脉脉
原：脉脉春阴天欲梦，老夫噫气与谁同？高田初足一犁雨，矮屋时当四面风。会有疾雷起沉蛰，任看飞缴逐冥鸿。枝拘坐对人间世，青鸟何由得暂通？

# 雨止，望章龙不见，感而作歌
原：三日不见章龙山，闭门听雨殊觉闲。偶到门前一相望，章龙何在空惆怅。我居山下三十年，年年不见章龙迁。迁亦何方止何处？夜半谁来负之去？或云连日雨滂沱，争说蛟龙欲出窝。此山自有真龙卧，疑是龙飞山壁破。又言秦皇曾赭湘山滨，亦恐山灵欲避秦。不然山自厌为人所扰，别有菟裘将送老。失山毕竟费疑猜，知是去还何日来。既非错被共工触，又非巧遇愚公谷。非触非移两不疑，问山山亦将何辞。山在众绿连天碧，山去一时皆失色。山在春生万树花，山去草木皆含嗟。山乎竟遁人间世，山乎一去其谁继？临风寄语告山灵，我为山歌山请听。惟山出云能作雨，惟山有眼能垂青。惟山能为万民仰，惟山能作大邦屏。禽兽非山不能育，宝藏非山无自兴。高隐非山无可托，奇勋非山无由铭。山兮归来吾望汝，风为扬旗雷击鼓。山兮归来慎勿迟，乘有豹兮从有狸。常思兼艮不出位，岂谓习坎还无时。山意若曰君无怒，别君未先君可恕。我肯忘君更适他，他县无君谁与语？凭君一为扫浮云，千里万里无尘氛。插天摩日伫相见，部娄百辈徒纷纷。

# 今希、约真昆仲见过
原：熙春丽日照尊罍，村酿初温喜客来。二月花如十五女，百年人醉几千杯。仙源杵臼空陈迹，尘世沧桑冷劫灰。但合逢君开口笑，此生何事更肠回？

# 馆夜
原：强欲偷闲竟未闲，东风渐见落花残。蛙声撼卧迷宵漏，雨气禁春酿晚寒。惊世文章徒自喜，忧天涕泪太无端。空王肯示皈心法，且办熏修习止观。

# 今希、约真昆仲过谈一首
原：刘安尚自耽《鸿烈》，而我犹能起《法言》。鹑首似怜天既醉，马肝欲使士无冤。花飞春尽闻鹃语，草长泥肥有燕喧。多幸故人数相访，高谈一为抉愁根。

# 寄陈豪生长沙
原：故人心事眼中存，肯枉相思问断魂？湖海寄愁君自健，山林照梦我无冤。忧天渐怯飘残泪，销骨宁知累众喧。滞酒耽吟只如昔，未妨秋雨病文园。

# 九日登磅冈山作
原：云山千里目，风雨一天秋。有客同佳节，因之揽近游。求仙寻洞口，探石出林陬。且坐一长啸，清风生还。山侧大石下有岩洞，面章龙，深广可八九尺。山背巨石陡起，高二丈，俗谓狗祭石，尝杀狗祓旱魃其上。事诞不经，当云陡起石为近。
原：虚舟沉绝壑，疑是禹王过。古殿迷苔藓，荷坟带薜萝。秋香纷烂漫，樵径累陂陀。莫负登临美，林皋落叶多。山顶巨石如舟，曰船槽。冈尽处，曰庵坪。相传有僧庵建此，今为墓地。
原：旧种家园菊，归来径已荒。犹能谋一醉，便与作重阳。出处两无著，江湖兴未忘。遥知南社客，相忆蟹脐黄。南社以是日雅集海上。

# 金山旧耸江心，今南接陆，可徒往。是日并观东坡玉带，下山一里试中泠泉，陆羽品为第七，今刻曰“天下第一泉”，依刘伯刍说也
原：沙浮更与岸平连，流徙从知历几年。寺里山依危磴出，风前塔尚语铃悬。镇门空见坡留带，甃石争传陆品泉。古往今来一惆怅，忍挥闲涕对江天。此诗既出，吴江陈佩忍自广州移书见告云：金山浮峙江中，洪杨之役，太平军运江西木排为舟航，期以东下。不图事败，遂悉弃其筏于山麓，绵亘数里，南北充塞，日久沙积，竟成平陆。此光绪乙已冬，亲得之镇江一老儒所口述者。

原：具区三万六千顷，腰腹槃槃此一毛。解与胸身空芥蒂，方知世外有逋逃。项王祠在松楸古，仙蠡墩荒杨柳高。且欲驾鼋沧海去，吾衰只合事渔篙。電山，湖中胜景。仙蠡墩在梁溪，相传蠡载西施停棹处。今惟老柳一株，婆娑待尽。

# 次韵和胡朴安焦山诗三首

# 六朝柏
原：日落未落天风高，潮生不生海水焦。南麓森然见双柏，铜柯石干凌神霄。斤斧刳肠香未歇，一株半削心难灭。一株合与伴椒山，苍颜犹凝千年血。柏有二：一在定慧寺前，已利削大半，垒砖补之；一在焦先祠内，其后堂即祀杨椒山。岁寒呵护若有神，恍然梦接六朝春。渡头无复桃根在，旧苑空杨柳新。当年知是何人树，应有高人隐云雾。宁为真逸与山樵，瘗鹤兹山劳汝护。人间积薪何其多，世无匠石空嵯峨。坡亦见竹不见柏，柏兮柏兮尔奈何。坡诗：“焦山何有有修竹。”

# 周鼎
原：灵光朗耀何融融，琉璃作室居当中。汉鼓唐幢那足数，有如仓粟堆陈红。山有诸葛孔明铜鼓及唐刻陀罗尼经幢。腹中奇字隐约见，刻画屈曲蟠虬龙。识近遗远未可读，十年讽籀吾何功。传闻此鼎在明室，权奸窥窃计剽工。献玉乃刖卞和足，归璧莫睨相如瞳。庸知转瞬遂勿保，神物非有藏之公。鼎故京口某公家物，严嵩欲之，不与，因嫁祸焉。鼎入严氏。及嵩败，复归某公，念祸由鼎作，不祥，乃舍之寺中，主人置鼎信有意，椒山曾此荡云胸。便与人林象魑魅，犹防跃水起雷风。隃麋定陶亦可贵，山有汉隃麋定陶鼎。启谋子寓俱无穷。周遂启谌鼎、周子寓鼎在金山。坐感古人三叹息，夕阳西下长烟空。

# 瘞鹤铭
原：雷公昼吼蛟龙怒，江天冥冥作烟雾。轰然裂石下江浔，零星碎乱不知处。即今存者字已奇，卧拓不复烦水湄。间从山僧得此本，眼福足补腰膝疲。墨痕斑驳藓花湿，云根割取如人立。九十一字朗可寻，岂止长沙夸七十。铭旧刻焦山之岸，雷雨中裂坠山麓，宋时已必俟水涸，仰卧施拓。欧阳公得六十字为最多，常仅数字而已。清康熙二十五年，长沙陈恪勤公鹏年始出石移立寺中，云得七十字。今寺僧拓本称八十九字，以余谛审，石上立字、表上华字尚存少半，可算九十一字，不知恪勤何以反少。胜事流传好事多，俗工刓凿神工泣。即今沧海起波澜，九土汩没地轴残。华表千年倘归鹤，满目应怜异昔观。隐居不作真侣逝，黄长睿以铭为陶隐居书，良是。亭林辨之尤审。思古有泪谁能干。夜梦羽衣绝寥廓，钟声欲动松风寒。

# 次韵和亚子
原：不饮真成负酒杯，沉忧其奈逼人来。抚头看镜斯何世，抉目悬门事可哀。湖海十年嗟我老，死生百辈剩君才。狂名减尽孤心炯，犹剔丛残到烬灰。

# 赠罗漫士
原：海上相逢鬓欲丝，尊前旧事忍重思。只今明月湘江夜，不似当年歌哭时。

# 梦蘧于临武县任葺后园为栩园，书来索题，因寄一首
原：讼庭如水吏人闲，官舍萧然昼掩关。赖有园林慰幽独，定知秀句满溪山。风云入座看腾达，鱼鸟依人自往还。待与欹眠怀旧事，斜阳正挂万峰间。今临武界上有欹眠馆，为韩张期宿处，其地即名期宿村。

# 终古，感五月四日事作
原：终古离骚事可叹，孤臣有泪莫轻弹。徒闻义帝存三户，不见怀王斩上官。六郡已知非楚塞，一行犹恐绝秦欢。从来亡国由昏惑，前史分明未忍看。
