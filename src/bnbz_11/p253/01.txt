# 剑华诗选
原：俞锷字剑华，江苏太仓人。今录诗三十八首。

# 无题四首
原：天上人间两不知，枉他眼意与心期。荆王岂有高唐梦？宋玉偷传神女词。难得鞭酬搔背意，可能歌动悦君思。红笺叠尽愁无语，底事翻教鹦鹉疑？
原：依稀故态识狂奴，想像深居属小姑。满儗松脂成琥珀，谁知铁网引珊瑚？梦回夜雨惊飘瓦，眼泣春波怨堕珠。赢得平生多少恨，只缘错认白云夫。
原：露冷天高风欲鸣，美人朱阁不胜情。乍看云气遮明月，岂讶尘心污太清。静夜莫闻啼碧树，红钉犹忆醉银筝。寒蛩争识深闺意，故向窗前作怨声。
原：绿鬓红尘旧岁华，不堪江上弄琵琶。蜀魂休怨汉宫月，秦客岂迷吴苑花？桐树千寻惟引凤，柘弹百尺莫栖鸦。当年应自笑痴绝，争向人前着意夸。

# 无题十首
原：钿雀银蝉双股钗，踏青新试凤头鞋。花须柳眼迎人笑，燕语莺啼簇队谐。乍省迷离来月殿，是谁绰约拜云阶？绵绵今夕知何夕？恼乱情丝春满怀。
原：夹岸晴烟绕碧丛，绿杨稳系玉花骢。娇痴隔座情波溜，消息重帘香篆通。罗袜空阶声细细，银钩小字印虫虫。红尘十丈生魔劫，弱质难禁擘柳风。
原：黄柑双擘祝春风，皖睨莺啼小苑东。射覆酒浮银凿落，迷藏花舞玉玲珑。语经猜破羞难吐，诗被催成意未工。齐道一声归去也，夕阳斜衬马蹄红。
原：君是诗中一世豪，风流我亦冠人曹。三秋泣别吟团扇，双桨催归折大刀。肠断争如贺梅子，魂销输与郑樱桃。晓莺残月知何处？芳草年年绿汉皋。
原：七夕曾经拜女牛，自怜命薄不风流。弯眉月上相思柳，绕鬓花簪并蒂榴。梦去空金带枕，愁来偷弄玉搔头。阿环别后青鸾杳，云销深深十二楼。
原：多情原不似微之，可奈前期误后期。死恨吴娃歌子夜，生憎越客网西施。青衫憔悴樽边泪，金缕凄凉梦里词。闻说江头潮有信，年年偷拜伍员祠。
原：画屏香冷博山炉，情泪珠殷玉唾壶。银宇笙调红尾凤，菱花镜破白头乌。女儿浦长相思树，新妇矶空十幅蒲。写尽琼笺无限恨，别翻新曲唱罗敷。
原：雕栏不见解绦人，十里湖光减却春。油壁曾经迎小小，生绡端合画真真。红牙低按思前度，翠钿深盟要后身。憔悴云鬟长不整，玉妆台胃绿丝尘。
原：羞向红楼斗钿妆，嫦娥笑对合欢床。蜻蛉早卸钗头玉，鹦鹉还呼马上郎。发薄渐嫌梳不胜，腰纤翻讶带何长。并州快剪真无赖，剪碎机头云锦裳。
原：荒唐云雨笑襄王，多病心情懒下床。试问浅深新粉黛，应怜细腻旧风光。望夫梦化点头石，倩女魂飞响屎廊。好谢麻姑相问讯，不堪人世又沧桑。

# 寄铁崖槟岛，兼柬碧君
原：人许风流自爱才，江湖载酒十年来。难销绮孽空中语，剩有生涯劫后灰。轻薄错疑魏蝴蝶，清狂谁识贺黄梅？旧游似梦还休说，珍重玫瑰好自栽。

# 别后寄亚子，顺讯卧子消息
原：别后伊家作么生？天涯消息不分明。闲吟豆蔻闺中曲，愁拨琵琶塞外行。潦倒只拚千日醉，风流终负百年情。未须各自成惆怅，好共婵娟弄玉笙。

# 庚戌除夕
原：结束前情总可哀，年华锦瑟忽蒿莱。此生已分同庚尽，底事还教守岁来？证到龙蛇殊怪诞，梦回蝴蝶费疑猜。炉烟遮莫成心字，一片心烟一片灰。

# 醉歌行
原：葭管灰飞愁破云，春魂欲返天犹醺。残客穷居意不适，短衣来访李将军。将军嗜饮尝犯夜，拔剑怒吼山灵诧。红亭日午喜逆余，口讲指画犹叱咤。交车柳下且复言，此邦酒兵纷集如云屯。说霸争王各不让，龙拏虎跳旦复昏。人生于兹合沉醉，胡为长愁自殄瘁？我本高阳旧酒徒，一闻流涎满口糊。相将笑索酒家去，但见密围四座正欢呼。将军为我一一道姓氏，争拉入席提壶卢。拍张叫号徐与褚，喧呶不知作何语。仰天大笑陆士龙，康弼。横飞一斗称快举。南山老翁兴尤豪，醇醪公瑾芷畦。亦老饕。据鞍矍铄空子，掀髯一饮话滔滔。我与将军互邀击，藏钩射覆亦劲敌。未知其趣有虎头，严纠觞政令如律。排日朦腾作酒狂，不知身处是何乡。一客曰胥塘，一客曰魏塘。魏塘与胥塘，出处俱渺茫。南山举杯笑而起，云直汉之酒泉耳。公瑾昂头云胡不竟名酒城，众人拍手皆曰是。独余奋臂大呼兴乎来，酒泉酒城何小哉！号曰酒国宁不该？南山其帝是国称酿王。将使尚书公瑾虎头监，将军好将酒兵阵四方。而我庶几为阎者，郊钧天矣祀杜康。陶陶兀兀乐未央，莫问醒世蝇头蜗角几百春秋几战场。

# 和小柳答际公韵
原：假息人争笑釜鱼，身无健翮欲焉如？荒阶露井蛩吟遍，剩水残山鼠窃。江月不随尘事改，酒杯长与世情疏。百城信美非吾土，何似成都四壁居？

# 重九同子实、朴庵、小柳、亚韩合影，即题一律，倒用前韵
原：移得南村镜里居，云萍不隔俗尘疏。定知此会何时再，只怕相逢又劫余。麹部我犹从事比，松根人亦大夫如。青鞋布袜归来未，可要官湖学种鱼？

# 和小柳思归韵
原：鸱鹉墙阴促漏残，几番乡梦落征鞍。浪游不信秋来倦，久客应知岁暮寒。剩有愁肠成九折，更无笑口向长安。霜林渐觉西风紧，堕叶纷纷可忍看？

# 海上
原：缥缈楼台傍水悬，定知海上驻神仙。投壶电息樱桃帐，挹袖云生玳瑁筵。九锡承恩花有主，一丸长逝药无缘。传杯漫倚双成管，买绢先应织丽娟。

# 朴庵、晦庵同还沪上，賦此志别，并東小柳
原：遥天风紧雁衔芦，赋别江郎泪眼枯。愁入湘江迎帝子，欲从沧海问麻姑。同舟却异来时伴，朴庵来闽时，与余偕。独客应怜后夜孤。寄语南昌陶小柳，新诗还唱比红无？
