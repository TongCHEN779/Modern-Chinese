# 挽遁初先生
原：流血竟五步，伤心此国殇。风云愁黯黯，水月幻茫茫。申浦原吾土，桃源是故乡。灵均应痛哭，谁为遣巫阳？
原：政海风潮烈，吾徒可若何？豺狼当道卧，魑魅喜人过。万恶人间世，横流大海波。回天终有术，誓起鲁阳戈。

# 挽邹亚云
原：珠玉宁无价？文章自有神。斯人不可作，千古此离群。心血呕如许，风徽渺若尘。锦囊佳句在，读罢涕沾巾。

# 出山海关
原：百年难得此身闲，渤海东来第一关。地势平临乌拉岭，海光遥挹白头山。炎风朔雪自今古，铁岭金州几往还。飞挽如龙行绝迹，长征何日唱刀环？

# 出关至沈阳作
原：榆关东瞰柳条边，辽海人民异昔年。龙虎旌辉唐节度，犬羊俗化汉屯田。长城迥在西风外，大漠平临北斗前。东望烟尘仍满目，几时返旆勒燕然？
原：百里森林辟大荒，不咸山北郁青苍。别开天地新窝集，凭吊辽金旧战场。野敞龙沙胡月白，天低雁碛塞云黄。不关猎火狼山照，丛木如磷夜放光。

# 戍楼秋望
原：戍楼高不极，怀古一登临。天险雄勾注，汾流下管涔。山光排闼入，秋气逼城阴。斯世多王粲，当风聊一吟。
原：天涯难极目，寥落此登楼。南岭攀熊耳，西崖扼虎头。日沉太行暮，木落大河秋。汾水黄如带，相看抱郭流。

# 题宣南枣花寺《牡丹图》四律
原：壬子旧历孟夏之三日，漫游长安，往访枣花古寺。新雨初霁，牡丹萎谢，惟欧家碧尚残留两蕊，而芍药则正怒放之时。妙慈上人乃出《牡丹图》卷属题。图绘于辛亥季春，首题者为无棣吴重熹并满洲庆珍博如，盖两君亦以是日来游而题者。去年今日花事正繁，今岁节候较早，月日同而花时已过，人间老眼，已输与一着矣。际此皇纲纽解，大地春残，岁月更新，莺花增丽，贞元朝士，半往析津，琼岛奇葩，谁人欣赏？今春卷中留题者，非前清长安之冷宦，即民国江湖之散人。仆也不才，敢效丰干之饶舌？爰次渔洋山人《秋柳》韵，漫成四律以应之。
原：阑珊花事最销魂，回忆春明旧日门。异术骊山新变种，小诗鸿爪旧题痕。予于丙午有《崇效寺看牡丹》绝句两首。东君欧碧犹留蕊，北地燕丹尚有村。燕丹村在宛平北乡。近侍只今惟芍药，传来彩笔共谁论？
原：今日麻姑鬓有霜，沧桑影事孔东塘。不名已黜群芳谱，分送应悭七宝箱。水际芳名标谢客，殿前异种退花王。人间老眼看谁得？谱到新声白纸坊。白纸坊为寺之所在地。
原：天香罢惹汉臣衣，北胜南强说是非。醉酒传呼人不见，和酥分赠客应稀。可堪经雨闻鹃泣，无复迟明作蝶飞。开落唐花争顷刻，逼人富贵意相违。
原：零落残香总可怜，宣南日暮起炊烟。卷中异卉常留影，寺外垂杨乍脱绵。家住天津原小隐，人称国色已残年。会昌朝士慈恩劫，忍断芳根堕溷边。旧寺有《青松红杏图》，清初名人题咏甚多。庚子之役，为邑人杨寿枢所得，妙慈上人拟向之赎归，乃杨君强以欧家碧相易，故落句云云。

# 胡子寄尘赐诗，谬承奖借，次韵答之
原：胡子字寄尘，藐此长天长。息壤在何所？身寄广漠乡。世界一微尘，山岳各低昂。炎荒日炽焰，明星夜吐芒。沧桑已三变，麻姑鬓有霜。人海正横流，砥柱中流藏。羡君逍遥游，研此出世方。
原：北风起天末，申浦夜潮寒。岁月如川逝，已去不复还。九龙近咫尺，徒唱念家山。何如去北征，顾盼据吟鞍。阳乌驰景白，胡马嘶声酸。祆教诛胡僧，骄子斩可汗。大漠何茫茫，飞沙目为瞒。玉门快生入，使我开心颜。

# 题潘兰史《出关图》
原：神京屏蔽古雄关，曾夺燕支塞外山。我是壮游君更北，汽车声里唱刀环。君是游直达张家口，予仅至南口耳。
原：千古才人迥绝群，潘郎诗句定庵文。定庵有《居庸关记》。磨崖勒后题图去，笔墨都成塞上云。

# 拟《凛凛岁云暮》
原：凛凛岁云暮，游子行不归。重城隔迢迢，雨雪想霏霏。欲晤路无由，此心良与违。此心虽与违，恍惚梦见之。衣带紧双束，犹是旧腰围。棱棱眉宇间，弈弈发容辉。欢笑若平生，把晤入重帏。彼时情逾亲，相对话依依。始梦以为真，再梦知已非。醒起思所见，前境想依稀。

# 舟出枫桥

原：梁溪吴苑隔迢迢，曲曲东塘不上潮。已是姑苏城外路，一声汽笛过枫桥。

# 五人墓
原：不欲求仁竟得仁，永垂义烈勒贞珉。纲常自足维千古，游侠宁传此五人。聂政已惭为知己，要离合并与为邻。英灵常在山塘路，当日悬知目怒瞋。

# 慧山谒泰伯庙
原：三让端为万代崇，让乡今尚被仁风。世家已是魁伦序，人表何因止上中？吴会桥坊巫史祝，城田沟洫禹王功。至今梅里平墟在，遗冢皇山说不同。
原：西瞻勾曲几重山，更托衡山采药还。至德无名留庙貌，故封唯伯此江蛮。化行商邑周原外，地在廉泉让水间。只有巢由堪比并，千秋如在渺难攀。
