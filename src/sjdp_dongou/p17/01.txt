# 1　值班室
原：（高兴 译）
原：医生的值班室（在任何城市任何医院任何病室）聚拢了五个不同的人物并将他们的言行编成一段琐碎却极为有趣的情节。
原：哈维尔大夫和阿兹贝塔护士正坐在值班室里（今天他们俩都值夜班）。此外，还有两个大夫（某个不甚重要的借口将他们引来，这样他们便可以边喝着刚刚端进来的几瓶葡萄酒，边和两位值班人员闲聊了）：该病室的秃头主任医生，外加一个长得挺标致的女大夫，她今年三十岁，是另一病室的。整个医院都知道他们俩勾勾搭搭。

原：除去已提到的四位外，还有第五位。事实上他此刻并不在场，因为，他年纪最轻，刚被打发去再弄一瓶酒。值班室里有扇窗。这扇窗可不容忽视，首先它敞开着；其次透过它，我们可以看到一个温馨、芬芳、月华皎洁的夏日夜晚。大家兴致勃勃、海阔天空，整个儿气氛显得十分安恬。其中，就数主任医生谈兴最浓。他似乎在洗耳恭听着自己的警世格言。
原：过了一会儿（实际上我们的故事现在才拉开帷幕），气氛有点儿紧张：阿兹贝塔作为值班护士，显然喝多了一些。更有甚者，她居然开始厚颜无耻地挑逗哈维尔。哈维尔极为反感，对她大加痛骂，以示警告。

# 撒尿
原：“这并不难猜，”答话的却是主任医生，“我更喜欢在自然中撒尿，而不是在臭气熏天的文明设施中。在自然中我的小小的金色喷泉很快便会与泥土，与青草，与大地神奇地融为一体。因为，费莱什曼，我源于尘土，现在至少应该部分地返归尘土。在自然中撒尿恰似一场宗教仪式，通过它我们可以向大地发誓最终必将全部回归。”
原：费莱什曼一声不吭。主任医生禁不住问道：“那么你呢？你是出来赏月的吗？”费莱什曼依然顽固不化，沉默不语。主任医生说：“你真是个怪人，费莱什曼。就因为这一点，我才喜欢你的。”费莱什曼觉出主任医生话中有刺。为了保持自己的形象，他冷冷地说道：“别扯什么月亮了，我出来也是为了撒尿。”
原：“亲爱的费莱什曼，”主任医生极为温和地说，“我觉得这是你对我这个上了岁数的上司最友好的表示。”
原：然后，他们俩一起，站在梧桐树下，撤起尿来。此项活动主任医生总是津津乐道，奉若神职。

# 2　英俊却刻薄的小伙子
原：撒完尿，他们俩沿着长廊往回走去。主任医生兄弟般地将手搭在了实习医生的肩上。实习医生确信好吃醋的秃头察觉出了女大夫的信号，此刻正装出一副同他友好交谈的样子，存心挖苦他哩。当然喽，他又不能将上司的手从肩上挪开。但这样，他心中的怒火便越烧越旺。唯一令他欣慰的是他不仅充满了怒火，而且立即看到了怒火中的自我。于是，他便对重返值班室的小伙子感到满意。令人吃惊的是这个小伙子一下子判若两人：尖酸刻薄、咄咄逼人，犹如恶魔一般。
原：当他们俩真正走进值班室时，阿兹贝塔正站在屋子的中央，不住地扭动着腰身，轻轻哼着什么歌曲。哈维尔大夫望着地板。女大夫为了平息他们的震惊，赶忙解释道：“阿兹贝塔正在跳舞。”
原：“她喝多了。”哈维尔加了一句。
原：阿兹贝塔并没有停止扭动屁股，上身依然一个劲儿地在哈维尔低着的脑袋周围摇来晃去。
原：“这么漂亮的舞你究竟是在哪儿学的？”主任医生问。
原：费莱什曼冷不丁无所顾忌地大笑起来，毫不掩饰自己的讽刺：“哈哈哈，漂亮的舞！哈哈哈！”
原：“我是在维也纳观看脱衣舞时学会的。”阿兹贝塔回答。
原：“好了，好了，”主任医生轻轻责备道，“从何时起我们的女护士开始看脱衣舞了？”
原：“我想这不违禁吧，先生。”阿兹贝塔围绕着主任医生扭动着上身。
原：一股怒火窜上了费莱什曼的心头并迫不及待地试图通过嘴唇发泄出来。于是，费莱什曼开口了：“你该吃点溴化物，而不是跳脱衣舞。不然，我们都怕你会强奸我们哩！”
原：“你们用不着害怕。我又不拐骗儿童。”阿兹贝塔一边厉声回敬道，一边围着哈维尔不住地扭动上身。
原：“你喜欢脱衣舞吗？”主任医生继续以慈父般的口吻问道。“是的，很喜欢。”阿兹贝塔回答，“那里有位瑞典姑娘，一对乳房真是硕大无比。可是，你们瞧，我的更漂亮。”（说完她抚摸起自己的乳房）“还有个姑娘假装在纸糊的浴缸里浸在肥皂泡里洗澡。另一个黑人姑娘竟然在大庭广众面前手淫—这才是最绝的……
原：“哈哈！”费莱什曼的冷嘲热讽达到了顶峰，“手淫，你干这最合适不过了！”

# 屁股形的悲哀
原：阿兹贝塔继续跳着。她的观众可要比维也纳脱衣舞场的逊色得多：哈维尔耷拉着脑袋，女大夫的眼神中充满了鄙夷，费莱什曼总是唱对台戏，只有主任医生不动声色，表现出慈父般的宽容。阿兹贝塔的屁股裹了块白色的护士围裙，在屋里旋转着，犹如一轮美丽的、圆圆的太阳，然而是一轮早已熄灭、早已死亡的太阳（由裹尸布裹着）。在场的医生们那无动于衷、心烦意乱的目光已将它判定为可怜的累赘。
原：忽然，阿兹贝塔似乎真的要开始脱衣了。主任医生慌忙表示反对，语气中流露出了明显的不安：“哦，亲爱的阿兹贝塔！我希望你并不想在此为我们表演维也纳脱衣舞。”
原：“你怕什么呢？先生！至少你该见识见识光屁股女人到底是啥样的！”阿兹贝塔尖声说道，然后重又转向哈维尔，两只奶子在他面前晃动着：“哈维尔，我的心肝，这是啥？你就像出席葬礼似的。抬起头来！什么，你们家什么人死了吗？看着我！无论如何，我还活着。我没死！暂时我还活着！我还活着！”说出这些话时，她的屁股已不再是屁股，而成了悲哀本身，在屋里来回舞动着的形状精美的悲哀。
原：“该打住了，阿兹贝塔。”哈维尔望着地面说。
原：“打住？”阿兹贝塔颇感吃惊，“说穿了，我是在为你跳舞。啊。现在我要为你表演脱衣舞了。一段精彩的脱衣舞！”说着，她解下围裙，一边舞着，一边将它扔到桌上。
原：主任医生又一次怯怯地反对着：“阿兹贝塔，我亲爱的，你为我们表演脱衣舞，这很好，不过得另找个地方，你得明白我们可是在工作单位呀。”

# 精彩的脱衣舞
原：“先生，我不会太离谱的。”阿兹贝塔回答。此时她身着白领淡蓝礼服，仍在不停地摇摆着。
原：接着她将双手放在臀部，顺着身体的两侧缓缓地向上滑动，一直滑动到头顶。然后用右手顺着举起的左臂上移，又用左手顺着举起的右臂上移，接下来忽然双臂朝费莱什曼猛烈一挥，直吓得他胆战心惊。“你这个脓包，别这样了。”她朝他大声喝道。
原：她重又将双手放在臀部，但这一回顺着双腿向下滑动。当她整个儿弯下身来时，她首先抬起右腿，然后又抬起左腿。然后，一眼不眨地盯着主任医生，用右臂猛烈地朝他甩了一下。与此同时，主任医生刚张开手指，又慌忙攥成一个拳头。他将一只手放在膝盖上，用另一只手向阿兹贝塔投了一个飞吻。
原：就这样摇摆舞动了一段时间后，阿兹贝塔踮起脚尖，双臂倚肘，又伸向后背，竭尽全力用手指够着自己的脊梁。然后，一边舞动着，一边伸出手臂，用右手掌摩娑着左肩膀，再用左手掌摩娑着右肩膀，接下来手臂又猛烈一挥，这一次朝着哈维尔。他极不耐烦地移动了一下手臂。
原：现在阿兹贝塔挺直了身子，神情庄重地在屋里迈着大步。她依次走到四个观众面前，向他们炫耀着象征性的半身裸体。最后，在哈维尔跟前站定，重又扭起了屁股，然后微微弯身，双臂顺着腰身缓缓滑动，又（如前），先后抬起了两条腿。随后，威风凛凛地挺直腰板，举起右手，拇指和食指紧紧并拢，又一次朝哈维尔有力地一挥。
原：接下来，她第二次踮起脚尖，得意扬扬地摆出一副想象的裸体姿势。她双眼微闭，头部稍侧，谁都不看，包括哈维尔在内，一心一意地凝望着自己扭动的身体。
原：忽然阿兹贝塔浑身松弛，停止卖弄，坐在了哈维尔的腿上。“我累坏了。”她打着呵欠说道，然后伸手抓起哈维尔的酒杯，喝了一口。“大夫，”她对哈维尔说，“你有什么兴奋药吗？我实在不想入睡。”
原：“什么都行，亲爱的阿兹贝塔。”哈维尔说。他将阿兹贝塔从腿上挪开，让她坐在椅子上，然后向药房走去。他取了些特别厉害的安眠药，递给阿兹贝塔两片。
原：“这能帮我提神吗？”她问。
原：“就像我的名字哈维尔一样确定无疑。”哈维尔说。

# 阿兹贝塔的临别之言
原：阿兹贝塔吞下两片药后，又想坐到哈维尔腿上。哈维尔忽然移开了双腿，她一下子跌倒在地。
原：哈维尔立马感到十分内疚，事实上，他并不是存心想让阿兹贝塔跌倒，遭受莫大的屈辱。他移开双腿，也只是一种无意识的动作，因为出于反感，他实在不愿自已的双腿触摸阿兹贝塔的屁股。
原：现在他只好又一次费劲地将她提溜起来，但可怜的阿兹贝塔竭力挣扎，死命地贴在地面上，就是不肯起来。
原：这时，费莱什曼站在她面前说：“你喝多了，该上床睡觉了。”阿兹贝塔从地板上仰视着他，（她躺在地板上，津津有味地体验着受虐狂似的感觉）目光中充满了鄙夷：“你这头畜生，你这个白痴。”接着又骂了一句：“你这个白痴。”
原：哈维尔再一次试图将她提溜起来，但她猛地挣脱开身，然后抽泣起来。谁都不知道该说些什么才好。她的抽泣声像小提琴独奏似的，在鸦雀无声的屋子里回响着。过了一会儿，女大夫轻轻吹起了口哨。阿兹贝塔忽然气鼓鼓地站起身来，直奔着房门走去。抓住门把手的刹那，她半转过身来，冲着所有的人说：“你们这些畜生，你们这些畜生。要是你们明白的话……可你们什么都不明白，你们什么都不明白。”

# 主任医生指控费莱什曼
原：她走之后，屋里一片沉默。主任医生首先打破了沉默。“你瞧，费莱什曼，我的孩子，你口口声声说同情妇女。如果你同情妇女的话，那你为何不同情阿兹贝塔？”
原：“她又关我什么事？”费莱什曼毫不服气。
原：“别装蒜啦！我刚刚告诉你，她对你一片痴心。”
原：“那我有啥办法呀？”费莱什曼问。
原：“你是没办法，”主任医生说，“然而你却有办法对她粗暴无礼，百般折磨。整个晚上你的一举一动对她都关系重大，如果你能面带微笑看她几眼，如果你能对她讲些愉快的事情的话……别忘了你对她说了些什么。”
原：“我并没有对她说任何可怕的事呀。”费莱什曼争辩道，但语气听上去很不自信。
原：“没说任何可怕的事，嗯？”主任医生冷笑着说，“你嘲笑她的舞姿，尽管她是为你而跳的；你建议她吃溴化物；你断言除了手淫她一无是处。还没有任何可怕的事吗？在她跳脱衣舞时，你将她的围裙弄到了地上。”
原：“什么围裙？”费莱什曼表示异议。
原：“她的围裙，”主任医生说，“别装傻了。最后，你打发她上床睡觉，尽管一分钟前她刚服完一片兴奋药片。”
原：“然而，说穿了，她是在追哈维尔，而不是我。”费莱什曼继续表白道。
原：“别装腔作势了。”主任医生严厉地说，“倘若你对她毫不在乎，她又有什么法子呢？她想方设法要刺激你。她仅仅渴望你能表现出一星半点的嫉妒，可你却是一副绅士风度。”
原：“别再折磨他了。”女大夫说，“他的确冷酷无情，但毕竟他还很年青嘛。”
原：“他是专司惩罚的天使长。”哈维尔说。

# 神话角色
原：“是的，的确如此，”女大夫说，“瞧他，一位邪恶却英俊的天使长。”
原：“我们都是名副其实的神话人物，”主任医生有气无力地说，“你是狄安娜，冷漠、淫荡而又恶毒。”
原：“而你是个森林之神，一个饶舌、好色的老家伙。”女大夫回敬道，“哈维尔是唐璜。他不算老，但正走向衰老。”
原：“根本不对。哈维尔是死神。”主任医生老调重弹，以示反对。

# 唐璜们的结局
原：“如果要我判定自己究竟是唐璜还是死神的话，我不得不倾向于主任医生的说法，尽管这令我很不愉快。”哈维尔说着喝了一大口酒，“唐璜，毕竟是一位征服者。是一位大写的征服者，一位伟大的征服者，但我倒要问你，在一个无人拒绝、事事顺随、一路畅通的领域中，你怎么可能成为一个征服者？唐璜的时代已经一去不复返了。唐璜的后代不再征服，仅仅收集。伟大的征服者已被伟大的收集者取而代之。只不过收集者已不再是名副其实的唐璜。唐璜是个悲剧形象。他背负着沉重的罪愆。他乐于违反禁令，敢于嘲笑上帝。他是个不折不扣的渎神者，结果地狱向他敞开了大门。
原：“唐璜的肩膀承受着引人注目的重担。伟大的收集者对此却毫无感觉。因为在他的世界里，所有负担都失去了重量。巨石变成了羽毛。而在征服者的世界里，情人间短暂的一瞥完全可以同收集者王国中十年之久的热恋相媲美。
原：“唐璜是主人。收集者则是奴隶。唐璜傲然违抗常规和法律。伟大的收集者却唯唯诺诺，勤勤恳恳，与常规和法律融为一体，因为收集已变成良好的规矩，良好的样式，几近于一种义务。说到底，如果说我该承担什么罪责的话，那就是我没有接受阿兹贝塔。
原：“伟大的收集者对悲剧或正剧一无所知。性欲曾一直被视作万恶之源。多亏了伟大的收集者，性爱即便不像坐公共汽车或购买商品，也起码像早餐和午餐，像集邮，像打乒乓。他已将它引入了周而复始的日常生活之中。他已将它变成了一座舞台。真正的正剧此时此刻早该上演了。哎呀，我的朋友们，”哈维尔满怀激情地说道，“我的爱情却是座没有任何演出的舞台。
原：“亲爱的大夫，还有你，亲爱的先生。你们将唐璜和死神摆在了相互对立的位置上。纯粹是由于巧合和无意，你们才抓住了事物的本质。看，唐璜顽强抗衡着不可能。这一举动充满了人性。而在伟大的收集者的王国中，一切均属可能，因为它是死神的王国。伟大的收集者是来收纳悲剧、收纳正剧，收纳爱情的死神，是来收纳唐璜的死神。在伟大的收集者的世界里，激情和感觉羽毛似的在空中振翅飞翔。然而在这个世界里，收集者永远地死了。
原：“毫不相干，我亲爱的大夫，”哈维尔的话语中充满了悲哀，“唐璜和我毫不相干！我又有什么资格同他相见？又有什么资格在灵魂中感觉到他那诅咒的可怕的重压？又有什么资格在内心中感觉到日益增强的悲剧的崇高？毫不相干，大夫，我顶多算个喜剧人物，甚至连这都并非我自身努力的结果，而得归功于唐璜，因为唯有以其悲剧性的放荡不羁作历史背景，你们才能在一定程度上觉察到我那纵欲生活的悲哀。倘若缺乏衡量尺度，那么，这种生活在单调乏味的环境中只能变得灰暗而又平庸。”

# 又一次信号
原：哈维尔在发表了一通长篇大论（在此期间睡意朦胧的主任医生两次差点睡着）后，终于疲惫不堪，陷入了沉默。值班室里充满了激动人心的气氛。片刻之后，女大夫打破了沉默：“我还真没想到，大夫，你的口齿如此伶俐。你将自己描绘成一个喜剧人物，灰暗，枯燥，实际上等于零。不幸的是，你说得似乎太崇高了一点。你真是狡猾透顶：自称乞丐，但讲话时，用的全是些庄严的字眼，听上去竟像个国王。你是个老骗子，哈维尔。即使你一味贬低自己，也无济于事。你纯粹是个老骗子。”
原：费莱什曼听后哈哈大笑。从女大夫的话中，他可以清楚地感到对哈维尔的讽刺。想到这，他不禁洋洋得意起来。女大夫的嘲弄，他自己的大笑，使他勇气倍增。他走到窗前，意味深长地说：“多美的夜啊！”
原：“是啊！”女大夫说，“一个灿烂的夜晚。而哈维尔居然想扮演死神。哈维尔，你注意到没有？夜色多美啊！”
原：“他当然没有注意到，”费莱什曼接茬道，“对于哈维尔来说，这个女人就等于那个女人，这个夜晚就等于那个夜晚，冬天就等于夏天。哈维尔大夫拒绝辨别事物的其它特性。”
原：“你一眼就将我识破了。”哈维尔说。
原：费莱什曼断定这一次他与女大夫的幽会只会成功，不会失败，主任医生喝得太多了，困顿不堪，早已放松了警惕。费莱什曼趁虚而入，装出一副若无其事的样子说：“噢，我的膀胱又发胀了！”说完，朝女大夫扫了一眼，走了出去。

# 煤气

# 哈维尔的理论
原：“先生，你所说的有一定道理，但你推断时有一个失误：高估了我在这幕戏中的作用。我不是什么关键人物。毕竟，并不是我一个人拒绝和阿兹贝塔上床。谁都不想和她上床。

# 夜空中飘着花的芬芳
原：费莱什曼最后抵达了郊区街道。他和父母住在一幢带有花园的房子里。他推开小门，但没有走进屋去。他在一条长椅上坐下。椅子周围种满了由他母亲精心培育的玫瑰花。

# 4　女大夫的返回

# 为主任医生辩护
原：“你说的句句是真，大夫，”哈维尔说道，“但所有这一切使我更有理由喜欢主任医生了，因为这一切要比你估计的更与我相近。我为何要去嘲笑一个我自己也逃脱不了的秃顶呢？我为何要去嘲笑他为改变真实形象所作的种种努力呢？

# 作品简介
原：作者简介见前。《座谈会》选自昆德拉的短篇小说集《可笑的爱》。昆德拉为数不多的短篇小说几乎都以情爱故事为主干，但他不是为了情爱而描写情爱，而是通过一个个生动又可笑的情爱故事来探索人的基本心态和生存状况。他的短篇小说，叙述简洁而准确，语言明快而幽默，哪怕是一个小小的故事，也力避平铺直叙，总以或大或小的波澜，使作品的形式和内容有起有伏、有声有色。《座谈会》便是具有代表性的一篇。玩世不恭者的空虚、花花公子的无聊、自以为是者的愚妄、伪君子的阴险在这个反讽色彩极浓的短篇中都得到了一定程度的揭露。
