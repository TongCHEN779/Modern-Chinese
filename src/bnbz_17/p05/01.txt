# 一
原：红豆似的相思啊！
原：一粒粒的
原：坠进生命底瓷坛里了……
原：听他跳激底音声，
原：这般凄楚！
原：这般清切！

# 二
原：相思着了火，
原：有泪雨洒着，
原：还烧得好一点；
原：最难禁的，
原：是突如其来，
原：赶不及哭的干相思。

# 三
原：意识在时间底路上旅行：
原：每逢插起一杆红旗之处，
原：那便是
原：相思设下的关卡，
原：挡住行人，
原：勒索路捐的。

# 四
原：袅袅的篆烟啊！
原：是古丽的文章，
原：淡写相思底诗句。

# 五
原：比方有一屑月光，
原：偷来匍匐在你枕上，
原：刺着你的倦眼，
原：撩得你镇夜不着，
原：你讨厌他不？
原：那么这样便是相思了！

# 六
原：相思是不做声的蚊子，
原：偷偷地咬了一口，
原：陡然痛了一下，
原：以后便是一阵底奇痒。

# 七
原：我的心是个没设防的空城，
原：半夜里忽被相思袭击了，
原：我的心旌
原：只是一片倒降；
原：我只盼望—
原：他恣情屠烧一回就去了；
原：谁知他竟永远占据着，
原：建设起宫墙来了呢？

# 八
原：有两样东西，
原：我总想撇开，
原：却又总舍不得：
原：我的生命，
原：同为了爱人儿的相思。

# 九
原：爱人啊！
原：将我作经线，
原：你作纬线，
原：命运织就了我们的婚姻之锦，
原：但是一帧迥文锦哦！
原：横看是相思，
原：直看是相思，
原：顺看是相思，
原：倒看是相思，
原：斜看正看都是相思，
原：怎样看也看不出团困二字。

# 十
原：我俩是一体了！
原：我们的结合，
原：至少也和地球一般圆满。
原：但你是东半球，
原：我是西半球，
原：我们又自己放着眼泪，
原：做成了这苍莽的太平洋，
原：隔断了我们自己。

# 十一
原：相思枕上的长夜，
原：怎样的厌厌难尽啊！
原：但这才是岁岁年年中之一夜，
原：大海里的一个波涛。
原：爱人啊！
原：叫我又怎样泅过这时间之海？

# 十二
原：我们有一天
原：相见接吻时，
原：若是我没小心，
原：掉出一滴苦泪，
原：渍痛了你的粉颊，
原：你可不要惊讶！
原：那里有多少年底
原：生了锈的情热底成分啊！

# 十三
原：我到底是个男子！
原：我们将来见面时，
原：我能对你哭完了，
原：马上又对你笑。
原：你却不必如此；
原：你可以仰面望着我，
原：像一朵湿蔷薇，
原：在霁后的斜阳里，
原：慢慢儿晒干你的眼泪。

# 十四
原：我把这些诗寄给你了，
原：这些字你若不全认识，
原：那也不要紧。
原：你可以用手指
原：轻轻摩着他们，
原：像医生按着病人的脉，
原：你许可以试出
原：他们紧张地跳着，
原：同你心跳底节奏一般。

# 十五
原：古怪的爱人儿啊！
原：我梦时看见的你
原：是背面的。

# 十六
原：在雪黯风骄的严冬里，
原：忽然出了一颗红日；
原：在心灰意冷的情绪里，
原：忽然起了一阵相思—
原：这都是我没料定的。

# 十七
原：讨诗债的债主
原：果然回来了！
原：我先不妨
原：倾了我的家资还着。
原：到底实在还不清了，
原：再剜出我的心头肉，
原：同心一起付给他罢。

# 十八
原：我昼夜唱着相思底歌儿。
原：他们说我唱得形容憔悴了，
原：我将浪费了我的生命。
原：相思啊！
原：我颂了你吗？
原：我是吐尽明丝的蚕儿，
原：死是我的休息；
原：我诅了你吗？
原：我是吐出毒剑底蜂儿，
原：死是我的刑罚。

# 十九
原：我是只惊弓的断雁，
原：我的嘴要叫着你，
原：又要衔着芦苇，
原：保障着我的生命。
原：我真狼狈哟！

# 二〇
原：扑不灭的相思，
原：莫非是生命之原上底野烧？
原：株株小草底绿意，
原：都要被他烧焦了啊！

# 二一
原：深夜若是一口池塘，
原：这飘在他的黛漪上的
原：淡白的小菱花儿，
原：便是相思底花儿了，
原：哦！他结成青的，血青的，
原：有尖角的果子了！

# 二二
原：我们的春又回来了，
原：我搜尽我的诗句，
原：忙写着红纸的宜春帖。
原：我也不妨就便写张
原：“百无禁忌”。
原：从此我若失错触了忌讳，
原：我们都不必介意罢！

# 二三
原：我们是两片浮萍：
原：从我们聚散底速率，
原：同距离底远度，
原：可以看出风儿底缓急，
原：浪儿底大小。

# 二四
原：我们是鞭丝抽拢的伙伴，
原：我们是鞭丝抽散的离侣。
原：万能的鞭丝啊！
原：叫我们赞颂吗？
原：还是诅咒呢？

# 二五
原：我们弱者是鱼肉；
原：我们曾被求福者
原：重看了盛在笾笠里，
原：供在礼教底龛前。
原：我们多么荣耀啊！

# 二六
原：你明白了吗？
原：我们与照着客们吃喜酒的
原：一对红蜡烛；
原：我们站在桌子底
原：两斜对角上，
原：悄悄地烧着我们的生命，
原：给他们凑热闹。
原：他们吃完了，
原：我们的生命也烧尽了。

# 二七
原：若是我的话
原：讲得太多，
原：讲到末尾，
原：便胡讲一阵了，
原：请你只当我灶上的烟囱：
原：口里虽薪地吐着黑灰，
原：心里依旧是红热的。

# 二八
原：这算他圆满底三绝罢！
原：莲子，
原：泪珠儿，
原：我们的婚姻。

# 二九
原：这一滴红泪：
原：不是别后的清愁，
原：却是聚前的炎痛。

# 三〇
原：他们削破了我的皮肉，
原：冒着险将伊的枝儿
原：强蛮地插在我的茎上。
原：如今我虽带着瘿肿的疤痕，
原：却开出从来没开过的花儿了。
原：他们是怎样狠心的聪明啊！
原：但每回我瞟出看花的人们
原：上下抛着眼珠儿，
原：打量着我的茎儿时，
原：我的脸就红了！

# 三一
原：哦，脑子啊！
原：刻着虫书鸟篆的
原：一块妖魔的石头，
原：是我的佩刀底砺石，
原：也是我爱河里的礁石，
原：爱人儿啊！
原：这又是我俩之间的界石！

# 三二
原：幽冷的星儿啊！
原：这般零乱的一团！
原：爱人儿啊！
原：我们的命运，
原：都摆布在这里了！

# 三三
原：冬天底长夜，
原：好不容易等到天明了，
原：还是一块冷冰冰的，
原：铅灰色的天宇，
原：那里看得见太阳呢？
原：爱人啊！哭罢！哭罢！
原：这便是我们的将来哟！

# 三四
原：我是狂怒的海神，
原：你是被我捕着的一叶轻舟。
原：我的情潮一起一落之间，
原：我笑着看你颠簸；
原：我的千百个涛头
原：用白晃晃的锯齿咬你，
原：把你咬碎了，
原：便和樯带舵吞了下去。

# 三五
原：夜鹰号啕地叫着；
原：北风拍着门环，
原：撕着牌纸，
原：撞着墙壁，
原：掀着屋瓦，
原：非闯进来不可。
原：红烛只不息地淌着血泪，
原：凝成大堆赤色的石钟乳，
原：爱人啊！你在那里？
原：快来剪去那乌云似的烛花，
原：快窝着你的素手
原：遮护着这抖颤的烛焰！
原：爱人啊！你在那里？

# 三六
原：当我告诉你们：
原：我曾在玉箫牙板，
原：一派悠扬的细乐里，
原：亲手掀起了伊的红盖帕；
原：我曾著着银烛，
原：一壁撷着伊的凤钗，
原：一壁在伊耳边问道：
原：“认得我吗？”
原：朋友们啊！
原：当你们听我讲这些故事时，
原：我又在你们的笑容里，
原：认出了你们私心的艳羡。

# 三七
原：这比我的新人，
原：谁个温柔？
原：从炉面镂空的双喜字间，
原：吐出了一线蜿蜒的香篆。

# 三八
原：你午睡醒来，
原：脸上印着红凹的簟纹，
原：怕是链子锁着的
原：梦魂儿罢？
原：我吻着你的香腮，
原：便吻着你的梦儿了。

# 三九
原：我若替伊画像，
原：我不许一点人工产物
原：污秽了伊的玉体。
原：我并不是用画家底肉眼，
原：在一套曲线里看伊的美；
原：但我要描出我常梦看的伊—
原：一个通灵澈洁的裸体的天使！
原：所以为免除误会起见，
原：我还要叫伊这两肩上
原：生出一双翅膀来。
原：若有人还不明白，
原：便把伊错认作一只彩凤，
原：那倒没什么不可。

# 四〇
原：假如黄昏时分，
原：忽来了一阵雷电交加的风暴。
原：不须怕得呀，爱人！
原：我将紧拉着你的手，
原：到窗口并肩坐下，
原：我们一句话也不要讲，
原：我们只凝视着
原：我们自己的爱力
原：在天边碰着，
原：碰出金箭似的光芒，
原：炫瞎我们自己的眼睛。

# 四一
原：有酸的，有甜的，有苦的，有辣的。
原：豆子都是红色的，
原：味道却不同了。
原：辣的先让礼教尝尝！
原：苦的我们分着囫囵地吞下。
原：酸的酸得像梅子一般，
原：不妨细嚼着止止我们的渴。
原：甜的呢！
原：啊！甜的红豆都分送给邻家作种子罢！

# 四二
原：我唱过了各样的歌儿，
原：单单忘记了你。
原：但我的歌儿该当越唱越新，越美。
原：这些最后唱的最美的歌儿，
原：一字一颗明珠，
原：一字一颗热泪，
原：我的皇后啊！
原：这些算了我赎罪底菲仪，
原：这些我跪着捧献给你。
