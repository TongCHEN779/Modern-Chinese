# 梅尧臣小传
原：梅尧臣（1002—1060）字圣俞，宣城人，有《宛陵先生集》。王禹偁没有发生多少作用；西昆体起来了，愈加脱离现实，注重形式，讲究华丽的词藻。梅尧臣反对这种意义空洞语言晦涩的诗体，主张“平淡”，在当时有极高的声望，起极大的影响。他对人民疾苦体会很深，用的字句也颇朴素，看来古诗从韩愈、孟郊、还有卢仝那里学了些手法，五言律诗受了王维孟浩然的启发。不过他“平”得常常没有劲，“淡”得往往没有味。他要矫正华而不实、大而无当的习气，就每每一本正经的用些笨重干燥不很像诗的词句来写琐碎丑恶不大入诗的事物，例如聚餐后害霍乱、上茅房看见粪蛆、喝了茶肚子里打咕噜之类。可以说是从坑里跳出来，不小心又恰恰掉在井里去了。再举一个例。自从《诗经·邶风》里《终风》的“愿言则嚏”，打嚏喷也算是入诗的事物了，尤其因为郑玄在笺注里采取了民间的传说，把这个冷热不调的生理反应说成离别相思的心理感应。诗人也有写自己打嚏喷因而说人家在想念的，也有写自己不打嚏喷因而怨人家不想念的。梅尧臣在诗里就写自己出外思家，希望他那位少年美貌的夫人在闺中因此大打嚏喷：“我今斋寝泰坛外，侘傺愿嚏朱颜妻。”这也许是有意要避免沈约《六忆诗》里“笑时应无比，嗔时更可怜”那类套语，但是“朱颜”和“嚏”这两个形像配合一起，无意中变为滑稽，冲散了抒情诗的气味；“愿言则嚏”这个传说在元曲里成为插科打诨的材料，有它的道理。这类不自觉的滑稽正是梅尧臣改革诗体所付的一部分代价。
注：平淡：《宛陵先生集》卷二十八《和晏相公》、卷四十六《读邵不疑诗卷》、卷六十《林和靖先生诗集序》。
注：肚子里打咕噜之类：《宛陵先生集》卷二十三《四月二十八日记与王正仲及舍弟饮》、卷三十《扪虱得蚤》、卷三十六《八月九日晨兴如厕有鸦啄蛆》、卷五十六《次韵和永叔〈尝茶〉》等等，参看贺裳《载酒园诗话》卷一“咏物”条又卷五。
注：别相思的心理感应：参看洪迈《容斋随笔》卷四。
注原：而说人家在想念的：例如苏轼《元日过丹阳》：“白发苍颜谁肯记，晓来频嚏为何人？”又黄庭坚《薛乐道自南阳来入都留宿会饮》：“举觞遥酌我，发嚏知见颂。”
注：而怨人家不想念的：例如辛弃疾《〈稼轩词〉补遗》里《谒金门·和陈提干》：“因甚无个阿鹊，地，没工夫说里。”
注原：侘傺愿嚏朱颜妻：《宛陵先生集》卷十三《愿嚏》。参看萧东夫《齐天乐》：“甚怕见灯昏，梦游间阻，怨煞娇痴，绿窗还嚏否？”（《草堂诗》卷中）《牡丹亭》第二十六出《玩真》柳梦梅所谓“叫得你喷嚏像天花唾”，正是这个意思。
注：为插科打诨的材料：例如杨文奎《儿女团圆》第二折“王兽医上，打悌科”；《李逵负荆》第三折、《看钱奴》第三折、《货郎旦》第四折等都有这个打诨。

# 田家
原：南山尝种豆，/碎荚落风雨；/空收一束萁，/无物充煎釜。
注：碎荚落风雨：豆荚给风吹雨打得都零落了。
注：空收一束萁：豆茎。
注原：无物充煎釜：这首诗借用两个古人的名句：汉代杨恽《报孙会宗书》的“田彼南山，芜秽不治；种一顷豆，落而为萁！”和三国时曹植《七步诗》的“萁向釜下燃，豆在釜中泣；本自同根生，相煎何太急！”杨恽是讽刺朝廷混乱，曹植是比喻兄弟残杀，梅尧臣把他们的话合在一起来写农民的贫困，仿佛移花接木似的，产生了一个新的形象。意思说：农民虽然还有豆萁可烧，却没有豆子可煮，锅里空空的，连“煮豆燃萁”都不可能了。

# 陶者
原：陶尽门前土，/屋上无片瓦；/十指不沾泥，/鳞鳞居大厦。
注原：鳞鳞居大厦：这是写劳动人民辛苦产生的果实，全给剥削者掠夺去享受。汉代刘安《淮南子》卷十七《说林训》里有几句类似谚语的话讲到这种不合理的现象，也提及梅尧臣诗里所说的烧瓦工人：“屠者藿羹，车者步行，陶人用缺盆，匠人处狭庐为者不得用，用者不肯为。”可是这几句只是轻描淡写，没有把“为者”和“用者”双方苦乐不均的情形对照起来，不像后来唐代一句谚语那样衬托得鲜明：“赤脚人趁兔，著靴人吃肉。”（慧明《五灯会元》卷十一延沼语录，《全唐诗》第十二函第八册“语”类。）唐诗里像孟郊《织妇词》的“如何织纨素，自著蓝缕衣！”郑谷《偶书》的“不会苍苍主何事，忍饥多是力耕人！”于渍《辛苦行》的“上扶犁儿，手种腹长饥；窗下掷梭女，手织身无衣；”和杜荀鹤《蚕妇》的“年年道我蚕辛苦，底事浑身著苎麻？”也都表示对这种现象的愤慨。梅尧臣这首诗用唐代那句谚语的对照方法，不加论断，简辣深刻；同时人张俞的《蚕妇》：“昨日到城郭，归来泪满巾；遍身罗绮者，非是养蚕人。”（吕祖谦《皇朝文鉴》卷二十六）虽然落在孟郊、杜荀鹤等的范围里，也可以参看。罗隐《蜂》：“采得百花成蜜后，为谁辛苦为谁甜？”正是同样的用意而采取了比喻的写法。

# 田家语
原：庚辰诏书：/凡民三丁籍一，/立校与长，/号“弓箭手”，/用备不虞。
注原：用备不虞：“庚辰”是宋仁宗赵祯康定元年，那年西夏出兵攻宋。宋代兵制，正规军队之外，还有“乡兵”或称“弓箭手”、或称“弩手”、或称“枪手”等等；就当地人口每户二丁三丁抽一，四丁五丁抽二，六丁七丁抽三，八丁以上抽四，“团结训练，以为防守”（《宋史》卷一百九十）。“籍”是把名字登记在兵士“花名册”上。
原：主司欲以多媚上，/急责郡吏；/郡吏畏，/不敢辨，/遂以属县令。
原：互搜民口，/虽老幼不得免。/上下愁怨，/天雨淫淫，/岂助圣上抚育之意耶？
注：天雨淫淫：中国古代流行“天人感应”那种说法，以为人事处置不当，就会引起天灾；诗里“愁气变久雨”也是这个意思。
原：因录田家之言，/次为文，/以俟采诗者云。
注原：以俟采诗者云：相传周代有“行人”这种官，负责搜集民间的诗歌，好让“天子”知道些人民的舆论和生活。白居易《新乐府》第五十首说：“采诗官，采诗听歌导人言；言者无罪闻者诫，下流上通上下泰。周灭秦兴至隋氏，十代采诗官不置。”宋代的学者甚至认为“采诗官不置”是秦亡的原因。（郑樵《夹漈遗稿》卷二《论秦因诗废而亡》）宋代当然也没有设立“采诗官”，梅尧臣的意思不过说希望他这首诗能够使下情上达。“次”是“编排”。
原：谁道田家乐？/春税秋未足！/里胥扣我门，/日夕苦煎促。
原：盛夏流潦多，/白水高于屋。/水既害我菽，/蝗又食我粟。
原：前月诏书来，/生齿复板录；/三丁籍一壮，/恶使操弓镯。
注原：生齿复板录：“生齿”就是人口；“板”通“版”，就是登记。
注：恶使操弓镯：“恶”就是“凶狠”；“镯”音“独”，又音“蜀”，弓的套子。
原：州符今又严，/老吏持鞭朴；/搜索稚与艾，/唯存跛无目。
注原：州符：“符”指命令或公文。“州”指那时候所谓“府”，就是序里的“郡”。
注：唯存跛无目：老的小的都抽去了，只留下些瘸子和瞎子。
原：田闾敢怨嗟，/父子各悲哭。/南亩焉可事？/买箭卖牛犊。
注：田闾敢怨嗟：“敢”等于“不敢”或“何敢”。在汉代作品里往往“如”等于“不如”，“敢”等于“不敢”（顾炎武《日知录》卷三十二“语急”条）；宋人常模仿这种语法，所以南宋的任渊、刘辰翁等人在注或评王安石、陈师道等诗集时，把“堪”解释为“不堪”，“得知”解释为“不得知”。
注：买箭卖牛犊：这是反用汉代龚遂教百姓“卖剑买牛，卖刀买犊”的故事。
原：愁气变久雨，/铛缶空无粥。/盲跛不能耕，/死亡在迟速。
注：死亡在迟速：早晚就要死。
原：我闻诚所渐，/徒尔叨君禄；/却咏《归去来》，/刈薪向深谷。
注：刈薪向深谷：据跟这首诗同时作的《汝坟贫女》来推测，这时候梅尧臣做河南襄城县令，所以说“叨君禄”；“却咏《归去来》”借用陶潜《归去来词》。

# 汝坟贫女
题解：河南汝河河边。“汝坟”原是《诗经》的《国风·周南》里一首诗题；那首诗是妇女的口气，说道：“鲂鱼颍尾，王室如毁；虽则如毁，父母孔迩。”梅尧臣这首诗也记载妇女的哀怨，进一层说私家也“毁”了，连父亲都磨折死了，自己没依没靠的了。
原：时再点弓手，/老幼俱集。/大雨甚寒，/道死者百人；/自壤河至昆阳老牛陂，/僵尸相继。
原：汝坟贫家女，/行哭音凄怆。/自言有老父，/孤独无丁壮。
原：郡吏来何暴，/县官不敢抗。/督遣勿稽留，/龙钟去携杖。
原：勤勤嘱四邻，/幸愿相依傍。/适闻闾里归，/问讯疑犹强。
注：幸愿相依傍：这一句是女孩子嘱托街坊的话。老头子逼得没路走，只好拄着拐棍去充乡兵，邻居也有人一同抽点去的，女孩子就恳求他们照顾她爸爸。
注：问讯疑犹强：以为他还能勉强支持，便去打听消息。
原：果然寒雨中，/僵死壤河上。/弱质无以托，/横尸无以葬；
原：生女不如男，/虽存何所当！/拊膺呼苍天，/生死将奈向?
注原：生死将奈向：活下去呢？还是一死完事呢？“奈”就是“何”。梅尧臣同时人的记载可以跟这两首诗印证的，是司马光的《论义勇六札子》。（《温国文正司马公文集》卷三十一至卷三十二）《第一札子》说：“康定庆历之际，赵元昊叛乱.....国家乏少正兵，遂籍陕西之民，三丁之内选一丁以为乡弓手......闾里之间，惶扰愁怨......骨肉流离，田园荡尽”;《第五札子》说抽去当弓箭手的人，脸上或手上都刺了字，还得缴纳军粮，“是一家而给二家之事”。

# 鲁山山行
题解：一名露山，在河南鲁山县东北。
原：适与野情惬，/千山高复低。/好峰随处改，/幽径独行迷。
注：适与野情惬：恰恰配合我爱好天然风物的脾气。
原：霜落熊升树，/林空鹿饮溪。/人家在何许？/云外一声鸡。

# 东溪
题解：一名宛溪，在梅尧臣故乡宣城。
原：行到东溪看水时，/坐临孤屿发船迟。/野凫眠岸有闲意，/老树着花无丑枝。
原：短短蒲茸齐似翦，/平平沙石净于筛。/情虽不厌住不得，/薄暮归来车马疲。

# 考试毕登铨楼
题解：这首是《宛陵先生集》里遗漏的诗，误收入“四库全书馆”辑本刘攽《彭城集》卷十八，现在根据北宋晁说之《晁氏客语》和南宋无名氏《爱日斋丛钞》卷三订正。梅尧臣是嘉祐二年（公元1057年）春天进士考试的“小试官”（欧阳修《归田录》卷二）；《宛陵先生集》所收这时期的诗里有《上元从主人登尚书省东楼》一首，大约就指这里所谓“铨楼”，“铨”是考选的意思。
原：春云浓淡日微光，/双阙重门耸建章。/不上楼来知几日，/满城无算柳梢黄。
注：双阙重门耸建章：借用汉武帝的宫名来指当时汴梁的宫殿。
注：不上楼来知：一作“今”。
注：满城无算：一作“多少”。
