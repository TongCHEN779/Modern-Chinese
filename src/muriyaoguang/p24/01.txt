# 张居正和明代中后期政局大事记


# 嘉靖四年至十四年(1525—1535)张居正1岁至11岁
原：政局
原：居正出生之时，“大礼”、“大狱”事件刚过最高潮，原首辅杨廷和、大学士蒋冕、毛纪等已相继下台，主张继统不继嗣的张璁、桂萼、方献夫等逐渐执政，嘉靖皇帝牢固地控制着统治权力。
原：四年，南京翰林院侍读严嵩调任北京国子监祭酒。
原：五年，龙虎山道士邵元节被封为真人，入朝直显灵宫。
原：六年，张璁入阁。
原：七年，敕定议礼诸臣罪状：杨廷和削籍，大学士蒋冕、毛纪，尚书汪俊各夺官闲住。
原：八年，桂萼入阁。
原：十年，征帑金七万两购金珠宝石。
原：兴建神祇坛、帝王庙、西苑仁寿宫等，开纳助工银两。
原：敕改皇帝出生地安陆州为承天府，县曰钟祥。
原：礼部右侍郎顾鼎臣上《步虚词》七章，又言青词直通神明最为重要，自此朝臣竞上青词。
原：十二年，致一真人邵元节加俸百石，给役四十人，掌道教。
原：十三年，嘉靖皇帝久不视朝，宣称“静摄”。
原：五年和十一年，湖广荆州均地震。
原：自五年至十四年，湖广荆州连年水灾，大饥，灾民流劫为患。
原：事迹
原：四年五月初三日，张居正出生在湖广荆州府江陵县隶属军籍的不第秀才家庭。祖父张镇为辽王府护卫卒，父亲张文明读书入庠，但七试均不第。
原：居正自少聪慧，3岁识字，5岁能句读，10岁通六经大义，文字通顺。

# 嘉靖十五年(1536）12岁
原：政局
原：嘉靖皇帝在本年内四次亲往天寿山谒陵，“自择寿宫”。
原：谕购红黄玉于西域。
原：西苑清虚殿完工，建金篆大醮于玄极殿。
原：宣府、大同、延宁均报警，蒙古俺答部分兵来犯。
原：延绥凶饥。
原：礼部尚书夏言入阁。
原：以道士邵元节为礼部尚书。
原：事迹
原：居正补博士弟子高第。知府李士翱，学使田顼盛称其才。初名白圭，始改名为居正，字叔大，别号太岳(太岳)。自是有“荆州张秀才”之称。

# 嘉靖十六年(1537)13岁
原：政局
原：皇子载垕出生，此即他日的明穆宗隆庆皇帝。
原：嘉靖皇帝在本年内又两次亲往天寿山，选定“寿宫”。
原：藩邸在荆州的辽王致格去世，其妃毛氏掌权，对年幼的张居正特别看重，并用以激励其子宪。
原：俺答部四万余人进犯宣府、大同。
原：礼部尚书严嵩摘指广东试录句有失崇上之义，逮捕巡按御史余光等下法司。事迹参加乡试，受湖广巡抚顾璘特别赏识，许以国士。顾璘又欲老其才，俾成大器，有意暂不取录。

# 嘉靖十七年(1538) 14岁
原：政局
原：敕开云南大理、河南宜阳等地银矿，以应大工之需。
原：嘉靖又两次亲赴天寿山，“营寿陵”。
原：嘉靖皇帝亲送其母蒋太后的灵柩归葬承天，行大享礼。
原：车驾至卫辉，行宫失火，锦衣指挥陆炳排闼负帝出险，自是受宠信逾常。
原：夏言任首辅。
原：辽东、大同相继发生兵变。
原：邵元节死，赠少师，谥文康荣靖，是为方士有谥之始。
原：进邵元节之徒陶仲文（典真）为真人，总领道教。

# 嘉靖十九年(1540) 16岁
原：政局
原：秉一真人陶仲文立雷坛，斋醮大兴。
原：太仆寺卿杨最疏谏勿误信方士，指揭白日升天之说、黄白金丹之术均为无稽荒诞，被杖死。
原：事迹
原：参加乡试成举人，巡抚顾璘赠以诗文玉带，勉励为国努力，缔结忘年交。

# 嘉靖二十年至二十二年(1541—1543)17岁至19岁
原：政局
原：嘉靖皇帝称疾，经年不视朝，日事斋醮。
原：工程繁兴，相继构建元极宝殿、大享殿、大高元（玄）殿。
原：二十年正月，河南道御史杨爵痛陈四方饥馑相仍，小民委命沟壑，请停妖诞邪妄之术，斥退方士，被下诏狱，反复杖责。户部广东司主事周天佐、陕西道御史浦镓亦以为言，均被杖死。
原：二十一年七月，礼部尚书严嵩兼武英殿大学士，预机务。
原：十月，发生宫婢杨金英等因不堪凌辱，企图用绳索勒死嘉靖的异常事件。事败，均被磔于市，仍剉尸枭示，收斩族属。端妃曹氏、宁嫔王氏均处死。嘉靖受此刺激，自此移住西苑，不复还宫。
原：严嵩初入内阁，夏言与严嵩的矛盾冲突从此展开。
原：二十二年，夏言一度失宠，被勒闲住。
原：严嵩之子世蕃任尚宝司少卿。
原：辽东、延绥、宣大诸边皆告急。
原：贵州铜仁苗族被地方官绅激变，攻掠湖广麻阳等地。

# 嘉靖二十三年(1544)20岁
原：政局
原：敕派右副都御史万镗率师镇压贵州铜仁苗族。
原：秉一真人陶仲文进少傅兼少保，支正一品俸。
原：进严嵩太子太傅，又进吏部尚书兼谨身殿大学士，“事取独断”。
原：谕礼部，谓“擒叛销氛，俱朕祷玄之功，即设醮谢上帝。”自此，凡有大事，俱谢玄。
原：事迹
原：参加会试，不第。自言因为“驰骛古典”，未在科举时文中下工夫所致。

# 嘉靖二十四年至二十五年(1545—1546)21岁至22岁
原：政局
原：二十四年，敕召夏言再入阁兼吏部尚书，位在严嵩上。夏骄矜，严谀忌，关系恶化。
原：陆炳署锦衣卫事。
原：二十五年，陕西总督曾铣上修边墙、复河套二策，受夏言支持。
原：俺答遣使诣大同求贡，不准。又率兵来犯宣府。
原：吏部尚书熊浃以谏仙箕，被罢官除名，押还乡里。

# 嘉靖二十六年至二十八年(1547—1549)23岁至25岁
原：政局
原：二十七年，秉一真人陶仲文六年考满，特授光禄大夫柱国，兼大学士俸，荫其子世恩尚宝司丞。不久，又增赐陶仲文支伯爵俸。
原：曾铣再上边务十八策，重点仍在恢复河套，一度受嘉靖嘉许，但不旋踵，又罢复套议，并逮治。夏言亦以私荐曾铣论罪，严嵩、陆炳乘隙力攻之，与曾铣俱被杀于西市。
原：严嵩为首辅。
原：徐阶从吏部侍郎拔擢为礼部尚书。
原：赐辽王宪清微忠教真人金印。
原：二十八年，俺答率部侵犯宣府，射书求款，且归还所掠人畜，声言如不许贡，将大举侵掠。拒之。
原：事迹
原：二十六年，会试成进士，选入翰林院为庶吉士。徐阶任教习。读中秘书，“潜求国家典故与政务之要切者”，致力了解枢垣政情，官场风气，边塞防务，民生动态，撰写《翰林院读书说》，针对时弊，阐述学术旨在经世的主张。深受其师徐阶的器重。
原：二十八年，升授翰林院编修。上《论时政疏》，历陈宗室骄恣、庶官瘰旷、吏治因循、边务未修、财用大匮等所谓五大弊，吁请从速采取整治措施。不报。

# 嘉靖二十九年(1550) 26岁
原：政局
原：俺答纠合各部，兴兵十余万人，分途间道攻掠密云、怀柔、顺义，直薄北京。京师被困，戒严，敕各路兵马入援。
原：国子监司业赵贞吉主张积极御敌，不可屈为城下之盟。一度受嘉靖认可，被派出城劳军，鼓舞士气，但却受严嵩、仇鸾刁难诬陷，反指为罪，被谪荔浦典史。
原：俺答饱掠辎重后退兵，京师解严，是为“庚戌大变”。
原：刑部郎中徐学诗愤“大变辱国戕民”，疏劾首辅严嵩“奸贪饵敌”，乞罢嵩以息外患，被革职，下诏狱。

# 嘉靖三十年至三十二年(1551一1553)27岁至29岁
原：政局
原：三十一年，建立内府营，以军制操练内侍。
原：西苑产嘉谷，各地藩王及官吏亦纷纷献上嘉谷瑞兔等，奏告太庙。以秉一真人陶仲文“阴兵慑虏”功，加岁禄百石，荫子入太学。
原：徐阶入内阁，仍兼礼部尚书。
原：徐阶串连陆炳共同揭发仇鸾“通虏误国”，仇鸾败死后被枭示。
原：严嵩嫉忌徐阶地位上升，阴柔笼络而密切监控之；徐则对严外托恭谨，中怀警惕，双方从此展开了长达十余年的明争暗斗。
原：三十二年，翰林院编修高拱、检讨陈以勤任裕王载垕侍讲官。
原：张四维、马自强会试得中，选为翰林院庶吉士。
原：锦衣卫经历沈谏、兵部武选司员外郎杨继盛、云贵巡抚御史赵锦等先后上疏弹劾严嵩父子贪贿鬻官、结党营私等罪状，均被廷杖。沈谪佃保安；继盛论死囚禁；赵锦削籍。
原：财政危机严重，岁入不能充岁出之半。京边军费用至596万两，备倭、营建、采木、斋醮费用又倍增，敕行加派，有箕敛、财贿、题增、派估、赃赎、算税契、折民壮、提编、均徭、推广事例诸多名目。
原：倭寇连年入掠浙江、南直隶、福建城邑，参将卢镗、解明道、李元律先后阵亡，守军望风而溃，东南大震。
原：俺答、吉能、小王子等部分道来犯，经紫荆关突入山西；自平型关入掠代州、繁峙，窥泾原；自宣府柴沟堡溃墙入胁京畿，守军多溃败。
原：把都儿台吉求互市，不许。
原：事迹
原：继续在翰林院编修任内，仍密切关心时事发展，思考扶危济倾之对策。对徐阶入阁曾寄予厚望，与徐的关系进一步密切，有时亦参与谋议。

# 嘉靖三十三年(1554)30岁
原：政局
原：司礼太监黄佐、锦衣卫左都督陆炳各荫子锦衣百户，奖励其侦伺缉捕立功。
原：山东、河南大饥，民相食。河南农民军师尚诏部连陷归德、柘城、鹿邑。湖广襄樊间流民结寨自保，抗拒官军。
原：贵州苗民武装反对苛扰暴敛。
原：事迹
原：深怀消沉失落，告假回乡“养病”。行前致书徐阶，表达对时局的忧虑以及本人的焦灼，希望徐阶能以在位之身，毅然采取对策。

# 嘉靖三十四年至三十八年(1555—1559)31岁至35岁
原：政局
原：嘉靖皇帝猜刻迷信暴虐贪婪更甚，以刑杀立威。
原：三十四年，严嵩、赵文华构陷作战有功的总督张经、巡抚李天宠，指为失误戎机，擅自纵敌，并将杨继盛附入案内，同日处死于西市。
原：三十五年，吏部尚书李默坐诽镑下锦衣狱，论死；户科左给事中杨允绳被指为“谤讪玄修”，论死；锦衣卫经历沈铺被处决于宣府；副总兵陈凤被斩首于延绥。众言官被斥革、除籍、廷杖、遣谪者甚多。
原：徐阶虽渐升为“次辅”，但因皇帝喜怒不常，曾两度受谗而几陷于危，“但精修青词以自保”。“严氏之焰尚炎”，徐阶之力尚不足与抗，在外表上仍采取“诎节卑礼”的低姿态，“而阴谋挠嵩权者久矣”。
原：给事中吴时来、刑部主事张翀、董传策交章弹劾严嵩，三人俱发烟瘴卫所远戍，徐阶几被指为主使者而罹祸。严徐关系进一步恶化。
原：俺答等部分兵攻犯辽东、宣大、蓟州，最多时集中兵力达二十余万人，边防告急。
原：倭警频传。这数年是明代倭患最严重的时期。倭兵及海盗合流，分道连犯乍浦、海宁，趋杭州；自闵行、斜塘进迫苏州，过江犯扬州；南京皇陵及漕运均受威胁；两浙俱燃战火；另一股又南下广东潮州。总兵俞大猷等力战，但未能稳定东南局面。
原：三十七年，翰林院修撰李春芳、侍读严讷等直西内撰玄，自是词官多舍本职，专注供奉玄文。
原：翰林院编修高仪署国子监司业。
原：敕派工部右侍郎刘伯跃总督四川湖广，专责采办大木；另一侍郎张舜臣专责采石于大石窝。
原：三十八年，指派顺天市珠四十万颗，广东采珠九十万颗进奉。
原：指派广东、福建进龙涎香。
原：诏礼部采芝名山。
原：敕开四川、山东、河南银矿，矿使开始为患。
原：设“大工开纳例”，凡交纳一定数目银两，可得世袭官。
原：湖广大旱又大水。
原：事迹
原：乡居六年，表面上闭门蛰居，表示有终老田间之意，但出世与入世，遁世与经世的矛盾一直交战于胸臆之间。中怀郁郁，未有忘情于政治。对于“北虏南倭，并为国患”，奸佞当朝，政事蜩螗，民生憔悴，道殣相望，无日不系念于怀。“目极心如怒，顾望但怀愁”。“抱火寝薪非一日，病夫空切杞人忧”。人在江湖，心驰廊庙。荆州故园，终非隐退之乡。

# 嘉靖三十九年(1560) 36岁
原：政局
原：时局酝酿重大变化；一为嘉靖皇帝本人衰病相寻，昏愦狂悖愈甚；二为徐阶在与严嵩的持久斗争中，已逐渐取得主动，从劣势转为相对优势。
原：秉一真人陶仲文、锦衣卫都督陆炳相继去世。
原：严世蕃护送其母灵柩回籍，严嵩留京，因耄昏，回奏及办事多有不如嘉靖意之处。
原：俺答出兵喜峰口，攻蓟镇，进入通州、顺义、密云，直指京师以北。小王子等以五万余骑攻陷辽东广中前卫，破一片石关，进入山西、陕西，大杀掠。
原：倭寇在福建流劫各州县，大埔之“密贼”，南湾之“水贼”，尤溪之“山贼”，龙岩之“矿贼”，南塘、永定之“流贼”，均乘间蜂起。
原：事迹
原：回京复职，升右春坊右中允，署国子监司业，祭酒由太常寺卿高拱兼任，是为二人共事之始。

# 嘉靖四十年(1561)37岁
原：政局
原：原万寿宫火灾，徐阶规划利用三殿余材从速重建，得嘉靖欢心。史家谓“阶虽任智数，要为不失其正”。
原：吏部侍郎袁炜以能巧撰青词得殊宠，被拔擢礼部尚书，进太子太保，入直西苑，供奉玄修。不久，又改为户部尚书武英殿大学士，入阁预机务。
原：戚继光誓师台州，严军纪、重训练，设伏歼灭来犯浙江之倭寇，军威稍振。
原：巡按御史潘季驯在广东倡行均平里甲之法，广人便之。
原：淳安知县海瑞在境内推行丈田，为均平赋役之初步。

# 嘉靖四十一年(1562) 38岁
原：政局
原：重建西苑万寿宫成，徐阶又请修建永寿宫，十旬而成，嘉靖嘉许徐阶忠，其子徐璠亦超擢太常寺少卿。自是严嵩乃日屈。
原：方士蓝道行诈为卟语，指严嵩为奸臣，御史邹应龙又抗疏专劾严世蕃，尽揭其贪贿擅权、鬻官卖爵诸罪恶，世蕃被下狱，严嵩亦被罢官。
原：徐阶为首辅，榜揭三语以为执政纲领，曰：“以威福还主上，以政务还诸司，以用舍刑赏还公论。”言路得发舒，朝士多拥戴。
原：严嵩败后，嘉靖意绪消沉，一度扬言要传位，退居西内以专祈长生。

# 隆庆二年(1568)44岁
原：政局
原：隆庆嗣位一年，其怠懒贪逸乐好财色的本质即有了充分的暴露。吏科给事中石星、南京户科给事中张历治、御史詹仰庇等均上疏请其“勤政”、“广听纳”、“崇俭戒奢”等。石星之疏文语极严峻，谓：“陛下清心寡欲，渐不如初。今为鳌山之乐，必纵饮，必耽声色。皓齿蛾眉，伐性之斧；甘脆肥浓，腐肠之药。倘不亟戒，万一起居失调，悔将奚及。”隆庆怒其轻讪，杖六十，削籍。张历治等被下所司切责。

# 隆庆四年(1570）46岁

原：“居正为政，以尊主权，课吏职，信赏罚，一号令为主。虽万里外，朝下而夕奉行”。仅在接任当年，即多重要举措。

原：加强对幼年皇帝的培养教育，张居正请从八月份起“开经筵”，距隆庆之丧未过百日。又乞更定常朝三六九日御门听政，余日“听日讲”。

原：居正进《帝鉴图说》，将前史所载兴亡治乱之事，撮其善可为法者八十一事，恶可为戒者三十六事，每一事前绘为一图，供万历皇帝参阅，用为特殊的帝皇教材。

# 万历二年(1574）50岁
原：政局
原：诏行内外官久任法，务求才宜于官，官宜于地（位)。

原：又请仿照明太祖引见廉能官的办法，引见朝觐廉能官浙江布政使谢鹏举等二十五人，面加奖励，各赐金币钞宴。对贪酷有据的保定知府贾淇等十八人，命下法司。

原：精简徒具形式的南京留都部分部院官。

# 万历三年（1575）51岁
原：政局
原：以礼部侍郎张四维为礼部尚书兼东阁大学士，预机务。万历在诏书中加注“随元辅等入阁办事”，于是四维恂恂若属吏，不敢以同僚自处。

原：事迹
原：整顿驿递制度。提高各省驿传道职权地位，颁给专敕关防，同于兵备道、提学道。官吏非公出不许乘传。公出驰驿亦有对日程、路程、供应待遇等的严格规定，违者法办。居正以身作则，谓：“驿递一事，近例颇严，人似无敢犯者。大抵为政必贵身先。顷小儿回籍应举，自行顾倩。昨冬遣仆归寿老亲，身负仪物，策蹇而行，盖不敢身自犯之也。”
