# 屈原

底本：郭沫若《屈原》（五幕历史剧，1942年初版），人民文学出版社“百年百种优秀中国文学图书”丛书本，2000年7月第1版。

整理说明：按人物表、第一至第五幕分页（第五幕分第一场、第二场）。去掉了封面、版权页、丛书前言与书目、评选委员会名单、作者简介、页码、页脚注（仅一条小注“阿金”，正文中的注码已删）。台词与舞台提示各自成段，角色名保留在原位；剧中《橘颂》、民歌、《礼魂》等诗行逐行成段。幕、场名为排版识别后人工补定。

已知 OCR 问题：
- 角色名有时被识别成“朱玉”“未玉”“老姐（应为老媪）”等，已改回；“三间/三闯/三阎大夫”统一为“三闾大夫”；其余OCR 错字未逐一校改（如“若干”“一趟”类形近字可能有漏网）。
- 第三幕“宋玉、子兰（同时）”两处，及第四幕“卫士甲、乙”，原版为竖排小字叠写，OCR 识别残缺，系据上下文补定，存疑。
- 第三幕末尾“靳尚……撕毁了”处原识别为字母“T”，已按文意改为“了”。
- 未发现整页缺失；正文自第一幕起至第五幕“1942年1月11日夜”完整。
