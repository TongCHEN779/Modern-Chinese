# 茶馆（bnbz_62）

## 底本

## 已知 OCR 问题
- 原书为双栏式排版，OCR 中说话人名常被识别到台词的前一行或后一行，整理时凭规则把名字归位；个别归位可能有误。
- 部分台词行首的角色名被 OCR 丢失，仍为无名字的独立段（如第一幕“我要活的，可不要死的！”已按版面补为庞太监，其余少数段未补）；个别位置只剩孤立的角色名而台词丢失，约 15 处（如第二幕“老陈”、第三幕“车当当”“谢勇仁”，龙须沟第二、三幕若干“二春/四嫂/娘子/大妈”等），这些空角色名已删除。
- 第三幕“（同周康顺子秀花下）”为两栏交错所致，应为“周秀花、康顺子”。
- 年份中的“〇”常被丢（“一九五年”已改为“一九五〇年”）；另有“一九五○年”写法保留原样。
- 个别形近字疑似错误（如“抓醛”“蹈蹦”“蹈够了”）未改动。
- 未发现整页缺失。
