# 秋瑾选集（增订本）

- 底本：［清］秋瑾著，郭延礼、郭蓁选注《秋瑾选集》（中国古典文学读本丛书典藏），人民文学出版社，2020 年第 2 版（增订本）。文字由书籍扫描件（PDF）经 OCR 识别、整理而成，**尚未逐字校对**。
- 分页：前言；文选；书信选；诗选分三期（第一期 出国前、第二期 留日时期、第三期 归国后直至就义）三页；词选；歌选；弹词《精卫石》（序及第一至六回）；附录《秋瑾年谱简编》（各年为一节）。
- 整理：去掉封面、版权页、丛书广告、总目录、页眉页脚与页码；每篇作品为一节，诗词按语句分行（句间 `/`），每四句左右为一段，文与弹词按自然段。原书的题解放在节首“题解”，其余注释放回各自所属段落之后。
- 注释定位：原书注释集中排在每部分（文选、书信选、各期诗、词选、歌选、弹词、年谱）之后，以正文里的 [n] 标号对应；本站按标号把各条放回对应的段落。OCR 丢失标号的 6 条（诗选第一期 2 条、弹词 1 条、年谱 3 条中的 1 条经词语定位，其余按前后位置）按注释词语或前后标号就近放置；标号写在篇题上的注释一律作“题解”。个别注释因词语在正文里查不到，在前面补了所注的一小段原文作词语。注释里的圆圈、多条合写的词条，按站内格式处理（部分以“注原”一条整录）。
- OCR 已知问题：原书脚注标号偶有误识（如把“7”识成“2”），已按顺序改正；个别句末标点为 ASCII 的，改为全角；其余错字、缺字（如弹词注释中个别词语被识丢）未改。弹词《精卫石》的回目页（全书二十回目录，仅前六回有正文）未收。
