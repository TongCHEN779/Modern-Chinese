# 包青天断案

- 底本：毕珍著《包青天断案》（“中国名人轶事丛书”之二，吴洪激主编），武汉大学出版社、台湾汉欣文化事业有限公司联合出版，1994 年 4 月第 1 版（ISBN 7-307-01629-X/I·136）。文字由扫描件（PDF，读秀/Anna's Archive 来源）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：共二十页——丛书出版缘由、主编絮语（吴洪激序）、十八篇故事各占一页；页标题取各篇篇名（风月一枝莲、窑中奇尸、翻江倒海金鲤鱼、石狮子眼中血、玄门迷药、冤狱怨鬼、大破光棍党、计审花和尚、金钗·玉钗、血光灾、罗汉·乞丐、赵王丧生龙头铡、梦冤、兔子戴帽、绣花鞋、灵龟、假金钗，破奇案、观音·黑龙·秀才）。各篇内以书中“二、三、四……”为小标题分节，书中第一节无编号，节名取“一”。目录页的“龙头刨”为 OCR 之误，据各页页眉作“龙头铡”。
- 去掉的内容：封面、书名页（“中国名人轶事丛书团　毕珍著”）、版权页、目录页、页眉（篇名、“包青天断案”）与页码（含与正文行粘连的“• 12•”之类）、书末丛书广告页与 Anna's Archive 水印页；《出版缘由》《主编絮语》文末的署名（OCR 作“是性激”“吴洪激”）。“主编絮语”文末的写作日期保留，原识作“甲戊年”，据干支改为“甲戌年”。
- 段落：按扫描版面的首行缩进重建（原 full.txt 的段落合并不可靠，故直接用 json 逐行坐标重排）；跨行、跨页的段落已接合（个别页首无缩进而上页以句号收尾者，按版面视为同一段）；诗词（第四篇无虚上人所留四句）用“诗：”每句一行；判词、状纸按一段处理，书中另起的“——告为……”“——审得……”标题行单独成段。
- 分节标记：书中只有“二、三、四、五……”居中成行，OCR 大量漏识（凡缺的都按版面上下留白的异常间距补回，并与前后已识别的序号核对一致）。补回的位置：第一篇二（p14）；第二篇二、三；第三篇二、三；第四篇二、三；第五篇二、三；第六篇二、三；第七篇二、三；第八篇二；第九篇二、三；第十篇二、三；第十一篇二（p206）；第十二篇二、三；第十三篇二、三（梦冤 p243、p247）；第十四篇二、三；第十五篇二；第十六篇二、三；第十七篇二、三；第十八篇二、三。《罗汉·乞丐》的“七”OCR 作“七日”（居中，疑“七”后带印刷杂点），按“七”处理；该篇末另有一个孤立的“11”，视为杂点删去。
- OCR 已知问题：个别单字错识与形近字（如“刨/铡”“侧/铡”“着”等）未逐一校改；“……”“——”有被识作单个字符或漏识的；单独成行的孤立“”（如 p48、p259）并入上一行；页眉页脚残留的碎片（孤立字母、数字、“反”“正”“A”等）已删，但仍可能有遗漏；半角标点已转为全角；书中“着”“象”等用字不改。原文本身疑有脱字（如《主编絮语》“有一子，名包，为董氏所生”应为“名绶”），保持原样。
