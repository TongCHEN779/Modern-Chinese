# 中国现代作家选集·茅盾

- 底本：庄钟庆编《茅盾》（“中国现代作家选集”），人民文学出版社、三联书店香港分店联合编辑出版，1983 年 8 月北京第 1 版第 1 次印刷，书号 10019·3500（无 ISBN）。文字由书籍扫描件（PDF 茅盾.pdf，共 296 页）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：共 36 页。书前叶圣陶《略谈雁冰兄的文学工作（代序）》一页；“作品部分”小说、散文、回忆文章三十三篇各一页（页标题用书中篇名）；“资料部分”庄钟庆《茅盾——中国新文学的巨匠》、茅盾著译简表各一页。篇内有“一、二、三”小节号的（《创造》《小巫》《林家铺子》《春蚕》《神的灭亡》《萧红的小说——《呼兰河传》》），各小节另起一节；著译简表每个年份为一节。
- 去掉了：封面、版权页、作者像与照片页、书信手迹页（OCR 不成字，PDF 第 11—14 页）、目次页、“作品部分”“资料部分”隔页、扫描件末尾的 Anna's Archive 说明页，页眉页脚页码，以及各页底部的脚注（《春蚕》《卖豆腐的哨子》《阿四的故事》等篇有脚注，正文里的脚注序号一并去掉）。每篇末尾的写作日期与“（原载……）”出处行保留为该篇最后的段落。
- 小节号：OCR 漏识的小节号按版面空行补回——《创造》一，《小巫》一、二（二在 PDF 第 52 页“老爷为的贩‘货’”前），《林家铺子》一、二（二在第 68 页“第二天，林先生的”前），《春蚕》一、二（二在第 108 页“天气继续暖和”前），《神的灭亡》一、二（二在第 126 页“神中之王奥定”前），《萧红的小说》一、二（二在第 229 页“萧红的坟墓”前）。
- 篇名补回：《小巫》（PDF 第 50 页）、《委屈》（第 157 页）、《桑树》（第 175 页）三篇篇名在 OCR 中漏识，据目次补；《香市》（第 173 页）篇名只识出“市”字，据正文及原载出处补“香”字。叶圣陶代序的篇名、作者行未收入正文，著译简表、评传的作者行同。
- OCR 已知问题：识别结果偶带“矇、懶、擷、盜、離、疊”等繁体异形，已统一改为简体；“拚命”“反覆”“爇”等书中可能原本如此的写法保留；“洗星海”改为“冼星海”。半角标点已在汉字旁改全角。《黄昏》中风声“呼~~呼~~”的符号为 OCR 结果，未核对原书。叶圣陶代序第 15 页版面偏移，段落由人工按内容接合。
