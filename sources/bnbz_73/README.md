# 台北人（bnbz_73）

## 底本
《台北人》，白先勇 著，作家出版社，2000 年 7 月第 1 版（“百年百种优秀中国文学图书”丛书）。OCR 来源：`百年百种优秀中国文学图书/73、台北人/full.txt`。

## 结构
共 17 页：十四篇小说各一页（篇末署“一九六五年春于美爱我华城”“一九七〇年冬末于美加州”之类作者落款原样保留），及附录三篇各一页：欧阳子《〈谪仙记〉序》、夏志清《白先勇论》（含篇末“附注”）、于梨华《白先勇笔下的女人》。小说内的编号小节（一、二…；《一把青》的“上”“下”）各为一节。
