# 世界短篇小说精品文库·阿拉伯卷

## 底本
- 柳鸣九 主编、郅溥浩 编选：《世界短篇小说精品文库·阿拉伯卷》，福州：海峡文艺出版社，1996 年 8 月第 1 版第 1 次印刷，ISBN 7-80534-879-0。
- 据该书扫描 PDF 的 OCR 整理稿（简体）整理，OCR 逐页坐标数据用于重建段落。

## 整理说明
- 分页：p01 柳鸣九《总序》，p02 郅溥浩《编选者序》（其中“埃及、西亚地区、黎巴嫩……海湾国家”等国别小标题各为一节），p03–p84 为 82 篇小说，每篇一页，页标题用书中篇名，第三项为作家名（作家名按各篇篇名下所署写法；《一对殉情的恋人》选自《一千零一夜》，署“《一千零一夜》”）。序言两页第三项为“序言”。
- 篇名序列与目录页逐篇核对，82 篇全部对上（目录页 OCR 较完整）。
- 书中每篇小说之后附“作家作品简介”（作家小传＋对本篇的说明）。本整理把作家小传移作该作家**第一篇**小说页的第一节“作者小传”，各篇对本篇的说明另列为该页最后一节“作品简介”；同一作家后几篇简介中的“作者简介见前。”一句不收。《一对殉情的恋人》的简介首段介绍的是《一千零一夜》这部书，故不设“作者小传”而并入“作品简介”。
- 译者署名：书中印在每篇正文末尾（“某某译”），本整理放在该篇小说第一段，写作“（某某 译）”；多人合译以顿号隔开（OCR 中连写的据目录点开）。
- 篇内带序号的小说（《玛尔塔·巴妮娅》《伊赫桑夫人》《教养室》《水的秘密》《车间》《打场工》）按“一、二、三……”分节；《不谐和音》按书中三个小标题分节；其余篇内用空行或“＊ ＊ ＊”隔开的不再另分节（星号隔断保留为一行“＊　＊　＊”）。
- 对话、书信、诗句各自成段（诗句每行一段）。
- 去掉：封面、版权页、目录页、页眉页脚、页码、页脚脚注（正文中遗留的脚注序号①②等一并删去）、版权页上的责编、装帧、定价等信息、右边缘的印刷帖号竖排小字。
- OCR 后处理：残留的繁体字形（约 245 处，如“現、貧、脫、賽”）统一改回简体；半角 `( ) , ; : ? !` 在汉字旁改全角；少数把句读识成“.”的改为“，”，“......”统一为“……”；年份范围中被识成“一/-”的改为“—”。

## OCR 已知问题与存疑
- OCR 原文质量总体可用，但约 220 处低置信度行（见 OCR 目录下 review.tsv）可能存在单字错识，本整理只在把握极大处更正，其余保留。
- 《总序》首页（PDF 第 4 页）扫描模糊，OCR 前两段几乎不可读，已对照页面图像重新识读（如“世界性的文库”“不无效颦性”等），仍可能有个别字存疑。
- OCR 常漏掉单独成行的“一”（序号）：《玛尔塔·巴妮娅》《伊赫桑夫人》《教养室》《车间》《打场工》篇首的“一”、《水的秘密》开头题诗之后的“一”、《车间》的“二”，均据版面（空行位置）补回。
- 《女继承人》《职业的荣誉》《失落》《信》《不谐和音》等篇中个别孤立的数字/字母噪点（如“2”“64”“1”“a”“D”）已删去。
- 《出路》“作品简介”中有一处书中印刷残缺：PDF 第 573 页末“作品将人物行为、心”与第 574 页首“（在埃及社会……”之间，原书排印即缺字（已对照影印页确认），无法补字。
- 译者、作家姓名的 OCR 误识：目录与正文互校后改“邹溥浩”为“郅溥浩”、“邮宇”为“邹宇”；《抵达》译者“赵湜”目录页 OCR 作“赵漫”，存疑，保留正文写法。《沐浴女》作者署“穆·伊雅德”（目录页 OCR 作“舒·伊雅德”，简介称舒克里·穆罕默德·伊雅德）；《相片》作者署“纳·莎尔达薇”（《编选者序》作“萨尔达薇”），均按各篇篇名下署名。
- 目录页码与实际页码个别不符（如《沙丘》），分篇以正文篇名行为准，不影响切分。
- 缺页：无。82 篇正文页均有 OCR 文字，未发现篇内缺页。
- 《一对殉情的恋人》、《白拉士、伊拉士和玉兰皇后》等古典篇章原书分段较少，每篇中有若干超长段落，系原书版式所致。
- 《不谐和音》为多人独白体，“某某：”的发言人名行保留为单独一段；其中日记体的日期行（“8月11日星期六”等）亦单独成段。
- 同一页内的“一”“二”等序号节名取书中序号本身。
