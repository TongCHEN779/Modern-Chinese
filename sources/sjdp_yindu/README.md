# 世界短篇小说精品文库·印度卷

- 底本：柳鸣九主编、周志宽编选《世界短篇小说精品文库·印度卷》，海峡文艺出版社 1996 年 8 月第 1 版（ISBN 7-80534-887-1）。文字由书籍扫描件（PDF）经 OCR 识别、整理而成，**尚未逐字校对**。
- 内容：总序（柳鸣九）、编选者序（周志宽）各一页，其后三十七篇小说各一页，共 39 页；作者 29 位（《五卷书》《本生经》两部古代故事集，及泰戈尔、普列姆昌德等 27 位近现代作家）。篇名、作家名、译者名依书中印刷与目录；译者署名统一放在各篇第一段，形如“（某某 译）”。目录页 OCR 残缺，译者名参照目录与篇末署名核对，“郭良鋆”“季羡林”等据 OCR 近似字订正。
- 页内结构：书中“作家作品简介”印在每位作家作品之后（含一段作者小传和一段作品评介），整理时挪到该作家第一篇小说页的第一节，节名“作者小传”（《五卷书》《本生经》两页因内容是作品介绍，节名为“作品简介”，且把各页的简介合并放在其第一篇前）。同一作者多篇的，简介只放第一篇（泰戈尔的简介在书中印在《摩诃摩耶》后，已移到《素芭》页；萨·查特吉的移到《奥帕吉的天堂》页；普列姆昌德的移到《沙伦塔夫人》页；巴·巴达查里亚的移到《我的勇敢的舅公》页）。
- 小说自带的编号小节（二、三……）每节另起一节，节名为编号；《朋友的决裂》含“第七个故事”“第九个故事”两个故事，各为一节；《已经得到的东西的丧失》开头的“吉祥”保留为第一段。小说内部用星号隔开的段落，统一写作“＊　＊　＊”一段。
- 去掉了：封面、版权页、编委会名单、主编与编选者简介（OCR 第 24 页）、目录页（第 25–28 页）、页眉页脚页码、页末脚注（译注）及正文中的脚注序号（①②…）、末页的数字化水印页（第 485 页）。书中脚注（如《血和石》页末的长篇译注）未收。
- 半角 `( ) , ; : ? !` 在汉字旁改为全角。

## OCR 已知问题

- **缺“二”字**：《拉达兰妮》《摩诃摩耶》《沙伦塔夫人》《打嘎儿》《可番布》《佛陀像》《婚姻》七篇的第二节编号“二”（扫描件上清晰可见，如 PDF 第 64 页），OCR 完全漏识，已按空行位置补回节名“二”；各篇第一节书中未印编号，故沿用篇名。《光和影》第二节位置（PDF 第 125 页）扫描件上只有空行、没有编号，未加节名，直接接在第一节中，该篇小节编号因此从“三”起。
- 《素芭》（PDF 第 89 页）末行扫描有污损，已对照第 89–90 页重读，文字完整（“她没有什么方法可以使贡赛家的孩子大吃一惊”）。
- 《素芭》开头段落的“极其沉静地坐着——一个在光芒四射的阳光之下……”已据影印页补回破折号与“一”；个别行末字符、破折号“——”仍可能被识成单个“—”或丢失。
- 段落是依版面缩进与行宽重建的：少数段落边界（如《婚姻》“……但迪克”与下段“迪克是我们区副专员的儿子”，另有《囚犯》《一个女人在法庭上的陈述》等篇个别处）可能有断错或漏句号，未核对原书。
- 《五卷书》《本生经》故事中的偈颂（诗行）一行一段，依版面行宽；偈颂行因换行而被折断的，已尽量接回，个别可能漏接。
- 编选者序中的个别 OCR 错字（如“談变”疑为“睒变”，“称为比较文学史’”的引号）原样保留；般吉姆小传（《拉达兰妮》页）里“（18381894）”据上下文改为“（1838—1894）”。
- 《血和石》中印地语拟声/呼喊（“Haai Bhagwan!”等）、《婚姻》英语对白保留原貌，仅整理引号。
