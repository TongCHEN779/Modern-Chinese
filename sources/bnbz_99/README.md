# 舒婷的诗

- 底本：舒婷《舒婷的诗》，人民文学出版社“百年百种优秀中国文学图书”丛书，2000 年 7 月第 1 版（据 1993 年人民文学出版社版）。文字由书籍扫描件（PDF）经 OCR 识别、整理而成，**尚未逐字校对**。
- 结构：全书三辑（第一辑《会唱歌的鸢尾花》，第二辑《双桅船》，第三辑《秋思》），每辑一页，每首诗一节，诗行逐行；辑页首引言为该辑所收诗集名。组诗《再见，柏林西》（含《代邮吉他女郎》《夜酒吧》《玛丽亚教堂音乐会》《胡苏姆野味餐厅》《西西里太阳》）合为一节，《仙人掌》另为一节；《黄昏剪辑》《会唱歌的鸢尾花》《银河十二夜（电视诗）》《风暴过去之后》《土地情诗》等多节诗各为一节，序号和小标题保留为诗行。诗行按 OCR 逐行识别结果，诗节间的空行未保留。
- 去掉：封面、版权页、丛书前言、丛书书目与评委名单、目录、页码页脚、书末水印说明页。
- 页脚脚注：《碧潭水》一首页脚的闽南语注“查某——闽南语：女人”已去掉，正文里的注码“①”仍留在原处。

## 已知 OCR 问题
- 标题按版式（字号）识别。《黄昏剪辑》第一节序号“一”、《会唱歌的鸢尾花》部分序号可能漏识；《银河十二夜》里“一初约”“二留言”“九无声的歌”等序号与小标题连在一起，保持 OCR 原样。
- 《……之 间》（第三辑）标题中的空格依 OCR 保留。
- 《滴水观音》里的“滴答”二字是大字号版式，此处作普通一行。
- 未发现整页缺失；PDF 第 23、111、227 页为空白页。
