# 世界短篇小说精品文库·俄罗斯卷（上）

- 底本：柳鸣九主编、钱善行编选《世界短篇小说精品文库·俄罗斯卷（上）》，海峡文艺出版社，1996 年 8 月第 1 版，ISBN 7-80534-890-1/I·785（全书共二册，本册为上册，下册未收）。扫描件中的版权页只印有责任编辑（林正让、林秀平）、封面设计、ISBN 与定价，出版年月按丛书统一信息填写。文字由书籍扫描件（PDF）经 OCR 识别、整理而成，**尚未逐字校对**。
- 结构：共 23 页。第一页柳鸣九《总序》，第二页钱善行《编选者序》，其后每篇小说一页（页标题为篇名，页的作者栏为作家名），共 21 篇、13 位作家（卡拉姆辛、普希金、果戈理、莱蒙托夫、屠格涅夫、列夫·托尔斯泰、陀思妥耶夫斯基、迦尔洵、契诃夫、列斯科夫、柯罗连科、高尔基、蒲宁）。总字数约 29.9 万。
- 译者署名：书中译者名印在每篇正文末尾（右下角），整理时移到该篇第一段，写作“（某某 译）”。人名用字依全书前后互证统一：戴聪（OCR 作“戴听”“戴聽”“戴 驰”）、臧仲伦（OCR 作“减仲伦”“藏仲伦”）、陈锌、冯加、吕绍宗、水夫、张耳、肖敏、陈馥、禾人、张羽。
- “作家作品简介”：本书不是把作者小传印在作品之前，而是每篇小说之后都有一段“作家作品简介”（作家某作品第一次出现时含作家生平，之后写“作家介绍见前”并只评该篇）。整理时原样放在该篇页面的最后一节，节名“作家作品简介”，不拆分；段末的“（译者）”表示该简介由译者所撰（序言末“附注”：除注明“译者”外均为编选者所撰），已并入该段段末。
- 页内小节：自带编号的小说按书中编号分节——《五月之夜，又名女落水鬼》“一、甘娜”至“六、梦醒”；《鼻子》《三死》《一个可笑人的梦》《红花》《马卡尔的梦》《安东诺夫卡苹果》为“一”至“二/三/…”；《一位柔弱的女子》分“作者的话”和第一章（一至六）、第二章（一至四）；《珍珠项链》为“第一章”至“第五章”。《编选者序》分“一”至“八”。
- 去掉的内容：封面、书名页、版权页、编委会名单、目录页（上册目录与下册目录连排，OCR 也把 461 页以后下册篇目混了进去，未收）、页眉页脚与页码、页底脚注（正文里的脚注序号①②等一并删去，包括《编选者序》的脚注）、书末的电子书水印页。

## OCR 已知问题与存疑

- 自动按版面重建自然段（按 OCR 行坐标：首行缩进、行宽、行距）：跨页接续、对话分段与原书基本一致，书信、歌谣/诗行（《五月之夜》《塔曼》《马卡尔·楚德拉》《女人》《安东诺夫卡苹果》中的短行）每行一段；个别书信/诗行的断行可能与原书略有出入（《鼻子》里的两封信已按整段处理）。《珍珠项链》第三至五章、《女人》《在巴黎》中几页对话行缩进异常，按行首引号分段。
- 篇名核对：《哞哞》篇名 OCR 低置信度识成“哗哗”，据版面字形（口字旁）和正文狗名改作“哞哞”，正文里 5 处狗名“哗哗”同改，简介里的《哗》改作《哞哞》；《一个官吏之死》篇名页印作“一个官吏之死”（目录与简介 OCR 作“一名官吏之死”），页标题按篇名页；《鼻子》篇名页作者栏印“果戈里”，作家栏统一作“果戈理”；《红花》作者“迦尔洵”（目录 OCR 作“迦尔泊”）。
- 漏识的节号：首节“一”在书中印作短横，OCR 一概丢弃，《鼻子》《三死》《一个可笑人的梦》《红花》《马卡尔的梦》《安东诺夫卡苹果》《编选者序》的“一”按版面位置补回；《鼻子》第 142 页、《一个可笑人的梦》第 316 页、《红花》第 336 页（PDF 页码）的“二”也被 OCR 漏掉，按版面空行位置补在“八等文官科瓦廖夫很早就醒来了”“你们知道，虽然我对一切都感到无所谓”“夜里他醒了”之前。
- 少数系统性错字已改：“自已”→“自己”，“由子/终子”→“由于/终于”，句首“子是”→“于是”，“关子/对子（他）”→“关于/对于”，序言附注“所模”→“所撰”；“已/己/巳”“于/干”“未/末”等形近字其余处只改把握很大者，未做逐字校对（如《哞哞》“自幼于惯了”应作“干惯了”，未改）。
- 半角标点：汉字旁的 `( ) , ; : ? !` 已改全角；书名号常被识成不成对的括号（如“《驿站长）”），已按成对规则改回《》。段末的 ASCII 引号已改为”（《驿站长》《一位柔弱的女子》《红花》《珍珠项链》各有一两处）。《塔曼》诗行“万家舟楫.”、《五月之夜》一处“铁钉.去钉”、《三死》一处“冬天准买.可现如今”按语气改为全角逗号/句号（《红花》《女人》“……”后的杂点同删）。
