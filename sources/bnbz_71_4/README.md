# 李自成（第4卷）

- 底本：姚雪垠著《李自成》第四卷，中国青年出版社、学习出版社，2019 年 9 月版（“新中国 70 年 70 部长篇小说典藏”丛书）。文字由书籍扫描件经 OCR 识别、整理而成，尚未逐字校对。
- 整理：全书二十九章各占一页，页标题即书中章号（书中章无标题）；页分组取目录中的部名（高夫人东征小记、燕山楚水、洪承畴出关、三雄聚会、辽海崩溃、项城战役、横扫宛叶、再攻开封、燕辽纪事）。去掉封面、版权页、作者简介、出版说明、评审专家名单、目录、书末丛书书目，以及每页页眉（“李自成·第四卷第N章”“新中国70年70部长篇小说典藏”）和页底脚注；正文里的脚注序号（①②…）一并删去。跨行、跨页断开的段落已接合。
- 已知问题：
  - 页眉常被 OCR 粘进正文行中，已按固定字样删去，个别残缺页眉（如“长篇小说典”后多出一字）可能有零星残留。
  - 脚注是按“页末、以①起头”的规律判断后切除的；脚注跨页续接处、脚注序号漏识处可能有少量脚注文字残留或误删（已抽查，仅发现并清除一处无序号的脚注残句）。
  - 页末恰为句号而段落在下页继续的情形，机器无法分辨，会被当作新段落。
  - 书中章内的空行分节在 OCR 稿中已丢失，未分节。
  - 偶有形近字、标点 OCR 错误，未改。
  - 第九章章号在 OCR 稿中被错置于上一页末，已据内容放回章首；未发现整页缺失。
