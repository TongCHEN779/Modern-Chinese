# 在黑暗中

- 底本：丁玲著《在黑暗中》，人民文学出版社 2000 年 7 月版（“百年百种优秀中国文学图书”丛书；原为 1928 年上海开明书店初版）。文字由书籍扫描件（PDF）经 OCR 识别、整理而成，**尚未逐字校对**。
- 整理：收《梦珂》《莎菲女士的日记》《暑假中》《阿毛姑娘》《最后一页》五篇，各占一页；页内小节依书中的编号（一、二……或日记日期）。《阿毛姑娘》分三章，章内小节名前加章名（如“第一章 二”）以免重名，各章首节即以“第一章”等为名。去掉封面、版权页、作者简介、丛书前言、评委名单、丛书书目、目录页、页码及 Anna's Archive 元数据。
- 已知问题：①《梦珂》第一节、《暑假中》第一节、《阿毛姑娘》各章的首节编号“一”在 OCR 中缺失（《梦珂》开头处识成孤立的“1”，已删），按位置补作“一”或章名；《暑假中》“二”节标题未识出（第一节实含“一”“二”两节），《阿毛姑娘》第三章“二”“三”节标题亦缺（直接由首节接“四”），均未再拆分。②页边零星噪点（孤立字母/数字）已删；《阿毛姑娘》一处“很痛的7了”中的“7”判为噪点删去，另有几处跨页或断行的短句尾（“上。”“解去。”“视那太阳”等）已并入前段。③《莎菲女士的日记》日记日期自“一月十八”直接到“三月六号”，未见二月条目，疑原书如此，未核。④未对照影印页逐字校对，仍可能有形近字错误。
