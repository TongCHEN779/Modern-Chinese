# 世界短篇小说精品文库·拉美卷

- 底本：柳鸣九主编、陈众议编选《世界短篇小说精品文库·拉美卷》，海峡文艺出版社，1996 年 8 月第 1 版第 1 次印刷，ISBN 7-80534-886-3。文字由书籍扫描件（PDF，675 页）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：共 56 页。p01 柳鸣九《总序》（全套文库总序），p02 陈众议《编选者序》，p03–p56 为 54 篇小说，每篇一页，页标题用书中篇名，页的第三项为作家姓名（取自书中各篇“作家作品简介”开头的全名写法，同一作家连续各页同名；帕尔玛有里卡多与克莱门特父子两位，各用全名）。序言类页第三项为“序言”。
- 每篇页的第一节为篇名节：第一段是译者署名“（某某 译）”（书中印在文末，原有“某某 校”者一并保留），其后是题词、献词、引语（如有）；小说自带“一、二、三”者，每个编号另起一节，节名即编号。《避难权》的七个小标题（“一 星期日”等）同样各为一节。
- 作家小传：本书没有印在作品之前的作家小传，而是在**每篇小说之后**印有该篇的“作家作品简介”（作家生平加对本篇的评介；同一作家的第二篇起只写“作者简介见前”并直接评介作品）。为保持书中次序与篇内评介的完整，该简介作为每页最后一节，节名“作家作品简介”，没有拆到作家第一篇之前。
- 去掉：封面、版权页、编委会名单、目录（总序、编选者序及各篇的作者名/译者名/页码行）、页眉页脚页码、页脚脚注及正文中的脚注序号（①②…，脚注本身不收）、总序与编选者序标题下的作者署名行；全书末尾 Anna's Archive 加在 PDF 末页的元数据文字（夜行记一页之后）。半角 `( ) , ; : ? !` 在汉字旁已改全角。
- 段落重建：OCR 稿 full.txt 在个别页因行首错位把一段拆成许多短段，故改用 json 行坐标重新分段（缩进、行宽、行末是否收足），再按篇切分。

## OCR 已知问题与存疑处

- 正文中编号小节“一”“二”常被 OCR 漏识（该字是一两道横笔，位置在段前独占一行），我据 json 行距与 PDF 页面核对后补回：一吻之死“一”；无主的怀表“一”“二”；毁灭“一”“二”；显灵节“一”“二”；虎仔“一”“二”；回归种子“一”“二”；可怜的母亲“一”；金卡斯之死“一”“二”；奥拉“一”。其余编号 OCR 本有。补回的位置依据版面空行判断，个别段首位置可能偏一段。
- full.txt 缺失 141、198、246、298、304、371 共六页（但 json 里有文字），这六页由 json 重建并并入相应篇章，内容没有缺。
- 幻影一篇（PDF 537 页）的篇名行 OCR 漏识，篇名据目录补；毁灭、日蚀、捷径、冠军、盛宴、玫瑰、道德、干渴等篇名被 OCR 拆成单字或残缺，也据目录与版面改回；目录页 OCR 残缺（避难权后的页码行缺），篇数以正文每篇起页为准，54 篇与目录列出的篇名全部对上。
- 作家名：各篇作者行为缩写（如“加·马尔克斯”“洛·波尔蒂约”），页的作家名统一用“作家作品简介”里的全名；邦巴尔、亚马多、多诺索三家因简介首段 OCR 在括号处断裂，名字据所见部分与前后文取用。“里贝伊罗”（目录与篇名行）与简介中的“里贝罗”不一致，作家名取简介写法。
- 页面右缘有扫描边缘的杂点与竖排残字（如 PDF 第 100、132、164、196、228、324、388、452、548、580、612 页），及行内孤立的小数字/字母杂点，已按位置与字高去掉；个别处可能有漏网的单字。
- 《避难权》《另一位》《奥拉》中诗行、独句分行较多，按书中排版每行一段；《奥拉》题记（米舍莱）几行已并成一段。
- 编选者序“把现实（生活）解释为幻想”的左括号已据影印页补回。其余明显的单字错识未逐一校改。
- 全文约 38.8 万字。
