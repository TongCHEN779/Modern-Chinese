# 哥德巴赫猜想（bnbz_77）

## 底本
徐迟《哥德巴赫猜想》（报告文学集），人民文学出版社，1978 年 4 月北京第 1 版（“百年百种优秀中国文学图书”所收，据读秀 PDF 的 OCR 整理稿）。

## 结构
共 8 页：《向着二十一世纪》《石油头》《地质之光》《哥德巴赫猜想》《生命之树常绿》《在湍流的涡漩中》《祁连山下》《后记》。篇内“三”“四”等编号小节各为一节；《生命之树常绿》末附“热带雨林插图简介”（附录）。

## 整理时去掉
封面、版权页、献词页、致谢页、目录、页码（含粘在行首行尾的页码）、插图/地图上的标注（如“华夏”“东亚构造格架”）、OCR 噪点（孤立字母、符号）、末页 Anna's Archive 水印说明、附录页的插图脚注编号。

## 已知 OCR 问题
- 各篇开头的第“一”“二”节编号 OCR 未识出，故这部分内容并在页标题同名的首节中，未能拆分（《地质之光》《哥德巴赫猜想》《祁连山下》均如此，编号自“三”起）；《向着二十一世纪》《石油头》《生命之树常绿》《在湍流的涡漩中》原书是否分节无法核实，未分。
- 《哥德巴赫猜想》篇引用的数学论文片段、引理公式（p55 起及“八”“九”“十一”节附近）OCR 为乱码，纯公式碎片已删除，故个别句子在公式处被直接接上（如“显见，我们有”“的证明”），公式本身缺失。
- 《地质之光》第 31–32 页（书 p23–24）之间疑有文字缺失，“山”字前后不连贯（“有些建筑物……山结果同地面观测……”）。
- 《哥德巴赫猜想》“三”节中“肺结核和腹膜结核症”前的“B中”噪点已删。
- 附录“热带雨林插图简介”中的注释圈码已去掉，个别拉丁学名括号可能有误。
- 跨页断开的段落按“上页末行无句末标点”的规则接合，少数句末恰好为标点的跨页段落可能未接。
