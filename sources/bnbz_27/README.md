# 子夜

## 底本
茅盾《子夜》，长江文艺出版社“现当代长篇小说典藏插图本”，2017年10月第1版（叶浅予插画）。OCR 自 PDF（366 页，含 7 页无字插图页）。

## 整理说明
- 按书的章序分为十九章（原书各章仅以汉字数字标序，无章名），页标题即“一”至“十九”。
- 去掉：封面、封底、书脊、版权页（CIP 数据）、扉页、插图页与其上的识别乱码、末页的数据库水印说明、页码与页眉页脚，以及每页底部的编者注/作者原注（正文中的注码①②等一并去掉）。
- 跨页、跨行断开的段落已合并；孤立的字母、数字、假名等噪点已删。未改写正文。

## 已知 OCR 问题
- 第一章、第二章的章号在 OCR 中缺失，按位置确定：第一章始于 p0005，第二章始于 p0023（“清晨五时许……”）；第五章标题识别为“1五”，第十三章为“-十三”，已更正。
- 部分页底脚注文字被 OCR 并入正文末行，已按脚注注码切除，个别可能有遗漏。PDF p0029 一处正文被夹在脚注行中，已复位到“……电影明星”，之后。
- 以下位置因插图页/乱码导致文字可能缺失或断裂：PDF p0081（“捞起那枝……”与“准那年青妇人开了一响”之间疑缺字）、p0097 页尾、p0173（““然而上海”后疑有缺字，OCR 为“9”）、p0239 页尾、p0304、p0308、p0361（开头“C 小’ 0的”暂改作“哇”）；第三章“这以后是”（p0060）为断裂的残句。
- 空白插图页 PDF p0042、p0063、p0109、p0229、p0250、p0257、p0342 无文字，非缺页。
