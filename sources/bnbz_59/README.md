## 整理说明
- 页面：p01 冯雪峰《论《保卫延安》》（原书代序位置的评论文章），p02–p09 第一至第八章（页标题取书中目录的章名），p10 作者《后记》（1954 初稿、1958 作者补记），p11《重印后记》（1978–1979）。章内的“一、二、三……”小节号作节名。
- 去掉：封面、版权页、作者小传、丛书前言、评选/编委名单、丛书书目、目录页、页码与页眉、页脚脚注（共 4 处：第 85、111、241、499 页的“竹竿”“陈赓兵团”“刘邓大军”“陕北的一个县”注）及正文里的脚注符号；冯雪峰文末的编者按语（“本文中关于小说的引文均根据……编者”）；末页 Anna's Archive 文件说明。
- 段落：依 json 逐行坐标按首行缩进重新合并断行与跨页段落；歌谣、快板、诗句保持一行一段。
- 保留正文里的信件、日记、通知等原貌。
