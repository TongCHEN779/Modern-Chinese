# 乐府诗选

- 底本：曹道衡选注、余冠英审定《乐府诗选》（中国古典文学读本丛书典藏），人民文学出版社，2000 年第 1 版、2017 年第 2 版（典藏本）。文字由书籍扫描件（PDF）经 OCR 识别、整理而成，**尚未逐字校对**。
- 整理：去掉封面、版权页、丛书广告、目录页（“返回总目录”链接）与页眉页脚。收曹道衡《前言》（一至四，1995 年）和全部选诗。
- 分页：书分“（一）汉魏西晋郊庙乐曲及民歌”“（二）汉魏西晋文人乐府诗”“（三）东晋南朝乐府民歌”“（四）东晋南朝文人乐府诗”“（五）北朝乐府民歌”“（六）北朝文人乐府诗”六编（页分组名即此）。民歌各编及（一）按书里的乐府分类分页：郊庙歌辞·汉郊祀歌、鼓吹曲辞·汉铙歌、相和歌辞、杂曲歌辞、杂歌谣辞、清商曲辞·吴声歌曲、清商曲辞·西曲歌、舞曲歌辞、横吹曲辞·梁鼓角横吹曲（页内第一节与页标题同名，放该类的总说明，即原书第 [1] 条注）。文人乐府三编（二、四、六）按作者分页，页标题照书里的写法“（朝代）作者”，每首一节，节名照书；书里“附：”的另一诗文（“晋乐所奏”本、古诗等）各自成节。
- 格式：诗按句以“/”分行，每段约四句；组诗里“其一”“其二”接在该首诗段首，“春歌”“战荥阳”之类小标题单独成段。每首的题解（书中第一条注“《某某》：……”，以及作者小传）放作“题解：”；其余注释放回所属段后。原书注释在（一）（三）（五）是整类之后集中印、在（二）（四）（六）是每首之后印，编号 [n] 与正文标号对应；转换时按标号放回，标号 OCR 有误处按编号递增顺序校正，再无法对上的，取原文所指一小段作词语，写成“词语：原注全文”。词条合写、转换后词语不能逐条对上的，用“注原：”整条照录。
- OCR 已知问题：诗题或注中个别生僻字识别成形近字或空缺（如曹植《𫚥篇》〔应为《鰕𬶐篇》〕、注里“唶”“裲”“蓰”“淄”等被识成“啃”“祸”等），原样保留；“古咄唶歌”“滟滪歌”两个题目据目录改正。页眉被识成正文的零星页码、“返回总目录”已删。个别注释页的编号识别有误（如连续两个 [2]），按序号顺延。原书编号为 [n] 的页脚注偶被并入正文行末，已拆出。
- 书中曹丕《善哉行》等几首诗的注释顺序、“其N”标号偶有 OCR 错位，未逐一对照影印页。
