- 底本：《中国现代小说经典文库·石评梅、冯铿小说经典》（封面作“石评梅·冯铿卷”），阿宏主编，印刷工业出版社，2001 年 3 月第 1 版第 1 次印刷，ISBN 7-80000-413-9/I·11（全套 12 卷）。文字由书籍扫描件（PDF）经 OCR 识别、整理而成，尚未逐字校对。
- 整理：每篇小说一页，书前编者“前言”一页；页标题用书中篇名；第三项分作“冯铿小说”“石评梅小说”两部。目录页、版权页、封面封底、页眉页脚和页码均未收入。正文依逐页 OCR 坐标重建，按行宽和缩进判断自然段，跨页断开的段落已接合。

- 页内分节：《遇合》《林楠的日记》《祷告》按日记日期分节；《最后的出路》（一至二十八）、《匹马嘶风录》（一至五）按数字分节，《重新起来》按（一）至（十三）分节。《最后的出路》《匹马嘶风录》第“一”节的序号 OCR 漏识，据版面补回（各在篇首）。《祷告》篇首的副题“婉婉的日记”并入第一节“九月三号”的首段。
- 目录页（PDF 第 11–12 页）识别不全，未见《毒蛇》及部分篇的页码；各篇起页依正文标题确定，《毒蛇》按正文标题收为一页。

- PDF 第 2–4、10、357–358 页无识别文字（封面、空白页等），第 11–12 页为目录。
- 冯铿三篇（《无着落的心》《最后的出路》《重新起来》）的对话以“——”引出，OCR 把破折号识成“一”“—”“-”等，已把段首的破折号统一改回“——”，段首真正以“一”起字的叙述（一阵、一个、一九二三年等）保留；少数行内破折号和个别漏识了破折号的对话段（如《重新起来》“你这个样子便想回去吗？”、“一定的，一定的！”起首）未补，可能有遗漏。
- 《重新起来》PDF 第 191 页 OCR 行序错乱，已按坐标重排。
- 《归来》中的分隔符“×××”OCR 为“X*XX”，已改作“×××”并单独成段。
- 半角标点已在汉字旁改全角；少数 OCR 杂点（段末“·”“.”等）已删。个别错字（如“箭簇”“锡铂[箔〕”“爷永远得不到幸福”等）按原样保留。
