# 曹禺剧本选

## 底本
曹禺 著《曹禺剧本选》，解放军文艺出版社，2000 年 7 月第 1 版（“百年百种优秀中国文学图书”丛书之一）。收《雷雨》（四幕）、《日出》（四幕）、《北京人》（三幕）及作者 1977 年 12 月《后记》。

## 整理说明
- 每部剧一页“登场人物”（含“时间和地点”）、其后每幕一页（《北京人》第三幕含“第一景”“第二景”两节），共 15 页，末页为《后记》。
- 去掉：封面、版权页、作者简介、丛书前言/评委名单/书目、目录页、页码、页眉页脚、每页底部的英文/方言等脚注（正文中的脚注序号①②③等一并删去）。
- 《日出》书末的《打夯歌》等曲谱页（原书第 303–307 页，OCR 仅为简谱数字与零散歌词，无法还原）整体略去。
- 排版版式（OCR 无冒号）已按坐标还原：台词段首补全角冒号“角色：”，舞台提示、幕启描写、“幕落”“剧终”及年份各自成段；《北京人》“第一景”“第二景”作为节标题。
- 角色表中丢失的破折号“——”按上下文补回；个别角色名 OCR 形近错字（周“繫/繁/系漪”→周蘩漪，鲁四“风”→鲁四凤）已统一更正。

- 其他 OCR 零星错字未逐一校对；《日出》中的英文台词（Hello、Good night 等）保持 OCR 原样。
