# 3小时读懂唐朝

- 底本：姜若木编著《3小时读懂唐朝》（“3小时一目了然速读历史故事”系列），京华出版社，2011 年 4 月第 1 版（CIP 标 2011.3）。文字由书籍扫描件（PDF）经 OCR 识别、整理而成，**尚未逐字校对**。
- 整理：按书的目录分页：前言一页，第一章至第二十二章各一页，附录一至附录四各一页，共 27 页；章内“一、二、三”小标题各为一节，第三章、第十六章里的“（一）（二）……”小标题也各为一节。每章章首有一句题记（原书印在章题上方的大字），保留为该章第一段；“点评”“相关链接”及其小标题（如“李世民小传”）作为所在节内独立段落。附录四的年表每行一段，各栏用全角空格隔开。
- 去掉了：封面、版权页、目录页、页眉页脚与页码、插图及图片说明（如各人物像、文物图）、书法图版、书末电子书信息页。
- OCR 已知问题：
  - 第一章“杨广被杀”处（原书第 7 页末），OCR 在“我是对不起百姓”与“杨广12岁的儿子……”之间漏了一行，原样保留。
  - 目录页 OCR 缺“第一章”与“第十七章”行，章题按正文章题页核对；第十六章小标题“叛军内讧”在 OCR 中为“内订/内证”，据文义改为“内讧”。
  - 附录一“一、初唐四杰奠定基础”在目录页缺失，按正文版面补出。
  - 个别明显形近字已改：魏徵小传（OCR 作“魏微”）、杨国忠（“杨園忠”）、萧瑀（“萧踽”）、濛池都护府（“潔池”）、李漼、李柷（年表）。其余形近错字、漏字未逐一校改（如“戎狱”之类存疑处原样保留）。
  - 带插图的页面（如第一章、第六章、第三章部分页）正文按图文绕排识别，段落按行坐标重建，个别段落划分可能与原书略有出入。
  - 附录四年表中，OCR 个别行缺“即位时间”（嗣圣、文明已据坐标补出），个别年号重复行（宝历、大中、咸通、天祐）为原表跨帝续写的年号，原样保留；“大(太)和”为原表写法。
