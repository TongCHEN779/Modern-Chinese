# 白鹿原

- 底本：陈忠实著《白鹿原》，人民文学出版社“百年百种优秀中国文学图书”本，2000 年 7 月北京第 1 版（2001 年 3 月第 2 次印刷）。文字由书籍扫描件经 OCR 识别、整理而成，**尚未逐字校对**。
- 分页：题记（巴尔扎克语）一页，其后正文三十四章各一页；全书各章只有“第N章”序号，没有章名，故页标题即章序号。章内无小标题。
- 去掉的内容：封面、版权页、作者简介页、丛书前言、评选委员会/编委会名单、丛书书目、丛书总题页、目录性内容、页码、书末 PDF 来源水印；每页底部的脚注（原书用①标注）连同正文里的脚注序号“①”一并去掉。
- 保留：章首题记；全书末尾作者的写作时间题署（“1988.4.—1989.1.草拟 / 1989.4.—1992.3.成稿”，附在第三十四章末）；第二章、第四章、第六章中的诗、书信、《乡约》文字，按书中排印逐行/逐段保留。
- 整理方法：由于 full.txt 把部分页的内容并入了前页，段落边界不可靠，本稿改用逐页 json 的行坐标，按首行缩进判断自然段、接合跨页断行，文字内容与 full.txt 逐章核对一致。
- 已知 OCR 问题：未发现漏页、缺章；约 18 处段末（页末最后一行）疑似丢失了句末标点或个别字，如第一章末“让阴阳先生给禳治禳治”、第十一章“耍笑我”、第二十一章“咳嗽。一”、第二十四章“微微颤栗”“说梦话”、第二十五章“杀咱娃的……媳妇”、第三十章“抱到炕上去”等，原样保留未补。《乡约》一段（第六章）因原书缩排方式，分段可能与原书略有出入。个别单字形近误识（如“泰恒老汉y”类孤立字母）未改。
