# 韩愈诗选

- 底本：陈迩冬选注《韩愈诗选》，人民文学出版社“中国古典文学读本丛书典藏”，2016 年版（初版 1984 年）。文字由书籍扫描件（PDF）经 OCR 识别、整理而成，**尚未逐字校对**。
- 整理：第一页为舒芜《序》（分一至七节，序末脚注列为“注释”一节）；其后按目录顺序把九十首诗分作四页，页标题为“第一首题—最后一首题”；每首为一节，节名取书中诗题（《秋怀诗》《青青水中蒲》《李花二首》《南溪始泛三首》《盆池》《题张十一旅舍三咏》《和虢州刘给事使君三堂新题二十一咏》等组诗每首另成一节，节名为“组题·子题”；《和虢州……》的小序为“组题·序”一节；《答张十一功曹》后所附张署《赠韩退之》诗另为一节）。末二页为附录《新唐书·韩愈列传》与陈迩冬《后记》。
- 注释：书中原把注释集中放在每首诗之后，按 OCR 里的 [1][2]… 序号放回各自所属的段后（OCR 数字常有误，如 7、9 识成 2，故按先后顺序而不按数字对应）；每首诗的“题解”放在诗前。诗每四句左右为一段，句间以“/”分行。““某某”二句：……”一类以句为单位的注，词语取引号内的字。少数注释在词语不见于所属段（多因正文该字 OCR 缺失或有异体字），改取注号前的几个字作词语，原注全文保留。个别注释含多个词条（如“炎瘴”条），为避免站点把其中引文拆成独立条目，用了“注原：”（一行一条、不再拆分）。
- 未收：封面、版权页、丛书广告、目录页（目录页的诗题仅用于定位）、页眉页脚页码。
- OCR 已知问题与改动：全文稿缺 p6936（《宿曾江口示侄孙湘》题解末两行）及个别句子，未补；《去岁自刑部侍郎……留题驿梁》诗题前三行据 json 补回；“查花”据正文改作“杏花”，“惠君叙别”据文意改作“惠书叙别”，“赏筜”改“筼筜”，“绳俛”改“渑俛”；《八月十五夜赠张功曹》正文缺“海气湿蛰熏腥臊”至“嗣皇继圣登夔皋”一节（原书印刷如此，注 [7][8] 附在其后一段）；序中“一《赴江陵途中……》”的“一”按破折号处理，作“——”。其余疑似错字（如“闽/阙”“悦慌”等）原样保留。
