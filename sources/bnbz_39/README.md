# 黄河大合唱

底本：光未然著《黄河大合唱》，“百年百种优秀中国文学图书”丛书，解放军文艺出版社，2000年7月第1版。OCR 自该书 PDF（共 103 页）。

## 整理说明
- 按书的目录分页：黄河大合唱（歌词八首，各含朗诵词与歌词）、三门峡大合唱（六首及附记）、五月的鲜花、红树林之歌（含附记）、星海园沉思录（含题记）、屈原（开篇、诗篇上下、尾声）、《黄河》本事、我怎样写《黄河》（冼星海）、《黄河大合唱》的诞生、冼星海同志回忆录、星海和我们共同奋斗（一九八五年再版序言）。
- 诗行逐行一段；原书的分节（空行）在 OCR 中已丢失，未还原。
- 去掉：封面、版权页、作者简介页、丛书前言、评选委员会/编委名单、丛书书目、目录页、页码、末页 Anna's Archive 水印、每页底部的作者脚注（《三门峡大合唱》《屈原》中的注释及正文中的注码①②）。
- 保留各文末的“载……”“摘自……”出处说明及写作日期。

## OCR 已知问题
- 已改正：“洗星海”→“冼星海”（含《星海园沉思录》“冼星海式的大手笔”），“躯于”→“躯干”，“团困”→“团团”，“鸣咽”→“呜咽”；《三门峡大合唱》第一首的序号“1”按全书体例写作“一、龙虎斗”。
- 《冼星海同志回忆录》《黄河》本事等页边的孤立字（“会”“心”）按噪点删去。
- 未发现整页缺失；《黄河大合唱》八首歌词序列完整。其余零星形近字误识（如《屈原》《红树林之歌》个别字）可能仍存在。
