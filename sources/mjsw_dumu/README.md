# 中国古代名家诗文集·杜牧集

- 底本：《中国古代名家诗文集·杜牧集》，（唐）杜牧著，黑龙江人民出版社，2005 年 8 月版（2005 年 11 月第 1 版，2009 年 1 月第 2 次印刷），单册。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成，字形取简体，**尚未逐字校对**。
- 整理：共 25 页。“杜牧简介”（扉页后的作者简介，四段）、“前言”（编者的丛书说明）各一页；正文按书的卷次各占一页：卷一分“赋三首”“诗二十八首”两页，卷二“律诗六十七首”，卷三“律诗八十八首”，卷四“长韵四首 律诗七十一首”，卷五至卷二十（论说、传记、碑志墓志、序记、书启、祭文行状、表状、制诰）各一页，外集、别集各一页。书中正文只在卷四起印有卷次大号数字，卷一至卷三的卷次和页标题“赋三首”“诗二十八首”“律诗六十七首”“律诗八十八首”据书前目录补定；卷五至卷二十的页标题用“卷五”等卷次。
- 节：一首诗或一篇文为一节，节名即书中标题。诗用 `诗：`，OCR 稿里一首诗是连排的一段，按标点拆成诗行（以 `/` 分行），每四句一段；诗的标点保持原样，未补标点。文（含“并序”的小序、赋）用 `原：`，一个自然段一行。“怀钟陵旧游四首”“台城曲二首”原书后三首（一首）题作“又”，并入同一节。同一页内重名的诗题（如“寄远”“逢故人”“遣怀”）后一首加“（二）”区分。别集页首一段是宋人田概的序，原书置于别集卷首。
- 去掉：封面与封底宣传语、版权页与 CIP 数据、书前目录、页眉“中国古代名家诗文集”“杜牧集”与页码、插图（每页诗文旁的白描插图）及 PDF 末尾的下载水印页。扉页后作者简介页末所附《赤壁》一首与正文重复，未收。书中无注释，无校记。
- 半角 `, ; : ? !` 与括号在汉字旁一律改作全角。

## OCR 已知问题

- 书中诗题常为字间疏排的二字题，OCR 漏识了五处，据原书页面图补回：醉眠（PDF 第 62 页）、九日（第 106 页）、洛阳（第 331 页，外集）、芭蕉（第 361 页，外集）、山寺（第 381 页，别集）。另“鹦鹉”（第 81 页）OCR 只识出“鹦”，据补；“论并序”据目录补作“守论并序”；“窦列女传”的标题 OCR 被并入上篇末尾（第 121 页），据目录拆出。“鸟鹊”（第 80 页，目录作“䴔鹊”）字形难辨，从目录作“䴔鹊”，存疑。
- 少数题名与目录对勘后更正：毕诚（OCR 作“毕誠诚”）、蒋係（OCR 多一“保”字）、郑悛（OCR 作“郑陵”）、郑漯（OCR 脱“漯”）、湓浦（OCR 作“溢浦”），并去掉粘在题名上的页码碎片“二三”、题名中的圆点。“裴休除礼部尚书裴除兵部侍郎等制”一题 OCR 与目录均脱一字（应为裴某某），原样保留。
- 低置信的孤立字符、页边噪点（如“立”“外”“工Ⅱ”“E以”等被 OCR 当作单独文字的碎片）已去掉；诗文正文里的形近错字没有逐一校改，凡不确定处保持原样。“唐故复州司马杜君墓志铭并序”中“年六哆？”一处（约在 PDF 第 156 至 157 页之间）是 OCR 对该处的残缺识别，原样保留；OCR 丢失标点处不补。
- 卷四页标题据书前目录为“长韵四首 律诗七十一首”，实际该卷所收诗题为 77 题、83 首（含“又”并入的各首），目录所标数目与实收不尽相符，未据此增删。
- 前言（编者）中有 OCR 识别错误（如“难经计数”“肯人一个共同特点”），原样保留。
