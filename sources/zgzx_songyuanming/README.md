# 中国历代哲学文选（宋元明编）

- 底本：中国科学院哲学研究所中国哲学史组、北京大学哲学系中国哲学史教研室编《中国历代哲学文选·宋元明编》，中华书局，1963 年 2 月第 1 版（编辑说明署一九六一年十二月）。竖排本，全书四个分册中的第三分册。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**；字形取 OCR 简体稿（原书为繁体）。
- 整理：页 = 一位思想家（李觏、邵雍、周敦颐、张载、王安石、程颢、程颐、朱熹、陆九渊、陈亮、叶适、邓牧、罗钦顺、王守仁、王廷相、王艮、李贽），页内第一节是编者对该家的简介，其后每节为一篇（或一部书的一组节录）选文；《通书》《道德经注》按原书小标题（各章）分节，节名写成“书名·章名”。前面另有“编辑说明”一页。选篇后的编者注释按位置挂在所注段落之后。
- 注释：原书注释在选篇的一段文字之后集中排印（“注”“注释”小标题下，按①②…序号），OCR 把序号读成数字/汉字或丢失，页面上又没有标点，所以注释的位置是用脚本推定的：按原注开头的词语（或注文里引到的原文字串）在这一组选文里找位置，找到的就写成 `注：词语：解释`（词语多取原注开头最长的、在正文里出现的字串，所以“词语”与“解释”的分界有时偏离原书，解释的开头可能是半个词）；找不到位置的（约 159 条，占 23%，多是只写“见周易系辞”或只有说明文字的注）放在该组选文最后一段之后，词语取原注开头两个字。`tools/check_src_notes.py` 报告的“词语不在所属段原文里”条数即这一部分。注号紧跟在词语后且与序号吻合的，已从正文里去掉；其余正文里仍可能残留夹在字间的注号（单个“一二三…”），没有逐一清除。
- 去掉：封面、版权页、目录页，页眉页脚与页码。正文里夹的小号注码已尽量去掉。
- 没有标点：OCR 稿几乎丢失了竖排本的全部句读，只保留了偶然识别出的「」、！、？、；和“。”，按规则不补标点；段落以版面缩进切分，选文末尾的出处（如“直讲李先生文集卷十九”）并在该段末尾。

## OCR 已知问题
- 编辑说明第 4 段（原书第 8 页中部）“……著述和思想我们对所选各家都作了简要的介绍……”一句，该列上半部（开头约二十字）OCR 漏识，只剩“著述和思想”以下，已另起一段。
- 选篇标题里的“节录”常被识成“笛录”“简录”“管录”“录”等，据版式改作“节录”；“傅习录”（传习录）、“洪范傅”（洪范传）、“正蒙大和篇”（太和篇）、“答取中丞”（答耿中丞）、“米启”（某启）、“雅”（《雅述》，“述”字漏识）等标题或字据书名更正。《答顾东桥书》一节在原书里随“传习录中”之后，未另有正文标题。
- 全书程朱语录之后的出处括注（“（遗书卷十八）”）常只剩残片，如“（书卷十八）”“（律卷三）”，原样保留；正文里“于戏”“工”等偶有杂字，“关”（《潜书》“希矣”）等个别单字误识未改；个别页尾孤字、孤立省略号（“……”）为原书省略记号，保留。
- 注释的序号与位置见上；注释正文中的引文、书名、年代括号同样没有标点，连在一起。
- 页码：程颢、程颐页的分界、各家选篇的首页由脚本按大标题定位，未逐页对照影印页核对。
