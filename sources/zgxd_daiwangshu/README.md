# 中国现代作家选集·戴望舒

- 底本：《戴望舒》（“中国现代作家选集”丛书），施蛰存、应国靖、盛美娣编，人民文学出版社、三联书店（香港）有限公司联合编辑出版，1993 年 4 月北京第 1 版第 1 次印刷，ISBN 7-02-001565-4/I·1367。文字由书籍扫描件（PDF，372 页）经 OCR 识别、整理而成，**尚未逐字校对**。
- 结构：引言一页；“第一辑”为全部诗作（每首一页，其后《诗论零札》一页，内含十七则，各为一节）；“第二辑”为游记、序跋及报刊小言（每篇一页，《山居杂缀》内“山风”“雨”“树”各为一节）；“资料部分”为序跋评论、《戴望舒诗校读记引言》、《校记》、研究论文、《戴望舒年表》（每篇一页，页内小标题为节，《戴望舒年表》以各年条目为节）。书的原目次没有再分诗集，故诗作按书中编排次序排列。

## 整理说明

- 去掉：丛书说明与版权页、插图页及图注、手迹页（PDF 第 1–12 页）、目次页、“作品部分”“资料部分”隔页、页眉页脚页码、末页的水印说明。
- 页下脚注（编者对个别诗的标题、人名、外文的注）去掉，正文里相应的圈码（①②…）一并去掉；《有赠》页下那段谱曲说明与歌词、《赠克木》页下的题注同样去掉。《试论戴望舒诗歌的外来影响与独创性》《戴望舒在香港》两篇的文末“注释”保留为该页最后一节，其正文里的圈码也保留。
- 《诗论零札》的“一”“二”两则序号 OCR 漏识，按版面补回。《试论戴望舒诗歌的外来影响与独创性》的“一”“二”两节序号同样漏识，按版面空行补回（“一”在“戴望舒的诗歌创作，始于二十年代初期”处，“二”在“戴望舒接受法国浪漫派影响主要体现在”处）。《论戴望舒的诗》各节标题书里不带序号，原样。
- 诗行逐行一段，节与节之间的空行（诗节划分）在站点格式里无法表示，未保留；《断指》一诗原书版面为长行，已把版面折行接回为原诗行。
- 半角 `( ) , ; : ? !` 在汉字旁已改全角；OCR 在诗行末把句号识成 `.` 的个别处改回“。”；西文跨行断词的连字符已接回。
- 《戴望舒年表》“戴望舒年表”节首为编者署名“应国靖”；各篇文章标题下的作者署名作为首段保留。

## OCR 已知问题

- 部分诗题的一个字被 OCR 漏识，已据 PDF 版面和书中目次补回：《静夜》《夜是》《断指》《印象》《村姑》《野宴》《二月》《微笑》《赠内》《偶成》《流水》。
- 第 22、242、244 页为空白页。第 261 页右侧《二月》引文署名被识成孤立的“二”，已按版面改回“——《二月》”。
- 《校记》（PDF 第 282–295 页）是多栏对照表：各行为“诗名　《戴望舒诗集》　《我底记忆》　《望舒草》/《望舒诗稿》”等栏，栏间以全角空格隔开，空栏留空；表中换行的单元格按位置并回，个别处栏位可能错位（如第 289 页表头把《望舒草》《望舒诗稿》并成一栏）；表中以“*”起首的是各诗的发表情况说明，另起一段，个别说明的折行尾部（如《古意答客问》条）被单列成行。
- 两篇文末“注释”里的圈码 OCR 误识较多（重复、错序、个别丢失，如“③”“①”多次出现），正文中的圈码也有漏识（《戴望舒在香港》中有两处识成“@”）；注释的先后次序按书。《试论戴望舒诗歌的外来影响与独创性》注释一条一行，个别折行的条目（“发表于《小说月报》二十一卷十二号。”）未能并回上一条。
- 个别西文人名、词语有 OCR 错字或漏空格（如“Th.Gautier”“LiliBrik”），原样保留；引文中个别单引号残缺（如《鲍尔陀一日》中酒名处）原样保留。
- 《试论…》中 “流水》” 一行为引诗署名“——《流水》”的残片，原样保留。
- 原书注释已按站内格式（注：词语：解释）挂在所注段落后，注码已去掉；个别注释的词语位置为推定。
