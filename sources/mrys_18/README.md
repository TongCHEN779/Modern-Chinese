# 亘古英才：陆放翁

- 底本：万文武著《亘古英才：陆放翁》（“中国名人轶事丛书”之十八，吴洪激主编），武汉大学出版社、台湾汉欣文化事业有限公司联合出版，1995 年 11 月第 1 版第 1 次印刷（书名页作《亘古英才——陆放翁》，版权页 CIP 作“亘古英才：陆放翁”，此处取后者）。文字由 Internet Archive / Anna's Archive 的扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：共十七页——丛书出版缘由、主编絮语（吴洪激序）、正文十五章（书中章题“一、少小爱诗”至“十五、莲花博士”），各占一页。书中章内没有小标题，每页只有一节（节名同页标题）。
- 去掉的内容：封面、CIP 版权页、丛书编审委员会名单、目录页、页眉页脚与页码、文末 Anna's Archive 水印页；出版缘由与主编絮语文末的署名（吴洪激）。“主编絮语”文末的写作时间地点保留，但 OCR 缺末字，作“1995年仲春于武昌珞珈山”（疑当为“珞珈山麓”，未补）。
- 段落按扫描版面的缩进重建（跨行、跨页接合；同一行被切成两个识别框的已按行合并）。诗词：单行成句的诗按原书每行一条“诗：”；书中按窄栏排印、折行的词（《钗头凤》《汉宫春》《点绛唇》《鹊桥仙》《卜算子》《眼波媚》、柳永《望海潮》）与古风，因折行位置不代表原句读，按句号/叹号/问号重新分行（叠句“错！错！错！”并入前句）；折行排印的引文（陆游《渭南文集》跋语、金大都督府牒、檄文、《南园记》）按一段处理。
- OCR 已知问题：个别单字错识（形近字，如“人”“入”）与引号缺失未逐一校改（仅改了明确的“唐苑”→“唐琬”）；少数标点缺失或错位；半角“,:;?!()”与汉字相邻处已改为全角；页下零星页码残片、孤立字符已尽量删除，仍可能有遗漏。柳永《望海潮》中“重湖叠献”疑为原书“叠巘”，仍照 OCR 保留。出版年份：任务说明称 1994 年，书中版权页为 1995 年 11 月。
