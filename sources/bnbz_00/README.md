# 百年百种优秀中国文学图书目录

- 底本：《百年百种优秀中国文学图书》（多人著），人民文学出版社 1999 年 10 月第 1 版（编者前言署“一九九九年九月十九日”）。文字由书籍扫描件（PDF）经 OCR 识别、整理而成，**尚未逐字校对**。
- 结构：前言一页；其后一百种入选图书每种一页（页标题为书名，次序同原书：官场现形记至舒婷的诗）；附录三页（评选委员会名单；复评委员会推荐二百种书目；评选委员会推荐增补书目）。每种图书页内，第一节（与书名同名）为书里标题下的“作者（生卒年）+ 初版年份、出版者”一行，第二节“作者简介”为其后全部正文（作者小传、内容与版本说明、署名）；原书这两部分之间没有分节标题，故未再拆分。
- 整理时去掉：封面、版权页、目录页本身；每页边上竖排的“百年百种”丛书页眉及页码；页面边缘的“现通行版本”式版权小注（如“1957年人民文学出版社版”，它们是印在页边的，OCR 时常插在正文中间）；扫描件末页的 Anna's Archive 元数据页。
- 整理方法：按 OCR 逐行坐标过滤边缘噪声，并按行尾长短、首行缩进合并断行与跨页段落；附录二、三按列坐标还原为“书名　作者　版本”一行一条（用全角空格隔开），类别名（近代小说、现代小说等）作节标题。
- 已知问题：
  - 个别 OCR 错字未改，如《官场现形记》作者简介“1906年以擦卒”（应为“以疾卒”之类）、少数括号误作“（……）”“(……）”混用、“《男人的一半是女人）”等标点错配。
  - 附录二个别条目：“死不着　张志民　1950 天津知识书店版”（“年”漏识）；报告文学一栏的“戊戌政变记”版本说明“1898年至1899年在《清议报》上连载，后出单行本”由两行接成；“太阳照在桑干河上　丁 玲”等少数行，书名与作者在 OCR 中粘连，已补一个全角空格。
  - 附录一的委员名单里，终评委员会“主任：朱寨严家炎”及“王富仁孙玉石朱寨朱向前……”等处姓名间原书空格 OCR 未识别，仍粘连；原书分两栏排列的人名按行顺序接成一段。
  - 附录三末四条（严秀杂文选、王鼎钧散文、人到中年、狗儿爷涅槃）在原书中没有版本栏。
  - 没有发现缺页：OCR 共 237 页，除封面、版权、目录外全部收入。
