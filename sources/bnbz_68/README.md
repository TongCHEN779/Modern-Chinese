# 红岩

- 底本：罗广斌、杨益言著《红岩》，中国青年出版社 2000 年 7 月第 3 版（2004 年 10 月印次；1961 年 12 月第 1 版）。文字由书籍扫描件（PDF）经 OCR 识别、整理而成，尚未逐字校对。
- 整理：按书中三十章各为一页，页标题用“第N章”（原书章下无标题、无小节标题）。页眉页脚、页码、封面与版权页、整页插图及其画家署名（如“吴凡作”）、每页底部的作者注释（共 27 页带注）均已去掉，正文里残留的注释标记（①②）一并去掉；原书无序跋、后记。段落依据行首缩进重新合并（含跨页续接）；章内的书信、通告、诗句等整段缩进的文字按原样分行或成段，诗歌类短句逐行成段。
- 已知问题：各章为按版面缩进自动合并的结果，个别段落的合并/断开可能与原书不完全一致（如第一章通告、第六章长篇训令、各章诗句与书信）；少数段末句号被 OCR 漏识；个别形近字未校。全书页码连续，未发现漏页；第 590 页（全页插图）、第 594 页（插图署名）未收，末页（原书第 592 页）排版为插图旁的竖排绕排文字，已按语义还原为段落，末尾画家署名“牛文作”已去掉。
