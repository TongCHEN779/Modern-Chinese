# 呐喊

- 底本：鲁迅著《呐喊》，人民文学出版社“百年百种优秀中国文学图书”丛书，1999 年版（2001 年 3 月第 2 次印刷）。书籍扫描件（PDF）经 OCR 识别、整理而成，**尚未逐字校对**。
- 整理：每篇一页，共 15 页：序、狂人日记、孔乙己、药、明天、一件小事、头发的故事、风波、故乡、阿Q正传、端午节、白光、兔和猫、鸭的喜剧、社戏。《狂人日记》内以“一”至“十三”分节，《阿Q正传》内以“第一章 序”至“第九章 大团圆”分节。
- 去掉：封面、版权页、作者简介、丛书前言与评委名单、丛书书目、目录页、末尾扫描站说明；各篇正文中的注码（如“[1]”）；各篇后出版社编者加的“注释”（含序后的注释）；零星页码、罗马数字等噪点。
- 补正：因首字大写字形，OCR 把《明天》《故乡》《白光》《社戏》的篇题截成单字（“天”“乡”“光”“戏”），页标题据目录补全；《狂人日记》正文“一”“二”“三”三个小节的序号 OCR 漏识，按结构补回；序末“《呐喊》”后补句号；《狂人日记》小序的断行合为一段。
- 已知 OCR 问题：个别字形近误（如“孔乙已”“自已”“阿Q,”的半角逗号、“~~~”应为波浪线）未改；《头发的故事》“这人也因此”处一个孤立噪点字已删，原文可能另有漏字；页面边缘噪点（C、I、Ⅲ 等字母）若混入行首已删除。未发现整页缺失。
