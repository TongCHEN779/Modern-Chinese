# 阿诗玛：撒尼民间叙事长诗

## 底本
《阿诗玛》（彝族民间叙事诗，重新整理本），云南人民文工团圭山工作组搜集整理，中国作家协会昆明分会重新整理，人民文学出版社，2000年7月第1版（“百年百种优秀中国文学图书”丛书）。书名取 OCR 文件夹名“阿诗玛：撒尼民间叙事长诗”。

## 整理说明
- 保留：李广田《序》（1959年7月，按原文的一、二、三、四分节；第一节编号 OCR 缺失，按顺序补为“一”）及长诗十三章（一 应该怎样唱呀？ 至 十三 回声），每章一页，诗行逐行成段。
- 去掉：封面、版权页、内容简介、丛书前言、评选委员会/编辑委员会名单、丛书书目、目次页、页眉页码、书末版权碎片，以及页脚脚注（口弦、阿着底/撒尼、公房、媒人礼节、祖先牌位、拜年礼、火把节等注）。正文中的脚注序号“①”一并去掉。
- 章标题前的数字取自书中章号；第一章“应该怎样唱呀？”章号原书无，按顺序加“一”。

## 已知 OCR 问题
- 版面噪点（页码旁的孤立字符）已删除；未发现缺页。
- 个别形近字未更正，如“囡”“因”、“撤尼”（应为“撒尼”）、“压追”（应为“压迫”）、“打坯主意”（应为“打坏主意”）、“迫得上”“放牛的老大妈”等处可能有误，保持原样。
- 目次页识别混乱，章号与章名按正文核对。
