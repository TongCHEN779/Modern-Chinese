# 白毛女

- 底本：延安鲁迅艺术文学院集体创作，贺敬之、丁毅执笔，马可、张鲁、瞿维、焕之作曲，向隅、陈紫、刘炽。《白毛女》（“百年百种优秀中国文学图书”），中国青年出版社 2000 年 7 月版（采用 1962 年修改本，含 2000 年重版前言）。文字由书籍扫描件经 OCR 识别、整理而成，尚未逐字校对。
- 收入：2000 年重版前言；人物表；文学剧本第一幕至第五幕（每幕一页，页内按“第N场”分节）；附录七篇（马可等《关于〈白毛女〉的音乐》、张庚《关于〈白毛女〉歌剧的创作》、贺敬之《〈白毛女〉的创作与演出》、马可、瞿维《〈白毛女〉音乐的创作经验》、丁毅《再版前言》、贺敬之、马可《前言（1950年）》、贺敬之《关于〈白毛女〉的修改》，各占一页）。
- 去掉：封面、版权页、作者简介、剧照说明、丛书前言及评选委员会/编委会名单、丛书书目、目录页、场景总表（OCR 次序错乱）、全部曲谱与“乐谱附录”（简谱及其歌词标注，原书第 128 页起约 80 页，OCR 为数字乱码）、页眉页脚、页码、页底脚注。文学剧本中各场的曲目标记（“唱第N曲”）保留。
- 剧本格式：台词按“角色：台词”成段，舞台提示（〔 〕）独立成段；唱段逐句分行。OCR 把“：”丢失，整理时由脚本据角色名补上；角色名与台词的分行主要由脚本判断，个别地方可能把相邻台词误并或误分。
- 第四幕：原书版面第一场标题“第一场”在 OCR 中缺失，据目录补为“第一场”节名（页内第一节）；第一幕页的第一节为幕首时间地点说明，节名用页标题。
- 已知 OCR 问题：
  - 第四幕第二场“弟兄们一路就着伴儿走，回家看望我的母亲”一带（原书第 105 页前后），多声部重叠的歌词被 OCR 打散，出现“我的母/亲。”“回家看望”“老：咱们乡”“我/们就是八路军！/他”等碎片，未改。
  - 个别“喜儿：”“众：”后台词缺失（原为角色名后紧跟括注，括注丢失），原样保留空台词。
  - “幕落”前的“一幕落”（第一幕末）疑为“—幕落”的识别结果。
  - 附录《〈白毛女〉的创作与演出》中“一九四年”（疑漏一字）、“有一十/七八岁之孤女”处，粘连的页码数字已去掉，可能有漏字；原文脚注（①②）及正文内脚注标记已去掉。
  - 前言里 1946 年版本署名一处的页脚脚注并入正文行尾，已去掉。
  - 附录末页（第 269 页）为曲谱附录的残片，未收入。
