# 尝试集

- 底本：胡适著《尝试集》（增订四版），人民文学出版社 2000 年 7 月版（“百年百种优秀中国文学图书”丛书）。文字由扫描件经 OCR 识别整理而成，尚未逐字校对。
- 结构：代序一、代序二、四版自序各一页；第一编、第二编、第三编、附录《去国集》各一页，每首诗一节；“所删初版内容”（含钱玄同序、初版自序及所删诗作）、“所删再版内容”（含再版自序及所删诗作）各一页。保持书中原字、原标点。
- 去掉的内容：封面、版权页、作者小传、丛书前言与评委名单、目录、丛书书目、末页水印、页眉页脚页码；每页底部的脚注（多为“初版……”的校记和作者原注）连同正文中的脚注序号（①②等）一并去掉。
- 两首歌的乐谱页（《平民学校校歌》《四烈士冢上的没字碑歌》）OCR 为乱码，未收，歌词保留。
- 对齐处理：书中竖排/小字的诗题被 OCR 拆散（如“蝶/蝴”），按目录与诗意还原为诗题；《例外》《相思》《秋柳》《孔丘》《一念》《自序》等标题残缺处按目录补全。诗前小序因版面折行被断开的，已按语意接成一段；跨页断开的句子已接合。《如梦令》一首 OCR 把“休做女孩儿相。”拆到下一行之后，据文意移回。《哀希腊歌》原文各章的罗马数字 OCR 有误，已按章序改正。
- 已知问题：不少诗的章序号“一”“二”（如《乐观》《哀希腊歌》中文译文、《新婚杂诗》）OCR 漏识，未补；散文序跋中个别段落被 OCR 在行首处误断（如四版自序引文、初版自序的引诗处），未强行合并；原书插页（如书影）未收。除上述外，未发现整页缺失（OCR 页码中 p0005–0006、0025、0043、0073、0075、0103、0105 为空白页或编编扉页）。
