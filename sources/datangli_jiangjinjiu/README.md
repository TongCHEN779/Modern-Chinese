# 大唐李白 第3卷 将进酒

- 底本：张大春《大唐李白·将进酒》，广西师范大学出版社（理想国），2015 年 6 月第 1 版（桂林）。简体中文版。文字由书籍扫描件（PDF，共 338 页）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 结构：p01 为“代序 变造化以窥天才”（书中分一至六节，各为一节）；p02–p34 为正文三十三章，页标题沿用书中章号与章名（如“一 一面红妆恼杀人”；章内无小标题，单节）；p35 为附录“李白的天下意、无情游”（廖伟棠撰，节的 author 字段填“廖伟棠”）。
- 去掉的内容：封面、版权页、目录页、卷首题词（“钟鼓馔玉不足贵……李白《将进酒》”）、页码与前文的罗马数字页码、末页作者简介（廖伟棠）和 Anna's Archive 水印页、“(第三卷完)”。书中无脚注。
- 诗句：整段连排的诗（如李白诗、拟作、小说中人物所作诗词）按“一联/一句一行”拆成段；带引号的夹叙引诗、对话中的歌词保持原段。拆分依据是整句规整度与缩进版式，个别杂言歌词的断行是推定的。
- 章号：OCR 稿里章号与章名常与上一段末尾挤在同一行（如“……一去不回。二三缠绵亦如之”），第 11、21、22 章章号漏识，均按目录补回；各章起点按章名在正文中定位，未逐页对照影印。

## OCR 已知问题
- 引号：多段连引的长引文按原书只开不合，故若干章的“”数目不等（相差 1–3），属原样；个别位置 OCR 把闭引号识成数字（“5”“9”等），能判断的已还原为”，其余数字噪点已删。
- 个别误插的闭引号做了修补（如“求一死所”“宁非如此”“其他三人”“尘吼多亦即俗称的头陀”四处与下文接回）；另有“皆动人”“不过”“无生”“由屯之豫”等处行末多出的 ” 难以判断，保持原样。
- 三处 OCR 误插的半角撇号（第 14、20 章引诗处）已删除；其余半角“?”“!”按位置改全角。仍有少量单字错识（如《独漉篇》引文中的“邕双雁”存疑、代序里“杀之’三”处引号错位）未改。
- 孤立的“àè F”等噪点、页眉页脚残留已删。
