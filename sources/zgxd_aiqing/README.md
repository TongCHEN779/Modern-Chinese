# 中国现代作家选集·艾青

- 底本：《艾青》（中国现代作家选集），高瑛编，人民文学出版社、三联书店香港分店联合编辑出版，1983 年 11 月北京第 1 版第 1 次印刷，书号 10019·3342。文字由书籍扫描件（PDF，艾青.pdf）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 结构：几句话（高瑛）一页；作品部分「诗」七十一首合为一页（每首一节，诗行逐行）；作品部分「诗论」四篇各一页（《诗人必须说真话》《形象思维和艺术魅力》《诗论》《诗人论》）；资料部分四页（周良沛《艾青的诗》、周红兴《艾青的狱中诗》、附《艾青二十五首狱中诗目录》、周红兴《艾青年表》）。《诗论》按书中分题（出发、诗、诗的精神、美学、思想、生活、主题与题材、形式、技术、形象、意像、象征、联想、想像及其他、语言、道德、服役、创造）分节，题下各条的序号单独成段；《诗人论》按条目序号（一至五十九）分节。《艾青的狱中诗》按文中序号分节（第一节无序号，书中亦无）。
- 去掉的内容：封面、扉页、版权页、目次、各部分扉页（作品部分、诗、诗论、资料部分）、页眉页脚页码、书末水印页；每页底部的脚注（《芦笛》《巴黎》《鹿回头》《诗人论》及两篇评介文章的注）连同正文里的注码（①②）。
- 诗题、诗行以书为准；半角 `( ) , ; : ? !` 在汉字旁改为全角；行末误识的句点改为“。”；《大堰河——我的褓姆》《吹号者》中因版心宽度折行的长句已接回，《吹号者》首节两段（散文式排法）按版面缩进分段。

## 整理时补回、更正的地方

- 小节序号（OCR 常把“一”“二”漏识）：《透明的夜》《光的赞歌》《迎接一个迷人的春天》《关于爱情》《吹号者》《写在彩色纸条上的诗》的“一”（及后者的“二”）按版面空行补回；《诗论》《诗人论》各题下的“一”“二”同样按版面空行补回，已与 OCR 保留下来的序号逐条核对，全书序号衔接无误。《诗论·意像、象征、联想、想像及其他》一题 OCR 作正文行，按版面（居中、前后空行）改为小题；《诗论·道德》一节第四条的序号“四”被误识为“围”，已改回。
- 《光的赞歌》文末日期“一九七八年八月一十二月”，据版面中间一笔应为破折号，改作“八月—十二月”。
- 《芦笛》题记法文首词“Pavais”改作“J'avais”，题记署名“—G. Apollinaire”补作“——G. Apollinaire”；《艾青的狱中诗》中“《叫喊》、《夜》”据正文所列篇目补作“《叫喊》、《监房的夜》”，一处段首误识的“？”删去，“一—《古宅的造访》”（引诗出处）改作“——《古宅的造访》”。
- 《附：艾青二十五首狱中诗目录》第 22—25 条“灯”“路”“搏动”“九百个”在 OCR 稿中只识出“九百个”，其余三条据 PDF 页面补入；各行篇名与日期之间用全角空格隔开，《Adieu—送我的R远行》依版面补回破折号。
- 《艾青年表》以年份行（“一九一〇年一岁”之类）独立成段，其下各条分段。

## OCR 已知问题

- 书中破折号“——”常被识成单个“—”甚至“一”（如《煤的对话》副题“——A—Y.R.”、诗行“——虽然昨夜……”），除上述个别处外未逐处改动。
- 《艾青的狱中诗》《艾青的诗》中引诗、引文的缩排行已各自成段；个别折行处的字（如“《监房的夜》”前的几个字）因版面丢失，只在把握极大处补回。
- 《艾青的狱中诗》中的“«Adieu一送我的R远行》”“Adieu一诗”等处，破折号与书名号残缺，原样保留。
- 页数、版面均无缺页；PDF 第 260、262 页为空白页，第 261 页为“资料部分”扉页。
