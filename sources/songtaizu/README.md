- 底本：范鑫编著《宋太祖赵匡胤传》（“中国历代帝王传记”丛书，邹屿晨主编），河北人民出版社 2016 年版。文字由书籍扫描件（PDF）经 OCR 识别、整理而成，**尚未逐字校对**。
