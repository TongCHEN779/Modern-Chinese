# 杜甫诗选注（增补本）

- 底本：萧涤非选注、萧光干、萧海川辑补《杜甫诗选注：增补本》（第 2 版），人民文学出版社“中国古典文学读本丛书典藏”，2017 年版（1979 年初版）。文字由书籍扫描件（PDF）经 OCR 识别、整理而成，**尚未逐字校对**。与同套的《杜甫诗选》（山东大学中文系选注）是两本不同的书。
- 结构：前言《诗人杜甫》（代前言）、《例言》各一页；其后按杜甫生平分四期各一页（第一期读书游历时期、第二期困守长安时期、第三期陷安史叛军中、为官时期、第四期漂泊西南时期），页内第一节为该期“说明”，其后每首诗一节（组诗如《前出塞九首》《秋兴八首》合为一节）；附录《〈杜甫诗选注〉批注》（萧涤非晚年批注，萧光干、萧海川辑补）分《批注辑录说明》、《正文中批注》（按四期各一页）、《封页等处批注》、《附记》五类页；末页《后记》。
- 注释：原书每期的注释集中印在该期诗作之后（按 [n] 编号），这里按正文里的 [n] 标号放回所属的诗句之后；注文首个词语（“某某，……”）改作 `词语：解释`，不能确定词语的（“这两句……”“以上四句……”之类）取标号前的几个字作词语。注文里含“……。某某：”样式、站点会误拆成两条的，用 `注原：` 保持一条。诗序（《同元使君舂陵行》《观公孙大娘弟子舞剑器行》等）里的注同样按标号放回。
- 诗行：OCR 稿把整首诗连成一行，按标点拆成句，四句左右为一段，句间用 `/`；OCR 稿里半角的逗号、分号、冒号、问号、叹号在汉字之后的改作全角。每首诗“题解”取原书诗后的说明文字（有的夹在两节诗之间，也一并放在节首）。
- 《同元使君舂陵行并序》后的“附：元结诗”（《春陵行并序》《贼退示官吏并序》）、《追酬故高蜀州人日见寄并序》后的“附：高适诗”（《人日寄杜二拾遗》）各列为一节，紧接在该诗之后；原书的“附：……诗”标签未收。
- 未收：封面、版权页、目录页、丛书广告、文前彩插与书影（萧涤非先生自存本的扉页、内页批注照片，无可识别文字）。书名页之后、前言之前的几页在 OCR 稿里全是空白页，未见“增补本”前言的文字；《批注辑录说明》和《后记》（含萧光干、萧海川所作后识）已全收。
- OCR 已知问题与处理：
  - 个别整行被 OCR 漏识，据同套另一册《杜甫诗选》对应诗句补回三处：《同诸公登慈恩寺塔》“行清秋。秦山忽破碎，泾渭不可求。俯视但一气，焉能”，《自京赴奉先县咏怀五百字》“香橘。朱门酒肉臭，路有冻死骨。荣枯咫尺异，惆怅难”，《发秦州》“求。密竹复冬笋，清池可方舟。虽伤旅寓远，庶遂平生”；这三处漏掉的注释标号（[178]、[340]、[443]）同时补上。
  - 《佳人》《留花门》各有一处同一行左右两段 OCR 次序颠倒（如“夫婿轻薄儿，”后接“[435]。但见新人笑，”），按版面坐标调回。
  - 生僻字常被 OCR 丢掉，诗中个别句子因此缺一字，未补（如《登兖州城楼》“荒城鲁殿”、《潼关吏》“小城万丈”、《送高三十五书记十五韵》“边城有力”、《复愁》“吟多意有”、《遭田父泥饮》“步随春风”等；据文意多为“馀”“屧”等字）；注释、题解里同类缺字无法一一发现。
  - 注释标号 OCR 有误（如“[2]”应为“[7]”“[9]”），按顺序对应；个别标号漏识，该条注释的词语取原注自带的词语或定位到所属段，位置可能偏移一两字。
  - 前言开头“一”的小标题 OCR 漏识，按“二”“三”补作“一”；各期“(公元七一二—七四五)”等年份区间的“—”OCR 漏识，据文意补回。
  - 《正文中批注》里夹在《登高》条下的读者来信（“萧先生：您好！……”）按 OCR 稿原样保留在该条之内。附录中各条批注按 OCR 稿的行为段，页与页之间被拆开的段落未重新合并。
- 原书注释已按站内格式（注：词语：解释）挂在所注段落后，注码已去掉；个别注释的词语位置为推定。
