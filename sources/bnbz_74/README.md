# 家变

## 底本
王文兴《家变》，辽宁大学出版社，1988 年（沈阳）。《现代台湾文学参考资料》丛书之一，OCR 自该书 PDF（全 199 页）。

## 整理说明
- 按书的三“部”分页：作者附言（无题）、第一部、第二部、第三部、附录；各部内以书里的字母 A–N 作节名。
- 去掉：封面、版权页、辽大社“出版说明”、编委会撰写的评介序文《王文兴及其〈家变〉》（非作者所作）、页码、书末 Anna's Archive 水印页。
- 保留：作者附言（书首一句，无标题，页标题记作“（无题）”）；书末附录“谈《家变》”（各家评语摘引）。
- 各节开头的报纸寻父启事（版式框内文字）作为该节首段保留。
- 书中原有的正文分段编号（1、2、3…）OCR 错乱且夹在行间，已一并去掉。
- 王文兴有意使用的怪异字词、不规则用字一律保留原样。

## 已知 OCR 问题
- 第二部 J 节、第三部 M、N 节开头的寻父启事 OCR 只剩残句（“尊意解决。”“解决。”），已略去。
- 第一部“她写二十四为：”后的手写数字图形 OCR 成乱码，已删去。
- 页码旁的罗马数字状残片（I、II、TT 等）已删；个别行内夹带的页码/编号数字（如“一118”“132”）已按页码规律清除，仍可能有少量漏网。
- 各页末行与下页首行的断句按标点合并，诗句、短句偶有误并或未并。
- 未发现整页缺失（PDF 页 14–197 连续）。
