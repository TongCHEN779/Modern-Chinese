# 滕固小说经典

- 底本：《滕固小说经典》，滕固 著，“中国现代小说经典文库”（阿宏 主编）之一，印刷工业出版社，2001 年 3 月第 1 版，ISBN 7-80000-413-9/I·11。文字由书籍扫描件（PDF）经 OCR 识别、整理而成，**尚未逐字校对**。
- 整理：前言一页，其后每篇小说一页（共 29 篇，依书中目录次序：《银杏之果》至《做寿》），页内“一、二、三”“（一）（二）”“上、下”“第一部……”等小节号各为一节；无小节的篇目只有一节，节名同篇名。《旧笔尖与新笔尖》为日记体，各则日期（二月四日等）作为小节名。篇末的写作日期、附记保留为该篇末尾的段落。
- 去掉了：封面、版权页、目录页、页眉（“滕固小说经典”）和页码、封底。书中无后记、附录。
- 小节号补回：《银杏之果》《百足虫》《新漆的偶像》《待期》《丽琳》《鹅蛋脸》各篇第一节的“一”印作一道短横，OCR 漏识，按版面补回节名“一”。
- 名字：书前“前言”里作者名印作“腾固”，正文页眉及版权页为“滕固”，前言保持原样。
- OCR 已知问题与处理：
  - 《壁画》《乡愁》《葬礼》《迷宫》《眼泪》《外遇》《诀别》《丽琳》《逐客》《待期》《做寿》等篇的篇题被 OCR 拆成单字或漏字（如“壁/画”“乡”“做”），篇题按书的目录补回，未使用识别结果。
  - 《古董的自杀》中青枝的信、报纸新闻，《一条狗》的附记，原书为较窄行宽，OCR 逐行断开，已按标点接成段。
  - 《眼泪》中两处行末的省略号“……”（“……的妇人也是产死的，……”“生、死、……死、生”）OCR 漏识，据影印页补回。
  - 《银杏之果》一处行末杂点“d”（“不d料他寄来父亲前了”）删去“d”，两处行末杂点“X”删去。《外遇》里孤立的“寄”字为杂点，删去。
  - 《银杏之果》“这是我非常愿意的，一—前年写给你的信”，此处破折号 OCR 识为“一—”，原样保留。
  - 页尾断开的段落按标点接上；极个别页尾处如有漏字，未补。
  - 半角 ( ) , ; : ? ! 与汉字相邻处改全角；英文名与原文外文原样保留。
