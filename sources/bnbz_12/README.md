# 雨天的书

- 底本：周作人著《雨天的书》，人民文学出版社，2000 年 7 月版（“百年百种优秀中国文学图书”丛书；据 1925 年北京新潮社初版）。文字由书籍扫描件经 OCR 识别、整理而成，**尚未逐字校对**。
- 整理：去掉封面、版权页、作者简介、丛书前言/评选委员会/编委会/书目、丛书页眉、目录页、末尾的 PDF 生成说明；保留自序、自序二及 50 篇正文中收入本版的 45 篇（《怀旧》《学校生活的一叶》《初恋》《娱园》《山中杂信》在目录中标“存目”，原书未收正文），以及附录汪仲贤《十五年前的回忆》。每篇一页，页标题即篇名；篇末日期、署名按原样保留为末段。页脚脚注已去掉（《笠翁与兼好法师》的阿太志野注、《读〈欲海回狂〉》的不净观注），正文里的注码“①”一并删去，《读〈欲海回狂〉》注后附的写作日期“十三年二月。”留作该篇末段。
- 页标题：《苦雨》《苍蝇》《“净观”》《沉默》《喝茶》《日本的海贼》《黑背心》的标题在 OCR 中残缺或缺失（分别识成“苦/雨”“蝇”“净又观”“沉”，《喝茶》无标题行，后二者不在目录页），按目录和内容补全；页面编号 p01 至 p50 与此无关。
- 《黑背心》中的葛木村权之丞妻年表、告密赏格两处原为表格，OCR 把年份与事项分行识别，已按“年份　事项”合并成行；“六五　夫弟太兵卫夫之从妹阿松被捕”一行 OCR 把两个事项挤在一起，原样保留。

  - 《笠翁与兼好法师》《济南道中》《济南道中之二》《济南道中之三》《生活之艺术》《与友人论怀乡书》《与友人论国民文学书》《沉默》等页为按行折断的版面，OCR 的行合并后原段落边界部分丢失：个别较长段落可能是原书几个自然段被并成一段（如《济南道中之二》末段、《与友人论怀乡书》第二段），个别短段可能被误断，未对照影印页逐一核对。
  - 全稿缺 p0114、p0117、p0135 三页（OCR 无输出），按前后文衔接看多为空白页，未发现缺文；《与友人论国民文学书》（PDF 第 95 页）开头的“一或是毘骞国王手中的账簿”前面疑漏识了一段文字（“……”处原样保留）。
  - 《读〈纺轮的故事〉》中“对于生之快乐”处 OCR 多出一个乱码字（PDF 第 136 页末），已删去。
