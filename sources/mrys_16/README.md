# 文苑异才：金圣叹

- 底本：郑卫国著《文苑异才：金圣叹》（“中国名人轶事丛书”之十六，吴洪激主编），武汉大学出版社、台湾汉欣文化事业有限公司联合出版，1995 年 10 月第 1 版。文字由 Internet Archive 的扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：共三十页——丛书出版缘由、主编絮语（吴洪激）、正文二十八章，各占一页。章名取书中目录与章首页标题（每章由“事由词＋对句”两部分组成，如“闹曲会　乞儿吟诗惊四座”，书中连排，整理时中间加一空格）。书中各章内无小标题，每页仅一节，节名同页标题。
- 去掉的内容：封面、丛书编审委员会名单、扉页与卷首插图页、版权页与 CIP 数据、图书馆章页、Internet Archive 水印页、目录页、页眉页脚与页码、书末丛书广告页；出版缘由与主编絮语开头的署名（吴洪激）；全书约十个整页/半页插图及其图下说明（如“小乞儿蘸满浓墨……写下四句打油诗来。”等，皆与正文重复）。“主编絮语”文末的写作日期保留，书中写作“1995 年初春编余随记”。
- 段落、诗词：按扫描版面逐行坐标重建——行首缩进为段首，跨行、跨页接合；整行居中的诗句（题壁诗、对联、顺口溜等）用“诗：”，句间以“/”分行，每四句一节；缩进更深的引文（批语等）仍按普通段落。
- OCR 已知问题：个别单字错识与引号缺失、错配（全书“ 与 ” 数目略有出入）未逐一校改；已更正“问日、答日”类明显的“曰”误识，以及少数噪点（“总不·能”“䥽”等）；个别页眉页码残留碎片已删，仍可能有遗漏；半角“:”“?”已改为全角。章末或页末遇插图页处，前后文已直接接合，个别段落可能因此被误断或误连。原书用字保持不变。
