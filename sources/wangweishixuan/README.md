# 王维诗选

- 底本：陈铁民选注《王维诗选》（中国古典文学读本丛书典藏），人民文学出版社，2002 年第 1 版，2017 年第 2 版。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：前言一页（一、二、三各为一节）；其后按书的“编年诗”“未编年诗”两部分，各按目录相邻成组（约 27 首一页），页标题为“第一首题—最后一首题”，pages.json 第三项填“编年诗”“未编年诗”。每首诗一节，节名取目录与书中原题（含题下小字“时年十七”等，原样保留）。去掉封面、丛书书目、版权页、目录页、出版社广告与插页。
- 题解与注释：原书在每首诗后集中列注，第一条注释（编年、题解式评析、题目中词语的解释）整条放在 `题解：`；其余注释按正文里的 ①② 标号放到所属诗节（四句一段）之后。一条原注含多个词语、且被站点按“词语：解释”规则拆开后会有碎片落不到原文上的，改用 `注原：` 整条保留。组诗（《济上四贤咏三首》《鱼山神女祠歌二首》《偶然作（五首选三）》《送友人归山歌二首（选一）》《辋川集》《皇甫岳云溪杂题五首》）每首小诗另起一节，节名为“组诗名·小题”（辋川集写作“辋川集·孟城坳”）；组诗总题下的注释并入第一节题解，小题后的注释并入该小题题解；《辋川集并序》自成一节（序文）。《送秘书晁监还日本国并序》的序文按句读分段，不加“/”。
- OCR 整理稿（full.txt）丢失了不少页首行（页面顶部的行被当作页眉删去），本册改用逐页识别结果（json）按行首缩进重新合并段落，因而页首的注释续行、被丢掉的整条注释（如“契阔”）都已补回。
- 已改正：目录里 OCR 误识的《丛军行》（作《从军行》）、《华子⊠》（华子冈）、《丘竹岭》（斤竹岭）、《茱萸沚》（茱萸沜；正文同误作“沂”）；前言“选入二五首”（实为二〇五首，已核对条数）。多首诗的题目行被 OCR 漏掉，题目均取自书前目录。
- 补回 OCR 漏识的字（均有句式与原注为证）：《洛阳女儿行》“十五余”、《喜祖三至留宿》“带余晖”、《偶然作》其二“没余齿”、《晓行巴峡》“余春忆帝京”、《陇头吟》“百余战”、《失题》“十载余”、《孟城坳》“古木余衰柳”、《木兰柴》“敛余照”、《金屑泉》“千余岁”、《辋川闲居赠裴秀才迪》“渡头余落日”、《题辋川图》“舍余习”、《沈十四拾遗新竹生读经处同诸公之作》“留余箨”、《寒食城东即事》“蹴鞠”、《鸬鹚堰》“褵褷”（注释词头同补）。
- 已知问题：①《敕赐百官樱桃》《送方尊师归嵩山》两首的正文中间各漏识一行（注释序号 [4][5] 无对应正文），未补，这两条注释排在该诗最后一段之后；②《送崔五太守》“使君年几三十”、《赠刘蓝田》“布成我衣”等句疑似漏字，原样保留；③注释序号 OCR 常把 [7] 误成 [2]（[8] 等同），已按顺序重新对位，个别误对位置难免；④书中引文的省略号“……”被识别成“.....”等，未改；⑤个别生僻字（如“沜”“褷”）及注音的拼音声调符号可能有误。
