# 黑恋（张资平情爱作品系列）

- 底本：张资平《黑恋》，“张资平情爱作品系列”之一，宁夏人民出版社 1993 年 6 月第 1 版（ISBN 7-227-00981-5/I·219）。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：全书为一篇中篇小说，原书以数字分为十七章，每章一页，页标题即书中章号“一”至“十七”（第一章章号原书未印，按次序补；第二章章号为一道短横，OCR 漏识，按版面补在 PDF 第 14 页“电车的音响。”与“第二天下午，君展从弈芳家里出来”之间；其余章号均为 OCR 识别）。
- 去掉了：封面、扉页、版权页、系列书目、出版社“编者的话”、责任编辑页、内容简介（均为出版社文字）、页眉“黑恋”及页码；篇末“（完）”。
- 整理时处理：按页面坐标重建段落，跨页断开的段落已接上；半角标点在汉字旁改作全角；第十七章“弈芳，·父母”处的“·”视为噪点删去。
- OCR 已知问题：个别字形近误识、漏识未改；英文词（Programme、Pavement、Boarding room 等）保留 OCR 原样。
