# 给战斗者

- 底本：田间著《给战斗者》，中国青年出版社 2000 年版（“百年百种优秀中国文学图书”丛书，根据人民文学出版社 1978 年版排印）。文字由书籍扫描件经 OCR 识别、整理而成，**尚未逐字校对**。
- 整理：小引一页；第一至第七辑各一页，辑内每首诗一节（节名取诗题，诗题下的题记、副题、日期保留为首行），诗行逐行成段；附录三篇（《写在〈给战斗者〉的末页》《〈给战斗者〉写作前后》《二〇〇〇年跋》）各一页，按文中序号“二、三……”分节，文内被硬换行拆开的段落已接上。
- 去掉：封面、版权页、作者小传、丛书前言、评选委员会/编委会名单、丛书书目、目录、各辑分隔页、页码、页脚脚注（《苓萼》《马莱》的花名注）、末页的网站水印。
- 已知问题：
  - 原书的诗节空行在 OCR 稿中丢失，各诗只按行排列，不分节；《给战斗者》中的 “一”（第一节序号）及部分诗内序号可能缺漏或与破折号混淆（如《祝山》“一一个人”、若干“—”应为“——”）。
  - 竖排诗题（如《火车》《鞋子》《多一些！》《地道》《王良》《骡夫》《攻击》《祝山》《叙诗》《苓萼》《马莱》《蝴蝶》《伯父》《山鹰》）的字序据正文与目录还原；目录里没有、正文单独成页的《警告》《井》按正文分节。
  - 《山鹰》原书即缺第二、三章（作者附注“因原稿遗失”）。《写在〈给战斗者〉的末页》中“呵啊”一行疑为“啊呵”之误，未改。
  - 未发现整页漏识。
