# 张居正大传

- 底本：朱东润著《张居正大传》，百花文艺出版社 2000 年版（“二十世纪四大传记丛书”）。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：序一页，正文按书中目录分十四章，每章一页，章内不设小标题。原书注释已按站内格式（注：词语：解释）挂在所注段落后，注码已去掉；个别注释的词语位置为推定（原书脚注按页排列，依注码编号配对）。
- 去掉：封面、版权页、目录页、页眉页脚页码。书前“张氏世系表”“隆庆、万历十六年间内阁七卿年表”两个表格（扫描页 20–32）OCR 结果为乱码，未收。
- OCR 已知问题：个别形近字错误未逐一更正（如“謇子”“循矩矮”等）；脚注内的书名、卷次可能偶有误识；少数段落若恰好在页末满行结束而下一段紧接，可能被并入同一段；引文、诗词按版面换行合并为一段。已将 ASCII 标点统一为全角，“○”统一为“〇”。
