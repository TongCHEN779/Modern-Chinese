# 中国古代名家诗文集·柳宗元集

- 底本：《中国古代名家诗文集·柳宗元集》，柳宗元 著，黑龙江人民出版社，2005 年 8 月 CIP 数据（2005 年 11 月第 1 版第 1 次印刷）。单册，PDF 共 513 页（OCR 起 514 页为 Anna's Archive 水印页）。文字由 PDF 扫描件经 OCR 识别、整理而成，**尚未逐字校对**，保持 OCR 的简体字形，未补标点。
- 结构：书按文体分类编次，页 = 一类（卷），节 = 一篇。共 34 页：总序，雅诗歌曲，赋，论，议辩，碑，释教碑铭，行状，表铭碣诔，志，志碣诔，墓表志，墓志，对，问答，说，传，骚，吊赞箴戒，铭杂题，题序，序，记，书，启，表，奏状，祭文，古今诗，非国语序、非国语上、非国语下（原书“非国语”一类的序与上、下卷各占一页），赋文志，补遗；共 670 节。本册没有题解、注释，只收作品原文及原有小序、自注文字。
- 去掉的内容：封面、封底简介、版权页（CIP 数据）、目录页、页眉（“柳宗元集”“中国古代名家诗文集”）、页码、Anna's Archive 水印页。保留“总序”（丛书编者序）与补遗中各篇的“录自……”出处句。
- 整理方法：以 json 行坐标重建段落（首行缩进为段首，跨页段落已接上），标题按居中版式识别并与目录逐条核对；原书的诗篇是连排成段、不分行的，诗行按原有标点切分，每四句（两联）一段，用 `/` 分句，**并非原书的分行**。《平淮夷雅》《铙歌鼓吹曲》中的诗章同样处理，各章的小序、“右《……》若干句”仍按原书作为普通段落。《贞符》《视民诗》以外的赋、箴、铭、骚等有韵之文，按书中自然段保留。
- 小标题的处理：目录中《为京兆府请复尊号表三首》《礼部为文武百寮请听政表三首》《为文武百官请复尊号表六首》的“第二表”等，《论语辩二篇》的“上篇”“下篇”，《扬子新注五则》的“学行篇”等，《巽公院五咏》的五个子题，均作为所属篇内的一行（`原：` 段）保留，未另起一节。《断刑论上》原题作“断刑论上文阙”，现节名取“断刑论上”，段落为“文阙”。目录中“六言”标目（《奉酬杨侍郎丈因送八叔拾遗戏赠诏追南来诸宾二首》后）正文版式中未识别到，未单列。
- 分页说明：目录在《南岳云峰寺和尚碑》前有“释教碑铭”标目，目录在《曹溪第六祖赐谥大鉴禅师碑》前另有一个“碑”字标目，正文 OCR 均无这些标题；本册按目录在《南岳云峰寺和尚碑》前另起“释教碑铭”页，《曹溪……》至《龙安海禅师碑》仍归“碑”页。
- OCR 缺失的标题（据目录或正文补回，均在页内位置核对过）：《贞符 并序》《瓶赋》《罴说》《禘说》《咸宜》《忧箴》《敌戒》《碑阴》（南岳大明寺律和尚碑后）《诉螭文 并序》《寿州安丰县孝门铭 并序》《独觉》《种术》《渔翁》《叠前》《怀嬴》（《非国语》）《青水驿丛竹天水赵云余手种一十二茎》《桂州北望秦驿手开竹径至钓矶留待徐容州》等。其中《禘说》目录 OCR 作“稽说”、正文 OCR 作“将褚”，据文意定为“禘说”；《怀嬴》仅存“嬴”字，据正文补“怀”；这两处为推定，存疑。
- 标题 OCR 校改：《种树郭橐驼传》（OCR 作“郭橐”“郭橐驰”）、《蝜蝂传》（OCR 作“蛸传”“蛸点传”）、《禜门文》（OCR 作“榮门文”）、《跂乌词》（OCR 作“跂鸟词”）、《铙歌鼓吹曲》（目录 OCR 作“饶歌”），据目录、正文及作品常称改，正文中对应的缺字（如《种树郭橐驼传》里漏掉的“驼”、《蝜蝂传》里的“蛸”）未补改。
- 已做的字符修正：“日：”“日“”误识的“曰”（约 30 处，限于其后紧接冒号或引号者）；半角括号、冒号、分号改全角；个别 OCR 把“”（右引号）识成 `'` 的已改回；零星的 `.` 标点噪点删去。《酬韶州裴曹长使君寄道州吕八大使因以见示二十韵一首并序》序中“余因拾其余韵酬焉”，OCR 在“其”“韵”之间只留下一个极低置信度的杂点，“余”字为据文意补入，存疑。
- OCR 已知问题：
  - 形近字、生僻字误识较多，如“貙”识作“驱/䝙”、“鹖”“鹃”、“悫”等，以及个别“已/己”“日/曰”（未带冒号引号者）、“待/侍”“憑/凭”之类，未逐一校改；古诗词未经校勘，字句以 OCR 为准。
  - 个别诗句中字数不整（如《铜鱼使赴都寄亲友》首句“行尽关山万里”），疑 OCR 漏字，未补。
  - 《天对》中“问：”“对：”各占一段；文中偶有断行处的段落合并/拆分误差。
  - 页眉与页码已用版式规则剔除，但仍可能有零星残留；未发现整页缺失（OCR 各页均有结果），缺字、漏行未逐页核对。
