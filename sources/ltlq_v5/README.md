- 底本：［英］斯图亚特·布朗（Stuart Brown）主编，高新民、曾晓平、殷筱、冯俊、程鑫 等译，高新民、冯俊 审校《劳特利奇哲学史》（十卷本）第五卷《英国哲学和启蒙时代》，中国人民大学出版社 2009 年版（总主编［英］帕金森、［加］杉克尔，中文翻译总主编冯俊）。文字由扫描件经 OCR 识别，用 json 坐标重建行与段落，**尚未逐字校对**。
- 页面：总主编序、作者简介、历史年表、导言、第一至十四章、名词解释、译后记，各占一页（共 20 页）。章内以书中小标题分节；章末“注释”（导言及第一至八、十一至十四章有，第九、十章为文中夹注，无注释）、“参考文献”为该页最后两节。各章首段为章作者署名（中文名与外文名）；总主编序末尾附两位总主编署名。
- 去掉的内容：封面、版权页、丛书简介（十卷本简介）、目录、页眉页脚、页边的原书（英文原版）页码、页脚脚注（译者注，含正文里的圈码）、主题索引、专名索引（页码对应原书）。
- 小标题：居中的标题为一级节；非居中的短小标题（如第二章“空间与时间”、第十二章“托马修斯派”）另起一节，紧跟在居中标题之后的则作为该节第一段保留。个别重名节（如第十二章两处“门德尔松”）未改名。

- 参考文献：条目按悬挂缩进拆分，条目编号（如 2.4）保留；书中的小标题（如“原文版本”“(i)全集和选集”）保留为独立一行。
- 名词解释、作者简介：每个词条（作者）一段。

## OCR 与整理的已知问题

- 页边的原书页码多数是独立的小框，已按坐标去掉；少数与正文行粘连的，按“与上一页边页码相邻”规则去掉（含行首、行尾及词中），个别可能残留或误删。
- 正文中的注释号为“[n]”形式，OCR 偶有丢失方括号或把注号当成页码的情况；章末“注释”中此类已按序号补回括号（如“[2笛卡尔……”改为“[2]笛卡尔……”），个别重号（如第七章两个“[15]”）保留。
- 注释中引用较长的引文（缩进、多行）有时被拆成数段。
- 导言末页有一条无注号的页脚脚注（“康德及其哲学不是本卷论述的对象”），因位置游离，并入了上一段末尾。
- 参考文献条目靠缩进拆分，条目编号缺失/重复处沿袭书中及 OCR 原样（第二章缺 2.5 的编号，第九章 9.16 重号，第十一章缺 11.93、11.110 重 11.100，第十二章缺 12.59）；换行处的西文连字符已合并（如 Lon-don 作 London），个别复合词可能被误合并。
- 历史年表：一年内的多个事件靠行距与栏宽判断是否为同一事件的折行，个别折行的事件被拆成两行或相邻事件被并成一行；右页（科学和技术、哲学栏）个别年份号 OCR 缺失（1667、1695、1699、1702、1707、1742），已用左页同一行的年份对齐；个别年份与事件错配（如“1624　堂恩……”实为首行并入年份框）。外文名、书名保持 OCR 原样，个别字形误识（如“詹姆土”）未改。
- 第十三章卷首题词“做，就是被做”与出处“S. 马拉梅”并成一段；第十二章“门德尔松”等小标题依版式判定，个别可能漏判或误判为段。
- 希腊文、拉丁文和外文人名、文献缩写保持 OCR 原样，空格丢失（如 HomericQuestions、TheEnlightenment）和个别字形误识未改。
