# 李自成（第2卷）

- 底本：姚雪垠著《李自成》第二卷，中国青年出版社、学习出版社，2019 年版（“新中国 70 年 70 部长篇小说典藏”丛书）。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：全书二十八章，每章一页，页标题为“第N章”（书中章无小标题）；按书的目录把页分为五组：商洛壮歌（第1—15章）、汴梁秋色（第16—18章）、杨嗣昌出京督师（第19—22章）、张献忠与左良玉（第23—24章）、从商洛到鄂西（第25—28章）。
- 去掉：封面、版权页、作者简介、出版说明、评审专家名单、目录页、页眉（“新中国70年70部长篇小说典藏”“李自成·第二卷第N章”）、页码、每页底部的作者脚注（及正文中的脚注序号①②等）、书末“商洛山战争形势示意图”和丛书书目页。
- 段落依版面缩进与行长判断，跨页、跨行的段落已接合；书信、谕旨、诗词等排版缩进不同处，诗词按行各占一段，个别书信（如第24章献忠致左良玉书、第26章“前有伏兵万勿追赶”告示）的分段为推定。
- OCR 已知问题：未发现缺页；个别字形近误识（如“己/已”“已卯”“知已”）、个别标点（半角“!”“,”）原样保留，未校改。第22章殷太白答词处有一行仅识出“饰…”，疑为台词被截断，原样保留。
