# 女神

- 底本：郭沫若《女神》，人民文学出版社，2000 年 7 月第 1 版（“百年百种优秀中国文学图书”丛书，初版本为 1921 年上海泰东图书局版）。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 结构：序诗一页，第一辑三部诗剧（《女神之再生》《湘累》《棠棣之花》）各一页；第二辑、第三辑按书中说明沿用 1921 年初版的分部，各分三页（凤凰涅槃之什、泛神论者之什、太阳礼赞之什；爱神之什、春蚕之什、归国吟），页内每首诗一节。页标题“……之什”“归国吟”及分部归属取自书前编辑说明，书中正文并无此标题。
- 去掉的内容：封面、版权页、作者小传、丛书前言、评选委员会名单、丛书书目、目次、书前编辑说明；每篇之后的编辑题注（“本篇最初发表于……”“本篇收入《女神》前未见发表过”及其引申的写作时间考订）；页脚脚注与书中的“作者原注”；正文里的脚注序号（①②……）；页码、页眉。作者的附白、附录（《凤凰涅槃》“附录”）、篇末日期行保留。
- 排版处理：诗行逐行为一段；戏剧中角色名统一写成“某某：……”（原书为“某某 ……”），舞台提示单独成段；《女神之再生》卷首歌德诗句原书中德文与中文逐行相间，这里先列中文八行、再列德文八行。第二辑、第三辑中的折行（因版心宽度折断的长行）已按坐标接回。

- 《雪朝》《光海》两首在 OCR 中完全没有标题（目次页也未识出这两个篇名），篇名系据全书目次与页码（79、85）补写，副题“——读 Carlyle:《The Hero as Poet》的时候”的括号已校正。
