# 李鸿章传（全译本）

- 底本：梁启超著《李鸿章传》（20世纪四大传记·最新全译本·双色珍藏版），中国城市出版社 2010 年 10 月版（2011 年第 3 次印刷）。这是梁启超文言原著的现代汉语全译本。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：原书上半为“译文部分”，下半为“原文部分”（文言原著）；这里只收译文部分，共十三页：序例与第一至第十二章，各占一页，页标题用书中章标题。译文各章在正文里没有小标题（章首列出的节名是本章内容提要，未收）；仅第十章内“一、二、三、四”四个标题保留为分节。
- 按版面坐标重建正文：去掉封面、版权页、目录、原文部分、页眉页脚、页码、竖排书名、图片及图注、图中文字（银票、股票、书札、时局图等）；序例页前的作者简介（出版社所加）未收。
- 表格改成一行一个段落，各栏以全角空格隔开：第五章捻军统帅表，第六章洋务事件表、北洋海军兵力表（附水雷船表、直隶淮军练勇表），第七章将帅表与海军损失表，第二章军机大臣表。海军兵力表原有的竖排分组字（主战舰队、防守舰队、补助舰队）与首列表头未收；其表头为按栏位自行合并的一行，“平远”一行末两栏 OCR 漏识。第七章将帅表序号（一、二、三、四）漏识，未补。
- 已更正：序例“史马迁”改“司马迁”，《辛丑条约》中“一九O一年”改“一九〇一年”；条约原文中的“□”为底本空缺。其余识别残留的错字、漏字未改。
- 段落按行首缩进与行末长短判断，个别段落可能误断或误合；跨页段落已接上。
