# 李自成（第1卷）

- 底本：姚雪垠著《李自成》第一卷，中国青年出版社、学习出版社 2019 年 9 月版（“新中国 70 年 70 部长篇小说典藏”）。文字由 PDF 扫描件经 OCR 识别、整理而成，**尚未逐字校对**。
- 整理：按书的 32 章各占一页（页标题“第一章”……“第三十二章”，原书章前无标题）；`pages.json` 第三项按目录填入各“部”名（北京在戒严中、潼关南原大战、义送摇旗、谷城会晤、崤函疑兵、卢象升之死、商洛潜伏、从北京到商洛、张献忠谷城起义、夫妻会师、北京的忧郁）。
- 去掉：封面、版权页、作者简介、出版说明、评审委员会名单、目录页、丛书页眉（“新中国70年70部/长篇小说典藏”）、书眉“李自成·第一卷第N章”、页码、每页底部的脚注及正文里的脚注序号（①②…）、“潼关南原大战行军路线示意图”、书末丛书书目、PDF 水印页。段落按版面缩进重新接合了断行与跨页处。
- 章内原有的数字小节序号（1、2、3…）大多未被 OCR 识别，整章作为一节，未分小节；小节之间的空行也未保留。
- 已知问题：第二十七章（PDF 第 527 页，“……流过许多血，死过几”之后）OCR 漏识了一行，句子在“死过几”处断开，接着下一段“许许多多往日的印象……”。个别诗词/文告/信件的行断在行尾处（如第十八章回目对联、第二十九章阮之钿檄文开头），按版面行分段。个别标点为半角（如“……吧?”已统一改作全角“？”“！”，其余半角括号未改）。其余形近字、漏字未逐一核对。
