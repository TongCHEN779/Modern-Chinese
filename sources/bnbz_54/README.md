# 解放区短篇创作选

底本：《解放区短篇创作选》，丁玲、孔厥等著，周扬编，解放军文艺出版社，2000年7月（“百年百种优秀中国文学图书”丛书之一；据1946年苏南新华书店、东北书店版重排）。OCR 来源：全书 PDF 的整理稿（354 页）。

## 整理说明
- 按书的目录，共 26 页：编者的话（周扬）；第一辑 12 篇；第二辑 13 篇。页标题为篇名，每页第一节为篇名节（内含副题、作者署名各一段），篇内的“一、二、三”或小标题另起一节。
- 去掉：封面、版权页、内容简介、丛书前言、评选委员会/编辑委员会名单、丛书书目、目录页、辑扉页、页脚作者注（“①②”及其注文）、正文中的脚注序号（《“众人原谅”》《草地》《一架机器的诞生》等篇的作者页脚注因此未保留）、末页水印文字。
- 跨页断开的段落已接上；孤立页码、零散数字已删。
- 《一天》原题 OCR 只剩“天”，依目录补为“一天”；《草地》标题 OCR 分作“草”“地”两行，合并。
- 《荷花淀》副题 OCR 作“一白洋淀记事之一”，整理为“——白洋淀纪事之一”（“一”改为破折号、“记”改为通行的“纪”）。
- 《八面山中》的两则日记以日期行（括注）作节名，《一坛血》《诺尔曼·白求恩片断》的章序号“二”“三”……作节名。
- 地雷歌、民歌式韵文逐行保留，短行各占一段。

## 已知 OCR 问题
- 《一坛血》开头部分未标“一”，《诺尔曼·白求恩片断》开头部分未标“一”，且“二”的章序号 OCR 缺失（该篇第 326–328 页附近，节号从“三”起），段落已并入前一节。
- 《一坛血》“男的”一行与下文“青年壮丁……”原为同一段（破折号 OCR 丢失），已补“——”接合。
- 《我的两家房东》《租佃之间》《一天》等多篇的对话段落，OCR 稿里常把一页内的多句对话合成一段，未再拆分。
- 个别 OCR 噪点（如“.”、“……”、前置引号后多余的句点）保留原样；《一架机器的诞生》中的电码文字（“XGY DE XOP……”等）为 OCR 结果，可能有误。
- 未发现整篇缺页；PDF 第 21 页、第 201 页（辑扉页后）空白，已略去。
