- 本书由大众文艺出版社“中国全史”丛书中的2册合并而成，共 100 页；各册整理记录如下。

## 第1册（tmp_qsyy_qing_gy_1）

- 底本：许啸天（民国）著《清代宫廷艳史》，大众文艺出版社“中国全史”丛书，年份不详（扫描件无可辨的版权页年份）。本册为该书第一册（上册），收第一回至第五十回；目录页所见全书共九十余回，其余在后续各册。文字由 PDF 扫描件经 OCR 识别、整理而成。
- 整理：每回一页，页标题为“第N回 回目上联 回目下联”，以各回开头的回目为准。去掉封面、丛书页、目录页、版权页与责任编辑页、页眉（“清代宫廷艳史”“中国全史”）及页码。按版面缩进与行宽重建自然段，跨页段落已接上；回末套语原样保留。奏章、上谕、《七恨》等引文各并为一段，诗词每句一行（随版面）。半角标点改为全角。
- 回数 1—50 连续，不缺不重；第四十九回仅四页（约二千六百字），按版面页码核对无缺页。
- 已知 OCR/原书问题：回目“辽鏖兵”（第七回）、“燃萁”（第三十三回）据目录改正；第三十二回回目“胤衹”、正文多处“胤っ”“胤i”“胤袖”及“胤”后缺字（第二十七、二十九、三十至三十三回）为生僻字识别失败，原样保留；“胤初”（应为胤礽，全册通用写法）、“和坤/和珅”两种写法并存，均原样；第四十三回回目作“和坤”，目录作“和珅”，从正文。第四十一回首段末句“上轿去了”后缺句号，原样。

## 第2册（tmp_qsyy_qing_gy_2）

- 底本：许啸天著《清代宫廷艳史》（“中国全史”丛书），大众文艺出版社，年份不详（版权页无可识别年份）。本册为下册，第五十一回至第一百回（全书共一百回，本册为后半部）。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：每回一页，页标题为“第N回 回目上联 回目下联”（回目依正文每回开头）；回数五十一至一百连续，不重不漏，无缺回。页内不分节。按版面坐标重建自然段，跨页段落已接上；引用的谕旨、诗词按缩进另起段，诗词每句一行。
- 去掉的内容：封面、书名页、版权页、空白页、页眉（“中国全史”“清代宫廷艳史”）、页码、书末责编与封面设计信息；PDF 第370页页末的一条脚注（清十二主说明）及正文中的脚注标号“①”。
