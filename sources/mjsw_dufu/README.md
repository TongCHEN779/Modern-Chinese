# 中国古代名家诗文集·杜甫集

- 底本：杜甫著《杜甫集》（“中国古代名家诗文集”丛书之一，原书封面署“（唐）李白等著”），黑龙江人民出版社，2005 年 11 月第 1 版，2009 年 1 月第 2 次印刷；全书 334 页。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成，保持简体，**尚未逐字校对**。
- 结构：书前《总序》一页；正文按书的卷次一卷一页（卷一至卷八为“古诗”，卷九至卷十八为“近体诗”，卷十九“表赋记说赞述”，卷二十“策问文状表碑志”），各卷页标题为卷次加书中的卷首标题（含“天宝未乱时并陷贼中作”之类的纪年纪地小注）；原书卷十八之后、卷十九之前的“附录”（他集互见、吴若本逸诗、草堂诗笺逸诗拾遗等）单为一页。节 = 一首诗或一篇文，节名取书中原题。
- 排版：原书诗歌连排成段，不分行。本站按原文标点把诗拆成一句一行（行间用“/”），大致四句一段（一首内的多章，如《秋兴八首》，按书中分章分段）；原书没有的标点未补。诗题下的小字题注、小序（如“并序”之序）、人名注、附录里“右一篇见某某本”之类的校勘说明，都原样放在该篇开头或末尾，写作“原：”段。《江头五咏》一首之下的五个小题（丁香、丽春、栀子、鷄、花鸭）放作该节中的小标题行。
- 去掉了：封面及书脚广告语（前三页）、版权页、目录页（目录由站点生成）、页眉“杜甫集”“中国古代名家诗文集”和页码、插图页与扫描件末页的 Anna's Archive 水印页。

## OCR 已知问题

- 书中标题多为字间加宽排印，OCR 常把一个题目拆成几行或丢字。能核对页图的已据 PDF 页图补正：总序（OCR 作“序”）、《台上得凉字》（OCR 只有“上得凉字”）、《赤甲》《阁夜》《巴山》《草堂》《石龛》《柴门》《遣怀》《对雪》《望岳》《日暮》《病马》《一室》《即事》《警急》《王命》《九日》《老病》《白帝》《宿昔》《暮归》《草阁》等单字或残缺的题目；《朝献太清宫赋》《已上人茅斋》《阻雨不得归瀼西甘林》三题据目录改正了形近字、重字。其余题目未逐一核对页图，个别长题、小字注（如“适”“虔”“源明”之类夹注人名）可能有误字漏字，夹注人名已与题目连排，未另分。
- 卷十四卷首标题 OCR 与页图均作“近体诗一百十九首行”，疑为原书误排，保留原样。
- 原书本身的个别误字（如《总序》中“难经计数”“肯人一个共同特点”）未改。OCR 的形近字误（如“徯”作“溪”“篌”、“旻”作“曼”、“羆”类生僻字、“鷄”“鵰”等异体）只在极有把握处更正，其余保留。
- 诗行中夹杂的零星 OCR 噪点（孤立的“.”“·”及个别无法判读的单字）已删去；一处句中误衍的句号（“开怀无愧辞”）已去掉；诗中个别生僻字（䴙、㧐、㺄、㸌等）依识别结果保留。
- 附录各篇后的“右…篇，见…本”等小字说明与诗文连排在页上，整理时按行首缩进、字号分开，个别说明与诗句的边界可能判断有误；附录的“句”（逸句）三首题目即书中所印。
- 页内偶有两个同名小节（如两首《短歌行》《野望》《雨》《遣兴五首》，均为书中原有的同题之作）。
- 书中原有的卷十九、卷二十的“表赋记说赞述”“策问文状表碑志”两卷，文章按自然段分段，未作任何增补。
