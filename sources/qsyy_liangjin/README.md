- 本书由大众文艺出版社“中国全史”丛书中的2册合并而成，共 100 页；各册整理记录如下。

## 第1册（tmp_qsyy_liangjin_1）

- 底本：（民国）蔡东藩著《两晋历史演义全书》上册，大众文艺出版社“中国全史”丛书；年份不详（扉页、版权页未见出版年份）。本册为全书第一册（上），含第一回至第五十回（书中目录列全书一百回，下册另收第五十一回至第一百回）。文字由书籍扫描件（PDF）经 OCR 识别、整理而成。
- 整理：一回一页，页标题为“第N回 上联 下联”，以每回正文开头的回目为准；去掉封面、丛书页眉、目录页、版权页、页码与页眉页脚；跨页的段落已接上；回末诗句、套语、评语原样保留；半角标点改全角。本册无序跋。
- 回数连续：第一回至第五十回不重不漏，每回均有回目与正文。
- 已知问题：回目中三处据目录核对更正（第二十四回“迓亲王”、第三十三回“段匹磾”、第三十九回“温峤”）；第四回、第五回、第十七回、第三十一回、第四十五回、第四十六回等回目文字在目录页识别不全，无法对照，按正文原样；正文中人名等偶有形近字、专名字的识别错误（如“荀酖”“冯郿”之类，应为“荀勖”“冯𬘘”），未逐一更正。
