# 雅舍小品

## 底本
梁实秋著《雅舍小品》，解放军文艺出版社，2000 年 7 月第 1 版（“百年百种优秀中国文学图书”丛书之一）。OCR 稿来自该书扫描件。

## 整理说明
- 共 133 篇，每篇一页，页标题取各篇题目；按书分为“雅舍小品”“雅舍小品续集”“雅舍小品三集”“雅舍小品四集”四组（pages.json 第三项）。
- 去掉：封面、版权页、作者简介（出版社所写）、丛书前言、评选委员会/编委会名单、丛书书目、目录页、各集分隔页、页码、末页的电子书元数据。书中无作者序跋。
- 段落依据 OCR 行的缩进与行宽重新合并，跨页断开的段落已接上；诗句、对话、歌谣每行一段。

## 已知问题
- 第 p0259 页起的一篇（“雅舍小品三集”中谈木屐/鞋履的一篇）题目 OCR 成单字“奚”，目录也漏掉标题，无法核实，页标题暂作“（无题）”（该页 PDF 页 259）。
- OCR 的目录页缺漏部分条目，篇目是按正文各篇首行标题切分的，已与目录页码核对无遗漏。
- 《洋罪》《同乡》个别段末的冒号疑被 OCR 丢失（如“所说的”后直接接诗句），未补。
- 腌猪肉、图章两篇含英文引诗，保持原样。
