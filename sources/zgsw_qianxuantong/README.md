# 中国现代散文经典文库·钱玄同卷

- 底本：钱玄同著《钱玄同散文经典》（扉页书名；封面为“中国现代散文经典文库·钱玄同卷”），阿宏主编“中国现代散文经典文库”，北京：印刷工业出版社，2001 年 3 月第 1 版第 1 次印刷，ISBN 7-80000-407-4/I·15。文字由书籍扫描件（PDF，《中国现代小说经典文库》系列文件夹内同名文件）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：去掉封面、版权页、目录、页眉“钱玄同散文经典”、页码与版面杂点；一页对应一篇（前言一页，其后每篇一页）。书内以“一、二、三”“（一）”“1、2、3”编号的小节各为一节；《随感录》中各则按书中的编号（八、十六、十七……）分节；附于文后的“附：某某的信”、《教育今语杂志章程》各章、《废话》中“开场白”“原经”等各为一节。文末的“（本篇发表于……）”出处说明按书保留。
- 书的分篇以目录为准：目录给出的第一篇“随感录”收《新青年》随感录若干则，其后为《李大钊〈新的！旧的！〉的附言》起各篇，至《太炎先生挽联》止。
- 补回与推定：
  - 小节号“一”被 OCR 漏识，据版面空行补回：《什么话？》《寸铁十二则》《和知堂五十自寿诗二首》《太炎先生挽联》开头的“一”；《刊行〈教育今语杂志〉之缘起》所附章程的“第一章宗旨”（章名同样被漏识，按“第二章定名”以下的体例补写）。
  - 《刊行〈教育今语杂志〉之缘起》所附章程中“第二章办法”，据章次顺序（第二章定名、第三章门类、第四……第五章经费）改作“第四章办法”。
  - 《废话》三篇的页标题为“废话”，其下的副题“——废话的废话”“——原经”“——关于‘三一八’”据版面并入页标题；篇中《废话的废话》的“废话”二字在原书为隔字排印。
  - 《赋得几分之几》中三处分隔符（OCR 识作 X/*）按版面写作“＊　＊　＊”。
  - 《恭贺爱新觉罗溥仪君迁升之喜并祝进步》中名片的版式（正面、背面）按行拆开，“（前面）”的“面）”OCR 漏识，据对称处补回。
  - 《关于魏建功的〈胡适之寿酒米粮库〉》文末署名表（地名、姓名、名）每行一段，各栏用全角空格隔开。
- 缺页：PDF 第 2–4 页（封二、扉页前页）、第 12 页（空白）、第 315–317 页（无内容页）OCR 无文字；各篇正文无缺页。
