# 肖邦：生平与时代

- 底本：〔英〕艾伦·沃克（Alan Walker）著，胡韵迪译《肖邦：生平与时代》（Fryderyk Chopin: A Life and Times，原著 2018 年），社会科学文献出版社，“索·恩人物档案馆”丛书。译者据书前页确认为胡韵迪；中文版出版年份在所得扫描件中未见（版权页缺），故未注。文字由书籍扫描件（PDF，907 页）经 OCR 识别、脚本整理而成，**尚未逐字校对**。
- 整理：按书的目录分章，每章一页，页标题用书中章题；章内以书中罗马数字（I、II、III……）为小节名，章首题辞与引言归入页标题一节。另有中文版序、致谢、序言、附录（李斯特《肖邦传》问卷）、肖邦作品总目录（仅存说明与注释）、参考书目各一页。各章章末集中的尾注保留为该页最后一节“注释”，条目前的 `[n]` 为书中注号。
- 去掉的内容：封面、书名页、版权页、作者译者简介、目录页、肖邦家谱（谱系图，OCR 成零碎文字）、插图图注、乐谱示例的识别残片、页眉页脚页码、**索引**（附英文页码，不收）；“肖邦作品总目录”的表格在 OCR 中栏位错乱，无法还原，未收，仅保留说明、缩写与注释。
- OCR 已知问题：全书正文里的乐谱示例、插图、图注被识别成杂乱碎片，已按规则（无汉字的短行、极短残片、含“绘/摄/画像”等字样的图注行）自动滤除，个别漏网或误删可能存在；跨页、跨行断开的段落按“上一行无句末标点且较长”接合，引文块、书信落款等偶有误并或误断；各节罗马数字按顺序校验，与目录页一致；注号序列与正文引注数逐章核对一致；外文（法、德、波兰语）引文及注释中的文献缩写识别有错字，未改；“——”常被识别为“一一”，原样保留；参考书目条目为“缩写＋全文”，个别条目的缩写与正文次序在版面上错位，已据体例复位，仍可能有错。
