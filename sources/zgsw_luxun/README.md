# 中国现代散文经典文库·鲁迅卷

- 底本：《鲁迅散文经典》（中国现代散文经典文库，阿宏主编；封面题“中国现代散文经典文库　鲁迅卷”），鲁迅 著，印刷工业出版社，2001 年 3 月第 1 版第 1 次印刷，ISBN 7-80000-407-4/I·15。文字由书籍扫描件（PDF，共 402 页）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 收录：编者前言一页；《且介亭杂文》38 篇（含序言、附记）；《三闲集》36 篇（含序言）。每篇各占一页，共 74 页。页标题用书里的篇名；`pages.json` 第三项填该篇所属的集名，《三闲集》再按书里的年份分成“三闲集·一九二七年 / 一九二八年 / 一九二九年”，其序言单列为“三闲集”。
- 整理：去掉封面、扉页、版权页、目录、页眉“鲁迅散文经典”和页码、孤立的装订噪点（PDF 第 400 页）。篇内的“一、二、三”“来信/回信”“夜记之一/二”等小标题各为一节，节名保留书中写法（编号与标题之间补一个全角空格）。
- 注释：本书的编者注全部集中排在每篇文末，并非页脚，故一律保留为各页最后一节“注释”，每条一段，条号作〔1〕〔2〕……；正文里的注码同样写成〔n〕。各篇注〔1〕按书的体例是篇题上的注码，题目上的注码未保留，故注〔1〕在正文里没有对应标记。文中没有页脚注。

## 整理说明与 OCR 已知问题

- **缺页**：PDF 缺少原书第 155—156 页（PDF 第 168 页与第 169 页之间），《中国文坛上的鬼魅》一篇止于“因为他们正握着涂抹”，其后的正文、文末日期和该篇全部注释均未收，故该页没有“注释”节，正文里的注码〔2〕—〔12〕找不到对应的注。
- **小节号补回**：《中国文坛上的鬼魅》《病后杂谈》《病后杂谈之余》第一节的“一”，《某笔两篇》第一则的“其一”，OCR 均已漏识，按版面（前者标有“二”“三”“四”，后者标有“其二”）补回节名；《病后杂谈之余》的“关于“舒愤懑””是该篇副题，放在“一”的首段。《答国际文学社问》首段的“原问”、《草鞋脚》小引的“（英译中国短篇小说集）”、《关于新文字》首段“答问”、《无声的中国》《现今的新文学的概观》的讲演日期副题，均作为正文首段保留。
- **篇题漏识**：许多篇名在扫描页上被 OCR 丢字（如“儒术”“隔膜”“运命”“阿金”只剩单字），页标题据书的目录写出，篇首残留的题字、注码已删。
- **注码**：个别注码在 OCR 里漏识或错识，已据上下文把握大的改回（如“〔11〕”被识成“〔1〕”，《病后杂谈之余》两处空括号补作〔4〕〔5〕，《书籍和财色》“张竞生6博士”补作〔6〕，《述香港恭祝圣诞》“浮海[1，”补作〔11〕，《“以眼还眼”》“辛那[11”补作〔11〕，《拿破仑与隋那》里“卐”字被识成“5”也已改回）。仍然缺正文注码的有：《儒术》〔9〕、《“以眼还眼”》〔9〕、《拿破仑与隋那》〔3〕、《附记》〔2〕、《三闲集·序言》〔11〕；《病后杂谈》第 9 条注 OCR 整条漏识，正文有〔9〕无对应注。
- **并排两栏**：《病后杂谈之余》第二节里晁说之《负薪对》“旧抄本”“四库本”左右并排对照的两栏，OCR 按行交错，已按栏拆开，整理成“旧抄本”“四库本”各一小标签加一段（“四库本”栏中印作“（无）”处原样保留在其位置上）。
- **段落**：缩进、行宽由逐页坐标重建；引文块（缩进较深者）与诗行按版面分行，个别引文末行断开处可能与原书不完全一致。跨页的段落已接上。
- **其他**：半角 `( ) , ; : ? !` 在汉字旁已改全角；少数外文名、年份中的半角标点保留；“一”与破折号“——”偶有 OCR 混淆（如《答〈戏〉周刊编者信》“第二个问题一”处应为破折号），未改；“一九三年”（应作一九三〇年）等个别脱字、数字错识（如注释里“一九三年二月”）未改。
