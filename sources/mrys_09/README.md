# 风流才子唐伯虎

- 底本：杨行恭著《风流才子唐伯虎》（“中国名人轶事丛书”之九，吴洪激主编），武汉大学出版社、台湾汉欣文化事业有限公司联合出版，1994 年 11 月第 1 版（封面作《风流才子　唐伯虎》，页脚作《风流才子——唐伯虎》，版权页 CIP 作《风流才子唐伯虎》）。文字由扫描件（PDF，Anna's Archive / 读秀来源）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：共十二页——丛书出版缘由、主编絮语（吴洪激序）、第一至第十章，各占一页。书中无章内小标题，每章只有一节（节名同章名）。书无引子、后记。
- 去掉的内容：封面、版权页（CIP、ISBN、定价、印刷信息）、目录页、页眉页脚与页码、PDF 末尾的 Anna's Archive 说明页；出版缘由与主编絮语文末的署名；“主编絮语”文末的写作日期“一九九四年记于古城黄州”保留。
- 段落：按扫描版面缩进与行宽重建，跨行、跨页的段落已接合（跨页是否接续依据版面缩进判断，个别处可能误判）。书中的诗词、联句、偈语按版面缩进识别，标作“诗：”行；两行一联等按原版每行一段，被版面折行的长句已接成一行。引文不加格式。
- OCR 已知问题：个别单字错识（如“高憎”类形近字在页眉中出现，已随页眉删去；正文中仍可能有“己/已”“未/末”等形近字误识）；扫描有漏行，致个别句子不完整或前后不接，保留原样，如第一章“……姑奶奶在床然动”、第四章“他努力寻觅”及“头，几乎要炸裂；胸腔，透不过气来”、第六章“从孙膑想到了司马迁”与“含辱而生，古人也不能免，我唐伯虎”之间；第一章“去腊梅没有”处原识出一孤立数字“1”，已删；两处因孤立数字使段落断开（“不是虚言”“情况突然发生变化”）已接合。“主编絮语”末“作品，值得一读。”一行，前接行文疑有缺漏，按原样单列。半角“:”“?”已改为全角；原书用字（如“着”“象”）保持不变。部分诗词的“诗：”标注靠版面缩进判断，个别散文化的联句（如第一章“唐伯虎：……”对联）可能与原书标点略有出入。
