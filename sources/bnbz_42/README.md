# 十四行集（冯至 著）

## 底本
《十四行集》，冯至著，解放军文艺出版社，2000 年 7 月第 1 版（“百年百种优秀中国文学图书”丛书之一）。据 OCR 整理稿（`full.txt`，并对照逐行识别的 `json/`）整理。

## 结构
- p01《十四行二十七首》（1941）：27 首十四行诗，每首一节，节名为“序号 诗题”（无题者取首句）。
- p02《补录》：早期诗作 36 首（1921–1933），每首一节；《吹箫人的故事》《帷幔》《蚕马》《暮春的花园》《别友》中的“二”“三”“尾声”等分章标记保留为诗行。诗末年份保留为“——年份”一行。

## 整理时去掉的内容
封面、扉页、CIP 与版权页、作者小传（封底简介）、丛书前言、评选委员会与编委名单、丛书书目、总目录、页码与页眉、扫描元数据页；每页底部的作者脚注（鼠曲草、郊外、蔡元培、鲁迅各一条）及诗题上的脚注号。保留《蚕马》诗后的作者“附注”。诗行按书的分行，诗节间空行不再保留。

## 已知 OCR 问题与改动
- 按把握较大的形近字更正：帷慢→帷幔、翁萃→翕萃、浙浙→淅淅、菩萨拿前→菩萨座前、洞箭→洞箫、眼晴→眼睛、进出来→迸出来、字宙→宇宙、念里外/念年前→廿里外/廿年前、薜苈→薜荔、一宴时→一霎时、蘑芜/藤芜→蘼芜、闪铄→闪烁、素爱的→亲爱的、人问的→人间的；题目“瞽者的暗示”按正文更正。
- 存疑未改：“激嗷的孤雁”“风翁翁”“乌云电”“活意”“棹上”等，可能另有误字。
- 全书无漏页，未发现整篇缺失；目录中个别诗题（如第十六首作“在高高的山巅我们站立”）与正文标题不同，以正文为准。
