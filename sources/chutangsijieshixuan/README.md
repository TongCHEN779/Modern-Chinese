# 初唐四杰诗选

底本：《初唐四杰诗选》，倪木兴选注，人民文学出版社（中国古典文学读本丛书典藏），2017 年 12 月第 1 次印刷（初版 2001 年 7 月）。OCR 整理稿取自“中国古典文学读本丛书典藏全集”合并稿的 PDF 第 11415–12066 页。

整理说明：
- 收前言（含四杰小传与编选说明）及王勃、杨炯、卢照邻、骆宾王四家诗，各家一页，页内一首诗一节，节名取书中原题（如“咏史（四首选二）”“从军中行路难（二首选一）”照书中小注保留）；组诗（如“铜雀妓二首”“别人四首”）合为一节，各首分段，书中的“二、三、四”序号行未收；“秋晨同淄川毛司马秋九咏”下的“秋蝉、秋水、秋菊”小题单独成段。
- 去掉封面、书名页、版权页、总目录、“返回总目录”、丛书介绍、书末广告与下一册的页面。
- 原书注释集中印在各家诗后，以全书各家各自从 [1] 起编号的方括号序号对应正文；据序号把每条注放回所属诗段之后（诗按四句或一个句群分段，句间以 / 分行）。标在诗题上的注号，其注文作为该首的“题解”原样搬入（其中含对题目字词的注）。一条注里含多个词条的，保留为一条（凡拆开后会把引文误拆的用“注原：”整条录入）。
- 注释词语在诗段中找不到（异体字、OCR 字形不同或原注为评说）的 17 条，在词语前补了所指的一小段原文。
- 全部注释 2,129 条；词语对位检查未发现落空。

- 前言第 11439 页页脚处混入的一段残缺脚注（“喜，褰衣绕床……即成卢。”）已删去。
- 个别诗句疑有脱字或误字（如《春晚山庄率题二首》其二“唯诗酒意”），无从核对，保持原样。
