# 中国现代作家选集·萧乾

- 底本：《中国现代作家选集　萧乾》，萧乾编，人民文学出版社、三联书店香港分店联合编辑出版，1986 年 8 月北京第 1 版第 1 次印刷（书号 10019·3983）。文字由书籍扫描件（PDF，萧乾.pdf）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：按书的目录分页，共 21 页：自序；“短篇小说”九篇（《篱下》《矮檐》《落日》《雨夕》《邮票》《栗子》《皈依》《蚕》《邓山东》）；“散文特写”八篇（《草原即景》《南德的暮秋》《美国散记》《伦敦三日记》《血肉筑成的滇缅路》《刘粹刚之死》《雁荡行》《流民图》）；“资料部分”三篇（鲍霁《萧乾的生平与创作》、舒辑《浅读萧乾的散文特写》、梅子彦火《萧乾年表简编》）。页内小标题即书中的节标题：《南德的暮秋》为“前奏”及各日日记，《美国散记》《血肉筑成的滇缅路》《雁荡行》《流民图》为“一、二、三……”节，《伦敦三日记》为“月曜日、火曜日、水曜日”，《浅读萧乾的散文特写》两节，《年表》按年份分节（年份行即节名）。篇末的写作日期、地点及“（选自《人生采访》）”出处说明保留为篇末段落；文中插入的歌词、诗句逐行一段。
- 去掉了：封面、版权页、作者照片和书影页、手迹页（PDF 第 11 页，为《矮檐》首页手迹影印，OCR 不可读）、目录页、“作品部分”“资料部分”隔页、页眉页脚页码、每页底部的脚注（自序、美国散记、鲍霁/舒辑两文的出处注等），正文中的脚注号（①②③……）一并去掉；PDF 末页的下载水印页。
- 小节号：鲍霁《萧乾的生平与创作》的“一”“二”两节号印作短横，OCR 漏识，据版面空白和次序补回（“一”在“萧乾，原名萧秉乾……”前，“二”在“萧乾的文学成就是多方面的……”前，“三”OCR 已识出）。《美国散记》等篇节号与标题 OCR 连在一起（如“一护航轮上”），整理时在节号后加了一个全角空格。小说中的空行分段不另设小节。
- 标题补回：《雨夕》（PDF 第 55 页）、《皈依》（PDF 第 81 页）两篇的篇名 OCR 漏识，据目录和版面补回。
- OCR 已知问题：全站版式不统一，段落按行首缩进和行末长短重建，少数引文/书信（《矮檐》《邮票》《刘粹刚之死》及鲍霁文中的引文块）的分段可能有出入；破折号“——”在识别中常只识出一横，凡孤立的一横已统一补成“——”，“——”被识成“一—”“—一”处未改；半角 ( ) , ; : ? ! 紧邻汉字处已改全角；《美国散记》中的英文歌词保留半角标点；“一九一○年”等年份里“〇/○”写法不统一；“（选自《人生采访》）”个别处缺右括号，已补；常见错识有“涅”（应作“浬”）、“缜缅路”（应作“滇缅路”）等，把握不足的未改。逐页识别稿中“萧乾”无误，整册稿（full.txt）曾把它简化成“萧干”，本整理依逐页识别稿。PDF 第 99 页在整册稿中丢失，已据逐页识别稿补回。无缺页。
