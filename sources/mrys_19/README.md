# 千古一相：姜子牙

- 底本：汪鹤年著《千古一相：姜子牙》（“中国名人轶事丛书”之十九，吴洪激主编），武汉大学出版社、台湾汉欣文化事业有限公司联合出版，1995 年 11 月第 1 版（版权页如此；序、后记署 1994 年）。文字由扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：共三十一页——丛书出版缘由、主编絮语（吴洪激）、正文二十八节（飞熊降世至马前泼水，书中以章回式短题各成一节，各占一页）、后记。各页只有一节，节名取页标题；书中无“一二三”小标题。
- 去掉的内容：封面、丛书介绍、CIP 与版权页、插图页、目录页、页眉（章题）、页脚（页码与“千古一相姜子牙”）、书末丛书编审委员会名单与丛书广告页、OCR 水印页；出版缘由与主编絮语文末的署名（吴洪激）。主编絮语文末“一九九四年冬日编余随记”、后记文末“一九九四年十月”保留。
- 段落：书的一行即一段；跨页断开的段落已接合。诗词、对联、歌谣用“诗：”居中，一联一行（撒帐歌后六行按原书每句一行）。
- OCR 已知问题：页脚页码与页眉常与正文粘连，已用脚本剥除（包括粘在行首/行尾的阿拉伯数字，正文原无阿拉伯数字），可能有漏剥或误剥；个别单字孤立行（如“之”“日”“山”“卜”“七”）判为噪点删去，其中个别可能是真字被切断（如第四页“偏／又不见一点动静”之间被删一“大”字，原稿“偏大又不见”疑为“偏偏又不见”之类），个别段首残留噪点字（如“亚韩升道”）；“后记”标题在 OCR 中缺失，据目录补；“妲己”偶被识作“妲已”；“……”“——”可能有误识；第十六页“其..”处按原样保留；页内“原：”段落是否应与前后行合并，凡一行末无句号而下行接续者均按跨页续行处理，诗词判定为脚本规则（五言、七言整齐联），可能有漏判。
