# 胡也频小说经典

- 底本：胡也频著《胡也频小说经典》（“中国现代小说经典文库”，阿宏主编，全套十二卷），印刷工业出版社，2001 年 3 月第 1 版第 1 次印刷，ISBN 7-80000-413-9/I·11。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：前言一页，其后二十篇小说各一页（《到莫斯科去》《光明在我们的前面》两篇较长，页内按书中的数字小节分节，节名即书中的编号；《家长》《猫》《小人儿》《傻子》《他和他的家》同样按编号分节）。书中无分辑，故页分组为空。
- 去掉了：封面、扉页、版权页（CIP 数据、定价、印数）、目录页、页眉“胡也频小说经典”、页码、封底及空白装饰页。
- 小节编号：书中每个编号是居中印的数字，OCR 常漏识。按版面补回的有：《到莫斯科去》的“一”（篇首）和“一一”，《光明在我们的前面》的“一”（篇首）、“一一”“二二”，《家长》《猫》《小人儿》《他和他的家》《傻子》的篇首“一”。“一〇”原印作“一0”，已写作“一〇”。
- 篇名：《毁灭》《傻子》的标题在 OCR 中漏识，据目录和版面补回。书里目录页把若干篇名截短（如“光明在我们的前”“小小的旅”“不能忘的影”），页标题以各篇正文标题为准；《不能忘的影》正文标题即如此，未补字。
- 标点：汉字旁的半角 `( ) , ; : ? !` 改全角；段末孤立的“.”“..”（实为“。”“……”）与上一行接成一段并改为“。”“……”。《到莫斯科去》中“Red Wine!”内的英文标点保留。
- 分段按版面缩进和行尾判断，个别页面倾斜处可能误分或漏分。
