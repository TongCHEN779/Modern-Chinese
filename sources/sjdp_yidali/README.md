# 世界短篇小说精品文库·意大利卷

- 底本：柳鸣九主编、吕同六编选《世界短篇小说精品文库·意大利卷》，海峡文艺出版社，1996 年 8 月第 1 版，ISBN 7-80534-882-0/I·777。文字由书籍扫描件（PDF）经 OCR 识别、整理而成，**尚未逐字校对**。
- 结构：第一页柳鸣九《总序》，第二页吕同六《编选者序》，其后每篇小说一页（页标题为篇名，页的作者栏为作家名），共 56 页、43 位作家、54 页小说。书中原按作家出生年代排列；每位作家的“作家作品简介”原印在该作家最后一篇之后，这里移到该作家第一篇所在页，作为第一节“作者小传”。每篇译者署名原印在篇末，这里统一放到该页正文第一段，写作“（某某 译）”。
- 特殊处理：①《故事两篇》是萨凯蒂两篇各有标题的故事，拆成《抢红袍》《花匠代替修道院长》两页，同署“吕同六 译”（原书只在第二篇末署名）。②曼加内利《微型小说五篇》保持一页，五篇以书中的编号“七、二十三、二十五、五十八、九十四”各为一节。③《切帕雷洛先生临终忏悔记》《抢红袍》《花匠代替修道院长》篇名下的内容提要，保留为各页译者署名后的第一段。④篇内以“＊＊＊”“ＸＸＸ”分隔的段落，统一写成“＊　＊　＊”一段。⑤夏侠《一个简单的故事》篇末署“沈萼梅译 刘锡荣校”，写作“（沈萼梅 译　刘锡荣 校）”；其篇首引的迪伦马特题词保留为正文第一、二段。
- 去掉的内容：封面、书名页、版权页、目录页，页眉页脚与页码，页底脚注（正文里的脚注序号①②等一并删去），书末主编柳鸣九、编选者吕同六的简介页，以及末页的电子书水印信息。
- 目录核对：目录 53 个条目（含“故事两篇”“微型小说五篇”）与正文篇名序列逐一对上；书中序言称“四十二位作家五十七篇”，按目录统计实为 43 位作家，与序言说法略有出入，以目录为准。

## OCR 已知问题与存疑

- 自动按版面重建自然段：以首行缩进、行宽判断分段，跨页接续。书信体（《失落的信》《没有归还的一天》《出版社的阅稿人》中的信）、诗歌/歌词（《母狼》《省督来访》）、连续对话处的分段可能与原书略有出入，个别段落末尾缺句号处按版面断开（如《中国盒子》《芳妲》《一个德国人的假期》各一处）。
- 《船夫》《坎迪亚的末日》两篇原有“一、二、三”三小节，OCR 只识出了“三”，开头的“一”和中间的“二”未被识别；按版面空白位置（《船夫》第 233 页开头、第 240 页；《坎迪亚的末日》第 254 页开头、第 258 页）补回了小节名“一”“二”，边界是推定的。
- 《母狼》篇名 OCR 只识出“狼”，按目录作“母狼”；《芳妲》篇名 OCR 作“芳姐”，按目录改。
- 作家译名在书中前后不一：目录作“乌莱尔巴”，小传作“马莱尔巴”；目录“拉卡普利亚”、小传“拉卡普里亚”；“夏侠/夏·侠”；“蓬滕佩利/蓬藤佩利”；“玛拉伊妮/玛拉依妮”。作家栏一律照目录。
- 《抢红袍》“进人宫廷”改作“进入宫廷”（OCR 形近）。《红雨衣》一处段末引号 OCR 为“，改作”。《坎迪亚的末日》第 257 页（PDF 页）一处对话行在 OCR 中位置错乱，“我也／后来我再也取不回来了”前后的断句、引号可能不准。
- 外文词（如《黑象》中的 orang-outang、《调皮捣蛋的猿猴》中的拉丁语祷语）与个别连字符、半角标点可能有残缺。
- 没有发现整页缺失；《一个简单的故事》的译者署名在 OCR 中与正文末段连在一起，已拆出。
