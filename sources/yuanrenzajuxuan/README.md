# 元人杂剧选

- 底本：顾学颉选注《元人杂剧选》（中国古典文学读本丛书典藏），人民文学出版社，1956 年第 1 版，2017 年第 2 版（典藏本，据 1993 年增补本）。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：去掉封面、版权页、丛书广告、目录页与页眉页脚；收前言（一页）和杂剧十六种（《窦娥冤》至《陈州粜米》，每剧一页）。页标题用简名，页内按“楔子/第一折……/题目正名”分节；每剧首节（与页标题同名）收全名、作者行，以及书中标题处的注（剧本总说、作者小传，作题解与注）。科白、曲词各占一段（曲牌并入曲词段首），一个原书段落一行。
- 注释：原书的注集中印在每折之后（《窦娥冤》集中在全剧之后），编号 [n] 与正文标号对应；转换时按编号配对放回所属段之后。“楔子”标题上的注（说明楔子体例）作为该节题解。多数注首是原文词语，取为词语；没有明确词语或词语写法与正文不同的（如曲牌〔仙吕赏花时〕），取标号前的一小段正文为词语，解释照原样保留。含多处引文、站点会把它误拆成几条的注，用 `注原：` 行保持整条。
- OCR 已知问题：正文中的 7、9 等编号常被误识为 2（已按顺序对回）；少数标号漏识，其注靠词语找回所属段；个别注末尾的破折号被识丢，词语与解释之间靠推断分开；《救风尘》标题处未识出注释（该剧页首无题解与作者注）；书中人名、生僻字、元曲衬字偶有形近误识，未改。
