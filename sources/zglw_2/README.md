# 中国历代文论选（第二册）

- 底本：郭绍虞主编、王文生副主编《中国历代文论选》第二册（高等学校文科教材），上海古籍出版社，2001 年 10 月新 1 版（2003 年 5 月第 2 次印刷）。文字由书籍扫描件（PDF）经 OCR 识别、整理而成，保持识别稿的简体字形，**尚未逐字校对**。
- 内容：隋唐五代、宋、金、元四个时期的文论选篇（自王通《中说》至朱权《太和正音谱》），共 61 个条目，每个条目含一篇主选文及其注释与说明，其后的“附录”篇目（相关文献）附于同一页。
- 整理：去掉封面、书名页、版权页、总目录、页眉页脚与页码；各篇篇末的版本出处行（如“《四部丛刊》影明本……卷八”）从略。页 = 一个主选条目（页标题为“作者·篇题”，页的第三项分组为朝代“隋唐五代／宋／金／元”），节 = 一篇；主选文之后的“附录”各篇依书中顺序各为一节，节内第一行 `题解：` 写原书的作者行（如“〔唐〕杨炯”）。书中每个条目篇末的【说明】照原样放在主选文的节首，作 `题解：`。篇内的小标题（如《诗式》的“明势”“明作用”，《诗品》二十四品的品名，《录鬼簿》各作家名）另起一节。
- 注释：原书每个条目的【注释】集中在主选文之后，按正文中的注号放回所属段后（OCR 的注号多有错位，以注号序列与词语对照恢复），写作 `注：词语：解释`；原注以“词语——解释”起头的，词语取破折号前的词；一条原注含数个词语的保留为一条。注文较长、含“某某：……”引文而会被站点自动拆条者，用 `注原：` 一行一条。诗、诗体篇章（如《戏为六绝句》《论诗三十首》《诗品》）用 `诗：`，每段四句，句间以“/”分行。
- OCR 与整理处理：页码残片（混入正文行首、行末或夹在字间的数字、圆点）已清除，被页码隔断的段落已接上；`<`、`>` 误识的书名号改为《》，半角括号与标点在汉字旁改全角；个别标题 OCR 缺字，据目录和正文校正（《中说》《诗式》《诗议》《评论》《诗格》《词源》《文薮序》《应责》《词论》《诗史》《王直方诗话》；“与会吉甫论诗”改“与曾吉甫论诗”）；“令狐德菜”改作“令狐德棻”。
- 已知问题：（1）原书校勘小注、版本异同保留在括号内（“原作……，据……校改”），未做统一；（2）约 26 个注号在 OCR 中丢失，相应原注并入前一条注释；约 130 条注释的词语不在所属段原文里，主要是挂在作者行或小标题上的作者小传、品名注（如《诗品》各品名的注），以及词语因 OCR 错字（如“衰”识作“表”、“昧”识作“忘”）而对不上的条目，这类注释在页面上不挂到词语上；（3）注释中的破折号偶被识作“一”“—一”，致词语与解释未能拆开的条目，以注号前的原文末几字作词语、原注全文作解释；（4）个别段首被 OCR 吞字（如《与杜䜣论祁公墓志书》两段段首）或残留孤立字母，已删去残片，缺字未补；（5）诗品、论诗绝句等诗体段落按 OCR 行内标点切分，可能与原书分行略有出入；（6）OCR 错字（如“于”“子”“己”“已”、形近字）大量存在，只更正了把握极大者。
