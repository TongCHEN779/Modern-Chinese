# 围城

- 底本：钱钟书著《围城》，人民文学出版社“百年百种优秀中国文学图书”本，2000 年 7 月第 1 版（2001 年 2 月第 2 次印刷）。文字由扫描 PDF 经 PaddleOCR 识别、整理，**尚未逐字校对**。
- 收入：重印前记、序、正文九章（原书只以“一”至“九”标章）、附录（杨绛《记钱钟书与〈围城〉》，其小节编号“一”“三”及标题“钱钟书写《围城》”照原样作节名）。
- 去掉：封面、版权页、作者小传、丛书前言与书目、目录页、页眉页码、每页底部的脚注（作者自注、译注）及正文中的脚注序号。
- 整理方式：full.txt 把 43 个空白页的文字并进了相邻页的超长行，故改以 json 逐行识别结果重建；段落按行首缩进、行末标点与行长推断，个别段界可能有误。
