# 棋王

底本：阿城《棋王》，作家出版社，2000年7月第1版（“百年百种优秀中国文学图书”丛书）。

## 整理说明
- 保留：作者序、《棋王》《树王》《孩子王》三篇、“遍地风流”七篇（会餐、节日、炊烟、傻子、卧铺、树桩、周转，按“遍地风流”分组）。
- 去掉：封面、版权页、作者简介页、丛书前言、评委名单、丛书书目、目录页、丛书页眉、书末扫描信息页、页码与OCR噪点。
- 跨页断开的段落已接合；歌谣诗行逐行保留；《孩子王》中学生作文《我的父亲》的硬换行已并为一段。
- 小说内以“一、二……”分节；各篇首节为“一”（原书该处无编号，按序补）。

## 已知OCR问题
- 《树王》“二”（第63页，“第二天一早，我们爬起来”前）与《节日》“二”（第140页，“试枪的时候”前）的编号OCR漏识，按版面空行与序号推定补上。
- 《会餐》开头“音河往东流去”、《周转》“余阴市，人口百万余，数箭方围”等处有疑似OCR错字，未改。
- 多处形近字错（如“人/入”“简/筒”）未逐一改动；PDF约13页被OCR合并入前页，内容未缺。
