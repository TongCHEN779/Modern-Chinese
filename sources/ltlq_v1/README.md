# 从开端到柏拉图（劳特利奇哲学史第一卷）

- 底本：［英］C.C.W.泰勒 主编，韩东晖、聂敏里、冯俊、程鑫 译，冯俊 审校《劳特利奇哲学史》（十卷本）第一卷《从开端到柏拉图》，中国人民大学出版社 2003 年版（总主编［英］帕金森、［加］杉克尔，中文翻译总主编冯俊）。文字由扫描件经 OCR 识别，用 json 坐标重建行与段落，**尚未逐字校对**。
- 页面：总主编序、作者简介、历史年表、文献来源、导言、第一至十二章、名词解释、译后记，各占一页（共 19 页）。章内以书中小标题分节；章末“注释”“参考书目”为该页最后两节。
- 去掉的内容：封面、版权页、丛书简介、目录、页眉页脚、页边的原书（英文原版）页码、页脚脚注（含正文里的圈码）、第八章的插图（只剩图中文字残片，已删）、三种索引（主题、文献、专名索引，页码对应原书）。
- 小标题：居中的标题为一级节；非居中的小标题（如“巴门尼德的诗”“1. …”）若紧跟在一级标题后，则作为该节第一段保留，其余另起一节。个别重名节（如“结论”“导言”）未改名。
- 表格：历史年表按页拆成左右两栏（政治和宗教、艺术、科技、哲学），每行“年代　事件”，栏间全角空格；无年代的并列事件以全角空格起首。

## OCR 与整理的已知问题

- 历史年表由坐标自动对齐，部分行的年代与事件错位或并合（尤其是“艺术”栏的续表页）；个别年代的破折号丢失。
- 正文页码清理靠“与原书页码接近的数字”判定，少量嵌在词中的页码数字可能残留，也可能误删与页码相同的数字。
- 参考书目的条目编号靠规则拆分，少数条目并入上一条（如第三章缺 3.18、第八章缺 8.5 等）；个别小标题与条目粘连。
- 引文、数学式的缩进有时与段首缩进难分，个别引文被并入上下段或拆成多段。
- 第二章“1. …”“4. …”等带编号的论证条目、第十章“(1)…”条目保留为普通段落。
- 希腊文、拉丁文和外文人名、文献缩写保持 OCR 原样，空格丢失（如 HomericQuestions）和个别字形误识（如“思培多克勒”）未改。
- 导言首段“公元前347年”后的脚注号“1”已删。
