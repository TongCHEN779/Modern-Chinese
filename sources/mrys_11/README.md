# 一代名媛：王昭君

- 底本：宁发新著《一代名媛：王昭君》（“中国名人轶事丛书”之十一，吴洪激主编），武汉大学出版社、台湾汉欣文化事业有限公司联合出版，1995 年 7 月第 1 版（据版权页；书内主编絮语署“1994 年秋”）。文字由扫描件（PDF，读秀/安娜的档案来源）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：共三十一页——丛书出版缘由、主编絮语（吴洪激序）、第一至第二十九章，各占一页。本书无引子、后记；各章内无小标题，每页只有一节，节名取章名。
- 去掉的内容：封面、书名页、版权页（CIP 数据等）、空白页、丛书书目与广告页、目录页、页眉（“第×章 章名”）与页脚（“一代名媛王昭君”）及页码；书中插图页及其图下说明文字（插图说明与正文重复）；主编絮语文末的署名（吴洪激）；书末 Anna's Archive 水印页。主编絮语文末的“1994 年秋夜灯下编余随记”保留。
- 诗歌：书中穿插的民谣、山歌（如烟墩坪民谣、刘老伯的山歌、《劝猴歌》等）按原书分行，逐行用“诗：”居中显示。
- 段落按扫描版面的缩进重建（跨行、跨页的段落已接合）；半角“? : ; ( )”已改为全角。原书用字（如“象”“着”）不改。
- OCR 已知问题：个别单字错识与形近字（如“已/自”“王/玉”）未逐一校改；少数章名在页眉处识别有误，已按目录与章首校正；第三章与第二十一章个别页的正文被 OCR 逐行断开，已按标点接合，可能有接错处；页眉页脚残留的碎片字符（孤立字母、数字）已删，仍可能有遗漏；插图夹在段中处的杂字（孤立数字）已删；个别被页脚粘连的词（如“出现昭君”处）已据上下文复原。
