# 中国现代作家选集·丁玲

- 底本：《中国现代作家选集·丁玲》，杨桂欣 编，人民文学出版社、三联书店香港分店联合编辑出版，1987 年 4 月北京第 1 版第 1 次印刷（书号 10019·4084，字数 206,000）。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 结构：丁玲《为香港版选集写几句话》（一九八三年）一页；“作品部分”之“小说”七篇（《莎菲女士的日记》《松子》《一颗未出膛的枪弹》《我在霞村的时候》《夜》《在医院中》《杜晚香》）、“散文”九篇（《三日杂记》《诗人应该歌颂您》《我所认识的瞿秋白同志》《一个真实人的一生》《初到密山》《“牛棚”小品（三章）》《曼哈顿街头夜景》《似无情，却有情》《我是一棵小草》）；“资料部分”陈明《三访汤原》、冯雪峰《从〈梦珂〉到〈夜〉》、杨桂欣《记老作家丁玲》、宋昌琴《丁玲生平及著作年表》。每篇一页，页内小标题（《莎菲女士的日记》的各日日期，《夜》《在医院中》《初到密山》的数字节号，《杜晚香》《三日杂记》《我所认识的瞿秋白同志》《“牛棚”小品》《三访汤原》的小标题，年表的各年）各为一节。篇末的写作日期、“原载……”“选自……”出处行原样保留为末段；副题、作者名保留为首节首段。
- 去掉的内容：封面、扉页、版权页、作者照片及图注页、手迹书影页（PDF 第 13、14 页，OCR 为乱码）、目次、“作品部分”“小说”“散文”“资料部分”隔页、每页页码、页下脚注（《一颗未出膛的枪弹》《夜》《杜晚香》的词语注、《一个真实人的一生》的“本文为《胡也频选集》序言”注、《三访汤原》的编者注）及正文对应的圈码标记（①）和《一个真实人的一生》篇题后的星号。
