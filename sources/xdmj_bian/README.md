# 现代名家名作全集·许地山小说全集（卷1，彼岸与此岸之间）

- 底本：许地山著《许地山小说全集》（书名据版心；该册无独立扉页，册名取自孙中田序《彼岸与此岸之间》，OCR 文件夹名“彼岸与此案之间”的“案”为“岸”之误），《现代名家名作全集》卷1，中国作家协会创作研究部选编，时代文艺出版社，ISBN 7-5387-1419-7/I·。版权页年份未能从 OCR 读出，出版年未详。文字由书籍扫描件（PDF，470 页）经 OCR 识别、整理而成，**尚未逐字校对**。
- 体例：小说集，按书的目录一篇一页，共三十七篇（含《无法投递之邮件》《危巢坠简》等书信体小说）；书前孙中田序《彼岸与此岸之间》一页（页内小节“1、2、3”为书中序号，末节“注释”为书中文末所附七条注）。
- 整理：去掉封面、书名页、版权页、目录页、页眉页脚与页码、空白页；按逐页坐标重建段落（首行缩进、行宽判断分段，跨页接续）；篇末无其他附录。序文作者署名“孙中田”未单列。
- 页底脚注去掉：《换巢鸾凤》粤讴中六条方言词注（唔、我地、人地话、睇、噉、嘅），《女儿心》中“播外”一注；正文里的注号 ①—⑥ 保留。
- 小节号：《东野先生》《玉官》《女儿心》各章开头及部分小节号印作短横或被 OCR 漏识，据版面空行补回。补回处：《东野先生》“一”（篇首）、“二”（PDF 第 272 页首）、“三”（第 282 页中部）；《玉官》“一”（篇首）、“二”（第 345 页首）；《女儿心》“一”（篇首）、“二”（第 412 页首）。《玉官》版面上“二”之后紧接“四”，没有发现“三”的标题痕迹，原样不补（书中或本无此号，或标题缺失）。《换巢鸾凤》各节标题“一　歌声”等为序号加标题连排，中间空格为整理时所加。《无法投递之邮件》文末“本书编者附注”一段为原书所有。
- OCR 校正（把握极大者）：“红5字会”“5字徽章”改“红卍字会”“卍字徽章”（OCR 把“卍”识成“5”）；《玉官》“-般”改“一般”；若干散落的小圆点（如“这.两句话”“船上.去罢”）删去，“你有钱.你雇人”等处的小圆点改作逗号；半角括号、问号改全角。
- 已知问题：个别段末标点被 OCR 吞掉（行尾为整行宽时句号常漏识，如《换巢鸾凤》“常在疑信之间”后），未补；《商人妇》《无法投递之邮件》中“儿句”“步覆”等疑似错字原样保留；《换巢鸾凤》《解放者》中“W山”“若是W她”的“W”疑为 OCR 误识，未改；“射复”应即“射覆”，原样；《命命鸟》中“她满面都是鲜红色”与“因为绣枕褪色”之间书中版面另起一行缩进，据版面分作两段；《缀网劳蛛》开头诗与《枯杨生花》开头诗的分行以版面为准；序中引用的《醍醐天女》一段合为一段；《无法投递之邮件》各信“不能投递之原因”行保留为各信首段。
