# 末代名臣——张之洞

- 底本：彭友元著《末代名臣——张之洞》（“中国名人轶事丛书”之十，吴洪激主编），武汉大学出版社、台湾汉欣文化事业有限公司联合出版，1994 年 11 月第 1 版（版权页书名作《末代名臣张之洞》，书内页眉与主编絮语作《末代名臣——张之洞》）。文字由 Anna's Archive（读秀）扫描件经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：共十一页——丛书出版缘由、主编絮语（吴洪激序）、第一至第九章（太后垂青、提督学政、诤言回天、封疆大吏、巨赌醵金、石破天惊、舍君其谁、两湖化龙、垂老惊梦），各占一页。书中各章以“一、二、三……”为小标题分节，第一节无编号，节名取“一”。
- 去掉的内容：封面、书名页、版权页（CIP）、目录页、页眉页脚与页码、Anna's Archive 水印页；出版缘由与主编絮语文末的署名（吴洪激）。
- 段落依扫描版面的缩进与行宽重建；书中的对联、诗词（缩进居中者）按每行一行，记为“诗：”。
- OCR 已知问题：
  - 个别单字错识（形近字，如“鹦鹉洲”“跃溪驹”处）与引号缺失/错位（“‘”“’”多余或缺）未逐一校改；少数“——”被识作“一”“—”。
  - 小节编号“二”在第一、二、三、四、六、七、九章的 OCR 中漏识，据版面空行位置补回；其余各章的编号均识出。
  - 引用的奏折、书信、报章等整块缩进文字，只按版面缩进/行宽重接；少数行末恰为句号处可能被误断成两段，少数短小的对句未被识别为“诗：”而按段落处理。
  - 第一章报章标题（“猴哥吃醋新娘惊魂”等）按段落处理，其前的单字乱码“洋”已删。
  - 半角“:”“?”等已改为全角；页眉页脚残留碎片已尽量删除，仍可能有遗漏。
