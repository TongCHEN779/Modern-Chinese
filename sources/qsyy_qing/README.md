# 清代历史演义全书

- 本书由大众文艺出版社“中国全史”丛书中的2册合并而成，共 100 页；各册整理记录如下。

## 第1册（tmp_qsyy_qing_1）

- 底本：（民国）蔡东藩著《清代历史演义全书》上册，大众文艺出版社“中国全史”丛书之一；年份不详（扉页、版权页均未见）。本册为全书第 1 册，收第一回至第五十回。文字由书籍扫描件（PDF）经 OCR 识别、整理而成。
- 整理：每回一页，页标题为正文里每回开头的回目（上下联之间一空格）；回数连续，第一回至第五十回不重不漏。每回末原有的评语保留，作为该页最后几段。回末套语原样保留；官样谕旨等引文、诗词按版面缩进、行宽分段。
- 去掉的内容：封面、书名页、目录页（目录页含全书一百回的目录，本册只含前五十回）、“中国全史”“清代历史演义全书”页眉、页码、版权页与封底。
- 回目改字：第二十一回“除大熟冲人定计”据文意改作“除大憝冲人定计”。
- OCR 已知问题：个别形近字误识未逐一更正；第一回评语“史乘-于”处的“-”、第三回“不.追”处的“.”为噪点，已删去；第三十八回评语末的孤立噪点“女”已删。评语段落的划分按版面缩进判断，个别处可能与原书略有出入。

## 第2册（tmp_qsyy_qing_2）

- 底本：（民国）蔡东藩著《清代历史演义全书》下册，大众文艺出版社“中国全史”丛书之一；年份不详（扫描件无版权页年份）。本册为全书第 2 册，收第五十一回至第一百回。文字由书籍扫描件（PDF）经 OCR 识别、整理而成。
- 整理：每回一页（p001–p050），页标题为正文里每回开头的回目（上下联之间一空格）；回数连续，第五十一回至第一百回不重不漏。书中无序跋附录，故无其他页。去掉封面、丛书页眉“清代历史演义全书”“中国全史”、页码、版权页与责任编辑信息。回末套语与回末评语（如有）原样保留；诗词、对联、谕旨、条款按版面分段或分行。
- 段落依 OCR 行坐标重建（缩进处另起段，跨页接续；两侧缩进的引文块按块合并）。
- 条款与名单：第八十回（俄约七条）、第八十五回（马关条约五条）、第九十一回（辛丑和约十二款）、第九十八回（宪法信条十九条）里每条各为一段，条序号与正文之间补全角空格；其中第八十回“四”、第八十五回“一”、第九十八回“一”“二”四处条序号 OCR 漏识，据影印页补回。第九十六回黄花冈烈士名单为多栏排版，按行排成若干段，同一栏内的人名 OCR 连在一起，未能逐个分开。
- 个别 OCR 漏字据影印页补回：第五十一回“略称：“义律等自津回南”处补开引号，“嗣又接到伊里布奏本，据说：“与英人订休战约，愿还我定海”等语。”一句 OCR 漏识后半，已补。第九十六回两副对联各折成两行，已并作一段。
- 已知问题：OCR 无整页缺失；少数行尾句号漏识（如第五十三回“悬梁自尽”后）、个别引号缺失，原样保留。繁体异体字多数保留书中原字（如“乾”“藉”“徵”），仅将明显的繁体残留（如“訢”作“䜣”、“還”作“还”）改为简体。
