# 世界短篇小说精品文库·日本卷

- 底本：柳鸣九主编、高慧勤编选《世界短篇小说精品文库·日本卷》，海峡文艺出版社，1996 年 8 月第 1 版（5 月版权页，8 月第 1 次印刷），ISBN 7-80534-884-7。文字由书籍扫描件（PDF）经 OCR 识别、整理而成，**尚未逐字校对**。
- 内容：柳鸣九《总序》、高慧勤《编选者序》各一页，其后三十九篇小说各一页（共 41 页），涉及二十九位作家；页的第三项为作家姓名（序言两页标“序言”）。篇名序列与书的目录逐一核对一致。
- 整理：去掉封面、版权页、目录、页眉页脚、页码、脚注（及正文里的脚注序号①②等）。自然段按版面首行缩进重建，跨页接合；对话每段另起一段。篇内“一、二、三”“上、中、下”等小标题各为一节；译者署名原印在每篇文末，已移到各篇第一段，写作“（某某 译）”，署名名字按目录（目录与文末 OCR 不一致时取更可能的写法，如“赵乐甡”）。
- “作家作品简介”：此书把作家小传与作品简评合成一段“作家作品简介”，印在该作家**最后一篇**译文之后（不在之前），已按书的位置放在该页最后一节，节名用原标题“作家作品简介”，未挪到作品之前，也未改称“作者小传”。同一作家若有多篇，简介印在其最后一篇之后（例如芥川龙之介的简介印在《竹林中》之后，川端康成的在《水月》之后，森鸥外的在《高濑舟》之后），其余各篇无此节。
- 页标题：与目录同；《黄漠奇闻》书中篇名下有副题“——幻想曲”，页标题写作“黄漠奇闻——幻想曲”。
- 小标题：《袈裟与盛远》“上”“下”两部分之内各有一个版面小标题“独白”，节名写作“上　独白”“下　独白”以区分；篇内以“※ ※ ※”类符号分隔场景处（OCR 作“* X *”，见《锻刀记》《秋山图》《女诫扇绮谈》），统一以“＊　＊　＊”一段保留。
- 数字小节标题的补回：OCR 把印成“一”的小节号（在版面上是一横）漏掉，因此《该隐的后裔》《带着孩子》《地狱变》《蜘蛛之丝》《拿破仑与疥癣》《伊豆的舞女》《志贺寺上人之恋》《浓雾中的卡莱莉雅》开头的“一”，以及《该隐的后裔》《带着孩子》《蜘蛛之丝》《黄漠奇闻》里个别漏识的节号，是依版面位置（标题应占的空行）和前后顺序补出的；《黄漠奇闻》开头“一”之前有一段楔子（朋友讲故事的框架），节名用页标题。
- 小节号疑似缺：《拿破仑与疥癣》四、六之间（对照影印页确无“五”标题），《浓雾中的卡莱莉雅》四、六之间（OCR 未见“五”，未对照影印页），原样按有的标题分节，未补。
- 外文及译名：人名、作品名译名与旧译用字原样保留；OCR 繁体字残留已转简体，半角标点在汉字旁改全角；书名号中 `〈 〉` 一律统一为 `《 》`，并补了个别脱漏的书名号（《地狱变》《秋山图》各一处）。
- 已知问题：
  - 个别句末标点被 OCR 漏识，因此少数段末无句号（如《黄漠奇闻》十三节“大吃一惊”）。
  - 个别段落可能因行尾漏识而在中途断开（如《源老头儿》中篇一处、《水月》两处、《黑衣》若干处，下一段首字缺漏之处不另标）；遇此未补写。
  - 《麒麟》中一处空引号“……”原 OCR 为“”，据影印页补为“……”。
  - 篇内版面空行（场景转换而无标题的空行）未保留，相邻段落直接连接，如《梦的时间》《圣家族》《黑衣》《浓雾中的卡莱莉雅》。
  - 《竹林中》“多襄丸”“老妪”（OCR 作“多里丸”“老枢”）、《秋山图》“拜观《秋山图》”等个别明显字形错误已更正。
  - 无缺页；各篇起止页以书的目录页码核对无误。
  - 版权页字数 584.4 千字，本整理稿约 45 万字（不含脚注、目录、版权页），差别主要在脚注与排版空白。
