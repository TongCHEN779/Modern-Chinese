# 包身工

- 底本：夏衍著《包身工》，解放军文艺出版社，2000 年 7 月第 1 版（“百年百种优秀中国文学图书”丛书）。文字由书籍扫描件（PDF）经 OCR 识别、整理而成，**尚未逐字校对**。
- 整理：共八页——《包身工》（1936）、《〈包身工〉余话》、《从〈包身工〉所引起的回忆》，以及书中“补录”的《劳勃生路》《旧家的火葬》《“四一二”之后的上海》《走险记》《〈新华日报〉及其他》。
- 去掉的内容：封面、书脊、版权页（CIP 数据）、作者简介页、丛书前言与评委会/编委会名单、丛书书目、目录页、末尾 Anna's Archive 水印页、页眉页脚与页码、每页底部的脚注（含正文里的脚注序号①②③）。
- 段落：OCR 稿里个别页面（如《〈包身工〉余话》中引用的调查记录与报纸来信、《〈新华日报〉及其他》中引用的报道与电文）是按版面逐行断开的，已对照原始逐页识别的行位置合并为自然段；引文是否分段按版面推断，个别处可能与原书略有出入。《新华日报》一章中的《献词》诗行逐行各成一段。
- OCR 已知问题：引号偶有残缺或错位（如“包身工’生活”“粢米饭’”一类单引号残留）；“一”“—”在对话开头处可能互相混淆（《走险记》中以破折号引导对白处）；个别形近字未改。全书无漏页，页码连续（OCR 稿中若干页码标记因版面合并而缺失，内容均在）。
