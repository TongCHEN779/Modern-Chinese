# 穆旦诗集（1939—1945）

底本：穆旦著《穆旦诗集（1939—1945）》，人民文学出版社“百年百种优秀中国文学图书”丛书，2000年7月第1版（原书 1945 年自印）。含献词、诗五十八首（题）、附录王佐良《一个中国诗人》（原载伦敦 LIFE AND LETTERS，1946 年 6 月号）。

整理说明：
- 分三页：p01 献词，p02 全部诗作（每首一节，诗行逐行一段），p03 附录。
- 去掉：封面、版权页、作者小传页、丛书前言/评委/书目、目录、页眉页脚页码、末页水印说明。
- 诗行依 OCR 逐行识别结果（json）分行，不分节，诗内小序号（（一）（二）等）保留为单独一行。

已知 OCR 问题：
- 《合唱》第二部分序号 OCR 为“其”，据上下文改为“二”。
- 第 71–72 页（书页 53–54，起句“告诉我们和平又必需杀戮”）与第 84 页（书页 66，起句“海波吐着沫溅在岩石上”）两首诗的标题 OCR 缺失，目录行也丢失，故节名写作“（无题）”。
- 个别诗行在 OCR 中被合并为一行（如《合唱》其二、《从空虚到充实》（三）、《神魔之争》若干处），诗节空行均未保留。
- 《五月》诗题旁多出的数字“1”已删；个别繁体字（黃、躪、虛、覆等）按 full.txt 校正。
- 未见整页缺失。
