# 苏轼诗词选

- 底本：陈迩冬选注《苏轼诗词选》（中国古典文学读本丛书典藏），人民文学出版社，2017 年版（CIP 2016）。内含《苏轼诗选》（1957 年初版，1983 年再版）与《苏轼词选》（1959 年初版，1985 年增订）。文字由书籍扫描件（PDF）经 OCR 识别整理，尚未逐字校对。
- 结构：诗选（前言一至六、再版告读者、二百四十九题，按目录顺序相邻成组，每页约 28 题，页标题为“首题—末题”）；词选（前言一至七及附言、八十五首，每页约 28 首）。pages.json 第三项分“苏轼诗选”“苏轼词选”两部。
- 去掉：封面、版权页、丛书广告、目录页、页眉页脚、页码、书末注释区的页码。
- 题解：原书每首诗词之后的编年与说明，放在节名之后的“题解：”里；原书中夹在两首之间的说明（如《渔父》四首共用的一段）也并入该节题解。词的“其二、其三”之类小标题并入下一段段首；诗中分题（北亭、轩窗、馈岁、别岁等）同样并入段首。
- 词的节名：有词题的作“词牌·题名”（词题很长或带序的，取其首句作题名，全文另作该节第一段）；原书无词题的作“词牌·首句”。“（选二首）”之类按目录保留。
- 注释：原书的注释集中在书末（诗 [1]–[1483]，词 [1]–[505]），按正文里的 [n] 标号放回所属诗词段后。原注自带“词语：”的照搬；没有词语的（如“这两句写……”）在前面补上标号前的一小段原文作词语，共约 780 条。个别注释含有“……。某某：”式的长段，若按 `注：` 拆分会被拆碎，用 `注原：` 保持一条（约 205 条）。
- 诗行：OCR 稿把整首诗连成一行，按标点拆成句，四句左右为一段，句间用 `/`；词按句（。！？）拆行、一阕或半阕为一段。诗句里夹着的作者自注（如《初发嘉州》末“是日，期乡僧宗一，会别钓鱼台下”）能识别的单列一段，其余的仍留在诗段内；半角逗号、分号、问号、叹号在汉字之后的改作全角。
- OCR 已知问题与处理：
  - 前言注释标号 OCR 有误（“[2]”应为“[7]”“[9]”），按顺序对应；
  - 个别标号 OCR 漏识：诗注 323、779、1305、1343、1434 及词注 229 在正文中找不到位置，挂在前一标号所在的段尾；诗注 1071、1354、1355 与词注 203、206 按词语在近旁定位；
  - 《中隐堂诗》第二首首句“二月惊梅晚，幽香此地无”在 OCR 稿里错排进上一首的末行，已按诗意移回；
  - 个别诗题的首行在整理稿里漏识（如《十二月十四日夜微雪，明日早往南溪小酌至晚》），据版面补回；
  - 《屈原塔》《画鱼歌》《安州老人食蜜歌》《涪州得山胡次子由韵》的题下自注（“屈原塔在忠州……”“湖中道中作”“赠僧仲殊”“山胡善鸣，出黔中”）单列为该节第一段；《吾谪海南》题目的后半部分（“子由雷州……作此诗示之”）同样单列；
  - 目录里个别字 OCR 有误，节名据正文改正（“上算子”作“卜算子”，“阻关曲”作“阳关曲”）；目录与正文异体字不同的（蒋颍叔／蒋颖叔、于潜／於潜）依目录；
  - 少数词的阕间空格识别丢失，段落拆分只能按句数均分，不一定落在阕界上；
  - 诗中夹注、注释里零星的 OCR 错字未改（如“万人鼓嗓”应为“鼓噪”）。
