# 中国古代名家诗文集·韩愈集

- 底本：《中国古代名家诗文集·韩愈集》，（唐）韩愈著，黑龙江人民出版社，2005 年 8 月版（2005 年 11 月第 1 版，2009 年 1 月第 2 次印刷），单册。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成，字形取简体，**尚未逐字校对**。
- 整理：共 25 页。“韩愈简介”（取自封面、封底的作者简介）、“总序”（编者的丛书说明）各一页；正文按书的卷次各占一页：诗集卷一至卷十二（12 页），文集卷一“赋杂著”、卷二“杂著书启”、卷三“书”、卷四“序”、卷五“哀辞祭文”、卷六“碑志”、卷七“碑志”、卷八“杂文状表状”（8 页），文外集“上”“下”（下为《顺宗实录》卷第一至卷第五）、集外文“附录”各一页。诗集卷一至卷三的卷次据书前目录补定（正文里这三卷的卷次大号数字 OCR 未识出），卷四以下据正文卷次数字。pages.json 第三项分作“诗集”“文集”“文外集”“集外文”四组。
- 节：一首诗或一篇文为一节，节名即书中标题（长标题在版面上断成数行的已接成一行）。诗用 `诗：`，OCR 稿里一首诗是连排的一段，按标点拆成诗行（以 `/` 分行），每四句一段；诗的标点保持原样，未补标点。文（含序、赋、碑志、《顺宗实录》）用 `原：`，一个自然段一行。诗前所附小序（如“送汴州监军俱文珍”“元和圣德诗并序”“石鼎联句诗”“郓州溪堂诗并序”等）写作 `原：` 段，置于诗前。组诗有分题的（“题张十一旅舍三咏”“祖席”“游城南十六首”“奉和虢州刘给事使君三堂新题二十一咏并序”“琴操十首并序”“疑伪诗三首”，及文中的“五箴五首并序”），归为一节，各分题写作 `原：分题名` 置于各首之前；琴操各篇之下的题注（如“孔子之赵闻杀鸣犊作。”）紧随分题。“与鄂州柳中丞书”后的“又一首”、“与大颠师书”“进士策问十三首”“杂说四首”“潮州祭神文五首”“袁州祭神文三首”中的“其一、其二……”小标题，也写作 `原：` 短行置于各篇之前。同一页内重名的节名（卷四“春雪”、卷四“序”页的“送王秀才序”）后一个加“（二）”区分。
- 去掉：封面与封底宣传语中的插图诗（简介页末的“蜂蝶去纷纷……”一首，与正文“花岛”重复）、版权页与 CIP 数据、书前目录、页眉“中国古代名家诗文集”“韩愈集”与页码、插图。书中无注释，无校记。

## OCR 已知问题

- 书中诗题、篇题常为字间疏排的二字题，OCR 漏识或拆开了若干处，据原书页面图或目录补回：夜歌（PDF 第 42 页）、苦寒（第 43 页）、朝归（第 137 页）、龙移（第 57 页）、射训狐（第 51 页，OCR 作正文短行“射训狐。”）、泷吏（第 127 页，目录亦漏）、原鬼（第 153 页）、讳辩（第 163 页，目录有）、通解（第 362 页）；“幽怀”“杏花”“春雪”（卷四第一首）“记梦”“鸣雁”“叉鱼”“庭楸”“原性”“本政”“画记”等 OCR 把两字拆成两行或颠倒，已还原。诗题后另起一行的“并序”（孟东野失子、送张道士）已并入题名。
- “其一、其二”一类小标题 OCR 只识出“其”“二”“三”等残片：“其”补作“其一”，单字“二”“三”补作“其二”“其三”；“潮州祭神文五首”的“其二”“其三”与“袁州祭神文三首”的“其三”整行漏识，据版面行距与各首起句“维年月日……”补回标题。
- 目录与正文对勘后更正的少数题名：路傍堠（OCR 作“路傍喉”）、寄卢仝（OCR 作“寄卢全”）、入关咏马（OCR 作“人关咏马”）、禘祫议（OCR 作“禘夹议”）、三器论（OCR 并入小字“事文类聚本”，该小注另置为首段）。“送齐皞埠下第序”按书中印刷原样保留（目录作“送齐皞下第序”）。“祭女挈女文”“女挈圹铭”中的“挈”疑为“挐”，OCR 一律识作“挈”，原样保留。
- 低置信的孤立字符、页边噪点（单个字母、孤立单字“综”“喻”“多”“零”“沙”“注”“求”等）已去掉；个别误识的符号（如卷五“赐じ跳踉”、卷八“应P乎府”中的 P）与圆点“·”已清除或保留，凡不确定处保持原样。诗文正文里的形近错字及 OCR 漏识的生僻字（如“气寒鼻莫”“高愁斗魁”等处）没有逐一校补，OCR 丢失标点处不补。
