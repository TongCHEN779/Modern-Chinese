# 中国神话世界（上编）

- 底本：王孝廉著《中国神话世界（上编）——东北、西南族群创世神话及其文化》，洪叶文化事业有限公司，台北，2006 年 1 月初版一刷（增订版；原名《中国的神话世界——各民族的创世神话及信仰》，1987 年首版）。文字由书籍扫描件（PDF，426 页）经 PaddleOCR 识别、整理而成（繁体识别后转简体），**尚未逐字校对**。
- 结构：按书的目录分页。序（萧兵）、增订版序（王孝廉）各一页；第一篇（东北族群）四章、第二篇（西南族群）七章各一页，章号在两篇里重复，所以页标题保留“第×章”，篇名放在 `pages.json` 第三项；附录一、二、三各一页；书末“参考文献资料”一页。页内的“一、二、三……”节标题照目录；各节下书里还有一些无编号的小标题（如“满族简述”“始祖卵生”“摆手祭”，以及排成三行的“(1)猎人头”之类），按字号大小、单独成行识别，另起一节，**节名都取自书中原文**。
- 去掉的内容：封面、版权页、目录页、页眉页脚与页码、**页脚脚注**（每页底部的注，凡小字号者；书里没有章末集中的注释）、正文旁的图片说明（多以“〔……〕”开头）、书末的图版页（第 426 页，纯图）和“台湾土著民族分布图”整页（第 278 页，地图标注）。第 192、219、401 页里夹在正文中的插图及其图注（藏族本教指路经、水书、西番历书等图）整块去掉。
- 表格：“五、附表”的四张表（人口分布、语言系属、文字类型、民族自治地方）及第五章的“台湾土著族类各家汉文命名对照表”、台湾高山族始祖传说的“简表”，按纵坐标分行、各栏用全角空格隔开，一行一段；单元格里折行的文字常被识成单独的一行（如“京和内蒙古等省、市·自治区”接在上一行的分布地区后），个别行的栏目有错位（如附表中“侗佬族”“土家族”“黎族”几行的分布地区）。
- 页内排版：正文旁绕图排的窄栏、整页的歌谣（每句一行、各成一段）、缩进的引文块，都按版面位置分段；引文块与随后正文之间的分段依缩进判断，个别地方可能并段或错断。页末与页首的断句已跨页接上。
- 标题：目录里的破折号（OCR 多脱落）按全书写法补回；“氐羌”（目录、页眉间或识成“氏羌”）统一为“氐羌”；第二篇第四章第四节“仫佬族、毛难族与黎族的创世神话”，OCR 识成“嬷佬族”“儕佬族”，据三个并列的民族小标题改作“仫佬族”（小标题“佬族”也补作“仫佬族”）。
- OCR 已知问题：
  - 顿号“、”常被识成间隔号“·”（如“陈梦家·闻一多”“二·《史记索隐》”），句号“。”偶被识成“·”；全书“·”大多原为顿号，但书名号内（《山海经·海外东经》）、外国人名（列维·斯特劳斯）里的是真间隔号，所以未做全局替换，仅把段末的“·”改回“。”。
  - 括号、书名号的左右常不配对（如“〈释王制〉”“（夷夏东西说〉”“《民间文化）”），“著/着”“衹/只”等沿用原书字形，未动。
  - 正文里的脚注序号（上标数字）多数已按页底注的编号去掉，仍可能有个别残留（如段末“……所化。7”、行中夹的小数字）；正文里本来就有的数字与序号相混处也可能误删。
  - 生僻字、古文字、外文（拉丁字母、日文、西夏文、纳西文）识别不稳，如“窦窳”“槃瓠”“牠”等沿用 OCR 结果。
  - 第 14、18、74、116、182、204、250、346、378、394 页为空白页，无内容。
