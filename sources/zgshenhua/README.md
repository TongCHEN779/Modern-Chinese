- 页内排版：正文旁绕图排的窄栏、整页的歌谣（每句一行、各成一段）、缩进的引文块，都按版面位置分段；引文块与随后正文之间的分段依缩进判断，个别地方可能并段或错断。页末与页首的断句已跨页接上。
- 标题：目录里的破折号（OCR 多脱落）按全书写法补回；“氐羌”（目录、页眉间或识成“氏羌”）统一为“氐羌”；第二篇第四章第四节“仫佬族、毛难族与黎族的创世神话”，OCR 识成“嬷佬族”“儕佬族”，据三个并列的民族小标题改作“仫佬族”（小标题“佬族”也补作“仫佬族”）。

## 下编（并入，页号 p18–p32）


- 底本：王孝廉著《中国神话世界 下编：中原民族的神话与信仰》，洪叶文化事业有限公司，台北，2006 年 1 月初版一刷（增订版；上编见 `zgshenhua`）。文字由书籍扫描件（PDF，477 页）经 PaddleOCR 识别、整理而成（繁体识别后转简体），**尚未逐字校对**。
- 结构：本编没有序言和分篇，按目录分页：第一章至第十章各一页，附录一（神话与诗）、附录二（神话研究的开拓者）、附录三（我的神话学历程）、“王孝廉先生著作年表”、“增订重编后记”（钟宗宪）各一页，共 15 页；`pages.json` 第三项统一写“下编：中原民族的神话与信仰”，便于并入上编。页内的“一、二、三……”“（一）（二）……”及书中无编号的小标题（如“盘古氏”“湘妃”“胚胎”“鹊桥”“夸父”“刑天”）各另起一节，节名取自书中原文；章内“之一、之二……”小节、“追记”“附记”也各成一节。
- 去掉的内容：封面、版权页、目录页、页眉页脚与页码、**页脚脚注**（每页底部的小字注，含脚注序号）、正文旁的图片及图注（多以“〔……〕”开头，如各类画像石、版画）、图中文字碎片。第 429—430 页（书本页 420—421）末附“参考书目”三条小字注按脚注处理，未收。
