- 书中图（石膏模型、乐器图、画法示意图等）未收；篇末“本文附图均从略”等原有说明保留。

## 整理时的处理

- 篇名以目录为准：目录与正文篇名在 OCR 中有出入处按文意取字（如“鼓山庋藏经版目录序”“蕅益大师年谱草稿序”“绍兴开元寺募建殿堂疏”“《韩偓评传》序”）。《“不行”》一篇正文标题 OCR 只识出““不”，《罪过》《漫语》《呼冤》标题的字距过疏，据目录补齐。《丢了三个》目录标题被截断，据正文标题。
- 小节号漏识补回：OCR 漏掉了印作一道短横的“一”，按版面空行（版面上该处有一个与标题间距相同的空档）补回：《高尔基及其他》开头的“一”；《改过实验谈》“总论”前的“一”；《我在西湖出家的经过》“我第一次到杭州”前的“一”；《南闽十年的梦影》“我第一回到南闽”前的“一”和“讲到这里，顺便将我个人对于僧教育的意见”前的“二”；《弘一大师最后一言》“这一次所要讲的”前的“一”；《石膏模型用法》第一种石膏模型前的“一”（该段首行行首补“一”）；《养正院亲闻记》后跋末尾署名“弘”后补“一”（据别篇署名“弘一”）。
- 表格与示意图：《图画修得法》中“图画之效力”表和“图画之种类”图（原为树状图，OCR 打散）、《水彩画略论》中“水彩绘具”对照表，按版面坐标重排为行，各栏用全角空格隔开，栏次以版面为准；其中法文色名拼写（如 Blane、Grance、Ronze）保持 OCR 原样；“明冶十年”据文意改作“明治十年”。《西洋乐器种类概况》等篇中“附图”说明文字原样保留。
- 引诗引词：章衣萍文中引录的词（《记濮文昶的词》《记石鹤舫的词》）书中按版面折行，整理时并为一段；短行诗句（《糟糕的《国语文学史》》《感叹符号与新诗》《护生画集》跋偈语等）逐行成段。
- 半角 `( ) , ; : ? !` 在汉字旁改为全角；页首“二”“（一）”等小节号统一用全角括号。书中原有的〔〕［］改字注（如“咀〔诅〕咒”“己「已]”）原样保留。

## OCR 已知问题

- 全书未对照影印页逐字校对，仍有形近字误识（如“二钟”应作“二种”、“鸣呼”应作“呜呼”、“韩屋”应作“韩偓”、“薄益”应作“蕅益”等）和个别异体字、生僻字被换作常见字；未逐一更正。
- 个别行尾 OCR 漏识一两个字、缺行：如《弘一大师最后一言》“才能达到艺术的最”后缺“高境界”之类；《辛丑北征泪墨》中原书的“□”缺字保留；《弘一大师最后一言》“假如诸位用一张白纸……他一定说：‘善哉，善哉”后引号漏识。
- 《图画修得法》中“土佐派……”一图的各条旁注（“传自支那，颇多变化。今所存者，厥有数派。”等）位置按版面相邻关系排列，归属是推定的。
- 《近世欧洲文学之概观》末的“编者按：此文原有多章……”原样收入。
- 页面缺失：无正文页缺失（PDF 第 4、14、16、124、278–281 页为空白页或隔页，未收）。
