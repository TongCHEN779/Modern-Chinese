# 大唐李白·少年游

- 底本：张大春著《大唐李白：少年游》（《大唐李白》第 1 卷），广西师范大学出版社（理想国），2014 年 1 月第 1 版。简体版据台湾新经典文化 2013 年繁体版授权。文字由书籍扫描件经 OCR 识别、整理而成，**尚未逐字校对**。
- 结构：代序（《一首诗，能传几条街？》）、《为〈大唐李白〉简体版所写的一篇序文》、题词（李白《少年行》二句）、正文五十七章（按书目录，章号用书中的“一、二……一〇、一一……”，页标题为“章号 章名”）、附录《小说家不穿制服——张大春对谈吴明益》，共 61 页。章内无小标题，每页一节。
- 去掉的内容：封面、书名页、版权页、目录页、页码、页脚水印；正文末页（“第一卷完”及其后的广告/下一卷预告页，OCR 为乱码）；附录末页的数据库水印。
- 诗句：书中单行排的诗句每行一段；连排的整首诗（五、七言）在每句末（。！？；）处断行，每行一段；杂言诗（《笑矣乎》《敕勒川》《悲平城》《越鸟从南来》《来日一身》《我眼之碧》《木可为羊》）同样在句末断行。引用的散文、契券、赋文按一段处理。
- 整理时的取舍：
  - 第一章、第十一章的章号在 OCR 与目录里都漏识，据序号补成“一”“一一”。
  - 《简体版序》末尾有一页（致谢，“如果世上还有任何业余的文学读者……”）后半被图章/手迹干扰，OCR 为乱码，只收前两段，附在该序之后；该页标题缺失，未另立页。
  - 附录对谈各段开头的人名（“吴明益”“张大春”）原无冒号，整理时补了全角冒号；对谈最后“不要忘记，小说家和制服在本质上是矛盾语。”一段、吴明益简介和“本文由……供稿”说明按原样保留。
  - “题词”页的页名为整理者所加（书中无标题）。
  - 第四十一章末句“至于薛稷”与第五十二章中段“此外，还有谢朓”为书中原文的断句（OCR 与版面均如此），未补。
  - 第四十四章一处诗句后接破折号的行文（“……蚁绿染僧衣——‘罪过！’”），破折号挪到了下一段开头。
- OCR 已知问题（未改）：
  - 第六章章名“锈涩碎心人”、第十三章章名“一医医国任鹪鹩”据目录与标题行一致照录，疑有形近字误（待对照影印页）。
  - 正文中仍有零星形近字（如“规樵”应为“规模”之类）、个别半角标点（?、!、'）；句末半角“？”“！”已改为全角，其余未动。
  - 书内诗句的断行（尤其连排诗）是按版面缩进与句读推断的，个别可能有误；少数 OCR 把引号错识为单引号。
  - 页内版面（缩进、行宽）推断分段，个别一段被拆开或并连在所难免。
