# 新月诗选

- 底本：陈梦家编《新月诗选》，解放军文艺出版社 2000 年 7 月版（“百年百种优秀中国文学图书”丛书，据 1931 年上海新月书店初版重排）。文字由书籍扫描件经 OCR 识别、整理而成，**尚未逐字校对**。
- 结构：序言一页；其后每位诗人一页（共 18 页，页标题为诗人名），页内每首诗一节，诗行逐行一段。
- 整理时去掉：封面、版权页、出版说明、丛书前言、评委名单、丛书书目、目录页、各诗人的分隔页（仅有人名的竖排页）、页眉页脚页码、杂散符号，以及诗末页脚的编者注（《沙扬娜拉一首》“沙扬娜拉，日语再会”、《薄暮》“‘亮圆’苗语月”）。
- 已知问题与处理：
  - 书中两字诗题在 OCR 里多被竖排拆成两行且字序时有颠倒，已按诗意还原（如“消息”“死水”“雨景”“回答”“情愿”“灵奇”“瓶花”“默示”“薄暮”“当铺”）；“有忆”（朱湘）的字序按推定。《火车擒住轨》OCR 作“禽”，据诗意改为“擒”。
  - 个别诗题与首行或副题被 OCR 并为一行（《我等候你》《洵美的梦》《我欢喜你》《她那颗小小的心》《大帅》等），已按推定拆开；《洵美的梦》《我欢喜你》等首行是据上下文复原的。
  - 部分诗行因版面或 OCR 被并行、断行位置与原书不一定相同（如《我等候你》《哈代》《奇迹》《想望》《生辰哀歌》《无题》（沈从文）等），个别并行的引语按“”分行。《最后的坚决》的叠句交错排列，OCR 顺序保持原样；破折号“一”误识处只改了一处。
  - 序言原有的一、二等序号 OCR 中缺失，仅留“三”，故序言分为“序言”“三”两节，“三”之前的内容连作一节。
  - 缺页：PDF 第 48、59、73、81、89、101、113、133、164、165 页在识别稿中为空，应是各诗人分隔页或空白、图版页，未发现正文缺失；诗人分隔页只有人名且识别不全，人名据序言与目录补定（“朱大柟”沿用目录写法，版权页简介作“朱大根”）。
  - 编者序言提到选入“八十首”，本稿实得 81 首，诗题与篇数以识别稿为准。孙大雨的长诗《自己的写照》未入选集。
