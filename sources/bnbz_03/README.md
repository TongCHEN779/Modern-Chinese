# 二十年目睹之怪现状

- 底本：吴趼人著、张友鹤校注《二十年目睹之怪现状》（“百年百种优秀中国文学图书”丛书），人民文学出版社 2000 年 7 月第 1 版第 1 次印刷（据 1958 年起的校注本，书前有舒芜 1958 年 11 月所作《前言》）。文字由书籍扫描件（PDF）经 OCR 识别、整理而成，**尚未逐字校对**。
- 结构：前言一页，其后正文一百零八回各占一页（页标题为“第N回 回目”，回目上下联以空格隔开；第一回为“楔子”）。共 109 页，约 54.7 万字。
- 去掉的内容：封面、版权页、作者小传、丛书前言与丛书书目、目录页、页眉页脚、页码、每页底部的校注者脚注（正文里的脚注序号①②…也已删去，各回末没有集中注释）、书末 Anna's Archive 水印页。保留了舒芜《前言》（其中的“三”“四”为原有的小标题，见下）。
- 段落依据 OCR 行框坐标重新接合：跨行、跨页的段落已接上，缩进处另起段；插入的书信、诗词、灯谜等缩进引文按行宽判断断行，诗词引文一行一段或接成整段不一定与原书完全一致。
- 标点：OCR 里的半角 `( ) , ; : ? !` 在汉字旁的改成全角；英文单引号 `'` 按位置改成 ‘ 或 ’（OCR 多把引号里的引号识成 `'` 且常漏掉开头的 ‘，所以全书仍有少量单引号不成对，且对话里“他道：我……”这类处原书的引号标记多已丢失）；个别孤立的 OCR 杂点（如“à”“·”）已删，《》括号被识错的几处（如“《四裔编年表)”）已改回。

## 已知问题（OCR）

- 第三十一回中间原书有一幅折纸示意图（PDF 第 313 页，OCR 只识出“第一折”“第二折”“反面”之类标注），图和标注已删去，正文“图如下：”之后直接接下文。
- 第七十四、七十五回的灯谜单（《论语》《孟子》《西厢》谜面）是带省略点的表格式排版，OCR 把部分编号、省略点识丢，个别条目（如“……药名一”“(三)四………”）残缺，保留原样。
- 前言的小标题：OCR 只识出“三”“四”两处（第一处位置在原书第 8 页，疑是“二”被识成“三”，其前后的“一”“三”等编号 OCR 漏识），按 OCR 原样保留。
- 书中有少量形近误字、漏字，除把握极大的以外未改；旧式用字、标点照底本。
- 个别页面的行内杂符、脚注序号错位可能还有漏网；全书未逐字校对。
