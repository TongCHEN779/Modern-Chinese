# 啼笑因缘

- 底本：《啼笑因缘》，张恨水著，中国青年出版社“百年百种优秀中国文学图书”丛书，2000 年 7 月第 1 版（据北京出版社 1981 年版排印）。文字由书籍扫描件（PDF）经 OCR 识别、整理而成，**尚未逐字校对**。
- 结构：严独鹤序、作者自序（各一页）；正集二十二回（每回一页）；《作完〈啼笑因缘〉后的说话》（作者创作谈，一页，分四节）；续集作者自序一页、续集十回（每回一页）。页标题用书中回目。
- 整理时去掉：封面、版权页、作者小传、丛书前言/评选委员会/丛书书目、目录页、每页页眉（回目或书名）与页码、扉页式的“续集”题页、OCR 附带的页末水印说明。回末“下回分解/交代”原样保留；回末诗句逐行成段。
- 整理方式：段落据 OCR 行框的缩进与行长判断分段，跨页段落已接合；页边的散落噪点（单个数字、字母、孤立汉字）已删。个别 ASCII 标点按上下文改为全角（“?”“.”“(”“)”），少数明显误识（如“·个”“-块”作“一”，“—一”作“——”）已更正，其余保持原样。
- 已知问题：
  - 正集第十九回报纸新闻、第二十回信件、续集第五回“订婚启事”等版式特殊处（窄栏、竖排式排版）只按行序合并，续集第五回启事由人工按语义重排为“订婚启事／正文／署名”，可能与原版式略有出入。
  - 第一回“先是由东边进来的，这且由西边出去，一一过去，却见一排都是茶棚”一句，OCR 行内次序错乱，已按文意重排并补标点。
  - 若干 OCR 形近字或漏标点可能存在（如“己/已”“末/未”），未逐一核对；个别引号可能错配。
  - 严独鹤序标题年份、作者自序标题年份在页眉中识别不全（“一九三○年”被识成“一九三年”），本整理未单列。
  - 全书页数完整（PDF 共 492 页，未发现漏页），暂未发现整章缺失。
