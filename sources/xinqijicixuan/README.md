# 辛弃疾词选

- 底本：朱德才选注《辛弃疾词选》（中国古典文学读本丛书典藏），人民文学出版社，2016 年第 2 版（初版 1988 年）。文字取自该书 PDF 的文字层（PDF 第 4195–4611 页），不是 OCR 稿：OCR 稿在词文里整行漏字、错序较多，文字层完整，且版式信息（字号、颜色、缩进）可靠，因此以文字层为准，OCR 稿只用来核对与补缺字。**尚未逐字校对。**
- 结构：前言（一至四，附 30 条脚注）；编年部分 139 首（p02–p06，每页约 28 首）；未编年部分 29 首（p07）——全书共选词 168 首；附录《词评辑要》（p08）、《行年事略》（p09，按年分节）。页标题为该页第一首至最后一首的节名。
- 节名：词牌，有题名者写“词牌·题名”；词前有小序（长序）的，节名只写词牌，小序放作该词首段。正文每阕一段，句间以 `/` 分行。
- 题解：每首词后的“简评”整段放作“题解：”；原书标在词牌、题名上的注释（标号在题上）也放在“题解：”里，排在简评之前。原书附录的他人原唱、和作（杨济翁、韩元吉、陈亮、姜夔、张镃）作为单独的节，节名取书中“附：……”字样，不带注释（韩元吉原唱题上有 1 条注，放在其题解里）。
- 注释：原书的注释集中在“编年部分”和“未编年部分”各自的末尾（两部分的标号各自从 [1] 起），这里按正文里的 [n] 标号放回所属那一阕（或小序）之后；一条原注含多个词语（如“‘千里’两句：……千里渥洼种：……”）的，拆成多条 `注：`。原注没有明确词语的，用标号前的几个字作词语（如“注：改今名：此闲居带湖之作。”）；后续解释若其词语不在本阕原文里，则沿用该条前一部分的词语。前言的 30 条脚注同样按标号放回段后。
- 去掉：封面、版权页、丛书广告、目录页、页眉页脚、页码。
- 文字处理：
  - PDF 文字层里的繁体异体、拉丁字母形 `ɡ`（拼音里的 g）已改作通行写法：`馀`→`余`、`煕`→`熙`、`侘胄`→`侂胄`；其余生僻字（如 檃栝、鴂、籋、簶、鸂鶒、溰溰、斸、緉、賸、鵩、薆、劄、昚）照书。
  - PDF 文字层里有约 50 处生僻字没有文字（只有字形图），按书页图像辨认后补入（檃、緉、艣、斸、賸、籋、鴂、溰溰、顗、鵩、薆、簶、藦、鸂鶒、鍧、橅、萝等）；“叮当”原字形为口旁加当，作“叮当”；注释里“哢（lòng）”后的同音字字形不清，作“弄”。
  - 有 2 处注释里的生僻字未能辨认，以 `〓` 占位：《洞仙歌·开南溪初成赋》注里“一本题作‘所居〓山为仙人舞袖形’”的〓；《踏莎行·赋稼轩，集经句》注里“乐（‘〓’的借省，‘〓’即‘疗’，治也）饥”（《诗经·陈风·衡门》）的〓（疒旁加“乐”）。
  - 前言里的引词、词评里的括注出处（如“（刘师培《论文杂记》）”）各占一段；前言引词按阕拆段，句间以 `/` 分行。
- 已知问题：
  - 词中各句的分行（`/`）按句号、问号、叹号拆开，而不是按词谱的句读，故每段里的句子长短不一。
  - 个别注释标号对应的词语在原文里位置略有偏移（按词语在本阕原文中首次出现处定位，少数词语在同一阕里出现多次）。
  - 《词评辑要》各条评语与其出处（括注）并列为段，未合并。
