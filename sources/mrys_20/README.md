# 绝色美人：西施

- 底本：熊文祥著《绝色美人：西施》（“中国名人轶事丛书”之二十，吴洪激主编），武汉大学出版社、台湾汉欣文化事业有限公司联合出版发行，1995 年 11 月第 1 版（CIP 数据页与版权页均作 1995.11；丛书其余各册多为 1994 年，此册以本书版权页为准）。文字由 Internet Archive 的扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。书名：封面作“绝色美人 西施”，CIP 作“绝色美人：西施”，meta 取后者。
- 整理：共十七页——丛书出版缘由、主编絮语（吴洪激序）、正文十五章，各占一页。本书没有“第×章”编号，十五章各以一句古诗词为题（目录页即如此），页标题与章题同；章首另有一两句引诗作题词，以“诗：”居中。章内无小标题，故整章只有一节，节名同章题。
- 去掉的内容：封面、丛书编审委员会名单、版权页与 CIP 页、图书馆章、Internet Archive 水印页、目录页、页眉页脚与页码、书末丛书广告页；插图页及其图说（图说文字摘自正文，如“西施有些饥渴……”）；出版缘由与主编絮语文末的署名（吴洪激）；乱码的末页（见下）。主编絮语文末的“1994年冬日记于古城黄州”保留。
- 段落依据 OCR 逐行坐标（缩进、行宽）重建，页眉页码按坐标剔除，跨页接合；序文两页用 OCR 整理稿（full.txt）的分段。歌谣、诗句（第二章“鸟鸟啊”歌谣，第四章“妾浣纱兮”歌，第六章《蓼莪》句，第十一章“高田种小麦”“桐叶冷”等）按原书每行一句，同一节用“/”分行连成一个“诗：”；书中整段缩进的曲词、颂辞（第三、六、十四章）按一段处理。半角“?”“;”“( )”已改为全角；阿拉伯数字保持原样。
