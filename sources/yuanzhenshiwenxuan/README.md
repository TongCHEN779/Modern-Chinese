# 元稹诗文选

- 底本：杨军、文笙、吕燕芳选注《元稹诗文选》（中国古典文学读本丛书典藏），人民文学出版社，2004 年第 1 版、2017 年第 2 版。文字由书籍扫描件（PDF 第 3559–4175 页）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：去掉封面、版权页、目录页、丛书书目与广告、页眉页脚页码；收入前言、诗选（164 题）、文选（7 篇）、小说《莺莺传》、附录《元稹谱略》。书中注释本在各部分之后集中排列（诗选、文选、小说各自编号），整理时依正文里的 [N] 标号放回所属诗节（诗每四句左右一段）或段落之后；每篇首条注释（标在题目上的）放在“题解”。题下的小字自注（如“此后并是学士时诗”）以“题下小注：”收在题解里。《哭吕衡州》《六年春遣怀》等选篇保留书中的“其二”“其四”等小标题。
- 注释写法：原注有明确词语的写作“词语：解释”；原注是“某句”“某二句”或没有词语的，取标号前的一小段原文作词语，注文照录。注文里含引文并分条的，用“注原：”一行保持完整。
- OCR 已知问题：
  1. 元稹自注在书中夹在诗行中间（小字），OCR 无法区分，现混在诗句里，个别诗节因此多出几句（如《酬乐天待漏入阁见赠》《酬翰林白学士代书一百韵》《和李校书新题乐府》《望云骓马歌》《酬乐天东南行诗一百韵》等）；个别诗节的行序被 OCR 打乱（如《空屋题》）。
  2. 少数题目与题下小注被 OCR 截断（如《君莫非》题下“此后九首和李”后半缺）；《寄吴士矩端公五十韵》《酬乐天思不尽加为六韵之作》的标题是从上一首末尾拆出来的。
  3. 个别注号 OCR 有误（已按顺序校正编号），极少数注释找不到对应标号，放在该篇相近的段后（约 5 条的词语不在所属段里）。
  4. 诗分段（四句一段）为整理时的划分，非书中分段。
