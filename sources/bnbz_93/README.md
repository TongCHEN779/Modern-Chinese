# 红高粱家族

- 底本：莫言《红高粱家族》，百年百种优秀中国文学图书丛书，南海出版公司，2000 年 8 月第 2 版（原版 1987 年解放军文艺出版社）。
- 结构：五章（红高粱、高粱酒、狗道、高粱殡、奇死），每章一页，章内按书中“一、二、三……”分节。

## 整理时去掉的内容
封面、版权页、丛书前言、评选委员会与书目页、作者简介、目录、页眉页脚页码；章末/书末无其他附文；页底作者脚注（第二章两处）及正文中的脚注序号“①”；OCR 噪点（孤立的“*”“X”“1”等）。跨行、跨页断开的自然段已接合。

## 已知问题
- 各章第一节的序号在底本中不印，OCR 亦无，节名统一写作“一”。第一章中的“二”“三”两节序号 OCR 未识别，其内容并入“一”（第 19–38 页，即首节之下，至“四”之前）；第四章“二”节序号同样未识别，并入“一”（第四章开头至“三”之前）。
- 第一章第 20 页“开枪开炮”处，OCR 把句末标点识成“1”，已改为“！”。
- 繁简、异体字保持底本 OCR 原样，OCR 形近字错误（如“高梁/高粱”混用、个别“己/已”）未做系统校改。
- 段落接合依据行末有无句末标点判断，个别跨页段落可能被误断或误并。
