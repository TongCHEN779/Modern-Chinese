# 李自成（第6卷）

底本：姚雪垠著《李自成》第六卷，中国青年出版社、学习出版社，2019年9月第1版（“新中国70年70部长篇小说典藏”丛书）。

整理方式：按书中章次分为 30 页（第一章至第三十章），页标题即章号，章内不另分节；目录所列七个部分（甲申初春、梦江南、北京！北京！、崇祯皇帝之死、李自成在武英殿、招降失败、决计东征）记在 pages.json 第三项作分组。

去掉的内容：封面、版权页、作者简介、出版说明、丛书编委名单、目录页；每页页眉（“新中国70年70部”“长篇小说典藏”“李自成·第六卷第N章”）；页脚作者脚注及正文中的脚注序号；书末明代紫禁城平面图、丛书书目、扫描说明页。页首页尾被切断的段落已接合。

已知问题：
- 全书为 OCR 文本，存在零星错字、漏字、半角标点（如“?”“!”）及个别乱码；仅更正了把握极大的几处（如第三十章“沉沉人睡”改“入睡”）。
- 约 170 页的原文按窄栏逐行识别，已按行末标点和行宽推断合并为段，个别段落的分合可能有误（尤其是整行恰为满行且以句号或引号结尾处）。
- 部分诗联、对联（如第十九章大明门对联、第三十章洞房题诗）保持分行。
- 页脚脚注按序号规律去除，页内脚注序号 OCR 异常处可能有极少残留或误删；未发现整章缺失，各章顺序完整（1–30）。
