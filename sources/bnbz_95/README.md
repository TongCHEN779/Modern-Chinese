# 余光中诗选

## 底本
《余光中诗选》，余光中 著，刘登翰、陈圣生 选编，中国青年出版社，2000 年 7 月第 1 版（“百年百种优秀中国文学图书”丛书之一）。据 OCR 整理稿（逐页识别结果）按诗分节，全书 6 页：四卷各一页（卷前·大陆时期、卷一·台湾前期、卷二·香港时期、卷三·台湾后期），另有选编者《“钟整个大陆的爱在一只苦瓜”——〈余光中诗选〉编后》与《二〇〇〇年版后记》各一页。每首诗一节，诗行逐行一段。

## 整理时去掉的内容
- 封面、版权页、丛书前言、评委与编委名单、目录页、丛书书目、末尾空白与扫描信息页，以及页眉页脚、页码。
- 选编者加的诗末“注：”“编者注：”（《羿射九日》《沙浮投海》《旅人（片断）》《凝望》《湘逝》）；编后文章页底的脚注（①②…）及正文中的脚注号。
- 目录中“（以上选自《某某集》）”之类分集标记（正文中本无）。
- 作者自己的诗末“附注/附记/后记”（如《敲打乐》的自注、《欢呼哈雷》《向日葵》等的后记）保留在该诗末尾，《蜀人赠扇记》后的流沙河《读〈蜀人赠扇记〉》作为附录另成一节。

## 结构说明
- 组诗的总题未单列，只列各分题：歌谣两首（清道夫、插新秧）、天狼星（选三）（古龙吟、多峰驼上、天狼星变奏曲）、垦丁十九首（选七）（大尖山、银梦海岸、浪淘沙、山海瀑、风剪树、蟛蜞菊、青蛙石）、三生石（当渡船解缆、就像仲夏的夜里、找到那棵树）、玉山五题（至尊、回声、青睐、拉库拉库溪、石之午梦）、母难日（今生今世、矛盾世界、天国地府）。
- 诗题以书中目录与正文互校为准：双字标题正文中竖排拆行、顺序错乱者（如“思/沉”“感/灵”“火/浴”“马/唐”）按目录改回；《蟛蜞菊》正文标题 OCR 作“蜞菊”，目录作“膨蝶菊”，依两者校定为“蟛蜞菊”；《绝色》正文标题只识别出“绝”字，按目录补“色”。
- 页内诗行按逐行识别结果保留，诗节间的空行未保留；个别因版面过宽而折行的长诗行（如《羿射九日》“刺我以白热的镖枪，/而又轰笑着……”）仍分作两行。
- 副题（如“——济慈逝世百卅二周年纪念”）保留为诗的首行；其破折号 OCR 作“一”或单“—”的（《沉思》《下次的约会》《梅花岭》《踢踢踏》）已统一为“——”；《踢踢踏》中 OCR 作“木展”者改回“木屐”。
- 《民歌》中 OCR 把上下两行叠排的“醒/梦”“哭/笑”识别成合并框（“醒梦”“哭笑”），已拆回“醒也听见”“梦也听见”“哭也听见”“笑也听见”。

## OCR 已知问题
- 无整页缺失，未发现整首漏识别；但个别行首单字漏识别，例如《民歌》第二节第二行只剩“也听见”（行首疑缺一字），其余未逐一核对。
- 一般形近字错误未改，仅记几处明显者：《沉思》“震顾”（应为震颤）、《敲打乐》“蜗迹烘”一行识别置信度低，疑有误；《旅人（片断）》“(一旅人背包蹒跚上)”的“一”应为标点残留。
- 《欢呼哈雷》首行 OCR 作“-Hail Halley,”，保持原样。
- 编后文章中引用的诗句（如“即使在爱奥华的沃土上……”）按引文分行，各占一段；其后的出处括注“敲打乐》”仅剩半个括注，原样保留。
