# 寄小读者

- 底本：冰心著《寄小读者》，中国青年出版社，2000 年版（“百年百种优秀中国文学图书”，根据“希望书库”1996 年版排印）。文字由扫描件经 OCR 识别、整理，未逐字校对。
- 结构：写信代序、四版自序，《寄小读者》通讯一至二十九（通讯二十七与二十八之间为《山中杂记》）；补录一《再寄小读者》通讯一至十四；补录二《三寄小读者》通讯一至十。各页以 pages.json 第三项分组。《山中杂记》按（一）至（十）分节，通讯十八按书中日期小标题分节，通讯二十五的诗《赞美所见》单列一节。
- 去掉：封面、版权页、作者简介页、丛书前言/书目/评委名单、目录、页眉页脚、孤立页码、“补录一”“补录二”等扉页，以及文末 Anna's Archive 水印页；通讯七中三个“X”分隔符、《山中杂记》（八）里算术题残留的零散数字符号也已删去。
- 版面处理：竖排窄栏造成的断行（引诗、引词）按标点和行长合并，短行诗句保持逐行；跨页断开的段落已接上；“冰/心”“你的朋友冰/心”被拆成两行的落款已合并。
- OCR 已知问题：英文诗行偶有空格、标点和大小写错误（通讯八、十三、十四）；通讯十六中左辅《浪淘沙》引词断行错乱（“魂一／片，招入孤舟”处），原样保留；个别生僻字或形近字（如“骗跹”应为“蹁跹”）未改；《山中杂记》（八）的算术题图式未能还原。未发现整页缺失（PDF 共 223 页，正文页均已识别）。
