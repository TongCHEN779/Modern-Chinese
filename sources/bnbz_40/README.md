# 呼兰河传

- 底本：萧红著《呼兰河传》，解放军文艺出版社 2000 年 7 月版（“百年百种优秀中国文学图书”丛书）。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：按书的七章加“尾声”各成一页（共 8 页），章内的“一、二、三……”编号各为一节。第二、六、七章开头一节书中未印编号，沿用页标题作节名。
- 去掉：封面、版权页（CIP 数据、定价等）、作者小传、丛书前言、评选委员会/编委会名单、丛书书目、“百年百种”扉页、页码。
- 书中第四章“团圆媳妇”一段、第七章末尾若干段每段开头带“（”，段末带“）”，系原书的括注写法，予以保留。
- OCR 已知问题：第一章原编号“二”重复出现，后一个按顺序改为“三”（第一章开头的“1”改作“一”）；第六章“失了形状”处页间断行已接上；几处页首的孤立杂点（“u.”“I”“3”及孤立字母）已删。未发现漏页、整章缺失；零星形近字错误未逐一校对。
