# 世界短篇小说精品文库·西班牙卷

- 底本：柳鸣九主编、许铎编选《世界短篇小说精品文库·西班牙卷》，海峡文艺出版社，1996 年 8 月第 1 版第 1 次印刷，ISBN 7-80534-885-5。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：序言两页（柳鸣九《总序》，1995 年 4 月 16 日；许铎《编选者序》），其后每篇小说一页，共 28 篇、19 位作者（含佚名《小癞子》）。页标题用篇名，pages.json 第三项为作者名（序言页为“序言”），作者名用书中译名写法。译者署名（原印在文末，如“杨绛译”）移作各篇第一节第一段，写作“（杨绛 译）”。
- 作家介绍：本书没有印在作品之前的作者小传，而是在**每篇小说之后**印有“作家作品简介”（兼介作者与该篇，文末署名如“（西宇）”）。整理时照原位保留为该页最后一节，节名“作家作品简介”，署名保留为该节末段。同一作者有几篇的，每篇各有一份简介（如塞万提斯、阿拉尔孔、伊巴涅斯）。
- 分节：小说自带“一、二、三”编号的，各编号另起一节，节名即编号（《烧炭夫村长》《一满网》《电车上的小说》《少夫老妻》《山之恋》《一桩好事》《在四百公里处》《星期六聚餐》首节为“一”）；《月光》先有一段引子文字，故首节用篇名，其后为“一”至“七”；《琴师佩雷斯》开头一段后即为“二”“三”“四”，原书这一篇未见“一”的标记，首节用篇名。《小癞子》分“前言”及“第一章”至“第七章”，章节名由章号加章题合成。小说里的“＊　＊　＊”分隔符保留为单独一段。《雨帘》中引用的民歌每行一段。
- 去掉了：封面、扉页、版权页、编委会名单、主编与编选者介绍、页眉页脚、页码、水印；**页脚译注（脚注）按体例全部去掉**，正文里的注码（①②等）一并去掉。书末 Anna's Archive 水印页也未收。
- 目录页 OCR 缺失（总序之后直接是编选者序、编委会），篇名与作者均据正文每篇首页的题名行识别；全书各篇皆从新页开始，篇数以篇末的“译者署名＋作家作品简介”对照为 28。

## OCR 已知问题与整理时的处理

- **缺页**：未发现篇内缺页；PDF 共 687 页，第 35 页（编选者介绍页，页首残缺）、第 687 页（水印）不属于小说。
- 《里加特舞厅》文末“作家作品简介”在 PDF 末页处截断（扫描件缺最后一页），OCR 稿止于“结果反落入他人圈套弄假成”，原样保留未补。
- 《幸福》（阿·玛·马图特）篇名 OCR 只识出“福”字，据书影及其简介改作“幸福”。皮康姓名里 OCR 的繁体字“奧”改作“奥”，其余繁简混杂处经 OpenCC 繁转简统一，仍可能有个别生僻字残留错字。
- **编号小节标记缺失**：原书的“一”“二”等节号（“一”印作一小段横线或方框，OCR 多半漏识）在 OCR 稿里常缺。我是按版面上下文行距（篇首标题后或段落之间出现明显空白）与前后编号顺序补回的，补回处：《烧炭夫村长》“一”；《一满网》“一”；《月光》“一”“二”；《电车上的小说》“一”“三”；《少夫老妻》“一”；《山之恋》“一”；《一桩好事》“一”“二”；《在四百公里处》“一”“二”；《星期六聚餐》“一”“二”。另《烧炭夫村长》“三”OCR 识成数字“2”，据顺序改回。位置据行距推定，未对照每页影印，个别可能略有偏差。
- 引号：原书的单引号‘ ’ 在 OCR 里有个别漏掉左半或右半（如《对手》“短命才子’”），原样保留；注码被识成“’”“1)”的少数几处（《嫉妒的埃斯特雷马杜拉人》“阿孙勃雷’”，《小癞子》“公差1)”，《一桩好事》“海蓝宝石’”，《不受赏识的艺术家》“福煦”1)”）已删。
- 《海上的得失》简介署名 OCR 作“(宇)”，据其余各篇同署“西宇”改作“（西宇）”。
- 段落据行首缩进与行宽重建，换页处接合；诗歌（《嫉妒的埃斯特雷马杜拉人》中的小曲、《山之恋》《雨帘》中的民歌）每行一段。少数短行（如整行引文、对话）可能被并入或拆开，抽查未见系统性错误。
- 《骗婚记》末尾转入《狗的对话》的标题“西皮恩和贝冈扎间的对话”，为本篇结尾原文，保留。
