# 风雪夜归人

- 底本：吴祖光著《风雪夜归人》，人民文学出版社，2000 年 7 月第 1 版（“百年百种优秀中国文学图书”丛书）。文字由书籍扫描件经 OCR 识别、整理而成，**尚未逐字校对**。
- 结构：全书为戏剧，页按剧本分：人物与地点（第 16–17 PDF 页）、序幕、第一幕、第二幕、第三幕、尾声，各占一页；每幕开头的“人物”表合并为首段“人物：……”。台词保留角色名并统一补上全角冒号“：”，舞台提示（〔……〕）独立成段。
- 去掉的内容：封面、版权页、作者简介、丛书前言、评委名单与丛书书目、目录页、页眉页脚页码、末尾 Anna's Archive 水印页。
- 整理：原稿每行是按版面折行的，按“〔”、角色名、短行句末等规则合并为自然段；OCR 把同一行里先后两位角色的台词连在一起处，按角色名切开；半角括号与 ! ? 改为全角；删除孤立的字母/数字噪点（如“J”“Y”“P”“T”及行首混入的“12”等）。
- 已知问题：
  - 折行合并与切分为程序规则，个别段落可能在台词与舞台提示交界处合并或切分有误。
  - 第一幕末尾幕终提示 OCR 为“一幕下”（他幕为“幕下”），原样保留。
  - 第二幕与第三幕个别地方出现单独一行角色名后台词缺失（如“魏莲生”后紧接另一人台词），原样保留，未补。
  - 序幕开头“序”“人物”表中的“病人即魏莲生”等原书为分行列示，已并入“人物”段。
  - 未发现整页缺失（PDF 页 18–157 连续）。
