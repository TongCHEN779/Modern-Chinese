# 傅雷家书

## 底本
《傅雷家书》（三联初版纪念本，“三联精选”丛书），傅雷 著，生活·读书·新知三联书店，2018年7月第1版（2021年3月第6次印刷）。OCR 底本为该书扫描件（非“百年百种”版）。

## 整理说明
- 按书的目录分页：一九五四年至一九六六年各一页（共13页），每封信为一节，节名为信首的写信日期；另有“附录1 赤子之心——傅聪谈傅雷（冬晓）”“附录2 范用与《傅雷家书》（傅敏）”两页。附录1内的小标题各为一节。
- 书中夹附的傅聪“音乐笔记”（1955年、1960年两处）保留在原位置，节名为“音乐笔记”；笔记内的小标题、分隔星号：小标题保留为段落，星号分隔符去掉。
- 去掉：封面、版权页、墨迹图版及说明、出版说明（编辑后记）、目录、页眉页脚、页码、每页底部的脚注及正文中的脚注序号〔1〕等、封底丛书广告与书评。
- 页边/跨页断开的段落已接上；“（甲盘）（乙盘）”两栏问题表按行排成段，栏间以全角空格隔开。

## 已知问题
- 原书第1–10页（pdf）为封面及墨迹照片，OCR 为乱码，已弃；pdf第45页（书第25页，一九五四年信，含“兰心斜对面……参观华东……美展预展”一段）full.txt 缺漏，改由逐页原始识别 json 补入，未经二次校对，可能有字句缺漏。
- pdf第200–201页（1961年2月5日信中夹附的丹纳《艺术哲学》“希腊的雕塑”译稿手迹影印页）OCR 全为乱码，整两页已删除，该信中可能因此缺一段文字。
- 页眉脚注、跨页脚注的剔除靠版面坐标判定，个别页可能残留脚注碎片或误删；个别正文行内的脚注序号被 OCR 为普通数字的已改（“市三1弹”“文章1是”），其余若有残留请对照原页。
- 少数日期标题（信首日期）与上一段正文被 OCR 连在一起，已按日期格式拆开；若有个别信首日期 OCR 错成别的字样，可能未被识别为节标题而并入上一封信。
- 附录2结尾处原书页下方的编者按语（“本文是范用辞世时傅敏撰写的纪念文章，初刊于《书痴范用》……”）作为脚注去掉。
- 外文（英、法、德文）和乐曲名因 OCR 偶有大小写、空格错误，未逐一校改；一般性错别字保持原样。
