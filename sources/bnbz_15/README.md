# 彷徨

- 底本：鲁迅《彷徨》，人民文学出版社“百年百种优秀中国文学图书”本，2000 年 7 月第 1 版（2001 年 11 月第 3 次印刷）。文字由书籍扫描件经 OCR 识别、整理而成，**尚未逐字校对**。
- 整理：题辞（《离骚》四句）一页，其后十一篇小说各一页，依次为《祝福》《在酒楼上》《幸福的家庭》《肥皂》《长明灯》《示众》《高老夫子》《孤独者》《伤逝》《弟兄》《离婚》。
- 去掉：封面、版权页、作者小传、丛书前言、评选委员会名单、丛书书目、目录页、页眉页脚与页码、书页边的杂点；每篇正文里的脚注序号（如“[1]”“〔3〕”）及每篇篇末集中的编者“注释”（该版为人民文学出版社编注，非作者自注）均未收入。每篇篇末的写作日期保留。
- 已知 OCR 问题：
  - 《孤独者》原有七节，节号只有“四”“五”两个被 OCR 识出并作为节名保留，“一”“二”“三”“六”“七”未识出，故未分节（整篇正文连续无缺）。
  - 《孤独者》第一页（p0100）的篇题行带有残留页码；其余各篇篇题均据目录核对。
  - 少数夹在行中的 OCR 杂字、杂点已依 OCR 置信度记录删去（如“孤线灯”“都祖母”“要他买东西”前的单字）；个别标点（如“<了凡纲鉴》”）已改为书名号，西文引文（《幸福的家庭》中的英语对话）的引号保留 OCR 原样。
  - 《高老夫子》中的聘书、《伤逝》中的解职通知，原为分行排版，已合并为段并保留“今敦请”“奉”等开头单行。
  - 未发现整页缺漏；各篇页码在 OCR 稿中连续。
- 原书注释已按站内格式（注：词语：解释）挂在所注段落后，注码已去掉；个别注释的词语位置为推定。
