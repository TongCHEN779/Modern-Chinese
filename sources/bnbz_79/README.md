# 四世同堂

- 底本：老舍《四世同堂》（上、下），人民文学出版社“百年百种优秀中国文学图书”，2000 年 7 月第 1 版（2001 年重印）。文字由书籍扫描件经 OCR 识别、整理而成，**尚未逐字校对**。
- 结构：序一页，其后按书的一百“段”各占一页（页标题即书中段号“一”至“一百”），分《惶惑》（一至三十四）、《偷生》（三十五至六十七）、《饥荒》（六十八至一百）三部。第一段在 OCR 稿中段号丢失，按顺序定为“一”。
- 去掉：封面、版权页、作者小传、丛书前言与书目、目录页、部标题页、页码、每页底部的脚注（北京土语、旧俗注释）及正文里的脚注标记。
- 版本说明：书中第八十八段至第一百段（共十三段）因中文原稿已毁，是据英译节译本 The Yellow Storm 由马小弥回译为中文，1982 年《十月》连载，收入本书时校勘过；文字风格与前面各段有别。这条注释原为页脚脚注，故未入正文，记于此。
- 序中“《偷生)，与(饥荒》”的括号、序里第 2、3 条的“字——”“部——三部”据上下文校正；其余未改。
- OCR 已知问题：个别断行造成的段落碎片已按“上一行无句末标点则并入”合并，少数段落可能误并或漏并；第七十五段末的一个孤立“中”字已删；第七十五段“土坯”处、第七十一段“教我也去当”与第八十六段“可是”之后疑有行末标点或文字丢失，原样保留。形近字、标点（半角引号等）仍有零星错误，未逐处更正。
