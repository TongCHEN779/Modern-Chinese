# 中国现代作家选集·卞之琳

- 底本：张曼仪编《卞之琳》（《中国现代作家选集》丛书），三联书店（香港）有限公司、人民文学出版社联合编辑出版，香港 1990 年 6 月第一版，32 开，ISBN 962-04-0813-6。原书竖排繁体；文字由 PDF 扫描件（297 页）经 PaddleOCR 识别、转简体后整理而成，**未逐字校对**。
- 整理：共 31 页。“份外附言”（卞之琳卷头语）一页；作品部份的全部诗作合为“诗”一页，每首诗一节；散文 10 篇、小说 3 篇（夜正深、海与泡沫、野猪田）、评论 8 篇各一页；资料部份（他人评论与年表）8 篇各一页。页标题与诗题按书中目次、正文标题定。“野猪田”页首的“篇前赘语”单列一节。
- 没有收入：封面、扉页、版权页、丛书介绍及作者小传简介（PDF 第 1—10、14 页）、照片页、手稿影印页（第 11 页《道旁》手迹）、目次（第 15—21 页）、“作品部份”“资料部份”隔页、末页电子书信息页；页码、页眉、各页下方的手迹影印图。
- 诗作：每个竖排栏为一行，不保留分节空行与缩进；诗末日期照排为末行；诗末作者原注（原书为带圈数字脚注）并为该诗末行“注：…”，注号及注与诗句的对应关系没有保留。散文、评论页末的小字注释并为页末“注”一节。

## 标点（重要）
OCR 对竖排文字几乎不输出逗号、句号等小标点。我用 PDF 扫描图对每一栏逐字格测量（行距分格，小标点占格、位置在格内右上），把 OCR 漏掉的 ，、。：；！？「」《》（）——…… 按位置补回，并与 OCR 所识字序对齐；约 4% 的栏（对齐失败，多为西文、手迹、小字页脚）保持 OCR 原样不补。已知偏差：

- 补回的标点个别可能错位一字，或漏补；顿号（、）与逗号（，）字形近，个别互混；引号、书名号个别漏补或成单个。
- 横画字“一”、破折号常被 OCR 漏识或错识（如《一城雨》“你总会觉得罢，一城雨”漏了“一”，年份“一九……”缺首字“一”），我只在日期行里把“，九三九年”之类补成“一九三九年”，其他处未改。
- 书中原有的圈码脚注标号被 OCR 识成杂字（如“）”“@”“D”“0”），已尽量删去，个别遗留。

## OCR 其他已知问题
- 简繁转换、形近字错识很多（如“蜜”“窰”“窑”，“村料”“才料”，“亮果厂”等），未逐一更正。第 94、121、148、158、163、245 页等页下方有手迹影印图，其 OCR 乱码已剔除；这些页可能缺字。
- 个别标题 OCR 有残缺，按目次与扫描图补全（如“一城雨”“煤窑探胜”“惊弦记：论乐”“漏室鸣”“海与泡沫”）；《海与泡沫》页末小注“*编总第二卷的又一章”字太小，OCR 残缺，原样保留。
- 年表（“卞之琳年表简编”）中“某某年某某岁”的年份小标题没有单列，与正文混作段落，部分年份、岁数 OCR 残缺（如“九1〇年”）。
- 《卞之琳论》页首“——中国现代作家选集，卞之琳编后”、其他页的副题“——……”按段落保留。
- 原书注释（p22《翻译对于中国现代诗的功过》）已按站内格式（注：词语：解释）挂在所注段落后，注码已去掉；个别注释的词语位置为推定（OCR 丢了注码的注释按内容或就近定位，实在定位不了的挂在该节末段）。
