## OCR 与整理的已知问题

- 页边原书页码、页眉的清理靠坐标判定，个别嵌在词中的页码数字或罗马数字可能残留，已查出的（如“早 XV期”“jx”）已手工改正。
- 历史年表由坐标自动对齐拆栏，个别折行条目可能并入上一条（如 1382 年），个别行年代与事件错位。
- 正文里的数学式、符号逻辑式缩进、排版有时丢失；引文块的缩进难与段首缩进区分，个别引文与上下段并合或拆成多段。
- 第十二章开头的诗句三行各为一段（“这永恒的光芒出自西格”等）。
- 第七章小标题“世纪初的四位大师”，OCR 脱了“12”（目录同），未补。
- 第五章 5.39、第六章 6.38 两条参考书目 OCR 中缺失；第七章 7.16、7.17 前有合并说明行；第十章参考书目起首有并列编号（10.3—10.8）。个别条目编号后多出的重复末位数字（如“17.43 3”）已删，仍可能有漏网。
- 外文（拉丁文、德文、法文、阿拉伯文转写）、人名与文献缩写保持 OCR 原样，空格丢失和字形误识（如“Aristotles Latinnus”）未改。
