# 传奇

## 底本
张爱玲《传奇》，中国青年出版社“百年百种优秀中国文学图书”，2000年7月第1版（根据人民文学出版社1986年版排印）。OCR 自该书 PDF（OCR 整理稿 full.txt）。

## 整理说明
- 按书内篇目分页：十页初版小说（《金锁记》至《封锁》，《沉香屑》两炉香各一页），原书附录《再版的话》，以及增订本增收的《有几句话同读者说》（含其后《传奇》增订说明）、《留情》《鸿鸾禧》《红玫瑰与白玫瑰》《等》《桂花蒸阿小悲秋》《中国的日夜》。每篇一页一节。
- 篇末的写作年月（如“(一九四三年十月)”）保留为单独段落。
- 去掉：封面、版权页、作者简介页、丛书前言、评选委员会名单、丛书书目、目录、扉页题词、页眉页脚碎片、OCR 乱码行、书末 Anna's Archive 水印页。
- 合并了断行和跨页的段落。《中国的日夜》中的两首诗逐行成段。

## 已知问题
- 个别篇名在 OCR 中残缺（《封锁》作“锁”、《留情》作“情”、《等》等），已按目录补正。
- 《琉璃瓦》中“结婚启事”框的文字 OCR 顺序已无法确定版式，整理为一段“熊致章　小儿启奎　为　结婚启事　姚源甫长女琤琤”，排列可能与原书不同。
- 《心经》《琉璃瓦》《红玫瑰与白玫瑰》《桂花蒸阿小悲秋》等篇末页有 OCR 乱码碎片，已删除；未发现整页缺失，但未逐页核对。
- “沉香屑 第一炉香”中“白石5字栏杆”的“5”疑为字母“S”，保留原样。
- 目录中《原书附录》《增订本增收》的层次在 OCR 中错乱，页分组依此大致对应。
