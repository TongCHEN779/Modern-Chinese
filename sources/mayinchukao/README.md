# 马寅初考

- 底本：梁中堂著《马寅初考》，中国发展出版社 2015 年 1 月第 1 版。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：按书的目录分页——作者自序一页，上篇九章、下篇五章、附录三篇各占一页，共 18 页；页标题用书里的章标题，上、下篇各章的编名记在 pages.json 第三项。上篇、下篇的篇首短文（出现在第一章标题之前）并入各自第一章的开头。
- 去掉的内容：封面、封底简介、版权页（CIP）、目录页、上篇/下篇/附录的篇题页、页眉（“马寅初考”“上篇马寅初事件始末”“下篇康生、陈伯达批判马寅初考略”“作者自序”“附录”）、页码、每页页脚的脚注，以及正文中的脚注序号（①②…）。本书无集中的章末注释。
- 无真正的表格。附录各篇为逐条的大事记、文章目录和杂志目录，每条一段；附录一的年份（1949年…1960年）、附录二的（一）至（四）类目、附录三的（一）（二）类目作为小标题另起一节。这三页的第一节即首个小标题，页标题不另设空节。
- 下篇第二、四章为分条的资料摘引加“略考”，摘引处原书是按行折行排印的小字，已按语意把折行接成整段。
- OCR 已知问题：折行接段靠“行末无句末标点则接下行”的规则，个别条目末尾无标点处可能误接或漏接；篇末分页处少数段落据标点接续，未对照影印页。第 25 页页脚与正文被识别串行，正文末句“毛、李工作室也……对外开放了”取 OCR 所存“对外开放了”，其间可能脱一两字。“马寅出”（附录二两处，应为“马寅初”）与目录“梳耙”（疑为“梳理”）按原样保留。其余错字、漏字未改。
