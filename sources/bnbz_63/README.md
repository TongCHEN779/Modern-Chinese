# 关汉卿

- 底本：田汉著《关汉卿》，作家出版社 2000 年 7 月版（“百年百种优秀中国文学图书”丛书）。文字由书籍扫描件（PDF）经 OCR 识别、整理而成，**尚未逐字校对**。
- 结构：全书为十二场话剧，页一为“人物”“时间”表，其后第一场至第十二场各一页，末页“代跋”（郭沫若来信与田汉复信，作者 1958 年 5 月）。
- 整理时去掉：封面、版权页、丛书前言、评选委员会与编辑委员会名单、作者简介、丛书书目、页码、末尾扫描来源水印。
- 剧本排版：每个自然段一行；台词按“角色名：台词”整理（原书角色名与台词之间无冒号，冒号为整理时所补，角色名“徹里·不花”统一写作“彻里·不花”）；舞台提示单独成段；剧中唱词按原书分行，每行一段。
- 未收入：书末三首“插曲”及《窦娥冤》选段的简谱页（约 PDF 第 114–125 页），OCR 把乐谱数字与歌词混杂成乱码，歌词无法还原；其中三支《沉醉东风》唱词已见于第十二场正文。
- 已知 OCR 问题：
  - 因 OCR 稿无法区分，台词接续行与舞台提示有时被合并为一段（如台词末行恰好排满时紧接着的舞台提示），已按版面缩进尽量拆开，仍可能有个别合并或误拆。
  - 第十场开头舞台提示“……缩坐在狱室的一角。两”后似漏一字（疑为“两个”）。
  - 第四场“外面人声：我。”一行，角色标记按原行“外面人声”理解，原书格式不确定。
  - 第六场三处“关汉卿”、第八场“禁婆”、第十二场“朱帘秀”，原书只有角色名而台词为空（或为未识出的省略号），整理稿仅保留“角色名：”。
  - 第六至七场剧中剧《窦娥冤》唱词，按原书版面把“魂旦”“天章”“窦娥”“监斩官”等作发言人标出。
  - 个别字形近之误未改，如“骙嗦”（疑“啰嗦”）、“薑醉”（疑“酒醉”）、“徹/彻”混用等。
  - “代跋”中郭沫若来信的落款与田汉复信的称呼“沫若兄：”原在同一行，已拆为两段。
