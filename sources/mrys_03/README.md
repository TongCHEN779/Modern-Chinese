# 风流学士：苏东坡

- 底本：丁永淮、熊文祥著《风流学士：苏东坡》（“中国名人轶事丛书”之三，吴洪激主编），武汉大学出版社、台湾汉欣文化事业有限公司联合出版，1994 年 7 月第 1 版（黄冈地委印刷厂印刷）。文字由扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：共八页——丛书出版缘由、主编絮语（吴洪激序）、第一至第六章，各占一页。每章页内第一节（节名同页标题）为章首题词（苏东坡诗词），其后以书中“二、三、四”为小标题分节，书中第一节无编号，节名取“一”。
- 去掉的内容：封面、书名页、版权页（CIP 数据等）、目录页、页眉页脚与页码、Anna's Archive 的元数据页；出版缘由与主编絮语文末的署名“吴洪激”；书中每页页下的脚注（①②…的注释文字）及正文中的脚注序号。“主编絮语”文末的写作日期“一九九四年春日记于武昌珞珈山”保留。
- 段落按扫描版面（据 json 坐标）的缩进与行宽重建，跨行、跨页的段落已接合；书中诗词、对联、谜语等插入的引文按原书每行一行，用“诗：”居中；词作若书中排成整段，则按一段一行。书中引述的文告、赋文、民间故事等整段缩进的引文按“原：”段落处理。每章题词的各句并作一行，署名“——苏东坡：《某某》”另起一段。
- OCR 已知问题：
  - 原扫描质量一般，个别字句识别有误或不通（如第一章“喝先人进了佛殿”“佛殿里暴然不道子的画”一带），未逐一校改；个别整行漏识，造成段落中途断开（如第二章“我提议”、第三章“但愿卑职不要说低了”、第四章“大老爷的这本诗集呈给了皇上”等处），保留原样。

  - 第一章“神智体”诗（以大字拆排的图示）与第二章“圆圈连环”谜笺的图形部分无法识别，已略去，仅有残字“雨”“4”等碎片，已删。
  - 每章题词的前一两句可能漏识（第六章题词自“清溪无底”起）。
  - “化齋”“又廟”等繁体字形为书中谜面，保持原样；半角“?”“.”已改为全角。
