# 聆听撒哈拉的歌声：三毛传

- 底本：田梦著《聆听撒哈拉的歌声：三毛传》，山东人民出版社 2017 年 8 月第 1 版。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：按书的目录分页：序言（蔡志忠）、走不完的心路（三毛）、自序、十章正文（每章一页，页内小标题即目录中各节标题；章首引语归入章名节）、后记、三毛年谱（附录）各一页。去掉封面、版权页、作者简介、目录页、图片说明（“三毛”“三毛与蔡志忠合影”）、页码、封底推荐语与责编信息。
- 补回与更正：OCR 稿中有七个小节标题（“去做毕加索的另外一个女人”“收纳一段珍贵的时光”“心有余悸，生死相依”“迎接海风，追寻人生”“痛苦在静默里山崩”“光影交织，人生一梦”“像风一样离去，追寻幸福的皈依”）被并入上一段末尾，已据目录和逐页识别结果拆回为小标题；年谱标题“沱年谱”据目录改为“三毛年谱”；“二上周年”改“二十周年”、“干山”改“千山”；序言末行多出的“附”字删去。
- 已知问题：第一章章名“童色载一段悠悠华彩岁月光泽”目录与正文同样如此识别，疑有误字，原样保留；序言、章内引用的三毛原文、信件、歌词按书中分行或分段保留，个别折行引文可能未完全合并；其余错字、漏字未改。
