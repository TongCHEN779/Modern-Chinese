# 中国古代戏剧选

- 底本：宁希元、宁恢选注《中国古代戏剧选》（全 2 册，中国古典文学读本丛书典藏），人民文学出版社，2003 年第 1 版，2017 年第 2 版。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：去掉封面、版权页、丛书广告、两册目录与页眉页脚；收前言一页，其后三十三个剧本各一页（上册十五种、下册十八种），页内按“楔子/第一折…”或“第一出…”分节；无折出之分的（《狂鼓史渔阳三弄》）整剧一节。每位作者首次入选时，作者简介作为该页第一节；科白、曲词各占一段（曲牌名并入曲词段首，按“（唱）【曲牌】”及“（某云）”处拆段）。
- 注释：原书的注释集中印在每剧之后，编号 [n] 与正文标号对应；转换时按正文标号把每条注放回所属段之后。注 [1] 为剧本说明，作为该页第一节（楔子/第一折）的题解；折首“楔子[2]”之类标在节名上的标号，注放在该节首段。注首若是原文词语则取为词语，否则取标号前一小段正文为词语（约 5%）。个别含多个句子的注释用“注原：”保持整条。
- OCR 已知问题：部分正文标号编号被误识（如“[2]”应作“[7]”“[9]”），已按序号连续性校正；少数剧末注释未能在正文找到标号（《王粲登楼》《渔樵记》《狂鼓史》），附在该剧末段之后；《渔樵记》注 [2] 的词语“鲊”据正文补。前言里提到“三十种”，而实际所收为三十三种，原样保留。多处 PDF 页无识别结果（空白或图版页），正文标号连续，未见缺文。跨页断开的段落按“前段末无句末标点”接合，曲白拆段依据括注规则，可能有个别误拆或漏拆。
- 原书注释已按站内格式（注：词语：解释）挂在所注段落后，注码已去掉；个别注释的词语位置为推定。
