## 整理说明

- 原书竖排，OCR 逐列识别后按“右至左”拼回；诗歌页上下两栏已按栏序拼接。较长的诗行在版面上折行的（《人力车夫》《一颗星儿》《我的儿子》），已接回原行；《沁园春（新俄万岁）》版面为连排，合为一段。
- 小节号“一、二、三”常被 OCR 漏识（印作一道短横）：《贞操问题》《九年的家乡教育》《易卜生主义》三篇的第一小节号“一”漏识，第一节径用“一”作节名；《乐观》诗中第一章的“一”按版面空位补回；《文学改良刍议》开篇列出“八事”的清单里第一条“一曰须言之有物”漏了“一”，正文中该小标题按“一曰须言之有物”补回；《吴敬梓传》“本传附录”下第一项的“一”补回。
- 《评「五四」文学革命中的胡适》“余论”二字标题 OCR 为空白，据原版面补回（置于“以《新青年》团体为中心的……”之前）。
- 文言诗五首（《弃父行》《睡美人歌》《送梅觐庄往哈佛大学》《秋声》《沁园春（誓诗）》）OCR 几乎丢光标点，已对照页面图像重录标点并按句分行；其余诗歌的分行以 OCR 行为准。
- 剧本《终身大事》：OCR 漏识的“人物名：”冒号按全剧体例补回，个别人物名后丢失的“（”按有“）”无“（”补回；人物表里的“田大大”改为“田太太”；“序”“跋”原文各为一段，随后分节。
- 诗歌里半角括号、标点按规则改为全角；各篇“（选自《尝试集》增订四版）”等出处行里丢失的书名号按全书体例补回。

## OCR 已知问题

- **标点为整理时据文意补加**：竖排小标点（逗号、句号、顿号、引号）经 OCR 后多数脱落，本稿已全书补加新式标点（古文按新式标点，引文用「」『』，书名号《》；诗歌保持原分行，只在行末、行间补标点；剧本人物名后冒号保持原样），可能与原书有出入。个别地方 OCR 字符本身有误或脱字（如《名教》“在孙行者手心写一个「」字”脱一字，“如果一「打倒帝国主义」是标语”的“一”本是引号，《评「五四」文学革命中的胡适》里个别“四”“曰”为脚注号误识），因不改字，标点据现有文字处理。
- 日期行多有脱漏或错识，如《人权论集》序文末“十八十1二。十1三1。”，《乐观》《礼！》《死者》《双十节的鬼歌》《晨星篇》等诗末的“十十四”“九十一二五”之类，均为原样保留。
- 页码混入正文的数字（如“老先35生”）已按页码去掉，个别识别成相近数字的也一并删去。
- 个别繁简/异体混用，如“靑/青”“尙/尚”“鎗”“窰”“鑛”等，按 OCR 原样保留；“尝试新诗的人”等篇名里丢失的引号尾「」已在页标题中补回。
- 没有缺页；PDF 第 20、216 页为空白页，第 5—12 页为照片、书影、手迹页（手迹 OCR 为乱码），均未收。
