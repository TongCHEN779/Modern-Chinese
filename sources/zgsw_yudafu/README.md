# 中国现代散文经典文库·郁达夫散文经典

- 底本：郁达夫著《郁达夫散文经典》（中国现代散文经典文库，阿宏主编），印刷工业出版社，2001 年 3 月第 1 版，ISBN 7-80000-407-4/I·15（全套十二卷）。文字由书籍扫描件（PDF）经 OCR 识别、整理而成，**尚未逐字校对**。
- 结构：前言一页，正文五十五篇各占一页；书的目录分三辑，《苏州烟雨记》辑（《江南的冬景》至《故都的秋》二十二篇）、《北国的微音》辑（《怀鲁迅》至《回忆鲁迅》十七篇）、《归航》辑（《归航》至《水样的春愁》十六篇），pages.json 第三项即辑名。
- 整理：去掉封面、版权页、目录页、页眉页脚、页码；因换行、换页断开的段落已接上；每篇内的小节号（一、二、三……）、《写作闲谈》的“（一）（二）（三）”、《记耀春之殇》附诗的“其一”至“其六”、《毁家诗纪原注》的诗序与“贺新郎”各为一节；《杭州》里的“四时幽赏”、《清新的小品文字》《移家琐记》《还乡后记》里缩进排印的引文，按书的版面各并为一段；书信、诗联每行（句）另起一段。《自传之一》至《自传之四》的副题保留为各篇首段，《情书一束》各函的称呼、署名、日期各为一段。

## 整理时的补正
- 小节号“一”在原书中印作一道短横，OCR 全部漏识，按版面空行补回：《小春天气》《苏州烟雨记》《毁家诗纪原注》《还乡记》《移家琐记》的首节为“一”；《还乡后记》开头引吴均文的题引之后补“一”（自“比在家庭的怀抱里觉得更好的地方”起），该章第二节“二”的短横也被漏识，补在“假使天公下一阵微雨”之前。其余小节号 OCR 已识出。
- 目录页 OCR 的篇名有残缺，页内标题也有断行（“暗 / 夜”“杭 / 州”“花 / 坞”“海”），篇名一律以目录为准：《海上》《茑萝行》（正文标题 OCR 作“笃萝行”）。
- 全书“鸣呼”均为“呜呼”之误，已改（《暗夜》）；“头—次”改“头一次”。半角括号、逗号、冒号等在汉字旁的已改全角；英文诗句、英文短语（《情书一束》《茑萝行》《还乡后记》中）原样保留。

## OCR 已知问题
- PDF 第 12 页、第 353 页无识别内容（空白页），无缺文。
- 部分文字识别有误或漏字，未逐一校改，如《归航》开头第二段末缺句号，《闽游滴沥之二》“坐下去休息了”之后缺句号，《暗夜》“暖，她大约不至于生病罢”的“暖”疑为“嗳”，《归航》“清冷同中世似的故乡”疑有误，《情书一束》中英文情话有识别错字（如 “L - e”）。
- 《情书一束》各函之间无单独标题，只以称呼、署名、日期行区分；每函的“达夫”署名与日期原为右对齐，各占一段。
- 《杭州的八月》《杭州》等篇名取自目录；《记耀春之殇》结尾所附《其一》至《其六》各为一节，之前的“【附】志亡儿耀春之殇”与篇末日期保留在页首节内。
