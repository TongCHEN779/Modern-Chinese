# 老残游记

- 底本：（清）刘鹗著《老残游记》（校注），人民文学出版社，“百年百种优秀中国文学图书”丛书，2000 年 7 月第 1 版、2001 年 10 月第 2 次印刷（校注本，据 1957 年版整理，附《老残游记二集》）。文字由书籍扫描件经 OCR 识别、整理而成，未逐字校对。
- 整理：自叙、正文二十回各占一页，附录《老残游记二集》自序及九回各占一页（页标题沿用书中回目，两句对偶回目以空格隔开）。
- 去掉的内容：封面、版权页、丛书前言与书目、作者小传、出版说明（编辑部 1957 年）、再版后记（校注者戴鸿森）、目录页、页眉页脚页码、每页底部的校注脚注；正文中的脚注序号（①②…）一并删去。
- 已知 OCR 问题：正文中的内层引号（原书为单引号 ‘ ’）多被识别成直引号 `'`，段内成对者已改回 ‘ ’，其余（约 90 处，多为跨段引文）保持原样；第六回末页“两人”下一行只剩“手。”，疑漏识中间文字（约在该回“我去拿油壶来添添这灯”一段后，未补）；回末诗词、歌谣按书的分行逐行成段。各回目、正文均未发现整页缺失，但未与原页逐一核对；个别形近字可能存在 OCR 误识。
