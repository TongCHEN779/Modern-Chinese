# 人境庐诗草

- 底本：黄遵宪著、钱仲联笺注《人境庐诗草》（上、下），“百年百种优秀中国文学图书”丛书，中国青年出版社 2000 年版（钱仲联笺注本，底本为 1936 年商务印书馆初印笺注本及其修订再版）。文字由扫描件经 OCR 识别整理，**尚未逐字校对**。
- 收入：钱仲联《前言》《发凡》，康有为序、黄遵宪自序、初印笺注本陈（衍）序、冯（振）序、王（蘧常）序、钱萼孙自序；正集卷一至卷十一全部诗作；原稿本卷五至卷八诸家跋、辛亥初印本跋、辛未校刊后记；附录一《日本杂事诗》（自序、两卷、跋，各首诗后附作者自注作为本节最后一段）；附录二《清史稿》本传、梁启超《嘉应黄先生墓志铭》、钱仲联撰《黄公度先生年谱》；附录三诗话上、下；二〇〇〇年版跋。
- 去掉：封面、版权页、丛书前言与书目、目录、页眉页脚页码；各诗的〔题解〕和逐词笺注（引文、典故、校勘异文，即每首诗后、各页的注释部分）；诗中的注码；二〇〇〇年版跋后的出版社“编者附识”。
- 诗行：每个分句（以“，。！？；”断开）一行。组诗（如《已亥杂诗》《岁暮怀人诗》《香港感怀十首》）按版面分段拆成“某某　其一、其二……”；《山歌》《海行杂感》《养疴杂诗》《不忍池晚游诗》《近世爱国志士歌》诗前的作者小序单列一节“……　序”。《三哀诗》按三位传主分为三节。

## 已知问题
- 诗行与注文在 OCR 里同页混排，是我按版面（字号、行距、位置）把诗行与笺注分开的，难免有误：个别单行诗句可能漏收（如《武清道中作》第四首只有七句，《新嘉坡杂诗》等少数首句数异常），个别笺注残句可能混入诗句。组诗的拆分依据是版面分段，少数组诗的首数与卷首“共若干首”不完全吻合（如卷三、卷四、卷六总数偏少），疑有长诗被并或短诗被并。
- 诗内注码（如（一）〔二〕）是按序号规律删去的，少数无括号的数字残留或误删（如句末确为数字的“四十”“十五”之类已保留，其余偏差未逐一核对）。OCR 残留的个别误识字（如“士/世”“已/己”、拉丁字母噪声）大多已删或保持原样。
- 个别诗题的 OCR 缺字，据目录或上下文补：《出门》《慷慨》《水滨》《纪事》《夜泊》《夜饮》《夜起》《群公》《京师》《述闻》；《庚辰四月重野成斋……》等长题据目录与正文拼合。第三卷中《陆军官学校开校礼成赋呈有栖川炽仁亲王》《徐晋斋观察……》两首目录页码与正文位置相反，以正文为准。
- 前言等散文页按缩进断段，引用块（《前言》中引黄遵宪《自序》《山歌》题记）被拆成若干短段；《日本杂事诗》卷二末作者自识（“朱竹垞收《吾妻镜》一部……遵宪自识”）并入最后一首的自注段；该书第 92 首（卷二）原被分页切开，已合并。
- 年谱、诗话各条的小标题（如“梁启超《饮冰室诗话》”）按居中短行判断，《诗话上》中梁启超所引三首军歌的歌名被当成了小节名。
