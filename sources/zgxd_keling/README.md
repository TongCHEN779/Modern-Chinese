# 中国现代作家选集·柯灵

- 底本：《中国现代作家选集　柯灵》，王继权、姚国华编，三联书店（香港）有限公司、人民文学出版社联合编辑出版，1990 年 2 月香港第一版第一次印刷，ISBN 962-04-0781-4。文字由书籍扫描件（PDF，柯灵.pdf，共 340 页）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。原书竖排繁体，已转为简体。
- 整理：按书的目录分页，共 48 页。卷首杨绛《序》一页；“散文”25 篇（《巷》至《回首灯火阑珊处》）；“杂文”11 篇（《人与鹰犬》至《碰壁》，其中《玉佛寺传奇》为短剧，每个角色/唱词一行一段）；“小说”4 篇（《同伴》《云》《酒》《舍》）；“资料部份”6 篇（刘以鬯、林非、海旸、陈颖的评论，陈国容《柯灵谈“创作经验”和“语文修养”》和《柯灵年表》）。分组名取自书的目录（散文、杂文、小说、资料部份）；序不属任何一组。
- 去掉了：封面、丛书介绍、版权页、作者照片及图版说明页（PDF 第 5–14 页，含第 14 页作者手迹题诗，OCR 无法识读）、目次页、页眉页脚页码、“资料部份”扉页及空白页、PDF 末页的附加数据；每页底部的脚注（《舞台因缘六十年》《钱锺书创作浅尝》两篇的引文出处注，《伟大的寂寞》《遥寄张爱玲》《人与鹰犬》《斗室漫步》《恐怖政策》《玉佛寺传奇》《我要控诉》《神·鬼·人》等篇的随页注）均已去掉，正文中的注号随之去掉。《回首灯火阑珊处》文末集中的“注”保留为该页最后一节，注号 OCR 漏识（偶留一个“0”或“O”已去掉），各条按版面分段。
- 小节与标题：
  - 书中小节号及小标题常印作短横或大字，OCR 多漏识。据页面图像补回：《忆江楼》的小标题“江楼、得月、枕畔歌声、渔舟上的喜剧、采菱、暴风雨中的孤舟”；《舞台因缘六十年》《钱锺书创作浅尝》《酒》《柯灵的文学道路》《常读常新的典范散文》的第“一”节（印作短横，OCR 漏识，按版面位置补回）；《神·鬼·人》的“关于土地、关于女吊、关于拳教师”；《斗室漫步》十节、《市楼独唱》八节的号次与小标题（据目录与图像校补，如“乡愁似海”“生命无价”“覆巢之下”“独唱开场”“西崽世界”“少年中国”“佳话拾零”）。
  - 篇名 OCR 损坏者据目录或图像补全：《恐怖政策》（OCR 作“恐政策”）、《人民的心》《望春》《在西湖　抗战结束那一天》《舍》（OCR 作“拾”）。副题与题下说明并入页标题，如《伟大的寂寞——悼周木斋》。
  - 《同伴》《云》《舍》及《酒》号次之外的空行不另设小节。
- 日期：文末日期 OCR 多有残缺，据页面图像校补：《巷》（一九三〇年秋）、《忆江楼》（一九三二年秋）、《野渡》（一九三三年）、《故园春》（一九三四年春）、《遗事》（一九三六年）、《人与鹰犬》（一九三五年）、《逆旅》（一九三九年十二月）、《鬼混哲学》（一九三九年十一月二十七日）、《神·鬼·人》（一九四〇年）、《从〈目莲记〉说起》（一九四〇年十一月）；另有若干年份首字“一”漏识（如“九三八年”），按前后文补作“一九三八年”；《伟大的寂寞》篇末“一九四年”据文中“一九四一年七月二十五日”改作“一九四一年”。
- 人名及用字统一（OCR 系统性错识，把握极大者）：“传雷”→“傅雷”，“何灵”→“柯灵”，“国城”→“围城”；《酒》中“郁微、郁徽、郁卫”统一为“郁征”（全篇以“郁征”最多）；《同伴》中“莉旧”统一为“莉蕾”；年表中“一九二二年二十四岁”按次序改为“一九三二年”，“一卷、一楼”等改“一岁”等。《玉佛寺传奇》中角色名“电R、电人、电B”按上下文改作“鬼B、鬼A、鬼B”，其余“电哈哈哈哈”等未改。
- 民谣、诗句：《故园春》中的七行民谣、《在西湖　抗战结束那一天》的打油诗两句，OCR 严重错识，据页面图像重录（原书逗号、句号小字，已按图像补入）；《神·鬼·人》中的吴语打油诗和女吊唱词 OCR 低置信，保留原样。诗行、唱词按书的分行各占一段。

## OCR 已知问题

- **标点大量缺失**：原书竖排，逗号、顿号、分号等小标点在 OCR 中绝大多数没有被识别出来，正文常整段无逗号、顿号；句号、问号、叹号、冒号、引号（「 」）识别较好但也不全，破折号和省略号时有丢失。整理中未补加标点，以免臆改；半角 `( ) , ; : ? !` 在汉字旁已改全角。
- 页间/列间乱序：个别页（如《忆江楼》首页、《玉佛寺传奇》）版面复杂，已按页面坐标重排；《玉佛寺传奇》中角色名、舞台提示与唱词的分行是按版面推定的，个别处并行不准。
- 低置信度残片：如《忆江楼·渔舟上的喜剧》末尾“叫电”两字（原为句末词，未识出）、《酒》《云》等小说里个别句末的“L”“C”“J”等噪点（已删，无法确定所对应的字的，如“L然地倒”“休H。”保留原样）。
- 小说中的对话分段按版面缩进判定，个别短句可能多分或少分一行。
- 《柯灵年表》：每个年份行与其下事项各一段；全表按版面顺序，个别条目的先后可能与原书小有出入。
- 《衣带渐宽终不悔》开头的书目信息（《文苑漫游录》、三联书店、定价、页数）在 OCR 中被拆成几行，保留为几段。
