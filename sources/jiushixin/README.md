# 九诗心：暗夜里的文学启明

- 底本：黄晓丹著《九诗心：暗夜里的文学启明》，上海三联书店出版（封面题“上海三联书店”）。OCR 稿无版权页，出版年份未见；后记称书稿 2022—2024 年修改，应为 2025 年前后版本。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：序一页、九位诗人各一章（屈原、李陵、曹丕、陶渊明、杜甫、欧阳修、李清照、文天祥、吴梅村）各一页、后记一页，共 11 页；页内小标题即书中各节标题。原书无附录。章首的题词（汉娜·阿伦特引语）、封面、各图版（帛画、帛书、墨迹题跋等）及其说明、页内水印未收。
- 去掉了全部脚注：本书脚注排在正文段落之间（缩进排版，含出处与作者补注，有的还引原文），按版式（首行缩进、续行位置）判别后整体删去，包括其中的补充说明与引文；诗词、正文引文与英文歌词保留为自然段，诗词每行一段，词的上下阕合为一段。
