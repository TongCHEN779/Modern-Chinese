# 暮日耀光：张居正与明代中后期政局

- 底本：韦庆远著《暮日耀光：张居正与明代中后期政局》（上、下册），江苏凤凰文艺出版社 2017 年 5 月第 1 版。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：上、下册合为一书，`pages.json` 第三项分别标“上册”“下册”。按书的目录分页：绪论一页，第一至第二十二章各一页（上册为绪论与第一至第十章，下册为第十一至第二十二章），其后大事记、引用文献和参考资料、后记各一页。页内“第 N 节”、章内“一、二、三”及绪论的“二”至“六”各为一节；每页首节取页标题（章页首节无正文，直接接“第一节”）。大事记以每个年份（或年段）为一节，“政局”“事迹”两个栏目名保留为单独一行。
- 去掉：封面、版权页、总目与上下册目录、页眉页脚与页码、每页脚注（含正文中的 `[1]` 之类注码）。引用文献页保留“一、文献”“二、参考资料”两节；“○”号为原书标记，原样保留。章末的“1996 年 8 月初稿……”落款保留在第二十二章末。
- 书中的整页脚注因 OCR 把注文与正文粘连，是用脚本按注码和行长识别去除的，个别处可能漏删（残留零星注文）或误删。
- 引文折行：书中缩进引文（块引）在 OCR 里按版面逐行断开，脚本把无句末标点的行与下一行接为一段；极少数地方可能把两段误合或未合。
- OCR 已知问题：原书一页常占 PDF 的半幅，跨页的段落靠脚本拼接。个别段落末尾的几行因 OCR 把它粘在脚注行后而缺失（段落停在半句，例如绪论中“……对他所处的时代以”之后，及第二十一章“值得注意的是，雷”处）；绪论第一节前的“一”在 OCR 中缺失；第六章第四节内有一处孤立的“一”被当作小标题保留；个别注码（如“[2”、孤立数字上标）已按规则清除，仍有少量脚注数字混入正文（如“疏》3。”）；绪论落款“于故乡广州师凿书室”等疑似形近字错误及其他识别错字（如“大乱之剡”）均未更正。
