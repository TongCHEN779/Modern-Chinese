## OCR 已知问题

- 英文行内常有词间漏空格（如 “thatthe”“KingPtolemaios”），未逐一补回；这是识别稿的系统性毛病。
- 碑铭边栏行号被丢弃，正文里的 “|”（原书表示碑铭换行）保留；个别行号混入行首者可能残留。
- 年代行中的斜线/连接号常被识成粘连数字（如 “7473 BC” 应为 “74/73 BC”，“4644 BC”“4443 BC” 同），未改动。
- 注释编号偶有与正文粘连（“2As the…”），或编号被识别为字母（如 “1I”）、个别注释编号丢失（如第 5 条注 9 起首“196 BC” 前缺“9”）。
- 第 3、89 等条的钱币图例（正反面文字并列的两栏排版）被按行读平，正反面说明与图例文字相互夹杂。
- 表格化的缩写说明中，“Wilcken, Grundzüge / Wilcken, Chrestomathie” 一对条目因跨行排版而释义错位；附录二个别人名换行处的连字符（如 “Callai-cus”）按需保留。
- 第 48 条正文标题的编号 “48” 被识别程序当作边栏行号丢掉，本稿按目录次序补回；第 20、63、66、77、96 条目录行 OCR 缺失，其标题取自正文标题行。
- 第 3 条节名取正文标题（比目录多 “Epiphanes”）。““希腊罗马史料集”总序” 末尾署名（E.B. / R.K.S.）为左右栏并排，识别时顺序错乱，已按版面调整为两行。
