# 史记选

- 底本：王伯祥选注《史记选》（中国古典文学读本丛书典藏），人民文学出版社，1957 年第 1 版、1982 年第 2 版，2017 年典藏重印。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：去掉封面、版权页、丛书广告、目录页与页眉页脚；收《史记选序例》（王伯祥序）、选文二十篇（《项羽本纪》至《滑稽列传》）、人民文学出版社后记，每篇一页。篇内无小标题，节名同篇名。
- 注释：原书的“校释”集中印在每篇之后，编号 [n] 与正文中的标号对应；转换时按正文标号把每条注放回所属段之后（《项羽本纪》《陈涉世家》《孙子吴起列传》《范睢蔡泽列传》《游侠列传》《滑稽列传》标题上的 [1]，因是对该体例的总说明，作为题解）。注首若是原文词语则取为词语，否则取标号前的一小段正文为词语。序例的注释（44 条）一并按此处理。
- OCR 已知问题：PDF 中无识别结果的空白/图版页（如 p7786、p7810 等）没有文字，正文标号连续，未见缺文；《范睢蔡泽列传》的注 [1] 未识别出，故该篇无题解；《陈丞相世家》一条注的编号被误识为 [2]，混入前一条；个别注释的词语在所属段原文里找不到（约 1.5%）。页尾被分开的段落按“前段末无句末标点”接合，可能有个别误接或未接。
