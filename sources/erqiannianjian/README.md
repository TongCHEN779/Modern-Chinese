# 二千年间

- 底本：胡绳《二千年间》，中华书局 2005 年 9 月第 1 版（“大家说史”丛书；含编者的话，导言节选自胡绳 1996 年为《胡绳全书》第五卷所写引言，附吴晗《读〈二千年间〉》）。原书写于 1944—1945 年，1946 年由开明书店初版，署名“蒲韧”。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 分页：按书的目录，编者的话、导言、九章正文、附录各占一页（共 12 页）；页内“一、二、三”小标题即书中各节标题，每章首节（节名同页标题）为章首无标题的引言，若该章开头即为“一、”则首节为空。
- 去掉的内容：封面与封底推荐语、版权页、目录页、页眉页脚与页码、全部插图及图注（书影、瓦当、地图、绘画等的说明文字）、图版里的古文/碑帖等图片文字、各章扉页。
- 未能收入：第一章“二、时间之流”之后的朝代年表（PDF 第 20 页）是图表，OCR 只剩乱码，整页未收，所以“我们试制下面这一个表”“表中又有‘大事记’一项”两处的表缺；章首“在『万人之上』的人”的引号改用通行的“”。
- 整理时更正的 OCR 错字（把握较大者）：“宦宫”→“宦官”，“胡屠者户”→“胡屠户”，“收人”→“收入”，“侵人／人侵／深人／人关／人学考试／进人仕途”→“侵入／入侵／深入／入关／入学考试／进入仕途”，“伶停(pīng)”→“伶俜(pīng)”，“既人学”→“既入学”，“十六年(1618～1644年）”→“(1628～1644年）”（按“十六年”推定）。
- 据版面图（json 坐标）补回的内容：OCR 整理稿漏掉的三处页首段落——第二章“四、在皇族内部的纠纷”开头、第六章“清朝政权……”一段之前的“朱元璋虽从农民造反的队伍中起来……”一段、第九章末节“统治者想维持整个秩序不变……”及其后各段（原稿中被当作眉批，且与图片文字混排），以及“（如在王莽时，在明末）。”的“末）。”（被误当噪点删去）。

## OCR 已知问题

- 全书插图很多、正文绕图排成窄栏，段落是按行首缩进（坐标）推断的，绕图处个别分段可能与原书不一致。
- 当兵一章第一节“兵对兵，将对将地厮杀起”与“机关枪的战争是何等的不同啊”之间，OCR 漏了约一行（应是“来。这和现代使用……”之类），未补。
- 当兵一章“军权的集中和分散”开头（长江上游荆州、下游扬州一段）绕图排版，行序为推定：“有着两个最强的武力集团。中，谁的力量最大……”“中，”之前疑有缺字。
- 存疑未改：“糠而不足”疑漏“籺”，“五月新谷”疑漏“粜”，“机阻不安”疑为“杌陧不安”，“不得不同趋于崩溃”疑为“日趋”，“但是在如《三国志演义》中”“不重要的现象这种想法”疑有缺字或标点，保留原样。
- 个别绕图页上的图注与正文紧贴，已尽量按行剔除；若仍见与上下文不接的短语，多为漏剔的图注。
