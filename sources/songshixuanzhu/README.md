# 宋诗选注

- 底本：钱锺书选注《宋诗选注》（中国古典文学读本丛书典藏），人民文学出版社，2016 年第 3 版。文字由书籍扫描件（PDF）经 OCR 识别整理，尚未逐字校对。
- 结构：序（一、二、三）、重印附记、柳开至萧立之八十位诗人各一页（页内第一节为“某某小传”，其后每首诗一节）、附录《香港版〈宋诗选注〉前言》。
- 注释：原书每首诗后的 [n] 注释，按正文里的 [n] 标号放回所属诗节之后；`词语` 取标号前的几个字。原书标在诗题上的注（题下注、题中注）放在该节的“题解：”里。序言、小传、附录里的注同样按标号放回段后。注释中紧接出现“补注：”的，用 `注原：` 保持一条。
- 去掉：封面、版权页、丛书广告、目录页、页眉页脚、页码、“文前辅文”。
- 诗行：OCR 稿把整首诗连成一行，按标点拆成句，四句左右为一段，句间用 `/`；标点据 OCR 稿，半角逗号、分号、问号、叹号在汉字之后的改作全角。
- 组诗：周紫芝《禽言》、曹勋《仆持节朔庭……》各为一节，分题（婆饼焦、提壶芦……入塞、出塞）并入各段段首。
- OCR 已知问题：
  - 陈师道小传四条注释（标号 [1]–[4]）在 OCR 稿里整块缺失，已略去；
  - 华岳小传正文缺第 [3] 号标记，该条注挂在小传末段末尾；
  - 刘宰《野犬行嘉定己巳作》的题目 OCR 漏识，据目录补回；陆游《九月十六日夜梦驻军河外遣使招降诸城觉而有作》题目前半漏识，据目录补回；
  - 序文注释的标号 OCR 有误（如“[2]”应为“[7]”“[9]”），按顺序对应；
  - 个别注释标号 OCR 漏识，注释词语取近旁文字，位置可能偏移一两字；
