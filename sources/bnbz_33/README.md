# 湘行散记

底本：沈从文《湘行散记》，作家出版社 2000 年 7 月第 1 版（“百年百种优秀中国文学图书”丛书）。OCR 来源：`百年百种优秀中国文学图书/33、湘行散记`。

## 整理说明
- 共 11 篇，每篇一页，篇名为页标题，各篇文末的写作日期（如“一九三五年三月作于北京”）保留。
- 去掉：封面、版权页（CIP、定价等）、作者小传页、丛书前言、评选委员会名单、丛书书目、目录页、页眉页脚、孤立页码、末页扫描版权信息。
- 《箱子岩》页脚脚注“① 农历五月十五为大端阳节”已去掉，正文中的圈码一并删除。
- 跨页断开的自然段按句末标点接合。
