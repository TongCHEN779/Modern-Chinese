## OCR 与整理的已知问题

- 历史年表由坐标对齐：个别年份在 OCR 中缺失（事件归入前一年）；“科学和技术”栏 1865—1869 年一行因 OCR 把多栏并成一行而混杂（达尔文、密尔、孟德尔、诺贝尔等事件连在一起）；少数行英文书名折行被并入下一事件。
- 页边原书页码靠“逐章按页递增的数字序列”识别后删除，个别漏删/误删（带数字的残留多为引文页码）；注释区的注号（“[1]”“1”）保留。
- 参考书目按条目编号拆分，条目编号后空格已统一（“1. 10First”→“1.10 First”）；第十三章缺 13.16、13.17 两条（并入相邻条）；英文单词间空格丢失（如 HomericQuestions 一类）、少数字形误识未改。
- 块引文靠缩进判定：个别引文并入上下段或被拆开；引文末的右对齐出处（如“(7:87)”）有时单独成段，有时并入下一段。
- 第九章的公式、第十一章等处的符号按 OCR 原样；第十四章 476 页“第章”处 OCR 缺数字。
- 两个版面并排的行（如第十一章的一处）按行位置合并，次序可能与原书略有出入。
