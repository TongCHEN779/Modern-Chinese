# 3小时读懂晋朝

- 底本：姜若木编著《3小时读懂晋朝》（“一目了然速读史”系列），京华出版社 2011 年 4 月第 1 版（版权页：2011 年 3 月 CIP，ISBN 978-7-5502-0197-2）。文字由书籍扫描件（PDF）经 OCR 识别、整理而成，**尚未逐字校对**。
- 整理：前言一页；正文九章各一页（页标题保留“第一章 …”整体，章首的两句对联作为该页页首引言）；章内小标题各为一节；末尾“附录”一页，七个小标题各为一节，其中“七、晋朝历代皇帝年表”每行一段，各栏用全角空格隔开（西晋、东晋两表，空缺的帝位栏照原样省略）。
- 栏目：每章末的“点评”“相关链接”及其下的链接短文，保留在该章最后一节内，栏目名与链接短文标题各自成段；第四章“相关链接”里的“西晋四帝生平简述”及其下“一、二、三、四”四个小标题同样各自成段。
- 去掉的内容：封面、版权页、目录页、页眉（“3小时读懂晋朝”）、右侧竖排的章名条、页码、插图及其说明文字、地图上的标注文字、附录前的图版页、书法/画作图片中的识别残字。
- 小标题：按目录与版面核对。目录中的“西晋士风”“秦晋淝水大战”等均在正文找到；正文里“周颛之死”被识别为“周页之死”，已按目录改；附录一至三的标题在正文页中无序号，序号取自目录。
- OCR 已知问题：
  - 书中文字常绕插图排成窄栏（如第一章“曹魏政权下的司马氏家族”、第四章“王与马，共天下”、第八章“王敦叛乱”等处），已按行坐标重新接合；窄栏与通栏交接处的段落划分是按缩进和行长推断的，个别处可能偏差。
  - 页首无缩进的行一律按上页段落的续行接合；个别上页恰在句末收尾的地方，可能本应另起一段。
  - 第三章“西晋士风”“贾南风与八王之乱”、第五章“桓温三伐”、第七章“秦晋淝水大战”各有地图，地图上的标注文字已删，图旁正文保留。
  - “严阵，寺”（第四章“西晋的丧钟”李特起事一段）应为“严阵以待”之类，OCR 疑有错字，原样保留；其余偶见的形近字错误未逐一校改。
