# 城南旧事

底本：林海音著《城南旧事》，人民文学出版社“百年百种优秀中国文学图书”丛书，2000 年 7 月第 1 版（2001 年 5 月第 2 次印刷）。OCR 整理稿来源于 PDF 扫描本（共 148 页）。

## 整理说明

- 收：出版后记《冬阳 童年 骆驼队》、代序《城南旧事》（含林海音《忆儿时》《我父》两篇附文及署名“林海音　一九六〇年七月”）、正文五篇（《惠安馆传奇》《我们看海去》《兰姨娘》《驴打滚儿》《爸爸的花儿落了》）。每篇一页。
- 去掉：封面、版权页（CIP、定价等）、作者简介页、丛书前言、评选委员会/编辑委员会名单、丛书书目、目次页、书末 Anna's Archive 水印页、页码和页眉。
- 篇内以汉字数字（二、三……）标的小节另起一节；每篇开头未标号的第一小节归入篇名节。
- 断行/跨页的段落已接合；整理时未改动原字。

## 已知问题

- 《惠安馆传奇》第二节标号“二”、《我们看海去》第三节标号“三”在 OCR 中丢失（版面上此处有标题式空行），按前后序号补写，位置依据版面空隙推定。
- 《我们看海去》有第二、三、……七节；《驴打滚儿》《爸爸的花儿落了》原书无数字小节标号。
- 《爸爸的花儿落了》篇名下另有一行“我也不再是小孩子”，作为首段保留（目次中与篇名并列，文末亦重复出现）。
- 《惠安馆传奇》中有一处“雷声/响了”之间夹有 OCR 误识的孤立数字“1”，已删除。
- 《爸爸的花儿落了》中歌词“……惟有别离多”一句、《兰姨娘》中“难道是一”均为原文截断处，照录。
