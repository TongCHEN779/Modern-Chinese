- 底本印刷质量一般，识别错字较多，系统性问题：冒号“：”与句号“。”、逗号常互相混淆，句末该用句号处常识别成冒号；个别字形近误识（如“感宫”应为“感官”；贝多芬传序言中“他的弗洛伊德所感染”疑为误识）、漏字、标点错位，均未校改。
- 贝多芬的遗嘱一页（第 41 页）在 OCR 中只剩手稿图的几行说明文字（Adagio、Al-Lein 等），其余为图，未收；“海林根施塔特遗嘱”页脚的两条注释识别严重错乱，已作为脚注去掉。
- 边栏批注与正文版面交错的页（贝多芬传、米开朗琪罗传、托尔斯泰传中各有若干页），按版面位置把边栏文字滤掉，个别靠近边栏的行首、行尾字符可能受影响。
- 书中引诗、书信里的分行，若版面上没有缩进，被接成了一个自然段。
- 脚注识别中无序号的两处（第 228、279 页）已手工去除；其他无序号的脚注行如有漏网，可能留在段尾。
