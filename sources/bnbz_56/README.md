# 人生采访

- 底本：萧乾著《人生采访》，作家出版社 2000 年 7 月第 1 版（“百年百种优秀中国文学图书”丛书；据文化生活出版社 1947 年 4 月初版本重新排印）。文字由书籍扫描件经 OCR 识别、整理而成，**尚未逐字校对**。
- 整理：前记一页，其后三十六篇各占一页（上部“国外”十七篇、下部“国内”十九篇，分别在 pages.json 第三项标明）；页内小标题（编号小节、日期小节、副题式小标题）各为一节。去掉了封面、版权页、作者简介、丛书前言/书目/评委名单、目录、各页眉（“人生采访”“子：西欧……”等地区页眉）、页码、书末“本书根据……重新排印—编者”说明及扫描水印页。
- 页标题取自书的目录；目录里“从德奥沿义[意]瑞边境到巴黎”“从兖[兖]州到济宁”的方括号校字原样保留；“林炎发入狱”“一九四〇年的圣诞”据目录/内容改正了 OCR 的“人”“一九四年”。
- 编号小节：OCR 把序号与标题粘在一起，整理时在序号后加了一个空格（如“二 吊和平宫”）。《瑞士之行》第一节“怎样去的”、《冷眼看台湾》《琼岛不是太平岛》等少数处序号“一”OCR 缺失，按原样不补号；《平绥道上》第一部分无编号，其内容直接归在页标题节下，之后是“二”至“七”。《安南的启示》第一个小标题“滇越道上瞑想录”前无引言，故该页第一节即此。“灰烬”在 OCR 稿中被拆成“灰”“烬”两行，已合并。
- 琼岛一文中的投资比例表（矿 53%、工 6%……）每行一段，栏间以全角空格隔开。
- 已知 OCR 问题：个别日期小标题疑有错字（如《从德奥沿义[意]瑞边境到巴黎》中“十月六日人窃插曲”，从上下文看应为“十月十六日”，原样保留）；数处硬换行块（如《由伦敦到法兰克福》“十月八日战犯开审”中间一页、《劫后的马来亚》第 173–174 页）按标点启发式接段，个别段落可能被错误合并或拆开；《三个检查员》中一处孤立字母“A”已删除。未发现整页缺失（PDF 页码连续）。
- 原书注释已按站内格式（注：词语：解释）挂在所注段落后，注码已去掉；个别注释的词语位置为推定。
