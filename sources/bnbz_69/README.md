# 燕山夜话（bnbz_69）

## 底本
马南邨（邓拓）著《燕山夜话》，作家出版社“百年百种优秀中国文学图书”丛书本，2000年7月第1版（原北京出版社1961—1962年五集本）。据 OCR 整理稿（含五集：第一集至第五集）。

## 整理说明
- 每篇杂文一页，页标题用文章题目；各集的“两点说明”“卷前寄语”“作者的话”“编余题记”“奉告读者”（作者原序语）各占一页；pages.json 第三项为“第一集”至“第五集”分组。
- 去掉：封面、版权页、作者小传、丛书前言、评委与编委名单、丛书书目、1979年丁一岚《不单是为了纪念——写在〈燕山夜话〉再版的时候》（再版说明，非作者原文）、目录页、各集扉页、页眉页码、书末 Anna's Archive 水印页。
- 合并了换行和跨页断开的段落，保留原字，不改写。

## 已知问题
- 第三集“（无题）”页（在《“推事”种种》之后，PDF 第 204 页）：该篇标题 OCR 只识出首字“涵”，目录项也缺，按规则记作“（无题）”（内容论“涵养”）。
- 目录页 OCR 不全，故部分文章（《不怕天》《起死回生》《广阳学派》《多学少评》等）凭正文标题定页名。
- 第一集扉页集序号 OCR 丢失，据顺序记为第一集。
- 《谁最早发现美洲》一文中俄文词“Φy一山AH”为 OCR 乱码，保留原样。
- 正文 OCR 已无整篇缺页迹象；空白页均为文章间的反面页。
