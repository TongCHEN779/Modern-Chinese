# 郭小川诗选

底本：郭小川《郭小川诗选》，人民文学出版社，2000年7月第1版（“百年百种优秀中国文学图书”丛书），2001年10月第2次印刷；原版为1977年人民文学出版社版。

整理说明：
- 依据 OCR 逐行识别（json）按诗行整理，每首诗一页；短诗、长诗分组。《将军三部曲（选章）》仅收“月下”一章，首节名为“月下 一 散会以后”。
- 去掉：封面、版权页、丛书前言、书目、评委名单、目录页、页码、页眉；每页底部的首刊出处等脚注，以及《厦门风姿》《战台风》等诗行末尾的脚注序号（①②）；诗题后的“*”。
- 诗题取自书中标题与目录（《骆驼商人挽歌》《祝酒歌》等的副题按目录括注）。

已知 OCR 问题：
- 多首诗的数字小节号“一”“二”等（《山中》《雪兆丰年》《望星空》《厦门风姿》《乡村大道》《西出阳关》《五言诗二首》）部分未被 OCR 识别，已依小节间距和前后连续的序号补出，可能有位置偏差。
- 《深深的山谷》最后附近及《将军三部曲》末页有一处“小川”落款疑似被识别为乱码，已略去。
- 《投入火热的斗争》一处孤立单字“学”（识别置信度极低）已删。
- 《无题（残篇）》《答问（残篇）》为作者残篇，非缺页。《秋歌（之一）》《秋歌（之六）》标题首字“秋”OCR丢失，据目录补。
- 《草鞋》《晨歌》两首目录页OCR缺失，标题取自正文页。
