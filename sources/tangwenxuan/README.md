# 唐文选

- 底本：李浩选，阎琦、李浩、李芳民注释《唐文选》（中国古典文学读本丛书典藏），人民文学出版社，2020 年第 1 次印刷（2011 年第 1 版）。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：去掉封面、版权页、丛书广告、目录与三页插图（书法图版）；收前言一页（分前言、一至四各一节），其后按作者一人一页（共 63 位，按书中时序），页内第一节为作者小传，其后每篇一节。文末的出处行（如“《全唐文》卷五”）照原书作为该篇最后一段保留。
- 注释：原书的注释集中印在每位作者全部文章之后，编号 [n] 在该作者各篇中连续排列，与正文标号对应；转换时按正文标号把每条注放回所属段之后。每篇标题上的标号（如“王羲之论[1]”）所对应的注释是该篇的说明，作为该节“题解”。注首若是原文词语则取为词语（“某某”句、“某某”二句取引号内的词语），否则取标号前一小段正文为词语；一条注含多个独立词条者用“注原：”保持整条。前言的注是页下脚注，同样放回所属段后。
- 标题：《执秤诫》《梅花赋》等原书标题带“并序”者保留；“钴𬭁潭西小丘记”正文标题 OCR 为“钴铒潭西小丘记”，已按目录校为“钴鉧潭西小丘记”（此处仍存疑，目录亦 OCR 错乱）；刘宽夫文的标题目录丢失，正文 OCR 为“剌竹记”，原样保留（疑为“翦竹记”）。柳宗元页末的《赖蛳传》不在目录中，但正文有标题与注释，单立一节；《三戒》三则的小标题作为该节内的短段。
- OCR 已知问题：正文标号多处被误识（如“[7]”“[9]”识为“[2]”，舒元舆《养狸述》多出“[528]”），已按序号连续性校正或丢弃；魏徵《论时政第二疏》注 [29]、柳宗元注 [507] 的正文标号缺失，按词语或邻近标号定位，个别（约 1 条）未能在所属段原文里找到词语。跨页断开的段落凡前段无句末标点者已接合，其余依整理稿原样，可能有个别误断。插图页文字混入处（《仙掌铭》《子产不毁乡校颂》《草堂记》《叙事》文末）已删去。《与元九书》开头“微之足下.”原样（疑为“：”）。
