- 底本：张资平《长途》，“张资平情爱作品系列”之一，宁夏人民出版社 1993 年 6 月第 1 版（ISBN 7-227-00983-1/I·221）。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
