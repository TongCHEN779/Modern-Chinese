# 白色花：二十人集

## 底本
绿原、牛汉 编《白色花：二十人集》，人民文学出版社，2000 年 7 月（“百年百种优秀中国文学图书”丛书版，据 1981 年人民文学出版社版重印）。OCR 自 PDF，简体。

## 整理说明
- 共 21 页：序（绿原）与二十位诗人各一页；每位诗人页首为作者小传（节名即诗人名），其后每首诗一节，诗行逐行成段。
- 去掉：封面、版权页、内容简介、丛书前言、评委与编委名单、丛书书目、目次页、页眉页脚页码、各诗人的扉页/目录页、末页 Anna's Archive 元数据。
- 保留：诗末日期、地点与“（选自……）”出处说明；组诗/分章诗内部的小标题与序号（如《延河散歌》的“星/山/河/野花”、《牢狱篇》《一条小河的三部曲》的分章、方然《报信者》的数字序号）作为诗中一行，不另分节。
- 页脚脚注去掉（阿垅《再生的日子》、牛汉《鄂尔多斯草原》“牙布牙”注、鲁煤《焚书》题注后的作者附注），正文中的注号 * ① 已删。
- 诗行按页面坐标重排：过长折行（行尾近右边界、下一行缩进）接为一行，其余每行一行；与 full.txt 的合并方式略有不同。
- 更正的明显 OCR 错字：序中“阿城”→“阿垅”；牛汉小传“负贵”→“负责”。人名按各家实际写法：阿垅、鲁藜、冀汸、芦甸、朱谷怀。

## 已知问题
- 总目次（p25–26）与各诗人目录页 OCR 残缺，部分诗题首字在正文中丢失（《窑洞》《纤夫》《泥土》《山坡》《行程》《诗人》《航海》《问讯》《回响》《有赠》等），标题依各诗人目录页补回；《贝壳》（鲁藜）、《雪天》（彭燕郊）、《青春》（曾卓）、《沉默》（朱健）的标题在正文中整行丢失，按目录页标题和诗的起止位置补回，起点为推定。
- 阿垅目录页顺序与书中次序不一致，按书中实际次序排列。
- 缺页：PDF 第 74 页（鲁藜《蜂之歌》之后）、234 页（绿原《重读〈圣经〉》之后）、286 页（徐放之后）、288 页（牛汉小传后）在 OCR 中无文字，可能为空白页，也可能漏识别；各页前一页诗均有收尾日期或自然终结，疑缺不大。序中原 p19 并入 p18 识别。
- 钟瑄页 p147 上有碎片文字（疑为插图/扉页杂讯），已略去。
- 诗中偶有零散数字或符号（如阿垅《琴的献祭》“5”、孙钿《雨》“4”、牛汉《鄂尔多斯草原》“一”“T”之类），可能是诗内序号或 OCR 噪点；明显的孤立拉丁字母已删，数字保留。
- 《白色花》另有总目所称“一百一十九首”，本整理含组诗小篇共 119 首（114 个目录条目）。
