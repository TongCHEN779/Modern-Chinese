# 风流神判：郑板桥

- 底本：吴洪激著《风流神判：郑板桥》（“中国名人轶事丛书”之十二，吴洪激主编），武汉大学出版社、台湾汉欣文化事业有限公司联合出版发行，1995 年 11 月第 1 版第 1 次印刷（黄冈地委印刷厂印刷；ISBN 7-307-02009-2/K·178）。书名页作“风流神判　郑板桥”，版权页（CIP）作“风流神判—郑板桥”，书眉作“风流神判——郑板桥”；此处取“风流神判：郑板桥”。主编絮语文末署“1994 年腊尽”，但版权页出版时间为 1995 年 11 月。文字由 Internet Archive 的扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：共十三页——丛书出版缘由、主编絮语（吴洪激序）、正文十章（依书目录：初审石头案、计了私盐案、巧断僧尼案、揭穿善人案、奇侦殉节案、智勘投毒案、复审斗牛案、巧圆赖婚案、重理无尸案、宽判杀人案）、附录“郑板桥年谱”，各占一页。各章以书中“一、二、三……”分节，每章第一节无编号，节名取“一”；《揭穿善人案》全章无节号，只有一节，节名同页标题。
- 节号补回：书中节号“二、三、四”等多数被 OCR 漏识或误识（章名与节号为大号字），据版面空行位置与序号次序补回（初审石头案二三、计了私盐案二三、巧断僧尼案二、奇侦殉节案二三、智勘投毒案二三、复审斗牛案二、巧圆赖婚案二三、重理无尸案二、宽判杀人案二三；其余节号 OCR 已识出）。《揭穿善人案》各案之间的转换在书中无节号、无空行，故未分节。补回为推断，如有误差在这些“二、三”处。
- 去掉的内容：封面、丛书编审委员会名单、版权页（CIP 数据）、图书馆章页、Internet Archive 水印页、目录页、各章题名页、页眉页脚与页码、书末丛书广告页与封底简介；全书各章所附整页插图（及插图页图中文字的 OCR 碎片），以及插图页下的图说（共十处，图说为所配正文的摘句，文字与正文略有出入）；主编絮语文末署名“吴洪激”及序首的签名残片。
- 段落按扫描版面的缩进与行宽重建（跨行、跨页的段落已接合）。诗词、对联、判词前后的引诗按原书每行一段，用“诗：”行；状子、陈驿散曲、《西江月》词、陈成“判”词等整块排印的引文按一段处理（“判”“此判”为书中单独成行的字样）。
- 年谱：书中为四栏表格（年号、公元、年龄、生平及事迹），每行一段、各栏以全角空格隔开，首行为栏目名；事迹栏的折行与归属行据版面位置推定。康熙三十三年（1694）一行在书中版面上无事迹，保留为空。
- OCR 已知问题：个别单字错识与引号缺失未逐一校改（如年谱“占哔之暇”或应为“佔毕之暇”；主编絮语“和病瘰天下”，封底作“疯天下”，原字存疑）；“……”常被识作“…”“。。”等；半角括号、冒号、问号已改为全角。两处按版面补了漏识的符号：巧断僧尼案“就莫怪”段末的 OCR 碎片“9”改为引号“”” 、“夏、吕二姓族人”段末“。。”改为“……”，巧圆赖婚案“魏相公”后单独识出的“”” 照录；““梆！梆！”一句疑缺后引号，保留原样。主编絮语称“《揭穿殉节案》”，书中章名为“奇侦殉节案”，均照原书。页眉页码及插图页的孤立字符已按版面位置删去，仍可能有遗漏。
