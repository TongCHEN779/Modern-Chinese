# 中国现代作家选集·叶圣陶

- 底本：《中国现代作家选集·叶圣陶》，叶至善 编，人民文学出版社、三联书店香港分店联合编辑出版，1985 年 9 月北京第 1 版第 1 次印刷（书号 10019·3827，字数 202,000，印数 0,001—8,000）。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 结构：卷首《自序》（一九八二年二月）一页；“作品部分”之“散文”二十七篇（《没有秋虫的地方》至《佩弦的死讯》）、“童话”七篇（《画眉》《玫瑰和金鱼》《跛乞丐》《稻草人》《古代英雄的石像》《书的夜话》《蚕和蚂蚁》）、“小说”十三篇（《一生》《一个朋友》《小蚬的回家》《校长》《潘先生在难中》《外国旗》《搭班子》《遗腹子》《抗争》《赤着的脚》《多收了三五斗》《丁祭》《皮包》）；“资料部分”叶至善《编后絮语》、朱自清《叶圣陶的短篇小说》、曾华鹏 范伯群《叶圣陶作品评析》、商金林《叶圣陶年表》。每篇一页，页标题依书的目次；页内小标题（《过去随谈》《潘先生在难中》《抗争》的数字节号，《叶圣陶作品评析》的数字节号，《两法师》的“附记”，年表的各年）各为一节。篇末的写作日期原样保留为末段；资料部分各篇的署名（叶至善、朱自清、曾华鹏 范伯群、商金林）保留为首段。
- 去掉的内容：封面、扉页、版权页、目次、“作品部分”“散文”“童话”“小说”“资料部分”隔页、每页页码、页下脚注（《叶圣陶作品评析》各页的引文出处注）及正文里对应的圈码标记（①②③④）；PDF 末页（第 299 页）的 Anna's Archive 水印说明。PDF 第 9、249 页为空白页。
