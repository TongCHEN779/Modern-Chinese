# 杜甫诗选

- 底本：山东大学中文系古典文学教研室选注、袁世硕 董治安 张可礼 张忠纲修订《杜甫诗选》，人民文学出版社“中国古典文学读本丛书典藏”，2020 年版（1998 年初版）。文字由书籍扫描件（PDF）经 OCR 识别、整理而成，**尚未逐字校对**。
- 整理：第一页为袁世硕执笔的《前言》（含“附记”）；其后按目录顺序（编年）把 193 首诗分作八页，页标题为“第一首题—最后一首题”；每首为一节，节名取书中诗题（组诗如《前出塞九首》《秋兴八首》合为一节，各首以“其一”“其二”起首的段分隔）；末页为附录《雕赋》。
- 注释：书中把注释集中放在每首诗之后，按正文里的 [1][2]… 序号放回各自所属的段后；每首的 [1] 号（题解）放在诗前作“题解”。诗每四句左右为一段，句间以“/”分行；《同元使君〈舂陵行〉并序》《观公孙大娘弟子舞〈剑器〉行并序》等的序文各为一段。每条原注为一行（“注原：”，不再拆分）；以“某某”二句／句起首的注，词语取引号内的字；少数无明确词语的评说式注释，词语取注号前的几个字，原注全文保留。
- 未收：封面、版权页、丛书广告、目录页（目录页的诗题仅用于定位）、页眉页脚页码、校对说明性的内容。
- OCR 已知问题与改动：OCR 常把注号数字认错（如 7、9 识成 2），故按先后顺序而不按数字对应；诗题后的上标注号、孤立的“[1]”行（位置错乱）已去掉；目录中少数诗题 OCR 有误（如“月”识成“且”、“宿昔”识成“宿茸”、“洛阳”识成“洛阻”、“客从”识成“客丛”），诗题以正文为准。个别字词因 OCR 缺字（如《登兖州城楼》“鲁殿”后缺“灵光”处）、拼音注文的识别错误（如“1éi”）原样保留，未作更正。
