# 3小时读懂周朝

- 底本：姜若木编著《3小时读懂周朝》（“3小时一目了然速读历史故事”丛书），京华出版社，2011 年 4 月第 1 版。文字由书籍扫描件（PDF）经 OCR 识别、整理而成，**尚未逐字校对**。
- 整理：按书自己的目录分页：前言一页，第一至第十一章各一页，附录一、二、三各一页；页内小标题即书中各节标题（“一、二、三……”），第十章“战国之四公子”与附录一“周代的文学”下另按书中小标题分出（一）（二）…各节。书中小节标题的序号 OCR 常漏识，现按目录与顺序补回。章末“点评”“相关链接”及其中的小文章标题，作为所在节内的独立段落保留。附录三的时间表每行一段，各栏用全角空格隔开。
- 去掉的内容：封面、封底、版权页、目录页、出版社信息页、页眉（书名）、页码、侧边章名标签、插图及图片说明、地图与示意图上的文字、页面角标。
- OCR 已知问题：
  - 段落按行坐标（缩进、行宽）重建，围绕插图的窄栏文字已按阅读顺序合并，个别段落分合可能与原书略有出入。
  - 识别残留的错字、漏字未逐一校改，只改了把握极大者：“自已”统一改为“自己”；附录三“康正”改为“康王”，“厉王（~胡星”改为“厉王（~胡）”。
  - 全书括号、感叹号、问号有半角与全角混用，保持识别原样。
  - 第十章“秦赵争衡”中楼缓一段，“大王，你这是”处文字在识别稿中即已截断，未补。
  - 附录三时间表中“在位时间”一栏只有数字，原书未见单位；“懿王”一行的名讳（~）缺字，原样保留。
  - 书中个别用字存疑（如“周昭王南恨荆蛮地”的“恨”，目录亦同），未改。
