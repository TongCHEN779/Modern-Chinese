- 本书由大众文艺出版社“中国全史”丛书中的3册合并而成，共 120 页；各册整理记录如下。

## 第1册（tmp_qsyy_ming_gw_1）

- 底本：（民国）许啸天著《明代宫闱史》，大众文艺出版社，“中国全史”丛书；年份不详（扫描件版权页未见出版年）。本册为全书上册（第一册），收第一回至第四十回；全书共一百二十回，其余各册另行整理。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成。
- 整理：每回一页，页标题为“第N回 上联 下联”，回目据各回正文开头，并与目录页核对；页内不分节。书前无序、例言，书末无跋，本册未另设页。
- 去掉的内容：封面、书名页、目录页（乱序，仅用于核对回目）、“中国全史”丛书页眉及版权/责任编辑页、插图、页码、页眉页脚。
- 回数连续：第一至四十回，不重不漏，无缺页。
- 回目：据目录改正两处 OCR 错识——“胡茄”改“胡笳”（第四十回）、“衾稠”改“衾裯”（第二十二回）。第十九回“趺”、第二十五回“杜鹃”，目录页识作“跌”“杜鹊”，以正文为准。
- 段落：同段因换页断开处已接上。祭文（第二十一回）、诗词、判词（第三十四回）等整块文字，因版面缩进、OCR 逐行断开，已按标点并为整段，回首开篇诗词仍按版面逐句一行，插在正文中的长篇韵文并为一段。
- OCR 已知问题：第二十二回“弃儒卖艺。”后有一处“i：”，当为“……道：”之类的残字，原样保留；第二十三回“歃血0为盟”中的“0”为噪点，已删。书中人名用字（如“篾尔干”“孛端察儿”）多有异写，未改。半角标点已改全角。
