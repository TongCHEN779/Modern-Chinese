# 3小时读懂明朝

- 底本：姜若木编著《3小时读懂明朝》（“一目了然速读史”系列），京华出版社，2011 年 4 月第 1 版（据版权页）。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：前言一页；正文六章各一页，页标题保留“第一章 …”整体；章内各小节（“一、二、三”及书中的小标题，如“徐达”“永乐大钟”“梃击案”）各为一节；四个附录各占一页（附录四为帝王年表，每行一段、各栏以全角空格隔开）。每章页首另有一节，内容为该章章名页上的一句导语。各章末的“点评”“相关链接”及其中的“某某小传”栏目，保留在所在小节内，栏目名单独成段。
- 去掉了：封面、版权页、目录页、页眉（“3小时读懂明朝”）、页码、侧边竖排章名、插图、地图及其图中文字、图片说明、手迹/碑帖图版文字、书末 OCR 附带的“General Information”信息页。
- 段落：书中大量文字绕图排成窄栏，按行坐标（缩进、行宽）重新接合为自然段，跨页接合。
- 已知问题：
  - 第一章“二、从和尚到元帅”“三、招贤纳士”、第四章等小节内页面绕图处，段落边界依缩进推定，个别处可能与原书略有出入。
  - 小标题序号：OCR 在“一、石人一只眼……”“一、专制统治的强化”“一、土木堡之变”“二、明穆宗朱载垕”“二、权倾朝野的魏忠贤”等处漏识序号，已按同章其他小标题顺序补回；第四章“五、放眼望世界”正文有而目录页未列，照正文收入；第五章“红丸案”目录未列，照正文收入。
  - 附录一三个作品小标题的破折号，OCR 中有“—”“——”不一，统一为“——”。
  - 附录四年表“世宗”名讳 OCR 作“朱厚熄”，改为“朱厚熜”。全书“自已”统一改作“自己”。其余识别错字未改。
  - 第六章“四、义军四起，上吊煤山”中“李自成中原大捷要图”一图的图中文字已去除，图旁的正文（第 165–166 页）按行坐标取出，未对照影印页。
