# 世界短篇小说精品文库·中国卷

- 底本：柳鸣九主编、杨义编选《世界短篇小说精品文库·中国卷》，海峡文艺出版社，1996 年 8 月第 1 版（ISBN 7-80534-891-X/I·786）。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 结构：序言两页（柳鸣九《序》、杨义《编选者序》，后者含“一”至“七”七节），其后每篇小说一页，共 41 篇，作者 35 位，另有三篇无署名的话本（《快嘴李翠莲记》《错斩崔宁》《杜十娘怒沉百宝箱》，页的第三项统一写“话本”）。页标题用书中篇名（《荷花淀》带副题“——白洋淀纪事之二”）。
- 每篇小说页的节：小说正文（篇内有“一、二、三”“第一章”“第一回”等小标题的，各另起一节，节名即小标题）；“作家作品简介”（书中印在每篇之后，内含作者生平及作品评介，整节保留，未拆为“作者小传”）；古代作品的“注释”（书中印在篇末，集中给出）已按站内格式拆开，各条紧跟在所注段落之后，不再单设“注释”节。现当代作品没有集中注释。
- 去掉的内容：封面、版权页、编委会名单、目录页、页眉页脚与页码、OCR 噪点；《手》《山那面人家》两篇页脚的个别脚注（及正文中对应的 ① 标记）；《红高粱》正文中的“* * *”分隔号（只表示场景转换）。场景转换的空行未另作标记。
- 整理中的推定与改动：
  - 《林家铺子》《包氏父子》《对倒》《棋王》《红高粱》各篇的小节号“一”（均在篇首）以及《林家铺子》《包氏父子》《红高粱》的“二”，《对倒》的“二”，序言里的“二”，OCR 都没有识别出来（单字笔画少，被漏识），我据版面空行位置补回；其余编号小节（三、四……）均为 OCR 原有。
  - 《合影楼》回目分两行印，已合并为一个节名；“防奸盗刻意藏形 起情氛无心露影”的空格为补加，“盜”按简体改作“盗”。
  - 作家名按书中写法：OCR 中“吴组湘（吴组细）”“蕭红”依据目录与全书写法改作“吴组缃”“萧红”；《紫鹭湖的忧郁》《祝福》《春桃》《丈夫》《手》等篇名因 OCR 在大字标题处漏字，据目录补全。
  - 阿Q正传第一章的标题 OCR 作“第一章这一章算是序”，原样保留，仅在“章”后补空格。
- OCR 已知问题：
  - 原 full.txt 漏掉了 28 页（如 p69、p107、p114、p115、p117、p227、p300、p320、p385、p443、p497、p549、p558、p567、p624、p645、p661、p666、p688、p692、p697–699、p704–706、p728、p734），本册直接从逐页识别结果（json）重建，这些页的内容均已收入，不缺页。
  - 古代作品（《女化蚕》至《葛巾》共 14 篇）的注释原为 OCR 版面混乱的碎段（折行拆条、编号错乱、缺词条），现已对照影印页重排为“词语：解释”，共 323 条，放在所注段落之后（词语取注文开头被注的词，须为该段原文的连续字串）。重排时的改动：① 正文里的注码按影印页纠正（如“②0”→⑳，误识的 ①③ 等按注的实际序号改正），OCR 丢失的注码按注的词语位置补回（补在词语之后，位置为推定；≥36 的序号站内无对应字符，不补），个别无法对应的零散注码（《合影楼》“林下③”、《婴宁》“舁归③①”后的 ①）删去；② 注文开头词语与正文用字不一致者（OCR 或原书异写，如“上已日”“覆餗”“计较一个常便”“阴骂”），词语取正文里的字串，原注开头词语保留在解释里；“某某句：”式的注，词语取正文里该句开头的字；③ 注文里的明显 OCR 错字按影印页改正（如“素缣”“褰幄”“觏止”“物类相感志”“斑犀钿花合子”）。《合影楼》注⑫“寤寐之求”与“参差之采”在原书合为一条（无⑬）。
  - 《包氏父子》“二——二——二十元……通学生除——除——除宿费膳费外”“郭纯，你要叫队员大家都……”两处漏识已据影印页补回；《林家铺子》“明秀，你的学校里有什么抗日会么”一段至“救苦救难观世音”各处丢失的破折号（“——”）已据影印页补回，其余各处仍可能有破折号被识成单个“—”。古代篇“霍小玉传”注⑤“便辟”已补全。
  - 分段依据行首缩进与行宽重建，诗词、歌谣、对联每行一段（说书、唱词里的折行处有个别误断）；《棋王》为长段落、对话多夹在段内，书中即如此，未强拆。
  - 小说篇末的写作日期、出处等小字保留为独立一段；《天堂之游》末“（选自《八十一梦》）”保留。个别外文被识别为空格丢失的形态（如《天堂之游》“Howdoyou do?"”），未改。
  - 《迟桂花》篇末“作者附注”四字为右对齐署名位置的字样，保留在正文末。
