# 蒲桥集

- 底本：汪曾祺著《蒲桥集》，作家出版社 2000 年 7 月第 1 版（“百年百种优秀中国文学图书”丛书，据 1989 年作家出版社初版）。文字由书籍扫描件经 OCR 识别、整理而成，未逐字校对。
- 收入：自序（页 p01）、正文六十一篇各占一页（页标题按书的目录）、再版后记（1990 年 12 月）。页内小标题按书中原有小标题分节；无小标题的篇目只有一节。
- 去掉：封面、丛书页眉与丛书前言/书目、CIP 版权页、封底作者简介、目录页、页码、末尾电子书信息页。
- 整理：按书中自然段分行，跨页被断开的段落已接上（以 OCR 坐标判断段首缩进）；混入行首、行末的页码已删除；篇末日期、写作地点原样保留为段落。诗句每行一段。
- OCR 已知问题：
  - 原稿未做逐字校对，个别错字、形近字（如“楼草打兔子”应为“搂草打兔子”）、中文逗号与句号丢失未改。
  - 《午门》《口蘑》《八仙》《银铛》《鳜鱼》《坝上》等篇的标题在 OCR 中被竖排拆成单字，据目录复原；《从桂林山水说到电视连续剧〈红楼梦〉》标题在 OCR 中分成两行，据目录合并。《杜甫草堂、三苏祠、升庵祠》《熬鹰、逮獾子》正文标题用“·”，页标题依目录用“、”。
  - 《天山行色》开头右下对齐的“行色匆匆”“常语”两行，原样保留为开头两段。
  - 《夏天的昆虫》第一段前，OCR 似漏掉一个小标题（开头“烟烟我们那里叫做‘叫子’”的“烟烟”也疑为字误），未补。
  - 《旅途杂记》小标题“三苏祠”“伏小六、伏小八”照 OCR 保留，与正文内容似不完全吻合，疑标题识别有误，未改。
  - 小标题中“野鸭·鹌鹑·斑鸠·鹞”“荠菜”“刀螂”据正文改了形近字；《故乡的食物》另一小标题的“萎蒿”原样保留。
  - 《字的灾难》末句句号缺失，原样保留。
  - 未发现整页缺失（PDF 页码 p0015–p0301 连续）；全书约 15.4 万字，版权页标“214 千字”，差额未查明，不能排除个别段落漏识。
