# 官场现形记

## 底本
李宝嘉（南亭亭长）著，张友鹤校注，《官场现形记》（上、下），人民文学出版社，2000 年 7 月第 1 版（“百年百种优秀中国文学图书”丛书）。该版以光绪二十九年（1903）上海世界繁华报本为底本，参校光绪三十年粤东书局石印本、宣统元年崇本堂石印本。现存六十回。

## 整理说明
- 按书的回目分为 60 页（第一回至第六十回），页标题为“第N回 上联 下联”，一回一节，全文共约 64.2 万字。
- 保持原字（如“捱”“拚”等写法），不改写；回末套语（“且听下回分解”“且听续编分解”“且听三续书中分解”“且听五编分解”“前半部终”）原样保留。
- 去掉：封面、版权页、作者小传页、丛书前言与评委/编委名单、编辑部“出版说明”、目录、每页页眉（回目标题）和页码、每页页脚的校注者脚注（含正文中的脚注序号 ①②… 和 “*”）、书末校注者所写附录“清代的官制”和后记、书末“丛书书目”页。
- 自动合并了断行与跨页的段落。书信、告示、谕札等引文内部每行缩进，已并回同一段；回内诗句每句一行（如第四十九回揭帖诗）。

## 已知 OCR 问题
- 正文取自逐页识别结果（json）重排，不是 full.txt 的页内顺序；个别单字可能有形近误识，未逐一校改。
- 正文中的内引号（原书的 ‘ ’ 单引号、部分 “ ” ）OCR 常漏识，故部分对话/引文只有开引号或只有闭引号，如第六十回病人梦话中的内引号缺失。
- 第四十九回（PDF 第 794 页）“到了中年，斫丧过度”的“斫”，OCR 误作数字“5”，已据文意改为“斫”。
- 脚注按版面位置（行距、缩进）自动切除，个别页判定可能有偏差，少量脚注碎片或正文行可能错位；第二十二回回目“勖孝子”依目录页改正（页眉 OCR 作“勖亲子”）。未发现整页缺失，60 回起止俱全。
