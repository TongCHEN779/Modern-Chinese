# 北方的河

- 底本：张承志《北方的河》，作家出版社，2000 年 7 月第 1 版（“百年百种优秀中国文学图书”丛书）。收中篇《北方的河》（1984）、《黑骏马》（1982）、《西省暗杀考》（1989）、《黄泥小屋》（1985）。文字由书籍扫描件经 OCR 识别、整理而成，**尚未逐字校对**。
- 分页：每篇作品为一组（pages.json 第三项）；《北方的河》《西省暗杀考》《黄泥小屋》各有一页篇名页（放篇首题记/引子），其后按“第一章……”分页；《黑骏马》为一页，页内按书中“一、三、四……八”分节；《西省暗杀考》另有“补考”一页，页末为作者“注释”；《黄泥小屋》章后有“结尾”“再结尾”两页。
- 去掉：封面、版权页、作者简介页、丛书前言/书目/编委名单、目录页、末尾电子书信息页、页眉页脚。《黑骏马》页脚脚注（“艾勒”“钢嘎·哈拉”“伯勒根”“英语：快乐”）及正文脚注符号已删；《西省暗杀考》作者集中注释保留，正文里的注号保留。夹在正文里的页码数字（如“附35上”“有些43若失所依”等 5 处）已删。
- 已知问题：
  - 《黑骏马》“一”“二”两个节号、《黄泥小屋》第一章“一”“二”、第二章“一”、第三章“一”“二”的节号 OCR 丢失；各章首节按“一”命名，其中被吞掉的“二”节（《黑骏马》、《黄泥小屋》第一、三章）并入前一节，具体起点未能确定。
  - 《西省暗杀考》“注释”页 OCR 次序错乱（部分词条断行、注号缺失，如“汤瓶”前缺⑧），原样按行保留。
  - 第二章《北方的河》“青枝呀绿叶展开了”及“哎哟哟，西宁城街里我去过”等歌词在 OCR 中与正文穿插，正文句子（如“……止住了他”）被歌词截断，原样保留。
  - 《黄泥小屋》“再结尾”里的歌词行也与正文行穿插，次序可能与原书不同。
  - 全书未发现整页缺失，但跨页断句靠规则合并，个别处可能误并或漏并。
