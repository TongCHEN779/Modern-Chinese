# 金元明清词选

- 底本：夏承焘、张璋编选《金元明清词选》，人民文学出版社“中国古典文学读本丛书典藏”，2016 年版（初版 1983 年）。文字由书籍扫描件（PDF）经 OCR 识别、整理而成，**尚未逐字校对**。
- 整理：p01 为《前言》（分“一”至“五”五节，末节含编选说明）；p02 起每位词人一页（共 226 家：金词 50 首、元词 81 首、明词、清词，各页分组名为“金词”“元词”“明词”“清词”），页标题为词人姓名，页首引言为作者小传，其后每首词一节，节名为“词牌”或“词牌·题名”（词前小序较长的，节名只取词牌，小序作该节第一段）。同牌多首同名；原书“某某（四首）”后接“二、三、四”的组词，拆成“词牌·一”“词牌·二”……各一节，不再带“（N首）”。词句以“/”分行，上下阕各为一段。
- 题解、前人评语：书中紧接在词后的题解放在节首作“题解：”；其后的“前人评语”等集评整段照录，放在该节末尾作“原：”（保留“前人评语：”字样）。
- 注释：原书注释集中印在每个朝代（金、元、明、清）各自词作之后，编号 [1]… 在各朝内连续（OCR 常把 7、9 识成 2，已按顺序对回）。转换时按编号配对放回所注那一段之后，一律用 `注原：` 行保持整条（原注内常有“……。《某书》：……”式多处引文，避免被站点拆成几条）。词语取原注开头的词；“‘某某’三句”类取引号内的词，“三句”留在解释开头；词语与正文写法不一致（OCR 或版本差异，约 3%）的，改取所注处附近正文中与之相同的几个字，解释保持原注全文。共 1973 条，金 275、元 372、明 418、清 908。
- 未收：封面、书名页、版权页、目录页、丛书广告、插页。
- OCR 已知问题：
  - 正文中的注释编号约有 12 处漏识（元 1、明 5、清 6），其注靠词语在前后标号之间找回所属段，找不到的挂在前一标号所在段末。
  - 清词《湘月》（龚自珍）原文“曾是东华生小客，屠狗功名，雕龙文卷，岂是平生意”一行有缺漏，注释 [537][538] 的词语因而对不上正文，按上述规则挂接；原文未补。
  - 梁鼎芬《菩萨蛮》（三首）末首的断行顺序据版面坐标调回；萨都剌《百字令》、王鹏运《浪淘沙》的断行已接上。
  - 张惠言《木兰花慢·杨花》题解后的“附：”标记未收，所附章质夫、苏轼《水龙吟》两词各作一节。
  - 版面疑似误识的人名、生僻字照录：张蜒（疑为张綖）、舒𬱖、汤允𪟝、赵孟𫖯，词中“o长妖鸟”“碧镱缃”等；个别词牌、标点（半角逗号、问号）已按上下文改全角。
  - 少数词前小序、题解的分段依据字号与版面判断，个别可能误分。
