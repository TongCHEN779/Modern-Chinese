# 八大山人传奇

- 底本：李晃生著《八大山人传奇》（“中国名人轶事丛书”，吴洪激主编），武汉大学出版社、台湾汉欣文化事业有限公司联合出版，1994 年 8 月第 1 版第 1 次印刷（ISBN 7-307-01784-9/K·157）。文字由 Anna's Archive（DuXiu 扫描件）的 PDF 经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 丛书序号：本册为“中国名人轶事丛书”之六（据用户确认）。OCR 文件夹名“5、八大山人传奇”的序号 5 是误标；书中版权页、书名页均未印“之几”，书末丛书广告页的排序亦与之不符。“之五”是站内《蒲松龄传奇》，未改动。目录名 mrys_06 沿用，不随序号更改。
- 整理：共十二页——丛书出版缘由、主编絮语（吴洪激序）、第一至第十章，各占一页。章内以书中“二、三、四……”为小标题分节，书中第一节无编号，节名取“一”。每章的小标题“二”（第六、八章还有“三”）在 OCR 稿中漏识，据版面行距（大空行）位置补回。
- 去掉的内容：封面、书名页、版权页（CIP、ISBN、定价）、目录页、页眉（“八大山人传奇”“第×章 ×××”）、页码、丛书编审委员会名单与书末丛书广告页、Anna's Archive 水印页；出版缘由、主编絮语文末的署名（吴洪激）。“主编絮语”文末写作日期“一九九三年七月于湖北古城黄州”保留。
- 段落依 OCR 版面坐标按首行缩进重建（跨行、跨页的段落已接合）。书中的题画诗、对联、引用的古诗按“诗：”居中，每首一行，句间以“/”分行。
- OCR 已知问题：作者署名书名页、CIP、主编絮语均作“李晃生”，照录。人名常见同形混用（朱耷/朱套/朱奔、朱谋垔/朱谋珲/朱谋军/朱谋挥/朱谋埤、朱谋鹳/朱谋鹦、朱谋玮/朱谋伟、饶宇朴/饶宇扑、澹雪、北蓝寺/北兰寺）保持原样未统一；个别形近字错识（如“酒”作“洒”、“着”“象”等）未逐一校改；个别诗句有缺字（□）保留；少数引号缺失或半角省略号被识成“.....”（已改为“……”）；个别页眉页码残留碎片已删，仍可能有遗漏。书末“弃道还俗”一章结尾为全书结尾，无后记。
