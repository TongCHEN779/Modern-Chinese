# 随想录

## 底本
《随想录（1—5集）》，巴金著，人民文学出版社，2000 年 7 月第 1 版（“百年百种优秀中国文学图书”丛书）。内含合订本新记、总序，以及《随想录》《探索集》《真话集》《病中集》《无题集》五集共一百五十篇，另有各集后记及附录。

## 整理说明
- 每篇文章一页（p001–p159），页组按“卷首”及五集分组。页标题取各篇标题（去掉目录里的序号），篇内“二、三、四”等小节号作为节名；篇首无编号的部分用页标题作节名。
- 保留：合订本新记、总序、各集后记、附录《我和文学》《答井上靖先生》《核时代的文学——我们为什么写作》、代跋《致树基》。《答井上靖先生》按目录是《病中集》的附录，页内与第一二〇篇相邻。
- 去掉：封面、版权页、丛书前言/书目/编委名单、目录页、各集书名页及版本说明（出版说明）、页眉页脚、页码、每篇篇末“本篇最初发表于……”及页脚脚注、正文内脚注圈码（①②等）。
- 引用的诗句、诗词按书中分行，每行一段。篇末署日期保留（如“1月2日。”）。
- 逐页依据 OCR 的 json 行坐标分段（首行缩进＝新段），跨页断行已接续。

## 已知问题
- 第一二三篇《为旧作新版写序》和第一三四篇《〈全集〉自序》在书中仅有“存目”，正文未收，故本整理未列页。
- 第一一篇《一颗桃核的喜剧》，书中目录 OCR 为“核桃”，正文标题为“桃核”，取正文。
- 第一三一篇《卖真货》的第二节节号 OCR 缺失，页内小节只见“三”；个别篇小节号（如第六二篇《我和读者》）疑有缺漏。
- 日期 OCR 偶有错字：已把明显的“N月M月”改为“N月M日”；仍有残留，如“10月2021日”（疑为 20、21 日）、“金1987年”“巴金”前一字丢失（如《合订本新记》署名）。
- OCR 文本中有零星错字、混入的页边杂字（已删除孤立单字），未逐篇校对；“《”“》”、引号偶有缺失。
- 页内个别小标题或脚注残片、未带标记的页脚文字，可能仍有少量残留；一般在篇末日期之后的已删除。
- 全稿共约 37.6 万字（按段落字符计）。
