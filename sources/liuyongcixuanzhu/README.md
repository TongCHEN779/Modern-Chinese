# 柳永词选注

- 底本：张惠民、张进选注《柳永词选注》，人民文学出版社“中国古典文学读本丛书典藏”，2017 年版（初版 2007 年）。文字由书籍扫描件（PDF）经 OCR 识别、整理而成，**尚未逐字校对**。
- 整理：p01 为选注者《前言》（分“一”至“四”及“（一）关于慢词”等节，前言脚注按所注引文挂为注释）；p02–p06 为全部 153 首词，按书中顺序每约 30 首一页，页标题“首题—末题”，每首为一节，节名取词牌（同牌多首同名，《木兰花》“杏花”一首题作“木兰花·杏花”），词文按句以“/”分行，上下阕各为一段；每首的第一条注（概述全词）作“题解：”，其余注释放在所注那一阕之后；p07 为书末《柳永词评辑要》，每条评语与其出处各占一段。
- 注释定位：原书用 ①②… 编号（OCR 作 [1][2]…，且常把 7、9 识成 2），按词中记号与注释的先后顺序一一对应；“暖律二句”“园林句”类的注释，词语取其首词（如“暖律”“园林”），“二句”“句”保留在解释开头。约 17 条（占 1.4%）因词语 OCR 与正文不一致，改取所注处前几个字为词语，解释全文照搬。
- 未收：封面、书名页、版权页、目录页、丛书广告。
- OCR 已知问题与改动：“満朝欢”改“满朝欢”，“爪茉莉”改“瓜茉莉”，“一寸金”改“二寸金”；“无僇”（疑为“无憀”）、“僇赖”“隼旄”“𣨼人娇”等罕用字原样保留；前言页脚引文出处中个别序号、书名号有误，未改。
