# 蒲松龄传奇

- 底本：熊文祥著《蒲松龄传奇》（“中国名人轶事丛书”之五，吴洪激主编），武汉大学出版社、台湾汉欣文化事业有限公司联合出版，1994 年 8 月第 1 版。文字由 Internet Archive 的扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：共九页——丛书出版缘由、主编絮语（吴洪激序）、引子、第一至第六章，各占一页。章内以“二、三、四”为小标题分节（书中第一节无编号，节名取章名）；第一章第二节、第四章第二节、第五章第二节的编号“二”OCR 漏识，据版面空行位置补回。
- 去掉的内容：封面、丛书编审委员会名单、版权页、图书馆章与借阅页、Internet Archive 水印页、目录页、页眉页脚与页码、书末丛书广告页；出版缘由与主编絮语文末的署名（吴洪激）；书中每页页下的脚注（①②…的注释文字）及正文中的脚注序号。“主编絮语”文末的写作日期“一九九三年六月于湖北黄州”保留。
- 段落按扫描版面的缩进与行宽重建（跨行、跨页的段落已接合；书中的诗词、对联按原书每行一段，引用的序文、祭文、书札等按一段处理）。
- OCR 已知问题：个别单字错识（如“井”“祭”之类形近字）与引号缺失未逐一校改；少数“——”被识作单字或漏识（如“你”“你—”）；个别页眉页码残留碎片（孤立字母、乱码）已删，但仍可能有遗漏；半角“:”“?”已改为全角。原书用字“象”“着”等保持不变。

- 章内小标题：各章页内以书中“一、二、三、四”分节。第一章至第六章每章开头的“一”在 OCR 稿里没有识别出来，整理时按章内序号补为首节节名“一”。
