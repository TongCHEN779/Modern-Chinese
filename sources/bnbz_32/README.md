# 大堰河

## 底本
艾青《大堰河》，人民文学出版社，2000 年 7 月，“百年百种优秀中国文学图书”丛书之一。全书两部分：诗集《大堰河》（9 首）与附录《北方》（序及 16 首）。

## 整理说明
- 共两页：p01《大堰河》（9 首诗，每首一节），p02《附录：北方》（序及 16 首诗，每首一节）。
- 去掉封面、版权页、作者小传、丛书前言与评委名单、丛书书目、目录、页眉页脚、页码及书中插图印章（“旋乎刺”“别孤”等）造成的碎片。
- 诗行沿用 OCR 的分行；个别被 OCR 并成一行的诗句（如《大堰河——我的褓姆》《巴黎》《风陵渡》《我爱这土地》），据文意拆回分行。

## 已知问题
- 诗行分行并非逐行与原书一致：OCR 常把相邻短行并为一行，或在跨页处断行，仍有残留。
- 更正的 OCR 错字：钮恨→忸怩，坑凳→炕凳，叫器→叫嚣，暖昧→暧昧，“写着--首”→“写着一首”，日期“九三七”→“一九三七”。
- 《一个拿撒勒人的死》第 p0034 页末“请不要为我哭泣”之后下页直接接“髑髅地到了”，疑漏去几行。
- 《巴黎》“广场上”之前有印章碎片“别粉”，已删，原地名可能被吞（疑为“协和广场”）。
- 作者在每首末的署名/地点日期（如“雪朝，十四，一，一九三三。”“临潼”）保留；《北方》序第四段末句缺句号，原样保留。
