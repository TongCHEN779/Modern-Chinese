## OCR 已知问题

- 行末脱字：不少行的末尾文字被识别丢失（尤其是行末的“……”“——”“一”等符号），表现为段落在句子中途断开、或下一行以半句开头，共约七十处（如《星》《山村一夜》《古渡头》《电网外》《向导》《校长先生》中的若干段）。这些地方原样保留，没有补写。
- 行末“·”：约三十处行末的“……”（或“……””）被识别成孤立的“·”。凡“·”前是句末标点且该段引号尚未闭合的，改作“……”；其余的删去“·”（如《丰收》“昨晚还说得好好的。……”、《火》“你的豆子六块八！……”），个别可能与原书不完全一致。
- 《星》第二章“黑色的东西摸到她的跟前了……”一带，“一股麻麻的火一般的热力”的“一”漏识，保留为“股麻麻……”。
- 《星》结尾引的歌谣中的波浪线“～～～”由 OCR 的“~”改为全角“～”。
- 《电网外》结尾页（书第 173 页）有一块版面装饰被识成乱码，已删去。
- 半角标点按规则改全角；单引号“'”按位置改作“‘”“’”；个别排印“1933一1936”中的“一”改为“—”。

- 原书注释（p05、p07、p08、p19、p20）已按站内格式（注：词语：解释）挂在所注段落后，注码已去掉；个别注释的词语位置为推定。
