# 中国现代作家选集·王统照

- 底本：《中国现代作家选集·王统照》，冯光廉、刘增人编选，人民文学出版社、三联书店（香港）有限公司联合编辑出版，1990 年 9 月北京第 1 版第 1 次印刷，ISBN 7-02-001011-3/Z·11（本册无另标册次）。文字由书籍扫描件（PDF，323 页）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 结构：王立诚序一页；“小说”16 篇（卖饼人至灰脊大衣）；“散文”14 题（“血梯”至“水就变成血了”，其中《听潮梦语（选四章）》《繁辞集（选七章）》各按书中章题分节）；“资料部分”5 篇（王统照《我读小说与写小说的经过》、瞿世英《〈春雨之夜〉序》、田仲济《淳朴的性格 凝炼的风格》、冯光廉 刘增人《王统照简论》、《王统照年表》）。作者署名放在各页首节的作者栏。
- 去掉的内容：封面、扉页、版权页、作者像与插图页（PDF 第 1–9 页）、手迹影印页（第 10–11 页，OCR 为乱码，不收）、目次页（第 15–17 页）、“作品部分”“资料部分”隔页及空白页、页眉页脚页码、末页的水印残留。
- 脚注：页底脚注一律去掉，正文里的脚注序号（①②）也一并删去。涉及：《沉船》（PDF 第 72、73 页）、《“小天分人”的生与死》（第 159 页）、田仲济文（第 272、274、276 页）。
- 补回与改动：
  - 田仲济文的小节号“一”在 OCR 中缺失，首节按版面补作“一”；“二”至“五”为书中所有。
  - 《打醮的故事》题下“传说的故事之一”作为首段保留。
  - 《沉船》（第 80 页）、《青岛素描》（第 214 页）里各有一行印作省略号““…………”的对话，OCR 识成“”，已按版面补回。
  - 小说内部以空行分隔的小节，书中没有标号，整理时只按段落连排，未另分节。
  - 篇末的写作日期、发表出处各自成段，原样保留。
  - 《王统照年表》按年份分节，节名取书中年份行（如“一八九七年一岁”）；表末“一九七八年以来……”等附记接在最后一节末尾。
  - 半角标点在汉字旁改全角，OCR 孤立的页码、噪点已删。
- OCR 已知问题：
  - 《序》第 3 段末“这是王动”疑有漏字（原句应为“这是王统照……”之类），原样保留。
  - 个别句子因 OCR 漏行而不完整（如《父子》“正好惹来了一个反”后接下一句对话），原样保留。
  - 《悼志摩》里的英文引句（拜伦诗题）识别不全。
  - 诗行、引诗依版面行宽判断分行，个别地方可能与原书不尽一致（《淳朴的性格 凝炼的风格》中的引诗）。
