# 死水微澜

## 底本
李劼人《死水微澜》，人民文学出版社“百年百种优秀中国文学图书”丛书本，2000年7月第1版（2001年10月第2次印刷）；作者前记写于1955年6月（修订本）。OCR 整理自 PDF。

## 整理说明
- 按书的目录分页：前记，第一至第六部分（序幕、在天回镇、交流、兴顺号的故事、死水微澜、余波）；各部分内的“一、二、三……”小节分节。
- 去掉：封面、版权页、丛书前言/评委会/编委会/丛书书目、目次、各部分题名页、页脚作者脚注（含正文中的脚注标记①②）、书末数字化信息页及其水印字样。
- 段落合并了换行与跨页断行；少数明显的标点OCR误识（?!"'）改为全角。

## 已知 OCR 问题
- 各部分第一节的编号“一”在书中无标注，节名据惯例补为“一”。
- 小节编号 OCR 漏识三处，据版面空白位置补回：第三部分“二”（自“声音流动的高潮”起）、第四部分“二”（自“报答？刘三金”起）、第六部分“三”（自“他们第七次会面”起）。
- 原稿 p0043、p0137、p0172 无页标记，内容并入前页；页脚脚注据 json 版面切除，个别脚注可能切除不净或误切。
- 正文有个别 OCR 误字与残余标点（如“T”“f”“To!”“A7”等噪点），书名号多处被识成圆括号如“(八仙图)”，均未改。
- 部分段末句号漏识，段落末尾无标点；第六部分第一节（p0233）为物理行，已按版面缩进重新分段。
