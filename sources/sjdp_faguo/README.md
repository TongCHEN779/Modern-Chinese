# 世界短篇小说精品文库·法国卷（上）

- 底本：柳鸣九主编《世界短篇小说精品文库·法国卷》上册，柳鸣九编选，海峡文艺出版社，1996 年 8 月第 1 版（ISBN 7-80534-889-8）。全书分上、下两册，这里只有上册（PDF 第 50 页为书页第 1 页，至“港口”结束于书页第 780 页）；目录页里列出的“下册”部分（法朗士《克兰比尔》起）不在这一册里，未收。文字由书籍扫描件经 OCR 识别、整理而成，**尚未逐字校对**。
- 内容：总序、编选者序（均为柳鸣九，各一页）；其后每篇小说一页，共 35 篇、17 位作家（纳瓦尔、斯卡隆、拉法耶特夫人、伏尔泰、狄德罗、夏多布里盎、斯丹达、维尼、巴尔扎克 3 篇、梅里美 3 篇、乔治·桑、奈瓦尔、福楼拜、缪塞、左拉 3 篇、都德 5 篇、莫泊桑 9 篇）。页标题用书中篇名；有副标题的并入页标题（《法尼娜·法尼尼》《希尔薇》《咪咪潘松》《最后一课》《雅尔雅依来到天主的家》）。pages.json 第三项为作家名，序言两页为“序言”。
- 整理：原书每篇小说之后印有“作家作品简介”（作家第一篇后含作家生平，其后各篇多为“作家简介见前”加该篇说明）。这里把作家第一篇里的作者部分放在该篇页首作“作者小传”一节，其余（作品说明及署名）及其他各篇的简介放在页末“作品简介”一节；奈瓦尔、《希尔薇》后的简介只有一段，作者与作品介绍连在一起，整段放在“作者小传”。译者署名原印在篇末，这里改放在每篇第一段，作“（某某 译）”。
- 去掉：封面、版权页、编委会名单、目录页、页码、脚注（及正文中的脚注序号）。小标题照书分节：《萝莱特》三节、《玄妙的杰作》两节、《希尔薇》十四节、《伊勒的维纳斯》末的“附记”。《玄妙的杰作》《希尔薇》的节号与节名之间 OCR 无分隔，统一补一个全角空格；《希尔薇》第十节“鬈毛阿哥”OCR 作“鬆毛阿哥”，据正文改。
- 段落据 OCR 逐行坐标（缩进、行宽）重建，跨页自然段已接合；诗歌、歌词、碑铭（《咪咪潘松》的歌、《伊勒的维纳斯》的拉丁铭文、《羊脂球》里的歌词、《卡门》题词等）每行一段。

## 已知问题
- 篇名：《在一个春天的晚上》正文标题 OCR 为“在一个春天晚上”，依目录用“的”；《最后一课》副标题 OCR 作“自叙”，页标题写作“自述”；篇名中 OCR 漏识的字（《勒内》《卡门》《月光》《项链》《港口》等）依目录补。
- 繁体残字：个别 OCR 残留繁体字（慳、賽、憤、這等）已改回简体；其余单字识别错误基本未动，书名号括号错配（“〈…》”“（…）”）只在作者小传、作品简介和序里做了有限归一。
- 《勒内》《法尼娜·法尼尼》《侯爵夫人》等篇内的信件、引文段落及全书对话的分段全由坐标判断，个别可能与书中不同。
- 《港口》篇末接着的页面是 OCR 附带的 Anna’s Archive 水印页，已去掉；该篇之后的“作品简介”完整。
- 全册 OCR 无整页缺失（full.txt 里个别页面标记缺失是因为内容被并入上一页，据逐页 json 核对无遗漏）；各页个别行有低置信识别，未逐一核对。
