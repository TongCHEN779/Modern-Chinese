# 中国历代文论选（第4册）

- 底本：《中国历代文论选》第四册（高等学校文科教材），郭绍虞主编、王文生副主编，上海古籍出版社，2001 年 10 月新 1 版（2003 年 5 月第 2 次印刷）。本册为近代部分，自龚自珍《书汤海秋诗集后》至陈独秀《文学革命论》。文字由书籍扫描件（PDF）经 OCR 识别、整理而成（简体），**尚未逐字校对**。
- 结构：页 = 书中目录的每一条一级篇目（共 43 页，页标题即该篇题目）；节 = 一篇文章。每页第一节是该一级篇目本身，其后各节是书中该篇“附录”下列的相关文章（题目、作者照目录）。
  - 每节第一段 `原：` 为书中篇题下的作者行（如“〔清〕龚自珍”）；其后为正文；正文之后一行为出处（如“中华书局《龚自珍全集》第三辑”）。原书中的小标题、编号（如“一”“二”“结论”）作为独立一段保留，未另起节。
  - 书中篇后的【说明】各段写作 `题解：`（它们只在一级篇目之后出现，附录各节没有）。
  - 书中篇后【注释】逐条写作 `注原：词语：解释`，按正文里的上标位置放回所注段后；词语取原注的词（如“昌谷”），原注里并列的几个词条合成的一条保持为一条。用 `注原：` 而非 `注：`，是为了让 build 不再按句号后的“某某：”把一条原注拆开（原注解释里常有这类字样）。原注里的“见本册某篇注[3]”之类互见标记原样保留。
  - 《复堂词录序》与《复堂词话》、《白雨斋词话自序》与《白雨斋词话》两对，原书只有一套【注释】【说明】（印在后一篇之后），故注释和题解都放在后一页，注释按词语定位到两篇中各自所属的段落（落在前一篇的就写在前一页）。前一篇的注释因此出现在后一页；个别词语在正文里对应不上的，注释放在后一页末尾。
  - 同一页内题目重复的节，第二个加括注区分：“艺槩词曲槩（选录）（附录）”“复堂词话（选录）（附录）”“白雨斋词话（选录）（附录）”“人境庐诗草跋（梁启超）”（同页另有黄遵楷的同题跋）。
  - 五、七言诗词整段识别为诗的段落写作 `诗：`，四句一段，句间用 `/`。
- 整理时去掉：封面、书名页、版权页（CIP 数据）、目录页（OCR 的目录文字乱序，仅据其核对篇目和页码）、页码、书末“总目索引”（全书四册的篇目索引）、页边与页脚的杂点；正文里的注释上标（[1][2]…）已去掉，改由注释的位置表示；篇名里的注释上标也已去掉。书中无序、前言、编后记，故无此类页。
- 方法：OCR 的 full.txt 有并页和丢段（此册约一百页的字数明显少于逐页识别），故改以逐页 json（带坐标）为准：t2s 简化后，按行首缩进、行尾长短分段，按“【注释】”“【说明】”标题和缩进（注释条首顶格、续行缩进）切分，篇目起点按目录核对页码和标题定位。字形与 full.txt 保持一致（谿→溪、幷→并等）。
- 已知问题：
  - 书里的篇目与注释很多，OCR 的单字错识未逐一校改，常见的有：已/己（如“已亥杂诗书后”实为“己亥杂诗书后”，已在篇名中改正）；注释里年份中的“入”应为“八”（仅在数字之间处已改，“九一入事变”之类未改）；“郎”应为“即”（如“郎吴伟业”“郎《晨钟报》”）；“井”应为“并”（如“兼容井包”“井畜”）；个别生僻字和外文拼写错误；刊名、出处行里个别字漏识（如《新青年》第二卷第六〔号〕、《南社》第五集的前一个“《”）。
  - 注释上标有一部分 OCR 丢失或误识；定位时以上标顺序、序号和词语对照。仍有约 30 条（占 1.8%）的注释词语在所属段原文里找不到（多半是 OCR 错字，或词语在篇名/作者行上，如“汤海秋”“《国故论衡》”“《日本国志》”之类），已放在该篇最后一段（出处行之前），词语取原注开头的词。少数注释的词语是由上标位置推出的（原注词与正文因 OCR 错字对不上时），可能与原注词略有出入。
  - 个别原书上标被误识成正文里的字符（如“……《天雨花》18]”已去掉，“[」”“缺有闲」者也”等零星符号未全部清除）。
  - 个别页面边缘有零星噪点被识别成字母或符号（如“i”“X”“2”），已尽量按位置去除；中间若有漏网者，多出现在页边缘附近的段首或段尾。
  - 《闻菽园居士欲为政变说部诗以速之》作者行在 OCR 里是“C11”，已据其后一行改作“〔清〕康有为”。
  - 没有发现缺页（本册正文 PDF 第 13–552 页，第 552 页为空白）；full.txt 缺的第 124、320、340…等页，现已由 json 补全。
