# 画梦录

## 底本
何其芳著《画梦录》，人民文学出版社，2000 年 7 月第 1 版（“百年百种优秀中国文学图书”丛书之一）。原书初版为 1936 年上海文化生活出版社版；本版在《画梦录》之后附录《梦中道路》及《呜咽的扬子江》《街》《县城风光》《乡下》《我们的城堡》《私塾师》诸篇。底本为 OCR 简体整理稿（PDF 第 17–127 页）。

## 整理说明
- 共 24 页：代序《扇上的烟云》，集中各篇各占一页；《画梦录》一篇内含《丁令威》《淳于棼》《白莲教某》三节；附录自《梦中道路》起至《私塾师》。
- 去掉：封面、版权页、作者小传、丛书前言、评选委员会名单、丛书书目、目录页、页码、书末电子版水印说明。
- 每页底部的脚注（《梦中道路》中对罗塞谛两行英诗的译注）去掉；篇末日期（如“一九三五年一月十六日”）按原文保留为一段。
- 被换页或换行断开的段落已接上。

- 原书《岩》《炉边夜话》等篇引文的单引号、双引号配对不一，保持原样。
- 页 116 有疑似噪点“4”，已删；页 120 孤立“车”字已删。其余字形（如“甚么”“荔”等）保持底本原字。
