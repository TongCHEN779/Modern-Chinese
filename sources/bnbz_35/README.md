# 上海屋檐下

- 底本：夏衍《上海屋檐下》（“百年百种优秀中国文学图书”），解放军文艺出版社 2000 年版。书中含：自序（1937 年）、剧本（三幕）、后记（1957 年）、《谈〈上海屋檐下〉的创作》，以及补录的四幕话剧《芳草天涯》。文字由书籍扫描件经 OCR 识别、整理，**尚未逐字校对**。
- 整理：每部分各占一页（自序、人物、三幕、后记、谈创作、《芳草天涯》人物及四幕）。去掉了封面、版权页、作者小传、丛书前言/评委会/书目、目录页、页眉页脚页码。剧本里的舞台提示和台词各自成段，角色名保留在行首。
- 已知 OCR 问题：
  - 台词与角色名之间的冒号（或空格）在 OCR 中基本丢失，形如“杨彩玉跟你说，时候不早啦！”；《芳草天涯》里角色名简写为单字（孟、太、志、云、许、咏等），同样与台词连写。
  - 原书按版面折行，段落是按行长和角色名位置推断合并的，个别台词与舞台提示、前后两个角色的台词可能误合或误断（如第一幕开头几处角色名单独成行：“葆珍”“杨彩玉”，其后的台词被识别到下一行）。
  - 舞台提示的括号〔 [ （ 的样式识别混乱，原样保留。
  - 《芳草天涯》人物表后的“时代”下有一个孤立的“司”字（当为“时间”的识别残留），已删去，标题仍作“时代”。
  - 书中页码 PDF 第 101、103 页无文字（空白/题名页），第 132、186 页的文字已被并入前一页的 OCR 结果，经核对内容连续，未发现缺失。
