OCR 已知问题与处理说明：
- 原 OCR 稿在行末、行首系统性漏识“——”“……”“……””及引号、省略号常被缩成单个“…”“—”。本册对照页面图像逐处补回：凡 OCR 出现孤立的“—”“…”一律还原为“——”“……”；另依图像补回数十处被漏识的破折号、行末“……”（”）及单引号（如《好消息》《夜雨飘流的回忆》《行军散记》《古渡头》《插田》《致张天翼书》等）。此类补回已逐处核对页面，但未必无遗漏。
- 《我为什么不多写》第 169 页首行 OCR 将两个文本框顺序颠倒，已按版面次序复原（“……我要是有胡诌的本事也好——“一天能胡诌出一两千字，也足可以维持生活的！”……”）。
- 《病中日记》：日期节名照书，其中“四月十六”无“日”字、“三月十二日（正月二十二）”无“日”字，“五月二十日（四月初二日）”与其后“五月廿日（四月初四）”、“六月六日”后的“四月十三日（四月二十六日）”按阴历推算疑为排印之误（后者应为六月十三日），均未改。书中以〔 〕标注的编者补字照旧，OCR 误作“[ ]”的已改回〔 〕。该篇第 63—64 页引录的一则旧日记与一首无题诗，诗按书中分行。
- 《前言》末段、《我怎样与文学发生关系》个别句末书中无句号处，照 OCR 原样保留；全书行文中仍可能有零星错字、漏字（如“伟犬”“利〔厉〕害”“骂置”“梦吃”等，以及“特落费谟/特落费漠”译名不统一）均照书/OCR，未改。
