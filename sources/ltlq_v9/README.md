## OCR 与整理的已知问题

- 历史年表由坐标自动对齐：原书相邻两栏的文字常被 OCR 并成一行，按字符比例切分，个别条目错位、并合或缺字（如 1938 年逻辑学栏“杜威”条混入心理学栏文字，部分技术栏条目缺首字）；年份被 OCR 吞并或误识的行可能年代错位；同年多条事件的分条靠行末标点与行宽判断，个别并为一条或误拆。表末个别噪点行已删。
- 原书页码清理靠“与原书页码接近且序号递增的数字”判定，少量嵌在词中的页码数字可能残留，也可能漏清；参考书目内的嵌入页码（如“41 Chicago”）同理。
- 第七章等处正文中的注释上标数字（如“……参见。26更多细节”）OCR 后失去方括号，保留在正文里；第七章注释缺 [25]。个别注释靠规则拆分，少数注释并入上一条。
- 参考书目条目编号靠规则拆分，少数缺编号的条目并入上一条；同一作者的“——”重复条目保持 OCR 原样。
- 公式、逻辑符号与真值表（第一、四、七章等）按行断开，缩进的引文、公式有时与正文段落难分（如连续的“(1)(2)…”条目偶被并成一段）；第三、四章图中文字残片（如“A B”“a b”）个别遗留。
- 外文人名、书名、期刊名保持 OCR 原样，空格丢失（如 HistoryofLogic）和个别字形误识未改。
- 名词解释的第二组标题“逻辑学”按 OCR 所见的小标题处理，其上可能另有书中未识别出的组名。
- 原书注释已按站内格式（注：词语：解释）挂在所注段落后，注码已去掉；个别注释的词语位置为推定。
