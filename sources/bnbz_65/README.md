## 整理说明
- 每篇作品一页（共 93 页），按书目录次序；《女人们（三篇）》《游击区生活一星期》《吴召儿》《村歌》等以书中小标题分节，数字序号（一、二……）各为一节；《村歌》下篇的序号节名前加“下篇 ”以免与上篇重名。
- 作品的副题（“白洋淀纪事之一”“平分杂记”“得胜回头”等）与篇末日期、地点，均作为段落原样保留。
- 去掉：封面、版权页、作者小传、丛书前言/评委名单/丛书书目、目录页、页码；编辑所作《编后说明》（康濯）与《二〇〇〇年版编校后记》（刘宗武）；页脚编者注（五处）及正文中的注码“①”。保留作者的《再版附记》《重版后记》。
- 歌谣、顺口溜等诗行逐行成段；OCR 断开的同一自然段（行末无句末标点、长度≥20字）已接合。接合处偶有一个孤立的“1”噪点（如《王香菊》前后的两三处）已删。
