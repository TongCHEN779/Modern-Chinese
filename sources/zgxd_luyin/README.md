# 中国现代作家选集·庐隐

- 底本：《庐隐》（中国现代作家选集），肖凤编，人民文学出版社、三联书店香港分店联合编辑出版，1984 年 7 月北京第 1 版第 1 次印刷，书号 10019·3087。文字由书籍扫描件（PDF）经 PaddleOCR 识别、按逐页坐标重建而成，**尚未逐字校对**。
- 整理：按书的目录分页。书前序一页（陆晶清《浅谈庐隐及其作品》）；小说八篇、散文（《玫瑰的刺》《东京小品》及单篇杂文）各篇一页；“资料部分”茅盾、李唯建、刘大杰、苏雪林的评论回忆各一页，肖凤《庐隐的生平与创作道路》《庐隐年表》各一页。`pages.json` 第三项为书里的“小说”“散文”“资料部分”。
- 《玫瑰的刺》内七个小节、《东京小品》内九个小节、《海滨故人》四节、茅盾《庐隐论》五节、肖凤评传的两节，页内各为一节；《父亲》里的日记各条以日期另起一段，不分节。篇末所注“（选自……）”及资料部分各篇的出处行去掉；评论、回忆各篇题下作者名保留为首段，序同。
- 去掉：封面、版权页、书中插图和图说、作者手迹页、目录页、页码，卷末 Anna's Archive 附页。
- 小节号“一”在原书中印作短横，OCR 漏识，据版面空行补回：《海滨故人》第一节、茅盾《庐隐论》第一节、肖凤评传第一节。
- OCR 已知问题：全书残留零星错字，除下列系统性错识已更正外其余原样保留：“攻瑰”→“玫瑰”，“梓肯、梓背”→“梓青”，“罗懒、罗傲”→“罗倾”，“儿乎”→“几乎”，“自已”→“自己”，“乐同”→“乐园”，若干单字（如“1子”→“日子”）。茅盾文末日期“一九三四年六月七日”OCR 只识出“九四年六月七日”，据注释补全；《海滨故人》中一封信的称呼“样1”据图改作“梓青！”。《父亲》日记一处“看报，，—”原样保留。年表中的“注释”按原书保留为末节。
- 全书无缺页；p0038、p0039 在原 full.txt 中被并页，本册由逐页 json 重建，已避免。
