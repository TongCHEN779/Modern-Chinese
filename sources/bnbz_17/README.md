# 死水

- 底本：闻一多著《死水》，解放军文艺出版社 2000 年 7 月版（“百年百种优秀中国文学图书”丛书之一，扫描件经 PaddleOCR 识别、整理，尚未逐字校对）。
- 结构：按书的分辑分页——《死水》（含补录《闻一多先生的书桌》）、《红烛》辑、《二月庐》辑、《黄鸟》辑、《红豆》；每首诗一节，诗行逐行一段。《红烛》《二月庐》《黄鸟》三辑的页标题加“辑”字，以免与同名首篇重名；《红豆》四十二首以书中序号作节名。
- 去掉：封面、版权页、作者简介、丛书前言、丛书书目与评委名单、目录、页码、每页底部的脚注（《李白之死》《艺术底忠臣》《忆菊》《秋色》等处的作者注，及正文里的①②③标号）、扉页残片（“烛 附 红”）、文末 Anna's Archive 水印页。
- 保留：诗前引语/小序（《荒村》《洗衣歌》《李白之死》《红荷之魂》的序言，《红烛》《剑匣》《西岸》的题引，《也许》的“(葬歌)”等副题）；《红荷之魂》的“有序”二字未保留，序文并为一段。
- 已知问题：
  - 《红豆》序号“二”“二一”“二二”在 OCR 中漏识，我按诗意拆分后补上（“二”在“相思着了火，”之前；“二一”在“深夜若是一口池塘，”之前；“二二”在“我们的春又回来了，”之前），边界为推定。
  - 个别错字未改，如“我將”“进出了一声清籁”（应作“迸”）、“Fra AngeLico”等；英文题引《剑匣》的引文有少量 OCR 断行，已按行合并。
  - 页面完整，未发现缺页；p0065 的封面残片及空白页（p0066）已略去。
