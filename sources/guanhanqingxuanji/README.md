# 关汉卿选集（修订版）

底本：《关汉卿选集》（中国古典文学读本丛书典藏），康保成、李树玲选注，人民文学出版社，2020 年 1 月第 2 版（修订版；初版 1998 年）。OCR 整理稿取自“中国古典文学读本丛书典藏全集”合并稿的 PDF 第 12071–12542 页；正文据逐页 `json/` 识别结果重新分段（合并稿 full.txt 在个别处漏掉了整句，如前言一句、《调风月》《玉镜台》《单刀会》各一小段、《拜月亭》“第一折”标题，均已据 json 补回）。

整理说明：
- 收前言、十二部杂剧（《窦娥冤》《救风尘》《望江亭》《调风月》《拜月亭》《金线池》《玉镜台》《谢天香》《单刀会》《鲁斋郎》《蝴蝶梦》《绯衣梦》，各一页）、散曲（小令、套数各一页）和修订后记。杂剧页内按楔子/折分节，末节“题目正名”；每节的科白、曲词各占一段（曲牌名并入曲词段首；一行里“（……唱）”后紧接曲牌的，在曲牌前断开）。小令一支一节、套数一套一节，句间以 / 分行，套数每个曲牌一段。小令节名“仙吕·一半儿·题情（一）”等为据书中分组标题加序号所拟（书中一组数首共用一个标题）。
- 去掉封面、书名页、版权页、总目录、丛书介绍与书末广告。
- 原书注释集中印在全部杂剧之后（序号 [1]–[1723] 通排）、小令之后（[1]–[41]）、套数之后（[1]–[96]），以正文中的方括号序号对应；据序号把每条注放回所属段落之后。标在剧名、折名、楔子、套数题名上的注号，其注文作为题解原样放入该节（一页中第一节带该剧题解，另有楔子/折名注，如“楔子”的解释）。一条注含多个词条的保留为一条（拆开会误拆引文的用“注原：”）。
- 全部注释 1,860 条，其中题解 28 条、词语注 1,832 条；词语对位检查未发现落空。
- 《望江亭》剧名 OCR 漏“鲙”字，据目录补回；“题目正名”各行据版面（json 坐标）整理，次序以书为准。

OCR 已知问题：
- 正文中少数注号漏识（如 1006“桑榆”、1007“锦心绣口”、1478“经钱”所挂位置），按上下注号位置推定放在邻近段，并在词语前补了所指的一小段原文。
- 注释词语与正文用字不一致处（如“缥缃/缥湘”“拖刀计/托刀计”“鞴/鞲”等，多为原书或 OCR 异体）共 58 条，在词语前补了正文里对应的一小段原文，注文原样保留。
- 个别注释序号被识别错（如 [9] 作 [2]），已按顺序改正。
- 繁简异体字（捱/挨、拚/拼、拋/抛、殢/𣨼 等）依 OCR 整理稿的统一写法。
- 《拜月亭》《调风月》为元刊本，科白残缺，原书用“云了”“住了”等标注，照录。
