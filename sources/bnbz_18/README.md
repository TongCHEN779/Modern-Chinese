# 背影

- 底本：朱自清《背影》（“博集典藏馆”青少年成长必读丛书·权威定本），湖南文艺出版社，2011 年 4 月第 1 版，博集天卷出品。来源为 OCR 整理稿（“百年百种优秀中国文学图书”批次 18 号）。
- 结构：全书分“抒情篇”“游记篇”“议论篇”“诗歌篇”四页（p01–p04），每篇散文/每首诗一节（共 76 篇/首）；《温州的踪迹》的“一、二、三、四”、《外东消夏录》的“引子”“夜大学”“人和书”“成都诗”按书中小标题另起一节（各文第一个小标题作为该文首段保留，避免空节）。
- 整理时去掉：封面、内容简介、版权页、目录、分篇扉页、页眉页脚页码、页底编者脚注（“现通译为……”等，含《你我》页底作者注）及正文中的脚注标号、出版社广告、作者简介和封底。正文原字原标点保留，仅把 json 底稿里个别混入的繁体字（如“緊”“愛”“圖”）按 full.txt 改回简体，另据上下文改正“观jE众”“动L”两处。
- 段落依据 OCR 版面坐标的缩进、行尾位置合并断行及跨页段落；文中引文、诗句逐行分段。
- 已知 OCR 问题：
  - 系统性漏识句号：许多“。”未被识别，句子之间常直接相连（如《背影》“他的背影那年冬天”，原应为“背影。那年冬天”），遍布全书，未擅补。
  - 个别错字未改，如《冬天》“也这未想着”、《海阔天空》“宇波S中学”“来li?”；《毁灭》《赠友》中的破折号被识成“一”，英文名拼写有误。
  - 个别页底注标号被识成引号或数字，已清理已知的，仍可能有遗漏。
  - 诗歌篇不保留诗节空行，每行一段；《爱国诗》首行“一个观念”原样保留。
  - 未发现整章缺失：PDF 第 246 页为空白页（《房东太太》已完结），第 389–390 页为空白。
