# 倪焕之

- 底本：叶圣陶著《倪焕之》，人民文学出版社“百年百种优秀中国文学图书”丛书，2000 年 7 月版。文字由书籍扫描件经 OCR 识别、整理而成，尚未逐字校对。
- 整理：去掉封面、版权页、作者简介、丛书前言、评选委员会名单、丛书书目、页眉页码、Anna's Archive 元数据等；全书按原书章序分为三十章（一至三十），每章一页。第一章、第二章在 OCR 稿中没有识别出章序号，按内容（第一章始于“吴淞江上，天色完全黑了”，第二章始于“倪焕之的父亲是钱庄里的伙友”）补入。篇末“1928年11月15日写毕”保留在第三十章末。
- 已知问题：跨页、断行的段落已接上；个别页末孤立的残字（“个”“道”）与页码、脚注序号式的孤立数字已删；“延续”“终身以之”两处混入的“一i”“1”噪点已清理。书中信件（第九、十章附近）每行折断处已合并。其余零星错字（如“颌导”类）未逐一校改，可能仍有；未发现整页缺失。
