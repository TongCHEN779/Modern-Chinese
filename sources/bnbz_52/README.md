# 果园城记

- 底本：师陀《果园城记》，解放军文艺出版社 2000 年 7 月版（“百年百种优秀中国文学图书”丛书）。文字由书籍扫描件经 OCR 识别、整理而成，未逐字校对。
- 整理：按书的目录，十七篇小说各占一页，另有《新版后记》一页，共 18 页；每篇末的写作日期保留。《期待》中徐大娘的信件与《三个小人物》中的报纸报道，原书为定宽折行，已并成段落。
- 去掉：封面、版权页、作者简介、丛书前言、评选与编委名单、目录页、页眉页脚、末页的数据库水印。
- 已知问题：目录页 OCR 混乱，部分标题与页码错位；《阿嚏》一篇的标题在正文中未识别出，标题据目录补入（该篇从原书第 54 页起，约对应 OCR 稿第 65 页，首句为“当我讲果园城的阿嚏之前”）。其余各篇标题取自正文。未发现漏页；个别字词的 OCR 错字未改。
