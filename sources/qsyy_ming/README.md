# 明代历史演义全书

- 本书由大众文艺出版社“中国全史”丛书中的2册合并而成，共 100 页；各册整理记录如下。

## 第1册（tmp_qsyy_ming_1）

- 底本：蔡东藩著《明代历史演义全书》（上），大众文艺出版社“中国全史”丛书之一，年份不详（扫描件无版权页文字）。本册为全书第 1 册，收第一回至第五十回（自朱元璋起兵濠州，至明武宗南巡、廷杖谏臣、宁王宸濠谋反消息传来），回数连续、不缺不重。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成，未逐字校对。
- 整理：每回一页，页标题为“第N回 回目上联 回目下联”，回目以正文每回开头为准，并对照目录页；页内不再分节。回末套语及每回之后的评语（版面上为缩进窄行）原样保留，评语合为一段。书中引用的奏疏、书信、名单等缩进窄行块，按版面接成一段；诗词每句一行。跨页的段落已接上。
- 去掉的内容：封面、书名页、目录、丛书页眉“中国全史”和书名页眉、页码、版权及责任编辑页、封底页。本册无序、跋。
- 已知 OCR 问题：第七回“张士德絜归绝粒”、第二十九回“闹蒲台妖妇揭竿”、第三十三回“儆权阉为主斥奸”三处回目，正文 OCR 误作“紫归”“蒲合”“权庵”，据目录改正；第十二回评语中一处孤立的“。”据上下文删去（“败没，。兀守危城”）。第二、十五、二十五、二十六回的人名列表在版面上无分隔，OCR 稿为连写，原样保留。其余识别残留错字（如形近字）未逐一订正。

## 第2册（tmp_qsyy_ming_2）

- 底本：（民国）蔡东藩著《明代历史演义全书》下册，大众文艺出版社（“中国全史”丛书），年份不详（扫描件无版权页）。本册为全书第二册（下册），收第五十一回至第一百回，共五十回。文字由书籍扫描件（PDF）经 OCR 识别、整理而成。
- 整理：每回一页，页标题为正文里每回开头的回目（“第N回 上联 下联”）；页内不再分节。回数序列 51–100 完整连续，无缺回、无重复。每回末尾的评语段（“本回叙……”）原在回后，保留为该回最后一段。
- 去掉的内容：封面、书名页、空白页、“中国全史”及书名页眉与页码、版权页与封底、目录页。本册无序、跋等其他内容。
- 段落按版面缩进重建；整段缩进的引文（奏疏、诗词）随版面。回末套语、诗句原样保留。半角标点改为全角。
- OCR 已知问题：识别残留的错字、形近字（如“大学上”应为“大学士”、“术上”应为“术士”、“勃令”应为“敕令”等）、个别漏字均未改；第七十七回“李Q”据上下文改为“李昖”，其前一处“国王李，当然拒绝”漏一字，未补。第九十二回、第九十四回的绰号名单随版面按行分段。
