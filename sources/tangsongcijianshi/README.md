# 唐宋词简释

- 底本：唐圭璋选释《唐宋词简释》，人民文学出版社“中国古典文学读本丛书典藏”，2016 年版（初版 2010 年）。文字由书籍扫描件（PDF）经 OCR 识别、整理而成，**尚未逐字校对**。
- 整理：按作者分页（李白至王沂孙共 66 位作者，外加无名氏一页），页标题为作者名，每首词为一节，节名“词牌·题名”（无题名者仅词牌）；词前小序放作该词首段，词文按句以“/”分行；每首的“简释”整段放作“题解：”。书中无词语注释，故无“注：”行。末页为作者《后记》。
- 未收：封面、版权页、目录页、丛书广告。
- OCR 已知问题与改动：“贺铐”改作“贺铸”，“満庭芳”改“满庭芳”，“令夕”改“今夕”，“烛花己落”改“烛花已落”；其余疑似错字（如“威喟”“拙重大”等）原样保留。OCR 多将词的上下阕并作一行，故除个别外未能按阕分段，一首词多为一段。
