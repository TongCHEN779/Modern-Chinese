# 中国现代小说经典文库·刘呐鸥、章衣萍卷

- 底本：阿宏主编《中国现代小说经典文库》之《刘呐鸥、章衣萍小说经典》（封面作“刘呐鸥·章衣萍卷”），印刷工业出版社，2001 年 3 月第 1 版第 1 次印刷，全套十二卷，ISBN 7-80000-413-9/I·11。文字由书籍扫描件（PDF）经 OCR 识别、整理而成，**尚未逐字校对**。
- 整理：前言一页，刘呐鸥《游戏》《风景》《流》《热情之骨》《两个时间的不感症者》《礼仪和卫生》《残留》《方程式》八篇，章衣萍《桃色的衣裳》《第一个恋人》《爱丽》《阿莲》《松萝山下》《你教我怎么办呢》《痴恋日记》《夜遇》《红迹》《给璐子的信》《从你走后》十一篇，每篇一页，共 20 页。分辑名取书里目录的“刘呐鸥小说经典”“章衣萍小说经典”。按版面坐标重建段落（缩进为段首；整行写满且下行无缩进的接排），跨页断开的段落已接上。
- 页内小节：《桃色的衣裳》依书中编号分节，上篇为“上篇·一”至“上篇·十四”，下篇为“下篇”（开头未印编号）、“下篇·二”至“下篇·四”，“上篇”“下篇”标题本身不单列；《第一个恋人》依书中“二”“三”“四”分节（开头一节未印编号）；《你教我怎么办呢》《痴恋日记》《红迹》依日期标题分节，《痴恋日记》末尾“贞一手记”另为一节；《给璐子的信》依“第一封信”至“第三十封信”分节，各信末的署名日期留在该信末尾。刘呐鸥各篇内部的空行分段不单列小节。
- 去掉：封面、版权页、目录页、页眉（“刘呐鸥小说经典”“章衣萍小说经典”）、页码、扫描噪点（零星的“X”“M”“心”等）、书末空白页和封底。目录第 12 页另起的章衣萍篇目（夜遇、红迹、给璐子的信、从你走后）与正文一致，未收。
- OCR 与整理说明：
  - 《红迹》篇名第二字“迹”在标题页未被识出，据目录补回；《桃色的衣裳》上篇第十二封的编号“十二”被识成“二”，按次序改回；下篇一封的日期“四日二十一日”改作“四月二十一日”。
  - 刘呐鸥各篇的对话破折号（“—”）常被识成汉字“一”，仅在相邻段落都以破折号开头的对话里改回（如《游戏》《两个时间的不感症者》中“一怎么……”“一你说呀”等）；《游戏》“一一个想着后天的‘飞扑’”据文意改作“——一个想着……”。个别仍可能有漏改。
  - 《流》中的英文招呼语“-Good morning!”等行首的连字符原样保留；《桃色的衣裳》中“□□□”、《给璐子的信》中“××”为书中原有。《给璐子的信》第十三封中诗两节之间的“*”分隔符已删去。
  - 半角 ( ) ! ? 等在汉字旁改为全角；段落首尾零星的“·”噪点已删去；其余错字、漏字（含少量把握不大的）原样保留。
  - 跨页处若上页末行恰好写满并以句号结束，下页首行无缩进，一般按接排处理，个别分段可能与原书不同（如《痴恋日记》九月十四日）。
