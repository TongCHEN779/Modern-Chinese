## OCR 与整理的已知问题

- 历史年表由坐标对齐：并列事件与同一事件的换行靠行长判断，个别事件被拆开或并合（如“约公元前280年”一行）；个别年代的破折号丢失或误识（如“公元前285—前46年”应为前246年，“前公元247年”）。
- 正文页码清理靠版心坐标：左右页边伸出版心的数字被删，嵌在版心内的页码若被识别为行内数字则可能残留；少量与页码相同的行尾数字可能被误删。
- 第五章书中第195—198页、第十二章第494—497页版面偏斜或为缩略语表，缩进判断偏弱，个别段落被拆开或并合。
- 引文缩进与段首缩进相近（均约 90 像素），引文段与相邻正文段偶有并合或拆分；紧接引文的导入句有时被单列为一段。
