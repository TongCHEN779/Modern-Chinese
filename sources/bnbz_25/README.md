# 望舒草

## 底本
戴望舒《望舒草》，人民文学出版社“百年百种优秀中国文学图书”之一，2000年7月第1版（2001年6月第2次印刷）；所据原版为1933年上海现代书局版。

## 整理说明
- 分三页：序（杜衡，1933）、诗集正文（《我的记忆》至《乐园鸟》共41首，每首一节，诗行逐行）、附：诗论零札（17条）。
- 去掉：封面、版权页、作者小传、丛书前言与书目、评委名单、目录页、页眉页脚页码、空白页、末页电子书信息。
- 序文中夹在正文里的引诗保留为独立段落，其出处（如“——（零札）十四”）按原书边注位置附在引文之后。
- 《梦都子》“致霞村”、《前夜》“一夜的纪念，呈呐鸥兄”为书中题记，保留为诗的首行。

## OCR 已知问题
- 诗行按 json 逐行识别结果重建（full.txt 中部分诗行被并成一行）；各诗标题因版面竖排被拆成碎字，据目录和上下文还原。《乐园鸟》标题 OCR 中缺失，据序文补；《印像》依目录原样。
- 诗论零札第一至三条的序号“一、二、三”OCR 漏识，按顺序补出；其余序号为识别所得。
- 已更正的明显字误：蛰居、竟使、蔷薇、颓唐、窠里、懒惰、揶揄、万花筒、自己、给予。
- 仍可能残留的形近字误（未改）：如序中“脚踏”（疑为“踌躇”类）、《夜》“缢死”、《梦都子》《单恋者》个别词，以及“沈/沉”并用。
- 无漏页、整诗缺失；《秋蝇》页边的零星数字符号已删。
