# 干校六记

- 底本：杨绛著《干校六记》，中国青年出版社“百年百种优秀中国文学图书”丛书，2000 年版（据中国社会科学出版社 1992 年作者校订本排印）。文字由书籍扫描件经 OCR 识别、整理而成，未逐字校对。
- 整理：去掉封面、版权页、作者简介、丛书前言/评委名单/书目、目录页、补录扉页及“丙午丁未年纪事”分目页、页眉页脚页码、水印页；合并硬换行与跨页断开的段落。共 16 页：小引，六记各一页，补录的“丙午丁未年纪事”引言一页及其七篇各一页，“从‘掺沙子’到‘流亡’”一页（页分组：干校六记、补录）。误传记妄末尾“回京已八年……因作此六记。”原样保留在该页末段。
- 已知问题：
  - 目录列有“校定本前言”，但对应的 PDF 第 20 页为空白（OCR 无文字），前言整篇缺失。
  - 《学圃记闲》标题在 OCR 中缺失，页标题按目录补；其余各记标题前的章号（四、五、六及补录各篇的二至七）已去掉。
  - 部分页为硬换行排版，段落边界依行长与句末标点推定，个别对话段落可能误合或误分。
  - 少量形近字、标点（如“已/己”、破折号）识别有误，未逐一校改。
