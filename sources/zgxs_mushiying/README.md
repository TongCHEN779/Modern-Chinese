# 穆时英小说经典

- 底本：穆时英《穆时英小说经典》（《中国现代小说经典文库》阿宏主编，扉页题“中国现代小说经典文库　穆时英小说经典”，PDF 文件名作“穆时英卷”），北京：印刷工业出版社，2001 年 3 月第 1 版第 1 次印刷，全套 12 卷，ISBN 7-80000-413-9/I·11。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：前言一页，其后二十三篇小说各占一页，次序依书。页内有小节的，小节名依书：《田舍风景》“一　扉语”“二　屋檐下”“三　晨”，《Craven“A”》《公墓》《烟》《骆驼·尼采主义者与女人》为“一、二、三……”，《断了条胳膊的人》为“第一节……第五节”，《夜总会里的五个人》“一　五个从生活里跌下来的人”等四节，《贫士日记》按日记日期分节。篇末的写作日期、《生活在海上的人们》篇末的“作者附志”保留为正文段落。
- 去掉了：封面、版权页（CIP 数据、定价、印数等）、目录页、页眉“穆时英小说经典”、页码、PDF 末尾的封底乱码页。
- 版面：OCR 稿按行断开，我据逐页坐标（缩进、行宽）重建段落：行首缩进且上一行已满行并以句末标点结束的另起一段，短行（诗行、对话）各为一段，跨页断开的段落已接上。个别行首缩进不明显处可能把两段合为一段，或把一段拆成两段。
- 小节号：小节号“一、二、三”印作一道短横，OCR 常漏识。已按版面补回：《Craven“A”》《公墓》《烟》《骆驼·尼采主义者与女人》各篇开头的“一”（PDF 第 140、157、323、317 页），《骆驼·尼采主义者与女人》第 318 页“是紫暗暗的晚霞……”前的“二”。《夜总会里的五个人》“一”小节的标题“五个从生活里跌下来的人”与号“一”相连，已加空格分开；其余小节名同。
- OCR 已知问题：
  - 目录页 OCR 错乱（篇名与页码错位），未收；篇名据正文页标题。《田舍风景》目录作“田舍风”，《生活在海上的人们》目录作“生活在海上的人”，页标题以正文为准。
  - 《手指》《油布》《公墓》《玲子》篇名在页面上竖排成上下两字，已按次序还原。
  - 《贫士日记》有两节均题“十二月十二日”（PDF 第 346 页），按 OCR 原样保留，未核对原书是否为“十三日”之误。《田舍风景》“三　晨”下的单行“小唱”、《夜总会里的五个人》的“街”等单行小标题当作普通段落保留。
  - 《夜总会里的五个人》《被当作消遣品的男子》里的对话说话人与引语之间原书可能有破折号，OCR 未见，未补。
  - 个别字形近或漏字（如“铁”“己”、第 82 页一行末尾疑有断句），明显处之外未改动。外文（法语、英语）夹杂处按 OCR 原样。
