# 献给爱与子宫的花束

- 底本：［日］铃木凉美《献给爱与子宫的花束》，蕾克 译（译者据书末“作者/译者”介绍页）。出版社与年份：所得扫描稿无版权页，未能确认。文字由书籍扫描件经 OCR 识别、整理而成，**尚未逐字校对**。
- 整理：去掉封面、电子书广告页、书末作者/译者介绍与封底引语、“写在前面/写在最后”的隔页、卷号隔页（Ⅰ、Ⅱ、Ⅲ）。全书按其卷次分为“写在前面”“Ⅰ 我和母亲”“Ⅱ 母亲们和女儿们”“Ⅲ 再一次，我和母亲”“写在最后”五页；各篇随笔题目作为页内小节。“写在前面”“写在最后”两页内只有一篇文章，其节名取该文题目（《夜晚，我恋慕灰姑娘式的不幸》《既不是鬣蜥，也不是人》）；三卷的第一节同样取第一篇随笔题目。
- 书中无单独目录页，分章依据正文的隔页与各篇首行标题。
- OCR 已知问题：段末右引号常被识成“ 或 "，已按成对关系改回；其余错字未逐一校，如“祖露”“暧昧”误作“暖昧”、“早沉好”等，原样保留。原稿缺 p0036、p0120 两页（隔页/空白页，应无正文）。
