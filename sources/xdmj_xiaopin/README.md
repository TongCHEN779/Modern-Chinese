- 每篇一页：出版说明 1 页，代序 4 页，散文 90 页，书信 60 页，日记 3 页（《西湖记》《志摩日记（选录）》《眉轩琐语（选录）》），共 158 页。`pages.json` 第三项：序文页为 null，其余填“散文”“书信”“日记”。
- 书信页标题取书中信题加日期，如“致陆小曼（1925年3月3日）”；《一封公开信》《山中来函》《给陆小曼》各信的副题并入页标题。五封“致凌叔华（日期不详）”书中同题，页标题末加“之一”至“之五”以区分（书中无此字样）。

- 文内小标题各为一节：（一）（二）……、一、二……、“六、西伯利亚”“丑西湖”“狗食盆”等；日记中的日期行保留为段落；《眉轩琐语（选录）》末的小诗《残春》单列一节。
- 原书每篇末的出处行（如“（《晨报副刊》，1923年6月10日）”）保留为段落。诗行、对话逐行或逐句另起一段。
- 去掉：封面、版权页、目录、页眉页码、空白页、书脊/封底。无作者小传。
- 半角标点在汉字旁改全角；字句一律照书，未改写。
