# 缘缘堂随笔

- 底本：丰子恺著《缘缘堂随笔》，人民文学出版社“百年百种优秀中国文学图书”丛书，2000 年 7 月第 1 版（2001 年重印）；该本依 1931 年上海开明书店版。文字由扫描件经 OCR 识别、整理而成，**尚未逐字校对**。
- 整理：每篇一页，共二十一篇（《翦网》《渐》《立达五周年纪念感想》《自然》《颜面》《儿女》《闲居》《从孩子得到的启示》《天的文学》《东京某晚的事》《楼板》《姓》《忆儿时》《华瞻的日记》《阿难》《晨梦》《艺术三昧》《缘》《大账簿》《秋》）加附录《告缘缘堂在天之灵》一页。页内“二”为原书小节序号（《从孩子得到的启示》《忆儿时》《华瞻的日记》）；原书第一节无序号，OCR 亦未见，故沿用页标题。附录文末“(1938年)”保留为最后一段。
- 去掉：封面、版权页、作者简介页、丛书前言/评选委员会/丛书书目、目录页、页眉页脚页码、末尾 OCR 附带的“General Information”元数据页。书中无脚注。
- 已知 OCR 问题：
  - 《儿女》第 34/35 页衔接处“最年长的不过九岁”的“九”前有噪点，已按上下文改；“——九岁的阿宝”前破折号亦为识别成“一”。《渐》“临到了”识别作“T!”，已改。《闲居》“middlc”已改为“middle”；其余英文拼写（如“Peethoven”“allegrio”“Mendelsson”）保持识别原样。
  - 《告缘缘堂在天之灵》偈中“××”为原样保留；《从孩子得到的启示》第 43 页的孤立页码“7”、《忆儿时》“二”前序号等已按上述处理，其余标点（顿号与逗号、“—一”破折号）可能有识别误差。
