# 世界短篇小说精品文库·德语国家卷

- 底本：柳鸣九主编、韩耀成编选《世界短篇小说精品文库·德语国家卷》，海峡文艺出版社，1996 年 8 月第 1 版（ISBN 7-80534-880-4/I·775）。文字由书籍扫描件（PDF，729 页）经 OCR 识别、整理而成，**尚未逐字校对**。
- 收录：德国、奥地利、瑞士 42 位作家的 45 篇小说（据目录；编选者序称“44 篇”，与目录相差一篇，以目录为准），从歌德到汉特克。全书 47 页：总序（柳鸣九《序》）一页、编选者序（韩耀成）一页，其后每篇小说一页。页标题用目录所载篇名，副标题（《露西多尔》《判决》《四月》）以“——”接在篇名后；棱茨、帆游、围城、隧道、一切、郊游、女友、爱情等篇名在标题页 OCR 中被拆成单字或缺字，一律按目录写。
- 译者署名：书中译者名印在文末，本站统一移到每页第一段，写作“（某某 译）”。OCR 中有三处译者名识错（“傅惟感”“傅趣寰”“王步涛泽”），按目录改为傅惟慈、傅越寰、王步涛。
- 作家介绍：书中每位作家的“作家作品简介”（含生平和对所选篇的评介）印在该作家作品**之后**（一页内文末），这里保持原位，作为各页最后一节“作家作品简介”（多德勒尔一篇书中印作“作者作品简介”，原样保留）。有两篇的作家（卡夫卡、伯尔、沃曼）简介只印在其第二篇之后，所以第一篇（《判决》《流浪人，你若到斯巴……》《郊游》）页上没有此节。
- 页内分节：茵梦湖按书中小标题分节（老人、儿时、林中、姑娘亭立路旁、还乡、一封信、茵梦湖、依着妈妈的心愿、伊莉莎白、老人），页标题同名的第一节只含译者署名；道口工梯尔、心按书中编号分“一、二、三”；编选者序按“一至五”分节（其前一段无编号）。小顽固里的“＊　＊　＊”分隔符保留为单独一段。
- 去掉了：封面、扉页、版权页、目录页、页眉页脚页码、页末脚注（正文里的脚注序号①②等一并去掉）、版权页之后的主编简介。无插图说明页。

## OCR 已知问题与处理

- **漏识的编号**：书中“一”（一道短横）OCR 没有识出：编选者序的“一”“二”、道口工梯尔与心的第一节“一”，均按页面图像与上下空白补出；其余编号“二”“三”等为 OCR 所识。
- **破折号**：OCR 常把“——”识成单个“—”（约二三百处），凡夹在汉字之间的单个“—”统一改为“——”；数字间的范围号（如“1749—1832”）未动。个别“—一”“一—”的位置按此规则处理，仍可能有错。
- **分段**：按行首缩进、行宽及相邻行缩进差重建自然段；整页倾斜、缩进不明显的页面可能有个别段落合并或断开。迪伦马特《隧道》全篇在书中即排成一个大段（共 7000 余字），保持为一段；施尼茨勒《死者无言》中也有一段长达三千余字，亦与书中排版一致。诗歌、歌词每行一段（茵梦湖、艾克贝尔特、棱茨等）。
- **噪点**：散落的单个字母、数字、符号（页边污点）已删；弗里施《一个名叫弗罗伦丝的混血女郎》中的英文对白（半角标点）原样保留；半角 `( ) , ; : ? !` 紧邻汉字处改全角。
- 其他识别残留（如“。，”、个别错字）未改。《棱茨》里一处以“[”开头的段落为书中方括号舞台说明，原样保留。
- 缺页：没有。（OCR 稿 full.txt 的页码有搬移，本整理直接据逐页坐标稿 json 重建，各页均有内容。）
- 小说起止以目录页码（正文页码 + 30 = PDF 页码）核对，45 篇篇起点均与版面标题吻合。
