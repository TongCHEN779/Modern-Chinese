# 宋词三百首笺注

- 底本：唐圭璋笺注《宋词三百首笺注》（中国古典文学读本丛书典藏），人民文学出版社，2005 年第 1 版，2017 年典藏重印；所笺为朱祖谋（彊村）所编《宋词三百首》。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：去掉封面、版权页、丛书广告、目录页与页眉页脚；收唐圭璋《自序》、况周颐《原序》、吴梅《笺序》（各一页），其后每位词人一页（共 81 页）。页内首节为词人小传及历代对其词的总评（节名同词人名），其后每首词一节；词牌与题名用“词牌·题名”，原书在词牌下另有较长的小序（如“丙辰中秋……”“淳熙丙申至日……”）的，作为该节第一段。
- 词：一阕为一段，句间用 `/` 分行。原书把上下阕接排，只在版面上有空档或行尾明显短缺处才分得出阕，其余双片词（约二十首，如《御街行》《一丛花》《千秋岁引》《贺新郎》“赋琵琶”）仍合为一段。
- 评笺：每首词后的“【评笺】”（本事、集评、校记）各条为一段，第一条段首保留“【评笺】”。
- 注释：原书把脚注集中印在每位词人最后一首词之后，编号 [n] 在该词人名下连续排列，转换时按正文标号放回所属段之后。注首若是原文词语则取为词语，找不到时取标号前的一小段正文为词语；标号在词牌或题名上的注，挂在该首第一段。注文里含“。某某：”形式的引文，为免被站点拆成多条，用“注原：”一行一条。
- OCR 已知问题：脚注标号 [7]、[9] 常被识成 [2]，已按序号连续性改回；《菩萨蛮》（郁孤台下）一首 OCR 脱去首行，据同套书《辛弃疾词选》补回“郁孤台下清江水，中间多少行人泪。西北望长安”；吴文英《澡兰香》“为当时曾写榴裙”与“唱江南古调”之间脱一行（注 [60][61] 所属文字），未能补；个别标号丢失（张孝祥、姚云文各一处，吴文英注 [60]）按注首词语在正文中找回；“別”统一改作“别”，“満”改作“满”；原书个别字形（如《词综偶评》中的“·”代“，”）照 OCR 保留；约 5% 的注释词语与正文用字不同（如“缸/钉”），挂在标号前的正文上。
