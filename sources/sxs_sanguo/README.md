# 3小时读懂三国

- 底本：姜若木编著《3小时读懂三国》（“一目了然速读史”系列），京华出版社，2011 年 4 月第 1 版第 1 次印刷（ISBN 978-7-5502-0223-8）。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：按书的目录分页——前言一页；第一至第七章各一页（页标题保留“第×章 ……”，章标题中的冒号改为空格）；附录一页。章内各节（目录中的“一、二、三……”小标题）各为一节；个别章内还有书中另设的小标题（第六章“推行屯田”“征讨山越”“发展交通和手工业生产”，附录中的“魏国经济”“蜀国经济”“吴国经济”“1.建安风骨”“2.竹林七贤”“嵇康及古琴曲《广陵散》”“蔡琰及《胡笳十八拍》”“阮籍及《酒狂》”），也各为一节，与所在节并列。附录“二、三国时期的文学成就”下紧接两个小标题，故该节本身无正文。
- 栏目框“点评”“相关链接”及其中的人物小传（如“董卓小传”）属正文，保留为所在节末尾的独立段落，栏目名单独成段。附录“四、三国历代皇帝年表”按表格每行一段，各栏用全角空格隔开；原表同一帝王名下的多个年号，后几行不重复帝王名。
- 去掉：封面、版权页、目录页、页眉（“3小时读懂三国”）、页码、章名竖排页边标、插图及图片说明、地图（黄巾起义形势图、赤壁之战示意图与形势图）及其标注文字、书末扫描信息页。
- 段落：依 OCR json 行坐标（缩进、行宽）重建，跨页接合；绕图排版的窄栏文字按纵向顺序接合。
- 改动：仅更正把握很大的 OCR 单字错误——“自已”“异已”“知已”“坚持/固执已见”“收为已用”改为“己”，“刘备人蜀”改为“入蜀”；西文括号、逗号在中文语境中改为全角。小标题的数字序号（如“一、”）在正文页里多被 OCR 漏识或误识，一律按目录补全；“人京”“人川”等标题误识据目录改正。
