# 诗坛鬼才：李贺

- 底本：李盾著《诗坛鬼才：李贺》（封面题“诗坛鬼才 李贺”；“中国名人轶事丛书”之八，吴洪激主编），武汉大学出版社、台湾汉欣文化事业有限公司联合出版，1994 年 7 月第 1 版（CIP 标 1994.6）。文字由 Anna's Archive 所收扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：共十七页——丛书出版缘由、主编絮语（吴洪激序）、楔子、第一至第十二章、尾声、后记（作者自撰），各占一页。书中章下只有章号（无章名、无小标题），故每页只有一节，节名同页标题。
- 去掉的内容：封面、书名页、版权页（CIP 数据）、目录页、丛书广告页、Anna's Archive 说明页、页眉页脚与页码、页下脚注（①②…的注释文字）及正文中的脚注序号、“主编絮语”与出版缘由文末署名（吴洪激）。“主编絮语”文末写作日期“一九九三年三月于古城黄州”保留。
- 诗词：书中的诗按原书每行一段，整理时以“诗：”行居中显示；诗行由脚本按行宽与句式识别（连续多行短句），并据人工抽查补入无句末标点的行与诗题（如《赠陈商》《杜家唐儿歌》、《高轩过》题序）。对话或段落内引用的诗句不分行。
- OCR 已知问题：页边的孤立数字、字母噪点已按规则删去，但仍可能有漏删或误删；个别单字错识（如“象/想”“已/己”之类）与引号缺失未逐一校改；少数“……”被识作“.…..”，已统一为“……”；若干行首“——”被识作单个“—”（如尾声中“—哈哈，又是杜撰了”）；个别诗行有残缺或多余标点（如第二章《西山日没东山昏》一句末“。，”、第七章《杜家唐儿歌》首句残字），保持原样；诗行是否整齐划一以脚本识别为准，个别短句（如“秋衾梦……”）可能与书中版面有出入。段落按 OCR 版面的缩进重建，跨页段落已接合，少数处可能误合或误断。
