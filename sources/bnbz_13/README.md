# 志摩的诗

底本：徐志摩著《志摩的诗》，作家出版社，2000 年 7 月第 1 版（“百年百种优秀中国文学图书”丛书之一，2001 年 11 月第 3 次印刷）。据 1925 年初版线装本重排，书中以脚注形式标出与平装本（1928 年中华书局版）的异文。OCR 来源 `13、志摩的诗`。

整理说明
- 全书 56 首诗，一首一页，页标题与诗题一致（取自书中目录，诗题行本身的 OCR 残缺时以目录为准）。
- 诗行按原书逐行保留，逐行一个“原：”；《灰色的人生》《毒药》《白旗》《婴儿》《常州天宁寺闻礼忏声》原书为悬挂缩进的长行，已按缩进接成自然段。节与节之间的空行（诗节）未保留。
- 去掉：封面、版权页、丛书目录与前言、编委会名单、作者小传（封面页）、每页页脚的平装本异文脚注及脚注标号（①②③④）、页码、末尾 Anna's Archive 水印页。
