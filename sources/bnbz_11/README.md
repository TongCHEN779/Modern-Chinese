# 南社丛选

- 底本：胡朴安选录、沈锡麟、毕素娟点校（校注）《南社丛选》（“百年百种优秀中国文学图书”之一），解放军文艺出版社 2000 年 7 月第 1 版；原书初版为 1924 年上海国学社版。文字由书籍扫描件（PDF）经 OCR 识别、整理而成，**尚未逐字校对**。原书上、下两册，本文库合为一书。
- 结构：汪序、傅序、柳序、自序各一页；其后每位作者的某一体裁（文选、诗选、词选）为一页，页标题为书里的“某某文选/诗选/词选”（作者以号相称），页内首节为作者小传（含“今录某首”），其后每篇文章、每题诗词一节，节名取书中原标题；同一标题下的多首诗词（如“某某四首”“浣溪沙”六首）按原样各占一段。`pages.json` 第三项为原书的卷次（文选卷一至卷十、诗选卷一至卷十二、词选卷一至卷二）。
- 去掉的内容：封面、版权页、丛书前言、评选委员会、丛书书目、总目与三部分目录（目录由站点自动生成）、页眉（“南社丛选”“文选卷×”等）、页码、末页的数字图书馆说明。原书无页脚注，作者小传与诗词自注、小注（排小字）原样并入所在段落。
- 已知 OCR 问题：
  - 诗词原书每首（每阕）为一段，换行只是版面折行，已按缩进合并；词的上下阕/长短句在版面上常分成左右两块，已按行拼回。
  - 标题与正文的划分依据版面（行距、缩进、有无句末标点），个别标题与小注（词序）并为一个较长的节名，如“秋宵吟……”（莼农词选）；个别地方标题与其后的小序各自成节，因此少数节只有标题而无正文（屯艮诗选“次韵和胡朴安焦山诗三首”、匪石诗选“醉歌”、楚伧诗选“梦吴江行”、小柳词选“一剪梅重九和朴庵韵”）。
  - 少数无句末标点的标题或带署名的和作可能被划错节；署名如“柳亚子”“陈佩忍”留在所属诗段末尾。
  - 页标题中“鹤雏”在 OCR 稿里常脱“鹤”字，已补回；“薜生”改作“薛生”，“孝穀”改作“孝谷”（据目录）；“民讦诗选”目录作“民订”，未改。“文选卷四”“诗选卷十一”的卷首页眉 OCR 未识出，卷次据目录推定（文选卷四自勒生文选起，诗选卷十一自鲁望诗选起）。
  - 页末残留的页码数字、个别混入正文的西文字母（如“Stick”“C州”）和形近字错识（“蝶／螢”“閔／阕”“賦／赋”等）未全部校改，约有十余处明显杂点；“次公文选”小传在 OCR 中漏记“今录文五首”。
  - 原书“总目”统计的篇数与实际文章数略有出入（如钝庵、巢南、匪石、摩西等文选实有篇数比小传所记多一篇），按实际排印为准。
