# 鲁迅杂感选集

- 底本：鲁迅著《鲁迅杂感选集》，解放军文艺出版社“百年百种优秀中国文学图书”丛书，2000 年 7 月第 1 版（原本为何凝即瞿秋白编选并作序，1933 年上海青光书局版）。文字由书籍扫描件经 OCR 识别、整理而成，**尚未逐字校对**。
- 整理：去掉封面、版权页、作者小传、丛书前言与评委名单、丛书书目、目录页、页眉页脚与页码。第一页为何凝《鲁迅杂感选集序言》，其后每篇杂感一页，页标题取目录篇名（“无题（‘新青年’随感录之二十五）”等六篇依正文标作“随感录（二十五）”等）。页分组按所出自的集子：热风、坟、华盖集、华盖集续编、而已集、三闲集、二心集（目录中的年份分组未保留）。篇内“一、二、三”“1、2、3”及《马上支日记》的日期作小标题。本书无页脚注，无集中注释。
- OCR 已知问题与处理：
  - 《杂忆》《记念刘和珍君》《空谈》《忽然想到（十一）》等篇内部分章节序号（如“一”“二”）OCR 稿中缺失，未补；《无花的蔷薇之二》版面中多出一个孤立的“6”，已删，使序号为 1–9；《忽然想到（十一）》中孤立的“1”、《文艺与革命》中孤立的“十”、《“公理之所在”》中孤立的“7”、《小杂感》中孤立的“2.”均作噪点删去。
  - 《青年必读书》一页版面混有表格框栏碎片（“附”“注”“庆世”等），按上下文手工复原，“人世”改作“入世”，“庆世”改作“厌世”，此篇段落文字请对照原书。《忽然想到（十一）》第 3 节末至第 4 节前的几行（“要中国好起来……明白以后……”）在 OCR 中与相邻段落交错，顺序可能不准。
  - 引文、版面窄栏中被硬换行的行已按“行末无句读则并入下一行”合并；个别诗行、引文仍可能分段不当。《古书与白话》OCR 页首作“古书与自话”，已按目录写作“白话”；《上海文艺之一瞥》同理。
  - 零星形近错字、标点错乱未逐一校改。
