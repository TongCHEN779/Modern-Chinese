# 世界短篇小说精品文库·澳大利亚、新西兰卷

## 底本

《世界短篇小说精品文库　澳大利亚、新西兰卷》，柳鸣九 主编，朱炯强、沈正明 编选，海峡文艺出版社，1996 年 8 月第 1 版，ISBN 7-80534-888-X/I·783（平装 28.00 元）。全书约 53 万字（OCR 的 PDF 共 704 页）；译者署名均印在各篇文末。

## 整理说明

- 共 67 页：柳鸣九《序》、编选者序（朱炯强、沈正明）各占一页，其后每篇小说一页，共 65 篇、58 位作家（澳大利亚 53 篇、新西兰 12 篇，篇目与书中目录一致；页标题用书中篇名，第三项为作家姓名，取自书中作家小传所写译名）。
- 书中的“作家作品简介”印在该作家第一篇小说的文末（译者署名之后），整理时移到该作家第一篇小说页的第一节，节名“作者小传”；同一作家的第二篇及以后各篇没有此节（劳森、怀特、凯琳·高尔斯华绥、曼斯菲尔德、萨吉森均有两篇以上）。彼得·高尔斯华绥一篇的小传后附有对《纯洁无邪》的简评，原文即在小传之内，一并保留。
- 译者署名由文末移到各篇正文第一段，写作“（某某 译）”；多位译者之间以空格隔开（据目录）。
- 小说自带的编号小节（沃拉恩、大卫·坎贝尔、亨格福特、麦洛夫、彼得·高尔斯华绥各篇的“一、二、三……”）每节另起一节；伊格尔《飞行组曲》的四个小标题、曼斯菲尔德《黑色便帽》的四个场景标题（去车站的路上、在车站、在旅馆、在出租汽车里）、乔莉《白鬃马》的两个人名小标题（劳拉、安德烈娅）亦各为一节。兰斯多恩《归心似箭》是日记体，日期各占一段。
- 去掉了：封面、版权页、目录、页眉页脚、页码、页脚脚注（共 20 余条；正文里的①②③ 等脚注标记一并删去）、文末附印的 Anna’s Archive 水印说明。
- 段落按 OCR 逐行坐标重建（缩进、行宽、页间接续），对话每段另起；半角标点在汉字旁改全角；少数繁体字残留（賽、遺、脫、奧等 20 余字）已改为简体，“山茂樫”依 full.txt 作“山茂㭴”。

## OCR 已知问题与存疑

- 目录与正文篇名不一致处：目录作“来得不易的早餐”，正文作“得来不易的早餐”，从正文；目录作“膨、嘭”，正文作“嘭、嘭”，从正文。
- OCR 中《学校》《纠偏》的篇名行缺失，篇名依目录；《夏鸟》《中士》《余暇》《苍蝇》《男孩》《老枪》《车子》的篇名首字或单字被识别丢失，亦依目录补。
- 《得来不易的早餐》《来吧，比利》《忘却身世的孤儿》《一个旅行者的故事》的小节编号“一”“二”（及《纯洁无邪》的“一”）OCR 漏识，按版面（小节标题的留白位置；《得来不易的早餐》《一个旅行者的故事》对照 PDF 页面核实，其余依同一版面规律）补入；《一个旅行者的故事》开头一节原书无编号，故首节仍用篇名。
- 《飞行组曲》四个小标题的罗马数字 OCR 不清（原书为“坎塔斯Ⅰ、坎塔斯Ⅱ、泰航、泰航Ⅰ，坎塔斯Ⅱ”之类），所记数字仅依版面推断，存疑。
- OCR 中夹有 11 页（p72、89、132、135、251、303、399、405、468、508、590）未输出，核对 json 后确认其内容已并入前一页（均为作家小传的续行），内容无缺失。
- 《疣的寿命》约在第 139–162 页处个别行有错序（如“……接受新的荣誉 / 房屋中、书架上……”一处），OCR 行序已如此；若干单字错识（如“大賽季”类）仅改把握极大者，其余保持原样。
- 小传中个别年份的“—”“-”符号 OCR 缺失（如彼得·高尔斯华绥“（1951）”，原书为“（1951—）”），保持原样。
- 段落重建靠版面推断，少数页首跨页处或无缩进的叙事（如《乳品点心铺》）可能有并段或误分段；抽样检查每位作家至少一篇的首尾，未发现缺漏。
