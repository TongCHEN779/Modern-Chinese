# 托洛茨基：先知三部曲·第一卷 武装的先知

## 底本

《先知三部曲》第一卷《武装的先知——托洛茨基：1879—1921》，〔波〕伊萨克·多伊彻（Isaac Deutscher）著，王国龙译，施用勤校（全书由施用勤、张以童统校），中央编译出版社，1998年10月第一版（1999年1月第1版第1次印刷），ISBN 7-80109-137-X（全三册）。原书英文版 Oxford University Press, 1954。

## 整理说明

- 每章一页，共 19 页：译者前言、前言、致谢，第一至第十四章，另有紧接第十三章之后单列的《托洛茨基军事思想评论》（目录中以括注形式列于第十三章之下，版面上另起一页、自有标题，故单列），书末参考书目。
- 本卷章内无标题小节，每页只设一节，节名同页标题；章内以“※”隔开的段落断点保留为单独一段“※　※　※”（原书印数个 ※，OCR 数目不稳，统一写作三个）。
- 第十一章标题中的“布列斯特一里托夫斯克”，书中连接号印作“一”，页标题写作“—”。
- 去掉：封面、扉页、版权页、目录、页眉页脚页码、每页底部的脚注（本卷无集中的章末/书末注释，故无“注释”一节）、插图及图版说明；正文中的脚注号（①②…）一并去掉。
- 本卷无大事年表，也无独立索引（书末仅有参考书目），故不收索引。第二、三卷各自成书，不在本册之内。
- 半角标点在汉字旁改为全角；中文书名号内被 OCR 误识为“)”的收尾符号，凡把握大的改为“》”。

## OCR 已知问题

- 底本按逐页坐标重建，版心、段落依首行缩进判断；引文块（缩进、窄行）较多的页，段落切分可能有少量误合或误断，个别段落末尾缺句号。
- 页底脚注按行距与脚注号位置判断，个别脚注的残句可能留在正文里或个别正文行被误去（已抽查修正数处）。
- 参考书目页：其中俄文条目 OCR 基本成乱码，已整行去掉，只保留可辨的西文条目；个别条目因缺行而合并或残缺，仅作参考。书目首页的括注说明保留。
- 前言、致谢之前的卷首引语（取自马基雅维里《君主论》）在 OCR 稿中未出现，未收。
- 个别西里尔字母、数字、人名拼写有 OCR 错识，除把握极大者外保持原样；书中以“一”代“—”（如“1879一1921”）处亦保持原样。
