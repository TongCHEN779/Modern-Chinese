## 第1册（qsyy_wudai）

- 底本：蔡东藩《五代历史演义全书》（“中国全史”丛书），大众文艺出版社，年份不详（扫描件未见版权页年份）。单册成书，全书六十回，起第一回“睹赤蛇老母觉异征　得艳凤枭雄偿夙愿”，止第六十回“得辽关因病返跸　殉周将禅位终篇”。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成。
- 整理：每回一页，页标题为“第N回 回目上联 回目下联”（以正文每回开头的回目为准，目录页仅用于核对）；页内不再分节。回数一至六十连续，无缺回、无重出。
- 去掉的内容：封面、扉页、目录、版权及封底、页眉“五代历史演义全书”“中国全史”、页码。本书无序跋、附录。
- 段落按版面坐标（缩进、行宽）重建，跨页段落已接上；每回后附的蔡东藩评语、诏书檄文等引文按版面（缩进较深的窄行）另成段落；诗词每句一行或整行随版面。回末套语原样保留。半角标点在汉字旁已改全角。
