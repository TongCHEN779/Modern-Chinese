# 马可瓦尔多

- 底本：［意］伊塔洛·卡尔维诺著、马小漠译《马可瓦尔多》，译林出版社 2020 年 1 月第 1 版（“卡尔维诺作品”丛书）。文字由书籍扫描件（PDF）经 OCR 识别、整理而成，**尚未逐字校对**。
- 整理：全书二十则故事，按书的目录各占一页，页标题为“序号 篇名”（原书每篇前另标春/夏/秋/冬季节，未写入页标题；顺序为春夏秋冬循环，共五轮）。原书无序、后记。
- 去掉：封面、版权页、目录、书末版权信息与封底文字、每页页眉（“马可瓦尔多 Italo Calvino”）和页码、页脚译注（译者脚注）及正文中的脚注序号（①②③）。
- OCR 已知问题：页眉常粘在句中，已剔除；个别跨页处接合可能有误；“念着”一处原为“念III着”（页码噪点），已删噪点；外文（Sbav、SPAAK-COGNAC、COGNACTOMAWAK 等）原样保留，第十四篇中广告牌字样的 OCR 可能与原书有细微出入。
