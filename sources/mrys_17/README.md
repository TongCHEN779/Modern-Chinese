# 山水诗人——孟浩然

- 底本：陈文道著《山水诗人——孟浩然》（“中国名人轶事丛书”之十七，吴洪激主编），武汉大学出版社、台湾汉欣文化事业有限公司联合出版发行，1995 年 11 月第 1 版（版权页 CIP 标 1995.11；丛书统称 1994 年联合出版）。书名页作“山水诗人孟浩然”，CIP 作“山水诗人：孟浩然”，主编序文作“《山水诗人——孟浩然》”，此处取后者。文字由 Internet Archive 扫描件经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：共六十一页——丛书出版缘由、主编絮语（吴洪激序）、五十八篇故事（各占一页，页标题即书中篇名，每页一节，节名同页名）、附录“孟浩然年表”。全书无章节编号，故事之内无小标题。
- 去掉的内容：封面、编审委员会名单、版权页、Internet Archive 水印页、图书馆章页、目录页、页眉页脚与页码、书末丛书广告页；插页（彩图页及其图下摘句题注：约 28、56、84、108、140、164、190、248、284 等 PDF 页，题注文字与正文重复）；出版缘由与主编絮语文末署名（吴洪激）。
- 段落依据 OCR 坐标（json/ 中的框）按版面缩进与行宽重建，跨行、跨页段落已接合；诗词、对联、谜语等居中排印的行按原书每行一条“诗：”。年表各栏用全角空格隔开，一行一条。主编絮语开头所引李白《赠孟浩然》，因 OCR 折行，据版面拆回四行。
- OCR 已知问题：
  - 个别页（如第 162 页后部）有整行漏识，造成段落残缺（“孟浩然回奏道：……棋艺不精”与下一行之间疑缺一行，见《诗傲帝王阻梦思》）。
  - 引号、书名号偶有缺失或不成对（如“雨打沙洲点点涡”前缺引号），未逐一校改。
  - 个别字形近误识或漏识：已校“襄阳带百日无雨”补“一”、对联“进土”改“进士”；其余未改。
  - 主编絮语称“五十余篇”，丛书广告称“六十余篇”，实收五十八篇。
