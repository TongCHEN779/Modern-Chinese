# 古船

- 底本：张炜《古船》，人民文学出版社“百年百种优秀中国文学图书”，2000年7月第1版。
- 整理：按书的章次分页（第一章至第二十七章，原书各章只有章次、无章名），另有书末“代后记 在济南、北京《古船》讨论会上的发言”一页。
- 去掉的内容：封面、版权页、作者简介、丛书前言与评委名单、百年百种书目、页眉页脚、孤立页码及 OCR 碎片、书末 Anna's Archive 生成说明。保留第二十七章末的写作时间地点，及“代后记”。
- 已知问题：OCR 中无段首缩进信息，跨页处仅依据上一行是否以句末标点结束来接段，个别恰好在页末句号处结束的段落可能被拆开或合并；段落划分以此为准，偶有不准。书内页码多已识别丢失，仅个别残留已删除。个别字形近误字未逐一校正。未发现明显缺页。
- “代后记”含济南（1986年10月）与北京（1986年11月27日）两次讨论会发言，北京发言的题记原在页末，已置于其发言之前。
