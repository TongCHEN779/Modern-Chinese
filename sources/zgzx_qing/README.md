- 各篇原文按底本版面重排：由 OCR 逐列坐标按竖排从右到左重新读序（原 full.txt 把低置信度的列放错了位置），再按缩进、列尾长短分段；篇末“注”按小字、缩进识别，条首的注号去掉，放回所注段后。
- 去掉了：封面、版权页、目录、页眉页脚、页码。选文中的节录省略号“……”保留为单独一段。篇末出处（如“（明夷待访录）”）并入末段。

## OCR 已知问题
- 标点大量丢失（逗号、顿号、句号多不见），按要求未补；半角括号等已改全角。
- 正文里的注号（原为〔一〕〔二〕）在 OCR 中变成夹在正文里的汉字数字（如“渐倍四于程朱”的“四”），未能可靠剔除，仍留在文中。
- 注释多无明确词语，且条首注号常被误识，约 9% 的注释（81/906）没能在所属篇中定位到词语，放在该篇最后一段之后；其余注释的词语是按注文开头与正文的匹配取的，个别较短或偏长，仅作定位。个别注条因 OCR 严重错乱被丢弃（少于 3 个汉字者）。
- 《系辞》《太和篇》等王夫之原文与注疏相间的篇章，按版面缩进与列尾长短分段，个别段落可能合并或拆分。
- 低置信度行有错字（如编辑说明末段“引否”、书名号丢失等），不确定的一律保留原样。

## 整理与已知问题

- **标点**：OCR 对小号标点识别很差，正文和注释里大部分标点已丢失（偶有保留的“。”“、”“；”“「」”），整理时未补标点；个别半角括号改作全角。
- **注号残留**：原书正文里的注号〔一〕〔二〕……被 OCR 识成孤立的汉字数字（如“同文四立于学官五著为国教”的“四”“五”），未能可靠剔除，仍夹在正文里；读时请留意。
- **注释定位**：注号 OCR 后多已错乱，注释靠开头的词语在正文中匹配来定位；词语与解释之间原本没有标点，二者的切分是按原文匹配和语法词推定的，个别切分不准（如词语多截或少截一两字）。有 138 条（约 17%）找不到可靠位置的注释，放在最相近的段落之后，其“词语”取自原注开头，不一定出现在该段原文里（这类注释在页面上会排在该段最后）。部分注释本身以“是说……”“见……”开头，没有单独标出被注词语，词语由解释中与正文重合的字串代替。
- **注号与序号**：原注的编号 OCR 后常见错识（如“一六”识成“六一”“吾”），整理时一律去掉编号，未据以重排顺序。
- **缺失**：康有为编者说明第 7 页（PDF 第 7 页）一行（“……保皇会，中华民国建立后又参……”）识别时只留下行尾部分，行首约二十字缺失，原样保留。
- **疑误**：谭嗣同编者说明中的“这里选取仁学一此条。”应有 OCR 漏字，未补；《上皇帝第六书》标题下的副题“应诏统筹全局折”（原有注号）作为该篇首段保留；《仁学界说》中的数学式及序号（括注数字）识别较乱，原样保留；少量形近字错识仅在把握极大处更正（仅改了康有为编者说明末尾的“酒了”→“西了”），其余原样保留。
- 书中引用的原文字形为简体（按识别稿转换），个别通假、异体字可能与原书不同。
