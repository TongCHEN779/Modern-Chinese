- 本书由大众文艺出版社“中国全史”丛书中的2册合并而成，共 100 页；各册整理记录如下。

## 第1册（tmp_qsyy_tang_1）

- 底本：蔡东藩著《唐代历史演义全书》，大众文艺出版社“中国全史”丛书本，年份不详（版权页未识别出）。本册为该书第 1 册（上），收第一回至第五十回；其余各回在后册。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成，未逐字校对。
- 整理：一回一页，页标题为“第N回 上联 下联”，回目以每回开头所印为准，并与目录页核对；目录、封面、版权页、丛书页眉、页码一律去掉。回末评语（每回正文后另起的小字评议）与回末套语原样保留；诗词、回中小表（如第二十九回的都护府与宗教名目、第四十二回姚崇“十事”）每行一段。
- 回数连续：第一回至第五十回不重不漏，共 50 页，未发现缺页。
- 回目修正（据目录页）：第十三回“受刃”（正文识作“受刀”），第二十七回“李勣”（正文漏“勣”），第四十八回“中毒”（正文漏“毒”）。第十二回“文幹”、第十回“刘黑闼”据正文，目录页识别有误，未随目录。
- 已知问题：第三十二回开头所列“唐宗”“唐臣”两份被杀名单，原书各人名之间有空格，OCR 未保留，人名连在一起；第四十二回“十事”中第三、五条因版式跨行，已按内容接回。第二十八回“奉士彟祀”中的“彟”字据人名补定。其余个别错字、漏字原样保留。
