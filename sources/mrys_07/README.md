# 张居正传奇

- 底本：刘之昆著《张居正传奇》（“中国名人轶事丛书”之七，吴洪激主编），武汉大学出版社、台湾汉欣文化事业有限公司联合出版发行，1994 年 7 月第 1 版（ISBN 7-307-01781-4/K·154，字数 188 千）。文字由扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：共二十二页——丛书出版缘由、主编絮语（吴洪激序）、楔子、第一至第十八章、尾声，各占一页。章内以书中“二、三、四、五”小标题分节（书中第一节无编号，节名取“一”；第七章、楔子、尾声无分节，节名同页标题）。
- 去掉的内容：封面、版权页（CIP 数据、定价等）、目录页、页眉页脚与页码、书末丛书广告页及 Anna's Archive 水印页；出版缘由与主编絮语文末的署名（吴洪激）；“主编絮语”文末的写作日期“一九九三年三月于古城黄州”保留。
- 段落：按扫描版面的缩进与行宽重建（跨行、跨页的段落已接合）。书中数处整齐分行的诗句、对联（张居正口占五绝、东坡《水调歌头》引句、殿中楹联、陆树声所得偈语、戚继光七绝等）按原书每行一条“诗：”；曲词、公文、书札按一段处理。
- 章内小节序号：OCR 稿里小节序号“二”“三”等有相当一部分没有识别出来，整理时依据 JSON 版面坐标中的大段空行位置补回（共补 18 处），并核对了每章序号连续；第七章未发现分节标记，按无分节处理。第十四章第三节内一封信末的签名“四”按正文保留，不是节号。
- 章名：第十七章目录与章首均作“精谋细划”，书中各页眉作“精细谋划”，此处取目录与章首写法；第十六章页眉多处误识为“粗龉暗生”，取目录“龃龉暗生”。
- OCR 已知问题：个别单字错识（形近字）与标点缺失未逐一校改；“已/己”等混用保持原样；偶有页码、页眉残片并入正文的情况已尽量清除，仍可能有遗漏；半角标点多已改为全角。原书用字（如“象”“着”）保持不变。
