# 中国现代作家选集·俞平伯

- 底本：乐齐编《中国现代作家选集·俞平伯》，人民文学出版社 / 三联书店（香港）有限公司联合出版，1992 年 6 月北京第 1 版第 1 次印刷，ISBN 7-02-001400-3/I·1272。卷首有韦柰（俞平伯外孙）代撰的序（1987 年）。文字由书籍扫描件（PDF，共 384 页）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 结构：全书分“作品部分”（新诗·旧体诗词、小说·散文、文论）与“资料部分”（朱自清《〈冬夜〉序》、乐齐《俞平伯的文学创作》《论俞平伯的新诗》、王保生《俞平伯和他的散文创作》、韦奈《我和外祖父俞平伯》、孙玉蓉《俞平伯年表》）。共 36 页：序一页；“新诗”“旧体诗词”各一页，每首诗一节；小说散文每篇一页（含小说《花匠》《炉景》《狗和褒章》）；文论七篇各一页；资料部分六篇各一页。页内小标题为书中原有的节标题、编号。
- 去掉的内容：封面、版权页、目次页、页眉页脚、页码、末页的网站水印；页脚脚注及作者在篇末加的注（如《陶然亭的雪》《稚翠和她情人的故事》《风化的伤痕等于零》里的①②③注，评论文章后的引文出处注，《俞平伯和他的散文创作》题下“本文收入本书时，略有删节”一句）一律未收，正文里的注码已删。诗文末的出处行（“选自《冬夜》……”）保留为每篇末一行，统一了括号。

## 整理时的处理（请留意）

- **小节号漏识**：书中“一、二、三”常印作短横，OCR 漏识，我按版面空行（用逐页识别结果的坐标测量）补回：《春水》一、二；《哭声》一；《欢愁底歌》一、二；《两年之后》一；《夜雨（九首选三）》七；《歌声（二首）》一、二；《迷途的鸟底赞颂》一、二；《呻吟》一；《忆（三十六首选八）》一；《狗和褒章》一（第二节的“二”被识成两个“1”）；《诗底进化的还原论》一、二；《俞平伯的文学创作》一；《俞平伯和他的散文创作》一。《忆游杂诗》“山阳三日篇”前补“一”；《北归杂诗》“七三塔”“八将别”“十四到家了”分别拆作“七 三塔”“八 将别”“十四 到家了”。
- **标题**：OCR 把两字竖排标题识成倒序或缺字，按书的目录改正：《春水》《风尘》《起来》《归路》《夜月》《晚风》《炉景》《眠月》；《进城》《花匠》《歌声（二首）》《呓语（三十五首选七）》《暮》缺字，按目录补；《小劫》的题目整个没被识出，据目录补；《草里的石碑和赑屃》“赑屃”（OCR 作“巅屃/最屃”）据字形改。
- **诗分行**：新诗逐行一段；诗内空行（节间空行）未保留，只保留书中印出的节号。《绍兴西郭门头的半夜》中间两个小装饰符号（OCR 成“丰”“半”）未收。
- **旧体诗词**：版面为连排，按书的行文每首（片）一段。第 152—159 页（《蝶恋花》《玲珑四犯》《菩萨蛮（三首）》《踏莎行》《思越人》）OCR 把折行的行尾字与别处接错，我按词牌格律把错位的字句放回原处（如《菩萨蛮（三首）》每首上下片、“更深梦也多”“空怜玉霄寒”“山前仍有山”“明眸一线红”，《踏莎行》“中庭瓜果为虚设”，《思越人》“回首家山路几千”“荒园自锁苔痕里”），《玲珑四犯》把小序与词分开；个别字（如“支柱晴空澹树色轻飓”）存疑。《重圆花烛歌》的第 141 页在整理稿里丢了，改用逐页识别稿补入（正文并入同一段），书中夹注（小字）保留在原位。《岁暮赋》末的出处句据影印页补全为“……俞平伯致叶圣陶函（十三）”。
- **页缺**：PDF 第 12、302 页为空白页；第 141 页见上。
- **错字更正（仅把握较大者）**：韦柰序里“还示认我们恐怕不是”改“承认”；《欢愁底歌》题下“三十一日一呈长环”改“，呈长环”；《迷途的鸟底赞颂》“第一般的圆”改“笛一般的圆”；《芝田留梦记》“roman-ce”接成“romance”；资料部分里“狂飙”的“飙”字被 OCR 漏识（“狂突进”“五四狂中的奋起”等），据影印页补回。
- **版面**：《诗底进化的还原论》里的树形表（好诗底效用）按坐标改作缩进的逐行文字；《湖楼小撷》《古槐梦遇》等的分节标题保留“一　春晨”“十五　游十殿小记之一”的样子；《俞平伯年表》每年一节。年表里一处年份标题与上一条目接在同一行（“……编辑、出版。一九八五年乙丑八十六岁”），已拆开。

## OCR 已知问题

- 半角/全角、引号、破折号有误识（如“——”被识成“—”），大多原样保留；“底”“的”依原书。
- 个别字形近之误未改（如《春水》诗里的“河冰绿如酒”引文，《〈冬夜〉序》里“无侍侣”“隄塘”等）。
- 夹排的外文词（Zero Theory、Comed Beef、Fare well、Posé 等）原样。
