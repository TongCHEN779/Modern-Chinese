# 速写三篇

- 底本：张天翼《速写三篇》，人民文学出版社“百年百种优秀中国文学图书”丛书，2000 年 7 月第 1 版。文字由 PDF 扫描件经 OCR 识别整理而成，尚未逐字校对。
- 内容：《谭九先生的工作》《华威先生》《“新生”》三篇，及附录《包氏父子》，各占一页；篇末作者署的写作时间（廿六年十一月、二十七年二月、1934 年）保留。
- 整理时去掉：封面、版权页、作者简介页、丛书前言、评选委员会与编委名单、丛书书目、目录页、页眉页脚页码、书末扫描信息页。
- 已知问题：OCR 稿中破折号常被识别成“一”“—一”“一一”，未改；个别括号（如“《辞源)”）识别不全，原样保留；《“新生”》第 65–66 页间被分页断开的“飘然”已接上；《包氏父子》中 Pass、Pa 等英文原书如此。未发现整页缺失。
