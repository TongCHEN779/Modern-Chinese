# 毛泽东诗词选

## 底本
《毛泽东诗词选》，毛泽东 著，人民文学出版社，2000 年 7 月第 1 版（2001 年 10 月第 3 次印刷），“百年百种优秀中国文学图书”丛书之一。原为 1986 年出版的五十首诗词注释本，分正编、副编；每首后附发表出处与编者注释，卷末附作者论诗书信三封。

## 整理说明
- 一首（组）诗词一页，页标题取书中诗题加写作时间（OCR 缺年份处只写诗题）；三封书信各一页（附录）。`pages.json` 第三项为“正编”“副编”“附录”分组。
- 每页首节为诗词正文、作者自序/题记与“这首词最早发表在……”一行；之后依书中次序分节：注释、作者原注、作者原注注释、附（和诗原作）及其注释。
- 去掉：封面、版权页、丛书前言与评委名单、丛书书目（p0010–p0017）、出版说明（编辑部 1986 年）、目录、页眉页脚与页码、末页 Anna's Archive 元数据。
- 注释保留为每条一段，条首的 `[`、`〔`、`「`、`(` 等 OCR 残留符号已去掉。

## 重建说明与已知问题
- 原书竖排，原 OCR 把各栏读乱，诗词与注释、相邻诗之间的文字曾互相拼错，标点也大量丢失；现已对着页图逐页重建 50 页：诗词正文、发表说明、各条注释、三封书信均恢复原书标点，诗词每首（组）连为一段；原书的『』改为“”。
- 此前所谓“缺页”（《念奴娇·昆仑》《沁园春·雪》的诗正文等）并非缺页，只是被 OCR 读乱后丢失，现已据页图补回。
- 条首 `〔 〕` 括号去掉，词条与注文连写；注文内部的 `〔 〕` 按书中所印保留。《七律二首·送瘟神》中书中印有的“其二”单列一段。
- 个别字形据页图判定：“斥鷃/斥鴳”“昆鸡（鶤鸡）”“庄跷”“罴”“庳”“骈阗”等，可能与书中实际用字略有出入。
- 少数标点按图推断，可能与原书略有出入（如《沁园春·雪》作者自注“大雕；只能如是”的分号、《柳直荀》条的逗号/顿号）。
- 标题“渔家傲 反第一次大围剿”“反第二次大围剿”中，书中的“围剿”带引号，页标题未保留。
