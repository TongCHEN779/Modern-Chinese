# 凤凰台（《大唐李白》第二卷）

- 底本：张大春《大唐李白·凤凰台》（第二卷），广西师范大学出版社（理想国），2014 年 7 月第 1 版。文字由书籍扫描件经 OCR 识别、整理而成，**尚未逐字校对**。
- 整理：序《再说李白》一页；书前引诗（李白《登金陵凤凰台》）一页，页标题取诗题；正文三十四章各占一页，页标题为“章号 章名”（章名照目录与正文）；附录一页（黄念欣《李白的学习年代与漫游年代》，按其三个小标题分节，文末作者简介保留）。章内无小标题，不分节。
- 去掉：封面、版权页（CIP）、目录页、页眉页脚、前言页码罗马数字、“（第二卷完）”标记、扫描文件的元数据附页。
- 诗句：书里的诗按联拆为一行一段（五言、七言及少数乐府、词；按“。！？；”断行）；对话或叙述里夹带的引诗不拆。个别 OCR 把诗行折断的，已按文意接上。
- OCR 已知问题：
  - 第六章章名按正文标题作“此行不为鲈鱼鲙”，而引诗里作“此行不为鲈鱼”（OCR 漏“鲙”字，原样保留）。
  - 第四章标题与上一页末行粘在一起，已拆出。
  - 第十七章“天火之余”后的引号被 OCR 拆到下一行，已接上；第八章“老君，汝是”、第二十三章“闲春一”两处引文被 OCR 截断，原样保留。
  - 个别形近字误识、标点错位未改；第二十八章酒令诗“病身绝谷粒，应笑臞者肥”后漏句号，原样保留。
  - 附录文末“原文注释经作者同意而删节”，书中本无注释。
