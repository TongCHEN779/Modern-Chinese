# 中国历代文论选（第3册）

- 底本：《中国历代文论选》第三册（高等学校文科教材），郭绍虞主编、王文生副主编，上海古籍出版社，2001 年 10 月新 1 版（2003 年 5 月第 2 次印刷）。本册为明、清部分，自宋濂《文原》至阮元《文言说》及其附录（刘师培《广阮氏文言说》）。文字由书籍扫描件（PDF）经 OCR 识别、整理而成（简体），**尚未逐字校对**。
- 结构：页 = 书中目录的每一条一级篇目（共 66 页，页标题“作者·篇题”，页的第三项分组为“明”“清”）；节 = 一篇文章（共 345 节）。每页第一节是该一级篇目本身，其后各节是书中该篇“附录”下列的相关文章（题目、作者照目录，共 317 篇，含一级篇目）。
  - 每节第一段 `原：` 为书中篇题下的作者行（如“〔明〕宋濂”）；其后为正文；正文之后一行为出处（如“严荣校刻本《宋文宪公全集》卷二”）。
  - 书中篇后的【说明】各段写作 `题解：`，放在一级篇目那一节的节首（附录各篇书中没有说明与注释）。
  - 书中篇后的【注释】逐条写作 `注原：词语：解释`，按正文里的上标位置放回所注段后；词语取原注破折号前的词（如“庖牺仰观俯察二句”取“庖牺仰观俯察”），原注若不是以“词语——”起头，或词语与正文因 OCR 错字对不上，则取上标前的几个字作词语，解释保留原注全文。用 `注原：` 而非 `注：`，是为了让 build 不按句号后的“某某：”拆开原注。原注里的“见本书第一册某篇注[3]”之类互见标记原样保留。
  - 一级篇目内的小标题（如《曲律》的“论家数第十四”、《闲情偶寄》的“结构第一”“立主脑”、《原诗》的“内篇上”“内篇下”）另起一节；附录篇目内的小标题（如袁枚《续诗品》的“崇意”“精思”）保留为一段。
  - 同一页内题目重复的节，后者加括注区分（作者名，如“聊斋志异序（高珩）”“诗归序（谭元春）”，或“（附录）”）。
  - 五、七言（及《续诗品》四言）诗的整段，按分句规律识别后写作 `诗：`，四句一段，句间用 `/`；《拙叟行》按此手工指定。散文中夹引的诗句、曲词仍作 `原：`。
- 整理时去掉：封面、书名页、版权页（CIP 数据）、目录页（OCR 的目录乱序，仅据其核对篇目与页码、作者）、页码、页眉页脚与页边杂点；正文中的注释上标（[1][2]…）已去掉，改由注释的位置表示。书中无序、前言、编后记，故无此类页。
- 方法：OCR 的 full.txt 有大量丢行、并页（约 110 页的字数明显少于逐页识别），故改以逐页 json（带坐标）为准：t2s 简化（谿→溪、幷→并、劄→札、舖→铺 与 full.txt 一致），按行首缩进与行尾长短分段，按“【注释】”“【说明】”标题切分，篇目起点按目录页码加作者行（“〔明〕某某”）定位。
- 对照目录与正文后更正的篇名、作者名（OCR 错识）：《童心说》（目录识作“实心说”）、《诗薮》《诗筏》、《曾助教文集序》、《续诗品三十二首》、《说诗晬语》、《蕙风词话》《海绡说词》、《论诗示黄镠》、《答袁简斋前辈书》、《芝廛集序》、《仿佛楼诗稿序》、《科诨第五》；作者高棅、朱彝尊、黄宗羲、王闿运、刘大櫆、孔尚任等。目录缺漏：《格调论中》（篇名缺，据正文补）、《与孙渊如观察论考据著作书》（作者缺，据正文为焦循）；赵翼《论诗》、曹雪芹《红楼梦第一回》两篇正文里篇名行 OCR 漏识，用目录篇名。
- 已知问题：
  - OCR 的单字错识未逐一校改，常见的有：已/己、于/子/于、八/入（如“入卦”“入柱之列”实为“八卦”“八柱之列”）、郎/即、井/并、“祇”“尙”等异体；个别生僻字与外文拼写错误；出处行里个别字（如“魏叔子”识作“魏叔于”、“卷八”识作“卷入”）。
  - 注释上标有一部分 OCR 丢失或误识；以上标顺序、序号和词语对照放回所属段。仍有 27 条（约 1.9%）的注释词语在所属段原文里找不到，多半是 OCR 错字，或原注挂在篇题上的（如《怀麓堂诗话》《南词叙录》篇题上标的注，已放在作者行上，词语取作者名）。少数注释的词语是由上标位置推出的，可能与原注词略有出入。
  - 个别上标被误识成正文里的字符（如“[」”）、个别标点未清除；“〔二郎神〕”等曲牌的方括号已统一为“〔〕”。
  - 诗与曲词的分行、四句一段是按 OCR 行内标点切分的，可能与原书分行略有出入；个别散文段落若恰为整齐的短句，也可能被误作诗（已抽查）。
  - 分段依据行首缩进与行尾长短，页首、页尾处偶有断开或并合不准。
  - 没有发现缺页；full.txt 缺的页已由 json 补全。
