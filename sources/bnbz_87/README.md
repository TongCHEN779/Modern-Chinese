# 汪曾祺短篇小说选

- 底本：汪曾祺著《汪曾祺短篇小说选》，中国青年出版社“百年百种优秀中国文学图书”丛书，2000 年 7 月版（据北京出版社 1982 年版排印）。文字由 PDF 扫描件经 OCR 识别、整理，未逐字校对。
- 收录：自序及《复仇》《老鲁》《落魄》《鸡鸭名家》《羊舍一夕》《看水》《王全》《骑兵列传》《塞下人物记》《黄油烙饼》《异秉》《受戒》《寂寞和温暖》《岁寒三友》《大淖记事》《七里茶坊》，每篇一页。《羊舍一夕》《塞下人物记》《大淖记事》按书中的数字小标题分节。
- 去掉：封面、版权页、作者简介页、丛书前言、评委名单、丛书书目、编委名单、目录页、每页底部的作者脚注（页中的脚注标号一并删去）、书末的电子书信息页。
- 已知问题：
  - 目录页 OCR 残缺，章名依正文标题。
  - 《大淖记事》第一节的“一”OCR 丢失，按“二”推定节号；第七节的节号“七”未识别到，其内容（“巧云一家有了三张嘴”前后）仍并在“六”节末，边界未能确定。
  - 《老鲁》第 29、36 页和《异秉》第 177 页在整理稿中没有独立页，文字已并入前后页段落，据逐页识别结果核对，未发现缺失。
  - 《黄油烙饼》《异秉》《受戒》《羊舍一夕》等篇个别页 OCR 原是按版面折行的，段落依坐标缩进重新合并，个别段落边界可能有误。
  - 少数噪点（孤立的 F、n 等）已删；其余形近字、漏字、标点（如“一九八年五月二十日重写”应是“一九八一年”之类）原样保留。
