# 百合花

- 底本：茹志鹃著《百合花》，人民文学出版社 2000 年 7 月版（“百年百种优秀中国文学图书”丛书之一；原为 1978 年人民文学出版社版）。文字由扫描件经 OCR 识别、整理而成，未逐字校对。
- 收录：十八篇短篇小说（每篇一页，按书中顺序）及作者《后记》（1978 年）。篇内用“二、三……”标出的分节各为一节，各篇首节用篇名。篇末的写作日期原样保留。
- 去掉：封面、版权页、作者简介、丛书前言、评选委员会/编委会名单、丛书书目、目录页、页末脚注（《黎明前的故事》“黄牛”注、《静静的产院》“害喜”注、《回头卒》“妈妈”注、《百合花》“大军北撤”注、《后记》“小吕宋”注）及正文中对应的注码“①”、末页数字化水印说明。
- 目录页 OCR 不全，漏掉《鱼圩边》一篇（正文有标题、有日期，位于《妯娌》与《黎明前的故事》之间，后记所称“十八个短篇”也与之相符），页标题据正文。《如愿》《里程》《阿舒》《后记》的标题在 OCR 中被竖排拆开或缺字（如“如”“舒/阿”），按目录与书名补正。
- 已知问题：个别页（《高高的白杨树》约第 98—100 页、《春暖时节》约第 138—140 页）原为逐行断行排版，已按版面缩进接回段落；个别段落末标点可能漏识（如《关大妈》第三节“心里还有些发跳”、《回头卒》“色泽鲜艳”后、《静静的产院》“荷妹提问了”后），原样保留。未发现整页缺失。
