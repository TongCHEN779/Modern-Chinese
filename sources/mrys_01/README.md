# 一代大帝：秦始皇

- 底本：吴淑君著《一代大帝秦始皇》（“中国名人轶事丛书”之一，吴洪激主编），武汉大学出版社、台湾汉欣文化事业有限公司联合出版，1994 年 4 月第 1 版（ISBN 7-307-01628-1/K·152）。文字由扫描件（PDF）经 OCR 识别、整理而成，**尚未逐字校对**。书名在书名页上作“一代大帝／秦始皇”，版权页作“一代大帝秦始皇”，此处据封面分行写作“一代大帝：秦始皇”。
- 整理：共二十页——丛书出版缘由、主编絮语（吴洪激序）、十八章正文各占一页。每章书中有两段式标题（如“不韦弄巧　赵姬产下秦始皇”），页标题照录，中间以空格隔开；章内书中无小标题，故每页只有一节，节名同页标题。末章“惩恶篇”无副题。
- 去掉的内容：封面、书名页、版权页（CIP、定价等）、目录页、页眉页脚与页码、书末丛书广告页（及 Anna's Archive 水印页）、主编絮语文末署名“吴洪激”、每页页眉的书名“一代大帝秦始皇”和章名、插图说明性的碎片文字（“春秋过客”“王孙怅恨”“雕制兵马俑”）。主编絮语文末的写作日期“一九九三年九月十二日于湖北黄州”保留。
- 段落按 OCR 行重建，跨页被页眉断开的段落已接合；《易水歌》、秦王与樱樱的誓词、梦中“红龙落凡”短文等韵语以“诗：”分行居中。
- OCR 已知问题：页眉常夹在行中（已剔除）；个别页码数字或字母残留碎片已删，可能仍有遗漏；“曰/日”“己/已”等形近字只改了把握大的（“上书曰”“责之曰”两处）；原书中少量对话省略号行（OCR 作“...。”“…。”）按“……。”补全引号，另有一个空的引号行“”（第三章“欣慕长生”，疑为漏识的省略号对话）删去；原书用字（如“成矫/成蚧”“赵高干谋/千谋”等）保持不变，其中“成矫”“成蚧”混用来自 OCR，未统一；人名、史实以书为准，书中小说笔法与正史不符之处不改。
