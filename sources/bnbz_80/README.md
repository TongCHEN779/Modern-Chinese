# 重放的鲜花

- 底本：《重放的鲜花》，王蒙等著，解放军文艺出版社 2000 年 7 月版（“百年百种优秀中国文学图书”丛书；原编本为上海文艺出版社 1979 年版）。文字由书籍扫描件（PDF）经 OCR 识别、整理而成，尚未逐字校对。
- 收录：全书二十篇作品，每篇一页（页标题即篇名），页内以篇中的“一、二、三……”编号为小节；《草木篇》以各则小标题（白杨、藤、仙人掌、梅、毒菌）为小节。各篇作者记在小节的 author 字段，篇末的原刊出处（如“《人民文学》1956年4月号”）保留为末段。
- 去掉的内容：封面、版权页、丛书前言与评委名单、丛书书目、目录页、编者简介页、页眉页脚与页码、脚注（如“耿简即柳溪”“何又化即秦兆阳”及《太阳的家乡》的三条注）、文末“Anna's Archive”水印页；正文中因换页被页码切断的段落已接上。篇名下的作者名不入正文。

## 已知问题
- 目录里《爬在旗杆上的人》一篇 OCR 的标题与作者分行错位，按正文页首核对；《入党》篇名 OCR 为“人党”、《美丽》篇名只剩“丽”，均据目录校改。
- 《在桥梁工地上》第二节的序号“二”被 OCR 成孤立的“7”（第 4 页），据前后序号补为“二”。《西苑草》第三节序号被 OCR 成“兰”，据序号次序补为“三”。
- 《本报内部消息》《组织部新来的青年人》的前两节（一、二）序号全部丢失，合并为以篇名为节名的首节；其后各节序号保留。《本报内部消息（续篇）》中间有一个孤立的“1”（第 104 页），按杂点删去。
- 《红豆》不见节序号，不分节。
- 原稿第 343、344 页（书页 323–324）与第 371、372 页（书页 351–352）在 OCR 稿里被合并到前一页，已按原顺序处理，未发现缺文。
- 少量段末缺句号、个别引号残缺（如“.”应为省略号，已将孤立的“.”＋引号改为“……”）；其余 OCR 错字（形近字，如“儿朵”应为“几朵”）原样保留。《太阳的家乡》的日记日期单独成段。
