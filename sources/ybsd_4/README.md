# 俄罗斯白银时代文学史（第4卷，1890年代—1920年代初）

- 底本：俄罗斯科学院高尔基世界文学研究所集体编写，李福清、高莽、顾蕴璞、臧传真翻译顾问，谷羽、王亚民等译《俄罗斯白银时代文学史（1890年代—1920年代初）》第4卷（全套共4册），敦煌文艺出版社，2006年9月，ISBN 7-80587-830-7。文字由扫描 PDF 经 OCR 识别、整理，未逐字校对。
- 收录范围：第五编的第二十九章至第三十七章、结束语、译后记，各占一页。第二十九章页标题据目录作“象征主义后文学（综述）”。各章译者与作者署名行（如“波格莫洛夫著　王彦秋译”）未收入正文。
- 章末的“注释”保留为所在页最后一节，每条一段；每页底部的译者注（以“*”标记者）去掉。正文中的注码（如“……”42）原样保留在行文里。结束语后的“注释”也保留为该页最后一节。
- 未收：封面、版权页、目录、各章前的分隔页、第五编扉页、汉俄对照人名索引（原书第4卷第298—375页）、汉英对照人名索引（第375—381页）（索引中的俄文、英文几乎全部识别失败，且篇幅长，不收）、书末的电子书信息页。
- 本卷无序言、前言、导论（在第1卷）；各章内无小标题，故每页只有一节正文加一节“注释”。
- 字符与版面处理：版面按 OCR 坐标重建，段落按缩进与行宽合并，跨页断行已接上；诗行逐行一段；章首大字（首字下沉）已并回首行；章内偶有的“* * *”分隔号保留为单独一段。半角括号、逗号、冒号、问号等在汉字旁改全角。
- OCR 已知问题：
  - 第三十二章标题 OCR 作“古米摩夫”，据目录改回“古米廖夫”。
  - 注释中的俄文、英文书目几乎全部丢失，有些条目只剩序号（集中在第三十四章注释第82—125条一带，PDF 第207—209页）；注释个别序号缺失（第三十一章缺第55、78条，第三十四章缺第96、104条），按识别所得原样排列。注释内个别两三条被识别成一行的，已按序号拆开。
  - 第三十四章 PDF 第167页、199—200页等处的俄文引文被识别成乱码，乱码行已删，其前后文可能因而缺少俄文原词；正文中夹的俄文、拉丁字母词也多有漏识（如括号内只剩空括号或孤立标点）。
  - 页边竖排的页眉（章名、编名）、页码、孤立的上标注码数字已去掉，因此少数注码可能随之丢失；个别“”42”“”84”之类的注码尾巴单独成行的，已并回上一段末，位置未必与原书上标位置一致。
  - 外国人名、译名用字（如“费奥多罗夫”“列米卓夫”）原样保留，OCR 形近字错识（如个别“己/已”）未逐一校改。
