## 整理说明
- 共 90 页：序 1 页；作品部分“诗歌”63 页（含两首散文诗、佚诗《致埃斯库罗斯》）、“散文”24 页；“资料部分”4 页（沈从文、苏雪林两篇《论朱湘的诗》，孙玉石《朱湘传略及其作品》《朱湘年表》）。次序、篇名依书中目次。
- 诗每篇一页，诗行逐行一段；原书的节与节之间空行不另表示。《王娇》按原书小节“一”至“七”分节；《图兜儿》《十四行　英体》《十四行　意体》各页按原书小序号分节（如“二”“七”“一七　蛙声”），序号后的篇题照目次。
- 书中四处“（以上……首选自《……》）”的归集说明（《夏天》《草莽集》《石门集》《永言集》），照录为所在末篇的末行；其中《石门集》一处原缺右括号，已补。
- 散文中间夹的诗行（如《北海纪游》的《棹歌》、各文引诗）逐行为段；文中被诗行截断的句子（如“这个雨并非/润物细无声/的那种毛毛雨”）接回同一段。每页脚注（《散文诗一》的“①”、序的两条脚注、雪林文的“①”）保留在所属页的末尾；《致埃斯库罗斯》的原注（＊、①至⑧）与附录英文原诗各自成节。
- 英文原诗中偶有 OCR 错字，已对照原页改正（如 Hercules、wields、grand Paean）。
- 去掉了：封面、书名页、版权页、照片和手迹插页（PDF 第 1—29 页）、目次（第 42—46 页）、“作品部分”“资料部分”隔页及空白页、页眉页脚页码、末页水印。

## OCR 已知问题
- 作者自撰各文中的短横“一”（小节号 一、二、三）被 OCR 漏识的，按版面补回：《王娇》小节“一”、《图兜儿》“一”“二”、《十四行　英体》“二”、《朱湘传略及其作品》小节“一”；《散文诗一》《散文诗二》页题的“一”“二”照目次补。
- 破折号“——”常被识成“—”“一一”“—一”，已按上下文改回“——”，个别处存疑。
- 目次与正文有出入处依正文：图兜儿第十四首目次作“十四”、正文作“一四”，从正文；《图兜儿》第七首篇题“旧信”据目次，正文 OCR 作“七月信”。
- 已更正的系统性错识：“草葬集/草养集/草举集”→《草莽集》，“未湘”→朱湘，“自已”→自己，“己经”→已经，“风凰”→凤凰，《月游》三处“势仪/蛰仪/费仪”→贽仪，“丫髮/丫鬓”→丫鬟，“悖饽”→饽饽，《昭君出塞》“低極”→低桠，《王娇》“妙眼肿中含者”→“妙眼眶中含着”，序中“巴把曲”→巴俚曲，《散文诗二》“让咒”→诅咒，《日与月的神话》文末日期“月”前补“三”（据原页）。
- 《南归》副题“答赠恩沱了一三友”照 OCR 录出，存疑；《哭城》副题“内战事实”已核对。
- 沈从文、苏雪林、孙玉石文中引用的朱湘诗句沿用该文所引字句，与本书诗歌正文偶有小异，未据诗歌正文互校；这些文章及散文部分仍有零星形近字错识未能逐一核对（如“眼晴”类已改，其余照录）。
- 《朱湘年表》个别条目（1927 年“修西洋文学、古英文、拉丁语和高级班法语、”）行末疑有脱字，照录。
- 缺页：无。OCR 识出的目次缺行较多，篇目与页码已据页图补定。
- 原书注释已按站内格式（注：词语：解释）挂在所注段落后，注码已去掉；个别注释的词语位置为推定。
