# 元代历史演义全书

- 本书由大众文艺出版社“中国全史”丛书中的1册合并而成，共 60 页；各册整理记录如下。

## 第1册（qsyy_yuan）

- 底本：蔡东藩著《元代历史演义全书》（“中国全史”丛书），大众文艺出版社，年份不详（版权页未识别出年份）。单册成书，全书六十回。文字由书籍扫描件（PDF）经 OCR 识别、整理而成。
- 整理：每回一页，页标题为“第N回 回目上联 回目下联”，回目以各回正文开头为准（目录页仅作核对）；页内一节，节名同页标题。回末套语、回末的作者评语（原书排成较窄的小字段落，列在各回末尾）原样保留；回中引用的诏奏、条款等按版面另起段。
- 去掉：封面、扉页、目录页、“中国全史”页眉与页码、书末版权页及责编、装帧信息。原书无序跋附录。
- 回数：第一回至第六十回完整，不重不漏。
- OCR 已知问题：目录页识别乱序，未用；第五十六回回目“授术”在正文标题处误识为“授木”，据目录改回；第三十一回“威□朝野”处原书该字外有方框，OCR 误识为数字，以“□”代之；其余识别残留错字、形近字未逐一校改。
