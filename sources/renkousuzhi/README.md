- 整理：按书的目录分页——代序言《祝贺和期待》（邬沧萍，1985 年 7 月）一页，绪论一页，其后二十三章各一页（共 25 页）；全书分五篇，篇名记在 pages.json 第三项，各篇标题页不单独成页。页内小标题（“一、二、三、……”）各为一节；绪论内的（一）至（四）各为一节，（一）并入首节“绪论”。书中没有后记、附录。

## OCR 已知问题
- 部分页的识别稿把整页或多个自然段连成一行，段落分界丢失，因此个别段落偏长（最长约 1300 字），按原行保留，未据内容另行拆分。
- 脚注被识别成夹在正文中的片段或错位的行，已按“①…页”等特征去掉；个别漏网或误删之处可能仍有。正文里偶有孤立的数字（脚注序号被识成数字，如“他2是”）未处理。
- 页码标记（“• 123 •”等）已删去；跨页被断开的段落按句末标点判断是否接上，句号恰在页末而下页接续同一段的情形无法识别，会被拆成两段。
- 章内三级小标题（如“人口数量对人口素质的限制 在……”）在书中与正文同行排印，仍留在段内，未另起一节。
- 其余未校对，仍可能有个别形近字错误（己/已/巳、未/末等），不确定处一律保留识别原样。
