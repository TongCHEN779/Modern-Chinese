# 烙印

底本：臧克家《烙印》，“百年百种优秀中国文学图书”之一，人民文学出版社，2000 年 7 月版（据 1933 年上海现代书局初版本重版，附录收《罪恶的黑手》诗集）。

## 整理说明

- 分三页：闻一多《序》；《烙印》诗集（22 首，一首一节）；附录《罪恶的黑手》（作者序及 17 首，一首一节）。诗行逐行一段，诗末写作日期原样保留为一行。
- 去掉：封面、版权页、作者小传、丛书前言、评委名单、丛书书目、目录页、页眉页脚页码、版本脚注（《万国公墓》页底关于写作日期有误的编者注）、DuXiu/Anna's Archive 水印页。
- 原稿标点（半角括号等）保持 OCR 原样。

## 已知 OCR 问题

- 附录原第 54 页（首句“我是平凡……”）一诗标题 OCR 未识别出，目录中也未核实，节名记作“（无题）”，需对照原书。
- 《吊》标题可能不全（OCR 仅得一字）；《亮的影子》标题疑缺首字，均保持 OCR 所得。
- 《罪恶的黑手》诗中原有的分节序号（“一”“二”“三”）OCR 仅余“三”，已删去，各节之间不再分隔。
- OCR 把部分相邻诗行合成一行，整理时按句读和押韵处据文义拆回，个别拆分处可能与原书分行不同；诗节间空行已丢失。
- 疑似错字保留未改：“铁力的疲倦”（《难民》）、“打预”（《亮的影子》）、“古琅玡”等。
- 原书第 57、59 页（空白页）无内容，无漏页。
