## OCR 与整理的已知问题

- 历史年表是自动对齐，条目边界靠“行是否写满”“是否与年代栏同行”判断：个别折行被拆成两条（如“奥格斯堡和约…天主教徒／在德国的暴力冲突”），个别同年并列事件被并入一条（如 1513、1572、1588 等年），个别年代被年代栏误配；书中已有的排印错误（如“1438—1845”）未改。
- 页边原书页码的清理依“页码递增序列”判定：自动去掉嵌在行首/行尾的页码，OCR 错误的页码（如 208→202、819→319）按序列修正后去掉；个别无法确认的页码残留或误并的可能仍有。导论第 3 页一处页码粘连成“于113世纪”，已按史实改作“于12世纪大教堂的学校中”（据上下文推断，请核对）。
- 引文缩进（块引文）靠缩进与行宽判断，个别块引文被并入上下段或拆成两段；右对齐的出处（如“(IV, 247f.; I, 365f.)”“(E III 381)”）并入前一段末尾。
