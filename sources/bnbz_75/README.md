# 将军族

- 底本：陈映真著《将军族》，“百年百种优秀中国文学图书”丛书，解放军文艺出版社 2000 年 7 月第 1 版。文字由书籍扫描件（PDF）经 OCR 识别、整理而成，未逐字校对。
- 收入：作者《序言》（2000 年 3 月 15 日）一页；十一篇小说各一页（《我的弟弟康雄》《家》《乡村的教师》《那么衰老的眼泪》《将军族》《一绿色之候鸟》《唐倩的喜剧》《第一件差事》《夜行货车》《山路》《赵南栋》），页内以书中“二、三、四……”等编号小标题分节；末页《陈映真写作年表》（书末附录）。各篇末的“原载……”出处说明保留在该页末。《夜行货车》《上班族的一日》的副题“华盛顿大楼之一/之二”保留为页首一段。
- 去掉：封面、书脊碎片、版权页、作者小传（封面页）、丛书前言、评选委员会名单、丛书书目、目录页、页眉页脚与页码、PDF 末尾附加的说明文字。
- 整理：目录里《家》（第 8 页）和《山路》（第 191 页）的标题 OCR 丢失，标题依正文首行确定。《山路》中蔡千惠的信、《第一件差事》中引用的文字、《上班族的一日》中的公文、《赵南栋》各节开头的病历记录，原书按窄行排版，已合并成自然段（段界按行末标点与行长推定，个别处可能与原书分段略有出入）。
- OCR 已知问题：版面残留的零星字符（如“寄”“A”“ri”“2”）已删。正文中少数形近字、标点（如“－”与“—”、引号配对）可能仍有误。《赵南栋》里的日文歌词（“人民の旗……”）保留为逐行段落，OCR 有个别假名错字（如“战士の尸フフむ”）。《唐倩的喜剧》等篇里个别英文夹杂处（如“I'llmiss you”）空格未补。未发现整页缺失。
