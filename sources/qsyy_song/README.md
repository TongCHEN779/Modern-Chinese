# 宋代历史演义全书

- 本书由大众文艺出版社“中国全史”丛书中的2册合并而成，共 100 页；各册整理记录如下。

## 第1册（tmp_qsyy_song_1）

- 底本：（民国）蔡东藩《宋代历史演义全书》，大众文艺出版社“中国全史”丛书，年份不详（版权页未识别到）。本册为该书上册（第一册），第一回至第五十回，回数连续，无缺回。文字由 PDF 扫描件经 OCR 识别、整理而成。
- 整理：每回一页，页标题为“第N回 上联 下联”，取自每回开头的回目（目录页识别有误，仅用于核对）；页内不再分节。书中未见序、例言，故无前言页。
- 去掉：封面、书名页、目录页、丛书页眉“中国全史”“宋代历史演义全书”、页码、书末版权页与封底。
- 保留：每回末的评语（回末总评，版面上比正文窄且缩进）作为该回最后一段；诗词每句或每联一行；上奏、诏书等引文按版面另起段；第四十九回“党人碑”名录按版面一行一段，同一行内的各名以全角空格隔开（第一部分几行 OCR 已把人名连成一串，未拆）。
- OCR 已知问题：系统性错字有“阐/闉”“觔”“干祐/乾祐”等，除把握极大者外未更正；个别标点误作半角句点已按文意改为全角；夹在正文里的孤立脚注数字已去掉。第五十回回目“朱勔”原 OCR 漏“勔”字，据目录补回。第四十九回名录中“谢文瓘鱼”一行疑有识别残字，原样保留。
- 目录对照：目录页将第一回“河洛”识作“河神”、第十三回“归诚”识作“归试”、第十七回“捐躯”识作“损躯”、第二十三回“磋商”识作“蹉商”，页标题均以正文为准。

## 第2册（tmp_qsyy_song_2）

- 底本：（民国）蔡东藩著《宋代历史演义全书》，大众文艺出版社“中国全史”丛书，年份不详（扫描件未见版权页年份）。本册为该书下册，第五十一回至第一百回，共五十回；与上册合为全书一百回。文字由书籍扫描件（PDF）经 OCR 识别、整理而成。
- 整理：每回一页，页标题为正文里每回开头的回目（“第N回 上联 下联”）。各回末蔡东藩的总评（“本回叙……”“观……”之类）属原书正文，随该回保留。
- 去掉：封面、丛书页眉（“中国全史”“宋代历史演义全书”）、页码、版权页与责任编辑等版权信息、空白页。全书无独立序跋，本册无附录。
- 段落按行坐标重建：缩进处另起段，其余接上，跨页段落已接上；诗词、对联、书信引文、名单按版面行排列。
- 回数五十一至一百连续，无缺回、无重复。
- OCR 校改：半角 `( ) . ?` 改为全角；明显的“.”误作句号改为“。”；“絜”作“絷”（拘絷、被絷）、回目“李瓊”作“李璮”、第九十七回“百官亦今”作“亦令”，据上下文更正。其余原样。
- 已知问题：第五十五回的梁山一百零八人名单每人一行，其中数处两人并作一行（版面如此）；第八十四回伪学党籍名单（赵汝愚等）按版面行合并为数段，人名间无分隔；第五十一回奏列蔡京罪状的标目三行并为一段；第九十三回、第八十五回各有一段以逗号结尾，疑 OCR 将句号识为逗号，未改。个别生僻字（如“㬎”）保留。
