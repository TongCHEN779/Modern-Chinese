# 九叶集（bnbz_86）

## 底本
《九叶集》，辛笛、陈敬容、杜运燮、杭约赫、郑敏、唐祈、唐湜、袁可嘉、穆旦 著，作家出版社，2000 年 7 月第 1 版（“百年百种优秀中国文学图书”丛书）。原本为人民文学出版社 1981 年版。

## 整理说明
- 保留：编者题记（悼念穆旦，书中无标题，页标题作“（无题）”）、袁可嘉《序》、九位诗人各自的小传（置于各人一页的首节）及其诗作。每位诗人一页，每首诗一节，诗行逐行成段；“选自……”出处与写作日期按书保留为诗末行。
- 去掉：封面、版权页、“出版说明”式内容简介、丛书前言/编委/书目页、目录、页眉页脚与页码、页脚脚注（含正文中的 ①②③ 脚注标记）、OCR 乱码碎片（如孤立字母、“o:,”）。
- 诗的行序、断行取自逐行识别的 json；序与小传取自 full.txt（跨页段落已接合）。

## 已知问题
- 竖排诗题 OCR 常丢字或错序，已据目录或正文核对：划分、神话、六行（“赠梅”为题下小字，保留为首行）、启示、夕语（OCR 为“2”）、进城（目录“进城”）、抗辩、拓荒、噩梦等。“誓”“姿”“航”“空”等单字题按识别结果保留，可能不全。
- 无法核实标题的诗用“（无题）”：辛笛第三首（首句“识字以来”，原样保留为首行）、唐祈第五首（题下小字“——从闻一多墓旁哀悼归来”）、穆旦第九首（首句“蓝天之漫游者，海的恋人，”）。袁可嘉“母亲”一题，识别结果为“母 士 亲”，取“母亲”。
- 唐祈《游牧人》末行为“选自《文艺复兴》、1946”，原样保留。
- 郑敏第一首末附“（本辑诗作前十九首选自《诗集1942—1947》）”说明，保留在《金黄的稻束》之末。
- 序中引诗处（穆旦、杜运燮等）因 OCR 合并，诗行与正文混排在同一段，未能拆开。
- 目录页缺失部分条目，诗数据正文核对：九位诗人分别为 21、20、12、14、20、13、15、12、17 首（诗八首计 8 首），与目录所标数相符。
- 杭约赫《复活的土地》仅为选段，其后的编者说明（长诗分章及出版信息）保留于该节末。
