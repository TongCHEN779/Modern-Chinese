# 中国现代作家选集·萧红

- 底本：《中国现代作家选集　萧红》，王述、盛绮云编，人民文学出版社、三联书店香港分店联合编辑出版，1984 年 2 月北京第 1 版第 1 次印刷（书号 10019·3547）。文字由书籍扫描件（PDF，萧红.pdf）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：按书的目录分页，共 19 页：胡风《悼萧红（代序）》，萧红自述《永久的憧憬和追求》，小说散文十五篇（《蹲在洋车上》至《小城三月》），书末王述《萧红和她的文学创作》和《萧红著作编目》。书中不分辑，无分组。
- 去掉了：封面、版权页、目录页、页眉页脚页码、每页底部的脚注（《牛车上》“染缸房”一条、《小城三月》“格得毛宁”两条，正文中的脚注号一并去掉）。
- 小节号：《王阿嫂的死》（一、二、三）、《看风筝》（一、二）、《夜风》（一、二）、《小城三月》（一）的小节号在书中印作短横，OCR 漏识，按版面空行和次序补回；《夜风》标题 OCR 亦漏识，据目录补。《山下》《逃难》标题 OCR 只识出一两字，据目录补全。《桥》《旷野的呼喊》等篇中的空行分段不另设小节；《家族以外的人》中的“＊＊＊”分隔符保留为“＊　＊　＊”一段。
- 《萧红著作编目》：按书中年份分节，每条著作一段，出处说明另起一段（含“（上）（下）”等逐行条目）。《萧红和她的文学创作》中的诗句逐行一段，小节名即书中小标题。
- OCR 已知问题：引号内套引号处原书用单引号，识别结果为半角 '，未改；破折号“——”个别处只识出一横；半角 ( ) , ; : ? ! 紧邻汉字处已改全角；《编目》中个别书名号（如“短篇集桥”）漏识；“一九八○年”等年份里“〇/○”写法不统一。无缺页。
