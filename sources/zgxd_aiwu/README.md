- 底本：《中国现代作家选集·艾芜》，胡德培 编，人民文学出版社、三联书店香港分店联合编辑出版，1986 年 8 月北京第 1 版第 1 次印刷（书号 10019·3982）。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 结构：序一页；“作品部份”十二篇小说（《人生哲学的一课》至《红艳艳的罂粟花》）、《关于小说题材与鲁迅的通信》（沙汀、艾芜致鲁迅，附鲁迅回信）、《墨水瓶挂在颈子上写作的》；“资料部份”胡德培《艾芜及其创作》、周立波《读〈南行记〉》、黄绰卿《艾芜漂泊在缅甸》、《艾芜年表简编》（黄莉如、毛文）。每篇一页，页内小标题（《人生哲学的一课》的“一、二、三”，《我的旅伴》的十五节，《艾芜及其创作》的十节，年表的各年）各为一节。
