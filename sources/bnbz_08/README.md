# 沉沦

- 底本：郁达夫著《沉沦》，作家出版社 2000 年 7 月第 1 版（“百年百种优秀中国文学图书”丛书；据 1921 年上海泰东图书局初版）。文字由书籍扫描件经 OCR 识别、整理而成，未逐字校对。
- 整理：收自序、《沉沦》（一至八）、《南迁》（一至七，附《迷娘的歌》）、《银灰色的死》（上、中、下，含篇末英文附记）。去掉封面、版权页、作者简介、丛书前言、评委会/编委会名单、丛书书目、目录页、页眉页脚水印、页码；跨页断开的段落已接上；每篇小说各占一页。
- 《沉沦》一、二两节的序号在 OCR 中缺失，据书的结构补出；《南迁》各节标题后的德文副题原样保留。《迷娘的歌》（歌德，达夫译）和《银灰色的死》中的告示按书中断行，诗行逐行排列，告示的折行已并为段。
- OCR 问题：个别字形近误识未改（如“渭迟渥斯”“盍县罢哈”本为书中译名，原样保留）；“…”类省略号在个别处被识成乱点，仅《沉沦》六/七节之间的一处据上下文改为“……”，另一处“××”乱码已改；页尾粘连的页码已去除。未发现整页缺失。
