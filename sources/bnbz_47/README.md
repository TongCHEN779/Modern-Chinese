# 小城风波

- 底本：沙汀著《小城风波》，人民文学出版社 2000 年 7 月版（“百年百种优秀中国文学图书”丛书）。文字由书籍扫描件经 OCR 识别、整理而成，尚未逐字校对。
- 整理：每篇小说一页，共七篇。去掉了封面、版权页、作者小传、丛书前言与书目、评委名单、目录页、页眉页脚页码、书末电子书信息页；跨页断开的段落已接上。
- 标题：第一篇目录印作“防空在“堪察加”的一角”（原题中间的破折号 OCR 与目录均未见），按目录写；《公道》标题在 OCR 中被拆成“公”“道”两行，已合并。
- 已知问题：个别引号 OCR 为英文单引号（如《小城风波》里“……，'他说……”）、省略号点数不一，均保留原样；偶有形近字错误未逐一校改。未发现漏页；《在其香居茶馆里》里一块匾额文字“尽瘁桑梓”单独成段。
