# 红楼梦魇

- 底本：张爱玲《文学评论·红楼梦魇》，哈尔滨出版社 2003 年版（“张爱玲典藏全集”）。文字由书籍扫描件（PDF）经 OCR 识别、整理而成，**尚未逐字校对**。
- 整理：按书的目录分八页——自序、《红楼梦》未完、《红楼梦》插曲之一（高鹗、袭人与畹君）、初详、二详、三详、四详、五详《红楼梦》；各篇篇内无小标题，每篇一节。《插曲之一》及各“详”的副题并入页标题。去掉封面、版权页、目录页、页眉（“文学评论·红楼梦魇”“张爱玲典藏全集”）、页码与封底；脚注（“注①.……”）已改挂到所注段落后。
- 书中大量引用旧本、脂本《红楼梦》原文及外文词（如 Nightmare in the Red Chamber、Cabaret），一律照原样保留，未作改动。
- OCR 已知问题：
  - 识别稿个别页（三详、四详中版面较窄、逐行断开者，PDF 页 140、188–195、204–211）依字符坐标的缩进还原段落，个别段界可能有误；PDF 第 209 页等处个别行在整理稿中已被合并，段界无从细辨。
  - 页眉常与正文首行连在一起，已剥离；跨页断开的段落按标点接合，个别短句、标签行（如“全抄本”“戚本”“甲戌本”）单独成段。
  - 引文中的“X本”、脂批、版本简称及全书的括号、引号（如“《(红楼梦》”）多有错配，仅更正把握极大者。
  - 自序末的对联“赢得红楼梦魔名”据文意改作“魇名”。
- 原书注释已按站内格式（注：词语：解释）挂在所注段落后，注码已去掉；个别注释的词语位置为推定。
