# 南北朝历史演义全书

- 本书由大众文艺出版社“中国全史”丛书中的2册合并而成，共 100 页；各册整理记录如下。

## 第1册（tmp_qsyy_nanbeichao_1）

- 底本：蔡东藩《南北朝历史演义全书》（又名《南北史通俗演义》），收于《中国全史（第二辑）》，大众文艺出版社，2000 年 5 月第 1 版。本册为该书上册，含第一回至第五十回。文字由书籍扫描件（PDF）经 OCR 识别、整理而成。
- 分册：本册为全书第 1 册，起第一回“射蛇首兴王呈预兆 睹龙颜慧妇忌英雄”，止第五十回“废故主迎立广陵王 煽众兵声讨尔朱氏”；第五十一回起见下册。回数连续，不缺不重。
- 整理：每回一页，页标题为正文每回开头的回目（目录页仅作核对）。书中无序、例言、跋，故无其他页。去掉封面、版权页、目录、丛书页眉、书眉页码及出版社信息。段落按版面缩进重建，跨页段落已接上；回末“欲知后事”等套语及每回末的作者评语原样保留，评语单独成段；诗词每句一行。
- 回目更正三处（OCR 与目录页比对）：第二十五回“栋林”改作“栎林”；第三十四回“秃骛”改作“秃鹜”；第三十五回“六贵游诛”改作“六贵就诛”（三处识读不一，据文义定，推定）。
- 正文校改：第一回开篇长段中 OCR 重复了半行（“江南最弱，鼎峙了好几年，齐为周并，周得中原十分之八，”重出），已删去重复；第三回“循遗裕益智:，”据文义补作“益智粽”；第三十六回“徐世:”“世剽”统一作“世檦”（推定）；半角标点已改全角。
- 已知 OCR 问题：个别生僻字识成形近字或乱码（如“䃅”“㥄”），未逐一考订；第三十四回有一处孤立的“』”未改。

## 第2册（tmp_qsyy_nanbeichao_2）

- 底本：（民国）蔡东藩著《南北朝历史演义全书》下册，大众文艺出版社“中国全史”丛书；年份不详（扫描件中未见版权页年份）。本批为该书第二册（下），收第五十一回至第一百回，共 50 回。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成。
- 整理：每回一页，页标题为正文里每回开头的“第N回 上联 下联”；回数五十一至一百连续，不重不漏。自然段依版面缩进重建，跨页的段落已接上；每回末的“小子有诗”等韵语每句一行，回末蔡氏评语（版面缩进更深的一段）作为该回最后的若干段原样保留。
- 去掉：封面、扉页、“中国全史”丛书页眉与书名页眉、页码、书末空白页与版权说明页。本册无序跋。
- 已知问题：OCR 单字错识未作系统校改（如“锻尾声”当为“殿尾声”之类，保持原样）；第九十一回所列“十六院名称”按版面每院一行；第六十七回内（PDF 第 144 页）有一个孤立的“一”字符号，疑为版面标记，已删去。
