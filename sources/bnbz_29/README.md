# 边城

## 底本
沈从文《边城》，人民文学出版社“百年百种优秀中国文学图书”本，2000年7月第1版（2001年10月第3次印刷）。OCR 整理稿来自 PDF 扫描件。

## 整理说明
- 按作者原文分页：题记，及正文第一至二十二节（页标题为“一”至“二十二”），共23页。
- 去掉：封面、版权页、作者简介页、丛书前言、评选委员会、编委会名单、丛书书目、丛书封面碎片，以及书末“Anna's Archive”水印及文件信息。
- 跨页断开的段落已接上；题记末的“二十三年四月二十四日记”单独成段，正文末“二十三年四月十九日完成”保留。

## 已知 OCR 问题
- 原稿中“一”“二”两节的章号被 OCR 吞掉：“一”从“由四川过湖南去”起算，“二”从“茶峒山城只隔渡头一里路”起算，“二十二”从“过了四七”起算，均按书的结构补回页标题。
- 题记标题的“题”字被 OCR 丢失，页标题按“题记”补。
- “一”一节“牵船过对岸”与“去”之间有页码噪点“4”，已删；“七”一节“愀然”后有孤立噪点“市”，已删并接上上下文。
- 其余未逐字校对，可能仍有个别形近字错误；未发现漏页。
