## OCR 与整理的已知问题

- 原书页码（页内嵌入的数字）用“按页递增的数字链”判定删除，个别页码仍可能残留，也可能误删恰好落在链上的正文数字；第十二、十四章正文里的注号（如“。18那么”）为上标注号，与页码不易区分，保留原样。
- 正文中的注号“[27]”等的右括号常被 OCR 丢掉，已按“[数字”后接汉字/字母补回；“注释”节的条目编号按顺序规范为“[n]”，少数条目被拆并时编号可能不连。
- 历史年表由坐标对齐，跨栏合并的框（如 1841、1787 行）有串栏；事件的拆行靠括号和字符规则判定，少数长条目被误拆或并合；各页首的承前事件无年代，行首为全角空格。
- 第十一章图 11.1（亲属关系图）只剩图中零散文字，已改为图题与图注两行。
- 小标题靠版面（居中或缩进短行）判定，个别缩进短行的正文可能被当成标题，个别标题（尤其两行的缩进标题）可能并入正文；参考书目中的小标题（如“原始文本”“翻译本”）保留为普通段落。
- 参考书目的编号条目已按行首缩进拆分，各章编号连续无缺；书目与英文引文的空格丢失（如 JacquesTaminiaux、HusserlianaVII）、斜体与引号误识等保持 OCR 原样。
- 人名中的连字符被识别成“一”（列维一斯特劳斯、梅洛一庞蒂、让一弗朗索瓦）、间隔号被识别成“。”或“•”的，已统一订正；其余错字未改。
- 原书注释已按站内格式（注：词语：解释）挂在所注段落后，注码已去掉；个别注释的词语位置为推定。
