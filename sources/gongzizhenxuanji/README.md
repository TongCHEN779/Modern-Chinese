# 龚自珍选集

- 底本：孙钦善选注《龚自珍选集》，人民文学出版社“中国古典文学读本丛书典藏”，2020 年版（前言署 1984 年 5 月）。文字由书籍扫描件（PDF）经 OCR 识别、整理而成，**尚未逐字校对**。
- 整理：分四页——前言（一至五节，末附署名与日期）、诗选、文选、词选；诗每首一节，组诗（《杂诗，己卯……》《戒诗五章》《小游仙词》《己亥杂诗》等）每首另成一节，节名为“组题·其N”（组题去掉“（选五首）”之类的选目说明）；词的题名（如“寄徐二义尊大梁”“道中作”）接在词牌后为“词牌·题名”，词前小序、诗前小序、诗后自注（括号文字）都按原样作为 `原：` 段；《己亥杂诗·其一〇二》后所附“某生与友人书”作为该首的两个 `原：` 段。
- 注释：书中注释集中放在每首（组）诗、每篇文之后，OCR 里以 [1][2]… 标号。按先后顺序把各条注释放回正文里对应标号所在的段后（OCR 数字常有误，如 7 识成 2，故按先后顺序而不按数字对应）；标号对不上的组（见下）改按数字配。每首的“题解”放在正文之前；文的“题解”是正文之后、注释之前不带标号的段落。注释一条一行；一条注释内部含多个词条的用“注原：”保持不拆。注释的词语取原书写法；其中词语与所属段原文对不上的（如词语跨在两个段之间、引号内带拼音）在注释前补了标号所在的几个字作词语。
- 去掉：封面、版权页、目录页、丛书广告、页眉页脚页码。
- OCR 已知问题：
  - 全文稿（full.txt）里个别页的行次错位，本册改用 `json/` 的逐行坐标自行排版，按行首缩进和行尾位置分段。
  - 《杂诗·其六》“从君烧尽虫鱼学”后漏识了一行，据前言引文补回“[7]，甘作东京卖饼家[8]。”。
  - 题名《呜呜硁硁》OCR 作“呜鸣坚”，正文“铿铿”据注中拼音 kēng 改作“硁硁”（前言中的引用同改）；《乙丙之际塾议三》《干禄新书自序》《捕狗蝇蚂蚁蚤蜚蚊虻第三》等篇名据目录与注文取舍。
  - 注释里个别字 OCR 漏识或误识（如《明良论二》注〔3〕“同偷”前漏一字、《尊史》注“，同‘呓’”前漏一字），原样保留。
  - 前言里几处原为右对齐的引文出处（如“《己卯杂诗》其一二。自注：……”）与后文连成一段，未拆开。
