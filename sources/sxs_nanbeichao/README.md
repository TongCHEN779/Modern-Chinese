# 3小时读懂南北朝

- 底本：姜若木编著《3小时读懂南北朝》（“3小时一目了然速读历史故事”丛书），京华出版社，2011 年 4 月第 1 版。文字由书籍扫描件（PDF）经 OCR 识别、整理而成，**尚未逐字校对**。
- 整理：前言一页，南朝四章（刘宋、南齐、萧梁、陈）、北朝三章（北魏、东魏北齐、西魏北周）各一页，附录一至四各一页（共 12 页）。页标题用书中章标题；`pages.json` 第三项按“南朝”“北朝”“附录”分组。页内以书中小标题分节：“一、二、三”级标题与“1. 2. 3.”级标题各为一节；个别章内还有无编号的小标题（西魏北周章“创立府兵制”“六条诏书与革新政治”，北魏章“文明冯太后”下“（一）（二）（三）”三节，附录二“南北朝民歌”等四节），同样各为一节。每章章名下的导语为该页的第一节（节名同页标题）。
- 栏目：每章末尾的“点评”“相关链接”及其下各“某某小传”，栏目名与小传标题都作单独一段，保留在所在节内（最后一个小节的末尾）。
- 附录四（历代皇帝年表）为表格：每行一段，各栏用全角空格隔开（帝位（姓名）　年号（使用年数）　即位时间）。原表中一位皇帝对应多个年号时只在第一行写帝号，整理时每行都补上帝号。
- 去掉：封面、版权页、目录页（目录由站点生成）、“南朝”“北朝”分部扉页、页眉页脚与页码、章扉页插图及图中乱码、各页插图与图片说明（如“萧衍像”“陶牛车(南朝)”）、地图标注文字（北魏章“梁、东魏、西魏对峙形势图”）、PDF 末页的数字化水印页。
- 小标题：书中二级小标题的“一、二、三”编号在版面上多数缺失（OCR 稿只有标题文字），编号按目录补出；标题文字按目录校对。目录与正文把“在内讧中急剧衰落的南齐”识别成“内订”“内江”，已改为“内讧”；正文中“内江”两处同样改为“内讧”，“自已”改为“自己”。
- 小标题缺内容两处：第三章萧梁“三、‘侯景之乱’与梁的衰亡”、附录二“一、文学成就”，在书中下面紧接着是下一级标题，中间没有文字，因此无法单独成节，已把这两个标题作为后一节（“1. 反复无常的侯景”“南北朝民歌”）的第一段保留。

  - “杨日票(biāo)”（萧梁章第一节）等人名读音注疑有识别错误，原样保留；括号全角、半角混用，未统一。
  - 附录四年表：“明帝（~或）”据字形改作“明帝（~彧）”；北魏表“前废帝”处年份“.465”去掉了小数点；西魏“恭帝”一行的年号栏（“—（3）”）OCR 漏识，按原版面补写；西魏、北周中无年号的帝王年号栏为“—”。表中“~”原书用以代替姓氏，原样保留。
