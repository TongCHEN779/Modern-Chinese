# 3小时读懂汉朝

- 底本：姜若木编著《3小时读懂汉朝》（“一目了然速读史”系列），京华出版社，2011 年 4 月第 1 版。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：按书的目录分页：前言一页；第一至第六章各一页（页标题用章标题）；附录“汉王朝的文化成就”一页（末节为“六、汉朝历代皇帝年表”，每行一段，各栏用全角空格隔开）。章内小标题各为一节。每章章首的题辞与导语归在页标题同名的首节。
- 去掉的内容：封面、版权页、目录页、页眉页脚与页码、竖排的章名页眉、插图及其图注、图中文字、地图与流程图上的标注、文末的元数据页。栏目框（“点评”“相关链接”及各“小传”）的文字保留，栏目名单独成段，位置按版面（多在小节末）。
- 段落：用 OCR 行坐标（缩进、行宽）重建自然段，跨行跨页接合；两处项羽、虞姬的歌（垓下歌）按书中分行，每行一段。
- 小标题：书中“一、二、三……”级标题的序号在 OCR 中多半漏识，按书的目录补回；“1.”“2.”级标题的序号用目录的写法统一了空格。小标题序列已与目录逐条对照，无缺漏。
- 更正：“自已”→“自己”（全书各处）、“占为已有”“留为已用”“知已知彼”的“已”→“己”、“敌血为盟”→“歃血为盟”；年表里 OCR 把“刘”识成“～”处按各帝姓名补回，“吕 雉”去掉空格，漏识的“初始(1) 8”“阳嘉(4) 132”“永和(6) 136”据影印页坐标补回。
- OCR 已知问题：其余错字（形近字、个别漏字、标点）未逐一校对；个别括号、引号可能不成对。第 11–12 页（第一章）一幅秦汉书法图中的乱码已整块删去；第 177 页（黄巾起义作战地图）上的地图标注已删去；第 118、176 页插图上的文字残片已删去。书中栏目框与正文紧邻处（如第五章“相关链接”与其后正文、各章末的“小传”）按版面顺序排列，归属节以版面为准，例如“张衡小传”“神医华佗小传”排在“五、佛教传入中国”节末。
