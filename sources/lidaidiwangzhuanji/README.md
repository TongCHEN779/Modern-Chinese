# 历代帝王传记

- 底本：《历代帝王传记》（中国历史小丛书合订本），中华书局 1990 年 1 月第 1 版。文字由书籍扫描件（PDF，467 页）经 OCR 识别、整理而成，**尚未逐字校对**。
- 结构：编者的话一页，其后十三位帝王各一页（秦始皇、汉高祖刘邦、汉文帝、汉武帝、汉光武帝、魏孝文帝、唐太宗、周世宗、宋太祖、元世祖忽必烈、朱元璋、努尔哈赤、康熙皇帝），页标题即书中篇名；各篇作者署名（据书目录：周琤杰、胡大冈、阎应清、范福元、雷大受、肖黎、袁定基、陈开树 王一川、龚延明、曾庆瑛、管玉春 吕武进、胡昭静、商鸿逵）作为该页第一节开头的独立一段；页内“一、二、三”小标题各为一节，宋太祖、康熙两篇中的“（一）（二）…”小标题也另起一节。
- 去掉的内容：封面、版权页、目录页、附录“中国历史小丛书合订本篇目”及书末广告与扫描水印；各篇标题页；历史地图、插图、图版及其图注（如“汉武帝像”“明孝陵石人”“西汉木船模型”“西汉时期的关中水利”图、辽东形势图）；汉光武帝篇中的户口垦田数字表；页码；脚注（页下注文）及正文中的脚注序号（①②…）。书中个别扫描页重复（如宋太祖篇两页内容相同），只保留一份。
- 段落按版面缩进重新接合（跨页、跨行断开的自然段已接上）。
- 朱元璋篇“明王朝的建立和巩固”一节下的四个无编号小标题（登上皇帝宝座、加强中央集权、执行“安养生息”的政策、厉行封建的君主专制），因紧接节标题而不另起节，保留为该节的短段。
- 节名中同行并排的两个部分之间用一个空格隔开（如“一、轻徭薄赋 发展生产”）；“四，迁都大都”据体例改为“四、迁都大都”；宋太祖篇“（一）杯酒释兵权”补回漏识的开引号。
- OCR 已知问题：书中生僻字的汉语拼音注音（如“嫪毐àoǎ”“赢yíng莹〕”“郴ren琛）”）识别得很乱，已保留原样，未改；个别字形近误识（如“土地”识成“上地”）、漏字、标点错位未逐一校正；个别段末缺句号；脚注序号偶有未被识别而无从删除者。
