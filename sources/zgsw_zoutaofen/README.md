## 整理说明
- 书前“前言”为 p01；其后每篇文章一页（p02–p119），页标题用书中篇名；第三项填该篇所属的辑名（爱与人生、忘名、深挚的友谊、风雨香港、萍踪寄语、萧伯纳的夫人，依目录），前言无辑名。
- 各辑首篇页上印有辑名：爱与人生（首篇亦名“爱与人生”）、忘名（首篇“两看的比较”）、深挚的友谊（首篇“工程师的幻想”）、风雨香港（首篇“波动”）、萍踪寄语（首篇“船上的民族意识”）、萧伯纳的夫人（首篇“大骂学校的当代文豪”）。辑名只作为页的分组，不另立页。
- 每篇文末的“（原载……）”出处行、萍踪寄语各篇文末的写作日期地点行均照原书保留为末段。
- 《〈读书偶译〉开头的话》按书中小标题分节（小小缘起、理论和实践的统一、读书尚友、威尔斯的几句话）；《最有益于全世界的老头子》有小标题“喜得说不出话来”，也分节。
- 去掉：封面、扉页、版权页、目录、页眉“邹韬奋散文经典”、页码、末尾空白页和封底。
- 页间断开的段落已接上；半角标点在汉字旁改全角；英文跨行连字符（如 No-bel）已合并。

- 目录中“海上拾零”，正文页首作“海上零拾”，页标题从目录；“月下中流—经苏彝士河”标题的破折号为 OCR 的单横，从正文页首；“开放给大众的休养胜地—克里米亚”正文标题折成两行，已合并为一个标题。
- 部分文章段内的旁注小标题（如《闲暇的伟力》中的“短的闲暇”“格兰斯敦”“法拉台”“虽忙”“心之所好”“现今”，《敏捷准确》《集中的精力》中同类小标题）OCR 与正文连在一起，未能分出，仍保留在段首。
- 版面上印在行间的零星杂字符（“X”“心”“车”等边栏噪点）已删去其中有把握者；个别可能仍有遗漏，英文人名、书名、地名的 OCR 拼写错误（如 Wrihgt、Tannel）原样保留。
