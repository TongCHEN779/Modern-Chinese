# 王贵与李香香

- 底本：李季著《王贵与李香香》，人民文学出版社“百年百种优秀中国文学图书”丛书，2000 年 7 月第 1 版，2001 年 11 月第 2 次印刷。文字由书籍扫描件（PDF）经 OCR 识别、整理而成，未逐字校对。
- 内容：长篇叙事诗《王贵与李香香》三部（各部按书中小节分节），及附录叙事诗《菊花石》（盘歌、第一天、第二天、第三天、尾声，各占一页）。诗行逐行一段；《菊花石》中牧童、采茶女的角色名单独成行。
- 去掉的内容：封面、版权页、作者小传页、丛书前言、评选委员会/编委会名单、丛书书目、丛书宣传页、目录页、页码、页脚作者注释（如“牲灵”“快里马撒”“荷花节”“马日事变”等词语注）及其注号、扫描件水印说明页。
- 整理时的小处理：竖排书名/标题碎片（“菊花石”“盘歌”“尾声”“第一部”）据目录还原；各小节序号与标题粘连处补空格；“老狗入你”两处据上下文改作“老狗日你”；《菊花石》末尾的日期“1950年冬一1951年春”改作破折号。其余保持 OCR 原字，包括“迩刻”“大坏”“—后天就是二十三”等疑似错、漏字处。
