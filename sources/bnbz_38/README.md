# 骆驼祥子

## 底本
老舍《骆驼祥子》，人民文学出版社“百年百种优秀中国文学图书”丛书本（2000年7月第1版，2001年11月第3次印刷），长篇小说，共二十四章。

## 整理说明
- 按书的章次分页：p01–p24 依次为“一”至“二十四”，每章一页一节。
- 去掉：封面、版权页（CIP 数据、印数、定价）、作者小传、丛书前言、评选委员会名单、丛书书目、丛书扉页、页眉页码、每页底部的编者脚注（含正文中的脚注序号①②）、PDF 末尾的 Anna's Archive 水印页。
- 合并了被换页/换行断开的段落，删除孤立的 OCR 噪点（个别单字母、数字）。

## 已知 OCR 问题
- 原 OCR 中第 230 页没有独立标记，其内容（第二十三章末段尾部）已并入前页文字，未发现缺失。
- 未逐字校对，零星形近字错误可能残留（如已更正第二十二章一处“将P把”）；第 17、62、188 页曾夹有孤立噪点，已处理。
- 书中仅有正文，未附其他作品或作者序跋。
