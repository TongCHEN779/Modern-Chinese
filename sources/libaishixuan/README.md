# 李白诗选

- 底本：薛天纬选注《李白诗选》，人民文学出版社“中国古典文学读本丛书典藏”之一，2017 年 10 月第 1 版（CIP 2016）。文字由书籍扫描件（PDF）经 OCR 识别、整理而成（整套丛书合在同一份 OCR 稿里，本册取第 3–662 页），**尚未逐字校对**。
- 整理：去掉封面、版权页、总目录、书末丛书广告与封底；前言（含编选说明）一页，正文按书的七个时期各一页（一 蜀中时期、二 “酒隐安陆”时期及初入长安前后、三 移家东鲁及供奉翰林时期、四 去朝十年、五 从璘及长流夜郎前后、六 晚年、七 未编年），每首诗为一节，共 289 题。
- 体例：每首诗的篇末注释按正文标号放回所属段后；第一条（题下注，标号[1]）作“题解”。诗每段取四句（词取一阕），句间以“/”分行；《赠武十七谔并序》《送张秀才谒高中丞并序》的小序保持为一段原文。一条原注若含数个词语而词语分处不同诗段，按词语拆开分挂在各段，或整条照录（`注原：`）。
- OCR 与整理处理：书中以注释号标记的位置据 OCR 稿恢复，个别注号 OCR 有误者按先后顺序归位；《长门怨二首》《丁督护歌》各缺一条注末尾几行在整理稿中丢失，已据逐页识别 json 补回。`宿鰕湖`、`白鼻騧` 两个题目中的生僻字（OCR 稿作“𫚥”“蜗”、总目录截断）按字形与书中位置改为“鰕”“騧”；“𪩘”“𬨎”改为常用写法“巘”“輶”；总目录里“谢眺”“丛弟”的 OCR 错字按正文题目改作“谢朓”“从弟”。
- 已知问题：少数注释（约 28 条）原注无明确词语或词语跨句，挂在注号所在句末几字上，写作“那几个字：原注全文”；整理稿在 OCR 阶段把部分异体字统一成了通行字（如“徵君”作“征君”），未逐一还原。
