# 中国现代作家选集·朱自清

- 底本：《中国现代作家选集·朱自清》，朱乔森编，叶圣陶序，人民文学出版社、三联书店香港分店联合编辑出版，1985 年 6 月北京第 1 版第 1 次印刷（书号 10019·3804，约 22 万字）。文字由书籍扫描件（PDF，336 页）经 PaddleOCR 识别，按逐页坐标重建行、段而成，**尚未逐字校对**。
- 结构：序（叶圣陶）一页；“新诗”一页（十八题，每题一节，含《匆匆》《歌声》两篇散文诗）；“散文”四十八篇，每篇一页；“旧体诗和词”一页（十六题，每题一节）；“资料部分”五页（叶圣陶《朱佩弦先生》、杨振声《朱自清先生与现代散文》、李广田《朱自清先生的道路》、朱乔森《关于父亲的创作》《朱自清生平著作编年简表》）。《温州的踪迹》《旅行杂记》按书中编号分节；《外东消夏录》按小标题分节；《关于父亲的创作》按书中小标题分节；年表按年份分节，末节“注释”。
- 去掉的内容：封面、版权页、插页照片及图注、手迹页、目次、页眉页脚页码、每页底部的脚注（《桨声灯影里的秦淮河》《温州的踪迹》《航船中的文明》《莱因河》《我所见的叶圣陶》及“挽歌”“重过清华园西院”等诗的作者自注、编者注）、书末 OCR 附带的下载水印页。年表的集中注释保留为末节“注释”，其中第⑩条起原书编号 OCR 未识出，只保留注文。
- 整理中的处理：同一段被换行、换页断开的已接上；诗按原书分行，旧体诗中因版面折行的长句已接回；半角标点在汉字旁改全角；个别 OCR 误成繁体的字改回简体（如“毀、臉、顛、嚇、燻”等）；“晶莹”“迂”“价钱”三处 OCR 单字或噪点有把握更正。《外东消夏录》“成都诗”一节末的年份“一九四。”据影印页改为“一九四一。”，《爱国诗》一节里《一个观念》一题 OCR 漏识书名号和冒号，据上下文补成“《一个观念》：”。《中国学术的大损失》原题下的“——悼闻一多先生”保留为首段，各篇署名（叶圣陶等）保留为首段。
- OCR 已知问题：
  - 破折号“——”常被识成“—”或“—一”，原样保留，未统一。
  - 个别字形近错识未改，如序中叶圣陶所引小诗“一九二一年轻轻地楚过去了”的“楚”字存疑；《温州的踪迹》各小节末的日期照书中印法（“二四，二，一”等）。
  - 《眼睁睁》《勿匆（匆匆）》等标题 OCR 有缺字，页标题与节名按目录和内容订正。
  - 年表中无一九一三至一九一五、一九一八年条目，识别稿中没有，疑原书未列。
  - 《毁灭》全诗分节处（空行）在逐行格式中未标出；《毁灭》诗前小序并为一段。
