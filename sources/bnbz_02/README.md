# 孽海花

- 底本：曾朴著、宇文校注《孽海花》，解放军文艺出版社“百年百种优秀中国文学图书”丛书本，2000 年 7 月第 1 版。文字由 PDF 扫描件经 OCR 识别、整理而成，**尚未逐字校对**。
- 结构：全书三十五回，每回一页，页标题为“第N回 上联 下联”（回目取自目录页；第二十四回目录误作“愤与论”，据正文页眉改“愤舆论”）。书中回目对句的断开位置，在 OCR 目录里未留空格处（第四、十回、三十四回）按对仗推定，其余无空格的按字数对半断开。
- 去掉的内容：封面、版权页、作者简介页、丛书前言/评委会/书目、目录页、页眉页脚、页码；每页底部校注者的注释（带圈数字①②…的脚注）一律删去，正文里的圈数字注码也已去掉；末页的 Anna's Archive 水印页。
- 整理方法：用 json 里的行坐标分行，按首行缩进、行末缩短判断自然段，跨页段落已接上；回内无小标题，每页只有一节。
- 已知 OCR 问题：
  - 人名“陆菶如”被识成“摹如”（约 12 处）、“u如”（约 5 处）、“蓁如”“莘如”，未改动。
  - 书信、告示、诗词等嵌入文字按缩进归并成段，个别行的分段可能与原版式不一致（如第六回的弹词按“解”分段、第十八回的名单）。
  - 个别字形近之误（如“娜狠”“刦”）与脚注标记误识为数字/字母的情况仍有残留。
  - 未发现整回缺失；各页均有对应 OCR 结果，但缺页与漏行未逐页核对。
