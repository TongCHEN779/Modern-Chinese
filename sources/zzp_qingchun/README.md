# 青春的悲哀（张资平情爱作品系列）

- 底本：张资平《青春的悲哀》，“张资平情爱作品系列”之一，宁夏人民出版社 1993 年 6 月第 1 版第 1 次印刷（ISBN 7-227-00980-7/I·218）。文字由书籍扫描件（PDF）经 PaddleOCR 识别、整理而成，**尚未逐字校对**。
- 整理：全书为一篇中篇小说，原书以数字分为三十二章，每章一页，页标题即书中章号“一”至“三十二”（第一章章号原书未印，按次序补；其余章号为 OCR 单独成行识别，三十一个均在，次序连贯）。全书无作者序跋。
- 去掉了：封面、扉页、版权页、系列书目、出版社“编者的话”、责任编辑页、内容简介（均为出版社文字）、页眉“青春的悲哀”及页码。
- 整理时处理：跨页断开的段落按“上页末无句末标点”接上；与页眉黏连的页码数字及混入正文的页码“71”已去除；半角标点在汉字旁改作全角；第三十二章“诊察费”账单按行各为一段，品名与金额以全角空格隔开（OCR 把品名与金额拆成两行，已合并）。
- OCR 已知问题：篇末署款“一九三年十二日抄病后脱稿”应有漏字，保留 OCR 原样；跨页处若上页末恰以句号收尾而下页首句实为接续，未能识别，可能多断一段；个别字形近误识（如“忆恨”“自已”“古慨”）、“Yety hot!”等外文拼写均未改。
